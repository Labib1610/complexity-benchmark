<STATEMENT>
# Problem A — System Observability

Time limit: 5 s   Memory limit: 256 MB

## Description

A laboratory is characterizing a system defined by $n$ unknown scalar variables, $x_1, x_2, \dots, x_n$. 

The objective is to achieve *partial observability* for a critical subset of $t$ target variables. Specifically, the laboratory must be able to uniquely determine the relative difference $(x_i - x_j)$ for every possible pair of target variables $i$ and $j$.

The variables cannot be measured directly. Instead, the laboratory can purchase pairwise differential measurements. There are $m$ available candidate measurements. 
The $k$-th candidate measurement involves variables $u$ and $v$. If purchased, it yields a linear equation of the form $x_u - x_v = C_k$, where $C_k$ is the observed constant. Purchasing this measurement incurs a financial cost of $w$. 

You may choose any subset of the candidate measurements to purchase. The purchased measurements collectively form a system of linear equations. The target differences must be mathematically deducible (uniquely determined) from this system alone.

Determine the minimum total cost to purchase a subset of measurements that provides enough information to uniquely determine the difference between every pair of the $t$ target variables.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the indices of the target variables.
Each of the subsequent $m$ lines specifies an available candidate measurement using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u$ ≠ $v$, 1 ≤ $w$ ≤ 1000000). This indicates a measurement providing the difference between $x_u$ and $x_v$ for a cost of $w$.
It is guaranteed that purchasing all available measurements would be sufficient to determine the differences between all target variables.

## Output

Print a single integer: the minimum total cost required to ensure the differences between all target variables are uniquely determined.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, purchasing the measurements involving the non-target variable 4 (which cost 1, 1, and 1; total cost = 3) yields the equations $x_1 - x_4 = C_1$, $x_2 - x_4 = C_2$, and $x_3 - x_4 = C_3$. From these, we can uniquely determine $x_1 - x_2 = C_1 - C_2$, $x_2 - x_3 = C_2 - C_3$, and $x_1 - x_3 = C_1 - C_3$. This is cheaper than purchasing the direct measurements between the three target variables (which would cost 4).
In Example 3, there is only a single target variable. The difference between a variable and itself is trivially 0 and requires no equations to determine, resulting in a total cost of 0.

<RATIONALE>
I changed the domain from "merging pools" (which strongly hints at equivalence classes and connected components) to achieving partial observability in a system of linear equations. This forces the model to mathematically deduce that variables are mutually observable if and only if they are connected by a path of measurements, breaking superficial pattern-matching to graph algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
The exact difference between two variables in a system of pairwise differential equations is uniquely determined if and only if they belong to the same connected component of the measurement graph, making this mathematically identical to finding the minimum cost to connect the target nodes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The requirement to connect a specific subset of $t$ vertices in a weighted graph using minimum total weight is exactly the Minimum Steiner Tree problem, keeping it NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "uniquely determined" if they do not recognize the standard linear algebra definition of observability, but the mathematical meaning of deducing a value from a system of equations is rigorously unambiguous.
</RISK>
