<STATEMENT>
# Matrix Exponential Configuration

Time limit: 5 s   Memory limit: 256 MB

## Description

A computational engineering team is configuring an $n \times n$ system matrix $M$. Initially, $M$ is set to the $n \times n$ identity matrix (entries on the main diagonal are 1, and all other entries are 0). The team is focused on a specific subset of $t$ critical indices.

They have a list of $m$ available symmetric updates. Each available update is defined by a pair of indices $u$ and $v$ ($u \neq v$) and a one-time activation cost $w$. Each available update is either selected or not selected. If an update is selected, its cost $w$ is paid, and the team adds 1 to the matrix entry $M_{u,v}$ and adds 1 to the entry $M_{v,u}$. The total cost is the sum of the activation costs of the selected updates.

After all selected updates are applied to the matrix $M$, the team analyzes the resulting matrix exponential $E$, which is mathematically defined by the infinite series:
$$E = \sum_{k=0}^\infty \frac{M^k}{k!}$$

Their objective is to ensure that for every pair of critical indices $i$ and $j$ (including when $i = j$), the corresponding entry in the matrix exponential is strictly positive (i.e., $E_{i,j} > 0$).

The team is permitted to select updates involving non-critical indices, provided their inclusion helps achieve the required condition for the critical indices. 

Determine the minimum total activation cost required to select a set of updates such that the resulting matrix exponential satisfies $E_{i,j} > 0$ for all critical indices $i$ and $j$.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the critical indices.
Each of the subsequent $m$ lines specifies an available update using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u$ ≠ $v$, 1 ≤ $w$ ≤ 1000000). This indicates an update between indices $u$ and $v$ with an activation cost of $w$.
It is guaranteed that selecting all $m$ available updates would be sufficient to satisfy the objective.

## Output

Print a single integer: the minimum total activation cost required to ensure $E_{i,j} > 0$ for all pairs of critical indices $i$ and $j$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the updates that involve the non-critical index 4 (which require costs of 1, 1, and 1; total cost = 3) is more efficient than selecting the updates directly involving only the three critical indices (which would result in a total cost of 4). By applying the updates for $(1,4)$ and $(2,4)$, the matrix $M$ gains positive entries such that the infinite series yields $E_{1,2} > 0$. Including the update for $(3,4)$ ensures that $E_{1,3} > 0$ and $E_{2,3} > 0$ as well, fulfilling the requirement for all critical indices. 
In Example 3, there is only a single critical index. The requirement $E_{1,1} > 0$ is inherently satisfied because the initial identity matrix guarantees strictly positive diagonal entries in $E$, so no updates need to be selected, resulting in a total cost of 0.

<PRESERVED_ANSWER>
Because $M = I + A$ where $A$ is the non-negative symmetric matrix of selected updates, $(M^k)_{i,j} > 0$ if and only if there is a walk of length $k$ between $i$ and $j$; thus $E_{i,j} > 0$ is mathematically identical to $i$ and $j$ being in the same connected component, preserving all minimum-cost subset solutions.
