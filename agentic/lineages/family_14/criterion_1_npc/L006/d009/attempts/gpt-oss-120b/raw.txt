**Solution Explanation**

For the given undirected weighted graph we have to choose a set of edges with
minimum total weight such that all *critical* vertices become mutually
reachable.
The problem is exactly the **Steiner Tree** problem with at most `t ≤ 10`
terminals, therefore a classic DP over subsets of terminals solves it
comfortably.

--------------------------------------------------------------------

#### 1.   DP definition  

`mask` – bitmask of terminals already connected (`0 … (1<<t)-1`)  
`v`    – a vertex of the whole graph (`0 … n-1`)

`dp[mask][v]` = minimum cost of a tree

* that connects **all terminals whose bits are set in `mask`**,
* and whose **root (any vertex of the tree) is `v`**.

The answer will be  

```
min_v dp[ALL][v]          (ALL = (1<<t)-1)
```

--------------------------------------------------------------------

#### 2.   Initialisation  

For every single terminal `i`

```
mask = 1<<i
dp[mask][terminal_i] = 0          # no edge is needed, the tree consists of the vertex itself
```

All other entries are `INF`.

--------------------------------------------------------------------

#### 3.   Merging two already built sub‑trees  

If a tree for `mask1` and a tree for `mask2` (disjoint masks) are already known,
they can be merged at the same vertex `v` :

```
dp[mask1|mask2][v] = min( dp[mask1][v] + dp[mask2][v] )
```

For a fixed `mask` we try **all** proper non‑empty sub‑masks `sub`
(`sub ⊂ mask`).  
The complementary part is `mask ^ sub`.  
The merging step is performed **before** we spread the distances through the
graph (see next section).

Complexity of the merging step  

```
∑_{mask}  (number of sub‑masks of mask) * n   =   O(3^t * n)
```

With `t ≤ 10` this is below 6·10⁶ operations.

--------------------------------------------------------------------

#### 4.   Propagation through the graph  

After merging, `dp[mask][v]` is the cheapest cost of a tree that already ends
in `v`.  
We may extend this tree by adding ordinary graph edges.
That is exactly a **single‑source shortest‑path** problem where the initial
distances are the current `dp[mask][*]`.

We run Dijkstra (edge weights are non‑negative) with all vertices whose
distance is finite as starting points.

```
while heap not empty:
        (d,u) = pop
        if d != dp[mask][u]: continue
        for (v,w) in adj[u]:
                nd = d + w
                if nd < dp[mask][v]:
                        dp[mask][v] = nd
                        push (nd,v)
```

After Dijkstra finishes, `dp[mask][v]` equals the cheapest cost of a tree that
connects the terminals of `mask` and ends in `v`, possibly using any
non‑terminal vertices as Steiner points.

Complexity per mask: `O( (n+m) log n )`.  
With at most `2^t = 1024` masks this easily fits into the limits.

--------------------------------------------------------------------

#### 5.   Whole algorithm  

```
read input
build adjacency list
dp = [[INF]*n for _ in range(1<<t)]

for each terminal i:
        dp[1<<i][terminal_i] = 0

for mask = 1 … (1<<t)-1:
        # 1) merge smaller masks
        sub = (mask-1) & mask
        while sub:
                other = mask ^ sub
                for v in 0..n-1:
                        dp[mask][v] = min(dp[mask][v],
                                          dp[sub][v] + dp[other][v])
                sub = (sub-1) & mask

        # 2) Dijkstra to spread through the graph
        heap = all (dp[mask][v], v) with dp[mask][v] < INF
        run Dijkstra as described

answer = min(dp[ALL][v] for v in 0..n-1)
print(answer)
```

The algorithm is exact, runs in  

```
O( 3^t * n + 2^t * (n+m) log n )   ≤   a few 10⁷ operations
```

and uses `O( 2^t * n )` memory (`≈ 10⁵` integers).

--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total activation cost.

---

##### Lemma 1  
For every mask and vertex `v`, after the Dijkstra step finishes,
`dp[mask][v]` equals the minimum cost of a **connected subgraph**
that

* contains all terminals of `mask`,
* contains vertex `v`,
* and whose total edge weight is minimal among all such subgraphs.

**Proof.**  
Induction over the order in which masks are processed.

*Base (`mask` with a single bit).*  
`dp[mask][terminal] = 0` and all other vertices are `INF`.  
Running Dijkstra computes the shortest path distances from that terminal to
every vertex, i.e. the cheapest way to connect the terminal with `v`.  
Thus the statement holds.

*Induction step.*  
Assume the statement true for all proper sub‑masks of `mask`.  
Before Dijkstra we performed the merging step:

```
dp'[mask][v] = min_{sub ⊂ mask} ( dp[sub][v] + dp[mask^sub][v] )
```

By the induction hypothesis each term `dp[sub][v]` (resp. `dp[mask^sub][v]`)
is the optimum cost of a tree that connects the terminals of `sub` (resp.
`mask^sub`) and ends in `v`.  
Their sum is the cost of the union of the two trees; the union is a connected
subgraph that contains all terminals of `mask` and also `v`.  
Taking the minimum over all `sub` yields the cheapest such subgraph **that
already contains `v`** (no extra edges outside the two trees).

Now Dijkstra adds arbitrary graph edges to the current subgraph.
Running Dijkstra with initial distances `dp'[mask][*]` computes for each
vertex `x` the cheapest cost of a subgraph that

* already contains a cheapest subgraph for some vertex `v` (cost `dp'[mask][v]`),
* plus a shortest path from `v` to `x`.

Consequently the resulting distance `dp[mask][x]` is the minimum possible
cost of a connected subgraph that contains all terminals of `mask` and the
vertex `x`. ∎



##### Lemma 2  
For every mask, after its processing `dp[mask][v]` is the minimum possible
cost of a Steiner tree that connects exactly the terminals of `mask` and has
`v` as a designated root.

**Proof.**  
A Steiner tree is a connected subgraph that may contain extra (Steiner)
vertices. Lemma&nbsp;1 already states that `dp[mask][v]` is the cheapest
connected subgraph with the required terminals and containing `v`.  
Any connected subgraph can be reduced to a tree without increasing its total
weight (remove cycles). Therefore the optimum value is attained by a tree,
i.e. a Steiner tree. ∎



##### Lemma 3  
Let `ALL` be the mask containing all `t` terminals.
`min_v dp[ALL][v]` equals the minimum possible total activation cost of a set
of edges that makes all critical sites mutually accessible.

**Proof.**  
By Lemma&nbsp;2, for each vertex `v` the value `dp[ALL][v]` is the cheapest
cost of a Steiner tree that connects all terminals (the whole set) and has
`v` as a root.  
Any feasible set of activated edges must contain a connected subgraph that
covers all terminals; a minimum‑cost feasible set can be reduced to a tree,
hence its cost is at least `min_v dp[ALL][v]`.  
Conversely, the tree achieving the minimum is a feasible set of edges, so the
minimum is attainable. ∎



##### Theorem  
The algorithm outputs the minimum total activation cost required to make
every pair of critical sites mutually accessible.

**Proof.**  
The algorithm processes all masks, in particular `ALL`.  
By Lemma&nbsp;2 the DP values after processing `ALL` are optimal for each root.
By Lemma&nbsp;3 the minimum over all roots equals the optimum overall cost.
The algorithm prints exactly this value. ∎

#### 7.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10 ** 18

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    terminals = [int(next(it)) - 1 for _ in range(t)]

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    full = 1 << t
    dp = [[INF] * n for _ in range(full)]

    for i, node in enumerate(terminals):
        dp[1 << i][node] = 0

    for mask in range(1, full):
        # combine smaller masks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            # combine only once per unordered pair to avoid redundant work
            # (optional optimisation, not required for correctness)
            for v in range(n):
                val = dp[sub][v] + dp[other][v]
                if val < dp[mask][v]:
                    dp[mask][v] = val
            sub = (sub - 1) & mask

        # Dijkstra to spread through the graph
        heap = [(dp[mask][v], v) for v in range(n) if dp[mask][v] < INF]
        heapq.heapify(heap)
        while heap:
            d, u = heapq.heappop(heap)
            if d != dp[mask][u]:
                continue
            for v, w in adj[u]:
                nd = d + w
                if nd < dp[mask][v]:
                    dp[mask][v] = nd
                    heapq.heappush(heap, (nd, v))

    ans = min(dp[full - 1])
    print(ans)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
