We can solve this by treating it as a **Steiner tree** problem, but since the number of critical sites is small (≤ 10), we can use a **bitmask DP** approach.

We’ll:
1. Run **Floyd–Warshall** to get shortest paths between all pairs of nodes.
2. Use **DP over subsets of critical sites**:
   - `dp[mask][v]` = minimum cost to connect the critical sites in `mask` with the tree rooted at node `v`.
   - Initialize for each critical site `c`: `dp[1 << idx][c] = 0`.
   - Combine subsets: `dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[mask ^ sub][v])`.
   - Relax using shortest paths: `dp[mask][v] = min(dp[mask][v], dp[mask][u] + dist[u][v])`.
3. The answer is `min(dp[full_mask][v])` over all `v`.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    critical = list(map(int, input().split()))
    critical = [x - 1 for x in critical]  # 0-based

    INF = 10**18
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w

    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    full_mask = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    # Initialize for single critical sites
    for i, c in enumerate(critical):
        dp[1 << i][c] = 0

    # DP over subsets
    for mask in range(1, 1 << t):
        # Combine subsets
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other < sub:  # avoid duplicate work
                for v in range(n):
                    if dp[sub][v] + dp[other][v] < dp[mask][v]:
                        dp[mask][v] = dp[sub][v] + dp[other][v]
            sub = (sub - 1) & mask

        # Relax via shortest paths
        # Run Dijkstra-like relaxation using dist matrix
        for _ in range(n):
            updated = False
            for u in range(n):
                for v in range(n):
                    if dp[mask][u] + dist[u][v] < dp[mask][v]:
                        dp[mask][v] = dp[mask][u] + dist[u][v]
                        updated = True
            if not updated:
                break

    ans = min(dp[full_mask])
    print(ans)

if __name__ == "__main__":
    solve()
```
