# Basis-Difference Subspace Synthesis

Time limit: 5 s   Memory limit: 256 MB

## Description

You are working with the vector space $\mathbb{R}^n$, which has standard basis vectors $e_1, e_2, \dots, e_n$. A target subset of $t$ critical indices is specified.

You can purchase a selection from $m$ available basis-difference vectors. Each available vector is formed by a specific pair of indices $u$ and $v$, defined as $x = e_u - e_v$, and has a one-time cost $w$. (Because we are only concerned with the linear span, the sign of the vector does not matter; $e_u - e_v$ and $e_v - e_u$ span the same one-dimensional subspace).

Your objective is to select a subset of these available vectors such that their linear span contains the vector $e_i - e_j$ for every pair of critical indices $i$ and $j$.

You may select vectors involving non-critical indices if their inclusion helps span the required differences between the critical indices. Each available vector is either selected or not, and its cost is paid exactly once if selected. The total cost is the sum of the costs of the distinct vectors you choose to select.

Determine the minimum total cost required to select a set of vectors such that the target condition is satisfied.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n \cdot (n−1)/2$).
The second line lists $t$ distinct integers representing the critical indices.
Each of the subsequent $m$ lines specifies an available vector using three integers $u$, $v$, and $w$ (1 ≤ $u, v$ ≤ $n$, $u \neq v$, 1 ≤ $w$ ≤ 1000000). This indicates an available vector $e_u - e_v$ with a cost of $w$.
It is guaranteed that the set of all $m$ available vectors is sufficient to satisfy the requirement for all critical indices.

## Output

Print a single integer: the minimum total cost required to ensure $e_i - e_j$ is in the linear span of the selected vectors for all pairs of critical indices $i$ and $j$.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the vectors that involve the non-critical index 4 (which require costs of 1, 1, and 1; total cost = 3) is more efficient than selecting the vectors directly involving only the three critical indices (which would result in a total cost of 4). The vectors $e_1 - e_4$ and $e_2 - e_4$ span $e_1 - e_2$ because $(e_1 - e_4) - (e_2 - e_4) = e_1 - e_2$. Including $e_3 - e_4$ ensures the required difference vectors are spanned for all pairs among the critical indices 1, 2, and 3. Thus, index 4 acts as an effective intermediary. 
In Example 3, there is only a single critical index. The requirement that $e_1 - e_1 = 0$ is in the span is inherently satisfied by the empty set of vectors. Therefore, no vectors need to be selected, resulting in a total cost of 0.

<PRESERVED_ANSWER>
The linear span of a set of vectors $e_u - e_v$ contains $e_i - e_j$ if and only if $i$ and $j$ are in the same connected component of the graph formed by the edges $(u,v)$; thus, the optimization objective remains identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Finding the minimum-weight subset of edges to connect a given subset of vertices is exactly the NP-complete Steiner Tree problem in graphs, which perfectly matches the minimum-cost subspace synthesis formulation.
</PRESERVED_CLASS>
