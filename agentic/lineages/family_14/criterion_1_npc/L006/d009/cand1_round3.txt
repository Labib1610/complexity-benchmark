<METHOD_NAME>Topological Connectivity Formulation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the power-series/graph-connectivity condition with an equivalent topological condition using "isolated subsets" (clopen sets). A subset is isolated if no activated update crosses its boundary. The objective is that no isolated subset contains a proper, non-empty subset of the critical variables. This perfectly encodes "all critical variables are in the same connected component" without using any graph reachability terms, forcing the model to deduce the connectivity requirement from first principles.</METHOD_DESCRIPTION>

<STATEMENT>
# Component Synchronization Network

Time limit: 5 s   Memory limit: 256 MB

## Description

A data engineering team is configuring a system of $n$ continuous feature variables, indexed 1 through $n$. The team is focused on a specific subset of $t$ critical variables.

The team can activate a selection from $m$ available bidirectional updates. Each available update acts on a specific pair of variables $u$ and $v$, and has a one-time activation cost $w$.

When a subset of updates is activated, it imposes a structural grouping on the system. A subset of variables $X$ is defined as *isolated* with respect to the selected updates if no activated update acts on one variable inside $X$ and one variable outside $X$. (Note that the empty set and the set of all $n$ variables are always considered isolated because there are no variables outside or inside them, respectively, to form such a boundary).

The team's objective is to choose a set of updates to activate such that no isolated subset of variables contains at least one, but not all, of the $t$ critical variables. In other words, every isolated subset must either contain all $t$ critical variables, or contain none of them.

The team is permitted to activate updates involving non-critical variables, provided their inclusion helps satisfy the objective. Each available update is either selected for activation or not selected. If selected, its activation cost is paid exactly once. The total cost is the sum of the activation costs of the distinct updates the team chooses to activate.

Determine the minimum total activation cost required to select a set of updates that satisfies the isolation condition for the critical variables.

## Input

The first line provides three integers $n$, $m$, and $t$ ($1 \le t \le 10$, $1 \le n \le 100$, $0 \le m \le n(n-1)/2$).
The second line lists $t$ distinct integers representing the indices of the critical variables.
Each of the subsequent $m$ lines specifies an available update using three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $u \neq v$, $1 \le w \le 1000000$). This indicates an update between variables $u$ and $v$ with a one-time activation cost of $w$.
It is guaranteed that the set of all $m$ available updates is sufficient to satisfy the requirement for all critical variables.

## Output

Print a single integer: the minimum total activation cost required to ensure that no isolated subset of variables contains at least one, but not all, of the critical variables.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating the updates that involve the non-critical variable 4 (which require costs of 1, 1, and 1; total cost = 3) is more efficient than activating the updates directly involving only the three critical variables (which would result in a total cost of 4). Activating updates (1, 4), (2, 4), and (3, 4) ensures that any isolated subset containing variable 1 must also contain variable 4, and therefore variables 2 and 3. Thus, no isolated subset can contain just one or two of the critical variables {1, 2, 3}. Variable 4 acts as an effective intermediary. 

In Example 3, there is only a single critical variable ($t=1$). The requirement is that no isolated subset contains at least one but not all critical variables. Since "not all" would mean 0 critical variables, which contradicts "at least one", the condition is inherently satisfied regardless of which updates are selected. Therefore, no updates need to be activated, resulting in a total cost of 0.
</STATEMENT>
<RATIONALE>
The power-series matrix positivity condition in the seed was a direct mathematical formulation of graph connectivity, which models easily reduced to a Steiner tree. To prevent this surface-level mapping while maintaining the exact same semantics, I replaced the reachability definition with a topological one. The problem now defines "isolated subsets" (clopen sets in the graph's topology) and requires that no isolated subset properly partitions the critical variables. This forces the model to mathematically prove that the condition is equivalent to requiring all critical variables to belong to the same connected component.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that no isolated subset cleanly separates the critical variables is mathematically identical to requiring that all critical variables lie in the same connected component, so the set of valid update subsets and their minimum cost is exactly the same for every input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on an undirected graph, preserving its NP-Complete complexity class.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "isolated subset" as requiring the subset to have no internal edges, but the phrasing "no activated update acts on one variable inside X and one variable outside X" strictly defines it as a boundary condition, which is standard and unambiguous.
</RISK>
