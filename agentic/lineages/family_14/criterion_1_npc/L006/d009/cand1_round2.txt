<METHOD_DESCRIPTION>Replaces the power-series reachability condition with the requirement that the relative load vector e_i - e_j lies in the column space of the stiffness matrix K (which mathematically acts as the Laplacian matrix of the selected subgraph). <STATEMENT>
# Framework Stiffness Configuration

Time limit: 5 s   Memory limit: 256 MB

## Description

A structural engineering firm is designing a framework with $n$ joints, indexed 1 through $n$. The firm is focused on a specific subset of $t$ critical joints.

The firm can install a selection from $m$ available bidirectional struts. Each available strut connects a specific pair of joints $u$ and $v$, and has a one-time installation cost $w$.

If the firm selects a subset of these struts to install, they construct an $n \times n$ stiffness matrix $K$ as follows:
- $K_{x,x}$ is the total number of installed struts connected to joint $x$.
- $K_{u,v} = K_{v,u} = -1$ if the available strut between $u$ and $v$ is installed.
- All other entries of $K$ are $0$.

The firm's objective is to select a subset of struts such that for every pair of critical joints $i$ and $j$, the relative load vector $F = e_i - e_j$ is in the column space of $K$. (Here, $e_k$ is the $n$-dimensional standard basis vector with a 1 at position $k$ and 0 elsewhere). This condition ensures that the structural system can support a relative load between any two critical joints, as there will exist a displacement vector $d$ satisfying $K d = e_i - e_j$.

The firm is permitted to install struts involving non-critical joints, as these may serve as cost-effective intermediaries to establish the required condition. Each available strut is either installed or not. If installed, its installation cost is paid exactly once. The total cost is the sum of the installation costs of the distinct struts the firm chooses to install.

Determine the minimum total installation cost required to select a set of struts such that the condition is satisfied for all pairs of critical joints $i$ and $j$.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the indices of the critical joints.
Each of the subsequent $m$ lines specifies an available strut using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u$ ≠ $v$, 1 ≤ $w$ ≤ 1000000). This indicates a strut between joints $u$ and $v$ with a one-time installation cost of $w$.
It is guaranteed that installing all $m$ available struts is sufficient to satisfy the requirement for all critical joints.

## Output

Print a single integer: the minimum total installation cost required to ensure the relative load vector $e_i - e_j$ is in the column space of $K$ for all pairs of critical joints $i$ and $j$ under the installed struts.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, installing the struts that connect to the non-critical joint 4 (which require costs of 1, 1, and 1; total cost = 3) is more efficient than installing the struts directly involving only the three critical joints (which would result in a total cost of 4). With struts (1, 4) and (2, 4) installed, the relative load $e_1 - e_2$ is in the column space of $K$. Adding the strut between (3, 4) ensures the condition holds for all pairs among the critical joints 1, 2, and 3. Thus, joint 4 acts as an effective intermediary. 
In Example 3, there is only a single critical joint. The requirement that $e_1 - e_1 = 0$ is in the column space of $K$ is inherently satisfied because the zero vector is in the column space of any matrix, regardless of which struts are installed. Therefore, no struts need to be installed, resulting in a total cost of 0.

<RATIONALE>
The problem was reframed using structural engineering and finite element analysis concepts. The connectivity requirement was replaced with the condition that the relative load vector e_i - e_j must be in the column space of the stiffness matrix K (which is mathematically the Laplacian matrix of the selected subgraph). This forces models to logically deduce the equivalence between the column space of a Laplacian matrix and graph connected components, rather than relying on surface-level graph vocabulary like "paths" or "reachability".
</RATIONALE>
<PRESERVED_ANSWER>
A vector e_i - e_j is in the column space of the Laplacian matrix K if and only if vertices i and j are in the same connected component; thus, minimizing the cost to satisfy this for all target vertices is exactly the same Steiner Tree optimization as the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical task remains finding a minimum-cost subgraph that connects a specific subset of terminals, which is exactly the NP-complete Steiner Tree problem.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the condition K d = e_i - e_j as a continuous optimization problem over real-valued vectors d rather than recognizing it as a discrete property of the chosen struts, though the text explicitly asks to select a subset of struts.
</RISK>
