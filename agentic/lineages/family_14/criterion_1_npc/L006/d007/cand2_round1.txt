<STATEMENT>
# Problem A — Feature Subspace Projection

Time limit: 5 s   Memory limit: 256 MB

## Description

A machine learning engineer is designing a dimensionality reduction pipeline for $n$-dimensional data points $(x_1, x_2, \dots, x_n)$. The engineer is focused on a specific subset of $t$ critical coordinates.

The objective is to define a linear subspace $S$ such that for any point $p \in S$, the values of all $t$ critical coordinates are strictly identical. That is, for any point $(x_1, \dots, x_n)$ in $S$, the coordinate $x_a$ must exactly equal $x_b$ for all $a, b$ in the critical subset.

To construct this subspace, the engineer starts with the full $n$-dimensional space $\mathbb{R}^n$ and repeatedly intersects it with available constraint hyperplanes. There are $m$ available hyperplanes to choose from. Each available hyperplane is defined by the condition that the $u$-th and $v$-th coordinates are equal ($x_u = x_v$). 

The engineer is permitted to intersect with hyperplanes involving non-critical coordinates, provided their inclusion restricts the subspace to satisfy the objective. Each available hyperplane is either selected for intersection or not. If selected, its computational penalty $w$ is paid exactly once. 

Determine the minimum total computational penalty required to select a set of constraint hyperplanes such that their intersection forms a subspace where all points have equal values across all $t$ critical coordinates.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the indices of the critical coordinates.
Each of the subsequent $m$ lines specifies an available constraint hyperplane using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u \neq v$, 1 ≤ $w$ ≤ 1000000). This indicates a hyperplane enforcing equality between the $u$-th and $v$-th coordinates, with a one-time computational penalty of $w$.
It is guaranteed that the set of all $m$ available hyperplanes is sufficient to satisfy the objective.

## Output

Print a single integer: the minimum total computational penalty required to ensure all points in the resulting subspace have identical values at the critical coordinates.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the hyperplanes that involve the non-critical coordinate 4 (which require penalties of 1, 1, and 1; total penalty = 3) is more efficient than selecting the hyperplanes directly involving only the three critical coordinates (which would result in a total penalty of 4). The intersection of the hyperplane enforcing equality between coordinates 1 and 4, and the hyperplane for coordinates 2 and 4, results in a subspace where coordinate 1 equals coordinate 2. Intersecting further with the hyperplane for coordinates 3 and 4 restricts the subspace such that coordinates 1, 2, 3, and 4 are all equal. Thus, coordinate 4 acts as an effective intermediary. 
In Example 3, there is only a single critical coordinate. The requirement is already satisfied by the full $n$-dimensional space, so no hyperplanes need to be selected, resulting in a total penalty of 0.

<RATIONALE>
The previous framing used permutation groups and orbits, which the surviving model successfully mapped to paths in a graph (since an orbit generated by transpositions is exactly the connected components). By completely changing the domain to continuous Euclidean geometry and intersecting linear subspaces, we remove all combinatorial vocabulary (paths, sequences, mappings, operators). The model must now independently deduce that intersecting hyperplanes of the form $x_u = x_v$ algebraically reduces to finding a connected component in a graph, forcing genuine mathematical reasoning over pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The intersection of hyperplanes of the form $x_u = x_v$ forms a subspace where coordinates are constant exactly on the connected components of the graph formed by the selected pairs; thus, requiring $x_a = x_b$ for all target coordinates is mathematically identical to connecting all target vertices in the graph, keeping all costs and optimal selections identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the Minimum Steiner Tree problem on an undirected weighted graph, which is NP-complete.
</PRESERVED_CLASS>
