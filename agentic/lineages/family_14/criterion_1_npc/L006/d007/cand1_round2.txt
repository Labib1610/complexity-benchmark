<STATEMENT>
# Problem A — Algebraic Ideal Configuration

Time limit: 5 s   Memory limit: 256 MB

## Description

A computational algebra system is working with the commutative ring $R = \mathbb{R}[z_1, z_2, \dots, z_n]$ of formal expressions over $n$ indeterminates, indexed 1 through $n$. The system must secure a specific property for a subset of $t$ core indeterminates.

The objective is to select a set of generators $S$ such that for any two core indeterminates $z_a$ and $z_b$, their difference $z_a - z_b$ belongs to the ideal $I = \langle S \rangle$ generated by $S$.

To achieve this, the system can choose from $m$ available difference binomials. Each available binomial is of the form $z_u - z_v$. 

The ideal $I = \langle S \rangle$ generated by the chosen set $S$ is the set of all finite sums $\sum f_k g_k$, where $g_k \in S$ and $f_k \in R$. The system's requirement is that the difference between every pair of core indeterminates must be contained within this single generated ideal $I$.

The system is permitted to include binomials involving non-core indeterminates in $S$, provided their inclusion helps satisfy the ideal membership requirement for the core indeterminates. Each available binomial is either selected for inclusion in $S$ or not selected. If selected, its inclusion cost is paid exactly once. 

Each available binomial has a fixed inclusion cost, $w$. The total cost is the sum of the inclusion costs of the distinct binomials the system chooses to include in $S$.

Determine the minimum total inclusion cost required to select a generating set $S$ such that all pairwise differences of the $t$ core indeterminates are in the generated ideal $I = \langle S \rangle$.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the indices of the core indeterminates.
Each of the subsequent $m$ lines specifies an available binomial using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u$ ≠ $v$, 1 ≤ $w$ ≤ 1000000). This indicates a binomial $z_u - z_v$ with a one-time inclusion cost of $w$.
It is guaranteed that the set of all $m$ available binomials is sufficient to satisfy the ideal membership requirement for all core indeterminates.

## Output

Print a single integer: the minimum total inclusion cost required to ensure the difference of any two core indeterminates belongs to the generated ideal.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, selecting the binomials that involve the non-core indeterminate $z_4$ (which require costs of 1, 1, and 1; total cost = 3) is more efficient than selecting the binomials directly involving only the three core indeterminates (which would result in a total cost of 4). The binomials $z_1 - z_4$ and $z_2 - z_4$ generate an ideal containing their difference $(z_1 - z_4) - (z_2 - z_4) = z_1 - z_2$. Including $z_3 - z_4$ ensures $z_1 - z_3$ and $z_2 - z_3$ are also in the ideal. Thus, $z_4$ acts as an effective intermediary. 
In Example 3, there is only a single core indeterminate. The pairwise difference requirement is vacuously satisfied (the difference of the core indeterminate with itself is 0, which is always in the ideal), so no binomials need to be selected, resulting in a total cost of 0.
