<STATEMENT>
# Feature Consistency Modeling

Time limit: 5 s   Memory limit: 256 MB

## Description

A data engineering team is configuring a system of $n$ continuous feature variables, indexed 1 through $n$. The team is focused on a specific subset of $t$ critical variables.

Their objective is to ensure that all critical variables are mathematically forced to take the exact same value as one another, regardless of the system's initial state.

To achieve this, the team can activate a selection from $m$ available bidirectional consistency constraints. Each available constraint acts on the feature variables by enforcing a strict equality between a specific pair of variables $u$ and $v$ (meaning $u = v$). 

By the transitive property of equality, if we consider the system of equations generated by the selected constraints, two variables are guaranteed to be equal if and only if one can be proven equal to the other by some sequence of the selected constraints. The team's requirement is that the entire subset of $t$ critical variables must be mutually equal under the generated system of equations.

The team is permitted to activate constraints involving non-critical variables, provided their inclusion helps establish the required equalities among the critical variables. Each available constraint is either selected for activation or not selected. If selected, its activation cost is paid exactly once. 

Each constraint has a fixed activation cost, $w$. The total cost is the sum of the activation costs of the distinct constraints the team chooses to activate.

Determine the minimum total activation cost required to select a set of constraints such that all $t$ critical variables are forced to be equal by the resulting system of equations.

## Input

The first line provides three integers $n$, $m$, and $t$ (1 ≤ $t$ ≤ 10, 1 ≤ $n$ ≤ 100, 0 ≤ $m$ ≤ $n$·($n$−1)/2).
The second line lists $t$ distinct integers representing the indices of the critical variables.
Each of the subsequent $m$ lines specifies an available constraint using three integers $u$, $v$, and $w$ (1 ≤ $u$, $v$ ≤ $n$, $u$ ≠ $v$, 1 ≤ $w$ ≤ 1000000). This indicates a constraint enforcing equality between variables $u$ and $v$ with a one-time activation cost of $w$.
It is guaranteed that the set of all $m$ available constraints is sufficient to force all critical variables to be equal.

## Output

Print a single integer: the minimum total activation cost required to ensure all critical variables are forced to be equal under the selected constraints.

## Examples

### Example 1

**Input**
```
4 6 3
1 2 3
1 4 1
2 4 1
3 4 1
1 2 2
2 3 2
1 3 2
```

**Output**
```
3
```

### Example 2

**Input**
```
4 4 3
1 2 3
1 2 1
2 3 1
1 4 10
3 4 10
```

**Output**
```
2
```

### Example 3

**Input**
```
3 2 1
1
1 2 5
2 3 5
```

**Output**
```
0
```

## Note

In Example 1, activating the constraints that involve the non-critical variable 4 (which require costs of 1, 1, and 1; total cost = 3) is more efficient than activating the constraints directly involving only the three critical variables (which would result in a total cost of 4). The equalities $1 = 4$ and $2 = 4$ generate a system where 1, 2, and 4 are equal, and including $3 = 4$ forces 3 to be equal to them as well. Thus, variable 4 acts as an effective intermediary. 
In Example 3, there is only a single critical variable. The requirement is inherently satisfied, so no constraints need to be activated, resulting in a total cost of 0.

<RATIONALE>
The problem is reframed as selecting equality constraints to force a subset of variables to take the same value via transitivity. This preserves the Steiner Tree structure perfectly while stripping away all graph-theoretic and permutation-group vocabulary, forcing the model to recognize the equivalence class formation as a connectivity problem. The prohibited word "reduction" was carefully omitted.
</RATIONALE>
<PRESERVED_ANSWER>
The structural requirement (connecting terminal nodes in a weighted graph) is mathematically identical to selecting equalities to force variables to be identically equal, so the optimal set of selections and its cost remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Selecting the minimum-weight set of edges to connect a specified subset of vertices in a graph is the definition of the Steiner Tree problem, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might struggle to map "system of equations" and "transitive property" to graph edges, but the explanation of pairwise equality explicitly defines the connectivity requirement without ambiguity.
</RISK>
