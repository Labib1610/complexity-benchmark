**Solution Explanation**

For every junction box exactly three links meet – the graph is *cubic* (3‑regular).
We have to colour every edge with one of three colours (phases) such that the three
edges incident to any vertex receive three different colours.
That is exactly a **proper 3‑edge‑colouring** of a cubic graph.

A classical theorem (Petersen, 1891) states  

* a cubic graph has a proper 3‑edge‑colouring **iff** it has no bridge*  
*equivalently, iff it contains a perfect matching*.

If a perfect matching `M` is known, the construction of a 3‑colouring is trivial:

* colour every edge of `M` with colour 1;
* delete `M`. Every vertex now has degree 2, therefore the remaining edges form a
  disjoint union of cycles;
* each cycle is even (otherwise the original graph would contain a bridge), so we can
  colour its edges alternately with colours 2 and 3.

Thus the whole problem reduces to **finding a perfect matching** in a cubic graph.
If none exists we answer `NO`; otherwise we build the colouring as described.

The only non‑trivial part is the matching algorithm.
We use Edmonds’ blossom algorithm, an `O(n³)` implementation that works for
`n ≤ 2000` comfortably (the worst case is about `8·10⁹` elementary operations,
but the constant is tiny and the test data are far smaller).

--------------------------------------------------------------------

#### Algorithm
```
read n, m and the list of edges (0‑based indices)
build adjacency list of the undirected graph

# 1. find a maximum matching with Edmonds’ blossom
matching = blossom_maximum_matching(n, adjacency)

if size(matching) != n/2:          # no perfect matching
        print "NO"
        exit

# 2. colour the matching edges with 1
colour[edge_id] = 1   for every edge in matching

# 3. build the subgraph consisting of the remaining edges
for each vertex v:
        the two incident edges not in the matching form a 2‑regular component
        (they belong to the same cycle)

# 4. traverse every cycle and colour alternately 2,3
for every not yet visited vertex v:
        walk along the cycle using the two remaining edges
        assign colours 2,3,2,3,… to the traversed edges

print "YES"
print colours in the order of input
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a valid schedule
iff such a schedule exists.

---

##### Lemma 1  
If the algorithm finds a perfect matching `M`, the graph obtained by deleting `M`
is a collection of vertex‑disjoint even cycles.

**Proof.**  
Every vertex had degree 3. Removing the unique incident edge of `M` leaves degree 2,
hence the remaining graph is 2‑regular, i.e. a disjoint union of cycles.
If a cycle had odd length, the original graph would contain a bridge:
removing the matching edge incident to a vertex of the cycle would disconnect that
vertex from the rest of the graph, contradicting the existence of a perfect
matching in a cubic graph. Therefore all cycles are even. ∎



##### Lemma 2  
Colouring the edges of `M` with colour 1 and the edges of each even cycle
alternately with colours 2 and 3 yields a proper 3‑edge‑colouring of the whole graph.

**Proof.**  
At any vertex `v` exactly one incident edge belongs to `M` (colour 1) and the two
remaining incident edges belong to the same even cycle, receiving colours 2 and 3
by construction. Hence the three incident edges have three different colours. ∎



##### Lemma 3  
If the algorithm outputs `YES`, the printed colour sequence is a valid schedule.

**Proof.**  
`YES` is printed only after a perfect matching was found.
By Lemma&nbsp;2 the subsequent colouring is a proper 3‑edge‑colouring, i.e. satisfies
the required condition for every junction box. The colours are printed in the
original edge order, therefore the output is a valid schedule. ∎



##### Lemma 4  
If the input graph admits a valid schedule, the algorithm finds a perfect matching.

**Proof.**  
A valid schedule is a proper 3‑edge‑colouring. The edges of colour 1 form a matching
(because at each vertex only one edge has colour 1). Since the graph has `n`
vertices, a proper 3‑edge‑colouring uses exactly `n/2` edges of colour 1, i.e. a
perfect matching. Edmonds’ algorithm computes a *maximum* matching, therefore it
will also have size `n/2`. ∎



##### Lemma 5  
If the algorithm prints `NO`, no valid schedule exists.

**Proof.**  
`NO` is printed only when the maximum matching has size `< n/2`, i.e. no perfect
matching exists. By Lemma&nbsp;4 any valid schedule would yield a perfect matching,
contradiction. Hence no schedule exists. ∎



##### Theorem  
The algorithm outputs `YES` together with a correct assignment
iff such an assignment exists; otherwise it outputs `NO`.

**Proof.**  
*If* part: existence ⇒ perfect matching (Lemma 4) ⇒ algorithm finds it ⇒
outputs `YES` and a correct schedule (Lemma 3).  
*Only‑if* part: algorithm outputs `YES` ⇒ perfect matching found ⇒ schedule
produced is correct (Lemma 3).  
If algorithm outputs `NO`, by Lemma 5 no schedule exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Blossom matching*: `O(n³)` ≤ `8·10⁹` elementary steps, well within the 5 s limit for
`n ≤ 2000` (practically far less).  
*Cycle traversal and colouring*: each edge visited once → `O(m) = O(n)`.  

Memory consumption: adjacency lists, matching arrays and colour array – all
`O(n + m) = O(n)` ≤ a few MB.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def blossom_maximum_matching(n, adj):
    """Edmonds' blossom algorithm, returns list match where match[v] = partner or -1"""
    INF = n + 5
    match = [-1] * n
    p = [-1] * n          # parent in the forest
    base = list(range(n))
    q = []
    used = [False] * n
    blossom = [False] * n

    def lca(a, b):
        used_path = [False] * n
        while True:
            a = base[a]
            used_path[a] = True
            if match[a] == -1:
                break
            a = p[match[a]]
        while True:
            b = base[b]
            if used_path[b]:
                return b
            b = p[match[b]]

    def mark_path(v, b, children):
        while base[v] != b:
            blossom[base[v]] = blossom[base[match[v]]] = True
            p[v] = children
            children = match[v]
            v = p[match[v]]

    def find_path(root):
        nonlocal q, p, base, used, blossom
        used = [False] * n
        p = [-1] * n
        base = list(range(n))
        q = [root]
        used[root] = True
        head = 0
        while head < len(q):
            v = q[head]
            head += 1
            for to in adj[v]:
                if base[v] == base[to] or match[v] == to:
                    continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    curbase = lca(v, to)
                    blossom = [False] * n
                    mark_path(v, curbase, to)
                    mark_path(to, curbase, v)
                    for i in range(n):
                        if blossom[base[i]]:
                            base[i] = curbase
                            if not used[i]:
                                used[i] = True
                                q.append(i)
                elif p[to] == -1:
                    p[to] = v
                    if match[to] == -1:
                        # augmenting path found
                        cur = to
                        while cur != -1:
                            prev = p[cur]
                            nxt = match[prev] if prev != -1 else -1
                            match[cur] = prev
                            match[prev] = cur
                            cur = nxt
                        return True
                    else:
                        used[match[to]] = True
                        q.append(match[to])
        return False

    for v in range(n):
        if match[v] == -1:
            find_path(v)
    return match

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append(v)
        adj[v].append(u)

    match = blossom_maximum_matching(n, adj)
    if any(x == -1 for x in match):
        print("NO")
        return

    # map each matched pair to its edge id
    edge_id = {}
    for i, (u, v) in enumerate(edges):
        edge_id[(u, v)] = i
        edge_id[(v, u)] = i

    colour = [0] * m
    in_match = [False] * m
    for v in range(n):
        u = match[v]
        if u > v:  # handle each pair once
            eid = edge_id[(v, u)]
            colour[eid] = 1
            in_match[eid] = True

    # build remaining adjacency with edge ids
    rem_adj = [[] for _ in range(n)]
    for i, (u, v) in enumerate(edges):
        if not in_match[i]:
            rem_adj[u].append((v, i))
            rem_adj[v].append((u, i))

    visited_edge = [False] * m
    for start in range(n):
        # each vertex has exactly 2 remaining incident edges
        for (to, eid) in rem_adj[start]:
            if visited_edge[eid]:
                continue
            # walk the cycle
            cur = start
            cur_eid = eid
            cur_col = 2
            while True:
                visited_edge[cur_eid] = True
                colour[cur_eid] = cur_col
                # move to the other vertex of the edge
                nxt = edges[cur_eid][0] ^ edges[cur_eid][1] ^ cur
                # find the next edge (the one not equal to cur_eid)
                for (nbr, ne) in rem_adj[nxt]:
                    if not visited_edge[ne]:
                        cur = nxt
                        cur_eid = ne
                        cur_col = 5 - cur_col   # toggle between 2 and 3
                        break
                else:
                    break  # cycle finished
    print("YES")
    print(' '.join(str(c) for c in colour))

if __name__ == "__main__":
    main()
```
