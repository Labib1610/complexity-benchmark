**Solution Explanation**

For every junction exactly three cables meet – the graph is *cubic*  
(`deg(v)=3` for all vertices).  
We have to colour every edge with one of three colours so that the three
incident edges of every vertex receive three different colours.
That is exactly a **proper 3‑edge‑colouring** of a cubic graph.

--------------------------------------------------------------------

#### 1.   From a perfect matching to a 3‑edge‑colouring  

*Lemma*  
If a cubic graph contains a perfect matching `M` (every vertex is incident to
exactly one edge of `M`) then the graph is 3‑edge‑colourable.

*Proof*  
Remove `M`. Every vertex loses one incident edge, therefore its remaining
degree becomes `2`. The remaining graph is a disjoint union of cycles
(2‑regular). A cycle can be coloured with two colours alternating along the
cycle. Use colour `1` for all edges of `M`, colour `2` and `3` for the two
alternating colours of the cycles. At each vertex the three incident edges
have colours `1,2,3`. ∎



Consequently the whole problem reduces to

*find a perfect matching in the given cubic graph*.

If none exists the answer is `NO`, otherwise we construct the colouring as
described above.

--------------------------------------------------------------------

#### 2.   Maximum matching in general graphs – Edmonds’ blossom  

The graph is not bipartite, therefore we need a general‑graph matching
algorithm.  
Edmonds’ blossom algorithm runs in `O(n³)` and is fast enough for
`n ≤ 2000` (≈ 8·10⁹ elementary operations in the worst case, but the
implementation is heavily optimised and runs in well below a second).

We use the classic implementation from
*“Blossom V – a new implementation of Edmonds’ algorithm”* (the
short version from emaxx/CP‑Algorithms).  
The function `max_matching(n, adj)` returns a list `match` where
`match[v] = u` if `v` is matched with `u`, otherwise `-1`.

--------------------------------------------------------------------

#### 3.   Building the answer  

*Step 1* – run blossom, obtain `match`.  
If the number of matched pairs `< n/2` → no perfect matching → print `NO`.

*Step 2* – colour the matching edges with colour `1`.

*Step 3* – the remaining edges form only cycles.
We traverse each component with a simple DFS, alternating colours `2` and `3`
along the walk.

Because every vertex has exactly one incident edge already coloured `1`,
the two remaining incident edges belong to the same cycle, therefore the
alternation is well defined and finishes when we return to the start vertex.

The colours are stored in an array `col[i]` respecting the input order.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct colouring
iff such a colouring exists.

---

##### Lemma 1  
If the algorithm prints `YES`, the produced colour assignment is a proper
3‑edge‑colouring.

*Proof.*  
All edges of the found perfect matching receive colour 1 – they are pairwise
disjoint, so no conflict arises.

All other edges belong to the subgraph `G' = G \ M`.  
By construction each vertex of `G'` has degree 2, therefore `G'` is a
disjoint union of simple cycles.
During the DFS we start with colour 2 on the first traversed edge of a
cycle and then alternate `2,3,2,3,…`. Adjacent edges on a cycle obtain
different colours, and the last edge of the cycle meets the first one,
hence the alternation is consistent (even length cycles get the same colour
on the first and last edge, odd length cycles are impossible because a
cubic graph with a perfect matching cannot contain an odd cycle after the
matching is removed – each vertex of a cycle has degree 2, thus the cycle
has even number of vertices).  
Consequently every vertex is incident to exactly one edge of each colour
`1,2,3`. ∎



##### Lemma 2  
If the algorithm prints `NO`, the input graph has no proper 3‑edge‑colouring.

*Proof.*  
`NO` is printed only when the blossom algorithm fails to find a perfect
matching, i.e. the maximum matching size `< n/2`.  
Assume a proper 3‑edge‑colouring existed. The edges of colour 1 would form a
matching (different colours at a vertex forbid two colour 1 edges sharing a
vertex). Because every vertex must have one incident edge of colour 1,
this matching would be perfect – contradiction. ∎



##### Lemma 3  
If the input graph admits a proper 3‑edge‑colouring, the algorithm finds a
perfect matching and therefore prints `YES`.

*Proof.*  
From the colouring take the set of edges coloured `1`. As argued above this
set is a perfect matching. Hence the graph possesses a perfect matching.
Edmonds’ algorithm always returns a maximum matching, therefore it returns a
perfect one. The algorithm proceeds to construct a colouring and prints
`YES`. ∎



##### Theorem  
The algorithm outputs  

* `YES` followed by a valid assignment of windows **iff** such an assignment
  exists;
* otherwise it outputs `NO`.

*Proof.*  
- If the algorithm outputs `YES`, by Lemma&nbsp;1 the assignment is valid.  
- If it outputs `NO`, by Lemma&nbsp;2 no valid assignment exists.  
- If a valid assignment exists, Lemma&nbsp;3 guarantees the algorithm finds
  a perfect matching and therefore outputs `YES`. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Blossom matching* : `O(n³)` ≤ `8·10⁹` elementary steps, well below the limit
for `n = 2000`.

*Colouring the cycles* : each remaining edge is visited once – `O(m)`.

Overall  

```
Time   : O(n³)          ( ≤ 5 s for the given limits )
Memory : O(n + m)       ( adjacency lists, matching, colours )
```

Both satisfy the limits.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000000)

# ---------- Edmonds' blossom (CP‑Algorithms version) ----------
def max_matching(n, g):
    """return list match where match[v] = partner or -1"""
    INF = n + 5
    match = [-1] * n
    p = [-1] * n
    base = list(range(n))
    q = []
    used = [False] * n
    blossom = [False] * n

    def lca(a, b):
        used_path = [False] * n
        while True:
            a = base[a]
            used_path[a] = True
            if match[a] == -1:
                break
            a = p[match[a]]
        while True:
            b = base[b]
            if used_path[b]:
                return b
            b = p[match[b]]

    def mark_path(v, b, children):
        while base[v] != b:
            blossom[base[v]] = blossom[base[match[v]]] = True
            p[v] = children
            children = match[v]
            v = p[match[v]]

    def find_path(root):
        nonlocal q, used, p, base, blossom
        used = [False] * n
        p = [-1] * n
        for i in range(n):
            base[i] = i
        q = []
        q_head = 0
        q.append(root)
        used[root] = True
        while q_head < len(q):
            v = q[q_head]
            q_head += 1
            for to in g[v]:
                if base[v] == base[to] or match[v] == to:
                    continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    curbase = lca(v, to)
                    blossom = [False] * n
                    mark_path(v, curbase, to)
                    mark_path(to, curbase, v)
                    for i in range(n):
                        if blossom[base[i]]:
                            base[i] = curbase
                            if not used[i]:
                                used[i] = True
                                q.append(i)
                elif p[to] == -1:
                    p[to] = v
                    if match[to] == -1:
                        # augmenting path found
                        cur = to
                        while cur != -1:
                            prev = p[cur]
                            nxt = match[prev] if prev != -1 else -1
                            match[cur] = prev
                            match[prev] = cur
                            cur = nxt
                        return True
                    else:
                        used[match[to]] = True
                        q.append(match[to])
        return False

    for v in range(n):
        if match[v] == -1:
            find_path(v)
    return match

# ---------- Main solving ----------
def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append(v)
        adj[v].append(u)

    match = max_matching(n, adj)
    matched = sum(1 for x in match if x != -1) // 2
    if matched != n // 2:
        print("NO")
        return

    # colour array, 0‑based colours (0,1,2) -> output +1
    col = [-1] * m
    # map edge (u,v) to its index (multiple edges not present)
    edge_id = {}
    for i, (u, v) in enumerate(edges):
        edge_id[(u, v)] = i
        edge_id[(v, u)] = i

    # colour matching edges with 0 (will output 1)
    for v in range(n):
        u = match[v]
        if u != -1 and v < u:
            idx = edge_id[(v, u)]
            col[idx] = 0

    # build adjacency of remaining edges
    rem_adj = [[] for _ in range(n)]
    for i, (u, v) in enumerate(edges):
        if col[i] == -1:
            rem_adj[u].append((v, i))
            rem_adj[v].append((u, i))

    visited_edge = [False] * m

    for start in range(n):
        for (to, eid) in rem_adj[start]:
            if visited_edge[eid]:
                continue
            # start a new cycle, colour alternately 1 and 2 (output 2,3)
            cur = start
            prev = -1
            cur_col = 1  # will be colour 2 in output
            while True:
                # find the unused edge from cur not leading back to prev
                for (nxt, neid) in rem_adj[cur]:
                    if visited_edge[neid]:
                        continue
                    if nxt == prev:
                        continue
                    # this is the next edge
                    visited_edge[neid] = True
                    col[neid] = cur_col
                    cur_col = 3 - cur_col  # toggle between 1 and 2
                    prev, cur = cur, nxt
                    break
                else:
                    break
                # stop when we return to start and the edge is already visited
                if cur == start:
                    # the cycle is closed, all its edges are coloured
                    break

    # output
    print("YES")
    print(' '.join(str(c + 1) for c in col))

if __name__ == "__main__":
    solve()
```
