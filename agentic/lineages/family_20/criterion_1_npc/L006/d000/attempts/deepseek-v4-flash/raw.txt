We can model this as a graph problem.  
Each junction has degree exactly 3, and we need to 3-color the edges so that no two edges at the same vertex share a color.  

This is equivalent to edge-coloring a 3-regular graph with 3 colors, which is always possible by **Kőnig’s line coloring theorem** for bipartite graphs, but here the graph may not be bipartite.  
However, for cubic graphs, a 3-edge-coloring exists if and only if the graph is **3-edge-colorable**, which is equivalent to the graph being **bridgeless** (by the Four Color Theorem equivalent for cubic graphs).  

Since the problem guarantees n even and m = 3n/2, the graph is cubic.  
We can attempt to find a 3-edge-coloring using a backtracking or matching-based approach.  

A practical approach:  
- Use a greedy algorithm with backtracking, since n ≤ 2000 and m ≤ 3000, which is feasible.  
- We can also use a known algorithm: repeatedly find a perfect matching and assign colors.  

Here’s a solution using backtracking with pruning:  

```python
import sys
sys.setrecursionlimit(10000)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    edges = []
    adj = [[] for _ in range(n)]
    for i in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edges.append((u, v))
        adj[u].append((v, i))
        adj[v].append((u, i))
    
    color = [-1] * m
    # For each vertex, track used colors
    used = [0] * n  # bitmask of used colors (1,2,4 for colors 1,2,3)
    
    # Sort edges by degree of endpoints (most constrained first)
    order = list(range(m))
    order.sort(key=lambda e: len(adj[edges[e][0]]) + len(adj[edges[e][1]]), reverse=True)
    
    def backtrack(idx):
        if idx == m:
            return True
        e = order[idx]
        u, v = edges[e]
        # Try colors 1,2,3
        for c in range(1, 4):
            bit = 1 << (c-1)
            if (used[u] & bit) == 0 and (used[v] & bit) == 0:
                color[e] = c
                used[u] |= bit
                used[v] |= bit
                if backtrack(idx + 1):
                    return True
                used[u] ^= bit
                used[v] ^= bit
                color[e] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(color[i]) for i in range(m)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
