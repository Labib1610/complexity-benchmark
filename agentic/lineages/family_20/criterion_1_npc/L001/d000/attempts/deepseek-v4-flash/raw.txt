We can model this as a graph problem.  
Each vertex has degree exactly 3, and we need to 3-color the edges such that at each vertex, the three incident edges have all three different colors (1, 2, 3).  

This is equivalent to finding a proper edge-coloring of a cubic graph with 3 colors.  
By a known theorem, every cubic graph with a bridge is not 3-edge-colorable, but if it’s bridgeless, it is (by the Four Color Theorem equivalent).  

However, since n ≤ 2000, we can solve it directly with backtracking or by reducing to a 2-SAT / matching problem.  

A simpler approach:  
- Each vertex has 3 edges.  
- We can assign colors to edges one by one, ensuring at each vertex all three colors appear.  
- This is equivalent to decomposing the graph into three perfect matchings (each color class is a perfect matching).  

We can find a 3-edge-coloring by:  
1. Finding a perfect matching (color 1).  
2. Removing it, the remaining graph is 2-regular (cycles), which can be 2-colored alternately.  

We can find a perfect matching in a cubic graph using standard matching algorithms (e.g., Blossom), but implementing that is heavy.  
Given constraints, we can use a backtracking approach with pruning, since each vertex has only 3 edges.  

Here’s a working solution using backtracking with constraint propagation:  

```python
import sys
sys.setrecursionlimit(10000)

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for i in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append(i)
        adj[v].append(i)
    
    color = [-1] * m
    # For each vertex, track which colors are used
    used = [set() for _ in range(n)]
    
    # Order edges by degree of endpoints (most constrained first)
    order = list(range(m))
    order.sort(key=lambda e: len(adj[edges[e][0]]) + len(adj[edges[e][1]]), reverse=True)
    
    def backtrack(idx):
        if idx == m:
            return True
        e = order[idx]
        u, v = edges[e]
        # Try colors 1,2,3
        for c in range(3):
            if c not in used[u] and c not in used[v]:
                color[e] = c
                used[u].add(c)
                used[v].add(c)
                if backtrack(idx + 1):
                    return True
                used[u].remove(c)
                used[v].remove(c)
                color[e] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(c + 1) for c in color))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
