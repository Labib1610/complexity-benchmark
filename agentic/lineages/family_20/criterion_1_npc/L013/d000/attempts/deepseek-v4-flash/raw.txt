We can model this as a **3-edge-coloring** problem on a **3-regular graph** (each vertex has degree 3).  
By **Kőnig’s line coloring theorem**, every bipartite graph is 3-edge-colorable, but here the graph may not be bipartite.  
However, for a **3-regular graph**, a 3-edge-coloring exists if and only if the graph is **bipartite** (by the equivalence of edge-coloring and vertex-coloring of the line graph, and the fact that a 3-regular graph is 3-edge-colorable iff it is bipartite).  

So the plan:
1. Check if the graph is bipartite using BFS/DFS.
2. If not bipartite → print `NO`.
3. If bipartite → assign colors based on the bipartition and the three edges at each vertex.

Since each vertex has degree exactly 3, we can color edges by:
- For each vertex, its three incident edges get distinct colors 1, 2, 3.
- We can do this by traversing the graph and assigning colors greedily, because in a bipartite 3-regular graph, the coloring is forced and consistent.

Implementation steps:
- Build adjacency list with edge indices.
- BFS to check bipartiteness and get a 2-coloring of vertices.
- If not bipartite → `NO`.
- Else, for each vertex, assign colors to its incident edges:  
  We can do this by iterating over vertices and assigning the three colors to the three edges in some order, ensuring no conflict.  
  Since the graph is bipartite and 3-regular, a simple method:  
  For each vertex, look at its three incident edges; if any is uncolored, assign the smallest available color not used by its neighbors' already colored edges.

Let’s implement it.  

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    edges = []
    for i in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edges.append((u, v))
        adj[u].append((v, i))
        adj[v].append((u, i))
    
    # Check bipartiteness
    color = [-1] * n
    for start in range(n):
        if color[start] == -1:
            color[start] = 0
            q = deque([start])
            while q:
                u = q.popleft()
                for v, _ in adj[u]:
                    if color[v] == -1:
                        color[v] = color[u] ^ 1
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
    
    # Edge coloring
    edge_color = [0] * m
    for u in range(n):
        used = [False] * 4
        for v, idx in adj[u]:
            if edge_color[idx] != 0:
                used[edge_color[idx]] = True
        # Assign colors to uncolored edges
        for v, idx in adj[u]:
            if edge_color[idx] == 0:
                for c in range(1, 4):
                    if not used[c]:
                        edge_color[idx] = c
                        used[c] = True
                        break
    
    print("YES")
    print(" ".join(map(str, edge_color)))

if __name__ == "__main__":
    solve()
```
