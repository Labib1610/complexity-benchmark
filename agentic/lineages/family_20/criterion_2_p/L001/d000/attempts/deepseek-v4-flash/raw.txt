 We can model this as an edge-coloring problem on a bipartite multigraph:  
upstream ports and downstream ports are the two vertex sets, and each cable is an edge.  
The maximum degree \( K \) in the graph is the minimum number of windows needed.  
We need to color the edges with \( K \) colors such that no two edges sharing a vertex have the same color.

We can solve this using a standard **bipartite edge-coloring** algorithm in \( O(m \log K) \) or \( O(m \sqrt{m}) \), but here we can use a simpler approach:  
Since the graph is bipartite, we can color edges by repeatedly matching edges of each color using a DFS-based approach (Kőnig’s line coloring theorem).  

We’ll implement an iterative edge-coloring algorithm using the **Kempe chain** idea, which runs in \( O(mK) \) worst-case but is fine for the constraints if implemented efficiently.  
However, \( m \) can be 400,000 and \( K \) up to 400,000, so we need something better.

A known efficient method is to use **Euler partition** to split the graph into \( \lceil \log_2 K \rceil \) bipartite subgraphs, then color recursively.  
But simpler: we can use the **greedy with backtracking**? No, that may exceed time.

We can use the **edge-coloring via bipartite matching** approach:  
- While there are uncolored edges, find a perfect matching in the subgraph of edges with degree > 0, assign a new color to that matching, and remove those edges.  
This runs in \( O(m \sqrt{m}) \) if we use Hopcroft-Karp for each matching, but that’s too slow if \( K \) is large.

Given the constraints, the intended solution is likely the **Kempe chain** method, which is \( O(mK) \) but with small constant and often passes because \( K \) is at most \( m \).  
But worst-case \( m=400000, K=200000 \) would be too slow.

Let’s implement the **recursive edge-coloring** using the standard algorithm for bipartite multigraphs:

Algorithm:
1. Compute degree of each vertex.
2. Let \( K = \max \text{degree} \).
3. Use a function `color_edges(edges, left_vertices, right_vertices)` that:
   - If max degree == 0: return.
   - Find a subgraph with max degree = current max degree.
   - Use Euler tour to split into two subgraphs with max degree = ceil(K/2).
   - Recurse on each subgraph, then merge colors.

This is \( O(m \log K) \) and works for large inputs.

Let’s implement that.
