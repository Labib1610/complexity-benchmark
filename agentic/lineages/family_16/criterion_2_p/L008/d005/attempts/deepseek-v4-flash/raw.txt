 We can treat this as a scheduling problem.  
For each sector, we have a net gain `p2 - p1`.  
If net gain is positive, it’s better to do it earlier to build up charge.  
If net gain is negative, it’s better to do it later to minimize the charge needed.  

So the optimal order is:  
- First do all sectors with `p2 >= p1` (positive or zero net), sorted by `p1` ascending (so we use less charge first).  
- Then do all sectors with `p2 < p1` (negative net), sorted by `p2` descending (so we lose less charge first).  

We simulate this order to compute the total cost.  

Here’s the implementation:  

```python
n = int(input())
pos = []
neg = []
for _ in range(n):
    p1, p2 = map(int, input().split())
    if p2 >= p1:
        pos.append((p1, p2))
    else:
        neg.append((p1, p2))

pos.sort(key=lambda x: x[0])
neg.sort(key=lambda x: -x[1])

charge = 0
cost = 0

for p1, p2 in pos + neg:
    if charge < p1:
        cost += p1 - charge
        charge = p1
    charge -= p1
    charge += p2
    cost += p2

print(cost)
```
