# Problem B — Biome Pathway

Time limit: 1 s   Memory limit: 256 MB

## Description

A nature reserve features **j** distinct biomes. You must design a linear path that visits all **j** biomes in an order of your choosing.

Each biome has two parallel segments: a Canopy walkway and a Forest floor trail. For each biome, you are given the length of its Canopy walkway (**p1**) and the length of its Forest floor trail (**p2**).

An inspector will walk your designed path to evaluate it. The inspector will travel from the first biome in your order to the last. For the first **k** biomes, the inspector will walk the Canopy walkways. Then, inside the **k**-th biome, the inspector will drop down and walk the Forest floor trails for the remaining biomes (from the **k**-th biome through the **j**-th biome).

This means that for a chosen switch point **k** (1 ≤ k ≤ j), the inspector's total walking distance is exactly the sum of the Canopy walkway lengths for the 1st through **k**-th biomes in your order, plus the sum of the Forest floor trail lengths for the **k**-th through **j**-th biomes in your order.

The inspector evaluates all possible choices of **k** and will choose the switch point **k** that **maximizes** their total walking distance.

Your task is to choose the order of the **j** biomes to **minimize** this maximum total distance. Report the smallest possible maximum total distance the inspector can be forced to walk.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the lengths of the Canopy walkway and the Forest floor trail for a biome.

## Output

Print a single integer: the smallest possible maximum total distance.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one biome, so the switch point must be **k** = 1. The inspector walks the Canopy walkway (5) and the Forest floor trail (3), for a total distance of 8.
