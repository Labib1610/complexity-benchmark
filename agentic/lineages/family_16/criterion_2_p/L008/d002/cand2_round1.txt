# Problem B — Expedition Pipeline

Time limit: 1 s   Memory limit: 256 MB

## Description

An expedition needs to survey **j** distinct sectors. For each sector, you are given its mapping duration and its drilling duration. 

You must arrange all **j** sectors into a single sequence from position 1 to position **j**. Once your sequence is chosen, its **overall completion time** is evaluated as follows:

- The Radar Rover begins at time 0 and maps the sectors in the exact order of your sequence. It finishes mapping the sector at position $k$ at a time equal to the sum of the mapping durations of the sectors in positions 1 through $k$.
- If the expedition were to trigger the Sampling Phase at position $k$, the total time required would be the time the Radar Rover finishes mapping the sector at position $k$, plus the sum of the drilling durations of all sectors from position $k$ through position **j**, inclusive.
- Because the exact trigger position is determined by external conditions, the expedition must be prepared for the worst case. The overall completion time of your sequence is the maximum possible total time across all **j** possible trigger positions $k$ (where $1 \le k \le j$).

Determine the sequence that minimizes this overall completion time. Report that smallest possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the mapping duration and the drilling duration for a sector.

## Output

Print a single integer: the smallest possible overall completion time.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one sector. The Radar Rover finishes mapping it at time 5. Triggering the Sampling Phase at position 1 adds the drilling duration of 3, resulting in a total time of 8.
</STATEMENT>
<RATIONALE>
The original problem explicitly described a two-machine flow-shop scheduling scenario (two rovers processing in the same order, with the second waiting for the first). Models pattern-matched this description directly to Johnson's rule. I replaced the operational scheduling rules with the mathematical equivalent of the 2-machine makespan formula (a min-max over prefix and suffix sums). This forces models to mathematically recognize the equivalence to the flow-shop problem rather than relying on surface-level keyword matching.
</RATIONALE>
<PRESERVED_ANSWER>
The formula for the overall completion time is mathematically identical to the completion time of the last job in a 2-machine permutation flow-shop, so the optimal sequence and minimum time remain exactly the same for every input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains mathematically equivalent to the 2-machine flow-shop scheduling problem, which is optimally solvable in O(n log n) time using Johnson's rule.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "position j" as a generic index rather than the end of the sequence, though the bounds (1 ≤ k ≤ j) and the input clearly defining j as the total number of sectors makes this unambiguous.
</RISK>
