# Problem B — Two-Segment Processing

Time limit: 1 s
Memory limit: 256 MB

## Description

An encryption module must process **j** data blocks. The encryption process consists of exactly two sequential operations: a substitution phase followed by a transposition phase. Each block requires **p1** microseconds to complete the substitution phase, and **p2** microseconds to complete the transposition phase.

You must choose a single sequence in which to process all **j** blocks. Both phases process the blocks in this exact chosen sequence. The completion time of the sequence is governed by the dependency between the two phases. The system tracks the availability of each phase using two time counters, $T_{sub}$ and $T_{trans}$, both initially set to 0. 

As each block in your chosen sequence is processed, the time counters update step-by-step:
1. The block completes its substitution phase, advancing the substitution counter: 
   $T_{sub} \leftarrow T_{sub} + p_1$
2. The block's transposition phase cannot begin until both its substitution phase is complete ($T_{sub}$) and the transposition phase of the previously processed block is complete ($T_{trans}$). Thus, the transposition counter updates to:
   $T_{trans} \leftarrow \max(T_{sub}, T_{trans}) + p_2$

Your objective is to determine the optimal sequence of the **j** blocks that minimizes the final value of $T_{trans}$ after all blocks have been processed. Report this minimum possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the substitution time and the transposition time of a block.

## Output

Print a single integer: the smallest possible time at which all blocks are complete.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one block. The substitution phase finishes at time 5 ($T_{sub} = 5$). The transposition phase then immediately begins and finishes at time 5 + 3 = 8 ($T_{trans} = 8$).

Deleted the crossover-point explanation which explicitly gave away the minimax nature of the problem, and replaced the physical pipeline description with a strict variable recurrence. This forces the model to recognize the flow-shop structure from its sequential state transitions rather than from explicit formulas or keyword associations.
</RATIONALE>
<PRESERVED_ANSWER>
The recurrence $T_{trans} = \max(T_{sub}, T_{trans}) + p_2$ is mathematically identical to the completion time of a two-machine permutation flow shop, so the optimal sequence and its completion time remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is still the classic 2-machine flow-shop scheduling problem, which is solvable in O(n log n) time using Johnson's rule.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the recurrence as applying independently to each block rather than sequentially accumulating, though the phrase "time counters update step-by-step" strongly implies accumulation.
</RISK>
