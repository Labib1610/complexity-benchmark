<STATEMENT>
# Problem B — Minimax Grid Arrangement

Time limit: 1 s
Memory limit: 256 MB

## Description

You are given **j** columns of numbers. Each column consists of exactly two cells: a top cell containing the value **p1**, and a bottom cell containing the value **p2**.

You must choose a single left-to-right sequence in which to place all **j** columns to form a $2 \times j$ grid. The top cells form the first row, and the bottom cells form the second row. 

Once you have chosen the arrangement, an adversary will traverse the grid. The adversary starts at the top-left cell (row 1, column 1) and must reach the bottom-right cell (row 2, column **j**). From any cell, the adversary can only move one step to the right, or one step down. The adversary cannot move diagonally, left, or up.

The score of the adversary's path is the sum of the values of all cells visited along the path. Because the adversary wants to maximize the score, they will always choose a valid path that yields the maximum possible sum.

Your objective is to find a left-to-right arrangement of the **j** columns that minimizes this maximum possible score. Report this lowest possible maximum score.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the top value and the bottom value of a column.

## Output

Print a single integer: the minimum possible score the adversary can achieve if you arrange the columns optimally.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one column. The grid is 2×1. The only valid path visits the top cell (5) and then the bottom cell (3), for a total score of 5 + 3 = 8.
</STATEMENT>
<RATIONALE>
The previous statement explicitly described a two-segment pipeline and crossover points, which directly triggered memorized associations with the two-machine flow-shop problem and Johnson's Rule. I removed all scheduling and pipeline terminology, representing the mathematically identical objective as a minimax path-finding game on a 2xN grid where columns are permuted. This forces the model to either re-derive the adjacent-swap comparator algebraically or fail, bypassing superficial pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The maximum path sum on a 2xN grid with right/down moves is mathematically identical to the makespan of a two-machine flow-shop, as both sum the first row up to a transition column $k$ and the second row from $k$ onwards; thus the optimal permutation and minimum cost remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the 2-machine flow-shop scheduling problem (solvable optimally in O(N log N) via Johnson's Rule), just described through an isomorphic grid-path framing.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "a single left-to-right sequence" as allowing the columns to be flipped upside-down (swapping p1 and p2), although the text explicitly states "The top cells form the first row, and the bottom cells form the second row" to prevent this.
</RISK>
