# Problem B — Minimax Array Arrangement

Time limit: 1 s
Memory limit: 256 MB

## Description

You are given **j** items. Each item has an ordered pair of attributes: a first value **p1** and a second value **p2**.

You must arrange all **j** items into a single sequence. You may only permute the items; for each item, its first value remains **p1** and its second value remains **p2**. The first and second values of an item cannot be swapped, and no operation other than reordering the given items is allowed.

Let the chosen sequence of items be $E_1, E_2, \dots, E_j$. For the item at position $i$ ($1 \le i \le j$), let $A_i$ be its first value and $B_i$ be its second value.

For a specific split index $k$ ($1 \le k \le j$), we define the cost function as the sum of the first values of all items from position $1$ to $k$, plus the sum of the second values of all items from position $k$ to $j$.
Mathematically, the cost at index $k$ is:
$$ C(k) = \sum_{i=1}^k A_i + \sum_{i=k}^j B_i $$

The overall score of the sequence is the maximum cost $C(k)$ among all possible choices of $k$ from $1$ to $j$. 

Your objective is to find a permutation of the **j** items that minimizes this overall score. Determine and output this minimum possible score.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the first value and the second value of an item.

## Output

Print a single integer: the smallest possible overall score achievable by any permutation of the items.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence places the items in the order: the item with values (1, 3) first, then (2, 4), then (3, 2).
The sequence of first values $A$ is $1, 2, 3$.
The sequence of second values $B$ is $3, 4, 2$.
The costs for each possible $k$ are:
- $k=1: C(1) = A_1 + (B_1 + B_2 + B_3) = 1 + (3 + 4 + 2) = 10$
- $k=2: C(2) = (A_1 + A_2) + (B_2 + B_3) = (1 + 2) + (4 + 2) = 9$
- $k=3: C(3) = (A_1 + A_2 + A_3) + B_3 = (1 + 2 + 3) + 2 = 8$

The overall score of this sequence is $\max(10, 9, 8) = 10$. No arrangement of the items yields a smaller maximum cost.

In Example 2, there is only one item, so the sequence is fixed. The only possible index is $k = 1$. The cost is $C(1) = A_1 + B_1 = 5 + 3 = 8$. The overall score is 8.
