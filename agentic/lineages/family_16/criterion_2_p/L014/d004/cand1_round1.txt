# Problem B — Adversarial Array Alignment

Time limit: 1 s
Memory limit: 256 MB

## Description

You are given a set of **j** tiles. Each tile has a top value and a bottom value. 

You must place all **j** tiles in a single row, from left to right. This forms a sequence of tiles $S = (S_1, S_2, \dots, S_j)$, where each $S_i$ has a top value $A_i$ and a bottom value $B_i$ (corresponding to the given **p1** and **p2** values). 

After you arrange the tiles, an adversary will choose an index $k$ ($1 \le k \le j$). The adversary will compute a score equal to the sum of the top values from tile $1$ to tile $k$ inclusive, plus the sum of the bottom values from tile $k$ to tile $j$ inclusive. 

Mathematically, for a chosen arrangement and a chosen $k$, the score is:
$$ \text{Score}(k) = \sum_{i=1}^k A_i + \sum_{i=k}^j B_i $$

The adversary will always choose the index $k$ that maximizes this score. Your objective is to determine the optimal arrangement of the tiles that minimizes the maximum possible score the adversary can achieve. Report this minimum possible maximum score.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the top value and the bottom value of a tile.

## Output

Print a single integer: the smallest possible maximum score the adversary can achieve.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal arrangement is to place the tiles in the order of the third input tile, then the second, then the first. 
This gives the top values $A = [1, 2, 3]$ and bottom values $B = [3, 4, 2]$.
If the adversary chooses $k=1$, the score is $1 + (3 + 4 + 2) = 10$.
If the adversary chooses $k=2$, the score is $(1 + 2) + (4 + 2) = 9$.
If the adversary chooses $k=3$, the score is $(1 + 2 + 3) + 2 = 8$.
The maximum score the adversary can achieve with this arrangement is 10. No other arrangement guarantees a maximum score strictly less than 10.

In Example 2, there is only one tile. The adversary must choose $k=1$. The score is $5 + 3 = 8$.
