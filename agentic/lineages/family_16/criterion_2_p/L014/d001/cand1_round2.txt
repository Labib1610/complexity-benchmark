# Problem B — Two-Stage Baking

Time limit: 1 s   Memory limit: 256 MB

## Description

You are managing a bakery schedule to fulfill **j** custom cake requests. Every request requires a heating phase in the oven, followed by a finishing phase at the decoration counter. You are given the duration of the heating phase and the duration of the finishing phase for each request.

The kitchen operates under these strict rules:
- The oven can heat only one cake at a time.
- The decoration counter can finish only one cake at a time.
- A cake's finishing phase cannot begin until its heating phase is entirely completed.
- You must establish a single master list of requests. The cakes must be processed in the oven according to this list, and they must be processed at the decoration counter in that exact same order.

Your objective is to arrange the master list so that the time when the final cake completes its finishing phase is as early as possible. Report this minimum time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the heating duration and the finishing duration of a request.

## Output

Print a single integer: the earliest possible time at which all requests have completed their finishing phase.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single request takes 5 units of time to heat and then 3 units of time to finish, completing the finishing phase at time 8.
