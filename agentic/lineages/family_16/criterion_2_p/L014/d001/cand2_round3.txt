# Problem B — Two-Stage Baking

Time limit: 1 s   Memory limit: 256 MB

## Description

A bakery must process **j** custom cake orders. Each order requires **p1** minutes of baking followed by **p2** minutes of decorating.
There is a single oven and a single icing station. You must organize the orders into a single sequence (from the 1st order to the **j**-th order). Both the oven and the icing station will handle the orders in this exact chosen sequence.

Based on your sequence, the completion times are determined as follows:
- Let **X_i** be the time the oven finishes baking the **i**-th order. The oven works continuously starting at time 0, so **X_i** is the sum of the baking times of all orders from the 1st up to the **i**-th.
- Let **Y_i** be the time the icing station finishes decorating the **i**-th order. The icing station processes one order at a time. It cannot begin decorating the **i**-th order until the order has been completely baked (at time **X_i**), nor can it begin until the station has finished the previous order (at time **Y_{i-1}**).
- Because the icing station starts as early as possible once both conditions are met, the **i**-th order finishes decorating at time **Y_i = max(X_i, Y_{i-1}) + p_{i,2}** (assume **Y_0 = 0**).

Your task is to find the sequence of the **j** orders that minimizes **Y_j**, the time the final order finishes decorating. Report this smallest possible finish time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the baking time and the decorating time of an order.

## Output

Print a single integer: the smallest possible time at which all orders are finished.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one order. It finishes baking at **X_1** = 5, and finishes decorating at **Y_1** = max(5, 0) + 3 = 8.
