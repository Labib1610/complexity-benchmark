# Problem B — Bakery Display Penalty

Time limit: 1 s   Memory limit: 256 MB

## Description

A bakery must prepare **j** custom cake orders. For each order, you are given a base preparation factor **p1** and a finishing factor **p2**.

You must choose the sequence in which the **j** orders are placed on the display counter (from position 1 to position **j**). Once the sequence is chosen, an independent quality inspector will evaluate it.

The inspector will choose exactly one transition position **k** (1 ≤ **k** ≤ **j**) to calculate the sequence's total penalty. The penalty for a chosen **k** is:
- The sum of the preparation factors of the orders at positions 1 through **k** (inclusive).
- PLUS the sum of the finishing factors of the orders at positions **k** through **j** (inclusive).

The inspector is adversarial and will always choose the transition position **k** that makes this total penalty as LARGE as possible. 

Choose the sequence of the orders so that the inspector's maximum possible penalty is as SMALL as possible. Report that smallest possible penalty.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the preparation factor and the finishing factor of an order.

## Output

Print a single integer: the smallest possible maximum penalty.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one order, so the sequence has length 1. The inspector must choose **k** = 1. The penalty is the preparation factor (5) plus the finishing factor (3), which totals 8.

<RATIONALE>
I replaced the two-machine flow-shop scenario with an adversarial inspector who calculates a specific partial-sum penalty over the sequence. This removes all traditional scheduling keywords ("workstations", "finished", "oven first") while preserving the exact mathematical formula for the makespan. Models must now mathematically derive the pairwise exchange condition or recognize the formula to realize that Johnson's rule still applies.
</RATIONALE>
<PRESERVED_ANSWER>
The inspector's maximum penalty over all possible transition points k is mathematically identical to the completion time of the last job in a two-machine flow shop, meaning the optimal sequence and its score remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because the objective function is exactly the makespan of a two-machine flow shop, the problem is still optimally solvable in O(N log N) time using Johnson's algorithm.
</PRESERVED_CLASS>
