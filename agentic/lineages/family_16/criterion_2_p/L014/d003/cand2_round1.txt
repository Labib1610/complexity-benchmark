<STATEMENT>
# Problem B — Two-Stage Baking

Time limit: 1 s
Memory limit: 256 MB

## Description

A bakery must fulfill a batch of custom cake orders. Each order $k$ requires a primary phase duration of $p_{1,k}$ minutes and a secondary phase duration of $p_{2,k}$ minutes. 

You must choose a permutation of all $j$ orders to form a sequential schedule. Let the chosen sequence of orders be $O_1, O_2, \dots, O_j$.

The primary phase of the order at position $i$ completes at time $T_1(i)$, and its secondary phase completes at time $T_2(i)$. These completion times are governed by the following strict event-based rules:
- $T_1(0) = 0$
- $T_1(i) = T_1(i-1) + p_{1, O_i}$ for all $1 \le i \le j$
- $T_2(0) = 0$
- $T_2(i) = \max(T_1(i), T_2(i-1)) + p_{2, O_i}$ for all $1 \le i \le j$

Your task is to find an optimal permutation of the orders that minimizes $T_2(j)$, the time at which the secondary phase of the final order is completed. Report this minimum possible completion time.

The bakery registers orders on a continuous roll of receipt paper. Each order takes up exactly 1 centimeter of paper. The total length of paper used for a batch of $j$ orders ranges from a minimum of 1 centimeter up to a maximum of exactly 2 kilometers. 
Each phase duration is a positive integer number of minutes. The maximum possible duration for any single phase is equal to the number of millimeters in exactly one kilometer.

## Input

The first line contains a single integer $j$, representing the number of orders.
Each of the next $j$ lines contains two integers $p_1$ and $p_2$: the primary phase duration and the secondary phase duration of an order.

## Output

Print a single integer: the smallest possible value of $T_2(j)$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one order ($j=1$). 
$T_1(1) = T_1(0) + 5 = 5$.
$T_2(1) = \max(T_1(1), T_2(0)) + 3 = \max(5, 0) + 3 = 8$.
The minimum possible value of $T_2(1)$ is 8.
</STATEMENT>
<RATIONALE>
I removed the explicit two-stage "mixer/froster" narrative and the description of the "pending counter" queue. Instead, I provided the exact mathematical recurrence relation for the completion times of a permutation sequence. This forces the model to mathematically map the recurrence to the makespan of a 2-machine flow-shop, rather than relying on surface-level keywords like "queue", "unoccupied", or "counter" to trigger Johnson's rule. I also encoded the numeric bounds into physical distance conversions (centimeters/millimeters to kilometers) to obscure them from simple regex scanning.
</RATIONALE>
