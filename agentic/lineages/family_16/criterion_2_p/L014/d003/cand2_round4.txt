# Problem B — State Progression

Time limit: 1 s
Memory limit: 256 MB

## Description

A system must process **j** tokens, moving each from state 0 to state 2. You must supply a single initial ordered list of all **j** tokens.

The system uses two single-threaded workers, Thread X and Thread Y, which operate according to these rules:
- All tokens begin in state 0. Whenever Thread X is idle and there is at least one token in state 0, Thread X immediately takes the token that appears earliest in your ordered list. It spends **p1** microseconds to move this token to state 1.
- Whenever Thread Y is idle and there is at least one token in state 1, Thread Y immediately takes the token that has been in state 1 for the longest continuous time. It spends **p2** microseconds to move this token to state 2.
- Once a thread begins a state transition for a token, it works continuously until that specific transition is complete.

Your task is to determine the optimal initial list of tokens that minimizes the exact microsecond when the final token reaches state 2. Report this minimum possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the microsecond duration for the 0-to-1 transition and the 1-to-2 transition of a token.

## Output

Print a single integer: the smallest possible microsecond at which all tokens have reached state 2.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one token. Thread X takes it at time 0 and finishes at time 5, moving it to state 1. Thread Y immediately takes it and finishes at time 5 + 3 = 8, moving it to state 2.
