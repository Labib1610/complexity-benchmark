<STATEMENT>
# Problem B — Drone Track Routing

Time limit: 1 s
Memory limit: 256 MB

## Description

You are designing a flight track that must visit $j$ distinct checkpoints exactly once. You must choose a single sequence in which all the checkpoints are ordered.

Two automated drones, the Scout and the Hauler, have specific operation times at each checkpoint. For a checkpoint given in the input with parameters **p1** and **p2**, the Scout's operation takes **p1** microseconds, and the Hauler's operation takes **p2** microseconds.

The performance of your sequence is evaluated based on a "transfer point". The transfer point can be any checkpoint in your sequence. If the $k$-th checkpoint in your sequence (where $1 \le k \le j$) is chosen as the transfer point, the "mission time" for that specific transfer point is calculated as the sum of:
1. The Scout's operation times for all checkpoints from the 1st position up to the $k$-th position (inclusive).
2. The Hauler's operation times for all checkpoints from the $k$-th position up to the $j$-th (last) position (inclusive).

Because the transfer point is chosen by an adversary after you set the sequence, the "worst-case mission time" of your sequence is the MAXIMUM mission time across all $j$ possible choices of the transfer point $k$.

Your objective is to determine the optimal sequence of checkpoints that MINIMIZES this worst-case mission time. Report this minimum possible worst-case mission time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000) representing a checkpoint. **p1** is the Scout's operation time, and **p2** is the Hauler's operation time.

## Output

Print a single integer: the minimum possible worst-case mission time.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence of the checkpoints (1-indexed based on the input order) is Checkpoint 3, then Checkpoint 2, then Checkpoint 1.
- If $k=1$ (Checkpoint 3 is the transfer point): mission time is $1 + (3 + 4 + 2) = 10$.
- If $k=2$ (Checkpoint 2 is the transfer point): mission time is $(1 + 2) + (4 + 2) = 9$.
- If $k=3$ (Checkpoint 1 is the transfer point): mission time is $(1 + 2 + 3) + 2 = 8$.

The worst-case mission time for this sequence is the maximum of these, which is 10. No sequence can achieve a lower worst-case mission time.
