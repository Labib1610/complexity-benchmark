We can solve this using **Johnson’s rule** for two-machine scheduling to minimize makespan.

**Steps:**
1. Split jobs into two groups:
   - Group A: jobs where `p1 <= p2`
   - Group B: jobs where `p1 > p2`
2. Sort Group A by `p1` ascending.
3. Sort Group B by `p2` descending.
4. Concatenate Group A + Group B to get the optimal order.
5. Simulate the schedule to compute the finish time on machine 2.

```python
n = int(input())
jobs = [tuple(map(int, input().split())) for _ in range(n)]

A = []
B = []
for p1, p2 in jobs:
    if p1 <= p2:
        A.append((p1, p2))
    else:
        B.append((p1, p2))

A.sort(key=lambda x: x[0])
B.sort(key=lambda x: x[1], reverse=True)

order = A + B

time_m1 = 0
time_m2 = 0
for p1, p2 in order:
    time_m1 += p1
    time_m2 = max(time_m1, time_m2) + p2

print(time_m2)
```
