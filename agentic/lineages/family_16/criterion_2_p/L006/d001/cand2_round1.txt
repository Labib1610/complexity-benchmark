# Problem B — Archival Digitization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are tasked with digitizing an archive of **j** historical manuscripts. For each manuscript, you are given the time it takes to scan it and the time it takes to index its contents.

The digitization process follows these rules:
- There is exactly one Scanner and one Indexer.
- You must arrange all **j** manuscripts into a single initial stack.
- The Scanner continuously takes the top manuscript from the stack, spends the required time scanning it, and immediately places its data into a digital transfer queue. The Scanner processes only one manuscript at a time and never pauses as long as the stack is not empty.
- The Indexer takes the next available manuscript's data from the transfer queue, spends the required time indexing it, and then moves to the next. The Indexer processes only one manuscript at a time.
- The transfer queue is strictly first-in, first-out. The Indexer must wait if the queue is empty, and it must process the manuscripts in the exact sequence they were scanned.

You have the freedom to choose the order of the manuscripts in the initial stack. Arrange the stack so that the time when the Indexer finishes the final manuscript is as early as possible. Report this earliest possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **s** and **i** (1 ≤ s, i ≤ 1000000): the scanning time and the indexing time of a manuscript, respectively.

## Output

Print a single integer: the earliest possible time at which all manuscripts have been fully indexed.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single manuscript takes 5 units of time to scan, after which its data enters the transfer queue. The Indexer then takes 3 units of time, finishing the entire process at time 8.
