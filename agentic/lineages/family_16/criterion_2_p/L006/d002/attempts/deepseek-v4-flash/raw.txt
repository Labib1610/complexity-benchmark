We can rearrange the ships to minimize the maximum of:

\[
T(k) = \sum_{i=1}^k p1_i + \sum_{i=k}^j p2_i
\]

For each \( k \), this can be rewritten as:

\[
T(k) = \left( \sum_{i=1}^j p2_i \right) + \sum_{i=1}^k (p1_i - p2_i)
\]

Let  
\( S = \sum_{i=1}^j p2_i \)  
and  
\( d_i = p1_i - p2_i \).

Then:

\[
T(k) = S + \sum_{i=1}^k d_i
\]

This is minimized by keeping the **prefix sums of \( d \)** as small as possible.  
The maximum prefix sum is minimized when we sort the items by decreasing \( d_i \) (placing large \( p1 - p2 \) last, or equivalently, sorting by \( p1 - p2 \) ascending).

Thus, the optimal strategy is to sort by \( d_i = p1_i - p2_i \) in **ascending** order)Skip. After sorting, compute prefix sums and track the maximum.

Here's the code:

```python
import sys

def main():
    input = sys.stdin.readline
    j = int(input())
    ships = []
    total_p2 = 0
    for _ in range(j):
        p1, p2 = map(int, input().split())
        ships.append((p1 - p2, p1, p2))
        total_p2 += p2

    ships.sort(key=lambda x: x[0])  # ascending p1 - p2

    max_time = 0
    prefix_p1 = 0
    for d, p1, p2 in ships:
        prefix_p1 += p1
        # T(k) = prefix_p1 + (total_p2 - prefix_p2_so_far)
        # But we can also just track S + prefix_d
    # Easier: after sorting, compute prefix sums of d
    prefix_d = 0
    for d, _, _ in ships:
        prefix_d += d
        if prefix_d > max_time:
            max_time = prefix_d

    print(total_p2 + max_time)

if __name__ == "__main__":
    main()
```
