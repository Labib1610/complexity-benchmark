# Problem B — Fleet Processing

Time limit: 1 s   Memory limit: 256 MB

## Description

An orbital holding area schedules the departure of a fleet. The scheduling system requires a minimum of a single vessel to activate, while the holding sector's strict limit of 200,000 docking clamps establishes the maximum possible fleet size, **j**.

Each vessel undergoes a primary scan followed by a secondary clearance. The duration of each operation is measured in microcycles, equal to the number of modular cargo pods the vessel allocates to that operation. Every ship carries at least 1 pod for a given operation, and the port authority strictly prohibits any operation from exceeding 1,000,000 pods.

You must assign a starting microcycle for each vessel's primary scan and a starting microcycle for its secondary clearance. The schedule must adhere to these directives:
- An operation runs continuously for its required duration once started.
- The primary scanner processes one vessel at a time. Primary scans cannot overlap, though one may begin at the exact microcycle another finishes.
- The secondary clearance zone processes one vessel at a time. Secondary clearances cannot overlap.
- A vessel's secondary clearance cannot commence until its primary scan is completely finished.
- The infrastructure allows no overtaking: for any pair of vessels, the one that begins its primary scan earlier must also begin its secondary clearance earlier.

Your objective is to find a valid schedule that minimizes the microcycle at which the final secondary clearance concludes. Output this earliest possible completion time.

## Input

The first line contains the fleet size **j**.
Each of the subsequent **j** lines details a vessel, providing two integers: the number of pods determining the primary scan duration, and the number of pods determining the secondary clearance duration.

## Output

Print a single integer representing the earliest possible microcycle when all vessels have fully completed both operations.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single vessel takes 5 microcycles for the primary scan, then 3 microcycles for the secondary clearance, concluding at microcycle 8.
