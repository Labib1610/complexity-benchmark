# Problem B — Secure Uplink

Time limit: 1 s   Memory limit: 256 MB

## Description

You need to process **j** data packets for transmission. Each packet must undergo two operations: encryption by the CPU, followed by transmission via the Antenna. 

The system operates under the following hardware constraints:
- The CPU encrypts one packet at a time.
- The Antenna transmits one packet at a time.
- A packet can only begin transmission after the CPU has completely finished encrypting it.
- After encryption, packets are pushed into a strict First-In-First-Out (FIFO) hardware buffer. The Antenna pops packets from this buffer, which forces the Antenna to transmit the packets in the exact same order that the CPU encrypted them.
- You have full control over the initial order in which the CPU processes the packets.

Your goal is to organize the initial processing order to ensure the Antenna finishes transmitting the entire batch of packets at the earliest possible moment. Calculate this minimum possible time when the Antenna completes its work.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the time required by the CPU to encrypt the packet, and the time required by the Antenna to transmit it.

## Output

Print a single integer: the earliest possible time at which the Antenna finishes transmitting all packets.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single packet takes 5 time units to be encrypted by the CPU, and then 3 time units to be transmitted by the Antenna, completing the process at time 8.
