# Problem B — Spaceport Clearance

Time limit: 1 s   Memory limit: 256 MB

## Description

A fleet of **j** vessels needs to enter a space station. The entry protocol involves an inner airlock and an outer airlock. The rules for entry are:

- You must arrange the vessels into a single master queue.
- The inner airlock handles one vessel at a time, taking them strictly in the order of the master queue.
- The outer airlock also handles one vessel at a time, taking them strictly in the order of the master queue.
- A vessel cannot begin its outer airlock procedure until its inner airlock procedure is entirely complete.
- The station's holding area has exactly 200000 clamps, which limits the maximum fleet size **j**, though missions can be as small as 1 vessel. The energy cells restrict any single airlock procedure to at most 1000000 cycles, and every procedure takes at least 1 cycle.

Your task is to arrange the master queue to minimize the time when the final vessel in the queue completes its outer airlock procedure. Output this earliest possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000), representing the number of vessels.
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration the vessel requires in the inner airlock and the outer airlock, respectively.

## Output

Print a single integer: the earliest possible time at which all vessels have completed the outer airlock procedure.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single vessel takes 5 cycles in the inner airlock, then 3 cycles in the outer airlock, completing the entire entry protocol at time 8.

<RATIONALE>
Replaced the explicit "exactly two stages" and "same chosen sequence" with an inner/outer airlock scenario and a "master queue" that both airlocks follow. This forces models to derive the precedence and common-sequence constraints of a permutation flow-shop from the operational mechanics rather than standard terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The structural constraints (two sequential operations, identical processing order, minimizing total completion time) exactly match the two-machine flow-shop model of the seed, keeping all optimal schedules and makespans identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
This remains exactly the two-machine permutation flow-shop makespan minimization problem, which is optimally solvable in O(n log n) using Johnson's rule.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "taking them strictly in the order of the master queue" as allowing arbitrary idle time between vessels, though the objective of minimizing the final completion time naturally prevents intentional delays.
</RISK>
