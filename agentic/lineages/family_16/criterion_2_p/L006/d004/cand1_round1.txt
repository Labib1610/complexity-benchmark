# Problem B — Reactor Cooling Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

You are operating a specialized thermal reactor that must process **j** fuel rods. Each fuel rod has a heating spike **p1** and a cooling drop **p2**.

Before processing begins, the reactor's baseline temperature is initialized to exactly the sum of the cooling drops (**p2**) of all **j** rods combined. 

You must process all **j** rods one by one in a sequence of your choosing. When a rod is processed, two things happen in order:
1. First, the reactor's temperature increases by the rod's heating spike **p1**.
2. Immediately after, the reactor's temperature decreases by the rod's cooling drop **p2**.

The critical metric is the absolute highest temperature the reactor reaches at any point during the entire sequence (which always occurs immediately after a heating spike and before the corresponding cooling drop). 

You must find an ordering of the **j** fuel rods that minimizes this maximum peak temperature. Report the lowest possible maximum temperature you can achieve.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the heating spike and cooling drop of a fuel rod.

## Output

Print a single integer: the lowest possible maximum peak temperature.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, the sum of all cooling drops is $2 + 4 + 3 = 9$. Thus, the initial temperature is 9.
An optimal sequence processes the rods in the order of the 3rd, 2nd, and 1st from the input.
- Process the 3rd rod (spike 1, drop 3): The temperature rises by 1 to **10** (a peak), then drops by 3 to 7.
- Process the 2nd rod (spike 2, drop 4): The temperature rises by 2 to **9** (a peak), then drops by 4 to 5.
- Process the 1st rod (spike 3, drop 2): The temperature rises by 3 to **8** (a peak), then drops by 2 to 6.
The highest temperature reached at any point is 10. No sequence can result in a strictly lower peak temperature.
