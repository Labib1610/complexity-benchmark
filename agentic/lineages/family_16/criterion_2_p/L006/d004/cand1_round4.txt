<METHOD_DESCRIPTION>Replaces the sequential scheduling simulation rules with their closed-form mathematical equivalent (minimizing the maximum of $j$ specific path sums on a 2-column grid). This removes all scheduling terminology while preserving the exact objective function.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem B — Two-Column Matrix Permutation

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of $j$ rows, where each row consists of exactly two positive integers: a left value $p1$ and a right value $p2$.

You must arrange all $j$ rows in some order to form a grid with $j$ rows and 2 columns. Let the chosen arrangement place the rows at indices $1, 2, \dots, j$ from top to bottom, so that the grid has values $p1_i$ in the first column and $p2_i$ in the second column for $1 \le i \le j$.

A valid path through this grid starts at the top-left cell $(1, 1)$ and ends at the bottom-right cell $(j, 2)$. From any cell, a path can only move down (to the next row in the same column) or right (to the second column in the same row). 

Because the grid has exactly two columns, any valid path must move down the first column to some row $k$, move right to the second column at row $k$, and then move down the second column to row $j$. There are exactly $j$ valid paths, one for each possible crossover row $k$ ($1 \le k \le j$).

The cost of the path that crosses at row $k$ is the sum of all cell values it visits. Formally, this path cost $C_k$ is:
$$C_k = \sum_{i=1}^{k} p1_i + \sum_{i=k}^{j} p2_i$$

The overall weight of your chosen arrangement is the maximum path cost among all $j$ valid paths. In other words, the arrangement weight $W$ is:
$$W = \max_{1 \le k \le j} C_k$$

Your task is to find an arrangement of the $j$ rows that minimizes the overall weight $W$, and report this minimum possible weight.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $p1$ and $p2$ ($1 \le p1, p2 \le 1000000$): the left and right values of a row.

## Output

Print a single integer: the smallest possible overall weight $W$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal arrangement places the rows from the input in the following order: the 3rd row, then the 2nd row, then the 1st row.
The resulting grid is:
- Row 1: `1 3` (from the 3rd input row)
- Row 2: `2 4` (from the 2nd input row)
- Row 3: `3 2` (from the 1st input row)

There are exactly 3 valid paths:
- Crossover at row 1 ($k=1$): visits (1,1), (1,2), (2,2), (3,2). Cost = $p1_1 + p2_1 + p2_2 + p2_3 = 1 + 3 + 4 + 2 = 10$.
- Crossover at row 2 ($k=2$): visits (1,1), (2,1), (2,2), (3,2). Cost = $p1_1 + p1_2 + p2_2 + p2_3 = 1 + 2 + 4 + 2 = 9$.
- Crossover at row 3 ($k=3$): visits (1,1), (2,1), (3,1), (3,2). Cost = $p1_1 + p1_2 + p1_3 + p2_3 = 1 + 2 + 3 + 2 = 8$.

The maximum path cost for this arrangement is $\max(10, 9, 8) = 10$. Thus, the overall weight is 10, which is the minimum possible over all arrangements.

The problem was reformulated from a sequential 2-machine flow shop scheduling task to a minimax path problem on a 2-column grid. This replaces the classic scheduling affordances with their exact mathematical closed-form equivalent, forcing the model to recognize the structural equivalence to Johnson's rule without domain hints.
