<STATEMENT>
# Problem B — Exhibition Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

You are organizing an exhibition with **j** distinct displays. Each display has two parameters: a setup cost **p1** and a teardown cost **p2**.

You must choose exactly one sequence in which to arrange these **j** displays, placing them from position 1 to position **j**. 

For any chosen sequence, a "peak operational load" is calculated. The peak operational load is defined as the maximum possible value of the following sum, evaluated over all possible split points **k** (where 1 ≤ **k** ≤ **j**):

(The sum of **p1** for all displays from position 1 through position **k**) + (The sum of **p2** for all displays from position **k** through position **j**).

Note that the display at the split point **k** is included in exactly both the **p1** sum and the **p2** sum. You choose the order first; for that fixed order, the split point **k** that gives the maximum total determines the peak operational load.

Find an arrangement of the displays that minimizes this peak operational load over all possible permutations. Report only this minimum possible peak operational load value.

## Input

The first line contains a single integer **j** (1 ≤ **j** ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ **p1**, **p2** ≤ 1000000): the setup cost and teardown cost of a display.

## Output

Print a single integer: the minimum possible peak operational load.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, an optimal arrangement places the displays in the order of the 3rd, 2nd, and 1st from the input.
The sequence of (**p1**, **p2**) is:
- Position 1: (1, 3)
- Position 2: (2, 4)
- Position 3: (3, 2)

We calculate the sum for each possible split point **k**:
- If **k** = 1: the sum is $1 + (3 + 4 + 2) = 10$.
- If **k** = 2: the sum is $(1 + 2) + (4 + 2) = 9$.
- If **k** = 3: the sum is $(1 + 2 + 3) + 2 = 8$.

For this sequence, the peak operational load is the maximum of these sums, which is $\max(10, 9, 8) = 10$. This is the minimum possible peak operational load over all permutations.
