# Problem B — Exhibition Tour

Time limit: 1 s   Memory limit: 256 MB

## Description

You are organizing an art exhibition in a long hallway containing **j** rooms arranged in a sequence from room 1 to room **j**. You have **j** distinct collections of art, and you must assign exactly one collection to each room.

Each collection has two parameters: a number of red paintings **p1** and a number of blue paintings **p2**.

When a visitor tours the exhibition, they walk through the rooms in order from the 1st room to the **j**-th room. The visitor has a specific viewing habit: they will choose exactly one room **k** (where 1 ≤ **k** ≤ **j**) to be their "transition room".
- The visitor looks at all the red paintings in rooms 1 through **k** (inclusive).
- The visitor looks at all the blue paintings in rooms **k** through **j** (inclusive).

(Note that in the transition room **k**, the visitor looks at *both* the red paintings and the blue paintings.)

The visitor will always choose the transition room **k** that maximizes the total number of paintings they look at. We call this maximum possible total the "visitor's score".

You want to arrange the **j** collections into the **j** rooms in an order that minimizes the visitor's score. Find an arrangement of the collections that makes this maximum total as small as possible, and report this minimum possible visitor's score.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the number of red paintings and the number of blue paintings for a collection.

## Output

Print a single integer: the minimum possible visitor's score.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, an optimal arrangement places the collections in the order of the 3rd, 2nd, and 1st from the input.
- Room 1 gets the 3rd collection: 1 red, 3 blue.
- Room 2 gets the 2nd collection: 2 red, 4 blue.
- Room 3 gets the 1st collection: 3 red, 2 blue.

Let's calculate the total paintings viewed for each possible transition room **k**:
- If **k** = 1: The visitor looks at red paintings in Room 1 (1), and blue paintings in Rooms 1, 2, 3 (3 + 4 + 2 = 9). Total = 1 + 9 = 10.
- If **k** = 2: The visitor looks at red paintings in Rooms 1, 2 (1 + 2 = 3), and blue paintings in Rooms 2, 3 (4 + 2 = 6). Total = 3 + 6 = 9.
- If **k** = 3: The visitor looks at red paintings in Rooms 1, 2, 3 (1 + 2 + 3 = 6), and blue paintings in Room 3 (2). Total = 6 + 2 = 8.
The visitor chooses the maximum of these totals, which is 10.
No other arrangement of the collections can result in a visitor's score lower than 10.
