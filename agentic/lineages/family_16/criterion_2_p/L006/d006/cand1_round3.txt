# Problem B — Thermal Reactor Sequencing

Time limit: 1 s   Memory limit: 256 MB

## Description

You are sequencing **j** cooling phases for a prototype thermal reactor. The reactor starts with a core temperature of 0.

Each cooling phase has two parameters: a cooling drop **p1** and a rebound spike **p2**.
When you execute a phase, the following three steps happen in exact order:
1. The core temperature decreases by **p1** (the temperature can become negative).
2. The core temperature then increases by **p2**.
3. Finally, a material constraint ensures the core temperature cannot end up lower than the rebound spike level of the current phase. If the temperature is currently less than **p2**, it is instantly set to exactly **p2**.

You must execute all **j** phases exactly once, in a single sequence of your choosing.

The overall "thermal stress" of your sequence is defined as the total cooling drops of all phases (the sum of all **p1** values) plus the final core temperature of the reactor after all **j** phases have finished.

Find an execution order for the phases that makes this thermal stress as small as possible. Report this minimum possible thermal stress.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the cooling drop and the rebound spike of a phase.

## Output

Print a single integer: the minimum possible thermal stress.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, an optimal arrangement runs the phases in the order of the 3rd, 2nd, and 1st from the input.
- The total cooling drop of all phases is $3 + 2 + 1 = 6$.
- The core temperature starts at 0.
- For the 3rd input phase ($p1=1, p2=3$): The temperature decreases by 1 to -1. It increases by 3 to 2. The constraint ensures the temperature is at least 3. Since 2 < 3, the temperature is set to 3.
- For the 2nd input phase ($p1=2, p2=4$): The temperature decreases by 2 to 1. It increases by 4 to 5. The constraint ensures the temperature is at least 4. Since 5 is not less than 4, the temperature remains 5.
- For the 1st input phase ($p1=3, p2=2$): The temperature decreases by 3 to 2. It increases by 2 to 4. The constraint ensures the temperature is at least 2. Since 4 is not less than 2, the temperature remains 4.
The final core temperature is 4.
The thermal stress is $6 + 4 = 10$.
