<STATEMENT>
# Problem B — Data Buffer Optimization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are optimizing the processing sequence of **j** data batches. Each batch consists of a deletion phase and an insertion phase. For a given batch, the deletion phase has a capacity of **p1** records, and the insertion phase adds **p2** records.

You must arrange all **j** batches into a single sequence (a permutation of the given batches). The system maintains a data buffer, which initially contains $B_0 = 0$ records.

The batches are processed one by one in your chosen order. For the batch placed at position $i$ (where $1 \le i \le j$), let its parameters be $p1_i$ and $p2_i$. The buffer size is updated deterministically as follows:
1. **Deletion Phase:** The system attempts to remove $p1_i$ records from the buffer. Because the buffer cannot hold a negative number of records, the new buffer size becomes $\max(0, B_{i-1} - p1_i)$.
2. **Insertion Phase:** The system then adds $p2_i$ records to the buffer. The buffer size at the end of step $i$ thus becomes:
   $$B_i = \max(0, B_{i-1} - p1_i) + p2_i$$

The only choice you have is the permutation of the $j$ batches. Once the sequence is fixed, the buffer updates are strictly deterministic.

Your goal is to find a permutation of the batches that minimizes the final buffer size $B_j$. 

However, the final evaluation metric for the system is its **Overall Footprint**, defined as the sum of all $p1$ capacities plus the final buffer size:
$$\text{Footprint} = \sum_{i=1}^j p1_i + B_j$$

Since the sum of all $p1_i$ values is strictly constant regardless of the sequence, minimizing the Overall Footprint is exactly equivalent to minimizing $B_j$.

Find a permutation of the batches that makes the Overall Footprint as small as possible. Report this minimum possible Overall Footprint.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the deletion capacity and the insertion amount for a batch.

## Output

Print a single integer: the minimum possible Overall Footprint.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal arrangement places the batches in the order of the 3rd, 2nd, and 1st from the input.
- Sum of all $p1$ values: $3 + 2 + 1 = 6$.
- Initial buffer $B_0 = 0$.
- For the 3rd input batch ($p1=1, p2=3$) at position 1: $B_1 = \max(0, 0 - 1) + 3 = 3$.
- For the 2nd input batch ($p1=2, p2=4$) at position 2: $B_2 = \max(0, 3 - 2) + 4 = 5$.
- For the 1st input batch ($p1=3, p2=2$) at position 3: $B_3 = \max(0, 5 - 3) + 2 = 4$.
The final buffer size $B_3$ is 4.
The Overall Footprint is $6 + 4 = 10$.

This is one optimal order; other orders may achieve the same minimum footprint.

<RATIONALE>
The previous formulation directly exposed the standard recurrence for a two-machine flow-shop makespan ($X += p1$, $Y = \max(X, Y) + p2$). I replaced this with an algebraically equivalent single-variable state $B = Y - X$, which updates as $B_i = \max(0, B_{i-1} - p1_i) + p2_i$. This forces models to derive the greedy exchange comparator dynamically rather than triggering memorized knowledge of Johnson's algorithm from a recognizable two-machine equation.
</RATIONALE>
<PRESERVED_ANSWER>
The overall footprint is defined as $\sum p1_i + B_j$, which is algebraically identical to the original $Y_j$ because $B_j$ exactly equals $Y_j - X_j$ and $\sum p1_i$ exactly equals $X_j$.
</PRESERVED_ANSWER>

The problem remains optimally solvable in O(n log n) time using the exact same greedy sorting logic (Johnson's rule) because the objective function and the effect of swapping adjacent elements are mathematically identical.
</PRESERVED_CLASS>
