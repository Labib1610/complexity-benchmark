# Observatory Scheduling

Time limit: 1 s   Memory limit: 256 MB

## Description

An observatory must observe $j$ star systems. You must arrange the $j$ star systems into a single sequence. You may permute all $j$ star systems in any order.

Observing each star system requires two sequential operations: alignment and exposure.
- The Telescope Mount performs the alignment for one star system at a time. For a given star system, this requires $p_1$ continuous seconds.
- The Camera Sensor performs the exposure for one star system at a time. For a given star system, this requires $p_2$ continuous seconds.

The observation process must strictly adhere to the following rules:
- Both the Telescope Mount and the Camera Sensor must process the star systems strictly in the exact same sequence you have chosen.
- The Telescope Mount operates continuously from time 0, starting the alignment for the next star system in the sequence immediately after finishing the alignment for the previous one.
- The Camera Sensor can begin the exposure for a star system only after the Telescope Mount has completely finished the alignment for that specific star system, and only after the Camera Sensor has completely finished the exposure for all preceding star systems in the sequence.

Determine the sequence arrangement of the $j$ star systems that minimizes the time at which the Camera Sensor finishes the exposure for the final star system in the sequence. Report this minimum completion time.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$): the duration required for the Telescope Mount alignment, and the duration required for the Camera Sensor exposure, respectively.

## Output

Print a single integer: the smallest possible time at which the Camera Sensor finishes the final exposure.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single star system takes 5 seconds for alignment, finishing at time 5. The exposure then starts at time 5 and takes 3 seconds, finishing at time 8.
