# Archival Restoration

Time limit: 1 s   Memory limit: 256 MB

## Description

A historical repository has recovered **j** decaying scrolls. Every scroll requires a mandatory two-step preservation treatment. Initially, its text must be deciphered by the chief linguist. Only after this is done can the scroll be sealed by the preservationist.

The repository operates under the following strict directives:
- The linguist can decipher only one scroll at any given time.
- The preservationist can seal only one scroll at any given time.
- For any given scroll, the preservationist's work can only initiate after the linguist has completely finalized that specific scroll.
- The curator must establish a single, universal processing roster containing all **j** scrolls. To ensure chain-of-custody, both specialists are strictly bound to this exact roster: the linguist will pull scrolls in the order they appear on the roster, and the preservationist will subsequently pull scrolls in that identical order. If the preservationist is ready for the next scroll on the roster but the linguist is still working on it, the preservationist must idle until it is available. They cannot skip ahead to a different scroll.

Determine the master list order that minimizes the overall time elapsed until the preservationist completes the final scroll. Output this minimum possible completion time.

## Input

The first line provides a single integer **j** (1 ≤ j ≤ 200000).
Each of the subsequent **j** lines provides two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration the linguist spends deciphering the scroll, and the duration the preservationist spends sealing it, respectively.

## Output

Print a single integer: the minimum possible time when the preservationist finishes sealing the very last scroll.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single scroll takes 5 units of time to decipher and then 3 units of time to seal, finishing at time 8.
