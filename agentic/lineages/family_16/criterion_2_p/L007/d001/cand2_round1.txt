<STATEMENT>
# Archival Restoration

Time limit: 1 s   Memory limit: 256 MB

## Description

An archive has recently acquired **j** ancient manuscripts. Each manuscript must undergo a two-phase restoration process: first, it must be transcribed by the master calligrapher; second, it must be bound by the head bookbinder.

The restoration follows these strict protocols:
- The calligrapher works on transcribing only one manuscript at a time from start to finish.
- The bookbinder works on binding only one manuscript at a time from start to finish.
- The bookbinder can only begin binding a specific manuscript after the calligrapher has completely finished transcribing it.
- The calligrapher may choose any order to transcribe the manuscripts.
- The bookbinder may choose any order to bind the manuscripts, entirely independent of the calligrapher's chosen order.

Determine the schedules for both artisans that minimize the time at which the bookbinder finishes the final manuscript. Report this minimum possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the time required for the calligrapher to transcribe the manuscript, and the time required for the bookbinder to bind it, respectively.

## Output

Print a single integer: the smallest possible time at which the bookbinder finishes the last manuscript.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, the calligrapher could transcribe the manuscripts in the order 3, 2, 1. The bookbinder could choose to bind them in the same order 3, 2, 1. The calligrapher finishes manuscript 3 at time 1, so the bookbinder starts it at time 1 and finishes at time 4. The calligrapher finishes manuscript 2 at time 3, so the bookbinder starts it at time 4 and finishes at time 8. The calligrapher finishes manuscript 1 at time 6, so the bookbinder starts it at time 8 and finishes at time 10. No combination of independent schedules for the calligrapher and bookbinder can finish all manuscripts earlier than time 10.
</STATEMENT>
<RATIONALE>
I replaced the explicit constraint that both artisans must process the manuscripts in the exact same sequence with an allowance for them to choose entirely independent sequences. This removes the surface-level pattern of a "permutation flow-shop," forcing models to mathematically deduce that the bookbinder can never decrease idle time by deviating from the calligrapher's completion order, before they can safely apply Johnson's rule.
</RATIONALE>
<PRESERVED_ANSWER>
The optimal schedule for a two-stage flow shop always occurs when both stages process the items in the identical order, so allowing independent orders does not change the minimum possible completion time.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains optimally solvable in O(n log n) time using Johnson's rule, because the optimal independent schedules are mathematically identical to the optimal permutation schedules.
</PRESERVED_CLASS>
<RISK>
Models might assume the independent sequences allowance implies the problem is NP-hard and attempt a search algorithm, but the wording itself is completely unambiguous about what is allowed and what must be minimized.
</RISK>
