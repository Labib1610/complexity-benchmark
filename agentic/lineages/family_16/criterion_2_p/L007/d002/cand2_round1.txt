# Archival Restoration

Time limit: 1 s   Memory limit: 256 MB

## Description

An archive has recently acquired **j** ancient manuscripts. Each manuscript requires continuous attention from two specialists: first the master calligrapher, and subsequently the head bookbinder.

The restoration environment operates under the following physical constraints:
- The calligrapher sits at the entrance of a straight, enclosed chute leading to the bookbinder's desk.
- You must decide the sequence in which the calligrapher will transcribe the manuscripts. The calligrapher works continuously through this sequence, handling one manuscript at a time without pausing.
- The instant a manuscript's transcription is complete, it is pushed into the chute. The chute instantly delivers items to its exit, but because it is so narrow, manuscripts cannot overtake one another. Any manuscript must wait behind earlier ones still in the chute.
- The bookbinder handles one manuscript at a time. Whenever the bookbinder is idle and a manuscript is available at the exit of the chute, they immediately pull it out and begin binding it.

Determine the optimal sequence for the calligrapher to begin with such that the entire batch is completed as early as possible. Report the minimum possible time at which the bookbinder finishes the very last manuscript.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000). These represent the duration the calligrapher needs for transcription, and the duration the bookbinder needs for binding, respectively, for that manuscript.

## Output

Print a single integer: the earliest possible time the bookbinder completes the final manuscript in the batch.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

```

```

**Output**
```

```

### Example 3


**Output**
```
8
```

<RATIONALE>
Removed the explicit sentence stating that the bookbinder processes manuscripts in the exact order arranged for the calligrapher. Replaced it with a physical description of a narrow chute where items cannot overtake one another, forcing the model to deduce that the first-in-first-out mechanics mathematically guarantee a shared permutation order.
</RATIONALE>
<PRESERVED_ANSWER>
The narrow chute enforces a strict FIFO queue with instantaneous travel time, meaning the bookbinder inevitably receives and processes the manuscripts in the exact same order the calligrapher finishes them, keeping the objective and optimal makespan identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly a two-machine permutation flow-shop scheduling problem, which is optimally solvable in O(n log n) time via Johnson's rule.
</PRESERVED_CLASS>
<RISK>
Models might assume that transit time down the chute is non-zero, though the phrase "instantly delivers" is intended to explicitly preclude this.
</RISK>
