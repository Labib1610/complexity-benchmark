We need to minimize the makespan for a two-machine flow shop with the same order for both machines.  
This is the classic **Johnson’s rule** problem.

The optimal sequence is:
- Split jobs into two groups:
  - Group A: jobs where `p1 <= p2`, sorted by `p1` ascending.
  - Group B: jobs where `p1 > p2`, sorted by `p2` descending.
- Concatenate Group A then Group B.

Then simulate the schedule to get the completion time.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    jobs = []
    idx = 1
    for _ in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx+1])
        idx += 2
        jobs.append((p1, p2))
    
    group1 = []
    group2 = []
    for p1, p2 in jobs:
        if p1 <= p2:
            group1.append((p1, p2))
        else:
            group2.append((p1, p2))
    
    group1.sort(key=lambda x: x[0])
    group2.sort(key=lambda x: -x[1])
    
    sequence = group1 + group2
    
    time1 = 0
    time2 = 0
    for p1, p2 in sequence:
        time1 += p1
        if time2 < time1:
            time2 = time1
        time2 += p2
    
    print(time2)

if __name__ == "__main__":
    main()
```
