We can sort the nodes by a custom comparator:  
- If `p1` differs, put smaller `p1` first.  
- If `p1` is equal, put larger `p2` first.  

Then simulate the process to get the minimal peak stress.

```python
import sys

def solve():
    input = sys.stdin.readline
    j = int(input())
    nodes = []
    for _ in range(j):
        p1, p2 = map(int, input().split())
        nodes.append((p1, p2))
    
    nodes.sort(key=lambda x: (x[0], -x[1]))
    
    C = 0
    E = 0
    for p1, p2 in nodes:
        C += p1
        if C > E:
            E = C
        E += p2
    
    print(E)

if __name__ == "__main__":
    solve()
```
