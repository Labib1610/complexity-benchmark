# Problem B — Two-Stage Assembly

Time limit: 1 s   Memory limit: 256 MB

## Description

As part of a larger manufacturing workflow, tasks arrive from an initial sorting phase and must pass through a core assembly process before being sent to the final packaging department. You are responsible for optimizing this core stage.

You must establish a single, linear sequence for a manifest of tasks. The core assembly consists of a preparation bay and a finishing bay. The preparation bay handles the tasks one by one, strictly following your chosen sequence. After a task clears the preparation bay, it must be processed by the finishing bay. The finishing bay also processes tasks strictly in the same chosen sequence, handling one task at a time.

A task can only be handled by the finishing bay after its preparation is entirely complete. If the finishing bay completes a task but the next task in your sequence is still occupying the preparation bay, the finishing bay must remain idle until that next task is ready.

To ensure the packaging department can begin its work as early as possible, you must find a sequence that minimizes the time at which the final task in the manifest clears the finishing bay. Report this earliest possible completion time.

## Input

The first line contains a single integer **j**, representing the number of tasks in the manifest. The value of **j** is at least 1, and at most the exact number of millimeters in 200 meters.

Each of the next **j** lines contains two integers **p1** and **p2**: the durations required for the task in the preparation bay and the finishing bay, respectively. Neither duration is less than 1, nor does any exceed the exact number of grams in a metric tonne.

## Output

Print a single integer: the earliest possible time at which all tasks have cleared the finishing bay.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```
