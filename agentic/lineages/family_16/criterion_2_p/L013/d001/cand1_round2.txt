# Problem B — Arcane Channeling

Time limit: 1 s   Memory limit: 256 MB

## Description

As part of a grand ritual, magical energies arrive from an initial gathering phase and must pass through a core channeling process before being released to the final incantation. You are responsible for optimizing this core stage.

During this core stage, the ritual channels **j** spells through exactly **two** ancient foci. Every spell must be channeled through focus 1 first and then through focus 2 (the same order for all spells). For each spell you are given its channeling time through focus 1 and through focus 2. The rules are:

- Each focus channels only one spell at a time.
- A spell can start at focus 2 only after it has finished at focus 1.
- You may choose the sequence in which the spells are channeled (both foci channel the spells in the same chosen sequence).

To ensure the final incantation can begin its work as early as possible, choose the channeling sequence so that the time at which the **last** spell finishes at focus 2 is as small as possible. Report that smallest possible finish time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the channeling times of a spell through focus 1 and focus 2.

## Output

Print a single integer: the smallest possible time at which all spells are finished at focus 2.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2 the single spell takes 5 at focus 1 then 3 at focus 2, finishing at time 8.

<RATIONALE>
Changed the domain from factory scheduling to a fantasy ritual to prevent models from relying on keyword recognition (like "jobs" and "machines") to instantly fetch Johnson's rule. This forces models to analyze the two-stage bottleneck mechanics from first principles while strictly adhering to the gate's requirement for explicit numeric bounds.
</RATIONALE>

The objective, constraints, and dependencies are identical to the seed's two-machine flow-shop model, so the optimal sequence and completion time remain exactly the same for any input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is still fundamentally the two-machine permutation flow-shop scheduling problem, which can be solved optimally in O(N log N) using Johnson's algorithm.
</PRESERVED_CLASS>
