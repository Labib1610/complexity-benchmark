<STATEMENT>
# Energy Node Calibration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are configuring a linear array of **j** energy nodes. You must choose a single sequence in which to arrange these nodes from position 1 to position $j$.

Each node has two properties: a *surge rating* (**p1**) and a *drain rating* (**p2**).
When the nodes are activated in your chosen sequence, the system's baseline energy level fluctuates. The baseline starts at $0$.

For each node in the sequence, in order:
1. The node initiates, causing a temporary energy spike. The peak level of this spike is exactly the current baseline plus the node's surge rating (**p1**).
2. The node then stabilizes, which permanently alters the baseline. The baseline is updated to equal its previous value plus the node's surge rating (**p1**) minus its drain rating (**p2**).

The *Maximum Spike* of the sequence is the highest peak level reached during any of the $j$ node initiations.
The *Peak Stress* of your configuration is a single final value, calculated as: (the Maximum Spike) + (the sum of the drain ratings of all $j$ nodes).

Your objective is to find an arrangement sequence that minimizes the Peak Stress. Output this minimum possible Peak Stress.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the surge rating and the drain rating of a node, respectively.

## Output

Print a single integer: the minimum possible Peak Stress.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one node (5 3).
The baseline starts at 0.
1. It initiates, causing a spike peak of 0 + 5 = 5.
2. It stabilizes, setting the new baseline to 0 + 5 - 3 = 2.
The Maximum Spike across all initiations is 5.
The total sum of drain ratings for all nodes is 3.
The Peak Stress is the Maximum Spike (5) plus the sum of drain ratings (3), which equals 8.
</STATEMENT>
<RATIONALE>
The previous framing directly mapped to the two-machine flow shop recurrence (`C = C + p1`, `E = max(E, C) + p2`), allowing models to trivially recognize the structure and apply Johnson's rule. I expanded this recurrence algebraically and factored out the total sum of `p2`. The problem is now framed as tracking a fluctuating baseline (`p1 - p2`) and minimizing the maximum intermediate spike. This forces models to either heuristically invent a sorting key (which will fail hidden tests) or algebraically reconstruct the flow-shop recurrence to deduce Johnson's rule.
</RATIONALE>
<PRESERVED_ANSWER>
By algebraic expansion, the makespan of a two-machine flow shop $E_n = \max_{1 \le k \le n} (\sum_{i=1}^k p1_i + \sum_{i=k}^n p2_i)$ is exactly equal to $\sum_{i=1}^n p2_i + \max_{1 \le k \le n} (p1_k + \sum_{i=1}^{k-1} (p1_i - p2_i))$, which perfectly mirrors the new baseline and spike mechanics, guaranteeing identical minimums for all inputs.
</PRESERVED_ANSWER>
