<STATEMENT>
# Energy Node Calibration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are configuring a linear array of **j** energy nodes. You must choose a single sequence in which to arrange these nodes from position 1 to position $j$.

Each node has two properties: a *charging duration* (**p1**) and a *discharging duration* (**p2**).

Once you fix the sequence, the system's *peak stress* is evaluated based on potential pivot points. 
For any chosen index $k$ (where $1 \le k \le j$), the *pivot cost* at $k$ is calculated as the sum of two values:
1. The sum of the charging durations of all nodes from position $1$ to position $k$, inclusive.
2. The sum of the discharging durations of all nodes from position $k$ to position $j$, inclusive.

The *peak stress* of your chosen sequence is the maximum pivot cost among all $j$ possible choices of $k$.

Your objective is to find an arrangement sequence of the $j$ nodes that minimizes this peak stress. Output this minimum possible peak stress.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the charging duration and the discharging duration of a node, respectively.

## Output

Print a single integer: the minimum possible peak stress.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence places the nodes with (p1, p2) properties in the order: (1, 3), then (2, 4), then (3, 2).
We calculate the pivot cost for each possible $k$:
- For $k = 1$: The charging sum is 1. The discharging sum is 3 + 4 + 2 = 9. The pivot cost is 1 + 9 = 10.
- For $k = 2$: The charging sum is 1 + 2 = 3. The discharging sum is 4 + 2 = 6. The pivot cost is 3 + 6 = 9.
- For $k = 3$: The charging sum is 1 + 2 + 3 = 6. The discharging sum is 2. The pivot cost is 6 + 2 = 8.
The peak stress is the maximum of these pivot costs, which is 10. No other sequence yields a peak stress strictly less than 10.
