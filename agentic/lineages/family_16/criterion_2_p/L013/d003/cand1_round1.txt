# Artifact Resonance

Time limit: 1 s   Memory limit: 256 MB

## Description

You are analyzing **j** magical artifacts. Each artifact has two properties: a *resonance* value and a *stability* value. 

You must arrange these **j** artifacts into a single sequence. Let the chosen sequence be $S_1, S_2, \dots, S_j$.

For any given sequence, we define the *peak interference* by looking at all possible split points. A split point is an index $k$ ($1 \le k \le j$). The interference at split point $k$ is calculated as the sum of the resonance values of all artifacts from position $1$ to $k$ inclusive, plus the sum of the stability values of all artifacts from position $k$ to $j$ inclusive. 

Note that the artifact at the split point $k$ contributes both its resonance and its stability to this sum.

The *peak interference* of the sequence is the maximum interference value across all $j$ possible split points.

Your objective is to find an ordering of the artifacts that minimizes the sequence's peak interference. Report this minimum possible peak interference.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers: the resonance value and the stability value of an artifact, respectively (1 ≤ resonance, stability ≤ 1000000).

## Output

Print a single integer: the smallest possible peak interference achievable by optimally ordering the artifacts.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one artifact. The only possible split point is $k=1$. The sum of resonance values from position 1 to 1 is 5, and the sum of stability values from position 1 to 1 is 3. The peak interference is $5 + 3 = 8$.
