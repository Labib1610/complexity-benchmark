# Mountain Railway Ascent

Time limit: 1 s   Memory limit: 256 MB

## Description

You are coordinating the dispatch of a fleet of cargo engines up a mountain route. The route is divided into two consecutive zones: the valley ascent followed by the glacier crossing.

For each engine in the fleet, you are provided the exact number of minutes it takes to traverse the valley ascent, and the exact number of minutes it takes to traverse the glacier crossing.

The dispatch must adhere to the following physical constraints:
- The valley ascent can only accommodate a single engine at any given moment.
- The glacier crossing can only accommodate a single engine at any given moment.
- An engine can only enter the glacier crossing after it has fully completed the valley ascent.
- You must assign a single departure rank to each engine. The valley ascent admits engines strictly in the order of their assigned departure ranks. The glacier crossing also admits engines strictly in that exact same order.

Assume all timing is measured in elapsed minutes from time 0 (the start of dispatching). Determine the earliest possible minute by which the final engine can complete the glacier crossing. If multiple rank assignments achieve the same minimum completion time, you do not need to output the ranks; output only that minimum elapsed time.

## Input

The first line contains a single integer representing the number of engines in the fleet. The fleet contains at least one engine, and the maximum possible number of engines is exactly one-fifth of a million.
Each of the subsequent lines corresponds to an engine and contains two integers: its required duration on the valley ascent, and its required duration on the glacier crossing. All such durations are at least one, and no single duration exceeds one million.

## Output

Print one integer — the minimum possible finishing time of the last engine.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single engine requires 5 minutes on the valley ascent and then 3 minutes on the glacier crossing, finishing at elapsed time 8.
