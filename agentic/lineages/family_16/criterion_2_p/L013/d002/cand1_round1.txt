<STATEMENT>
# Mountain Railway Ascent

Time limit: 1 s   Memory limit: 256 MB

## Description

You are managing the daily dispatch of **j** trains up a steep mountain railway. The route consists of a lower segment and an upper segment, separated by a midpoint signal.

For each train, you are given the time it takes to travel the lower segment and the time it takes to travel the upper segment. You must establish a single departure sequence for all **j** trains. 

The movement of the trains follows strict safety protocols. Let the chosen sequence of trains be $T_1, T_2, \dots, T_j$. Let $A_k$ be the time $T_k$ reaches the midpoint signal, and let $B_k$ be the time $T_k$ arrives at the summit. The timing is determined as follows:

- The base station sends the next train only when the current train reaches the midpoint. Thus, $A_k = A_{k-1} + (\text{lower segment duration of } T_k)$, where $A_0 = 0$.
- A train begins its upper segment climb immediately once two conditions are met: it is at the midpoint, and the previous train has cleared the summit. Thus, $B_k = \max(A_k, B_{k-1}) + (\text{upper segment duration of } T_k)$, where $B_0 = 0$.

To ensure the summit station can begin its daily operations as early as possible, you need to find a departure sequence that minimizes $B_j$, the time the final train arrives at the summit. Output this minimum possible time.

## Input

The first line contains a single integer **j** (1 ≤ **j** ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ **p1**, **p2** ≤ 1000000): the lower segment duration and the upper segment duration for a train.

## Output

Print a single integer: the smallest possible time $B_j$ at which the final train arrives at the summit.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one train. It reaches the midpoint at $A_1 = 0 + 5 = 5$, and arrives at the summit at $B_1 = \max(5, 0) + 3 = 8$.

The previous wording explicitly described a two-stage sequential process ("stage 1 first and then stage 2") where each stage accommodates one train at a time. This allowed models to easily pattern-match the scenario to the classic two-machine flow-shop problem and immediately apply Johnson's rule. I replaced the verbal description of the stages with recursive equations that define the exact completion times. Models must now analyze these recurrences to recognize that they represent the makespan of a two-machine flow shop before they can apply the intended algorithm.
