# Sequence Evaluation Iteration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a collection of **j** elements. Each element has two associated integer values: a primary modifier (**U**) and a secondary modifier (**V**).

You must arrange these **j** elements into a single sequence. Once an order is chosen, let $(U_1, V_1), (U_2, V_2), \dots, (U_j, V_j)$ be the modifiers of the elements in your chosen sequence from first to last.

We define two running totals, $\alpha$ and $\beta$, over this sequence.
Initially, before any elements are processed, $\alpha_0 = 0$ and $\beta_0 = 0$.
For each position $k$ from 1 to $j$, the values are updated as follows:
- First, $\alpha_k$ is calculated as $\alpha_{k-1} + U_k$.
- Then, $\beta_k$ is calculated by taking the maximum of $\alpha_k$ and $\beta_{k-1}$, and adding $V_k$ to that maximum.

Your objective is to find an arrangement of the **j** elements that minimizes the final value $\beta_j$. Output this minimum possible value of $\beta_j$.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **U** and **V** (1 ≤ U, V ≤ 1000000): the primary modifier and the secondary modifier of an element, respectively.

## Output

Print a single integer: the minimum possible value of $\beta_j$ over all possible arrangements.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, an optimal sequence is to order the elements as follows: (1, 3), then (2, 4), then (3, 2).
- For the first element (1, 3): $\alpha_1 = \alpha_0 + 1 = 0 + 1 = 1$. Then, $\beta_1 = \max(\alpha_1, \beta_0) + 3 = \max(1, 0) + 3 = 4$.
- For the second element (2, 4): $\alpha_2 = \alpha_1 + 2 = 1 + 2 = 3$. Then, $\beta_2 = \max(\alpha_2, \beta_1) + 4 = \max(3, 4) + 4 = 8$.
- For the third element (3, 2): $\alpha_3 = \alpha_2 + 3 = 3 + 3 = 6$. Then, $\beta_3 = \max(\alpha_3, \beta_2) + 2 = \max(6, 8) + 2 = 10$.
The final value $\beta_3$ is 10, which is the minimum possible result.

This forces the model to algebraically recognize the structure of Johnson's rule rather than relying on scheduling keywords.
