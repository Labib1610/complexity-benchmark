# Problem B — Stress Testing

Time limit: 1 s   Memory limit: 256 MB

## Description

You are setting up a sequential stress-testing track with **j** different stress-inducers. You must arrange the inducers into a strict sequence from position 1 to position **j**.

Each inducer has a specific heating parameter and a specific cooling parameter.

Once you have chosen the sequence of the **j** inducers, a diagnostic sensor will be attached to exactly one of them. If the sensor is attached to the **k**-th inducer in your sequence (where $1 \le k \le j$), it will record a total stress value equal to:
- The sum of the heating parameters of all inducers from position 1 to position **k** (inclusive), PLUS
- The sum of the cooling parameters of all inducers from position **k** to position **j** (inclusive).

Because the sensor's placement is determined by a randomized auditing system after your sequence is set, you must prepare for the worst-case scenario. The *peak stress* of your sequence is defined as the maximum possible total stress value the sensor could record, over all **j** possible attachment positions **k**.

You are given the heating and cooling parameters for each inducer. Determine the arrangement of the inducers that minimizes the peak stress. Output this minimum possible peak stress.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the heating parameter and the cooling parameter of an inducer.

## Output

Print a single integer: the smallest possible peak stress you can achieve by optimally arranging the inducers.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single inducer has a heating parameter of 5 and a cooling parameter of 3. The only possible sensor attachment is at position k=1. The recorded stress is the sum of heating parameters up to position 1 (which is 5) plus the sum of cooling parameters from position 1 onwards (which is 3), giving a peak stress of 5 + 3 = 8.

<RATIONALE>
The previous wording explicitly described the step-by-step timeline of a two-machine flow shop, allowing models to instantly recognize the classic scheduling problem and apply Johnson's rule. This rewrite replaces the sequential timeline with its exact mathematical equivalent: a closed-form minimax over prefix and suffix sums. Models must now bridge the conceptual gap between this minimax formulation and the sorting strategy, which prevents surface-level pattern matching on scheduling keywords.
</RATIONALE>
<PRESERVED_ANSWER>
The makespan of a two-machine flow shop is mathematically identical to the maximum, over all k, of the sum of the first processing times up to k plus the sum of the second processing times from k onwards; therefore, the objective function evaluates to the exact same value for every permutation.
</PRESERVED_ANSWER>

The problem remains solvable in O(n log n) time using Johnson's rule, as the underlying mathematical optimization is unchanged.
</PRESERVED_CLASS>
