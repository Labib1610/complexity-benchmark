# Problem B — Testing Facility

Time limit: 1 s   Memory limit: 256 MB

## Description

A single-track testing facility evaluates a fleet of **j** prototype vehicles. The track consists of two sequential zones: an acceleration straightway followed immediately by a handling course. Every vehicle must complete the straightway before it can begin the handling course.

Because the facility operates on a single continuous guide rail, vehicles can never overtake each other. The sequence in which vehicles enter the straightway will be the exact same sequence in which they proceed through the handling course. Safety protocols dictate that the straightway can accommodate at most one vehicle at any given moment, and similarly, the handling course can accommodate at most one vehicle at a time. A vehicle will wait between zones if it finishes the straightway but the handling course is currently occupied by the preceding vehicle.

You are provided with the duration each vehicle requires to complete the straightway, and the duration it requires to complete the handling course. You must choose the entry sequence for the vehicles to minimize the total elapsed time from when the first vehicle enters the straightway until the final vehicle finishes the handling course. Report this minimum possible completion time.

## Input

The first line contains a single integer **j**, the number of prototype vehicles. The value of **j** is at least 1, and its maximum possible value corresponds exactly to the number of distinct 6-character ID codes where the first character is either 'A' or 'B', and the remaining five characters are digits from 0 to 9.

Each of the next **j** lines contains two integers: the duration required for the vehicle on the straightway, and the duration required on the handling course. Each duration is at least 1, and no single duration exceeds the number of millimeters in exactly one kilometer.

## Output

Print a single integer: the earliest possible time the final vehicle can finish the handling course.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single vehicle takes 5 time units on the straightway and then 3 time units on the handling course, finishing at time 8.
