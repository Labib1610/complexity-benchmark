# Problem B — Pivot Cost Optimization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of **j** elements. Each element has two associated values: a left-weight **t1** and a right-weight **t2**.

You must arrange these **j** elements into a linear sequence. Let your chosen sequence of elements be indexed from 1 to **j**. 

For any chosen index $k$ (where $1 \le k \le j$), we define the *pivot cost* at $k$ as the sum of the left-weights of all elements from position 1 to $k$ inclusive, plus the sum of the right-weights of all elements from position $k$ to **j** inclusive. Note that the element at position $k$ contributes both its left-weight and its right-weight to this pivot cost.

The *overall cost* of your sequence is the maximum pivot cost evaluated over all possible choices of $k$ ($1 \le k \le j$). 

Your task is to find an arrangement of the elements that minimizes this overall cost, and output the minimum possible overall cost.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the left-weight and the right-weight of an element.

## Output

Print a single integer: the smallest possible overall cost among all valid sequences.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single element has a left-weight of 5 and a right-weight of 3. The only possible sequence has this element at position 1. The pivot cost at $k=1$ is the left-weight of the first element (5) plus the right-weight of the first element (3), which is 5 + 3 = 8. The overall cost is exactly 8.

The problem was completely reframed from a scheduling task involving phases and timelines into an algebraic array optimization task. By presenting the objective as a minimax over prefix and suffix sums, the identical completion-time math is preserved without triggering semantic recognition of the two-machine flow-shop problem, forcing the model to either derive Johnson's rule mathematically or discover the structural isomorphism itself.
</RATIONALE>
<PRESERVED_ANSWER>
The makespan of a 2-machine flow shop is mathematically identical to the maximum over all $k$ of the sum of stage 1 times up to $k$ plus the sum of stage 2 times from $k$, meaning the optimal permutations and their resulting values are exactly the same.
</PRESERVED_ANSWER>
