<STATEMENT>
# Problem B — Canal Convoy

Time limit: 1 s   Memory limit: 256 MB

## Description

A fleet of **j** vessels is scheduled to travel down a canal. Each vessel is defined by a Primary duration and a Secondary duration.

You must choose the sequence in which the vessels travel. Once the sequence is chosen, we calculate two milestones for each vessel at position $k$ (from $k=1$ to $j$) in your sequence:
- The **Primary Milestone** of the vessel at position $k$ is the sum of the Primary durations of all vessels from position $1$ up to position $k$.
- The **Secondary Milestone** of the vessel at position $k$ is calculated by taking the maximum of two values: the Primary Milestone of the vessel at position $k$, and the Secondary Milestone of the vessel at position $k-1$ (if $k=1$, this previous Secondary Milestone is considered to be 0). The Secondary duration of the vessel at position $k$ is then added to this maximum to establish its Secondary Milestone.

Your task is to determine the sequence that minimizes the Secondary Milestone of the final vessel (at position $j$), and output this minimum possible value.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the Primary duration and the Secondary duration of a vessel.

## Output

Print a single integer: the smallest possible Secondary Milestone of the final vessel.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single vessel has a Primary duration of 5 and a Secondary duration of 3. Its Primary Milestone is 5. Its Secondary Milestone is max(5, 0) + 3 = 8.

I replaced the explicit physical delay process ("Alpha phase", "Beta phase", "waiting for preceding vessel") with an equivalent mathematical recurrence over a sequence. This forces models to algebraically recognize that the recurrence computes the makespan of a two-machine flow shop, rather than relying on standard scheduling terminology to retrieve Johnson's rule.
</RATIONALE>
<PRESERVED_ANSWER>
The recurrence precisely calculates the completion time of each vessel in a two-stage sequential process without gaps or overtaking, meaning the final calculated value matches the original completion time for any given sequence.
</PRESERVED_ANSWER>

The mathematical objective is identical to the makespan of a two-machine flow-shop problem, which remains optimally solvable in O(n log n) time using Johnson's algorithm.
</PRESERVED_CLASS>
