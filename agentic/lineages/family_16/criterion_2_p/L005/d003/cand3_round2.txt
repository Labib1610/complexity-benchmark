# Problem B — Stratigraphic Core Alignment

Time limit: 1 s   Memory limit: 256 MB

## Description

You are analyzing **j** distinct geological sites. For each site, you have measured the thickness of its upper "Shale" layer and its lower "Limestone" layer.

You must arrange these **j** sites in a sequence from left to right (from position 1 to position **j**). 

Once the sequence is chosen, we model an underground water current that travels through the layers. The current enters the Shale layer of the first site in your sequence. It flows rightward through the Shale layers. At exactly one chosen site **k** (where 1 ≤ **k** ≤ **j**), the current percolates downward into the Limestone layer of that same site. It then continues flowing rightward through the Limestone layers until it exits after the **j**-th site.

The total transit resistance of the current, if it percolates downward at site **k**, is calculated as:
(Sum of Shale thicknesses for sites 1 through **k** inclusive) + (Sum of Limestone thicknesses for sites **k** through **j** inclusive).

The current will naturally find the percolation site **k** that results in the MAXIMUM possible total transit resistance. We call this worst-case resistance the "sequence rating".

Your task is to choose the left-to-right arrangement of the **j** sites that MINIMIZES the sequence rating. Output this minimum possible sequence rating.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the Shale thickness and the Limestone thickness of a site.

## Output

Print a single integer: the smallest possible sequence rating.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if we arrange the sites in the original input order (Site 1, Site 2, Site 3):
- For **k**=1: Resistance is 3 + (2+4+3) = 12.
- For **k**=2: Resistance is (3+2) + (4+3) = 12.
- For **k**=3: Resistance is (3+2+1) + 3 = 9.
The sequence rating (the maximum of these resistances) is max(12, 12, 9) = 12.

However, if we arrange them in the order Site 3, Site 2, Site 1:
- For **k**=1: Resistance is 1 + (3+4+2) = 10.
- For **k**=2: Resistance is (1+2) + (4+2) = 9.
- For **k**=3: Resistance is (1+2+3) + 2 = 8.
The sequence rating is max(10, 9, 8) = 10. This is the minimum possible sequence rating for any arrangement.

In Example 2, there is only **j**=1 site. The only possible sequence is the site itself. The current must percolate at **k**=1. The transit resistance is the Shale thickness of site 1 (5) plus the Limestone thickness of site 1 (3), giving a sequence rating of 8.
