# Problem B — Canal Convoy

Time limit: 1 s   Memory limit: 256 MB

## Description

A fleet of **j** vessels must travel down a narrow canal in a single-file convoy. Each vessel has two characteristic timings: a primary transit duration and a secondary transit duration.

Because the canal is strictly one-lane and overtaking is physically impossible, you must arrange the given fleet into a sequence $v_1, v_2, \dots, v_j$. 

Once the sequence is chosen, the canal authority evaluates the convoy's *overall transit time*. To do this, they check every possible position $k$ (where $1 \le k \le j$) as a potential "pivot" vessel. 
For a given pivot at position $k$, the *pivot cost* is defined as:
- The sum of the primary transit durations of all vessels from position 1 to $k$ inclusive, PLUS
- The sum of the secondary transit durations of all vessels from position $k$ to $j$ inclusive.

The *overall transit time* of your chosen sequence is the maximum *pivot cost* across all $j$ possible choices of $k$.

Your task is to determine the sequence of vessels that minimizes this overall transit time, and output this minimum possible value.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the primary transit duration and the secondary transit duration of a vessel.

## Output

Print a single integer: the smallest possible overall transit time.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one vessel, so the sequence is just $v_1$. The only valid pivot is $k=1$. The pivot cost is the primary duration of $v_1$ plus the secondary duration of $v_1$, which is $5 + 3 = 8$. The maximum pivot cost is 8, so the overall transit time is 8.
