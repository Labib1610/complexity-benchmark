# Problem B — Canal Convoy

Time limit: 1 s   Memory limit: 256 MB

## Description

A fleet of **j** vessels must be organized into a strict sequence for a canal crossing. 

Each vessel has two parameters: an Alpha coefficient **t1** and a Beta coefficient **t2**.

The canal system's *base pressure* is determined by the fleet as a whole: it is exactly the sum of the Beta coefficients of all **j** vessels. The system's running pressure begins at this base value.

You must choose the order in which the fleet proceeds. As each vessel is processed in your chosen sequence, it interacts with the system in two steps:
1. The vessel's Alpha coefficient is added to the running pressure. The pressure at this exact moment is recorded as a *peak*.
2. The vessel's Beta coefficient is then subtracted from the running pressure.

This sequence of events happens for every vessel, one by one.

Your task is to determine the optimal sequence of the fleet that minimizes the highest *peak* pressure recorded during the entire process.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the Alpha coefficient and the Beta coefficient of a vessel.

## Output

Print a single integer: the smallest possible highest *peak* pressure you can achieve by optimally sequencing the fleet.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, the sum of all Beta coefficients is 2 + 4 + 3 = 9. The running pressure starts at 9. 
If the sequence of vessels is chosen as (1, 3), then (3, 2), then (2, 4):
- First vessel (1, 3): running pressure increases by 1 to a peak of 10, then decreases by 3 to 7.
- Second vessel (3, 2): running pressure increases by 3 to a peak of 10, then decreases by 2 to 8.
- Third vessel (2, 4): running pressure increases by 2 to a peak of 10, then decreases by 4 to 6.
The highest peak recorded is 10. No other sequence results in a lower highest peak.
