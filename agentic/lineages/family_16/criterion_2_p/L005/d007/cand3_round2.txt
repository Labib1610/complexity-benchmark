# Problem B — River Cascade

Time limit: 1 s   Memory limit: 256 MB

## Description

You are designing a cascade of **j** hydroelectric dams along a river. You must arrange the dams into a strict sequence from upstream (position 1) to downstream (position **j**), determining exactly which dam is first, second, and so on.

Each dam has two structural properties: its *base width* **t1** and its *spillway height* **t2**.

After the sequence is built, an inspection station will be placed at exactly one of the dams. Let the chosen dam be at position $k$ (where $k$ ranges from $1$ to $j$) in your sequence.

The *inspection cost* for a station placed at position $k$ is calculated as the sum of two values:
- The sum of the *base widths* of all dams from position $1$ up to position $k$ of your sequence (inclusive).
- PLUS the sum of the *spillway heights* of all dams from position $k$ up to position $j$ of your sequence (inclusive).

Because the station's location $k$ is chosen after construction by an independent auditor who wants to maximize the cost, the *vulnerability score* of your entire sequence is defined as the maximum *inspection cost* calculated among all $j$ possible choices for the station position $k$.

Your task is to determine the optimal sequence of the dams that minimizes this overall *vulnerability score*.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the base width and the spillway height of a dam.

## Output

Print a single integer: the smallest possible *vulnerability score* you can achieve by optimally sequencing the dams.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one dam ($j=1$). The only possible station position is $k=1$. The inspection cost for $k=1$ is the base width of the first dam (5) plus the spillway height from position 1 onwards (3). The vulnerability score is therefore 5 + 3 = 8.
