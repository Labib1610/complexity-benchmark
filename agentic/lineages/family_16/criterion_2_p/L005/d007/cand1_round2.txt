# Problem B — Data Pipeline

Time limit: 1 s   Memory limit: 256 MB

## Description

You are configuring a sequential pipeline of **j** data processing modules. You must determine the exact order in which these modules operate.

Each module has two parameters: its *allocation requirement* **t1**, and its *release capacity* **t2**.

When the pipeline runs, it tracks the system's *active footprint* at each step. This footprint is calculated as follows:
First, determine the *baseline footprint*, which is simply the sum of the release capacities (**t2**) of all **j** modules in the pipeline.

The active footprint is then recorded at each step $k$ (from $1$ to $j$) as the pipeline progresses:
- For the first module ($k = 1$), the footprint is the allocation requirement of the first module PLUS the baseline footprint.
- For each subsequent module ($k$ from $2$ to $j$), the footprint is the footprint at step $k-1$, PLUS the allocation requirement of the $k$-th module, MINUS the release capacity of the $(k-1)$-th module.

The *peak footprint* of the pipeline is the maximum active footprint recorded across all $j$ steps.

Your task is to arrange the modules into a sequence that minimizes this overall *peak footprint*.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the allocation requirement and the release capacity of a module.

## Output

Print a single integer: the smallest possible *peak footprint* you can achieve by optimally sequencing the modules.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, consider the sequence of modules given by the third input, then the first, then the second.
The modules' parameters in this order are:
Module 1: t1 = 1, t2 = 3
Module 2: t1 = 3, t2 = 2
Module 3: t1 = 2, t2 = 4

The baseline footprint is the sum of all t2 values: 3 + 2 + 4 = 9.

The active footprint is recorded as follows:
- Step 1: footprint is t1 of Module 1 plus baseline = 1 + 9 = 10.
- Step 2: footprint is previous footprint (10) + t1 of Module 2 (3) - t2 of Module 1 (3) = 10.
- Step 3: footprint is previous footprint (10) + t1 of Module 3 (2) - t2 of Module 2 (2) = 10.

The peak footprint across all steps is 10. It is impossible to achieve a peak footprint strictly less than 10 with any other sequence.
</STATEMENT>
<RATIONALE>
Replaced the explicit prefix-suffix sum with an exact mathematical equivalent expressed as a step-by-step recurrence relation. This removes the surface-level pattern that models use to immediately identify the 2-machine flow-shop makespan, forcing them to algebraically expand the recurrence to discover the underlying structure.
</RATIONALE>
<PRESERVED_ANSWER>
The recurrence $F_k = F_{k-1} + t1_k - t2_{k-1}$ with base case $F_1 = t1_1 + \sum t2_i$ is algebraically identical to the prefix-suffix sum $\sum_{i=1}^k t1_i + \sum_{i=k}^j t2_i$, so the objective value for any sequence is exactly the same as in the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Since the objective function is mathematically identical to the seed problem, the optimal sequence is the same and can still be found in $O(n \log n)$ time using Johnson's rule.
</PRESERVED_CLASS>
