<STATEMENT>
# Problem B — Canal Convoy

Time limit: 1 s   Memory limit: 256 MB

## Description

You are managing a canal that processes a fleet of **j** ships. The canal has an entry gate and an exit gate. For each ship, you know its required transit duration through the entry gate and its required transit duration through the exit gate.

Because the canal is extremely narrow, no ship can overtake another. You must dispatch the ships into the canal one by one. Let the chosen arrangement of dispatched ships be $S_1, S_2, \ldots, S_j$. The timing of their progress is determined by the following events:

- The entry gate processes the ships continuously. The $k$-th ship dispatched finishes the entry gate at time $E_k = E_{k-1} + t1(S_k)$, where $E_0 = 0$ and $t1(S_k)$ is its entry gate duration.
- The exit gate processes a ship only after it has cleared the entry gate. Because no overtaking is physically possible, the exit gate naturally processes the ships in the exact same arrangement $S_1, S_2, \ldots, S_j$.
- The $k$-th ship can begin its exit gate transit only when it has cleared the entry gate (at time $E_k$) and the exit gate is no longer occupied by the previous ship (at time $X_{k-1}$).
- Thus, the $k$-th ship finishes the exit gate at time $X_k = \max(E_k, X_{k-1}) + t2(S_k)$, where $X_0 = 0$ and $t2(S_k)$ is its exit gate duration.

Your task is to choose the arrangement $S_1, S_2, \ldots, S_j$ that minimizes the time at which the final ship clears the exit gate (i.e., minimizes $X_j$).

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the duration in the entry gate and the duration in the exit gate of a ship.

## Output

Print a single integer: the smallest possible value for $X_j$ (the time all ships have completely cleared the exit gate).

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single ship finishes the entry gate at $E_1 = 0 + 5 = 5$. It finishes the exit gate at $X_1 = \max(5, 0) + 3 = 8$.
