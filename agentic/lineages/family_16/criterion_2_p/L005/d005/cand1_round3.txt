# Problem B — Artifact Resonance

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a collection of **j** artifacts. You must arrange all **j** artifacts into a strict sequence.

For each artifact, you are given its stabilization factor, **t1**, and its disruption factor, **t2**.

When you process the artifacts in your chosen sequence, you track an "instability level". The process follows these exact rules:
- Before processing the first artifact in your sequence, your instability level is 0.
- You process the artifacts one by one in your chosen order.
- When you process an artifact, it updates your instability level in two sequential steps:
  1. First, the artifact's stabilization factor **t1** reduces the instability level. The instability level cannot drop below zero. If `I` is the instability level before processing this artifact, it becomes `I_mid = max(0, I - t1)`.
  2. Second, the artifact's disruption factor **t2** increases the instability level. The new instability level after the artifact is fully processed becomes `I_mid + t2`.

After all **j** artifacts have been processed, the "total resonance" of your sequence is calculated. The total resonance is defined exactly as:
(The sum of the stabilization factors **t1** of all **j** artifacts) + (Your final instability level).

Your task is to determine the optimal ordering of the artifacts that minimizes the total resonance.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the stabilization factor and the disruption factor of an artifact.

## Output

Print a single integer: the smallest possible total resonance you can achieve by ordering the artifacts optimally.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single artifact has a stabilization factor of 5 and a disruption factor of 3. The initial instability level `I` is 0.
First, applying the stabilization factor yields `I_mid = max(0, 0 - 5) = 0`.
Second, applying the disruption factor yields a final instability level of `0 + 3 = 3`.
The sum of the stabilization factors for all artifacts is 5.
The total resonance is 5 + 3 = 8.
