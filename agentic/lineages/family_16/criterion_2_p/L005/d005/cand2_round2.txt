<STATEMENT>
# Problem B — Canal Convoy

Time limit: 1 s   Memory limit: 256 MB

## Description

A fleet of **j** vessels must be organized for a canal crossing. You must arrange the fleet into a strict sequence, determining exactly which vessel is first, second, and so on.

For each vessel, the crossing consists of two distinct operational phases: the Alpha phase and the Beta phase. You are provided the duration of the Alpha phase, **t1**, and the duration of the Beta phase, **t2**, for each vessel.

The timeline of these operational phases across the entire fleet is strictly dictated by the following event constraints:
- The Alpha phase for the first vessel in your sequence begins at time 0.
- For every vessel after the first, its Alpha phase begins at the exact moment the Alpha phase of the preceding vessel ends.
- A vessel's Beta phase begins at the earliest moment when all applicable conditions below are true:
  1. The vessel's own Alpha phase has ended.
  2. If the vessel is not the first in the sequence, the Beta phase of the preceding vessel has ended.
- A vessel's Alpha phase lasts exactly its given **t1** duration.
- A vessel's Beta phase lasts exactly its given **t2** duration.

Your task is to determine the optimal sequence of the fleet that minimizes the time at which the Beta phase for the final vessel ends.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the Alpha phase duration and the Beta phase duration of a vessel.

## Output

Print a single integer: the smallest possible time at which the final vessel in your sequence ends its Beta phase.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single vessel has an Alpha phase duration of 5 and a Beta phase duration of 3. Its Alpha phase begins at 0 and ends at 5. Its Beta phase begins immediately at 5, ending at time 5 + 3 = 8.

<RATIONALE>
Removed the physical "lock" and "transit" terminology that strongly signals a two-machine flow shop. Replaced it with pure event precedence rules (Alpha phase and Beta phase) that define the exact same mathematical recurrence. This forces models to derive the makespan logic from first principles rather than pattern-matching standard scheduling descriptions.
</RATIONALE>
<PRESERVED_ANSWER>
The event constraints mathematically enforce the exact same timeline as the original two sequential locks: Alpha phases run consecutively without gaps, and Beta phases run consecutively but wait for their corresponding Alpha phases to finish.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the 2-machine permutation flow-shop makespan minimization problem, which is solvable optimally in O(n log n) time using Johnson's rule.
</PRESERVED_CLASS>
