# Problem B — Tile Grid Path

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given **j** tiles. Each tile features two integers: a top value **t1** and a bottom value **t2**.

You must arrange all **j** tiles in a single horizontal line to form a grid with 2 rows and **j** columns. You may choose any left-to-right order for the tiles, but you cannot rotate or flip them (the top value must remain in the top row, and the bottom value must remain in the bottom row).

Consider a token that starts at the top-left cell of your grid and must travel to the bottom-right cell. The token can only move in two ways:
- Move one cell to the right.
- Move one cell down.

The cost of a path is the sum of the values in all the cells the token visits, including the starting and ending cells. Because the grid has exactly 2 rows, any valid path will move right along the top row to some column $k$, move down to the bottom row at column $k$, and then continue right along the bottom row until the end of the grid.

The "adversarial score" of a specific arrangement of tiles is the MAXIMUM possible path cost among all valid paths the token could take from the top-left to the bottom-right.

Your task is to determine the optimal left-to-right ordering of the tiles that MINIMIZES this adversarial score.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the top value and the bottom value of a tile.

## Output

Print a single integer: the smallest possible adversarial score.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

For Example 1, an optimal arrangement of the tiles is to place them in the order: (1, 3), (2, 4), and then (3, 2).
This forms the following grid:
Row 1:  1  2  3
Row 2:  3  4  2

The possible paths for the token are:
- Move down at column 1: visits 1, 3, 4, 2. Cost = 1 + 3 + 4 + 2 = 10.
- Move down at column 2: visits 1, 2, 4, 2. Cost = 1 + 2 + 4 + 2 = 9.
- Move down at column 3: visits 1, 2, 3, 2. Cost = 1 + 2 + 3 + 2 = 8.

The adversarial score (maximum path cost) for this arrangement is 10. No other arrangement yields a smaller maximum path cost.
