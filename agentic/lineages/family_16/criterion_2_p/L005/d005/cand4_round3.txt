# Problem B — Dual-Phase Signal Alignment

Time limit: 1 s   Memory limit: 256 MB

## Description

A burst of $j$ signals must be transmitted through a narrow channel. You must arrange the signals into a strict sequence.

The channel features exactly two sequential filters: Filter Alpha and Filter Beta. Every signal must pass Filter Alpha before it can pass Filter Beta. Both filters process the signals in the exact same chosen sequence (a single permutation).

For each signal, you are given its Filter Alpha processing coefficient, $t_1$, and its Filter Beta processing coefficient, $t_2$.

The alignment of the transmission adheres to the following rules:
- The first signal in your sequence begins its Filter Alpha processing at an offset of 0.
- Filter Alpha can only accommodate one signal at a time. It processes the signals back-to-back with no gap; as soon as one signal establishes its Filter Alpha completion offset, the next signal in the sequence immediately begins.
- Filter Beta can also only accommodate one signal at a time.
- A signal may only begin its Filter Beta processing once both of the following prerequisites are met:
  1. It has fully established its own completion offset through Filter Alpha.
  2. The preceding signal in your sequence (if any) has fully established its completion offset through Filter Beta.
- Once permitted to enter a filter, a signal adds exactly its specific processing coefficient ($t_1$ or $t_2$) to the current offset to establish its completion offset for that filter.

Your task is to determine the optimal ordering of the signals that minimizes the final completion offset of the last signal in your sequence through Filter Beta.

*Mathematical Clarification:*
Equivalently, for a chosen sequence of signals, if we denote the Filter Alpha coefficient of the $i$-th signal in the sequence as $A_i$ and its Filter Beta coefficient as $B_i$, the final completion offset through Filter Beta evaluates exactly to:
$$ \max_{1 \le k \le j} \left( \sum_{i=1}^k A_i + \sum_{i=k}^j B_i \right) $$
You must find the permutation of the $j$ signals that minimizes this maximum value.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains exactly 2 integers $t_1$ and $t_2$ ($1 \le t_1, t_2 \le 1000000$): the Filter Alpha processing coefficient and the Filter Beta processing coefficient of a signal.

## Output

Print a single integer: the smallest possible final completion offset of the last signal in your sequence through Filter Beta.

## Examples

### Example 1

**Input**

```
2 4
1 3
```

**Output**
```

```

### Example 2

**Input**


**Output**
```

```

### Example 3

**Input**


**Output**
```
8
```

## Note

In Example 2, the single signal has a Filter Alpha coefficient of 5 and a Filter Beta coefficient of 3. It establishes its Filter Alpha completion offset at 5, and immediately begins Filter Beta, establishing a final completion offset of 5 + 3 = 8. (Using the clarification formula, with $k=1$, the sum is $5 + 3 = 8$).
