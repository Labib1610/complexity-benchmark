# Problem B — Sequence Peak

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of **j** elements. Each element has two attributes: a primary value **t1** and a secondary value **t2**.

You must arrange all **j** elements into a single sequence (a permutation).

Once you have chosen a sequence, its overall "peak value" is evaluated. To find the peak value, we consider every possible split point **k** (where 1 ≤ **k** ≤ **j**).

For a specific split point **k**, its cost is calculated as the sum of the primary values (**t1**) of the elements from position 1 to **k** inclusive, plus the sum of the secondary values (**t2**) of the elements from position **k** to **j** inclusive.

The peak value of your sequence is the maximum cost among all **j** possible choices of the split point **k**.

Your task is to determine the optimal ordering of the elements that minimizes this peak value.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains exactly 2 integers **t1** and **t2** (1 ≤ t1, t2 ≤ 1000000): the primary value and the secondary value of an element.

## Output

Print a single integer: the smallest possible peak value achievable by optimally ordering the elements.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, suppose we order the elements such that their original input order becomes: element 3, then element 2, then element 1.
The sequence of (t1, t2) pairs is:
Position 1: (1, 3)
Position 2: (2, 4)
Position 3: (3, 2)

Let's calculate the cost for each possible split point **k**:
- For k = 1: The primary sum is up to position 1: (1). The secondary sum is from position 1 to 3: (3 + 4 + 2 = 9). Cost = 1 + 9 = 10.
- For k = 2: The primary sum is up to position 2: (1 + 2 = 3). The secondary sum is from position 2 to 3: (4 + 2 = 6). Cost = 3 + 6 = 9.
- For k = 3: The primary sum is up to position 3: (1 + 2 + 3 = 6). The secondary sum is from position 3 to 3: (2). Cost = 6 + 2 = 8.

The peak value for this sequence is the maximum of these costs, which is max(10, 9, 8) = 10.
This is the minimum possible peak value among all permutations.
