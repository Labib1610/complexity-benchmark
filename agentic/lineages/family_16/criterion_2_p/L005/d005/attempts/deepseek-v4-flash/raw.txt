We can model the problem as follows:  

For a given order of vessels, the finish time of the last vessel’s Beta phase is:

- Let `A` be the sum of all `t1` values (total Alpha time).
- The Beta phase of the first vessel starts at `t1[0]`.
- For each subsequent vessel `i`, its Beta starts at `max(alpha_end[i], beta_end[i-1])`, where `alpha_end[i]` is the cumulative sum of `t1` up to that vessel.

This is a classic scheduling problem. The optimal ordering is to sort vessels by **decreasing t2** (Beta duration).  
Why? Because longer Beta phases should start as early as possible to avoid delaying the end.

We can prove it by exchange argument: if two adjacent vessels have `t2[i] < t2[i+1]`, swapping them reduces or keeps the same finish time.

So the algorithm:
1. Read all vessels.
2. Sort by `t2` descending.
3. Simulate the process to compute the finish time.

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    j = int(data[0])
    vessels = []
    idx = 1
    for _ in range(j):
        t1 = int(data[idx])
        t2 = int(data[idx+1])
        vessels.append((t1, t2))
        idx += 2

    # Sort by t2 descending
    vessels.sort(key=lambda x: x[1], reverse=True)

    alpha_end = 0
    beta_end = 0
    for t1, t2 in vessels:
        alpha_end += t1
        if beta_end == 0:
            beta_end = alpha_end + t2
        else:
            beta_end = max(alpha_end, beta_end) + t2

    print(beta_end)

if __name__ == "__main__":
    main()
```
