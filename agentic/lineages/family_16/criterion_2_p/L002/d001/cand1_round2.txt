# Problem B — Freight Corridor

Time limit: 1 s   Memory limit: 256 MB

## Description

A logistics company is routing **j** shipments along a dedicated freight corridor. To complete the route, every shipment must pass through a strict sequence of zones: first an entry checkpoint, then an intermediate transit link (which takes zero time), and finally an exit checkpoint. For each shipment, you are given the time it takes to clear the entry checkpoint and the time it takes to clear the exit checkpoint. The following constraints apply:

- Each checkpoint can handle only one shipment at a time.
- A shipment can begin clearance at the exit checkpoint only after it has completely finished clearance at the entry checkpoint.
- You may choose the sequence in which the shipments are processed (both the entry checkpoint and the exit checkpoint process the shipments in the same chosen sequence).

Choose the processing sequence so that the time at which the **last** shipment finishes clearance at the exit checkpoint is as small as possible. Report that smallest possible finish time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the entry clearance time and exit clearance time of a shipment.

## Output

Print a single integer: the smallest possible time at which all shipments finish their exit clearance.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2 the single shipment takes 5 for entry clearance then 3 for exit clearance, finishing at time 8.
</STATEMENT>
<RATIONALE>
The explicit mention of "exactly two operations" was removed and replaced with an indirect routing scenario involving zones and an intermediate zero-time transit link. This prevents models from immediately matching the "two operations" keyword to the classic two-machine flow-shop pattern, forcing them to derive the two-stage structure from the routing constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical task is identical: finding an optimal permutation for a set of items passing through two sequential, single-capacity bottlenecks to minimize the makespan.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the two-machine flow-shop scheduling problem, solvable in O(j log j) time using Johnson's rule.
</PRESERVED_CLASS>
