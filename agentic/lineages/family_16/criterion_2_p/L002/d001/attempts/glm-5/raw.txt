Looking at this problem, I need to find the optimal ordering of ships through two consecutive locks to minimize the makespan.

**Key Insight:** This is a classic two-machine flow shop scheduling problem. Johnson's rule gives the optimal solution.

**Johnson's Rule:**
- Ships with `p1 <= p2` go first, sorted by `p1` ascending
- Ships with `p1 > p2` go later, sorted by `p2` descending

**Why it works:** The bottleneck is the transition between the two locks. Ships that are "fast on upper, slow on lower" should go early to keep the lower lock busy. Ships that are "slow on upper, fast on lower" should go late so they don't block the upper lock unnecessarily.

**Simulation:** After sorting, simulate:
- `upper_free` = time when upper lock is free
- `lower_free` = time when lower lock is free
- For each ship: it starts upper at `upper_free`, finishes upper at `upper_free + p1`, starts lower at `max(finish_upper, lower_free)`, finishes lower at that + p2

The answer is the final `lower_free`.

**Verification with Example 1:**
- Ships: (3,2), (2,4), (1,3)
- Group A (p1≤p2): (1,3), (2,4) → sorted by p1: (1,3), (2,4)
- Group B (p1>p2): (3,2) → sorted by p2 desc: (3,2)
- Order: (1,3), (2,4), (3,2)
- Simulation: upper_free=0→1→3→6; lower_free: 4→8→10 ✓

**Verification with Example 3:**
- All (2,2), p1=p2, all in group A, any order
- upper_free: 0→2→4→6; lower_free: 4→6→8 ✓

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    j = int(data[0])
    idx = 1
    A = []  # p1 <= p2, sort by p1 ascending
    B = []  # p1 > p2, sort by p2 descending
    for _ in range(j):
        p1 = int(data[idx]); p2 = int(data[idx+1])
        idx += 2
        if p1 <= p2:
            A.append((p1, p2))
        else:
            B.append((p1, p2))
    A.sort(key=lambda x: x[0])
    B.sort(key=lambda x: x[1], reverse=True)
    
    upper_free = 0
    lower_free = 0
    for p1, p2 in A:
        upper_free += p1
        if upper_free > lower_free:
            lower_free = upper_free + p2
        else:
            lower_free += p2
    for p1, p2 in B:
        upper_free += p1
        if upper_free > lower_free:
            lower_free = upper_free + p2
        else:
            lower_free += p2
    
    print(lower_free)

main()
```
