# Problem B — Cargo Inspection

Time limit: 1 s   Memory limit: 256 MB

## Description

A port authority manages a fleet of **j** vessels arriving for cargo inspection. You must arrange the vessels into a single sequence $v_1, v_2, \ldots, v_j$.

The inspection involves two sequential phases: Local and Federal. You are given the duration each vessel requires for the Local phase ($p1$), and the duration it requires for the Federal phase ($p2$). 

The progression of the sequence strictly follows these rules, where $L_i$ is the time the $i$-th vessel in your sequence completes its Local phase, and $F_i$ is the time it completes its Federal phase:

- The Local phase processes the sequence of vessels continuously. The $i$-th vessel finishes its Local phase at time $L_i = L_{i-1} + p1_{v_i}$ (where $L_0 = 0$).
- The Federal phase for the $i$-th vessel can only begin when two conditions are satisfied: the vessel has finished its own Local phase (at time $L_i$), and the Federal phase has finished processing the previous vessel in the sequence (at time $F_{i-1}$).
- Once both conditions are met, the $i$-th vessel takes $p2_{v_i}$ units of time to finish its Federal phase. Therefore, it finishes at time $F_i = \max(L_i, F_{i-1}) + p2_{v_i}$ (where $F_0 = 0$).

You must determine an initial sequence of vessels that minimizes $F_j$, the time the final vessel in the sequence completes its Federal phase. Output this minimum possible finish time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for a vessel to complete the Local phase and the Federal phase, respectively.

## Output

Print a single integer: the smallest possible time at which the final vessel completes the Federal phase (i.e., the minimum possible value of $F_j$).

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, with only one vessel, $L_1 = 0 + 5 = 5$. The Federal phase finishes at $F_1 = \max(5, 0) + 3 = 8$.

In Example 1, if we choose the sequence of vessels as the 3rd, then 2nd, then 1st from the input:
- 1st in sequence (input vessel 3): $L_1 = 1$, $F_1 = \max(1, 0) + 3 = 4$.
- 2nd in sequence (input vessel 2): $L_2 = 1 + 2 = 3$, $F_2 = \max(3, 4) + 4 = 8$.
- 3rd in sequence (input vessel 1): $L_3 = 3 + 3 = 6$, $F_3 = \max(6, 8) + 2 = 10$.
This yields the minimum possible $F_3$ of 10.
