# Problem B — Cargo Inspection

Time limit: 1 s   Memory limit: 256 MB

## Description

A port authority manages a fleet of **j** vessels arriving for cargo inspection. The inspection requires two consecutive stages: the Local Desk, followed by the Federal Desk. You are given the duration each vessel takes at the Local Desk, and then the duration it takes at the Federal Desk.

The operational rules are:
- Each desk processes exactly one vessel at a time. Inspections cannot be interrupted once they begin.
- A vessel becomes eligible for the Federal Desk only the moment its Local Desk inspection is completely finished.
- Between desks, vessels gather in a transit zone. The Federal Desk is permitted to select any vessel from this transit zone to inspect next, regardless of the order they arrived from the Local Desk.
- The Local Desk operates continuously, accepting the next vessel as soon as the current one finishes.

You must determine the full schedule: the order vessels are sent to the Local Desk, and the sequence in which the Federal Desk pulls from the transit zone. Choose the schedule that minimizes the time at which the final vessel finishes its Federal Desk inspection. Output this minimum possible finish time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for a vessel to complete the Local Desk and the Federal Desk inspections, respectively.

## Output

Print a single integer: the smallest possible time at which all vessels have completely finished the Federal Desk inspection.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single vessel takes 5 to complete the Local Desk and then 3 to complete the Federal Desk, finishing at time 8.
</STATEMENT>
<RATIONALE>
The previous wording explicitly mandated that vessels be processed on the second machine in the exact same order as the first machine, which is the defining characteristic of a permutation flow-shop. By explicitly allowing the Federal Desk to reorder waiting vessels, the problem appears to be a more complex non-permutation scheduling task. This forces models to either prove that permutation schedules are dominant for two machines or attempt a more complex (and likely incorrect or slow) search algorithm, breaking the direct pattern match to Johnson's rule.
</RATIONALE>
<PRESERVED_ANSWER>
It is a proven theorem in scheduling that for makespan minimization in a two-machine flow shop, permutation schedules (identical order on both machines) are strictly dominant, so allowing reordering does not reduce the optimal finish time.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Because permutation schedules remain dominant and achieve the exact same minimum makespan, the optimal answer can still be found in O(j log j) time by applying Johnson's rule.
</PRESERVED_CLASS>
