# Problem B — Cargo Inspection

Time limit: 1 s   Memory limit: 256 MB

## Description

A port authority manages a fleet of **j** vessels arriving for cargo inspection. You must arrange the fleet into a single line. Two officers, a Local officer and a Federal officer, will inspect the vessels. You are given the duration the Local officer spends on each vessel, followed by the duration the Federal officer spends on it.

You must decide the initial sequence of vessels in the line. Both officers will process the vessels in this exact same chosen order. 

Because the Federal officer's inspection of any vessel can only occur after the Local officer has finished their inspection of that same vessel, the overall duration of the process is constrained by bottleneck points. Specifically, for any chosen sequence of vessels, the time at which the final vessel completely finishes its Federal inspection is given by the maximum possible bottleneck sum. 

If we choose a position $k$ (where $1 \le k \le j$) as the bottleneck, the bottleneck sum at $k$ is calculated by adding the Local inspection durations of all vessels from position 1 to $k$ inclusive, and the Federal inspection durations of all vessels from position $k$ to $j$ inclusive. The total completion time for the entire fleet is the maximum of these bottleneck sums over all $j$ possible choices of $k$.

You must decide the initial sequence of vessels in the line. Choose the sequence that minimizes this total completion time. Output this minimum possible finish time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the Local officer and the Federal officer to inspect a vessel, respectively.

## Output

Print a single integer: the smallest possible time at which all vessels have completely finished the Federal inspection.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single vessel takes 5 for the Local officer and then 3 for the Federal officer, finishing at time 8.

<RATIONALE>
I changed the definition of the final completion time from a step-by-step physical simulation of an officer "waiting" to its exact mathematical equivalent: the maximum prefix-suffix bottleneck sum. This forces the model to recognize the algebraic identity of the 2-machine flow shop makespan rather than relying on the standard narrative triggers, preventing surface pattern matching while fully respecting the seed's scheduling semantics.
</RATIONALE>
<PRESERVED_ANSWER>
The maximum prefix-suffix bottleneck sum is mathematically identical to the makespan of a 2-machine flow shop for any given sequence, so the optimal sequence and its completion time remain exactly unchanged.
</PRESERVED_ANSWER>
