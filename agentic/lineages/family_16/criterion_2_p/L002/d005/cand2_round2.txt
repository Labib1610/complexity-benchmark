# Problem B — Array Evaluation

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a collection of $j$ items. Each item has two positive integer values associated with it: $p_1$ and $p_2$.

You must arrange all $j$ items into a single sequence $S = (s_1, s_2, \dots, s_j)$. 

For any chosen sequence $S$, we define its *bottleneck value*. To compute it, we evaluate a function $E(k)$ for every index $k \in \{1, 2, \dots, j\}$. The value of $E(k)$ is defined as the sum of $p_1$ for all items from index $1$ up to $k$ inclusive, plus the sum of $p_2$ for all items from index $k$ up to $j$ inclusive. 

Formally, for a given index $k$:
$$E(k) = \sum_{i=1}^k p_1(s_i) + \sum_{i=k}^j p_2(s_i)$$

Note that the item at index $k$, $s_k$, is included in both sums. Its $p_1$ value contributes to the first sum, and its $p_2$ value contributes to the second sum.

The bottleneck value of the sequence $S$ is the maximum value of $E(k)$ over all possible choices of $k$ ($1 \le k \le j$):
$$B(S) = \max_{1 \le k \le j} E(k)$$

Your goal is to choose the sequence $S$ that minimizes $B(S)$, and output this minimum possible bottleneck value.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$) for that item.

## Output

Print a single integer: the smallest possible bottleneck value $B(S)$ across all valid sequences.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence is to place the third item first, then the second item, then the first item. 
The chosen sequence of $(p_1, p_2)$ pairs is: $s_1 = (1, 3)$, $s_2 = (2, 4)$, $s_3 = (3, 2)$.
We evaluate $E(k)$ for each $k \in \{1, 2, 3\}$:
- For $k=1$: $E(1) = p_1(s_1) + [p_2(s_1) + p_2(s_2) + p_2(s_3)] = 1 + (3 + 4 + 2) = 10$.
- For $k=2$: $E(2) = [p_1(s_1) + p_1(s_2)] + [p_2(s_2) + p_2(s_3)] = (1 + 2) + (4 + 2) = 9$.
- For $k=3$: $E(3) = [p_1(s_1) + p_1(s_2) + p_1(s_3)] + p_2(s_3) = (1 + 2 + 3) + 2 = 8$.

The bottleneck value for this sequence is $\max(10, 9, 8) = 10$. No sequence can achieve a bottleneck value strictly less than 10.

In Example 2, there is only one item, so $k=1$. $E(1) = 5 + 3 = 8$.
