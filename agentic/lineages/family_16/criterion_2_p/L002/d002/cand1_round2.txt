# Problem B — Canal Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

A port director is coordinating the departure of **j** vessels. Each vessel has a specific departure protocol consisting of two mandatory clearances: a local clearance (duration **p1**) and a federal clearance (duration **p2**).

The port operates under strict regulations:
- The director must publish a single, fixed departure roster for the fleet.
- The local clearance desk calls vessels exactly in the order of this roster. It can only serve a single vessel at a time. Once a vessel finishes here, the desk immediately begins serving the next vessel on the roster.
- After finishing local clearance, a vessel proceeds to the federal clearance desk. This desk also serves only one vessel at a time.
- A vessel cannot begin its federal clearance until its local clearance is fully complete.
- The corridor between the desks is strictly single-file. Consequently, no vessel can bypass another, meaning the federal clearance desk is forced to process the vessels in the exact same sequence as the published roster.

Assuming the local clearance desk begins processing the first vessel on the roster at time 0, your task is to determine the optimal roster of vessels that minimizes the absolute time when the final vessel finishes its federal clearance. Output this minimal completion time.

## Input

The first line provides a single integer **j**, representing the number of vessels. The port requires a minimum fleet size of 1 and has a maximum capacity of 200000 vessels.
Each of the subsequent **j** lines provides two integers **p1** and **p2**, specifying the time required for the local and federal clearances, respectively. The physical limits of the port dictate that any clearance duration takes at least 1 time unit, up to a regulatory maximum of 1000000 time units.

## Output

Print a single integer: the smallest possible time at which all vessels have completely finished their federal clearance.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single vessel takes 5 to clear the local desk and then 3 to clear the federal desk, finishing at time 8.
