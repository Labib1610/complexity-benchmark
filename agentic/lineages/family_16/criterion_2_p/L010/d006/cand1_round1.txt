# Problem B — Temporal Anomaly Mitigation

Time limit: 1 s   Memory limit: 256 MB

## Description

You are tasked with stabilizing a timeline by executing a batch of $j$ chronal shifts. You must arrange the $j$ given shifts into a single sequence $S_1, S_2, \dots, S_j$ (a permutation of the given shifts).

Each shift has a Forward phase $d_1$ and a Reverse phase $d_2$. Let $d_1(S_k)$ and $d_2(S_k)$ denote the respective phases for the shift placed at position $k$ in your sequence.

The total forward displacement $T$ is the sum of the Forward phases of all $j$ shifts. This value $T$ is constant regardless of your chosen sequence:
$T = \sum_{k=1}^j d_1(S_k)$

When the sequence is executed, each shift produces a localized temporal anomaly. The **anomaly magnitude** at position $k$ ($1 \le k \le j$) is calculated as follows:
1. Start with the total forward displacement $T$.
2. Add the Reverse phase of the shift at position $k$.
3. For every shift placed strictly *after* position $k$ in the sequence (i.e., positions $k+1$ through $j$), add its Reverse phase and subtract its Forward phase.

Formally, the anomaly magnitude $A_k$ at position $k$ is:
$A_k = T + d_2(S_k) + \sum_{i=k+1}^j \left( d_2(S_i) - d_1(S_i) \right)$
*(Note: If $k = j$, the sum over $i$ from $j+1$ to $j$ is empty and equals 0).*

Your goal is to find a sequence of the $j$ shifts that minimizes the maximum anomaly magnitude produced across all $j$ positions. Report this smallest possible maximum anomaly magnitude.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the Forward and Reverse phases of a shift.

## Output

Print a single integer: the smallest possible maximum anomaly magnitude across all positions.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only $j=1$ shift with $d_1 = 5$ and $d_2 = 3$. 
The total forward displacement $T = 5$. 
The anomaly magnitude at position $k=1$ is calculated as:
$A_1 = T + d_2(S_1) + 0 = 5 + 3 + 0 = 8$. 
The maximum anomaly magnitude is 8, which is the minimum possible.
</STATEMENT>
<RATIONALE>
I completely removed the two-track flow-shop geometry, which models were heavily pattern-matching. Instead, the problem is framed algebraically using a localized anomaly formula. By introducing the constant $T$ (sum of all $d_1$), the standard makespan prefix/suffix sum structure is obfuscated into a base value minus a suffix sum of differences. This forces models to genuinely reason: they must either algebraically simplify the formula to recognize the underlying structure, or derive the correct greedy sorting condition from scratch using an adjacent-exchange argument.
</RATIONALE>
<PRESERVED_ANSWER>
The anomaly magnitude formula $T + d_2(k) + \sum_{i=k+1}^j (d_2(i) - d_1(i))$ algebraically simplifies exactly to $\sum_{i=1}^k d_1(i) + \sum_{i=k}^j d_2(i)$ for any sequence, which is the exact makespan of the original 2-machine flow-shop problem, ensuring the maximum over all $k$ is identical for every possible permutation.
</PRESERVED_ANSWER>

Because the objective function evaluated for any permutation is mathematically identical to the original makespan, the optimal sequence is still found using the exact same $O(j \log j)$ sorting logic (Johnson's rule).
