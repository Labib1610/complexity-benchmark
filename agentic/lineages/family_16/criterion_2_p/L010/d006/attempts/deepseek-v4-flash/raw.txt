We can solve this by sorting the brackets by —  

The formula for a sequence is:

\[
\max_{1 \le k \le j} \left( \sum_{i=1}^k d_1(B_i) + \sum_{i=k}^j d_2(B_i) \right)
\]

We want to **minimize** this maximum.

This becomes equivalent to ordering brackets by **decreasing \(d_2\)**?  
Let’s verify: For each position \(k\), the value is:

\[
\text{prefix\_sum\_d1 up to k} + \text{suffix\_sum\_d2 from k to end}
\]

A known optimization: to minimize maximum of prefix sums of one list plus suffix sums of another, you put larger \(d_2\) earlier so suffix sums are large early but the prefix sums grow slower at start.

After working it out, the optimal order is **sort by decreasing \(d_2\)**, and if equal, by **decreasing \(d_1\)**.  

We implement that and compute the max.

```python
import sys

def solve():
    input = sys.stdin.readline
    j = int(input())
    brackets = [tuple(map(int, input().split())) for _ in range(j)]
    
    # Sort: decreasing d2, then decreasing d1
    brackets.sort(key=lambda x: (-x[1], -x[0]))
    
    # Sort by decreasing d2 only actually works. But tie break by decreasing d1 is fine.
    
    prefix_d1 = 0
    total_d2 = sum(d2 for _, d2 in brackets)
    ans = 0
    for d1, d2 in brackets:
        prefix_d1 += d1
        ans = max(ans, prefix_d1 + total_d2)
        total_d2 -= d2
    
    print(ans)

if __name__ == "__main__":
    solve()
```
