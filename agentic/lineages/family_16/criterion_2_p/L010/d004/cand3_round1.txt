# Problem B — Orbital Shield Calibration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are calibrating the energy shields of a starcruiser. The calibration process requires executing a batch of $j$ modules in a sequence. You must choose the optimal order to execute all $j$ given modules exactly once.

The ship's diagnostic bay can hold a maximum of 200,000 modules at once, which constrains the maximum possible value of $j$. There is always at least one module.

Each module has two parameters: its energy draw $d_1$ and its thermal output $d_2$. To prevent hardware damage, safety limits dictate that any single parameter (energy draw or thermal output) must be at least 1, and cannot exceed 1,000,000.

The ship's thermal buffer $W$ starts at $0$. When a module with parameters $(d_1, d_2)$ is executed, the following happens in exact order:
1. The module's energy draw $d_1$ powers the cooling systems, reducing the thermal buffer by $d_1$. The buffer cannot drop below zero, so its new value becomes $\max(0, W - d_1)$.
2. The module then dumps its thermal output $d_2$ into the buffer, increasing it by $d_2$. 

Thus, if the buffer was $W$ before the module is executed, it becomes $\max(0, W - d_1) + d_2$ after execution. This updated value becomes the starting buffer $W$ for the next module in your chosen sequence.

Your goal is to find a sequence of all $j$ modules that minimizes the final value of the thermal buffer after all modules have been executed. 

To ensure the output format matches the ship's diagnostic system, you must report a single combined metric. Print a single integer: the total sum of $d_1$ across all $j$ modules, added to the minimized final value of the thermal buffer.

Note: The answer may exceed the capacity of a 32-bit signed integer.

## Input

The first line contains a single integer $j$.
Each of the next $j$ lines contains two integers $d_1$ and $d_2$: the energy draw and thermal output of a module.

## Output

Print a single integer: the sum of all energy draws plus the minimized final thermal buffer.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one module with $d_1 = 5$ and $d_2 = 3$. The thermal buffer starts at $W = 0$.
Upon execution:
1. The buffer is reduced by $d_1$: $\max(0, 0 - 5) = 0$.
2. The buffer is increased by $d_2$: $0 + 3 = 3$.
The final thermal buffer is $3$.
The sum of all energy draws is $5$.
The combined metric to report is $5 + 3 = 8$.
