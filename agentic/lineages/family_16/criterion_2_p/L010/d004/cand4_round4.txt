# Problem B — Terraced Landscape Architecture

Time limit: 1 s   Memory limit: 256 MB

## Description

You are designing a straight, terraced landscape using a batch of $j$ prefabricated modules. You must arrange the $j$ modules into a single sequence $M_1, M_2, \dots, M_j$ (a permutation of the given modules).

Each module features two structural tiers: a Base Tier and an Elevated Tier. For each module, you are given its Base Tier length $p$ and its Elevated Tier length $q$. Let $p(M_k)$ and $q(M_k)$ denote the respective lengths for the module placed at position $k$ in your sequence.

You must assign a starting horizontal coordinate $C_k$ for the Base Tier and a starting horizontal coordinate $D_k$ for the Elevated Tier for each position $k$ ($1 \le k \le j$). The physical placement must satisfy the following non-overlapping and structural rules:
- Along the foundation, the Base Tiers are placed one after another in your chosen sequence without overlapping. Thus, the next module cannot start its Base Tier until the current one's Base Tier ends:
  $C_{k+1} \ge C_k + p(M_k)$ for $1 \le k < j$
- For any given module, its Elevated Tier must be physically supported by its Base Tier. To ensure this, the Elevated Tier must start at or after the coordinate where its own Base Tier ends:
  $D_k \ge C_k + p(M_k)$ for $1 \le k \le j$
- Along the upper level, the Elevated Tiers are placed one after another in the exact same chosen sequence without overlapping. Thus, the next module cannot start its Elevated Tier until the current one's Elevated Tier ends:
  $D_{k+1} \ge D_k + q(M_k)$ for $1 \le k < j$

Assume the terrace foundation begins at $C_1 \ge 0$. Your goal is to find a sequence of the $j$ modules and a valid coordinate assignment that minimizes the furthest horizontal coordinate reached by the final module's Elevated Tier, which is defined as $D_j + q(M_j)$. Report this smallest possible final boundary value.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $p$ and $q$ ($1 \le p, q \le 1000000$): the Base Tier and Elevated Tier lengths of a module.

## Output

Print a single integer: the smallest possible final boundary value.

## Examples

```

**Output**

```

## Note

In Example 2, there is only one module with $p = 5$ and $q = 3$. We can set $C_1 = 0$, satisfying $C_1 \ge 0$. The structural rules require $D_1 \ge C_1 + p(M_1) = 5$. We can set $D_1 = 5$. The final boundary value is $D_1 + q(M_1) = 5 + 3 = 8$.
