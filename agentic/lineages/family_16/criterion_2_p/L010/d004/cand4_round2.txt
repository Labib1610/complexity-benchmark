<STATEMENT>
# Problem B — Structural Pillar Assembly

Time limit: 1 s   Memory limit: 256 MB

## Description

You are designing a support structure using a batch of $j$ specialized load-bearing brackets. You must arrange the $j$ brackets into a single vertical sequence, from first to last (a permutation of the given batch).

Each bracket has two vertical components: a Primary strut and a Secondary strut. For each bracket, you are given the height of its Primary strut, $d_1$, and the height of its Secondary strut, $d_2$. 

The brackets are assembled to form two parallel columns (the Primary column and the Secondary column) governed by the following structural rules:
- The Primary column is built by stacking the Primary struts directly on top of each other, in your chosen sequence, starting from a foundation at elevation 0.
- The Secondary column is built by stacking the Secondary struts directly on top of each other, in the exact same chosen sequence.
- Every bracket features a rigid horizontal crossbar that connects the top of its Primary strut to the bottom of its Secondary strut. Because of this rigid connection, the base of a bracket's Secondary strut cannot be at an elevation lower than the peak of its own Primary strut.
- To make the overall structure as compact as possible, each Secondary strut is placed at the lowest possible elevation that satisfies both the stacking rule (its base must be at or above the peak of the preceding bracket's Secondary strut in your sequence, if any) and the crossbar rule (its base must be at or above its own Primary strut's peak).

Your goal is to find a sequence of the $j$ brackets that minimizes the highest elevation reached by the structure. This is defined as the peak elevation of the final bracket's Secondary strut. Report this smallest possible final peak elevation.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the heights of the Primary and Secondary struts of a bracket.

## Output

Print a single integer: the smallest possible final peak elevation.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one bracket with $d_1 = 5$ and $d_2 = 3$. The Primary column starts at a foundation of elevation 0, so the Primary strut's base is 0 and its peak is at elevation 5. The crossbar rule requires the Secondary strut's base to be at least at elevation 5. Placing it at the lowest possible valid elevation (5), its peak reaches $5 + 3 = 8$. The final peak elevation is 8.

<RATIONALE>
I translated the two-machine flow-shop scheduling problem into a static 1D geometric stacking problem. By replacing time, jobs, and machines with elevations, struts, and crossbars, I removed the semantic cues that trigger LLMs to apply Johnson's rule. Furthermore, I replaced the explicit algebraic inequalities from the seed with procedural physical placement rules ("lowest possible elevation that satisfies..."), which forces the model to construct the mathematical recurrence itself rather than pattern-matching the equations.
</RATIONALE>

The geometry maps exactly to the flow-shop completion times: the Primary column is machine 1, the Secondary column is machine 2, and the crossbar rule enforces the precedence constraint, resulting in the exact same optimal makespan for any given sequence.
