# Problem B — Tile Grid Path

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of $j$ rectangular tiles. Each tile has a top value $d_1$ and a bottom value $d_2$.

You must arrange all $j$ tiles in a single horizontal row from left to right. Let your chosen sequence of tiles be $T_1, T_2, \dots, T_j$. This arrangement forms a $2 \times j$ grid of values, where the first row contains the top values of the tiles in order, and the second row contains the bottom values in order.

Consider a path from the top-left cell (row 1, column 1) to the bottom-right cell (row 2, column $j$). A valid path can only move right (to the next column in the same row) or down (to the same column in the second row). The cost of a path is the sum of the values in all the cells it visits.

Because there are only two rows, any valid path will move right along the first row up to some column $k$ ($1 \le k \le j$), move down to the second row at column $k$, and then move right along the second row until column $j$. The cost of such a path is exactly:
$$ \sum_{i=1}^k \text{top}(T_i) + \sum_{i=k}^j \text{bottom}(T_i) $$

For a given arrangement of tiles, the "grid score" is defined as the maximum cost among all valid paths from the top-left to the bottom-right cell.

Your goal is to choose an arrangement of the $j$ tiles that minimizes this grid score. Output the minimum possible grid score.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the top and bottom values of a tile.

## Output

Print a single integer: the minimum possible grid score.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one tile with $d_1 = 5$ and $d_2 = 3$. There is only one column, so $k=1$. The path visits the top cell (5) and the bottom cell (3). The grid score is $5 + 3 = 8$.
</STATEMENT>
<RATIONALE>
The problem was reframed from a two-machine flow-shop scheduling task to a 2D grid path task. The makespan of a permutation flow shop is mathematically identical to the maximum-weight path in a $2 \times j$ grid graph. This removes all scheduling terminology (machines, jobs, axis clearances) while providing an explicit, unambiguous formula for the objective function.
</RATIONALE>
<PRESERVED_ANSWER>
The maximum path sum in a $2 \times j$ grid exactly corresponds to the makespan of the original two-machine flow shop, so minimizing it yields the identical minimum boundary value.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable using Johnson's rule in $O(j \log j)$ time, keeping it in the polynomial time complexity class.
</PRESERVED_CLASS>
