<STATEMENT>
# Problem B — Column Permutation Grid Score

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a multiset of $j$ columns. Each column consists of two cells: a top cell and a bottom cell. 

For each given column $i$ ($1 \le i \le j$), you are provided the weight of its top cell, $T_i$, and the weight of its bottom cell, $B_i$. (Note that identical $(T_i, B_i)$ pairs may appear multiple times in the input and must all be included).

You must arrange all $j$ columns into a single sequence $c_1, c_2, \dots, c_j$ (a permutation of the given columns) to form a $2 \times j$ grid. 
Let $t_m$ denote the top cell weight of the column placed at position $m$, and $b_m$ denote its bottom cell weight.

For any chosen sequence, we define the "drop-down sum" at position $k$ ($1 \le k \le j$) as the sum of the top cell weights from position $1$ to $k$, plus the sum of the bottom cell weights from position $k$ to $j$. Formally, the sum at position $k$ is:
$$S(k) = \sum_{m=1}^k t_m + \sum_{m=k}^j b_m$$

The overall "grid score" for your chosen sequence is the maximum value of $S(k)$ over all $1 \le k \le j$.

Your goal is to find a permutation of the $j$ columns that minimizes this grid score, and output this minimum possible grid score.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers: $T_i$ and $B_i$ ($1 \le T_i, B_i \le 1000000$), representing the top and bottom cell weights of the $i$-th column.

## Output

Print a single integer: the minimum possible grid score among all column permutations.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only $1$ column with $T_1 = 5$ and $B_1 = 3$. The only possible sequence has $t_1 = 5$ and $b_1 = 3$. There is only one drop-down position ($k=1$), yielding $S(1) = 5 + 3 = 8$. The maximum $S(k)$ is $8$, which is the minimum possible grid score.
</STATEMENT>
<RATIONALE>
The problem was completely reformulated from scheduling spatial clearances on axes to minimizing the maximum drop-down sum algebraically over a permuted grid. This removes all obvious "two-machine flow-shop" vocabulary, forcing the model to algebraically derive or recognize that the objective is mathematically identical to minimizing the makespan before applying Johnson's rule.
</RATIONALE>
<PRESERVED_ANSWER>
The maximum drop-down path sum in a $2 \times j$ grid is a known algebraic identity for the final completion time (makespan) of a two-machine permutation flow-shop, so minimizing it over permutations yields identical outputs.
</PRESERVED_ANSWER>

Because the objective is algebraically equivalent to the makespan of a two-machine flow-shop, it can still be solved in $O(j \log j)$ time using Johnson's optimal sorting algorithm.
