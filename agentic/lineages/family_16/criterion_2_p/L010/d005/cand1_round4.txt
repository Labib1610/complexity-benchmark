# Problem B — Structural Bracket Assembly

Time limit: 1 s   Memory limit: 256 MB

## Description

You are evaluating the structural footprint of a batch of $j$ brackets. You must arrange the $j$ given brackets into a single sequence $B_1, B_2, \dots, B_j$ (a permutation of the given brackets).

Each bracket has an Alpha span $d_1$ and a Beta span $d_2$. Let $d_1(B_i)$ and $d_2(B_i)$ denote the respective spans for the bracket placed at position $i$ in your sequence.

For any chosen sequence, and for any chosen split point $k$ ($1 \le k \le j$), we define the *split cost* as the sum of the Alpha spans of the first $k$ brackets, plus the sum of the Beta spans of the brackets from position $k$ to $j$ inclusive. Mathematically, the split cost at position $k$ is:
$$C(k) = \sum_{i=1}^k d_1(B_i) + \sum_{i=k}^j d_2(B_i)$$

The *overall boundary* of the sequence is the maximum split cost over all possible split points $k$ ($1 \le k \le j$).

Your goal is to find a permutation of the $j$ brackets that minimizes this overall boundary, and report this minimum possible value.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the Alpha and Beta spans of a bracket.

## Output

Print a single integer: the smallest possible overall boundary value.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one bracket with $d_1 = 5$ and $d_2 = 3$. There is only one possible sequence and one valid split point ($k=1$). The split cost is $C(1) = d_1(B_1) + d_2(B_1) = 5 + 3 = 8$. The maximum split cost is therefore 8, which is the minimum possible overall boundary.
