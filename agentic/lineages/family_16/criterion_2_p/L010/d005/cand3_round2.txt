# Problem B — Mystical Seal Resonance

Time limit: 1 s   Memory limit: 256 MB

## Description

You are preparing a sequence of $j$ mystical seals. You must arrange the $j$ given seals into a single sequence $S_1, S_2, \dots, S_j$ (a permutation of the given seals).

Each seal has a Crimson energy value $d_1$ and an Azure energy value $d_2$. Let $d_1(S_i)$ and $d_2(S_i)$ denote the respective energy values for the seal placed at position $i$ in your sequence.

When the sequence is activated, energy flows through it. A "fracture path" occurs when the energy travels through the Crimson values of the first $k$ seals, and then shifts to the Azure values for the remaining seals from position $k$ to $j$. 

Specifically, for any chosen split point $k$ ($1 \le k \le j$), the total energy of that path is the sum of the Crimson values of seals $S_1$ through $S_k$, plus the sum of the Azure values of seals $S_k$ through $S_j$. Mathematically, the total energy for a split point $k$ is:
$$ \sum_{i=1}^k d_1(S_i) + \sum_{i=k}^j d_2(S_i) $$

The "peak resonance" of your sequence is the maximum total energy among all $j$ possible fracture paths.

Your goal is to find an arrangement of the $j$ seals that minimizes this peak resonance. Report this smallest possible peak resonance.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the Crimson and Azure energies of a seal.

## Output

Print a single integer: the smallest possible peak resonance.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one seal with $d_1 = 5$ and $d_2 = 3$. The only possible split point is $k = 1$. The total energy is the Crimson value of $S_1$ plus the Azure value of $S_1$, which is $5 + 3 = 8$. The peak resonance is 8.

I replaced the explicit two-stage coordinate distance constraints (which models recognize as a flow-shop scheduling problem) with their exact mathematical equivalent: the minimax path sum over prefixes and suffixes. This forces the model to either derive Johnson's rule from first mathematical principles or fail by attempting to use dynamic programming, binary search, or segment trees which will TLE.
</RATIONALE>
