# Problem B — Network Potential Minimization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are configuring a directed dependency network consisting of $j$ modular components. You must first choose a strict linear sequence for these components, denoted $C_1, C_2, \dots, C_j$ (a permutation of the given components).

Each component has two associated weights: a Primary weight $w_1$ and a Secondary weight $w_2$. Let $w_1(C_k)$ and $w_2(C_k)$ be the respective weights of the component placed at position $k$ in your chosen sequence.

Once the sequence is chosen, you must assign a scalar potential value to two nodes for each position $k$ ($1 \le k \le j$): a Primary node $P_k$ and a Secondary node $S_k$. The potentials must satisfy the following directed edge requirements (where the potential difference between the destination and the source must be at least the given edge weight):
- The edge from the current Primary node to the next Primary node requires:
  $P_{k+1} - P_k \ge w_1(C_k)$ for $1 \le k < j$
- The internal edge from a component's Primary node to its own Secondary node requires:
  $S_k - P_k \ge w_1(C_k)$ for $1 \le k \le j$
- The edge from the current Secondary node to the next Secondary node requires:
  $S_{k+1} - S_k \ge w_2(C_k)$ for $1 \le k < j$

Assume the base potential is $P_1 \ge 0$. Your objective is to determine a permutation of the $j$ components and a valid assignment of potentials that minimizes the terminal potential boundary, defined as $S_j + w_2(C_j)$. Report this smallest possible terminal potential boundary.

Note: The answer may exceed the range of a 32-bit signed integer.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $w_1$ and $w_2$ ($1 \le w_1, w_2 \le 1000000$): the Primary and Secondary weights of a component.

## Output

Print a single integer: the smallest possible terminal potential boundary.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one component with $w_1 = 5$ and $w_2 = 3$. We can set $P_1 = 0$, satisfying $P_1 \ge 0$. The edge requirements state $S_1 - P_1 \ge w_1(C_1) = 5$, so $S_1 \ge 5$. We can set $S_1 = 5$. The terminal potential boundary is $S_1 + w_2(C_1) = 5 + 3 = 8$.
