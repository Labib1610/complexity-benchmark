<STATEMENT>
# Problem B — Manufacturing Order Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

A production facility is establishing a new protocol to evaluate a batch of custom orders. You must arrange the orders into a single sequence (a permutation of the given orders).

Each order $i$ is defined by two properties: an alpha coefficient $a_i$ and a beta coefficient $b_i$. Once you choose a sequence of the orders, denoted by the ordered sequence of indices $p_1, p_2, \dots, p_N$, you will compute two tracking metrics, $U_k$ and $V_k$, for each position $k$ from $1$ to $N$.

The metrics are defined by the following recurrences:
- $U_0 = 0$
- $V_0 = 0$
- $U_k = U_{k-1} + a_{p_k}$ for $1 \le k \le N$
- $V_k = \max(V_{k-1}, U_k) + b_{p_k}$ for $1 \le k \le N$

Your task is to determine the sequence of orders that minimizes the final tracking metric $V_N$, and output this minimum possible value.

## Input

The first line contains a single integer $N$. The value of $N$ is at least 1 and at most the number of meters in 200 kilometers.
Each of the next $N$ lines contains two integers $a_i$ and $b_i$. These coefficients are at least 1 and at most the number of grams in 1000 kilograms.

## Output

Print a single integer: the smallest possible value of $V_N$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one order with $a_1 = 5$ and $b_1 = 3$. We compute the tracking metrics for this single item:
$U_1 = U_0 + a_1 = 0 + 5 = 5$.
$V_1 = \max(V_0, U_1) + b_1 = \max(0, 5) + 3 = 8$.
The final tracking metric $V_1$ is 8.
</STATEMENT>

This forces the model to recognize the algebraic structure of the recurrence as equivalent to the two-machine flow-shop makespan rather than relying on standard problem terminology.
