# Problem B — Crystal Lattice Synthesis

Time limit: 1 s   Memory limit: 256 MB

## Description

You are synthesizing a linear crystal out of a batch of $j$ distinct mineral seeds. You must arrange the $j$ seeds into a single sequence $M_1, M_2, \dots, M_j$ (a permutation of the given seeds) along the crystal axis.

Each mineral seed induces two distinct crystallization zones. For each seed, you are given the length of its core zone, $d_1$, and the length of its mantle zone, $d_2$. Let $d_1(M_k)$ and $d_2(M_k)$ denote the respective zone lengths for the mineral placed at position $k$ in your sequence.

You must assign a core starting coordinate $X_k$ and a mantle starting coordinate $Y_k$ for each position $k$ ($1 \le k \le j$). The crystal lattice must satisfy the following structural integrity inequalities:
- Core zones cannot overlap: $X_{k+1} \ge X_k + d_1(M_k)$ for $1 \le k < j$
- A mineral's mantle zone must form beyond its own core zone: $Y_k \ge X_k + d_1(M_k)$ for $1 \le k \le j$
- Mantle zones cannot overlap: $Y_{k+1} \ge Y_k + d_2(M_k)$ for $1 \le k < j$

Assume the crystal begins forming at coordinate $X_1 \ge 0$. Find a sequence of the $j$ mineral seeds and a valid coordinate assignment that minimizes the final boundary of the crystal, defined as $Y_j + d_2(M_j)$. Report this smallest possible final boundary coordinate.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $d_1$ and $d_2$ ($1 \le d_1, d_2 \le 1000000$): the core zone length and mantle zone length of a mineral seed.

## Output

Print a single integer: the smallest possible final boundary coordinate.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one mineral seed with $d_1 = 5$ and $d_2 = 3$. We can set $X_1 = 0$, satisfying $X_1 \ge 0$. The inequalities require $Y_1 \ge X_1 + d_1(M_1) = 5$. We can set $Y_1 = 5$. The final boundary coordinate is $Y_1 + d_2(M_1) = 5 + 3 = 8$.
</STATEMENT>
