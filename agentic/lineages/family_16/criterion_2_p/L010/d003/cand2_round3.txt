# Problem B — Signal Cascade Calibration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are calibrating a cascade system using a batch of $j$ signal packets. You must arrange the $j$ packets into a single sequence $P_1, P_2, \dots, P_j$ (a permutation of the given packets).

The calibration process has exactly 2 stages. Accordingly, each packet is associated with exactly two metrics. For each packet, you are given its primary metric, $m_1$, and its secondary metric, $m_2$. Let $m_1(P_k)$ and $m_2(P_k)$ denote the respective metrics for the packet placed at position $k$ in your sequence.

For any chosen sequence, you determine the system's final target value by processing the packets in order. You maintain two accumulators, $X$ and $Y$, both initially set to $0$. For each position $k$ from $1$ to $j$, you update the accumulators as follows:
1. First, increase $X$ by $m_1(P_k)$.
2. Next, ensure $Y$ is at least as large as $X$. If $Y < X$, you must set $Y$ equal to $X$.
3. Finally, increase $Y$ by $m_2(P_k)$.

After processing all $j$ packets in the sequence, the value of $Y$ is the final target value. Find a sequence of the $j$ packets that minimizes this final target value. Report this smallest possible target value.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains exactly two integers $m_1$ and $m_2$ ($1 \le m_1, m_2 \le 1000000$): the primary and secondary metrics of a packet.

## Output

Print a single integer: the smallest possible final target value.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one packet with $m_1 = 5$ and $m_2 = 3$. We start with $X = 0$ and $Y = 0$. 
Processing the packet at position 1 ($P_1$):
- Increase $X$ by $m_1(P_1) = 5$, so $X = 5$.
- Ensure $Y \ge X$. Since $0 < 5$, we set $Y = 5$.
- Increase $Y$ by $m_2(P_1) = 3$, so $Y = 8$.
The final target value is $8$.
