# Problem B — Coordinate Sequence Optimization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a collection of $j$ pairs of integers. You must arrange the $j$ pairs into a single sequence $P_1, P_2, \dots, P_j$ (a permutation of the given pairs).

Each pair consists of a first increment, $u$, and a second increment, $w$. Let $u(P_k)$ and $w(P_k)$ denote the respective increments for the pair placed at position $k$ in your sequence.

You must assign a primary coordinate $X_k$ and a secondary coordinate $Y_k$ for each position $k$ ($1 \le k \le j$). The assignment must satisfy the following transition inequalities:
- $X_{k+1} \ge X_k + u(P_k)$ for $1 \le k < j$
- $Y_k \ge X_k + u(P_k)$ for $1 \le k \le j$
- $Y_{k+1} \ge Y_k + w(P_k)$ for $1 \le k < j$

Assume $X_1 \ge 0$. Find a sequence of the $j$ pairs and a valid coordinate assignment that minimizes the final target value, defined as $Y_j + w(P_j)$. Report this smallest possible target value.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers $u$ and $w$ ($1 \le u, w \le 1000000$): the first and second increments of a pair.

## Output

Print a single integer: the smallest possible final target value.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one pair with $u = 5$ and $w = 3$. We can set $X_1 = 0$, satisfying $X_1 \ge 0$. The inequalities require $Y_1 \ge X_1 + u(P_1) = 5$. We can set $Y_1 = 5$. The final target value is $Y_1 + w(P_1) = 5 + 3 = 8$.
