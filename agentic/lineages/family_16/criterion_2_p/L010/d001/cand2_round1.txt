# Problem B — Campaign Workflow

Time limit: 1 s   Memory limit: 256 MB

## Description

You are preparing a batch of **j** digital assets for a marketing campaign. Each asset requires text localization followed by visual rendering. The team consists of exactly one editor (who handles all localization) and exactly one animator (who handles all rendering).

For workflow consistency, you must publish a single master playlist of all assets. 
The editor processes assets one by one, strictly following the master playlist from beginning to end. 
The animator also processes assets one by one, strictly following the exact same master playlist. However, the animator can only begin processing a specific asset after the editor has completely finished that asset. If the animator is ready for the next asset on the playlist but the editor is still working on it, the animator must remain idle until the asset becomes available.

You need to arrange the master playlist to minimize the total elapsed time from when the editor starts the first asset until the animator finishes the final asset. Report this smallest possible total elapsed time.

The number of assets **j** is at least 1. The maximum number of assets in a batch is exactly the number of millimeters in 200 meters. 
Each phase (localization or rendering) takes a positive integer number of minutes. The maximum time required for any single phase is exactly the number of millimeters in one kilometer.

## Input

The first line contains a single integer **j**.
Each of the next **j** lines contains two integers **L** and **R**: the time in minutes required for the localization and rendering of an asset, respectively.

## Output

Print a single integer: the earliest possible time at which all assets have completed both phases.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single asset takes 5 minutes for localization and then 3 minutes for rendering, finishing at time 8.
