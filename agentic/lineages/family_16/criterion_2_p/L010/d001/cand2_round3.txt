# Problem B — Convoy Routing

Time limit: 1 s   Memory limit: 256 MB

## Description

A commanding officer must route **j** convoys across a treacherous mountain pass. The route features exactly two major bottlenecks: the North Gorge and the South Pass. Every convoy must fully traverse the North Gorge first, and then traverse the South Pass. For each convoy, you are given the duration it takes to cross the North Gorge and the duration it takes to cross the South Pass.

The movement is subject to the following tactical constraints:
- The North Gorge is narrow and can accommodate only one convoy at a time.
- The South Pass is also narrow and can accommodate only one convoy at a time.
- A convoy cannot begin entering the South Pass until it has completely finished clearing the North Gorge.
- To maintain discipline, the commanding officer must establish a single strict marching order for all **j** convoys. The convoys will enter the North Gorge in this sequence, and they will subsequently enter the South Pass in this exact same sequence.

Determine the optimal marching order to ensure the entire operation is completed as early as possible. Report the earliest possible time at which the South Pass becomes permanently clear of all convoys.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the time required for a convoy to cross the North Gorge and the South Pass, respectively.

## Output

Print a single integer: the earliest possible time at which all convoys have finished crossing the South Pass.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single convoy takes 5 time units to cross the North Gorge, then 3 time units to cross the South Pass, completing the operation at time 8.

The problem has been reframed from a standard factory scheduling context (machines and jobs) to a tactical convoy routing scenario (bottlenecks and convoys). By removing the canonical "two machines" terminology and replacing it with sequential geographic bottlenecks, models that rely on keyword matching for "two-machine flow-shop" or "Johnson's rule" are forced to deduce the underlying scheduling structure from the movement constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical model remains exactly the same: a permutation flow-shop with two stages where the objective is to minimize the makespan, ensuring identical outputs for all inputs.
</PRESERVED_ANSWER>

The problem is mathematically identical to a two-machine permutation flow-shop scheduling problem, which is optimally solvable in O(n log n) time using Johnson's algorithm.
</PRESERVED_CLASS>
