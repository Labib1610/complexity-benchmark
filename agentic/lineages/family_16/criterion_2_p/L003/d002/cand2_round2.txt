# Problem B — Variety Show Lineup

Time limit: 1 s   Memory limit: 256 MB

## Description

A theater receives a lineup of **j** distinct acts. Each act undergoes a two-step procedure: it requires stage preparation, and subsequently, the live performance.

The theater operates under the following structural rules:
- The preparation crew works on one act at a time, processing the lineup continuously in an order of your choosing.
- The main stage hosts the live performance of one act at a time.
- As soon as the preparation crew completely finishes an act, that act is placed at the back of a waiting queue.
- The main stage continually takes the act at the front of the waiting queue and hosts it. If the waiting queue is empty, the main stage simply waits until a prepared act arrives.

For each act, the duration required for preparation and the duration required for the live performance are provided. Based on these rules, you must establish the initial order for the preparation crew that minimizes the total elapsed time from the moment the first act begins preparation to the moment the final act is fully completed on the main stage. Output this minimum possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the durations required for an act in preparation and the live performance, respectively.

## Output

Print a single integer: the smallest possible time at which all acts are fully completed.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single act takes 5 in preparation and then 3 in the live performance, finishing at time 8.
