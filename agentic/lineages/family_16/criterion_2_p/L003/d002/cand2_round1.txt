# Problem B — Variety Show Scheduling

Time limit: 1 s   Memory limit: 256 MB

## Description

A theatre director is scheduling a sequence of **j** distinct acts for a variety show. Each act consists of two consecutive phases: a stage setup, followed by the actual performance.

The director must choose the order in which the **j** acts will appear. The schedule strictly follows these rules:
- The stage crew works continuously in the background from time zero, completing the setups for the acts one at a time, strictly one after another in the chosen sequence, without any pauses between setups.
- The performance of the first act in the sequence begins exactly when its setup is finished.
- For every subsequent act in the sequence, its performance begins exactly when both of the following conditions are met:
  1. The stage crew has completely finished setting up this specific act.
  2. The performance of the immediately preceding act in the sequence has entirely concluded.

You are given the duration required to set up each act and the duration of its performance. Determine the sequence of the acts that minimizes the total time elapsed from the start of the first act's setup until the final act's performance completely ends. Output this minimum possible completion time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the duration required for the stage setup and the duration of the actual performance for that act, respectively.

## Output

Print a single integer: the smallest possible elapsed time at which all performances are fully completed.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single act requires 5 for its stage setup and then 3 for its performance, finishing at time 8.

<RATIONALE>
I replaced the explicit two-machine flow-shop framing (fabrication, assembly, staging line, queueing) with a theatre scheduling scenario. By describing the flow of work strictly through two logical dependencies for when a performance can start, models can no longer trigger a surface-level match to Johnson's rule via flow-shop keywords, forcing them to genuinely deduce the optimal sorting strategy from the underlying recurrence relation.
</RATIONALE>
<PRESERVED_ANSWER>
The continuous setup and the two start conditions for the performances perfectly reproduce the exact same mathematical delay recurrence as the original two-stage assembly pipeline, ensuring every sequence evaluates to the exact same completion time.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical model is still a permutation two-machine flow shop makespan minimization, which remains solvable in O(j log j) time using Johnson's algorithm.
</PRESERVED_CLASS>
<RISK>
Models might misread "works continuously in the background" as implying a setup could happen in parallel with its own performance, but the explicit condition that a performance starts only after the crew "has completely finished setting up this specific act" unambiguously prevents this.
</RISK>
