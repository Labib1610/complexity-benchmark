<STATEMENT>
# Problem B — Order Fulfillment

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of **j** elements. Each element has two associated positive integers, **p1** and **p2**.

You must arrange these **j** elements into a sequence. Let your chosen sequence be $v_1, v_2, \dots, v_j$, where every element from the set appears exactly once.

For your sequence, we define an evaluation score $S_k$ for each position $k$ ($1 \le k \le j$). The score $S_k$ is the sum of the **p1** values for all elements up to position $k$ (inclusive), plus the sum of the **p2** values for all elements from position $k$ to the end of the sequence (inclusive). Formally:

$$S_k = \sum_{m=1}^k p1_{v_m} + \sum_{m=k}^j p2_{v_m}$$

where $p1_{v_m}$ and $p2_{v_m}$ are the values of the element at position $m$ in your sequence.

The overall cost of the sequence is the maximum of these evaluation scores:
$$\text{Cost} = \max_{1 \le k \le j} S_k$$

Determine the sequence that minimizes this overall cost. Output the minimum possible cost.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the two values associated with that element.

## Output

Print a single integer: the smallest possible overall cost.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence places the third element first, the second element next, and the first element last.
The sequence of (p1, p2) pairs is: (1, 3), (2, 4), (3, 2).
The evaluation scores are:
- For $k = 1$: $S_1 = 1 + (3 + 4 + 2) = 10$.
- For $k = 2$: $S_2 = (1 + 2) + (4 + 2) = 9$.
- For $k = 3$: $S_3 = (1 + 2 + 3) + 2 = 8$.
The overall cost is $\max(10, 9, 8) = 10$.

In Example 2, there is only one element. For $k = 1$, $S_1 = 5 + 3 = 8$.
