<STATEMENT>
# Problem B — Sequence Evaluation

Time limit: 1 s   Memory limit: 256 MB

## Description

A system must process a batch of **j** independent elements. Each element has two associated parameters: **p1** and **p2**.

You must arrange these elements into a single sequence. Let the chosen sequence of elements be indexed from 1 to **j**, where the element placed at position $i$ in your sequence has parameters $p1_i$ and $p2_i$.

We define two sequences of values, $A$ and $B$, computed step-by-step for $i = 1, 2, \dots, j$ as follows:
- Initially, $A_0 = 0$ and $B_0 = 0$.
- For each position $i$ from 1 to $j$:
  - $A_i = A_{i-1} + p1_i$
  - $B_i = \max(A_i, B_{i-1}) + p2_i$

Your objective is to find an ordering of the **j** elements that minimizes the final value $B_j$. Output this minimum possible value for $B_j$.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the two parameters for one of the elements.

## Output

Print a single integer: the smallest possible value for $B_j$ across all possible orderings of the elements.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal ordering is to place the third element first, the second element second, and the first element last.
For this sequence, the parameters are:
- $i=1$: $p1_1 = 1, p2_1 = 3$ (this is the original 3rd element)
- $i=2$: $p1_2 = 2, p2_2 = 4$ (this is the original 2nd element)
- $i=3$: $p1_3 = 3, p2_3 = 2$ (this is the original 1st element)

The values are calculated as follows:
- $i=1$: $A_1 = 0 + 1 = 1$, $B_1 = \max(1, 0) + 3 = 4$
- $i=2$: $A_2 = 1 + 2 = 3$, $B_2 = \max(3, 4) + 4 = 8$
- $i=3$: $A_3 = 3 + 3 = 6$, $B_3 = \max(6, 8) + 2 = 10$

The final value $B_3$ is 10, which is the minimum possible.

<RATIONALE>
Removed the procedural "Alpha/Beta step" scheduling narrative that models recognize as a flow-shop problem. Instead, the problem is defined strictly through the exact max-plus recurrence relation that governs completion times in a two-machine flow-shop. This forces models to deduce the optimization structure from the algebra rather than matching standard scheduling terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The variables A_i and B_i exactly compute the completion times on the first and second machines of a flow-shop, respectively, so minimizing B_j is mathematically identical to minimizing the makespan.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the 2-machine flow-shop problem, which is optimally solved in O(n log n) time using Johnson's rule.
</PRESERVED_CLASS>
