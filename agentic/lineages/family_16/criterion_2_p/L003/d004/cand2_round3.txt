# Problem B — Grid Column Permutation

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of **j** columns. Each column consists of two cells: a top cell and a bottom cell.
You must arrange all **j** columns in a specific order from left to right to construct a $2 \times j$ grid.

Once the grid is constructed, consider all valid paths from the top-left cell (row 1, column 1) to the bottom-right cell (row 2, column **j**).
- A valid path starts at the top-left cell.
- From any cell, a path can only move exactly one step to the right (to the next column in the same row) or exactly one step down (to the bottom row in the same column).
- A path cannot move left or up.
- The path must end at the bottom-right cell.

The cost of a path is defined as the sum of the values in all the cells it visits, including the starting and ending cells.
The "grid score" for your chosen arrangement of columns is the maximum cost among all valid paths in the grid.

Given the value **p1** for the top cell and the value **p2** for the bottom cell of each column, determine the optimal left-to-right sequence of these columns. Your objective is to minimize the grid score. Output this minimum possible grid score.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the values of the top cell and the bottom cell for a column, respectively.

## Output

Print a single integer: the smallest possible grid score that can be achieved by optimally ordering the columns.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if you arrange the columns in the order of the third input column, then the second, then the first, the top row is `[1, 2, 3]` and the bottom row is `[3, 4, 2]`. There are 3 valid paths from top-left to bottom-right:
- Move down at column 1, then right: 1 + 3 + 4 + 2 = 10.
- Move right to column 2, down, then right: 1 + 2 + 4 + 2 = 9.
- Move right to column 3, then down: 1 + 2 + 3 + 2 = 8.
The maximum cost among these paths is 10. No other arrangement yields a smaller maximum cost, so the minimum possible grid score is 10.

In Example 2, there is only 1 column. The grid is $2 \times 1$. The only valid path visits the top cell (5) and then moves down to the bottom cell (3). The cost is 5 + 3 = 8. The minimum grid score is 8.
