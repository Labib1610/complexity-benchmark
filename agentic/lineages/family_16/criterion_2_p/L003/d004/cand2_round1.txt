# Problem B — Grid Vulnerability

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of **j** independent blocks. Each block has two values: a top value and a bottom value.

You must place all **j** blocks in a sequence from left to right. This forms a grid with 2 rows and **j** columns. The top row consists of the top values of your arranged blocks, and the bottom row consists of the bottom values.

Consider a token that starts at the top-left cell of this grid and travels to the bottom-right cell. In a single step, the token can only move to the adjacent cell directly to its right, or to the adjacent cell directly below it.

The cost of a specific path is the sum of the values in all the cells the token visits, including both the starting and ending cells. 
The *peak cost* of your arrangement is the maximum cost among all possible valid paths the token could take from the top-left to the bottom-right.

Your objective is to find an arrangement of the blocks that minimizes this peak cost. Output this minimum possible peak cost.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the top value and bottom value of a block, respectively.

## Output

Print a single integer: the smallest possible peak cost achievable by arranging the blocks optimally.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

For Example 1, if you arrange the blocks in the order (1, 3), (2, 4), and (3, 2), the grid is:
```
1 2 3
3 4 2
```
The token can take three possible paths:
- Move down at column 1, then right: 1 + 3 + 4 + 2 = 10
- Move right to column 2, down, then right: 1 + 2 + 4 + 2 = 9
- Move right to column 3, then down: 1 + 2 + 3 + 2 = 8

The peak cost for this arrangement is the maximum of these path costs, which is 10. No other arrangement yields a peak cost strictly less than 10.

In Example 2, there is only 1 block. The grid is 2×1. The only valid path moves down, with a cost of 5 + 3 = 8.
