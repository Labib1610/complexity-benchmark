# Problem B — Altitude Stress

Time limit: 1 s   Memory limit: 256 MB

## Description

You are designing a custom obstacle course consisting of **j** consecutive stages. You have a set of **j** unique stages, and each must be included exactly once. You must choose the sequence in which these **j** stages are arranged.

Each stage requires climbing and then descending. Specifically, each stage has an altitude gain **p1** and an altitude drop **p2**.

Once the order of the stages is chosen, we evaluate the course's difficulty. For each position $k$ (where $1 \le k \le j$) in your sequence, the *stress level* at that position is calculated as the sum of the altitude gains of all stages from position 1 up to position $k$ (inclusive), plus the sum of the altitude drops of all stages from position $k$ up to position $j$ (inclusive).

The *overall difficulty* of your chosen sequence is the maximum stress level among all $j$ positions.

Given the parameters for each of the $j$ stages, determine the sequence that minimizes this overall difficulty. Output the minimum possible overall difficulty.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the altitude gain and the altitude drop for a stage, respectively.

## Output

Print a single integer: the smallest possible overall difficulty of the course.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence of the stages is to place the third stage first, the second stage second, and the first stage third. The sequence of (gain, drop) pairs is (1, 3), (2, 4), and (3, 2).
- For position $k=1$, the stress level is $1 + (3 + 4 + 2) = 10$.
- For position $k=2$, the stress level is $(1 + 2) + (4 + 2) = 9$.
- For position $k=3$, the stress level is $(1 + 2 + 3) + 2 = 8$.
The overall difficulty is the maximum of these, which is 10. No other arrangement yields a lower overall difficulty.

In Example 2, the single stage has a stress level of $5 + 3 = 8$.
