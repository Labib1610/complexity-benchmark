# Problem B — Order Fulfillment

Time limit: 1 s   Memory limit: 256 MB

## Description

A publishing team is finalizing a book consisting of **j** independent chapters. Each chapter must first go through the Translation phase, and subsequently the Proofreading phase.

You must choose a single sequence of all **j** chapters; each chapter must appear exactly once in this sequence. Both the Translation and Proofreading phases will process the chapters in this exact chosen order.

The workflow adheres to these rules:
- The Translation phase handles one chapter at a time. It begins the first chapter at time 0 and moves immediately to the next chapter in the sequence as soon as the current one finishes, without any gaps.
- The Proofreading phase handles one chapter at a time.
- The Proofreading phase can only begin a chapter after the Translation phase has fully completed that specific chapter.
- The Proofreading phase will start working on a chapter as early as possible. If it finishes a chapter but the Translation phase has not yet finished the next chapter in the sequence, the Proofreading phase remains idle until that next chapter is ready.

For each chapter, you are given the duration **p1** it requires in the Translation phase, and the duration **p2** it requires in the Proofreading phase. Your objective is to find a chapter sequence that minimizes the total elapsed time from the moment the Translation phase starts the first chapter until the moment the Proofreading phase completes the final chapter. 

Output this minimum possible total time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the durations required for the chapter in the Translation phase and the Proofreading phase, respectively.

## Output

Print a single integer: the smallest possible total elapsed time at which all chapters are fully completed in the Proofreading phase.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single chapter takes 5 in Translation and then 3 in Proofreading, finishing at time 8.
