# Problem B — Ritual Harmonization

Time limit: 1 s   Memory limit: 256 MB

## Description

You are tasked with conducting a ceremony consisting of **j** distinct magical rituals. Each ritual requires two sequential phases to be completed: Chanting, followed immediately by Manifestation.

You have access to a single Chanting Circle and a single Manifestation Altar. 
- The Chanting Circle can only host one ritual at a time. You must choose the sequence in which the **j** rituals are conducted. The Chanting Circle will perform its phase for all rituals back-to-back in your chosen sequence, without any pauses.
- The Manifestation Altar also hosts one ritual at a time. It must perform the Manifestation phase for the rituals in the exact same sequence you chose for the Chanting Circle. 
- A ritual can only begin its Manifestation phase after its Chanting phase is entirely complete. If the Manifestation Altar is free but the next scheduled ritual has not yet finished its Chanting phase, the Altar must remain idle until that ritual is ready.

Given the time **p1** required in the Chanting Circle and the time **p2** required on the Manifestation Altar for each ritual, determine the optimal sequence for the rituals. Your goal is to minimize the total time elapsed from the moment the first ritual begins Chanting until the moment the last ritual completes Manifestation. Output this minimum possible total time.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the durations required for a ritual in the Chanting Circle and on the Manifestation Altar, respectively.

## Output

Print a single integer: the smallest possible total elapsed time at which all rituals are fully completed.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single ritual takes 5 in the Chanting Circle and then 3 on the Manifestation Altar, finishing at time 8.
