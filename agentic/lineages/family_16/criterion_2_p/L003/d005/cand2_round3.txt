# Problem B — Factory Processing

Time limit: 1 s   Memory limit: 256 MB

## Description

A factory must process a batch of jobs. You must arrange the jobs into a single production sequence to be used by both machines in the facility. 

The processing requires two stages, handled sequentially by Machine 1 and Machine 2:
- Machine 1 processes the jobs one by one in your chosen sequence, starting the very first job at time 0. It operates continuously, meaning the time any job finishes on Machine 1 is exactly the sum of the **p1** processing times of all jobs up to and including it in the sequence.
- Machine 2 processes the jobs in the exact same sequence. It cannot overtake or reorder them.
- For any given job, its processing on Machine 2 begins at the latest of two events: the moment the job finishes on Machine 1, and the moment Machine 2 finishes the previous job in the sequence.
- Once a job begins on Machine 2, it runs continuously for its required **p2** processing time.

For each job, you are given the processing time **p1** it requires on Machine 1, and the processing time **p2** it requires on Machine 2.

Determine the optimal sequence of jobs to minimize the time at which Machine 2 completes the final job. Output this minimum possible time.

## Input

The first line contains a single integer **j**. The value of **j** is at least 1, and at most the exact number of seconds in 55 hours, 33 minutes, and 20 seconds.
Each of the next **j** lines contains two integers **p1** and **p2**: the processing times required for a job on Machine 1 and Machine 2, respectively. The processing times are positive integers, neither exceeding the number of milligrams in one kilogram.

## Output

Print a single integer: the smallest possible time at which Machine 2 completes the final job in the batch.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single job takes 5 on Machine 1 and 3 on Machine 2. It finishes on Machine 1 at time 5, immediately starts on Machine 2, and finishes at time 8.
