<STATEMENT>
# Problem B — Grid Arrangement

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given **j** tiles. Each tile has a top value and a bottom value. 
You must arrange all **j** tiles in a single row from left to right. This creates a grid with 2 rows and **j** columns, where the first row contains the top values of your chosen sequence, and the second row contains the bottom values.

A valid path through this grid starts at the top-left cell (row 1, column 1) and ends at the bottom-right cell (row 2, column **j**), moving only right and down. 
The cost of a path is the sum of the values in all the cells it visits.
The *score* of your arrangement is the maximum cost among all valid paths.

Determine the optimal left-to-right sequence of the tiles to minimize the score of the arrangement. Output this minimum possible score.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000): the top value and the bottom value of a tile, respectively.

## Output

Print a single integer: the minimum possible score of the arrangement.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, an optimal arrangement places the tiles in the following order:
Tile 1: top 1, bottom 3 (the third tile from the input)
Tile 2: top 2, bottom 4 (the second tile from the input)
Tile 3: top 3, bottom 2 (the first tile from the input)

This forms the grid:
1 2 3
3 4 2

There are three valid paths from top-left to bottom-right:
- Down at column 1: 1 + 3 + 4 + 2 = 10
- Down at column 2: 1 + 2 + 4 + 2 = 9
- Down at column 3: 1 + 2 + 3 + 2 = 8

The score of this arrangement is the maximum of these path costs, which is 10. No other arrangement yields a score lower than 10.

<RATIONALE>
Removed all factory and scheduling terminology (machines, queues, continuous operation) that triggered models to recognize the 2-machine flow shop and apply Johnson's rule. Instead, the problem is framed algebraically as minimizing the maximum path sum in a 2xN grid where column order can be permuted. This is mathematically identical to the makespan of a 2-machine flow shop, but forces the models to either independently derive the adjacent-swap comparator or recognize the deeper structural isomorphism.
</RATIONALE>
<PRESERVED_ANSWER>
The maximum path sum in a 2xN grid is exactly sum(top_1..k) + sum(bottom_k..N), which is the algebraic definition of the completion time of the last job in a 2-machine flow shop, meaning the optimal permutations and minimal scores are identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains solvable in O(N log N) using Johnson's rule or an equivalent custom sorting comparator, keeping it in P.
</PRESERVED_CLASS>
