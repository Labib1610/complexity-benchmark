# Problem B — Tile Labyrinth

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of **j** rectangular tiles. Each tile is divided into a top half and a bottom half, and each half contains a positive integer. 

You must place all **j** tiles side-by-side in a single row to form a grid with 2 rows and **j** columns. You can choose any left-to-right order for the tiles, but you cannot rotate them (the top half must remain on top).

Once you have arranged the grid, a token will be moved from the top-left cell (the top half of the first tile) to the bottom-right cell (the bottom half of the last tile). The token can only move one cell to the right or one cell down at each step. It cannot move left or up. 

The "cost" of a path is the sum of the integers in all the cells the token visits (including the starting and ending cells). 

An adversary will observe your chosen arrangement and select a valid path that **maximizes** the cost. Your goal is to choose the order of the tiles to **minimize** this maximum possible cost.

Determine the optimal arrangement of the tiles and output the minimum possible cost the adversary can force you to pay.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000), the number of tiles.
Each of the next **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000). These represent the integer on the top half and the integer on the bottom half of a tile, respectively.

## Output

Print a single integer: the lowest possible maximum path cost you can achieve.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if you arrange the tiles in the order `(1, 3)`, `(2, 4)`, `(3, 2)`, the grid becomes:
```
Row 1:  1  2  3
Row 2:  3  4  2
```

The token has three possible paths:
- Move down at column 1: cost is 1 + 3 + 4 + 2 = 10.
- Move down at column 2: cost is 1 + 2 + 4 + 2 = 9.
- Move down at column 3: cost is 1 + 2 + 3 + 2 = 8.

The adversary will choose the first path to maximize the cost (10). No other arrangement of the tiles can result in a smaller maximum cost.

In Example 2, the single tile forms a 2x1 grid. The only path visits both halves, giving a cost of 5 + 3 = 8.
