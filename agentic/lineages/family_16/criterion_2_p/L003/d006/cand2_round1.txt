# Problem B — Crystal Array Routing

Time limit: 1 s   Memory limit: 256 MB

## Description

You are assembling a rectangular crystal array using a set of **j** dual-core tiles. Each tile has a top core and a bottom core, each possessing a specific integer value. You must arrange all **j** tiles in a single horizontal row from left to right. This creates a grid with 2 rows and **j** columns. The top cores form the first row, and the bottom cores form the second row.

Energy flows through this array starting from the top core of the leftmost tile and must exit through the bottom core of the rightmost tile. The energy can only step to the right (to the adjacent core in the same row) or downward (from the top core to the bottom core of the same tile). The cost of any specific path is the sum of the values of all cores it passes through, including the starting and ending cores.

Since the energy will naturally take the path of maximum resistance, the total energy cost for a given arrangement of tiles is defined as the maximum path cost among all valid paths from the top-left core to the bottom-right core.

Your objective is to find a left-to-right arrangement of the **j** tiles that minimizes this maximum path cost.

You must place at least one tile. The mounting rail has a total length of exactly 2 kilometers. Each tile occupies exactly 1 centimeter of rail space, dictating the maximum number of tiles. Every core has a strictly positive integer value. The maximum possible value of a core is exactly the number of millimeters in one kilometer.

## Input

The first line contains a single integer **j**.
Each of the next **j** lines contains two integers: the value of the top core and the value of the bottom core for that tile.

## Output

Print a single integer: the minimum possible value of the maximum path cost.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence is to arrange the tiles in the order of the 3rd tile, then the 2nd tile, then the 1st tile. The resulting grid is:
- Row 1 (top): 1, 2, 3
- Row 2 (bottom): 3, 4, 2

There are 3 possible paths for the energy:
- Path dropping at column 1: 1 (top) + 3 (bottom) + 4 (bottom) + 2 (bottom) = 10
- Path dropping at column 2: 1 (top) + 2 (top) + 4 (bottom) + 2 (bottom) = 9
- Path dropping at column 3: 1 (top) + 2 (top) + 3 (top) + 2 (bottom) = 8

The maximum path cost for this arrangement is 10. No other arrangement yields a smaller maximum path cost.

In Example 2, the single tile has a top core of 5 and a bottom core of 3. The only path costs 5 + 3 = 8.

<RATIONALE>
I completely replaced the pipeline scheduling scenario with an isomorphic grid-path minimization problem. By asking to minimize the maximum path cost in a 2xN grid formed by permuting columns, the problem remains mathematically identical to the 2-machine flow shop makespan but strips away all "stage 1 / stage 2" scheduling terminology that models use to pattern-match Johnson's Rule. I also applied S07 by expressing the numeric limits through physical measurements (e.g., 2 kilometers of rail at 1 cm per tile = 200,000 tiles).
</RATIONALE>

The maximum path sum in a 2xN grid where moves are only right and down is mathematically identical to the makespan of a 2-machine flow shop, so the optimal permutation and the resulting minimum cost remain exactly the same for all inputs.
