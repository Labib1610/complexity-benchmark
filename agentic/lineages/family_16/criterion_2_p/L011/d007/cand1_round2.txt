# Problem B — Phase Calibration Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

You are configuring a system that requires applying a set of **j** calibration steps. Each step has a primary duration **A** and a secondary duration **B**. 

You must choose an order in which to apply all **j** given steps exactly once. Multiple steps may have identical durations, but they are treated as separate individual steps.

We track two cumulative metrics, the Base Phase **X** and the Peak Phase **Y**, both starting at 0. When the next step in your chosen sequence is applied, the metrics update as follows:
1. The Base Phase advances: **X_new** = **X_current** + **A**
2. The Peak Phase synchronizes and advances: **Y_new** = max(**X_new**, **Y_current**) + **B**

After these calculations, **X_current** becomes **X_new** and **Y_current** becomes **Y_new** for the next step in the sequence.

Your task is to find an ordering of the **j** steps that minimizes the final value of the Peak Phase **Y** after all steps are applied.

What is the minimum possible final value of **Y**?

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **A** and **B** (1 ≤ A, B ≤ 1000000), representing the primary and secondary durations for one calibration step.

## Output

Print a single integer: the minimum possible final value of the Peak Phase **Y**.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if we order the steps as the 3rd step, then the 2nd step, then the 1st step from the input:
- Initially, X_current = 0, Y_current = 0.
- Apply the 3rd step (A=1, B=3):
  X_new = 0 + 1 = 1
  Y_new = max(1, 0) + 3 = 4
  (X_current becomes 1, Y_current becomes 4)
- Apply the 2nd step (A=2, B=4):
  X_new = 1 + 2 = 3
  Y_new = max(3, 4) + 4 = 8
  (X_current becomes 3, Y_current becomes 8)
- Apply the 1st step (A=3, B=2):
  X_new = 3 + 3 = 6
  Y_new = max(6, 8) + 2 = 10
  (X_current becomes 6, Y_current becomes 10)

The final value of Y is 10. This is the minimum possible value across all valid orderings.

In Example 2, there is only one step. X_new = 0 + 5 = 5. Y_new = max(5, 0) + 3 = 8.
