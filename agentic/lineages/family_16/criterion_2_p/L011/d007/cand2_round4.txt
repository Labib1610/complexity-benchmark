<METHOD_DESCRIPTION>Replaces the factory/worker domain with an abstract sequence evaluation computing running totals. This removes the semantic cues that trigger Johnson's rule pattern matching while providing an explicit, identical mathematical recurrence.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Two-Stage Sequence Evaluation

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a collection of **j** items. Each item consists of a primary value and a secondary value.

You must establish a single sequence (an ordering of the **j** items). Both the primary values and the secondary values will be evaluated in this exact same order.

The evaluation process computes two running totals, $X_k$ and $Y_k$, for each item $k$ in your sequence (from $1$ to $j$), determined by the following rules:
1. The first running total processes the primary values continuously, one after another in your chosen sequence, starting with $X_0 = 0$. Thus, $X_k = X_{k-1} + a_k$ (where $a_k$ is the primary value of the $k$-th item in your sequence).
2. The second running total processes the secondary values one after another in the exact same sequence, starting with $Y_0 = 0$.
3. For any given item, the second running total cannot be evaluated until two conditions are met:
   - The first running total for that item ($X_k$) has been completely evaluated.
   - The second running total for the previous item ($Y_{k-1}$) has been completely evaluated (this applies to all items after the first).
4. The second running total is evaluated at the earliest possible value that satisfies the conditions above: $Y_k = \max(X_k, Y_{k-1}) + b_k$ (where $b_k$ is the secondary value of the $k$-th item).

Your task is to find an ordering of the **j** items that minimizes the final value of the second running total—specifically, $Y_j$ after the final item in your sequence is evaluated.

What is the minimum possible value of $Y_j$?

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the primary value and secondary value of the item, respectively.

## Output

Print a single integer: the minimum possible value of $Y_j$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if we order the items as the 3rd item, then the 2nd item, then the 1st item from the input:
- The 3rd item has a primary value of 1 ($X_1 = 0 + 1 = 1$). Its secondary value is 3. It must wait for $X_1$ (1) and $Y_0$ (0). $Y_1 = \max(1, 0) + 3 = 4$.
- The 2nd item has a primary value of 2 ($X_2 = 1 + 2 = 3$). Its secondary value is 4. It must wait for $X_2$ (3) and $Y_1$ (4). $Y_2 = \max(3, 4) + 4 = 8$.
- The 1st item has a primary value of 3 ($X_3 = 3 + 3 = 6$). Its secondary value is 2. It must wait for $X_3$ (6) and $Y_2$ (8). $Y_3 = \max(6, 8) + 2 = 10$.
The final value $Y_3$ is 10. This is the minimum possible value across all valid orderings.

In Example 2, there is only one item. $X_1 = 5$. $Y_1 = \max(5, 0) + 3 = 8$.
</STATEMENT>
<RATIONALE>
The rewrite replaces the "Prepare/Finalize worker" terminology with an abstract mathematical recurrence ($X_k$ and $Y_k$). This removes the semantic cues of a "two-machine flow-shop" that triggered the models to apply Johnson's rule by rote pattern matching, forcing them to instead analyze the algebraic properties of the recurrence to discover the sorting strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical definition of $Y_k = \max(X_k, Y_{k-1}) + b_k$ is exactly equivalent to the completion time of a job on the second machine in a flow-shop, so the optimum sequence yields the exact same minimum value.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to the two-machine flow-shop makespan minimization problem, which is solvable in O(n log n) time using Johnson's rule.
</PRESERVED_CLASS>
