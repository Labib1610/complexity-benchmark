# Problem B — Artifact Shielding

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of **j** artifacts. Each artifact has a left-side thickness and a right-side thickness.

You must stack all **j** artifacts in a vertical column, from position 1 (top) to position **j** (bottom).

A testing laser will strike the column from the top. It will travel downwards through the left sides of the artifacts, and at some specific artifact **k** (where 1 ≤ **k** ≤ **j**), it will shift to the right sides and continue travelling downwards through the right sides until it exits the bottom of the **j**-th artifact. 

Specifically, if the laser shifts at artifact **k**, it must penetrate:
- The left-side thicknesses of all artifacts from position 1 down to **k** (inclusive).
- The right-side thicknesses of all artifacts from position **k** down to **j** (inclusive).

The total resistance encountered by the laser is the sum of all these penetrated thicknesses. The laser's targeting system will automatically choose the shift position **k** that maximizes this total resistance.

Your task is to find an ordering of the **j** artifacts that minimizes this maximum total resistance.

What is the minimum possible total resistance?

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the left-side thickness and right-side thickness of an artifact, respectively.

## Output

Print a single integer: the minimum possible total resistance.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, if we order the artifacts as the 3rd artifact, then the 2nd artifact, then the 1st artifact from the input:
- The left-side thicknesses are 1, 2, and 3.
- The right-side thicknesses are 3, 4, and 2.
If the laser shifts at k = 1: the resistance is the left side of the 1st artifact (1) plus the right sides of the 1st, 2nd, and 3rd artifacts (3 + 4 + 2) = 10.
If the laser shifts at k = 2: the resistance is the left sides of the 1st and 2nd artifacts (1 + 2 = 3) plus the right sides of the 2nd and 3rd artifacts (4 + 2 = 6) = 9.
If the laser shifts at k = 3: the resistance is the left sides of the 1st, 2nd, and 3rd artifacts (1 + 2 + 3 = 6) plus the right side of the 3rd artifact (2) = 8.
The laser will shift at k = 1 to maximize the resistance, resulting in 10.
This is the minimum possible resistance across all valid orderings.

In Example 2, there is only one artifact. The laser must shift at k = 1. The resistance is the left side (5) plus the right side (3), which equals 8.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from a temporal scheduling task into a spatial path-finding scenario (minimizing the maximum path sum in a 2xN grid). This entirely removes "prepare/finalize" and worker-based vocabulary, forcing models to algebraically recognize the equivalence between the 2xN grid path sum and the two-machine flow-shop makespan in order to apply Johnson's rule.
</RATIONALE>
<PRESERVED_ANSWER>
The objective function evaluating a permutation, max_k (sum_{i=1}^k p1_i + sum_{i=k}^j p2_i), is mathematically identical to the makespan formula for the two-machine flow-shop, guaranteeing identical outputs for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains optimally solvable in O(j log j) using Johnson's algorithm, preserving its P complexity class.
</PRESERVED_CLASS>
