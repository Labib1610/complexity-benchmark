<METHOD_NAME>Grid Path Formulation</METHOD_NAME>
<METHOD_DESCRIPTION>Transforms the two-machine scheduling problem into a tile-arrangement problem where the objective is to minimize the maximum path sum in a 2xk grid. The explicit formula ensures mathematical equivalence while removing the machine scheduling narrative.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem B — Freight Depot Inspections

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given $j$ rectangular tiles. Each tile has a top value and a bottom value. The $i$-th tile in the input has a top value of $p_{1, i}$ and a bottom value of $p_{2, i}$. 

You must arrange all $j$ tiles in a sequence from left to right to form a $2 \times j$ grid. The top values form the first row, and the bottom values form the second row. You may choose any left-to-right order for the tiles, but you cannot rotate them (the top value must stay on top).

Let your chosen sequence of tiles be $d_1, d_2, \dots, d_j$. 
The top value of $d_i$ is denoted $\text{top}(d_i)$ and the bottom value is denoted $\text{bottom}(d_i)$.

We define the *evaluation score* of your arrangement as the maximum possible sum of values along a path from the top-left cell (first row, first column) to the bottom-right cell (second row, last column). A valid path can only step to the right or step down. Because the grid has exactly 2 rows, any valid path starts in the top row, moves right some number of times, steps down exactly once at some column $k$ ($1 \le k \le j$), and then moves right along the bottom row until the end.

Equivalently, the score of the arrangement $d_1, \dots, d_j$ is given by the formula:
$$ \text{Score} = \max_{1 \le k \le j} \left( \sum_{i=1}^{k} \text{top}(d_i) + \sum_{i=k}^{j} \text{bottom}(d_i) \right) $$

Your objective is to find an arrangement of the $j$ tiles that minimizes this evaluation score. 

What is the minimum possible evaluation score?

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the following $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$), representing the top and bottom values of a tile.

## Output

Print a single integer: the minimum possible evaluation score.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal arrangement is to place the input tiles in the order: 3rd tile, then 2nd tile, then 1st tile.
The grid becomes:
Top row:    1, 2, 3
Bottom row: 3, 4, 2

Let's calculate the path sum for each possible column $k$ where the path steps down:
- If $k=1$, the sum is $\text{top}(d_1) + \text{bottom}(d_1) + \text{bottom}(d_2) + \text{bottom}(d_3) = 1 + 3 + 4 + 2 = 10$.
- If $k=2$, the sum is $\text{top}(d_1) + \text{top}(d_2) + \text{bottom}(d_2) + \text{bottom}(d_3) = 1 + 2 + 4 + 2 = 9$.
- If $k=3$, the sum is $\text{top}(d_1) + \text{top}(d_2) + \text{top}(d_3) + \text{bottom}(d_3) = 1 + 2 + 3 + 2 = 8$.

The maximum of these sums is $10$. Thus, the evaluation score for this arrangement is 10. 
This is the minimum possible score across all valid arrangements.
