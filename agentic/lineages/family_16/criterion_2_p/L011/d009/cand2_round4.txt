<STATEMENT>
# Problem B — Freight Depot Inspections

Time limit: 1 s   Memory limit: 256 MB

## Description

You are managing a freight depot that must dispatch exactly $j$ cargo trains. Each train requires a Structural inspection followed by a Cargo clearance.

You must establish a single dispatch sequence for the $j$ trains. For the $k$-th train in your chosen sequence, let its Structural inspection duration be $X_k$ and its Cargo clearance duration be $Y_k$. 

The depot's schedule is simulated step-by-step using a readiness threshold $R$ (initially 0) and a completion tracker $T$ (initially 0). For each train $k$ from $1$ to $j$ in your sequence, the depot processes it as follows:

1. Add $X_k$ to the readiness threshold $R$. (This represents the continuous back-to-back progression of the Structural inspections starting from minute 0).
2. If the completion tracker $T$ is strictly less than $R$, update $T$ to equal $R$. (This ensures a train's Cargo clearance does not begin until its Structural inspection is finished).
3. Add $Y_k$ to the completion tracker $T$. (This represents the time taken to perform the Cargo clearance).

After processing all $j$ trains, the final value of $T$ is the completion minute of the depot.

Your objective is to find an ordering of the $j$ trains that minimizes this final completion minute.

What is the minimum possible final completion minute?

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the following $j$ lines contains two integers $X$ and $Y$ ($1 \le X, Y \le 1000000$), representing the time required in minutes for a train's Structural inspection and Cargo clearance, respectively.

## Output

Print a single integer: the minimum possible final completion minute of the depot.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence is to process the 3rd input train first, then the 2nd, then the 1st. 
The durations in sequence are $(X_1=1, Y_1=3)$, $(X_2=2, Y_2=4)$, and $(X_3=3, Y_3=2)$.
- **Train 1:** Add 1 to $R$ ($R=1$). $T=0 < 1$, so update $T$ to 1. Add 3 to $T$ ($T=4$).
- **Train 2:** Add 2 to $R$ ($R=3$). $T=4$ is not less than 3, so $T$ remains 4. Add 4 to $T$ ($T=8$).
- **Train 3:** Add 3 to $R$ ($R=6$). $T=8$ is not less than 6, so $T$ remains 8. Add 2 to $T$ ($T=10$).

The final completion minute is 10. This is the minimum possible value across all valid sequences.
</STATEMENT>
<RATIONALE>
To address the H5 task drift critique while still defeating the LLMs, I returned the narrative to the exact semantic framing of the seed (Structural inspections and Cargo clearances with continuous back-to-back progression). However, instead of presenting the constraints as a system of concurrent inequalities ($t_{k+1}=t_k+X_k$, $u_k \ge t_k+X_k$), which LLMs use to pattern-match the flow shop, I formalized the evaluation into a sequential, step-by-step imperative algorithm using accumulator variables ($R$ and $T$). This forces solvers to analyze the state machine to deduce Johnson's rule rather than relying on declarative keyword matching.
</RATIONALE>
<PRESERVED_ANSWER>
The imperative loop exactly calculates the makespan of a 2-machine flow shop ($T_k = \max(T_{k-1}, R_k) + Y_k$), meaning the final completion minute is identical to the seed for every possible sequence and input.
</PRESERVED_ANSWER>
