<STATEMENT>
# Problem B — Domino Grid Path

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given $j$ dominoes. Each domino has a top value and a bottom value. 

You must place all $j$ dominoes upright in a single row, side by side, to form a grid with 2 rows and $j$ columns. You cannot rotate or invert the dominoes; the top value must always remain in the first row, and the bottom value must always remain in the second row.

A token is placed on the top-left cell of this grid (the top value of the first domino in your row). The token must travel to the bottom-right cell (the bottom value of the last domino). From any cell, the token can only move exactly one cell to the right, or exactly one cell down. It cannot move left or up, and it cannot move diagonally.

The cost of a path is defined as the sum of the values of all the cells the token visits, including the starting and ending cells. 

For a given left-to-right arrangement of the $j$ dominoes, the grid's evaluation score is the maximum total cost among all valid paths from the top-left to the bottom-right.

Your objective is to order the $j$ dominoes such that the grid's evaluation score is minimized.

What is the minimum possible evaluation score?

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the following $j$ lines contains two integers $p_1$ and $p_2$ ($1 \le p_1, p_2 \le 1000000$), representing the top value and the bottom value of a domino, respectively.

## Output

Print a single integer: the minimum possible evaluation score.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal arrangement is to place the 3rd input domino first, then the 2nd, then the 1st.
The grid becomes:
Row 1 (top values): 1, 2, 3
Row 2 (bottom values): 3, 4, 2

The grid has 3 possible paths from the top-left to the bottom-right:
- Move down at column 1, then right to column 3: visits 1 (col 1), 3 (col 1), 4 (col 2), 2 (col 3). Total cost = 1 + 3 + 4 + 2 = 10.
- Move right to column 2, down at column 2, then right to column 3: visits 1 (col 1), 2 (col 2), 4 (col 2), 2 (col 3). Total cost = 1 + 2 + 4 + 2 = 9.
- Move right to column 3, then down at column 3: visits 1 (col 1), 2 (col 2), 3 (col 3), 2 (col 3). Total cost = 1 + 2 + 3 + 2 = 8.

The grid's evaluation score is the maximum of these costs, which is 10.
This evaluation score of 10 is the minimum possible across all arrangements of the dominoes.
