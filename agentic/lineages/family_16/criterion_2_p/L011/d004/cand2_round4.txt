<METHOD_DESCRIPTION>Transforms a 2-machine flow-shop makespan problem into a mathematically equivalent single-state buffer minimization over permutations. By proving that the makespan equals the final buffer size plus the sum of all first-stage times, we replace all scheduling affordances with an algebraic state update rule (E = max(E - a, 0) + b). <STATEMENT>
# Problem B — Energy Shield Calibration

Time limit: 1 s   Memory limit: 256 MB

## Description

You are calibrating a spaceship's energy shield using **j** distinct modules. Each module has two parameters: a depletion value and a recharge value.

The shield's energy level starts at exactly 0. You must choose a single sequence in which to activate all **j** modules one by one.

When a module is activated, the following two steps occur in order:
1. The shield's energy level decreases by the module's depletion value. However, the energy level cannot drop below 0; if a depletion would take it below 0, it simply becomes 0.
2. The shield's energy level then increases by the module's recharge value.

After all **j** modules have been activated in your chosen sequence, the shield will have a final energy level, let's call it $E$.

Your goal is to find an activation sequence that minimizes this final energy level $E$. 

To complete the calibration, you must calculate a specific checksum: the minimum possible final energy level $E$, plus the sum of the depletion values of all **j** modules.

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the depletion value and the recharge value of a module, respectively.

## Output

Print a single integer: the minimum possible final energy level $E$ plus the sum of the **p1** values of all **j** modules.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one module. The shield starts at exactly 0. The depletion of 5 attempts to reduce the energy to -5, but it is bounded at 0. The recharge of 3 then increases the energy to 3. The final energy level $E$ is 3. The sum of the **p1** values is 5. The required checksum is 3 + 5 = 8.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from a two-machine flow-shop scheduling task into a single-variable algebraic state update. By defining the state transition as `E = max(E - p1, 0) + p2`, we remove all scheduling terminology (Main Stage, Review Room, elapsed time) while preserving the exact mathematical structure of the makespan calculation. Models that rely on keyword pattern matching to recognize Johnson's rule will fail, forcing them to genuinely analyze the algebraic properties of the state transition to derive the optimal comparator.
</RATIONALE>
<PRESERVED_ANSWER>
By induction, the final energy level $E$ plus the sum of all depletion values is mathematically identical to the completion time of the final job in a 2-machine permutation flow-shop, so minimizing $E$ yields the exact same optimal sequence and identical output for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is mathematically equivalent to minimizing the makespan of a 2-machine flow-shop, meaning it remains optimally solvable in O(n log n) time using Johnson's rule.
</PRESERVED_CLASS>

A model might misinterpret "sum of the p1 values of all j modules" as requiring them to compute the sum over only a subset of modules, but "all j modules" combined with the instruction to activate them all makes the constant nature of this sum unambiguous.
