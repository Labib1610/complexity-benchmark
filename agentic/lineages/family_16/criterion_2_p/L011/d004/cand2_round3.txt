<STATEMENT>
# Problem B — Sequence Evaluation

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a collection of $j$ distinct elements. Each element has two positive integer properties, $A$ and $C$.

You must arrange these elements into two sequences: sequence $P$ (which contains all $j$ elements in any order you choose) and sequence $Q$ (which also contains all $j$ elements in any order you choose). The order of elements in $Q$ can be completely different from the order in $P$ if you wish.

Based on your chosen sequences, each element receives an $X$-score and a $Y$-score.

First, the $X$-scores are calculated using sequence $P$:
- For any element $e$, its $X$-score is the sum of the $A$ properties of every element that precedes $e$ in sequence $P$, plus the $A$ property of $e$ itself.

Next, the $Y$-scores are calculated one by one, strictly in the order the elements appear in sequence $Q$:
- For the very first element in sequence $Q$, its $Y$-score is equal to its $X$-score plus its $C$ property.
- For every subsequent element in sequence $Q$, its $Y$-score is equal to the maximum of two values:
  1. The element's own $X$-score.
  2. The $Y$-score of the element that immediately precedes it in sequence $Q$.
  
  After taking the maximum of these two values, you add the element's $C$ property to get its final $Y$-score.

Your goal is to choose sequences $P$ and $Q$ such that the $Y$-score of the final element in sequence $Q$ is as small as possible.

What is the minimum possible $Y$-score of the final element in sequence $Q$?

## Input

The first line contains a single integer $j$ (1 ≤ j ≤ 200000).
Each of the following $j$ lines contains two integers $A$ and $C$ (1 ≤ A, C ≤ 1000000), representing the two properties of an element.

## Output

Print a single integer: the minimum possible $Y$-score of the final element in sequence $Q$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one element. Its $X$-score is 5. Its $Y$-score is its $X$-score (5) plus its $C$ property (3), resulting in 8.
</STATEMENT>
<RATIONALE>
I completely removed the scheduling and manufacturing semantics (Main Stage, Review Room, performances, time) and replaced them with an abstract mathematical sequence evaluation (X-score and Y-score). This forces the model to recognize the two-machine flow-shop structure from the recursive definition of the scores, rather than relying on surface keywords like "schedule" or "venues".
</RATIONALE>
<PRESERVED_ANSWER>
The X-score and Y-score calculations are mathematically identical to the completion times on the first and second machines in a flow-shop, so the minimum possible Y-score remains the optimal makespan.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem asks for the exact same optimization over permutations, preserving its equivalence to the two-machine flow-shop makespan problem (solvable in O(N log N) via Johnson's rule).
</PRESERVED_CLASS>
<RISK>
Models might interpret "every element that precedes e" as only the immediately preceding element, though "every element" strongly implies the entire prefix.
</RISK>
