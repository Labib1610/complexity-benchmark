 We can think of this as a scheduling problem with two stages:  
- Stage 1: Structural inspection (time \(X_i\))  
- Stage 2: Cargo clearance (time \(Y_i\))  

The goal is to minimize the makespan (total time until the last cargo clearance finishes).  

This is a classic **two-machine flow shop scheduling** problem, and the optimal ordering is given by **Johnson’s rule**:  

- If \(X_i < Y_i\), sort by increasing \(X_i\).  
- If \(X_i \ge Y_i\), sort by decreasing \(Y_i\).  
- Put the first group before the second group.  

Then simulate the schedule to get the completion time.

Here’s the implementation:

```python
j = int(input())
trains = [tuple(map(int, input().split())) for _ in range(j)]

# Johnson's rule
group1 = []  # X < Y
group2 = []  # X >= Y

for x, y in trains:
    if x < y:
        group1.append((x, y))
    else:
        group2.append((x, y))

group1.sort(key=lambda t: t[0])       # increasing X
group2.sort(key=lambda t: -t[1])      # decreasing Y

order = group1 + group2

# Simulate
t_struct = 0
t_cargo = 0
for x, y in order:
    t_struct += x
    if t_cargo < t_struct:
        t_cargo = t_struct
    t_cargo += y

print(t_cargo)
```
