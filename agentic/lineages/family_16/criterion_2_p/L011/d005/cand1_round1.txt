# Problem B — Pipeline Bottleneck

Time limit: 1 s   Memory limit: 256 MB

## Description

You are configuring a data processing pipeline consisting of **j** distinct transformation modules. 
Each module requires a specific allocation cost and a specific deallocation cost.
You must establish a single linear sequence (an ordering) of these **j** modules.

For your chosen sequence, let $A_i$ be the allocation cost of the $i$-th module in the sequence, and $B_i$ be its deallocation cost (where $1 \le i \le j$).

Once the sequence is established, a diagnostic analyzer evaluates the pipeline. The analyzer isolates each possible split point $k$ ($1 \le k \le j$) and calculates a bottleneck score for that point. 
The bottleneck score at index $k$ is defined exactly as:
(The sum of the allocation costs of all modules from index $1$ up to $k$, inclusive) 
PLUS 
(The sum of the deallocation costs of all modules from index $k$ up to $j$, inclusive).

The pipeline's overall latency $C$ is the maximum bottleneck score found across all $j$ possible split points. 
Mathematically, $C = \max_{1 \le k \le j} \left( \sum_{i=1}^k A_i + \sum_{i=k}^j B_i \right)$.

Your task is to find an ordering of the **j** modules that minimizes the overall latency $C$.
What is the minimum possible value of $C$?

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the allocation cost and deallocation cost of a module, respectively.

## Output

Print a single integer: the minimum possible value of $C$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence places the modules in this order of their costs: Module 1 is (1, 3), Module 2 is (2, 4), Module 3 is (3, 2).
The bottleneck scores for each split point $k$ would be:
- $k=1$: $1 + (3 + 4 + 2) = 10$
- $k=2$: $(1 + 2) + (4 + 2) = 9$
- $k=3$: $(1 + 2 + 3) + 2 = 8$
The maximum of these scores is 10. This is the minimum possible overall latency $C$.

In Example 2, there is only one module. The only possible index is $k=1$. The bottleneck score is the allocation cost (5) plus the deallocation cost (3). Thus, $C = 5 + 3 = 8$.
