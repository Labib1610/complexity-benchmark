<STATEMENT>
# Problem B — Vector Sequence

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a set of **j** two-dimensional vectors. Each vector $i$ has an X-component $x_i$ and a Y-component $y_i$.

You must arrange all **j** vectors into a single sequence $v_1, v_2, \dots, v_j$. 

Once the sequence is chosen, you generate a sequence of points $P_0, P_1, \dots, P_j$ in the 2D plane according to the following rules:
1. The starting point is at the origin: $P_0 = (0, 0)$.
2. For each step $k$ from $1$ to $j$, let the previous point be $P_{k-1} = (X_{prev}, Y_{prev})$. The next point $P_k = (X_k, Y_k)$ is calculated using the components of the vector $v_k = (x_{v_k}, y_{v_k})$:
   - First, the X-coordinate is updated by adding the vector's X-component: 
     $X_k = X_{prev} + x_{v_k}$
   - Then, the Y-coordinate is updated by taking the maximum of the previous Y-coordinate and the new X-coordinate, and adding the vector's Y-component: 
     $Y_k = \max(Y_{prev}, X_k) + y_{v_k}$

Your task is to find an ordering of the **j** vectors that minimizes the final Y-coordinate, $Y_j$.

What is the minimum possible value of $Y_j$?

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers $x$ and $y$ (1 ≤ x, y ≤ 1000000), representing the X-component and Y-component of a vector, respectively.

## Output

Print a single integer: the minimum possible value of the final Y-coordinate, $Y_j$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, the three vectors are $(3, 2)$, $(2, 4)$, and $(1, 3)$. 
One optimal sequence is $v_1 = (1, 3)$, $v_2 = (2, 4)$, $v_3 = (3, 2)$.
Starting at $P_0 = (0, 0)$:
- **Step 1:** $v_1 = (1, 3)$
  $X_1 = 0 + 1 = 1$
  $Y_1 = \max(0, 1) + 3 = 4$
  $P_1 = (1, 4)$
- **Step 2:** $v_2 = (2, 4)$
  $X_2 = 1 + 2 = 3$
  $Y_2 = \max(4, 3) + 4 = 8$
  $P_2 = (3, 8)$
- **Step 3:** $v_3 = (3, 2)$
  $X_3 = 3 + 3 = 6$
  $Y_3 = \max(8, 6) + 2 = 10$
  $P_3 = (6, 10)$

The final Y-coordinate is 10, which is the minimum possible value for any arrangement.

<RATIONALE>
The problem was completely reframed from a scheduling task (which language models easily map to Johnson's algorithms via terms like "stages", "performances", and "order") into an abstract 2D coordinate accumulation. The mathematical recurrence is identical to the makespan calculation of a two-machine flow shop, ensuring identical test cases, but forces the model to derive the optimization strategy from algebraic rules rather than matching domain keywords.
</RATIONALE>

The variables $X_k$ and $Y_k$ perfectly substitute the completion times for machine 1 and machine 2 in a two-stage flow shop, maintaining the exact same makespan recurrence and therefore the exact same optimal order and minimum value.
</PRESERVED_ANSWER>
