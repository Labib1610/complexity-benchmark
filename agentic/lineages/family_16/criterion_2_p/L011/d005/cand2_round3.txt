<METHOD_DESCRIPTION>Frame the problem as evaluating a sequence of pairs using a specific mathematical recurrence relation. The recurrence $D_i = \max(D_{i-1} + Y_{i-1} - X_i, 0)$ mathematically computes the exact same makespan as the two-machine flow-shop problem (representing the second machine's accumulated idle time), but completely removes all scheduling terminology (machines, stages, jobs, time). <STATEMENT>
# Problem B — Sequence Evaluation

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a collection of **j** items. Each item consists of exactly two integers: an X-value and a Y-value. The collection may contain duplicate items, and every given item must be used exactly once.

You must arrange these **j** items into a single ordered sequence. Let your chosen sequence of items be $(X_1, Y_1), (X_2, Y_2), \dots, (X_j, Y_j)$.

Once the sequence is chosen, you compute a series of values $D_i$ for $1 \le i \le j$ according to the following rules:
1. $D_1 = 0$
2. For every $i > 1$, $D_i = \max(D_{i-1} + Y_{i-1} - X_i, \, 0)$

After computing all $D_i$, the overall score $C$ of the sequence is determined as:
$C = D_j + Y_j + \sum_{k=1}^j X_k$

Your task is to find an arrangement of the **j** items that minimizes the value of $C$. What is the minimum possible value of $C$?

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **X** and **Y** (1 ≤ X, Y ≤ 1000000), representing the X-value and Y-value of an item, respectively.

## Output

Print a single integer: the minimum possible value of $C$.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, there is only one item. Following the rules, $D_1 = 0$. The overall score is $C = D_1 + Y_1 + X_1 = 0 + 3 + 5 = 8$.
</STATEMENT>
<RATIONALE>
I replaced the two-machine scheduling narrative with an abstract algebraic sequence evaluation. The recurrence relation computes the equivalent of the second machine's idle time, completely hiding the flow-shop makespan structure. This forces models to derive the pairwise exchange condition purely from the algebra rather than relying on semantic pattern matching to trigger their Johnson's rule templates.
</RATIONALE>
<PRESERVED_ANSWER>
The recurrence $D_i$ combined with the final score $C = D_j + Y_j + \sum X_k$ is mathematically identical to the original makespan calculation $S_i = \max(S_{i-1} + B_{i-1}, \sum A_k)$, ensuring every permutation yields the exact same score as in the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying objective function and permutation space are mathematically unchanged, meaning the problem remains solvable in O(j log j) time by applying Johnson's rule.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the sum $\sum_{k=1}^j X_k$ as a prefix sum up to $i$ rather than the total sum of all given $X$ values, though the index $j$ makes it standard notation.
</RISK>
