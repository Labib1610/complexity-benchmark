# Problem B — Festival Lineup

Time limit: 1 s   Memory limit: 256 MB

## Description

You are organizing a festival featuring **j** distinct performances. Each performance consists of a live act on the Main Stage, followed by a critique session in the Review Room.

Both the Main Stage and the Review Room can only accommodate one performance at a time. The festival follows these strict scheduling rules:

- You must establish a single, fixed lineup of all **j** performances.
- The Main Stage hosts the live acts consecutively in the exact order of your lineup, starting at time 0, with no idle time between them.
- The Review Room also hosts the critique sessions in that exact same lineup order.
- For each performance, its critique session in the Review Room begins at the earliest possible moment. This moment is exactly when both of the following conditions are met:
  1. The performance has fully completed its live act on the Main Stage.
  2. The Review Room has finished the critique session of the previous performance in the lineup (this second condition does not apply to the first performance).

Because the two venues operate independently, the Main Stage can host a later performance while the Review Room is holding a critique for an earlier one. You must determine the optimal lineup of performances to minimize the total elapsed time. 

What is the earliest possible moment the final performance in your lineup can conclude its critique session?

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the duration the performance requires on the Main Stage and in the Review Room, respectively.

## Output

Print a single integer: the minimum possible time at which the Review Room finishes the final performance's critique session.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single performance occupies the Main Stage for 5 time units, and then the Review Room for 3 time units. It finishes at time 8.
