# Problem B — Festival Lineup

Time limit: 1 s   Memory limit: 256 MB

## Description

You are organizing a festival featuring **j** distinct performances. Each performance consists of a live act on the Main Stage, followed by a critique session in the Review Room.

Both venues can only accommodate one performance at a time. The festival scheduling follows these rules:

- You must establish a schedule for the Main Stage by ordering all **j** live acts.
- The Main Stage hosts the live acts consecutively in your chosen order, starting at time 0, with no gaps between them.
- Once a performance fully completes its live act on the Main Stage, it immediately joins the pool of performances waiting for a critique.
- The Review Room conducts the critique sessions. It operates independently of the Main Stage and can select waiting performances in any order. The Review Room can only handle one critique at a time. Once a critique begins, it runs to completion without interruption.
- The Review Room will begin a new critique the exact moment it becomes free, provided there is at least one performance waiting. If no performances are waiting, it remains idle until the next live act finishes.
- You have full control over both the Main Stage ordering and the order in which the Review Room selects from the waiting performances.

You must determine the optimal Main Stage schedule and Review Room selection strategy to minimize the total elapsed time from time 0 until all critiques are finished.

What is the earliest possible moment all **j** critique sessions can be fully concluded?

## Input

The first line contains a single integer **j** (1 ≤ j ≤ 200000).
Each of the following **j** lines contains two integers **p1** and **p2** (1 ≤ p1, p2 ≤ 1000000), representing the duration the performance requires on the Main Stage and in the Review Room, respectively.

## Output

Print a single integer: the minimum possible time at which all critique sessions are completed.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single performance occupies the Main Stage for 5 time units, and then the Review Room for 3 time units. It finishes at time 8.
</STATEMENT>
<RATIONALE>
Removed the explicit constraint that the second stage must process performances in the exact same order as the first stage. This strips away the obvious permutation flow-shop framing that models used to pattern-match Johnson's rule, forcing them to deduce that the optimal makespan is still achieved by a permutation schedule.
</RATIONALE>
<PRESERVED_ANSWER>
It is a fundamental property of the two-machine flow shop that the minimum makespan among all schedules is always achievable by a permutation schedule, so allowing independent ordering on the second machine does not decrease the optimal time.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for the minimum makespan in a two-machine flow shop, which remains solvable in O(j log j) time via Johnson's algorithm.
</PRESERVED_CLASS>
