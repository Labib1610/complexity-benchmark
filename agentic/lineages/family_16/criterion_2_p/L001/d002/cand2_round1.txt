# Canyon Checkpoints

Time limit: 1 s   Memory limit: 256 MB

## Description

A convoy leader must arrange their merchants into a single-file formation to pass through a restricted mountain route. The route features two sequential toll gates. Each merchant requires a specific duration to be inspected at the first gate, and another specific duration to be inspected at the second gate.

The transit is governed by the following mechanics:
- The leader establishes a fixed single-file sequence of all merchants before reaching the first gate.
- The first gate inspects the merchants one by one in this exact sequence.
- The moment a merchant passes the first gate, they immediately join the waiting line for the second gate.
- The second gate inspects merchants one by one. It processes merchants from the waiting line in the exact order they arrived. A merchant must wait in line if the second gate is currently occupied with a previous merchant.

The leader wants to minimize the total time until the last merchant clears the second gate. Determine this minimum possible completion time.

The total number of merchants is limited by the staging camp's maximum capacity of 200,000, with a minimum of 1 merchant always present. The inspection durations are measured in whole minutes. The guards use sandglasses that run out after exactly 1,000,000 minutes, establishing a strict maximum for any single inspection at either gate, while the minimum duration is 1 minute.

## Input

The first line contains a single integer **j**: the number of merchants in the convoy.
Each of the next **j** lines contains two integers **p1** and **p2**: the inspection durations at the first and second gates for that merchant.

## Output

Print a single integer: the smallest possible time at which all merchants have cleared the second gate.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 2, the single merchant takes 5 minutes for the first gate's inspection and then 3 minutes for the second gate, clearing the route at time 8.
