# Problem A — Resonance Calibration

Time limit: 5 s   Memory limit: 256 MB

## Description

A geological scanner operates in a subterranean measurement space of dimensions **k** × **k** × **k**. Every position in this space is defined by a stratum **x**, a parallel **y**, and a meridian **z**.

The scanner has identified **t** acoustic anomalies at specific `(x, y, z)` positions. 

To calibrate the scanning array, you must activate exactly **k** acoustic anomalies from the provided list. However, the array's sensors will fail if any two activated anomalies are aligned. Two anomalies are considered aligned if they share the same stratum, the same parallel, or the same meridian. 

Determine whether it is possible to activate exactly **k** anomalies such that no two are aligned, and if so, report one valid configuration.

## Input

The first line provides the measurement space dimension **k** and the number of identified anomalies **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k). 
Each of the following **t** lines contains three integers **x**, **y**, and **z** (1 ≤ x, y, z ≤ k), representing the stratum, parallel, and meridian of an acoustic anomaly. No position is listed more than once.

## Output

If a valid configuration of exactly **k** unaligned anomalies exists, print `YES` on the first line. Then, print exactly **k** lines, each containing the three coordinates `x y z` of one activated anomaly. Any valid configuration is accepted, and the anomalies may be printed in any order.

If no valid configuration exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both identified anomalies are located at parallel 1. Any configuration of 2 anomalies would include two that are aligned along the parallel axis, causing the sensors to fail.
