<METHOD_NAME>Geometric Projection Inequalities</METHOD_NAME>
<METHOD_DESCRIPTION>Translates the exact-cover requirement (every coordinate value 1..k appears exactly once) into a set of strict inequalities comparing 3D Manhattan distances to their 2D planar projections. This forces the model to algebraically deduce that differences in all three dimensions must be strictly positive for every pair, which combined with the set size implies a permutation of coordinates, hiding the exact cover structure.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Resonance Calibration

Time limit: 5 s   Memory limit: 256 MB

## Description

A geological scanner operates in a subterranean grid. Every location in the grid is defined by a depth **x**, a latitude **y**, and a longitude **z**, each taking an integer value from 1 up to the grid's bounding dimension **k**.

The scanner has identified **t** resonance pockets at specific `(x, y, z)` locations. 

To calibrate the system, you must load a subset of the identified pockets into the scanner's memory bank. The memory bank has exactly **k** slots, and every slot must be filled with a distinct pocket from the identified list.

Once loaded, the scanner evaluates the spatial isolation of the chosen subset to prevent harmonic feedback. For any two pockets `(x1, y1, z1)` and `(x2, y2, z2)`, their 3-dimensional Manhattan distance is defined as `|x1 - x2| + |y1 - y2| + |z1 - z2|`. 

The calibration is successful if and only if, for every pair of distinct pockets loaded in the memory bank, their 3-dimensional Manhattan distance is:
- strictly greater than the distance between their projections on the depth-latitude plane (`|x1 - x2| + |y1 - y2|`),
- strictly greater than the distance between their projections on the depth-longitude plane (`|x1 - x2| + |z1 - z2|`), and
- strictly greater than the distance between their projections on the latitude-longitude plane (`|y1 - y2| + |z1 - z2|`).

Determine whether a successful calibration is possible, and if so, report one valid selection of resonance pockets.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the grid dimension and the number of identified resonance pockets.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), the coordinates of a resonance pocket. No location is listed more than once.

## Output

If a valid calibration configuration of exactly **k** pockets exists, print `YES` on the first line. Then, print **k** lines, each containing the three coordinates `x y z` of one selected pocket. Any valid selection is accepted, and the pockets may be printed in any order.

If no valid selection exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the grid dimension is 2, so the memory bank requires exactly 2 pockets. The two identified pockets are `(1, 1, 1)` and `(2, 1, 2)`. If both are loaded, we evaluate their isolation. Their 3-dimensional Manhattan distance is `|1 - 2| + |1 - 1| + |1 - 2| = 1 + 0 + 1 = 2`. The distance between their projections on the depth-longitude plane is `|1 - 2| + |1 - 2| = 1 + 1 = 2`. Since 2 is not strictly greater than 2, the isolation check fails. Thus, a successful calibration is impossible.
</STATEMENT>
<RATIONALE>
The explicit coordinate-wise exact cover requirements have been replaced with strict inequalities comparing 3D Manhattan distances to 2D projections. To succeed efficiently, a model must algebraically deduce that `|x1 - x2| + |y1 - y2| + |z1 - z2| > |x1 - x2| + |y1 - y2|` implies `|z1 - z2| > 0`, meaning no two chosen pockets can share any coordinate.
</RATIONALE>
<PRESERVED_ANSWER>
Requiring `k` items where no two share an `x`, `y`, or `z` coordinate from a domain of size `k` is mathematically identical to requiring that exactly one item exists for every `x`, `y`, and `z` value, preserving all valid subsets.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, as it still asks to find a subset of `k` disjoint triples from a given set of triples.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the strict inequalities as a continuous geometry problem rather than a discrete combinatorial one, though the explicit definition of Manhattan distance using absolute differences should mitigate this.
</RISK>
