We need to select exactly k points from the given t points such that the x-values, y-values, and z-values each form the set {1, 2, ..., k}.  

This is essentially a 3D matching problem, which is NP-hard in general, but k ≤ 22 and t ≤ k³, so we need a clever approach.  

We can model it as a bipartite matching problem:  
- Left side: x-values (1..k)  
- Right side: (y, z) pairs (k² possibilities)  
- Edge exists if there is a point (x, y, z) in the input.  

We need a perfect matching that covers all x-values and all (y, z) pairs exactly once. But that’s not exactly the same as our problem — we need each y and each z to appear exactly once, not each (y,z) pair.  

Better approach:  
We can think of it as a 3D matching problem, but since k is small (≤22), we can use backtracking with pruning, or reduce to a flow problem.  

Actually, we can reduce to a bipartite matching between x and y, and then check z feasibility, but that’s tricky.  

A known approach:  
- Since k ≤ 22, we can use a recursive backtracking that assigns each x-value a point, ensuring y and z are unique.  
- We can precompute for each x the list of possible (y,z) pairs.  
- Use bitmasks for y and z to track used values.  
- With pruning (e.g., if remaining x's can't cover remaining y or z, backtrack), this should be fast enough for k=22.  

Let's implement that.  

We'll store points in a dictionary: for each x, a list of (y,z).  
Then we do DFS over x from 1 to k, trying each (y,z) for that x, ensuring y and z are unused.  

We also need to handle t=0 or insufficient points.  

Let's code it.  

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    points_by_x = [[] for _ in range(k+1)]
    for _ in range(t):
        x, y, z = map(int, input().split())
        points_by_x[x].append((y, z))
    
    # If any x has no points, impossible
    for x in range(1, k+1):
        if not points_by_x[x]:
            print("NO")
            return
    
    # Sort points for deterministic order
    for x in range(1, k+1):
        points_by_x[x].sort()
    
    used_y = [False] * (k+1)
    used_z = [False] * (k+1)
    chosen = [None] * (k+1)
    
    # Precompute for each x the list of (y,z) that are still possible given used_y, used_z
    # We'll do DFS with pruning.
    
    def dfs(x):
        if x > k:
            return True
        # Prune: count remaining y and z availability
        remaining_y = sum(1 for i in range(1, k+1) if not used_y[i])
        remaining_z = sum(1 for i in range(1, k+1) if not used_z[i])
        remaining_x = k - x + 1
        if remaining_y < remaining_x or remaining_z < remaining_x:
            return False
        
        for y, z in points_by_x[x]:
            if not used_y[y] and not used_z[z]:
                used_y[y] = True
                used_z[z] = True
                chosen[x] = (x, y, z)
                if dfs(x+1):
                    return True
                used_y[y] = False
                used_z[z] = False
        return False
    
    if dfs(1):
        print("YES")
        for x in range(1, k+1):
            print(*chosen[x])
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
