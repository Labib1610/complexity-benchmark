<STATEMENT>
# Problem A — Resonance Calibration

Time limit: 5 s   Memory limit: 256 MB

## Description

A geological scanner operates in a subterranean grid of dimensions **k** × **k** × **k**. Every location in the grid is defined by a depth **x**, a latitude **y**, and a longitude **z**, each taking an integer value from 1 to **k**.

The scanner has identified **t** resonance pockets at specific `(x, y, z)` locations. 

To calibrate the scanning array, you must select a subset of exactly **k** resonance pockets from the identified list. A successful calibration requires that the selected pockets completely span all three coordinate axes. Specifically, the set of depth values of the chosen pockets must be exactly $\{1, 2, \dots, k\}$. The set of latitude values and the set of longitude values of the chosen pockets must also each equal $\{1, 2, \dots, k\}$.

Determine whether a successful calibration is possible, and if so, report one valid selection of resonance pockets.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the grid dimension and the number of identified resonance pockets.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), the coordinates of a resonance pocket. No location is listed more than once.

## Output

If a valid calibration configuration of exactly **k** pockets exists, print `YES` on the first line. Then, print **k** lines, each containing the three coordinates `x y z` of one selected pocket. Any valid selection is accepted, and the pockets may be printed in any order.

If no valid selection exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both identified resonance pockets are located at latitude 1. For any selection of 2 pockets, the set of latitude values would be $\{1\}$, which does not equal $\{1, 2\}$. Thus, a successful calibration is impossible.
</STATEMENT>
<RATIONALE>
The simulated feedback suggested adding a new `x+y+z` constraint, which was ignored because it would alter the valid answers and violate Hard Constraint #1. Instead, the observed affordance was removed by replacing the explicit "no two pockets share..." interference rule with a set-coverage requirement. Models can no longer rely on surface pattern-matching for pairwise distinctness; they must logically deduce that covering a set of size $k$ using exactly $k$ items implies mutual distinctness across all three axes.
</RATIONALE>
<PRESERVED_ANSWER>
Selecting exactly $k$ pockets such that the set of their depths is exactly $\{1, 2, \dots, k\}$ mathematically requires that all $k$ pockets have distinct depths; applying this to all three axes ensures the constraint perfectly matches the original interference rule.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, as it still asks to find $k$ mutually disjoint triplets from a given subset of $V_1 \times V_2 \times V_3$ where each $|V_i| = k$.
</PRESERVED_CLASS>
