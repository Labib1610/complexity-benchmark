<STATEMENT>
# Problem A — Resonance Calibration

Time limit: 5 s   Memory limit: 256 MB

## Description

A geological scanner probes a subterranean grid of dimensions **k** × **k** × **k**. Each position within the grid is given by three coordinates: a depth **x**, a latitude **y**, and a longitude **z**. These coordinates take integer values ranging from 1 to **k**.

During an initial sweep, the scanner detected **t** resonance pockets, each situated at a specific `(x, y, z)` position. 

Calibration of the scanning array requires choosing a subset of exactly **k** resonance pockets from those detected. The array evaluates the structural coverage of the chosen subset along all three axes. A calibration is deemed successful if and only if every depth value from 1 to **k** is represented by at least one chosen pocket, every latitude value from 1 to **k** is represented by at least one chosen pocket, and every longitude value from 1 to **k** is represented by at least one chosen pocket.

Determine whether a successful calibration is possible. If so, report one valid selection of resonance pockets.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the grid dimension and the number of detected resonance pockets.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), the coordinates of a resonance pocket. No location is listed more than once.

## Output

If a valid calibration configuration of exactly **k** pockets exists, print `YES` on the first line. Then, print **k** lines, each containing the three coordinates `x y z` of one chosen pocket. Any valid selection is accepted, and the pockets may be printed in any order.

If no valid selection exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both detected resonance pockets have a latitude value of 1. For any selection of 2 pockets, the latitude value 2 will not be represented. Thus, a successful calibration is impossible.
</STATEMENT>
<RATIONALE>
Changed the explicit set equality constraint (which directly signaled a bijection/matching by stating the sets of coordinates must exactly equal `{1..k}`) into a coverage requirement ("at least one pocket" per coordinate value). Because exactly `k` pockets are selected, this mathematically forces a perfect matching, but models must now deduce this structural equivalence themselves rather than pattern-matching the set notation.
</RATIONALE>
<PRESERVED_ANSWER>
Selecting exactly k pockets that cover all k values in each of the 3 dimensions is mathematically identical to requiring the sets of coordinates to exactly equal {1..k}, so the valid configurations remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, which is an NP-complete problem.
</PRESERVED_CLASS>
