<STATEMENT>
# Problem A — Compound Synthesis

Time limit: 5 s   Memory limit: 256 MB

## Description

A laboratory is synthesizing complex compounds. The inventory contains distinct base fluids (labeled 1 through **k**), catalysts (labeled 1 through **k**), and thermal profiles (labeled 1 through **k**).

When mixed, a specific base fluid, a single catalyst, and one thermal profile form a reaction. However, only certain specific combinations of these three elements are stable. You are provided with a database of **t** stable reactions.

A valid synthesis protocol requires identifying a subset of exactly **k** reactions from the database such that a global exact-incidence requirement is met: across the chosen subset, every base fluid label from 1 to **k** must be utilized exactly once, every catalyst label from 1 to **k** must be utilized exactly once, and every thermal profile label from 1 to **k** must be utilized exactly once.

Your task is to determine whether such a protocol can be formed. If it can, you must also provide the list of the **k** reactions that achieve this.

## Input

The first line contains two integers **k** and **t**. The parameter **k** is at least 1 and is bounded by the laboratory's maximum capacity of 22 storage vats per ingredient type. The parameter **t** represents the number of stable reactions and ranges from 0 up to the theoretical maximum of **k**·**k**·**k**.

Each of the next **t** lines contains three integers **x**, **y**, **z** (where each value is between 1 and **k** inclusive), representing a stable reaction made of base fluid **x**, catalyst **y**, and thermal profile **z**. No reaction is listed more than once.

## Output

If a valid synthesis protocol can be formed, print `YES` on the first line, then print **k** lines, each containing the three integers `x y z` of one chosen reaction. Any valid protocol is accepted; the reactions may be printed in any order.

If no valid synthesis protocol can be formed, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both stable reactions require catalyst 1, leaving catalyst 2 impossible to consume.
</STATEMENT>
<RATIONALE>
The explicit breakdown of "no two reactions may share the same base fluid" has been replaced with a symmetric global exact-incidence requirement. This removes the implicit hint to decompose the problem by iterating over one specific ingredient type (e.g., base fluids) and forces the model to independently deduce the viability of row-wise backtracking or exact-cover reduction. Numeric bounds have been embedded into the scenario text to comply with the strategy while ensuring the exact numeric values are retained for automatic checkers.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to select exactly k reactions covering all labels from 1 to k exactly once is mathematically identical to selecting one reaction per base fluid without reusing catalysts or thermal profiles.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, which is NP-complete, as the structure of choosing triples to exactly cover three sets of size k is unchanged.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "global exact-incidence requirement" if they fail to parse that it means each label appears exactly once across the entire chosen subset, though the phrasing "must be utilized exactly once" is highly explicit.
</RISK>
