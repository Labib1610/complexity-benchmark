<STATEMENT>
# Problem A — Compound Synthesis

Time limit: 5 s   Memory limit: 256 MB

## Description

A laboratory is synthesizing complex compounds. The inventory contains **k** distinct base fluids (labeled 1 through **k**), **k** catalysts (labeled 1 through **k**), and **k** thermal profiles (labeled 1 through **k**).

When mixed, a specific base fluid, a single catalyst, and one thermal profile form a reaction. However, only certain specific combinations of these three elements are stable. You are provided with a database of **t** stable reactions.

Your task is to extract a subset of these stable reactions to form a complete testing sequence. A valid sequence is defined by a strict consumption rule: across all the reactions you choose to include, every base fluid from 1 to **k** must appear exactly once, every catalyst from 1 to **k** must appear exactly once, and every thermal profile from 1 to **k** must appear exactly once. 

Determine whether such a sequence can be compiled.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k), representing the number of each ingredient type and the number of known stable reactions.
Each of the next **t** lines contains three integers **x**, **y**, and **z** (1 ≤ x, y, z ≤ k), representing a stable reaction composed of base fluid **x**, catalyst **y**, and thermal profile **z**. No reaction is listed more than once.

## Output

If a complete testing sequence can be compiled, print `YES` on the first line, followed by **k** lines. Each of these lines must contain the three integers `x y z` of one chosen reaction in the sequence. Any valid sequence is accepted, and its reactions may be printed in any order.

If no such sequence exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both stable reactions require catalyst 1. Any subset that includes both reactions will use catalyst 1 twice, and any subset that omits one will fail to use all base fluids or thermal profiles exactly once, making a valid sequence impossible.

The description was rewritten to remove explicit instructions to "select exactly k stable reactions" where "no two reactions may share the same base fluid". Instead, the selection is framed as a global exact-incidence requirement over a subset. This forces the model to deduce the row-wise backtracking decomposition (picking exactly one reaction per base fluid) from the global exact-cover constraints, rather than having the decomposition handed to it in the problem text.
