We need to select exactly k reactions such that each base fluid, catalyst, and thermal profile is used exactly once. This is a 3D matching problem, which is NP-hard in general, but k ≤ 22 allows a meet-in-the-middle or backtracking with pruning approach.

A common approach for k up to ~22 is to use **backtracking with bitmasks** and **recursive search with pruning**, possibly using **Dancing Links** or **bitmask DP** if the structure allows.

Here’s a plan:

- Represent each reaction as a tuple (x, y, z).
- We need to pick k reactions such that:
  - All x values are distinct (cover 1..k)
  - All y values are distinct
  - All z values are distinct
- This is exactly a perfect 3D matching.

We can do backtracking:
- Sort reactions by some heuristic (e.g., by how constrained they are).
- Use bitmasks for used x, y, z.
- At each step, pick the next unused x (or the most constrained one) and try reactions with that x.

Since k ≤ 22, the search space can be large, but with good pruning (e.g., checking if remaining y/z can still cover all), it should pass.

We can also use **meet-in-the-middle**:
- Split reactions into two halves, but that’s tricky for 3D matching.

Given constraints, a well-optimized backtracking with bitmask and forward checking should work.

    reactions = []

    by_x = [[] for _ in range(k)]

    for i in range(k):

    used_y = 0
    used_z = 0
    chosen = [None] * k
    full_mask = (1 << k) - 1

    # We'll do recursive backtracking with forward checking

    order = sorted(range(k), key=lambda x: len(by_x[x]))

    def backtrack(pos):
        nonlocal used_y, used_z
        if pos == k:
            return True
        x = order[pos]
        for y, z, idx in by_x[x]:
            if (used_y >> y) & 1:
                continue
            if (used_z >> z) & 1:
                continue

            # Simple check: count remaining y and z vs remaining slots
            # We'll do a quick check: number of unused y must be >= remaining slots, same for z
            remaining = k - pos - 1
            unused_y_count = k - bin(used_y).count("1")
            unused_z_count = k - bin(used_z).count("1")
            if unused_y_count - 1 < remaining or unused_z_count - 1 < remaining:
                continue
            # Also check if any remaining x has no valid y/z left
            # This is more expensive but can prune a lot
            # We'll do a simple check: for each remaining x, at least one option with unused y,z
            possible = True
            for j in range(pos+1, k):
                x2 = order[j]
                found = False
                for y2, z2, _ in by_x[x2]:
                    if not ((used_y >> y2) & 1) and not ((used_z >> z2) & 1):
                        found = True
                        break
                if not found:
                    possible = False
                    break

            used_z |= (1 << z)
            chosen[x] = (x+1, y+1, z+1)
            if backtrack(pos+1):
                return True
            # Undo
            used_y ^= (1 << y)
            used_z ^= (1 << z)
        return False

    if backtrack(0):
        print("YES")

    else:
