<STATEMENT>
# Problem A — Sensor Placement

Time limit: 5 s   Memory limit: 256 MB

## Description

A research facility is testing a new spatial anomaly detector. The testing chamber is modeled as a 3D grid with coordinates ranging from 1 to **k** in each dimension. 

You need to deploy exactly **k** sensors within this chamber. Sensors can only be installed at specific locations where mounting brackets have been pre-installed. You are given a list of all viable bracket locations.

To avoid interference, no two deployed sensors may share an X-coordinate. Similarly, no two may share a Y-coordinate, and no two may share a Z-coordinate. 

Determine whether it is possible to deploy exactly **k** sensors under these conditions, and if so, report the coordinates of the chosen brackets.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the dimension of the chamber and the number of available brackets.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing the coordinates of a mounting bracket. No coordinate triplet is listed more than once.

## Output

If a valid deployment of **k** sensors exists, print `YES` on the first line. Then, print **k** lines, each containing three integers `x y z` representing the coordinates of a deployed sensor. Any valid assignment is accepted; the sensors may be printed in any order.

If no valid deployment exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both available brackets are located at Y-coordinate 1. It is impossible to deploy 2 sensors without them sharing a Y-coordinate.
</STATEMENT>
<RATIONALE>
Replaced the resource allocation scenario with a 3D geometric placement problem (placing sensors in a grid). This symmetric spatial framing discourages models from arbitrarily breaking symmetry to form a bipartite matching from `(x, y)` to `z`, forcing them to reason about the full three-dimensional constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that no two sensors share an X, Y, or Z coordinate while selecting exactly `k` sensors from a `k` × `k` × `k` space is mathematically identical to selecting `k` resource combinations such that every resource from 1 to `k` is used exactly once.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, an NP-complete problem, merely represented as non-intersecting coordinates rather than non-intersecting sets.
</PRESERVED_CLASS>
