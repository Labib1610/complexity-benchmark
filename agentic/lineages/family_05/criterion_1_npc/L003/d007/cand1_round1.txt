<STATEMENT>
# Resonance Alignment

Time limit: 5 s   Memory limit: 256 MB

## Description

You are calibrating a quantum resonance array. The array requires exactly $N$ focus nodes to achieve criticality. 

You have access to a repository of $M$ candidate nodes. Each candidate node is characterized by three frequency harmonics: Alpha, Beta, and Gamma. 

When a set of nodes is installed, the array exhibits a *resonance signature* for each harmonic category. The resonance signature of a category is defined as the sum of $2^h$ across all installed nodes, where $h$ is the harmonic value of the node in that category. 

To achieve perfect calibration, the resonance signature for the Alpha harmonics, the Beta harmonics, and the Gamma harmonics must each equal exactly $2^{N+1} - 2$.

Determine if it is possible to select exactly $N$ nodes from the repository to achieve perfect calibration.

## Input

The first line contains two integers, $N$ and $M$. The array requires exactly $N$ focus nodes (where $N$ is between 1 and 22, inclusive). The repository contains $M$ available candidate nodes (from 0 up to a maximum of $N^3$). 

The following $M$ lines each contain three integers $a$, $b$, and $c$, representing the Alpha, Beta, and Gamma harmonics of a candidate node. These harmonic values are guaranteed to be positive integers no larger than $N$. All candidate nodes listed in the input are distinct. You may use each listed node at most once.

## Output

If a perfectly calibrated array can be formed, print `YES` on the first line. Then, output $N$ lines, each containing the three integers $a$ $b$ $c$ of a chosen node. If multiple valid selections exist, you may output any of them. The nodes may be printed in any order.

If it is impossible to select $N$ nodes that meet the calibration requirement, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, if we select both available nodes `1 1 1` and `2 1 2`, the Alpha resonance signature is $2^1 + 2^2 = 6$. The Beta resonance signature is $2^1 + 2^1 = 4$. The Gamma resonance signature is $2^1 + 2^2 = 6$. The required signature for $N=2$ is $2^{2+1} - 2 = 6$. Since the Beta signature (4) does not equal 6, this selection is not perfectly calibrated. With only 2 nodes available, it is impossible to satisfy the requirement.
</STATEMENT>
<RATIONALE>
I removed the "diversity product" condition, which easily gave away that the target was a bijection. I replaced it with a constraint on the sum of powers of 2 for the selected harmonics. The model must now reason about binary representations or arithmetic properties to deduce that summing $N$ powers of 2 (each $\le 2^N$) to exactly $2^{N+1}-2$ strictly requires selecting every power from 1 to $N$ exactly once. I also replaced bare inequalities in the input section with physical limits via Strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
Because of the uniqueness of binary representation, the only way to sum $N$ powers of 2 to $2^{N+1}-2$ without carries is if each exponent from 1 to $N$ appears exactly once, making this condition mathematically identical to the original "perfectly balanced" diversity constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires selecting $N$ triples from a given set such that no two triples share the same value in any coordinate, which is exactly the NP-complete 3-Dimensional Matching problem.
</PRESERVED_CLASS>
<RISK>
The model might interpret $2^h$ as a risk of integer overflow, but since $N \le 22$, $2^{23}$ easily fits in standard 32-bit integers, so there is no practical ambiguity.
</RISK>

Binary Signature Disguise
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces a requirement for "all distinct values" (previously framed as a maximum product of diversities) with an arithmetic sum of powers of 2. Since summing $N$ terms of $2^{x_i}$ to $2^{N+1}-2$ strictly enforces that $\{x_1, \dots, x_N\} = \{1, \dots, N\}$, it perfectly preserves the 3DM reduction without using any words related to uniqueness, sets, or diversity.
