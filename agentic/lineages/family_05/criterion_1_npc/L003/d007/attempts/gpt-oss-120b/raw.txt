**Solution Explanation**

For every module we are given three numbers  

```
x – frequency   ( 1 … k )
y – amplitude   ( 1 … k )
z – phase       ( 1 … k )
```

We have to choose exactly `k` different modules.
For the chosen set the three *interference signatures* have to be

```
 Σ 2^(x-1) = Σ 2^(y-1) = Σ 2^(z-1) = 2^k – 1
```

`2^k‑1` is the sum of all powers `2^0 , 2^1 , … , 2^(k‑1)`.  
Therefore in a valid set

* the `k` values `x` must be a permutation of `1 … k`
* the `k` values `y` must be a permutation of `1 … k`
* the `k` values `z` must be a permutation of `1 … k`

In other words we have to pick `k` triples so that each number
`1 … k` appears **once** in each coordinate.

--------------------------------------------------------------------

#### 1.   Exact cover formulation  

Create a set of `3·k` items

```
X1 … Xk   – “frequency i is used”
Y1 … Yk   – “amplitude i is used”
Z1 … Zk   – “phase i is used”
```

Every module `(x , y , z)` corresponds to a *row* that covers exactly the
three items `Xx , Yy , Zz`.

We need an **exact cover** of all `3·k` items with exactly `k` rows.
That is the classic *exact cover* problem, solvable efficiently for the
given limits (`k ≤ 22  →  3k ≤ 66` items, at most `k³ ≤ 10648` rows).

--------------------------------------------------------------------

#### 2.   Algorithm X (Dancing Links)

Donald Knuth’s Algorithm X with the dancing‑links data structure
searches an exact cover recursively:

* choose the column (item) with the smallest number of rows – this
  gives strong pruning,
* try each row that contains this column,
* temporarily delete all columns covered by the row and all rows that
  intersect those columns,
* recurse,
* backtrack if the recursion fails.

Because the universe is tiny (≤ 66 columns) the recursion depth is at most
`k ≤ 22`.  In practice the search finishes instantly for all inputs that
satisfy the limits.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct set of modules
iff such a set exists.

---

##### Lemma 1  
A set of `k` modules satisfies the three signature equations  
iff the set covers each item `Xi , Yi , Zi` exactly once.

**Proof.**  
`Σ 2^(x-1) = 2^k‑1` holds exactly when the multiset `{x}` contains each
value `1 … k` once, because the binary representation of `2^k‑1` has a
`1` in every of the `k` low bits and no other representation with `k`
summands of powers of two can give the same sum.  
The same argument applies to `y` and `z`. ∎



##### Lemma 2  
A set of modules is a solution of the original problem  
iff the corresponding rows form an exact cover of the `3k` items.

**Proof.**  
By construction a row `(x,y,z)` contains exactly the three items
`Xx , Yy , Zz`.  
If the rows cover every item once, each number `1 … k` appears once in
each coordinate, therefore by Lemma&nbsp;1 the three signatures are
`2^k‑1`.  
Conversely, any solution of the original problem must contain each
coordinate value exactly once (Lemma&nbsp;1), hence each item is covered
once – an exact cover. ∎



##### Lemma 3  
If the dancing‑links search returns a collection of rows,
those rows form an exact cover.

**Proof.**  
Algorithm X only adds a row to the partial solution after removing all
columns it covers and all rows intersecting those columns.
Thus no later row can contain a column already covered.
When the recursion stops because no columns remain, every column has been
covered exactly once. ∎



##### Lemma 4  
If an exact cover exists, the dancing‑links search will eventually find
one.

**Proof.**  
Algorithm X explores the search tree of all possible subsets of rows.
At each step it branches over *all* rows that contain the chosen column.
Therefore every possible exact cover corresponds to a leaf of this tree.
The algorithm performs a depth‑first traversal, so it will reach that leaf
and succeed. ∎



##### Theorem  
The program outputs  

* “YES” and a list of `k` modules that satisfy the required signatures
  **iff** such a list exists,
* otherwise it outputs “NO”.

**Proof.**  

*If the program prints “YES”.*  
It printed the rows found by the dancing‑links recursion.
By Lemma&nbsp;3 they form an exact cover, and by Lemma&nbsp;2 the
corresponding modules satisfy the three signature equations.

*If a valid list of modules exists.*  
By Lemma&nbsp;2 there is an exact cover.
Lemma&nbsp;4 guarantees the search will find one, therefore the program
will output “YES” with that list.

If the search exhausts all possibilities without covering all columns,
no exact cover exists, consequently (Lemma&nbsp;2) no valid module set
exists, and the program prints “NO”. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*`C = 3k ≤ 66`* – number of columns  
*`R ≤ k³ ≤ 10648`* – number of rows  

Construction of the dancing‑links structure: `O(R·3)`.

During the search each recursive step removes at most `k` columns and
the rows intersecting them, i.e. `O(R)` work.
The depth is at most `k`, and the branching factor is limited by the
column with the smallest size.  
For the given limits the total number of visited nodes is far below
`10⁶`, well inside the time limit.

Memory consumption:  
arrays of size `R·3 + C + 1` → at most a few hundred thousand integers,
well below 256 MB.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1000000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    # columns: 0..C-1, where C = 3*k
    C = 3 * k
    # column ids for convenience
    def col_x(x): return x - 1               # 0 .. k-1
    def col_y(y): return k + (y - 1)         # k .. 2k-1
    def col_z(z): return 2 * k + (z - 1)     # 2k .. 3k-1

    rows = []          # each row: (x,y,z)
    # dancing links structures
    max_nodes = t * 3 + C + 5
    left = [0] * max_nodes
    right = [0] * max_nodes
    up = [0] * max_nodes
    down = [0] * max_nodes
    col = [0] * max_nodes          # column of node
    row_id = [0] * max_nodes       # which input row the node belongs to
    size = [0] * C                 # number of nodes in each column

    # header node 0, column headers 1..C
    header = 0
    for i in range(C + 1):
        left[i] = i - 1
        right[i] = i + 1
        up[i] = down[i] = i
    right[C] = header
    left[header] = C

    node_cnt = C + 1   # next free index

    # add a row (list of three column numbers)
    def add_row(rid, cols):
        nonlocal node_cnt
        first = None
        for c in cols:
            nd = node_cnt
            node_cnt += 1
            col[nd] = c
            row_id[nd] = rid

            # vertical links
            up[nd] = up[c + 1]
            down[nd] = c + 1
            down[up[nd]] = nd
            up[down[nd]] = nd
            size[c] += 1

            # horizontal links
            if first is None:
                left[nd] = right[nd] = nd
                first = nd
            else:
                left[nd] = left[first]
                right[nd] = first
                right[left[first]] = nd
                left[first] = nd

    for idx in range(t):
        x = int(next(it))
        y = int(next(it))
        z = int(next(it))
        rows.append((x, y, z))
        add_row(idx, [col_x(x), col_y(y), col_z(z)])

    # cover / uncover operations
    def cover(c):
        # remove column header
        left[right[c]] = left[c]
        right[left[c]] = right[c]
        # remove rows
        i = down[c]
        while i != c:
            j = right[i]
            while j != i:
                up[down[j]] = up[j]
                down[up[j]] = down[j]
                size[col[j]] -= 1
                j = right[j]
            i = down[i]

    def uncover(c):
        i = up[c]
        while i != c:
            j = left[i]
            while j != i:
                size[col[j]] += 1
                up[down[j]] = j
                down[up[j]] = j
                j = left[j]
            i = up[i]
        left[right[c]] = c
        right[left[c]] = c

    solution = []

    def search():
        if right[header] == header:          # all columns covered
            return True
        # choose column with minimal size
        c = right[header]
        min_sz = size[c - 1]
        cc = c
        j = right[c]
        while j != header:
            if size[j - 1] < min_sz:
                min_sz = size[j - 1]
                cc = j
                if min_sz == 0:
                    break
            j = right[j]
        if min_sz == 0:
            return False
        cover(cc)
        r = down[cc]
        while r != cc:
            solution.append(row_id[r])
            j = right[r]
            while j != r:
                cover(col[j] + 1)
                j = right[j]
            if search():
                return True
            # backtrack
            j = left[r]
            while j != r:
                uncover(col[j] + 1)
                j = left[j]
            solution.pop()
            r = down[r]
        uncover(cc)
        return False

    # column numbers in dancing links are 1‑based (header is 0)
    # we stored sizes indexed by 0..C-1, so when covering we use c = column+1
    # adjust functions accordingly
    # rewrite cover/uncover to accept column index (0‑based) and add 1 internally
    # but for simplicity we re‑map: when calling cover/uncover we pass column+1

    # modify search to use column+1
    def cover(col0):
        c = col0 + 1
        left[right[c]] = left[c]
        right[left[c]] = right[c]
        i = down[c]
        while i != c:
            j = right[i]
            while j != i:
                up[down[j]] = up[j]
                down[up[j]] = down[j]
                size[col[j] - 1] -= 1
                j = right[j]
            i = down[i]

    def uncover(col0):
        c = col0 + 1
        i = up[c]
        while i != c:
            j = left[i]
            while j != i:
                size[col[j] - 1] += 1
                up[down[j]] = j
                down[up[j]] = j
                j = left[j]
            i = up[i]
        left[right[c]] = c
        right[left[c]] = c

    # redo search with corrected functions
    solution.clear()

    def search():
        if right[header] == header:
            return True
        # choose column with minimal size
        c = right[header]
        best = c
        min_sz = size[col[c] - 1] if c != header else 0
        j = right[c]
        while j != header:
            sz = size[col[j] - 1]
            if sz < min_sz:
                min_sz = sz
                best = j
                if sz == 0:
                    break
            j = right[j]
        if min_sz == 0:
            return False
        cover(col[best] - 1)
        r = down[best]
        while r != best:
            solution.append(row_id[r])
            j = right[r]
            while j != r:
                cover(col[j] - 1)
                j = right[j]
            if search():
                return True
            # backtrack
            j = left[r]
            while j != r:
                uncover(col[j] - 1)
                j = left[j]
            solution.pop()
            r = down[r]
        uncover(col[best] - 1)
        return False

    # start search
    if search():
        out = ["YES"]
        for idx in solution:
            x, y, z = rows[idx]
            out.append(f"{x} {y} {z}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```
