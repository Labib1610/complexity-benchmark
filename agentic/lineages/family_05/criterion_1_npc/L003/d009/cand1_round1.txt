<STATEMENT>
# Quantum Resonance Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a quantum resonance core. The core requires exactly **k** modules to operate.

You are provided with a catalog of **t** available modules. Each module is characterized by exactly 3 parameters: Frequency, Amplitude, and Phase.

When a set of exactly **k** modules is selected, we evaluate its stability by computing a resonance signature for each parameter category. For a given category (e.g., Frequency), let the values of the **k** selected modules be $v_1, v_2, \dots, v_k$. 

The resonance signature $R$ for this category is defined as:
$R = \sum_{i=1}^k 3^{k - v_i}$

For the core to be perfectly stable, the resonance signature $R$ must evaluate to exactly $\frac{3^k - 1}{2}$ for *each* of the three parameter categories—Frequency, Amplitude, and Phase—independently. 

*System Architecture Note:* The catalog order may be adversarial, with decoy modules arranged specifically to make a fixed-parameter, first-available depth-first search explore exponentially many dead ends. 

Determine if such a stable core can be formed by selecting exactly **k** modules from the catalog.

## Input

The first line provides two integers, **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k³). Here, **k** represents the number of modules required, and **t** is the total number of available modules in the catalog.
The next **t** lines each contain three integers **x**, **y**, and **z** (1 ≤ x, y, z ≤ k), representing the Frequency, Amplitude, and Phase parameters of a module in the catalog. Every module listed in the input is distinct. You may choose only among these listed modules, and each module from the catalog may be selected at most once.

## Output

If a perfectly stable core can be formed, output `YES` on the initial line. Following this, output **k** lines each containing three integers `x y z`, specifying the modules used for your core. If several valid selections exist, supplying any one of them is sufficient. The modules may be printed in any sequence.

If it is impossible to find **k** modules satisfying the condition, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the two available modules are `1 1 1` and `2 1 2`. If both are selected, the Amplitude values are $v_1 = 1$ and $v_2 = 1$. The resonance signature for Amplitude is $R = 3^{2 - 1} + 3^{2 - 1} = 3^1 + 3^1 = 6$. 
For the core to be stable, the required signature for $k=2$ is $\frac{3^2 - 1}{2} = 4$. 
Because $6 \neq 4$, they do not form a perfectly stable core. With only 2 modules available, it is impossible to select 2 that satisfy the requirement.

<RATIONALE>
The problem was modified to replace the Vandermonde determinant condition with a sum of powers of 3. Mathematically, the sum of k powers of 3 bounded by 3^(k-1) equals (3^k-1)/2 if and only if the powers are exactly 0, 1, ..., k-1, which forces the selected values to be a permutation of 1..k. This requires genuine algebraic reasoning to recognize as an Exact Cover constraint, preventing LLMs from triggering their DLX templates through simple pattern matching of the Vandermonde matrix.
</RATIONALE>

The condition R = (3^k-1)/2 is mathematically equivalent to requiring that all k selected modules have distinct values for that category, which is exactly the same requirement as the original non-zero Vandermonde determinant.
</PRESERVED_ANSWER>
