<STATEMENT>
# Quantum Resonance Selection

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a quantum resonance core. The core requires exactly **k** modules to operate.

You are provided with a catalog of **t** available modules. Each module is characterized by exactly 3 parameters: Frequency, Amplitude, and Phase. Because each listed module has coordinates `x`, `y`, `z` with `1 ≤ x, y, z ≤ k`, every parameter value in each category is an integer from `1` to `k`.

When a set of exactly **k** modules is selected, we evaluate its stability by calculating a base-3 signature for each parameter category. For a given category (e.g., Amplitude), let the values of the **k** selected modules be $v_1, v_2, \dots, v_k$. We define the signature of this category as $R = \sum_{i=1}^{k} 3^{v_i - 1}$. 

For the core to be perfectly stable, the signature $R$ must evaluate exactly to $(3^k - 1) / 2$ for *each* of the three parameter categories—Frequency, Amplitude, and Phase—independently. 

Under these bounds, $R = (3^k - 1)/2$ for a category if and only if the selected values in that category are exactly a permutation of `1..k` (each value used once). Therefore, a valid selection uses each Frequency index, each Amplitude index, and each Phase index exactly once.

Determine if such a stable core can be formed by selecting exactly **k** modules from the catalog.

## Input

The first line provides two integers, **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k³). Here, **k** represents the number of modules required, and **t** is the total number of available modules in the catalog.
The next **t** lines each contain three integers **x**, **y**, and **z** (1 ≤ x, y, z ≤ k), representing the Frequency, Amplitude, and Phase parameters of a module in the catalog. Each triple coordinate is an integer from 1 to k. Every module listed in the input is distinct. You may choose only among these listed modules, and each module from the catalog may be selected at most once.

## Output

If a perfectly stable core can be formed, output `YES` on the initial line. Following this, output **k** lines each containing three integers `x y z`, specifying the modules used for your core. If several valid selections exist, supplying any one of them is sufficient. The modules may be printed in any sequence.

If it is impossible to find **k** modules satisfying the condition, output `NO`.

## Note

In Example 2, the two available modules are `1 1 1` and `2 1 2`. If both are selected, the Amplitude values are $v_1 = 1$ and $v_2 = 1$. The base-3 signature for Amplitude is $R = 3^{1-1} + 3^{1-1} = 1 + 1 = 2$. However, the required signature for $k=2$ is $(3^2 - 1)/2 = 8/2 = 4$. Because the signature for Amplitude is not 4, they do not form a perfectly stable core. This directly corresponds to the uniqueness failure: both use Amplitude 1, so Amplitude 2 is uncovered. With only 2 modules available, it is impossible to select 2 that satisfy the requirement.
