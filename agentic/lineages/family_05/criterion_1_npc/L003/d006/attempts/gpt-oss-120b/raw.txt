**Solution Explanation**

For the required alloy we have to choose exactly `k` triples  

```
(x , y , z) ,   1 ≤ x , y , z ≤ k
```

from the given list.  
For the three rating categories we denote

* `A` – number of different `x` values among the chosen triples,
* `B` – number of different `y` values,
* `C` – number of different `z` values.

The alloy is *perfectly balanced* iff  

```
A · B · C = k³ .
```

--------------------------------------------------------------------

#### 1.   What must `A , B , C` be ?

`A , B , C` are at most `k` and they are divisors of `k` because we have
exactly `k` triples, therefore each value can appear an integer number of
times.

```
k = A·(k/A) = B·(k/B) = C·(k/C)          (k/A , k/B , k/C are integers)
```

Multiplying the three equalities

```
k³ = A·B·C · (k/A)·(k/B)·(k/C) .
```

The left hand side must be `k³` and the right hand side contains the factor
`A·B·C`.  Hence we need  

```
(k/A)·(k/B)·(k/C) = 1 .
```

All three factors are positive integers, therefore each of them equals `1`
and consequently  

```
A = B = C = k .
```

So in a valid alloy **every value `1 … k` appears exactly once in each
coordinate**.  
The `k` triples must be a *Latin transversal* :

```
(i , π(i) , σ(i))   for i = 1 … k
```

where `π` and `σ` are permutations of `{1 … k}`.

--------------------------------------------------------------------

#### 2.   Reformulation as an Exact Cover problem  

We have `3·k` constraints

* “value `i` is used as hardness”   (i = 1 … k)
* “value j is used as malleability” (j = 1 … k)
* “value l is used as conductivity” (l = 1 … k)

A triple `(x , y , z)` satisfies exactly three of them:
hardness‑column `x`, malleability‑column `y`, conductivity‑column `z`.

We have to pick `k` triples so that **each of the `3k` columns is covered
exactly once** – the classic *exact cover* problem.
`k ≤ 22`, therefore the number of columns is at most `66`,
the number of rows (available triples) is at most `k³ ≤ 10648`.
This size is easily handled by Donald Knuth’s DLX (Dancing Links)
algorithm.

--------------------------------------------------------------------

#### 3.   DLX algorithm  

* each column stores the number of rows that still contain it (for the
  heuristic “choose the column with the smallest size”);
* rows are linked doubly in four directions (left, right, up, down);
* recursive search:
  * if no column remains → all constraints satisfied → solution found;
  * pick column `c` with minimal size;
  * for every row `r` that contains `c`
        * cover all columns of `r`;
        * recurse;
        * if recursion fails, uncover the columns again and try next row.

The recursion depth never exceeds `k ≤ 22`.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
In any perfectly balanced alloy the diversities of the three coordinates
are all equal to `k`.

**Proof.** Shown in Section&nbsp;1. ∎



##### Lemma 2  
A set of `k` triples satisfies the condition of Lemma&nbsp;1
iff it is an exact cover of the `3k` columns described in Section&nbsp;2.

**Proof.**  
*If* the set is a perfect alloy, each value `1…k` occurs exactly once in
each coordinate, therefore each column is covered exactly once.  
*Conversely*, if an exact cover is given, every column is covered once,
hence each value appears exactly once in each coordinate, giving diversities
`k`. ∎



##### Lemma 3  
DLX returns a collection of rows exactly when an exact cover exists.

**Proof.**  
DLX is a depth‑first search that explores **all** possible subsets of rows,
pruning only when a column cannot be satisfied (i.e. its size becomes zero).
If an exact cover exists, the recursive choices can follow that cover and
reach the empty‑column base case, returning it.
If no exact cover exists, every branch eventually hits a dead column and
backtracks, finally exhausting the search space and reporting failure. ∎



##### Lemma 4  
If the program outputs “YES” and the listed triples, they form a perfectly
balanced alloy.

**Proof.**  
The program outputs the rows returned by DLX.
By Lemma&nbsp;3 they constitute an exact cover.
By Lemma&nbsp;2 an exact cover yields diversities `k` in all three
coordinates, i.e. the product is `k³`. ∎



##### Lemma 5  
If a perfectly balanced alloy exists, the program outputs “YES”.

**Proof.**  
From the alloy we obtain an exact cover (Lemma&nbsp;2).
DLX will find it (Lemma&nbsp;3) and the program prints it. ∎



##### Theorem  
The program prints “YES” followed by a valid selection of `k` components
iff such a selection exists; otherwise it prints “NO”.

**Proof.**  
*If* the program prints “YES”, Lemma&nbsp;4 guarantees validity.  
*If* a valid selection exists, Lemma&nbsp;5 guarantees the program finds
one and prints “YES”.  
If neither case holds, the program reaches the end of the search and
prints “NO”. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*`C = 3k ≤ 66` columns, `R ≤ k³ ≤ 10648` rows.*

* Building the DLX structure: `O(R·3)` time, `O(R·3 + C)` memory.
* Search: each recursive level removes at least one column,
  depth ≤ `k`.  
  In the worst case the algorithm may examine many subsets, but with the
  heuristic “choose the smallest column” and the very small `k` the
  practical running time is far below the limit.
* Overall time fits easily into the 5 s limit; memory usage is below
  a few megabytes.

#### 6.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    triples = []
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        triples.append((x, y, z))

    # columns: 0..k-1 hardness, k..2k-1 malleability, 2k..3k-1 conductivity
    ncol = 3 * k

    # DLX structures
    size = ncol + 1                     # column headers 0..ncol-1, root=ncol
    up = list(range(size))
    down = list(range(size))
    left = list(range(size))
    right = list(range(size))
    col = [i for i in range(size)]      # column of each node (header points to itself)
    cnt = [0] * ncol                    # number of nodes in each column
    row_of_node = []                    # for solution reconstruction

    # link column headers horizontally (circular)
    for i in range(ncol):
        left[i] = i - 1 if i else ncol
        right[i] = i + 1 if i + 1 < ncol else ncol
    left[ncol] = ncol - 1
    right[ncol] = 0

    node_id = ncol  # next free node index

    # add a row for each triple
    for idx, (x, y, z) in enumerate(triples):
        cols = [x, k + y, 2 * k + z]
        first = None
        for c in cols:
            node = node_id
            node_id += 1
            # vertical links
            up[node] = up[c]
            down[node] = c
            down[up[c]] = node
            up[c] = node
            col.append(c)
            cnt[c] += 1
            row_of_node.append(idx)   # store original triple index
            # horizontal links within the row
            if first is None:
                left[node] = right[node] = node
                first = node
            else:
                # insert to the left of first
                left[node] = left[first]
                right[node] = first
                right[left[first]] = node
                left[first] = node

    solution_rows = []

    def cover(c):
        # remove column header
        right[left[c]] = right[c]
        left[right[c]] = left[c]
        # remove rows
        i = down[c]
        while i != c:
            j = right[i]
            while j != i:
                down[up[j]] = down[j]
                up[down[j]] = up[j]
                cnt[col[j]] -= 1
                j = right[j]
            i = down[i]

    def uncover(c):
        i = up[c]
        while i != c:
            j = left[i]
            while j != i:
                cnt[col[j]] += 1
                down[up[j]] = j
                up[down[j]] = j
                j = left[j]
            i = up[i]
        right[left[c]] = c
        left[right[c]] = c

    def search():
        if right[ncol] == ncol:          # all columns covered
            return True
        # choose column with minimal cnt
        c = right[ncol]
        min_cnt = cnt[c]
        cc = c
        while cc != ncol:
            if cnt[cc] < min_cnt:
                min_cnt = cnt[cc]
                c = cc
                if min_cnt == 0:
                    break
            cc = right[cc]
        if min_cnt == 0:
            return False
        cover(c)
        r = down[c]
        while r != c:
            solution_rows.append(row_of_node[r])
            j = right[r]
            while j != r:
                cover(col[j])
                j = right[j]
            if search():
                return True
            # backtrack
            j = left[r]
            while j != r:
                uncover(col[j])
                j = left[j]
            solution_rows.pop()
            r = down[r]
        uncover(c)
        return False

    if search():
        out = ["YES"]
        for idx in solution_rows:
            x, y, z = triples[idx]
            out.append(f"{x+1} {y+1} {z+1}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
