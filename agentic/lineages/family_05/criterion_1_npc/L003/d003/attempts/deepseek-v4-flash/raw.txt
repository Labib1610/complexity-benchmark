We need to find a perfect matching in a 3-partite 3-uniform hypergraph, where each part has exactly \(k\) nodes, and we want to cover all \(3k\) nodes with \(k\) hyperedges.  

Since \(k \le 22\), we can solve it with DP over bitmasks — specifically, we can represent the set of used **left pillars** and **right pillars** as a bitmask, and iterate keystones.

A standard approach:

- Let there be a DP entry `dp[maskL][maskR]` = possible or not.  
- That’s \(2^k \times 2^k\) states, which is too big (\(~ 2^{44}\)).  
- But since we always pick \(k\) hyperedges with distinct lefts and rights, we can fix the order of picking — e.g., pick left pillar 0, then 1, etc.  
- That reduces the state to only the mask of used right pillars and keystones as we go left by left.

Algorithm:

- Iterate over left pillars in a fixed order (say from 0 to k-1). At each step, we choose a triplet for that left pillar.  
- The state is `(i, maskR, maskZ)` — we’ve processed left pillars `0..i-1`. Since we process lefts sequentially, `i` is just the number of used lefts, and the used lefts are exactly `0..i-1`.  
- So we store `dp[maskR][maskZ] = True/False`.

We can do a BFS/DP expanding left by left:

```
dp = { (0,0): True }
for left in range(k):
    newdp = {}
    for (maskR, maskZ) in dp:
        for (right, keystone) in edges_for_left[left]:
            if not (maskR>>right)&1 and not (maskZ>>keystone)&1:
                newdp[maskR | (1<<right), maskZ | (1<<keystone)] = True
    dp = newdp
```

At the end, if `dp` contains `( (1<<k)-1, (1<<k)-1 )`, then YES, with reconstruction via backtracking.

We retain parent info for reconstruction.

Complexity:  
- For each left, we iterate over its possible edges (≤ k²).  
- Number of states at step i is at most \( \binom{k}{i}^2 \), which for k=22, i=11 is ~ (705432)^2 huge. But in practice it’s manageable? Actually worst-case is astronomical.  
- Need a better method.

Since k ≤ 22, we can instead do exact cover using **recursive backtracking with bitmask for right and keystone**, choosing the left with fewest remaining options (like Algorithm X). This will be fast in practice for the given limits.

Let’s implement Algorithm X / DLX-style backtracking but with bitmasks.

We’ll store for each left pillar the list of (right, keystone) pairs.  
We'll keep `maskR`, `maskZ`, and for each left either used or not.

We recursively pick the left with smallest number of available choices (that is not yet used). We try each choice that doesn't conflict with used maskslays.

If we assign all k lefts, we have a solution.

Memory is fine, speed should be O(k! × something) but with pruning it’s okay for k ≤ 22.

Let’s code.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    k = int(next(it))
    t = int(next(it))
    
    # edges_by_left[x] = list of (y, z)
    edges_by_left = [[] for _ in range(k)]
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        edges_by_left[x].append((y, z))
    
    # Sort edges for each left for deterministic behavior
    for i in range(k):
        edges_by_left[i].sort()
    
    full_mask = (1 << k) - 1
    assignment = [None] * k
    
    # We'll do backtracking with bitmasks for right and keystone
    # and a mask for used lefts
    
    used_left_mask = 0
    used_right_mask = 0
    used_keystone_mask = 0
    
    # We'll store partial assignment
    
    # To speed up, we can reorder lefts by number of edges
    # But we need to map back
    
    # Compute number of options for each left given current masks
    def count_options(left):
        cnt = 0
        for y, z in edges_by_left[left]:
            if not (used_right_mask >> y) & 1 and not (used_keystone_mask >> z) & 1:
                cnt += 1
        return cnt
    
    sys.setrecursionlimit(1000000)
    
    def backtrack(step):
        nonlocal used_left_mask, used_right_mask, used_keystone_mask
        if step == k:
            return True
        # Find left with fewest options among unused
        best_left = -1
        best_cnt = 10**9
        for left in range(k):
            if not (used_left_mask >> left) & 1:
                cnt = count_options(left)
                if cnt == 0:
                    return False
                if cnt < best_cnt:
                    best_cnt = cnt
                    best_left = left
        if best_left == -1:
            return False
        # Try each option for best_left
        for y, z in edges_by_left[best_left]:
            if (used_right_mask >> y) & 1:
                continue
            if (used_keystone_mask >> z) & 1:
                continue
            # Place
            used_left_mask |= (1 << best_left)
            used_right_mask |= (1 << y)
            used_keystone_mask |= (1 << z)
            assignment[best_left] = (best_left, y, z)
            if backtrack(step + 1):
                return True
            # Undo
            used_left_mask ^= (1 << best_left)
            used_right_mask ^= (1 << y)
            used_keystone_mask ^= (1 << z)
            assignment[best_left] = None
        return False
    
    if backtrack(0):
        print("YES")
        for x, y, z in assignment:
            print(x+1, y+1, z+1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
