**Solution Explanation**

For every module we have three numbers  

* frequency `x`  ( 1 … k )  
* amplitude `y`  ( 1 … k )  
* phase `z`      ( 1 … k )

We have to choose exactly `k` modules such that

* all chosen frequencies are different,
* all chosen amplitudes are different,
* all chosen phases are different.

So we have to cover the set  

```
F = {F1 … Fk}          – frequencies
A = {A1 … Ak}          – amplitudes
P = {P1 … Ak}          – phases
```

with `k` triples, each triple covering **one** element of `F`, **one** of `A`
and **one** of `P`.  
That is exactly the *exact cover* problem with `3·k ≤ 66` columns
and at most `k³ ≤ 10648` rows.

The classical algorithm for exact cover is **Algorithm X** (Donald Knuth)
implemented with *dancing links* (DLX).  
Because the number of columns is tiny we can implement a much simpler
version using bit‑masks and ordinary Python lists – it is fast enough for
the given limits.

--------------------------------------------------------------------

#### 1.   Data representation

* column index  

```
0 … k-1           – frequencies  (F1 … Fk)
k … 2k-1          – amplitudes   (A1 … Ak)
2k … 3k-1         – phases       (P1 … Pk)
```

* a row (a module) → integer mask with exactly three bits set  

```
mask = (1 << (x-1)) | (1 << (k + y-1)) | (1 << (2k + z-1))
```

* for every column we store the list of row indices that contain this
  column – `col_rows[col]`.

--------------------------------------------------------------------

#### 2.   Recursive search (Algorithm X)

```
search(chosen_rows, used_mask):
    if used_mask has all 3k bits set:   # all columns covered
            solution found
    choose a column c that is still uncovered and has the smallest
            number of rows (heuristic)
    for each row r in col_rows[c]:
            if row r does not intersect used_mask:
                    add r to chosen_rows
                    search(chosen_rows, used_mask | row_mask[r])
                    if solution found → return
                    remove r from chosen_rows
```

The heuristic (column with fewest possible rows) keeps the branching factor
tiny.  
Maximum recursion depth is `k ≤ 22`.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of modules
iff such a set exists.

---

##### Lemma 1  
During the search `used_mask` always contains exactly the columns covered
by the rows stored in `chosen_rows`.

**Proof.**  
Initially both are empty.  
When a row `r` is added, we set `used_mask ← used_mask ∪ row_mask[r]`,
i.e. we add precisely the three columns of `r`.  
When backtracking we remove the same row and also remove its bits
(implicitly, because we restore the previous `used_mask`). ∎



##### Lemma 2  
A recursive call `search(chosen_rows, used_mask)` is reachable
iff the rows in `chosen_rows` are pairwise column‑disjoint
(i.e. no two rows share a frequency, an amplitude or a phase).

**Proof.**  
The only way a row is added is after the test  
`row_mask[r] & used_mask == 0`.  
By Lemma&nbsp;1 `used_mask` contains exactly the columns of the already
chosen rows, therefore the new row shares no column with them.
Conversely, if a set of rows is pairwise disjoint, the algorithm can add
them one after another, never failing the test. ∎



##### Lemma 3  
If the algorithm reaches a state with `used_mask` containing all `3k`
bits, the rows in `chosen_rows` form a valid selection of `k` modules.

**Proof.**  
All `3k` columns are covered, each column exactly once because a column is
never covered twice (Lemma&nbsp;2).  
Thus every frequency `1…k`, every amplitude `1…k` and every phase `1…k`
appears exactly once among the selected rows, i.e. the three required
conditions hold. The number of rows is `k` because each row contributes
three new columns. ∎



##### Lemma 4  
If a valid selection of `k` modules exists, the algorithm will eventually
find it.

**Proof.**  
Take any valid selection `S`.  
Consider the recursion tree: at each level the algorithm chooses a still
uncovered column `c`. Because `S` covers every column, `c` is covered by
exactly one row `r∈S`. That row is present in `col_rows[c]`, therefore the
branch that picks `r` is explored. By Lemma&nbsp;2 the algorithm can follow
the whole set `S` without conflict, reaching the leaf where all columns are
covered. Hence the search will find a solution. ∎



##### Lemma 5  
If the algorithm finishes without finding a solution, no valid selection
exists.

**Proof.**  
Assume a valid selection existed. By Lemma&nbsp;4 the algorithm would have
found it, contradiction. ∎



##### Theorem  
The program outputs  

* `YES` and a list of `k` modules satisfying the three uniqueness
  conditions **iff** such a list exists,
* otherwise outputs `NO`.

**Proof.**  
*If* the program prints `YES`, it did so after reaching a state with all
columns covered; by Lemma&nbsp;3 the printed rows are a correct selection.  

*Only‑if*: if a correct selection exists, Lemma&nbsp;4 guarantees the
search finds one, therefore the program prints `YES`.  
If the search exhausts all possibilities, by Lemma&nbsp;5 no correct
selection exists and the program prints `NO`. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*`C = 3k ≤ 66` columns, `R = t ≤ k³ ≤ 10648` rows.*

* building masks and column lists: `O(R)`
* each recursive level tries at most the size of the smallest column,
  which is ≤ `R`.  
  Depth ≤ `k ≤ 22`.  
  In the worst theoretical case the algorithm could explore many nodes,
  but with the strong heuristic and the tiny column count the practical
  running time is far below the limit (well under a second for the
  maximal input).

Memory consumption:

* masks: `R` integers → ≤ 10648 × 8 B ≈ 85 KB
* column lists: total length `3R` → ≤ 320 KB
* recursion stack: ≤ 22 frames.

Overall far below the 256 MB limit.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    C = 3 * k                     # number of columns
    row_masks = []                # mask for each row
    rows = []                     # original triples for output
    col_rows = [[] for _ in range(C)]

    for idx in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        mask = (1 << x) | (1 << (k + y)) | (1 << (2 * k + z))
        row_masks.append(mask)
        rows.append((x + 1, y + 1, z + 1))
        # store index in each column list
        col_rows[x].append(idx)
        col_rows[k + y].append(idx)
        col_rows[2 * k + z].append(idx)

    full_mask = (1 << C) - 1
    solution = []
    found = False

    # pre‑compute column sizes for heuristic
    col_sizes = [len(col_rows[i]) for i in range(C)]

    def choose_column(used_mask: int) -> int:
        """return an uncovered column with minimal remaining rows"""
        best = -1
        best_sz = 10**9
        m = ~used_mask & full_mask
        while m:
            c = (m & -m).bit_length() - 1
            sz = col_sizes[c]
            if sz < best_sz:
                best_sz = sz
                best = c
                if sz == 0:
                    break
            m &= m - 1
        return best

    def dfs(used_mask: int):
        nonlocal found
        if found:
            return
        if used_mask == full_mask:
            # all columns covered
            found = True
            return
        c = choose_column(used_mask)
        for r in col_rows[c]:
            rm = row_masks[r]
            if rm & used_mask:
                continue
            solution.append(r)
            dfs(used_mask | rm)
            if found:
                return
            solution.pop()

    dfs(0)

    out = []
    if found:
        out.append("YES")
        for idx in solution:
            out.append(f"{rows[idx][0]} {rows[idx][1]} {rows[idx][2]}")
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
