We need to select exactly **k** triples `(x, y, z)` such that all `x` are distinct, all `y` are distinct, and all `z` are distinct.  
This is a 3D matching problem, but with `k ≤ 22`, we can solve it using **bitmask DP with backtracking**.

We can model it as:  
- We have `k` foundations, `k` shafts, `k` capitals.  
- We need to match each foundation to a unique shaft and capital.

We can use a **recursive backtracking** approach with memoization on the set of used shafts and capitals.

---

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    triples = []
    for _ in range(t):
        x, y, z = map(int, input().split())
        triples.append((x-1, y-1, z-1))  # 0-index

    # Group by foundation
    by_foundation = [[] for _ in range(k)]
    for x, y, z in triples:
        by_foundation[x].append((y, z))

    # We'll try to assign each foundation a unique (shaft, capital)
    used_shaft = 0
    used_cap = 0
    assignment = [None] * k

    # Memoization: (foundation_index, used_shaft_mask, used_cap_mask) -> bool
    memo = {}

    def dfs(i, used_shaft, used_cap):
        if i == k:
            return True
        key = (i, used_shaft, used_cap)
        if key in memo:
            return memo[key]
        for y, z in by_foundation[i]:
            if not (used_shaft & (1 << y)) and not (used_cap & (1 << z)):
                assignment[i] = (i, y, z)
                if dfs(i+1, used_shaft | (1 << y), used_cap | (1 << z)):
                    memo[key] = True
                    return True
        memo[key] = False
        return False

    if dfs(0, 0, 0):
        print("YES")
        for x, y, z in assignment:
            print(x+1, y+1, z+1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
