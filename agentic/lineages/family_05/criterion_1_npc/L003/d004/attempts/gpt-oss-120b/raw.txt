**Solution Explanation**

For every identifier `1 … k` we have three kinds of objects  

* foundation block `F_i`
* column shaft `C_i`
* capital `P_i`

A catalogue entry `(x , y , z)` means that the three objects  
`F_x , C_y , P_z` can be assembled into one monument.

We have to choose exactly `k` catalogue entries such that

* each foundation block is used at most once,
* each column shaft is used at most once,
* each capital is used at most once,

and because we need `k` monuments and there are only `k` objects of each
type, every object must be used **exactly once**.

So we have an *exact cover* problem:

* **columns** – the `3·k` objects (`F_1 … F_k , C_1 … C_k , P_1 … P_k`)
* **rows**   – the catalogue triples, each row covers the three columns
  belonging to its three objects.

We have to pick `k` rows that cover every column exactly once.

`k ≤ 22`, therefore the number of columns is at most `66`.
The number of rows `t` is at most `k³ ≤ 10648`.  
Exact cover with at most a few dozen columns and a few ten‑thousands rows
is easily solved by Knuth’s **Algorithm X** (DLX – dancing links).

The algorithm works recursively:

```
search():
    if no column left → solution found
    choose column with the smallest number of rows (heuristic)
    for each row r that contains this column:
        add r to the partial solution
        cover all columns of r (remove them and all rows that intersect)
        if search() succeeds → propagate success
        uncover the columns again (backtrack)
    return failure
```

Because the branching factor is limited by the smallest column size,
the search finishes very quickly for the given limits.

The implementation stores the sparse matrix with four integer arrays
(`L,R,U,D` links) and an array `S[c]` = number of rows still containing column `c`.
Rows are numbered `0 … t‑1`; when a row is chosen we remember its index to
output the corresponding triple later.

If a solution is found we output `YES` and the `k` triples,
otherwise `NO`.

The whole program fits easily into the limits.



**Correctness Proof**

We prove that the algorithm outputs `YES` with a valid set of `k`
triples iff such a set exists.

---

*Lemma 1*  
During the execution of `search` the set of uncovered columns is exactly the
set of objects that are not used by the rows already placed in the partial
solution.

*Proof.*  
Initially all columns are uncovered, no object is used – true.
When a row `r` is added, `cover` removes every column that `r` contains and
also removes every other row that contains any of those columns.
Thus those columns become “used” and cannot be covered again.
When backtracking, `uncover` restores precisely the columns and rows removed
by the corresponding `cover`. ∎



*Lemma 2*  
If `search` reaches the state “no column left”, the rows stored in the
partial solution form a set of `k` triples that uses each object exactly once.

*Proof.*  
“No column left” means every of the `3k` columns is covered.
By Lemma&nbsp;1 each covered column corresponds to an object used by exactly one
chosen row, because a column is removed only together with the row that first
covers it and never re‑appears while uncovered columns exist.
Since there are `3k` columns and each chosen row covers three distinct columns,
the number of chosen rows is `k`. ∎



*Lemma 3*  
If a set `S` of `k` disjoint triples exists, `search` will eventually find a
solution.

*Proof.*  
Consider the recursion tree of `search`.  
At each step a column `c` is selected.
Because `S` is a perfect cover, some row `r∈S` contains `c`.
When the algorithm iterates over the rows of `c`, it will try `r` at some
iteration.  
Choosing `r` removes exactly the columns covered by `r`; the remaining
columns are still perfectly coverable by `S\\{r}`.
Thus the recursive call after picking `r` has a solution.
Induction on the number of remaining columns shows that the recursion can
follow the rows of `S` all the way down to the empty set, where it succeeds.
∎



*Lemma 4*  
If `search` reports failure, no set of `k` disjoint triples exists.

*Proof.*  
Assume contrary that a perfect cover `S` exists.
By Lemma&nbsp;3 the recursion would have a branch that always picks a row from
`S` and therefore reaches the empty‑column state, which would be reported as
success. Since the algorithm reports failure, such a branch cannot exist,
hence `S` does not exist. ∎



*Theorem*  
The program prints `YES` followed by `k` triples that are pairwise disjoint
iff such a collection exists; otherwise it prints `NO`.

*Proof.*  

*If* the program prints `YES`, it did so after `search` terminated with
“no column left”. By Lemma&nbsp;2 the printed triples are a perfect cover,
hence a valid solution.

*Only‑if* a valid solution exists, Lemma&nbsp;3 guarantees that `search`
finds one, therefore the program prints `YES`.  
If no solution exists, Lemma&nbsp;4 shows that `search` cannot succeed,
so the program prints `NO`. ∎



**Complexity Analysis**

Let `C = 3k ≤ 66` be the number of columns and `R = t ≤ k³ ≤ 10648` the number
of rows.

*Construction* of the DLX structure: `O(C + R·3)` time and memory.

*Search* – each recursive level covers at least one new column,
so depth ≤ `k`. The branching factor is bounded by the smallest column size,
which in the worst case can be `R`, but the exponential part is limited to
`k ≤ 22`. In practice the heuristic makes the search very fast.
The theoretical worst‑case time is `O( R·k )` for each visited node,
and the number of nodes is bounded by the number of exact covers,
which is at most `k!` (far below the limits for `k ≤ 22`).

Memory consumption: the DLX arrays store at most `C + 3R` nodes,
i.e. ≤ `3·10648 + 66 ≈ 32000` integers → well under the 256 MB limit.



**Reference Implementation (Python 3)**

```python
import sys

sys.setrecursionlimit(1000000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        triples.append((x, y, z))

    # columns: 0..k-1 foundations, k..2k-1 columns, 2k..3k-1 capitals
    C = 3 * k
    # DLX structures
    max_nodes = C + 3 * t + 5
    L = [0] * max_nodes
    R = [0] * max_nodes
    U = [0] * max_nodes
    D = [0] * max_nodes
    Ccol = [0] * max_nodes   # column of a node
    S = [0] * C               # size of each column
    row_id = [0] * max_nodes  # which input row a node belongs to

    # header node 0, column headers 1..C
    header = 0
    for i in range(C + 1):
        L[i] = i - 1
        R[i] = i + 1
        U[i] = D[i] = i
    R[C] = header
    L[header] = C

    node_cnt = C + 1  # next free index

    # add rows
    for idx, (x, y, z) in enumerate(triples):
        cols = [x, k + y, 2 * k + z]
        first = -1
        for col in cols:
            col_header = col + 1          # shift by 1 because header is 0
            node = node_cnt
            node_cnt += 1
            Ccol[node] = col_header
            row_id[node] = idx

            # vertical links
            U[node] = U[col_header]
            D[node] = col_header
            D[U[col_header]] = node
            U[col_header] = node
            S[col] += 1

            # horizontal links
            if first == -1:
                first = node
                L[node] = R[node] = node
            else:
                L[node] = L[first]
                R[node] = first
                R[L[first]] = node
                L[first] = node

    solution_rows = []

    def cover(col):
        # remove column header
        R[L[col]] = R[col]
        L[R[col]] = L[col]
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[Ccol[j] - 1] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[Ccol[j] - 1] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        R[L[col]] = col
        L[R[col]] = col

    def choose_column():
        # heuristic: column with minimal S
        c = R[header]
        min_s = 10**9
        chosen = -1
        while c != header:
            col_idx = c - 1
            if S[col_idx] < min_s:
                min_s = S[col_idx]
                chosen = c
                if min_s == 0:
                    break
            c = R[c]
        return chosen

    def search():
        if R[header] == header:
            return True
        col = choose_column()
        if col == -1 or S[col - 1] == 0:
            return False
        cover(col)
        r = D[col]
        while r != col:
            solution_rows.append(row_id[r])
            j = R[r]
            while j != r:
                cover(Ccol[j])
                j = R[j]
            if search():
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(Ccol[j])
                j = L[j]
            solution_rows.pop()
            r = D[r]
        uncover(col)
        return False

    if search():
        out = ["YES"]
        for idx in solution_rows:
            x, y, z = triples[idx]
            out.append(f"{x+1} {y+1} {z+1}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
