# Problem A — Assembly Line Orchestration

Time limit: 5 s   Memory limit: 256 MB

## Description

A manufacturing facility needs to set up temporary assembly lines. An assembly line requires exactly three components: a chassis handler, a precision welder, and a testing rig.

The facility owns a number of components in each of these three categories. Specifically, there are **k** chassis handlers, **k** precision welders, and **k** testing rigs. Within each category, the machines are assigned ID numbers from 1 to **k**. The physical floor space can accommodate at most 22 machines per category, and there is always at least 1 machine of each type available.

Because of differing calibration standards, machines cannot be grouped arbitrarily. You are provided with a log of **t** approved combinations. Each approved combination specifies exactly one chassis handler, one precision welder, and one testing rig that are confirmed to work perfectly together. The number of approved combinations **t** can range from a minimum of 0 up to the maximum possible number of unique combinations.

Your task is to completely deploy the facility's inventory by forming **k** functional assembly lines. You may only use combinations from the approved log. Furthermore, each machine can only be used once: no two assembly lines may share the same chassis handler, nor the same precision welder, nor the same testing rig. Determine if such a deployment is possible, and if so, output the combinations to be activated.

## Input

The first line contains two integers **k** and **t**. The integer **k** represents the inventory per category (between 1 and the floor capacity of 22, inclusive). The integer **t** represents the number of approved combinations (between 0 and the maximum possible **k**·**k**·**k**, inclusive).

Then, **t** lines follow. Each line consists of three integers **x**, **y**, and **z** (between 1 and **k**, inclusive), indicating that chassis handler **x**, precision welder **y**, and testing rig **z** form an approved combination. All combinations in the log are distinct.

## Output

If all equipment can be successfully deployed into **k** assembly lines, print `YES` on the first line. On the following **k** lines, print three integers `x y z` per line, representing the equipment used in each assembly line. Any valid deployment will be accepted. You may print the chosen assembly lines in any order.

If there is no way to deploy all equipment into **k** assembly lines under these rules, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both approved combinations require precision welder 1. This means precision welder 2 cannot be utilized, making it impossible to form 2 valid assembly lines without sharing a precision welder.

<RATIONALE>
Changed the description of the exact cover constraint. Instead of explicitly stating that every item must be incorporated into exactly one track, the problem now requires forming `k` assembly lines such that no two lines share any component of the same type. This mathematically forces a perfect 3D matching via the pigeonhole principle but avoids the standard "exact cover" wording that models use as a pattern-matching shortcut. Bounds were also integrated into the prose as required by the strategy, explicitly retaining the `0` to satisfy the validation gate.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to choose `k` triplets from a given list such that no two share an element in any of the three positions, given that there are exactly `k` elements in each position, is logically equivalent to finding a perfect 3D matching, ensuring identical outputs for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, which is NP-complete, as it asks to find `k` non-overlapping triplets from a given set of allowed triplets.
</PRESERVED_CLASS>

Models might fail to deduce that "no two lines share" combined with "form k lines" implies that every component is used exactly once, though this is a straightforward application of the pigeonhole principle.
