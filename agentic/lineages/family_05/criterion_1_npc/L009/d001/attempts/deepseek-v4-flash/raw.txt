We need to select exactly **k** triples from the allowed list such that each of the three coordinates covers all values from 1 to k.  

This is essentially a 3-dimensional matching problem with size k ≤ 22, which is small enough for a backtracking approach with pruning.  

We can model it as:  
- We need to pick k triples.  
- Each operator, apparatus, and shift must appear at least once.  
- Since we pick exactly k triples and there are k distinct values in each dimension, each value must appear exactly once in its dimension.  

So we can treat it as finding a perfect matching in a 3-partite hypergraph.  

We can use backtracking with bitmasks to track used operators, apparatuses, and shifts.  

Here’s the implementation:  

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    triples = []
    for _ in range(t):
        x, y, z = map(int, input().split())
        triples.append((x-1, y-1, z-1))
    
    # Group triples by operator for faster lookup
    by_operator = [[] for _ in range(k)]
    for idx, (x, y, z) in enumerate(triples):
        by_operator[x].append((y, z, idx))
    
    used_op = 0
    used_app = 0
    used_shift = 0
    chosen = []
    
    # Backtracking
    def dfs(op):
        nonlocal used_op, used_app, used_shift
        if op == k:
            return True
        for y, z, idx in by_operator[op]:
            if not (used_app & (1 << y)) and not (used_shift & (1 << z)):
                used_app |= (1 << y)
                used_shift |= (1 << z)
                chosen.append(triples[idx])
                if dfs(op + 1):
                    return True
                chosen.pop()
                used_app &= ~(1 << y)
                used_shift &= ~(1 << z)
        return False
    
    if dfs(0):
        print("YES")
        for x, y, z in chosen:
            print(x+1, y+1, z+1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
