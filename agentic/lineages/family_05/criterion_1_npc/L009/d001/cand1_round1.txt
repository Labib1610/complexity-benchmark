<STATEMENT>
# Problem A — Crew Assembly

Time limit: 5 s   Memory limit: 256 MB

## Description

You need to finalize a project schedule for $k$ specialists. For each specialist (numbered 1 to $k$), you must assign them a machine (numbered 1 to $k$) and a time slot (numbered 1 to $k$). 

You are provided with a list of approved operating parameters. Each parameter is given as a triplet $(x, y, z)$ indicating that specialist $x$ is authorized to use machine $y$ during time slot $z$.

A finalized schedule must select exactly one approved parameter triplet for each specialist. Furthermore, the schedule must be conflict-free:
- A machine can be assigned to at most one specialist.
- A time slot can be assigned to at most one specialist.

Determine if a conflict-free schedule is possible. If so, report the chosen parameters.

## Input

The first line of input provides two integers: the number of specialists $k$ and the number of approved parameters $t$. The workforce size $k$ is at least a single specialist, and will not exceed the facility's maximum capacity of 22 specialists. The number of parameters $t$ can be any non-negative integer up to the theoretical maximum where every one of the $k$ specialists is authorized for every one of the $k$ machines across all $k$ time slots.

The following $t$ lines each describe one approved parameter as three integers $x$, $y$, and $z$. These identifiers are positive integers and will never exceed the workforce size $k$. No parameter triplet is listed more than once.

## Output

If a conflict-free schedule exists, print `YES` on the first line, then print $k$ lines, each containing the three members $x$ $y$ $z$ of one chosen parameter triplet. Any schedule following the conflict-free rules is accepted; the chosen parameters may be printed in any order.

If no such schedule exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both approved parameters assign a specialist to machine 1. Since a machine can be assigned to at most one specialist, we cannot schedule both specialists, making a complete schedule impossible.
</STATEMENT>
<RATIONALE>
Changed the framing from a symmetric selection of $k$ combinations to assigning parameters to each of the $k$ specialists. This hides the 3-dimensional exact cover structure by presenting one dimension as an assignment requirement and the other two as packing constraints, forcing the model to deduce the structural equivalence rather than relying on standard exact-cover templates. The numeric bounds were also replaced with physical limits according to the strategy.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to assign exactly one triplet per specialist while using each machine and time slot at most once is mathematically identical to selecting exactly $k$ triplets with no shared elements.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, simply described as a constrained assignment problem rather than a symmetric subset selection.
</PRESERVED_CLASS>
