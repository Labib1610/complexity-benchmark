**Solution Explanation**

For every allowed path we have a triple  

```
(x , y , z)      1 ≤ x , y , z ≤ k
```

`x` is an input port, `y` an encryptor, `z` an output channel.
We have to choose exactly `k` triples such that each number `1 … k`
appears **once** as an input, once as an encryptor and once as an output.
In other words we have to select `k` rows of a 0‑1 matrix

```
columns :  k input‑columns   (I1 … Ik)
           k encryptor‑columns (E1 … Ek)
           k output‑columns   (O1 … Ok)
rows    :  one row for every allowed triple (x,y,z)
           the row has three 1’s – in Ix , Ey , Oz
```

and we need a set of rows that covers every column exactly once.
That is the classic **exact cover** problem.

`k ≤ 22`, therefore the matrix has at most `3·k = 66` columns and at most
`k³ ≤ 10648` rows – tiny for the well‑known *Algorithm X* (Dancing Links).

--------------------------------------------------------------------

#### 1.  Dancing Links (Algorithm X)

* each column knows how many rows are still present (`size`);
* each row is a circular doubly linked list of its nodes;
* the whole structure is a torus of nodes, plus a header node.

Recursive search:

```
search():
    if no column left → all columns covered → solution found
    choose column c with minimal size                (heuristic)
    cover(c)
    for each row r in column c:
        add r to current solution
        for each node j in row r (except the column node):
            cover( column(j) )
        if search() succeeds → propagate success
        for each node j in row r (reverse order):
            uncover( column(j) )
        remove r from current solution
    uncover(c)
    return failure
```

`cover` removes a column and all rows that contain a 1 in this column,
`uncover` restores them – both in *O(number of removed nodes)*.

Because the matrix is tiny the recursion depth never exceeds `k ≤ 22`,
and the total work is far below the limits.

--------------------------------------------------------------------

#### 2.  Building the matrix

* columns are numbered `0 … 3k‑1`
  * `0 … k‑1`          – input ports `I1 … Ik`
  * `k … 2k‑1`         – encryptors `E1 … Ek`
  * `2k … 3k‑1`        – outputs   `O1 … Ok`
* for every allowed triple `(x,y,z)` (1‑based) we create a row that
  contains the three column indices  

```
    (x-1) , (k + y-1) , (2k + z-1)
```

The row also stores the original triple, needed for the output.

--------------------------------------------------------------------

#### 3.  Output

If the search succeeds we have exactly `k` rows in the solution list.
We print

```
YES
x y z          (one line per selected row, any order)
```

Otherwise we print `NO`.

--------------------------------------------------------------------

#### 4.  Correctness Proof  

We prove that the algorithm prints `YES` and a correct configuration
iff such a configuration exists.

---

##### Lemma 1  
The matrix constructed in Section&nbsp;2 has a 1 in column `Ix`
iff the corresponding triple uses input `x`; similarly for encryptors
and outputs.

**Proof.** By construction each row for triple `(x,y,z)` contains exactly
the three columns `x‑1`, `k+y‑1`, `2k+z‑1`, i.e. the columns representing
`Ix`, `Ey`, `Oz`. No other columns are set. ∎



##### Lemma 2  
A set of rows covers every column exactly once **iff** the corresponding
triples use each input, each encryptor and each output exactly once.

**Proof.** By Lemma&nbsp;1 a column is covered by a row exactly when the
triple of that row uses the corresponding element.
Thus “each column covered exactly once” is equivalent to
“each element of each kind appears in exactly one selected triple”. ∎



##### Lemma 3  
Algorithm X returns a set of rows covering all columns exactly once
iff such a set exists.

**Proof.** Algorithm X is a complete backtracking search for exact covers:
*If* a cover exists, the recursion can follow the rows of that cover
(step by step) because covering a column never removes a row that is part
of the cover (it would already have been chosen). Hence the algorithm
will eventually reach the empty matrix and succeed.

*Only if* the algorithm succeeds, it has removed all columns, i.e. the
chosen rows together contain a 1 in every column and no column remains,
so they form an exact cover. ∎



##### Lemma 4  
If the program prints `YES` and the listed triples, they form a valid
full‑capacity configuration.

**Proof.** `YES` is printed only when Algorithm X succeeded, i.e. it
returned a set of rows covering all columns. By Lemma&nbsp;2 the
corresponding triples use each input, encryptor and output exactly once,
which is precisely the definition of a valid configuration. ∎



##### Lemma 5  
If a valid full‑capacity configuration exists, the program prints `YES`
and some configuration.

**Proof.** A valid configuration corresponds (Lemma&nbsp;2) to an exact
cover of the matrix. By Lemma&nbsp;3 Algorithm X finds such a cover,
the program detects success and prints `YES` together with the triples
of the found rows. ∎



##### Theorem  
The program outputs `YES` and a correct set of `k` triples
iff a full‑capacity configuration of size `k` exists; otherwise it outputs
`NO`.

**Proof.** Directly from Lemma&nbsp;4 (soundness) and Lemma&nbsp;5
(completeness). ∎



--------------------------------------------------------------------

#### 5.  Complexity Analysis  

*`C = 3k ≤ 66` columns, `R ≤ k³ ≤ 10648` rows.*

Construction: `O(R)`.

During the search each node (a 1 in the matrix) is removed and restored
at most once per level, so the total work is `O(number of nodes)`  
`= O(3R) = O(k³)`.

With `k ≤ 22` this is far below the 5 seconds limit; memory consumption
is `O(C + R + 3R) = O(k³)` ≤ a few MB.

--------------------------------------------------------------------

#### 6.  Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    # column indices
    # 0..k-1          inputs
    # k..2k-1         encryptors
    # 2k..3k-1        outputs
    ncol = 3 * k

    rows = []          # each element: (cols list, original triple)
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        cols = [x, k + y, 2 * k + z]
        rows.append((cols, (x + 1, y + 1, z + 1)))

    # ---------- Dancing Links structures ----------
    # node 0 is the header
    max_nodes = 1 + ncol + 3 * len(rows) + 5
    L = [0] * max_nodes
    R = [0] * max_nodes
    U = [0] * max_nodes
    D = [0] * max_nodes
    C = [0] * max_nodes          # column of node
    S = [0] * (ncol + 1)         # size of column, column headers are 1..ncol
    row_id = [0] * max_nodes     # which input row a node belongs to

    # header links columns in a doubly linked list
    header = 0
    for i in range(ncol + 1):
        L[i] = i - 1
        R[i] = i + 1
        U[i] = D[i] = i
    L[0] = ncol
    R[ncol] = 0

    node_cnt = ncol + 1          # next free index

    # add rows
    for rid, (cols, triple) in enumerate(rows):
        first = -1
        for col in cols:
            col_hdr = col + 1      # column headers are 1‑based
            nd = node_cnt
            node_cnt += 1

            C[nd] = col_hdr
            row_id[nd] = rid

            # vertical links (insert at bottom of column)
            U[nd] = U[col_hdr]
            D[nd] = col_hdr
            D[U[col_hdr]] = nd
            U[col_hdr] = nd
            S[col_hdr] += 1

            # horizontal links within the row
            if first == -1:
                first = nd
                L[nd] = R[nd] = nd
            else:
                L[nd] = L[first]
                R[nd] = first
                R[L[first]] = nd
                L[first] = nd

    solution_rows = []

    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    def search():
        if R[header] == header:          # all columns covered
            return True
        # choose column with minimal size
        c = R[header]
        min_s = S[c]
        col = c
        j = R[c]
        while j != header:
            if S[j] < min_s:
                min_s = S[j]
                col = j
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(col)
        r = D[col]
        while r != col:
            solution_rows.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search():
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution_rows.pop()
            r = D[r]
        uncover(col)
        return False

    ok = search()
    if not ok:
        print("NO")
        return
    # solution_rows contains indices of selected rows (may have duplicates because each row has 3 nodes)
    # we need unique rows, they are stored three times each; deduplicate preserving order
    seen = set()
    final = []
    for rid in solution_rows:
        if rid not in seen:
            seen.add(rid)
            final.append(rows[rid][1])
    # final must have k triples
    print("YES")
    for triple in final:
        print(*triple)

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
