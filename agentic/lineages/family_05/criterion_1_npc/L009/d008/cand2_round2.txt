<STATEMENT>
# Problem A — Resonant Waveforms

Time limit: 5 s   Memory limit: 256 MB

## Description

A continuous-wave communications array operates across three distinct parameter spaces:
- **k** frequency bands (indexed 1 to **k**),
- **k** polarization states (indexed 1 to **k**),
- **k** phase shifts (indexed 1 to **k**).

You are provided with a catalog of **t** potential signal paths. Each path is characterized by a triplet `(x, y, z)`, corresponding to its frequency band, polarization state, and phase shift, respectively.

Your objective is to stabilize the array by activating exactly **k** paths from the catalog. The array reaches a stable state if and only if the combined resonance profile of the chosen paths matches a critical target profile.

Specifically:
- The resonance profile of a single path `(x, y, z)` is represented by the rational function of a complex variable $w$:
  $$R(w) = \frac{1}{w - x} + \frac{1}{w - (k+y)} + \frac{1}{w - (2k+z)}$$
- A set of exactly **k** paths forms a stable configuration if the algebraic sum of their resonance functions is identically equal to the target profile:
  $$S(w) = \sum_{i=1}^{3k} \frac{1}{w - i}$$
  for all $w$ where the functions are defined.

Determine whether there is a subset of exactly **k** paths that achieves this stable configuration. If a valid configuration exists, output one such valid set.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the scale of the system and the number of available signal paths in the catalog.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an available path. No path is listed more than once.

## Output

If a valid stable configuration of exactly **k** paths exists, print `YES` on the first line, then print **k** lines, each containing the three parameters `x y z` of one chosen path. Any valid configuration is accepted; the paths may be printed in any order.

If no valid configuration exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, **k** = 2, so the target profile is:
$$S(w) = \frac{1}{w - 1} + \frac{1}{w - 2} + \frac{1}{w - 3} + \frac{1}{w - 4} + \frac{1}{w - 5} + \frac{1}{w - 6}$$

If we select the two available paths:
- The path `1 1 1` has a resonance profile of $R_1(w) = \frac{1}{w - 1} + \frac{1}{w - (2+1)} + \frac{1}{w - (4+1)} = \frac{1}{w - 1} + \frac{1}{w - 3} + \frac{1}{w - 5}$.
- The path `2 1 2` has a resonance profile of $R_2(w) = \frac{1}{w - 2} + \frac{1}{w - (2+1)} + \frac{1}{w - (4+2)} = \frac{1}{w - 2} + \frac{1}{w - 3} + \frac{1}{w - 6}$.

The algebraic sum of these profiles is:
$$R_1(w) + R_2(w) = \frac{1}{w - 1} + \frac{1}{w - 2} + \frac{2}{w - 3} + \frac{1}{w - 5} + \frac{1}{w - 6}$$

This sum is not identically equal to the target profile $S(w)$ (for instance, the combined function has a term $\frac{2}{w - 3}$ and lacks a term for $w - 4$). Since the profiles do not match, this configuration is invalid, making it impossible to form a stable configuration.
</STATEMENT>
<RATIONALE>
Restored the explicit bounds `1 ≤ k ≤ 22` and `0 ≤ t ≤ k·k·k` to the Input section to satisfy the hard constraint. Substituted the bitwise sum with a rational function identity. The models must deduce that equating the sum of rational functions to a target sum of distinct simple poles forces a bijection of those poles, requiring genuine mathematical reasoning rather than mapping familiar exact-cover keywords.
</RATIONALE>
<PRESERVED_ANSWER>
By the uniqueness of partial fraction decomposition, the sum of fractions matches the target if and only if exactly one of each pole from 1 to 3k is chosen, which is mathematically identical to the exact-cover requirement of the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains identically 3-Dimensional Matching, as it still requires selecting k disjoint triplets from a set of available triplets to exactly cover 3k elements.
</PRESERVED_CLASS>
<RISK>
A model might attempt to solve the problem by symbolically evaluating the rational functions at random points rather than recognizing the combinatorial constraint, leading it to timeout or memory limit.
