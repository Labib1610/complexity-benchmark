# Problem A — Resonant Waveforms

Time limit: 5 s   Memory limit: 256 MB

## Description

A quantum communications array operates across three distinct parameter spaces:
- frequency bands (indexed 1 to **k**),
- polarization states (indexed 1 to **k**),
- phase shifts (indexed 1 to **k**).

The system scale **k** is always a strictly positive integer, bounded by the facility's hardware limit: there are exactly 66 prime-frequency resonators available. Since a complete stable configuration requires exactly $3k$ distinct prime frequencies to be covered, this physical limit dictates the maximum possible value of **k**. 

You are provided with a catalog of **t** potential signal paths. The catalog size **t** can range from 0 up to the theoretical maximum where every valid triplet of the three parameters is listed exactly once. Each path is characterized by a triplet `(x, y, z)`, corresponding to its frequency band, polarization state, and phase shift, respectively.

Your objective is to stabilize the array by activating exactly **k** paths from the catalog. The array reaches a stable state if and only if the combined energy signature of the chosen paths matches a critical threshold. 

Specifically:
- The energy signature of a single path `(x, y, z)` is given by the integer value $E = p_x \times p_{k+y} \times p_{2k+z}$, where $p_i$ denotes the $i$-th prime number (for example, $p_1 = 2$, $p_2 = 3$, $p_3 = 5$, and so on).
- A set of exactly **k** paths forms a stable configuration if the standard arithmetic product of their energy signatures equals exactly the product of the first $3k$ prime numbers.

Determine whether there is a subset of exactly **k** paths that achieves this stable configuration. If a valid configuration exists, output one such valid set.

## Input

The first line contains two integers **k** and **t**: the scale of the system and the number of available signal paths in the catalog, respecting the physical limits described above.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an available path. No path is listed more than once.

## Output

If a valid stable configuration of exactly **k** paths exists, print `YES` on the first line, then print **k** lines, each containing the three parameters `x y z` of one chosen path. Any valid configuration is accepted; the paths may be printed in any order.

If no valid configuration exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, **k** = 2, so the target total system footprint is the product of the first $3 \times 2 = 6$ prime numbers: $2 \times 3 \times 5 \times 7 \times 11 \times 13 = 30030$.
If we select the two available paths:
- The path `1 1 1` has an energy signature of $p_1 \times p_3 \times p_5 = 2 \times 5 \times 11 = 110$.
- The path `2 1 2` has an energy signature of $p_2 \times p_3 \times p_6 = 3 \times 5 \times 13 = 195$.

The standard arithmetic product of these signatures is $110 \times 195 = 21450$. Since this product does not exactly equal the target threshold of 30030, this configuration is invalid, making it impossible to form a stable configuration.
