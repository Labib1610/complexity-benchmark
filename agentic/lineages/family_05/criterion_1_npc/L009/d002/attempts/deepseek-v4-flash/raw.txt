We need to select exactly `k` triples `(x, y, z)` such that all `x` are distinct, all `y` are distinct, and all `z` are distinct. This is equivalent to finding a perfect matching in a 3-partite 3-uniform hypergraph, which is NP-hard in general. However, with `k ≤ 22`, we can use a backtracking approach with pruning.

We can model it as:  
- We have `k` operators, `k` apparatuses, `k` shifts.  
- We need to assign each operator a unique apparatus and shift, such that the triple is in the allowed set.

We can use recursion with bitmasks to track used apparatuses and shifts.  
We iterate over operators in order, and for each operator, try all allowed triples that use unused apparatus and shift.

Since `k` is small (≤ 22), and `t` can be up to `k^3` (≈ 10648), we can precompute for each operator the list of possible `(y, z)` pairs.

We'll implement backtracking with memoization to avoid re-exploring the same state.

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    allowed = [[] for _ in range(k)]
    for _ in range(t):
        x, y, z = map(int, input().split())
        allowed[x-1].append((y-1, z-1))
    
    # Sort to have deterministic order
    for i in range(k):
        allowed[i].sort()
    
    used_app = [False] * k
    used_shift = [False] * k
    chosen = [None] * k
    
    # Memoization: state = (operator_index, apparatus_mask, shift_mask)
    from functools import lru_cache
    
    @lru_cache(None)
    def dfs(op_idx, app_mask, shift_mask):
        if op_idx == k:
            return True
        for y, z in allowed[op_idx]:
            if not (app_mask >> y) & 1 and not (shift_mask >> z) & 1:
                chosen[op_idx] = (op_idx+1, y+1, z+1)
                if dfs(op_idx+1, app_mask | (1 << y), shift_mask | (1 << z)):
                    return True
        return False
    
    if dfs(0, 0, 0):
        print("YES")
        for x, y, z in chosen:
            print(x, y, z)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
