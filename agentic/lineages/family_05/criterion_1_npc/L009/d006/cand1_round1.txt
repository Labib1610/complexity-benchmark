<METHOD_DESCRIPTION>Replaced the bitwise exact-cover condition with an algebraically isomorphic condition: the sum of unit fractions of distinct primes. Each path contributes 1/P_x + 1/P_{k+y} + 1/P_{2k+z} where primes are strictly > k (specifically > 22). <STATEMENT>
# Problem A — Resonant Waveforms

Time limit: 5 s   Memory limit: 256 MB

## Description

A quantum communications array needs to filter data streams through three dimensional parameters:
- **k** frequency bands, identified by integers 1 through **k**,
- **k** polarization states, identified by integers 1 through **k**,
- **k** phase shifts, identified by integers 1 through **k**.

You are provided with a catalog of **t** available signal paths. Each path is a triplet `(x, y, z)`, meaning it operates at frequency band **x**, polarization state **y**, and phase shift **z**.

To achieve perfect resonance, you must activate exactly **k** paths from the catalog. A selection of exactly **k** paths is considered a valid perfect resonance configuration if and only if it satisfies the following harmonic resonance condition:

- Let $P_1, P_2, \dots, P_{3k}$ be the sequence of the first $3k$ prime numbers strictly greater than 22, in ascending order. (For example, $P_1 = 23$, $P_2 = 29$, $P_3 = 31$, $P_4 = 37$, and so on).
- For each chosen path `(x, y, z)`, calculate its harmonic signature as the sum of three unit fractions:
  $H(x,y,z) = \frac{1}{P_x} + \frac{1}{P_{k+y}} + \frac{1}{P_{2k+z}}$
- The sum of the harmonic signatures of all **k** chosen paths must be exactly mathematically equal to the target system resonance $R$, defined as:
  $R = \sum_{j=1}^{3k} \frac{1}{P_j}$

Determine whether such a perfect resonance configuration of exactly **k** paths can be formed. If it is possible, output one valid set of **k** paths.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the scale of the system and the number of available signal paths in the catalog.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an available path. No path is listed more than once.

## Output

If a valid perfect resonance configuration of exactly **k** paths exists, print `YES` on the first line, then print **k** lines, each containing the three parameters `x y z` of one chosen path. Any valid configuration is accepted; the paths may be printed in any order.

If no valid configuration exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, **k** = 2. The first $3(2) = 6$ prime numbers strictly greater than 22 are $P_1=23, P_2=29, P_3=31, P_4=37, P_5=41, P_6=43$.
The target system resonance $R$ is $\frac{1}{23} + \frac{1}{29} + \frac{1}{31} + \frac{1}{37} + \frac{1}{41} + \frac{1}{43}$.

If we select the two available paths:
- The path `1 1 1` has a harmonic signature of $\frac{1}{P_1} + \frac{1}{P_{2+1}} + \frac{1}{P_{4+1}} = \frac{1}{23} + \frac{1}{31} + \frac{1}{41}$.
- The path `2 1 2` has a harmonic signature of $\frac{1}{P_2} + \frac{1}{P_{2+1}} + \frac{1}{P_{4+2}} = \frac{1}{29} + \frac{1}{31} + \frac{1}{43}$.

The sum of their harmonic signatures is $\frac{1}{23} + \frac{1}{29} + \frac{2}{31} + \frac{1}{41} + \frac{1}{43}$.
Because this sum does not exactly equal $R$ (specifically, $\frac{2}{31}$ appears instead of $\frac{1}{31} + \frac{1}{37}$), this configuration is invalid.
</STATEMENT>
<RATIONALE>
The bitwise exact-cover condition was replaced with an algebraically isomorphic condition: matching a target sum of unit fractions of distinct primes. Because the primes are chosen to be strictly greater than the maximum possible multiplicity (k ≤ 22), number theory guarantees that the sum can only be reached if the exact set of primes is chosen without duplication. This forces the student to deduce the exact-cover isomorphism; models that blindly simulate the fraction arithmetic will either hit floating-point precision errors or time out due to the massive unpruned search space.
</RATIONALE>
<PRESERVED_ANSWER>
Any selection of k paths satisfies the harmonic resonance condition if and only if it forms a perfect 3-dimensional matching (exact cover), which is exactly the same mathematical requirement as the original bitwise condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching (an NP-complete exact cover problem), just with its defining constraints encoded through prime reciprocals instead of binary masks.
</PRESERVED_CLASS>
<RISK>
Models might complain about floating-point precision being required for "exact mathematical equality", though the wording "exactly mathematically equal" heavily implies an algebraic rather than numerical expectation.
</RISK>
