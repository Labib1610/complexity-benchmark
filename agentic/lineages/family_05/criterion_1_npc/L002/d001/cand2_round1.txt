<STATEMENT>
# Problem A — Engineered Biogenesis

Time limit: 5 s   Memory limit: 256 MB

## Description

A bio-engineering facility aims to produce a generation of exactly $k$ synthetic entities. Every viable entity must be assembled from exactly three distinct biological modules:

- One structural membrane (chosen from a prepared supply of $k$ distinct variants, indexed 1 through $k$),
- One metabolic engine (chosen from a prepared supply of $k$ distinct variants, indexed 1 through $k$),
- One regulatory sequence (chosen from a prepared supply of $k$ distinct variants, indexed 1 through $k$).

Because of complex biochemical folding requirements, not all combinations are stable. You are provided with a database of $t$ known viable assemblies, each consisting of a specific structural membrane, metabolic engine, and regulatory sequence.

The facility's objective is to select exactly $k$ assemblies from the database to produce the $k$ synthetic entities. To guarantee maximum genetic diversity across the generation, the selection must strictly utilize the entire prepared supply: every structural membrane variant, every metabolic engine variant, and every regulatory sequence variant must each be incorporated into exactly one of the chosen assemblies.

Determine whether such a selection can be achieved. If it can, provide one valid set of $k$ assemblies.

## Input

The first line of input contains two integers $k$ and $t$. Since the facility's standard growth incubator contains exactly 22 cultivation pods, the generation size $k$ is at least 1 and will never exceed this capacity. The database size $t$ can be anywhere from 0 up to the absolute maximum number of unique assemblies that can be formed by choosing one variant from each of the three $k$-sized module supplies.

Each of the subsequent $t$ lines provides three integers $m$, $e$, and $s$ (each between 1 and $k$ inclusive) describing a viable assembly of a structural membrane, a metabolic engine, and a regulatory sequence. All listed assemblies are distinct.

## Output

If a valid selection of $k$ assemblies exists, print `YES` on the first line. Following this, print $k$ lines, each containing the three integers `m e s` of a chosen assembly. Any valid selection that incorporates every variant exactly once will be accepted, and the assemblies may be printed in any order.

If no such selection can be achieved, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both known viable assemblies use metabolic engine 1, so metabolic engine 2 can never be utilized.
