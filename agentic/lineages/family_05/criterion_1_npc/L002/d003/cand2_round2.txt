<STATEMENT>
# Problem A — Resonant Configuration Vectors

Time limit: 5 s   Memory limit: 256 MB

## Description

A quantum optical system operates using a set of **t** known stable configurations. Each configuration is defined by a vector of three integer parameters: `(u, v, w)`.

To achieve a full-spectrum resonance, you must select exactly **k** configurations from the known list. This subset of **k** configurations forms a valid resonance if and only if, when their vectors are stacked to form a **k** × 3 matrix (with each selected configuration forming one row), every column of the matrix contains all integers from 1 to **k** exactly once.

Determine whether such a full-spectrum resonance can be formed. If it is possible, output one valid set of exactly **k** configurations.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the system scale (representing the number of distinct components available for each parameter), and the number of known stable configurations.
Each of the following **t** lines contains three integers **u**, **v**, and **w** (1 ≤ u, v, w ≤ k), representing a stable configuration vector. No configuration is listed more than once.

## Output

If a valid full-spectrum resonance of exactly **k** configurations exists, print `YES` on the first line. Then, print **k** lines, each containing the three integers `u v w` of a selected configuration. Any valid set of **k** configurations that meets all requirements is accepted; the configurations may be printed in any order.

If no such set exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both known configurations have 1 as their second parameter. Selecting exactly 2 configurations from the list would require choosing both, which means the value 1 would appear twice in the second column of the resulting matrix. This violates the requirement that the second column must contain every integer from 1 to 2 exactly once. Thus, no valid resonance exists.
</STATEMENT>
<RATIONALE>
The previous wording heavily emphasized three distinct dimensions (input port, output port, frequency) and explicitly forbade repetition in each. This mapped immediately to a well-known heuristic: group by the first dimension and pick exactly one option for each value 1..k.
To force genuine algorithmic reasoning, the problem is reframed as selecting a subset of k vectors that form a k × 3 matrix where every column is a permutation of 1..k. This makes the dimensions perfectly symmetric. A model relying on surface pattern matching will likely attempt a generic subset search (which will TLE), while a model that genuinely analyzes the constraints will deduce that it can still optimize the search by anchoring the recursion to the first column.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to select k vectors such that each of the 3 positions contains all integers 1..k exactly once is mathematically identical to selecting k pathways with no shared input, output, or frequency.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching (3DM), retaining its NP-complete status and requiring the same optimized backtracking approach to pass within the time limit.
</PRESERVED_CLASS>
