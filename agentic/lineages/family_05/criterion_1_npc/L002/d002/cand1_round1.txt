<STATEMENT>
# Problem A — Optical Switch Configuration

Time limit: 5 s   Memory limit: 256 MB

## Description

An optical network switch is tasked with routing data from **k** input terminals to **k** output terminals. To prevent cross-talk, each active route must be modulated with one of **k** distinct carrier wavelengths. 

Not all connections are physically possible. You are given a registry of **t** feasible routes. Each entry in the registry is a triplet `(u, v, w)`, indicating that input terminal `u` can be linked to output terminal `v` using wavelength `w`. The terminals and wavelengths are uniformly indexed starting from 1 up to **k**.

Your objective is to establish a full-capacity routing state. To achieve this, you must activate exactly **k** routes from the registry such that the entire system is covered without conflict: each input terminal, each output terminal, and each carrier wavelength must appear in exactly one of the activated routes.

You must determine if such a state can be achieved, and if so, report the routes to activate.

## Input

The first line provides two integers, **k** and **t**. The system's backplane requires at least 1 terminal of each type to function and limits the terminal count **k** to a maximum of 22. The number of feasible routes **t** may be zero, or it may be as large as the total number of unique triplets formed by choosing one input terminal, one output terminal, and one wavelength.

The subsequent **t** lines each contain three integers **u**, **v**, and **w**. These denote the input terminal, output terminal, and carrier wavelength of a feasible route, respectively. Each of these values is a valid index for the given system size (ranging from 1 to **k** inclusive). The registry contains no duplicate entries.

## Output

If a full-capacity routing state can be established, output `YES` on the initial line. Following this, output **k** lines detailing the activated routes, each providing the three integers `u v w` corresponding to a route from the registry. These may be listed in any order.

If establishing a full-capacity state is impossible, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both feasible routes target output terminal 1, which means output terminal 2 can never be covered.

<RATIONALE>
I applied strategy S07, removing the explicit mathematical inequality bounds (e.g., `1 <= k <= 22` and `0 <= t <= k*k*k`). Instead, I expressed these limits as physical constraints of the hardware's backplane and the combinatorial maximum of possible triplets, forcing the model to deduce the variable bounds from the text's semantic meaning.
</RATIONALE>
<PRESERVED_ANSWER>
The requirements to select exactly k routes such that every input, output, and wavelength is used exactly once are logically identical to the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains an exact formulation of 3-Dimensional Matching, preserving its NP-complete complexity.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the upper bound of `t` if they fail to recognize that "unique triplets formed by choosing one input terminal, one output terminal, and one wavelength" strictly means `k^3`.
</RISK>
