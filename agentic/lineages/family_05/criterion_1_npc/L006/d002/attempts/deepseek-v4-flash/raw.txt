 We can model this as a 3D matching problem, but since **k ≤ 22**, we can use a backtracking approach with pruning, or reduce it to a bipartite matching problem by fixing one dimension.

Here’s the idea:

- We need to pick exactly **k** triples `(m, c, f)` such that all `m`, all `c`, and all `f` are distinct.
- We can fix the assignment of raw materials to batches (i.e., each material 1..k must be used exactly once).
- Then for each material, we need to choose a catalyst and finishing treatment, ensuring no catalyst or treatment is repeated.

This becomes a bipartite matching problem between catalysts and treatments, but with the constraint that each material has a fixed set of allowed `(c, f)` pairs.

We can solve it by:
1. For each material `m`, collect all possible `(c, f)` pairs.
2. Use backtracking with pruning: assign materials one by one, and for each, try all possible `(c, f)` pairs that are still unused.
3. Since k ≤ 22, worst-case backtracking might be heavy, but with pruning and early exit it works within limits.

We can also use a maximum bipartite matching approach:  
- Create a graph where left side = catalysts, right side = treatments.  
- For each material, we need to pick one edge from its allowed set.  
- This is a 3D matching, but we can solve it by trying all permutations of materials (k! is too large), so backtracking with pruning is better.

Let’s implement backtracking with bitmasks for used catalysts and treatments.

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    protocols = []
    for _ in range(t):
        m, c, f = map(int, input().split())
        protocols.append((m-1, c-1, f-1))
    
    # Group by material
    by_material = [[] for _ in range(k)]
    for m, c, f in protocols:
        by_material[m].append((c, f))
    
    # Sort materials by number of options (smallest first) for pruning
    order = sorted(range(k), key=lambda x: len(by_material[x]))
    
    used_c = [False] * k
    used_f = [False] * k
    chosen = [None] * k
    
    def dfs(idx):
        if idx == k:
            return True
        m = order[idx]
        for c, f in by_material[m]:
            if not used_c[c] and not used_f[f]:
                used_c[c] = True
                used_f[f] = True
                chosen[m] = (m, c, f)
                if dfs(idx + 1):
                    return True
                used_c[c] = False
                used_f[f] = False
        return False
    
    if dfs(0):
        print("YES")
        for m, c, f in chosen:
            print(m+1, c+1, f+1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
