<STATEMENT>
# Problem A — Structural Integrity

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a structural support matrix that requires exactly **k** load-bearing pillars. The foundation is mapped onto three independent structural axes: the X-axis, Y-axis, and Z-axis. Each axis has exactly **k** discrete grid lines, numbered 1 through **k**.

You have a blueprint containing **t** potential anchor points. Each anchor point is located at a specific X-axis line (**x**), Y-axis line (**y**), and Z-axis line (**z**). No two anchor points in the blueprint have the exact same combination of all three coordinates.

To ensure the structural integrity of the matrix, the **k** chosen pillars must be placed at anchor points such that:
- No two pillars share the same X-axis line.
- No two pillars share the same Y-axis line.
- No two pillars share the same Z-axis line.

Determine whether it is possible to select exactly **k** anchor points from the blueprint to place the pillars. If so, report one such valid selection.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of required pillars (which is also the number of grid lines per axis), and the number of potential anchor points. 
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an anchor point on X-axis line **x**, Y-axis line **y**, and Z-axis line **z**. No anchor point is listed more than once.

## Output

If a valid placement of **k** pillars exists, print `YES` on the first line, then print **k** lines, each containing the three integers `x y z` of a chosen anchor point. Any selection meeting the conditions is accepted; the anchor points may be printed in any order.

If no such placement exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both available anchor points are on Y-axis line 1. Choosing both would violate the structural integrity condition, so it is impossible to place 2 valid pillars.
