# Problem A — Industrial Alchemy

Time limit: 5 s   Memory limit: 256 MB

## Description

You manage a specialized chemical plant that must fulfill a massive contract. Your production schedule entails operating a set of mixing vats. The plant's physical footprint limits it to a maximum of 22 vats, but it will always operate at least 1. Every active vat must be assigned exactly one product batch, meaning the number of batches required is exactly the number of vats, **k**.

To produce these batches, your facility stocks several distinct raw materials, distinct catalysts, and distinct finishing treatments. The inventory is maintained such that the number of available options for each of these three resource categories perfectly matches the number of vats in operation. Every individual resource is identified by a positive integer, starting from 1 and not exceeding the number of vats.

Your research division maintains a database of **t** viable synthesis protocols. Each protocol defines a process using exactly one raw material, one catalyst, and one finishing treatment. No two protocols in the database are identical. The database might be entirely empty, or it might be completely comprehensive, containing up to every conceivable unique combination of the available resources.

To fulfill the contract, you must select a number of protocols from the database exactly equal to the number of vats. However, to prevent cross-contamination and equipment fatigue, the schedule must adhere to a strict diversity condition:
- No two chosen protocols may utilize the same raw material.
- No two chosen protocols may utilize the same catalyst.
- No two chosen protocols may utilize the same finishing treatment.

Determine whether it is possible to select the required number of protocols from your database to form a valid schedule, and if so, report one such selection.

## Input

The first line contains two integers **k** and **t**: the number of vats in operation, and the number of known protocols. The values of these integers are restricted by the physical limits and database extremes described in the scenario.

Each of the next **t** lines contains three integers **m**, **c**, and **f**. These represent an available protocol that uses raw material **m**, catalyst **c**, and finishing treatment **f**. The resource identifiers are restricted by the inventory numbering scheme described previously. No protocol is listed more than once.

## Output

If a valid schedule of **k** protocols exists, print `YES` on the first line. Then, print **k** lines, each containing the three integers `m c f` of one chosen protocol. Any selection meeting the conditions is accepted; the chosen protocols may be printed in any order.

If no such schedule exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```
