<STATEMENT>
# Problem A — Harmonious Task Forces

Time limit: 5 s   Memory limit: 256 MB

## Description

A company wants to assemble task forces. There are three departments: Alpha, Beta, and Gamma. Each department employs exactly $k$ staff members, who hold ID numbers from $1$ to $k$.

A valid task force requires three members—one from Alpha, one from Beta, and one from Gamma. However, due to differing work styles, only certain specific combinations of three employees can collaborate effectively. You will be provided with the complete catalog of $t$ compatible combinations.

Your goal is to organize the entire workforce into task forces. The final arrangement must place every single employee from all three departments into a compatible combination, with no individual participating in more than one task force. 

Determine whether such a full deployment is achievable, and if so, report one valid roster of task forces.

## Input

The first line contains two integers $k$ and $t$. The staffing level $k$ is at least 1 and is constrained by the maximum capacity of 22 workstations per department. The catalog size $t$ ranges from 0 up to the theoretical maximum of all conceivable three-person groupings.

Each of the following $t$ lines contains three integers $a$, $b$, and $c$, indicating that Alpha employee $a$, Beta employee $b$, and Gamma employee $c$ can effectively collaborate. The IDs $a$, $b$, and $c$ are guaranteed to be valid department IDs. No combination is listed more than once.

## Output

If a complete deployment of all personnel is possible, print `YES` on the first line. Then, output $k$ lines, each containing the three IDs $a$ $b$ $c$ of a chosen task force. Any valid deployment is acceptable, and the task forces may be printed in any order.

If no such deployment is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both compatible combinations require Beta employee 1. Consequently, Beta employee 2 can never be assigned to any task force, making a full deployment impossible.
</STATEMENT>
<RATIONALE>
Replaced the abstract formulation of parameters and values with a scenario about assigning employees from three departments to task forces. The numeric bounds are now expressed indirectly through physical office capacities and theoretical maximums (Strategy S07). By phrasing the requirement as "deploying the entire workforce" rather than "every value is used exactly once for each parameter", models must infer the exact-cover properties from the scenario rather than pattern-matching the formal definition.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still asks for a selection of $k$ valid triples that cover all elements $1 \dots k$ exactly once for each of the three positions, so the valid outputs for any input remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying task is still exactly 3-Dimensional Matching, which is a known NP-complete problem.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "theoretical maximum of all conceivable three-person groupings" if they forget that order within the group is fixed by department, but the context clearly defines a combination as one from each department, making $k^3$ unambiguous.
</RISK>
