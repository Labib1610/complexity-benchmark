We need to select exactly k triples from the given stable configurations such that:

- All first coordinates are distinct (1..k)
- All second coordinates are distinct (1..k)
- All third coordinates are distinct (1..k)

This is equivalent to finding a perfect matching in a 3-partite 3-uniform hypergraph, which is NP-hard in general. But since k ≤ 22, we can use a backtracking / DFS with pruning, or model it as a bipartite matching problem after fixing one coordinate.

A common approach:  
We can fix the first coordinate values 1..k, and for each, try to assign a second and third coordinate such that all are distinct. This becomes a bipartite matching problem between second and third coordinates for each first coordinate.

We can solve it using maximum bipartite matching (Hopcroft-Karp or DFS-based) for each first coordinate, but we need to assign all k first coordinates simultaneously. This is a 3D matching problem, which is NP-hard, but k ≤ 22 allows backtracking with pruning.

We can do backtracking over first coordinates, and for each, try all possible (p2, p3) pairs from the given list, maintaining used sets for p2 and p3. With pruning and early exit, this should work for k ≤ 22.

Let's implement a DFS with bitmask for used p2 and p3 (since k ≤ 22, we can use integers as bitmasks).

We'll store for each p1 a list of (p2, p3) pairs.

Then DFS:

```
def dfs(i, used2, used3, chosen):
    if i == k+1: return True
    for (p2, p3) in options[i]:
        if not (used2 & (1 << (p2-1))) and not (used3 & (1 << (p3-1))):
            chosen.append((i, p2, p3))
            if dfs(i+1, used2 | (1 << (p2-1)), used3 | (1 << (p3-1)), chosen):
                return True
            chosen.pop()
    return False
```

We start from i=1 to k. If any p1 has no options, return NO.

This should be fast enough for k ≤ 22 because the search space is limited by the given t.

Let's code it.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    k = int(next(it))
    t = int(next(it))
    
    options = [[] for _ in range(k+1)]
    for _ in range(t):
        p1 = int(next(it))
        p2 = int(next(it))
        p3 = int(next(it))
        options[p1].append((p2, p3))
    
    # If any p1 has no options, impossible
    for i in range(1, k+1):
        if not options[i]:
            print("NO")
            return
    
    chosen = []
    
    def dfs(i, used2, used3):
        if i == k+1:
            return True
        for p2, p3 in options[i]:
            if not (used2 & (1 << (p2-1))) and not (used3 & (1 << (p3-1))):
                chosen.append((i, p2, p3))
                if dfs(i+1, used2 | (1 << (p2-1)), used3 | (1 << (p3-1))):
                    return True
                chosen.pop()
        return False
    
    if dfs(1, 0, 0):
        print("YES")
        for p1, p2, p3 in chosen:
            print(p1, p2, p3)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
