**Solution Explanation**

For every value `1 … k` we have three *positions*  

* column `A_i` – the first parameter equals `i`  
* column `B_i` – the second parameter equals `i`  
* column `C_i` – the third parameter equals `i`

A stable configuration `(x , y , z)` uses exactly the three columns `A_x , B_y , C_z`.
We have to choose **k** configurations such that every column is used **once**.
That is exactly the *exact cover* problem:

*columns* – `3·k` columns (`A_1 … A_k , B_1 … B_k , C_1 … C_k`)  
*rows*    – one row for every given stable configuration, containing the three
            columns belonging to this configuration.

We need a set of rows covering all columns exactly once.

`k ≤ 22`, therefore at most `3·k = 66` columns and at most `k³ ≤ 10648` rows.
The classic Algorithm X with dancing‑links (DLX) solves such instances
comfortably within the limits.



--------------------------------------------------------------------

#### Algorithm
```
read k , t
for each stable triple (x,y,z)
        create a row containing columns  A_x , B_y , C_z

run DLX (Algorithm X) on this exact‑cover instance
        – choose the column with the smallest remaining row count (heuristic)
        – recursively cover/uncover rows
        – stop when all columns are covered (solution found)

if a solution of exactly k rows is found
        output YES and the corresponding triples
else
        output NO
```

The DLX data structure stores the sparse matrix with four integer arrays
`L,R,U,D` (left, right, up, down links) and `C` (column of a node).
`S[col]` holds the current number of rows still containing `col`.
The header node links all still‑uncovered columns in a circular list.

The recursive search:

```
search():
        if header.right == header:          # no uncovered column
                solution found
        choose column c with minimal S[c]
        cover(c)
        for each row r in column c (downwards):
                add r to current answer
                for each node j in row r (rightwards):
                        cover( column of j )
                if search() succeeds: return True
                # backtrack
                for each node j in row r (leftwards):
                        uncover( column of j )
                remove r from answer
        uncover(c)
        return False
```

The recursion depth never exceeds `k` (we need exactly `k` rows), therefore
the stack is safe.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a valid schedule
iff such a schedule exists.

---

##### Lemma 1  
During DLX execution, a column is *covered* exactly when the algorithm has
chosen a row that contains this column, and *uncovered* exactly when that row
is removed from the partial solution.

**Proof.**  
`cover(c)` removes column `c` from the header list and, for every row `r`
containing `c`, removes all other columns of `r` from their column lists.
Thus any later selection cannot use those columns – they are considered already
covered by `r`.  
`uncover(c)` restores the links in the reverse order, making the columns
available again. ∎



##### Lemma 2  
At any recursive call, the set of rows stored in the current answer
covers precisely the set of columns that have been removed from the header.

**Proof.**  
Induction over recursion depth.  
*Base*: depth 0 – answer empty, no column covered – true.  
*Step*: when a row `r` is added, the algorithm calls `cover` for each of its
columns (Lemma&nbsp;1). Hence all those columns become removed from the header,
and the invariant holds. When backtracking, the corresponding `uncover`
calls restore the columns, and the row is removed from the answer, restoring
the invariant. ∎



##### Lemma 3  
If the algorithm reaches the state “header has no column”, the rows in the
answer form a set of **k** pairwise column‑disjoint triples, i.e. a valid
schedule.

**Proof.**  
No column left uncovered ⇒ every column `A_i , B_i , C_i` appears in exactly one
chosen row (by Lemma&nbsp;2).  
Thus each value `i` occurs exactly once as first, second and third parameter.
The number of rows equals the number of distinct first‑parameter values,
which is `k`. Hence the answer is a schedule satisfying all constraints. ∎



##### Lemma 4  
If a valid schedule exists, the DLX search will eventually find it.

**Proof.**  
Consider any valid schedule `S`. Its rows constitute a exact cover of all
columns. Algorithm X explores the search tree by trying **all** possibilities:
for the currently chosen column it iterates over *every* row containing it,
recursively exploring the sub‑problem after covering that row’s columns.
Since `S` contains a row for the first chosen column, the branch following that
row is explored, and by induction the whole schedule `S` is reachable and
accepted when the header becomes empty. ∎



##### Lemma 5  
If the algorithm outputs `NO`, no valid schedule exists.

**Proof.**  
`NO` is printed only when the recursive search exhausts all branches without
covering all columns. By Lemma&nbsp;4, any existing exact cover would be found.
Therefore none exists. ∎



##### Theorem  
The program prints `YES` followed by a list of `k` stable configurations
iff such a list exists; otherwise it prints `NO`.

**Proof.**  
*If* part: when the program prints `YES`, it has found a solution via DLX.
By Lemma&nbsp;3 the printed configurations form a valid schedule.

*Only‑if* part: if a valid schedule exists, Lemma&nbsp;4 guarantees DLX finds
one, so the program prints `YES`. If DLX fails, Lemma&nbsp;5 shows that no
schedule exists, and the program correctly prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

* `C = 3k ≤ 66` columns, `R ≤ k³ ≤ 10648` rows, each row has exactly 3 nodes.  
*Memory*: `O(C + 3R) ≤ O(k³)` ≤ about 32 k integers → well below limits.

*Search*: In the worst case Algorithm X may explore an exponential number of
states, but with `k ≤ 22` the practical running time is far below the 5 s
limit (the classic exact‑cover benchmark with similar sizes runs in milliseconds).

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1000000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    # column ids: 0..3k-1  (A0..A(k-1), B0..B(k-1), C0..C(k-1))
    ncol = 3 * k
    rows = []          # each row: (x,y,z) and list of column ids
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        cols = [x, k + y, 2 * k + z]
        rows.append(((x, y, z), cols))

    # ---------- DLX construction ----------
    max_nodes = len(rows) * 3 + ncol + 5
    L = [0] * max_nodes
    R = [0] * max_nodes
    U = [0] * max_nodes
    D = [0] * max_nodes
    C = [0] * max_nodes          # column of node
    S = [0] * (ncol + 1)         # size of column, column 0 is header

    header = 0
    # header linked list of column headers 1..ncol
    for i in range(ncol + 1):
        L[i] = i - 1
        R[i] = i + 1
        U[i] = D[i] = i
    R[ncol] = header
    L[header] = ncol
    R[header] = 1
    L[1] = header

    node_id = ncol + 1
    row_node_ids = []   # first node id of each row (for answer retrieval)

    for (triple, cols) in rows:
        first = -1
        for col in cols:
            col_id = col + 1          # shift: column headers are 1..ncol
            nid = node_id
            node_id += 1
            C[nid] = col_id
            # vertical links
            U[nid] = U[col_id]
            D[nid] = col_id
            D[U[col_id]] = nid
            U[col_id] = nid
            S[col_id] += 1
            # horizontal links
            if first == -1:
                first = nid
                L[nid] = R[nid] = nid
            else:
                L[nid] = L[first]
                R[nid] = first
                R[L[first]] = nid
                L[first] = nid
        row_node_ids.append(first)

    answer_rows = []
    solution = []

    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    found = False

    def search():
        nonlocal found
        if R[header] == header:
            # all columns covered
            found = True
            return True
        # choose column with minimal S
        c = R[header]
        min_s = S[c]
        col = c
        j = R[c]
        while j != header:
            if S[j] < min_s:
                min_s = S[j]
                col = j
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(col)
        r = D[col]
        while r != col:
            answer_rows.append(r)
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search():
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            answer_rows.pop()
            r = D[r]
        uncover(col)
        return False

    if search():
        # retrieve triples from selected rows
        out = []
        for node in answer_rows:
            # node belongs to a row; find its row index
            # we stored rows in order, each row's first node id is in row_node_ids
            # map node -> row index via a dict
            pass
        # Build mapping from any node id to its row index
        node_to_row = {}
        for idx, first in enumerate(row_node_ids):
            cur = first
            while True:
                node_to_row[cur] = idx
                cur = R[cur]
                if cur == first:
                    break
        triples = []
        for node in answer_rows:
            triples.append(rows[node_to_row[node]][0])
        # output
        out_lines = ["YES"]
        for (x, y, z) in triples:
            out_lines.append(f"{x+1} {y+1} {z+1}")
        sys.stdout.write("\n".join(out_lines))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```
