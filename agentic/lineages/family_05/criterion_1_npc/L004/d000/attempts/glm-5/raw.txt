def solve():

        return

    t = int(data[1])
    idx = 2
    edges = []
    for _ in range(t):
        a = int(data[idx]) - 1
        b = int(data[idx+1]) - 1
        c = int(data[idx+2]) - 1
        idx += 3
        edges.append((a, b, c))

Actually we need exact count to determine if nonzero after signed sum. But counts can be huge. We can use arbitrary precision or mod a large prime? But the count could be zero mod a prime even if nonzero. However, if we compute the exact count using big integers, we can determine zero. But computing the exact count efficiently is the challenge.

    # So only bijections f contribute. Then the sum is sum_{bijections f} prod_i [f(i) in D_i] = number of bijections f such that f(i) in D_i for all i.

    # Backtrack: for a in order, try each (b,c) with b and c unused.

    adj = [[] for _ in range(k)]
    for a, b, c in edges:
        adj[a].append((b, c))
    
    # Order a by increasing degree (most constrained first)
    order = sorted(range(k), key=lambda a: len(adj[a]))
    
    # Precompute for each a in order, the list of (b,c)

    used_b = 0
    used_c = 0
    assignment = [None] * k  # assignment[a] = (b,c)
    
    # We'll do iterative or recursive backtracking. Recursive with Python might hit recursion limit, but k<=22 is fine.
    # Use recursion with pruning.

    def backtrack(i, used_b, used_c):

            return True
        a = order[i]
        for b, c in adj_ordered[i]:
            if not (used_b >> b) & 1 and not (used_c >> c) & 1:
                assignment[a] = (b, c)
                if backtrack(i+1, used_b | (1 << b), used_c | (1 << c)):
                    return True
        return False
    
    if backtrack(0, 0, 0):
        print("YES")
        for a in range(k):
            b, c = assignment[a]
            print(a+1, b+1, c+1)
    else:
        print("NO")
