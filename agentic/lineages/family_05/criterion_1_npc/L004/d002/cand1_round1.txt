<STATEMENT>
# Problem A — Spatial Anchors

Time limit: 5 s   Memory limit: 256 MB

## Description

You are given a list of **t** candidate anchor points in a 3D space. Each point is defined by its coordinates (**x**, **y**, **z**), where each coordinate is an integer from 1 to **k**.

You must select exactly **k** anchor points from this list to form a stable framework. 
A framework is considered stable if and only if, for every pair of distinct selected points, the displacement vector between them has no zero components. In other words, if two selected points have coordinates (**x₁**, **y₁**, **z₁**) and (**x₂**, **y₂**, **z₂**), then |**x₁** - **x₂**| > 0, |**y₁** - **y₂**| > 0, and |**z₁** - **z₂**| > 0.

Determine whether a stable framework of exactly **k** anchor points can be formed from the given candidates. If it is possible, report one valid selection of **k** points.

## Input

The first line contains two integers **k** and **t** (1 ≤ **k** ≤ 22, 0 ≤ **t** ≤ **k**³): the coordinate limit and the number of candidate anchor points.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ **x**, **y**, **z** ≤ **k**), representing a candidate point. No point is listed more than once.

## Output

If a stable framework of **k** points exists, print `YES` on the first line, then print **k** lines, each containing the three coordinates `x y z` of one chosen point. Any selection meeting the requirements is accepted; the points may be printed in any order.

If no valid selection exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, any framework of 2 points would have to include both candidate points. However, the absolute difference between their **y**-coordinates is |1 - 1| = 0, which violates the stability requirement.
</STATEMENT>
<RATIONALE>
I replaced the explicit "no two chosen configurations share the same value" constraint with a geometric condition requiring the displacement vector between any two chosen points to have no zero components. This hides the "exactly once" property of the parameters behind a pairwise distance inequality, forcing the model to deduce the Exact Cover structure mathematically rather than matching the standard wording.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the absolute difference between coordinates is strictly greater than 0 is mathematically identical to requiring that no two points share the same coordinate value.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to 3-Dimensional Matching (or Exact Cover), as finding $k$ points in a $k \times k \times k$ grid that share no coordinates is exactly the same NP-complete problem.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "displacement vector has no zero components" if they do not read the explicit inequality clarification, but the provided inequalities (|x1-x2|>0) strictly eliminate any ambiguity.
</RISK>
