**Solution Explanation**

For every integer `i (1 … k)` we have three different “positions”

* primary   – element `P_i`
* secondary – element `S_i`
* tertiary  – element `T_i`

A stable configuration `(a,b,c)` uses the three elements `P_a , S_b , T_c`.
We have to choose exactly `k` configurations such that every element `P_i , S_i , T_i`
appears **once**.  
So we have to find an *exact cover* of the set  

```
U = { P_1 … P_k , S_1 … S_k , T_1 … T_k }      (|U| = 3k)
```

by `k` triples, each triple covering three different elements of `U`.

The classic algorithm for exact cover is **Algorithm X** (Donald Knuth) together
with the dancing‑links data structure.  
`k ≤ 22` ⇒ `|U| ≤ 66`, the number of rows (stable configurations) is at most `k³ ≤ 10648`,
well inside the limits for DLX.

The algorithm:

```
search():
    if no column left → all elements covered → solution found
    choose column c with the smallest number of rows (heuristic)
    for each row r that contains c:
        add r to the partial solution
        cover all columns of r (and the rows that intersect them)
        if search() succeeds → propagate success
        uncover everything (backtrack)
    return failure
```

If a solution is found we output the `k` rows (the original triples).

The implementation follows the usual DLX node structure:

* each column header stores the number of rows still containing it (`size`);
* each node has four links (`L,R,U,D`) and a pointer to its column header;
* covering a column removes it from the header list and removes all rows that
  contain it from the other columns;
* uncovering restores everything in reverse order.

The recursion depth never exceeds `k ≤ 22`.

If the search finishes without a solution we output `NO`.

The whole program fits easily into the limits.



**Correctness Proof**

We prove that the algorithm prints `YES` and a valid schedule
iff such a schedule exists.

---

*Lemma 1*  
During the execution of `search` the set of uncovered columns is exactly the
set of elements of `U` that are not yet covered by the rows already chosen.

*Proof.*  
Initially all columns are uncovered, no element is covered – true.
Covering a column `c` removes `c` from the header list, i.e. marks the element
as covered. For every row `r` that contains `c` we also remove all other
columns of `r`; those elements become covered as well because `r` will be part
of the final solution. Uncovering restores the columns and rows in the exact
reverse order, therefore the invariant holds after every recursive step. ∎



*Lemma 2*  
When `search` reaches the line “if no column left”, the rows stored in the
partial solution cover every element of `U` exactly once.

*Proof.*  
“No column left” means the header list is empty, i.e. all columns are covered.
By Lemma&nbsp;1 this is equivalent to every element of `U` being covered.
Because covering a column removes **all** rows that intersect it, no element can
be covered by two different chosen rows. Hence each element appears exactly
once. ∎



*Lemma 3*  
If `search` returns success, the `k` rows it outputs form a valid schedule.

*Proof.*  
Success is returned only at the situation of Lemma&nbsp;2, therefore the
selected rows cover each `P_i , S_i , T_i` exactly once.
Consequently the first components of the rows are a permutation of
`1…k`, the same for the second and third components, i.e. the schedule satisfies
the required condition. The algorithm never selects more than `k` rows
(because each step covers three previously uncovered elements, and there are
`3k` elements total), therefore exactly `k` rows are selected. ∎



*Lemma 4*  
If a valid schedule exists, `search` will eventually find one.

*Proof.*  
Consider any valid schedule `X`. Its rows constitute an exact cover of `U`.
Algorithm X explores **all** possible exact covers: at each recursion level it
chooses a column `c` and tries **every** row that contains `c`. Since `X`
contains some row `r` covering `c`, the branch that picks `r` is explored.
Induction on the recursion depth shows that the whole set `X` is a possible
path of the search tree, therefore the algorithm will reach the leaf where
all columns are covered and return success. ∎



*Theorem*  
The program outputs `YES` followed by a schedule exactly when such a schedule
exists; otherwise it outputs `NO`.

*Proof.*  

*If* the program outputs `YES`, it did so after `search` succeeded.
By Lemma&nbsp;3 the printed rows form a valid schedule.

*Only‑if* a valid schedule exists, Lemma&nbsp;4 guarantees that `search`
finds one, thus the program prints `YES`.  
If no schedule exists, `search` explores the whole search tree without
reaching the “no column left” state and returns failure, so the program prints
`NO`. ∎



**Complexity Analysis**

* `n = 3k ≤ 66` columns, `m ≤ k³ ≤ 10648` rows.
* Each covering/uncovering step touches at most the nodes of the involved rows,
  i.e. `O(k)` nodes.
* The recursion depth is `k`.  
  In the worst case the algorithm may examine many branches, but for the given
  limits the total running time is far below the 5 s limit (empirically well
  under a second for the maximal input).

Memory consumption: one node per 1‑entry in the matrix → `3·m ≤ 31944` nodes,
each storing a few integers/pointers → well under the 256 MB limit.

    sys.setrecursionlimit(1000000)

    k = int(next(it)); t = int(next(it))

    ncol = 3*k

    U = [0]*max_nodes
    D = [0]*max_nodes
    L = [0]*max_nodes
    R = [0]*max_nodes
    C = [0]*max_nodes
    S = [0]*ncol          # column sizes
    row_of = [0]*max_nodes

    header = 0
    # header list: 0 is root, columns are 1..ncol
    for i in range(ncol+1):
        L[i] = i-1
        R[i] = i+1
    L[0] = ncol
    R[ncol] = 0

    # column headers are nodes 1..ncol, each column i corresponds to element i-1
    for i in range(1, ncol+1):
        U[i] = D[i] = i

    node_cnt = ncol+1

    def add_row(rid, cols):
        nonlocal node_cnt
        first = -1
        for col in cols:
            col_id = col+1
            node = node_cnt
            node_cnt += 1
            C[node] = col_id
            row_of[node] = rid
            # vertical link
            U[node] = U[col_id]
            D[node] = col_id
            D[U[col_id]] = node
            U[col_id] = node
            S[col] += 1
            # horizontal link
            if first == -1:
                first = node
                L[node] = R[node] = node
            else:
                L[node] = L[first]
                R[node] = first
                R[L[first]] = node
                L[first] = node
        return

    for idx, (a,b,c) in enumerate(triples):
        add_row(idx, [a, k+b, 2*k+c])

    solution = []
    found = False

    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]-1] -= 1

            return True
