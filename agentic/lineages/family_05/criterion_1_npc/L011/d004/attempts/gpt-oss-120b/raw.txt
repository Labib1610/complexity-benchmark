**Solution Explanation**

For every approved configuration we have a triple  

```
(x , y , z) ,   1 ≤ x , y , z ≤ k
```

We have to choose exactly `k` triples such that each number `1 … k`
appears **once** among the chosen `x`‑coordinates,
once among the chosen `y`‑coordinates and once among the chosen `z`‑coordinates.
So we have to cover the following set of `3·k` items

```
X1 … Xk ,   Y1 … Yk ,   Z1 … Zk
```

with `k` triples, each triple covering exactly three different items
(`Xi , Yj , Zℓ`).  
That is an *exact cover* problem.

`k ≤ 22`, therefore the number of items is at most `66`.
The number of rows (approved triples) is at most `k³ ≤ 10648`.
Exact cover with at most a few hundred columns and a few ten‑thousands rows
is solved instantly by Knuth’s **Algorithm X** (depth‑first search with
dancing‑links).

--------------------------------------------------------------------

#### 1.   Dancing‑Links structure

*Columns* – one for every required item (`X1…Xk , Y1…Yk , Z1…Zk`).  
*Rows* – one for every approved triple.  
A row contains three nodes, each linked to the column of the covered item.

The data structure consists of four integer arrays (all 0‑based indices)

```
U, D, L, R   – up, down, left, right neighbours
C            – column of a node
S            – size of a column (how many rows still contain it)
col_head[i]  – node index of the column header i   (0 … 3k-1)
```

The header of the whole matrix is node `0`.  
All other nodes are numbered consecutively while the input is read.

The usual operations are implemented:

* `cover(col)`   – removes a column and all rows that contain it
* `uncover(col)` – restores them (exact inverse)

Both run in time proportional to the number of removed nodes.

--------------------------------------------------------------------

#### 2.   Search

```
search():
    if header.right == 0:               # no column left → all covered
            solution found
    choose column c with minimal S[c]   # heuristic, reduces branching
    cover(c)
    for each row r in column c (downwards):
            add r to current answer
            for each node j to the right of r:
                    cover( column of j )
            if search() succeeds: return success
            # backtrack
            for each node j to the left of r (reverse order):
                    uncover( column of j )
            remove r from answer
    uncover(c)
    return failure
```

The recursion depth never exceeds `k (≤22)`.  
Because each step removes at least one column, the total number of recursive
calls is bounded and the program finishes far below the time limit.

--------------------------------------------------------------------

#### 3.   Reconstructing the answer

When a solution is found we have stored the row indices of the selected rows.
From the original input we output the corresponding triples.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
During the execution of `search` the set of uncovered columns is exactly the
set of items that are not yet covered by the rows stored in the current
partial answer.

**Proof.**  
Initially all columns are uncovered and the answer is empty – the statement
holds.  
When a row `r` is added, `cover` is called for every column that `r` contains.
`cover` removes the column and also removes every other row that also contains
this column, i.e. it guarantees that no later row can reuse the same item.
Thus after covering all three columns of `r` the uncovered columns are precisely
the items not yet covered by any chosen row.  
When backtracking, `uncover` restores exactly the columns and rows that were
removed, restoring the invariant. ∎



##### Lemma 2  
If `search` reaches the line “header.right == 0” then the rows stored in the
answer cover every column exactly once.

**Proof.**  
`header.right == 0` means that no column header is linked to the master header,
hence all columns are covered (removed).  
By Lemma&nbsp;1 the uncovered set is empty, therefore every item is covered by
some chosen row.  
Because a column is removed only together with *all* rows that contain it,
no two chosen rows can contain the same column. Hence each item is covered
exactly once. ∎



##### Lemma 3  
If a set of `k` triples satisfying the problem statement exists,
`search` will eventually find a solution.

**Proof.**  
Consider any such valid set `T`.  
All its rows are present in the matrix.  
During the depth‑first search the algorithm tries **every** possible row of the
currently selected column (the column with minimal size).  
Because `T` covers every column, for the first selected column there is at
least one row of `T` that contains it; the algorithm will eventually try that
row.  
Choosing that row removes exactly the three columns that the row covers.
The remaining rows of `T` still cover all still‑uncovered columns (they are
disjoint).  
Induction on the number of already chosen rows shows that there exists a
search path that always picks a row belonging to `T`.  
When the last column is covered, the algorithm reaches the success condition
(Lemma&nbsp;2). ∎



##### Lemma 4  
If `search` reports failure, no set of `k` triples satisfying the statement
exists.

**Proof.**  
Assume the contrary: a valid set `T` exists but the algorithm fails.
During the search the algorithm explores **all** possibilities for the first
column, then recursively all possibilities for the second, etc.
Whenever a row is chosen, all rows conflicting with it (sharing a column) are
removed, exactly mirroring the requirement that a valid set cannot contain two
rows with a common item.
Therefore the branch that always picks the rows of `T` (as argued in Lemma 3)
is a valid search path and would lead to success.
Since the algorithm exhaustively explores all branches, it cannot finish with
failure. Contradiction. ∎



##### Theorem  
The program outputs

* “YES” and a list of `k` triples **iff** such a list exists,
* otherwise “NO”.

**Proof.**  

*If the program prints “YES”.*  
It printed the rows stored when `search` succeeded.
By Lemma 2 these rows cover each `Xi , Yi , Zi` exactly once, i.e. the three
sorted coordinate lists are `1…k`. Hence the printed triples form a valid
selection.

*If a valid selection exists.*  
By Lemma 3 `search` will find a solution, therefore the program prints “YES”.
If no valid selection exists, Lemma 4 shows that `search` cannot succeed,
so the program prints “NO”. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Let* `n = t` be the number of approved triples, `m = 3k ≤ 66` the number of
columns.

* Building the structure: `O(n)` nodes, each insertion is `O(1)`.  
* Each recursive level removes at least one column, depth ≤ `k ≤ 22`.  
* The total number of node operations performed by Algorithm X is bounded by
`O( n * k )` in the worst case, which for the maximal input (`n ≤ 10648`,
`k ≤ 22`) is far below the time limit (≈ 2·10⁵ operations).

Memory consumption: one node per 1 in the matrix → `3·n ≤ 3·10648 ≈ 32000`
nodes, each storing a few integers → well under the 256 MiB limit.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    triples = []
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        triples.append((x, y, z))

    # columns: 0..k-1 -> X, k..2k-1 -> Y, 2k..3k-1 -> Z
    col_cnt = 3 * k

    # dancing links arrays (0 is the master header)
    U = [0]   # up
    D = [0]   # down
    L = [0]   # left
    R = [0]   # right
    C = [0]   # column of node
    S = [0] * (col_cnt + 1)   # size of each column, index 0 unused

    # create column header nodes (1 .. col_cnt)
    for i in range(col_cnt):
        node = i + 1
        U.append(node)
        D.append(node)
        L.append(node - 1 if i > 0 else 0)
        R.append(node + 1 if i < col_cnt - 1 else 0)
        C.append(i + 1)   # column header points to itself (not used)
    # fix links of master header (0)
    L[0] = col_cnt
    R[0] = 1
    L[1] = 0
    R[col_cnt] = 0

    # store for each row the index of its first node (to retrieve later)
    row_first_node = []
    # mapping from node index to row index
    node_to_row = []

    # add rows
    for idx, (x, y, z) in enumerate(triples):
        cols = [x + 1, k + y + 1, 2 * k + z + 1]   # column numbers (1‑based)
        first = None
        prev = None
        for col in cols:
            node = len(U)
            U.append(U[col])
            D.append(col)
            L.append(0)
            R.append(0)
            C.append(col)
            # vertical links
            D[U[col]] = node
            U[col] = node
            S[col] += 1

            if first is None:
                first = node
            if prev is not None:
                # horizontal links
                R[prev] = node
                L[node] = prev
            prev = node
            node_to_row.append(idx)
        # close the row circle
        R[prev] = first
        L[first] = prev
        row_first_node.append(first)

    answer_rows = []
    solved = False

    def cover(col):
        # remove column header
        R[L[col]] = R[col]
        L[R[col]] = L[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        R[L[col]] = col
        L[R[col]] = col

    def search():
        nonlocal solved
        if R[0] == 0:          # all columns covered
            solved = True
            return True
        # choose column with minimal size
        c = R[0]
        min_s = S[c]
        col = c
        j = R[c]
        while j != 0:
            if S[j] < min_s:
                min_s = S[j]
                col = j
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(col)
        r = D[col]
        while r != col:
            answer_rows.append(node_to_row[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search():
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            answer_rows.pop()
            r = D[r]
        uncover(col)
        return False

    if search():
        out = ["YES"]
        for row_idx in answer_rows:
            x, y, z = triples[row_idx]
            out.append(f"{x+1} {y+1} {z+1}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
