<STATEMENT>
# Problem A — Signal Synchronization

Time limit: 5 s   Memory limit: 256 MB

## Description

A communication receiver needs to synchronize a multiplexed transmission. The transmission consists of exactly **k** discrete channels. Each channel is defined by a combination of three parameters: a frequency band, a modulation scheme, and a cryptographic key. The receiver supports exactly **k** distinct frequency bands, **k** distinct modulation schemes, and **k** distinct cryptographic keys. Each parameter is identified by an integer from 1 to **k**. The hardware capacity limits the number of channels **k** to at most the atomic number of Titanium.

Environmental noise means that only certain parameter combinations can be successfully decoded. The receiver's diagnostic system has logged **t** viable combinations. Each viable combination is recorded as a triplet `(x, y, z)`, indicating that frequency band **x**, modulation scheme **y**, and cryptographic key **z** can be synchronized together.

To establish a full connection, the receiver must select a subset of exactly **k** combinations from the logged list. This selected subset must satisfy a strict structural property: if you isolate the frequency bands of the **k** chosen combinations and sort them in ascending order, they must form the exact sequence 1, 2, ..., **k**. Similarly, if you isolate the modulation schemes of the chosen combinations and sort them in ascending order, they must also form the exact sequence 1, 2, ..., **k**. Finally, isolating and sorting the cryptographic keys of the chosen combinations must again yield the exact sequence 1, 2, ..., **k**.

Determine whether it is possible to select exactly **k** viable combinations that meet these synchronization requirements. If such a subset exists, provide it.

## Input

The first line contains two integers **k** and **t** (1 ≤ **k** ≤ atomic number of Titanium, 0 ≤ **t** ≤ **k**·**k**·**k**): the number of parameter options in each category and the total number of viable combinations logged. 
Each of the following **t** lines provides three integers **x**, **y**, **z** (1 ≤ **x**, **y**, **z** ≤ **k**), representing a viable combination of frequency band **x**, modulation scheme **y**, and cryptographic key **z**. All listed combinations are distinct.

## Output

If a valid subset of **k** combinations can be selected, print `YES` on the first line. Then, output **k** lines, each containing the three integers `x y z` of one selected combination. Any valid subset of **k** combinations that satisfies the sorting requirements is accepted; the chosen combinations may be printed in any order.

If no such subset is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both viable combinations use modulation scheme 1. If both are selected, their isolated modulation schemes sort to `1, 1`, which fails to form the required sequence `1, 2`. Thus, a valid subset of 2 combinations cannot be selected.
</STATEMENT>
<RATIONALE>
The explicit constraints preventing combinations from sharing components have been replaced by a mathematically equivalent sorting requirement. This prevents models from immediately mapping the problem to an exact cover template using keywords like "no two chosen" or "share the same". Furthermore, the upper bound of 22 has been replaced by the atomic number of Titanium to fulfill the indirect bounds strategy.
</RATIONALE>
<PRESERVED_ANSWER>
Requiring exactly k integers to sort to the sequence 1..k is mathematically identical to requiring that they are all distinct and drawn from 1..k, which perfectly preserves the mutual exclusivity constraints from the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains exactly 3-Dimensional Matching (Karp's 21 NP-complete problems), as we are still finding k disjoint triplets from three sets of size k.
</PRESERVED_CLASS>
<RISK>
Models might struggle to map "atomic number of Titanium" to 22 if they lack basic chemical knowledge, though this is highly unlikely for modern LLMs.
</RISK>
