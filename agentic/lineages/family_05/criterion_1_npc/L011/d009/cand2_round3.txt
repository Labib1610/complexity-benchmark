# Problem A — Calibration Matrices

Time limit: 5 s   Memory limit: 256 MB

## Description

A satellite communications array requires the setup of a stable transmission network. The system has a capacity limit of **k** channels.

The engineering team has certified exactly **t** approved configurations. Each approved configuration is given as a triplet `(x, y, z)`, representing a channel utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All values are integers between 1 and **k**. All listed configurations are distinct.

To finalize the network setup, you must select and deploy exactly **k** configurations from the approved list.

A deployed network is considered fully operational only if its resonance levels match the baseline threshold across all three parameter types. The resonance is calculated by evaluating the diversity of the components used. Specifically, if you select **k** configurations, the system's resonance levels are evaluated as follows:
- The frequency resonance is the total number of distinct frequency bands present among the **k** selected configurations.
- The modulation resonance is the total number of distinct modulation schemes present among the **k** selected configurations.
- The encryption resonance is the total number of distinct encryption keys present among the **k** selected configurations.

The baseline threshold for a system of capacity **k** is exactly **k**.

A valid deployment of **k** configurations must satisfy all three of the following conditions simultaneously:
1. Its frequency resonance exactly equals the baseline threshold.
2. Its modulation resonance exactly equals the baseline threshold.
3. Its encryption resonance exactly equals the baseline threshold.

Determine whether it is possible to deploy exactly **k** approved configurations that meet these criteria. If a valid set exists, provide it.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the capacity limit and the total number of approved configurations.
Each of the following **t** lines provides three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an approved configuration utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All listed configurations are distinct.

## Output

If a valid deployment of **k** configurations can be formed, print `YES` on the first line. Then, output **k** lines, each containing the three integers `x y z` of one selected configuration. Any valid deployment of **k** configurations is accepted; the chosen configurations may be printed in any order.

If no such deployment is possible, print `NO`.

## Examples

### Example 1

**Input**
```

2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```

1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the baseline threshold for capacity **k** = 2 is 2. If we select the only two available configurations, the frequency bands used are `1` and `2` (frequency resonance 2), but the modulation schemes used are `1` and `1`. The modulation resonance is the number of distinct modulation schemes, which is 1. This does not equal the baseline threshold of 2. Thus, a valid deployment is impossible.

I changed the power-of-2 sums to a direct requirement for counting the number of distinct values. The prompt suggested using the arithmetic sum (e.g. sum = k(k+1)/2), but that is mathematically flawed because multisets like {2, 2, 2} for k=3 also sum to 6, which would alter the valid outputs and violate Constraint 1. This distinct-value framing successfully removes the bitmask hint while preserving the exact logical conditions of the seed, forcing models to deduce the exact cover requirement without relying on binary arithmetic shortcuts.
</RATIONALE>
