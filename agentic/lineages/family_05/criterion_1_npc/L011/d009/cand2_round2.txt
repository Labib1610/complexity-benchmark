<METHOD_NAME>Distinct-Count Cardinality Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the power-of-two sum with a cardinality constraint: choosing k items and requiring exactly k distinct values for each coordinate uniquely forces a permutation (exact cover) without using combinatorial keywords, binary sums, or polynomials.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Calibration Matrices

Time limit: 5 s   Memory limit: 256 MB

## Description

A satellite communications array requires the setup of a stable transmission network. The system has a capacity limit of **k** channels. The capacity limit **k** is an integer that is at least 1 and never exceeds the total number of players on the pitch during a standard association football match (22).

The engineering team has certified exactly **t** approved configurations. This non-negative integer is at most the volume of a cube with edge length **k** (i.e., $k^3$). Each approved configuration is given as a triplet `(x, y, z)`, representing a channel utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All values are integers between 1 and **k**. All listed configurations are distinct.

To finalize the network setup, you must select and deploy exactly **k** configurations from the approved list.

A deployed network is considered fully operational only if it provides complete coverage across all parameter types without any redundancies. Specifically, a valid deployment of **k** configurations must satisfy all three of the following conditions simultaneously:
1. The **k** chosen configurations must feature exactly **k** distinct frequency bands.
2. The **k** chosen configurations must feature exactly **k** distinct modulation schemes.
3. The **k** chosen configurations must feature exactly **k** distinct encryption keys.

Determine whether it is possible to deploy exactly **k** approved configurations that meet these criteria. If a valid set exists, provide it.

## Input

The first line contains two integers **k** and **t**: the capacity limit and the total number of approved configurations.
Each of the following **t** lines provides three integers **x**, **y**, **z**, representing an approved configuration utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All listed configurations are distinct.

## Output

If a valid deployment of **k** configurations can be formed, print `YES` on the first line. Then, output **k** lines, each containing the three integers `x y z` of one selected configuration. Any valid deployment of **k** configurations is accepted; the chosen configurations may be printed in any order.

If no such deployment is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, if we select the only two available configurations, the chosen configurations would feature exactly two distinct frequency bands (1 and 2), but only one distinct modulation scheme (1). Because the number of distinct modulation schemes does not equal the required **k** = 2, a valid deployment is impossible.
</STATEMENT>
<RATIONALE>
The power-of-two sums were removed and replaced with a cardinality constraint: selecting exactly `k` configurations and requiring exactly `k` distinct values for each coordinate. This uniquely forces an exact cover without using algebraic giveaways or explicit subset terminology. The numeric bounds were moved from the Input section to the narrative description, forcing the model to extract and map them manually.
</RATIONALE>
<PRESERVED_ANSWER>
Choosing exactly `k` tuples with elements from `1` to `k` such that each coordinate has exactly `k` distinct values is only possible if every value is used exactly once, which perfectly matches the original exact cover requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains 3-Dimensional Matching (Exact Cover), as the requirement to select `k` non-overlapping triples from a given set is mathematically unchanged.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "feature exactly k distinct frequency bands" as a condition on the entire pool of `t` configurations rather than the `k` chosen ones, though the text explicitly says "The k chosen configurations must feature".
</RISK>
