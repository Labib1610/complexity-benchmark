<METHOD_NAME>Implicit Bijection via Set Cover</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced the explicit sorted-sequence permutation check with a requirement to collectively cover all available parameters using exactly k configurations. This forces the model to deduce the 1-to-1 mapping property itself. Without this deduction, models are likely to write a naive combination search over t choose k, which will time out, rather than an optimized backtracking search that assigns one configuration per frequency band.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Calibration Matrices

Time limit: 5 s   Memory limit: 256 MB

## Description

A satellite communications array requires the setup of a stable transmission network. The system has exactly **k** frequency bands, **k** modulation schemes, and **k** encryption keys available, each indexed from 1 to **k**. The hardware capacity limits **k** to at most 22.

Due to physical constraints, only specific combinations of parameters are viable. The engineering team has certified exactly **t** approved configurations. Each approved configuration is given as a triplet `(x, y, z)`, meaning frequency band **x**, modulation scheme **y**, and encryption key **z** can be successfully combined into a single transmission channel.

To finalize the network setup, you must deploy exactly **k** configurations from the approved list. A deployed network is considered fully operational only if no component is neglected. Thus, your chosen set of **k** configurations must collectively utilize all **k** frequency bands, all **k** modulation schemes, and all **k** encryption keys.

Determine whether it is possible to deploy exactly **k** approved configurations that satisfy this requirement. If a valid set exists, provide it.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of options in each parameter category and the total number of approved configurations.
Each of the following **t** lines provides three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an approved configuration utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All listed configurations are distinct.

## Output

If a valid deployment of **k** configurations can be formed, print `YES` on the first line. Then, output **k** lines, each containing the three integers `x y z` of one selected configuration. Any valid deployment of **k** configurations that meets the collective utilization requirement is accepted; the chosen configurations may be printed in any order.

If no such deployment is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both approved configurations use modulation scheme 1. If both are selected (which is the only way to choose exactly 2 configurations), they collectively fail to utilize modulation scheme 2. Therefore, a valid deployment is impossible.
</STATEMENT>
<RATIONALE>
Removed the explicit "extract and sort to get 1..k" rule, which immediately gave away the permutation/exact-cover structure. Replaced it with a "collectively utilize all components" requirement for exactly k configurations, which mathematically forces the same 1-to-1 mapping but requires the model to independently deduce that it must assign exactly one configuration per frequency band to avoid a combinatorial explosion.
</RATIONALE>
<PRESERVED_ANSWER>
Selecting exactly k triplets that collectively contain all k distinct values for each of the three coordinates is mathematically identical to selecting k triplets where each coordinate's extracted list sorts to 1..k, so the valid sets of configurations remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching (an NP-complete problem), as it still requires finding a perfect matching in a 3-partite hypergraph.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "collectively utilize" as allowing multiple configurations to share the same frequency band, but since exactly k configurations must be chosen to cover k items, the pigeonhole principle strictly enforces exactly one per item, leaving no true ambiguity.
</RISK>
