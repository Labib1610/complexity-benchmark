<METHOD_NAME>Implicit Perfect Matching via Set Cover</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit permutation/sorting requirement with a "full coverage" requirement. By asking to select k items that collectively cover all k options of each parameter, the exact-once property becomes an emergent mathematical consequence rather than a stated rule. Models that fail to deduce this will attempt general combinations or unpruned backtracking and TLE.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Calibration Matrices

Time limit: 5 s   Memory limit: 256 MB

## Description

A satellite communications array requires the calibration of exactly **k** transmission channels. Each channel configuration is composed of three parameters: a frequency band, a modulation scheme, and an encryption key. For each parameter category, the available options are indexed by integers from 1 to **k**. The hardware capacity limits the number of channels **k** to at most 22.

Due to signal interference, only specific combinations of parameters are viable. The engineering team has certified exactly **t** approved configurations. Each approved configuration is given as a triplet `(x, y, z)`, meaning frequency band **x**, modulation scheme **y**, and encryption key **z** can be successfully combined.

To finalize the calibration, your task is to activate a subset of exactly **k** configurations from the approved list. This subset must achieve full operational coverage, which is satisfied only when:
- Every frequency band from 1 to **k** is utilized by at least one configuration in your subset.
- Every modulation scheme from 1 to **k** is utilized by at least one configuration in your subset.
- Every encryption key from 1 to **k** is utilized by at least one configuration in your subset.

Determine whether it is possible to activate exactly **k** approved configurations that satisfy these coverage requirements. If a valid subset exists, provide it.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of options in each parameter category and the total number of approved configurations.
Each of the following **t** lines provides three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an approved configuration utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All listed configurations are distinct.

## Output

If a valid subset of **k** configurations can be formed, print `YES` on the first line. Then, output **k** lines, each containing the three integers `x y z` of one activated configuration. Any valid subset of **k** configurations that meets the coverage requirements is accepted; the chosen configurations may be printed in any order.

If no such subset is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both approved configurations use modulation scheme 1. If both are activated, the subset will only cover modulation scheme 1, leaving modulation scheme 2 unused. Because it fails to utilize every modulation scheme from 1 to 2, a valid subset of 2 configurations is impossible.
</STATEMENT>
<RATIONALE>
The explicit sorting/permutation rule was replaced with a "full coverage" requirement ("utilized by at least one"). Because exactly $k$ configurations must be chosen to cover $k$ options, the requirement mathematically forces exactly one of each option to be used, but models relying on surface translation will likely implement it as Set Cover. Without deducing the implicit exact-once property, they will fail to prune overlapping assignments early in their search and will Time Limit Exceed.
</RATIONALE>
<PRESERVED_ANSWER>
Selecting exactly $k$ configurations that collectively cover all $k$ options for each parameter is mathematically identical to selecting exactly $k$ configurations where each parameter option appears exactly once, preserving all valid subsets.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching (or Exact Cover with 3-sets), as the task still requires finding a perfect matching in a tripartite hypergraph.
</PRESERVED_CLASS>
