<STATEMENT>
# Problem A — Production Cycle

Time limit: 5 s   Memory limit: 256 MB

## Description

A manufacturing plant needs to finalize a production cycle consisting of exactly **k** distinct product variations. The assembly requires three distinct types of components: molds, dyes, and packaging lines. The plant has exactly **k** distinct molds, **k** distinct dyes, and **k** distinct packaging lines. Each component is identified by an index from 1 to **k**. The plant's physical capacity limits the number of variations **k** to at most 22.

Due to chemical and physical constraints, not all combinations of components are viable. The engineering team has certified exactly **t** approved configurations. Each approved configuration is given as a triplet `(x, y, z)`, meaning mold **x**, dye **y**, and packaging line **z** can be successfully combined to create a product.

To maximize efficiency and avoid cross-contamination, the plant manager must select exactly **k** configurations from the approved list to form the cycle. This selection must adhere to a strict exclusivity rule: no two chosen configurations can share the same mold, no two can share the same dye, and no two can share the same packaging line.

Determine whether it is possible to select exactly **k** approved configurations that satisfy these conditions. If a valid set exists, provide it.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of components in each category and the total number of approved configurations.
Each of the following **t** lines provides three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an approved configuration utilizing mold **x**, dye **y**, and packaging line **z**. All listed configurations are distinct.

## Output

If a valid selection of **k** configurations can be formed, print `YES` on the first line. Then, output **k** lines, each containing the three integers `x y z` of one selected configuration. Any valid selection of **k** configurations that meets the exclusivity rule is accepted; the chosen configurations may be printed in any order.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both approved configurations require dye 1, meaning they cannot both be chosen. Therefore, a selection of 2 configurations is impossible.
