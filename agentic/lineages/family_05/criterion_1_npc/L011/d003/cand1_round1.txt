<STATEMENT>
# Problem A — Factory Configurations

Time limit: 5 s   Memory limit: 256 MB

## Description

A manufacturing plant needs to execute a full production cycle. The plant utilizes three categories of resources: molds, dyes, and packagings. For a cycle of size **k**, the plant will process exactly **k** distinct molds, **k** distinct dyes, and **k** distinct packagings. Within each category, the resources are numbered from 1 to **k**.

The plant's automated assembly lines have been tested and approved for exactly **t** specific operational setups. Each approved setup is a triplet `(x, y, z)`, meaning that mold **x**, dye **y**, and packaging **z** can be successfully combined on a single assembly line. 

To execute a full production cycle, you must assign each of the **k** molds to a different dye, and then assign each of these **k** resulting pairs to a different packaging. This process constructs exactly **k** complete resource triplets, ensuring that every individual resource from all three categories is utilized exactly once across the cycle. The cycle is only valid if every single one of these **k** constructed triplets is present in the plant's list of approved setups.

Determine whether it is possible to design a full production cycle. If it is possible, provide the **k** valid triplets.

## Input

The first line contains two integers **k** and **t**. The cycle size **k** relies on the facility's capacity, which requires a minimum of one resource per category and maxes out at twenty-two resources per category. The number of approved setups **t** ranges from a minimum of zero up to the theoretical limit of all possible combinations of one mold, one dye, and one packaging.
Each of the following **t** lines contains three integers **x**, **y**, and **z** (representing valid resource indices starting at one and not exceeding the cycle size), describing an approved setup consisting of mold **x**, dye **y**, and packaging **z**. All listed setups are distinct.

## Output

If a full production cycle is possible, print `YES` on the first line. Then, print **k** lines, each containing the three integers `x y z` of one of the constructed triplets. Any valid arrangement of **k** triplets that achieves the required utilization and relies only on approved setups is accepted; the triplets may be printed in any order.

If no such cycle is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, any attempt to construct 2 triplets using all resources exactly once will require utilizing dye 1 in one triplet and dye 2 in the other. However, the only approved setups both require dye 1, so no valid cycle can be formed.
</STATEMENT>
<RATIONALE>
The description was inverted to remove the "select k non-overlapping items from a list" affordance. Instead of asking to find a valid subset within the provided list, the problem now asks the reader to conceptually generate a perfect combination of all resources and then verify if those generated triplets are a subset of the provided list. Models that blindly translate the generative instructions will produce an O((k!)^2) algorithm and fail on time limits; models that genuinely reason about the structure will deduce that this is mathematically identical to finding a 3D perfect matching within the list. Additionally, all explicit numeric bounds were replaced with textual capacity descriptions (Strategy S07).
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to construct exactly k triplets using every resource exactly once such that all triplets are in the valid list is mathematically identical to selecting exactly k non-overlapping triplets from the list.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching, which is an NP-complete problem.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "combinations of one mold, one dye, and one packaging" as something other than k*k*k, though in context it is the only logical maximum for t.
</RISK>
