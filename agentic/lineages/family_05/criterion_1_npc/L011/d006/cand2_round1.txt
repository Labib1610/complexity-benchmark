<STATEMENT>
# Problem A — Calibration Matrices

Time limit: 5 s   Memory limit: 256 MB

## Description

A satellite communications array requires the setup of a stable transmission network. The system has exactly **k** frequency bands, **k** modulation schemes, and **k** encryption keys available, each indexed from 1 to **k**. The hardware capacity limits **k** to at most 22.

Due to physical constraints, only specific combinations of parameters are viable. The engineering team has certified exactly **t** approved configurations. Each approved configuration is given as a triplet `(x, y, z)`, meaning frequency band **x**, modulation scheme **y**, and encryption key **z** can be successfully combined into a single transmission channel.

To finalize the network setup, you must deploy exactly **k** configurations from the approved list. For your chosen subset of **k** configurations, let $d_1$ be the number of distinct frequency bands used by these **k** configurations, $d_2$ be the number of distinct modulation schemes used, and $d_3$ be the number of distinct encryption keys used. The network achieves full spectrum redundancy if and only if the volume of the utilized parameter space, calculated as the product $d_1 \times d_2 \times d_3$, is exactly $k^3$.

Determine whether it is possible to deploy exactly **k** approved configurations that satisfy this requirement. If a valid set exists, provide it.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of options in each parameter category and the total number of approved configurations.
Each of the following **t** lines provides three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an approved configuration utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All listed configurations are distinct.

## Output

If a valid deployment of **k** configurations can be formed, print `YES` on the first line. Then, output **k** lines, each containing the three integers `x y z` of one selected configuration. Any valid deployment of **k** configurations that meets the volume requirement is accepted; the chosen configurations may be printed in any order.

If no such deployment is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both approved configurations use modulation scheme 1. If both are selected (which is the only way to choose exactly 2 configurations), the number of distinct frequency bands is 2, the number of distinct modulation schemes is 1, and the number of distinct encryption keys is 2. The volume of the utilized parameter space is $2 \times 1 \times 2 = 4$, which is not equal to $2^3 = 8$. Therefore, a valid deployment is impossible.
</STATEMENT>
<RATIONALE>
Removed the explicit instruction to "collectively utilize all k" components across the three categories. Instead, the coverage requirement is presented as an algebraic constraint where the product of the counts of distinct elements used must equal $k^3$. Because there are only $k$ possible values in each category, this product can only reach $k^3$ if every element is used exactly once. Models must perform this deductive reasoning step to realize they can prune the search space heavily; otherwise, they will attempt an unpruned combination search and time out.
</RATIONALE>
<PRESERVED_ANSWER>
The maximum possible number of distinct elements in any category is $k$, so the product $d_1 \times d_2 \times d_3$ equals $k^3$ if and only if $d_1=k$, $d_2=k$, and $d_3=k$, which strictly enforces the original exact-cover condition.
</PRESERVED_ANSWER>

The underlying mathematical task remains exactly 3-Dimensional Matching, requiring the selection of $k$ disjoint triplets from a given set.
</PRESERVED_CLASS>
