<STATEMENT>
# Problem A — Calibration Matrices

Time limit: 5 s   Memory limit: 256 MB

## Description

A satellite communications array requires the setup of a stable transmission network. The system has **k** frequency bands, **k** modulation schemes, and **k** encryption keys available, each indexed from 1 to **k**. The hardware capacity limits **k** to at most 22.

Due to physical constraints, only specific combinations of parameters are viable. The engineering team has certified exactly **t** approved configurations. Each approved configuration is given as a triplet `(x, y, z)`, representing a channel utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All listed configurations are distinct.

To finalize the network setup, you must deploy exactly **k** configurations from the approved list. A deployed network is considered fully operational only if it avoids any cross-channel interference. We define two configurations as *perfectly isolated* if they do not share any parameter—that is, they must have different frequency bands, different modulation schemes, and different encryption keys.

Determine whether it is possible to deploy exactly **k** approved configurations such that every pair of distinct configurations in your chosen set is perfectly isolated. If a valid set exists, provide it.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of options in each parameter category and the total number of approved configurations.
Each of the following **t** lines provides three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an approved configuration utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All listed configurations are distinct.

## Output

If a valid deployment of **k** configurations can be formed, print `YES` on the first line. Then, output **k** lines, each containing the three integers `x y z` of one selected configuration. Any valid deployment of **k** perfectly isolated configurations is accepted; the chosen configurations may be printed in any order.

If no such deployment is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the two approved configurations share modulation scheme 1. Therefore, they are not perfectly isolated from each other. Since you must select exactly 2 configurations, and the only available pair is not isolated, a valid deployment is impossible.

<RATIONALE>
I removed the explicit requirement to "collectively utilize all k" elements. Instead, the problem now requires selecting exactly k configurations such that no two share any parameter. This forces the model to deduce that selecting k pairwise-disjoint configurations from a domain of k elements implies an exact cover, rather than having the exact cover property handed to it in the text.
</RATIONALE>
<PRESERVED_ANSWER>
Selecting exactly k configurations from a domain of k possible values per category such that no two share any parameter mathematically requires that every parameter value is used exactly once, which is identical to the original exact cover requirement.
</PRESERVED_ANSWER>

The problem remains 3-Dimensional Matching (NP-complete), as it still asks to find a subset of size k from a set of 3-tuples such that no two tuples agree in any coordinate.
</PRESERVED_CLASS>
