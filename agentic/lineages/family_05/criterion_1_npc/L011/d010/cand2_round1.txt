<METHOD_NAME>Tripartite Cycle-Cover Matrix Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the three independent Vandermonde matrices with a single 3k x 3k matrix B. For each chosen configuration (x, y, z), we add 1 to B at (x, k+y), (k+y, 2k+z), and (2k+z, x). The determinant of B is non-zero if and only if x, y, and z are all permutations of 1..k. If any is not a permutation, some row remains all zeros (det=0). If they are permutations, B becomes a permutation matrix (det=\pm 1). This forces the model to reason about global matrix sparsity and cycle covers rather than applying row-wise identical-element logic.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Calibration Matrices

Time limit: 5 s   Memory limit: 256 MB

## Description

A satellite communications array requires the setup of a stable transmission network. The system has a capacity limit of **k** channels (where **k** is at most 22).

The engineering team has certified exactly **t** approved configurations. Each approved configuration is given as a triplet `(x, y, z)`, representing a channel utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All values are integers between 1 and **k**. All listed configurations are distinct.

To finalize the network setup, you must select and deploy exactly **k** configurations from the approved list.

A deployed network is considered fully operational only if its unified routing matrix is non-singular. Specifically, you must construct a $3k \times 3k$ matrix $B$, initially filled entirely with zeros. For each of the **k** chosen configurations, let its parameters be $x$, $y$, and $z$. You must add 1 to the following three entries in $B$ (using 1-based indexing for rows and columns):
- Row $x$, Column $k + y$
- Row $k + y$, Column $2k + z$
- Row $2k + z$, Column $x$

After processing all **k** selected configurations, the network is considered stable if and only if the determinant of $B$ is non-zero.

Determine whether it is possible to deploy exactly **k** approved configurations such that the matrix $B$ has a non-zero determinant. If a valid set exists, provide it.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the capacity limit and the total number of approved configurations.
Each of the following **t** lines provides three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an approved configuration utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All listed configurations are distinct.

## Output

If a valid deployment of **k** configurations can be formed, print `YES` on the first line. Then, output **k** lines, each containing the three integers `x y z` of one selected configuration. Any valid deployment of **k** configurations is accepted; the chosen configurations may be printed in any order.

If no such deployment is possible, print `NO`.

## Examples

### Example 1

**Input**

```
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```

```

**Output**
```

```

### Example 3

**Input**
```

```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, if we select the only two available configurations, we process `(1, 1, 1)` and `(2, 1, 2)`.
For `(1, 1, 1)`, we add 1 to $B_{1, 3}$, $B_{3, 5}$, and $B_{5, 1}$.
For `(2, 1, 2)`, we add 1 to $B_{2, 3}$, $B_{3, 6}$, and $B_{6, 2}$.
Row 4 of the $6 \times 6$ matrix $B$ corresponds to the modulation scheme value 2 (since $k+y = 2+2 = 4$). However, neither configuration has $y = 2$, so no additions are ever made to Row 4. Because Row 4 consists entirely of zeros, the determinant of $B$ is 0. A valid deployment requires the determinant to be non-zero, so this deployment is impossible.

<RATIONALE>
I replaced the three independent Vandermonde matrices with a single 3k x 3k tripartite adjacency matrix. This forces the model to reason about global matrix sparsity and cycle covers (realizing that a non-zero determinant requires exactly one addition per row, meaning each coordinate must be a permutation) rather than relying on the isolated identical-row logic of polynomial basis matrices.
</RATIONALE>

The determinant of the 3k x 3k matrix B is non-zero if and only if x, y, and z are all permutations of 1..k, which is exactly the same mathematical requirement as the original Vandermonde matrices.
</PRESERVED_ANSWER>
