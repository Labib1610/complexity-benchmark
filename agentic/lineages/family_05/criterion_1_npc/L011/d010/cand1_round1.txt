<METHOD_NAME>Common Divisor Matrix Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit monomial evaluation matrix (Vandermonde) with a matrix where entry (i,j) is the number of common positive divisors of x_i and j. This matrix is a row permutation of a known non-singular matrix (D = A A^T where A is the divisor matrix, giving det(D)=1), so its determinant is non-zero if and only if all x_i are distinct. This completely removes the polynomial/Vandermonde affordance while preserving the exact mathematical condition.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Calibration Matrices

Time limit: 5 s   Memory limit: 256 MB

## Description

A satellite communications array requires the setup of a stable transmission network. The system has a capacity limit of **k** channels (where **k** is at most 22).

The engineering team has certified exactly **t** approved configurations. Each approved configuration is given as a triplet `(x, y, z)`, representing a channel utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All values are integers between 1 and **k**. All listed configurations are distinct.

To finalize the network setup, you must select and deploy exactly **k** configurations from the approved list.

A deployed network is considered fully operational only if its parameter matrices are non-singular. Specifically, if you select **k** configurations, let $x_1, x_2, \dots, x_k$ be their frequency bands. You must construct a $k \times k$ matrix $F$ where the entry in the $i$-th row and $j$-th column is the number of common positive divisors of $x_i$ and $j$ (using 1-based indexing for rows and columns). The frequency bands are considered stable if and only if the determinant of $F$ is non-zero.

The exact same stability requirement applies independently to the modulation schemes and the encryption keys. You must construct a $k \times k$ matrix $M$ from the modulation schemes $y_1, y_2, \dots, y_k$ (where $M_{i,j}$ is the number of common positive divisors of $y_i$ and $j$) and a $k \times k$ matrix $E$ from the encryption keys $z_1, z_2, \dots, z_k$ (where $E_{i,j}$ is the number of common positive divisors of $z_i$ and $j$). The determinants of $M$ and $E$ must also be non-zero.

Determine whether it is possible to deploy exactly **k** approved configurations such that the matrices $F$, $M$, and $E$ all have non-zero determinants. If a valid set exists, provide it.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the capacity limit and the total number of approved configurations.
Each of the following **t** lines provides three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing an approved configuration utilizing frequency band **x**, modulation scheme **y**, and encryption key **z**. All listed configurations are distinct.

## Output

If a valid deployment of **k** configurations can be formed, print `YES` on the first line. Then, output **k** lines, each containing the three integers `x y z` of one selected configuration. Any valid deployment of **k** configurations is accepted; the chosen configurations may be printed in any order.

If no such deployment is possible, print `NO`.

## Examples

**Input**


**Output**
```
YES

```

### Example 2


**Output**

```

```


## Note

In Example 2, if we select the only two available configurations, their modulation schemes are $y_1 = 1$ and $y_2 = 1$. The corresponding $2 \times 2$ matrix $M$ will have two identical rows, `[1, 1]` and `[1, 1]`. The determinant of this matrix is 0. Because a valid deployment requires the determinant to be non-zero, this deployment is impossible.
</STATEMENT>
<RATIONALE>
The explicit Vandermonde matrix (using powers of entries) was replaced with a matrix based on the count of common positive divisors. Mathematically, the $k \times k$ matrix where entry $(i,j)$ is the number of common divisors of $i$ and $j$ has a determinant of exactly 1, meaning it is non-singular. Consequently, the constructed matrix has a non-zero determinant if and only if the chosen values are all distinct, perfectly preserving the exact cover / 3D matching requirement while completely removing the polynomial and Vandermonde affordances. Models must now genuinely reason about the properties of this specific matrix to deduce that duplicates cause a determinant of zero and distinct values guarantee a non-zero determinant.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the common divisor matrix is non-zero if and only if all selected values for a coordinate are distinct, which is exactly equivalent to the Vandermonde condition in the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to selecting k non-overlapping triplets (3-Dimensional Matching), preserving its NP-complete status.
</PRESERVED_CLASS>
