# Problem A — Blueprint Integration

Time limit: 5 s   Memory limit: 256 MB

## Description

An engineering firm is assembling complex systems. There are three categories of modules required: primary, secondary, and tertiary. The firm has an inventory consisting of exactly **k** primary modules, **k** secondary modules, and **k** tertiary modules. Within each category, the modules are assigned unique identification numbers from 1 to **k**.

The assembly process requires forming exactly **k** complete systems. A complete system consists of exactly one primary module, one secondary module, and one tertiary module. 

Not all modules can interface with one another safely. You are provided with a catalog of **t** certified integration blueprints. Each blueprint is represented by a sequence `(x, y, z)`, which guarantees that primary module **x**, secondary module **y**, and tertiary module **z** can be successfully assembled together. All blueprints in the catalog are distinct.

Your objective is to determine if it is possible to select exactly **k** blueprints from the catalog to guide the assembly of **k** systems, under the strict condition that there is absolutely no module reuse. Every primary module, every secondary module, and every tertiary module in the inventory must be incorporated into exactly one assembled system.

If such a comprehensive assembly plan is possible, you must output the selected blueprints.

## Input

The first line contains two integers **k** and **t**. The batch size **k** is at least the minimum operational requirement of 1 and at most the facility's maximum capacity of 22 bays. The blueprint count **t** can be as small as 0 and as large as the total theoretical limit of **k**·**k**·**k**.
Each of the next **t** lines contains three integers **x**, **y**, and **z**. Each identifier **x**, **y**, and **z** is guaranteed to be at least 1 and at most **k**. These three integers represent a certified blueprint combining primary module **x**, secondary module **y**, and tertiary module **z**. All listed blueprints are distinct.

## Output

If a valid selection of exactly **k** blueprints exists that utilizes every single primary, secondary, and tertiary module exactly once, print `YES` on the first line. Then, print **k** lines, each containing the three integers `x y z` of one selected blueprint. Any valid set of blueprints that achieves this perfect, non-overlapping utilization is accepted; the chosen blueprints may be printed in any order.

If no such complete assembly plan is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both certified blueprints require secondary module 1, which means secondary module 2 can never be utilized, making a complete assembly impossible.

To apply strategy S07, the explicit mathematical inequalities for the bounds were replaced with textual descriptions tied to the physical limits of the facility (e.g., minimum requirement of 1, maximum capacity of 22 bays). This forces the model to carefully read and extract the bounds from the prose rather than relying on standard inequality notation, while preserving the exact numerical limits needed for the input contract.
</RATIONALE>
