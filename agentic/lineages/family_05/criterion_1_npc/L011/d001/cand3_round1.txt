# Problem A — Resonant Hyperspace

Time limit: 5 s   Memory limit: 256 MB

## Description

A starfleet must execute a sequence of exactly **k** hyperspace jumps. Each jump requires the precise synchronization of three independent navigational parameters: a pulsar frequency, a gravimetric distortion, and a subspace harmonic. The fleet's instruments can generate exactly **k** distinct pulsar frequencies, **k** distinct gravimetric distortions, and **k** distinct subspace harmonics. All parameters are indexed from 1 to **k**.

Not all parameter combinations are safe for travel. The navigational computer has identified exactly **t** stable synchronization vectors. Each vector `(x, y, z)` indicates that pulsar frequency **x**, gravimetric distortion **y**, and subspace harmonic **z** can be safely synchronized into a single jump.

To prevent a catastrophic resonant collapse of the local space-time, the fleet must execute exactly **k** jumps such that no parameter is ever reused. Over the course of the **k** jumps, every single pulsar frequency must be utilized exactly once, every gravimetric distortion exactly once, and every subspace harmonic exactly once.

Determine whether it is possible to select exactly **k** stable vectors from the computer's list that satisfy these strict non-repetition constraints. If such a selection exists, provide one valid set of vectors.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the number of each type of navigational parameter and the total number of stable synchronization vectors.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing a stable vector consisting of pulsar frequency **x**, gravimetric distortion **y**, and subspace harmonic **z**. All listed vectors are distinct.

## Output

If a safe sequence of **k** jumps is possible, print `YES` on the first line. Then, print **k** lines, each containing the three integers `x y z` of one selected vector. Any valid selection that perfectly utilizes all parameters exactly once is accepted; the chosen vectors may be printed in any order.

If no such sequence is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both stable vectors require gravimetric distortion 1, meaning gravimetric distortion 2 can never be utilized.
