# Problem A — Signal Routing

Time limit: 5 s   Memory limit: 256 MB

## Description

A communications relay has a symmetrical architecture: exactly **k** input channels, **k** frequency bands, and **k** transmission antennas. All resources are numbered starting from 1 up to **k**. The relay must establish exactly **k** independent communication links. Each link combines exactly one input channel, one frequency band, and one transmission antenna.

To prevent interference, the system has already analyzed all configurations. You are given a list of **t** verified link profiles. Each profile `(x, y, z)` indicates that input channel **x**, frequency band **y**, and transmission antenna **z** can operate together without signal degradation.

Your task is to finalize the routing. You must select exactly **k** profiles from the list such that there are no resource conflicts. Specifically, every single input channel must be utilized exactly once, every frequency band utilized exactly once, and every transmission antenna utilized exactly once.

Determine whether such a perfectly balanced, non-overlapping selection can be extracted from the provided list, and if so, report one valid configuration.

## Input

The first line contains two integers **k** and **t**. The size of each resource pool **k** is at least 1 and is strictly constrained by the physical limit of the legacy routing bus, which supports a maximum of 22 concurrent operations. The number of verified profiles **t** is non-negative and will not exceed the total number of all possible combinations of one input channel, one frequency band, and one transmission antenna.
Each of the next **t** lines contains three integers **x**, **y**, **z** (all ranging from 1 to **k**), representing a verified profile consisting of input channel **x**, frequency band **y**, and transmission antenna **z**. All listed profiles are guaranteed to be distinct.

## Output

If a valid configuration of **k** links exists, print `YES` on the first line. Then, print **k** lines, each containing the three integers `x y z` of one selected profile. Any valid selection that perfectly utilizes all resources exactly once is accepted; the chosen profiles may be printed in any order.

If no such configuration is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both verified profiles require frequency band 1, meaning frequency band 2 is never utilized in any valid link, so a complete selection is impossible.

<RATIONALE>
I replaced the explicit mathematical inequality bounds with descriptive text defining the physical limits of the system (e.g., maximum of 22 concurrent operations). This forces the model to extract the constraints from natural language rather than relying on standard regex-friendly inequality syntax, testing whether it recognizes that the small upper bound on `k` permits an exponential-time backtracking approach. I also removed a previously flagged structural word (`cover`) and rephrased the constraints strictly in terms of utilizing each resource exactly once.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to select exactly `k` triplets such that every integer from 1 to `k` appears exactly once in each coordinate position is mathematically identical to the original problem, ensuring all valid configurations and outputs remain the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core task is still selecting exactly `k` disjoint triplets from a provided set to perfectly align three dimensions, which is exactly the NP-complete 3-Dimensional Matching problem.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "total number of all possible combinations" as something other than `k^3`, though `k^3` is the standard mathematical interpretation for combining one item from each of three sets of size `k`.
</RISK>
