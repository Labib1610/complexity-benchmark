# Problem A — Drone Assembly Protocol

Time limit: 5 s   Memory limit: 256 MB

## Description

An automated manufacturing plant is tasked with producing a fleet of drones. The production quota requires exactly **k** completed units. The plant's inventory holds exactly **k** components for each of three necessary systems:

- **k** core frames (numbered 1 to k)
- **k** guidance computers (numbered 1 to k)
- **k** optical arrays (numbered 1 to k)

Each completed drone requires one core frame, one guidance computer, and one optical array. Because of differing power voltage requirements and data interface standards, only specific triplets of these three parts can be successfully wired together. You will receive a full manifest of all compatible triplets `(c, n, i)`.

Your objective is to design a comprehensive production schedule that consumes every available component. You must select exactly **k** compatible triplets from the manifest so that every core frame, guidance computer, and optical array is used exactly once, leaving zero leftover parts and ensuring no part is double-booked.

Determine whether such a complete production schedule can be formed, and output the selected triplets if it is achievable.

*Note on test data:* The manifest entries are intentionally sequenced to exploit rigid evaluation strategies. The official evaluation suite features highly intertwined configurations. If a proposed schedule resolves core frames in a strict numerical sequence (1 through k) while evaluating compatible triplets exactly in the order they appear in the input, it will be forced to exhaustively traverse an immense number of dead-end combinations that only reveal their flaws at the final assignments.

## Input

The first line provides two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k), where **k** is the quantity of components per system, and **t** is the total number of compatible triplets in the manifest.
The following **t** lines each provide three integers **c**, **n**, and **i** (1 ≤ c, n, i ≤ k), detailing a compatible triplet consisting of core frame **c**, guidance computer **n**, and optical array **i**. The manifest contains no duplicate triplets.

## Output

If a complete production schedule of **k** drones is achievable, output `YES` on the first line. Following this, output **k** lines, each displaying the three integers `c n i` of a selected triplet. Any valid schedule that incorporates every core frame, guidance computer, and optical array exactly once is acceptable. The selected triplets may be printed in any sequence.

If no such production schedule can be formed, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both compatible triplets demand guidance computer 1. As a result, guidance computer 2 remains permanently unused, rendering a complete production schedule impossible.
