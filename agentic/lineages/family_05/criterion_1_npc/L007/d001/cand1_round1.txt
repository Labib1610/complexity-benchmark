# Problem A — Synthetic Organism Protocol

Time limit: 5 s   Memory limit: 256 MB

## Description

A research facility is scheduling a synthetic biology run. The process demands exactly **k** concurrent assemblies. The facility has prepped three sets of components, each containing exactly **k** items:
- **k** bio-catalysts (indexed sequentially starting from 1)
- **k** nutrient bases (indexed sequentially starting from 1)
- **k** incubation cycles (indexed sequentially starting from 1)

A single assembly consumes exactly one bio-catalyst, one nutrient base, and one incubation cycle. Due to complex biochemical dependencies, only specific combinations of these three components will successfully react. You are provided with a catalog of all viable component combinations `(c, n, i)`.

To ensure the integrity of the experimental data, the overall run must utilize every single bio-catalyst, every nutrient base, and every incubation cycle in exactly one assembly. This means you must select exactly **k** viable combinations from the catalog such that no component from any category is left unused or used more than once.

Determine whether it is possible to formulate a valid run, and if so, report the combinations to be used. Be aware that the catalog may be ordered adversarially. Official evaluation data includes dense configurations specifically designed to produce many partial schedules that only reveal their invalidity near the final bio-catalyst assignment.

## Input

The first line contains two integers **k** and **t**. The number of concurrent assemblies **k** is a positive integer that cannot exceed the 22 available chambers in the master sequencer. The number of known viable assemblies **t** is a non-negative integer bounded by the absolute maximum number of ways to form a combination from the three sets of **k** items.

Each of the following **t** lines contains three integers **c**, **n**, **i**. These are positive integers that do not exceed **k**, representing a viable assembly of bio-catalyst **c**, nutrient base **n**, and incubation cycle **i**. No combination is listed more than once in the catalog.

## Output

If a valid run of **k** assemblies exists, print `YES` on the first line. Then, print **k** lines, each containing the three integers `c n i` of a chosen combination. Any selection that uses every bio-catalyst, nutrient base, and incubation cycle exactly once will be accepted. You may print the chosen combinations in any order.

If no valid run exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both viable combinations require nutrient base 1. Consequently, nutrient base 2 can never be utilized, making a valid run impossible.
