# Problem A — Temporal Harmonization

Time limit: 5 s   Memory limit: 256 MB

## Description

You are configuring a chronal engine requiring exactly $k$ temporal stabilizers. You are given a catalog of $t$ candidate stabilizers to choose from.

Each stabilizer operates independently across three distinct frequency spectra: Alpha, Beta, and Gamma. A candidate stabilizer is defined by a triplet of positive integers $(a, b, c)$, representing its focal points in these three spectra.

When a stabilizer with Alpha focal point $a$ is activated, it completely stabilizes the Alpha frequency spectrum over the continuous mathematical interval $[a-1, a]$. 
Similarly, its Beta focal point $b$ stabilizes the Beta spectrum over the interval $[b-1, b]$, and its Gamma focal point $c$ stabilizes the Gamma spectrum over $[c-1, c]$.

When multiple stabilizers are activated, the overall stabilized region for a given spectrum is the mathematical union of the intervals covered by each individual stabilizer. The "coverage length" of a spectrum is the total continuous length of this combined region. For example, if two chosen stabilizers have Alpha focal points 2 and 3, they cover $[1, 2]$ and $[2, 3]$. Their union is exactly the interval $[1, 3]$, which has a coverage length of 2. If both stabilizers have an Alpha focal point of 2, their union is simply $[1, 2]$, which has a coverage length of 1.

To achieve temporal harmonization, you must select exactly $k$ stabilizers from the catalog such that:
- The coverage length of the stabilized Alpha spectrum across all $k$ chosen stabilizers is exactly $k$.
- The coverage length of the stabilized Beta spectrum across all $k$ chosen stabilizers is exactly $k$.
- The coverage length of the stabilized Gamma spectrum across all $k$ chosen stabilizers is exactly $k$.

Determine whether it is possible to select exactly $k$ valid stabilizers from the catalog. If it is, output the $k$ chosen stabilizers.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the required number of stabilizers and the total number of candidates in the catalog. 

The next $t$ lines each contain three integers $a$, $b$, and $c$, detailing a candidate stabilizer. Each focal point is a positive integer that does not exceed $k$ ($1 \le a, b, c \le k$). No stabilizer appears more than once in the catalog.

## Output

If a valid selection of exactly $k$ stabilizers is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $a$ $b$ $c$ of a chosen stabilizer. The chosen stabilizers can be printed in any order. Any valid selection will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the two candidate stabilizers are $(1, 1, 1)$ and $(2, 1, 2)$. If we select both of them ($k=2$), the overall stabilized regions are:
- Alpha spectrum: The union of $[0, 1]$ and $[1, 2]$ is $[0, 2]$. The coverage length is 2.
- Beta spectrum: The union of $[0, 1]$ and $[0, 1]$ is $[0, 1]$. The coverage length is 1.
- Gamma spectrum: The union of $[0, 1]$ and $[1, 2]$ is $[0, 2]$. The coverage length is 2.

The required coverage length for each of the three spectra is $k = 2$. Because the stabilized Beta spectrum only has a coverage length of 1 rather than 2, this selection is invalid. It is impossible to select 2 stabilizers that satisfy the requirement.
