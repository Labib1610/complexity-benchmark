**Solution Explanation**

For every relay we are given three numbers  

```
a – primary channel   ( 1 … k )
b – secondary channel ( 1 … k )
c – tertiary channel  ( 1 … k )
```

For a set `S` of exactly `k` relays we build three `k × k` matrices.
In the *primary* matrix the `i`‑th row contains a single `1` in column `a_i`
(the primary number of the `i`‑th relay), all other entries are `0`.
The same is done for the secondary and the tertiary numbers.

A matrix of that shape has a non‑zero determinant **iff**
every column also contains exactly one `1`.  
Consequently a set `S` is valid **iff**

* the `a`‑values of the `k` relays are a permutation of `1 … k`,
* the `b`‑values are a permutation of `1 … k`,
* the `c`‑values are a permutation of `1 … k`.

So we have to choose `k` triples such that each value `1 … k`
appears **once** in each coordinate.
If we view the three coordinate sets as three disjoint parts

```
A = {1,…,k}   (primary)
B = {1,…,k}   (secondary)
C = {1,…,k}   (tertiary)
```

every triple `(a,b,c)` is a hyper‑edge connecting one vertex of each part.
The task is to find a *perfect 3‑dimensional matching* – a set of `k`
hyper‑edges covering every vertex exactly once.

`k ≤ 22`, therefore the whole problem can be solved as an **exact cover**
instance with at most `3·k ≤ 66` columns and at most `k³ ≤ 10648` rows.
Algorithm X (Dancing Links) solves exact cover very fast for these sizes.



--------------------------------------------------------------------

#### 1.   Exact cover formulation
*Columns* (constraints)

```
0 … k-1          – “primary value i+1 is used”
k … 2k-1         – “secondary value i-k+1 is used”
2k … 3k-1        – “tertiary value i-2k+1 is used”
```

*Rows* (candidates) – for a triple `(a,b,c)` we create a row covering the
three columns

```
a-1 , k+(b-1) , 2k+(c-1)
```

A solution of the exact cover problem is a set of rows that covers every
column exactly once, i.e. a required set of `k` relays.



--------------------------------------------------------------------

#### 2.   Dancing Links (Algorithm X)

The data structure consists of four doubly linked lists:

* one circular list of column headers,
* for each column a vertical list of the rows that contain this column,
* for each row a horizontal circular list of its three nodes.

All operations are `O(1)` :

```
cover(col)   – removes a column and all rows that contain it
uncover(col) – restores them
```

The recursive search:

```
search()
    if no column left → all constraints satisfied → success
    choose column with the smallest number of rows   (heuristic)
    cover(chosen column)
    for each row r in this column
        add r to the partial solution
        for each other column c' of r   cover(c')
        if search() succeeds → propagate success
        undo the coverings of r
    uncover(chosen column)
    return failure
```

Because each row covers exactly three columns, a successful cover always
contains exactly `k` rows – the required number of relays.



--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct set of relays
iff such a set exists.

---

##### Lemma 1  
For a set of `k` triples the three matrices are non‑singular
iff each of the three coordinate multisets is a permutation of `1 … k`.

**Proof.**  
Each row of a matrix contains exactly one `1`.  
If a column contains `0` or more than `1` ones, two rows are equal in that
column, therefore the rows are linearly dependent and the determinant is `0`.  
If every column contains exactly one `1`, the matrix is a permutation matrix,
its determinant is `±1 ≠ 0`. ∎



##### Lemma 2  
A set of `k` triples satisfies Lemma&nbsp;1  
iff the corresponding rows form an exact cover of the `3k` columns.

**Proof.**  
The three columns belonging to a triple are exactly the three constraints
“primary = a”, “secondary = b”, “tertiary = c”.  
Covering each column once means that each value `1 … k` appears once in each
coordinate, i.e. the three multisets are permutations. ∎



##### Lemma 3  
During the execution of `search` the set of already chosen rows always
covers a subset of columns exactly once and never covers a column twice.

**Proof.**  
`cover(col)` removes `col` and *all* rows that contain `col`.  
Therefore after a column is covered, no later chosen row can contain it.
When a row is selected, all its other columns are covered as well,
so the invariant holds inductively. ∎



##### Lemma 4  
If `search` reaches the state “no column left”, the rows stored in the
solution list form a perfect 3‑dimensional matching (a valid relay set).

**Proof.**  
No column left means every of the `3k` constraints is covered exactly once.
By Lemma&nbsp;2 the selected rows satisfy Lemma&nbsp;1, i.e. each coordinate
is a permutation. The number of selected rows is `k` because each row covers
three columns and there are `3k` columns. ∎



##### Lemma 5  
If a perfect matching exists, `search` will eventually find it.

**Proof.**  
Consider any perfect matching `M`.  
At the first recursive level `search` chooses a column `c`.  
`c` belongs to some row `r` of `M` (otherwise `M` would not cover `c`).  
`r` is among the rows iterated in the `for` loop, therefore the branch that
selects `r` is explored.  
After covering `r` the remaining uncovered columns are exactly those covered
by `M \ {r}`; the same argument applies recursively.
Thus the recursion can follow the whole matching and reaches a leaf where
all columns are covered, which is accepted by Lemma&nbsp;4. ∎



##### Lemma 6  
If `search` reports failure, no perfect matching exists.

**Proof.**  
Assume a perfect matching existed.
By Lemma&nbsp;5 the recursive search would have a branch that follows this
matching and would succeed, contradicting the reported failure. ∎



##### Theorem  
The program outputs  

* “YES” and a list of `k` relays **iff** such a list exists,
* otherwise outputs “NO”.

**Proof.**  

*If the program prints “YES”.*  
It printed the rows stored by `search`.  
By Lemma&nbsp;4 these rows form a perfect matching, therefore the printed
triples satisfy Lemma&nbsp;1 and are a valid selection.

*If a valid selection exists.*  
By Lemma&nbsp;1 it corresponds to a perfect matching, i.e. an exact cover.
By Lemma&nbsp;5 `search` finds one, the program prints “YES”.

*If the program prints “NO”.*  
`search` returned failure, therefore by Lemma&nbsp;6 no perfect matching (no
valid selection) exists. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

```
columns          : 3·k ≤ 66
rows (candidates): t ≤ k³ ≤ 10648
nodes            : 3·t + columns ≤ 31950
```

All operations on the dancing‑links structure are `O(1)`.  
The algorithm explores only a tiny fraction of the exponential search tree;
in the worst case it may try all possibilities, i.e. `O( (t choose k) )`,
but with `k ≤ 22` and the strong column‑size heuristic this easily fits
into the 5 seconds limit.  
Memory consumption is `O(nodes) ≤ 32 KB` (well below the limit).

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        c = int(next(it))
        triples.append((a, b, c))

    ncol = 3 * k                     # total columns
    max_nodes = t * 3 + ncol + 1    # header + column headers + all nodes

    # dancing‑links arrays
    left = [0] * max_nodes
    right = [0] * max_nodes
    up = [0] * max_nodes
    down = [0] * max_nodes
    col = [0] * max_nodes           # column of a node
    row_of_node = [0] * max_nodes   # which input row a node belongs to
    size = [0] * (ncol + 1)         # number of rows in each column

    # header (0) linked with column headers 1..ncol
    right[0] = 1 if ncol else 0
    left[0] = ncol if ncol else 0
    for i in range(1, ncol + 1):
        left[i] = i - 1
        right[i] = i + 1 if i < ncol else 0
        up[i] = down[i] = i
        size[i] = 0

    node_id = ncol + 1               # first free node index

    for idx, (a, b, c) in enumerate(triples):
        cols = [a, k + b, 2 * k + c]   # 1‑based column numbers
        first = -1
        prev = -1
        for cc in cols:
            nd = node_id
            node_id += 1
            col[nd] = cc
            row_of_node[nd] = idx

            # vertical links (insert just above column header)
            up[nd] = up[cc]
            down[nd] = cc
            down[up[cc]] = nd
            up[cc] = nd
            size[cc] += 1

            # horizontal links inside the row
            if first == -1:
                first = nd
                left[nd] = right[nd] = nd
            else:
                left[nd] = prev
                right[nd] = right[prev]
                left[right[prev]] = nd
                right[prev] = nd
            prev = nd

    solution_rows = []

    sys.setrecursionlimit(10000)

    def cover(c):
        # remove column header
        left[right[c]] = left[c]
        right[left[c]] = right[c]
        # remove rows
        i = down[c]
        while i != c:
            j = right[i]
            while j != i:
                down[up[j]] = down[j]
                up[down[j]] = up[j]
                size[col[j]] -= 1
                j = right[j]
            i = down[i]

    def uncover(c):
        i = up[c]
        while i != c:
            j = left[i]
            while j != i:
                size[col[j]] += 1
                down[up[j]] = j
                up[down[j]] = j
                j = left[j]
            i = up[i]
        left[right[c]] = c
        right[left[c]] = c

    def search() -> bool:
        if right[0] == 0:          # all columns covered
            return True
        # choose column with minimal size
        c = right[0]
        s = size[c]
        j = right[c]
        while j != 0:
            if size[j] < s:
                s = size[j]
                c = j
                if s == 0:
                    break
            j = right[j]
        if s == 0:
            return False
        cover(c)
        r = down[c]
        while r != c:
            solution_rows.append(row_of_node[r])
            j = right[r]
            while j != r:
                cover(col[j])
                j = right[j]
            if search():
                return True
            # backtrack
            j = left[r]
            while j != r:
                uncover(col[j])
                j = left[j]
            solution_rows.pop()
            r = down[r]
        uncover(c)
        return False

    if search():
        out = ["YES"]
        for idx in solution_rows:
            a, b, c = triples[idx]
            out.append(f"{a} {b} {c}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
