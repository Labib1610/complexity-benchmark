<STATEMENT>
# Problem A — Deep Space Relays

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a communication array and must select exactly $k$ relay configurations from a provided catalog.

You are given a log of $t$ candidate relays. Each candidate is specified by a triplet of positive integers $(a, b, c)$, representing its primary, secondary, and tertiary channel assignments.

To ensure the array operates without signal collapse, the selected relays must form a non-singular network across all three channel types. 

Consider a proposed selection of $k$ relays. If we arrange them in any arbitrary order, we can construct a $k \times k$ *Primary Channel Matrix* $M$ (with rows and columns indexed from $1$ to $k$). The entry $M_{i,j}$ is set to $1$ if the $i$-th relay in the arrangement has its primary channel assignment equal to $j$, and $0$ otherwise. The primary channel configuration is considered stable if and only if the determinant of $M$ is non-zero. (Because rearranging the relays only swaps rows and flips the sign of the determinant, the property of being non-zero is strictly independent of the chosen order.)

A selection of exactly $k$ relays is valid if and only if it satisfies all three of the following conditions:
1. Its Primary Channel Matrix has a non-zero determinant.
2. Its Secondary Channel Matrix (constructed in the exact same way using the secondary channel assignments) has a non-zero determinant.
3. Its Tertiary Channel Matrix (constructed using the tertiary channel assignments) has a non-zero determinant.

Determine whether it is possible to select exactly $k$ valid relays from the log. If it is, output the $k$ chosen relays.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the required number of relays and the total number of candidate relays in the log. 

The next $t$ lines each contain three integers $a$, $b$, and $c$, detailing a candidate relay. Each parameter of a candidate relay is a positive integer that does not exceed $k$ ($1 \le a, b, c \le k$). No relay appears more than once in the log.

## Output

If a valid selection of exactly $k$ relays is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $a$ $b$ $c$ of a chosen relay. The chosen relays can be printed in any order. Any valid selection will be accepted.

If no such selection is possible, print `NO`.

### Example 1

**Input**

1 1 1

2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

```

## Note

In Example 2, the required number of relays is $k=2$. The two candidate relays are $(1, 1, 1)$ and $(2, 1, 2)$. If we select both of them, we can construct the matrices to check validity.

The Primary Channel Matrix $M$ is formed by looking at the first parameter of each relay:
- Relay 1 has primary channel 1, so its row is `[1, 0]`.
- Relay 2 has primary channel 2, so its row is `[0, 1]`.
The determinant of this matrix is $(1 \times 1) - (0 \times 0) = 1$, which is non-zero.

The Secondary Channel Matrix is formed by looking at the second parameter of each relay:
- Relay 1 has secondary channel 1, so its row is `[1, 0]`.
- Relay 2 has secondary channel 1, so its row is `[1, 0]`.
The determinant of this matrix is $(1 \times 0) - (0 \times 1) = 0$.

Because the determinant of the Secondary Channel Matrix is zero, this selection is invalid. It is impossible to select 2 relays that satisfy all requirements.
</STATEMENT>
<RATIONALE>
Replaced the explicit power-of-two subset sum with a linear algebra property: the chosen relays define three $k \times k$ row-monomial matrices which must have non-zero determinants. This forces models to mathematically deduce that a binary matrix with one '1' per row is only non-singular if it is a permutation matrix, meaning no two relays can share a channel. Models that fail to make this deduction will either fail to prune their search space (resulting in TLE) or attempt costly matrix operations in the innermost loop.
</RATIONALE>
<PRESERVED_ANSWER>
A binary matrix with exactly one '1' per row has a non-zero determinant if and only if it is a permutation matrix; thus, the chosen relays must cover every channel from 1 to $k$ exactly once, which is mathematically identical to the seed's power-of-two sum condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-Dimensional Matching (NP-complete), as it still asks to find an exact cover of three sets of size $k$ using $k$ chosen triplets.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the matrix bounds if they assume 0-indexing, but the explicit "(with rows and columns indexed from 1 to k)" mitigates this.
</RISK>
