# Problem A — Deep Space Relays

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a quantum stabilization grid and must select exactly $k$ stabilizer configurations from a provided catalog.

You are given a log of $t$ candidate stabilizers. Each candidate is specified by a triplet of positive integers $(a, b, c)$.

Each stabilizer operates on three independent continuous dimensions: Alpha, Beta, and Gamma. 
For a stabilizer with parameters $(a, b, c)$:
- It projects an Alpha field over the continuous interval $[a-1, a]$.
- It projects a Beta field over the continuous interval $[b-1, b]$.
- It projects a Gamma field over the continuous interval $[c-1, c]$.

When a set of exactly $k$ stabilizers is activated, the *total stabilized length* for a given dimension is the total length of the union of the intervals projected by the chosen stabilizers in that dimension. 

A selection of exactly $k$ stabilizers is valid if and only if:
- The total stabilized length for the Alpha dimension is exactly $k$.
- The total stabilized length for the Beta dimension is exactly $k$.
- The total stabilized length for the Gamma dimension is exactly $k$.

Determine whether it is possible to select exactly $k$ valid stabilizers from the log. If it is, output the $k$ chosen stabilizers.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the required number of stabilizers and the total number of candidate stabilizers in the log. 

The next $t$ lines each contain three integers $a$, $b$, and $c$, detailing a candidate stabilizer. Each parameter of a candidate stabilizer is a positive integer that does not exceed $k$ ($1 \le a, b, c \le k$). No stabilizer appears more than once in the log.

## Output

If a valid selection of exactly $k$ stabilizers is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $a$ $b$ $c$ of a chosen stabilizer. The chosen stabilizers can be printed in any order. Any valid selection will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the two candidate stabilizers are $(1, 1, 1)$ and $(2, 1, 2)$. If we select both of them ($k=2$), we evaluate the intervals for each dimension:
- Alpha dimension: The intervals are $[0, 1]$ and $[1, 2]$. Their union is $[0, 2]$, which has a total stabilized length of $2$.
- Beta dimension: The intervals are $[0, 1]$ and $[0, 1]$. Their union is $[0, 1]$, which has a total stabilized length of $1$.
- Gamma dimension: The intervals are $[0, 1]$ and $[1, 2]$. Their union is $[0, 2]$, which has a total stabilized length of $2$.

The target length for all dimensions is $k = 2$. Because the total stabilized length for the Beta dimension is $1$ rather than $2$, this selection is invalid. It is impossible to select 2 stabilizers that satisfy the requirements.

<RATIONALE>
Replaced the binary sum condition (sum of 2^(x-1) = 2^k - 1) with an equivalent geometric condition: the length of the union of unit intervals [x-1, x] must equal k. This forces models to bridge continuous 1D geometry back to the discrete distinct-values requirement, breaking exact-cover template matching while avoiding flagged terminology like "cover".
</RATIONALE>
<PRESERVED_ANSWER>
Since each interval [x-1, x] has length 1 and x is bounded between 1 and k, the union of k such intervals has length k if and only if the intervals are disjoint, which directly mandates that the k chosen integers are a permutation of 1..k, exactly mirroring the original binary sum requirement.
</PRESERVED_ANSWER>
