**Solution Explanation**

For a required number `k` we have to choose exactly `k` triples  

```
(a , b , c) ,   1 ≤ a,b,c ≤ k
```

from the given list (`t` triples, `t ≤ k³`).  
For the chosen triples let  

* `S1` – set of used first components,
* `S2` – set of used second components,
* `S3` – set of used third components.

The condition of the statement is  

```
|S1| · |S2| · |S3| = k³ .
```

--------------------------------------------------------------------

#### 1.   What must the three sets look like ?

For `k = 1` the condition is always satisfied – we only have to take the
single possible triple.

For `k > 1`

```
|S1| ≤ k , |S2| ≤ k , |S3| ≤ k
```

If one of the three numbers were `< k`, the product would be at most  

```
(k‑1)·k·k = k³ – k²  <  k³ .
```

Hence for `k > 1`

```
|S1| = |S2| = |S3| = k .
```

Only the numbers `1 … k` exist, consequently each of the three sets must be
exactly `{1,…,k}` and every value appears **once** in each coordinate
(because we have only `k` triples).  
So we have to select `k` triples such that

* each value `1 … k` occurs exactly once as a first component,
* each value `1 … k` occurs exactly once as a second component,
* each value `1 … k` occurs exactly once as a third component.

--------------------------------------------------------------------

#### 2.   Reformulation as an Exact‑Cover problem  

Create three groups of columns

```
A0 … A(k‑1)   – one column for each possible first component
B0 … B(k‑1)   – one column for each possible second component
C0 … C(k‑1)   – one column for each possible third component
```

A triple `(a,b,c)` corresponds to a **row** covering the three columns

```
Aa‑1 ,  B(b‑1) ,  C(c‑1) .
```

Choosing `k` triples that satisfy the condition is *exactly* the problem of
selecting `k` rows that cover **every column once** – the classic *exact cover*
problem.

The number of columns is `3·k ≤ 66`, the number of rows is at most `k³ ≤ 10648`,
both very small.  
An exact cover can be found by the well‑known recursive Algorithm X
(Dancing Links).  Because the depth never exceeds `k ≤ 22`,
a straightforward implementation using Python sets is fast enough
(only a few megabytes of data and a few million elementary operations).

--------------------------------------------------------------------

#### 3.   Algorithm  

```
if k == 1:
        answer exists iff t ≥ 1
else:
        build an array rows[] : for every given triple store the three column numbers
        for every column store the list of rows that contain it   (col_rows)

        remaining_rows = set of all row indices
        uncovered       = set of all 3·k columns
        selected        = empty list

        recursively run Algorithm X:
                if uncovered is empty -> solution found
                choose the uncovered column with the smallest number of
                       rows still remaining (pruning)
                try every remaining row that covers this column:
                        remove all rows that intersect any of the three
                        columns of the chosen row
                        recurse with the reduced sets
                if none succeeds -> backtrack
```

The recursion depth is at most `k`.  
At each level we inspect at most all rows once, therefore the total work is
well below the time limit.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints **YES** together with a correct set of
triples iff such a set exists.

---

##### Lemma 1  
For `k > 1` any feasible selection of `k` triples must contain each value
`1 … k` exactly once in each of the three coordinates.

**Proof.**  
From Section&nbsp;1 we have `|S1| = |S2| = |S3| = k`.  
All possible values are between `1` and `k`, therefore each set must be the
whole `{1,…,k}`.  
Because the selection contains exactly `k` triples, a value cannot appear
twice in the same coordinate – otherwise some value would be missing.
∎



##### Lemma 2  
A set of `k` triples satisfies the original condition **iff**
the corresponding `k` rows form an exact cover of the `3k` columns.

**Proof.**  

*If* the triples satisfy the condition, by Lemma&nbsp;1 each value `1…k` occurs
once in each coordinate, i.e. each column `Aa , Bb , Cc` is covered exactly once.

*Only‑if* the rows form an exact cover, every column is covered once, hence each
value `1…k` occurs exactly once as a first, as a second and as a third component.
Consequently the three sets have size `k` and their product equals `k³`. ∎



##### Lemma 3  
During the recursion the algorithm always keeps the invariant  

> `remaining_rows` = all rows that do **not** intersect any already covered column,  
> `uncovered`    = the set of columns not yet covered.

**Proof.**  
Initially nothing is covered, the invariant holds.  
When a row `r` is chosen, the algorithm removes from `remaining_rows`
every row that shares any of the three columns of `r`; exactly those rows would
intersect a newly covered column, therefore they must disappear from the set of
still usable rows.  
The three columns of `r` are removed from `uncovered`.  
All other rows keep the property of not intersecting covered columns.
Thus the invariant is preserved. ∎



##### Lemma 4  
If the recursion reaches a state with `uncovered = ∅`,
the rows stored in `selected` constitute a feasible selection.

**Proof.**  
`uncovered = ∅` means every column is covered.
By Lemma&nbsp;3 none of the selected rows intersect each other,
hence each column is covered exactly once.
The number of selected rows equals the number of covered columns divided by 3,
i.e. `k`.  
By Lemma&nbsp;2 the corresponding triples fulfil the required condition. ∎



##### Lemma 5  
If a feasible selection exists, the recursion will eventually find it.

**Proof.**  
Consider any feasible exact cover `F`.  
At the first recursive call the algorithm chooses an uncovered column `c`.
`c` belongs to exactly one row `f ∈ F` (because `F` is a cover).
All rows covering `c` are examined; in particular the algorithm will try `f`.
When `f` is taken, Lemma&nbsp;3 guarantees that the remaining problem is exactly
the sub‑instance obtained from `F` after removing `f`.  
Induction on the number of yet uncovered columns shows that the algorithm can
follow the rows of `F` down to the empty set of columns, where it succeeds
(Lemma&nbsp;4). ∎



##### Lemma 6  
If the recursion reports failure, no feasible selection exists.

**Proof.**  
Assume the contrary: a feasible exact cover `F` exists but the algorithm
fails.  
The failure can only happen when, for the current `uncovered` set,
the algorithm picks a column `c` for which **every** row containing `c`
leads to a dead end.
But `F` contains a row `f` that covers `c`.  
Choosing `f` cannot be a dead end because the remaining uncovered columns are
exactly those of `F \{f}` – a smaller exact cover.
Thus the algorithm would have succeeded via `f`, contradiction. ∎



##### Theorem  
The program prints

* `YES` and a list of `k` triples **iff** such a list exists,
* otherwise prints `NO`.

**Proof.**  

*If the program prints `YES`*: it output the triples belonging to the rows
stored in `selected` at the moment `uncovered` became empty.
By Lemma&nbsp;4 they form a feasible selection.

*If a feasible selection exists*: by Lemma&nbsp;5 the recursion reaches a
state with `uncovered = ∅`, consequently the program prints `YES`.

*If the program prints `NO`*: the recursion terminated without success,
hence by Lemma&nbsp;6 no feasible selection exists.

All cases are covered, therefore the theorem holds. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

```
k ≤ 22 ,   t ≤ k³ ≤ 10648 ,   columns = 3k ≤ 66
```

Let `R = t` be the number of rows.

*Building the data structures* – `O(R)` time, `O(R + k)` memory.

*Recursive search* – depth ≤ `k`.  
At each level we examine at most all rows once to count candidates for the
chosen column and to build the set of rows to delete.
Hence total work ≤ `k · R` ≤ `22·10648`  ≈ 2·10⁵ elementary operations.

Memory used by the recursive copies:
each level stores two sets (`remaining_rows`, `uncovered`) of size at most `R`
and `3k`.  With `k ≤ 22` this is well below the 256 MB limit.

Thus the program easily satisfies the limits.

#### 6.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    triples = []
    for _ in range(t):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        triples.append((a, b, c))

    if k == 1:
        if t >= 1:
            print("YES")
            a, b, c = triples[0]
            print(a + 1, b + 1, c + 1)
        else:
            print("NO")
        return

    # quick impossibility check
    if t < k:
        print("NO")
        return

    # column numbering:
    # 0..k-1               -> first component (A)
    # k..2k-1              -> second component (B)
    # 2k..3k-1             -> third component (C)
    ncols = 3 * k
    rows = []                     # list of (colA, colB, colC)
    col_rows = [[] for _ in range(ncols)]

    for idx, (a, b, c) in enumerate(triples):
        ca = a
        cb = k + b
        cc = 2 * k + c
        rows.append((ca, cb, cc))
        col_rows[ca].append(idx)
        col_rows[cb].append(idx)
        col_rows[cc].append(idx)

    # initial sets
    all_rows = set(range(len(rows)))
    uncovered = set(range(ncols))

    # ---------- recursive exact cover ----------
    def search(selected, remaining, uncovered_cols):
        if not uncovered_cols:          # all columns covered
            return selected

        # choose column with the fewest remaining rows (heuristic)
        best_col = None
        best_cnt = None
        for col in uncovered_cols:
            cnt = 0
            for r in col_rows[col]:
                if r in remaining:
                    cnt += 1
            if cnt == 0:                # dead end
                return None
            if best_cnt is None or cnt < best_cnt:
                best_cnt = cnt
                best_col = col
                if cnt == 1:
                    break

        # try every row that covers the chosen column
        for r in col_rows[best_col]:
            if r not in remaining:
                continue
            ca, cb, cc = rows[r]
            # rows that intersect any of the three columns
            to_remove = set()
            for col in (ca, cb, cc):
                for rr in col_rows[col]:
                    if rr in remaining:
                        to_remove.add(rr)

            new_remaining = remaining - to_remove
            new_uncovered = uncovered_cols - {ca, cb, cc}
            res = search(selected + [r], new_remaining, new_uncovered)
            if res is not None:
                return res
        return None

    solution = search([], all_rows, uncovered)

    if solution is None:
        print("NO")
    else:
        print("YES")
        out = []
        for r in solution:
            a, b, c = triples[r]
            out.append(f"{a+1} {b+1} {c+1}")
        sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
