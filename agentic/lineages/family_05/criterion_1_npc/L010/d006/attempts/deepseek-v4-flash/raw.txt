We need to select exactly \( k \) relays from the given candidates such that:

\[
|S_1| \times |S_2| \times |S_3| = k^3
\]

Since each parameter is between 1 and \( k \), the maximum possible size of each set is \( k \).  
The product equals \( k^3 \) only if each set has size exactly \( k \).  
So we need to choose \( k \) relays such that:

- All \( k \) possible values for \( a \) appear at least once.
- All \( k \) possible values for \( b \) appear at least once.
- All \( k \) possible values for \( c \) appear at least once.

Since we choose exactly \( k \) relays, each chosen relay must be distinct, and to cover all \( k \) values in each coordinate, each coordinate must appear exactly once across the chosen relays.  
That means the chosen relays must form a **perfect matching** in a 3-partite hypergraph where each coordinate value appears exactly once.

This is equivalent to finding a permutation-like selection:  
We need to pick \( k \) triples such that the first coordinates are a permutation of \( 1..k \), the second coordinates are a permutation of \( 1..k \), and the third coordinates are a permutation of \( 1..k \).

So the problem reduces to:  
Given a set of triples \((a,b,c)\) with \(1 \le a,b,c \le k\), can we select \(k\) of them such that each number \(1..k\) appears exactly once in each position?

This is a 3D matching problem, which is NP-hard in general, but here \(k \le 22\), so we can use backtracking with pruning.

We can model it as:  
We need to assign each \(a\) value to a unique \(b\) and \(c\) value, using only the given triples.

We can do a DFS over the \(a\) values from 1 to \(k\), trying to match each with a \(b\) and \(c\) that are still unused.

We'll store candidates grouped by \(a\).  
We'll also keep track of used \(b\) and \(c\) sets.

Since \(k\) is small (max 22), backtracking with bitmasks will be fast enough.

Let's implement:

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    k = int(next(it))
    t = int(next(it))
    
    # candidates grouped by a
    by_a = [[] for _ in range(k+1)]
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        c = int(next(it))
        by_a[a].append((b, c))
    
    # We need to pick exactly one from each a group (since a must be 1..k each once)
    # If any a group is empty, impossible
    for a in range(1, k+1):
        if not by_a[a]:
            print("NO")
            return
    
    # Sort groups maybe by size for better pruning
    order = list(range(1, k+1))
    order.sort(key=lambda x: len(by_a[x]))
    
    used_b = 0
    used_c = 0
    chosen = [None] * (k+1)  # chosen[a] = (b, c)
    
    def dfs(idx):
        nonlocal used_b, used_c
        if idx == k:
            return True
        a = order[idx]
        for b, c in by_a[a]:
            if (used_b >> (b-1)) & 1:
                continue
            if (used_c >> (c-1)) & 1:
                continue
            # choose
            used_b |= (1 << (b-1))
            used_c |= (1 << (c-1))
            chosen[a] = (b, c)
            if dfs(idx+1):
                return True
            # backtrack
            used_b ^= (1 << (b-1))
            used_c ^= (1 << (c-1))
            chosen[a] = None
        return False
    
    if dfs(0):
        print("YES")
        for a in range(1, k+1):
            b, c = chosen[a]
            print(a, b, c)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
