<STATEMENT>
# Problem A — Composite Task Forces

Time limit: 5 s   Memory limit: 256 MB

## Description

You are tasked with assembling composite task forces. A task force consists of three distinct components: a supervisor, a facility, and a shift. There are $k$ supervisors, $k$ facilities, and $k$ shifts in total, each component type indexed from $1$ up to $k$.

To form a task force, you must select exactly one supervisor, one facility, and one shift. You are given a ledger of approved configurations $(x, y, z)$, meaning supervisor $x$, facility $y$, and shift $z$ are authorized to operate together.

Your objective is to mobilize exactly $k$ task forces from the ledger. A mobilization is only legitimate if it is perfectly comprehensive: every individual supervisor, every single facility, and every shift must be allocated to exactly one of the $k$ mobilized task forces.

The ledger of approved configurations is provided by an adversarial auditor. The ledger can be extremely dense, and the entries are specifically ordered to mislead verification strategies that prioritize the most restricted choices, forcing any evaluation process to examine a vast number of invalid combinations before finding a legitimate mobilization or concluding none exists.

Determine if a legitimate mobilization is achievable. If it is, report the configurations that constitute the task forces.

## Input

The first line provides two integers $k$ and $t$. The integer $k$ indicates the quantity of each component type. This quantity is at least 1, and its maximum possible value is exactly the total number of starting players on the pitch in a standard association football match. The integer $t$ represents the total number of approved configurations, ranging from zero up to the theoretical maximum of $k$ cubed.
Each of the subsequent $t$ lines contains three integers $x$, $y$, and $z$. These values specify an approved configuration, where each index is between $1$ and $k$ inclusive. All configurations in the ledger are unique.

## Output

If it is possible to mobilize $k$ task forces meeting the criteria, output `YES` on the first line. Following that, output $k$ lines, each containing the identifiers $x$ $y$ $z$ of a selected task force. The task forces may be listed in any order. Any legitimate mobilization will be accepted.

If no such mobilization is possible, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both approved configurations require facility 1. Consequently, it is impossible to incorporate facility 2 into any task force, meaning a legitimate mobilization cannot be formed.
