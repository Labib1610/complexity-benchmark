<STATEMENT>
# Problem A — Crew Assembly

Time limit: 5 s   Memory limit: 256 MB

## Description

You are managing a manufacturing project that involves $k$ specialists, $k$ machines, and $k$ time intervals. All resources in these three categories are assigned identification numbers from $1$ to $k$.

A work crew requires exactly one specialist, one machine, and one time interval. However, only certain combinations of these elements are compatible. You will receive a registry of certified triplets $(x, y, z)$, indicating that specialist $x$, machine $y$, and time interval $z$ can successfully operate together.

To meet production demands, you must deploy a roster of exactly $k$ crews chosen from the registry. A deployment roster is only valid if it integrates every single resource—meaning each specialist, each machine, and each time interval is assigned to exactly one of the $k$ chosen crews.

Determine if a valid deployment is possible, and if so, report the triplets that make up the crews.

## Input

The first line provides two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), representing the quantity of each resource type and the total number of certified triplets.
Each of the following $t$ lines contains three integers $x$, $y$, and $z$ ($1 \le x, y, z \le k$), defining a certified triplet. All triplets in the registry are distinct.

## Output

If it is possible to deploy $k$ crews meeting the criteria, output `YES` on the first line. Following that, output $k$ lines, each containing the identifiers $x$ $y$ $z$ of a selected crew. The crews may be listed in any order. Any valid deployment roster will be accepted.

If no such deployment is possible, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both valid triplets require machine 1. Consequently, it is impossible to incorporate machine 2 into any crew, meaning a valid deployment cannot be formed.
