<METHOD_NAME>Exponential Subset Sum Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the pairwise distinctness condition (x1 != x2) with an equivalent subset-sum condition using powers of 5. Since exactly k items are chosen, summing to the geometric series sum (which has exactly k ones in base 5) uniquely implies the items must be a distinct permutation of 1..k. This forces the model to mathematically deduce this equivalence to reconstruct the efficient Algorithm X / grouping logic; failing that, it will fall back to a naive subset sum search which will TLE due to the O(t^k) search space.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Deep Space Relays

Time limit: 5 s   Memory limit: 256 MB

## Description

You are designing a communication array and must select exactly $k$ relay configurations from a provided catalog.

You are given a log of $t$ candidate relays. Each candidate is specified by a triplet of integers $(x, y, z)$, where each integer is between $1$ and $k$ inclusive.

To prevent signal interference and ensure uniform coverage, the chosen relays must satisfy a strict power-balancing condition across all three operational bands. For any relay with parameters $(x, y, z)$, its $x$-band power is defined as $5^x$, its $y$-band power as $5^y$, and its $z$-band power as $5^z$.

A selection of exactly $k$ relays is valid if and only if all three of the following conditions hold simultaneously:
1. The sum of the $x$-band powers of the $k$ chosen relays is exactly $\frac{5^{k+1} - 5}{4}$.
2. The sum of the $y$-band powers of the $k$ chosen relays is exactly $\frac{5^{k+1} - 5}{4}$.
3. The sum of the $z$-band powers of the $k$ chosen relays is exactly $\frac{5^{k+1} - 5}{4}$.

Determine whether it is possible to select exactly $k$ relays from the log that meet these power requirements. If it is, output the $k$ chosen relays.

*(Note: The maximum possible required sum fits comfortably within standard 64-bit integer types.)*

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the required number of relays (which is also the upper bound for any parameter) and the total number of candidate relays in the log.
The next $t$ lines each contain three integers $x$, $y$, and $z$ ($1 \le x, y, z \le k$), detailing a candidate relay. No relay appears more than once in the log.

## Output

If a valid selection of $k$ relays is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $x$ $y$ $z$ of a chosen relay. The chosen relays can be printed in any order. Any valid selection will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 1, $k=2$. The target sum for each band is $\frac{5^3 - 5}{4} = 30$. By selecting the relays $(1, 1, 1)$ and $(2, 2, 2)$, the sum of the $x$-band powers is $5^1 + 5^2 = 30$. The $y$-band and $z$-band sums are identically $30$. This selection is valid.

In Example 2, we must select $k=2$ relays, so we are forced to pick both available candidates: $(1, 1, 1)$ and $(2, 1, 2)$. The sum of their $y$-band powers is $5^1 + 5^1 = 10$, which does not equal the target sum of $30$. Therefore, no valid selection is possible.
</STATEMENT>
<RATIONALE>
Replaced the pairwise distinctness condition (x1 != x2) with an equivalent target-sum condition over powers of 5. Because the base-5 representation of the geometric series target has exactly $k$ ones, and exactly $k$ powers are chosen, no carries can occur. This mathematically guarantees the chosen parameters are a strictly distinct permutation of 1..k. Models that fail to deduce this structural equivalence will attempt a generic subset-sum search and TLE.
</RATIONALE>
<PRESERVED_ANSWER>
The subset-sum condition is mathematically identical to requiring all chosen x, y, and z parameters to be mutually distinct permutations of 1..k, meaning the exact same valid subsets satisfy the problem.
</PRESERVED_ANSWER>

The problem remains exactly 3-Dimensional Matching, just with its isolation condition obscured via an arithmetic invariant.
</PRESERVED_CLASS>
