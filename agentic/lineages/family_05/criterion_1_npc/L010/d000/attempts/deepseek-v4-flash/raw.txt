We need to find a perfect matching in a 3-partite hypergraph, which is NP-hard in general.  
However, with k ≤ 22, we can use a meet-in-the-middle or DP over subsets approach.

We can model it as:  
- Choose for each specialist x a machine y and time z such that all machines and times are used exactly once.  
- This is equivalent to finding a perfect matching in a bipartite graph between (x, y) pairs and z, but with the constraint that each x and y appear exactly once.

A common approach:  
- Enumerate all possible assignments of machines to specialists (k! possibilities) — too large.  
- Instead, use DP over subsets of machines and times.

We can transform:  
- Create a bipartite graph: left side = all (x,y) pairs that appear in allowed triples, right side = z values.  
- We need to select k edges such that each x appears once, each y appears once, each z appears once.  
- This is a 3D matching problem, but we can solve with DP over subsets of x and y.

Alternative:  
We can use a recursive search with bitmasks for X, Y, Z, and prune heavily.  
Since k ≤ 22, worst-case branching might be large, but with t limited, we can try.

We can also use the fact that we can fix the order of specialists and try to assign machines and times via backtracking with bitmasks.

Let’s implement a backtracking that assigns for each specialist x (in order) a machine y and time z, using bitmasks for used machines and times.  
We’ll precompute for each x the list of (y,z) pairs.

We’ll also add pruning: if at any point the number of remaining specialists exceeds the number of available machines or times, fail.

Given k ≤ 22, worst-case branching could be huge, but with t ≤ k³ and typical constraints, it should pass in 5s if we use bitmasks and recursion with good ordering.

Let’s code it.

```python
import sys
sys.setrecursionlimit(1000000)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))
    
    # allowed[x] = list of (y,z)
    allowed = [[] for _ in range(k+1)]
    for _ in range(t):
        x = int(next(it))
        y = int(next(it))
        z = int(next(it))
        allowed[x].append((y-1, z-1))  # 0-index
    
    # Sort by number of options for better pruning
    order = list(range(1, k+1))
    order.sort(key=lambda x: len(allowed[x]))
    
    usedY = 0
    usedZ = 0
    assignment = [None] * (k+1)  # assignment[x] = (y,z)
    
    # Precompute for each x a list of (y,z) as bitmask-friendly
    # We'll just use lists.
    
    def dfs(idx):
        nonlocal usedY, usedZ
        if idx == k:
            return True
        x = order[idx]
        for y, z in allowed[x]:
            if (usedY >> y) & 1:
                continue
            if (usedZ >> z) & 1:
                continue
            # prune: remaining specialists must be <= remaining machines and times
            rem = k - idx - 1
            if rem > k - bin(usedY).count("1") - 1:
                continue
            if rem > k - bin(usedZ).count("1") - 1:
                continue
            usedY |= (1 << y)
            usedZ |= (1 << z)
            assignment[x] = (y+1, z+1)
            if dfs(idx+1):
                return True
            usedY ^= (1 << y)
            usedZ ^= (1 << z)
            assignment[x] = None
        return False
    
    if dfs(0):
        print("YES")
        for x in range(1, k+1):
            y, z = assignment[x]
            print(x, y, z)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
