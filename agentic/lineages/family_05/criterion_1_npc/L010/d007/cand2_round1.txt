<METHOD_NAME>Histogram Support Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces set cardinality with the number of non-zero entries (the support) of a frequency array (histogram). This obscures the fact that elements must be strictly unique, hiding the exact-cover structure and preventing models from applying early pruning on coordinate collisions.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Climate Model Balancing

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a dataset of $t$ meteorological events to build a climate model of order $k$. Each event is characterized by three integer indices $(a, b, c)$, representing the temperature zone, humidity level, and wind shear category.

You need to select exactly $k$ events from the dataset to form a balanced model. For any selection of $k$ events, we define three frequency profiles, $F_1, F_2$, and $F_3$, each being an array of size $k$ indexed from $1$ to $k$.
- $F_1[i]$ is the number of selected events whose temperature zone is exactly $i$.
- $F_2[i]$ is the number of selected events whose humidity level is exactly $i$.
- $F_3[i]$ is the number of selected events whose wind shear category is exactly $i$.

The *activation score* of a frequency profile $F$ is defined as the number of indices $j$ ($1 \le j \le k$) where $F[j] > 0$.

A model is deemed perfectly balanced if and only if the product of the activation scores of the three frequency profiles is exactly $k^3$:

$$ (\text{activation score of } F_1) \times (\text{activation score of } F_2) \times (\text{activation score of } F_3) = k^3 $$

Determine whether it is possible to select exactly $k$ events from the dataset to form a perfectly balanced model. If it is, output the $k$ chosen events.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the order of the model and the total number of events in the dataset. 

The next $t$ lines each contain three integers $a$, $b$, and $c$, detailing an event. Each index of an event is a positive integer that does not exceed $k$. No event appears more than once in the dataset.

## Output

If a perfectly balanced model of $k$ events is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $a$ $b$ $c$ of a chosen event. The chosen events can be printed in any order. Any valid selection will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the two events are $(1, 1, 1)$ and $(2, 1, 2)$. If we select both of them ($k=2$), the frequency profiles are:
- $F_1 = [1, 1]$ (one event with temperature zone 1, one with 2). Its activation score is 2.
- $F_2 = [2, 0]$ (two events with humidity level 1, zero with 2). Its activation score is 1.
- $F_3 = [1, 1]$ (one event with wind shear 1, one with 2). Its activation score is 2.

The product of their activation scores is $2 \times 1 \times 2 = 4$. Since $4$ is not equal to $2^3 = 8$, they do not form a perfectly balanced model. It is impossible to select 2 events that satisfy the requirement.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from "sets of unique elements" to "frequency profiles" (histograms) and their "activation scores" (number of non-zero entries). To succeed, models must deduce that achieving a product of exactly $k^3$ from three arrays of size $k$ representing $k$ events requires every chosen event to have entirely distinct coordinates. Without this mathematical deduction step, models will fail to apply early pruning on coordinate collisions and will time out on the large search space.
</RATIONALE>
<PRESERVED_ANSWER>
The number of positive entries in a frequency array is mathematically identical to the cardinality of the set of unique elements, meaning the constraint evaluates exactly the same for all possible combinations.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying constraint still strictly requires choosing exactly $k$ items with non-overlapping coordinates in all three dimensions, maintaining its equivalence to the NP-complete 3-Dimensional Matching problem.
</PRESERVED_CLASS>
