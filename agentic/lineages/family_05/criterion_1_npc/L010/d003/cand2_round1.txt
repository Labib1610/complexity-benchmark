<STATEMENT>
# Problem A — Phase Harmonization

Time limit: 5 s   Memory limit: 256 MB

## Description

You are auditing a system that tracks a universe of $3k$ logical flags. These flags are distributed across three distinct namespaces: Alpha, Beta, and Gamma. Within each namespace, the flags are indexed by integers from $1$ to $k$.

You are provided with a log of $t$ certified transactions. Each transaction is represented by a triplet of integers $(x, y, z)$, indicating that it targets flag $x$ in the Alpha namespace, flag $y$ in the Beta namespace, and flag $z$ in the Gamma namespace.

Your objective is to authorize exactly $k$ transactions from the log to form a valid batch. A batch is considered valid if and only if the targeted flags of the authorized transactions form a partition of the entire flag universe. In other words, across the $k$ chosen transactions, every one of the $3k$ logical flags must be targeted exactly once, with no flag left out and no flag targeted multiple times.

Determine whether such a batch of transactions can be formed. If it is possible, output the transactions that make up the batch.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the number of flags per namespace and the total number of certified transactions in the log.
The next $t$ lines each contain three integers $x$, $y$, and $z$ ($1 \le x, y, z \le k$), detailing a certified transaction. No transaction appears more than once in the log.

## Output

If a valid batch of $k$ transactions is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $x$ $y$ $z$ of an authorized transaction. The chosen transactions can be printed in any order. Any valid batch will be accepted.

If no such batch is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both certified transactions target flag 1 in the Beta namespace. Because a valid batch must partition the universe without overlaps, you can authorize at most one of these transactions. Consequently, it is impossible to authorize exactly $k=2$ transactions without leaving flags untargeted, meaning a valid batch cannot be formed.

<RATIONALE>
Removed the explicit "each technician, hardware unit, and shift exactly once" phrasing that triggered the exact-cover bitmask template. Replaced it with an abstract "flag universe" partition where the three resource categories are mapped indirectly via namespaces, forcing the model to deduce the tripartite disjoint-set structure from the namespace definitions rather than relying on surface pattern matching of three distinct physical resource types.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to select $k$ triplets such that every value from 1 to $k$ appears exactly once in each position (Alpha, Beta, Gamma) is mathematically identical to selecting $k$ squads with exactly one of each resource type.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains 3-Dimensional Matching (NP-complete), as it still asks for an exact cover of a $3k$-element set by $k$ subsets of size 3, where each subset contains exactly one element from each of three disjoint $k$-element domains.
</PRESERVED_CLASS>
