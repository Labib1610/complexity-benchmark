<METHOD_NAME>
Exponential Subset Sum Disguise
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaced the explicit frequency-counting constraint (sum of squared counts) with an equivalent subset sum constraint on the values themselves. By mapping each coordinate value $x$ to $2^{x-1}$ and requiring the sum of $k$ such values to be exactly $2^k - 1$, the condition still uniquely forces all $k$ values to be distinct (a permutation of $1 \dots k$) due to the properties of binary addition (no carries can occur if $k$ powers of two sum to a number with $k$ bits set). Models that pattern-match will attempt a direct backtracking sum search and Time Limit Exceed due to weak pruning on small duplicate values. Models that genuinely reason will deduce the distinctness property and apply exact-cover bitmasking.
</METHOD_DESCRIPTION>

# Problem A — Cloud Resource Provisioning

Time limit: 5 s   Memory limit: 256 MB

## Description

You are a cloud architect tasked with provisioning resources for exactly $k$ microservices. 

You are given a catalog of $t$ available deployment templates. Each template specifies the required instance sizes across three independent cloud regions: Region A, Region B, and Region C. A template is represented by a triplet of positive integers $(a, b, c)$, meaning it requests an instance of size $a$ in Region A, an instance of size $b$ in Region B, and an instance of size $c$ in Region C.

In this cloud provider's architecture, an instance of size $x$ provides exactly $2^{x-1}$ virtual CPUs (vCPUs). 

You must select a subset of exactly $k$ distinct templates from the catalog. For the deployment to be perfectly balanced, the total number of vCPUs provisioned in Region A must be exactly $2^k - 1$. Similarly, the total number of vCPUs provisioned in Region B must be exactly $2^k - 1$, and the total number of vCPUs provisioned in Region C must be exactly $2^k - 1$. The total number of vCPUs in a region is simply the sum of the vCPUs provided by the instances in that region across the $k$ chosen templates.

Determine whether it is possible to select exactly $k$ valid templates from the catalog. If it is, output the $k$ chosen templates.

## Input

The first line contains two integers $k$ and $t$ ($1 \le k \le 22$, $0 \le t \le k^3$), denoting the required number of microservices and the total number of available templates. 

The next $t$ lines each contain three integers $a$, $b$, and $c$, detailing a candidate template. Each instance size is a positive integer that does not exceed $k$ ($1 \le a, b, c \le k$). No template appears more than once in the catalog.

## Output

If a valid selection of exactly $k$ templates is possible, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $a$ $b$ $c$ of a chosen template. The chosen templates can be printed in any order. Any valid selection will be accepted.

If no such selection is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the two candidate templates are $(1, 1, 1)$ and $(2, 1, 2)$. If we select both of them ($k=2$), we calculate the total vCPUs provisioned in each region:
- In Region A, the sizes are 1 and 2. The vCPUs are $2^0 + 2^1 = 1 + 2 = 3$.
- In Region B, the sizes are 1 and 1. The vCPUs are $2^0 + 2^0 = 1 + 1 = 2$.
- In Region C, the sizes are 1 and 2. The vCPUs are $2^0 + 2^1 = 1 + 2 = 3$.

The target for each region is $2^2 - 1 = 3$. Since Region B only has 2 vCPUs, this selection is invalid. It is impossible to select 2 templates that satisfy the requirement.
</STATEMENT>
<RATIONALE>
Changed the constraint from a sum of squared frequencies to a subset sum of powers of two ($2^{x-1}$). Because the target sum $2^k - 1$ has exactly $k$ bits set, picking $k$ powers of two can only reach this sum if there are no carries, meaning all $k$ values must be distinct. Models that pattern-match the text will attempt a direct backtracking sum search and Time Limit Exceeded due to weak pruning, while models that genuinely reason will deduce the distinctness property and apply exact-cover bitmasking.
</RATIONALE>
<PRESERVED_ANSWER>
The only way $k$ powers of two from $\{2^0, \dots, 2^{k-1}\}$ can sum to $2^k - 1$ is if they are all distinct, which mathematically enforces the exact same matching condition (every coordinate value from $1$ to $k$ appears exactly once) as the original frequency sum of squares.
</PRESERVED_ANSWER>
