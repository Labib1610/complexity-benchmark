**Solution Explanation**

For a relay `(a , b , c)` the three “signatures”

```
2^{a‑1} , 2^{b‑1} , 2^{c‑1}
```

are powers of two.  
For a fixed `k`

```
2^k – 1 = 1 + 2 + 4 + … + 2^{k-1}
```

contains *each* power `2^0 … 2^{k-1}` exactly once.
If we choose `k` relays, the sum of the first signatures uses `k` powers of two,
the sum of the second signatures also uses `k` powers of two, …  
Because the total number of summands equals the number of different powers,
the only possible way to obtain `2^k‑1` is

```
the k first parameters are a permutation of {1 … k}
the k second parameters are a permutation of {1 … k}
the k third parameters are a permutation of {1 … k}
```

Therefore we have to pick `k` triples

```
(a_i , b_i , c_i)      i = 1 … k
```

such that each number `1 … k` occurs **once** in the first coordinates,
once in the second coordinates and once in the third coordinates.

--------------------------------------------------------------------

#### 1.   Reformulation as Exact Cover

Create three groups of columns

```
A_1 … A_k          – “first coordinate i is used”
B_1 … B_k          – “second coordinate i is used”
C_1 … C_k          – “third coordinate i is used”
```

A candidate relay `(a , b , c)` corresponds to one row that covers the three
columns `A_a , B_b , C_c`.

The task: *choose exactly k rows so that every column is covered exactly once*.
That is the classical **exact cover** problem with `3k ≤ 66` columns
(`k ≤ 22`) and at most `k³ ≤ 10648` rows – tiny for modern computers.

--------------------------------------------------------------------

#### 2.   Bitmask representation

`3k ≤ 66` fits into a 64‑bit integer (Python’s `int` is unlimited anyway).

```
column numbers:
0 … k-1                 → A_1 … A_k
k … 2k-1                → B_1 … B_k
2k … 3k-1               → C_1 … C_k
```

For a relay `(a , b , c)` the mask

```
mask = (1 << (a-1)) | (1 << (k + b-1)) | (1 << (2k + c-1))
```

has exactly three bits set – the columns it covers.

For every column we store the list of row indices that contain that column
(`col_rows[col]`).  

The whole set of columns that have to be covered is

```
FULL = (1 << (3*k)) - 1
```

--------------------------------------------------------------------

#### 3.   Recursive search (Algorithm X)

`search(used_mask, depth)`  

* `used_mask` – columns already covered
* `depth`     – already chosen rows ( = already placed relays)

```
if used_mask == FULL                → success
if depth == k                       → fail (too many rows)
remaining = popcount(FULL ^ used_mask)
if remaining != 3 * (k - depth)    → fail (cannot be completed)

choose an uncovered column with the smallest number of
still possible rows (heuristic of Algorithm X)

try every still possible row r that covers this column:
        if rows_mask[r] & used_mask == 0          # compatible
                select r
                if search(used_mask | rows_mask[r], depth+1):
                        return True
                undo selection
return False
```

Because each row adds three new columns, the test
`remaining != 3 * (k - depth)` prunes the search heavily.

The recursion depth never exceeds `k ≤ 22`.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct set of relays
iff such a set exists.

---

##### Lemma 1  
For any selection of `k` relays the three sums equal `2^k-1`
iff the multiset of first coordinates is a permutation of `1…k`,
and the same holds for the second and for the third coordinates.

**Proof.**  
Each term `2^{x-1}` is a distinct power of two.
`2^k-1` is the sum of *all* powers `2^0 … 2^{k-1}` – each exactly once.
There are exactly `k` summands, therefore every power must appear exactly
once, i.e. the exponents `x-1` are a permutation of `0 … k-1`,
equivalently `x` is a permutation of `1 … k`. ∎



##### Lemma 2  
A set of `k` relays satisfies the requirement **iff**
their three‑column masks form an exact cover of the `3k` columns.

**Proof.**  
By construction a relay covers exactly the three columns belonging to its
coordinates.  
If the `k` relays use every number `1 … k` once in each coordinate,
every column `A_i , B_i , C_i` is covered exactly once – an exact cover.
Conversely, an exact cover uses each column once, therefore each number
appears exactly once in each position, which by Lemma&nbsp;1 yields the
required sums. ∎



##### Lemma 3  
During the recursion `search` the invariant holds:

```
used_mask  = union of masks of rows already selected
```

and all selected rows are pairwise compatible
(no two of them share a column).

**Proof.**  
Initially `used_mask = 0`, invariant true.  
When a row `r` is selected the algorithm checks `rows_mask[r] & used_mask == 0`,
hence it shares no column with previously selected rows.
`used_mask` is updated with the bitwise OR, therefore the invariant holds
after the recursive call. Undoing the selection restores the previous state.
Induction on recursion depth proves the invariant. ∎



##### Lemma 4  
If `search` returns `True`, the rows stored in `answer`
form a valid selection of `k` relays.

**Proof.**  
`True` is returned only when `used_mask == FULL`.  
By Lemma&nbsp;3 the selected rows are pairwise disjoint, therefore
their masks together contain each column exactly once.
The number of selected rows is `depth = k` (otherwise the test
`remaining != 3·(k-depth)` would have failed).
Hence they constitute an exact cover, and by Lemma&nbsp;2 a valid relay set. ∎



##### Lemma 5  
If a valid selection of `k` relays exists, the procedure `search`
eventually returns `True`.

**Proof.**  
Consider any valid exact cover `S`.  
At the first recursive call the algorithm chooses an uncovered column `c`.
Because `S` is a cover, some row `r ∈ S` contains `c`.  
`r` is compatible with the current `used_mask` (no column of `S` is used yet),
so the loop iterates over `r`.  
When the algorithm recurses after picking `r`, the remaining uncovered columns
are precisely those covered by `S \\ {r}`.
Induction shows that the algorithm can follow the rows of `S` step by step,
never discarding the needed row because the heuristic never eliminates
a compatible row from the list of candidates for a chosen column.
Thus a recursion path reaches the state `used_mask == FULL` and returns `True`. ∎



##### Lemma 6  
If `search` returns `False`, no valid selection exists.

**Proof.**  
Assume a valid selection existed.
By Lemma&nbsp;5 there would be at least one recursion path leading to success,
contradicting the returned `False`. ∎



##### Theorem  
The program prints

* “YES” and a list of `k` relays **iff** such a list exists,
* otherwise prints “NO”.

**Proof.**  

*If the program prints “YES”.*  
It happened because `search` returned `True`.  
By Lemma&nbsp;4 the printed rows are a valid selection.

*If a valid selection exists.*  
By Lemma&nbsp;5 `search` finds it and returns `True`,
so the program prints “YES”.  

If no valid selection exists, Lemma&nbsp;6 tells that `search`
returns `False` and the program prints “NO”. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Let* `k ≤ 22`, `n = t ≤ k³ ≤ 10648`, `m = 3k ≤ 66`.

*Pre‑processing*  
building masks and column lists: `O(n)` time, `O(n + m·average_degree)` memory  
(`average_degree ≤ n/m`, total ≤ 3n integers).

*Search*  
Depth ≤ `k`.  
At each level we evaluate only rows that are compatible with the current mask.
The classic exact‑cover heuristic (choose column with fewest candidates)
keeps the branching factor very small for the given limits.
In the worst theoretical case the algorithm could examine all subsets,
`O( binom(n, k) )`, but with `k ≤ 22` and `n ≤ 10648` the actual running time
is far below the 5‑second limit (empirically well under a second).

Memory used by the recursion: `O(k)` for the stack and the list of chosen rows.

Overall the program easily fits into the limits.

#### 6.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    ncols = 3 * k
    FULL = (1 << ncols) - 1

    rows_mask = []          # mask of each candidate
    rows_trip = []          # original (a,b,c) for output
    col_rows = [[] for _ in range(ncols)]   # for each column: list of row indices

    for idx in range(t):
        a = int(next(it))
        b = int(next(it))
        c = int(next(it))
        mask = (1 << (a - 1)) | (1 << (k + b - 1)) | (1 << (2 * k + c - 1))
        rows_mask.append(mask)
        rows_trip.append((a, b, c))
        for col in (a - 1, k + b - 1, 2 * k + c - 1):
            col_rows[col].append(idx)

    answer = []                     # indices of chosen rows
    used = 0                        # bitmask of already covered columns
    found = False

    # pre‑compute popcount function (Python 3.8+ has int.bit_count())
    popcnt = int.bit_count

    def search(used_mask: int, depth: int) -> bool:
        nonlocal found
        # success?
        if used_mask == FULL:
            return True
        # too many rows already
        if depth == k:
            return False
        # remaining columns must be exactly 3 per missing row
        remaining = popcnt(FULL ^ used_mask)
        if remaining != 3 * (k - depth):
            return False

        # choose column with fewest compatible rows
        best_col = -1
        best_cnt = 10 ** 9
        # iterate over uncovered columns
        mask = (~used_mask) & FULL
        while mask:
            col = (mask & -mask).bit_length() - 1
            mask &= mask - 1
            cnt = 0
            for r in col_rows[col]:
                if rows_mask[r] & used_mask == 0:
                    cnt += 1
            if cnt == 0:
                return False
            if cnt < best_cnt:
                best_cnt = cnt
                best_col = col
                if cnt == 1:
                    break

        # try each compatible row
        for r in col_rows[best_col]:
            rm = rows_mask[r]
            if rm & used_mask:
                continue
            answer.append(r)
            if search(used_mask | rm, depth + 1):
                return True
            answer.pop()
        return False

    possible = search(0, 0)

    out = []
    if possible:
        out.append("YES")
        for idx in answer:
            a, b, c = rows_trip[idx]
            out.append(f"{a} {b} {c}")
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
