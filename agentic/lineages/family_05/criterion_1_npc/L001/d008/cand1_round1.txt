<STATEMENT>
# Problem A — Harmonic Resonance

Time limit: 5 s   Memory limit: 256 MB

## Description

You are tuning a complex instrument that requires installing a set of harmonic resonators. The instrument operates on a fundamental capacity **k**. The instrument requires at least one resonator to function, and features a physical structural limit of 22 bays, dictating the minimum and maximum possible values for the capacity **k**.

You are provided with a catalog of **t** available resonator models. The catalog might be completely empty. Each model is manufactured with three specific parameters: alpha, beta, and gamma. These parameters are positive integers that never exceed the fundamental capacity. Because no two resonator models in the catalog have the exact same combination of all three parameters, the maximum possible catalog size **t** is exactly the number of cells in a 3D grid of dimensions **k** by **k** by **k**.

You must select exactly **k** resonator models from the catalog to install into the instrument. Once a set of **k** models is chosen, its *operational load* is calculated based on the frequencies of its parameter values.

Specifically:
- For any integer `x`, let `A_x` be the number of chosen models whose alpha parameter is exactly `x`. The *alpha-load* is the sum of `(A_x × A_x)` over all integers `x`.
- Let `B_x` be the number of chosen models whose beta parameter is exactly `x`. The *beta-load* is the sum of `(B_x × B_x)` over all integers `x`.
- Let `G_x` be the number of chosen models whose gamma parameter is exactly `x`. The *gamma-load* is the sum of `(G_x × G_x)` over all integers `x`.

The total operational load of the selection is the sum of the alpha-load, beta-load, and gamma-load. 

Your task is to determine whether it is possible to select exactly **k** resonator models such that their total operational load is exactly **3k**.

## Input

The first line specifies the fundamental capacity **k** and the catalog size **t**. 

The following **t** lines each contain three positive integers representing the alpha, beta, and gamma parameters of a resonator model.

## Output

If a successful installation of exactly **k** resonators achieving a total operational load of **3k** is possible, print `YES` on the first line. Following this, print **k** lines, each containing the three parameters of an installed resonator model. If multiple valid installations exist, any of them is acceptable, and the models may be printed in any order.

If no such installation is possible, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```

1 1 1

```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, the fundamental capacity **k** is 2, so exactly 2 models must be installed. There are only two available models in the catalog, so both must be selected. The first model has parameters (1, 1, 1) and the second has parameters (2, 1, 2). 

Among these two chosen models:
- For alpha: `A_1 = 1`, `A_2 = 1`, and all other `A_x = 0`. The alpha-load is `1 × 1 + 1 × 1 = 2`.
- For beta: `B_1 = 2`, and all other `B_x = 0`. The beta-load is `2 × 2 = 4`.
- For gamma: `G_1 = 1`, `G_2 = 1`, and all other `G_x = 0`. The gamma-load is `1 × 1 + 1 × 1 = 2`.

The total operational load is `2 + 4 + 2 = 8`. Because the total load is not equal to **3k** (which would be 6), the installation is not successful. Therefore, a successful installation is impossible.
</STATEMENT>
<RATIONALE>
Removed the explicit uniqueness counting (U_alpha + U_beta + U_gamma = 3k) which directly mapped to "distinct elements" and replaced it with a sum of squared frequencies constraint. Because the sum of frequencies is `k`, the minimum possible sum of squares is `k`, achieved if and only if all frequencies are 0 or 1. This forces models to algebraically deduce that a total load of `3k` is synonymous with all parameters being distinct, breaking pattern matching on standard exact-cover formulations. Additionally, bounds were encoded indirectly through the physical limits of the system to satisfy S07.
</RATIONALE>
<PRESERVED_ANSWER>
The mathematical minimum of sum(F_x^2) subject to sum(F_x)=k (where F_x are non-negative integers) is exactly k, occurring only when all F_x are in {0, 1}; therefore, the total load equals 3k if and only if all selected alpha, beta, and gamma values are completely distinct, which is identical to the original problem's condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem requires finding a subset of k triples such that no two share a coordinate across any of the three dimensions, which remains the exact definition of 3-Dimensional Matching (NP-complete).
</PRESERVED_CLASS>

Models might misinterpret the infinite sum "over all integers x", although the finite number of chosen models guarantees only a finite number of non-zero terms, making the math unambiguous.
</RISK>
