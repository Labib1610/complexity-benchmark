# Problem A — Confectionery Formulation

Time limit: 5 s   Memory limit: 256 MB

## Description

A master chocolatier is designing a new tasting box containing exactly **k** unique truffles. The creation process relies on three distinct sets of ingredients, each containing exactly **k** distinct varieties:
- Flavor extracts (identified by integers 1 through k)
- Texturizing agents (identified by integers 1 through k)
- Visual colorants (identified by integers 1 through k)

A single truffle is formulated by combining exactly one flavor extract, one texturizing agent, and one visual colorant. Because some ingredients react poorly with others, the chocolatier has a master recipe book containing only the stable, tested combinations of these three components.

Your task is to select exactly **k** recipes from the master recipe book to form the tasting box. To ensure a perfectly balanced tasting experience, the final selection of **k** truffles must use every flavor extract, every texturizing agent, and every visual colorant exactly once across the entire box.

Determine if such a tasting box can be assembled. If it can, provide one valid set of recipes.

## Input

The first line provides two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k), representing the number of varieties in each ingredient category and the total number of tested recipes in the master book.
The following **t** lines each contain three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), describing a tested recipe consisting of flavor extract **x**, texturizing agent **y**, and visual colorant **z**. No recipe appears more than once in the book.

## Output

If a valid tasting box of **k** recipes can be formulated, output `YES` on the first line. Following this, output **k** lines, each containing three integers `x y z` corresponding to a chosen recipe. Any valid selection that uses every flavor extract, texturizing agent, and visual colorant exactly once is acceptable. The recipes may be printed in any order.

If no such tasting box can be formulated, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both tested recipes require texturizing agent 1, meaning texturizing agent 2 can never be utilized in the tasting box.

Changed the real-world scenario from crew scheduling to chocolate truffle formulation. This completely removes the "time slot" dimension, replacing it with a third ingredient category (colorants) that lacks any chronological implication. This forces the model to recognize the symmetric 3-dimensional matching structure without relying on time-based grouping heuristics.
</RATIONALE>

</PRESERVED_ANSWER>
