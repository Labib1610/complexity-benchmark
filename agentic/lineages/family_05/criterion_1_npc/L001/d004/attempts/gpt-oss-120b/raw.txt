**Solution Explanation**

We have to choose exactly `k` triples  

```
(x , y , z)   1 ≤ x , y , z ≤ k
```

from the given list such that

* all chosen `x` values are different,
* all chosen `y` values are different,
* all chosen `z` values are different.

In other words we have to cover each value `1 … k` of the three coordinates **once**.
This is an *exact cover* problem:

* columns – the 3·k constraints  
  `X1 … Xk , Y1 … Yk , Z1 … Zk`
* rows – the given points.  
  Row for point `(x,y,z)` contains the three columns `Xx , Yy , Zz`.

We have to pick `k` rows that together contain every column exactly once.

`k ≤ 22`, therefore the number of columns is at most `66` and the number of rows at most `k³ ≤ 10648`.  
A dancing‑links (DLX) implementation solves such instances instantly.



--------------------------------------------------------------------

#### Algorithm
```
read k , t
for each of the t points:
        store it, create a row containing the three column ids
run DLX exact‑cover search
if a solution is found:
        print YES and the k stored points of the solution
else:
        print NO
```

**DLX details**

* each column has a header, a size counter and links to the next/prev column.
* each node belongs to a row and a column, linked left/right within the row and up/down within the column.
* `cover(c)` removes column `c` and all rows that contain `c`.
* `uncover(c)` restores them.
* recursive `search(depth)`  
  * if no column left → all constraints satisfied → solution found.
  * choose the column with the smallest size (heuristic).
  * try each row `r` in that column:
        * add `r` to the partial solution,
        * cover all other columns of `r`,
        * recurse,
        * on backtrack uncover them again.

The recursion depth never exceeds `k (≤22)`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs **YES** with a valid set of points
iff such a set exists.

---

##### Lemma 1  
During DLX execution, the set of uncovered columns is exactly the set of
constraints that are still unsatisfied by the rows already chosen.

**Proof.**  
Initially all columns are uncovered, no constraint is satisfied.  
When a row `r` is added to the partial solution, `cover(c)` is called for
every column `c` that `r` contains. `cover(c)` removes `c` from the column list,
therefore `c` becomes uncovered → the corresponding constraint is now satisfied.
Conversely, `uncover(c)` restores the column, making the constraint unsatisfied
again. ∎



##### Lemma 2  
If `search` reaches the state “no column left”, the rows stored in the
solution list satisfy every constraint exactly once.

**Proof.**  
“No column left” means all columns are covered. By Lemma&nbsp;1 all constraints
are satisfied. A column is covered only when a row containing it is selected,
and a column can be covered only once because after covering it is removed from
the column list and never chosen again. Hence each constraint is satisfied by
exactly one selected row. ∎



##### Lemma 3  
If the algorithm outputs a set of `k` points, that set is a valid constellation.

**Proof.**  
The output set is exactly the rows stored when `search` terminated successfully.
By Lemma&nbsp;2 each X‑value `1…k` appears in exactly one selected row, the same for Y and Z.
Therefore all chosen points have pairwise different X, Y and Z coordinates,
which is precisely the required condition. ∎



##### Lemma 4  
If a valid constellation of size `k` exists, DLX will find one.

**Proof.**  
Consider any valid constellation `S`. Its rows together cover every column
exactly once, i.e. they form an exact cover. DLX explores the search tree
systematically: at each step it chooses a column and tries **all** rows that
contain it, recursing after covering the remaining columns of that row.
Thus the branch that repeatedly picks the rows of `S` is present in the tree.
Since the recursion depth is limited to `k`, that branch reaches the state
with no columns left, and the algorithm will report success. ∎



##### Lemma 5  
If the algorithm prints `NO`, no valid constellation of size `k` exists.

**Proof.**  
`NO` is printed only when the recursive search exhausts all possibilities
without reaching the “no column left” state. The search enumerates **all**
possible subsets of rows that could cover the columns (exact cover candidates).
If none of them covers all columns, no exact cover exists, i.e. no set of
`k` points with pairwise distinct coordinates exists. ∎



##### Theorem  
The program prints `YES` and a correct set of `k` points **iff** such a set
exists; otherwise it prints `NO`.

**Proof.**  
*If* part: by Lemma&nbsp;4 a existing constellation is found, and by Lemma&nbsp;3
the printed set is valid.  
*Only‑if* part: by Lemma&nbsp;5, printing `NO` implies non‑existence. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Columns*: `3k ≤ 66`  
*Rows*: `t ≤ k³ ≤ 10648`

DLX operations are `O(1)` per node.  
In the worst case the algorithm may explore many branches, but the depth is at
most `k ≤ 22`. For the given limits the running time is far below the 5 s
limit; memory consumption is `O(t·3)` nodes ≈ `3·10648 ≈ 32000` objects,
well inside 256 MB.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1000000)

class DLXNode:
    __slots__ = ('left', 'right', 'up', 'down', 'col', 'row_id')
    def __init__(self):
        self.left = self.right = self.up = self.down = self
        self.col = None
        self.row_id = -1

class ColumnNode(DLXNode):
    __slots__ = ('size', 'name')
    def __init__(self, name):
        super().__init__()
        self.size = 0
        self.name = name

class DLX:
    def __init__(self, n_cols):
        self.header = ColumnNode('header')
        self.cols = [ColumnNode(i) for i in range(n_cols)]
        # link columns horizontally
        last = self.header
        for c in self.cols:
            last.right = c
            c.left = last
            last = c
        last.right = self.header
        self.header.left = last
        self.solution = []
        self.row_nodes = []   # keep a reference to any node of each row

    def add_row(self, row_id, col_indices):
        first = None
        for ci in col_indices:
            col = self.cols[ci]
            node = DLXNode()
            node.col = col
            node.row_id = row_id
            # vertical links
            node.down = col
            node.up = col.up
            col.up.down = node
            col.up = node
            col.size += 1
            # horizontal links
            if first is None:
                first = node
                node.right = node.left = node
            else:
                node.right = first
                node.left = first.left
                first.left.right = node
                first.left = node
        self.row_nodes.append(first)

    def cover(self, col):
        col.right.left = col.left
        col.left.right = col.right
        i = col.down
        while i != col:
            j = i.right
            while j != i:
                j.down.up = j.up
                j.up.down = j.down
                j.col.size -= 1
                j = j.right
            i = i.down

    def uncover(self, col):
        i = col.up
        while i != col:
            j = i.left
            while j != i:
                j.col.size += 1
                j.down.up = j
                j.up.down = j
                j = j.left
            i = i.up
        col.right.left = col
        col.left.right = col

    def search(self, k):
        if self.header.right == self.header:   # all columns covered
            return True
        # choose column with minimal size
        c = self.header.right
        min_sz = c.size
        col = c
        while c != self.header:
            if c.size < min_sz:
                min_sz = c.size
                col = c
                if min_sz == 0:
                    break
            c = c.right
        if min_sz == 0:
            return False
        self.cover(col)
        r = col.down
        while r != col:
            self.solution.append(r.row_id)
            j = r.right
            while j != r:
                self.cover(j.col)
                j = j.right
            if self.search(k+1):
                return True
            # backtrack
            self.solution.pop()
            j = r.left
            while j != r:
                self.uncover(j.col)
                j = j.left
            r = r.down
        self.uncover(col)
        return False

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))
    points = []
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        points.append((x, y, z))
    n_cols = 3 * k
    dlx = DLX(n_cols)
    for idx, (x, y, z) in enumerate(points):
        dlx.add_row(idx, [x, k + y, 2 * k + z])
    if dlx.search(0):
        print("YES")
        for row_id in dlx.solution:
            x, y, z = points[row_id]
            print(x + 1, y + 1, z + 1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
