<STATEMENT>
# Problem A — Facility Schedule

Time limit: 5 s   Memory limit: 256 MB

## Description

A facility operates using three distinct resource pools. Each pool contains exactly **k** elements:
- Specialists, identified by integers 1 through k,
- Machines, identified by integers 1 through k,
- Time slots, identified by integers 1 through k.

A tri-link is formed by assigning one Specialist to one Machine during one Time slot. Due to strict safety rules, only specific (Specialist, Machine, Time slot) assignments are allowed. You are given an approved list of these allowed assignments.

Your task is to build a full schedule consisting of exactly **k** allowed assignments chosen from the approved list. To ensure safe operation, the chosen assignments must be entirely mutually exclusive. Specifically, no two assignments in the schedule may share the same Specialist, no two assignments may share the same Machine, and no two assignments may share the same Time slot.

Determine if such a schedule can be constructed. If it can, provide one valid set of **k** assignments.

## Input

The first line provides two integers **k** and **t**. The integer **k** represents the headcount of Specialists (which is equal to the number of Machines and Time slots); this headcount is at least 1 and cannot exceed the facility's maximum operational capacity of 22. The integer **t** represents the size of the approved list, ranging from 0 up to the theoretical maximum of k·k·k.

The following **t** lines each contain three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), describing an allowed assignment consisting of Specialist **x**, Machine **y**, and Time slot **z**. No assignment appears more than once in the approved list.

## Output

If a valid schedule of **k** assignments can be constructed, output `YES` on the first line. Following this, output **k** lines, each containing three integers `x y z` corresponding to a chosen assignment. Any valid schedule meeting the mutual exclusivity conditions is acceptable. The assignments may be printed in any order.

If no such schedule can be constructed, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both allowed assignments use Machine 1. A schedule of exactly 2 assignments cannot be formed without reusing Machine 1, which violates the mutual exclusivity conditions.
