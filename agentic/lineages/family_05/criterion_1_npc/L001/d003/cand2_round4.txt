# Problem A — Crew Assembly

Time limit: 5 s   Memory limit: 256 MB

## Description

A facility must schedule a set of diagnostic tests. There are **k** Technicians available (numbered 1 to **k**). The facility has **k** Diagnostic bays (numbered 1 to **k**) and **k** Processing cores (numbered 1 to **k**).

A valid test requires the exclusive assignment of exactly one Technician, one Diagnostic bay, and one Processing core. However, only certain specific groupings of these three resources are certified to work together safely. You are given a list of **t** such certified groupings.

Your objective is to determine whether it is possible to select exactly **k** tests from the provided list such that they are entirely mutually exclusive. Specifically, no two selected tests may share the same Technician, no two may share the same Diagnostic bay, and no two may share the same Processing core.

Determine if such a selection exists. If it does, provide one valid set of **k** tests.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k). Here, **k** represents the number of resources in each of the three categories, and **t** is the number of certified groupings provided.

The next **t** lines each contain three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k). Each line describes a certified grouping consisting of Technician **x**, Diagnostic bay **y**, and Processing core **z**. No grouping appears more than once in the list.

## Output

If a valid selection of exactly **k** tests exists, output `YES` on the first line. Following this, output **k** lines, each containing three integers `x y z` corresponding to a chosen certified grouping. Every Technician, Diagnostic bay, and Processing core must be used exactly once among the **k** printed groupings. Any valid selection is acceptable, and the groupings may be printed in any order.

If no such selection exists, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both certified groupings rely on Diagnostic bay 1. A selection of exactly 2 tests cannot be formed without reusing Diagnostic bay 1, which violates the mutual exclusivity requirement.
