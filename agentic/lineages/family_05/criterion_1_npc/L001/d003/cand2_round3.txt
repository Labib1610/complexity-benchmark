# Problem A — Reactor Maintenance

Time limit: 5 s   Memory limit: 256 MB

## Description

A maintenance operation requires coordinating three distinct pools of resources. Each pool contains exactly **k** elements:
- Technicians, identified by integers 1 through **k**,
- Diagnostic Bays, identified by integers 1 through **k**,
- Reactor Cores, identified by integers 1 through **k**.

A maintenance task is formed by linking one Technician, one Diagnostic Bay, and one Reactor Core. Due to strict safety protocols, only specific (Technician, Bay, Core) combinations are authorized. You will receive a catalog of these authorized combinations.

Your task is to select exactly **k** authorized combinations from the catalog to form a complete schedule. In a valid schedule, every Technician, every Diagnostic Bay, and every Reactor Core must be utilized exactly once.

Determine if such a schedule can be formulated. If it can, provide one valid set of **k** combinations.

## Input

The first line provides two integers **k** and **t**. The value **k** represents the size of each resource pool. A facility requires at least 1 of each resource type, up to a structural limit of 22. The value **t** represents the number of authorized combinations in the catalog, starting from 0 up to a theoretical maximum of k·k·k.

The following **t** lines each contain three integers **x**, **y**, **z** (each bounded between 1 and **k** inclusive), describing an authorized combination consisting of Technician **x**, Diagnostic Bay **y**, and Reactor Core **z**. No combination appears more than once in the catalog.

## Output

If a valid schedule of **k** combinations can be formulated, output `YES` on the first line. Following this, output **k** lines, each containing three integers `x y z` corresponding to a chosen combination. Any valid schedule meeting the conditions is acceptable. The combinations may be printed in any order.

If no such schedule can be formulated, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both authorized combinations use Diagnostic Bay 1. A schedule of exactly 2 combinations cannot be formed without reusing Diagnostic Bay 1, which violates the condition that each bay must be utilized exactly once.
