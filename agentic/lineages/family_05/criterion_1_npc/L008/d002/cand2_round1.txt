<STATEMENT>
# Problem A — Cosmic Resonance

Time limit: 5 s   Memory limit: 256 MB

## Description

You are analyzing a spatial anomaly within a cubic sector. The sector is partitioned into a discrete coordinate system $(x, y, z)$, where each axis is indexed by an integer from 1 to **k**. The sector's dimensions are constrained such that **k** is at least 1 and at most 22.

Within this sector, your sensors have identified **t** stable energy signatures. Each signature is located at a specific grid coordinate. There might be no signatures, or there could be up to k·k·k signatures.

Your task is to isolate exactly **k** of these stable signatures to trigger a "perfect resonance". To prevent destructive interference, the isolated signatures must be completely orthogonal. Specifically, no two chosen signatures may share the same $x$-coordinate, no two may share the same $y$-coordinate, and no two may share the same $z$-coordinate. 

Determine whether it is possible to trigger a perfect resonance. If it is possible, report the coordinates of the signatures you have isolated.

## Input

The first line contains two integers **k** and **t** (1 ≤ k ≤ 22, 0 ≤ t ≤ k·k·k): the size of the sector along each dimension, and the number of detected energy signatures.
Each of the next **t** lines contains three integers **x**, **y**, **z** (1 ≤ x, y, z ≤ k), representing the location of a stable energy signature. No coordinate triplet appears more than once in the input.

## Output

If a perfect resonance can be triggered by isolating exactly **k** signatures, output `YES` on the first line. Following this, output **k** lines, each containing the three integers `x y z` of an isolated signature. Any valid set of **k** signatures where no two share the same $x$, $y$, or $z$ coordinate is accepted. You may print the chosen signatures in any order.

If no such set of signatures exists, output `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 2 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 1 2
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```

## Note

In Example 2, both available signatures have a $y$-coordinate of 1. If you choose either of them, you cannot choose the other without violating the condition that no two signatures share the same $y$-coordinate. Since you must choose exactly 2 signatures, it is impossible to avoid interference.
</STATEMENT>
<RATIONALE>
The problem was completely reframed from an alchemy ingredient matching task to a 3D grid selection task. The core constraint was changed from "every item must be used exactly once" to "choose k items such that no two share a coordinate". This forces the model to recognize that selecting k non-overlapping items from k possible options per dimension is mathematically equivalent to an exact cover, rather than relying on surface-level exact-cover phrasing.
</RATIONALE>
<PRESERVED_ANSWER>
Selecting exactly k signatures with no shared x, y, or z coordinates among k possible values means every coordinate 1 through k must appear exactly once in each dimension, which is logically identical to using every ingredient exactly once as required by the seed problem.
</PRESERVED_ANSWER>

The problem remains 3-Dimensional Matching (an NP-complete problem), as it still requires finding a subset of k triples from a given set such that all elements across the three dimensional sets are covered exactly once.
</PRESERVED_CLASS>
