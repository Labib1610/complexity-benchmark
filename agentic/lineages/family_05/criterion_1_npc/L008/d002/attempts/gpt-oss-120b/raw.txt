**Solution Explanation**

For every plane number `1 … k` we need exactly one sensor whose
* x‑coordinate* is that number,
exactly one whose * y‑coordinate* is that number and
exactly one whose * z‑coordinate* is that number.
So we have to choose `k` triples  

```
(xi , yi , zi)      i = 1 … k
```

such that  

* all `xi` are different,
* all `yi` are different,
* all `zi` are different,

and every chosen triple must belong to the given list of stable
coordinates.

The problem is an **exact cover** problem:
the universe consists of the `3·k` items  

```
X1 … Xk ,   Y1 … Yk ,   Z1 … Zk
```

and each stable coordinate is a subset containing exactly three items
`{Xx , Yy , Zz}`.
We have to pick `k` subsets that together cover every item exactly once.

`k ≤ 22`, therefore a simple depth‑first search with bit masks is fast
enough.

--------------------------------------------------------------------

#### Data structures

* `rows_by_x[x]` – list of all stable coordinates whose x‑coordinate is `x`
  (each element is a pair `(y, z)`).
* three bit masks  

```
maskX , maskY , maskZ          (k bits each)
```

  `maskX` has a `1` at position `x-1` iff plane `x` is already used,
  analogously for `maskY` and `maskZ`.
* `solution` – list of chosen triples (will contain exactly `k` elements).

--------------------------------------------------------------------

#### Recursive search  

```
search(maskX, maskY, maskZ):
    if maskX has k bits set:          # all X‑planes are used → solution found
        return True

    choose the smallest x (1‑based) with bit 0 in maskX   # branching factor is small
    for each (y, z) in rows_by_x[x]:
        if bit y-1 not set in maskY and bit z-1 not set in maskZ:
            set the three bits
            add (x, y, z) to solution
            if search(new masks): return True
            undo the three bits and pop from solution
    return False
```

The recursion depth is at most `k (≤22)`.  
In the worst case we try every stable coordinate once, i.e. `O(t)` work,
which is far below the limits (`t ≤ k³ ≤ 10648`).

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs **YES** with a correct set of
coordinates iff such a set exists.

---

##### Lemma 1  
During the execution of `search` the three masks always represent the
set of planes already covered by the triples stored in `solution`.

**Proof.**  
Initially all masks are zero and `solution` is empty – the statement holds.
When the algorithm adds a triple `(x,y,z)` it sets the three corresponding
bits and appends the triple to `solution`. When it backtracks it clears the
same bits and removes the triple. No other modifications are performed.
∎



##### Lemma 2  
If `search` reaches the line `if maskX has k bits set` then `solution`
contains exactly `k` triples and each plane `1 … k` appears exactly once
in each dimension.

**Proof.**  
`maskX` has `k` bits set ⇔ every X‑plane is covered.
Because each added triple also sets one new Y‑bit and one new Z‑bit
(Lemma&nbsp;1) and the algorithm never adds a triple whose Y‑ or Z‑bit is
already set, all Y‑ and Z‑bits are also distinct.
The number of triples equals the number of set X‑bits, i.e. `k`. ∎



##### Lemma 3  
If a valid deployment exists, `search` eventually returns `True`.

**Proof.**  
Consider any valid set `S` of `k` triples.
The recursion always picks the smallest uncovered X‑plane `x`.
Since `S` contains a triple with this `x`, that triple is present in
`rows_by_x[x]`. Its Y and Z values are still uncovered because `S` uses
each plane only once. Hence the algorithm will try this triple,
add it and continue recursively.
Inductively the algorithm can follow the triples of `S` step by step,
never backtracking, and finally reaches the success condition.
Therefore it returns `True`. ∎



##### Lemma 4  
If `search` returns `True`, the triples stored in `solution` form a valid
deployment.

**Proof.**  
By Lemma&nbsp;2 the condition for returning `True` guarantees that
`solution` contains `k` triples covering each plane exactly once in every
dimension, i.e. a valid deployment. ∎



##### Theorem  
The program prints  

* `YES` and a correct list of `k` coordinates **iff** such a list exists,
* otherwise it prints `NO`.

**Proof.**  

*If a deployment exists*: by Lemma&nbsp;3 `search` returns `True`,
by Lemma&nbsp;4 the collected triples are valid, and the program prints
`YES` followed by them.

*If no deployment exists*: assume the program would print `YES`. Then
`search` must have returned `True`, contradicting Lemma&nbsp;4 because a
valid deployment would then exist. Hence `search` returns `False` and the
program prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`k ≤ 22`, `t ≤ k³ ≤ 10648`.

*Each recursive call* scans at most all triples with the current `x`,
overall each triple is examined at most once per level, so the total
work is `O(t)`.  
The recursion depth is `k`, therefore the memory consumption is `O(k)` for
the masks and the solution list.

Both time (`≤ 10⁴` operations) and memory (`<< 1 MB`) are far inside the
limits.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    rows_by_x = [[] for _ in range(k + 1)]          # 1‑based
    for _ in range(t):
        x = int(next(it)); y = int(next(it)); z = int(next(it))
        rows_by_x[x].append((y, z))

    full_mask = (1 << k) - 1
    solution = []

    sys.setrecursionlimit(10000)

    def search(maskX: int, maskY: int, maskZ: int) -> bool:
        if maskX == full_mask:          # all X‑planes are used
            return True

        # choose smallest uncovered X
        # (~maskX) has 1s where not used, isolate lowest set bit
        # but we need index, simple loop is fine (k ≤ 22)
        for x in range(1, k + 1):
            if not (maskX >> (x - 1)) & 1:
                break

        for y, z in rows_by_x[x]:
            bity = 1 << (y - 1)
            bitz = 1 << (z - 1)
            if (maskY & bity) or (maskZ & bitz):
                continue
            # take this triple
            solution.append((x, y, z))
            if search(maskX | (1 << (x - 1)), maskY | bity, maskZ | bitz):
                return True
            solution.pop()
        return False

    if search(0, 0, 0):
        out = ["YES"]
        out.extend(f"{x} {y} {z}" for x, y, z in solution)
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
