We can model this as a bipartite matching problem.  
Each specialist is already fixed to a machine, so we can treat each specialist–machine pair as a single node on the left.  
Each time slot is a node on the right.  
We need to match each specialist–machine pair to a distinct time slot, using only allowed combinations.

Since each specialist is already assigned to exactly one machine, we can reduce the problem to:  
- Left side: k specialists (each with a fixed machine).  
- Right side: k time slots.  
- Edge exists if the triple (x, y, z) is allowed.

We need a perfect matching.  
We can use DFS-based bipartite matching (Kuhn’s algorithm) since k ≤ 1200.

import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    k = int(next(it))
    t = int(next(it))
    
    # We'll store allowed time slots for each specialist
    allowed = [[] for _ in range(k)]
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        # x is specialist, y is machine (fixed), z is time slot
        allowed[x].append(z)
    
    # Kuhn's algorithm for bipartite matching
    match_to_spec = [-1] * k  # time slot -> specialist
    match_to_time = [-1] * k  # specialist -> time slot
    
    def dfs(spec, visited):
        for time_slot in allowed[spec]:
            if not visited[time_slot]:
                visited[time_slot] = True
                if match_to_spec[time_slot] == -1 or dfs(match_to_spec[time_slot], visited):
                    match_to_spec[time_slot] = spec
                    match_to_time[spec] = time_slot
                    return True
        return False
    
    for spec in range(k):
        visited = [False] * k
        if not dfs(spec, visited):
            print("NO")
            return
