 We can model this as a matching problem.  
Since each API endpoint is already tied to exactly one database shard, we only need to assign IP addresses to endpoints.  
That means we can reduce the problem to:  

- We have `k` endpoints, each with a fixed database shard.  
- We have a list of allowed IPs for each endpoint.  
- We need to assign each endpoint a distinct IP from its allowed list.  

This is a **bipartite matching** problem between endpoints and IPs.  
We can solve it using **maximum bipartite matching** (e.g., Hopcroft–Karp or DFS-based augmenting path).  

Here’s the implementation:  

```python
import sys
sys.setrecursionlimit(1000000)

def main():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    
    # For each endpoint, store allowed IPs
    allowed = [[] for _ in range(k + 1)]
    # Also store the fixed database shard for each endpoint
    db_for_endpoint = [0] * (k + 1)
    
    for _ in range(t):
        e, d, i = map(int, input().split())
        allowed[e].append(i)
        db_for_endpoint[e] = d
    
    # Bipartite matching: endpoints (1..k) -> IPs (1..k)
    match_ip = [0] * (k + 1)  # which endpoint is assigned to each IP
    visited = [False] * (k + 1)
    
    def dfs(e):
        for ip in allowed[e]:
            if not visited[ip]:
                visited[ip] = True
                if match_ip[ip] == 0 or dfs(match_ip[ip]):
                    match_ip[ip] = e
                    return True
        return False
    
    for e in range(1, k + 1):
        visited = [False] * (k + 1)
        if not dfs(e):
            print("NO")
            return
    
    # If we reach here, matching exists
    print("YES")
    for ip in range(1, k + 1):
        e = match_ip[ip]
        d = db_for_endpoint[e]
        print(e, d, ip)

if __name__ == "__main__":
    main()
```
