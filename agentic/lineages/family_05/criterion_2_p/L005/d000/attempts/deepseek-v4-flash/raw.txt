We can model this as a bipartite matching problem between protein–receptor pairs and catalyst enzymes.  

Since each protein is tied to exactly one receptor siteable to be fully deterministic, we'll map protein chains (1..k) to their fixed receptor sites)Skip that: We just need to assign a distinct catalyst to each protein–receptor pair. This is exactly a matching problem between the set of `(protein, receptor)` pairs (each protein has its unique receptor) and the available catalysts.  

We can solve it using **maximum bipartite matching** via DFS (Kuhn's algorithm).  
If the maximum matches equals `k`, then YES and output chosen edges.

Here’s the implementation:

```python
import sys

def main():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    # Map protein -> receptor, and store possible catalysts for each protein
    protein_receptor = {}
    protein_catalysts = {}
    
    # Protein is tied to exactly one receptor due to constraints
    for _ in range(t):
        x, y, z = map(int, input().split())
        protein_receptor[x] = y
        protein_catalysts.setdefault(x, []).append(z)
    
    # If any protein has no complexes at all, impossible
    if len(protein_receptor) != k:
        print("NO")
        return
    
    # Build matching from catalysts to proteins
    match_catalyst = {}   # catalyst -> protein
    match_protein = {}    # protein -> catalyst
    
    # Kuhn's algorithm for bipartite matching
    def try_kuhn(p, visited):
        for c in protein_catalysts.get(p, []):
            if c in visited:
                continue
            visited.add(c)
            if c not in match_catalyst or try_kuhn(match_catalyst[c], visited):
                match_catalyst[c] = p
                match_protein[p] = c
                return True
        return False
    
    for p in range(1, k+1):
        visited = set()
        if not try_kuhn(p, visited):
            print("NO")
            return
    
    # If we matched all k proteins
    print("YES")
    for p in range(1, k+1):
        print(p, protein_receptor[p], match_protein[p])

if __name__ == "__main__":
    main()
```
