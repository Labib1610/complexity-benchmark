We can model this as a matching problem.  
Each catalyst is paired with a unique reagent, so we can treat each catalyst–reagent pair as a single node on the left side, and solvents as nodes on the right side.  
We need to match each catalyst–reagent pair to a distinct solvent, using only the given configurations.

This becomes a bipartite matching problem:  
- Left side: catalyst–reagent pairs (size k)  
- Right side: solvents (size k)  
- Edge exists if the configuration (x, y, z) is in the catalog.

We can solve it with a standard DFS-based bipartite matching (Kuhn’s algorithm), which is fast enough for k ≤ 1200.

```python
import sys
sys.setrecursionlimit(1000000)

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    
    # Map each catalyst to its reagent
    cat_to_reagent = {}
    # Store edges: for each catalyst, list of solvents
    edges = [[] for _ in range(k + 1)]
    
    for _ in range(t):
        x, y, z = map(int, input().split())
        cat_to_reagent[x] = y
        edges[x].append(z)
    
    # Bipartite matching: left = catalyst (1..k), right = solvent (1..k)
    match_solvent = [0] * (k + 1)  # match_solvent[s] = catalyst assigned to solvent s
    match_cat = [0] * (k + 1)      # match_cat[c] = solvent assigned to catalyst c
    
    def dfs(cat, visited):
        for sol in edges[cat]:
            if not visited[sol]:
                visited[sol] = True
                if match_solvent[sol] == 0 or dfs(match_solvent[sol], visited):
                    match_solvent[sol] = cat
                    match_cat[cat] = sol
                    return True
        return False
    
    for cat in range(1, k + 1):
        visited = [False] * (k + 1)
        if not dfs(cat, visited):
            print("NO")
            return
    
    # If we matched all catalysts, output YES
    print("YES")
    for cat in range(1, k + 1):
        sol = match_cat[cat]
        reagent = cat_to_reagent[cat]
        print(cat, reagent, sol)

if __name__ == "__main__":
    solve()
```
