# Phase II: Telemetry Routing

Time limit: 2 s   Memory limit: 256 MB

## Description
The orbital observatory's data pipeline operates in three distinct phases:

**Phase I: Sensor Calibration.** The observatory has $k$ sensor arrays and $k$ signal processors, each numbered 1 to $k$. During calibration, the onboard diagnostic system locks each sensor array to exactly one unique signal processor. This one-to-one lock is hardware-enforced and cannot be changed. This phase has already concluded successfully.

**Phase II: Telemetry Routing.** The observatory has $k$ transmission antennas, numbered 1 to $k$. To downlink the data, the system must establish exactly $k$ active telemetry channels. A valid channel consists of one sensor array, one signal processor, and one transmission antenna. You are provided a list of pre-verified channel configurations generated by the onboard computer. Your task is to select exactly $k$ channels from this list such that every sensor array, every signal processor, and every transmission antenna is utilized in exactly one active channel. 

**Phase III: Data Downlink.** Once you select the channels, the system will execute the downlink sequence using your selection.

Given the list of pre-verified channel configurations (which respects the hardware locks from Phase I), determine if a valid Phase II routing selection exists. If it does, output the selected channels.

## Input
The first line contains two integers $k$ and $t$ ($1 \le k \le 1200$, $0 \le t \le k \cdot k$), representing the number of components of each type (sensor arrays, signal processors, transmission antennas) and the number of pre-verified channel configurations, respectively.

Each of the next $t$ lines contains three integers $s$, $p$, and $a$ ($1 \le s, p, a \le k$), describing a pre-verified channel configuration consisting of sensor array $s$, signal processor $p$, and transmission antenna $a$. All listed configurations are unique. As guaranteed by Phase I, any configurations involving the same sensor array $s$ will always feature the same signal processor $p$, and no two distinct sensor arrays will be locked to the same signal processor.

## Output
If it is possible to select exactly $k$ channels that satisfy the Phase II requirements, print `YES` on the first line. Then, print $k$ lines, each containing the three integers $s$ $p$ $a$ of a selected channel. The channels can be printed in any order. If multiple valid selections exist, any of them will be accepted.

If no such selection exists, print `NO`.

## Examples

### Example 1

**Input**
```
2 3
1 1 1
1 1 2
2 2 2
```

**Output**
```
YES
1 1 1
2 2 2
```

### Example 2

**Input**
```
2 2
1 1 1
2 2 1
```

**Output**
```
NO
```

### Example 3

**Input**
```
1 1
1 1 1
```

**Output**
```
YES
1 1 1
```
