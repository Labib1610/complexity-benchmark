We can model this as a bipartite matching problem:  

- Each director–film pair is fixed (since each director has exactly one film).  
- We need to assign each director to a unique screening room.  
- This becomes: match directors to rooms using the given acceptable configurations.

We can solve it using maximum bipartite matching (Hopcroft–Karp or DFS-based augmenting path).  
Since k ≤ 1200, an O(k·t) DFS matching is fine.

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    
    # Since each director has exactly one film, we can map director -> film
    director_film = {}
    # adjacency: director -> list of rooms
    adj = [[] for _ in range(k + 1)]
    
    for _ in range(t):
        d, f, s = map(int, input().split())
        director_film[d] = f
        adj[d].append(s)
    
    # Matching: room -> director
    match_room = [0] * (k + 1)
    
    def dfs(d, visited):
        for s in adj[d]:
            if not visited[s]:
                visited[s] = True
                if match_room[s] == 0 or dfs(match_room[s], visited):
                    match_room[s] = d
                    return True
        return False
    
    matched = 0
    for d in range(1, k + 1):
        visited = [False] * (k + 1)
        if dfs(d, visited):
            matched += 1
    
    if matched == k:
        print("YES")
        for s in range(1, k + 1):
            d = match_room[s]
            print(d, director_film[d], s)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
