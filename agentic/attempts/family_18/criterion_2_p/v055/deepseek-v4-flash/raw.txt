We need to assign bay numbers \(1..n\) to nodes such that the total cable length equals the sum of absolute differences over all edges, and it must be ≤ \(B\).

This is like finding a **linear arrangement** of a tree with a given maximum cut-sum.  
We can use a DFS-based dynamic programming approach.

However, here’s a key insight:  
If we have a tree (which can be rooted anywhere), the total cable cost for any permutation can be computed by summing, over each edge, the size of the smaller side of the tree when that edge is removed — this works if we assign positions in order of visiting via DFS, which gives the optimal *bandwidth* arrangement.  

But since our budget \(B\) might be larger than the minimum possible sum, we can often just output the "DFS order" assignment, which tends to give a small total, and this can match small budgets. If even the minimal possible arrangement exceeds \(B\), it’s impossible.

So algorithm:
1. Build adjacency.
2. DFS from 1 to compute subtree sizes (sizes of components if each edge removed).
3. Compute minimal possible sum = sum over edges of min(size_subtree, n - size_subtree).
4. If minimal > B → NO.
5. Else assign bay numbers by DFS order (nodes in discovery order) → this gives the minimal sum.
6. Output YES and the assignment.

Implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, B = map(int, input().split())
    g = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        g[u].append(v)
        g[v].append(u)
    
    parent = [-1]*n
    order = []
    stack = [0]
    parent[0] = 0
    while stack:
        u = stack.pop()
        order.append(u)
        for v in g[u]:
            if parent[v] == -1:
                parent[v] = u
                stack.append(v)
    
    size = [1]*n
    for u in reversed(order):
        for v in g[u]:
            if parent[v] == u:
                size[u] += size[v]
    
    min_cost = 0
    for u in range(1, n):
        s = size[u]
        min_cost += min(s, n - s)
    
    if min_cost > B:
        print("NO")
        return
    
    # Assign by DFS preorder
    assign = [0]*n
    idx = 1
    stack = [0]
    visited = [False]*n
    visited[0] = True
    while stack:
        u = stack.pop()
        assign[u] = idx
        idx += 1
        for v in g[u]:
            if not visited[v]:
                visited[v] = True
                stack.append(v)
    
    print("YES")
    print(" ".join(map(str, assign)))

if __name__ == "__main__":
    solve()
```
