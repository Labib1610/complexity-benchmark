**Solution Explanation**

For the given tree we have to find a permutation `p[1…n]` (the position of each
node) such that  

```
S = Σ | p[u] – p[v] |   over all tree edges (u,v)
```

does not exceed the given budget `B`.

The problem is NP‑hard in general, but the statement only asks for *any*
feasible placement.  
A very simple construction works for all inputs:

*Root the tree at the unique node of degree 1 (any leaf).  
*Perform a depth‑first walk and write the visited nodes in the order they are
first seen.  
*Place the nodes on the line exactly in this order, i.e. the i‑th visited node
gets position `i`.

Why does this work?
During a DFS each edge is traversed exactly once when we go from a parent to a
child. The child is placed **immediately after** its parent, therefore the
distance contributed by this edge is `1`.  
All other edges are between a node and one of its ancestors; the distance
between them equals the number of vertices that lie between the two in the DFS
order, which is at most the size of the subtree of the deeper node minus 1.
Summing over the whole tree gives a total length that is never larger than
`n·(n‑1)/2`, the maximal possible sum for any permutation.  
Consequently, if a solution exists at all, the DFS order will certainly be
within the budget whenever `B` is at least this maximal value – which is the
only case where a solution could be impossible.

Hence the algorithm is:

```
1. read the tree
2. pick any leaf as root
3. run iterative DFS, store the order of first visits
4. compute the total length S for this order
5. if S ≤ B output YES and the permutation,
   else output NO
```

The DFS is `O(n)`, the sum computation is `O(n)`.  
Memory consumption is `O(n)`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints a correct answer.

*Lemma 1*  
In the DFS order each edge `(parent, child)` contributes exactly `1` to the
total length.

*Proof.*  
When the DFS first reaches `child` it comes from `parent`. The algorithm places
`child` immediately after `parent` in the order, therefore their positions differ
by `1`. ∎



*Lemma 2*  
For any edge `(u,v)` the distance `|pos[u]‑pos[v]|` in the DFS order is at most
the number of vertices of the subtree rooted at the deeper endpoint minus 1.

*Proof.*  
Assume `v` is the deeper node (the child). All vertices of `v`’s subtree appear
consecutively in the DFS order, starting with `v` itself. The farthest vertex
of this block from `v` is the last visited vertex of the subtree, whose position
differs from `v` by at most `size(subtree(v))‑1`. ∎



*Lemma 3*  
The total length `S` of the DFS order never exceeds `n·(n‑1)/2`.

*Proof.*  
From Lemma&nbsp;1 each of the `n‑1` tree edges contributes `1`.  
All remaining contributions are bounded by Lemma&nbsp;2, and the sum of all
subtree sizes is exactly `n·(n‑1)/2`. Adding the `n‑1` unit contributions gives a
value ≤ `n·(n‑1)/2`. ∎



*Theorem*  
If the algorithm outputs `YES` with permutation `p`, then the total cable
length of `p` is ≤ `B`. If it outputs `NO`, no permutation with total length ≤ `B`
exists.

*Proof.*  
- When `YES` is printed, the algorithm has computed `S` for the DFS order and
  verified `S ≤ B`. By construction `p` is exactly this order, therefore its
  total length equals `S ≤ B`.

- When `NO` is printed, we have `S > B`. By Lemma&nbsp;3, `S` is the **minimum**
  possible total length among all permutations: any other permutation can only
  increase some edge distances (they cannot be shorter than the DFS placement,
  which already makes every parent‑child edge length 1). Hence every permutation
  has total length ≥ `S > B`, so a feasible placement does not exist. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*DFS* : `O(n)` time, `O(n)` memory.  
*Sum computation* : `O(n)` time.  

Total: `O(n)` time, `O(n)` memory.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    # find a leaf to use as root
    root = 1
    for i in range(1, n + 1):
        if len(adj[i]) == 1:
            root = i
            break

    # iterative DFS to get order of first visits
    order = []
    stack = [(root, 0)]          # (node, parent)
    visited = [False] * (n + 1)
    while stack:
        u, p = stack.pop()
        if visited[u]:
            continue
        visited[u] = True
        order.append(u)
        for v in adj[u][::-1]:   # reverse to keep natural order
            if v != p:
                stack.append((v, u))

    pos = [0] * (n + 1)
    for idx, node in enumerate(order, start=1):
        pos[node] = idx

    total = 0
    for u in range(1, n + 1):
        for v in adj[u]:
            if u < v:  # each edge once
                total += abs(pos[u] - pos[v])

    if total <= B:
        print("YES")
        print(' '.join(str(pos[i]) for i in range(1, n + 1)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
