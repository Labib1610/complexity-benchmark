We need to assign machines to bays (a permutation of 1..n) so that the sum of |pos[u] - pos[v]| over all edges is ≤ B.  
The graph is a tree (n-1 edges).  

We can think of this as: we have a tree, and we want to place its nodes on a line (positions 1..n) to minimize the sum of edge lengths.  
The optimal way to minimize the sum of edge lengths for a tree on a line is to place nodes in a DFS order (or BFS) such that subtrees are contiguous. This is equivalent to finding a linear arrangement that minimizes the sum of edge lengths, which is known to be NP-hard in general, but for trees there is a known optimal solution: place nodes in the order of a DFS traversal, because that keeps each subtree contiguous and minimizes the sum of distances.

However, we don't necessarily need the absolute minimum; we just need a solution within budget B.  
A simple approach:  
- Root the tree at node 1.  
- Do a DFS, and assign positions in the order of first visit.  
This gives a valid permutation.  
- Compute the total cost. If ≤ B, output YES and the permutation.  
- If not, we can try other orderings (e.g., BFS, or reverse DFS, or try different roots) to see if any fits.  
But since n can be large (up to maybe 2e5), we need an O(n) or O(n log n) solution.

We can also try to place nodes in a "centroid" order, but DFS is simple and often works.

Let's implement:  
1. Read n, m, B.  
2. Build adjacency list.  
3. Do DFS from node 1, assign positions in preorder.  
4. Compute total cost.  
5. If cost ≤ B, print YES and the positions.  
6. Else, try BFS order, or reverse preorder, etc.  
If none works, print NO.

But we must be careful: The problem guarantees m = n-1, so it's a tree.  
We can also try to place nodes in a "level order" (BFS) which might reduce cost for star-like trees.

Let's implement multiple strategies and pick the first that fits.

We'll write a function to compute cost given an order.

Edge cases: n=1, cost=0.

Let's code.```python
import sys
from collections import deque

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    # Try multiple orderings
    orders = []
    
    # 1. DFS preorder from node 0
    parent = [-1]*n
    order = []
    stack = [0]
    parent[0] = -2
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if parent[v] == -1:
                parent[v] = u
                stack.append(v)
    orders.append(order)
    
    # 2. BFS order
    order = []
    q = deque([0])
    parent = [-1]*n
    parent[0] = -2
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj[u]:
            if parent[v] == -1:
                parent[v] = u
                q.append(v)
    orders.append(order)
    
    # 3. Reverse of DFS preorder
    parent = [-1]*n
    order = []
    stack = [0]
    parent[0] = -2
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if parent[v] == -1:
                parent[v] = u
                stack.append(v)
    orders.append(order[::-1])
    
    # 4. Reverse BFS
    order = []
    q = deque([0])
    parent = [-1]*n
    parent[0] = -2
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj[u]:
            if parent[v] == -1:
                parent[v] = u
                q.append(v)
    orders.append(order[::-1])
    
    # Also try starting from each node? Too slow. But we can try a few.
    # Try starting from node with max degree
    deg = [len(adj[i]) for i in range(n)]
    start = max(range(n), key=lambda i: deg[i])
    for s in [start]:
        parent = [-1]*n
        order = []
        stack = [s]
        parent[s] = -2
        while stack:
            u = stack.pop()
            order.append(u)
            for v in adj[u]:
                if parent[v] == -1:
                    parent[v] = u
                    stack.append(v)
        orders.append(order)
    
    # Try BFS from max degree
    for s in [start]:
        order = []
        q = deque([s])
        parent = [-1]*n
        parent[s] = -2
        while q:
            u = q.popleft()
            order.append(u)
            for v in adj[u]:
                if parent[v] == -1:
                    parent[v] = u
                    q.append(v)
        orders.append(order)
    
    seen = set()
    for order in orders:
        # assign positions: order[0] -> 1, order[1] -> 2, ...
        pos = [0]*n
        for i, node in enumerate(order):
            pos[node] = i+1
        # compute cost
        cost = 0
        for u in range(n):
            for v in adj[u]:
                if u < v:
                    cost += abs(pos[u] - pos[v])
        if cost <= B:
            print("YES")
            print(" ".join(str(pos[i]) for i in range(n)))
            return
    
    print("NO")

if __name__ == "__main__":
    solve()
