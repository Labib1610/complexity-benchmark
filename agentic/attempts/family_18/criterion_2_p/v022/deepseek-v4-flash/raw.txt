We can model the entities and interactions as a tree (since \( m = n-1 \) and it’s connected).  
The problem reduces to: can we assign distinct integers \( 1 \dots n \) to tree nodes so that the sum of absolute differences along edges is \(\le B\)?

A key observation: For any tree, the **minimum possible sum** of absolute differences over all edges is achieved by placing nodes in **DFS order** (or any order that respects the tree’s structure).  
In fact, the minimum possible total cost is:

\[
\text{min\_cost} = \sum_{\text{edges}} |\text{pos}(u) - \text{pos}(v)|
\]

The optimal arrangement is to assign positions according to a **DFS traversal** of the tree. This yields the smallest possible sum because it minimizes the “spread” of connected nodes.

So the algorithm is:
1. Build adjacency list from input.
2. Perform DFS from node 1, assigning positions in the order visited.
3. Compute the total cost for this assignment.
4. If cost \(\le B\), output `YES` and the assignment; otherwise `NO`.

Let’s implement it.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    n, m, B = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    pos = [0] * n
    visited = [False] * n
    order = []
    
    def dfs(u):
        visited[u] = True
        order.append(u)
        for v in adj[u]:
            if not visited[v]:
                dfs(v)
    
    dfs(0)
    
    # Assign positions 1..n in DFS order
    for idx, node in enumerate(order):
        pos[node] = idx + 1
    
    # Compute cost
    cost = 0
    for u in range(n):
        for v in adj[u]:
            if u < v:
                cost += abs(pos[u] - pos[v])
    
    if cost <= B:
        print("YES")
        print(" ".join(map(str, pos)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
