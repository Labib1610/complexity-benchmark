We can model the modules and cables as a tree.  
The problem asks if we can assign the tree’s nodes to positions 1..n on a line so that the sum of edge lengths is ≤ B.  

This is equivalent to finding a **linear arrangement** of a tree minimizing the sum of edge lengths.  
The optimal arrangement for a tree is to place nodes in DFS order (or BFS order) — this is known to minimize the sum of edge lengths for trees.  

We can do a DFS from any node, assign positions in the order we visit them, and compute the total length. If it’s ≤ B, output YES and the assignment; otherwise NO.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input_data = sys.stdin.read().strip().split()
    n, m, B = map(int, input_data[:3])
    edges = [[] for _ in range(n)]
    idx = 3
    for _ in range(m):
        u = int(input_data[idx]) - 1
        v = int(input_data[idx+1]) - 1
        idx += 2
        edges[u].append(v)
        edges[v].append(u)
    
    pos = [0] * n
    visited = [False] * n
    order = []
    
    # DFS to get an ordering
    stack = [0]
    visited[0] = True
    while stack:
        u = stack.pop()
        order.append(u)
        for v in edges[u]:
            if not visited[v]:
                visited[v] = True
                stack.append(v)
    
    # Assign positions 1..n in DFS order
    for i, node in enumerate(order):
        pos[node] = i + 1
    
    # Compute total cable length
    total = 0
    for u in range(n):
        for v in edges[u]:
            if u < v:
                total += abs(pos[u] - pos[v])
    
    if total <= B:
        print("YES")
        print(" ".join(map(str, pos)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
