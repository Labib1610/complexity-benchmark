Looking at this problem, we have a tree on n nodes, and we need to assign a permutation of {1..n} to nodes such that the sum of |channel(u) - channel(v)| over all edges is ≤ B.

**Key insight:** The minimum possible total penalty for a tree is achieved by a DFS/in-order traversal layout. Specifically, if we do a DFS and assign channels in DFS order (1, 2, 3, ...), each edge contributes exactly the size of the subtree being entered. The total minimum is the sum of all subtree sizes (excluding the root), which equals n-1 + (sum of subtree sizes of children of root's children, etc.).

Actually, the minimum total penalty for any tree equals the sum over all edges of the subtree size on the child side. This is achieved by assigning channels in DFS order where each subtree gets a contiguous block.

**Greedy approach:** Root the tree at node 1. For each node, process children in order of decreasing subtree size. Assign contiguous channel blocks via DFS. This minimizes the total penalty.

The reason: when a node has children with subtrees s1 ≥ s2 ≥ ..., assigning them in decreasing order minimizes the sum. The edge to child i contributes si, but also the "gap" between consecutive child blocks contributes. By placing largest subtrees first, we minimize cross-subtree penalties (which are 0 since blocks are contiguous and adjacent).

Wait, with contiguous blocks, the total is simply the sum of subtree sizes of all children (recursively), which is fixed regardless of order. So the minimum is: sum over all non-root nodes of (subtree size of that node).

Let me verify with the example: n=3, edges 1-2, 1-3. Root at 1. Children 2 and 3, each subtree size 1. Minimum = 1+1 = 2 = B. ✓

So the algorithm: compute subtree sizes, the minimum is sum of subtree sizes (non-root). If min > B, output NO. Otherwise, assign channels via DFS (any order works for achieving the minimum).

```python
import sys
from sys import setrecursionlimit

def solve():
    input_data = sys.stdin.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    B = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    # Root at 1, compute subtree sizes iteratively
    parent = [0] * (n+1)
    order = []
    stack = [1]
    parent[1] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if parent[v] == 0:
                parent[v] = u
                stack.append(v)
    
    size = [1] * (n+1)
    for u in reversed(order):
        if parent[u] > 0:
            size[parent[u]] += size[u]
    
    # Minimum total penalty = sum of subtree sizes of non-root nodes
    min_penalty = 0
    for u in range(2, n+1):
        min_penalty += size[u]
    
    if min_penalty > B:
        print("NO")
        return
    
    # Assign channels via DFS (preorder), contiguous blocks
    channels = [0] * (n+1)
    # Process children in decreasing subtree size order for determinism
    children = [[] for _ in range(n+1)]
    for u in range(2, n+1):
        children[parent[u]].append(u)
    for u in range(1, n+1):
        children[u].sort(key=lambda x: -size[x])
    
    # Iterative DFS assigning channels
    ch = 1
    stack = [1]
    while stack:
        u = stack.pop()
        channels[u] = ch
        ch += 1
        # Push children in reverse so largest is processed first
        for c in reversed(children[u]):
            stack.append(c)
    
    print("YES")
    print(' '.join(str(channels[i]) for i in range(1, n+1)))

solve()
```
