We need to assign stations to pads (a permutation of 1..n) so that the sum of |pos[u] - pos[v]| over all edges is ≤ B.

This is essentially a **tree layout problem** — minimizing the sum of edge lengths.  
The optimal layout for a tree on a line is to place it in **DFS order** (or BFS order) so that edges are as short as possible.  
The minimum possible sum is achieved by placing nodes in the order of a **DFS traversal** (preorder), which gives each edge length 1 except for back edges in the DFS tree (which are not present here since it's a tree).

For a tree, the minimum sum of edge lengths is **n - 1** (if we place nodes in DFS order).  
So if B < n - 1, it's impossible.

If B ≥ n - 1, we can always find a placement with sum ≤ B by using DFS order (sum = n - 1).  
We just need to output any valid permutation.

Let's implement:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    # Minimum possible sum is n-1 (DFS order)
    if B < n - 1:
        print("NO")
        return
    
    # DFS order
    visited = [False] * n
    order = []
    
    def dfs(u):
        visited[u] = True
        order.append(u)
        for v in adj[u]:
            if not visited[v]:
                dfs(v)
    
    dfs(0)
    
    # Assign pads 1..n in order
    pos = [0] * n
    for i, node in enumerate(order):
        pos[node] = i + 1
    
    print("YES")
    print(" ".join(map(str, pos)))

if __name__ == "__main__":
    solve()
```
