We can model the workstations and channels as a tree (since \( m = n-1 \) and it’s connected).  
We need to assign each node a distinct slot from 1 to \( n \) such that the sum of absolute differences along edges is ≤ \( B \).

A known fact: For a tree, the minimum possible sum of edge lengths (when placing nodes on a line) is achieved by placing nodes in the order of a DFS (or BFS) traversal, which yields a “contiguous” layout.  
The minimal possible sum is \( n-1 \) (if the tree is a path and we place them in order).  
The maximum possible sum is when we place nodes in an order that maximizes distances, which is bounded by \( \lfloor n^2/4 \rfloor \) for a star.

We can try a constructive approach:  
- If \( B \) is too small (less than \( n-1 \)), output `NO`.  
- Otherwise, we can try to place nodes in a DFS order starting from some root, which gives a sum close to minimal.  
- If that sum is ≤ \( B \), output it.  
- If not, we can try to increase distances by placing nodes in a different order (e.g., BFS order or a “zigzag” order) until we meet the budget.

A simple robust method:  
1. Root the tree at node 1.  
2. Perform a DFS to get an ordering.  
3. Assign slots in that order (1 to n).  
4. Compute the sum.  
5. If sum ≤ B, output.  
6. Else, try a BFS ordering, or a “reverse” ordering, etc.  
If none works, output `NO`.

Given the constraints (not specified, but typical for such problems), we can try a few orderings.

Let’s implement:

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    # Try multiple orderings
    orderings = []
    
    # DFS order
    parent = [-1]*n
    order = []
    stack = [0]
    parent[0] = 0
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if parent[v] == -1:
                parent[v] = u
                stack.append(v)
    orderings.append(order)
    
    # BFS order
    order = []
    q = deque([0])
    parent = [-1]*n
    parent[0] = 0
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj[u]:
            if parent[v] == -1:
                parent[v] = u
                q.append(v)
    orderings.append(order)
    
    # Reverse DFS order
    orderings.append(orderings[0][::-1])
    # Reverse BFS order
    orderings.append(orderings[1][::-1])
    
    # Also try a "zigzag" order: take DFS order and interleave from ends
    dfs_order = orderings[0]
    zigzag = []
    l, r = 0, n-1
    while l <= r:
        if l == r:
            zigzag.append(dfs_order[l])
            break
        zigzag.append(dfs_order[l])
        zigzag.append(dfs_order[r])
        l += 1
        r -= 1
    orderings.append(zigzag)
    
    for order in orderings:
        pos = [0]*n
        for slot, node in enumerate(order, start=1):
            pos[node] = slot
        total = 0
        for u in range(n):
            for v in adj[u]:
                if u < v:
                    total += abs(pos[u] - pos[v])
        if total <= B:
            print("YES")
            print(" ".join(str(pos[i]) for i in range(n)))
            return
    
    print("NO")

if __name__ == "__main__":
    solve()
```
