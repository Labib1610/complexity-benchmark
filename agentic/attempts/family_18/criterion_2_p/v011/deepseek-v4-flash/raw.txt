We can model the problem as a tree (since \( m = n-1 \) and it’s connected and acyclic).  
We need to assign positions \( 1 \dots n \) to the nodes so that the sum of absolute differences along edges is minimized, and check if it’s ≤ \( B \).

The optimal way to minimize the sum of absolute differences on a tree is to place nodes in a **DFS order** (or any linear extension that keeps connected subtrees contiguous). This is equivalent to finding a **minimum linear arrangement** of a tree, which can be done by a DFS that visits subtrees in any order — the sum of distances is minimized when each subtree is placed contiguously.

We can do a DFS from any root, assign positions in preorder, and compute the total strain. If it’s ≤ \( B \), output the assignment.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    n, m, B = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    pos = [0] * n
    visited = [False] * n
    order = []
    
    def dfs(u):
        visited[u] = True
        order.append(u)
        for v in adj[u]:
            if not visited[v]:
                dfs(v)
    
    dfs(0)
    
    # Assign positions in DFS order
    for idx, node in enumerate(order):
        pos[node] = idx + 1
    
    # Compute total strain
    total = 0
    for u in range(n):
        for v in adj[u]:
            if u < v:
                total += abs(pos[u] - pos[v])
    
    if total <= B:
        print("YES")
        print(" ".join(map(str, pos)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
