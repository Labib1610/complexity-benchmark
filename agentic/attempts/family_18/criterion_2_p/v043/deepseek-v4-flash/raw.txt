We can model the modules and cables as a tree.  
The problem is to assign numbers 1..n to the nodes so that the sum of absolute differences along edges is ≤ B.  

A known fact: For a tree, the minimum possible sum of edge lengths (when placing nodes on a line) is achieved by an **in-order traversal** of the tree (DFS order).  
That is, assign slot numbers according to the order in which nodes are visited in a DFS.  

This works because any tree can be embedded on a line with total length equal to the sum over edges of the size of the smaller side when the edge is cut, and the DFS order achieves this minimum.  

So the algorithm:
1. Build adjacency list.
2. Run DFS from node 1, record the order of first visits.
3. Assign slot numbers 1..n in that order.
4. Compute total cable length.
5. If ≤ B, print YES and the assignment; else NO.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input_data = sys.stdin.read().strip().split()
    n, m, B = map(int, input_data[:3])
    edges = []
    idx = 3
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(input_data[idx]) - 1
        v = int(input_data[idx+1]) - 1
        idx += 2
        adj[u].append(v)
        adj[v].append(u)
    
    order = []
    visited = [False] * n
    
    def dfs(u):
        visited[u] = True
        order.append(u)
        for v in adj[u]:
            if not visited[v]:
                dfs(v)
    
    dfs(0)
    
    pos = [0] * n
    for slot, node in enumerate(order, start=1):
        pos[node] = slot
    
    total_len = 0
    for u in range(n):
        for v in adj[u]:
            if u < v:
                total_len += abs(pos[u] - pos[v])
    
    if total_len <= B:
        print("YES")
        print(" ".join(str(pos[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
