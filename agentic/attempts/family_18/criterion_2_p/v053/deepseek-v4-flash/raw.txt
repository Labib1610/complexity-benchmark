 We can model the modules and their connections as a tree (since there are exactly \( n-1 \) edges and the graph is connected).  
We need to assign the \( n \) modules to positions \( 1 \dots n \) (a permutation) so that the sum of edge lengths is ≤ \( B \).

A key observation:  
For a tree, the total length of all edges in a linear arrangement can be expressed as:

\[
\text{Total length} = \sum_{\text{edge } e} w_e \cdot \text{(number of pairs separated by } e\text{)}
\]

But here all edges have weight 1, so:

\[
\text{Total length} = \sum_{\text{edge } e} (\text{size of one side}) \times (\text{size of other side})
\]

This is minimized when we place the tree in a *DFS order* (or any order that keeps subtrees contiguous).  
The minimal possible total length for a given tree is achieved by a *DFS ordering* (also called *contiguous ordering*), and equals:

\[
\sum_{e} \min(s, n-s)
\]

where \( s \) is the size of one component after removing edge \( e \).

So the minimal possible total length is fixed for the tree.  
If this minimal value > \( B \), then answer is `NO`.  
Otherwise, we can output a DFS ordering (which achieves that minimum).

---

### Steps:
1. Read input.
2. Build adjacency list.
3. Root the tree at node 1.
4. Compute subtree sizes.
5. Compute minimal total length = sum over edges of \(\min(\text{subtree size}, n - \text{subtree size})\).
6. If minimal > B → print `NO`.
7. Else, perform DFS to assign positions in preorder (or any DFS order) and output.

---

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    parent = [-1] * n
    order = []
    stack = [0]
    parent[0] = -2
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if parent[v] == -1:
                parent[v] = u
                stack.append(v)
    
    size = [1] * n
    for u in reversed(order):
        for v in adj[u]:
            if parent[v] == u:
                size[u] += size[v]
    
    min_total = 0
    for u in range(1, n):
        s = size[u]
        min_total += min(s, n - s)
    
    if min_total > B:
        print("NO")
        return
    
    # Assign positions via DFS preorder
    pos = [0] * n
    idx = 1
    stack = [0]
    visited = [False] * n
    visited[0] = True
    while stack:
        u = stack.pop()
        pos[u] = idx
        idx += 1
        for v in adj[u]:
            if not visited[v]:
                visited[v] = True
                stack.append(v)
    
    print("YES")
    print(" ".join(str(x) for x in pos))

if __name__ == "__main__":
    solve()
```
