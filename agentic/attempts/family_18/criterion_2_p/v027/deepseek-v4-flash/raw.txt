We can model the collaborations as a tree (since \( m = n-1 \) and it’s connected).  
We need to assign numbers \( 1 \dots n \) to the nodes to minimize the sum of absolute differences along edges.  

The optimal way to minimize the sum of absolute differences on a tree is to place the nodes in **DFS order** (or BFS order) — this is equivalent to an in-order traversal of the tree, which yields the minimal possible total distance for a tree when labels are \( 1 \dots n \).  

We can compute the minimal possible total friction by doing a DFS and assigning labels in visit order. If that minimal sum is ≤ B, we output YES and the assignment; otherwise NO.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    n, m, B = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        adj[u-1].append(v-1)
        adj[v-1].append(u-1)
    
    assignment = [0] * n
    pos = [0] * n
    visited = [False] * n
    order = []
    
    # DFS to get order
    stack = [0]
    visited[0] = True
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if not visited[v]:
                visited[v] = True
                stack.append(v)
    
    # Assign labels 1..n in DFS order
    for i, node in enumerate(order):
        assignment[node] = i + 1
        pos[node] = i + 1
    
    # Compute total friction
    total = 0
    for u in range(n):
        for v in adj[u]:
            if u < v:
                total += abs(pos[u] - pos[v])
    
    if total <= B:
        print("YES")
        print(" ".join(map(str, assignment)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
