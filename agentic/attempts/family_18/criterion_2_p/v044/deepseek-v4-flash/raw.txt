We can model the modules and links as a tree.  
The problem is to assign the tree’s nodes to positions 1..n on a line so that the sum of edge lengths is minimized, and check if that minimum is ≤ B.

The optimal way to place a tree on a line to minimize the sum of edge lengths is to place it in **inorder traversal order** (DFS order).  
This is because for a tree, the sum of absolute differences between parent and child positions is minimized when the tree is laid out in a depth-first order.

We can:
1. Build adjacency from input.
2. Run DFS from node 1 to get an ordering.
3. Assign positions according to that order.
4. Compute total cable length.
5. Compare with B.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    order = []
    visited = [False] * n
    
    def dfs(u):
        visited[u] = True
        order.append(u)
        for v in adj[u]:
            if not visited[v]:
                dfs(v)
    
    dfs(0)
    
    pos = [0] * n
    for idx, node in enumerate(order):
        pos[node] = idx + 1
    
    total = 0
    for u in range(n):
        for v in adj[u]:
            if u < v:
                total += abs(pos[u] - pos[v])
    
    if total <= B:
        print("YES")
        print(" ".join(str(pos[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
