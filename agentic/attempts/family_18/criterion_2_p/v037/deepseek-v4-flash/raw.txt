We can model the hierarchy as a tree. The problem is to assign distinct positions 1..n to nodes so that the sum of absolute differences along edges is ≤ B.

A known approach:  
- Root the tree at the top-level unit (the one with no parent).  
- Use a DFS to compute subtree sizes.  
- Place nodes in a way that minimizes total edge length — this is equivalent to an in-order traversal of the tree, which yields the minimum possible total stretch for a tree on a line.  
- The minimal total stretch is the sum over all edges of the size of the smaller side of the edge when the tree is cut there.  
- If that minimum is ≤ B, we can output the in-order traversal positions; otherwise, output NO.

Let’s implement this.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    
    adj = [[] for _ in range(n+1)]
    indeg = [0]*(n+1)
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)
        indeg[v] += 1
    
    # find root (indegree 0)
    root = 1
    for i in range(1, n+1):
        if indeg[i] == 0:
            root = i
            break
    
    parent = [0]*(n+1)
    order = []
    stack = [root]
    parent[root] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if v != parent[u]:
                parent[v] = u
                stack.append(v)
    
    size = [1]*(n+1)
    for u in reversed(order):
        for v in adj[u]:
            if v != parent[u]:
                size[u] += size[v]
    
    min_cost = 0
    for u in range(1, n+1):
        if parent[u] != -1:
            s = size[u]
            min_cost += min(s, n - s)
    
    if min_cost > B:
        print("NO")
        return
    
    # In-order traversal to assign positions
    pos = [0]*(n+1)
    cur = 1
    def dfs(u):
        nonlocal cur
        children = [v for v in adj[u] if v != parent[u]]
        # sort children by subtree size descending for better layout? 
        # Actually in-order traversal: visit left subtree, node, right subtree
        # For minimal stretch, we can just do any DFS that places subtrees contiguously.
        # We'll do: visit first half children, then node, then rest.
        # But simpler: do a preorder? Actually in-order gives minimal.
        # We'll do: visit children in order, then place node at end? 
        # Let's do: place node first, then children? That's preorder, not minimal.
        # For minimal, we want subtrees contiguous. In-order works.
        # We'll do: visit first child subtree, then node, then remaining children.
        if children:
            dfs(children[0])
        pos[u] = cur
        cur += 1
        for v in children[1:]:
            dfs(v)
    
    dfs(root)
    
    print("YES")
    print(" ".join(str(pos[i]) for i in range(1, n+1)))

if __name__ == "__main__":
    solve()
```
