We can model the problem as assigning labels 1..n to the nodes of a tree such that the sum over edges of |label(u) - label(v)| is minimized, and check if that minimum is ≤ B.

The optimal labeling for minimizing sum of absolute differences on a tree is to assign labels according to an in-order traversal of the tree (DFS order). This is because the tree is a hierarchy, and the optimal arrangement is to place connected nodes as close as possible in the linear order.

Here’s the step-by-step plan:

1. Read n, m, B.
2. Build adjacency list for the tree.
3. Root the tree at node 1 (main module).
4. Perform DFS to get an ordering of nodes (in-order traversal).
5. Assign labels 1..n according to that order.
6. Compute total cable length.
7. If total ≤ B, print YES and the labels; else print NO.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input_data = sys.stdin.read().strip().split()
    n, m, B = map(int, input_data[:3])
    adj = [[] for _ in range(n)]
    idx = 3
    for _ in range(m):
        u = int(input_data[idx]) - 1
        v = int(input_data[idx+1]) - 1
        idx += 2
        adj[u].append(v)
        adj[v].append(u)
    
    order = []
    parent = [-1] * n
    
    def dfs(u):
        order.append(u)
        for v in adj[u]:
            if v != parent[u]:
                parent[v] = u
                dfs(v)
    
    dfs(0)
    
    label = [0] * n
    for i, node in enumerate(order):
        label[node] = i + 1
    
    total = 0
    for u in range(n):
        for v in adj[u]:
            if u < v:
                total += abs(label[u] - label[v])
    
    if total <= B:
        print("YES")
        print(" ".join(map(str, label)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
