We have a tree (n nodes, n-1 edges) and need to assign positions 1..n to nodes so that the sum of edge lengths ≤ B.  

This is essentially finding a **linear arrangement** of a tree with total edge length ≤ B.  

A known approach:  
- The sum of edge lengths in a linear arrangement can be computed as:  
  For each edge, its contribution is the absolute difference of positions of its endpoints.  
- We can use a DFS-based DP to check feasibility and construct the arrangement.

We can think of it as:  
- Root the tree at any node.  
- For each subtree, we decide its span (min and max positions) and how it connects to the parent.  
- The total cost is sum over edges of (distance between positions).  

A simpler approach:  
We can try to place nodes in a DFS order (preorder) and compute the cost.  
But that may not be optimal.  

Better:  
We can use a **greedy DFS** that places nodes in a way that minimizes total edge length.  
For a tree, the optimal linear arrangement is obtained by a DFS that visits children in a certain order (by subtree size).  

We can do:  
- Root at 1.  
- Compute subtree sizes.  
- Assign positions by DFS, visiting children in increasing order of subtree size (smallest first) to keep connected nodes close.  
- Compute total cost. If ≤ B, output YES and positions; else NO.  

Let’s implement that.  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    n, m, B = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    parent = [-1]*n
    order = []
    stack = [0]
    parent[0] = 0
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if parent[v] == -1:
                parent[v] = u
                stack.append(v)
    
    size = [1]*n
    for u in reversed(order):
        for v in adj[u]:
            if v != parent[u]:
                size[u] += size[v]
    
    pos = [0]*n
    cur = 1
    def dfs(u):
        nonlocal cur
        pos[u] = cur
        cur += 1
        # visit children in increasing subtree size
        children = [v for v in adj[u] if v != parent[u]]
        children.sort(key=lambda x: size[x])
        for v in children:
            dfs(v)
    
    dfs(0)
    
    total = 0
    for u in range(n):
        for v in adj[u]:
            if u < v:
                total += abs(pos[u] - pos[v])
    
    if total <= B:
        print("YES")
        print(" ".join(str(pos[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
