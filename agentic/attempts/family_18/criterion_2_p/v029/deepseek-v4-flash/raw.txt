We can model the reporting structure as a tree.  
The problem asks for a permutation of positions \(1 \dots n\) assigned to the nodes such that the sum of absolute differences along each edge is ≤ \(B\).

This is equivalent to finding a **linear arrangement** of a tree minimizing the sum of edge lengths.  
The optimal arrangement for a tree on a line is obtained by a **DFS order** (or BFS order) that places nodes in a contiguous block for each subtree — this is known to minimize the sum of edge lengths.

We can do a DFS from any root, assign positions in preorder, and compute the total length.  
If that total ≤ \(B\), output YES and the permutation; otherwise NO.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    pos = [0] * n
    order = []
    parent = [-1] * n
    
    # DFS to get preorder
    stack = [0]
    parent[0] = 0
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            stack.append(v)
    
    # Assign positions in preorder
    for idx, node in enumerate(order):
        pos[node] = idx + 1
    
    # Compute total length
    total = 0
    for u in range(n):
        for v in adj[u]:
            if u < v:
                total += abs(pos[u] - pos[v])
    
    if total <= B:
        print("YES")
        print(" ".join(str(pos[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
