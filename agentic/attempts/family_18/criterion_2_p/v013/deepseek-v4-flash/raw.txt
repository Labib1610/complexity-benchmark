We can model the units and links as a tree (since \( m = n-1 \) and it’s connected).  
We need to assign positions \( 1 \dots n \) to the nodes so that the sum of absolute differences along edges is ≤ \( B \).

A known fact: for a tree, the minimum possible sum of edge lengths (when placing nodes on a line) is achieved by placing nodes in DFS order (or BFS order) — specifically, any ordering that respects the tree’s structure without “crossing” edges.  
The minimal sum is obtained by a **DFS ordering** of the tree, which gives each edge length exactly 1 in the best case, but that’s only possible if the tree is a path. For general trees, the minimal sum is the sum over edges of the size of the smaller side when the tree is cut at that edge.

We can compute this minimal possible sum. If it’s > \( B \), answer is `NO`. Otherwise, we can output a DFS order (which gives a valid placement).

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, B = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    # Compute minimal possible sum of edge lengths
    parent = [-1] * n
    order = []
    stack = [0]
    parent[0] = 0
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if parent[v] == -1:
                parent[v] = u
                stack.append(v)

    size = [1] * n
    min_sum = 0
    for u in reversed(order):
        for v in adj[u]:
            if v != parent[u]:
                size[u] += size[v]
    for u in range(1, n):
        min_sum += min(size[u], n - size[u])

    if min_sum > B:
        print("NO")
        return

    # Produce a DFS ordering
    pos = [0] * n
    visited = [False] * n
    res = []
    def dfs(u):
        visited[u] = True
        res.append(u)
        for v in adj[u]:
            if not visited[v]:
                dfs(v)
    dfs(0)

    for i, u in enumerate(res, start=1):
        pos[u] = i

    print("YES")
    print(" ".join(str(pos[i]) for i in range(n)))

if __name__ == "__main__":
    solve()
```
