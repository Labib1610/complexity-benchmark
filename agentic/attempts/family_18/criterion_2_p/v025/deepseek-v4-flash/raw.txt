We can model the problem as a tree (since \( m = n-1 \) and it’s connected).  
We need to assign distinct integers \(1\) to \(n\) to the nodes so that the sum of absolute differences along edges is \(\le B\).

This is equivalent to finding a **linear arrangement** of a tree with total edge length ≤ B.  
A known fact: the minimum possible sum of edge lengths for a tree is achieved by a **DFS order** (or BFS order) and equals:

\[
\sum_{\text{edges}} |\text{pos}(u) - \text{pos}(v)|
\]

We can try to find an arrangement with sum ≤ B.  
A simple approach: assign positions by a DFS traversal. This often gives a small sum.  
If that sum ≤ B, we output it. Otherwise, we can try other orders (like BFS, or reverse DFS) to see if any fits.

Since \(n\) can be large, we must be efficient.  
We'll try a few traversal orders and check the sum.

Here’s the implementation:

```python
import sys
from collections import deque

sys.setrecursionlimit(300000)

def solve():
    input_data = sys.stdin.read().strip().split()
    n, m, B = map(int, input_data[:3])
    edges = [[] for _ in range(n)]
    idx = 3
    for _ in range(m):
        u = int(input_data[idx]) - 1
        v = int(input_data[idx+1]) - 1
        idx += 2
        edges[u].append(v)
        edges[v].append(u)
    
    # Try multiple orders
    orders = []
    
    # DFS order
    parent = [-1]*n
    order = []
    stack = [0]
    parent[0] = 0
    while stack:
        u = stack.pop()
        order.append(u)
        for v in edges[u]:
            if parent[v] == -1:
                parent[v] = u
                stack.append(v)
    orders.append(order)
    
    # BFS order
    order = []
    q = deque([0])
    parent = [-1]*n
    parent[0] = 0
    while q:
        u = q.popleft()
        order.append(u)
        for v in edges[u]:
            if parent[v] == -1:
                parent[v] = u
                q.append(v)
    orders.append(order)
    
    # Reverse DFS
    orders.append(orders[0][::-1])
    # Reverse BFS
    orders.append(orders[1][::-1])
    
    for order in orders:
        pos = [0]*n
        for i, node in enumerate(order):
            pos[node] = i+1
        total = 0
        for u in range(n):
            for v in edges[u]:
                if u < v:
                    total += abs(pos[u] - pos[v])
        if total <= B:
            print("YES")
            print(" ".join(str(pos[i]) for i in range(n)))
            return
    
    print("NO")

if __name__ == "__main__":
    solve()
```
