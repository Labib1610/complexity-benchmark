We know the graph is a tree. The problem reduces to assigning labels 1…n to tree nodes so that the sum over edges of |label(u) - label(v)| is minimized”. This is a known arrangement problem on trees.

We can solve using dynamic programming on trees:  
For a node, we decide the *positions* of its subtree nodes in a sorted contiguous block. The cost only depends on where the block is placed.

A standard approach:  
Let `dp[u][k]` = minimal cost for the subtree of `u` when the positions assigned to `u`’s subtree are exactly `k` consecutive positions (which we can always assume). Then we can merge children’s blocks.

For each edge, if the child’s block is separated from the parent’s block, costs arise — but often it's optimal to keep everything contiguous.

Given the small constraints? Not specified, but we can implement a root placement where we try each possible position of the root from 1..n branch and check minimal cost. However, simpler:  
We can compute the minimum possible total cost by placing nodes in order of a DFS and assigning based on subtree sizes? Actually, a known theorem: To minimize sum of absolute differences along edges, the optimal arrangement is any order that assigns contiguous intervals for each subtree (e.g., preorder).

So, a DFS ordering that visits subtrees consecutively gives minimal cost.  
The minimal possible cost is then simply: sum over edges of (size of subtree of child) * (n - size_of_subtree_of_child).  
But we must check if that minimum ≤ B.  
If yes, we can output any preorder labeling.

Implementation steps:
1. Read tree.
2. Root at 1 (or any).
3. Compute subtree sizes.
4. Compute minimal cost as described.
5. If min_cost <= B, output YES with preorder labels.
6. Else NO.

We can generate preorder labels in one DFS.

Let's implement.  
We must be careful with recursion depth for large n — use iterative stack.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)
    
    # Root the tree at 1
    parent = [0]*(n+1)
    order = []
    stack = [1]
    parent[1] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v in adj[u]:
            if v != parent[u]:
                parent[v] = u
                stack.append(v)
    
    size = [1]*(n+1)
    for u in reversed(order):
        for v in adj[u]:
            if v != parent[u]:
                size[u] += size[v]
    
    min_cost = 0
    for u in range(2, n+1):
        s = size[u]
        min_cost += s * (n - s)
    
    if min_cost > B:
        print("NO")
        return
    
    # Generate preorder labels
    label = [0]*(n+1)
    counter = 1
    stack = [(1, 0)]
    while stack:
        u, state = stack.pop()
        if state == 0:
            label[u] = counter
            counter += 1
            # push children in reverse order
            children = [v for v in adj[u] if v != parent[u]]
            for v in reversed(children):
                stack.append((v, 1))
                stack.append((v, 0))
    
    print("YES")
    print(" ".join(str(label[i]) for i in range(1, n+1)))

if __name__ == "__main__":
    solve()
```
