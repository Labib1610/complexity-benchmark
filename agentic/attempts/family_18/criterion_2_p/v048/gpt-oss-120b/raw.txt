**Solution Explanation**

For the layout we may choose any permutation `p[1…n]` – `p[i]` is the slot number of qubit `i`.
The total length of all links is  

```
S(p) = Σ | p[u] – p[v] |   over all given edges (u , v)
```

The statement asks only whether *some* permutation makes `S(p) ≤ B` and, if it exists,
to output one such permutation.

A trivial permutation is the identity `p[i] = i` (qubit `i` goes to slot `i`).
We compute its total length `S_id`.  
If `S_id ≤ B` the answer is obviously **YES** and the identity permutation is a
valid layout.  
If `S_id > B` then *any* permutation will have total length at least `S_id`,
because changing positions can only increase some absolute differences
(the identity already makes every edge length as small as possible for the
given numeric labels). Consequently no layout satisfies the budget and the
answer is **NO**.

Thus the whole problem reduces to a single linear scan over the `m = n‑1`
edges.

--------------------------------------------------------------------

#### Algorithm
```
read n, m, B
read the m edges into a list E
total = 0
for each (u, v) in E:
        total += abs(u - v)          # length under identity permutation
if total <= B:
        print "YES"
        print 1 2 … n                # identity permutation
else:
        print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints a correct answer.

*Lemma 1*  
For the identity permutation `p_id[i] = i` the total length is  
`S_id = Σ |u - v|` over all edges `(u, v)`.

*Proof.* Directly from the definition of `S(p)` with `p = p_id`. ∎

*Lemma 2*  
For any permutation `p` we have `S(p) ≥ S_id`.

*Proof.* Consider an edge `(u, v)`.  
`|p[u] - p[v]|` is the distance between two distinct integers from `1…n`.  
The smallest possible distance between two distinct numbers is `1`.  
If `|u - v| = 1` then the identity already attains this minimum.
If `|u - v| > 1` the identity places the two vertices exactly `|u - v|`
positions apart; any other placement cannot make them closer than `1`,
hence cannot make the sum smaller than the identity’s contribution for that
edge. Summing over all edges yields `S(p) ≥ S_id`. ∎

*Lemma 3*  
If `S_id > B` then no permutation satisfies the budget.

*Proof.* By Lemma&nbsp;2 every permutation has total length at least `S_id`,
which is already larger than `B`. ∎

*Theorem*  
The algorithm outputs **YES** and a valid layout exactly when such a layout
exists; otherwise it outputs **NO**.

*Proof.*  
- If the algorithm prints **YES**, it has `S_id ≤ B`. The identity
  permutation is then a layout whose total length equals `S_id`,
  therefore ≤ `B`. So a valid layout exists.
- If the algorithm prints **NO**, it has `S_id > B`. By Lemma&nbsp;3 no
  permutation can meet the budget, hence no valid layout exists.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

Reading the input and computing `S_id` scans `m = n‑1` edges once.

```
Time   :  O(n)
Memory :  O(1)   (apart from the input list, which can be processed on the fly)
```

Both limits easily satisfy the given constraints.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))

    total = 0
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        total += abs(u - v)

    out = []
    if total <= B:
        out.append("YES")
        out.append(" ".join(str(i) for i in range(1, n + 1)))
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
