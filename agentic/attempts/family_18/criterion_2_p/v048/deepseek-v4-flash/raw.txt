We can model the problem as a tree (since \( m = n-1 \) and it’s connected).  
We need to assign numbers \( 1 \dots n \) to nodes so that the sum of absolute differences along edges is ≤ \( B \).

A known fact: For a tree, the **minimum possible sum of edge lengths** is achieved by a **DFS order** (or BFS order) labeling.  
That minimum is:

\[
\text{min\_sum} = \sum_{\text{edges } (u,v)} |pos[u] - pos[v]|
\]

If we label nodes in DFS order, each edge contributes at least 1, and the total is exactly \( n-1 \) if the tree is a path, but for general trees it can be larger.  
However, the **absolute minimum** possible is \( n-1 \) (when the tree is a path). For any tree, the minimum is at least \( n-1 \).

We can compute the minimum possible sum by doing a DFS and assigning positions in preorder.  
If that minimum ≤ \( B \), we output YES with that assignment; otherwise NO.

Let’s implement:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input_data = sys.stdin.read().strip().split()
    n, m, B = map(int, input_data[:3])
    edges = [[] for _ in range(n)]
    idx = 3
    for _ in range(m):
        u = int(input_data[idx]) - 1
        v = int(input_data[idx+1]) - 1
        idx += 2
        edges[u].append(v)
        edges[v].append(u)
    
    pos = [0] * n
    visited = [False] * n
    order = []
    
    def dfs(u):
        visited[u] = True
        order.append(u)
        for v in edges[u]:
            if not visited[v]:
                dfs(v)
    
    dfs(0)
    
    # Assign positions in DFS order
    for i, node in enumerate(order):
        pos[node] = i + 1
    
    # Compute total length
    total = 0
    for u in range(n):
        for v in edges[u]:
            if u < v:
                total += abs(pos[u] - pos[v])
    
    if total <= B:
        print("YES")
        print(" ".join(map(str, pos)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
