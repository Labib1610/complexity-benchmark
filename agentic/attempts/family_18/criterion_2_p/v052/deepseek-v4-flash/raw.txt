We can model the components and links as a tree (since \( m = n-1 \)).  
The problem is to find a linear ordering (permutation of slots) of the tree’s nodes such that the sum of distances between connected nodes is at most \( B \).  

A known approach:  
- The minimum possible total wire length for a tree is achieved by placing nodes in a DFS order (or BFS order) that minimizes the sum of edge lengths.  
- For a tree, the optimal linear arrangement is obtained by a **DFS traversal** that visits subtrees in a way that keeps connected nodes close.  
- The minimal sum is achieved by a **contiguous DFS ordering** (also called a *DFS numbering*), which yields the smallest possible sum of edge lengths for a tree.  

We can compute the minimal possible sum by doing a DFS and assigning slots in visit order.  
If that minimal sum is ≤ \( B \), we output the assignment; otherwise, output `NO`.  

Here’s the implementation:  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    n, m, B = map(int, sys.stdin.readline().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, sys.stdin.readline().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    slot = [0] * n
    pos = [0] * n
    visited = [False] * n
    order = []
    
    def dfs(u):
        visited[u] = True
        order.append(u)
        for v in adj[u]:
            if not visited[v]:
                dfs(v)
    
    dfs(0)
    
    # Assign slots in DFS order
    for idx, node in enumerate(order):
        slot[node] = idx + 1
        pos[node] = idx + 1
    
    total_len = 0
    for u in range(n):
        for v in adj[u]:
            if u < v:
                total_len += abs(pos[u] - pos[v])
    
    if total_len <= B:
        print("YES")
        print(" ".join(map(str, slot)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
