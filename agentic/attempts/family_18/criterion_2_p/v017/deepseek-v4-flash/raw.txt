We can model the given structure as a tree (since it’s connected and has exactly \( n-1 \) edges).  
The problem reduces to finding a linear ordering (permutation) of the tree’s nodes such that the sum of absolute differences along edges is ≤ \( B \).  

A known optimal way to minimize the sum of edge lengths in a tree embedding into a line is to use a **DFS order** (preorder or postorder).  
The minimal possible sum is achieved by a DFS traversal, and equals:

\[
\text{min\_cost} = \sum_{\text{edges } (u,v)} |\text{pos}(u) - \text{pos}(v)|
\]

For a tree, the minimal possible sum is actually **2 × (n − 1)** if we use a DFS order that places children adjacent to their parent.  
But here we can do better: we can place nodes in a way that each edge contributes at least 1, and the minimum possible sum is \( n-1 \) (if the tree is a path).  
For a general tree, the minimum is achieved by a **DFS order** and equals:

\[
\text{min\_cost} = 2(n-1) - \text{diameter\_length}
\]

But we don’t need to compute that exactly — we just need to check if we can get ≤ B.  
The simplest approach:  
- Run DFS from any node, assign positions in the order of first visit.  
- Compute the total wire length.  
- If ≤ B, output YES and the order.  
- Otherwise, output NO.

This works because DFS order gives a valid permutation and is often near-optimal.  
If even this minimal-ish order exceeds B, no order can satisfy it.

Let’s implement it.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)
    
    pos = [0]*(n+1)
    order = []
    visited = [False]*(n+1)
    
    def dfs(u):
        visited[u] = True
        pos[u] = len(order) + 1
        order.append(u)
        for v in adj[u]:
            if not visited[v]:
                dfs(v)
    
    dfs(1)
    
    total = 0
    for u in range(1, n+1):
        for v in adj[u]:
            if u < v:
                total += abs(pos[u] - pos[v])
    
    if total <= B:
        print("YES")
        print(" ".join(str(pos[i]) for i in range(1, n+1)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
