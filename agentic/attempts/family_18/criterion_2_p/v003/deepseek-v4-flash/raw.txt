We can model the units and their reporting links as a tree.  
The problem asks us to place the tree’s nodes on a line (positions 1..n) so that the sum of edge lengths (absolute differences of positions) is ≤ B.

This is equivalent to finding a **linear arrangement** of a tree with total edge length ≤ B.

A known fact: For a tree, the minimum possible sum of edge lengths over all linear arrangements is achieved by placing nodes in **DFS order** (or BFS order) — but more precisely, the optimal is obtained by a **depth-first traversal** where we place each subtree contiguously.

We can solve it by:
1. Root the tree at node 1.
2. Perform a DFS, assigning positions in the order we visit nodes.
3. Compute the total edge length for that arrangement.
4. If ≤ B, output YES and the permutation; else NO.

This works because DFS order minimizes the sum of edge lengths for trees (each edge is crossed only once in the traversal).

Let’s implement it.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    pos = [0] * n
    order = []
    visited = [False] * n
    
    def dfs(u):
        visited[u] = True
        order.append(u)
        for w in adj[u]:
            if not visited[w]:
                dfs(w)
    
    dfs(0)
    
    # assign positions in DFS order
    for idx, node in enumerate(order):
        pos[node] = idx + 1
    
    total = 0
    for u in range(n):
        for v in adj[u]:
            if u < v:
                total += abs(pos[u] - pos[v])
    
    if total <= B:
        print("YES")
        print(" ".join(str(pos[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
