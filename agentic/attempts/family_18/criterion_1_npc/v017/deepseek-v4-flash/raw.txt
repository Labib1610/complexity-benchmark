 We need to find a permutation of modules to bays that minimizes the total harness length, and check if it is ≤ B.  

This is equivalent to the **Minimum Linear Arrangement (MinLA)** problem, which is NP-hard in general.  
However, for small n (likely n ≤ 15 or so), we can solve it exactly using **bitmask DP**.

We’ll do:

- Precompute the adjacency matrix `dist[i][j]` = 1 if there is an edge between i and j, else 0.
- DP over subsets:  
  `dp[mask][last]` = minimum cost to place the modules in `mask` (already placed) with `last` being the last placed module.
- When adding a new module `nxt` at position `pos = popcount(mask)`, the cost added is:
  - For every already placed module `u` in `mask`, if there is an edge between `u` and `nxt`, add `(pos - pos_of_u)`.
  - We can precompute this incremental cost.

But we also need to reconstruct the permutation.

Since n might be up to maybe 18–20 in the worst case for this problem (but not specified), we can still do O(n * 2^n) which is fine for n ≤ 20.

Let’s implement:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m, B = map(int, input().split())
    adj = [[0]*n for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u][v] = 1
        adj[v][u] = 1

    INF = 10**9
    dp = [[INF]*n for _ in range(1<<n)]
    parent = [[-1]*n for _ in range(1<<n)]

    # Initialize: first module placed at position 0
    for i in range(n):
        dp[1<<i][i] = 0

    # Precompute popcounts
    popcount = [0]*(1<<n)
    for mask in range(1, 1<<n):
        popcount[mask] = popcount[mask>>1] + (mask&1)

    for mask in range(1<<n):
        pos = popcount[mask]
        if pos == 0:
            continue
        for last in range(n):
            if not (mask & (1<<last)):
                continue
            cur_cost = dp[mask][last]
            if cur_cost == INF:
                continue
            # Try to add a new module
            for nxt in range(n):
                if mask & (1<<nxt):
                    continue
                # cost added: sum over u in mask of adj[u][nxt] * (pos - pos_of_u)
                # We can compute incrementally, but for simplicity compute directly
                add = 0
                # We need positions of each u in mask
                # We can compute by iterating over bits
                # But we can also store positions in reconstruction later.
                # For now, compute by iterating over all u in mask
                for u in range(n):
                    if mask & (1<<u):
                        if adj[u][nxt]:
                            # position of u is not directly known here, but we can compute
                            # Actually we need pos_of_u. We can compute by iterating bits.
                            # Let's compute pos_of_u by counting bits in mask up to u.
                            # This is O(n) per edge, fine for n<=20.
                            # But we can precompute pos_in_mask[mask][u]? That's 2^n * n memory, too big.
                            # Instead, we can compute pos_of_u on the fly.
                            # Since n small, we can do:
                            pass
                # We'll do a simpler approach: store positions in DP state? That's too big.
                # Alternative: when adding nxt at position pos, the cost added is:
                # sum_{u in mask} adj[u][nxt] * (pos - pos_of_u)
                # = pos * (number of edges from nxt to mask) - sum_{u in mask} adj[u][nxt]*pos_of_u
                # We can precompute for each mask and nxt the sum of positions of neighbors.
                # But positions depend on the order, not just mask.
                # So we need to know positions.

    # Because of this, we need a different DP: dp[mask] = min cost for placing exactly the modules in mask in the first |mask| positions.
    # Then we don't need last, just the set.
    # The cost added when placing a new module at position |mask| is:
    # sum_{u in mask} adj[u][nxt] * (|mask| - pos_of_u)
    # But pos_of_u is not known from mask alone.
    # However, we can compute it if we know the order, but that's the problem.

    # So we need to store the order. That's why we use dp[mask][last] and reconstruct.

    # Let's implement with O(n^2 * 2^n) by computing pos_of_u on the fly using bit tricks.

    # Precompute pos_in_mask[mask][u]? 2^n * n is too big for n=20 (20M ints, ~160MB) maybe okay? But we can do better.

    # Actually, we can compute pos_of_u in mask by:
    # pos = popcount(mask & ((1<<u)-1))
    # That's O(1) with precomputed popcount.

    # So we can compute add cost in O(n) per transition.

    for mask in range(1<<n):
        pos = popcount[mask]
        if pos == 0:
            continue
        for last in range(n):
            if not (mask & (1<<last)):
                continue
            cur = dp[mask][last]
            if cur == INF:
                continue
            for nxt in range(n):
                if mask & (1<<nxt):
                    continue
                add = 0
                # compute cost
                for u in range(n):
                    if mask & (1<<u):
                        if adj[u][nxt]:
                            pos_u = popcount(mask & ((1<<u)-1))
                            add += pos - pos_u
                new_mask = mask | (1<<nxt)
                if cur + add < dp[new_mask][nxt]:
                    dp[new_mask][nxt] = cur + add
                    parent[new_mask][nxt] = last

    # Find min cost
    full = (1<<n)-1
    best_cost = INF
    best_last = -1
    for last in range(n):
        if dp[full][last] < best_cost:
            best_cost = dp[full][last]
            best_last = last

    if best_cost > B:
        print("NO")
        return

    # Reconstruct
    perm = [0]*n
    mask = full
    last = best_last
    for pos in range(n-1, -1, -1):
        perm[pos] = last + 1
        prev = parent[mask][last]
        mask ^= (1<<last)
        last = prev

    print("YES")
    print(" ".join(map(str, perm)))

if __name__ == "__main__":
    solve()
```
