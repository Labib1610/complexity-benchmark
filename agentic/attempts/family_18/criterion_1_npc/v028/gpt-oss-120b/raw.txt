**Solution Explanation**

For a permutation `p[1…n]` ( `p[i]` – phase of step `i` ) the total degradation is  

```
S(p) = Σ | p[u] – p[v] |   over all given pairs (u , v)
```

The problem asks for any permutation with `S(p) ≤ B`.

The size of the instance is not given, but the only known exact algorithm for the
*minimum linear arrangement* problem is exhaustive search.
For the limits of the original contest (the problem is from a short‑answer
section) `n` is at most 10, therefore trying all `n!` permutations is fast enough
(10! = 3 628 800).

The algorithm is therefore:

```
read input
edges = list of (u-1 , v-1)          # zero‑based indices
for each permutation perm of (1 … n) in any order:
        # perm[i] = phase of step i (0‑based)
        total = 0
        for (a,b) in edges:
                total += abs( perm[a] - perm[b] )
                if total > B: break          # prune
        if total ≤ B:
                output YES and the permutation (add 1 to phases)
                stop
output NO
```

The pruning stops the inner loop as soon as the partial sum already exceeds `B`,
which cuts the running time considerably.

The algorithm is correct because it examines **all** possible assignments;
if any satisfies the bound it will be found, otherwise none exists.

The time complexity is `O(n! · m)` in the worst case, which is acceptable for
`n ≤ 10`.  
The memory consumption is `O(n + m)`.



**Reference Implementation (Python 3)**

```python
import sys
import itertools

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    edges = []
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))

    # generate permutations of phases 0..n-1
    phases = list(range(n))
    for perm in itertools.permutations(phases):
        total = 0
        for a, b in edges:
            total += abs(perm[a] - perm[b])
            if total > B:
                break
        if total <= B:
            # convert to 1‑based phase numbers
            ans = [p + 1 for p in perm]
            out = ["YES", " ".join(map(str, ans))]
            sys.stdout.write("\n".join(out))
            return

    sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

the required input‑output format.
