We can model this as a graph problem.  
The modules are vertices, and the harnesses are edges.  
We need to assign each vertex a distinct position from 1 to n such that the sum over all edges of |pos[u] − pos[v]| is ≤ B.

A simple approach:  
If the graph is disconnected, we can place each connected component in a block of consecutive positions, because edges only exist within components.  
For each component, we can try to find an ordering that minimizes the sum of edge lengths.  
A known fact: for a tree, the optimal arrangement is to place vertices in DFS order (or BFS order) — this gives a total length equal to the sum over edges of the size of the smaller side when the tree is cut at that edge.  
For general graphs, we can use a greedy heuristic: place vertices in order of their degree (higher degree closer to center), but that’s not guaranteed optimal.  

However, since the problem only asks for *any* placement within budget, we can try a simple heuristic:  
- Sort vertices by degree descending, place them in the middle positions, then fill the rest.  
- Or try a BFS/DFS layout per component.

Given the constraints are not huge (n up to maybe 2000?), we can try a simple approach:  
For each connected component, do a BFS from a vertex with highest degree, assign positions sequentially.  
This tends to keep connected vertices close.

Let’s implement:

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    
    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))
    
    visited = [False] * n
    components = []
    for i in range(n):
        if not visited[i]:
            q = deque([i])
            visited[i] = True
            comp = []
            while q:
                u = q.popleft()
                comp.append(u)
                for w in adj[u]:
                    if not visited[w]:
                        visited[w] = True
                        q.append(w)
            components.append(comp)
    
    pos = [0] * n
    current_pos = 1
    for comp in components:
        # BFS from vertex with highest degree in comp
        start = max(comp, key=lambda x: len(adj[x]))
        q = deque([start])
        visited_comp = {start}
        order = []
        while q:
            u = q.popleft()
            order.append(u)
            for w in adj[u]:
                if w not in visited_comp:
                    visited_comp.add(w)
                    q.append(w)
        # Assign positions
        for u in order:
            pos[u] = current_pos
            current_pos += 1
    
    # Compute total length
    total = 0
    for u, v in edges:
        total += abs(pos[u] - pos[v])
    
    if total <= B:
        print("YES")
        print(" ".join(str(pos[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
