We need a permutation of artifacts into bays such that the total absolute difference sum over given edges is ≤ B.  

This is essentially: we have a graph on n vertices (artifacts), labels 1..n are permuted to vertices, cost = sum over edges |pos(u) - pos(v)|.  

We need to check if there is a permutation with cost ≤ B. This problem is NP-hard in general, but for constraints small enough (n up to maybe 10 or 12?) we can use backtracking with pruning.  

Here, no constraints are given explicitly in description besides n, m, B — but to be safe, we can do backtracking with pruning for moderate n. If n is large, maybe we try greedy. But given it's a past contest problem from some place, often n ≤ 10 or so for this exact problem.

We'll solve with search:  
Try all permutations (n! too big for n > 10-11). We'll use branch and bound:  
- Place artifacts in positions 1..n. Track cost so far; prune if cost > B.  
- To speed up, we can use lower bound estimation: minimal possible add for remaining edges.

Given the problem statement does not specify n limit, but in practice in such tasks n is small (say ≤ 10), backtracking works. I'll implement backtracking with pruning and use recursion.

We'll also use adjacency list and cost increment when placing.

Let's code.  

```python
import sys

sys.setrecursionlimit(10000000)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append(v)
        adj[v].append(u)
    
    # If n small enough, we can use backtracking
    # Let's try all permutations for n <= 10; for bigger, try heuristic
    # But we can still attempt backtracking if n<=12 or so; if fails quickly?
    # We'll use recursion with pruning.

    pos = [-1] * n
    used = [False] * (n + 1)  # bay indices 1..n
    best_perm = None

    # Precompute edge list for quick cost computation
    # When placing artifact idx at position p, we can add cost for edges to already placed ones

    def backtrack(idx, cost):
        nonlocal best_perm
        if cost > B:
            return
        if idx == n:
            if cost <= B:
                best_perm = pos[:]
            return
        # Try placing artifact idx at some bay
        # Heuristic: try to place near already placed neighbors to reduce cost
        # We'll try all unused bays
        for bay in range(1, n + 1):
            if used[bay]:
                continue
            # compute added cost
            added = 0
            for nb in adj[idx]:
                if pos[nb] != -1:
                    added += abs(pos[nb] - bay)
            if cost + added > B:
                continue
            # place
            pos[idx] = bay
            used[bay] = True
            backtrack(idx + 1, cost + added)
            used[bay] = False
            pos[idx] = -1
            if best_perm is not None:
                return
    
    backtrack(0, 0)
    
    if best_perm is not None:
        print("YES")
        print(" ".join(str(x) for x in best_perm))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
