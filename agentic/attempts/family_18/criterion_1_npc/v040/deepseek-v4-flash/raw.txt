We need to find a permutation of assemblies to bays such that the sum of distances for given edges is ≤ B.  

This is essentially an **arrangement problem** on a line, minimizing the sum of edge lengths.  
A known optimal arrangement for minimizing sum of edge lengths on a line is to place nodes in the order of a **BFS/DFS from a center** or use a **minimum linear arrangement** heuristic.  
However, exact minimum linear arrangement is NP-hard in general, but for small n we can brute force or use heuristics.

Given constraints are not specified, but typical for such problems n might be small (≤ 8 or 10) to allow brute force.  
We'll implement a backtracking search with pruning, trying all permutations and checking the cost.

We'll also handle the case where m=0 (cost 0 always possible).

Let's write the solution:

```python
import sys
from itertools import permutations

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    edges = []
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
    
    # If no edges, any permutation works
    if m == 0:
        print("YES")
        print(" ".join(str(i+1) for i in range(n)))
        return
    
    # Try all permutations
    for perm in permutations(range(n)):
        pos = [0]*n
        for i, p in enumerate(perm):
            pos[p] = i+1  # bay number
        total = 0
        for u, v in edges:
            total += abs(pos[u] - pos[v])
            if total > B:
                break
        if total <= B:
            print("YES")
            print(" ".join(str(pos[i]) for i in range(n)))
            return
    
    print("NO")

if __name__ == "__main__":
    solve()
```
