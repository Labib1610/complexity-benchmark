We need to assign components to stations (a permutation of 1..n) so that the sum of distances between linked components is ≤ K.

This is essentially: given a graph, find a linear arrangement (permutation) minimizing the sum of edge lengths, and check if it’s ≤ K.

This is the **Minimum Linear Arrangement** problem, which is NP-hard in general. But constraints are not given explicitly in the statement — we must infer from typical contest problems. Since it’s Problem A, likely n is small (maybe ≤ 8 or 10), so we can brute force all permutations.

We’ll:
- Read n, m, K.
- Build adjacency list.
- Try all permutations of 1..n.
- For each, compute sum of |pos[u] - pos[v]| for each edge.
- If any ≤ K, output YES and the permutation.
- Else NO.

Let’s implement with `itertools.permutations`.

```python
import sys
from itertools import permutations

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n = int(data[0])
    m = int(data[1])
    K = int(data[2])
    edges = []
    idx = 3
    for _ in range(m):
        u = int(data[idx]) - 1
        v = int(data[idx+1]) - 1
        idx += 2
        edges.append((u, v))
    
    for perm in permutations(range(n)):
        pos = [0] * n
        for i, p in enumerate(perm):
            pos[p] = i
        total = 0
        for u, v in edges:
            total += abs(pos[u] - pos[v])
            if total > K:
                break
        if total <= K:
            print("YES")
            print(" ".join(str(p+1) for p in perm))
            return
    print("NO")

if __name__ == "__main__":
    main()
```
