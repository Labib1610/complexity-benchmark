We can model this as a graph problem. The modules are vertices, and the links are edges. We need to assign each vertex to a distinct slot (1 to n) to minimize the sum of absolute differences along edges.

A key observation:  
The optimal arrangement for minimizing the sum of edge lengths in a 1D layout is to place vertices according to their **BFS/DFS order** from a central vertex, or more generally, by **graph bandwidth minimization** heuristics.  
For small n, we can try all permutations and check the cost. But n can be large, so we need a smarter approach.

A known fact:  
For a tree, the optimal linear arrangement can be found by placing the centroid at the center and recursively placing subtrees.  
For general graphs, we can use a greedy heuristic:  
- Start with the vertex of highest degree in the middle.  
- Then place its neighbors around it, then their neighbors, etc.

We can implement a BFS-based layout:  
1. Pick a starting vertex (e.g., highest degree).  
2. BFS from it, assigning slots from the center outward.  
3. Compute total cost.  
4. If cost ≤ B, output YES and the assignment.  
5. If not, try other starting vertices (or a few heuristics) and check again.  
If none works, output NO.

Since the problem is from a contest, n might be up to maybe 200 or 500, so trying a few starting points is fine.

Let’s implement:

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m, B = map(int, input().split())
    edges = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edges[u].append(v)
        edges[v].append(u)
    
    # Try multiple starting points: highest degree first, then others
    order = sorted(range(n), key=lambda x: -len(edges[x]))
    
    for start in order:
        # BFS from start
        dist = [-1]*n
        dist[start] = 0
        q = deque([start])
        bfs_order = []
        while q:
            u = q.popleft()
            bfs_order.append(u)
            for v in edges[u]:
                if dist[v] == -1:
                    dist[v] = dist[u] + 1
                    q.append(v)
        # Assign slots: center = start gets middle slot
        # We'll assign slots from center outward by BFS order
        # Actually, we want to place closer nodes near center.
        # Sort by distance, then assign slots from center outward.
        nodes_by_dist = sorted(range(n), key=lambda x: dist[x])
        # Place them: first node (start) gets slot n//2+1 (1-indexed)
        # Then place others alternating left/right
        slot = [0]*n
        left = n//2
        right = n//2 + 1
        # start at center
        slot[start] = n//2 + 1
        # For others, fill from closest to farthest
        placed = {start}
        for node in nodes_by_dist:
            if node in placed:
                continue
            # place on left if possible, else right
            if left >= 1:
                slot[node] = left
                left -= 1
            else:
                slot[node] = right
                right += 1
            placed.add(node)
        
        # compute cost
        cost = 0
        for u in range(n):
            for v in edges[u]:
                if u < v:
                    cost += abs(slot[u] - slot[v])
        if cost <= B:
            print("YES")
            print(" ".join(str(x) for x in slot))
            return
    
    print("NO")

if __name__ == "__main__":
    solve()
```
