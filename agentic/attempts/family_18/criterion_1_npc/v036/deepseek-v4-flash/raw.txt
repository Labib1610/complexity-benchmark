We need to assign instruments to brackets such that the total cable length for all required pairs is at most B.  

This is essentially a graph layout problem: we have a graph with n vertices (instruments) and m edges (required connections). We need to place vertices on a line (positions 1..n) to minimize the sum of edge lengths, and check if that minimum is ≤ B.

The minimum linear arrangement problem is NP-hard in general, but here n is not given explicitly in the statement — but from typical constraints, we can assume n is small enough for a DP over subsets (bitmask DP) if n ≤ 20 or so.  

We’ll implement a DP over subsets:  
- `dp[mask]` = minimum total cable length for placing the instruments in `mask` on the first `popcount(mask)` positions.  
- Transition: add a new instrument to the next position, adding the sum of distances to already placed neighbors.

We also need to reconstruct the assignment.

Let’s write the solution.  

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    B = int(next(it))
    
    adj = [[False] * n for _ in range(n)]
    for _ in range(m):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        adj[x][y] = adj[y][x] = True
    
    # DP over subsets
    INF = 10**18
    dp = [INF] * (1 << n)
    parent = [-1] * (1 << n)
    dp[0] = 0
    
    for mask in range(1 << n):
        if dp[mask] == INF:
            continue
        pos = bin(mask).count("1")  # next position index (0-based)
        for v in range(n):
            if not (mask >> v) & 1:
                # add v at position pos
                cost = 0
                for u in range(n):
                    if (mask >> u) & 1 and adj[u][v]:
                        cost += pos - bin(mask).count("1") + 1  # distance = pos - pos_u
                # Actually distance = pos - pos_u, where pos_u is position of u
                # We can compute by iterating over placed vertices
                # Let's do it properly:
                cost = 0
                for u in range(n):
                    if (mask >> u) & 1 and adj[u][v]:
                        # position of u is its order in mask
                        # We can compute by counting bits before u
                        # Simpler: store positions in reconstruction later
                        # For now, we can compute distance as (pos - pos_u)
                        # pos_u = number of set bits in mask among indices < u
                        pos_u = bin(mask & ((1 << u) - 1)).count("1")
                        cost += pos - pos_u
                new_mask = mask | (1 << v)
                if dp[new_mask] > dp[mask] + cost:
                    dp[new_mask] = dp[mask] + cost
                    parent[new_mask] = mask
    
    full = (1 << n) - 1
    if dp[full] > B:
        print("NO")
        return
    
    # Reconstruct
    assignment = [0] * n
    mask = full
    pos = n - 1
    while mask:
        prev = parent[mask]
        # find the added vertex
        diff = mask ^ prev
        v = diff.bit_length() - 1
        assignment[v] = pos + 1  # 1-based bracket
        mask = prev
        pos -= 1
    
    print("YES")
    print(" ".join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```
