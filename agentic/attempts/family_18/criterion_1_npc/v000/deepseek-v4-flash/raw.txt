We need to decide if there’s a permutation (placement) of vertices along positions 1..n such that the sum of distances between endpoints of each edge is ≤ B.  

This is equivalent to:  
- We have an undirected graph with n vertices and m edges.  
- We need to find a vertex ordering (bijection to 1..n) minimizing sum over edges |pos(u) - pos(v)|.  
- If the minimal possible sum ≤ B, print YES and one optimal ordering; else NO.

This is the “Minimum Linear Arrangement” (MinLA) problem. It’s NP-hard in general, but in contest problems we often encounter small n or specific structures. Since no constraints on n are given in the statement explicitly, but time limit is 5s, typical intended solution uses branch-and-bound / DP over subsets for small n (n ≤ maybe 20 or 24), or some greedy/heuristic if n large but m small? We must be careful.

However, without n bound we must assume it’s small enough for subset DP (e.g., n ≤ 20) — otherwise the problem would be infeasible in contest. I’ll implement a DP over subsets for n ≤ 20 (or possibly up to 22 with bitmask optimization). If n is larger, we may fall back to greedy ordering, but likely n is small.

Standard DP:  
- `dp[mask]` = minimal cost to place vertices in `mask` in the first |mask| positions.  
- When adding a vertex v to the end of current permutation (mask), the added cost is the sum of distances from v to all already placed neighbors, which is simply:  
    distance = |mask| (position of v) − position(u) for each already placed neighbor u. But easier: for each edge (u,v), the contribution when the later of the two is placed is (position_of_later − position_of_earlier). So when we add v at position k (k = number of vertices already placed before adding), the cost contributed by edges from v to already placed u is: (# of such edges) * (k) − sum_of_positions_of_u.  
Thus with precomputed adjacency list and order of positions, we can compute incrementally.

Actually |pos(a)-pos(b)| = number of positions between them. But we can think of cost as sum over each position i from 1 to n-1 of (# edges crossing the cut between positions i and i+1). That's the classic cut formulation: MinLA = sum over cuts of number of edges with one endpoint on each side.  

That's much easier for DP via subset:  
If we choose the set S of vertices placed in the first i positions, then the number of edges crossing that cut is the cut size between S and V\S. The total cost = sum_{i=1}^{n-1} cut(S_i) where S_i is the set of vertices in positions 1..i.

Thus DP over subsets:  
We build permutation by choosing which vertices go to the first i positions. At step i, we choose S_i (size i) and ensure S_{i-1} subset of S_i.  
Cost contribution for step i is cut(S_i). Total cost = sum over i=1..n-1 cut(S_i).  
We want min sum.

This DP:  
`dp[mask]` = minimum total cut cost for the first |mask| positions being exactly `mask`.  
Transition: dp[mask] = min over submask of size |mask|-1 of dp[submask] + cut(mask).  
Because cut(mask) is the cost added when we extend from submask to mask (placing one new vertex). This is valid because cut(mask) depends only on mask, not on order.  
So we can precompute cut[mask] for all masks.

Then we need to find min over full set mask = (1<<n)-1 of dp[full]. The dp recurrence:  
dp[mask] = min_{v in mask} dp[mask ^ (1<<v)] + cut(mask).

This is O(n * 2^n), feasible for n ≤ 20. For n ≤ 20 it's ~20 million operations — fine in Python with optimizations.

After computing dp, we reconstruct order by tracing parent.

Implementation steps:
1. Read n, m, B.
2. Build adjacency matrix or count edges (if multiple edges, count them).
3. Precompute `cut[mask]` = number of edges with one endpoint in mask and one outside.
   - Efficient: For each mask, cut = sum over vertices in mask of deg(v) − 2 * (edges internal to mask).  
     Internal edges count = number of edges with both endpoints in mask.  
     Can precompute `internal[mask]` = number of edges fully inside mask.  
     Then cut[mask] = sum_deg[mask] − 2*internal[mask].  
     Where sum_deg[mask] = sum of degrees of vertices in mask.
   - Precompute sum_deg[mask] and internal[mask] for all masks in O(n*2^n) or via DP.

4. DP:
   dp[0] = 0.  
   For mask from 1 to (1<<n)-1:
       dp[mask] = min_{v in mask} dp[mask ^ (1<<v)] + cut[mask].

   But careful: cut[mask] is the cost contributed by the cut after placing the first |mask| vertices. For the first |mask|, we add cut[mask] once. So yes, dp[mask] = min(dp[prev] + cut[mask]).

   Initialize dp[0]=0.

5. After dp[full] computed, if dp[full] ≤ B, reconstruct:
   - Start from mask=full, repeatedly remove the last added vertex (the one that gave min).  
   - That gives reverse order, reverse it to get final permutation.

6. Output YES and permutation (1-based).

import sys

def solve():
    input = sys.stdin.readline
    n, m, B = map(int, input().split())
    if n == 0:
        print("NO")
        return

    # adjacency count matrix for multiple edges
    edge_count = [[0]*n for _ in range(n)]
    deg = [0]*n
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edge_count[u][v] += 1
        edge_count[v][u] += 1
        deg[u] += 1
        deg[v] += 1

    # If n is too large for exact DP, fallback to heuristic
    if n > 22:
        # Greedy: place most connected first
        order = sorted(range(n), key=lambda x: -deg[x])
        pos = [0]*n
        for i, v in enumerate(order):
            pos[v] = i
        total = 0
        for u in range(n):
            for v in range(u+1, n):
                if edge_count[u][v]:
                    total += abs(pos[u]-pos[v]) * edge_count[u][v]
        if total <= B:
            print("YES")
            print(" ".join(str(pos[i]+1) for i in range(n)))
        else:
            print("NO")
        return

    N = 1 << n
    # sum_deg[mask]
    sum_deg = [0]*N
    # internal[mask] = number of edges with both endpoints inside mask
    internal = [0]*N

    # precompute sum_deg and internal
    for mask in range(1, N):
        lsb = mask & -mask
        v = (lsb.bit_length() - 1)
        prev = mask ^ lsb
        sum_deg[mask] = sum_deg[prev] + deg[v]
        # increase internal by edges from v to vertices already in prev
        inc = 0
        # iterate bits in prev
        pm = prev
        while pm:
            l = pm & -pm
            u = l.bit_length() - 1
            inc += edge_count[u][v]
            pm ^= l
        internal[mask] = internal[prev] + inc

    # cut[mask] = sum_deg[mask] - 2*internal[mask]
    cut = [0]*N
    for mask in range(1, N):
        cut[mask] = sum_deg[mask] - 2*internal[mask]

    INF = 10**18
    dp = [INF]*N
    dp[0] = 0
    parent = [-1]*N  # last added vertex for reconstruction

    for mask in range(1, N):
        best = INF
        best_v = -1
        # try removing each vertex present in mask
        mm = mask
        while mm:
            l = mm & -mm
            v = l.bit_length() - 1
            prev = mask ^ l
            val = dp[prev] + cut[mask]
            if val < best:
                best = val
                best_v = v
            mm ^= l
        dp[mask] = best
        parent[mask] = best_v

    full = N - 1
    if dp[full] > B:
        print("NO")
        return

    # reconstruct permutation (0-based positions)
    perm = [0]*n
    mask = full
    pos = n - 1
    while mask:
        v = parent[mask]
        perm[v] = pos
        pos -= 1
        mask ^= (1 << v)

    print("YES")
    print(" ".join(str(p+1) for p in perm))

if __name__ == "__main__":
    solve()
