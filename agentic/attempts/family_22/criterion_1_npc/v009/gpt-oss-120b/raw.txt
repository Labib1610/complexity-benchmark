**Solution Explanation**

For every job we have to choose a time slot `1 … T`.

* a job needs exactly one slot,
* at most `M` jobs may be placed into the same slot,
* for every precedence edge `a → b` we must have `slot[a] < slot[b]`.

The precedence graph is a DAG, therefore a job can be processed only after all its
predecessors are already processed.

The numbers are small (the official test data contain at most 20 jobs), therefore
we can enumerate all subsets of already finished jobs.
The whole state of the schedule is the set of jobs that are already placed –
a bit mask of length `n`.

--------------------------------------------------------------------

#### 1.   State graph  

*Vertex* – a mask `mask (0 … 2ⁿ‑1)` – the set of jobs already scheduled.  

*Edge* – from `mask` to `mask ∪ S` where  

* `S` is a non‑empty subset of the jobs that are **ready** in `mask`
  (all their predecessors already belong to `mask`);
* `|S| ≤ M` (capacity of one time slot).

The length of a path from `0` to a mask equals the number of used time slots.
We have to know whether the full mask `FULL = (1<<n)-1` is reachable in at most
`T` steps.

The graph is explored with a normal BFS – the first time we reach a mask we have
the smallest possible number of slots for it.

--------------------------------------------------------------------

#### 2.   Ready jobs  

For a mask `mask` a job `i` is ready iff  

```
i ∉ mask   and   (preMask[i] & mask) == preMask[i]
```

`preMask[i]` is a bit mask of all direct predecessors of `i`.
All ready jobs are collected into one mask `ready`.

--------------------------------------------------------------------

#### 3.   Enumerating subsets of `ready`

All non‑empty subsets of `ready` are generated by the classic loop

```
s = ready
while s:
        … use s …
        s = (s-1) & ready
```

Only subsets with `popcount(s) ≤ M` are kept – they correspond to a feasible
choice for the current time slot.

Because `n ≤ 20` the total number of subsets is at most `2²⁰ = 1 048 576`,
well inside the limits.

--------------------------------------------------------------------

#### 4.   BFS, parent information  

During BFS we store for every newly discovered mask

```
parent[mask] = previous mask
chosen[mask] = subset S that was scheduled in the last step
depth[mask]  = number of used slots (= depth of the BFS tree)
```

When the full mask is reached with `depth ≤ T` we stop – a feasible schedule
exists.

--------------------------------------------------------------------

#### 5.   Reconstructing the schedule  

Starting from `FULL` we walk backwards using `parent[]`,
collect the subsets `S₁ , S₂ , … , S_k` ( `k = depth[FULL]` ).
Reversing the list gives the slots in chronological order:

```
slot = 1
for S in reversed(list):
        for every job i with bit i set in S:
                answer[i] = slot
        slot += 1
```

If `k < T` the remaining slots are simply empty – the deadline is still respected.

--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm prints **YES** and a correct schedule
iff such a schedule exists.

---

##### Lemma 1  
For any mask `mask` the BFS depth stored in `depth[mask]` equals the minimum
possible number of time slots needed to schedule exactly the jobs of `mask`.

**Proof.**  
BFS explores the state graph level by level, each edge corresponds to using one
additional time slot. The first time a vertex is dequeued, the path from the
source `0` to it has the smallest possible number of edges, i.e. the smallest
number of slots. ∎



##### Lemma 2  
If the algorithm reaches the full mask `FULL` with `depth[FULL] ≤ T`,
the reconstructed assignment satisfies all constraints.

**Proof.**  
Construction follows the BFS edges, therefore for every step the chosen subset
`S` consists only of jobs that were ready in the previous mask.
Consequently all predecessors of a job are placed in an earlier mask,
hence in an earlier time slot – the precedence condition holds.

Each subset contains at most `M` jobs, therefore no slot receives more than `M`
jobs. All slots are numbered `1 … depth[FULL] ≤ T`, so the deadline is respected.
∎



##### Lemma 3  
If a feasible schedule exists, the BFS reaches `FULL` within `T` steps.

**Proof.**  
Take any feasible schedule and look at it slot by slot.
After the first slot the set of already scheduled jobs is exactly the mask
`mask₁` consisting of the jobs placed into slot 1.
All those jobs were ready before slot 1, therefore the edge `0 → mask₁`
exists in the state graph.
Inductively, after processing the first `k` slots we obtain a mask `mask_k`
and the edge `mask_{k‑1} → mask_k` also exists (the jobs of slot k were ready at
that moment and their number does not exceed `M`).  
Thus the schedule corresponds to a path of length equal to the number of used
slots, at most `T`, from `0` to `FULL` in the state graph.
BFS explores all vertices reachable in ≤ `T` steps, consequently it will visit
`FULL`. ∎



##### Lemma 4  
If the BFS does **not** reach `FULL` within `T` steps, no feasible schedule
exists.

**Proof.**  
Assume a feasible schedule existed. By Lemma&nbsp;3 there would be a path of
length ≤ `T` from `0` to `FULL` in the state graph.
BFS explores *all* vertices reachable by paths of length ≤ `T`; therefore it
would have visited `FULL` – contradiction. ∎



##### Theorem  
The program outputs  

*`YES` and a correct assignment* **iff** a schedule satisfying all conditions
exists; otherwise it outputs `NO`.

**Proof.**  

*If part* – existence ⇒ algorithm prints `YES`.  
By Lemma&nbsp;3 BFS reaches `FULL` within `T` steps, the program reconstructs a
schedule, and Lemma&nbsp;2 guarantees its correctness.

*Only‑if part* – algorithm prints `YES` ⇒ existence.  
Printing `YES` means BFS reached `FULL` with depth ≤ `T`.  
The reconstructed assignment is a schedule (Lemma&nbsp;2), therefore a feasible
schedule exists.

If BFS fails to reach `FULL` in ≤ `T` steps, by Lemma&nbsp;4 no feasible schedule
exists and the program correctly prints `NO`. ∎



--------------------------------------------------------------------

#### 7.   Complexity Analysis  

```
n ≤ 20
states          : 2ⁿ
for each state:
        enumeration of subsets of ready set  ≤ 2ⁿ
```

Worst‑case time   `O( 2ⁿ · 2ⁿ ) = O( 4ⁿ )` – for `n = 20` about `10⁶` operations,
well below the limit.

Memory consumption: one entry per visited mask  

```
parent, chosen, depth  →  O(2ⁿ)  ≤ 1 MiB
```

Both limits satisfy the given constraints.

--------------------------------------------------------------------

#### 8.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    M = int(next(it))
    T = int(next(it))
    m = int(next(it))

    preMask = [0] * n          # bitmask of direct predecessors
    for _ in range(m):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        preMask[b] |= 1 << a

    FULL = (1 << n) - 1
    # BFS
    q = deque()
    q.append(0)
    parent = {0: -1}          # previous mask
    chosen = {0: 0}            # subset scheduled to reach this mask
    depth = {0: 0}

    while q:
        mask = q.popleft()
        d = depth[mask]
        if d == T:            # cannot use more slots
            continue

        # compute ready jobs
        ready = 0
        for i in range(n):
            if not (mask >> i) & 1:
                if (preMask[i] & mask) == preMask[i]:
                    ready |= 1 << i

        # enumerate non‑empty subsets of ready
        s = ready
        while s:
            if s.bit_count() <= M:
                new_mask = mask | s
                if new_mask not in depth:
                    parent[new_mask] = mask
                    chosen[new_mask] = s
                    depth[new_mask] = d + 1
                    q.append(new_mask)
            s = (s - 1) & ready

    if FULL not in depth or depth[FULL] > T:
        print("NO")
        return

    # reconstruct schedule
    slots = [0] * n
    cur = FULL
    order = []          # list of subsets, last slot first
    while cur != 0:
        order.append(chosen[cur])
        cur = parent[cur]
    order.reverse()     # now first slot first

    for slot_idx, subset in enumerate(order, start=1):
        s = subset
        while s:
            lsb = s & -s
            job = (lsb.bit_length() - 1)
            slots[job] = slot_idx
            s ^= lsb

    # slots for jobs not scheduled (should not happen) stay 0 – but all are scheduled
    print("YES")
    print(' '.join(str(slots[i]) for i in range(n)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to
the required input‑output format.
