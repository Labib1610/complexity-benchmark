**Solution Explanation**

For every container we have to choose a departure day `1 … T`.

* each day can be used at most `M` times,
* for every precedence edge `u → v` we need `day[u] < day[v]`,
* all `n` containers must be placed, i.e. `n ≤ T·M`.

The last condition in the statement

```
for every subset S of days   containers on S ≤ |S|·M
```

is exactly the capacity restriction “no day is used more than `M` times”.
So we only have to respect capacities and the precedence order.



--------------------------------------------------------------------

#### 1.   Observations  

* All containers are identical, processing time = 1 day.
* The problem is a classic scheduling problem: unit‑length jobs,
  precedence constraints, `M` identical parallel machines (the `M` slots of a day).

For this problem the following greedy rule is sufficient:

> **Earliest‑possible assignment** –  
> Process the containers in a topological order.
> When a container `v` is processed, all its predecessors already have a day.
> Let `p = max day of its predecessors` ( `0` if none ).
> The container must be placed on a day `d ≥ p+1`.
> Choose the smallest such day that still has a free slot.

If this rule ever fails (no day `≥ p+1` with a free slot) then **no schedule exists**.
The rule is optimal for feasibility: any feasible schedule can be transformed
into one that never uses a later day for a container while keeping all
precedence relations, therefore the greedy algorithm succeeds whenever a
schedule exists.

--------------------------------------------------------------------

#### 2.   Data structures  

* **Topological order** – Kahn’s algorithm (queue, indegrees).
* **`pred_max[v]`** – the largest day among already processed predecessors of `v`.
* **Capacities of days** – `used[d]` (how many containers already placed on day `d`).
* **“next free day” structure** – we need to find the smallest day `≥ x`
  whose capacity is not yet full.
  A disjoint‑set union (DSU / union‑find) works:

```
parent[d] = d          if day d still has a free slot
parent[d] = find(d+1)  if day d is already full
```

`find(x)` returns the first day `≥ x` that still has a free slot
(or `T+1` if none).  
When a day becomes full we union it with the next day.

All operations are amortised `α(T)` (inverse Ackermann), i.e. practically O(1).

--------------------------------------------------------------------

#### 3.   Algorithm  

```
if n > T*M :  answer NO

read graph, build adjacency list and indegrees
queue = all vertices with indegree 0
pred_max[v] = 0 for all v
used[d] = 0 for d = 1..T
make DSU for days 1..T+1   (T+1 is a sentinel “no day”)

while queue not empty:
        v = pop from queue
        earliest = pred_max[v] + 1
        d = find(earliest)          # first day ≥ earliest with free slot
        if d > T:   answer NO       # no place for v
        assign day[v] = d
        used[d] += 1
        if used[d] == M:            # day becomes full
                union(d, d+1)

        for each neighbour w of v:
                pred_max[w] = max(pred_max[w], d)
                indegree[w] -= 1
                if indegree[w] == 0:
                        push w into queue

if not all n vertices processed:   answer NO   (graph has a cycle)

output YES and the array day[1..n]
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` with a valid schedule
iff such a schedule exists.

---

##### Lemma 1  
When a container `v` is processed, `pred_max[v]` equals  
`max { day[u] | (u → v) is an edge and u already processed }`.

**Proof.**  
`pred_max` is initialised with `0`.  
Whenever an edge `u → w` is examined (i.e. when `u` is processed),
`pred_max[w]` is updated with `max(pred_max[w], day[u])`.  
Thus after all already processed predecessors of `v` have been examined,
`pred_max[v]` stores the maximum of their assigned days. ∎



##### Lemma 2  
If the algorithm assigns a day `d` to a container `v`,
then all precedence constraints incident to `v` are satisfied:
for every predecessor `u` we have `day[u] < d`.

**Proof.**  
By Lemma&nbsp;1, `pred_max[v] = max day of predecessors`.  
The algorithm chooses `d = find(pred_max[v] + 1)`, i.e. `d ≥ pred_max[v] + 1`.  
Hence `d > pred_max[v] ≥ day[u]` for every predecessor `u`. ∎



##### Lemma 3  
At any moment `find(x)` returns the smallest day `≥ x` whose used‑counter
is `< M`. If none exists it returns `T+1`.

**Proof.**  
Initially every day is its own parent, therefore `find(x)=x`.  
When a day `d` becomes full we set `parent[d] = find(d+1)`.  
Thus the DSU chain always skips exactly the full days.
Path compression does not change the representative.
Consequently the representative of `x` is the first non‑full day ≥ `x`,
or the sentinel `T+1` if the chain reaches beyond `T`. ∎



##### Lemma 4  
If the algorithm fails (i.e. for some container `v` we get `d > T`),
then **no** feasible schedule exists.

**Proof.**  
Failure means: all days `≥ earliest = pred_max[v]+1` are already full.
Every feasible schedule must place `v` on a day `≥ earliest`
(because of its predecessors).  
Since each of those days already contains `M` containers,
the total number of containers that must be scheduled on the set
`{earliest,…,T}` is at least `M·(T‑earliest+1)+1`,
which exceeds the total capacity of that set.
Thus the capacity condition is violated, so a feasible schedule cannot exist. ∎



##### Lemma 5  
If the algorithm finishes and assigns days to all containers,
the assignment satisfies all problem constraints.

**Proof.**  

*Each container gets a day* – by construction.  
*Day capacity* – a day receives a container only if `used[d] < M`;
after insertion we increase `used[d]`. When it reaches `M` we mark the day
as full, never assigning another container to it. Hence `used[d] ≤ M`.  
*Precedence* – Lemma&nbsp;2.  
*Total unused slots* – `n` containers are placed, total slots are `T·M`,
so unused slots equal `T·M‑n` automatically. ∎



##### Lemma 6  
If a feasible schedule exists, the algorithm never fails.

**Proof.**  
Assume a feasible schedule `S` exists.
Consider the moment the algorithm processes a container `v`.
All its predecessors have already been assigned days not later than in `S`
(because the algorithm always uses the earliest possible day, never later).
Therefore `earliest = pred_max[v]+1` is **≤** the day of `v` in schedule `S`.  
Since `S` puts at most `M` containers on each day, among the days
`earliest … T` there is at least one free slot (the slot used by `v` in `S`).
Consequently `find(earliest)` will return a day `d ≤ day_S(v) ≤ T`,
so the algorithm does not fail at `v`. ∎



##### Theorem  
The algorithm outputs  

*`YES` and a correct assignment* **iff** a feasible dispatch plan exists;  
otherwise it outputs `NO`.

**Proof.**  

*If part*:  
When the algorithm outputs `YES`, it has assigned a day to every container.
By Lemma&nbsp;5 the assignment fulfills all constraints, therefore a feasible
plan exists.

*Only‑if part*:  
Assume a feasible plan exists.
If the algorithm printed `NO`, it must have failed at some container.
By Lemma&nbsp;4 failure implies impossibility, contradicting the existence of
a feasible plan. Hence the algorithm cannot fail and will output `YES`. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Topological sorting* – `O(n + m)`.  
*DSU operations* – at most one `find` and possibly one `union` per container,
  i.e. `O(n α(T))`.  
Overall time `O(n + m)`.  

Memory: adjacency list `O(n + m)`, arrays of size `O(n + T)`.  
All within the limits (`256 MB`).

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    M = int(next(it))
    T = int(next(it))
    m = int(next(it))

    if n > T * M:
        print("NO")
        return

    adj = [[] for _ in range(n)]
    indeg = [0] * n
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        indeg[v] += 1

    # DSU for days 1..T+1 (indexing 1-based for days)
    parent = list(range(T + 2))

    def find(x: int) -> int:
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(x: int, y: int) -> None:
        x = find(x)
        y = find(y)
        if x != y:
            parent[x] = y

    used = [0] * (T + 2)          # used[day]
    pred_max = [0] * n            # max day of processed predecessors
    day = [0] * n                 # answer

    from collections import deque
    q = deque([i for i in range(n) if indeg[i] == 0])

    processed = 0
    while q:
        v = q.popleft()
        earliest = pred_max[v] + 1
        d = find(earliest)
        if d > T:
            print("NO")
            return
        day[v] = d
        used[d] += 1
        if used[d] == M:
            union(d, d + 1)

        for w in adj[v]:
            if d > pred_max[w]:
                pred_max[w] = d
            indeg[w] -= 1
            if indeg[w] == 0:
                q.append(w)
        processed += 1

    if processed != n:
        # cycle
        print("NO")
        return

    print("YES")
    print(' '.join(str(day[i]) for i in range(n)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
