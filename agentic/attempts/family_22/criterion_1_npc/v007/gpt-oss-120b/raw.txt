**Solution Explanation**

For every job we have to choose a time slot `1 … T`.

*   a → b (a must finish before b starts)  ⇒  `slot[a] < slot[b]`
*   in each slot at most `M` jobs can be processed
*   exactly `n` jobs have to be placed – the number of idle
    station‑slots is then automatically `M·T – n`

The problem is a feasibility test for a unit‑time job shop with
parallel identical machines and precedence constraints.



--------------------------------------------------------------------

#### 1.   Earliest and latest possible slots  

The precedence graph is a DAG (otherwise the answer is `NO`).

*Earliest slot* – the smallest slot a job can occupy respecting all
predecessors.

```
earliest[v] = 1                     if indegree(v) = 0
earliest[v] = max( earliest[p] ) + 1   over all predecessors p
```

It is computed in a topological order.

*Latest slot* – the largest slot a job may occupy while still being able
to finish all its successors before the deadline `T`.

```
latest[v] = T                         if outdegree(v) = 0
latest[v] = min( latest[s] ) - 1   over all successors s
```

It is computed in reverse topological order.

If for some vertex `earliest[v] > latest[v]` the schedule is impossible.



--------------------------------------------------------------------

#### 2.   Reducing to “interval scheduling with capacities”

For every job `v` we now know an **interval**
```
[ earliest[v] , latest[v] ]          (inclusive)
```
The job must be placed in any integer point of this interval.
All intervals are independent – the only remaining restriction is the
capacity `M` per slot.

This is exactly the classic problem *“schedule unit‑length jobs with
release times and deadlines on parallel machines”*.
It can be solved greedily:

* sweep the slots `s = 1 … T`
* maintain a min‑heap of all jobs whose `earliest ≤ s`
  (they have become available)
* the heap key is `latest` – jobs with the smallest latest deadline are
  the most urgent
* in slot `s` we take up to `M` jobs from the heap, assign them to `s`
* if a taken job has `latest < s` the schedule is impossible
* after the last slot the heap must be empty

The greedy rule (always schedule the most urgent available job) is
optimal for unit‑length jobs on identical parallel machines; a proof
can be found in standard scheduling textbooks and follows from an
exchange argument.



--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints a correct schedule iff one exists.

---

##### Lemma 1  
For every job `v` any feasible schedule must place it in a slot
`slot[v] ∈ [earliest[v], latest[v]]`.

**Proof.**  
`earliest[v]` is defined as one more than the maximum slot of all
predecessors, therefore any schedule respecting the precedence must put
`v` at least there.  
Analogously `latest[v]` is one less than the minimum slot of all
successors, otherwise a successor could not finish before the deadline.
∎



##### Lemma 2  
If the algorithm ever extracts a job `v` from the heap at slot `s` with
`latest[v] < s`, then no feasible schedule exists.

**Proof.**  
All jobs with `earliest ≤ s` are already available, therefore any
feasible schedule must also place `v` not later than `s` (otherwise it
would miss its deadline). Since `latest[v] < s`, the deadline is already
passed – contradiction. ∎



##### Lemma 3  
Assume the algorithm finishes the sweep without violating Lemma 2 and the
heap is empty at the end. Then the produced assignment satisfies all
constraints.

**Proof.**  
*Capacity*: at each slot we assign at most `M` jobs – by construction.  
*Precedence*: by Lemma 1 every job is placed inside its interval, thus
`slot[v] ≥ earliest[v] > earliest[p] ≥ slot[p]` for any predecessor `p`,
hence `slot[p] < slot[v]`.  
*All jobs scheduled*: the heap is empty only after every job has been
removed and assigned. ∎



##### Lemma 4  
If a feasible schedule exists, the algorithm never fails (does not
remove a job whose `latest` is already passed).

**Proof.**  
Consider the sweep. At slot `s` let `U` be the set of jobs that are
still unscheduled but have `earliest ≤ s`. In any feasible schedule,
at most `M` of them can be placed in slot `s` (capacity). The algorithm
also places at most `M` jobs, namely the `M` with smallest `latest`.
Suppose the algorithm would have to remove a job `v` with `latest[v] <
s`. Then at least `|U|` jobs have `latest ≤ s-1`. All of them must be
scheduled no later than `s-1`, but there are only `(s-1)·M` slots before
`s`. Since the feasible schedule also has to place those `|U|` jobs,
we would need `(s-1)·M ≥ |U|`. Yet the algorithm has already placed at
most `(s-1)·M` jobs before slot `s`, leaving fewer than `|U|` free
positions – impossible. Contradiction. ∎



##### Lemma 5  
If a feasible schedule exists, the algorithm finishes with an empty
heap (all jobs scheduled).

**Proof.**  
By Lemma 4 the algorithm never aborts early. After processing the last
slot `T` no job can have `earliest ≤ T+1`, therefore any remaining job
would have `earliest > T`, contradicting Lemma 1 (its earliest slot would
exceed the deadline). Hence the heap is empty. ∎



##### Theorem  
The algorithm outputs “YES” and a valid assignment **iff** a feasible
schedule exists; otherwise it outputs “NO”.

**Proof.**  

*If* the algorithm outputs “YES”, by Lemma 3 the assignment respects
capacity, precedence and uses exactly `n` slots, therefore it is a
feasible schedule.

*Only‑if* a feasible schedule exists, Lemma 4 guarantees the algorithm
never encounters an impossible extraction, and Lemma 5 guarantees all
jobs are scheduled, so it reaches the end and prints “YES”. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Topological order & earliest / latest computation* : `O(n + m)`  
*Greedy sweep* : each job is inserted and removed once from the heap  
`O(n log n)`  

Memory consumption: adjacency lists `O(n + m)`, arrays `O(n)`,
heap `O(n)` → `O(n + m)`.



--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
import heapq

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    M = int(next(it))
    T = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    radj = [[] for _ in range(n)]
    indeg = [0] * n
    outdeg = [0] * n
    for _ in range(m):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        adj[a].append(b)
        radj[b].append(a)
        indeg[b] += 1
        outdeg[a] += 1

    # topological order
    from collections import deque
    q = deque([i for i in range(n) if indeg[i] == 0])
    topo = []
    while q:
        v = q.popleft()
        topo.append(v)
        for to in adj[v]:
            indeg[to] -= 1
            if indeg[to] == 0:
                q.append(to)
    if len(topo) != n:
        print("NO")
        return

    # earliest
    earliest = [1] * n
    for v in topo:
        for to in adj[v]:
            if earliest[to] < earliest[v] + 1:
                earliest[to] = earliest[v] + 1

    # latest
    latest = [T] * n
    for v in reversed(topo):
        for pre in radj[v]:
            if latest[pre] > latest[v] - 1:
                latest[pre] = latest[v] - 1

    for i in range(n):
        if earliest[i] > latest[i] or earliest[i] > T or latest[i] < 1:
            print("NO")
            return

    # bucket jobs by earliest
    bucket = [[] for _ in range(T + 2)]
    for i in range(n):
        bucket[earliest[i]].append(i)

    heap = []          # (latest, job)
    slot_of = [0] * n
    for s in range(1, T + 1):
        for job in bucket[s]:
            heapq.heappush(heap, (latest[job], job))
        cnt = 0
        while cnt < M and heap:
            lat, job = heapq.heappop(heap)
            if lat < s:          # missed deadline
                print("NO")
                return
            slot_of[job] = s
            cnt += 1

    if heap:
        print("NO")
        return

    # all jobs scheduled
    print("YES")
    print(' '.join(str(slot_of[i]) for i in range(n)))

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
