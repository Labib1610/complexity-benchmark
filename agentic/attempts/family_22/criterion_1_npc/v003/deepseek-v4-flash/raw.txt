We can model this as a scheduling problem with precedence constraints and a capacity limit per time slot.  

We need to assign each task a slot from 1 to T such that:
- If task a must be before task b, then slot[a] < slot[b].
- No slot has more than M tasks.

This is essentially a **topological ordering with capacity constraints**.  
We can solve it using a greedy approach with a priority queue:

1. Compute in-degrees for all tasks.
2. Put all tasks with in-degree 0 into a min-heap keyed by their earliest possible slot (which is 1 initially).
3. For each slot from 1 to T:
   - Assign up to M tasks from the heap to this slot.
   - After assigning a task, decrease in-degrees of its dependents; if a dependent becomes ready, push it with slot = current slot + 1.
4. If we assign all tasks within T slots, output YES and the slots; otherwise NO.

Here’s the implementation:

```python
import sys
import heapq

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    M = int(next(it))
    T = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n + 1)]
    indeg = [0] * (n + 1)
    
    for _ in range(m):
        a = int(next(it))
        b = int(next(it))
        adj[a].append(b)
        indeg[b] += 1
    
    # heap entries: (earliest_slot, task_id)
    heap = []
    for i in range(1, n + 1):
        if indeg[i] == 0:
            heapq.heappush(heap, (1, i))
    
    slot = [0] * (n + 1)
    assigned = 0
    
    for t in range(1, T + 1):
        if not heap:
            break
        # assign up to M tasks in this slot
        count = 0
        temp = []
        while heap and count < M:
            earliest, task = heapq.heappop(heap)
            if earliest > t:
                # cannot assign yet, put back and stop
                heapq.heappush(heap, (earliest, task))
                break
            slot[task] = t
            assigned += 1
            count += 1
            # reduce indegree of dependents
            for nxt in adj[task]:
                indeg[nxt] -= 1
                if indeg[nxt] == 0:
                    heapq.heappush(heap, (t + 1, nxt))
    
    if assigned == n:
        print("YES")
        print(" ".join(str(slot[i]) for i in range(1, n + 1)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
