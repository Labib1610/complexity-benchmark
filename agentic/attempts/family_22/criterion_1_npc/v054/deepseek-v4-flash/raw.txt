We need to assign each step to a cycle such that:

- Each step takes exactly one cycle.
- At most \( M \) steps per cycle.
- If \( a \to b \) (a produces for b), then cycle(b) > cycle(a).
- All steps must be within cycles \( 1 \) to \( T \).

This is essentially a scheduling problem with precedence constraints and capacity limits.

We can model it as a **topological sort with level assignment**:

1. Build a directed graph where edge \( a \to b \) means \( a \) must be before \( b \).
2. Compute in-degrees.
3. Use a queue to process nodes in topological order.
4. For each node, assign it the smallest cycle ≥ 1 such that:
   - It is greater than the cycle of all its predecessors.
   - The number of steps already assigned to that cycle is less than \( M \).
5. If any node cannot be assigned within \( T \), output `NO`.

We can implement this with a priority queue (min-heap) keyed by the earliest possible cycle, to ensure we fill cycles efficiently.

Here’s the code:

```python
import sys
import heapq

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    M = int(next(it))
    T = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    indeg = [0] * n
    for _ in range(m):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        adj[a].append(b)
        indeg[b] += 1
    
    # earliest possible cycle for each node
    earliest = [1] * n
    # count of steps per cycle
    cycle_count = {}
    
    # min-heap: (earliest_cycle, node)
    heap = []
    for i in range(n):
        if indeg[i] == 0:
            heapq.heappush(heap, (1, i))
    
    assigned = [0] * n
    processed = 0
    
    while heap:
        cyc, u = heapq.heappop(heap)
        # find actual cycle: must be >= cyc and capacity < M
        while cycle_count.get(cyc, 0) >= M:
            cyc += 1
        if cyc > T:
            print("NO")
            return
        assigned[u] = cyc
        cycle_count[cyc] = cycle_count.get(cyc, 0) + 1
        processed += 1
        
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                # earliest cycle for v is at least assigned[u] + 1
                heapq.heappush(heap, (assigned[u] + 1, v))
    
    if processed != n:
        print("NO")
        return
    
    print("YES")
    print(" ".join(str(x) for x in assigned))

if __name__ == "__main__":
    solve()
```
