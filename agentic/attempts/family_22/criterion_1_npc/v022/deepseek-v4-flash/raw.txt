We need to assign each crate to a day from 1 to T, respecting:

- Each day has capacity M.
- If a must be before b, then day(a) < day(b).

This is essentially a scheduling problem with precedence constraints and capacity limits.

We can model it as follows:

1. Build a directed graph from the precedence rules.
2. Check for cycles — if there is a cycle, it’s impossible.
3. Use topological sorting to get an order.
4. Assign days greedily:  
   - Process crates in topological order.  
   - For each crate, assign the earliest possible day that is after all its predecessors and still has capacity.

We can do this efficiently using Kahn’s algorithm with a priority queue or just a simple queue, but we must track the earliest day each crate can be placed.

**Approach:**

- Compute in-degrees.
- For each node, keep `earliest_day` = max(earliest_day of predecessors) + 1.
- Use a min-heap keyed by `earliest_day` to assign days while respecting capacity.

Let’s implement:

```python
import sys
import heapq

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    M = int(next(it))
    T = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    indeg = [0] * n
    for _ in range(m):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        adj[a].append(b)
        indeg[b] += 1
    
    # Kahn's algorithm
    earliest = [1] * n
    heap = []
    for i in range(n):
        if indeg[i] == 0:
            heapq.heappush(heap, (1, i))
    
    assigned_day = [0] * n
    day_count = [0] * (T + 1)
    processed = 0
    
    while heap:
        day, u = heapq.heappop(heap)
        # Find the earliest day >= day with capacity
        d = day
        while d <= T and day_count[d] >= M:
            d += 1
        if d > T:
            print("NO")
            return
        assigned_day[u] = d
        day_count[d] += 1
        processed += 1
        
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                heapq.heappush(heap, (d + 1, v))
    
    if processed != n:
        print("NO")
        return
    
    print("YES")
    print(" ".join(str(assigned_day[i]) for i in range(n)))

if __name__ == "__main__":
    solve()
```
