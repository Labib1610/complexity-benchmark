**Solution Explanation**

For every operation we have to choose a cycle (an integer from `1 … T`)

* each cycle may contain at most `M` operations,
* if there is a dependency `a → b` then `cycle[a] < cycle[b]`.

The dependencies form a directed acyclic graph (DAG) – otherwise the
instance is impossible immediately.

--------------------------------------------------------------------

#### 1.   Earliest and latest possible cycles

For a vertex `v`

* `earliest[v]` – the smallest cycle in which `v` can be placed,
  respecting only the predecessors.
* `latest[v]`   – the largest cycle in which `v` can be placed,
  respecting only the successors and the global limit `T`.

Both values are obtained by a single topological order.

```
earliest[v] = 1 + max( earliest[u] ) over all u → v          (sources → 1)
latest[v]   = T - max( latest[w] - 1 ) over all v → w       (sinks → T)
```

If for some vertex `earliest[v] > latest[v]` the instance is impossible.

Now every operation `v` may be scheduled **anywhere** inside the interval

```
Iv = [ earliest[v] , latest[v] ]          (inclusive)
```

--------------------------------------------------------------------

#### 2.   Reducing the problem to a flow problem  

We have to pick for each vertex exactly one integer inside its interval,
while each integer `t` may be used by at most `M` vertices.
That is a classic bipartite‑matching‑with‑capacities problem and can be
solved by a flow network.

```
source → (capacity 1) → operation vertex v
operation v → (capacity 1) → every time t ∈ Iv
time t → (capacity M) → sink
```

If the maximum flow equals `n` we have a feasible schedule,
otherwise it does not exist.

The naïve network would contain `O(n·T)` edges – far too many.
The intervals are *contiguous*, therefore we can replace the
`operation → all times in Iv` edges by a **segment‑tree gadget**:

* a segment tree over the range `[1 … T]` is built,
  each leaf corresponds to one concrete time `t`,
  each internal node represents an interval,
* an edge of capacity `1` is added from an operation `v`
  to **O(log T)** segment‑tree nodes that together cover `Iv`,
* every internal node has edges of infinite capacity to its two children,
* each leaf (real time) has an edge of capacity `M` to the sink.

The total number of edges is `O( (n+T)·log T )`, easily fast enough.

--------------------------------------------------------------------

#### 3.   Extracting the concrete schedule  

After the flow is computed, each operation vertex has exactly one outgoing
unit of flow, which reaches a leaf of the segment tree.
The leaf’s index is the chosen cycle for that operation.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct schedule
iff such a schedule exists.

---

##### Lemma 1  
For every operation `v` any feasible schedule must place `v`
in a cycle `c` with `earliest[v] ≤ c ≤ latest[v]`.

**Proof.**  
`earliest[v]` is defined as `1 + max` of the cycles of all predecessors,
hence any schedule respecting the edges must use a cycle at least that
large.  
Analogously `latest[v]` is derived from the successors and the global bound
`T`; a later cycle would make some successor impossible.
∎



##### Lemma 2  
If the flow network described above admits a flow of value `n`,
the schedule obtained from the flow satisfies all constraints.

**Proof.**  

*Exactly one time per operation.*  
Capacity `1` on the edge `source → v` forces at most one unit of flow
through `v`. Because the total flow is `n`, each `v` carries exactly one
unit, which must continue to a leaf (capacity `1` on the edge
`v → segment‑node`). Hence each operation receives exactly one time.

*Precedence.*  
By Lemma&nbsp;1 the interval of `v` contains only admissible times,
therefore the chosen leaf lies inside `[earliest[v], latest[v]]`,
which respects all predecessors and successors.

*Capacity per cycle.*  
All flow that reaches leaf `t` must pass the edge `leaf t → sink`,
whose capacity is `M`. Consequently at most `M` units (operations)
can be assigned to the same cycle.

Thus the derived assignment is a feasible schedule. ∎



##### Lemma 3  
If a feasible schedule exists, the flow network has a flow of value `n`.

**Proof.**  
Take any feasible schedule. For each operation `v` let `c(v)` be its
assigned cycle. By Lemma&nbsp;1 `c(v) ∈ Iv`. Send one unit of flow
`source → v → leaf c(v) → sink`.  
All capacities are respected:

* `source → v` capacity `1` – exactly one unit is sent.
* `v → leaf` – the leaf belongs to the interval, therefore the edge
  `v → segment‑node` that covers `c(v)` exists, and the capacity `1`
  is not exceeded.
* `leaf → sink` – at most `M` operations share the same cycle in the
  schedule, so the total flow through that leaf is ≤ `M`.

All flow conservations hold, giving a flow of value `n`. ∎



##### Lemma 4  
The algorithm outputs “YES” **iff** a feasible schedule exists.

**Proof.**  

*If* the algorithm outputs “YES”, it has found a flow of value `n`
(Lemma&nbsp;2) and therefore a feasible schedule.

*Only‑if* a feasible schedule exists, Lemma&nbsp;3 guarantees a flow
of value `n`; the max‑flow algorithm will find it, so the algorithm will
output “YES”. ∎



##### Theorem  
The program prints “YES” and a correct assignment of cycles
exactly when such an assignment exists; otherwise it prints “NO”.

**Proof.**  
Directly from Lemma&nbsp;4 and the construction of the output. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Topological order & earliest / latest computation* : `O(n + m)`

*Segment‑tree construction* : `O(T)`

*Edges from operations to the segment tree* : each operation adds
`O(log T)` edges → `O(n log T)`

*Dinic’s algorithm* on a graph with  
`V = n + 4·T + 2` vertices,  
`E = O( (n+T)·log T )` edges.

For unit capacities Dinic runs in `O( sqrt(V)·E )`, well below the limits
for the given constraints (the official limits allow up to several
10⁵ edges).  

Overall time   `O( (n+T)·log T )`  
Memory usage   `O( (n+T)·log T )` – fits into 256 MiB.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

# ---------- Dinic ----------
class Edge:
    __slots__ = ('to', 'rev', 'cap')
    def __init__(self, to, rev, cap):
        self.to = to
        self.rev = rev
        self.cap = cap

class Dinic:
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]

    def add_edge(self, fr, to, cap):
        f = Edge(to, len(self.g[to]), cap)
        b = Edge(fr, len(self.g[fr]), 0)
        self.g[fr].append(f)
        self.g[to].append(b)

    def bfs_level(self, s, t):
        level = [-1] * self.n
        q = [s]
        level[s] = 0
        for v in q:
            for e in self.g[v]:
                if e.cap and level[e.to] < 0:
                    level[e.to] = level[v] + 1
                    q.append(e.to)
        self.level = level
        return level[t] >= 0

    def dfs(self, v, t, f):
        if v == t:
            return f
        for i in range(self.it[v], len(self.g[v])):
            e = self.g[v][i]
            if e.cap and self.level[v] < self.level[e.to]:
                ret = self.dfs(e.to, t, min(f, e.cap))
                if ret:
                    e.cap -= ret
                    self.g[e.to][e.rev].cap += ret
                    return ret
            self.it[v] += 1
        return 0

    def max_flow(self, s, t):
        flow = 0
        INF = 10 ** 18
        while self.bfs_level(s, t):
            self.it = [0] * self.n
            while True:
                f = self.dfs(s, t, INF)
                if not f:
                    break
                flow += f
        return flow

# ---------- main ----------
def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); M = int(next(it)); T = int(next(it)); m = int(next(it))
    adj = [[] for _ in range(n)]
    radj = [[] for _ in range(n)]
    indeg = [0]*n
    for _ in range(m):
        a = int(next(it))-1
        b = int(next(it))-1
        adj[a].append(b)
        radj[b].append(a)
        indeg[b] += 1

    # topological order
    from collections import deque
    q = deque([i for i in range(n) if indeg[i]==0])
    topo = []
    while q:
        v = q.popleft()
        topo.append(v)
        for to in adj[v]:
            indeg[to] -= 1
            if indeg[to]==0:
                q.append(to)
    if len(topo)!=n:
        print("NO")
        return

    earliest = [1]*n
    for v in topo:
        for to in adj[v]:
            if earliest[to] < earliest[v] + 1:
                earliest[to] = earliest[v] + 1

    latest = [T]*n
    for v in reversed(topo):
        for pre in radj[v]:
            if latest[pre] > latest[v] - 1:
                latest[pre] = latest[v] - 1

    for i in range(n):
        if earliest[i] > latest[i]:
            print("NO")
            return

    # segment tree nodes
    # we will number nodes:
    # 0 ... n-1          : operation vertices
    # n ... n+seg_cnt-1  : segment tree internal + leaves
    # last two nodes: source, sink
    seg_offset = n
    # build segment tree
    size = 1
    while size < T:
        size <<= 1
    seg_cnt = 2*size
    total_nodes = n + seg_cnt + 2
    SRC = total_nodes - 2
    SNK = total_nodes - 1
    dinic = Dinic(total_nodes)

    # edges source -> operation
    for v in range(n):
        dinic.add_edge(SRC, v, 1)

    # leaf to sink (capacity M)
    for leaf in range(size, size+T):
        dinic.add_edge(seg_offset + leaf, SNK, M)

    INF = 10**9
    # internal edges (parent -> child) infinite capacity
    for node in range(1, size):
        dinic.add_edge(seg_offset + node, seg_offset + node*2, INF)
        dinic.add_edge(seg_offset + node, seg_offset + node*2+1, INF)

    # helper to add edges from operation to interval [l,r] (1‑based)
    def add_interval(v, l, r):
        l += size-1
        r += size-1
        while l <= r:
            if l & 1:
                dinic.add_edge(v, seg_offset + l, 1)
                l += 1
            if not (r & 1):
                dinic.add_edge(v, seg_offset + r, 1)
                r -= 1
            l >>= 1
            r >>= 1

    for v in range(n):
        add_interval(v, earliest[v], latest[v])

    flow = dinic.max_flow(SRC, SNK)
    if flow != n:
        print("NO")
        return

    # retrieve assignment
    ans = [0]*n
    for v in range(n):
        for e in dinic.g[v]:
            if e.to >= seg_offset and e.cap == 0:   # used edge
                node = e.to - seg_offset
                # go down to leaf
                while node < size:
                    # which child has flow?
                    left = node*2
                    right = left+1
                    # check edges from current node
                    for ee in dinic.g[seg_offset + node]:
                        if ee.to == seg_offset + left and ee.cap == 0:
                            node = left
                            break
                        if ee.to == seg_offset + right and ee.cap == 0:
                            node = right
                            break
                    else:
                        # should not happen
                        break
                # leaf index to time
                time = node - size + 1
                ans[v] = time
                break

    print("YES")
    print(' '.join(map(str, ans)))

if __name__ == "__main__":
    solve()
```
