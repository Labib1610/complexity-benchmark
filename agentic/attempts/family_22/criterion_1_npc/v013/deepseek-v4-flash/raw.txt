We can model this as a scheduling problem with precedence constraints and capacity limits.  
We need to assign each task a time slot from 1 to T such that:

- If there is an edge a → b, then time[a] < time[b].
- At most M tasks per time slot.

This is essentially a **topological scheduling** problem.  
We can solve it using a greedy approach with a priority queue:

1. Compute in-degrees for all tasks.
2. Put all tasks with in-degree 0 into a min-heap keyed by their earliest possible time (which is 1 initially).
3. For each time slot from 1 to T:
   - Take up to M tasks from the heap that are ready (in-degree 0) and assign them to this slot.
   - After assigning, reduce in-degrees of their dependents; if any become 0, push them into the heap with time = current slot + 1.
4. If we assign all tasks within T slots, output YES and the schedule; otherwise NO.

Here’s the implementation:

```python
import sys
import heapq

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    M = int(next(it))
    T = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    indeg = [0] * n
    
    for _ in range(m):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        adj[a].append(b)
        indeg[b] += 1
    
    # min-heap of (earliest_time, task_index)
    heap = []
    for i in range(n):
        if indeg[i] == 0:
            heapq.heappush(heap, (1, i))
    
    schedule = [0] * n
    assigned = 0
    
    for t in range(1, T + 1):
        if not heap:
            break
        # take up to M tasks
        batch = []
        for _ in range(M):
            if not heap:
                break
            earliest, task = heapq.heappop(heap)
            if earliest > t:
                # cannot schedule this task now, put back and stop
                heapq.heappush(heap, (earliest, task))
                break
            schedule[task] = t
            assigned += 1
            batch.append(task)
        
        # update dependencies
        for task in batch:
            for nxt in adj[task]:
                indeg[nxt] -= 1
                if indeg[nxt] == 0:
                    heapq.heappush(heap, (t + 1, nxt))
    
    if assigned == n:
        print("YES")
        print(" ".join(map(str, schedule)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
