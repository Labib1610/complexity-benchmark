**Solution Explanation**

For every regulator `i` we have a Boolean variable  

* `xi = 1` – regulator `i` is active  
* `xi = 0` – regulator `i` is dormant  

A relief channel is described by two non‑zero integers `l1 , l2`.

* `l > 0` means `xl` must be **true** (`xl = 1`)
* `l < 0` means `x|l|` must be **false** (`x|l| = 0`)

The channel works iff at least one of its two conditions holds, i.e.

```
(l1)  OR  (l2)
```

Thus the whole problem is exactly the classic **2‑SAT** problem:
given `m` clauses each containing two literals, find a satisfying assignment
or report that none exists.

--------------------------------------------------------------------

#### 1.   Implication graph

For a variable `xi` we create two vertices

```
idx(xi = true)   = 2*(i-1)
idx(xi = false)  = 2*(i-1) + 1
```

The negation of a vertex is obtained by `v ^ 1`.

A clause `(a ∨ b)` is equivalent to the two implications

```
¬a → b
¬b → a
```

We add directed edges for all clauses, obtaining a graph with `2·n` vertices
and `2·m` edges.

--------------------------------------------------------------------

#### 2.   Strongly connected components

In a 2‑SAT instance the formula is unsatisfiable **iff**
some variable and its negation belong to the same strongly connected component
(SCC).  
If they are in different SCCs, a satisfying assignment can be built from the
topological order of the SCC‑condensation graph:

*process SCCs in reverse topological order* (the order produced by the second
pass of Kosaraju).  
For each variable `xi` we set it to **true** if the SCC of `xi = true`
appears **after** the SCC of `xi = false`; otherwise we set it to false.
This respects all implications.

We use Kosaraju’s algorithm (two depth‑first passes).  
Complexities: `O(n + m)` time, `O(n + m)` memory – well inside the limits.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
For every clause `(a ∨ b)` the added edges `¬a → b` and `¬b → a`
are satisfied by any assignment that satisfies the clause.

**Proof.**  
If `a` is true, `¬a` is false, the implication `¬a → b` holds trivially.
If `a` is false, then `b` must be true (otherwise the clause is false);
hence `¬a` is true and the edge forces `b` to be true, which it is.
The same argument works for the second edge. ∎



##### Lemma 2  
If a variable `xi` and its negation belong to the same SCC, the formula is
unsatisfiable.

**Proof.**  
Inside an SCC every vertex reaches every other, therefore we have both
implications `xi → ¬xi` and `¬xi → xi`. Any assignment would make at least one
of them false, contradicting Lemma&nbsp;1. ∎



##### Lemma 3  
Assume no variable shares an SCC with its negation.
Let `order(v)` be the index of the SCC of vertex `v` in the reverse‑topological
order (larger index = later).  
Setting `xi = true` iff `order(xi=true) > order(xi=false)` satisfies all
implications of the graph.

**Proof.**  
Consider any edge `u → v`. By construction of the order,
`order(u) ≤ order(v)` (edges never go from a later SCC to an earlier one).
If `order(u) > order(v)` the edge would go backward, impossible.
Now suppose `u` is assigned **true**. Then `order(u)` is larger than the order
of its negation, therefore `order(u) > order(¬u)`. Because `order(u) ≤ order(v)`,
we also have `order(v) > order(¬u)`. Consequently `v` cannot be assigned false,
otherwise `order(v) < order(¬v) = order(¬u)`, contradiction. Hence `v` is true,
so the implication holds. ∎



##### Lemma 4  
The assignment constructed in Lemma&nbsp;3 satisfies every original clause.

**Proof.**  
By Lemma&nbsp;1 each clause is equivalent to its two implication edges.
Lemma&nbsp;3 guarantees that all edges are satisfied, therefore every clause is
satisfied. ∎



##### Theorem  
The algorithm outputs  

* “NO” **iff** the given instance has no satisfying assignment;  
* otherwise “YES” and an assignment that satisfies all channels.

**Proof.**  

*If the algorithm prints “NO”.*  
That happens only when some variable and its negation lie in the same SCC.
By Lemma&nbsp;2 the instance is unsatisfiable.

*If the instance is unsatisfiable.*  
Any satisfying assignment would satisfy all implication edges (Lemma&nbsp;1),
hence no variable can be in the same SCC as its negation (otherwise Lemma&nbsp;2
gives a contradiction). Therefore the algorithm would never encounter such an
SCC and would not print “NO”. Contradiction. So the algorithm prints “NO”
exactly for unsatisfiable instances.

*If the algorithm prints “YES”.*  
All variables are in different SCCs, and the assignment is built as in
Lemma&nbsp;3. By Lemma&nbsp;4 this assignment satisfies every clause, i.e. all
relief channels are operational.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Vertices*: `2·n`  
*Edges*: `2·m`

Kosaraju:

* first DFS – `O(V+E)`  
* second DFS – `O(V+E)`

Overall time `O(n + m)` ≤ `3·10⁵`.  
Memory: adjacency lists for forward and reverse graph, each `O(V+E)`.  
Fits easily into the limits.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # number of vertices
    g = [[] for _ in range(N)]    # forward graph
    rg = [[] for _ in range(N)]   # reverse graph

    def lit_index(x: int) -> int:
        """return vertex index for literal x (positive -> true, negative -> false)"""
        v = abs(x) - 1
        if x > 0:
            return 2 * v          # true
        else:
            return 2 * v + 1      # false

    for _ in range(m):
        a = int(next(it))
        b = int(next(it))
        ia = lit_index(a)
        ib = lit_index(b)
        na = ia ^ 1                # negation
        nb = ib ^ 1
        # ¬a -> b
        g[na].append(ib)
        rg[ib].append(na)
        # ¬b -> a
        g[nb].append(ia)
        rg[ia].append(nb)

    sys.setrecursionlimit(1 << 25)

    visited = [False] * N
    order = []

    def dfs(v: int):
        stack = [(v, 0)]
        while stack:
            node, state = stack.pop()
            if state == 0:
                if visited[node]:
                    continue
                visited[node] = True
                stack.append((node, 1))
                for to in g[node]:
                    if not visited[to]:
                        stack.append((to, 0))
            else:
                order.append(node)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cur = 0

    def rdfs(v: int, label: int):
        stack = [v]
        while stack:
            node = stack.pop()
            if comp[node] != -1:
                continue
            comp[node] = label
            for to in rg[node]:
                if comp[to] == -1:
                    stack.append(to)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, cur)
            cur += 1

    assignment = [0] * n
    for i in range(n):
        if comp[2 * i] == comp[2 * i + 1]:
            print("NO")
            return
        # true component appears later (higher number) -> assign true
        assignment[i] = 1 if comp[2 * i] > comp[2 * i + 1] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
