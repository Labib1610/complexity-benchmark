We can model this as a **2-SAT** problem.  
Each switch `i` has two possible literals:  
- `i` means switch `i` is ON (1)  
- `-i` means switch `i` is OFF (0)  

Each rule `(l1, l2)` means:  
`l1 OR l2` must be true.  

In 2-SAT, an implication `(¬l1 → l2)` and `(¬l2 → l1)` is added to the implication graph.  
Then we check for contradictions using SCC (Strongly Connected Components).  

If a variable and its negation are in the same SCC → unsatisfiable.  
Otherwise, assign values based on topological order of SCCs.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(1 << 20)
input = sys.stdin.readline

n, m = map(int, input().split())
N = 2 * n  # nodes: 0..n-1 for positive, n..2n-1 for negative

def node(lit):
    # lit is int, positive means switch ON, negative means OFF
    if lit > 0:
        return (lit - 1) * 2      # even index for positive
    else:
        return (-lit - 1) * 2 + 1 # odd index for negative

def neg_node(idx):
    return idx ^ 1

g = [[] for _ in range(N)]
gr = [[] for _ in range(N)]

for _ in range(m):
    a, b = map(int, input().split())
    u = node(a)
    v = node(b)
    # ¬u -> v
    g[neg_node(u)].append(v)
    gr[v].append(neg_node(u))
    # ¬v -> u
    g[neg_node(v)].append(u)
    gr[u].append(neg_node(v))

# Kosaraju SCC
visited = [False] * N
order = []

def dfs1(u):
    visited[u] = True
    for w in g[u]:
        if not visited[w]:
            dfs1(w)
    order.append(u)

for i in range(N):
    if not visited[i]:
        dfs1(i)

comp = [-1] * N
def dfs2(u, cid):
    comp[u] = cid
    for w in gr[u]:
        if comp[w] == -1:
            dfs2(w, cid)

cid = 0
for u in reversed(order):
    if comp[u] == -1:
        dfs2(u, cid)
        cid += 1

# Check contradiction
for i in range(n):
    if comp[2*i] == comp[2*i+1]:
        print("NO")
        sys.exit()

# Assign values: choose the one with higher comp id (in Kosaraju, comp id order is topological)
assignment = [0] * n
for i in range(n):
    # comp[2*i] is for positive, comp[2*i+1] for negative
    # If positive has larger comp id, set to 1, else 0
    assignment[i] = 1 if comp[2*i] > comp[2*i+1] else 0

print("YES")
print(" ".join(map(str, assignment)))
```
