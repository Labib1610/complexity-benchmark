**Solution Explanation**

The condition *“for every protocol at least one of its two states must be present”* is exactly a
2‑SAT clause  

```
(l1 is true)  OR  (l2 is true)
```

where a *state* is a literal:
* `+i`  – vent *i* is open  (variable `xi = 1`)
* `-i`  – vent *i* is closed (variable `xi = 0`)

A 2‑SAT instance can be solved in linear time by building the implication graph
and checking its strongly connected components (SCC).

--------------------------------------------------------------------

#### 1.   Graph construction  

For each variable `xi` we create two vertices  

```
idx_false = 2*(i-1)          # xi = 0
idx_true  = idx_false ^ 1    # xi = 1
```

`idx_true` is the opposite of `idx_false` (xor 1).

A literal `l` is transformed to a vertex:

```
if l > 0 :   vertex = (l-1)*2 + 1          # true
else      :   vertex = (-l-1)*2            # false
```

Clause `(a ∨ b)` is equivalent to the two implications  

```
¬a → b
¬b → a
```

We add both directed edges to the graph.

--------------------------------------------------------------------

#### 2.   SCC with Kosaraju (iterative)

Kosaraju works in two passes:

1. DFS on the original graph, store vertices in order of finishing time.
2. DFS on the reversed graph, processing vertices in reverse finishing order,
   assigning a component id to each visited vertex.

Both DFS are written iteratively (explicit stack) to avoid recursion limits.

--------------------------------------------------------------------

#### 3.   Satisfiability test and assignment  

If for some variable `i` the two vertices `idx_false` and `idx_true`
belong to the same SCC, the instance is unsatisfiable → output `NO`.

Otherwise the SCCs form a DAG.  
In Kosaraju the component ids are assigned in the order we discover them in the
second pass, i.e. in **reverse topological order**.
Therefore a variable is set to `true` iff `comp[idx_true] > comp[idx_false]`
(the true literal appears later in the topological order).

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm outputs `YES` and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
For every clause `(a ∨ b)` the added edges `¬a → b` and `¬b → a`
are logically equivalent to the clause.

**Proof.**  
If `a` is true, the clause is satisfied regardless of `b`.  
If `a` is false, then `¬a` is true, so the edge forces `b` to be true.
Thus the clause holds exactly when the implication graph respects those edges. ∎



##### Lemma 2  
If a variable and its negation belong to the same SCC, the formula is unsatisfiable.

**Proof.**  
Inside an SCC each vertex reaches the other.
Hence `xi = true` reaches `xi = false` and vice‑versa, meaning both
implications `xi = true → xi = false` and `xi = false → xi = true` hold.
Both cannot be true simultaneously, so no assignment satisfies all clauses. ∎



##### Lemma 3  
If for every variable the two literals are in different SCCs,
assigning `xi = true` exactly when `comp(true) > comp(false)` satisfies all clauses.

**Proof.**  
Consider any edge `u → v` in the implication graph.
If `u` is true in the assignment, then `comp(u) ≥ comp(v)` because edges never go
from a later SCC to an earlier one (topological order).
If `comp(u) > comp(v)`, then `v` lies in an earlier SCC and is assigned false,
which would violate the implication. Therefore `comp(u) > comp(v)` cannot happen.
Thus `u` true ⇒ `v` true, i.e. every implication is respected.
By Lemma&nbsp;1 each clause is satisfied. ∎



##### Lemma 4  
The algorithm assigns `xi = true` exactly when `comp(true) > comp(false)`.

**Proof.** Directly from the implementation. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff the given set of protocols is contradictory,  
* otherwise `YES` and a configuration that satisfies all protocols.

**Proof.**  

*If the algorithm prints `NO`.*  
That happens only when some variable’s two literals share an SCC.
By Lemma&nbsp;2 the formula is unsatisfiable, i.e. the protocols are contradictory.

*If the algorithm prints `YES`.*  
All literals are in distinct SCCs, otherwise it would have printed `NO`.
The assignment is built as in Lemma&nbsp;4, therefore by Lemma&nbsp;3 it satisfies
all clauses, i.e. all protocols.  

Conversely, if a satisfying assignment exists, the implication graph cannot have
a variable together with its negation in one SCC (otherwise Lemma&nbsp;2 would
contradict existence). Hence the algorithm will not output `NO` and will produce
the assignment described in Lemma&nbsp;3, which is also satisfying. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Vertices*: `2 n`  
*Edges*: `2 m` (two per clause)

Both DFS passes run in `O(V + E) = O(n + m)` time.
Memory consumption is `O(V + E)` for adjacency lists and auxiliary arrays,
well within the limits (`n ≤ 10⁵, m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # total vertices
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def lit_to_idx(l: int) -> int:
        if l > 0:
            return (l - 1) * 2 + 1   # true
        else:
            return (-l - 1) * 2       # false

    for _ in range(m):
        a = int(next(it)); b = int(next(it))
        A = lit_to_idx(a)
        B = lit_to_idx(b)
        NA = A ^ 1
        NB = B ^ 1
        # ¬A -> B
        g[NA].append(B)
        rg[B].append(NA)
        # ¬B -> A
        g[NB].append(A)
        rg[A].append(NB)

    # first pass: order
    visited = [False] * N
    order = []

    for v in range(N):
        if not visited[v]:
            stack = [(v, 0)]
            while stack:
                node, state = stack.pop()
                if state == 0:
                    if visited[node]:
                        continue
                    visited[node] = True
                    stack.append((node, 1))
                    for to in g[node]:
                        if not visited[to]:
                            stack.append((to, 0))
                else:
                    order.append(node)

    # second pass: assign components
    comp = [-1] * N
    cid = 0
    for v in reversed(order):
        if comp[v] == -1:
            stack = [v]
            comp[v] = cid
            while stack:
                node = stack.pop()
                for to in rg[node]:
                    if comp[to] == -1:
                        comp[to] = cid
                        stack.append(to)
            cid += 1

    # check satisfiability and build answer
    ans = [0] * n
    for i in range(n):
        f = 2 * i
        t = f ^ 1
        if comp[f] == comp[t]:
            print("NO")
            return
        ans[i] = 1 if comp[t] > comp[f] else 0

    print("YES")
    print(' '.join(map(str, ans)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to the required input‑output format.
