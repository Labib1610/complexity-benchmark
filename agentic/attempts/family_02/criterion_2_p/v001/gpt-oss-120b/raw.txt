**Solution Explanation**

For every relay `i` we have a Boolean variable  

```
xi = 1   … relay i is in mode 1
xi = 0   … relay i is in mode 0
```

A rule contains two *targets* `t1 , t2`.  
A target `+k` means `xk = 1`, a target `-k` means `xk = 0`.  
The rule is satisfied iff at least one of its two targets is satisfied, i.e.

```
(t1 is true)  OR  (t2 is true)
```

Thus each rule is a 2‑SAT clause.  
The whole problem is exactly the classic **2‑SAT** decision problem:
*Is there an assignment of the `n` Boolean variables that satisfies all
clauses?*  
If yes we also have to output one such assignment.

--------------------------------------------------------------------

#### 1.   Implication graph

For a clause `(a ∨ b)` we add the two implications

```
¬a → b
¬b → a
```

The graph has `2·n` vertices, one for each literal (`xi` and `¬xi`).

Indexing  

```
literal  xi (true)   → 2*i
literal ¬xi (false)  → 2*i+1          (0‑based i)
```

Negation is obtained by `v ^ 1`.

--------------------------------------------------------------------

#### 2.   Strongly connected components

A 2‑SAT instance is satisfiable **iff** no variable and its negation belong to
the same strongly connected component (SCC) of the implication graph.
If it is satisfiable, a topological order of the SCC‑DAG gives a concrete
assignment:

*process SCCs in reverse topological order*  
(if a component is assigned `True`, all literals inside become `True`,
their negations become `False`).

We use Kosaraju’s algorithm (two DFS passes) – it is linear and fits easily
into the limits (`O(n+m)` time, `O(n+m)` memory).

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n, m
build adjacency lists G (forward) and GR (reverse) with 2*n vertices
for each rule (l1, l2):
        a = literal index of l1
        b = literal index of l2
        add edge (a^1) → b   to G,   b → (a^1) to GR
        add edge (b^1) → a   to G,   a → (b^1) to GR

first DFS on G, store vertices by finishing time
second DFS on GR in decreasing finishing order, obtain component id comp[v]

for each variable i:
        if comp[2*i] == comp[2*i+1] → unsatisfiable → print NO
        else assignment[i] = 1 if comp[2*i] > comp[2*i+1] else 0
        (higher component id means earlier in reverse topological order)

print YES and the assignment
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints **YES** and a correct configuration
iff such a configuration exists.

---

##### Lemma 1  
For every clause `(a ∨ b)` the added edges correctly encode the logical
implications `¬a → b` and `¬b → a`.

**Proof.**  
`a` is a literal, its vertex is `v(a)`. Its negation `¬a` is `v(a) ^ 1`.
We add an edge from `v(a)^1` to `v(b)`. This is exactly the implication
`¬a → b`. The symmetric edge is added analogously. ∎



##### Lemma 2  
If a variable `xi` and its negation belong to the same SCC, the formula is
unsatisfiable.

**Proof.**  
Inside an SCC every vertex reaches every other, therefore from `xi` we can
reach `¬xi` and vice‑versa. Hence the implications force `xi = true`
and `xi = false` simultaneously – impossible. ∎



##### Lemma 3  
If no variable collides with its negation in an SCC, the assignment produced
by the algorithm satisfies all clauses.

**Proof.**  
Consider the SCC‑DAG. Kosaraju numbers components in reverse topological order:
if there is an edge `C → D` then `order[C] > order[D]`.  
When processing components in decreasing order we set all literals of the
current component to `True` unless already assigned. Because all outgoing
edges go to already processed (thus already assigned) components, no later
assignment can contradict a previously set literal.

Take any implication `p → q`. If `p` is set `True`, then `p` and `q` lie in the
same SCC or `p`'s SCC has a path to `q`'s SCC, therefore `order[p] > order[q]`
and `q` is processed earlier, i.e. already `True`. Hence every implication
holds, and each original clause `(a ∨ b)` holds because at least one of
`a , b` must be `True` (otherwise both `¬a` and `¬b` would be `True`,
giving edges `¬a → b` and `¬b → a` and forcing a contradiction). ∎



##### Lemma 4  
If the formula is satisfiable, the algorithm never reports a collision
(`comp[2*i] == comp[2*i+1]`).

**Proof.**  
Assume a satisfying assignment exists.
Take any variable `xi`. In the implication graph, all literals true in the
assignment can reach each other (by repeatedly applying implications),
and all false literals can reach each other, but a true literal cannot reach
its false counterpart, otherwise the assignment would force the opposite
value. Hence `xi` and `¬xi` lie in different SCCs. ∎



##### Theorem  
The algorithm outputs  

* “NO” **iff** the instance has no satisfying configuration;  
* otherwise “YES” and an assignment that satisfies all rules.

**Proof.**  

*If the algorithm prints “NO”.*  
It found a variable whose two literals share an SCC. By Lemma&nbsp;2 the
instance is unsatisfiable.

*If the instance is unsatisfiable.*  
Any assignment violates some clause, which yields a contradiction in the
implication graph, i.e. some variable and its negation become mutually
reachable, thus belong to the same SCC. The algorithm will detect it and
print “NO”.

*If the algorithm prints “YES”.*  
No variable collides with its negation, so by Lemma&nbsp;3 the constructed
assignment satisfies all implications, consequently all original clauses.
Thus a valid configuration is produced.

*If a satisfying configuration exists.*  
By Lemma&nbsp;4 no collision occurs, the algorithm reaches the assignment
phase and prints “YES”. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Vertices*: `2n`  
*Edges*: `2m` (two per clause)

*Time*  
- building the graph: `O(m)`  
- first DFS: `O(n+m)`  
- second DFS: `O(n+m)`  
- final assignment: `O(n)`

Total `O(n + m)` ≤ `3·10⁵`.

*Memory*  
Adjacency lists store `2m` integers, plus arrays of size `2n`.  
All fit into the 256 MB limit.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def lit(x: int) -> int:
        """return vertex index for literal x (positive -> xi, negative -> ¬xi)"""
        v = abs(x) - 1
        if x > 0:
            return 2 * v          # xi
        else:
            return 2 * v + 1      # ¬xi

    for _ in range(m):
        a = int(next(it))
        b = int(next(it))
        A = lit(a)
        B = lit(b)
        NA = A ^ 1
        NB = B ^ 1
        # ¬A -> B
        g[NA].append(B)
        rg[B].append(NA)
        # ¬B -> A
        g[NB].append(A)
        rg[A].append(NB)

    visited = [False] * N
    order = []

    sys.setrecursionlimit(1 << 25)

    def dfs(v: int):
        stack = [(v, 0)]
        while stack:
            v, state = stack.pop()
            if state == 0:
                if visited[v]:
                    continue
                visited[v] = True
                stack.append((v, 1))
                for to in g[v]:
                    if not visited[to]:
                        stack.append((to, 0))
            else:
                order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cur = 0
    def rdfs(v: int, label: int):
        stack = [v]
        while stack:
            v = stack.pop()
            if comp[v] != -1:
                continue
            comp[v] = label
            for to in rg[v]:
                if comp[to] == -1:
                    stack.append(to)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, cur)
            cur += 1

    assignment = [0] * n
    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return
        # higher component id = earlier in reverse topological order
        assignment[i] = 1 if comp[2*i] > comp[2*i+1] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
