We can model this as a 2-SAT problem.  
Each zone can be either 0 or 1, and each protocol is an implication:  
`(c1 == false) → (c2 == true)`, which is equivalent to `(c1 OR c2)`.

We can represent each variable `x` as two nodes:  
- `2*x` for `x = 0`  
- `2*x + 1` for `x = 1`  

For a clause `(a OR b)`, we add implications:  
`(not a → b)` and `(not b → a)`.

Then we run SCC (Tarjan or Kosaraju) to check satisfiability.  
If a variable and its negation are in the same SCC, it's unsatisfiable.  
Otherwise, we assign values based on topological order of SCCs.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(10**6)
input = sys.stdin.readline

n, m = map(int, input().split())
N = 2 * n
g = [[] for _ in range(N)]
gr = [[] for _ in range(N)]

def node(var):
    # var > 0: zone var is 1 => literal (var-1)*2 + 1
    # var < 0: zone |var| is 0 => literal (|var|-1)*2
    v = abs(var) - 1
    if var > 0:
        return 2 * v + 1
    else:
        return 2 * v

def add_imp(a, b):
    g[a].append(b)
    gr[b].append(a)

for _ in range(m):
    c1, c2 = map(int, input().split())
    a = node(c1)
    b = node(c2)
    # (not a -> b) and (not b -> a)
    add_imp(a ^ 1, b)
    add_imp(b ^ 1, a)

# Kosaraju's SCC
visited = [False] * N
order = []

def dfs1(u):
    visited[u] = True
    for v in g[u]:
        if not visited[v]:
            dfs1(v)
    order.append(u)

for i in range(N):
    if not visited[i]:
        dfs1(i)

comp = [-1] * N
def dfs2(u, cid):
    comp[u] = cid
    for v in gr[u]:
        if comp[v] == -1:
            dfs2(v, cid)

cid = 0
for u in reversed(order):
    if comp[u] == -1:
        dfs2(u, cid)
        cid += 1

# Check satisfiability
for i in range(n):
    if comp[2*i] == comp[2*i+1]:
        print("NO")
        sys.exit()

# Assign values: choose the one with larger SCC id (topological order)
res = [0] * n
for i in range(n):
    # comp[2*i] is false literal, comp[2*i+1] is true literal
    if comp[2*i+1] > comp[2*i]:
        res[i] = 1
    else:
        res[i] = 0

print("YES")
print(" ".join(map(str, res)))
```
