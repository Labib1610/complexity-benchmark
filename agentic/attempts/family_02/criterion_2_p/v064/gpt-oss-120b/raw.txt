**Solution Explanation**

For every valve `i` we have a Boolean variable `x_i`

* `x_i = 1` – the valve is set to state **1**
* `x_i = 0` – the valve is set to state **0**

Each interlock gives a clause with two *literals*  

```
l > 0   →   literal  x_l      (needs state 1)
l < 0   →   literal ¬x_|l|   (needs state 0)
```

The interlock is safe iff at least one of its two literals is true, i.e. the
clause is satisfied.
Thus the whole problem is exactly the classic **2‑SAT** problem.

--------------------------------------------------------------------

#### 1.   Implication graph

For a clause `(a ∨ b)` we add the two implications

```
¬a → b
¬b → a
```

If we can assign truth values to all literals so that no implication is
violated, the original clauses are satisfied.

We build a directed graph with `2·n` vertices – one for each literal:

```
vertex 2·i     :  ¬x_i   (x_i = 0)
vertex 2·i + 1 :   x_i   (x_i = 1)
```

`neg(v) = v ^ 1` flips the last bit, i.e. gives the opposite literal.

For every interlock we translate the two literals to vertices,
add the two directed edges described above and also store the reversed edges
(needed for Kosaraju).

--------------------------------------------------------------------

#### 2.   Strongly Connected Components (SCC)

In a 2‑SAT instance the formula is **unsatisfiable** iff for some variable
`i` the two vertices `¬x_i` and `x_i` belong to the same SCC.
Otherwise a satisfying assignment exists and can be constructed from the
topological order of the SCC‑condensation graph.

We compute SCCs with **Kosaraju’s algorithm** (two depth‑first passes).

* First pass – DFS on the original graph, store vertices in order of
  finishing time.
* Second pass – DFS on the reversed graph, processing vertices in the
  *reverse* finishing order, assigning a component id to each visited vertex.

The component ids are produced in **reverse topological order**:
if there is an edge `u → v` then `comp[u] ≤ comp[v]`.

--------------------------------------------------------------------

#### 3.   Building a concrete assignment

For each variable `i`

```
if comp[x_i] > comp[¬x_i]   →   set x_i = 1
else                         →   set x_i = 0
```

Because the component of a literal that appears later in the topological order
must be false in any satisfying assignment, the rule above yields a
correct one.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct configuration
iff such a configuration exists.

---

##### Lemma 1  
For every clause `(a ∨ b)` the two added implications are logically equivalent
to the clause: any assignment satisfies the clause **iff** it satisfies both
implications.

**Proof.**  
`(a ∨ b)` is false exactly when `a` is false **and** `b` is false.
`¬a → b` is false exactly when `¬a` is true **and** `b` is false,
i.e. when `a` is false **and** `b` is false.
The same holds for `¬b → a`.  
Thus the clause is false ⇔ at least one implication is false ⇔ both
implications are true. ∎



##### Lemma 2  
If a variable `x_i` and its negation belong to the same SCC, the formula is
unsatisfiable.

**Proof.**  
Inside an SCC every vertex reaches every other vertex.
Hence `x_i → ¬x_i` and `¬x_i → x_i` are both implied.
If we set `x_i = 1`, the first implication forces `¬x_i = 1`,
contradiction.  
If we set `x_i = 0`, the second implication forces `x_i = 1`,
contradiction.  
No assignment can satisfy both, therefore the whole formula is unsatisfiable. ∎



##### Lemma 3  
If for every variable `x_i` the two literals lie in different SCCs,
the assignment defined by  

```
x_i = 1  iff  comp[x_i] > comp[¬x_i]
```

satisfies all implications, hence all original clauses.

**Proof.**  
Consider any implication `p → q`.  
If `p` is false under the assignment, the implication is trivially true.
If `p` is true, then `p`'s literal belongs to a component that appears **later**
in the topological order than `¬p` (by construction of the assignment).
Because there is an edge `p → q`, SCC‑condensation contains an edge
`comp[p] → comp[q]`. Topological order guarantees `comp[p] ≤ comp[q]`.
Since `comp[p] > comp[¬p]`, we have `comp[q] ≥ comp[p] > comp[¬p]`.
If `q` were false, `comp[q]` would be ≤ `comp[¬q]`, contradicting the inequality
above (SCCs are distinct). Therefore `q` must be true.
Thus every implication holds, and by Lemma&nbsp;1 all clauses hold. ∎



##### Lemma 4  
If the algorithm outputs “NO”, the formula is unsatisfiable.

**Proof.**  
The algorithm outputs “NO” exactly when it finds a variable whose two literals
share the same SCC. By Lemma&nbsp;2 the formula cannot be satisfied. ∎



##### Lemma 5  
If the algorithm outputs “YES” and the produced assignment,
the assignment satisfies all interlocks.

**Proof.**  
“YES” is printed only when every variable’s literals are in different SCCs.
The assignment is built exactly as in Lemma&nbsp;3, therefore all
implications (and consequently all clauses) are satisfied. ∎



##### Lemma 6  
If a satisfying assignment exists, the algorithm never outputs “NO”.

**Proof.**  
Assume a satisfying assignment exists but the algorithm finds a variable
with both literals in the same SCC. By Lemma&nbsp;2 the formula would be
unsatisfiable – contradiction. Hence such a variable cannot exist and the
algorithm will not output “NO”. ∎



##### Theorem  
The algorithm prints

* “NO” **iff** no configuration avoids all shutdowns,
* otherwise “YES” followed by a configuration that avoids all shutdowns.

**Proof.**  
*If part*: By Lemma&nbsp;4, “NO” ⇒ unsatisfiable.  
*Only‑if part*: If the formula is unsatisfiable, Lemma&nbsp;2 guarantees that
some variable’s literals share an SCC, so the algorithm prints “NO”.  

If a satisfying configuration exists, Lemma&nbsp;6 guarantees the algorithm
does not print “NO”. It therefore prints “YES” and, by Lemma&nbsp;5,
the accompanying assignment is valid. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Vertices*: `2·n`  
*Edges*: two per clause → `2·m`  

```
Time   :  O( n + m )   (two DFS passes)
Memory :  O( n + m )   (adjacency lists, component array, stack)
```

Both satisfy the limits (`n ≤ 10⁵`, `m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1_000_000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # number of vertices
    g = [[] for _ in range(N)]    # implication graph
    rg = [[] for _ in range(N)]   # reversed graph

    def lit_to_node(l: int) -> int:
        v = abs(l) - 1            # 0‑based variable index
        if l > 0:
            return 2 * v + 1      # x_v  (true)
        else:
            return 2 * v          # ¬x_v (false)

    for _ in range(m):
        a = int(next(it))
        b = int(next(it))
        a_node = lit_to_node(a)
        b_node = lit_to_node(b)
        na = a_node ^ 1           # negation of a
        nb = b_node ^ 1           # negation of b

        # ¬a → b
        g[na].append(b_node)
        rg[b_node].append(na)

        # ¬b → a
        g[nb].append(a_node)
        rg[a_node].append(nb)

    # ---------- Kosaraju ----------
    visited = [False] * N
    order = []

    def dfs(v: int):
        visited[v] = True
        for to in g[v]:
            if not visited[to]:
                dfs(to)
        order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    label = 0

    def rdfs(v: int, lbl: int):
        comp[v] = lbl
        for to in rg[v]:
            if comp[to] == -1:
                rdfs(to, lbl)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, label)
            label += 1

    # ---------- Check satisfiability ----------
    for i in range(n):
        if comp[2 * i] == comp[2 * i + 1]:
            print("NO")
            return

    # ---------- Build assignment ----------
    ans = [0] * n
    for i in range(n):
        ans[i] = 1 if comp[2 * i + 1] > comp[2 * i] else 0

    print("YES")
    print(' '.join(map(str, ans)))


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
