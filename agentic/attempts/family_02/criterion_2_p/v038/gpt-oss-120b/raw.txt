**Solution Explanation**

For every additive `i` we have a Boolean variable  

* `x_i = 1` – the additive is **included**  
* `x_i = 0` – the additive is **excluded**

A directive contains two *criteria* (literals).  
A literal is either `x_i` (positive integer) or `¬x_i` (negative integer).  
The directive is satisfied iff at least one of its two literals is true, i.e. it is a
2‑SAT clause  

```
(lit1) ∨ (lit2)
```

The whole problem is exactly the classic **2‑SAT** problem.

--------------------------------------------------------------------

#### 1.   Implication graph

For a clause `(a ∨ b)` we add the two implications  

```
¬a → b
¬b → a
```

If we can assign truth values to all variables so that every implication is respected,
the assignment satisfies all clauses.

We create a directed graph with `2·n` vertices:

```
vertex 2*i     :  x_i   (true)
vertex 2*i + 1 : ¬x_i   (false)
```

`idx(v)` – index of a literal  

```
idx(x_i)   = 2*i
idx(¬x_i)  = 2*i + 1
```

Negation is obtained by `idx ^ 1`.

For each directive we read the two signed integers `c1 , c2`

```
lit =  x_{|c|}   if c > 0
       ¬x_{|c|}  if c < 0
```

and add the two edges described above.

--------------------------------------------------------------------

#### 2.   Strongly connected components

A 2‑SAT instance is solvable **iff** for every variable `i`
the vertices `x_i` and `¬x_i` belong to different SCCs.
If they are in the same SCC we would have a path `x_i → … → ¬x_i`
and also `¬x_i → … → x_i`, forcing `x_i` to be both true and false.

We compute SCCs with **Kosaraju’s algorithm** (two DFS passes).  
Both passes are written iteratively to avoid recursion limits.

*First pass* – DFS on the original graph, store vertices in order of finishing time.  
*Second pass* – DFS on the reversed graph, processing vertices in reverse finishing order,
assigning a component id to each visited vertex.

--------------------------------------------------------------------

#### 3.   Building a concrete assignment

The component ids are produced in **reverse topological order**:
the first component found in the second pass is a source in the condensation DAG,
the next one is later, etc.

For a variable `i`

```
if comp[x_i] > comp[¬x_i]   →   x_i = 1
else                         →   x_i = 0
```

(The component discovered later gets a larger id, therefore it must be set to true,
otherwise the implication from the later component to the earlier one would be violated.)

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
For every clause `(a ∨ b)` the two added edges `¬a → b` and `¬b → a`
are satisfied by a truth assignment **iff** the clause itself is satisfied.

**Proof.**  
If the clause is satisfied, at least one literal, say `a`, is true.
Then `¬a` is false, so the implication `¬a → b` holds vacuously.
If both literals are true, both implications hold as well.
Conversely, if both implications hold and the clause were false,
both `a` and `b` would be false, i.e. `¬a` and `¬b` true.
Then `¬a → b` would require `b` true – contradiction. ∎



##### Lemma 2  
If in the implication graph a variable and its negation belong to the same SCC,
the 2‑SAT instance is unsatisfiable.

**Proof.**  
Inside one SCC there is a directed path from `x_i` to `¬x_i` and also from `¬x_i` to `x_i`.
Thus the graph contains the implications `x_i → ¬x_i` and `¬x_i → x_i`,
which force `x_i` to be both true and false in any assignment that respects all
implications – impossible. ∎



##### Lemma 3  
If for every variable `i` the vertices `x_i` and `¬x_i` lie in different SCCs,
the assignment defined by  

```
x_i = 1  iff  comp[x_i] > comp[¬x_i]
```

satisfies all implications of the graph.

**Proof.**  
Consider any edge `u → v`.  
In the condensation DAG (graph of SCCs) there is an edge from `comp[u]` to `comp[v]`.
Topological order of SCCs guarantees `comp[u] ≤ comp[v]`.  
If `comp[u] = comp[v]` the edge is inside one SCC, which cannot happen because
different literals of the same variable are never in the same SCC (by premise).
Hence `comp[u] < comp[v]`.  
Our assignment sets a literal true exactly when its component id is larger.
Therefore `u` being true (`comp[u]` larger) would imply `comp[u] > comp[v]`,
contradicting `comp[u] < comp[v]`. So `u` cannot be true while `v` is false;
the implication `u → v` is respected. ∎



##### Lemma 4  
The assignment of Lemma&nbsp;3 satisfies every original clause.

**Proof.**  
By Lemma&nbsp;1 it suffices to show that all implications are satisfied,
which holds by Lemma&nbsp;3. ∎



##### Theorem  
The algorithm outputs  

* `NO` **iff** the given instance has no satisfying assignment;  
* otherwise `YES` and a sequence `s_1 … s_n` that satisfies all directives.

**Proof.**  

*If the algorithm prints `NO`.*  
That happens only when for some variable `i` we found `comp[x_i] = comp[¬x_i]`.
By Lemma&nbsp;2 the instance is unsatisfiable.

*If the instance is unsatisfiable.*  
Any satisfying assignment would respect all implications (Lemma&nbsp;1),
hence would give a topological ordering of SCCs where each variable and its negation
are in different SCCs. Contradiction, therefore some variable must share an SCC with its negation,
the algorithm prints `NO`.

*If the algorithm prints `YES`.*  
All variables have distinct SCCs, and the produced assignment is exactly the one
from Lemma&nbsp;3, which satisfies all clauses by Lemma&nbsp;4.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Vertices*: `2·n ≤ 2·10^5`  
*Edges*: `2·m ≤ 4·10^5`

Both DFS passes visit each vertex and edge once.

```
Time   :  O(n + m)
Memory :  O(n + m)   (adjacency lists, reverse lists, stacks, arrays)
```

Both fit easily into the limits.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # total vertices
    g = [[] for _ in range(N)]   # forward graph
    rg = [[] for _ in range(N)]  # reversed graph

    def lit_idx(c: int) -> int:
        v = abs(c) - 1            # 0‑based variable index
        if c > 0:
            return 2 * v          # x_i
        else:
            return 2 * v + 1      # ¬x_i

    for _ in range(m):
        c1 = int(next(it))
        c2 = int(next(it))
        a = lit_idx(c1)
        b = lit_idx(c2)
        na = a ^ 1                 # negation
        nb = b ^ 1
        # ¬a -> b
        g[na].append(b)
        rg[b].append(na)
        # ¬b -> a
        g[nb].append(a)
        rg[a].append(nb)

    sys.setrecursionlimit(1 << 25)

    # ---------- first pass: order ----------
    visited = [False] * N
    order = []

    for v in range(N):
        if not visited[v]:
            stack = [(v, 0)]          # (vertex, next_child_index)
            visited[v] = True
            while stack:
                cur, idx = stack[-1]
                if idx < len(g[cur]):
                    nxt = g[cur][idx]
                    stack[-1] = (cur, idx + 1)
                    if not visited[nxt]:
                        visited[nxt] = True
                        stack.append((nxt, 0))
                else:
                    order.append(cur)
                    stack.pop()

    # ---------- second pass: components ----------
    comp = [-1] * N
    cur_comp = 0
    for v in reversed(order):
        if comp[v] == -1:
            stack = [v]
            comp[v] = cur_comp
            while stack:
                cur = stack.pop()
                for nxt in rg[cur]:
                    if comp[nxt] == -1:
                        comp[nxt] = cur_comp
                        stack.append(nxt)
            cur_comp += 1

    # ---------- check satisfiability ----------
    assignment = [0] * n
    for i in range(n):
        if comp[2 * i] == comp[2 * i + 1]:
            print("NO")
            return
        # larger component id => true
        assignment[i] = 1 if comp[2 * i] > comp[2 * i + 1] else 0

    # ---------- output ----------
    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
