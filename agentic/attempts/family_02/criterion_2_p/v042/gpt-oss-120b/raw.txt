**Solution Explanation**

For every case `i` we have a Boolean variable  

```
xi = 1   … case i gets an amber filter
xi = 0   … case i gets a blue filter
```

A guideline contains two *literals*  

```
c1 , c2   (|c| ≤ n , c ≠ 0)
```

* `c  > 0`  means literal  “xi is 1”   (xi)
* `c  < 0`  means literal  “xi is 0”   (¬xi)

The guideline is satisfied iff at least one of its literals is true, i.e.

```
(c1) ∨ (c2)
```

Thus the whole problem is exactly a **2‑SAT** instance.



--------------------------------------------------------------------

#### 1.   Implication graph

For a clause `(a ∨ b)` we add the two implications

```
¬a → b
¬b → a
```

If we can assign truth values to all variables so that every implication
holds, the original clause set is satisfied.

We build a directed graph with `2·n` vertices:

```
vertex 2·(i-1)     : xi   (true)
vertex 2·(i-1)+1   : ¬xi  (false)
```

```
idx(literal):
    if literal > 0 : return 2·(literal-1)          # xi
    else           : return 2·(-literal-1) + 1    # ¬xi
neg(v) = v ^ 1
```

For each guideline we add the two edges described above.



--------------------------------------------------------------------

#### 2.   Strongly connected components

In an implication graph a 2‑SAT instance is **unsatisfiable** iff for some
variable `i` the vertices `xi` and `¬xi` belong to the same strongly
connected component (SCC).  
Otherwise a satisfying assignment exists and can be obtained from the
topological order of the SCC‑condensation graph:

```
xi = 1   if   comp[xi]  >  comp[¬xi]
xi = 0   otherwise
```

(Components are numbered in reverse topological order by Kosaraju’s
second DFS pass.)

We use Kosaraju’s algorithm – two linear passes, iterative stacks
to avoid recursion limits.



--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
For every clause `(a ∨ b)` the added edges `¬a → b` and `¬b → a`
are logically equivalent to the clause.

**Proof.**  
If `a` is true, the clause is satisfied regardless of `b`.  
If `a` is false, then `¬a` is true, therefore the edge forces `b` to be
true, satisfying the clause. Symmetric for `b`. ∎



##### Lemma 2  
If the algorithm finds a variable `i` with `xi` and `¬xi` in the same SCC,
the original instance is unsatisfiable.

**Proof.**  
Inside one SCC every vertex reaches every other, thus `xi → ¬xi` and
`¬xi → xi`. Any assignment would have to make both true, impossible.
Hence no assignment can satisfy all implications, and by Lemma&nbsp;1
no assignment can satisfy all clauses. ∎



##### Lemma 3  
Assume no variable has `xi` and `¬xi` in the same SCC.
Let `order(v)` be the component number (higher = later in topological order).
The assignment `xi = 1` iff `order(xi) > order(¬xi)` satisfies all
implications.

**Proof.**  
Consider any edge `u → v`. In the condensation DAG edges go from a
component to a *different* component that appears later in topological
order, i.e. `order(u) < order(v)`.  
If `u` is assigned true, then `order(u) > order(¬u)`. Because `order(u) <
order(v)`, we have `order(v) > order(¬u)`. Two cases:

* `v` is the literal itself → `v` true, implication satisfied.
* `v` is the negation of some variable → then `order(v) > order(¬v)`,
  so `v` is true as well.

Thus every edge’s premise being true forces its conclusion true,
so all implications hold. ∎



##### Lemma 4  
If all implications hold, all original clauses hold.

**Proof.**  
By Lemma&nbsp;1 each clause is equivalent to its two implications.
If both implications are true, the clause is true. ∎



##### Theorem  
The algorithm outputs  

* “NO”  **iff** the 2‑SAT instance is unsatisfiable,
* otherwise “YES” and a binary array that satisfies every guideline.

**Proof.**  

*If the algorithm prints “NO”.*  
That happens only when some variable has `xi` and `¬xi` in the same SCC.
By Lemma&nbsp;2 the instance is unsatisfiable.

*If the instance is unsatisfiable.*  
Any satisfying assignment would satisfy all implications (Lemma&nbsp;1),
hence cannot have a variable with both literals in the same SCC
(otherwise Lemma&nbsp;2 gives a contradiction). Therefore the algorithm
must detect such a SCC and print “NO”.

*If the algorithm prints “YES”.*  
No variable has both literals in one SCC. The assignment constructed
from component order satisfies all implications (Lemma&nbsp;3) and thus
all clauses (Lemma&nbsp;4). Hence it is a valid lighting configuration.

*If a satisfying assignment exists.*  
Then no variable can have both literals in one SCC (otherwise Lemma&nbsp;2
contradicts existence). The algorithm therefore reaches the “YES” branch
and outputs a valid assignment (as just proved). ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Vertices*: `2·n`  
*Edges*: `2·m` (two per clause)

Kosaraju:

* first DFS pass – `O(V+E)`
* second pass – `O(V+E)`

Overall  

```
Time   : O(n + m)   ≤ 3·10^5
Memory : O(n + m)   (adjacency lists, stacks, component array)
```

Both fit easily into the limits.



--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def idx(lit: int) -> int:
        if lit > 0:
            return 2 * (lit - 1)          # xi
        else:
            return 2 * (-lit - 1) + 1     # ¬xi

    for _ in range(m):
        a = int(next(it))
        b = int(next(it))
        A = idx(a)
        B = idx(b)
        NA = A ^ 1
        NB = B ^ 1
        # ¬a -> b
        g[NA].append(B)
        rg[B].append(NA)
        # ¬b -> a
        g[NB].append(A)
        rg[A].append(NB)

    # ---------- first pass ----------
    visited = [False] * N
    order = []

    for v in range(N):
        if not visited[v]:
            stack = [(v, 0)]
            while stack:
                node, state = stack.pop()
                if state == 0:
                    if visited[node]:
                        continue
                    visited[node] = True
                    stack.append((node, 1))
                    for to in g[node]:
                        if not visited[to]:
                            stack.append((to, 0))
                else:
                    order.append(node)

    # ---------- second pass ----------
    comp = [-1] * N
    cur = 0
    for v in reversed(order):
        if comp[v] == -1:
            stack = [v]
            comp[v] = cur
            while stack:
                node = stack.pop()
                for to in rg[node]:
                    if comp[to] == -1:
                        comp[to] = cur
                        stack.append(to)
            cur += 1

    # ---------- check satisfiability ----------
    assignment = [0] * n
    for i in range(n):
        if comp[2 * i] == comp[2 * i + 1]:
            print("NO")
            return
        # true component has larger number (appears earlier in second pass)
        assignment[i] = 1 if comp[2 * i] > comp[2 * i + 1] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
