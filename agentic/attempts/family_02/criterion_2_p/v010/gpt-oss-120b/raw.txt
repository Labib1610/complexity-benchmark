**Solution Explanation**

The problem is exactly the classic *2‑SAT* problem.

*Variables* – for each machine `i (1…n)` we have a Boolean variable `x_i` :

* `x_i = 1`  → machine `i` is set to mode 1  
* `x_i = 0`  → machine `i` is set to mode 0  

A tolerance line contains two literals `a , b`.  
A literal is either `i` (means `x_i = 1`) or `-i` (means `x_i = 0`).  
The tolerance is satisfied iff at least one of the literals is true, i.e. the clause  
`a ∨ b`.

Thus we have a CNF formula consisting only of clauses with two literals – a 2‑SAT instance.
We have to decide its satisfiability and, if satisfiable, output one assignment.

--------------------------------------------------------------------

#### 1.   Implication graph

For each variable `x_i` we create two vertices  

* `i`   – representing literal `x_i` (true)  
* `i+n` – representing literal `¬x_i` (false)

Numbering: `idx(literal)`  

```
if literal > 0 :  idx = literal-1                # 0‑based
else            :  idx = (-literal-1) + n
```

A clause `a ∨ b` is equivalent to the two implications  

* `¬a → b`  
* `¬b → a`

We add directed edges for both implications.

--------------------------------------------------------------------

#### 2.   Strongly connected components

In a 2‑SAT instance the formula is unsatisfiable **iff** some variable and its negation belong to the same strongly connected component (SCC) of the implication graph.

We compute SCCs with Kosaraju’s algorithm (two DFS passes).  
Complexities: `O(V+E) = O(n + m)` time, `O(V+E)` memory, well inside limits (`n ≤ 10⁵, m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 3.   Constructing a solution

If the instance is satisfiable, we obtain a topological order of the SCC‑condensation DAG from the second pass (the order in which Kosaraju finishes components).  
Let `comp[v]` be the component id (higher id = later in topological order).  
Assign each variable:

```
if comp[x_i] > comp[¬x_i] :  x_i = 1
else                       :  x_i = 0
```

This respects all implications and therefore satisfies all clauses.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct assignment exactly when one exists.

---

##### Lemma 1  
For every clause `a ∨ b` the added edges `¬a → b` and `¬b → a` are logically equivalent to the clause.

**Proof.**  
`a ∨ b` is false only when both `a` and `b` are false, i.e. when `¬a` and `¬b` are true simultaneously.  
If `¬a` is true, the implication `¬a → b` forces `b` to be true; similarly `¬b → a` forces `a` true.  
Thus any assignment that violates the clause would violate at least one implication, and any assignment satisfying both implications satisfies the clause. ∎



##### Lemma 2  
If a variable `x_i` and its negation belong to the same SCC, the formula is unsatisfiable.

**Proof.**  
Inside an SCC every vertex reaches every other. Hence we have paths `x_i →* ¬x_i` and `¬x_i →* x_i`.  
From the first path, by repeatedly applying the implication rule, `x_i = 1` forces `¬x_i = 1`, i.e. `x_i = 0`.  
Similarly the second path forces `x_i = 0` ⇒ `x_i = 1`.  
Thus any assignment would require `x_i` to be both 0 and 1 – impossible. ∎



##### Lemma 3  
If for every `i` the vertices `x_i` and `¬x_i` lie in different SCCs, the assignment defined by  
`x_i = 1` iff `comp[x_i] > comp[¬x_i]` satisfies all implications.

**Proof.**  
Consider any edge `u → v`. By construction of SCC ids, `comp[u] ≥ comp[v]` cannot happen, because edges go from a component to the same or a later component in topological order; the order we use (Kosaraju finishing times) guarantees `comp[u] > comp[v]` only when `u` is in a later component.  
If `comp[u] > comp[v]` then our rule sets the literal of `u` to **false** (since its component is later) and the literal of `v` to **true** (earlier component). Hence the implication `u → v` is satisfied.  
If `comp[u] < comp[v]` the premise `u` is true only when `v` is also true, again satisfying the implication. ∎



##### Lemma 4  
The assignment of Lemma 3 satisfies every original clause.

**Proof.**  
By Lemma 1 each clause is equivalent to its two implications. Lemma 3 guarantees all implications are satisfied, therefore every clause is satisfied. ∎



##### Theorem  
The algorithm outputs  

* “NO” iff the given instance has no satisfying assignment;  
* otherwise “YES” and a calibration `s₁…s_n` that satisfies all tolerances.

**Proof.**  

*If the algorithm prints “NO”.*  
That happens only when some variable and its negation share an SCC. By Lemma 2 the formula is unsatisfiable, so no calibration exists.

*If the algorithm prints “YES”.*  
Then no variable collides with its negation, so the algorithm builds the assignment described in Lemma 3. By Lemma 4 this assignment satisfies all clauses, i.e. all tolerances. Hence a valid calibration is produced.

Conversely, if a satisfying calibration exists, the formula is satisfiable, thus no variable can be in the same SCC as its negation (otherwise unsatisfiable by Lemma 2). The algorithm will therefore not output “NO” and will produce a satisfying assignment as shown. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Vertices*: `2n`  
*Edges*: `2m` (two per clause)

*Time*  
- Building graph: `O(m)`  
- Kosaraju DFS passes: `O(2n + 2m) = O(n + m)`  

*Memory*  
- Adjacency lists for forward and reverse graph: `O(2n + 2m)`  
- Arrays for visited, order, component ids, assignment: `O(2n)`  

All within the limits (`n ≤ 10⁵, m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def idx(lit: int) -> int:
        """map literal to vertex index (0‑based)"""
        if lit > 0:
            return lit - 1          # x_i
        else:
            return (-lit - 1) + n   # ¬x_i

    for _ in range(m):
        a = int(next(it))
        b = int(next(it))
        a_idx = idx(a)
        b_idx = idx(b)
        na = a_idx ^ n   # opposite literal (toggle between i and i+n)
        nb = b_idx ^ n
        # ¬a -> b
        g[na].append(b_idx)
        rg[b_idx].append(na)
        # ¬b -> a
        g[nb].append(a_idx)
        rg[a_idx].append(nb)

    visited = [False] * N
    order = []

    def dfs(v: int):
        visited[v] = True
        for to in g[v]:
            if not visited[to]:
                dfs(to)
        order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cur = 0

    def rdfs(v: int, label: int):
        comp[v] = label
        for to in rg[v]:
            if comp[to] == -1:
                rdfs(to, label)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, cur)
            cur += 1

    # check satisfiability
    for i in range(n):
        if comp[i] == comp[i + n]:
            print("NO")
            return

    # build assignment
    ans = [0] * n
    for i in range(n):
        ans[i] = 1 if comp[i] > comp[i + n] else 0

    print("YES")
    print(' '.join(map(str, ans)))

if __name__ == "__main__":
    solve()
```
