**Solution Explanation**

The condition *“at least one of the two literals must be true”* is exactly a
2‑SAT clause  

```
(l1 ∨ l2)
```

where a literal is either `xi` (switch *i* is ON) or `¬xi` (switch *i* is OFF).
The whole instance is a conjunction of such clauses, therefore it is a
standard 2‑SAT problem.

The classic linear‑time algorithm:

* build the implication graph with `2·n` vertices  
  (one vertex for each literal, the opposite literal is its complement);
* for each clause `(a ∨ b)` add edges `¬a → b` and `¬b → a`;
* compute strongly connected components (SCC);
* the instance is unsatisfiable iff a variable and its negation belong to the
  same SCC;
* otherwise the SCCs give a topological order – the variable is assigned
  **true** if its SCC appears later than the SCC of its negation.

We use Kosaraju’s algorithm (two DFS passes) which is easy to implement
iteratively and works in `O(n+m)` time and memory.



--------------------------------------------------------------------

#### Graph representation

```
index of literal:
    xi  (true)  -> 2*(i-1) + 1
    ¬xi (false) -> 2*(i-1)
negation:  v ^ 1
```

`2·n` vertices, adjacency lists stored in plain Python lists.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list G and reverse list GR
for each clause (a, b):
        u = node(a)          # literal a
        v = node(b)          # literal b
        add edge (u^1) → v   to G and GR
        add edge (v^1) → u   to G and GR

# 1st pass: order vertices by finish time (DFS on G)
visited = [False]*2n
order = []
for each vertex v:
        if not visited[v]:
                iterative DFS from v, push vertices to order when leaving

# 2nd pass: assign component ids on GR following reversed order
comp = [-1]*2n
cid = 0
for v in reversed(order):
        if comp[v] == -1:
                iterative DFS on GR, marking all reachable vertices with cid
                cid += 1

# check satisfiability
for i = 0 … n-1:
        if comp[2*i] == comp[2*i+1]:
                print "NO" and exit

# build a satisfying assignment
assignment = [0]*n
for i = 0 … n-1:
        # component with larger id appears earlier in topological order
        assignment[i] = 1 if comp[2*i+1] > comp[2*i] else 0

print "YES" and the assignment
```

Both DFS passes are iterative (explicit stack) to avoid recursion limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints **YES** and a correct assignment iff the
instance is satisfiable, otherwise prints **NO**.

---

##### Lemma 1  
For every clause `(a ∨ b)` the added edges `¬a → b` and `¬b → a` are
logically equivalent to the clause: any truth assignment satisfies the clause
iff it satisfies both implications.

**Proof.**  
`¬a → b` is false only when `¬a` is true and `b` is false, i.e. when `a` is
false and `b` is false. The same holds for `¬b → a`. Both implications are
simultaneously true exactly when at least one of `a, b` is true, which is the
definition of the clause. ∎



##### Lemma 2  
If a variable `x` and its negation `¬x` belong to the same SCC, the formula is
unsatisfiable.

**Proof.**  
Inside an SCC there is a directed path from `x` to `¬x` and also from `¬x` to
`x`. By Lemma&nbsp;1 each edge corresponds to an implication that must hold in
any satisfying assignment, therefore the paths give the implications
`x ⇒ ¬x` and `¬x ⇒ x`. Together they force `x` and `¬x` to have the same truth
value, which is impossible. ∎



##### Lemma 3  
If for every variable `x` the literals `x` and `¬x` are in different SCCs,
assigning `x = true` exactly when `comp(x) > comp(¬x)` satisfies all clauses.

**Proof.**  
Consider any edge `p → q` of the implication graph. By construction of SCCs,
`comp(p) ≥ comp(q)` (edges never go from a later component to an earlier one in
the topological order). If `p` is assigned true, then `comp(p) > comp(¬p)`.
Because `comp(p) ≥ comp(q)`, we have `comp(q) > comp(¬p)`. Since `comp(q)` and
`comp(¬q)` are different, `comp(q) > comp(¬q)` holds, i.e. `q` is also true.
Thus every implication is respected, and by Lemma&nbsp;1 all original clauses
are satisfied. ∎



##### Lemma 4  
The algorithm outputs **NO** iff the formula is unsatisfiable.

**Proof.**  
*If* the algorithm prints **NO**, it found a variable with `comp(x)=comp(¬x)`.
By Lemma&nbsp;2 the formula is unsatisfiable.

*Only‑if*: assume the formula is unsatisfiable. In any 2‑SAT instance, unsat
means that some variable must be forced to both true and false, which in the
implication graph forces `x` and `¬x` to be mutually reachable, i.e. belong to
the same SCC. Kosaraju finds exactly the SCC decomposition, so the algorithm
detects such a pair and prints **NO**. ∎



##### Lemma 5  
If the algorithm prints **YES**, the produced assignment satisfies all clauses.

**Proof.**  
When **YES** is printed, no variable shares an SCC with its negation.
The assignment is built exactly as in Lemma&nbsp;3, therefore all implications
(and consequently all clauses) are satisfied. ∎



##### Theorem  
The algorithm is correct.

**Proof.**  
From Lemma&nbsp;4 the algorithm distinguishes satisfiable from unsatisfiable
instances. From Lemma&nbsp;5, when it declares satisfiable it also outputs a
valid assignment. Hence the output conforms to the specification. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building the graph*: `O(m)` edges, `O(n+m)` memory.  
*Kosaraju* performs two DFS traversals, each `O(V+E) = O(n+m)`.  
*Assignment* is `O(n)`.

Total time `O(n + m)` ≤ `3·10^5`, well inside the limits.  
Memory usage `O(n + m)` ≤ about 3 · 10⁵ integers → < 10 MB.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    N = 2 * n
    G = [[] for _ in range(N)]
    GR = [[] for _ in range(N)]

    def lit_to_node(x: int) -> int:
        v = abs(x) - 1
        if x > 0:
            return 2 * v + 1   # true
        else:
            return 2 * v       # false

    for _ in range(m):
        a = int(next(it))
        b = int(next(it))
        u = lit_to_node(a)
        v = lit_to_node(b)
        nu = u ^ 1
        nv = v ^ 1
        G[nu].append(v)
        GR[v].append(nu)
        G[nv].append(u)
        GR[u].append(nv)

    # first pass: order by finish time
    visited = [False] * N
    order = []

    for start in range(N):
        if visited[start]:
            continue
        stack = [(start, 0)]  # (vertex, next child index)
        while stack:
            v, idx = stack[-1]
            if not visited[v]:
                visited[v] = True
            # explore next neighbour
            if idx < len(G[v]):
                nxt = G[v][idx]
                stack[-1] = (v, idx + 1)
                if not visited[nxt]:
                    stack.append((nxt, 0))
            else:
                order.append(v)
                stack.pop()

    # second pass: assign components on reversed graph
    comp = [-1] * N
    cid = 0
    for v in reversed(order):
        if comp[v] != -1:
            continue
        stack = [v]
        comp[v] = cid
        while stack:
            cur = stack.pop()
            for nb in GR[cur]:
                if comp[nb] == -1:
                    comp[nb] = cid
                    stack.append(nb)
        cid += 1

    # check satisfiability
    for i in range(n):
        if comp[2 * i] == comp[2 * i + 1]:
            sys.stdout.write("NO")
            return

    # build assignment
    assign = [0] * n
    for i in range(n):
        assign[i] = 1 if comp[2 * i + 1] > comp[2 * i] else 0

    out = ["YES", " ".join(map(str, assign))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
