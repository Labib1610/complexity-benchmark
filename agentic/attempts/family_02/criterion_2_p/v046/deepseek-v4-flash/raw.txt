We can model this as a **2-SAT** problem.  

Each toggle `i` has two possible literals:  
- `i` means toggle `i` is active (True).  
- `-i` means toggle `i` is inactive (False).  

A contract `(a, b)` means:  
`(a OR b)` must be true.  

In 2-SAT, `(a OR b)` is equivalent to:  
`(!a → b)` and `(!b → a)`.  

We build an implication graph with `2n` nodes (one for each literal and its negation).  
Then we run **Tarjan’s SCC** algorithm.  
If a variable and its negation are in the same SCC, the formula is unsatisfiable.  
Otherwise, we assign values based on the topological order of SCCs.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(10**6)
input = sys.stdin.readline

n, m = map(int, input().split())
N = 2 * n  # nodes: 0..n-1 for positive, n..2n-1 for negative

def node(lit):
    # lit is int, positive means var index lit-1, negative means var index -lit-1 + n
    if lit > 0:
        return lit - 1
    else:
        return n + (-lit) - 1

def neg_node(idx):
    # given node index, return negation node
    if idx < n:
        return idx + n
    else:
        return idx - n

g = [[] for _ in range(N)]
gr = [[] for _ in range(N)]

for _ in range(m):
    a, b = map(int, input().split())
    u = node(a)
    v = node(b)
    # !a -> b
    g[neg_node(u)].append(v)
    gr[v].append(neg_node(u))
    # !b -> a
    g[neg_node(v)].append(u)
    gr[u].append(neg_node(v))

# Kosaraju's algorithm for SCC
visited = [False] * N
order = []

def dfs1(v):
    visited[v] = True
    for to in g[v]:
        if not visited[to]:
            dfs1(to)
    order.append(v)

for i in range(N):
    if not visited[i]:
        dfs1(i)

comp = [-1] * N

def dfs2(v, cid):
    comp[v] = cid
    for to in gr[v]:
        if comp[to] == -1:
            dfs2(to, cid)

cid = 0
for v in reversed(order):
    if comp[v] == -1:
        dfs2(v, cid)
        cid += 1

# Check satisfiability
for i in range(n):
    if comp[i] == comp[i + n]:
        print("NO")
        sys.exit()

# Assign values: if comp[var] > comp[!var] then True
res = [0] * n
for i in range(n):
    res[i] = 1 if comp[i] > comp[i + n] else 0

print("YES")
print(" ".join(map(str, res)))
```
