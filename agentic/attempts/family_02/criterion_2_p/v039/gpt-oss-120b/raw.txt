**Solution Explanation**

The problem is a classic *2‑SAT* instance.

* each valve `i` is a Boolean variable `x_i` (`0` = closed, `1` = open)
* each rule gives a clause `(a ∨ b)` where a literal `a` is either `x_i` (if the
  input number is `+i`) or `¬x_i` (if the input number is `-i`)

A clause `(a ∨ b)` is equivalent to the two implications  

```
¬a → b
¬b → a
```

If we build a directed graph whose vertices are all literals
(`2·n` vertices, one for each `x_i` and `¬x_i`) and add the above edges for
every clause, the formula is satisfiable **iff** no variable and its negation
belong to the same strongly connected component (SCC).  
A satisfying assignment can be obtained from the topological order of the SCC
graph: a literal that appears later (i.e. in a component with larger
post‑order number) is set to `true`.

The constraints (`n ≤ 10⁵ , m ≤ 2·10⁵`) allow an `O(n+m)` algorithm.
We use Kosaraju’s algorithm (two DFS passes) which is simple and fast enough.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
create adjacency lists G[2n], GR[2n]   // graph and reversed graph

for each rule (l1, l2):
        a = literal(l1)          // 0 … 2n-1
        b = literal(l2)
        add edge (a^1) → b   to G and GR
        add edge (b^1) → a   to G and GR

// 1st pass: order vertices by finish time
visited = [False]*2n
order = empty list
for v in 0 … 2n-1:
        if not visited[v]:
                iterative_dfs(v, G, visited, order)   // pushes v after exploring

// 2nd pass: assign component ids on reversed graph
comp = [-1]*2n
cid = 0
for v in reversed(order):
        if comp[v] == -1:
                iterative_dfs_assign(v, GR, comp, cid)
                cid += 1

// check for contradictions
for i in 0 … n-1:
        if comp[2*i] == comp[2*i+1]:
                print "NO" and exit

// build a satisfying assignment
ans = [0]*n
for i in 0 … n-1:
        // component with larger id appears earlier in topological order
        ans[i] = 1 if comp[2*i+1] > comp[2*i] else 0

print "YES"
print ans
```

*`literal(k)`*  
```
idx = abs(k) - 1
if k > 0:   // x_i must be 1  → literal is true
        return 2*idx + 1
else:       // x_i must be 0  → literal is false
        return 2*idx
```
Negation of a literal is `lit ^ 1` (flips the last bit).

Both DFS passes are written iteratively with an explicit stack to avoid Python
recursion limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints **YES** and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
For every clause `(a ∨ b)` the algorithm adds exactly the two implications
`¬a → b` and `¬b → a` to the implication graph.

**Proof.**  
`a` and `b` are transformed to their literal indices `la, lb`.  
`¬a` is `la ^ 1`, `¬b` is `lb ^ 1`.  
The algorithm adds edges `(la ^ 1) → lb` and `(lb ^ 1) → la`. ∎



##### Lemma 2  
If a variable `x_i` and its negation belong to the same SCC, the formula is
unsatisfiable.

**Proof.**  
Inside an SCC each vertex reaches every other, therefore from `x_i` we can
reach `¬x_i` and vice‑versa.  
If we set `x_i = true`, the implication `x_i → ¬x_i` forces `¬x_i = true`,
contradiction. The same holds for `x_i = false`. Hence no assignment can
satisfy all implications, and consequently the original formula. ∎



##### Lemma 3  
If for every `i` the literals `x_i` and `¬x_i` are in different SCCs, the
assignment defined by  

```
x_i = true  iff  comp[x_i] > comp[¬x_i]
```
satisfies all implications.

**Proof.**  
Consider any edge `u → v` in the implication graph.
Topologically, SCCs are ordered so that edges go from a component with larger
`comp` id to a component with smaller id (Kosaraju’s second pass assigns ids in
reverse topological order).  
Thus `comp[u] > comp[v]`.  
If the algorithm sets `u` to true, then `comp[u] > comp[¬u]`.  
Because `comp[u] > comp[v]`, we have `comp[v] ≥ comp[¬u]`.  
If `v` were false, then `comp[v] < comp[¬v]`. Combining the inequalities leads
to a contradiction with the ordering of SCCs. Therefore `v` must be true.
Hence every implication is respected. ∎



##### Lemma 4  
The assignment of Lemma&nbsp;3 also satisfies every original clause.

**Proof.**  
A clause `(a ∨ b)` is equivalent to the two implications of Lemma&nbsp;1.
If both literals `a` and `b` were false, then `¬a` and `¬b` would be true,
and the implications would force `b` and `a` to be true – contradiction.
Thus at least one of `a, b` is true, i.e. the clause holds. ∎



##### Lemma 5  
If the algorithm outputs **YES** and the assignment, the assignment satisfies
all given rules.

**Proof.**  
The algorithm outputs **YES** only when no variable collides with its negation,
so Lemma&nbsp;3 applies and the assignment respects all implications.
By Lemma&nbsp;4 it also satisfies every clause, i.e. every rule. ∎



##### Lemma 6  
If the algorithm outputs **NO**, the instance is unsatisfiable.

**Proof.**  
The algorithm outputs **NO** exactly when some variable `x_i` shares an SCC
with `¬x_i`. By Lemma&nbsp;2 any such situation makes the formula unsatisfiable. ∎



##### Theorem  
The algorithm prints **YES** and a valid configuration of the `n` valves
iff such a configuration exists; otherwise it prints **NO**.

**Proof.**  
*If* the algorithm prints **YES**, Lemma&nbsp;5 guarantees the printed
configuration satisfies all rules.  
*Only if*: suppose a satisfying configuration exists.
Then the implication graph cannot contain a variable together with its
negation in the same SCC (otherwise Lemma&nbsp;2 would contradict existence).
Hence the algorithm will not output **NO**; it will output **YES** and, by
Lemma&nbsp;5, a (possibly different) satisfying configuration. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building the graph*: `O(m)` edges, `O(n+m)` time, `O(n+m)` memory.  
*Kosaraju* (two DFS passes): `O(n+m)` time, `O(n+m)` memory.  
*Assignment construction*: `O(n)` time.  

Overall: **Time `O(n + m)`**, **Memory `O(n + m)`**, well within limits.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    N = 2 * n
    G = [[] for _ in range(N)]
    GR = [[] for _ in range(N)]

    def lit(k: int) -> int:
        idx = abs(k) - 1
        return 2 * idx + (1 if k > 0 else 0)

    for _ in range(m):
        a = int(next(it))
        b = int(next(it))
        la = lit(a)
        lb = lit(b)
        na = la ^ 1
        nb = lb ^ 1
        G[na].append(lb)
        GR[lb].append(na)
        G[nb].append(la)
        GR[la].append(nb)

    # first pass: order
    visited = [False] * N
    order = []

    for v in range(N):
        if not visited[v]:
            stack = [(v, 0)]  # (node, next_child_index)
            while stack:
                node, idx = stack[-1]
                if not visited[node]:
                    visited[node] = True
                # explore next neighbor
                if idx < len(G[node]):
                    nxt = G[node][idx]
                    stack[-1] = (node, idx + 1)
                    if not visited[nxt]:
                        stack.append((nxt, 0))
                else:
                    order.append(node)
                    stack.pop()

    # second pass: assign components
    comp = [-1] * N
    cid = 0
    for v in reversed(order):
        if comp[v] == -1:
            stack = [v]
            comp[v] = cid
            while stack:
                node = stack.pop()
                for nxt in GR[node]:
                    if comp[nxt] == -1:
                        comp[nxt] = cid
                        stack.append(nxt)
            cid += 1

    # check contradictions
    for i in range(n):
        if comp[2 * i] == comp[2 * i + 1]:
            print("NO")
            return

    # build assignment
    ans = [0] * n
    for i in range(n):
        ans[i] = 1 if comp[2 * i + 1] > comp[2 * i] else 0

    print("YES")
    print(' '.join(map(str, ans)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
