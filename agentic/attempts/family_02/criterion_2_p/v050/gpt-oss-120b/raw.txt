**Solution Explanation**

For every array we have a Boolean variable  

* `x_i = 1` – array *i* works in **active** mode  
* `x_i = 0` – array *i* works in **standby** mode  

A failure scenario is given by two *target behaviours* (literals)

```
l1  l2
```

`l > 0` means “array |l| is active” → literal `x_|l|`  
`l < 0` means “array |l| is standby” → literal `¬x_|l|`

The scenario is avoided iff at least one of the two literals is true, i.e.

```
(l1)  OR  (l2)
```

Thus the whole problem is exactly the **2‑SAT** problem:
find a truth assignment for `x1 … xn` satisfying all clauses
`(l1 ∨ l2)`.

--------------------------------------------------------------------

#### 1.   Implication graph

For a clause `(a ∨ b)` we add the two implications

```
¬a → b
¬b → a
```

All literals are vertices of a directed graph.
If a variable and its negation belong to the same strongly connected
component (SCC) the formula is unsatisfiable,
otherwise a satisfying assignment can be built from the topological order
of the SCC‑condensation graph.

Numbering of vertices  

```
variable i (1‑based)
    true  : 2·(i‑1)
    false : 2·(i‑1)+1
```

`idx(l)` – vertex of literal `l`  

```
if l > 0 : 2·(|l|‑1)          # true
else      : 2·(|l|‑1) + 1    # false
```

Negation is simply `v ^ 1` (toggle the last bit).

--------------------------------------------------------------------

#### 2.   Kosaraju’s algorithm

* first DFS on the original graph – store vertices by finishing time
* second DFS on the reversed graph, processing vertices in reverse
  finishing order – each DFS tree is one SCC

The SCC numbers are assigned in the order they are discovered in the
second pass.  
If there is an edge `u → v` in the original graph, then
`comp[u] ≤ comp[v]`.  
Therefore for a variable `i`

```
x_i = true   if   comp[true_i] > comp[false_i]
x_i = false  otherwise
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
For every clause `(a ∨ b)` the algorithm adds exactly the two
implications `¬a → b` and `¬b → a` to the implication graph.

**Proof.** By construction (`idx`, `^1`) the two edges are inserted
for each input line, no other edges are added. ∎



##### Lemma 2  
If a variable `x_i` and its negation belong to the same SCC,
the formula is unsatisfiable.

**Proof.** Inside one SCC there is a directed path from `x_i` to `¬x_i`
and also a path back.  
Consequently the graph contains the implications `x_i → ¬x_i`
and `¬x_i → x_i`.  
Any truth assignment would have to satisfy both, which is impossible.
∎



##### Lemma 3  
If for every variable `x_i` the vertices `true_i` and `false_i`
are in different SCCs, the assignment  

```
x_i = true  iff  comp[true_i] > comp[false_i]
```

satisfies all clauses.

**Proof.**  
Consider any edge `u → v` of the implication graph.
By the property of Kosaraju’s second pass,
`comp[u] ≤ comp[v]`.  
If `comp[u] > comp[v]` the edge would go from a later component to an
earlier one, contradicting the inequality, therefore the inequality holds.

Take a clause `(a ∨ b)`.  
The graph contains the edges `¬a → b` and `¬b → a`.

*Assume* the assignment makes `a` false, i.e. `comp[a] < comp[¬a]`.  
From `¬a → b` we have `comp[¬a] ≤ comp[b]`.  
Because `comp[a] < comp[¬a] ≤ comp[b]`, we obtain `comp[b] > comp[a]`,
hence `b` is true.  
Thus at least one literal of the clause is true.
The same reasoning works when `b` is false.
∎



##### Lemma 4  
If the algorithm outputs “YES” and the produced assignment,
the assignment satisfies all clauses.

**Proof.** The algorithm outputs “YES” only when for every `i`
`comp[true_i] ≠ comp[false_i]`.  
By Lemma&nbsp;3 the derived assignment satisfies every clause. ∎



##### Lemma 5  
If the formula is satisfiable, the algorithm never outputs “NO”.

**Proof.** Assume a satisfying assignment exists.
In any satisfying assignment no variable can imply its own negation,
otherwise the assignment would be forced to be both true and false.
Hence `true_i` and `false_i` cannot be in the same SCC
(otherwise each would reach the other, giving both implications).
Therefore the algorithm will not detect a conflict and will output
“YES”. ∎



##### Theorem  
The algorithm prints  

* “NO” **iff** the instance has no satisfying assignment,  
* otherwise “YES” and a concrete assignment that satisfies all
  critical‑failure scenarios.

**Proof.**  

*If* the algorithm prints “NO”, it found a variable whose two literals
share an SCC. By Lemma&nbsp;2 the instance is unsatisfiable.

*If* the algorithm prints “YES”, Lemma&nbsp;4 guarantees the printed
assignment satisfies all clauses, therefore a solution exists.

Conversely, if a solution exists, Lemma&nbsp;5 shows the algorithm cannot
print “NO”. Hence it prints “YES” and, by Lemma&nbsp;4, a correct
assignment. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Vertices* : `2·n`  
*Edges*    : `2·m` (two per clause)

```
Time   :  O( n + m )   (two DFS passes)
Memory :  O( n + m )   (adjacency lists, stacks, arrays)
```

Both satisfy the limits (`n ≤ 10⁵`, `m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1_000_000)

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)

    N = 2 * n                     # total vertices
    g = [[] for _ in range(N)]    # forward graph
    rg = [[] for _ in range(N)]   # reversed graph

    def lit_idx(l: int) -> int:
        v = abs(l) - 1
        if l > 0:
            return v * 2          # true
        else:
            return v * 2 + 1      # false

    for _ in range(m):
        a = next(it)
        b = next(it)
        a_idx = lit_idx(a)
        b_idx = lit_idx(b)
        na = a_idx ^ 1
        nb = b_idx ^ 1
        # ¬a → b
        g[na].append(b_idx)
        rg[b_idx].append(na)
        # ¬b → a
        g[nb].append(a_idx)
        rg[a_idx].append(nb)

    visited = [False] * N
    order = []

    def dfs1(v: int):
        visited[v] = True
        for to in g[v]:
            if not visited[to]:
                dfs1(to)
        order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs1(v)

    comp = [-1] * N
    label = 0

    def dfs2(v: int, lbl: int):
        stack = [v]
        comp[v] = lbl
        while stack:
            cur = stack.pop()
            for to in rg[cur]:
                if comp[to] == -1:
                    comp[to] = lbl
                    stack.append(to)

    for v in reversed(order):
        if comp[v] == -1:
            dfs2(v, label)
            label += 1

    # check for contradictions
    for i in range(n):
        if comp[2 * i] == comp[2 * i + 1]:
            print("NO")
            return

    # build assignment
    ans = [0] * n
    for i in range(n):
        ans[i] = 1 if comp[2 * i] > comp[2 * i + 1] else 0

    print("YES")
    print(' '.join(map(str, ans)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
