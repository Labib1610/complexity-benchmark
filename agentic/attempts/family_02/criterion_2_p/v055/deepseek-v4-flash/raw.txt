We can model each account as a boolean variable, and each alert as a clause requiring at least one of its two literals to be true.  
This is exactly the **2-SAT** problem.

We’ll build an implication graph:
- For each literal `x`, we have nodes `2*i` for `x_i = true` and `2*i+1` for `x_i = false`.
- For each clause `(a OR b)`, add implications:
  - `not a → b`
  - `not b → a`

Then we run **Tarjan’s SCC** algorithm.  
If a variable and its negation are in the same SCC, it’s unsatisfiable → `NO`.  
Otherwise, we assign values based on the topological order of SCCs.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(1 << 20)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    N = 2 * n
    g = [[] for _ in range(N)]
    rg = [[] for _ in range(N)]

    def node(var):
        # var > 0: account var true -> node 2*(var-1)
        # var < 0: account -var false -> node 2*(-var-1)+1
        if var > 0:
            return 2 * (var - 1)
        else:
            return 2 * (-var - 1) + 1

    def neg_node(u):
        return u ^ 1

    for _ in range(m):
        a, b = map(int, input().split())
        u = node(a)
        v = node(b)
        # not u -> v
        g[neg_node(u)].append(v)
        rg[v].append(neg_node(u))
        # not v -> u
        g[neg_node(v)].append(u)
        rg[u].append(neg_node(v))

    # Kosaraju's SCC
    visited = [False] * N
    order = []

    def dfs1(u):
        visited[u] = True
        for w in g[u]:
            if not visited[w]:
                dfs1(w)
        order.append(u)

    for i in range(N):
        if not visited[i]:
            dfs1(i)

    comp = [-1] * N
    def dfs2(u, cid):
        comp[u] = cid
        for w in rg[u]:
            if comp[w] == -1:
                dfs2(w, cid)

    cid = 0
    for u in reversed(order):
        if comp[u] == -1:
            dfs2(u, cid)
            cid += 1

    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return

    # Assign values: choose the one with larger SCC id (later in topological order)
    res = [0] * n
    for i in range(n):
        # comp[2*i] > comp[2*i+1] means true is later -> assign true
        res[i] = 1 if comp[2*i] > comp[2*i+1] else 0

    print("YES")
    print(" ".join(map(str, res)))

if __name__ == "__main__":
    solve()
```
