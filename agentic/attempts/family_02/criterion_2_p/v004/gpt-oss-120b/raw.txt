**Solution Explanation**

The condition of a rule is a *literal* – a variable together with a required
value (ON = 1, OFF = 0).  
A rule contains two literals `a , b` and is satisfied iff at least one of them
holds, i.e. the Boolean clause  

```
a  OR  b
```

All rules have to hold simultaneously – exactly the classic **2‑SAT** problem.
`n ≤ 10^5 , m ≤ 2·10^5`, therefore a linear‑time algorithm is required.

--------------------------------------------------------------------

#### 1.   Implication graph

For every variable `x (1 … n)` we create two vertices  

* `x_false` – the literal “x = 0”  
* `x_true`  – the literal “x = 1”

```
index(x, value) = 2·(x‑1) + value          // value = 0 → false, 1 → true
```

A clause `(a OR b)` is equivalent to the two implications  

```
¬a → b          and          ¬b → a
```

Thus we add two directed edges for each rule.

--------------------------------------------------------------------

#### 2.   Strongly connected components (SCC)

In the implication graph a 2‑SAT instance is **unsatisfiable** iff for some
variable `x` the two vertices `x_false` and `x_true` belong to the same SCC.
Otherwise a satisfying assignment exists and can be obtained from the
topological order of the SCC‑condensation graph:

*process SCCs in reverse topological order*  
If the SCC of `x_true` is visited **after** the SCC of `x_false`,
set `x = 1`, otherwise `x = 0`.

We compute SCCs with Kosaraju’s algorithm (two depth‑first passes), which is
`O(V+E)` and fits easily into the limits.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
For every clause `(a OR b)` the added edges `¬a → b` and `¬b → a`
are logically equivalent to the clause.

**Proof.**  
If `a` is true, the clause is satisfied regardless of `b`.  
If `a` is false, then `¬a` holds, and the edge forces `b` to be true,
hence the clause is satisfied. The same argument holds swapping `a` and `b`. ∎



##### Lemma 2  
If a variable `x` has `x_false` and `x_true` in the same SCC,
the formula is unsatisfiable.

**Proof.**  
Inside one SCC each vertex reaches the other, therefore we have both
implications `x_false → x_true` and `x_true → x_false`.  
Consequently any assignment must set `x` to both 0 and 1, impossible. ∎



##### Lemma 3  
Assume no variable has its two literals in the same SCC.
Let `order(v)` be the index of the SCC of `v` in the reverse‑topological order
(Kosaraju gives larger numbers to later SCCs).  
Setting a variable `x` to `1` iff `order(x_true) > order(x_false)` yields a
satisfying assignment.

**Proof.**  
Consider any implication edge `p → q`.  
If `order(p) > order(q)`, then `p` belongs to a later SCC, i.e. `p` is set
to **true** while `q` is **false** – this would violate the implication.
Kosaraju’s ordering guarantees that every edge goes from a later SCC to an
earlier or the same SCC, never the opposite.  
Thus for every edge we have `order(p) ≤ order(q)`.  
If `p` is true in the constructed assignment, then `order(p) > order(¬p)`.
Because `order(p) ≤ order(q)`, also `order(q) > order(¬p)`, i.e. `q` is true.
Hence all implications hold, and by Lemma&nbsp;1 all original clauses hold. ∎



##### Lemma 4  
If the algorithm outputs “YES” and the assignment described in Lemma&nbsp;3,
the assignment satisfies all rules.

**Proof.** Directly from Lemma&nbsp;3. ∎



##### Lemma 5  
If the algorithm outputs “NO”, the instance is unsatisfiable.

**Proof.** “NO” is printed exactly when some variable has both literals in the
same SCC. By Lemma&nbsp;2 such a formula cannot be satisfied. ∎



##### Theorem  
The algorithm prints “YES” and a valid assignment **iff** a satisfying
assignment exists; otherwise it prints “NO”.

**Proof.**  

*If part*:  
When the algorithm prints “YES”, no variable has both literals in one SCC.
By Lemma&nbsp;4 the produced assignment satisfies all clauses, therefore a
solution exists.

*Only‑if part*:  
If a satisfying assignment exists, the implication graph cannot contain a
variable whose two literals are mutually reachable (otherwise the assignment
would contradict Lemma&nbsp;2). Hence the algorithm will not encounter such a
SCC and will output “YES”. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Vertices*: `2·n`  
*Edges*:   `2·m` (two per clause)

Kosaraju:

* first DFS pass – `O(V+E)`  
* graph reversal – `O(V+E)` (built once)  
* second DFS pass – `O(V+E)`

Overall time `O(n + m)` ≤ `3·10^5`.  
Memory: adjacency lists for both directions, each storing `2·m` integers,
plus a few auxiliary arrays – well below the 256 MB limit.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    N = 2 * n                     # total vertices
    g = [[] for _ in range(N)]    # forward graph
    rg = [[] for _ in range(N)]   # reversed graph

    def idx(var: int, val: int) -> int:
        """return vertex index for variable var (1‑based) with value val (0/1)"""
        return 2 * (var - 1) + val

    for _ in range(m):
        a = int(next(it))
        b = int(next(it))

        # literal a
        var_a = abs(a)
        val_a = 1 if a > 0 else 0          # a is true when variable = val_a
        lit_a = idx(var_a, val_a)
        not_a = idx(var_a, 1 - val_a)

        # literal b
        var_b = abs(b)
        val_b = 1 if b > 0 else 0
        lit_b = idx(var_b, val_b)
        not_b = idx(var_b, 1 - val_b)

        # add implications ¬a → b , ¬b → a
        g[not_a].append(lit_b)
        rg[lit_b].append(not_a)

        g[not_b].append(lit_a)
        rg[lit_a].append(not_b)

    # ---------- Kosaraju ----------
    visited = [False] * N
    order = []

    sys.setrecursionlimit(1 << 25)

    def dfs(v: int):
        visited[v] = True
        for to in g[v]:
            if not visited[to]:
                dfs(to)
        order.append(v)

    for v in range(N):
        if not visited[v]:
            dfs(v)

    comp = [-1] * N
    cur = 0

    def rdfs(v: int, label: int):
        comp[v] = label
        for to in rg[v]:
            if comp[to] == -1:
                rdfs(to, label)

    for v in reversed(order):
        if comp[v] == -1:
            rdfs(v, cur)
            cur += 1

    # ---------- check satisfiability ----------
    assignment = [0] * n
    for var in range(1, n + 1):
        f = idx(var, 0)
        t = idx(var, 1)
        if comp[f] == comp[t]:
            print("NO")
            return
        # component with larger number appears earlier in topological order
        assignment[var - 1] = 1 if comp[t] > comp[f] else 0

    print("YES")
    print(' '.join(map(str, assignment)))

if __name__ == "__main__":
    solve()
```
