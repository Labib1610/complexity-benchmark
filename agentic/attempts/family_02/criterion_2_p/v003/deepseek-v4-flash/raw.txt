We can model this as a **2-SAT** problem.  
Each switch `i` has two possible literals:  
- `i` means switch `i` is ON (true)  
- `-i` means switch `i` is OFF (false)  

Each rule `(l1, l2)` means:  
`l1 OR l2` must be true.  

In 2-SAT, an implication `(a OR b)` is equivalent to:  
`(¬a → b)` and `(¬b → a)`.  

We build an implication graph with `2n` nodes (one for each literal and its negation).  
Then we run **Kosaraju’s algorithm** or **Tarjan’s SCC** to find strongly connected components.  
If a variable and its negation are in the same SCC, the formula is unsatisfiable → `NO`.  
Otherwise, we assign values based on the topological order of SCCs.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(1 << 20)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    N = 2 * n
    g = [[] for _ in range(N)]
    gr = [[] for _ in range(N)]
    
    def idx(x):
        # x is signed int, return node index
        if x > 0:
            return (x - 1) * 2      # true literal
        else:
            return (-x - 1) * 2 + 1 # false literal
    
    def neg(x):
        return x ^ 1
    
    for _ in range(m):
        a, b = map(int, input().split())
        ia = idx(a)
        ib = idx(b)
        # a OR b => (¬a -> b) and (¬b -> a)
        g[neg(ia)].append(ib)
        g[neg(ib)].append(ia)
        gr[ib].append(neg(ia))
        gr[ia].append(neg(ib))
    
    # Kosaraju
    visited = [False] * N
    order = []
    
    def dfs1(u):
        visited[u] = True
        for v in g[u]:
            if not visited[v]:
                dfs1(v)
        order.append(u)
    
    for i in range(N):
        if not visited[i]:
            dfs1(i)
    
    comp = [-1] * N
    def dfs2(u, cid):
        comp[u] = cid
        for v in gr[u]:
            if comp[v] == -1:
                dfs2(v, cid)
    
    cid = 0
    for u in reversed(order):
        if comp[u] == -1:
            dfs2(u, cid)
            cid += 1
    
    # Check contradiction
    for i in range(n):
        if comp[2*i] == comp[2*i+1]:
            print("NO")
            return
    
    # Assign values: in SCC order, if comp[true] > comp[false] => true
    ans = [0] * n
    for i in range(n):
        ans[i] = 1 if comp[2*i] > comp[2*i+1] else 0
    
    print("YES")
    print(" ".join(map(str, ans)))

if __name__ == "__main__":
    solve()
```
