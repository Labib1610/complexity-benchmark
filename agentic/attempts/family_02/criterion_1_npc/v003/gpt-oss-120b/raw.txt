**Solution Explanation**

For a switch `i`

* value `1`  – the switch is **ON**
* value `0`  – the switch is **OFF**

A rule contains three signed integers  

```
l1 l2 l3          ( |li| ≤ n , li ≠ 0 )
```

`+i` means *“switch i must be ON”*,
`-i` means *“switch i must be OFF”*.

The rule is violated **only** when *all three* conditions are false.
Therefore a rule is satisfied exactly when at least one of its three
conditions is true – it is the ordinary 3‑SAT clause  

```
(l1  OR  l2  OR  l3)
```

The whole problem is to find a truth assignment for `n ≤ 90` variables
that satisfies `m ≤ 400` 3‑clauses, or to decide that none exists.

The size is tiny, so a classic backtracking SAT solver (DPLL) is more
than fast enough.

--------------------------------------------------------------------

#### 1.   Data structures

* `clauses` – list of clauses, each clause is a list of three integers.
* `assign[0…n]` – current partial assignment  
  `-1` … unassigned, `0` … false, `1` … true.

--------------------------------------------------------------------

#### 2.   Core procedures  

All procedures work only with the current `assign`; the list of clauses
is never changed.

*`value(lit)`* – value of a literal under the current assignment  

```
v = assign[abs(lit)]
if v == -1 :   unknown
else          lit > 0 ? v == 1 : v == 0
```

*`clause_status(clause)`* – returns  

* `SAT`   – at least one literal is true,
* `UNSAT` – all three literals are false,
* `UNIT`  – exactly one literal is unknown, the other two are false,
* `UNKNOWN` – none of the above.

--------------------------------------------------------------------
**Unit propagation**

Repeatedly look for a `UNIT` clause, force its remaining literal to be
true, and restart the scan.  
If a clause becomes `UNSAT` → conflict → backtrack.

--------------------------------------------------------------------
**Pure literal elimination**

A variable that appears only with one polarity in all *still unsatisfied*
clauses can be set to that polarity without harming any clause.
We assign all such pure literals, then repeat until none exist.

--------------------------------------------------------------------
**Recursive DPLL**

```
dpll(assign):
    unit propagation
    pure literal elimination
    if every clause is SAT:   return assign
    choose an unassigned variable v
    for val in [1,0]:               # try true, then false
        new_assign = copy(assign)
        new_assign[v] = val
        res = dpll(new_assign)
        if res != None: return res
    return None                     # unsatisfiable under this prefix
```

The recursion depth never exceeds `n = 90`.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints **YES** and a satisfying assignment
iff such an assignment exists.

---

##### Lemma 1  
During unit propagation, if a clause is `UNIT` with remaining literal
`ℓ`, any satisfying assignment must set `ℓ` to true.

**Proof.** In a `UNIT` clause the other two literals are already false.
The clause can be satisfied only by making the remaining literal true.
∎



##### Lemma 2  
Pure literal elimination never removes a satisfying assignment.

**Proof.** Let variable `x` appear only positively (or only negatively) in
all still unsatisfied clauses.
If a satisfying assignment set `x` opposite to that polarity,
every clause containing `x` would become false (because the other two
literals are already false – otherwise the clause would already be
satisfied). Hence the assignment could not be satisfying.
Therefore any satisfying assignment must give `x` the pure polarity,
so fixing it is safe. ∎



##### Lemma 3  
After applying unit propagation and pure literal elimination,
the current partial assignment can be extended to a full satisfying
assignment **iff** the original formula is satisfiable under the same
partial assignment.

**Proof.** Both procedures only perform forced assignments that are
necessary in *every* satisfying extension (Lemma&nbsp;1 and Lemma&nbsp;2).
Thus they do not discard any possible extension, and they never create
a new satisfying assignment that did not exist before. ∎



##### Lemma 4  
When the recursive call `dpll` returns an assignment `A`,
`A` satisfies every clause of the original formula.

**Proof.** The recursion returns only after the final test
“every clause is SAT”.  At that moment all clauses are satisfied under
the current (complete) assignment, which is exactly `A`. ∎



##### Lemma 5  
If the formula is satisfiable, `dpll` eventually returns a satisfying
assignment.

**Proof.** Consider a fixed satisfying assignment `S`.  
During the execution of `dpll`:

* Unit propagation and pure literal elimination keep `S` compatible
  (Lemma&nbsp;3).
* When a variable `v` is chosen, `S` gives it a definite value.
  The recursive branch that tries this value keeps `S` compatible,
  the other branch may fail, but the successful branch exists.
* Recursion proceeds on a strictly larger set of assigned variables,
  therefore after at most `n` levels it reaches a complete assignment,
  which must be `S` (or another satisfying one). ∎



##### Lemma 6  
If `dpll` returns `None`, the formula is unsatisfiable.

**Proof.** `None` is returned only after exploring **both** possible
values for the chosen variable and each branch ending in conflict.
By Lemma&nbsp;3 each branch explores *all* assignments extending the
current partial one.  Hence no extension exists, i.e. the formula is
unsatisfiable under the current prefix.  The initial call has an empty
prefix, therefore the whole formula is unsatisfiable. ∎



##### Theorem  
The program prints  

* `YES` and a list of `0/1` values **iff** there exists a global
  setting of the `n` switches satisfying all `m` rules,
* otherwise prints `NO`.

**Proof.**  
*If* the program prints `YES`, it obtained an assignment from `dpll`;
by Lemma&nbsp;4 this assignment satisfies every clause, i.e. every rule.

*Only‑if*:  
If a satisfying assignment exists, Lemma&nbsp;5 guarantees that `dpll`
finds (and returns) one, so the program prints `YES`.  
If none exists, Lemma&nbsp;6 shows that `dpll` returns `None`,
hence the program prints `NO`. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

`n ≤ 90`, `m ≤ 400`.

*Unit propagation* scans all clauses – `O(m)` – and may be executed at
most `n` times per recursion level, still `O(n·m)`.

The recursion depth ≤ `n`.  
In the worst case the algorithm explores the whole binary tree,
`2^n` leaves, but with the strong pruning of unit propagation and pure
literals the practical number of visited nodes is tiny for the given
limits.

Memory consumption: the clause list (`O(m)`) and a copy of the assignment
(`O(n)`) per recursion level – at most `O(n·depth) = O(n²)` ≤ a few KiB,
well inside the limits.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    clauses = []
    for _ in range(m):
        c = [int(next(it)), int(next(it)), int(next(it))]
        clauses.append(c)

    # ------------------------------------------------------------
    # helper functions working on a given assignment
    # ------------------------------------------------------------
    def literal_is_true(lit, assign):
        v = assign[abs(lit)]
        if v == -1:
            return None
        return (lit > 0 and v == 1) or (lit < 0 and v == 0)

    # ------------------------------------------------------------
    # DPLL recursive solver
    # ------------------------------------------------------------
    def dpll(assign):
        # ---- unit propagation ----
        while True:
            unit_lit = None
            for cl in clauses:
                sat = False
                unknown = []
                for lit in cl:
                    val = literal_is_true(lit, assign)
                    if val is True:
                        sat = True
                        break
                    elif val is None:
                        unknown.append(lit)
                if sat:
                    continue
                if not unknown:          # all false -> conflict
                    return None
                if len(unknown) == 1:   # unit clause
                    unit_lit = unknown[0]
                    break
            if unit_lit is None:
                break
            var = abs(unit_lit)
            needed = 1 if unit_lit > 0 else 0
            if assign[var] != -1:
                if assign[var] != needed:
                    return None
            else:
                assign[var] = needed

        # ---- pure literal elimination ----
        while True:
            pos = [0] * (n + 1)
            neg = [0] * (n + 1)
            for cl in clauses:
                # skip already satisfied clauses
                satisfied = False
                for lit in cl:
                    if literal_is_true(lit, assign):
                        satisfied = True
                        break
                if satisfied:
                    continue
                for lit in cl:
                    if assign[abs(lit)] == -1:
                        if lit > 0:
                            pos[abs(lit)] += 1
                        else:
                            neg[abs(lit)] += 1
            pure_var = 0
            pure_val = 0
            for v in range(1, n + 1):
                if assign[v] != -1:
                    continue
                if pos[v] > 0 and neg[v] == 0:
                    pure_var = v
                    pure_val = 1
                    break
                if neg[v] > 0 and pos[v] == 0:
                    pure_var = v
                    pure_val = 0
                    break
            if pure_var == 0:
                break
            assign[pure_var] = pure_val

        # ---- check if all clauses are satisfied ----
        all_sat = True
        for cl in clauses:
            if not any(literal_is_true(lit, assign) for lit in cl):
                all_sat = False
                break
        if all_sat:
            return assign

        # ---- choose a variable (first unassigned) ----
        for v in range(1, n + 1):
            if assign[v] == -1:
                var = v
                break
        for val in (1, 0):
            new_assign = assign[:]
            new_assign[var] = val
            res = dpll(new_assign)
            if res is not None:
                return res
        return None

    # ------------------------------------------------------------
    initial_assign = [-1] * (n + 1)
    result = dpll(initial_assign)

    if result is None:
        print("NO")
    else:
        # replace any still-unassigned variables by 0 (any value works)
        for i in range(1, n + 1):
            if result[i] == -1:
                result[i] = 0
        print("YES")
        print(' '.join(str(result[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
