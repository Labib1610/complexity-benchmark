We can model this as a 2-SAT problem.  
Each tumbler is a boolean variable.  
Each pin is a clause: at least one of its three literals must be true.  

A clause of three literals can be converted into 2-SAT form by introducing auxiliary variables, but here we can also solve it directly using implication graph with 3-literal clauses by adding helper variables.  

However, since n ≤ 90 and m ≤ 400, we can use a simpler approach:  
We can treat it as a SAT problem and use brute force with backtracking, but that may be too slow.  

Better: Convert each 3-literal clause into 2-SAT using the standard reduction:  
For clause (a ∨ b ∨ c), introduce a new variable x, and add clauses:  
(a ∨ b ∨ x) and (¬x ∨ c).  
But that still has 3-literal clauses.  

Actually, the standard reduction for 3-SAT to 2-SAT is not possible in general, but here we can use a different approach:  
We can use the fact that n ≤ 90, so we can use a SAT solver via brute force with pruning, or use a DPLL-like algorithm.  

Given constraints, we can implement a simple backtracking with unit propagation and pure literal elimination.  

Let’s implement a simple DPLL SAT solver.  

We’ll represent each clause as a list of integers (positive = variable true, negative = variable false).  

We’ll do recursive search with unit propagation.  

Here’s the code:  

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    clauses = []
    for _ in range(m):
        l1 = int(next(it))
        l2 = int(next(it))
        l3 = int(next(it))
        clauses.append([l1, l2, l3])
    
    # DPLL solver
    def dpll(assignment):
        # Propagate units
        changed = True
        while changed:
            changed = False
            for clause in clauses:
                # Check if clause is satisfied
                sat = False
                unassigned = []
                for lit in clause:
                    var = abs(lit)
                    val = assignment.get(var)
                    if val is not None:
                        if (lit > 0 and val == 1) or (lit < 0 and val == 0):
                            sat = True
                            break
                    else:
                        unassigned.append(lit)
                if sat:
                    continue
                if not unassigned:
                    return None
                if len(unassigned) == 1:
                    lit = unassigned[0]
                    var = abs(lit)
                    val = 1 if lit > 0 else 0
                    if var in assignment and assignment[var] != val:
                        return None
                    assignment[var] = val
                    changed = True
        
        # Check if all clauses satisfied
        for clause in clauses:
            sat = False
            for lit in clause:
                var = abs(lit)
                val = assignment.get(var)
                if val is not None:
                    if (lit > 0 and val == 1) or (lit < 0 and val == 0):
                        sat = True
                        break
            if not sat:
                return None
        
        # All satisfied
        return assignment
    
    # Try to find a solution
    assignment = {}
    result = dpll(assignment)
    if result is not None:
        # Fill remaining variables with 0
        for i in range(1, n+1):
            if i not in result:
                result[i] = 0
        print("YES")
        print(" ".join(str(result[i]) for i in range(1, n+1)))
        return
    
    # If unit propagation didn't solve, do backtracking
    def backtrack(assignment):
        # Propagate
        assignment = dict(assignment)
        res = dpll(assignment)
        if res is not None:
            return res
        # Find unassigned variable
        for i in range(1, n+1):
            if i not in assignment:
                # Try 0
                assign0 = dict(assignment)
                assign0[i] = 0
                res0 = backtrack(assign0)
                if res0 is not None:
                    return res0
                # Try 1
                assign1 = dict(assignment)
                assign1[i] = 1
                res1 = backtrack(assign1)
                if res1 is not None:
                    return res1
                return None
        return None
    
    result = backtrack({})
    if result is None:
        print("NO")
    else:
        for i in range(1, n+1):
            if i not in result:
                result[i] = 0
        print("YES")
        print(" ".join(str(result[i]) for i in range(1, n+1)))

if __name__ == "__main__":
    solve()
```
