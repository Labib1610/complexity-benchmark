We can model each contract as a logical condition:  
A contract is breached only if all three shots fail.  
So, to avoid breach, at least one of the three shots must be satisfied.

Let’s represent each truck’s assignment as a boolean variable:  
- `x_i = True` means truck i goes to upper corridor (1).  
- `x_i = False` means lower corridor (0).

A shot `+k` means `x_k` must be True.  
A shot `-k` means `x_k` must be False (i.e., `not x_k`).

For each contract `(l1, l2, l3)`, we need:

```
(shot1) OR (shot2) OR (shot3) = True
```

This is a 3-SAT clause. Since n ≤ 90 and m ≤ 400, we can solve it using a SAT solver approach.  
We can implement a simple backtracking with unit propagation, or use a DPLL-like algorithm.

Here’s the implementation:

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    clauses = []
    for _ in range(m):
        l1 = int(next(it))
        l2 = int(next(it))
        l3 = int(next(it))
        clause = []
        for lit in (l1, l2, l3):
            var = abs(lit) - 1
            is_true = lit > 0
            clause.append((var, is_true))
        clauses.append(clause)
    
    # DPLL SAT solver
    assignment = [None] * n
    
    def unit_propagate(assign):
        changed = True
        while changed:
            changed = False
            for clause in clauses:
                unassigned = []
                satisfied = False
                for var, val in clause:
                    if assign[var] is None:
                        unassigned.append((var, val))
                    elif assign[var] == val:
                        satisfied = True
                        break
                if satisfied:
                    continue
                if len(unassigned) == 0:
                    return False  # conflict
                if len(unassigned) == 1:
                    var, val = unassigned[0]
                    if assign[var] is None:
                        assign[var] = val
                        changed = True
                    elif assign[var] != val:
                        return False
        return True
    
    def backtrack(assign):
        # unit propagation
        if not unit_propagate(assign):
            return False
        # find unassigned variable
        for i in range(n):
            if assign[i] is None:
                # try True
                assign[i] = True
                if backtrack(assign):
                    return True
                assign[i] = False
                if backtrack(assign):
                    return True
                assign[i] = None
                return False
        # all assigned, check all clauses
        for clause in clauses:
            ok = False
            for var, val in clause:
                if assign[var] == val:
                    ok = True
                    break
            if not ok:
                return False
        return True
    
    if backtrack(assignment):
        print("YES")
        print(" ".join("1" if assignment[i] else "0" for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
