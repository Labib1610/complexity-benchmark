**Solution Explanation**

The problem is exactly the classic *3‑SAT* problem.

* variables – the `n` ingredients, each can be **Activated** (`1`) or **Dormant** (`0`);
* clauses – the `m` stabilizers, each contains three literals.
  A positive literal `i` means “ingredient `i` is Activated”, a negative literal `‑i`
  means “ingredient `i` is Dormant”.
* we have to find a truth assignment satisfying all clauses or decide that none exists.

`n ≤ 90 , m ≤ 400`, therefore a simple back‑tracking SAT solver with
*unit propagation* and a small heuristic is more than fast enough
(2 s limit, Python).

--------------------------------------------------------------------

#### 1.   Data structures
* `clauses` – list of clauses, each clause is a list of three integers (the literals).
* `assign` – list of length `n+1` (`assign[0]` unused).  
  `assign[i] = -1` – not assigned yet,  
  `assign[i] = 0` – Dormant,  
  `assign[i] = 1` – Activated.
* For fast access we also store for each variable the list of clause indices
  where it appears (both positively and negatively).  
  `occ[i] = [ (clause_id, sign) , … ]` where `sign = 1` for positive literal,
  `sign = 0` for negative literal.

--------------------------------------------------------------------

#### 2.   Helper functions
* `value(lit)` – returns the Boolean value of a literal under the current
  partial assignment (`True`, `False` or `None` if the variable is still unassigned).
* `is_clause_satisfied(cl)` – `True` if at least one literal of the clause is already `True`.
* `is_clause_conflict(cl)` – `True` if all three literals are already `False`
  (the clause can never become satisfied).

--------------------------------------------------------------------

#### 3.   Unit propagation
A clause becomes a *unit clause* when all its literals are `False`
except exactly one literal that is still unassigned.
That remaining literal **must** become `True`, otherwise the clause will stay unsatisfied.

Algorithm `propagate(stack)`  

```
while there is a clause that is unit:
        let (var, needed_sign) be the only unassigned literal
        assign var = needed_sign
        push var onto stack   # for later undo
        if this creates a conflict -> return False
return True
```

The stack records all variables assigned during the current recursion level,
so they can be undone when backtracking.

--------------------------------------------------------------------

#### 4.   Recursive DPLL
```
def dfs():
        # 1. unit propagation
        if not propagate([]):   return False

        # 2. check if all variables are assigned
        if all assigned:   return True

        # 3. choose a variable (simple heuristic: the first unassigned)
        v = choose_unassigned()

        # 4. try v = 1, then v = 0
        for val in (1,0):
                assign[v] = val
                saved = []          # variables assigned by propagation
                if propagate(saved):
                        if dfs():   return True
                # undo everything of this branch
                for u in saved: assign[u] = -1
                assign[v] = -1
        return False
```

The recursion depth is at most `n = 90`.  
Each propagation scans all clauses, i.e. `O(m)`.  
The total work is far below the limits.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` and a satisfying assignment
iff such an assignment exists.

---

##### Lemma 1 (Unit propagation soundness)  
When `propagate` assigns a variable, the assignment is forced:
every satisfying full assignment extending the current partial assignment
must give the same value to that variable.

**Proof.**  
A unit clause contains exactly one unassigned literal `ℓ` and the other two
are already `False`. To satisfy the clause, `ℓ` must be `True`.  
Therefore any full satisfying assignment must set the variable of `ℓ`
accordingly. ∎



##### Lemma 2 (Propagation completeness)  
If after propagation no clause is a unit clause, then the current partial
assignment does **not** force any further variable values.

**Proof.**  
Assume a variable `x` were forced. Then there would exist a clause that
becomes unsatisfied unless `x` takes a specific value, i.e. a unit clause.
Since none exists, no variable is forced. ∎



##### Lemma 3 (DFS invariant)  
At the entry of each recursive call `dfs` the current partial assignment
is *consistent*: no clause is already false.

**Proof.**  
The initial call starts with an empty assignment – trivially consistent.  
Inside `dfs` the first operation is `propagate`.  
`propagate` returns `False` immediately if it discovers a clause where all
three literals are `False`. In that case `dfs` returns `False` and never
continues deeper. Hence any recursive call that proceeds past propagation
has a consistent assignment. ∎



##### Lemma 4 (DFS completeness)  
If there exists a full satisfying assignment extending the current partial
assignment, then `dfs` returns `True`.

**Proof.**  
Consider such a satisfying assignment `A`.  
After propagation (Lemma&nbsp;1) the partial assignment is still a subset of `A`
(because forced values are exactly those of `A`).  
If all variables are already assigned, `dfs` succeeds.  
Otherwise pick the first unassigned variable `v`.  
`A` gives it either `1` or `0`. The algorithm tries both values.
When it tries the value equal to `A(v)`, the recursive call receives a
partial assignment still extendable to `A`. By induction on the number of
unassigned variables the recursive call eventually returns `True`. ∎



##### Lemma 5 (DFS soundness)  
If `dfs` returns `True`, the assignment stored in `assign` satisfies every clause.

**Proof.**  
`dfs` returns `True` only after a recursive call that reached the base case
“all variables assigned”. At that moment, by Lemma&nbsp;3 no clause is false.
Since every clause contains three literals, a clause that is not false must
contain at least one true literal, i.e. it is satisfied. ∎



##### Theorem (Overall correctness)  
The program outputs  

* `YES` and a binary vector `s` **iff** there exists an assignment of the
  `n` ingredients that satisfies all `m` stabilizers;  

* otherwise it outputs `NO`.

**Proof.**  

*If the program prints `YES`.*  
It printed the assignment stored after a successful `dfs`.  
By Lemma&nbsp;5 this assignment satisfies all clauses, therefore a feasible
formulation exists.

*If a feasible formulation exists.*  
The empty assignment can be extended to it, so by Lemma&nbsp;4 the initial
call of `dfs` returns `True`. Consequently the program prints `YES` and a
satisfying assignment.

*If no feasible formulation exists.*  
Assume the program would print `YES`. Then, as shown above, a satisfying
assignment would exist – contradiction. Hence it must print `NO`. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*`n ≤ 90`, `m ≤ 400`.*

*Propagation* scans all clauses → `O(m)` time, `O(1)` extra memory.  
Each recursive level performs at most two propagations, and the recursion
depth is at most `n`.  
In the worst case the algorithm explores the whole binary tree of assignments,
`O(2^n)`, but with unit propagation and the small limits the actual explored
search space is tiny (empirically far below one million nodes).

Memory consumption:  
`assign` – `O(n)`, `clauses` – `O(m)`, occurrence lists – `O(m)`.  
All well under the 256 MB limit.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    clauses = []
    occ = [[] for _ in range(n + 1)]          # (clause_id, sign) sign:1 positive,0 negative
    for cid in range(m):
        lits = [int(next(it)), int(next(it)), int(next(it))]
        clauses.append(lits)
        for lit in lits:
            var = abs(lit)
            sign = 1 if lit > 0 else 0
            occ[var].append((cid, sign))

    assign = [-1] * (n + 1)   # -1 unassigned, 0 Dormant, 1 Activated

    # ---------- helper ----------
    def lit_value(lit):
        v = assign[abs(lit)]
        if v == -1:
            return None
        return v == 1 if lit > 0 else v == 0

    # ---------- propagation ----------
    def propagate(stack):
        """perform unit propagation, record newly assigned vars in stack.
           return False if a conflict is found."""
        changed = True
        while changed:
            changed = False
            for cid, cl in enumerate(clauses):
                # evaluate clause
                true_found = False
                unassigned_lit = None
                for lit in cl:
                    val = lit_value(lit)
                    if val is True:
                        true_found = True
                        break
                    if val is None:
                        unassigned_lit = lit
                if true_found:
                    continue
                # no true literal
                if unassigned_lit is None:
                    # all false -> conflict
                    return False
                # check if unit: exactly one unassigned and others false
                # we already know there is at least one unassigned;
                # need to ensure the other two are false
                # count unassigned literals
                cnt_un = 0
                last_un = None
                for lit in cl:
                    val = lit_value(lit)
                    if val is None:
                        cnt_un += 1
                        last_un = lit
                if cnt_un == 1:
                    var = abs(last_un)
                    needed = 1 if last_un > 0 else 0
                    if assign[var] == -1:
                        assign[var] = needed
                        stack.append(var)
                        changed = True
                    elif assign[var] != needed:
                        return False
        return True

    # ---------- DPLL ----------
    def dfs() -> bool:
        # unit propagation
        unit_stack = []
        if not propagate(unit_stack):
            # undo assignments made by this propagation
            for v in unit_stack:
                assign[v] = -1
            return False

        # check if all assigned
        if all(a != -1 for a in assign[1:]):
            return True

        # choose variable (first unassigned)
        for v in range(1, n + 1):
            if assign[v] == -1:
                var = v
                break

        # try true then false
        for val in (1, 0):
            assign[var] = val
            local_stack = []
            if propagate(local_stack):
                if dfs():
                    return True
            # undo
            for u in local_stack:
                assign[u] = -1
            assign[var] = -1
        return False

    if dfs():
        out = ['YES']
        out.append(' '.join('1' if assign[i] == 1 else '0' for i in range(1, n + 1)))
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
