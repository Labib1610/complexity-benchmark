**Solution Explanation**

The problem is exactly a *3‑SAT* instance:

* variables – the `n` lenses, each can be `0` (defocusing) or `1` (focusing);
* clauses – the `m` diagnostic paths, each contains three literals  
  (`x`  means “lens `x` must be `1`”, `-x` means “lens `x` must be `0`”);
* a clause is satisfied if at least one of its literals is true.

We have to decide whether the formula is satisfiable and, if it is, output one
satisfying assignment.

`n ≤ 90 , m ≤ 400` – small enough for a classic DPLL SAT solver with
unit‑propagation and pure‑literal elimination.



--------------------------------------------------------------------

#### 1.   Data structures

* **clauses** – list of lists, each inner list contains three integers
  (`+i` or `-i`).
* **assign** – dictionary `var → value` (`value` is `0` or `1`).

During the search we repeatedly simplify the clause set:

* a clause becomes **true** as soon as one of its literals is satisfied;
* a clause becomes a **unit clause** when all but one literal are already
  falsified – the remaining literal must be true;
* a clause becomes **empty** → conflict.

To avoid copying the whole clause list at each recursion step we keep the
original list and work on a *stack* of changes:

```
trail = []          # (clause_index, old_clause) pairs
```

When we assign a variable we scan all clauses, remove falsified literals and
detect new unit clauses.  The old clause is stored on the trail, so we can
undo the changes when backtracking.



--------------------------------------------------------------------

#### 2.   Unit propagation

```
propagate(assign):
    queue ← all unit literals implied by current assign
    while queue not empty:
        lit ← queue.pop()
        var = |lit|
        val = 1 if lit>0 else 0
        if var already assigned:
            if assign[var] != val:  conflict → return False
            continue
        assign[var] = val
        for each clause c containing var:
            save old clause on trail
            delete falsified literals from c
            if c becomes empty: conflict → return False
            if c becomes unit: push its single literal to queue
    return True
```

The procedure returns `False` on conflict, otherwise `True` and the
`assign` dictionary is extended with all forced values.



--------------------------------------------------------------------

#### 3.   Pure literal elimination (optional)

A variable that appears only with one polarity in the remaining clauses can be
set to that polarity safely.  Implemented as a cheap scan before each
recursive call.



--------------------------------------------------------------------

#### 4.   Recursive DPLL

```
dpll():
    if all clauses satisfied → success
    choose an unassigned variable (first occurring)
    for value in (0,1):
        push current trail size
        assign[var] = value
        if propagate(assign):
            if dpll(): return True
        undo changes to trail size, restore assign
    return False
```

The recursion depth never exceeds `n ≤ 90`, well inside limits.



--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` and a satisfying assignment
iff such an assignment exists.

---

##### Lemma 1 (Soundness of propagation)

During `propagate` the algorithm only adds assignments that are forced by the
current partial assignment, i.e. every model of the original formula that
extends the current assignment also satisfies the new assignments.

**Proof.**  
A literal is added to the queue only when it is the sole remaining literal of
a clause whose other literals are already falsified by the current assignment.
For the clause to be satisfied, this literal must be true in any extension,
hence the assignment is forced. ∎



##### Lemma 2 (Conflict detection)

If `propagate` returns *conflict*, the current partial assignment cannot be
extended to a full model.

**Proof.**  
A conflict appears only when a clause becomes empty, i.e. all its literals are
false under the current assignment. No further assignment can change this,
therefore any extension also falsifies the clause. ∎



##### Lemma 3 (Preservation of satisfiability)

Assume the original formula is satisfiable and the algorithm reaches a recursive
call with partial assignment `A`.  
If `propagate(A)` succeeds, the extended assignment `A'` is still compatible
with at least one full model of the formula.

**Proof.**  
By Lemma&nbsp;1 every new literal added by propagation is forced, therefore any
model extending `A` must also satisfy them. Hence a model extending `A`
exists ⇔ a model extending `A'` exists. ∎



##### Lemma 4 (Completeness of the search)

If the formula is satisfiable, DPLL eventually reaches a recursive state where
all clauses are satisfied.

**Proof.**  
Consider a satisfying full assignment `M`.  
During the search the algorithm explores a binary decision tree where each
node fixes a variable to `0` or `1`.  
Whenever the algorithm chooses a variable `x`, the branch where `x` receives
the value given by `M` is never pruned:

* unit propagation cannot cause a conflict on that branch (Lemma&nbsp;2) because
  `M` satisfies every clause.
* pure‑literal elimination also chooses the polarity consistent with `M`.

Thus the path following the choices of `M` is explored completely and ends with
all clauses satisfied. ∎



##### Lemma 5 (If the algorithm outputs YES, the printed assignment satisfies
all clauses.)

**Proof.**  
The algorithm prints an assignment only after `dpll` returns success.
Success means every clause is either removed (already satisfied) or never
became empty.  All literals forced by propagation are satisfied by construction,
and the remaining variables are assigned arbitrarily at the leaf of the
recursion.  Therefore every clause contains at least one true literal. ∎



##### Theorem (Correctness)

The program prints  

*`NO`* iff the given instance is unsatisfiable,  

*`YES`* and a configuration otherwise.

**Proof.**  

*If the program prints YES*: by Lemma&nbsp;5 the printed configuration satisfies
all clauses, hence the instance is satisfiable.

*If the program prints NO*: this happens only when `dpll` exhausts the whole
search tree without success. By Lemma&nbsp;4, if a satisfying assignment existed,
the search would have found it. Therefore no satisfying assignment exists,
i.e. the instance is unsatisfiable. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

`n ≤ 90 , m ≤ 400`.

*Each propagation step scans at most all literals* → `O(m·3) = O(m)`.  
In the worst case the recursion explores the full binary tree of depth `n`,
so time `O(2^n · m)`.  
With the given limits this exponential worst case is acceptable; typical
instances are solved instantly.

Memory consumption:

* clauses – `O(m)` integers,
* assignment, trail – `O(n + m)`.

Both well below the 256 MB limit.

#### 7.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    clauses = []
    for _ in range(m):
        c = [int(next(it)), int(next(it)), int(next(it))]
        clauses.append(c)

    # For each variable keep list of clause indices where it appears
    var_pos = [[] for _ in range(n + 1)]
    var_neg = [[] for _ in range(n + 1)]
    for idx, cl in enumerate(clauses):
        for lit in cl:
            v = abs(lit)
            if lit > 0:
                var_pos[v].append(idx)
            else:
                var_neg[v].append(idx)

    assign = {}                     # var -> 0/1
    trail = []                      # (clause_index, old_clause_copy)

    # ---------- helper functions ----------
    def clause_is_satisfied(cl):
        for lit in cl:
            v = abs(lit)
            if v in assign:
                val = assign[v]
                if (lit > 0 and val == 1) or (lit < 0 and val == 0):
                    return True
        return False

    def unit_literal(cl):
        # return the only literal that is not yet falsified, or None
        unk = None
        for lit in cl:
            v = abs(lit)
            if v not in assign:
                if unk is not None:
                    return None
                unk = lit
            else:
                val = assign[v]
                if (lit > 0 and val == 1) or (lit < 0 and val == 0):
                    return None  # clause already satisfied
        return unk

    def propagate() -> bool:
        """unit propagation, returns False on conflict."""
        queue = []
        # initial unit clauses
        for idx, cl in enumerate(clauses):
            if clause_is_satisfied(cl):
                continue
            u = unit_literal(cl)
            if u is not None:
                queue.append(u)

        while queue:
            lit = queue.pop()
            var = abs(lit)
            val = 1 if lit > 0 else 0
            if var in assign:
                if assign[var] != val:
                    return False
                continue
            assign[var] = val
            # update clauses containing var
            affected = var_pos[var] if val == 1 else var_neg[var]
            for ci in affected:
                old = clauses[ci]
                if old is None:   # already satisfied
                    continue
                # save copy
                trail.append((ci, old))
                # remove falsified literals
                new = [l for l in old if not (abs(l) == var and ((l > 0) != (val == 1)))]
                # if clause becomes satisfied, mark as None
                sat = False
                for l in new:
                    v = abs(l)
                    if v in assign:
                        vv = assign[v]
                        if (l > 0 and vv == 1) or (l < 0 and vv == 0):
                            sat = True
                            break
                if sat:
                    clauses[ci] = None
                    continue
                if not new:          # empty clause -> conflict
                    return False
                clauses[ci] = new
                if len(new) == 1:
                    queue.append(new[0])
        return True

    def undo(trail_sz):
        while len(trail) > trail_sz:
            ci, old = trail.pop()
            clauses[ci] = old
        # remove assignments that were added after the saved point
        # we cannot know exactly which vars, so recompute from clauses:
        # simpler: keep a stack of assigned vars
        # We'll maintain a separate assign_stack
        while assign_stack and len(assign_stack) > assign_sz:
            v = assign_stack.pop()
            del assign[v]

    # To be able to undo assignments we keep a stack
    assign_stack = []
    assign_sz = 0

    # ---------- DPLL ----------
    def dpll() -> bool:
        # check if all clauses satisfied
        all_sat = True
        for cl in clauses:
            if cl is None:
                continue
            all_sat = False
            break
        if all_sat:
            return True

        # pure literal elimination (optional, cheap)
        while True:
            pos = [0] * (n + 1)
            neg = [0] * (n + 1)
            for cl in clauses:
                if cl is None:
                    continue
                for lit in cl:
                    v = abs(lit)
                    if v in assign:
                        continue
                    if lit > 0:
                        pos[v] = 1
                    else:
                        neg[v] = 1
            pure_found = False
            for v in range(1, n + 1):
                if v in assign:
                    continue
                if pos[v] and not neg[v]:
                    # set to 1
                    assign[v] = 1
                    assign_stack.append(v)
                    if not propagate():
                        return False
                    pure_found = True
                    break
                if neg[v] and not pos[v]:
                    assign[v] = 0
                    assign_stack.append(v)
                    if not propagate():
                        return False
                    pure_found = True
                    break
            if not pure_found:
                break

        # choose variable
        for v in range(1, n + 1):
            if v not in assign:
                var = v
                break
        else:
            return True  # all assigned

        for val in (0, 1):
            saved_trail = len(trail)
            saved_assign_sz = len(assign_stack)
            assign[var] = val
            assign_stack.append(var)
            if propagate():
                if dpll():
                    return True
            # backtrack
            undo(saved_trail)
            while len(assign_stack) > saved_assign_sz:
                vv = assign_stack.pop()
                del assign[vv]
        return False

    # initial propagation (none)
    if dpll():
        out = ['YES']
        res = [str(assign.get(i, 0)) for i in range(1, n + 1)]
        out.append(' '.join(res))
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
