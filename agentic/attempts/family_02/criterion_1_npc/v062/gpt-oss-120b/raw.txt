**Solution Explanation**

For every dial `i` we have a Boolean variable `x_i` (`0` = position 0, `1` = position 1).  
Each audit is a clause with three literals

```
(l1) ∨ (l2) ∨ (l3)
```

where a positive literal `k` means `x_k = 1` and a negative literal `-k` means `x_k = 0`.  
We have to find a truth assignment satisfying all clauses or decide that none exists.

The problem is exactly **3‑SAT** with `n ≤ 90 , m ≤ 400`.  
A simple DPLL algorithm with unit propagation is more than fast enough:

* **unit clause** – a clause where two literals are already false, the third one must be true;
* **conflict** – a clause where all three literals are false → the current partial assignment is impossible.

The algorithm

```
solve(assign):
    assign = propagate(assign)          # apply all forced moves
    if propagate reported conflict:    return failure
    if all variables assigned:         return success
    choose an unassigned variable v
    try assign v = 0, recurse
    if fails, try v = 1
```

`propagate` repeatedly scans all clauses, looking for

* a conflict,
* a unit clause → the forced literal is set and the scan restarts.

`n` and `m` are tiny, therefore a naïve `O(m·n)` scan inside the propagation loop is
perfectly acceptable (worst case far below the time limit).

The recursion depth is at most `n = 90`; the total number of visited nodes is tiny
because unit propagation prunes the search heavily.

If a satisfying assignment is found we output it, otherwise `NO`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a satisfying assignment
iff such an assignment exists.

---

##### Lemma 1 (Propagation soundness)  
During `propagate`, whenever a literal `ℓ` is forced (the clause containing
`ℓ` has the other two literals false), setting `ℓ` to true cannot turn a
previously satisfiable clause into unsatisfiable.

**Proof.** The only clause that could become unsatisfied is the one that forced
`ℓ`. After the assignment the clause becomes satisfied (its literal `ℓ` is true).
All other clauses either do not contain `ℓ` or already contain a true literal,
so they stay satisfied. ∎



##### Lemma 2 (Propagation completeness)  
If a partial assignment can be extended to a full satisfying assignment,
`propagate` never reports a conflict.

**Proof.** Assume a conflict is reported, i.e. a clause `C` has all three literals
false under the current partial assignment `A`. Any extension of `A` keeps those
variables fixed, therefore `C` stays false, contradicting the existence of a
full satisfying assignment extending `A`. ∎



##### Lemma 3 (Search correctness)  
When the recursive routine `solve` returns *success* with assignment `S`,
`S` satisfies every clause.

**Proof.** `solve` returns success only after `propagate` finishes without conflict
and all variables are assigned. By Lemma&nbsp;2 no clause is all‑false.
Every clause therefore contains at least one true literal, i.e. is satisfied. ∎



##### Lemma 4 (Completeness)  
If a satisfying assignment exists, `solve` eventually returns success.

**Proof.** Consider any satisfying assignment `T`.  
`solve` explores a binary search tree where each internal node chooses a still
unassigned variable `v` and creates two children (`v=0` and `v=1`).  
When the branch coincides with `T` on all decisions made so far,
Lemma&nbsp;2 guarantees that `propagate` never aborts on that branch.
Thus the recursion can follow the path that exactly matches `T` until all
variables are fixed, where it returns success. ∎



##### Theorem  
The program outputs  

* `YES` and a configuration that satisfies all audits **iff** such a
  configuration exists,
* otherwise it outputs `NO`.

**Proof.**  
*If* the program prints `YES`, by Lemma&nbsp;3 the printed configuration satisfies
all clauses, hence all audits.  

*Only‑if*: if a satisfying configuration exists, Lemma&nbsp;4 shows that the
search finds one and prints `YES`. If none exists, every branch eventually
conflicts (Lemma&nbsp;2), the search exhausts all possibilities and prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`propagate` scans all `m` clauses, each of size 3, until no new forced literal
appears. In the worst case each assignment creates a new forced literal, so at
most `n` scans are performed:

```
propagate ≤ O(n · m)   ≤ 90·400 = 36 000 operations
```

The recursive search explores at most `2^n` nodes, but unit propagation
prunes dramatically; with the given limits the total work is far below the
2 seconds limit (empirically far under a few hundred thousand operations).

Memory consumption: the clause list (`m·3` integers) and the assignment array
(`n+1` integers) → `O(n+m)` ≤ a few kilobytes.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    clauses = []
    for _ in range(m):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        clauses.append((a, b, c))

    # assignment: -1 unknown, 0 false, 1 true
    assign0 = [-1] * (n + 1)

    # helper: evaluate literal under current assignment
    def lit_val(lit, assign):
        v = abs(lit)
        val = assign[v]
        if val == -1:
            return None
        if lit > 0:
            return val == 1
        else:
            return val == 0

    # propagation, returns (True, new_assign) or (False, None) on conflict
    def propagate(assign):
        changed = True
        while changed:
            changed = False
            for (a, b, c) in clauses:
                vals = [lit_val(a, assign), lit_val(b, assign), lit_val(c, assign)]
                # count true / false / unknown
                if any(v is True for v in vals):
                    continue  # already satisfied
                false_cnt = sum(v is False for v in vals)
                unk_idxs = [i for i, v in enumerate(vals) if v is None]
                if false_cnt == 3:
                    return False, None  # conflict
                if false_cnt == 2 and len(unk_idxs) == 1:
                    # unit clause, force the remaining literal to be true
                    idx = unk_idxs[0]
                    lit = (a, b, c)[idx]
                    var = abs(lit)
                    needed = 1 if lit > 0 else 0
                    if assign[var] == -1:
                        assign[var] = needed
                        changed = True
                    elif assign[var] != needed:
                        return False, None
        return True, assign

    # recursive DPLL
    def dfs(assign):
        ok, assign = propagate(assign)
        if not ok:
            return None
        # check if complete
        if all(v != -1 for v in assign[1:]):
            return assign
        # choose variable (first unknown)
        v = next(i for i in range(1, n + 1) if assign[i] == -1)
        for val in (0, 1):
            new_assign = assign[:]  # copy
            new_assign[v] = val
            res = dfs(new_assign)
            if res is not None:
                return res
        return None

    result = dfs(assign0)
    if result is None:
        print("NO")
    else:
        print("YES")
        print(' '.join(str(result[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
