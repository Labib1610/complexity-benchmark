We can model each audit as a clause: at least one literal must be true.  
This is exactly a **3‑SAT** problem, but with a special property:  
each clause has exactly 3 literals, and **all 7 assignments except one** satisfy it.  
That means the only falsifying assignment is when all three literals are false.

We can solve this using **implication graph + 2‑SAT style** reasoning:  
If two literals in a clause are false, the third must be true.  
That gives logical implications:  
- (¬a ∧ ¬b) → c  
which is equivalent to:  
¬a → (b ∨ c)  etc.

But since it’s a **3‑SAT with only one false case**, it is actually a **Horn‑like** structure.  
Actually, we can transform each clause into implications and then use **2‑SAT** by considering all pairs.

We use standard trick:  
A clause `(a ∨ b ∨ c)` can be converted into 2‑SAT clauses:
- `(¬a → (b ∨ c))` — not 2‑SAT directly.  
Instead, introduce auxiliary variables? That’s heavy.

Better:  
Because n ≤ 90, m ≤ 400, we can use **brute force backtracking with pruning**.  
Each variable is 0/1, so 2^90 is too big, but we can use **DPLL** with unit propagation.

The clause structure:  
A clause is false only if all three literals are false. So we can search assignment iteratively and prune when a clause has all literals false.  
We can also propagate: if in a clause two literals are already false, the third must be true.

This leads to a deterministic propagation algorithm:  
- Repeatedly find clauses with two false literals, set the third to true.  
If at any point a clause has all three false, contradiction.

We can do **backtracking** with this propagation. Complexity should be manageable because propagation resolves most.

Implementation plan:

- Represent each literal as positive or negative variable.
- For each clause, store the three literals.
- Use an array `val[1..n]` with `-1` = unknown, `0`, `1`.
- Propagation loop:
  - For each clause, count how many are known false, how many true.
  - If two false → set third true.
  - If all three false → contradiction.
  - If one true → clause satisfied, we can ignore it.
- In backtracking, pick an unassigned variable and try both values.

Because n ≤ 90 and m ≤ 400, with propagation, many assignments get forced.

Let’s implement that.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    clauses = []
    for _ in range(m):
        a, b, c = map(int, input().split())
        clauses.append((a, b, c))
    
    val = [-1] * (n + 1)
    
    # returns True if assignment consistent, False otherwise
    def propagate():
        changed = True
        while changed:
            changed = False
            for (a, b, c) in clauses:
                # count true and false literals
                true_lits = []
                false_lits = []
                unknown_lits = []
                for lit in (a, b, c):
                    var = abs(lit)
                    need = 1 if lit > 0 else 0
                    if val[var] == -1:
                        unknown_lits.append(lit)
                    elif val[var] == need:
                        true_lits.append(lit)
                    else:
                        false_lits.append(lit)
                if true_lits:
                    continue  # already satisfied
                # none true, so if 2 false -> set third true
                if len(false_lits) == 2 and len(unknown_lits) == 1:
                    lit = unknown_lits[0]
                    var = abs(lit)
                    need = 1 if lit > 0 else 0
                    if val[var] == -1:
                        val[var] = need
                        changed = True
                    elif val[var] != need:
                        return False
                elif len(false_lits) == 3:
                    return False
        return True
    
    def backtrack():
        if not propagate():
            return False
        # find unassigned var
        for i in range(1, n+1):
            if val[i] == -1:
                # try 0 and 1
                for v in (0, 1):
                    val[i] = v
                    if backtrack():
                        return True
                    val[i] = -1
                return False
        # no unassigned variables, check all satisfied
        for (a,b,c) in clauses:
            ok = False
            for lit in (a,b,c):
                var = abs(lit)
                need = 1 if lit > 0 else 0
                if val[var] == need:
                    ok = True
                    break
            if not ok:
                return False
        return True
    
    if backtrack():
        print("YES")
        print(" ".join(str(val[i]) for i in range(1, n+1)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
