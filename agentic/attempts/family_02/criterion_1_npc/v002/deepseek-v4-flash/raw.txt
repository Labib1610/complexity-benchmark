We can model this as a 2-SAT problem. Each ingredient is a boolean variable.  
A demand like `(a, b, c)` means at least one of the three literals must be true.  
That is equivalent to the clause:  
`(a OR b OR c)`.

We can convert a 3-literal clause into 2-SAT form using auxiliary variables, but here n ≤ 90 and m ≤ 400, so we can also solve directly with brute force over 2^n? No, 2^90 is too large.

Instead, we can use a standard 3-SAT to 2-SAT reduction, or use a SAT solver approach.  
But since n is small (≤ 90), we can use a backtracking / DPLL-like search with pruning, or use a 2-SAT transformation.

Actually, a simpler approach:  
We can use a **watchlist-based DPLL** SAT solver.  
Given n ≤ 90 and m ≤ 400, this is feasible.

Let’s implement a simple DPLL SAT solver.

We'll represent each literal as an integer:  
- positive x means variable x is true  
- negative -x means variable x is false  

We'll store clauses as lists of literals.

We'll implement:
- Unit propagation
- Pure literal elimination (optional)
- Choose variable with most occurrences in unresolved clauses
- Recursive backtracking

We'll output a satisfying assignment if found.

Let's code it.

def solve():

    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))

        l1 = int(next(it))
        l2 = int(next(it))
        l3 = int(next(it))
        clauses.append([l1, l2, l3])

    # Literal representation: positive int for variable, negative for negation
    # variable index from 1 to n

    assignment = [0] * (n + 1)
    
    # For each clause, we keep a list of literals (not yet satisfied)
    # We'll use a watchlist approach for efficiency, but simple is fine for n<=90, m<=400
    
    # We'll implement recursive DPLL with unit propagation
    
    def propagate(assign):

    # We'll implement a simple recursive function:
    # dpll(assign) returns (satisfiable, final_assign)
    
    def dpll(assign):
        # Unit propagation
        changed = True
        while changed:
            changed = False
            for clause in clauses:
                # Check if clause is already satisfied
                sat = False
                unassigned = []
                for lit in clause:
                    var = abs(lit)
                    val = assign[var]
                    if val == 0:
                        unassigned.append(lit)
                    elif (lit > 0 and val == 1) or (lit < 0 and val == -1):
                        sat = True
                        break
                if sat:
                    continue
                if len(unassigned) == 0:
                    return False, None
                if len(unassigned) == 1:
                    # unit clause
                    lit = unassigned[0]
                    var = abs(lit)
                    val = 1 if lit > 0 else -1
                    if assign[var] != 0 and assign[var] != val:
                        return False, None
                    if assign[var] == 0:
                        assign[var] = val
                        changed = True
        
        # Check if all clauses satisfied
        for clause in clauses:
            sat = False
            for lit in clause:
                var = abs(lit)
                val = assign[var]
                if val != 0 and ((lit > 0 and val == 1) or (lit < 0 and val == -1)):
                    sat = True
                    break
            if not sat:
                break
        else:
            return True, assign
        
        # Choose unassigned variable
        for var in range(1, n+1):
            if assign[var] == 0:
                # Try true
                assign[var] = 1
                ok, res = dpll(assign)
                if ok:
                    return True, res
                # Try false
                assign[var] = -1
                ok, res = dpll(assign)
                if ok:
                    return True, res
                # backtrack
                assign[var] = 0
                return False, None
        return False, None
    
    ok, final_assign = dpll(assignment)
    if not ok:

        for i in range(1, n+1):
            out.append('1' if final_assign[i] == 1 else '0')
        print(' '.join(out))
