We can model each valve as a Boolean variable (open/closed) and each constraint as a clause that is a disjunction of literals.  
This is exactly the **2-SAT** problem if each clause has at most 2 literals, but here each clause can have 3 literals — so it’s **3-SAT**, which is NP-complete in general.

However, the problem constraints are small:  
- Number of valves ≤ 90  
- Number of constraints ≤ 400  

We can solve it using **backtracking with pruning** or **DPLL** (a SAT solver approach).  
Since each clause has exactly 3 literals, we can implement a simple recursive search.

Here’s the plan:
1. Read input.
2. Represent each constraint as a list of literals (positive = valve open, negative = valve closed).
3. Use recursive search:
   - Pick an unassigned variable.
   - Try assigning it `True` (open) and `False` (closed).
   - At each step, check if any clause is already falsified (all literals false) → backtrack.
   - If all variables assigned and all clauses satisfied → return solution.
4. If no assignment works, print `NO`.

We can also add unit propagation for speed, but with n ≤ 90 and m ≤ 400, simple backtracking should be fine.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    clauses = []
    for _ in range(m):
        l1 = int(next(it))
        l2 = int(next(it))
        l3 = int(next(it))
        clauses.append([l1, l2, l3])
    
    assignment = [None] * (n + 1)  # 1-indexed, None = unassigned
    
    def check_clause(clause):
        # Check if clause is satisfied, unsatisfied, or undetermined
        satisfied = False
        all_false = True
        for lit in clause:
            var = abs(lit)
            val = assignment[var]
            if val is None:
                all_false = False
            elif (lit > 0 and val == 1) or (lit < 0 and val == 0):
                satisfied = True
                break
        if satisfied:
            return True
        if all_false:
            return False
        return None  # undetermined
    
    def backtrack():
        # Find first unassigned variable
        try:
            var = next(i for i in range(1, n+1) if assignment[i] is None)
        except StopIteration:
            # All assigned, check all clauses
            for clause in clauses:
                if not check_clause(clause):
                    return False
            return True
        
        # Try assigning True (open)
        assignment[var] = 1
        ok = True
        for clause in clauses:
            res = check_clause(clause)
            if res is False:
                ok = False
                break
        if ok and backtrack():
            return True
        assignment[var] = None
        
        # Try assigning False (closed)
        assignment[var] = 0
        ok = True
        for clause in clauses:
            res = check_clause(clause)
            if res is False:
                ok = False
                break
        if ok and backtrack():
            return True
        assignment[var] = None
        return False
    
    if backtrack():
        print("YES")
        print(" ".join(str(assignment[i]) for i in range(1, n+1)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
