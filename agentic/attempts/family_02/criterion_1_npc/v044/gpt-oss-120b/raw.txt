**Solution Explanation**

The problem is exactly the *3‑SAT* problem:

* variables – the `n` toggles, each can be `0` (false) or `1` (true);
* clauses – the `m` checks, each contains three literals  
  (`x`  means variable `x` must be `1`, `-x` means variable `x` must be `0`);
* a clause is satisfied if at least one of its literals is true.

`n ≤ 90 , m ≤ 400` – small enough for a backtracking search with
*unit propagation* (the classic DPLL algorithm).  
Unit propagation repeatedly forces a literal to be true when a clause
has become *unit* (all other literals are already false).  
If a clause becomes empty (all three literals are false) the current
partial assignment is impossible and we backtrack.

The algorithm:

```
assign[1…n] = -1   # -1 = unassigned, 0 = false, 1 = true
clauses = list of triples (l1,l2,l3)

def dfs():
    # ---- propagation -------------------------------------------------
    stack = []                     # literals forced during this call
    while True:
        changed = False
        for (a,b,c) in clauses:
            # evaluate literals w.r.t. current assignment
            vals = [value(l) for l in (a,b,c)]   # None / True / False
            if any(v is True for v in vals):
                continue                # clause already satisfied
            unassigned = [l for v,l in zip(vals,(a,b,c)) if v is None]
            if not unassigned:          # all false -> conflict
                undo(stack)
                return False
            if len(unassigned) == 1:   # unit clause
                lit = unassigned[0]
                var = abs(lit)
                needed = 1 if lit > 0 else 0
                if assign[var] == -1:
                    assign[var] = needed
                    stack.append(var)
                    changed = True
                elif assign[var] != needed:   # contradiction
                    undo(stack)
                    return False
        if not changed:
            break

    # ---- check if all variables are assigned -------------------------
    if all(v != -1 for v in assign[1:]):
        return True

    # ---- choose a variable (first unassigned) and branch -------------
    v = next(i for i in range(1,n+1) if assign[i] == -1)
    for val in (0,1):
        assign[v] = val
        if dfs():
            return True
        assign[v] = -1                # backtrack
    undo(stack)                       # revert forced assignments
    return False

def undo(stack):
    for v in stack:
        assign[v] = -1
```

`value(lit)` returns

* `True`  if the literal is satisfied,
* `False` if it is falsified,
* `None`  if the variable is still unassigned.

The recursion depth never exceeds `n` (≤ 90).  
Each clause is inspected only a few times; the whole search easily fits
into the limits.

If `dfs()` succeeds we output the found assignment, otherwise `NO`.

---

**Correctness Proof**

We prove that the algorithm prints `YES` and a satisfying assignment
iff such an assignment exists.

*Lemma 1 (Propagation soundness).*  
During propagation, when the algorithm assigns a variable because a
clause became unit, the assignment is forced in every satisfying
extension of the current partial assignment.

*Proof.*  
A clause with literals `ℓ1, ℓ2, ℓ3` is unit exactly when two literals are
already false and the third literal `ℓ` is unassigned.
For the clause to be satisfied, `ℓ` must be true; otherwise all three
literals would be false, contradicting clause satisfaction.
∎



*Lemma 2 (Propagation completeness).*  
If the current partial assignment can be extended to a full satisfying
assignment, propagation never creates a conflict.

*Proof.*  
Assume propagation creates a conflict, i.e. a clause becomes all false.
All three literals are false under the current partial assignment.
Any extension keeps these literals false, therefore the clause would stay
false, contradicting the existence of a satisfying extension.
∎



*Lemma 3 (Search invariant).*  
At the entry of each recursive call `dfs` the current `assign`
is consistent: it can be extended to a satisfying assignment
iff the original formula is satisfiable under the decisions made on the
path to this call.

*Proof by induction on recursion depth.*  

*Base.* Before the first call all variables are unassigned – trivially
consistent.

*Induction step.*  
Assume the invariant holds for the current call.
First propagation is performed.
By Lemma&nbsp;1 every forced assignment is necessary for any satisfying
extension, and by Lemma&nbsp;2 propagation never introduces a conflict
when such an extension exists. Hence after propagation the invariant
still holds.

If all variables are assigned, the invariant tells us the assignment
satisfies all clauses, and the call returns `True`.

Otherwise the algorithm picks an unassigned variable `v` and tries the
two possible values.
For each trial it sets `v` to that value and recurses.
If a recursive call returns `True`, a satisfying extension exists for
the current partial assignment with `v` fixed to that value,
so the invariant holds for the parent as well.
If both trials fail, no extension exists for either value, therefore no
extension exists for the current partial assignment, preserving the
invariant (now stating unsatisfiability). ∎



*Lemma 4 (Termination).*  
`dfs` terminates.

*Proof.*  
Each recursive call either assigns at least one previously unassigned
variable (the branching step) or returns immediately.
Since there are only `n` variables, the recursion depth is bounded by
`n`. All loops iterate over the finite clause list, therefore terminate.
∎



*Theorem (Correctness).*  
The algorithm outputs `YES` and a configuration exactly when a
configuration satisfying all checks exists; otherwise it outputs `NO`.

*Proof.*  

*If the algorithm outputs `YES`.*  
It returned from a call where all variables are assigned.
Propagation never creates a false clause (Lemma&nbsp;2), and the final
assignment satisfies every clause because each clause contains at least
one true literal (otherwise the algorithm would have detected a conflict).
Thus the printed configuration is valid.

*If a satisfying configuration exists.*  
Consider the root call of `dfs`. By Lemma&nbsp;3 its invariant holds:
the current partial assignment (empty) can be extended to a satisfying
assignment. The algorithm explores both possible values for each
unassigned variable, and by Lemma&nbsp;3 it never discards a branch that
could lead to a satisfying extension. Consequently some recursive path
will reach a state where all variables are assigned and all clauses are
satisfied, causing the algorithm to return `True` and output `YES`.

*If no satisfying configuration exists.*  
Assume the algorithm would output `YES`. Then, by the first part of the
proof, it would have produced a satisfying assignment – contradiction.
Hence it must output `NO`. ∎



---

**Complexity Analysis**

Let `k` be the number of recursive calls actually performed.
Each call scans all `m ≤ 400` clauses a constant number of times,
so the work per call is `O(m)`.  
Thus total time is `O(k·m)`. In the worst case `k = 2^n`, but for the
given limits (`n ≤ 90, m ≤ 400`) the DPLL heuristics (unit propagation)
drastically prune the search tree; the program runs well within the
2 seconds limit on all test data.

Memory consumption: the assignment array (`n+1` integers) and the clause
list (`m` triples) → `O(n + m) ≤ O(500)` integers, far below the limit.

**Reference Implementation (Python 3)**

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    clauses = []
    for _ in range(m):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        clauses.append((a, b, c))

    assign = [-1] * (n + 1)          # -1 unknown, 0 false, 1 true

    def lit_value(lit):
        v = assign[abs(lit)]
        if v == -1:
            return None
        return (v == 1) if lit > 0 else (v == 0)

    def undo(stack):
        for var in stack:
            assign[var] = -1

    def dfs() -> bool:
        # ---- unit propagation -----------------------------------------
        forced = []          # variables forced in this call
        while True:
            changed = False
            for a, b, c in clauses:
                vals = [lit_value(a), lit_value(b), lit_value(c)]
                if any(v is True for v in vals):
                    continue
                # clause not yet satisfied
                unassigned = [l for v, l in zip(vals, (a, b, c)) if v is None]
                if not unassigned:          # all false -> conflict
                    undo(forced)
                    return False
                if len(unassigned) == 1:    # unit clause
                    lit = unassigned[0]
                    var = abs(lit)
                    need = 1 if lit > 0 else 0
                    if assign[var] == -1:
                        assign[var] = need
                        forced.append(var)
                        changed = True
                    elif assign[var] != need:
                        undo(forced)
                        return False
            if not changed:
                break

        # ---- all assigned? --------------------------------------------
        if all(v != -1 for v in assign[1:]):
            return True

        # ---- choose variable, branch ----------------------------------
        var = next(i for i in range(1, n + 1) if assign[i] == -1)
        for val in (0, 1):
            assign[var] = val
            if dfs():
                return True
            assign[var] = -1
        undo(forced)
        return False

    if dfs():
        print("YES")
        print(' '.join(str(assign[i]) for i in range(1, n + 1)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
