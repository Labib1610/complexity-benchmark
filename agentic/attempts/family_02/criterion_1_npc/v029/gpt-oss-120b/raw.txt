**Solution Explanation**

For every dial we have a Boolean variable  

```
xi = 0   (dial i is in position 0)
xi = 1   (dial i is in position 1)
```

Each inspection check is a clause with three literals, e.g.

```
  5  -2  7   →   (x5 = 1) ∨ (x2 = 0) ∨ (x7 = 1)
```

The whole task is the classic **3‑SAT** problem:

*find an assignment of the `n` variables that makes all `m` clauses true*.

`n ≤ 90 ,  m ≤ 400` – small enough for a back‑tracking search equipped with
the usual SAT heuristics (unit propagation, pure‑literal elimination,
variable ordering).  
The algorithm is a depth‑first DPLL solver.

--------------------------------------------------------------------

#### 1.   Data structures

* `clauses` – list of clauses, each clause is a list of three signed integers.
* `assign` – list `assign[1 … n]`  
  `-1` … not assigned yet, `0` … false, `1` … true.

All functions work on a *copy* of `assign`; copying a list of length ≤ 90 is cheap.

--------------------------------------------------------------------

#### 2.   Clause status helpers  

```text
literal  l  is true  ⇔  (assign[|l|] == 1 and l > 0)  or  (assign[|l|] == 0 and l < 0)
literal  l  is false ⇔  assign[|l|] != -1 and not true
```

For a clause we need three facts

* **satisfied** – at least one literal is true
* **conflict**   – all three literals are false
* **unit**       – exactly one literal is still unassigned, the other two are false

The functions below scan a clause and return the appropriate information.

--------------------------------------------------------------------

#### 3.   Propagation

```
unit_propagate(assign):
        repeatedly
                find a unit clause
                assign the forced literal
                if a clause becomes conflicting → return True (conflict)
        return False (no conflict)
```

After unit propagation we also apply **pure‑literal elimination**:

```
pure_literal_assign(assign):
        while a pure literal exists
                assign it (only positive → 1, only negative → 0)
                run unit_propagate again (new units may appear)
                if conflict → return True
        return False
```

Both steps are deterministic and never need backtracking.

--------------------------------------------------------------------

#### 4.   Recursive search (DPLL)

```
solve(assign):
        if unit_propagate(assign) → conflict → backtrack
        if pure_literal_assign(assign) → conflict → backtrack
        if every clause is satisfied → success, return assign

        choose an unassigned variable (most frequent in still unsatisfied clauses)
        try value 1, then 0:
                copy current assignment, set the variable, recurse
                if recursion succeeds → propagate success upwards
        return None   (both branches failed)
```

The variable ordering heuristic (most occurrences) dramatically reduces the
search tree for the given limits.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the program prints **YES** and a satisfying configuration
iff such a configuration exists; otherwise it prints **NO**.

---

##### Lemma 1  
`unit_propagate` never assigns a variable to a value that contradicts any
already satisfied clause.

**Proof.**  
A unit clause is, by definition, a clause where all literals are false except
one unassigned literal. The only way to satisfy the clause is to set that
literal to true. Assigning the corresponding variable to the required value
makes the clause true and cannot falsify any other clause because the other
two literals of the same clause are already false, and the assignment does not
touch any other literal. ∎



##### Lemma 2  
If `unit_propagate` returns *conflict*, the current partial assignment cannot be
extended to a full satisfying assignment.

**Proof.**  
A conflict is reported only when a clause is found with **all three literals
false**. No future assignment can change the value of already assigned
variables, therefore the clause will stay false forever. Hence no total
assignment extending the current one can satisfy all clauses. ∎



##### Lemma 3  
`pure_literal_assign` never creates a conflict and preserves satisfiability:
if the current partial assignment can be extended to a full solution, after
assigning a pure literal the extended assignment still exists.

**Proof.**  
A pure literal appears only with one polarity in every *still unsatisfied*
clause. Setting the variable to the polarity that makes the literal true
satisfies all those clauses and does not affect any other clause (the
variable does not occur there with the opposite polarity). Therefore any full
solution can be modified to use this forced value without breaking any clause.
∎



##### Lemma 4  
When `solve` reaches the line “every clause is satisfied”, the current
assignment is a total satisfying assignment.

**Proof.**  
All clauses are satisfied, i.e. each contains a true literal. Unassigned
variables, if any, do not appear in any clause (otherwise the clause would be
unsatisfied). Assigning arbitrary values to them keeps every clause true.
Thus the assignment can be completed to a full satisfying configuration. ∎



##### Lemma 5  
If `solve` returns a concrete assignment, that assignment satisfies all
clauses.

**Proof.**  
`solve` returns only after one of the two following situations:

1. The *all‑clauses‑satisfied* test succeeded – by Lemma&nbsp;4 the assignment is
   satisfying.
2. A recursive call returned a satisfying assignment – by induction hypothesis
   the returned assignment satisfies all clauses, and the current call never
   changed any already assigned variable (it only added a new assignment before
   the recursive call). Hence the returned assignment is still satisfying. ∎



##### Lemma 6  
If a satisfying assignment exists, `solve` eventually returns one.

**Proof.**  
Consider any satisfying total assignment `A`.  
During the execution of `solve` we maintain a *partial* assignment `P`
that is always a subset of `A`:

* Unit propagation (Lemma&nbsp;1) forces exactly the values that `A` already has,
  otherwise a conflict would appear contradicting Lemma&nbsp;2.
* Pure‑literal elimination (Lemma&nbsp;3) also forces values that `A` can be
  changed to without loss of satisfiability, therefore we may assume `A`
  already uses those values.
* When the algorithm chooses a variable `v` to branch, `A` gives it a definite
  value (`0` or `1`). The branch that tries this value keeps `P ⊆ A`; the other
  branch inevitably leads to a conflict (Lemma&nbsp;2) and is discarded.

Thus the recursion follows the path consistent with `A` and never backtracks
away from it. When all variables of `A` become assigned, the “all clauses
satisfied” test succeeds (Lemma&nbsp;4) and the algorithm returns the assignment.
∎



##### Lemma 7  
If `solve` returns `None`, no satisfying assignment exists.

**Proof.**  
`solve` returns `None` only after exploring **both** branches for the chosen
unassigned variable and each branch either

* produced a conflict (Lemma&nbsp;2) or
* recursively returned `None`.

By induction on the recursion depth, every explored partial assignment cannot be
extended to a full solution. Since the search explores *all* possible
assignments consistent with unit propagation and pure‑literal elimination,
no satisfying total assignment exists. ∎



##### Theorem  
The program prints

* “YES” and a configuration that satisfies every inspection check
  **iff** such a configuration exists,
* otherwise prints “NO”.

**Proof.**  

*If the program prints “YES”.*  
It obtained the configuration from `solve`. By Lemma&nbsp;5 the configuration
satisfies all clauses, therefore it is a valid global dial setting.

*If a valid configuration exists.*  
`solve` is invoked with an empty assignment. By Lemma&nbsp;6 it returns a
satisfying assignment, consequently the program prints “YES”.

*If the program prints “NO”.*  
That happens only when `solve` returned `None`. By Lemma&nbsp;7 no satisfying
assignment exists.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

`n ≤ 90`, `m ≤ 400`.

*Unit propagation* scans all clauses repeatedly; each scan is `O(m·3)`.  
In the worst case it may be executed once per assigned variable, i.e. `O(n·m)`.

*Pure‑literal elimination* also scans all clauses a constant number of times,
again `O(n·m)`.

The recursive search explores at most `2^n` branches, but the strong
propagation reduces the explored tree dramatically. For the given limits the
running time is far below the 2 seconds limit; the memory consumption is
`O(n + m)` (the clauses and a few auxiliary arrays).

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve_sat(n, clauses):
    # ------------------------------------------------------------
    # helpers
    def clause_satisfied(cl):
        """return True if clause already satisfied under current assign"""
        for lit in cl:
            v = abs(lit)
            a = assign[v]
            if a != -1 and ((a == 1 and lit > 0) or (a == 0 and lit < 0)):
                return True
        return False

    def unit_propagate():
        """perform unit propagation, return True if conflict detected"""
        while True:
            unit_lit = None
            for cl in clauses:
                # skip satisfied clauses
                if clause_satisfied(cl):
                    continue
                unassigned = []
                for lit in cl:
                    v = abs(lit)
                    a = assign[v]
                    if a == -1:
                        unassigned.append(lit)
                    else:
                        # literal already false, continue
                        pass
                if not unassigned:          # all three false -> conflict
                    return True
                if len(unassigned) == 1:    # unit clause
                    unit_lit = unassigned[0]
                    break
            else:
                break          # no unit clause found

            # assign the forced literal
            v = abs(unit_lit)
            val = 1 if unit_lit > 0 else 0
            if assign[v] == -1:
                assign[v] = val
            elif assign[v] != val:
                return True    # contradictory assignment
        return False

    def pure_literal_assign():
        """assign pure literals, return True if conflict occurs"""
        while True:
            pos = [False] * (n + 1)
            neg = [False] * (n + 1)
            any_unsat = False
            for cl in clauses:
                if clause_satisfied(cl):
                    continue
                any_unsat = True
                for lit in cl:
                    v = abs(lit)
                    if assign[v] == -1:
                        if lit > 0:
                            pos[v] = True
                        else:
                            neg[v] = True
            if not any_unsat:
                break
            changed = False
            for v in range(1, n + 1):
                if assign[v] != -1:
                    continue
                if pos[v] and not neg[v]:
                    assign[v] = 1
                    changed = True
                elif neg[v] and not pos[v]:
                    assign[v] = 0
                    changed = True
            if not changed:
                break
            if unit_propagate():
                return True
        return False

    def all_clauses_satisfied():
        for cl in clauses:
            if not clause_satisfied(cl):
                return False
        return True

    def choose_variable():
        """heuristic: variable occurring most often in unsatisfied clauses"""
        cnt = [0] * (n + 1)
        for cl in clauses:
            if clause_satisfied(cl):
                continue
            for lit in cl:
                v = abs(lit)
                if assign[v] == -1:
                    cnt[v] += 1
        best = -1
        var = -1
        for v in range(1, n + 1):
            if assign[v] == -1 and cnt[v] > best:
                best = cnt[v]
                var = v
        return var

    # ------------------------------------------------------------
    # recursive DPLL
    def dpll():
        if unit_propagate():
            return None
        if pure_literal_assign():
            return None
        if all_clauses_satisfied():
            return assign[:]

        var = choose_variable()
        if var == -1:          # all variables assigned but some clause unsatisfied
            return None

        for val in (1, 0):
            saved = assign[:]
            assign[var] = val
            res = dpll()
            if res is not None:
                return res
            assign[:] = saved
        return None

    # start with all unassigned
    assign = [-1] * (n + 1)
    return dpll()


def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    clauses = []
    for _ in range(m):
        l1 = int(next(it))
        l2 = int(next(it))
        l3 = int(next(it))
        clauses.append([l1, l2, l3])

    result = solve_sat(n, clauses)
    if result is None:
        print("NO")
    else:
        print("YES")
        # result[0] is dummy
        print(' '.join(str(result[i]) if result[i] != -1 else '0' for i in range(1, n + 1)))

if __name__ == "__main__":
    main()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
