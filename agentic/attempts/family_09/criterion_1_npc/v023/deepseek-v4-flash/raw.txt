We need to find an independent set of size exactly `k` in a graph with `n` vertices and `m` edges.  

The constraints are not fully given, but the problem mentions the maximum number of bands is 46, so `n` can be up to 46. That means we can use a backtracking or bitmask approach.

We can use a recursive backtracking with pruning:

- Sort vertices by degree (optional, but helps).
- Try to build an independent set of size `k`.
- If at any point we can't reach `k` with remaining vertices, prune.

Here’s the implementation:

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))
    
    adj = [0] * n
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
    
    # If k > n, impossible
    if k > n:
        print("NO")
        return
    
    # If k == 0, but problem says at least one band, so k >= 1
    if k == 0:
        print("NO")
        return
    
    # Try to find independent set of size k
    # Use backtracking with pruning
    vertices = list(range(n))
    # Sort by degree ascending for better pruning
    vertices.sort(key=lambda x: bin(adj[x]).count("1"))
    
    chosen = []
    
    def backtrack(start, chosen_count):
        if chosen_count == k:
            return True
        # Prune: not enough remaining vertices
        if n - start < k - chosen_count:
            return False
        for i in range(start, n):
            v = vertices[i]
            # Check if v conflicts with chosen
            conflict = False
            for c in chosen:
                if (adj[v] >> c) & 1:
                    conflict = True
                    break
            if conflict:
                continue
            chosen.append(v)
            if backtrack(i + 1, chosen_count + 1):
                return True
            chosen.pop()
        return False
    
    if backtrack(0, 0):
        print("YES")
        print(" ".join(str(x + 1) for x in chosen))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
