**Solution Explanation**

For the given undirected graph we have to find an *independent set* (a set of vertices
with no edge inside) of exactly `k` vertices, or decide that it does not exist.
`n ≤ 46`, therefore a simple exponential search with good pruning is fast enough.

--------------------------------------------------------------------

#### 1.   Bitset representation  

Vertex numbers are `0 … n‑1` (the input uses `1 … n`, we subtract one).
For every vertex `v`

```
adj[v]   –  bitmask of neighbours of v (including v itself is NOT set)
```

All sets of vertices are also stored as bitmasks (`int` in Python).  
`popcount(x)` = `x.bit_count()` – number of set bits.

--------------------------------------------------------------------

#### 2.   Depth‑first search with pruning  

```
search(cur_mask, cand_mask):
    cur_sz = popcount(cur_mask)

    # already have k vertices → success
    if cur_sz == k:
        return cur_mask

    # not enough vertices left → dead end
    if cur_sz + popcount(cand_mask) < k:
        return None

    # choose a vertex v from cand_mask (lowest set bit)
    v = (cand_mask & -cand_mask).bit_length() - 1

    # ----- try to take v -----
    # it can be taken because we never keep a vertex that is adjacent to an already
    # chosen one – the recursion guarantees that
    new_cand = cand_mask & ~adj[v]          # remove neighbours of v
    new_cand &= ~(1 << v)                   # also remove v itself
    res = search(cur_mask | (1 << v), new_cand)
    if res is not None:
        return res

    # ----- try to skip v -----
    res = search(cur_mask, cand_mask & ~(1 << v))
    return res
```

The recursion depth is at most `n (≤46)`.  
The two pruning rules are enough for the given limits:

* if we already have `k` vertices – stop,
* if even taking **all** remaining candidates cannot reach `k` – stop.

The branching factor is at most `2`, therefore the worst case is `O(2^n)`,
but the pruning cuts the tree dramatically; for `n = 46` it runs far below the
time limit (the same technique is standard for the *Maximum Independent Set*
problem on such sizes).

--------------------------------------------------------------------

#### 3.   Algorithm  

```
read n, m, k
build adj[0…n-1] as bitmasks
all_vertices = (1 << n) - 1
answer_mask = search(0, all_vertices)

if answer_mask is None:
    print "NO"
else:
    print "YES"
    output the (1‑based) indices of the set bits of answer_mask
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct set iff such a set exists.

---

##### Lemma 1  
During the whole execution of `search(cur, cand)` the invariant holds:

*All vertices in `cur` are pairwise non‑adjacent, and no vertex in `cand`
is adjacent to any vertex in `cur`.*

**Proof.**  
Initially `cur = ∅`, `cand = V` – invariant holds.  
Induction step:

*When we take a vertex `v`* we set `cur' = cur ∪ {v}` and
`cand' = cand \ ( {v} ∪ N(v) )`.  
Because `v` is removed from `cand`, no vertex remaining in `cand'` is adjacent to `v`.
All previous vertices of `cur` stay non‑adjacent to each other by the induction
hypothesis, and they were also non‑adjacent to `v` (otherwise `v` would have been
removed earlier). Hence invariant holds for the recursive call.

*When we skip `v`* we only delete `v` from `cand`; adjacency relations are unchanged,
so the invariant also holds. ∎



##### Lemma 2  
If `search` returns a mask `S`, then `S` is an independent set of size `k`.

**Proof.**  
The only returning statements are when `popcount(cur) == k`.  
By Lemma&nbsp;1 `cur` (the returned mask) contains no adjacent pair, therefore it
is an independent set, and its size is exactly `k`. ∎



##### Lemma 3  
If there exists an independent set `I` of size `k`, then `search(0, V)` returns
some mask (not `None`).

**Proof.**  
Consider the execution tree of `search`.  
At each node we either *take* the current vertex `v` or *skip* it.
Follow the unique path that **always makes the same decision as `I`**:
* if `v ∈ I` we take it,
* otherwise we skip it.

Because `I` is independent, taking `v` never conflicts with already taken
vertices, therefore the recursive call is allowed.
Consequently the path is never cut by the “already have k vertices” test
(because we reach exactly `k` at the leaf) and never cut by the
“not enough vertices left” test (the remaining part of `I` is still inside
`cand`).  
Thus the leaf of this path returns a mask of size `k`. ∎



##### Lemma 4  
`search` returns `None` **iff** no independent set of size `k` exists.

**Proof.**  
*If part*: by Lemma&nbsp;2 any returned mask is a valid set, therefore returning
`None` means no such mask was found, i.e. none exists.

*Only‑if part*: if a set exists, Lemma&nbsp;3 guarantees that the recursion
finds it and returns a mask, contradicting `None`. ∎



##### Theorem  
The program outputs  

* `YES` and a list of `k` vertices forming an all‑strangers group
  **iff** such a group exists,
* otherwise outputs `NO`.

**Proof.**  
The program runs `search`.  
By Lemma&nbsp;4 the returned mask is `None` exactly when no independent set of
size `k` exists, leading to output `NO`.  
Otherwise a mask is returned; by Lemma&nbsp;2 it is a correct independent set,
the program prints `YES` and its vertices, which satisfies the specification. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

`n ≤ 46`.

*Each recursive call* does only O(1) work (bit operations, popcount).  
The number of visited nodes is bounded by the size of the search tree.
In the worst case it is `O(2^n)`, but the two pruning rules cut huge branches.
For the maximal input (`n = 46`, dense graph) the tree is tiny; for the
empty graph the algorithm stops as soon as it has taken `k` vertices
(`k ≤ n`), exploring at most `∑_{i=0}^{k} C(n,i)` nodes, which is far below
`2^n` for any realistic `k`.  

Memory consumption is `O(n)` for the adjacency array and the recursion stack
(`≤ 46` frames).

Both limits easily satisfy the given limits (5 s, 256 MiB).

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj = [0] * n
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    all_vertices = (1 << n) - 1

    # depth‑first search with pruning
    def dfs(cur_mask: int, cand_mask: int):
        cur_sz = cur_mask.bit_count()
        if cur_sz == k:
            return cur_mask
        # not enough vertices left
        if cur_sz + cand_mask.bit_count() < k:
            return None
        # pick a vertex v (lowest set bit)
        v_bit = cand_mask & -cand_mask
        v = (v_bit.bit_length() - 1)

        # try to take v
        new_cand = cand_mask & ~adj[v]          # remove neighbours
        new_cand &= ~v_bit                      # also remove v itself
        res = dfs(cur_mask | v_bit, new_cand)
        if res is not None:
            return res

        # skip v
        return dfs(cur_mask, cand_mask & ~v_bit)

    ans_mask = dfs(0, all_vertices)

    out = []
    if ans_mask is None:
        out.append("NO")
    else:
        out.append("YES")
        vertices = [str(i + 1) for i in range(n) if (ans_mask >> i) & 1]
        out.append(" ".join(vertices))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
