We can model the accounts as a bipartite graph: the two demographics are the two color classes.  
A set of accounts with no mutual contacts means we must pick accounts all from the same demographic (since contacts only exist across demographics).  

So the problem reduces to:  
- Find the sizes of the two color classes in the bipartite graph.  
- If either size is at least `k`, we can pick `k` accounts from that side.  
- Otherwise, output `NO`.

We can find the two sides using BFS/DFS coloring.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m, k = map(int, input().split())
adj = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * (n + 1)
side_size = [0, 0]

for start in range(1, n + 1):
    if color[start] == -1:
        # BFS to color this component
        q = deque([start])
        color[start] = 0
        side_size[0] += 1
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    side_size[color[v]] += 1
                    q.append(v)

if max(side_size) >= k:
    target_color = 0 if side_size[0] >= k else 1
    chosen = [i for i in range(1, n + 1) if color[i] == target_color][:k]
    print("YES")
    print(" ".join(map(str, chosen)))
else:
    print("NO")
```
