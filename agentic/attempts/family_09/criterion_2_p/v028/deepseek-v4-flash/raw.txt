We can model the gears as a bipartite graph (since the system is workable, it’s bipartite).  
We need to pick exactly `k` vertices with no edges between them — that’s an independent set.  

In a bipartite graph, the maximum independent set size is `n - size_of_minimum_vertex_cover`, which equals `n - size_of_maximum_matching` (by König’s theorem).  
But here we don’t need the maximum — we just need *any* independent set of size `k`.  

A simple approach:  
- Color the graph bipartitely (two colors).  
- Let `cnt0` and `cnt1` be the sizes of the two color classes.  
- If `k <= max(cnt0, cnt1)`, we can pick `k` vertices from the larger color class — that’s an independent set.  
- Otherwise, it’s impossible.  

We can implement BFS/DFS to color the graph.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m, k = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
color_count = [0, 0]

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        color_count[0] += 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    color_count[color[v]] += 1
                    q.append(v)

# Pick from the larger color class
if k <= max(color_count):
    chosen_color = 0 if color_count[0] >= color_count[1] else 1
    chosen = [i + 1 for i in range(n) if color[i] == chosen_color][:k]
    print("YES")
    print(" ".join(map(str, chosen)))
else:
    print("NO")
```
