**Solution Explanation**

For every conflict edge the two endpoints belong to different departments.
Therefore the whole graph is *bipartite* – it can be coloured with two colours
(`0` and `1`) such that every edge connects vertices of different colours.
The departments are exactly the two colour classes, they are not given
explicitly, we recover them by a simple BFS/DFS colourisation.

--------------------------------------------------------------------

#### 1.   From a committee to a vertex cover  

A set of vertices without an edge inside it is an **independent set**.
For a bipartite graph

```
size(maximum independent set) = |V| – size(minimum vertex cover)
                               = |V| – size(maximum matching)          (Kőnig)
```

If we can find an independent set of size `≥ k` we can simply throw away
some vertices and obtain a committee of exactly `k` members.
So we only have to know whether the *maximum* independent set is large
enough.

--------------------------------------------------------------------

#### 2.   Maximum matching – Hopcroft‑Karp  

The graph is bipartite, `n ≤ 10⁵ , m ≤ 4·10⁵`.  
The Hopcroft‑Karp algorithm runs in `O(m·√n)` and easily fits into the
limits.

* left side = colour `0` vertices, right side = colour `1` vertices  
* `pairU[u]` – partner of left vertex `u` (`-1` if free)  
* `pairV[v]` – partner of right vertex `v` (`-1` if free)  

The algorithm repeatedly

* BFS – builds distance layers from all free left vertices,
* DFS – augments along the shortest alternating paths found by the BFS.

The number of found augmentations is the size `M` of a maximum matching.

--------------------------------------------------------------------

#### 3.   Constructing a maximum independent set  

From a maximum matching we obtain a *minimum* vertex cover by the classic
alternating‑reachability construction:

```
Z = vertices reachable from a free left vertex
    by alternating paths (non‑matched edge, matched edge, …)

minimum vertex cover = (left \ Z) ∪ (right ∩ Z)
maximum independent set = (left ∩ Z) ∪ (right \ Z)
```

The set `Z` is found by a BFS that

* starts from every unmatched left vertex,
* from a left vertex follows only **non‑matched** edges,
* from a right vertex follows only the **matched** edge back to the left.

All vertices of the maximum independent set are collected,
its size is exactly `n – M`.

--------------------------------------------------------------------

#### 4.   Answer  

*If* `|independent| ≥ k` we output `YES` and any `k` vertices of the set.  
Otherwise we output `NO`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The colouring phase produces a bipartition `(L,R)` of the vertex set such
that every edge of the input connects a vertex of `L` with a vertex of `R`.

**Proof.**  
The input is guaranteed to be bipartite.  
A standard BFS/DFS 2‑colouring colours each connected component with two
colours, never assigning the same colour to the two ends of an edge.
Therefore after the traversal every edge has endpoints of different
colours, i.e. one endpoint in `L` (colour 0) and the other in `R` (colour 1). ∎



##### Lemma 2  
`M` returned by Hopcroft‑Karp equals the size of a maximum matching of the
graph.

**Proof.**  
Hopcroft‑Karp is a well‑known algorithm; its correctness proof shows that
after the BFS/DFS phases no augmenting path exists, i.e. the current
matching is maximum. ∎



##### Lemma 3  
Let `Z` be the set of vertices reachable from a free left vertex by
alternating paths (as constructed in the algorithm).  
Then `C = (L \ Z) ∪ (R ∩ Z)` is a minimum vertex cover.

**Proof.**  
Standard theorem for bipartite graphs (Kőnig’s theorem).  
Every edge either has its left endpoint in `L \ Z` (then the edge is covered)
or its right endpoint in `R ∩ Z`.  
Conversely, if a vertex cover were smaller, the alternating‑reachability
argument would give an augmenting path, contradicting maximality of the
matching. ∎



##### Lemma 4  
`I = (L ∩ Z) ∪ (R \ Z)` is an independent set of size `n – M`.

**Proof.**  
`I` is the complement of the minimum vertex cover `C` from Lemma&nbsp;3,
hence it contains no edge (otherwise that edge would not be covered by `C`).
Because `|C| = M` (Kőnig’s theorem) we have `|I| = n – M`. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a set `S` of `k` vertices,
then `S` is conflict‑free.

**Proof.**  
The algorithm first builds the independent set `I` from Lemma&nbsp;4,
which contains no edge.  
`S` is a subset of `I`, therefore it also contains no edge. ∎



##### Lemma 6  
If the algorithm outputs `NO` then no conflict‑free committee of size `k`
exists.

**Proof.**  
`NO` is printed exactly when `|I| < k`.  
By Lemma&nbsp;4 `|I|` is the size of a *maximum* independent set.
Hence every independent set (and therefore every conflict‑free committee)
has size at most `|I| < k`. ∎



##### Theorem  
The program prints

* `YES` and a list of `k` employee numbers forming a conflict‑free committee
  **iff** such a committee exists,
* otherwise prints `NO`.

**Proof.**  

*If the program prints `YES`* – by Lemma&nbsp;5 the printed vertices form a
conflict‑free committee of size `k`.

*If a conflict‑free committee of size `k` exists* – there exists an
independent set of size at least `k`.  
The maximum independent set has size `|I| ≥ k`.  
Consequently the algorithm will not output `NO` (Lemma&nbsp;6) and will
output `YES`. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Colouring* – `O(n + m)`  
*Hopcroft‑Karp* – `O(m·√n)`  
*Construction of `Z` and the independent set* – `O(n + m)`  

Overall  

```
Time   : O(m·√n)   ≤ 4·10⁵·√10⁵  ≈ 1.3·10⁸ elementary operations
Memory : O(n + m)  ≤ 5·10⁵ integers  (well below 256 MiB)
```

Both satisfy the limits.

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

# -------------------------------------------------------------

def solve() -> None:
    sys.setrecursionlimit(1 << 25)
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    # original adjacency (only needed for colouring)
    adj_orig = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj_orig[u].append(v)
        adj_orig[v].append(u)
        edges.append((u, v))

    # 1) colour the graph -> bipartition
    colour = [-1] * (n + 1)          # 0 = left, 1 = right
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        colour[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            cu = colour[u]
            for v in adj_orig[u]:
                if colour[v] == -1:
                    colour[v] = cu ^ 1
                    q.append(v)

    # build lists of vertices per side and mapping to indices
    left_nodes = []
    right_nodes = []
    left_id = [-1] * (n + 1)
    right_id = [-1] * (n + 1)
    for v in range(1, n + 1):
        if colour[v] == 0:
            left_id[v] = len(left_nodes)
            left_nodes.append(v)
        else:
            right_id[v] = len(right_nodes)
            right_nodes.append(v)

    L = len(left_nodes)
    R = len(right_nodes)

    # adjacency from left side to right side (indices)
    adj = [[] for _ in range(L)]
    for u, v in edges:
        if colour[u] == 0:          # u is left, v right
            adj[left_id[u]].append(right_id[v])
        else:                       # v is left, u right
            adj[left_id[v]].append(right_id[u])

    # ---------------------------------------------------------
    # Hopcroft‑Karp
    pairU = [-1] * L
    pairV = [-1] * R
    dist = [0] * L
    INF = 10 ** 9

    def bfs() -> bool:
        q = deque()
        for u in range(L):
            if pairU[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = -1
        found = False
        while q:
            u = q.popleft()
            for v in adj[u]:
                pu = pairV[v]
                if pu == -1:
                    found = True          # free vertex on right reachable
                elif dist[pu] == -1:
                    dist[pu] = dist[u] + 1
                    q.append(pu)
        return found

    sys.setrecursionlimit(1 << 25)

    def dfs(u: int) -> bool:
        for v in adj[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = -1
        return False

    matching = 0
    while bfs():
        for u in range(L):
            if pairU[u] == -1 and dfs(u):
                matching += 1

    # ---------------------------------------------------------
    # Build the alternating reachable set Z
    visitedL = [False] * L
    visitedR = [False] * R
    q = deque()
    for u in range(L):
        if pairU[u] == -1:
            visitedL[u] = True
            q.append(u)

    while q:
        u = q.popleft()          # left vertex
        for v in adj[u]:
            if pairU[u] == v:    # matched edge – skip
                continue
            if not visitedR[v]:
                visitedR[v] = True
                pu = pairV[v]    # matched partner on left, if any
                if pu != -1 and not visitedL[pu]:
                    visitedL[pu] = True
                    q.append(pu)

    # independent set = (L ∩ Z) ∪ (R \ Z)
    independent = []
    for idx, orig in enumerate(left_nodes):
        if visitedL[idx]:
            independent.append(orig)
    for idx, orig in enumerate(right_nodes):
        if not visitedR[idx]:
            independent.append(orig)

    if len(independent) >= k:
        out = ['YES']
        out.append(' '.join(map(str, independent[:k])))
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')


# -------------------------------------------------------------
if __name__ == '__main__':
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
