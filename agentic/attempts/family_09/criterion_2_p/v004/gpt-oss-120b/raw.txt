**Solution Explanation**

For a graph `G = (V,E)` an *independent set* (all‑strangers group) is a set of vertices
containing no edge.
The graph is guaranteed to be **bipartite** – all edges go between two hidden
categories (parts).  
For a bipartite graph the classical König theorem holds  

```
size(minimum vertex cover) = size(maximum matching)
size(maximum independent set) = |V| – size(maximum matching)
```

So an independent set of size `k` exists **iff**

```
|V| – maxMatching ≥ k .
```

Moreover the minimum vertex cover can be constructed from a maximum matching,
hence we can also construct a maximum independent set and output any `k`
vertices from it.



--------------------------------------------------------------------

#### 1.   Build the bipartition

The two parts are not given, we colour the graph with two colours
by a BFS/DFS (the graph is guaranteed bipartite, so this always succeeds).

* `col[v] = 0` – left part  
* `col[v] = 1` – right part



--------------------------------------------------------------------

#### 2.   Maximum matching – Hopcroft‑Karp

Only edges from the left part are stored (`adjL[u]` – neighbours in the right
part).  
Hopcroft‑Karp runs in `O(E √V)` which is easily fast enough
(`E ≤ 4·10⁵ , V ≤ 10⁵`).

It returns two arrays

```
pairU[u] – matched right vertex of left u   (0 = unmatched)
pairV[v] – matched left vertex of right v   (0 = unmatched)
```



--------------------------------------------------------------------

#### 3.   Minimum vertex cover from the matching  

König’s constructive proof:

* start from every **unmatched left vertex**
* walk alternatingly  
  – left → right through **non‑matching** edges  
  – right → left through **matching** edges
* let `Z` be the set of vertices reached by this BFS.

Then  

```
minCover = (Left \ Z)  ∪  (Right ∩ Z)
```

Consequently a maximum independent set is the complement

```
indSet = (Left ∩ Z)  ∪  (Right \ Z)
```

We collect all vertices of `indSet`.  
If its size ≥ `k` we output the first `k` of them, otherwise answer is `NO`.



--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The colouring step produces a bipartition `(L,R)` of the input graph.

**Proof.**  
All edges are between the two hidden categories, i.e. the graph is bipartite.
A BFS/DFS that assigns opposite colours to the ends of every traversed edge
never meets a conflict, therefore each vertex receives a colour and every
edge connects vertices of different colours. ∎



##### Lemma 2  
`matching` returned by Hopcroft‑Karp is a maximum matching of the bipartite
graph `(L,R)`.

**Proof.**  
Hopcroft‑Karp is a well‑known algorithm that repeatedly augments along a
shortest augmenting path until none exists. The absence of augmenting paths
characterises a maximum matching (Berge’s theorem). ∎



##### Lemma 3  
Let `Z` be the set of vertices reachable from unmatched left vertices by the
alternating BFS described in the algorithm.
Then `C = (L \ Z) ∪ (R ∩ Z)` is a minimum vertex cover.

**Proof.**  
Standard König construction.  
*Every edge* is of one of the two forms:

1. left vertex `u ∈ Z`.  
   If the edge `u‑v` is **not** in the matching, `v` is reached from `u`,
   therefore `v ∈ Z`. The edge is covered by `u ∈ L∩Z` (which is **not**
   in `C`) **or** by `v ∈ R∩Z` (which **is** in `C`).  
2. left vertex `u ∉ Z`.  
   Then `u` is in `L\Z ⊆ C`, so the edge is covered.

Thus `C` covers all edges.  
Its size equals the size of the matching (König’s theorem), therefore it is
minimum. ∎



##### Lemma 4  
`I = (L ∩ Z) ∪ (R \ Z)` is a maximum independent set.

**Proof.**  
`I` is the complement of the minimum vertex cover `C`, hence it is an
independent set (otherwise an uncovered edge would exist).  
Because `|C| = |matching|`,  

```
|I| = |V| – |C| = |V| – |matching| = size of a maximum independent set
```

by König’s theorem. ∎



##### Lemma 5  
If `|I| ≥ k` the algorithm outputs `k` distinct vertices that form an
independent set.

**Proof.**  
The algorithm selects the first `k` vertices from `I`.  
All selected vertices belong to `I`, which is independent by Lemma&nbsp;4,
hence no two of them are adjacent. ∎



##### Lemma 6  
If `|I| < k` no independent set of size `k` exists.

**Proof.**  
`|I|` is the size of a *maximum* independent set (Lemma&nbsp;4).  
If it is smaller than `k`, any independent set is at most `|I| < k`. ∎



##### Theorem  
The program prints  

* `YES` and a valid group of `k` users **iff** such a group exists,
* otherwise prints `NO`.

**Proof.**  

*If the program prints `YES`*:  
It happened because `|I| ≥ k`. By Lemma&nbsp;5 the printed vertices are an
independent set of size `k`. Hence a required group exists.

*If a required group exists*:  
Let `S` be any independent set of size `k`. By maximality of `I`,
`|I| ≥ |S| = k`. The program therefore finds `|I| ≥ k` and prints `YES`
and a (possibly different) independent set of size `k`.  

If the program prints `NO`, it means `|I| < k`; by Lemma&nbsp;6 no independent
set of size `k` exists, contradicting the assumption. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Colouring* – `O(n + m)`  
*Hopcroft‑Karp* – `O(m √n)`  
*BFS for vertex cover* – `O(n + m)`  

Overall `O(m √n)` ≤ `4·10⁵·√10⁵ ≈ 1.3·10⁸` operations, well inside the 2 s limit
in CP‑Python (the constant factor is small).  

Memory consumption: adjacency lists (`2·m` integers) + a few arrays of size
`n` → `O(n + m)` ≤ about 5 MB.



--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))
    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    # 1. bipartition
    col = [-1] * (n + 1)
    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        col[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if col[v] == -1:
                    col[v] = col[u] ^ 1
                    q.append(v)

    left = [i for i in range(1, n + 1) if col[i] == 0]
    right = [i for i in range(1, n + 1) if col[i] == 1]

    # adjacency from left to right
    adjL = [[] for _ in range(n + 1)]
    for u, v in edges:
        if col[u] == 0:
            adjL[u].append(v)
        else:
            adjL[v].append(u)

    # 2. Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [0] * (n + 1)   # left -> right
    pairV = [0] * (n + 1)   # right -> left
    dist = [0] * (n + 1)

    def bfs() -> bool:
        q = deque()
        for u in left:
            if pairU[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while q:
            u = q.popleft()
            if dist[u] < dist[0]:
                for v in adjL[u]:
                    if dist[pairV[v]] == INF:
                        dist[pairV[v]] = dist[u] + 1
                        q.append(pairV[v])
        return dist[0] != INF

    def dfs(u: int) -> bool:
        if u == 0:
            return True
        for v in adjL[u]:
            if dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v]):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in left:
            if pairU[u] == 0 and dfs(u):
                matching += 1

    # 3. Build Z (alternating reachable set)
    visitedL = [False] * (n + 1)
    visitedR = [False] * (n + 1)
    q = deque()
    for u in left:
        if pairU[u] == 0:
            visitedL[u] = True
            q.append(('L', u))
    while q:
        side, x = q.popleft()
        if side == 'L':
            for v in adjL[x]:
                if not visitedR[v] and pairU[x] != v:   # non‑matching edge
                    visitedR[v] = True
                    q.append(('R', v))
        else:  # side == 'R'
            pu = pairV[x]
            if pu and not visitedL[pu]:
                visitedL[pu] = True
                q.append(('L', pu))

    # 4. independent set = (L∩Z) ∪ (R\Z)
    indep = []
    for u in left:
        if visitedL[u]:
            indep.append(u)
    for v in right:
        if not visitedR[v]:
            indep.append(v)

    if len(indep) < k:
        print("NO")
        return
    print("YES")
    print(' '.join(map(str, indep[:k])))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
