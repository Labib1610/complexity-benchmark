**Solution Explanation**

For a graph `G = (V ,E)` a *vertex cover* is a set `C ⊆ V` that contains at least one endpoint of every edge.
The complement `V \ C` is an *independent set* (no two vertices are adjacent).

For every graph  

```
size(maximum independent set) = |V| – size(minimum vertex cover)
```

and for bipartite graphs the size of a minimum vertex cover equals the size of a
maximum matching (Kőnig’s theorem).  
Therefore for a bipartite graph we can

1. find a maximum matching,
2. from it obtain a minimum vertex cover,
3. take its complement – a maximum independent set,
4. if this set has at least `k` vertices we output any `k` of them,
   otherwise answer `NO`.

The only difficulty is to construct the bipartition, because the input does not
label the two camps. The graph is guaranteed to be bipartite, so a simple BFS
colouring (0/1) gives the two sides.

--------------------------------------------------------------------

#### Algorithm
```
read n,m,k
build adjacency list G
colour vertices by BFS (0/1) → left = colour 0, right = colour 1

# Hopcroft‑Karp
pairU[u] – partner of left vertex u (0 if free)
pairV[v] – partner of right vertex v (0 if free)
dist[u] – BFS distance in the layered graph

while BFS() builds distance layers:
        for each free u in left:
                if DFS(u) finds augmenting path: increase matching size

# after matching we have pairU / pairV

# minimum vertex cover from the matching
queue all free left vertices
BFS using
        - edges NOT in matching from left → right
        - edges IN matching from right → left
mark visited left Lvis, right Rvis

minCover = (left \ Lvis) ∪ (right ∩ Rvis)
independent = V \ minCover

if |independent| ≥ k:
        print YES and first k vertices of independent
else:
        print NO
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct group iff such a group
exists.

---

##### Lemma 1  
The BFS colouring produces a bipartition `(L,R)` of the input graph.

**Proof.** The graph is guaranteed bipartite, i.e. it contains no odd cycle.
BFS colours the start vertex `0`, all its neighbours `1`, their uncoloured
neighbours `0`, etc. Whenever an edge connects two already coloured vertices,
they must have opposite colours, otherwise an odd cycle would appear.
Thus every edge joins a vertex of colour `0` with a vertex of colour `1`. ∎



##### Lemma 2  
After the Hopcroft‑Karp phase, `pairU / pairV` describe a maximum matching of the
bipartite graph `(L,R)`.

**Proof.** Hopcroft‑Karp is a classic algorithm; it repeatedly augments along a
set of shortest augmenting paths until none exist. The absence of augmenting
paths is equivalent to maximality of the matching (Berge’s theorem). Hence the
resulting matching is maximum. ∎



##### Lemma 3  
The set `C = (L \ Lvis) ∪ (R ∩ Rvis)` computed from the BFS after the matching
is a minimum vertex cover.

**Proof.** This is the standard construction for bipartite graphs:
start from all unmatched left vertices, follow alternating paths
(non‑matching edges left→right, matching edges right→left).
Let `Z` be the set of vertices reachable this way.
Kőnig’s theorem proof shows that `C = (L \ Z) ∪ (R ∩ Z)` is a vertex cover,
and any vertex cover must contain at least these vertices, therefore `C` is
minimum. ∎



##### Lemma 4  
`I = V \ C` is a maximum independent set.

**Proof.** By definition `I` contains no vertex of the minimum vertex cover,
hence no edge can have both ends in `I`; otherwise the edge would be uncovered.
Thus `I` is independent. Its size is `|V| – |C|`. Because `C` is minimum,
`|C| = size(maximum matching)` (Kőnig). Consequently `|I| = |V| – size(maximum matching)`
which equals the size of a maximum independent set (the complement of a minimum
vertex cover). ∎



##### Lemma 5  
If the algorithm outputs `YES` and a set `S`, then `S` is an all‑strangers group
of size `k`.

**Proof.** The algorithm outputs `YES` only when `|I| ≥ k` and chooses any `k`
vertices from `I`. By Lemma&nbsp;4 `I` is independent, therefore any subset of it,
in particular `S`, contains no adjacent pair. Its size is exactly `k`. ∎



##### Lemma 6  
If an all‑strangers group of size `k` exists, the algorithm outputs `YES`.

**Proof.** Any independent set of size `k` is a subset of a maximum independent
set, whose size is `|I|` (Lemma&nbsp;4). Hence `|I| ≥ k`. The algorithm will then
detect `|I| ≥ k` and output `YES`. ∎



##### Theorem  
The algorithm prints `YES` and a correct group of `k` users iff such a group
exists; otherwise it prints `NO`.

**Proof.**  
*If* part: by Lemma&nbsp;5.  
*Only‑if* part: by Lemma&nbsp;6. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Colouring*: `O(n + m)`  
*Hopcroft‑Karp*: `O(m √n)` ( ≤ 4·10⁵·√10⁵ ≈ 1.3·10⁸ operations, fast in practice)  
*BFS for vertex cover*: `O(n + m)`  

Overall time `O(m √n)`, memory `O(n + m)` – well inside the limits.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    # 1. colour graph -> bipartition
    colour = [-1] * (n + 1)
    left = []
    right = []
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        colour[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = colour[u] ^ 1
                    q.append(v)
        # continue, colours set
    for v in range(1, n + 1):
        if colour[v] == 0:
            left.append(v)
        else:
            right.append(v)

    # map vertex id to index in left/right arrays for fast arrays
    left_id = {v: i+1 for i, v in enumerate(left)}   # 1‑based for HK
    right_id = {v: i+1 for i, v in enumerate(right)}

    L = len(left)
    R = len(right)

    # adjacency for HK using indices
    hk_adj = [[] for _ in range(L + 1)]
    for u in left:
        uid = left_id[u]
        for v in adj[u]:
            hk_adj[uid].append(right_id[v])

    # Hopcroft‑Karp
    pairU = [0] * (L + 1)
    pairV = [0] * (R + 1)
    dist = [0] * (L + 1)

    INF = 10 ** 9

    def bfs():
        q = deque()
        for u in range(1, L + 1):
            if pairU[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while q:
            u = q.popleft()
            if dist[u] < dist[0]:
                for v in hk_adj[u]:
                    if dist[pairV[v]] == INF:
                        dist[pairV[v]] = dist[u] + 1
                        q.append(pairV[v])
        return dist[0] != INF

    def dfs(u):
        if u == 0:
            return True
        for v in hk_adj[u]:
            if dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v]):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    while bfs():
        for u in range(1, L + 1):
            if pairU[u] == 0:
                dfs(u)

    # 2. minimum vertex cover
    # start from free left vertices
    Lvis = [False] * (L + 1)
    Rvis = [False] * (R + 1)
    q = deque()
    for u in range(1, L + 1):
        if pairU[u] == 0:
            q.append(u)
            Lvis[u] = True
    while q:
        u = q.popleft()
        # from left, follow non‑matching edges
        for v in hk_adj[u]:
            if pairU[u] != v and not Rvis[v]:
                Rvis[v] = True
                # from right, follow matching edge back
                pu = pairV[v]
                if pu and not Lvis[pu]:
                    Lvis[pu] = True
                    q.append(pu)

    # vertices in minimum vertex cover
    in_cover = [False] * (n + 1)
    for v in left:
        idx = left_id[v]
        if not Lvis[idx]:
            in_cover[v] = True
    for v in right:
        idx = right_id[v]
        if Rvis[idx]:
            in_cover[v] = True

    independent = [i for i in range(1, n + 1) if not in_cover[i]]

    if len(independent) >= k:
        print("YES")
        print(' '.join(map(str, independent[:k])))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
