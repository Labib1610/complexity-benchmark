**Solution Explanation**

For the given graph

* every edge connects the two different camps → the graph is **bipartite**,
* there is no triangle, but this is already guaranteed by bipartiteness.

For a bipartite graph  

```
maximum independent set size = n – size(minimum vertex cover)
minimum vertex cover size      = size(maximum matching)          (Kőnig’s theorem)
```

So we only have to

1. rebuild the two camps (a bipartition),
2. find a maximum matching,
3. from it obtain a minimum vertex cover,
4. the complement of the cover is a maximum independent set,
5. if it contains at least `k` vertices we output any `k` of them,
   otherwise answer `NO`.

The only non‑trivial part is the maximum matching.
`n ≤ 10⁵ , m ≤ 4·10⁵`, therefore Hopcroft‑Karp (`O(m·√n)`) easily fits
into the limits.



--------------------------------------------------------------------

#### 1.   Building the bipartition  

A BFS/DFS colours the graph with two colours `0 / 1`.  
All vertices with colour `0` are the **left** part, colour `1` the **right**
part.  
While colouring we also store adjacency lists `adjL[u]` (only from left to
right) – needed by Hopcroft‑Karp.

The graph is guaranteed to be bipartite, so the colouring never fails.



--------------------------------------------------------------------

#### 2.   Hopcroft‑Karp  

```
pairU[u] – matched right vertex of left u   (0 = free)
pairV[v] – matched left  vertex of right v  (0 = free)
dist[u]  – BFS distance layer of left u
```

Standard implementation:

* BFS builds layers of the alternating graph,
* DFS (called `dfs(u)`) tries to augment along edges that respect the layers.

The algorithm returns the size of a maximum matching and fills `pairU`,
`pairV`.



--------------------------------------------------------------------

#### 3.   Minimum vertex cover from a maximum matching  

Let  

* `freeL` = all left vertices with `pairU[u] == 0`.

From every vertex in `freeL` we run a DFS/BFS **only** through
alternating edges:

* from a left vertex we may follow **non‑matched** edges to the right,
* from a right vertex we may follow **matched** edges to the left.

All visited vertices are marked `visL[u]`, `visR[v]`.

Kőnig’s theorem gives the minimum vertex cover:

```
Cover = (left vertices NOT visited)  ∪  (right vertices visited)
```

Consequently the maximum independent set is the complement:

```
IndSet = (left visited) ∪ (right NOT visited)
```



--------------------------------------------------------------------

#### 4.   Answer  

If `|IndSet| ≥ k` we output `YES` and any `k` vertices of `IndSet`
(e.g. the first `k` while iterating 1 … n).  
Otherwise we output `NO`.



--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The BFS colouring produces a bipartition `(L,R)` such that every edge of the
input connects a vertex of `L` with a vertex of `R`.

**Proof.**  
The graph is bipartite (given). Starting from any uncoloured vertex we assign
colour `0` and BFS‑propagate opposite colours along edges. Because the graph
contains no odd cycle, no conflict appears, therefore every edge joins vertices
with different colours. ∎



##### Lemma 2  
`pairU , pairV` after Hopcroft‑Karp constitute a **maximum matching** of the
bipartite graph `(L,R)`.

**Proof.**  
Hopcroft‑Karp is a classic algorithm; it repeatedly augments along a set of
shortest augmenting paths until none exist. The absence of augmenting paths
characterises a maximum matching (Berge’s theorem). Hence the returned
matching is maximum. ∎



##### Lemma 3  
Let `Z` be the set of vertices reachable from the free left vertices by the
alternating walk described in step&nbsp;3.
Then  

```
C = (L \ Z) ∪ (R ∩ Z)
```

is a **minimum vertex cover**.

**Proof.**  
Standard theorem for bipartite graphs: from any maximum matching,
the vertices reachable from free left vertices via alternating paths form the
set `Z`. The set `C` defined above covers every edge:
* an edge with left endpoint in `Z` is not matched (otherwise the right
  endpoint would also be in `Z`), so its right endpoint lies in `R∩Z ⊆ C`;
* an edge with left endpoint not in `Z` has its left endpoint in `L\Z ⊆ C`.

Conversely, `C` has size `|matching|` (each matched edge contributes exactly
one vertex to `C`), therefore by König’s theorem it is a minimum vertex cover.
∎



##### Lemma 4  
`I = (L ∩ Z) ∪ (R \ Z)` is a **maximum independent set**.

**Proof.**  
`I` is the complement of the minimum vertex cover `C`, thus it is an
independent set (no edge can have both ends in `I`, otherwise the edge would be
uncovered by `C`).  
Its size is `n – |C| = n – |matching|`, which equals the size of a maximum
independent set by König’s theorem. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a set `S` of `k` vertices, then `S` is an
all‑strangers group.

**Proof.**  
The algorithm selects `S` as a subset of `I` (the maximum independent set).
Since `I` contains no edge, any subset of it also contains no edge.
Therefore no two vertices of `S` are friends. ∎



##### Lemma 6  
If the algorithm outputs `NO` then **no** all‑strangers group of size `k`
exists.

**Proof.**  
`NO` is printed exactly when `|I| < k`.  
`I` is a maximum independent set (Lemma&nbsp;4), thus every independent set
has size at most `|I|`. Consequently no independent set of size `k` exists. ∎



##### Theorem  
The program prints `YES` and a valid group of `k` users iff such a group
exists; otherwise it prints `NO`.

**Proof.**  

*If the program prints `YES`*: by Lemma&nbsp;5 the printed vertices form an
independent set of size `k`, i.e. a required group.

*If the program prints `NO`*: by Lemma&nbsp;6 no independent set of size `k`
exists, therefore the required group does not exist.

Both directions hold, completing the proof. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Bipartition* – `O(n + m)`  
*Hopcroft‑Karp* – `O(m·√n)`  
*Building `Z`* – one BFS/DFS over the alternating graph, `O(n + m)`  

Overall  

```
Time   : O(m·√n)   ≤ 4·10⁵·√10⁵  ≈ 1.3·10⁸ operations  (well inside 2 s in PyPy)
Memory : O(n + m)  ≤ 5·10⁵ integers  (≈ few MB)
```

Both satisfy the limits.

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))

    g = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        g[u].append(v)
        g[v].append(u)
        edges.append((u, v))

    # 1. bipartition
    color = [-1] * (n + 1)
    left = []
    right = []
    for start in range(1, n + 1):
        if color[start] != -1:
            continue
        dq = deque([start])
        color[start] = 0
        while dq:
            u = dq.popleft()
            for v in g[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    dq.append(v)
        # continue, all vertices will be coloured

    for v in range(1, n + 1):
        if color[v] == 0:
            left.append(v)
        else:
            right.append(v)

    # map vertex id -> index in left/right arrays (1‑based for HK)
    lid = {v: i + 1 for i, v in enumerate(left)}
    rid = {v: i + 1 for i, v in enumerate(right)}
    L = len(left)
    R = len(right)

    adj = [[] for _ in range(L + 1)]
    for u, v in edges:
        if color[u] == 0:
            adj[lid[u]].append(rid[v])
        else:
            adj[lid[v]].append(rid[u])

    # 2. Hopcroft‑Karp
    pairU = [0] * (L + 1)
    pairV = [0] * (R + 1)
    dist = [0] * (L + 1)

    INF = 10 ** 9

    def bfs() -> bool:
        dq = deque()
        for u in range(1, L + 1):
            if pairU[u] == 0:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        reachable = False
        while dq:
            u = dq.popleft()
            for v in adj[u]:
                if pairV[v] == 0:
                    reachable = True
                elif dist[pairV[v]] == INF:
                    dist[pairV[v]] = dist[u] + 1
                    dq.append(pairV[v])
        return reachable

    def dfs(u: int) -> bool:
        for v in adj[u]:
            if pairV[v] == 0 or (dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v])):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, L + 1):
            if pairU[u] == 0 and dfs(u):
                matching += 1

    # 3. build Z (alternating reachable set)
    visL = [False] * (L + 1)
    visR = [False] * (R + 1)
    dq = deque()
    for u in range(1, L + 1):
        if pairU[u] == 0:
            dq.append(('L', u))
            visL[u] = True
    while dq:
        side, x = dq.popleft()
        if side == 'L':
            for v in adj[x]:
                if not visR[v] and pairU[x] != v:   # non‑matched edge
                    visR[v] = True
                    dq.append(('R', v))
        else:  # side == 'R'
            pu = pairV[x]
            if pu and not visL[pu]:
                visL[pu] = True
                dq.append(('L', pu))

    # 4. independent set = (L visited) ∪ (R not visited)
    indep = []
    for v in left:
        if visL[lid[v]]:
            indep.append(v)
    for v in right:
        if not visR[rid[v]]:
            indep.append(v)

    if len(indep) >= k:
        print("YES")
        print(' '.join(map(str, indep[:k])))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
