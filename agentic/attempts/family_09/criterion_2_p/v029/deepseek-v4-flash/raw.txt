We can model the network as a bipartite graph.  
A completely disconnected group means an independent set in the graph.  

In a bipartite graph, the maximum independent set size is `n - size_of_maximum_matching`.  
But here we only need to check if an independent set of size `k` exists, and if so, output one.

We can find a bipartition (status 0/1) using BFS/DFS.  
Then, the largest independent set is simply the larger of the two color classes.  
If `k` is larger than that, answer is `NO`.  
Otherwise, we can pick any `k` users from the larger color class.

Let’s implement this.

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m, k = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    groups = [[], []]
    
    for i in range(n):
        if color[i] == -1:
            color[i] = 0
            groups[0].append(i)
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 1 - color[u]
                        groups[color[v]].append(v)
                        q.append(v)
    
    # The larger color class is an independent set
    if len(groups[0]) >= k:
        chosen = groups[0][:k]
    elif len(groups[1]) >= k:
        chosen = groups[1][:k]
    else:
        print("NO")
        return
    
    print("YES")
    print(" ".join(str(x + 1) for x in chosen))

if __name__ == "__main__":
    solve()
```
