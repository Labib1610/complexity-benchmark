**Solution Explanation**

For every conflict pair `{u , v}` the two micro‑services belong to different
architectural tiers.
Therefore the whole conflict graph is *bipartite*.
Let the two colour classes be `L` (left) and `R` (right).

For a bipartite graph

* a **vertex cover** – a set of vertices touching every edge –
* a **matching** – a set of pairwise disjoint edges –

are linked by **Kőnig’s theorem**

```
size(minimum vertex cover) = size(maximum matching)
```

For any graph

```
size(maximum independent set) = n – size(minimum vertex cover)
```

Consequently

```
maximum independent set size = n – size(maximum matching)
```

A safe batch of exactly `k` services exists **iff**

```
maximum matching size ≤ n – k
```

If the condition holds we can obtain an independent set of size
`n – matching`.  
From it we output any `k` vertices.

--------------------------------------------------------------------

#### 1.   Build the bipartition

The input guarantees bipartiteness, but the two sides are not given.
We colour the graph with BFS/DFS:

```
colour[v] = 0  → left side L
colour[v] = 1  → right side R
```

All vertices are visited; isolated vertices may obtain any colour
(their colour does not matter).

--------------------------------------------------------------------

#### 2.   Maximum matching – Hopcroft‑Karp

`L` is the left part, `R` the right part.
`adj[u]` (for `u ∈ L`) stores all neighbours in `R`.

Hopcroft‑Karp runs in `O( E √V )`, well inside the limits
(`E ≤ 4·10⁵ , V ≤ 10⁵`).

The algorithm returns

* `pairU[u]` – matched partner of `u ∈ L` (`0` if free)
* `pairV[v]` – matched partner of `v ∈ R` (`0` if free)
* `matching` – size of the maximum matching.

--------------------------------------------------------------------

#### 3.   Minimum vertex cover from the matching

Standard construction:

* start from all **free** vertices of `L`
* follow alternating paths (edges not in the matching, then in the matching, …)
* let `visL`, `visR` be the vertices reached.

Then

```
minimum vertex cover = (L \ visL)  ∪  (R ∩ visR)
```

--------------------------------------------------------------------

#### 4.   Independent set and answer

The complement of the minimum vertex cover is a maximum independent set:

```
independent = (L ∩ visL)  ∪  (R \ visR)
```

Its size is `n – matching`.  
If `matching ≤ n – k` we take any `k` vertices from `independent`,
print `YES` and the list.
Otherwise print `NO`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The graph coloured by the BFS is bipartite with parts `L` and `R`.

**Proof.**  
All given edges connect vertices of different hidden tiers.
BFS colours a vertex opposite to every neighbour, therefore every edge
joins vertices of different colours. ∎



##### Lemma 2  
`matching` returned by Hopcroft‑Karp equals the size of a maximum matching
in the input graph.

**Proof.**  
Hopcroft‑Karp is a classic algorithm that repeatedly augments along
shortest augmenting paths until none exist.
When it stops, no augmenting path exists, which is equivalent to the
matching being maximum (Berge’s theorem). ∎



##### Lemma 3  
The set `C = (L \ visL) ∪ (R ∩ visR)` is a minimum vertex cover.

**Proof.**  
The construction is the standard one for bipartite graphs:
`visL, visR` are exactly the vertices reachable from free left vertices
by alternating paths.
Kőnig’s theorem together with the proof of the construction shows that
`C` covers every edge and has size equal to the matching size,
hence it is minimum. ∎



##### Lemma 4  
The set `I = (L ∩ visL) ∪ (R \ visR)` is a maximum independent set.

**Proof.**  
`I` is the complement of `C`.  
Since `C` is a vertex cover, `I` contains no edge, i.e. it is independent.
Its size is `n – |C| = n – matching`, which equals the maximum possible
independent set size (by the relation `α = n – τ` and Lemma&nbsp;3). ∎



##### Lemma 5  
If `matching ≤ n – k` then the algorithm outputs a set of `k` vertices
with no internal conflict.

**Proof.**  
From Lemma&nbsp;4 we have an independent set `I` of size `n – matching`.
The inequality gives `|I| ≥ k`.  
The algorithm selects any `k` vertices from `I`; they remain independent
because a subset of an independent set is independent. ∎



##### Lemma 6  
If `matching > n – k` then no safe batch of size `k` exists.

**Proof.**  
Maximum independent set size is `n – matching` (Lemma&nbsp;4).
If `matching > n – k` then `n – matching < k`, i.e. every independent set
has fewer than `k` vertices. Hence a safe batch of size `k` is impossible. ∎



##### Theorem  
The program prints

* `YES` and a valid batch of size `k` **iff** such a batch exists,
* otherwise prints `NO`.

**Proof.**  

*If the program prints `YES`.*  
It happened because `matching ≤ n – k`.  
By Lemma&nbsp;5 the printed vertices form an independent set of size `k`,
i.e. a safe batch.

*If a safe batch of size `k` exists.*  
Then an independent set of size `k` exists, therefore the maximum
independent set size is at least `k`.  
Thus `n – matching ≥ k` ⇒ `matching ≤ n – k`.  
The program will not output `NO`; it will output `YES` and a batch
(Lemma&nbsp;5).

*If the program prints `NO`.*  
Then `matching > n – k`. By Lemma&nbsp;6 no independent set of size `k`
exists, so a safe batch is impossible.

All cases are covered, establishing the theorem. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Bipartition (BFS)* : `O(n + m)`  
*Hopcroft‑Karp*      : `O(m √n)`  
*Construction of cover / independent set* : `O(n + m)`  

Overall time   `O(m √n)` ≤ `4·10⁵·√10⁵` ≈ `1.3·10⁸` operations, fast enough
in 2 seconds in PyPy / CPython with optimised code.

Memory consumption:

* adjacency list : `2·m` integers
* several arrays of length `n`  

Total ≤ a few tens of MB, well below 256 MB.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
import collections

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj_all = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj_all[u].append(v)
        adj_all[v].append(u)
        edges.append((u, v))

    # 1. bipartition
    colour = [-1] * (n + 1)          # 0 = left, 1 = right
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        colour[start] = 0
        q = collections.deque([start])
        while q:
            u = q.popleft()
            for v in adj_all[u]:
                if colour[v] == -1:
                    colour[v] = colour[u] ^ 1
                    q.append(v)

    # Build adjacency from left to right
    left_nodes = [i for i in range(1, n + 1) if colour[i] == 0]
    right_nodes = [i for i in range(1, n + 1) if colour[i] == 1]

    # map original ids to 0‑based indices inside each part
    left_id = {v: idx for idx, v in enumerate(left_nodes)}
    right_id = {v: idx for idx, v in enumerate(right_nodes)}

    L = len(left_nodes)
    R = len(right_nodes)
    adj = [[] for _ in range(L)]
    for u, v in edges:
        if colour[u] == 0:
            adj[left_id[u]].append(right_id[v])
        else:
            adj[left_id[v]].append(right_id[u])

    # 2. Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [ -1 ] * L
    pairV = [ -1 ] * R
    dist = [0] * L

    from collections import deque

    def bfs() -> bool:
        q = deque()
        for u in range(L):
            if pairU[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        reachable = False
        while q:
            u = q.popleft()
            for v in adj[u]:
                pu = pairV[v]
                if pu != -1 and dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    q.append(pu)
                elif pu == -1:
                    reachable = True
        return reachable

    def dfs(u: int) -> bool:
        for v in adj[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(L):
            if pairU[u] == -1 and dfs(u):
                matching += 1

    # 3. Build alternating reachability from free left vertices
    visL = [False] * L
    visR = [False] * R
    q = deque()
    for u in range(L):
        if pairU[u] == -1:
            visL[u] = True
            q.append(('L', u))

    while q:
        side, idx = q.popleft()
        if side == 'L':
            u = idx
            for v in adj[u]:
                if not visR[v] and pairU[u] != v:   # edge not in matching
                    visR[v] = True
                    q.append(('R', v))
        else:  # side == 'R'
            v = idx
            pu = pairV[v]
            if pu != -1 and not visL[pu]:
                visL[pu] = True
                q.append(('L', pu))

    # 4. Independent set = (L∩visL) ∪ (R\visR)
    independent = []
    for i, u in enumerate(left_nodes):
        if visL[i]:
            independent.append(u)
    for i, v in enumerate(right_nodes):
        if not visR[i]:
            independent.append(v)

    if matching <= n - k:
        # we have enough vertices
        print("YES")
        print(' '.join(map(str, independent[:k])))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
