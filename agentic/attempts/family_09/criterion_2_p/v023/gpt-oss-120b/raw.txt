**Solution Explanation**

For every module we know with which other modules it conflicts.
The statement guarantees that all conflicts are *between* the two
architectures, therefore the conflict graph is **bipartite**.
A set of modules without any conflict is an **independent set** of this
graph.

For a bipartite graph  

```
size(maximum independent set) = |V| – size(minimum vertex cover)
                              = |V| – size(maximum matching)          (Kőnig)
```

So we

1. colour the graph with two colours → the two partitions `L` and `R`.
2. find a maximum matching with Hopcroft‑Karp (`O(E·√V)`).
3. from the matching obtain a minimum vertex cover  
   (standard alternating‑path construction).
4. the complement of that cover is a maximum independent set.
5. if its size is at least `k` we output any `k` vertices from it,
   otherwise answer `NO`.

All steps are linear‑or‑near‑linear and fit easily into the limits
(`n ≤ 10⁵ , m ≤ 4·10⁵`).

--------------------------------------------------------------------

#### 1.   Building the bipartition  

We run a BFS/DFS over every not yet coloured vertex and colour neighbours
with the opposite colour (`0` / `1`).  
Because the input is guaranteed bipartite this never fails.

--------------------------------------------------------------------

#### 2.   Hopcroft‑Karp  

Only edges from the left side (`colour = 0`) are stored.
For every left vertex `u`

```
pairU[u] – matched right vertex (0 = free)
pairV[v] – matched left vertex  (0 = free)
dist[u]  – distance in the layered graph
```

The usual BFS builds layers, the DFS tries to augment along them.
Complexity `O(E·√V)`.

--------------------------------------------------------------------

#### 3.   Minimum vertex cover from a maximum matching  

* start with all **free** left vertices,
* follow **unmatched** edges `L → R`,
* from a right vertex follow the **matched** edge `R → L`,
* repeat (ordinary BFS/DFS).

Let  

```
visL = left vertices reached,
visR = right vertices reached
```

Then  

```
minimum vertex cover = (L \ visL) ∪ (R ∩ visR)
maximum independent set = (L ∩ visL) ∪ (R \ visR)
```

--------------------------------------------------------------------

#### 4.   Output  

If `|independent| ≥ k` we print `YES` and the first `k` vertices of the
independent set, otherwise `NO`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The graph coloured by the BFS is bipartite with parts `L` (colour 0) and
`R` (colour 1).

**Proof.**  
The BFS colours every edge `u‑v` with opposite colours, because when a
vertex is visited all its neighbours receive the opposite colour.
Since the input guarantees that all edges join the two architectures,
no edge ever connects vertices of the same colour. ∎



##### Lemma 2  
`matching` returned by Hopcroft‑Karp is a maximum matching of the
conflict graph.

**Proof.**  
Hopcroft‑Karp is a classic algorithm; it repeatedly augments along a
maximal set of shortest augmenting paths. It terminates only when no
augmenting path exists, i.e. when the current matching is maximum
(Kőnig‑Egérváry theorem). ∎



##### Lemma 3  
Let `C` be the set constructed in step&nbsp;3  
`C = (L \ visL) ∪ (R ∩ visR)`.  
Then `C` is a minimum vertex cover.

**Proof.**  
The construction is the standard one for bipartite graphs:
start from all free left vertices, walk alternating
(unmatched, matched, …) edges.
Kőnig’s theorem states that the set described above is a minimum vertex
cover. ∎



##### Lemma 4  
`I = (L ∩ visL) ∪ (R \ visR)` is a maximum independent set.

**Proof.**  
`I` is exactly the complement of the minimum vertex cover `C`
(Lemma&nbsp;3), therefore it is an independent set of size
`|V| – |C|`.  
By Kőnig’s theorem `|C| = size(maximum matching)`, hence  

```
|I| = |V| – size(maximum matching) = size(maximum independent set)
```

so `I` is maximum. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a list `S`, then `S` is a stable
cluster of size `k`.

**Proof.**  
`S` is taken from `I` (Lemma&nbsp;4), therefore no two vertices of `S`
are adjacent – the cluster is stable.
The algorithm outputs exactly `k` vertices, so the size condition holds. ∎



##### Lemma 6  
If the algorithm outputs `NO` then no stable cluster of size `k`
exists.

**Proof.**  
`NO` is printed only when `|I| < k`.  
`I` is a *maximum* independent set (Lemma&nbsp;4), therefore every
independent set (stable cluster) has size at most `|I|`.  
Consequently no independent set of size `k` exists. ∎



##### Theorem  
The algorithm prints `YES` and a correct list of `k` modules
iff such a list exists; otherwise it prints `NO`.

**Proof.**  
*If* part: when a list is printed, Lemma&nbsp;5 guarantees its validity.  
*Only‑if* part: when `NO` is printed, Lemma&nbsp;6 shows that a solution
cannot exist. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Colouring* – `O(n + m)`  
*Hopcroft‑Karp* – `O(m·√n)`  
*Cover / independent set construction* – `O(n + m)`  

With `n ≤ 10⁵ , m ≤ 4·10⁵` this is well below the limits.

Memory consumption  

* adjacency list – `2·m` integers  
* several arrays of length `n` – `O(n)`  

Overall `O(n + m)` ≤ about 5 · 10⁵ integers → < 10 MB.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)
        edges.append((u, v))

    # 1. bipartition
    colour = [-1] * (n + 1)          # 0 = left, 1 = right
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        colour[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = colour[u] ^ 1
                    q.append(v)

    # build adjacency from left to right only
    left_adj = [[] for _ in range(n + 1)]
    for u, v in edges:
        if colour[u] == 0:
            left_adj[u].append(v)
        else:
            left_adj[v].append(u)

    # 2. Hopcroft‑Karp
    pairU = [0] * (n + 1)   # left -> right
    pairV = [0] * (n + 1)   # right -> left
    dist = [0] * (n + 1)

    INF = 10 ** 9

    def bfs() -> bool:
        q = deque()
        for u in range(1, n + 1):
            if colour[u] != 0:
                continue
            if pairU[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        found = False
        while q:
            u = q.popleft()
            for v in left_adj[u]:
                pu = pairV[v]
                if pu == 0:
                    found = True
                elif dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    q.append(pu)
        return found

    def dfs(u: int) -> bool:
        for v in left_adj[u]:
            pu = pairV[v]
            if pu == 0 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, n + 1):
            if colour[u] == 0 and pairU[u] == 0:
                if dfs(u):
                    matching += 1

    # 3. minimum vertex cover / maximum independent set
    visL = [False] * (n + 1)
    visR = [False] * (n + 1)
    stack = []

    for u in range(1, n + 1):
        if colour[u] == 0 and pairU[u] == 0:
            stack.append(u)
            visL[u] = True

    while stack:
        u = stack.pop()
        if colour[u] == 0:          # left, follow unmatched edges
            for v in left_adj[u]:
                if not visR[v] and pairU[u] != v:   # edge not in matching
                    visR[v] = True
                    stack.append(v)
        else:                       # right, follow matched edge only
            pu = pairV[u]
            if pu and not visL[pu]:
                visL[pu] = True
                stack.append(pu)

    independent = []
    for v in range(1, n + 1):
        if (colour[v] == 0 and visL[v]) or (colour[v] == 1 and not visR[v]):
            independent.append(v)

    if len(independent) >= k:
        out = ['YES', ' '.join(map(str, independent[:k]))]
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
