We can model the network as a bipartite graph.  
The key observation: users of the same profile type are never friends, so any group consisting only of users from one side of the bipartition is automatically all-strangers.  

Thus, if either side has at least `k` users, we can pick `k` from that side.  
If both sides have fewer than `k`, then the largest all-strangers group is the larger side, so we check if that size is at least `k`.  

We can find the bipartition using BFS/DFS over the graph.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m, k = map(int, input().split())
adj = [[] for _ in range(n + 1)]
for _ in range(m):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * (n + 1)
side0 = []
side1 = []

for i in range(1, n + 1):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        side0.append(i)
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    if color[v] == 0:
                        side0.append(v)
                    else:
                        side1.append(v)
                    q.append(v)

if len(side0) >= k:
    print("YES")
    print(" ".join(map(str, side0[:k])))
elif len(side1) >= k:
    print("YES")
    print(" ".join(map(str, side1[:k])))
else:
    print("NO")
```
