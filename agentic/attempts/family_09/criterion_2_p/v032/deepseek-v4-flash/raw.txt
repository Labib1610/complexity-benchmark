We can model the users as vertices of a bipartite graph, where conflicts are edges between the two partitions.  
Since conflicts only occur between different preferences, the graph is bipartite.  

We can find the two color classes using BFS/DFS.  
Then, if either color class has size at least `k`, we can pick `k` users from that class — they have no conflicts among themselves.  

If both classes are smaller than `k`, it’s impossible.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m, k = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
groups = [[], []]

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        groups[0].append(i)
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    groups[color[v]].append(v)
                    q.append(v)

if len(groups[0]) >= k:
    print("YES")
    print(" ".join(str(x + 1) for x in groups[0][:k]))
elif len(groups[1]) >= k:
    print("YES")
    print(" ".join(str(x + 1) for x in groups[1][:k]))
else:
    print("NO")
```
