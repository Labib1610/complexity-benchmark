**Solution Explanation**

For every conflict we know that the two workers belong to different shifts,
therefore the whole conflict graph is *bipartite*.
A set of workers without any conflict is an **independent set** of this graph.

--------------------------------------------------------------------

#### 1.   From independent set to matching  

For a bipartite graph  

```
size(maximum independent set) = |V| – size(minimum vertex cover)
```

and by Kőnig’s theorem  

```
size(minimum vertex cover) = size(maximum matching)
```

Consequences  

* we can compute a maximum matching,
* from it we obtain a minimum vertex cover,
* the complement of the cover is a **maximum independent set**.

If the maximum independent set has at least `k` vertices we can output any
`k` of them – a subset of an independent set is still independent.

--------------------------------------------------------------------

#### 2.   Overall algorithm  

```
read input
build undirected adjacency list
colour the graph by BFS (0 / 1) → the two shifts
build the bipartite representation:
        left side = colour 0 vertices
        right side = colour 1 vertices
        store each edge only once (left → right)

maximum matching = Hopcroft‑Karp(left, right, edges)

if |V| – matching_size < k :          # maximum independent set too small
        print "NO"
else
        compute minimum vertex cover from the matching
        independent = complement of the cover
        print "YES" and any k vertices of independent
```

--------------------------------------------------------------------

#### 3.   Details  

*Colouring* – BFS from every not yet visited vertex, assign colour `0`,
push neighbours with opposite colour. The input guarantees the graph is
bipartite, so no conflict appears.

*Hopcroft‑Karp* – classic `O(E·√V)` implementation.
`pairU[u]` – right partner of left vertex `u` (`-1` = free)  
`pairV[v]` – left partner of right vertex `v`.

*Minimum vertex cover* – standard alternating‑path construction  

```
start = all free left vertices
traverse
        left → right   via edges NOT in the matching
        right → left   via edges IN the matching
visitedL, visitedR = reached vertices
cover = (left \ visitedL) ∪ (right ∩ visitedR)
independent = (left ∩ visitedL) ∪ (right \ visitedR)
```

*Choosing exactly k* – the independent set we obtained is maximal.
Any subset of it is still independent, therefore we output the first `k`
vertices of the set.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct team iff such a team
exists.

---

##### Lemma 1  
The graph built from the input is bipartite and the BFS colouring
produces a valid bipartition (no edge connects vertices of the same colour).

**Proof.**  
The statement of the problem guarantees that every conflict connects workers
belonging to different shifts, i.e. the graph is bipartite.
BFS colours a start vertex `0`, all its neighbours `1`, their neighbours `0`,
and so on. Because the graph is bipartite, no edge ever connects two vertices
already coloured equally, therefore the produced colours form a bipartition. ∎



##### Lemma 2  
`matching_size` returned by Hopcroft‑Karp equals the size of a maximum
matching of the conflict graph.

**Proof.**  
Hopcroft‑Karp is a well‑known algorithm that repeatedly augments along
shortest alternating paths until none exists.
When it stops, the current matching is maximum for bipartite graphs.
The implementation follows the textbook algorithm, therefore the size it
returns is the maximum possible. ∎



##### Lemma 3  
Let `C` be the vertex set constructed by the alternating‑path procedure
(starting from all unmatched left vertices).  
Then `C` is a minimum vertex cover of the graph.

**Proof.**  
The construction is the standard proof of Kőnig’s theorem.
Define  

```
Z = (left visited) ∪ (right NOT visited)
```

`C = (left \ visited) ∪ (right ∩ visited) = V \ Z`.

*Every edge is incident to C*:  
* if its left endpoint is visited, the edge is either not in the matching
  (then the right endpoint is visited as well) or it is in the matching,
  in which case the right endpoint is visited by the second rule.
* if its left endpoint is not visited, the left endpoint itself belongs to `C`.

Thus `C` covers all edges.  
The classic theorem shows that `|C| = |matching|`, therefore `C` is a
minimum vertex cover. ∎



##### Lemma 4  
`I = V \ C` (the set returned by the algorithm) is a maximum independent set
and `|I| = n – matching_size`.

**Proof.**  
`I` is the complement of a vertex cover, hence it contains no edge –
it is independent.  
From Lemma&nbsp;3, `|C| = matching_size`. Consequently  

```
|I| = n – |C| = n – matching_size .
```

Kőnig’s theorem tells that any independent set has size at most `n –
matching_size`, therefore `I` is maximum. ∎



##### Lemma 5  
If `|I| ≥ k` the algorithm outputs a set of `k` workers with no conflicts.

**Proof.**  
The algorithm takes the first `k` vertices of `I`.  
A subset of an independent set is still independent, thus the printed set
contains no conflicting pair. ∎



##### Lemma 6  
If the algorithm prints `NO` then no harmonious team of size `k` exists.

**Proof.**  
`NO` is printed exactly when `|I| = n – matching_size < k`.  
By Lemma&nbsp;4, `|I|` is the size of a *maximum* independent set.
Hence every independent set (every harmonious team) has size at most `|I|`,
which is smaller than `k`. ∎



##### Lemma 7  
If a harmonious team of size `k` exists, the algorithm prints `YES`.

**Proof.**  
Existence of a team of size `k` means there is an independent set of size
`k`. Therefore the maximum independent set size is at least `k`,
i.e. `n – matching_size ≥ k`. The algorithm then goes to the `YES` branch
and, by Lemma&nbsp;5, outputs a valid team. ∎



##### Theorem  
The algorithm outputs  

* `YES` and a list of `k` workers with no mutual conflict **iff**
  such a team exists,  

* otherwise it outputs `NO`.

**Proof.**  
*If* part – Lemma&nbsp;7.  
*Only‑if* part – Lemma&nbsp;6. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Colouring* – `O(n + m)`  
*Hopcroft‑Karp* – `O(m·√n)` ( ≤ 4·10⁵·√10⁵ ≈ 1.3·10⁸ operations, fast enough in
Python with careful coding)  
*Vertex‑cover construction* – `O(n + m)`  
*Overall* – `O(m·√n)` time, `O(n + m)` memory.

Both limits satisfy the problem constraints.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
import collections

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    # ----- build undirected graph for colouring -----
    g = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        g[u].append(v)
        g[v].append(u)
        edges.append((u, v))

    # ----- bipartition by BFS -----
    color = [-1] * n          # 0 = left, 1 = right
    for start in range(n):
        if color[start] != -1:
            continue
        dq = collections.deque([start])
        color[start] = 0
        while dq:
            v = dq.popleft()
            for to in g[v]:
                if color[to] == -1:
                    color[to] = color[v] ^ 1
                    dq.append(to)

    # ----- create left/right index maps -----
    left_idx = [-1] * n
    right_idx = [-1] * n
    left_nodes = []
    right_nodes = []
    for v in range(n):
        if color[v] == 0:
            left_idx[v] = len(left_nodes)
            left_nodes.append(v)
        else:
            right_idx[v] = len(right_nodes)
            right_nodes.append(v)

    L = len(left_nodes)
    R = len(right_nodes)

    # ----- adjacency from left to right -----
    adj = [[] for _ in range(L)]
    for u, v in edges:
        if color[u] == 0:
            lu = left_idx[u]
            rv = right_idx[v]
        else:
            lu = left_idx[v]
            rv = right_idx[u]
        adj[lu].append(rv)

    # ----- Hopcroft‑Karp -----
    INF = 10 ** 9
    pairU = [-1] * L
    pairV = [-1] * R
    dist = [0] * L

    from collections import deque

    def bfs() -> bool:
        q = deque()
        for u in range(L):
            if pairU[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        found = False
        while q:
            u = q.popleft()
            for v in adj[u]:
                pu = pairV[v]
                if pu != -1 and dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    q.append(pu)
                elif pu == -1:
                    found = True
        return found

    sys.setrecursionlimit(1 << 25)

    def dfs(u: int) -> bool:
        for v in adj[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(L):
            if pairU[u] == -1 and dfs(u):
                matching += 1

    # ----- minimum vertex cover via alternating paths -----
    visitedL = [False] * L
    visitedR = [False] * R
    q = deque()
    for u in range(L):
        if pairU[u] == -1:
            visitedL[u] = True
            q.append(('L', u))

    while q:
        side, x = q.popleft()
        if side == 'L':
            for v in adj[x]:
                if pairU[x] != v and not visitedR[v]:
                    visitedR[v] = True
                    q.append(('R', v))
        else:  # side == 'R'
            pu = pairV[x]
            if pu != -1 and not visitedL[pu]:
                visitedL[pu] = True
                q.append(('L', pu))

    # independent set = (left visited) ∪ (right NOT visited)
    independent = []
    for idx, v in enumerate(left_nodes):
        if visitedL[idx]:
            independent.append(v + 1)          # back to 1‑based
    for idx, v in enumerate(right_nodes):
        if not visitedR[idx]:
            independent.append(v + 1)

    if len(independent) < k:
        sys.stdout.write("NO")
        return

    sys.stdout.write("YES\n")
    sys.stdout.write(" ".join(map(str, independent[:k])))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
