We can model the workers as a bipartite graph where edges are conflicts.  
A harmonious team means we pick workers with no edges between them — that is, an independent set.  

In a bipartite graph, the maximum independent set size is `n - maximum matching size` (by König’s theorem).  
But here we only need to check if we can pick exactly `k` workers with no conflicts.  

Since the graph is bipartite, we can color it into two shifts (partitions).  
If we pick all workers from one shift, we get a conflict-free team.  
So the largest possible harmonious team is the size of the larger shift.  

Thus, if `k` is larger than the size of the larger shift, answer is `NO`.  
Otherwise, we can just pick any `k` workers from the larger shift.  

We don’t even need to compute a matching — just find the bipartition sizes.  

```python
import sys
from collections import deque

def main():
    input = sys.stdin.readline
    n, m, k = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * n
    shift0 = []
    shift1 = []

    for i in range(n):
        if color[i] == -1:
            color[i] = 0
            q = deque([i])
            shift0.append(i)
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = color[u] ^ 1
                        if color[v] == 0:
                            shift0.append(v)
                        else:
                            shift1.append(v)
                        q.append(v)

    if len(shift0) >= k:
        team = shift0[:k]
    elif len(shift1) >= k:
        team = shift1[:k]
    else:
        print("NO")
        return

    print("YES")
    print(" ".join(str(x + 1) for x in team))

if __name__ == "__main__":
    main()
```
