**Solution Explanation**

For every test we are given an undirected graph  

* `n` – vertices (modules) `1 … n`  
* `m` – edges (bidirectional pipelines)  

The graph satisfies the following property  

*for any vertex `X` the set of vertices reachable from `X` by a walk of
even length contains no edge.*

--------------------------------------------------------------------

#### 1.   What does the property mean?

If a walk has even length, the parity of the number of edges is even,
therefore the start and the end vertex belong to the **same side** of a
bipartition.
Consequently the property says:

> vertices that belong to the same side of a bipartition are never
> adjacent.

That is exactly the definition of a **bipartite graph**.
The statement guarantees that the input graph is bipartite
(and possibly disconnected).

--------------------------------------------------------------------

#### 2.   Independent set ↔ vertex cover

For a graph `G`

```
independent set  I   ⇔   V \ I   is a vertex cover
```

A *vertex cover* touches every edge, an *independent set* contains no
edge.  
In a bipartite graph König’s theorem holds:

```
size(minimum vertex cover) = size(maximum matching)
```

Let  

* `M` – size of a maximum matching,
* `Cmin` – a minimum vertex cover (|Cmin| = M).

If we are able to build a vertex cover of size `|C| = n – k`,
its complement is an independent set of size `k`.

*We can enlarge a vertex cover by adding arbitrary vertices – it stays a
cover.*  
Therefore a cover of any size `s` with `M ≤ s ≤ n` exists.

Hence a required independent set exists **iff**

```
k ≤ n – M          (1)
```

--------------------------------------------------------------------

#### 3.   Algorithm
```
1. read the graph
2. colour it (0 / 1) by BFS → bipartition L (colour 0) , R (colour 1)
3. run Hopcroft‑Karp on the bipartite graph → maximum matching, size M
4. build a minimum vertex cover Cmin from the matching
       (standard alternating‑path construction)
5. if k > n – M :  answer NO
   else
        target = n – k                # desired cover size
        C = Cmin
        add arbitrary vertices not in C until |C| = target
        I = V \ C                     # independent set, |I| = k
        answer YES and output I
```

All steps are linear or `O(E·√V)` (Hopcroft‑Karp), well inside the limits.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
The input graph is bipartite and the colouring performed in step&nbsp;2
produces a proper bipartition `L, R`.

**Proof.**  
The given property forbids an edge between two vertices that can be
reached from each other by an even‑length walk.
If a graph contained an odd cycle, pick any vertex `X` on the cycle.
Walking two edges along the cycle reaches a neighbour of `X` by an even
walk, contradicting the property.
Thus the graph has no odd cycle → it is bipartite.
BFS colours neighbours with opposite colours, therefore the obtained
colouring is a proper bipartition. ∎



##### Lemma 2  
After step&nbsp;3 `M` equals the size of a maximum matching of the input
graph.

**Proof.**  
Hopcroft‑Karp is a classic algorithm that always returns a maximum
matching for bipartite graphs. By Lemma&nbsp;1 the graph is bipartite,
hence the returned matching is maximum. ∎



##### Lemma 3  
The set `Cmin` constructed in step&nbsp;4 is a minimum vertex cover and
`|Cmin| = M`.

**Proof.**  
The construction is the standard one:

* start from all unmatched vertices of the left side,
* follow **unmatched** edges `L → R` and **matched** edges `R → L`,
* let `Z` be the set of vertices reachable this way,
* then `Cmin = (L \ Z) ∪ (R ∩ Z)`.

König’s theorem proves that this set is a vertex cover of size exactly
the size of the maximum matching `M`, and that no smaller cover exists.
∎



##### Lemma 4  
If `k ≤ n – M` the algorithm produces a vertex cover `C` of size `n – k`.

**Proof.**  
`C` is built from `Cmin` (size `M`) by repeatedly adding vertices that are
not yet in `C`. Adding vertices never destroys the covering property,
so after the loop finishes `C` is still a vertex cover.
The loop stops exactly when `|C| = n – k`. ∎



##### Lemma 5  
If `k ≤ n – M` the set `I = V \ C` output by the algorithm is an
independent set of size `k`.

**Proof.**  
`C` is a vertex cover, therefore every edge has at least one endpoint in
`C`. No edge can have both endpoints in `V \ C = I`; consequently `I`
contains no edge – it is independent.
By Lemma&nbsp;4 `|C| = n – k`, thus `|I| = n – |C| = k`. ∎



##### Lemma 6  
If `k > n – M` no independent set of size `k` exists.

**Proof.**  
Assume an independent set `I` of size `k` existed.
Its complement `C = V \ I` would be a vertex cover of size `n – k`.
Because `M` is the size of a *minimum* vertex cover (Lemma&nbsp;3),
`n – k = |C| ≥ M` ⇒ `k ≤ n – M`, contradicting the assumption. ∎



##### Theorem  
The algorithm prints  

*`YES` and a valid set of `k` modules* **iff** such a set exists,
otherwise it prints `NO`.

**Proof.**  

*If part.*  
When the algorithm prints `YES`, we have `k ≤ n – M` (otherwise it would
have printed `NO`). By Lemma&nbsp;5 the printed set is an independent set
of size `k`. Hence a valid selection exists.

*Only‑if part.*  
If a valid selection exists, an independent set of size `k` exists.
By Lemma&nbsp;6 this implies `k ≤ n – M`. The algorithm therefore does
not output `NO` and proceeds to construct a set as described.
By Lemma&nbsp;5 the produced set is a valid selection, so the algorithm
outputs `YES`. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Colouring* – `O(n + m)`  
*Hopcroft‑Karp* – `O(m·√n)` ( ≤ `4·10⁵·√10⁵` ≈ `1.3·10⁸` operations, fast in C/PyPy)  
*Minimum cover construction* – `O(n + m)`  
*Final augmentation* – `O(n)`

Memory consumption: adjacency lists `O(n + m)`, several integer arrays
`O(n)`. All well below the limits.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    # 1) bipartition
    color = [-1] * (n + 1)          # 0 = left, 1 = right
    left_nodes = []
    right_nodes = []
    for start in range(1, n + 1):
        if color[start] != -1:
            continue
        q = deque([start])
        color[start] = 0
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
        # after BFS component coloured
    for v in range(1, n + 1):
        if color[v] == 0:
            left_nodes.append(v)
        else:
            right_nodes.append(v)

    # 2) Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [0] * (n + 1)   # left -> right
    pairV = [0] * (n + 1)   # right -> left
    dist = [0] * (n + 1)

    def bfs() -> bool:
        q = deque()
        for u in left_nodes:
            if pairU[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        d_augment = INF
        while q:
            u = q.popleft()
            if dist[u] >= d_augment:
                continue
            for v in adj[u]:
                if pairV[v] == 0:
                    d_augment = dist[u] + 1
                elif dist[pairV[v]] == INF:
                    dist[pairV[v]] = dist[u] + 1
                    q.append(pairV[v])
        return d_augment != INF

    def dfs(u: int) -> bool:
        for v in adj[u]:
            if pairV[v] == 0 or (dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v])):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in left_nodes:
            if pairU[u] == 0 and dfs(u):
                matching += 1

    # 3) minimum vertex cover from the matching
    visL = [False] * (n + 1)
    visR = [False] * (n + 1)
    q = deque()
    for u in left_nodes:
        if pairU[u] == 0:
            q.append(u)
            visL[u] = True
    while q:
        u = q.popleft()          # u is left
        for v in adj[u]:
            if not visR[v] and pairU[u] != v:   # edge not in matching
                visR[v] = True
                pu = pairV[v]
                if pu != 0 and not visL[pu]:
                    visL[pu] = True
                    q.append(pu)

    cover = set()
    for u in left_nodes:
        if not visL[u]:
            cover.add(u)
    for v in right_nodes:
        if visR[v]:
            cover.add(v)

    min_cover_size = len(cover)
    # 4) feasibility test
    if k > n - min_cover_size:
        print("NO")
        return

    target = n - k                     # desired cover size
    # enlarge cover arbitrarily
    if len(cover) < target:
        for v in range(1, n + 1):
            if v not in cover:
                cover.add(v)
                if len(cover) == target:
                    break

    independent = [str(v) for v in range(1, n + 1) if v not in cover]
    # independent size must be exactly k
    independent = independent[:k]

    print("YES")
    print(" ".join(independent))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
