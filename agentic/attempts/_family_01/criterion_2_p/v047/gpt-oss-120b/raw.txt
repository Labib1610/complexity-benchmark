**Solution Explanation**

For every incompatibility `(u , v)` the two staff members must work in different
periods.
Therefore we have to 2‑colour the given undirected graph:

* colour `1`  → period 1  
* colour `2`  → period 2  

The other two conditions of the statement are always satisfied
(`∑ degree = 2m` and every edge is counted once), so the whole problem is
exactly the bipartite‑checking problem.

If the graph is bipartite there are two possible colourings for each connected
component – they differ only by swapping the two colours.
To obtain the **lexicographically smallest** sequence
`c1 c2 … cn` (with `1 < 2`) we can decide independently for every component:

* choose the smallest numbered vertex of the component and colour it `1`,
  the rest of the component follows uniquely.

Because swapping colours would turn that smallest vertex into `2`,
the chosen orientation is always the better (or equal) one for the global
lexicographic order.

So the algorithm is:

```
for v = 1 … n
    if v is not coloured yet
        start BFS/DFS from v
        colour v with 1
        propagate opposite colours to neighbours
        if a conflict appears → graph not bipartite → answer NO
output YES and the obtained colours
```

`O(n+m)` time, `O(n+m)` memory – easily fits the limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
valid allocation iff such an allocation exists.

---

##### Lemma 1  
If the algorithm finishes without conflict, the produced colouring assigns
different colours to the ends of every edge.

**Proof.**  
During BFS/DFS each visited edge `(x , y)` is processed exactly once.
When `x` gets a colour, the algorithm forces `y` to receive the opposite colour.
If later `y` is reached again, the algorithm checks that the already assigned
colour equals the required opposite colour; otherwise a conflict would be
detected. Hence every edge connects vertices of different colours. ∎



##### Lemma 2  
If the algorithm reports a conflict, the input graph is not bipartite.

**Proof.**  
A conflict appears only when an edge `(x , y)` is examined and both ends already
have the same colour. Any 2‑colouring must give opposite colours to the ends of
an edge, therefore no proper 2‑colouring exists. ∎



##### Lemma 3  
Assume the graph is bipartite. For each connected component the algorithm
colours the smallest‑indexed vertex of that component with colour 1.

**Proof.**  
The outer loop visits vertices in increasing order.
When the first vertex `v` of a component is encountered, it is still uncoloured,
so the algorithm starts a search from `v` and explicitly sets `colour[v]=1`. ∎



##### Lemma 4  
Let `C` be a connected component of a bipartite graph.
Among the two possible proper colourings of `C`,
the one that gives the smallest vertex of `C` colour 1 is lexicographically
not larger than the other one (and strictly smaller if the component size > 1).

**Proof.**  
Both colourings are identical except that all colours are swapped.
Thus the colour of the smallest vertex decides which colouring is smaller:
`1` is smaller than `2`. ∎



##### Lemma 5  
If the graph is bipartite, the colouring produced by the algorithm is the
lexicographically smallest among all proper colourings of the whole graph.

**Proof.**  
Consider the vertices in order `1 … n`.  
Take the first vertex `v` where the algorithm’s colouring could differ from
some other proper colouring `C'`.  
`v` belongs to a component `K`. By Lemma&nbsp;3 the algorithm colours `v` with `1`.  
If `C'` also uses `1` for `v`, the colourings are equal up to `v`.  
If `C'` uses `2` for `v`, then `C'` must be the opposite orientation of `K`
(because a component has only two colourings). By Lemma&nbsp;4 this orientation
is lexicographically larger. Hence no proper colouring is lexicographically
smaller than the algorithm’s one. ∎



##### Lemma 6  
If the graph is bipartite, the algorithm outputs a valid allocation.

**Proof.**  
By Lemma&nbsp;1 the produced colouring respects all edges, i.e. satisfies the
only real requirement of the problem. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no safe allocation exists,  
* otherwise `YES` and the lexicographically smallest safe allocation.

**Proof.**  

*If the algorithm prints `NO`.*  
A conflict was detected, therefore by Lemma&nbsp;2 the graph is not bipartite,
hence no proper 2‑colouring exists, i.e. no safe allocation exists.

*If the algorithm prints `YES`.*  
No conflict occurred, so the graph is bipartite. By Lemma&nbsp;6 the printed
colouring is a safe allocation. By Lemma&nbsp;5 it is the lexicographically
smallest among all safe allocations.

Conversely, if a safe allocation exists, the graph is bipartite, the algorithm
never meets a conflict and therefore prints `YES` with the smallest allocation.
∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency lists*: `O(n+m)` time, `O(n+m)` memory.  
*BFS/DFS over all components*: each vertex and edge is processed once →  
`O(n+m)` time, `O(n)` extra memory for the queue/stack and colour array.

Total: **`O(n+m)` time, `O(n+m)` memory**.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [0] * (n + 1)          # 0 = unvisited, 1 or 2 otherwise
    q = deque()

    for start in range(1, n + 1):
        if colour[start]:
            continue
        # start new component, give smallest vertex colour 1
        colour[start] = 1
        q.append(start)
        while q:
            v = q.popleft()
            cv = colour[v]
            nxt = 2 if cv == 1 else 1
            for nb in adj[v]:
                if colour[nb] == 0:
                    colour[nb] = nxt
                    q.append(nb)
                elif colour[nb] != nxt:
                    # conflict -> not bipartite
                    sys.stdout.write("NO")
                    return

    # all good
    sys.stdout.write("YES\n")
    sys.stdout.write(' '.join(str(colour[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
