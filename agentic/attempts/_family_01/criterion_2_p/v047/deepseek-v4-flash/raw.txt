We can model this as a graph problem.  
The conditions imply:

- The graph must be bipartite (no odd cycles), because incompatible pairs must be in different periods.
- The sum condition simplifies to:  
  \[
  \sum_{x \in P_1} c_x + \sum_{y \in P_2} c_y = 2m
  \]  
  But since each edge contributes 1 to the degree of each endpoint,  
  \[
  \sum_{i=1}^n c_i = 2m
  \]  
  So the condition is automatically satisfied for any partition.  
- The condition \(k = m\) means every edge must be between different periods — which is exactly the bipartite condition.

Thus, we just need to check if the graph is bipartite, and if so, output the lexicographically smallest 2-coloring (with 1 and 2).

To get lexicographically smallest, we assign period 1 to the smallest possible nodes first, using BFS/DFS with priority to 1.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

# Convert to 1-based periods: 0 -> 1, 1 -> 2
res = [1 if c == 0 else 2 for c in color]
print("YES")
print(" ".join(map(str, res)))
```
