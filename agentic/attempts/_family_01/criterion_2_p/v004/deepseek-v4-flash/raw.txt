We can model this as a bipartite graph problem: each worker is a node, and each conflict is an edge.  
We need to assign each node to one of two shifts (1 or 2) such that no edge connects two nodes with the same shift.  
That’s exactly checking if the graph is bipartite, and if so, finding the lexicographically smallest 2-coloring.

We’ll use BFS/DFS to color the graph, trying shift 1 first for each unvisited node to get the lexicographically smallest assignment.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0  # shift 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
