We need to check if the graph is bipartite and, if so, output a valid 2-coloring in lexicographically smallest order.

A simple approach:

- Build adjacency list.
- BFS/DFS to check bipartiteness, assigning colors 1 and 2.
- Since we want lexicographically smallest labeling where color 1 is first possible, we must start every connected component with color 1 if possible, and for any unvisited node we assign color 1 first.
- But careful: for a connected component, after picking color 1 for the root, the rest is determined (up to flip). If flipping gives a lexicographically smaller sequence, we must choose the flip that is smaller at the first differing position.

Simplest robust method: For each component, try both colorings (root = 1 or root = 2), and pick the one that gives lexicographically smaller full vector for that component once all components are merged. But comparing entire vectors per component can be done by comparing the two alternatives directly per component.

Implementation plan:

1. Read n, m.
2. Build adjacency list.
3. visited array of -1 (uncolored).
4. For each node i from 1 to n:
   - if not visited:
     - BFS/DFS from i, assign colors starting with i = 1.
     - If conflict → NO.
     - Collect component nodes.
     - After BFS, we have two possible colorings: the one we got, and the flipped one (swap 1↔2).
     - To choose lexicographically smaller for the whole solution, we need to compare the two assignments for this component (only relative to the nodes in this component). Since components are independent, picking the smaller one per component yields the globally lexicographically smallest (because earlier nodes in the sequence come from earlier components as we iterate in node order).
     - So: build arrays comp_assign1 and comp_assign2, then decide which is lexicographically smaller. The nodes are ordered by index. So we can simply iterate through sorted component nodes and compare colors.
     - Assign the better one to the global colors array.
5. If any conflict → print NO.
6. Otherwise print YES and the colors.

Complexity O(n+m).

Now write code.

Edge cases: m=0, all singletons => color 1.

import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * n
    answer = [0] * n

    for start in range(n):
        if color[start] != -1:
            continue

        # BFS component
        q = deque([start])
        color[start] = 0  # 0 and 1 internally, we'll map to 1 and 2 later
        comp = [start]
        possible = True

        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    comp.append(v)
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break

        if not possible:
            print("NO")
            return

        # Try both colorings for this component (root 0 or root 1)
        # comp is already with root 0.
        # Flip: root 1
        comp_sorted = sorted(comp)

        # Compare two assignments lexicographically for this component
        # Assignment A: as we have (root=0)
        # Assignment B: flipped
        better = None
        for node in comp_sorted:
            ca = color[node]  # 0 or 1
            cb = 1 - color[node]  # flip
            # map 0->1, 1->2
            a_val = ca + 1
            b_val = cb + 1
            if a_val < b_val:
                better = "A"
                break
            elif b_val < a_val:
                better = "B"
                break
        if better is None:
            better = "A"  # they are all equal? Actually for a 2-coloring, flip gives opposite values, so there will be diff at first node. But safe.

        # Assign
        for node in comp:
            if better == "A":
                colors[node] = color[node] + 1
            else:
                colors[node] = (1 - color[node]) + 1

    print("YES")
    print(' '.join(map(str, colors)))

if __name__ == "__main__":
    solve()
