To solve this problem, we need to determine if the given graph is bipartite (can be colored with two colors such that no two adjacent nodes have the same color). If it is bipartite, we need to find the lexicographically smallest valid coloring, where color 1 is preferred over color 2, and nodes are processed in order from 1 to n.

### Approach
1. **Graph Representation**: Represent the graph using an adjacency list. Since the graph is undirected, each edge (u, v) should be added in both directions.
2. **Bipartite Check**: Use a BFS approach to check if the graph is bipartite. For each node, if it hasn't been colored yet, start BFS from that node, assigning it color 1. For each adjacent node, assign the opposite color. If at any point an adjacent node has the same color as the current node, the graph is not bipartite, and we return "NO".
3. **Lexicographically Smallest Coloring**: To ensure the lexicographically smallest coloring, we process nodes in order from 1 to n. For each node, if it hasn't been colored, we start BFS from it, assigning color 1. This ensures that the smallest node in each connected component gets color 1, and subsequent nodes are colored in a way that prefers color 1 whenever possible.

### Solution Code
```python
import sys
from collections import deque

def solve():
    input = sys.stdin.read().split()
    ptr = 0
    n, m = map(int, input[ptr:ptr+2])
    ptr +=2
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v = map(int, input[ptr:ptr+2])
        ptr +=2
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0]*(n+1)
    possible = True
    
    for i in range(1, n+1):
        if color[i] == 0:
            queue = deque()
            queue.append(i)
            color[i] = 1
            while queue and possible:
                current = queue.popleft()
                for neighbor in adj[current]:
                    if color[neighbor] == 0:
                        color[neighbor] = 3 - color[current]
                        queue.append(neighbor)
                    elif color[neighbor] == color[current]:
                        possible = False
                        break
                if not possible:
                    break
            if not possible:
                break
    
    if not possible:
        print("NO")
    else:
        print("YES")
        print(' '.join(map(str, color[1:n+1])))

solve()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Graph Construction**: The adjacency list `adj` is built from the input edges, representing the undirected graph.
3. **Bipartite Check**: The algorithm iterates over each node. If a node hasn't been colored, it starts a BFS from that node, coloring it with 1. Each adjacent node is colored with the opposite color (2 if the current node is 1, and vice versa). If a conflict is found (adjacent nodes with the same color), the graph is not bipartite, and "NO" is printed.
4. **Output**: If the graph is bipartite, "YES" is printed followed by the color assignments for each node from 1 to n. The BFS ensures that nodes are processed in order, and each node is colored with the smallest possible value (1) first, ensuring the lexicographically smallest solution.

This approach efficiently checks for bipartiteness and constructs the lexicographically smallest coloring by leveraging BFS and processing nodes in ascending order.
