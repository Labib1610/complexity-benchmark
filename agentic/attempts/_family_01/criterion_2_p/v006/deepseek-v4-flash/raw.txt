We can model the arms as vertices and the overlapping pairs as edges in a graph.  
The condition “no two connected vertices can have the same grid” is exactly a **bipartite** check.  
We can solve it with BFS, assigning colors 1 and 2 alternately.  

If we find a conflict → output `NO`.  
Otherwise output the coloring.  

To get the lexicographically smallest assignment, always start unvisited nodes with color `1`.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 1
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]  # alternate between 1 and 2
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
