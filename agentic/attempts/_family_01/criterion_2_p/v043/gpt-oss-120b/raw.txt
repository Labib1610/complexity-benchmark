**Solution Explanation**

For every constraint `{u , v}` we need  

```
value[u] + value[v] = 3 ,   value[x] ∈ {1,2}
```

Therefore the two satellites must receive *different* values  
(`1` together with `2`).  
The whole set of constraints is a graph whose edges demand opposite
values → the graph must be *bipartite*.
If it is not bipartite there is no configuration.

If the graph is bipartite, each connected component has exactly two
possible assignments:
* side A gets `1`, side B gets `2`
* side A gets `2`, side B gets `1`

We have to output the **lexicographically smallest** whole array.
Lexicographic order is decided by the first position where two arrays differ.
Hence, for each component we only have to look at the smallest‑indexed
vertex belonging to that component:

*If we give that vertex value `1`, the whole array becomes not larger
than any array where it would receive `2` (all earlier positions are equal).*

Thus the optimal rule is:

```
for every component:
    let r = smallest vertex index in the component
    if colour[r] == 0:   # colour is the bipartite side obtained by BFS
         side 0 → 1 , side 1 → 2
    else:
         side 1 → 1 , side 0 → 2
```

The algorithm:

1. Build adjacency lists.
2. `colour[i] = -1` (unvisited).  
   For each vertex `i` not visited:
   * BFS/DFS, colour neighbours with opposite colour.
   * If a conflict appears → graph not bipartite → print `NO`.
   * Store all vertices of this component in a list `comp`.
   * After the BFS, find `r = min(comp)`.
   * Decide which colour gets value `1` as described above and fill the
     answer array.
3. After processing all components print `YES` and the answer.

`n, m ≤ 2·10⁵`, BFS runs in `O(n+m)` time, memory `O(n+m)`.

---

#### Correctness Proof  

We prove that the algorithm outputs `YES` with the lexicographically
smallest feasible assignment iff such an assignment exists.

---

##### Lemma 1  
If the algorithm reports a conflict during BFS, the constraint graph is
not bipartite, therefore no assignment satisfying all constraints exists.

**Proof.**  
A conflict means an edge `{u,v}` with `colour[u] == colour[v]`.  
BFS always colours neighbours with opposite colours, so equal colours on an
edge imply an odd cycle, i.e. the graph is not bipartite.
Any feasible assignment must give opposite values to the ends of every
edge, which is exactly a 2‑colouring. Hence no feasible assignment exists. ∎



##### Lemma 2  
If the algorithm finishes without conflict, the produced values satisfy
all constraints.

**Proof.**  
For each component the BFS produced a proper 2‑colouring:
adjacent vertices have different colours.
The algorithm assigns the same numeric value (`1` or `2`) to all vertices
of one colour and the opposite value to the other colour.
Thus for every edge its endpoints receive different numbers, i.e.
their sum is `1+2 = 3`. ∎



##### Lemma 3  
For a fixed component, among the two possible assignments the algorithm
chooses the one that is lexicographically smallest for the whole array,
provided the values of all earlier indices (outside the component) are
already fixed.

**Proof.**  
Let `r` be the smallest index in the component.
All indices `< r` belong to earlier components, already fixed.
The two possible assignments differ exactly on the whole component;
in particular they differ on position `r`:
one gives `1`, the other gives `2`.
Since `1 < 2`, the assignment giving `1` at `r` is lexicographically
smaller, independent of later positions. The algorithm gives `1` to the
colour containing `r`, therefore it selects the smaller of the two. ∎



##### Lemma 4  
Processing components in increasing order of their smallest vertex
produces the globally lexicographically smallest feasible array.

**Proof.**  
Consider the first index `i` where two feasible arrays differ.
`i` belongs to some component `C`. All components whose smallest vertex is
`< i` are identical in both arrays (they were processed earlier and have a
unique optimal choice by Lemma&nbsp;3).  
Within `C`, by Lemma&nbsp;3 the algorithm picks the assignment that gives
value `1` to the smallest vertex of `C`, which is exactly the smaller of the
two possibilities at position `i`. Hence no other feasible array can be
lexicographically smaller. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no feasible configuration exists;
* otherwise `YES` and the lexicographically smallest feasible configuration.

**Proof.**  
*If the algorithm outputs `NO`* – this happens only when a conflict is
detected. By Lemma&nbsp;1 no feasible configuration exists.

*If a feasible configuration exists* – the graph is bipartite, so BFS never
conflicts. By Lemma&nbsp;2 the algorithm’s assignment satisfies all
constraints. By Lemma&nbsp;4 it is the lexicographically smallest among
all feasible assignments. Hence the algorithm outputs `YES` and the
required array. ∎



---

#### Complexity Analysis  

*Building adjacency lists*: `O(n+m)` time, `O(n+m)` memory.  
*BFS over all components*: each vertex and edge visited once → `O(n+m)` time,
`O(n)` extra memory for colour array and component list.  

Total: **Time `O(n+m)`**, **Memory `O(n+m)`**, well within limits.

#### Reference Implementation (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 bipartite colour
    ans = [0] * (n + 1)              # final values (1-indexed)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        ok = True
        while q:
            u = q.popleft()
            cu = colour[u]
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = cu ^ 1
                    q.append(v)
                    comp.append(v)
                elif colour[v] == cu:
                    print("NO")
                    return
        # decide mapping to values 1/2
        r = min(comp)               # smallest index in component
        # side containing r gets value 1
        side_one = colour[r]        # colour that will be mapped to 1
        for v in comp:
            ans[v] = 1 if colour[v] == side_one else 2

    # all components processed without conflict
    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
