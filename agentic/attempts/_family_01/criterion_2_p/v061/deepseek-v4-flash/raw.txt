We can treat this as a graph problem. Since shifts are only `1` or `2` and linked employees must differ by exactly 1, their shifts must be opposite.  
So each edge means the two nodes must have different colors.

That makes this a **bipartite graph checking** problem. If the graph is not bipartite, output `NO`.  
If it is bipartite, we assign colors and then try to make the lexicographically smallest assignment.

A standard way:  
- Use BFS/DFS and assign colors `1` or `2`.  
- When assigning, always try to assign the smaller available value (1) first.

Here's the code:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 1  # start with 1 for lexicographic smallest
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]  # opposite
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
