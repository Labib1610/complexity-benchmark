We need to check if the graph is bipartite and, if so, produce the lexicographically smallest 2-coloring (with colors 1 and 2).

The key point:  
- If the graph is not bipartite → output `NO`.  
- If bipartite → we want the lexicographically smallest assignment of 1/2 to vertices 1..n.

A standard BFS/DFS coloring gives *a* valid 2-coloring, but not necessarily the lexicographically smallest.  
To get the lexicographically smallest, we can try to assign color 1 to vertex 1 if possible, then proceed greedily.

A known approach:  
- For each vertex in order 1..n, if it’s uncolored, try to color it 1 and BFS/DFS to color its component. If conflict occurs, try color 2.  
- But we must be careful: if we start with color 1 for a component and it fails, we must try color 2 for that component.  
- However, if the component is already partially colored from previous steps, we must respect that.

We can implement it as follows:

1. Build adjacency list.
2. Initialize color array with -1 (uncolored).
3. For each vertex i from 1 to n:
   - If uncolored, try to color it 1 and BFS/DFS to color its component.
   - If conflict, try color 2 and BFS/DFS.
   - If both fail → output NO.
4. Output YES and the color array.

This greedy works because we process vertices in order and always try the smaller color first.

Let's write the code.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start, col):
    q = deque([start])
    color[start] = col
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        # try color 1
        temp = color[:]
        color[i] = 1
        q = deque([i])
        ok = True
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break
            if not ok:
                break
        if not ok:
            # revert and try color 2
            color = temp
            color[i] = 2
            q = deque([i])
            ok = True
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 1 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        ok = False
                        break
                if not ok:
                    break
            if not ok:
                print("NO")
                sys.exit()
        # else keep color 1 assignment

print("YES")
print(' '.join(str(c) for c in color))
```
