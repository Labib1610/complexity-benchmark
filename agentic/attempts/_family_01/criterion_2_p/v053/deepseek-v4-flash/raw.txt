We can model this as a bipartite graph problem. Each gear is a node, and each interacting pair is an edge. We need to assign each node either 1 or 2 such that no edge connects two nodes with the same value. This is exactly checking if the graph is bipartite, and if so, producing the lexicographically smallest coloring (with 1 preferred over 2).

We’ll do a BFS/DFS over each connected component, assigning colors greedily, starting with 1, and if a conflict occurs, the graph is not bipartite → output `NO`.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 1
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
