**Solution Explanation**

For every tower we have to choose frequency `1` or `2`.
If two towers interfere they must receive different frequencies.
The interference graph is therefore required to be *bipartite*.
If it is not bipartite the answer is “NO”.

If it is bipartite there are exactly two colourings for each connected
component – the two colour classes may be exchanged.
Among all global colourings we have to output the **lexicographically
smallest** one, i.e. the smallest possible sequence  

```
f1 f2 … fn          (fi ∈ {1,2})
```

--------------------------------------------------------------------

#### 1.   Observations

* In one component the two possible colourings differ only by swapping the
  two colour classes.
* Lexicographic order is decided by the first position where the two
  assignments differ.
* The first vertex of a component (the vertex with the smallest index in this
  component) appears earlier in the whole sequence than any other vertex of
  the same component.
* Therefore, for a component we should give colour `1` to its smallest‑index
  vertex – any other choice would make the whole sequence larger,
  no matter how the remaining vertices are coloured.

Consequences  

* Process each connected component independently.
* Choose an arbitrary start vertex, colour the component with colours `0/1`
  (any bipartite 2‑colouring).
* Let `vmin` be the smallest index inside this component.
  If `colour[vmin] == 0` we keep the colours,
  otherwise we flip all colours inside the component.
  After that `vmin` receives colour `1`.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n, m
build adjacency list

colour[1…n] = -1               # -1 = not visited, else 0 or 1
answer[1…n] = 0

for vertex i = 1 … n
    if colour[i] == -1
        start BFS/DFS from i
        store all visited vertices of this component in list comp
        during the search assign provisional colours 0/1
        if a conflict (edge between equal colours) occurs → print NO and exit

        vmin = minimum vertex id in comp
        need_flip = colour[vmin]            # 0 → keep, 1 → flip

        for each vertex v in comp
            final = 1 + (colour[v] ^ need_flip)   # 0→1, 1→2 after possible flip
            answer[v] = final

print YES
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints “NO” iff no valid assignment exists,
otherwise it prints the lexicographically smallest valid assignment.

---

##### Lemma 1  
During the BFS of a component the algorithm assigns provisional colours
`0/1` exactly when the component is bipartite; otherwise it detects a conflict.

**Proof.**  
Standard bipartite BFS: the start vertex receives colour `0`.
Whenever we traverse an edge `(u,v)` we set `colour[v] = colour[u] xor 1`.
If we ever meet an already coloured neighbour with the same colour,
the edge connects two vertices of the same colour, which contradicts
bipartiteness. Conversely, if the component is bipartite, this never
happens and the algorithm finishes with a proper 2‑colouring. ∎



##### Lemma 2  
For a bipartite component `C` let `vmin` be its smallest numbered vertex.
After the *orientation step* (`need_flip = colour[vmin]`) the algorithm
assigns colour `1` to `vmin` and produces a valid 2‑frequency assignment for
all vertices of `C`.

**Proof.**  
If `colour[vmin] = 0` then `need_flip = 0` and each vertex `v`
receives `1 + colour[v]`.  
If `colour[vmin] = 1` then `need_flip = 1`; each vertex receives  
`1 + (colour[v] xor 1)`, i.e. colour `0` becomes `2` and `1` becomes `1`.  
Thus the colour of `vmin` becomes `1` in both cases.
All edges join vertices whose provisional colours differ,
hence after (possible) flipping they still differ. ∎



##### Lemma 3  
Among all valid assignments for a component `C`,
the assignment produced by the algorithm is lexicographically smallest
when restricted to the vertices of `C`.

**Proof.**  
The first vertex of `C` in the global order is `vmin`.  
Any valid assignment must give `vmin` either colour `1` or `2`.  
If it receives `2`, the whole global sequence is already larger than the
algorithm’s assignment (which gives `1`).  
If it receives `1`, the remaining vertices of `C` must respect the bipartite
alternation, i.e. they are uniquely determined – exactly the colouring
chosen by the algorithm (the unique colouring consistent with `vmin = 1`). ∎



##### Lemma 4  
Let the algorithm finish without reporting “NO”.  
The concatenation of the component assignments is the lexicographically
smallest valid assignment for the whole graph.

**Proof.**  
Consider the vertices in order `1 … n`.  
When we first encounter a vertex belonging to a component `C`,
the algorithm has already decided the orientation of `C` (during the first
visit of that component).  
By Lemma&nbsp;3 this orientation gives the smallest possible colour at the
first vertex of `C`.  
All earlier vertices belong to already processed components, whose
orientations are already optimal (by the same argument).  
Therefore no other global assignment can be smaller at the first position
where the two assignments differ. ∎



##### Lemma 5  
If the algorithm prints “NO”, no valid assignment exists.

**Proof.**  
“NO” is printed only when Lemma&nbsp;1 detects a conflict, i.e. an edge whose
endpoints received the same provisional colour.
Any 2‑colouring of the component would have to give different colours to
the endpoints, contradicting the presence of an odd cycle.
Thus the component, and consequently the whole graph, is not bipartite,
so a valid frequency assignment does not exist. ∎



##### Theorem  
The algorithm outputs  

* “NO” **iff** the interference graph cannot be coloured with two frequencies,  
* otherwise “YES” followed by the lexicographically smallest feasible
  frequency assignment.

**Proof.**  
*If* the algorithm prints “NO”, by Lemma&nbsp;5 the graph is not bipartite,
hence no assignment exists.

*Only‑if* the graph is not bipartite, some component contains an odd cycle.
During its BFS a conflict inevitably appears, so the algorithm prints “NO”.

If the algorithm finishes without conflict, every component is bipartite,
and Lemma&nbsp;2 gives a valid assignment for each component.
By Lemma&nbsp;4 the concatenation of those component assignments is the overall
lexicographically smallest feasible assignment.
Thus the printed answer satisfies the specification. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and each edge is processed once →  
`O(n + m)` time, `O(n)` extra memory for colour arrays and component list.

Overall  

```
Time   :  O(n + m)   ≤ 4·10⁵
Memory :  O(n + m)   ≤ 4·10⁵
```

Both fit easily into the limits.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # provisional 0/1
    answer = [0] * (n + 1)           # final 1/2

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # start new component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        ok = True
        while q:
            u = q.popleft()
            cu = colour[u]
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = cu ^ 1
                    q.append(v)
                    comp.append(v)
                elif colour[v] == cu:
                    # not bipartite
                    print("NO")
                    return
        # decide orientation
        vmin = min(comp)
        need_flip = colour[vmin]          # 0 -> keep, 1 -> flip
        for v in comp:
            answer[v] = 1 + (colour[v] ^ need_flip)

    # all components processed, graph bipartite
    out = ['YES', ' '.join(str(answer[i]) for i in range(1, n + 1))]
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

to the required input / output format.
