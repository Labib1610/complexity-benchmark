We can model this as a bipartite graph problem: each tower is a node, and each interfering pair is an edge. We need to color the graph with two colors (frequencies 1 and 2) such that no two adjacent nodes share the same color. This is possible if and only if the graph is bipartite.

We also need the lexicographically smallest assignment, so we assign frequency 1 to the first node and propagate colors via BFS/DFS, choosing the smallest possible color at each step.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
