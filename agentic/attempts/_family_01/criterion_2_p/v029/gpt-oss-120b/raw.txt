**Solution Explanation**

For every person we have to choose one of two roles `1` or `2`.
For each given incompatible pair `(u , v)` the two persons must obtain
different roles.

The incompatibility graph is undirected.
The task is exactly the *bipartite‑graph 2‑colouring* problem,
plus the requirement that among all possible colourings we have to output
the lexicographically smallest one
(`s1 s2 … sn` with `si ∈ {1,2}`).

--------------------------------------------------------------------

#### 1.   Observations  

* A connected component of a bipartite graph has **exactly two**
  valid colourings – they are obtained from each other by swapping the
  two colours.
* Different components are independent, we may choose the orientation
  of each component separately.
* Lexicographic order compares the sequence from left to right.
  The first position where two colourings differ belongs to some
  component, namely the component that contains the smallest index
  still not fixed.
  Making that vertex colour `1` is always better (or equal) than colour
  `2`, and it does not influence any earlier vertex because they belong
  to other components.

Therefore the optimal strategy is:

*For every connected component set the smallest numbered vertex of this
component to colour `1` (if the component is bipartite).*

If a component is not bipartite, the whole instance is impossible.

--------------------------------------------------------------------

#### 2.   Algorithm  

```
read n , m
build adjacency list

colour[1..n] = -1          # 0 / 1 = side inside a component
answer[1..n] = 0           # final 1 / 2

for v = 1 .. n:
    if colour[v] != -1: continue          # already processed

    # ---- BFS of one component ----
    queue = [v]
    colour[v] = 0                         # arbitrary side
    component = []                        # vertices of this component
    while queue not empty:
        x = queue.pop()
        component.append(x)
        for y in adj[x]:
            if colour[y] == -1:
                colour[y] = colour[x] ^ 1
                queue.append(y)
            elif colour[y] == colour[x]:
                print "NO" and exit        # not bipartite

    # ---- choose orientation ----
    # v is the smallest index of this component (we iterate increasing)
    if colour[v] == 0:                    # side 0 will become role 1
        for u in component:
            answer[u] = 1 if colour[u] == 0 else 2
    else:                                 # side 1 becomes role 1
        for u in component:
            answer[u] = 1 if colour[u] == 1 else 2

print "YES"
print answer[1] … answer[n] separated by spaces
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `"NO"` iff no valid assignment exists,
otherwise it prints `"YES"` and the lexicographically smallest valid
assignment.

---

##### Lemma 1  
During the BFS of a component the algorithm detects a conflict
(`colour[y] == colour[x]` for an edge `x‑y`) **iff** the component is not
bipartite.

**Proof.**  
The BFS colours vertices with two sides `0` and `1` exactly as the usual
bipartite test does.
If an edge connects two vertices of the same side, the graph contains an
odd cycle, hence is not bipartite.
Conversely, if the component is not bipartite it contains an odd cycle,
and while traversing that cycle the algorithm will eventually meet an
edge whose ends already have equal colours. ∎



##### Lemma 2  
If the algorithm finishes without printing `"NO"`, the array `answer`
is a valid assignment (no incompatible pair receives the same role).

**Proof.**  
For each component the BFS succeeded, therefore by Lemma&nbsp;1 the
component is bipartite and the stored `colour` values give a proper
2‑colouring: adjacent vertices have opposite `colour`.
When we write `answer`, we either keep the mapping `0→1, 1→2` or swap it,
but in both cases opposite `colour`s become opposite roles.
Thus every edge connects vertices with different roles. ∎



##### Lemma 3  
For every component the algorithm assigns role `1` to its smallest
indexed vertex.

**Proof.**  
Components are processed in increasing order of the first uncoloured
vertex `v`.  
All vertices with index `< v` already belong to earlier components,
hence `v` is the smallest index inside the current component.
If `colour[v] == 0` we map side `0 → 1`; otherwise we map side `1 → 1`.
In both cases `answer[v] = 1`. ∎



##### Lemma 4  
Let `A` be the assignment produced by the algorithm and `B` any other
valid assignment.
Then `A` is lexicographically not larger than `B`.

**Proof.**  
Consider the first position `i` where `A` and `B` differ.
Vertex `i` belongs to some component `C`.  
All vertices with index `< i` belong to components processed earlier,
hence by Lemma&nbsp;3 both assignments give them role `1`.  
Thus `i` is the smallest index of component `C`.  
By Lemma&nbsp;3 `A_i = 1`.  
Since `B` is a valid assignment, it must give either `1` or `2` to `i`.
If `B_i = 1` then `A` and `B` are equal at `i`, contradicting the choice
of `i`. Therefore `B_i = 2` and `A_i < B_i`.  
Consequently `A` is lexicographically smaller than `B`. ∎



##### Lemma 5  
If a valid assignment exists, the algorithm never prints `"NO"`.

**Proof.**  
Assume a valid assignment exists.
Then every connected component of the graph is bipartite
(otherwise the assignment would violate an edge inside a non‑bipartite
component).  
During BFS each component is bipartite, so by Lemma&nbsp;1 no conflict
is found and the algorithm never prints `"NO"`. ∎



##### Theorem  
The algorithm outputs  

* `"NO"` **iff** no valid assignment exists;  
* otherwise `"YES"` followed by the lexicographically smallest valid
  assignment.

**Proof.**  

*If the algorithm prints `"NO"`*: by Lemma&nbsp;1 some component is not
bipartite, therefore no 2‑colouring (and no assignment) exists.

*If a valid assignment exists*: by Lemma&nbsp;5 the algorithm does not
print `"NO"`.  
By Lemma&nbsp;2 the produced `answer` is a valid assignment.  
By Lemma&nbsp;4 it is lexicographically minimal among all valid
assignments. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and each edge is processed once,
`O(n + m)` time.  
*Additional work* (building the answer) is linear in the component size,
overall `O(n)`.

Total  

* **Time** `O(n + m)` ≤ `4·10⁵` operations – well inside the 1 s limit.  
* **Memory** `O(n + m)` for adjacency lists, colour and answer arrays –
  ≤ `~3·10⁶` integers, far below 256 MB.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # 0 / 1 inside a component
    answer = [0] * (n + 1)           # final 1 / 2

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue

        # BFS of this component
        q = deque([start])
        colour[start] = 0
        comp = []                     # vertices of this component
        while q:
            v = q.popleft()
            comp.append(v)
            cv = colour[v]
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    q.append(to)
                elif colour[to] == cv:
                    sys.stdout.write("NO")
                    return

        # orient so that the smallest vertex (== start) gets role 1
        if colour[start] == 0:
            for v in comp:
                answer[v] = 1 if colour[v] == 0 else 2
        else:
            for v in comp:
                answer[v] = 1 if colour[v] == 1 else 2

    out = ["YES", " ".join(str(answer[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
