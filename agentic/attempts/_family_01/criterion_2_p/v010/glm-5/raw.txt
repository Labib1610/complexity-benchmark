To solve this problem, we need to determine if the employees can be divided into two periods such that any two employees sharing a workstation are in different periods. This is essentially a bipartite graph checking problem where employees are nodes and workstations are edges. If the graph is bipartite, we need to find the lexicographically smallest valid assignment.

### Approach
1. **Bipartite Check**: The problem reduces to checking if the graph is bipartite. A graph is bipartite if it can be colored with two colors such that no two adjacent nodes have the same color. This can be checked using a BFS or DFS approach.
2. **Lexicographically Smallest Assignment**: To ensure the assignment is lexicographically smallest, we should process nodes in order from 1 to n. For each node, if it hasn't been colored yet, we start BFS/DFS from that node, assigning it color 1 (the smallest possible). Then, for each adjacent node, we assign the opposite color. This ensures that the earliest nodes get the smallest possible colors, leading to the lexicographically smallest sequence.

### Solution Code
```python
import sys
from collections import deque

def solve():
    input = sys.stdin.read().split()
    ptr = 0
    n, m = map(int, input[ptr:ptr+2])
    ptr +=2
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v = map(int, input[ptr:ptr+2])
        ptr +=2
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0]*(n+1)
    possible = True
    
    for i in range(1, n+1):
        if color[i] == 0:
            queue = deque()
            queue.append(i)
            color[i] = 1
            while queue and possible:
                u = queue.popleft()
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = 3 - color[u]
                        queue.append(v)
                    elif color[v] == color[u]:
                        possible = False
                        break
                if not possible:
                    break
        if not possible:
            break
    
    if not possible:
        print("NO")
    else:
        print("YES")
        print(' '.join(map(str, color[1:n+1])))

solve()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Graph Construction**: An adjacency list is built to represent the graph where each node points to its neighbors (employees sharing a workstation).
3. **Bipartite Check**: Using BFS, each node is processed. If a node hasn't been colored, it is colored with 1, and its neighbors are colored with 2. If during this process, a neighbor is found with the same color as the current node, the graph is not bipartite, and we print "NO".
4. **Lexicographical Order**: By processing nodes from 1 to n and assigning the smallest available color (1) first, the solution ensures the lexicographically smallest valid assignment. The BFS ensures that once a node is colored, its neighbors are processed immediately, maintaining the constraint that adjacent nodes must have different colors.
5. **Output**: If the graph is bipartite, the color assignments are printed from node 1 to n, ensuring the lexicographically smallest sequence.

This approach efficiently checks for bipartiteness while ensuring the solution meets the lexicographical order requirement by processing nodes in ascending order and assigning the smallest valid color first.
