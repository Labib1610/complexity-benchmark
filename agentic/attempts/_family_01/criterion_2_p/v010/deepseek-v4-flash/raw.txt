We can model this as a bipartite graph problem. Each employee is a node, and each workstation is an edge between two employees. We need to check if the graph is bipartite and, if so, produce the lexicographically smallest 2-coloring.

Here’s the approach:

1. Build an adjacency list from the input.
2. Use BFS/DFS to color the graph with two colors (1 and 2).
3. If we find a conflict (an edge connecting two nodes of the same color), output `NO`.
4. Otherwise, output `YES` and the coloring.

To get the lexicographically smallest assignment, we should try to assign color 1 to the smallest-index node whenever possible. This can be done by iterating nodes in order and starting BFS from uncolored nodes with color 1.

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n  # 0 = uncolored, 1 or 2 = period
    
    for i in range(n):
        if color[i] == 0:
            color[i] = 1
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = 3 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
    
    print("YES")
    print(" ".join(str(c) for c in color))

if __name__ == "__main__":
    solve()
```
