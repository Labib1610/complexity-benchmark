We can model this as a bipartite graph problem: each emitter is a node, and each intersection is an edge.  
We need to check if the graph is bipartite. If it is, we can assign colors (1 or 2) to nodes such that no edge connects same-colored nodes.

To get the lexicographically smallest assignment, we run BFS/DFS from each unvisited node, assigning color 1 to the starting node, and alternate colors.  
If we encounter a conflict, the graph is not bipartite → output `NO`.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
