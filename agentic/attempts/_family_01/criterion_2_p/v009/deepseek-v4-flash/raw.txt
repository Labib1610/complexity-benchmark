We need to determine if the conflict graph is bipartite, and if so, produce the lexicographically smallest assignment where shift 1 is preferred for lower indices.

We can do a BFS/DFS coloring with two colors (1 and 2). To get lexicographically smallest, we try to assign 1 whenever possible while respecting the bipartite constraintargest precedence when choosing colors, we can do BFS starting from smallest unvisited node, assigning color 1 if possible.  

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 1
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
