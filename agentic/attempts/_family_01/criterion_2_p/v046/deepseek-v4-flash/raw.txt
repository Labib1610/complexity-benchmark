We can model the workers as nodes in a graph, where each conflict is an edge.  
The condition that conflicting workers must be in different shifts means the graph must be bipartite.  
If it’s not bipartite, we output `NO`.  

If it is bipartite, we want the lexicographically smallest assignment.  
We can do a BFS/DFS coloring, but to get the lexicographically smallest result, we should try to assign shift 1 whenever possible, starting from the smallest index.  

A simple approach:  
- Color the graph using BFS.  
- For each connected component, try to color the smallest-index node as 1, then propagate.  
- If a conflict occurs, try the opposite coloring for that component.  
- If both fail, output `NO`.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start, col):
    q = deque([start])
    color[start] = col
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        # try coloring with 0 first
        tmp = color[:]
        if bfs(i, 0):
            continue
        # if fails, try coloring with 1
        color = tmp
        if not bfs(i, 1):
            print("NO")
            sys.exit()

print("YES")
print(' '.join(str(c + 1) for c in color))
```
