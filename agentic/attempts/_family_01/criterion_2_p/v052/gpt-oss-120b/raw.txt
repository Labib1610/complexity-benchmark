**Solution Explanation**

For every edge `{u,v}` we need  

```
value[u] + value[v] = 3 ,   value[x] ∈ {1,2}
```

Therefore the two endpoints must receive *different* numbers:
`1` together with `2` and vice‑versa.
So the whole graph has to be **bipartite** – its vertices can be coloured with
two colours such that adjacent vertices have opposite colours.
If the graph is not bipartite the required assignment does not exist.

If the graph is bipartite, each connected component has exactly two possible
assignments – we may exchange the two colour classes.
To obtain the lexicographically smallest overall assignment we decide the
orientation of every component independently:

*look at the smallest index vertex inside the component*.
Give this vertex the value `1`.  
All other vertices of the component are forced then.

That rule yields the globally smallest array because the first position where
two possible solutions differ belongs to the smallest‑index vertex of some
component, and we always choose `1` there.

--------------------------------------------------------------------

#### Algorithm
```
read n, m and the edges
build adjacency list

colour[1…n] = -1          // -1 = not visited, 0/1 = bipartite colour
answer[1…n] = 0

for each vertex i = 1 … n
    if colour[i] == -1                     // new component
        BFS/DFS from i
            assign colours 0/1
            collect all vertices of this component in list comp
            if a conflict (edge with equal colours) → print "NO" and stop

        min_v = minimum index in comp
        if colour[min_v] == 0
                for v in comp: answer[v] = 1 if colour[v]==0 else 2
        else
                for v in comp: answer[v] = 1 if colour[v]==1 else 2

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest assignment.

---

##### Lemma 1  
If the algorithm detects a conflict during BFS, the graph is not bipartite,
hence no assignment satisfying all edges exists.

**Proof.**  
A conflict means an edge `{u,v}` with `colour[u] == colour[v]`.  
BFS always colours a neighbour with the opposite colour, therefore such an
edge lies on an odd cycle. A graph containing an odd cycle is not bipartite.
If a graph is not bipartite, it is impossible to give opposite numbers to
both ends of every edge, i.e. no required assignment exists. ∎



##### Lemma 2  
If the algorithm finishes without conflict, the produced `answer` satisfies
`value[u] + value[v] = 3` for every edge.

**Proof.**  
Finishing without conflict means the BFS coloured the whole graph with two
colours such that adjacent vertices have opposite colours – the graph is
bipartite.  
Inside each component the algorithm maps one colour class to `1` and the other
to `2`. Consequently every edge connects a vertex with value `1` and a vertex
with value `2`; their sum is `3`. ∎



##### Lemma 3  
For a connected component `C`, among all assignments that satisfy the edges
inside `C`, the algorithm’s assignment is the lexicographically smallest
restricted to the vertices of `C`.

**Proof.**  
Let `p` be the smallest index vertex of `C`. Any feasible assignment must give
`p` either `1` or `2`.  
If we give `p` the value `2`, the whole assignment is lexicographically larger
than any assignment giving `p` the value `1` (because `1 < 2`).  
The algorithm chooses the orientation that gives `p` the value `1`.  
All other vertices of `C` are forced by this orientation, so no other
assignment can keep `p = 1` and be smaller. ∎



##### Lemma 4  
The whole array `answer` output by the algorithm is the lexicographically
smallest feasible assignment for the whole graph.

**Proof.**  
Consider the vertices in increasing order.
When the first vertex `i` belonging to a not‑yet‑oriented component `C` is met,
the algorithm orients `C` so that `i` receives `1` (Lemma&nbsp;3).  
Any feasible global assignment must also decide an orientation for `C`;
if it gave `i = 2` the whole array would be lexicographically larger.
Thus the algorithm’s choice is optimal at the first differing position.
Proceeding inductively over the components, the algorithm never makes a
choice that can be improved later. Hence the final array is the smallest among
all feasible ones. ∎



##### Theorem  
The algorithm

* prints `NO` **iff** no assignment of `{1,2}` to the vertices satisfies all
  edges,
* otherwise prints `YES` and the lexicographically smallest such assignment.

**Proof.**  

*If the algorithm prints `NO`*: this happens only when a conflict is found.
By Lemma&nbsp;1 no feasible assignment exists.

*If a feasible assignment exists*: the graph is bipartite, therefore the
algorithm never encounters a conflict and finishes. By Lemma&nbsp;2 the
produced `answer` satisfies all edges. By Lemma&nbsp;4 it is the
lexicographically smallest among all satisfying assignments. Hence the
algorithm prints `YES` and the required array. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once →  
`O(n + m)` time, `O(n)` extra memory for colour, queue, component list.  

Overall: **Time `O(n + m)`**, **Memory `O(n + m)`**, well within the limits
(`n, m ≤ 2·10⁵`).

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * n          # -1 = unvisited, 0/1 = bipartite colour
    answer = [0] * n

    for start in range(n):
        if colour[start] != -1:
            continue

        # BFS for this component
        q = deque([start])
        colour[start] = 0
        comp = [start]

        while q:
            u = q.popleft()
            cu = colour[u]
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = cu ^ 1
                    q.append(v)
                    comp.append(v)
                elif colour[v] == cu:
                    print("NO")
                    return

        # orient component to make its smallest index vertex equal 1
        min_v = min(comp)
        if colour[min_v] == 0:
            for v in comp:
                answer[v] = 1 if colour[v] == 0 else 2
        else:
            for v in comp:
                answer[v] = 1 if colour[v] == 1 else 2

    print("YES")
    sys.stdout.write(' '.join(map(str, answer)) + '\n')


if __name__ == "__main__":
    solve()
```

to the required input‑output format.
