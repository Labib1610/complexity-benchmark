 We need to assign each node either 1 or 2 such that every edge connects nodes with different values (since 1+2=3). This is exactly checking if the graph is bipartite, and if so, output the lexicographically smallest assignment.

The lexicographically smallest assignment means we should try to assign 1 to as many early nodes as possible. In a bipartite graph, we can do a BFS/DFS starting from node 1, assigning 1 to it, and then alternate. If a conflict occurs, it's not bipartite.

Here’s the implementation:

```python
from collections import deque

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    adj[u-1].append(v-1)
    adj[v-1].append(u-1)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            node = q.popleft()
            for nei in adj[node]:
                if color[nei] == -1:
                    color[nei] = 1 - color[node]
                    q.append(nei)
                elif color[nei] == color[node]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(' '.join(str(c + 1) for c in color))
```
