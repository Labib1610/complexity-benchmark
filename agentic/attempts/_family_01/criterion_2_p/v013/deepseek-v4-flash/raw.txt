We can model this as a bipartite graph problem: workers are vertices, and each constraint is an edge where the two workers must be in different shift groups (1 or 2).  

If the graph is not bipartite, no valid assignment exists → print `NO`.  
If it is bipartite, the lexicographically smallest assignment is found by a BFS/DFS that assigns group 1 to the smallest possible uncolored vertex, and alternates.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
