We need to check if the graph is bipartite, and if so, produce the lexicographically smallest 2-coloring (with colors 1 and 2).

The lexicographically smallest assignment means: for each module from 1 to n, we prefer to assign it to environment 1 if possible, while still being able to complete a valid bipartite coloring.

A standard BFS/DFS coloring can find a valid 2-coloring, but to get lexicographically smallest, we can process nodes in order and try to assign color 1 if it doesn't cause a conflict, otherwise color 2.

We can do this by:
1. Build adjacency list.
2. Initialize color array with -1 (unassigned).
3. For each node from 1 to n:
   - If unassigned, try to assign color 1 and BFS/DFS to color the component. If conflict occurs, try color 2. If both fail, output NO.
   - If already assigned, skip.

But careful: if a node is already assigned from a previous component, we don't change it.

Let's implement:

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    
    def bfs(start, start_color):
        q = deque([start])
        color[start] = start_color
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    return False
        return True
    
    for i in range(n):
        if color[i] == -1:
            # try color 1
            temp = color[:]
            if bfs(i, 0):  # 0 means environment 1
                continue
            # revert and try color 2
            color = temp
            if not bfs(i, 1):  # 1 means environment 2
                print("NO")
                return
    
    print("YES")
    print(' '.join(str(c + 1) for c in color))

if __name__ == "__main__":
    solve()
```
