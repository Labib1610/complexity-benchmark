**Solution Explanation**

For every incompatible pair `(u , v)` the two compounds must be placed in different
vaults.  
Thus the graph whose vertices are the compounds and whose edges are the
incompatible pairs has to be *bipartite*.  
If the graph is not bipartite no allocation exists.

If the graph is bipartite, each connected component has exactly two possible
assignments – we may exchange the two colour classes.
Among all global assignments we need the lexicographically smallest sequence

```
s1 s2 … sn   (si ∈ {1,2})
```

--------------------------------------------------------------------

#### 1.   Lexicographically smallest assignment

Consider one connected component `C`.  
Let `vmin` be the smallest vertex number inside `C`.  
All vertices with a smaller index belong to components whose minimum vertex is
even smaller, therefore they are already fixed when we decide the colours of
`C`.

To obtain the smallest possible overall sequence we must give `vmin` the
smallest possible label, i.e. `1`.  
If we colour the component (by BFS/DFS) starting from `vmin` and obtain two
colour classes `col = 0` and `col = 1`, we simply set

```
all vertices with col = col(vmin) -> 1
all vertices with the other col   -> 2
```

This choice is forced for optimality; any other choice would put a `2` at the
position `vmin` while a `1` is feasible.

Processing the components in increasing order of their `vmin` therefore yields
the lexicographically smallest global assignment.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n, m
build adjacency list
colour[1…n] = -1   // -1 = unvisited, 0/1 = two sides
answer[1…n] = 0

for v = 1 … n (in increasing order):
    if colour[v] != -1: continue          // already processed component
    // start a new component, BFS from v
    queue ← [v]; colour[v] = 0
    component_vertices = []
    while queue not empty:
        x = pop queue
        component_vertices.append(x)
        for each neighbour y of x:
            if colour[y] == -1:
                colour[y] = colour[x] ^ 1
                push y into queue
            else if colour[y] == colour[x]:
                print "NO" and exit        // not bipartite

    // decide which colour gets label 1
    // v is the smallest vertex of this component
    col_of_v = colour[v]          // 0
    for each vertex u in component_vertices:
        if colour[u] == col_of_v:
            answer[u] = 1
        else:
            answer[u] = 2

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible allocation exists,
otherwise prints `YES` and the lexicographically smallest feasible allocation.

---

##### Lemma 1  
If the algorithm prints `NO`, the input graph is not bipartite.

**Proof.** `NO` is printed only when during BFS an edge `(x, y)` with
`colour[x] == colour[y]` is found. This means the graph contains an odd cycle,
hence it is not bipartite. ∎



##### Lemma 2  
If the input graph is not bipartite, the algorithm prints `NO`.

**Proof.** A non‑bipartite graph contains an odd cycle. While exploring the
connected component containing that cycle, BFS will eventually colour two
adjacent vertices equally (standard property of BFS 2‑colouring). The algorithm
detects this and prints `NO`. ∎



##### Lemma 3  
Assume the graph is bipartite. For every connected component `C` the algorithm
outputs a feasible assignment for the vertices of `C`.

**Proof.** BFS colours the component with two colours `0` and `1` such that every
edge connects vertices of different colours – this is exactly the definition
of a bipartite colouring. Afterwards the algorithm assigns label `1` to all
vertices of the colour class containing the smallest vertex `vmin` and label `2`
to the other class. Hence every edge connects a `1` with a `2`. ∎



##### Lemma 4  
For a bipartite graph, the assignment produced by the algorithm is the
lexicographically smallest feasible assignment.

**Proof.** Consider the components ordered by their smallest vertex
`v1 < v2 < …`.  
When processing component `Ci` the algorithm fixes the label of `vi` to `1`
(because `vi` belongs to the colour class we map to `1`). Any feasible global
assignment must also give some label to `vi`. Since the component is bipartite,
both labels `1` and `2` are possible for `vi`. Choosing `1` is strictly better
lexicographically, and it does not affect earlier positions (`v1 … v_{i-1}`) –
they belong to earlier components already fixed. Therefore any feasible
assignment that differs from the algorithm’s one must have a `2` at the first
position where they differ, making it lexicographically larger. ∎



##### Lemma 5  
If the graph is bipartite, the algorithm always outputs an assignment.

**Proof.** By Lemma 3 each component yields a feasible local assignment.
All components together cover all vertices, so the concatenated assignment is
feasible for the whole graph. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no allocation satisfying all incompatibilities exists;  

* otherwise `YES` and the lexicographically smallest allocation.

**Proof.**  
*If part*: If the algorithm prints `NO`, by Lemma 1 the graph is not bipartite,
hence no feasible allocation exists.  

*Only‑if part*: If no feasible allocation exists, the graph cannot be bipartite,
otherwise a bipartite colouring would give a feasible allocation (Lemma 3).
Thus the graph is non‑bipartite and by Lemma 2 the algorithm prints `NO`.  

If a feasible allocation exists, the graph is bipartite. The algorithm then
produces an assignment (Lemma 5) and this assignment is the lexicographically
smallest one (Lemma 4). ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)`  
*BFS over all vertices*: each vertex and edge is processed once → `O(n + m)`  
*Memory*: adjacency list `O(n + m)`, colour and answer arrays `O(n)`.

Both limits satisfy the constraints (`n, m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 two sides
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # new component, BFS from start (which is the smallest vertex of it)
        q = deque([start])
        colour[start] = 0
        comp = []
        while q:
            x = q.popleft()
            comp.append(x)
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = colour[x] ^ 1
                    q.append(y)
                elif colour[y] == colour[x]:
                    sys.stdout.write("NO")
                    return
        # assign labels: colour of start -> 1, other -> 2
        col_start = colour[start]
        for v in comp:
            ans[v] = 1 if colour[v] == col_start else 2

    out = ["YES\n"]
    out.append(' '.join(str(ans[i]) for i in range(1, n + 1)))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to
the required input‑output format.
