We need to solve this using a graph bipartiteness check because incompatible pairs are edges and we need different vaults on each side of an edgewwhich means the graph must be bipartitearke.

We also must produce the lexicographically smallest assignment (1’s as early as possible) consistent with bipartiteness.

We can:
- Build adjacency list.
- Color each node with 0/1 (representing vault 1/2).
- For each connected component, try to assign the smallest possible label to the smallest index. That is, attempt to assign 1 to the smallest vertex in the component Barnes– we then propagate colors via BFS/DFS, if conflict → NO.
- If conflict with first attempt, we can try the opposite color for the smallest vertex (but that’s rarely needed save for remain correct), but note lexicographically smallest ensures smallest indices favor 1 early, so we must try that first per component in increasing index order.

Because the input constraints are large, we should use iterative BFS/DFS to avoid recursion depth issues.

**Approach code**:

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    
    for start in range(n):
        if color[start] != -1:
            continue
        # try to color start with 0 (vault 1) for lexicographically smallest
        color[start] = 0
        q = deque([start])
        ok = True
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break
            if not ok:
                break
        if not ok:
            # We can also try opposite coloring for this component
            # reset colors in this component and try inverted
            comp_nodes = []
            # find all nodes in this component
            # Actually simpler: reset colors for this component by BFS again
            # We'll re-color by BFS from start with color 1 instead
            # First, clear previously colored nodes in this component
            # We don't have full list yet, so we'll collect during the failed BFS
            # But easier: we can do a second pass starting with color 1.
            # For that we need to know all nodes in this component before.
            # Let's gather them with a quick BFS/DFS (no coloring yet)
            stack = [start]
            comp = []
            visited = [False]*n
            visited[start] = True
            while stack:
                u = stack.pop()
                comp.append(u)
                for v in adj[u]:
                    if not visited[v]:
                        visited[v] = True
                        stack.append(v)
            # Now color with 1-start
            for node in comp:
                color[node] = -1
            color[start] = 1
            q = deque([start])
            ok2 = True
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 1 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        ok2 = False
                        break
                if not ok2:
                    break
            if not ok2:
                print("NO")
                return
            # else keep this coloring
    
    # Build result
    res = [1 if c == 0 else 2 for c in color]
    print("YES")
    print(" ".join(map(str, res)))

if __name__ == "__main__":
    solve()
```
