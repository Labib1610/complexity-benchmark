We can model the modules and interference links as an undirected graph.  
The condition “no two connected modules have the same mode” means the graph must be bipartite.  
If it’s not bipartite, we output `NO`.  

The load-balancing condition says the absolute difference between counts of mode 1 and mode 2 must not exceed \( n \).  
Since \( n \) is the total number of modules, this condition is always satisfied for any assignment (the difference is at most \( n \)).  
So the only real constraint is bipartiteness.

We also need the lexicographically smallest assignment.  
We can do a BFS/DFS coloring, trying to assign mode 1 whenever possible, and mode 2 otherwise, while respecting the bipartite constraint.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    # color 0 -> mode 1, color 1 -> mode 2
    res = [1 if c == 0 else 2 for c in color]
    print("YES")
    print(" ".join(map(str, res)))
```
