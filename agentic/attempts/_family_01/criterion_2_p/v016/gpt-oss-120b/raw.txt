**Solution Explanation**

For every interference link the two incident modules must obtain different
operational modes.
Therefore we have to 2‑colour the given undirected graph.
A graph is 2‑colourable **iff** it is *bipartite*.
If a component is not bipartite the answer is `NO`.

If the graph is bipartite each connected component has exactly two possible
colourings – they are obtained from each other by swapping the two colours.
Among all global colourings we have to output the lexicographically smallest
sequence  

```
s1 s2 … sn   (si ∈ {1,2})
```

--------------------------------------------------------------------

#### 1.   Lexicographically smallest colouring

Consider one connected component `C`.
Let `p = min(C)` be the smallest vertex index belonging to `C`.
All vertices with index `< p` lie in other components, therefore the value of
`sp` is the first position where the choice of orientation of `C` can influence
the whole sequence.
To obtain the smallest possible sequence we must set `sp = 1`.
Consequently we orient the component so that its smallest vertex receives
colour 1.  
Doing this independently for every component yields the globally
lexicographically smallest assignment.

--------------------------------------------------------------------

#### 2.   Algorithm
```
for every vertex v = 1 … n
        if v is not visited
                run BFS/DFS from v
                – colour the component with colours 0 / 1
                – if a conflict (edge joining equal colours) appears → NO
                – collect all vertices of the component
                – let p = smallest vertex of the component
                – if colour[p] == 0   keep the current orientation
                  else                flip the whole component
                – write the final modes (1 / 2) into answer array
output YES and the answer
```

*Flipping* means exchanging the meaning of colour 0 and colour 1.
If we keep the orientation: `mode = 1 + colour` (0→1, 1→2)  
If we flip:                `mode = 2 - colour` (0→2, 1→1)

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible assignment exists,
otherwise it prints the lexicographically smallest feasible assignment.

---

##### Lemma 1  
During the BFS of a component the algorithm detects a conflict
iff the component is not bipartite.

**Proof.**  
BFS colours a vertex with `0` and always gives the opposite colour to its
neighbours.  
If an edge connects two vertices that already have the same colour,
any 2‑colouring would give them equal colours – contradiction to the
requirement that adjacent vertices differ.  
Conversely, if the component is not bipartite, it contains an odd cycle.
Walking along the cycle forces the first vertex to obtain both colours,
hence a conflict is discovered. ∎



##### Lemma 2  
If the algorithm finishes without printing `NO`, the produced assignment
satisfies all interference links.

**Proof.**  
By Lemma&nbsp;1 every processed component is bipartite, therefore the BFS
colours it properly: every edge joins vertices of opposite BFS colours.
The final step possibly flips the whole component, which still keeps opposite
vertices different. Hence every edge of the whole graph connects vertices with
different final modes. ∎



##### Lemma 3  
For a processed component `C` the algorithm assigns mode 1 to its smallest
vertex `p = min(C)`.

**Proof.**  
After BFS we know the BFS colour of `p`.  
*If* it is `0` we keep the orientation, thus `mode(p)=1+0=1`.  
*If* it is `1` we flip, thus `mode(p)=2-1=1`. ∎



##### Lemma 4  
Among all feasible assignments the one produced by the algorithm is
lexicographically smallest.

**Proof.**  
Consider the vertices in increasing order.
Let `p1 < p2 < … < pk` be the minima of the connected components
(in that order, each component appears exactly once).
By Lemma&nbsp;3 the algorithm forces `sp_i = 1` for every `i`.
Any feasible assignment must give each `p_i` either `1` or `2`.
If some feasible assignment had `sp_i = 2` for the first index `i` where it
differs from the algorithm, then at position `p_i` it would be larger while all
previous positions are equal, i.e. the whole sequence would be lexicographically
greater.  
Therefore no feasible assignment is lexicographically smaller. ∎



##### Lemma 5  
If a feasible assignment exists, the algorithm never prints `NO`.

**Proof.**  
A feasible assignment implies the graph is bipartite, i.e. every component is
bipartite. By Lemma&nbsp;1 the BFS of each component finds no conflict, so the
algorithm never reaches the `print("NO")` statement. ∎



##### Theorem  
The algorithm outputs  

* `NO` **iff** no assignment satisfying the constraints exists;  
* otherwise `YES` and the lexicographically smallest valid assignment.

**Proof.**  

*If part*:  
If the algorithm prints `NO`, by Lemma&nbsp;1 some component is not bipartite,
hence no 2‑colouring exists, thus no feasible assignment exists.

*Only‑if part*:  
Assume a feasible assignment exists.
By Lemma&nbsp;5 the algorithm does not print `NO`.  
By Lemma&nbsp;2 the produced assignment is feasible.  
By Lemma&nbsp;4 it is the lexicographically smallest feasible assignment. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency lists*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once →  
`O(n + m)` time, `O(n)` additional memory for colour / answer arrays.  

Overall  

```
Time   :  O(n + m)   ≤ 4·10⁵ operations
Memory :  O(n + m)   ≤ 2·10⁵·2 integers  (well below 256 MB)
```

Both limits satisfy the problem constraints.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        g[u].append(v)
        g[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0 / 1 = bfs colours
    answer = [0] * (n + 1)           # final modes 1 / 2

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue

        # BFS of one component
        q = deque([start])
        colour[start] = 0
        component = [start]

        while q:
            u = q.popleft()
            cu = colour[u]
            for v in g[u]:
                if colour[v] == -1:
                    colour[v] = cu ^ 1
                    q.append(v)
                    component.append(v)
                elif colour[v] == cu:
                    # not bipartite
                    sys.stdout.write("NO")
                    return

        # orient component so that its smallest vertex gets mode 1
        p = min(component)                 # smallest index in this component
        flip = (colour[p] == 1)             # need to swap colours?
        if not flip:
            for v in component:
                answer[v] = 1 + colour[v]   # 0->1, 1->2
        else:
            for v in component:
                answer[v] = 2 - colour[v]   # 0->2, 1->1

    # all components processed successfully
    out = ["YES", " ".join(str(answer[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
