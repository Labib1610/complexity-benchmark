We can model this as a graph problem.  
If the employees are vertices and each constraint is an edge between two vertices that must have different colors, then this becomes a **graph bipartiteness check** with a specific tie-breaking rule.  

We proceed as follows:

- Build an undirected graph from the given constraints.  
- Use BFS/DFS to check if the graph is bipartite.  
- If not bipartite → print `"NO"`.  
- If bipartite → assign colors with the lexicographically smallest possible sequence starting from employee 1.  

The tie-breaking rule:  
We want employee 1 assigned the smallest possible branch number (1), and then employee 2, etc.  

We can implement a BFS that assigns colors greedily, but for disconnected components we need to decide their starting color based on the smallest uncolored vertex in the component.

Here’s the solution:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 1
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

# Try to color each component
for i in range(n):
    if color[i] == -1:
        # If this component can start with color 1 (smallest)
        # We must check both possibilities and pick the lexicographically best.
        # Temporarily color this component starting with 1 and 2, then compare
        tmp_color = color[:]
        color[i] = 1
        q = deque([i])
        ok1 = True
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    ok1 = False
                    break
            if not ok1:
                break
        if ok1:
            continue
        # If starting with 1 fails, restore and try starting with 2
        color = tmp_color
        color[i] = 2
        q = deque([i])
        ok2 = True
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    ok2 = False
                    break
            if not ok2:
                break
        if not ok2:
            print("NO")
            sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
