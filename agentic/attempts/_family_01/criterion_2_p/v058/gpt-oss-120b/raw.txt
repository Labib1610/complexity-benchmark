**Solution Explanation**

For every pair `(u , v)` the two workers must be on different shifts.
So the graph formed by the `m` pairs has to be *bipartite*.
If it is not bipartite the answer is `NO`.

If it is bipartite, each connected component has exactly two possible
colourings – they are each other’s complement.
We have to choose, for every component, one of the two possibilities so
that the whole sequence  

```
s1 s2 … sn   (si ∈ {1,2})
```

is lexicographically minimal.
`1` is smaller than `2`, therefore we want the earliest worker that we
still can decide to obtain shift 1.

--------------------------------------------------------------------

#### 1.   Data obtained from a BFS/DFS

For every vertex `v`

* `comp[v]` – id of the connected component,
* `col[v]`   – colour inside the component, `0` or `1`
  (the colour given by the first BFS of this component).

During the search we also check bipartiteness:
if an edge connects two vertices with the same `col`,
the graph is not bipartite.

All vertices of one component are stored in a list `verts[comp_id]`.

--------------------------------------------------------------------

#### 2.   Deciding the orientation of a component

We walk through the workers in increasing order `i = 1 … n`.

*If the final shift of `i` is already known* – continue.

Otherwise we meet the **first** vertex of its component.
Only two possibilities exist for this component:

```
orientation = 0 :   colour 0 → shift 1 , colour 1 → shift 2
orientation = 1 :   colour 0 → shift 2 , colour 1 → shift 1   (flipped)
```

To obtain the lexicographically smallest whole sequence we must give
worker `i` shift 1 if it is possible.
`col[i]` is either `0` or `1`.

```
if col[i] == 0 :   choose orientation 0   (0 → 1)
else               choose orientation 1   (1 → 1)
```

The chosen orientation is stored (`orient[comp_id]`) and all vertices of
this component receive their final shift immediately.

After that, later workers belonging to the same component are already
fixed, so the walk continues.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically
smallest feasible assignment iff one exists.

---

##### Lemma 1  
If the algorithm reports `NO`, the input graph is not bipartite.

**Proof.**  
`NO` is printed only when during BFS an edge `(u,v)` with `col[u]==col[v]`
is found. This is exactly the definition of a non‑bipartite graph. ∎



##### Lemma 2  
If the input graph is bipartite, the algorithm assigns a shift to every
worker and the assignment satisfies all constraints.

**Proof.**  
For a bipartite graph the BFS never finds a conflict, therefore every
connected component is coloured with two colour classes `0` and `1`.
The algorithm chooses for each component either the identity mapping
`0→1,1→2` or the flipped mapping `0→2,1→1`.  
Both mappings give different shifts to the two colour classes, i.e. to
the two ends of every edge. Hence all constraints are satisfied. ∎



##### Lemma 3  
For a fixed component, among the two possible assignments the algorithm
chooses the one that is lexicographically smaller **restricted to the
indices belonging to this component**.

**Proof.**  
The first vertex of the component encountered while scanning `1…n` is the
smallest index of the component.  
If its colour is `0` the algorithm uses orientation `0`, giving it shift 1;
otherwise it uses orientation `1`, also giving it shift 1.
Thus the smallest index of the component receives shift 1, which is the
best possible value. All later indices of the component are forced by
this choice, so the whole restricted sequence is the lexicographically
smallest one. ∎



##### Lemma 4  
When the algorithm finishes scanning `1…n`, the produced whole sequence
is the lexicographically smallest feasible sequence.

**Proof.**  
Consider the first position `p` where the algorithm’s output could differ
from any other feasible output.
All positions `< p` belong to components already fixed earlier in the
scan, therefore they are identical in every feasible solution
(because for each of those components the algorithm already gave the
lexicographically smallest restricted sequence, Lemma&nbsp;3).

Vertex `p` is the first vertex of its component that has not been fixed
before. By Lemma&nbsp;3 the algorithm gives it shift 1, which is the
minimum possible value for this position among all feasible assignments.
Hence any other feasible assignment must have `sp = 2` or be identical.
Thus the algorithm’s whole sequence is lexicographically minimal. ∎



##### Theorem  
The program outputs  

* `NO` iff no valid shift assignment exists,  
* otherwise `YES` and the lexicographically smallest valid assignment.

**Proof.**  

*If the program prints `NO`*: by Lemma&nbsp;1 the graph is not bipartite,
hence no assignment exists.

*If the program prints `YES`*: the graph is bipartite, Lemma&nbsp;2 gives a
valid assignment, and Lemma&nbsp;4 shows it is the lexicographically
smallest one.

Conversely, if a valid assignment exists the graph is bipartite,
the program never encounters a conflict, therefore it prints `YES` and,
by the previous argument, the smallest assignment. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency lists*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge processed once → `O(n+m)`.  
*Scanning vertices to fix orientations*: `O(n)`.  

Total time `O(n + m)` ≤ `4·10⁵`, well inside the limit.  
Memory: adjacency list (`2m` integers) + several `O(n)` arrays → `O(n+m)`.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    comp = [0] * (n + 1)          # component id, 0 = unvisited
    col = [0] * (n + 1)           # 0 / 1 inside component
    verts = []                    # list of vertex lists per component
    from collections import deque

    comp_cnt = 0
    for start in range(1, n + 1):
        if comp[start]:
            continue
        comp_cnt += 1
        q = deque([start])
        comp[start] = comp_cnt
        col[start] = 0
        cur = []
        ok = True
        while q:
            v = q.popleft()
            cur.append(v)
            for to in adj[v]:
                if not comp[to]:
                    comp[to] = comp_cnt
                    col[to] = col[v] ^ 1
                    q.append(to)
                elif col[to] == col[v]:
                    print("NO")
                    return
        verts.append(cur)

    # orientation per component: 0 = as coloured, 1 = flipped
    orient = [-1] * (comp_cnt + 1)
    ans = [0] * (n + 1)

    for i in range(1, n + 1):
        if ans[i]:
            continue
        cid = comp[i]
        # decide orientation using vertex i (the smallest index of this component)
        if col[i] == 0:
            o = 0          # colour 0 -> shift 1
        else:
            o = 1          # colour 1 -> shift 1
        orient[cid] = o
        # assign all vertices of this component
        for v in verts[cid - 1]:
            if o == 0:
                ans[v] = 1 if col[v] == 0 else 2
            else:
                ans[v] = 1 if col[v] == 1 else 2

    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
