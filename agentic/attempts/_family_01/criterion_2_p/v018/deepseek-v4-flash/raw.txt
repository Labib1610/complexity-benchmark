We can model the workers as nodes in a graph, where incompatible pairs are edges.  
The condition “two incompatible workers must be in different shifts” means the graph must be bipartite.  
If it’s not bipartite, output `NO`.  

If it is bipartite, we need the lexicographically smallest assignment.  
We can do a BFS/DFS coloring, but to get the lexicographically smallest sequence, we should try to assign shift 1 whenever possible, starting from worker 1.  

A simple approach:  
- Initialize all workers as uncolored.  
- For each worker from 1 to n, if uncolored, start BFS/DFS and color with 1.  
- During traversal, assign opposite colors to neighbors.  
- If conflict → not bipartite → `NO`.  

This yields the lexicographically smallest because we always start with 1 for the smallest uncolored node.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
