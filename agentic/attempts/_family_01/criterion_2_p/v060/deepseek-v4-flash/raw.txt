We can model this as a **bipartite graph coloring** problem.  
Each access point is a node, and each interference constraint is an edge.  
We need to color the graph with two colors (1 and 2) such that no two adjacent nodes share the same color.

If the graph is not bipartite, output `NO`.  
Otherwise, we need the **lexicographically smallest** valid assignment.

To get the lexicographically smallest assignment, we can use **BFS/DFS** and always try to assign the smallest possible color (1) to each node when we start a new component.  
If a node is already colored, we don't change it.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    
    for i in range(n):
        if color[i] == -1:
            color[i] = 1
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
    
    print("YES")
    print(" ".join(str(c) for c in color))

if __name__ == "__main__":
    solve()
```
