**Solution Explanation**

For every server we have to choose a window `1` or `2`.
For each given pair `(u , v)` the two servers must obtain *different* windows.
So we have to 2‑colour the undirected graph whose vertices are the servers
and whose edges are the given pairs.

*If the graph is not bipartite* – i.e. a component contains an odd cycle –
no assignment exists.

If the graph is bipartite there are exactly two possible colourings for each
connected component (they are each other’s global colour swap).
The whole answer is the concatenation of the colourings of all components.
We have to output the lexicographically smallest possible sequence
` s1 … sn ` ( `1 < 2` ).

--------------------------------------------------------------------

#### 1.   Observations

* Components are independent – we may flip the colours inside a component
  without influencing any other component.
* Lexicographic order is decided by the first index where two answers differ.
  Therefore the *first* vertex of a component (the smallest numbered vertex
  belonging to it) is the only one that matters for choosing the orientation
  of this component.
* To obtain the smallest possible answer we simply force this first vertex to
  receive colour `1`.  
  After that the rest of the component is forced automatically.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n , m
build adjacency list

comp_id[1…n] = -1          # component number, -1 = unvisited
parity[1…n]   = 0          # 0 / 1 inside its component
min_vertex[component] = +∞
flip[component] = 0        # will be decided later

component = 0
for v = 1 … n:
    if comp_id[v] == -1:
        BFS starting from v
        during BFS:
            assign comp_id[u] = component
            assign parity[u] (alternating 0/1)
            if we ever see an edge (x , y) with parity[x] == parity[y]:
                print "NO" and exit   # not bipartite
            update min_vertex[component] = min(min_vertex, u)
        component += 1

# decide orientation of every component
for c = 0 … component-1:
    first = min_vertex[c]                # smallest vertex of this component
    if parity[first] == 1:               # we want it to become 1 → flip
        flip[c] = 1
    else:
        flip[c] = 0

# build answer
ans[1…n]
for v = 1 … n:
    c = comp_id[v]
    colour = parity[v] ^ flip[c]        # 0 or 1 after possible flip
    ans[v] = 1 if colour == 0 else 2

print "YES"
print ans[1] … ans[n]
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no safe plan exists,
otherwise it prints the lexicographically smallest safe plan.

---

##### Lemma 1  
During each BFS the algorithm assigns `parity` values that are consistent
with a 2‑colouring of the visited component **iff** the component is bipartite.

**Proof.**  
BFS starts with the source vertex coloured `0`. Every traversed edge forces
the neighbour to obtain the opposite colour. This is exactly the standard
bipartite test. If an edge connects two vertices already coloured equally,
an odd cycle exists, the component is not bipartite and the algorithm detects
the conflict. Conversely, if no such conflict appears, the obtained
colouring is a proper 2‑colouring. ∎



##### Lemma 2  
For a bipartite component `C` let `f` be the smallest vertex of `C`.
The algorithm chooses `flip[C]` so that the final assignment gives
`sf = 1`.

**Proof.**  
`parity[f]` is either `0` or `1`.  
If it is `0` the algorithm sets `flip = 0`; then final colour of `f` is
`0 ^ 0 = 0` → window `1`.  
If it is `1` the algorithm sets `flip = 1`; final colour becomes
`1 ^ 1 = 0` → window `1`. ∎



##### Lemma 3  
For any bipartite component `C` the algorithm’s assignment is the
lexicographically smallest among the two possible assignments of `C`.

**Proof.**  
The two possible assignments differ exactly by swapping the two colour
classes. By Lemma&nbsp;2 the algorithm picks the one where the smallest vertex
`f` receives `1`. Any other assignment would give `f` the value `2`,
hence would be lexicographically larger (the first differing position is
`f`). ∎



##### Lemma 4  
Let `A` be the sequence produced by the algorithm and `B` any other feasible
sequence. Then `A` is lexicographically not larger than `B`.

**Proof.**  
Consider the first index `i` where `A` and `B` differ.
Both sequences respect all edges, therefore `i` belongs to some component
`C`. All vertices `< i` belong to components whose orientation is already
fixed and identical in `A` and `B`.  
Inside `C` the two feasible orientations are exactly the two colour swaps.
By Lemma&nbsp;3 the algorithm chooses the orientation with the smaller value at
the smallest vertex of `C`. Since `i` is the smallest vertex of `C` (otherwise
a smaller index would already differ), we have `Ai = 1` and `Bi = 2`. Hence
`A` is lexicographically smaller. ∎



##### Lemma 5  
If the algorithm prints `NO` then no safe deployment plan exists.

**Proof.**  
`NO` is printed only when during BFS an edge connects two vertices with the
same parity. By Lemma&nbsp;1 this means the corresponding component is not
bipartite, i.e. it contains an odd cycle. An odd cycle cannot be 2‑coloured,
so no assignment satisfies all constraints. ∎



##### Lemma 6  
If the algorithm prints `YES` then the produced sequence is a safe plan.

**Proof.**  
`YES` is printed only if every component passed the bipartite test,
hence each component has a proper 2‑colouring (`parity`).  
The final colour of a vertex is `parity ^ flip`, i.e. possibly swapped for the
whole component. Swapping does not break the property that adjacent vertices
have opposite colours. Therefore every edge connects vertices with different
final colours, i.e. different windows. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no safe deployment plan exists;  
* otherwise `YES` and the lexicographically smallest safe plan.

**Proof.**  
*If the algorithm outputs `NO`* – by Lemma&nbsp;5 no plan exists.  

*If the algorithm outputs `YES`* – by Lemma&nbsp;6 the printed sequence is a
valid plan. By Lemma&nbsp;4 no other valid plan is lexicographically smaller.
Thus it is the required answer. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge processed once → `O(n + m)`.  
*Final construction*: `O(n)`.

Total time `O(n + m)` ≤ `4·10⁵`, well inside the 1 s limit.  
Memory consumption `O(n + m)` ≤ about 3 MB for the adjacency list plus arrays,
well below 256 MB.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    comp_id = [-1] * (n + 1)
    parity = [0] * (n + 1)
    min_vertex = []
    comp_cnt = 0

    for start in range(1, n + 1):
        if comp_id[start] != -1:
            continue
        # new component
        q = deque([start])
        comp_id[start] = comp_cnt
        parity[start] = 0
        cur_min = start
        while q:
            v = q.popleft()
            cur_min = min(cur_min, v)
            for to in adj[v]:
                if comp_id[to] == -1:
                    comp_id[to] = comp_cnt
                    parity[to] = parity[v] ^ 1
                    q.append(to)
                else:
                    if parity[to] == parity[v]:
                        sys.stdout.write("NO")
                        return
        min_vertex.append(cur_min)
        comp_cnt += 1

    # decide orientation
    flip = [0] * comp_cnt
    for c in range(comp_cnt):
        first = min_vertex[c]
        if parity[first] == 1:
            flip[c] = 1

    # build answer
    ans = [0] * n
    for v in range(1, n + 1):
        c = comp_id[v]
        col = parity[v] ^ flip[c]   # 0 or 1
        ans[v - 1] = 1 if col == 0 else 2

    out = ["YES", " ".join(map(str, ans))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
