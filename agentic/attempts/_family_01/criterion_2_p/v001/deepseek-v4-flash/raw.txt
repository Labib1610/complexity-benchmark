We can model this as a bipartite graph problem: each worker is a node, and incompatible pairs are edges. We need to assign each node to one of two schedules (1 or 2) such that no edge connects two nodes with the same schedule. This is exactly checking if the graph is bipartite.

We also need the lexicographically smallest valid assignment. That means we should try to assign schedule 1 as early as possible (for node 1, then node 2, etc.), but still respecting bipartiteness.

We can do a BFS/DFS coloring, but to get lexicographically smallest, we process nodes in order and try to assign 1 if possible, otherwise 2.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

# First, color all components with BFS (any valid coloring)
for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

# Now we have a valid coloring, but we want lexicographically smallest.
# We can try to flip colors in each component if it makes earlier nodes 1.
# Since each component is independent, we can check for each component
# whether flipping gives a lexicographically smaller result.

# Build component list
visited = [False] * n
components = []
for i in range(n):
    if not visited[i]:
        comp = []
        q = deque([i])
        visited[i] = True
        while q:
            u = q.popleft()
            comp.append(u)
            for v in adj[u]:
                if not visited[v]:
                    visited[v] = True
                    q.append(v)
        components.append(comp)

# For each component, decide whether to flip
for comp in components:
    # comp is sorted by index because we process in order
    comp.sort()
    # Check if flipping gives smaller lexicographic order
    # We compare the first node in comp: if color[comp[0]] == 1, flipping makes it 0 -> better
    if color[comp[0]] == 1:
        for u in comp:
            color[u] ^= 1

print("YES")
print(' '.join(str(c + 1) for c in color))
```
