**Solution Explanation**

For every redundancy link `(u , v)` the two modules must be on different buses.
So the whole set of modules together with the links is a graph that has to be
*2‑coloured* – i.e. it must be **bipartite**.
If the graph is not bipartite the answer is `NO`.

If it is bipartite there are two possible colourings for each connected
component (they are obtained from each other by swapping the two colours).
We have to output the lexicographically smallest sequence  
`c1 c2 … cn` (`ci` = 1 or 2).

--------------------------------------------------------------------

#### 1.   Observations

* In a connected component the two possible colourings are exact opposites.
* The first (smallest index) vertex of a component decides the whole
  lexicographic order of that component, because all later vertices are
  larger indices.
* Therefore we can always choose the orientation that gives colour **1**
  to the smallest indexed vertex of the component – this is optimal for the
  whole sequence.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n , m
build adjacency list

colour[1…n] = -1          # -1 = not visited, 0/1 = temporary colours
answer[1…n] = 0

for v = 1 … n
    if colour[v] == -1                # new component
        run BFS starting with v, colour[v] = 0
        during BFS:
            for each edge (x , y)
                if colour[y] == -1          colour[y] = colour[x] xor 1
                else if colour[y] == colour[x]   # same colour on an edge
                        print "NO" and exit
        component = list of all visited vertices in this BFS
        min_vertex = minimum index in component
        if colour[min_vertex] == 1          # min vertex would become 2
                for every u in component
                        colour[u] ^= 1    # flip whole component
        for every u in component
                answer[u] = colour[u] + 1   # map 0→1 , 1→2

print "YES"
print answer[1] … answer[n] separated by blanks
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible assignment exists,
otherwise it prints the lexicographically smallest feasible assignment.

---

##### Lemma 1  
During BFS, if an edge connects two vertices with the same temporary colour,
the graph is not bipartite.

**Proof.**  
BFS colours neighbours with opposite colours, i.e. it tries to build a proper
2‑colouring. If an edge `(x , y)` is found with `colour[x] == colour[y]`,
any 2‑colouring would have to give the same colour to both ends, contradicting
the requirement that they be different. ∎



##### Lemma 2  
If the algorithm finishes without printing `NO`, the produced `answer`
is a feasible assignment (all linked modules are on different buses).

**Proof.**  
For each component BFS assigned temporary colours `0/1` such that every edge
joins vertices of opposite temporary colours (otherwise Lemma&nbsp;1 would
have triggered `NO`).  
If the component is flipped, both colours are inverted, still opposite on
every edge. Finally we map `0 → 1` and `1 → 2`. Hence every edge connects a `1`
with a `2`. ∎



##### Lemma 3  
For a fixed connected component, among the two possible feasible colourings
the algorithm chooses the one that is lexicographically smaller on the
indices belonging to this component.

**Proof.**  
Let `p` be the smallest vertex index of the component.
The two feasible colourings differ exactly by swapping the colours of *all*
vertices, therefore `p` receives colour `1` in one orientation and `2` in the
other. The algorithm forces `p` to obtain colour `1` (by flipping if necessary),
hence its orientation is the lexicographically smaller one for this component. ∎



##### Lemma 4  
Let `C1 , C2 , … , Ck` be the components ordered by their smallest vertex index.
The concatenation of the colourings chosen by the algorithm is the
lexicographically smallest feasible colouring of the whole graph.

**Proof.**  
Consider the first index where two feasible global colourings differ.
It belongs to some component `Ci`.  
All earlier indices belong to components `C1 … C_{i-1}` and are identical
in both colourings, because those components are already fixed.
By Lemma&nbsp;3 the algorithm uses the smallest possible colour for the first
vertex of `Ci`, therefore any other feasible global colouring must have a
larger colour at this position. Consequently the algorithm’s concatenation is
lexicographically minimal. ∎



##### Lemma 5  
If a feasible assignment exists, the algorithm never prints `NO`.

**Proof.**  
Assume a feasible assignment exists. Then the graph is bipartite.
During BFS the algorithm only fails when it discovers an edge whose ends
receive the same temporary colour. In a bipartite graph such a situation
cannot happen, because a proper 2‑colouring exists and BFS reproduces one of
them (up to a global flip). Hence Lemma&nbsp;1 never triggers, and the algorithm
does not output `NO`. ∎



##### Theorem  
The algorithm outputs  

* `NO` **iff** no assignment satisfying all redundancy links exists;  

* otherwise `YES` and the lexicographically smallest assignment.

**Proof.**  

*If part*:  
If the algorithm prints `NO`, by Lemma&nbsp;1 a non‑bipartite component was
found, therefore no feasible assignment exists.

*Only‑if part*:  
If a feasible assignment exists, Lemma&nbsp;5 guarantees the algorithm does
not print `NO`. By Lemma&nbsp;2 the produced `answer` is feasible, and by
Lemmas&nbsp;3 and&nbsp;4 it is the lexicographically smallest feasible one. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and each edge is processed once →  
`O(n + m)` time, `O(n)` additional memory for colour array, queue and component
list.  

Overall: **Time `O(n + m)`**, **Memory `O(n + m)`**, well inside the limits
(`n, m ≤ 2·10⁵`).

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # temporary 0/1 colours
    answer = [0] * (n + 1)           # final 1/2 bus numbers

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS for this component
        q = deque([start])
        colour[start] = 0
        comp = []                     # vertices of this component
        while q:
            v = q.popleft()
            comp.append(v)
            cv = colour[v]
            for nb in adj[v]:
                if colour[nb] == -1:
                    colour[nb] = cv ^ 1
                    q.append(nb)
                elif colour[nb] == cv:
                    sys.stdout.write("NO")
                    return

        # decide orientation: smallest index must become colour 0 (=> bus 1)
        min_v = min(comp)
        if colour[min_v] == 1:        # would become bus 2, so flip whole component
            for v in comp:
                colour[v] ^= 1

        for v in comp:
            answer[v] = colour[v] + 1   # map 0->1, 1->2

    out = ["YES\n"]
    out.append(' '.join(str(answer[i]) for i in range(1, n + 1)))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```
