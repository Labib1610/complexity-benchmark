We can model this as a **graph coloring problem** with 3 colors.  
Each artifact is a vertex, and each interfering pair is an edge.  
We need to assign each vertex one of 3 colors such that no two adjacent vertices share the same color.

Since \( n \leq 40 \), we can use **backtracking with pruning** to find a valid 3-coloring.

Here’s the Python solution:

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        # Try colors 1,2,3
        for c in range(1, 4):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(color[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
