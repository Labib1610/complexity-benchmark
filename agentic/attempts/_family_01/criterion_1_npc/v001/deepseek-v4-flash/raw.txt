 We can solve this by trying all possible assignments of 3 shifts to n workers, but since n can be up to 40, brute force over 3^n is impossible.  
Instead, we can use backtracking with pruning, or reduce it to a graph coloring problem with 3 colors. Since n ≤ 40, we can use a backtracking approach with constraint propagation.

Here’s a possible implementation:

```python
n, m = map(int, input().split())
edges = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    edges[u].append(v)
    edges[v].append(u)

colors = [0] * n  # 0 = uncolored, 1,2,3 = shifts

def is_safe(node, color):
    for neighbor in edges[node]:
        if colors[neighbor] == color:
            return False
    return True

def solve(node):
    if node == n:
        return True
    for color in (1, 2, 3):
        if is_safe(node, color):
            colors[node] = color
            if solve(node + 1):
                return True
            colors[node] = 0
    return False

if solve(0):
    print("YES")
    print(" ".join(map(str, colors)))
else:
    print("NO")
```
