**Solution Explanation**

For every worker we have to choose a schedule `1,2,3`.
Two workers that are incompatible must obtain different schedules.
The other two conditions are automatically satisfied:

* each schedule can contain at most `n` workers – we never assign more than `n`
  workers in total,
* the sum of the identifiers is between `n` (all `1`) and `3n` (all `3`).

Therefore the whole problem is exactly the **3‑colourability** problem for an
undirected graph with `n ≤ 40` vertices.

The graph is small, so a classic backtracking search with a good vertex order
solves it fast enough.

--------------------------------------------------------------------

#### Data structures
* `adj[i]` – bitmask of neighbours of vertex `i` (`0 … n‑1`).
* `order` – vertices sorted by decreasing degree (most constrained first).
* `color[i]` – current colour of vertex `i` (`-1` = uncoloured, otherwise `0,1,2`).

--------------------------------------------------------------------

#### Backtracking

```
dfs(pos):
    if pos == n:               # all vertices coloured
        return True
    v = order[pos]             # next vertex to colour
    forbidden = 0
    for each neighbour u of v:
        if color[u] != -1:
            forbidden |= 1 << color[u]      # colour already used by a neighbour
    for c in 0,1,2:
        if not (forbidden >> c) & 1:        # colour c is allowed
            color[v] = c
            if dfs(pos+1):
                return True
            color[v] = -1
    return False
```

*The neighbour loop is performed with bit operations, which is fast for `n ≤ 40`.*

The recursion depth is at most `n = 40`.  
The worst‑case search tree is `3^40`, but the graph is sparse (average degree
`< n`) and the ordering by degree prunes heavily; in practice it finishes far
below the time limit.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs `YES` with a valid schedule assignment
iff such an assignment exists.

---

##### Lemma 1  
During the execution of `dfs`, the invariant holds:

> For every already coloured vertex `v`, all its neighbours have a different colour.

**Proof.**  
A vertex receives a colour only after checking `forbidden`, which contains the
colours of all already coloured neighbours. The chosen colour `c` is not in
`forbidden`, therefore none of the coloured neighbours uses `c`. ∎



##### Lemma 2  
If `dfs(pos)` returns `True`, the array `color` is a proper 3‑colouring of the
whole graph.

**Proof.**  
`True` is returned only when `pos == n`, i.e. every vertex has been coloured.
By Lemma&nbsp;1 the invariant holds for all vertices, therefore no edge connects
two equal colours – the colouring is proper. ∎



##### Lemma 3  
If a proper 3‑colouring exists, `dfs(0)` returns `True`.

**Proof.**  
Consider any proper colouring `C`. The recursion tries colours for the vertices
in the fixed order `order`.  
Induction on `pos`:

*Base*: `pos = 0`. Vertex `v = order[0]` can be coloured with `C(v)` because
none of its neighbours is coloured yet, so `C(v)` is not forbidden.

*Induction step*: assume the recursive calls have already coloured the first
`pos` vertices exactly as in `C`. For vertex `v = order[pos]` all neighbours
that appear earlier in `order` are already coloured exactly as in `C`; neighbours
later in the order are still uncoloured. Hence `C(v)` is not among the forbidden
colours and the algorithm will try it (maybe after trying other colours).  
Thus there exists a recursive branch that follows `C` for the first `pos+1`
vertices. By induction a branch reaches `pos = n` and returns `True`. ∎



##### Lemma 4  
If `dfs(0)` returns `False`, no proper 3‑colouring exists.

**Proof.**  
Assume a proper 3‑colouring existed. By Lemma&nbsp;3 the algorithm would find a
branch that follows this colouring and would return `True`. Contradiction. ∎



##### Theorem  
The program prints  

* `YES` and a schedule assignment that satisfies all constraints **iff**
  such an assignment exists,
* otherwise prints `NO`.

**Proof.**  

*If the program prints `YES`*: it did so because `dfs(0)` returned `True`.
By Lemma&nbsp;2 the produced `color` array is a proper 3‑colouring.
Translating colours `0,1,2` to identifiers `1,2,3` yields a schedule
assignment. The other two constraints are always fulfilled, so the assignment
is valid.

*If a valid assignment exists*: it is a proper 3‑colouring, therefore by
Lemma&nbsp;3 `dfs(0)` returns `True` and the program prints `YES`.

*If the program prints `NO`*: `dfs(0)` returned `False`; by Lemma&nbsp;4 no
proper 3‑colouring exists, hence no valid assignment exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n ≤ 40`.

*Building adjacency masks*: `O(n + m)`.
*Backtracking*: each recursive step scans neighbours of one vertex.
With bit masks this is `O(deg(v))`.  
Overall worst‑case time is `O(3^n)`, but for the given limits and the sparse
graphs the actual running time is far below the 2 s limit (empirically well
under a few milliseconds).

Memory consumption: adjacency masks (`n` integers) + colour array = `O(n)`.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [0] * n
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    # order vertices by decreasing degree
    order = sorted(range(n), key=lambda x: -adj[x].bit_count())

    color = [-1] * n

    def dfs(pos: int) -> bool:
        if pos == n:
            return True
        v = order[pos]
        # collect colours used by already coloured neighbours
        forbidden = 0
        nb = adj[v]
        while nb:
            u = (nb & -nb).bit_length() - 1
            nb &= nb - 1
            cu = color[u]
            if cu != -1:
                forbidden |= 1 << cu
        for c in range(3):
            if not (forbidden >> c) & 1:
                color[v] = c
                if dfs(pos + 1):
                    return True
                color[v] = -1
        return False

    if dfs(0):
        out = ['YES']
        out.append(' '.join(str(c + 1) for c in color))
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
