**Solution Explanation**

The problem asks for a partition of the vertices of a given undirected graph into three
sets (zones) such that adjacent vertices are never placed in the same set.
That is exactly a *3‑coloring* problem.

`n ≤ 40`, therefore an exponential backtracking search with good pruning easily fits
into the limits.

--------------------------------------------------------------------

#### 1.   Data structures  

* `adj[v]` – list of neighbours of vertex `v` (0‑based indices).  
* `color[v]` – assigned colour (`0,1,2`) or `-1` if not assigned yet.  
* `mask[v]` – 3‑bit mask of still possible colours for `v`.  
  bit `i` (`1<<i`) is set iff colour `i` is still allowed.  
  Initially `mask[v] = 0b111` for every vertex.

--------------------------------------------------------------------

#### 2.   Backtracking with forward checking  

When we assign a colour `c` to a vertex `v`

```
color[v] = c
mask[v] = 1<<c
for each neighbour u of v:
        if colour u not fixed yet:
                remove c from mask[u]
                if mask[u] becomes 0 → conflict → undo and backtrack
```

All modifications of `mask` are stored on a stack
(`changes = [(u, old_mask), …]`) so they can be undone when we backtrack.

--------------------------------------------------------------------

#### 3.   Variable ordering (MRV)

At each recursion step we pick an *uncoloured* vertex with the **minimum**
number of still possible colours (`popcount(mask[v])`).  
If a vertex has only one possible colour we are forced to use it – this gives strong
pruning.

--------------------------------------------------------------------

#### 4.   Recursion

```
def dfs():
        if all vertices coloured → success
        choose vertex v with smallest popcount(mask[v]) (MRV)
        for each colour c whose bit is set in mask[v]:
                record current stack size
                assign colour c to v (updating neighbours)
                if dfs(): return True
                undo all changes back to recorded stack size
        return False
```

Because `n` is tiny, this simple scheme is fast enough.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm outputs “YES” with a valid assignment
iff such an assignment exists.

---

##### Lemma 1  
During the search `mask[v]` always contains exactly the colours that can still be
assigned to `v` without violating already fixed neighbour colours.

**Proof.**  
Initially all three colours are possible, so the statement holds.
When a vertex `x` gets colour `c`, the algorithm removes `c` from the masks of all
uncoloured neighbours of `x`. No other colours become impossible, because only the
newly fixed vertex can create a new conflict. Hence the invariant is preserved.
Undoing a step restores the previous masks, so the invariant also holds after backtracking. ∎



##### Lemma 2  
If the algorithm reaches a state where some uncoloured vertex has `mask = 0`,
the current partial colouring cannot be extended to a full 3‑colouring.

**Proof.**  
By Lemma&nbsp;1 `mask = 0` means *no* colour can be assigned to that vertex without
conflicting with already coloured neighbours. Any extension would have to colour it,
which is impossible. ∎



##### Lemma 3  
Whenever the algorithm assigns a colour to a vertex, the partial colouring
remains proper (no edge has equal colours on both ends).

**Proof.**  
A colour `c` is assigned to `v` only if `c` is present in `mask[v]`.  
`mask[v]` contains a colour only if none of `v`'s already coloured neighbours uses it
(Lemma&nbsp;1). Therefore the new assignment does not create a conflict. ∎



##### Lemma 4  
If the algorithm returns a complete assignment, it is a valid 3‑colouring.

**Proof.**  
All vertices are coloured, and by Lemma&nbsp;3 the partial colouring was proper at
each step, thus the final colouring is proper. Every colour belongs to `{1,2,3}`.
∎



##### Lemma 5  
If a valid 3‑colouring exists, the depth‑first search will eventually find one.

**Proof.**  
Consider any fixed valid colouring `C`.  
During the search, when the algorithm chooses a vertex `v`, it tries **all**
colours allowed by `mask[v]`. By Lemma&nbsp;1 the colour `C(v)` is always allowed,
because `C` does not conflict with already fixed vertices. Therefore there exists
a branch of the recursion that follows exactly the colours of `C`.  
Since the recursion explores every branch unless it is pruned by a conflict,
the branch corresponding to `C` is never pruned (Lemma&nbsp;2) and reaches a leaf
where all vertices are coloured. Hence the algorithm will find a solution. ∎



##### Theorem  
The program prints “YES” and a zone assignment exactly when such an assignment
exists; otherwise it prints “NO”.

**Proof.**  

*If the program prints “YES”*: by Lemma&nbsp;4 the printed assignment is a proper
3‑colouring, i.e. a feasible deployment.

*If a feasible deployment exists*: by Lemma&nbsp;5 the search will eventually
reach a complete proper colouring and return success, causing the program to
output “YES”.  
If the search exhausts all possibilities without success, no proper colouring
exists, therefore the correct answer is “NO”. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

`n ≤ 40`.  
In the worst case the algorithm explores the full 3‑colouring search tree:
`O(3^n)`.  
The MRV heuristic and forward checking dramatically cut the tree; for the given
limits the program runs well within 2 seconds.

Memory usage: adjacency list `O(n^2)` in worst case, colour array, mask array,
and a stack of at most `n·degree` changes – all `O(n^2)` ≤ a few kilobytes.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * n               # -1 = uncoloured, else 0/1/2
    mask = [0b111] * n             # possible colours bitmask
    changes = []                    # stack of (vertex, old_mask)

    # helper: popcount of 3-bit mask
    popcnt = lambda x: (x & 1) + ((x >> 1) & 1) + ((x >> 2) & 1)

    def assign(v: int, c: int) -> bool:
        """assign colour c to vertex v, update neighbours, record changes.
           return False if conflict arises."""
        color[v] = c
        old_mask = mask[v]
        mask[v] = 1 << c
        changes.append((v, old_mask))
        for nb in adj[v]:
            if color[nb] == -1:
                old = mask[nb]
                if old & (1 << c):
                    new = old & ~(1 << c)
                    if new == 0:
                        # conflict, record change then fail
                        mask[nb] = new
                        changes.append((nb, old))
                        return False
                    if new != old:
                        mask[nb] = new
                        changes.append((nb, old))
        return True

    def undo(to_len: int) -> None:
        """undo changes back to given stack length."""
        while len(changes) > to_len:
            v, old = changes.pop()
            mask[v] = old
            if color[v] != -1 and (old & (1 << color[v])) == 0:
                # vertex was coloured, revert
                color[v] = -1

    def dfs(colored_cnt: int) -> bool:
        if colored_cnt == n:
            return True
        # MRV: choose uncoloured vertex with smallest domain
        best_v = -1
        best_sz = 4
        for v in range(n):
            if color[v] == -1:
                sz = popcnt(mask[v])
                if sz < best_sz:
                    best_sz = sz
                    best_v = v
                    if sz == 1:
                        break
        if best_v == -1 or best_sz == 0:
            return False
        cur_mask = mask[best_v]
        for c in range(3):
            if cur_mask & (1 << c):
                stack_len = len(changes)
                if assign(best_v, c):
                    if dfs(colored_cnt + 1):
                        return True
                undo(stack_len)
        return False

    possible = dfs(0)
    if not possible:
        print("NO")
    else:
        print("YES")
        # convert 0/1/2 to 1/2/3
        print(' '.join(str(color[i] + 1) for i in range(n)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to the
required input‑output format.
