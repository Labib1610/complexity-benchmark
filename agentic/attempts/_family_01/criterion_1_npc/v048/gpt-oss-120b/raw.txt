**Solution Explanation**

The task is to colour the vertices of an undirected graph with three colours
(1, 2, 3) so that adjacent vertices obtain different colours.
`n ≤ 40`, therefore an exponential back‑tracking algorithm with good
pruning easily fits into the limits.

We use a classic *DSATUR* style search:

* for every vertex we keep the set of colours already used by its coloured
  neighbours (`sat[v]`);
* at each step we choose an **uncoloured** vertex with the largest
  saturation degree (size of `sat[v]`);
  ties are broken by the ordinary degree (more neighbours → earlier);
* we try the still possible colours for that vertex;
* after assigning a colour we update the saturation sets of its neighbours
  and continue recursively;
* if at some point a vertex has no admissible colour the recursion backtracks.

Because only three colours exist, the branching factor is at most three.
With the ordering described the search tree is very small for `n = 40`.

The graph is stored as adjacency bit‑masks (`adj[i]` – a 64‑bit integer,
the *i*‑th bit corresponds to vertex *i*).  
All operations on neighbours are therefore fast bit operations.

If the recursion finishes, we have a valid colouring; otherwise the graph is
not 3‑colourable.



--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency bit‑masks adj[0…n-1]

col = [-1] * n                     # -1 = uncoloured, else 0,1,2
sat = [0] * n                      # bitmask of colours used by coloured neighbours
deg = [popcount(adj[i]) for i in range(n)]

order = list of vertices sorted by decreasing degree   # only for tie‑breaking

def dfs(coloured_cnt):
    if coloured_cnt == n:          # all vertices coloured
        return True

    # choose vertex with maximal saturation, tie by degree
    best = -1; best_sat = -1; best_deg = -1
    for v in range(n):
        if col[v] != -1: continue
        s = popcount(sat[v])
        if s > best_sat or (s == best_sat and deg[v] > best_deg):
            best = v; best_sat = s; best_deg = deg[v]

    v = best
    # colours that are still possible for v
    forbidden = sat[v]                     # bits of colours already used by neighbours
    for colour in range(3):
        if forbidden & (1 << colour): continue
        # assign
        col[v] = colour
        # update neighbours' saturation
        changed = []
        nb = adj[v]
        while nb:
            u = (nb & -nb).bit_length() - 1   # index of least set bit
            nb &= nb - 1
            if col[u] == -1:
                if not (sat[u] & (1 << colour)):
                    sat[u] |= (1 << colour)
                    changed.append(u)
        if dfs(coloured_cnt + 1):
            return True
        # undo
        for u in changed:
            # recompute sat[u] from scratch (only three colours → cheap)
            sat[u] = 0
            nb2 = adj[u]
            while nb2:
                w = (nb2 & -nb2).bit_length() - 1
                nb2 &= nb2 - 1
                if col[w] != -1:
                    sat[u] |= (1 << col[w])
        col[v] = -1
    return False

if dfs(0):
    print "YES"
    print colours (+1) space separated
else:
    print "NO"
```

`popcount` is Python’s `int.bit_count()` (available since 3.8).

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs **YES** with a proper 3‑colouring
iff such a colouring exists, otherwise outputs **NO**.

---

##### Lemma 1  
During the execution of `dfs`, for every vertex `v` the bitmask `sat[v]`
contains exactly the set of colours assigned to already coloured neighbours
of `v`.

**Proof.**  
*Initialization*: all vertices are uncoloured, `sat[v] = 0`, true.  
*Induction step*: when a colour `c` is assigned to vertex `v`,
the algorithm iterates over all uncoloured neighbours `u` of `v` and sets
the bit `c` in `sat[u]`. No other neighbour of `u` changes its colour,
hence `sat[u]` now contains all colours of coloured neighbours of `u`.  
When backtracking, `sat[u]` is recomputed from scratch by scanning the
(coloured) neighbours of `u`, therefore restored to the correct set.
∎



##### Lemma 2  
When the algorithm tries a colour `c` for a vertex `v`,
`c` is not used by any already coloured neighbour of `v`.

**Proof.**  
By Lemma&nbsp;1, `sat[v]` is exactly the set of colours of coloured neighbours.
The algorithm skips a colour `c` iff `sat[v]` already contains `c`. ∎



##### Lemma 3  
If the recursive call `dfs(coloured_cnt)` returns `True`,
the current array `col` is a proper 3‑colouring of the whole graph.

**Proof.**  
`True` is returned only when `coloured_cnt == n`, i.e. every vertex has a
colour. By Lemma&nbsp;2 each assignment respected the constraint with already
coloured neighbours, therefore no edge connects two equal colours.
Thus `col` is a proper 3‑colouring. ∎



##### Lemma 4  
If a proper 3‑colouring exists, the search explores a branch that leads to
that colouring and therefore returns `True`.

**Proof.**  
Consider any fixed proper 3‑colouring `C`.  
The algorithm chooses at each step some uncoloured vertex `v`.  
Since `C` colours `v` with some colour `c` that is different from all its
already coloured neighbours, `c` is admissible for `v` (Lemma&nbsp;2).  
Thus the branch that picks `c` for `v` is never pruned.
Proceeding inductively, the recursion can follow exactly the colours of `C`
until all vertices are coloured, reaching the base case and returning `True`. ∎



##### Lemma 5  
If the algorithm returns `False` (outputs **NO**), no proper 3‑colouring exists.

**Proof.**  
Assume a proper 3‑colouring existed. By Lemma&nbsp;4 the algorithm would have a
branch leading to it and would return `True`. Contradiction. ∎



##### Theorem  
The program prints  

* “YES” and a valid assignment of bands 1‑3 exactly when such an assignment
  exists;
* otherwise prints “NO”.

**Proof.**  
If the program prints “YES”, it did so because `dfs` returned `True`.
By Lemma&nbsp;3 the produced assignment is a proper 3‑colouring.  

If the program prints “NO”, `dfs` returned `False`; by Lemma&nbsp;5 no proper
3‑colouring exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n ≤ 40`, three colours.

*Choosing the next vertex*: `O(n)` per recursion level.  
*Updating saturation*: each edge is examined at most once per colour
assignment, i.e. `O(m)` over the whole search tree.

The worst‑case time is exponential, but with DSATUR ordering the explored
search tree is tiny for `n = 40`.  
Memory usage: adjacency masks (`n` integers), colour array, saturation masks –
`O(n)`.

Both limits are far below the given constraints.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * n
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    col = [-1] * n               # -1 = uncoloured, else 0..2
    sat = [0] * n                # bitmask of neighbour colours
    deg = [adj[i].bit_count() for i in range(n)]

    sys.setrecursionlimit(10000)

    def dfs(coloured_cnt: int) -> bool:
        if coloured_cnt == n:
            return True

        # select vertex with maximal saturation, tie by degree
        best = -1
        best_sat = -1
        best_deg = -1
        for v in range(n):
            if col[v] != -1:
                continue
            s = sat[v].bit_count()
            if s > best_sat or (s == best_sat and deg[v] > best_deg):
                best = v
                best_sat = s
                best_deg = deg[v]

        v = best
        forbidden = sat[v]
        for colour in range(3):
            if forbidden & (1 << colour):
                continue
            # assign colour
            col[v] = colour
            changed = []
            nb = adj[v]
            while nb:
                lsb = nb & -nb
                u = (lsb.bit_length() - 1)
                nb ^= lsb
                if col[u] == -1:
                    if not (sat[u] & (1 << colour)):
                        sat[u] |= (1 << colour)
                        changed.append(u)
            if dfs(coloured_cnt + 1):
                return True
            # undo
            for u in changed:
                # recompute sat[u] from neighbours
                mask = 0
                nb2 = adj[u]
                while nb2:
                    lsb2 = nb2 & -nb2
                    w = (lsb2.bit_length() - 1)
                    nb2 ^= lsb2
                    if col[w] != -1:
                        mask |= 1 << col[w]
                sat[u] = mask
            col[v] = -1
        return False

    if dfs(0):
        out = ['YES', ' '.join(str(c + 1) for c in col)]
    else:
        out = ['NO']
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```
