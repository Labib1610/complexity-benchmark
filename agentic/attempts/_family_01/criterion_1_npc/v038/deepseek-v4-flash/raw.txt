 We have to assign each worker a positive integer code \( s_i \) such that \( s_i^2 \le 9 \), meaning \( s_i \in \{1, 2, 3\} \).  
The constraints say that for each edge \((u, v)\), \( u + v < 2n + 1 \) and \( 2m < n^2 \). This is a hint that the graph is sparse enough for a backtracking solution.

Since \( n \le 40 \) and each node has at most 3 possible values, we can use backtracking with pruning.  
We’ll assign codes one by one, checking constraints with already assigned neighbors.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

colors = [0] * n

def backtrack(idx):
    if idx == n:
        return True
    for c in (1, 2, 3):
        ok = True
        for nb in adj[idx]:
            if colors[nb] == c:
                ok = False
                break
        if ok:
            colors[idx] = c
            if backtrack(idx + 1):
                return True
            colors[idx] = 0
    return False

if backtrack(0):
    print("YES")
    print(" ".join(map(str, colors)))
else:
    print("NO")
```
