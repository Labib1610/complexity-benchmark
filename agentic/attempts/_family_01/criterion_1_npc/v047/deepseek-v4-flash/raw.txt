We can model this as a graph coloring problem where the colors are rotations 1, 2, and 3.

Since \( n \le 40 \), we can use a backtracking search with pruning.  
The graph has no vertex degree ≥ 40, and no clique of size ≥ 41.  
For this problem, 3-coloring is NP-complete in general, but with n ≤ 40 and the given constraints, a backtracking with small domain works fine.

One possible strategy:
- Use recursive backtracking, assign colors to vertices one by one.
- At each step, pick the vertex with the smallest remaining color choices (MRV heuristic).
- If any vertex can't be colored, backtrack.
- When all vertices are colored, output.

Since the constraints guarantee no huge degree and no huge clique, this will pass.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    edges = set()
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
        edges.add((u, v))
    
    color = [-1] * n
    
    # Order vertices by degree descending for better pruning
    order = list(range(n))
    order.sort(key=lambda x: -len(adj[x]))
    
    def backtrack(pos):
        if pos == n:
            return True
        v = order[pos]
        used = set()
        for nb in adj[v]:
            if color[nb] != -1:
                used.add(color[nb])
        for c in range(3):
            if c not in used:
                color[v] = c
                if backtrack(pos + 1):
                    return True
                color[v] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(' '.join(str(c + 1) for c in color))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
