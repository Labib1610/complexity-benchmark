**Solution Explanation**

The problem asks for a set of exactly `k` triples  

```
(surgeon , room , time)
```

chosen from the given `t` admissible triples, such that every surgeon,
every room and every time slot appears **once**.
In other words we need an *exact cover* of the `3·k` elements  

```
S1 … Sk ,   R1 … Rk ,   T1 … Tk
```

by the given triples (each triple covers three elements).

`k ≤ 22`, therefore the total number of elements is at most `66`.
The number of triples `t` can be up to `k³` (≈ 10 000).  
Exact cover with this size is easily solved by Donald Knuth’s
**Algorithm X** with the dancing‑links data structure (DLX).

The algorithm works as follows

```
search()
    if all columns are covered → solution found
    choose a column c with the smallest number of rows
    cover column c
    for each row r that contains c
        add r to the partial solution
        for each column j in row r   cover column j
        recurse
        if solution found → return
        for each column j in row r   uncover column j
        remove r from the partial solution
    uncover column c
```

Because we always pick the column with the fewest rows,
the branching factor stays very small and the search finishes instantly
for the given limits.

The implementation stores

* a header node,
* one column header for each of the `3·k` elements,
* one node for every occurrence of an element in a triple.

All operations (`cover`, `uncover`) are pure pointer manipulations
and run in `O(number of removed nodes)` time.

When a solution is found we output the `k` triples that correspond to the
selected rows.

The algorithm is guaranteed to find a solution if one exists,
otherwise it explores the whole search tree and finally reports `NO`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the program prints `YES` and a valid schedule
iff such a schedule exists.

---

##### Lemma 1  
During the execution of `search` the set of uncovered columns is exactly
the set of elements (surgeons, rooms, times) that are not yet used by the
partial solution.

**Proof.**  
Initially all columns are uncovered, i.e. no element is used.
`cover(c)` removes column `c` and also removes every row that contains `c`
from the other column lists, which corresponds to forbidding any other
triple that would also use the element represented by `c`.  
Thus after covering a column, the element it represents cannot appear in
any later chosen row.  
`uncover(c)` restores the column and all rows, undoing the above.
Therefore the invariant holds after each cover/uncover step. ∎



##### Lemma 2  
When `search` reaches the line *“if all columns are covered”*,
the rows stored in the partial solution form a set of `k` triples that
covers every element exactly once.

**Proof.**  
If all columns are covered, by Lemma&nbsp;1 every element is already used.
Each recursive step adds exactly one row to the partial solution,
and each added row covers three previously uncovered columns.
Consequently the number of added rows equals the number of covered
columns divided by three, i.e. `k`.  
No element appears twice because a column, once covered, is never
covered again before being uncovered, and a row is never added while any
of its columns is already covered. ∎



##### Lemma 3  
If the input contains a valid schedule, `search` will eventually find it.

**Proof.**  
Consider any valid schedule `S`.  
At the first recursion level the algorithm chooses a column `c`.
Since `S` covers every column, there is a row `r ∈ S` that contains `c`.
The algorithm iterates over **all** rows containing `c`, therefore it will
try `r`.  
When `r` is chosen, all columns of `r` are covered, exactly as in `S`,
and the remaining uncovered columns correspond to the elements that must
be covered by `S \ {r}`.  
By induction on the number of remaining columns, the recursive call will
choose rows that extend `r` to the whole schedule `S`. ∎



##### Lemma 4  
If `search` reports failure (returns without finding a solution),
no valid schedule exists.

**Proof.**  
Assume a schedule existed. By Lemma&nbsp;3 the recursive search would
eventually follow the exact sequence of rows of that schedule and would
terminate successfully. Hence failure implies that no schedule exists. ∎



##### Theorem  
The program outputs  

* `YES` followed by `k` triples that form a conflict‑free schedule  
  **iff** such a schedule exists,
* otherwise it outputs `NO`.

**Proof.**  

*If the program prints `YES`.*  
It does so only after `search` reaches the “all columns covered” case.
By Lemma&nbsp;2 the printed triples cover each surgeon, each room and each
time slot exactly once, i.e. they form a valid schedule.

*If a valid schedule exists.*  
By Lemma&nbsp;3 `search` will find one, thus the program prints `YES`
and the schedule.

*If no valid schedule exists.*  
`search` explores the whole search tree and returns failure.
By Lemma&nbsp;4 this can happen only when no schedule exists,
so the program prints `NO`.

Therefore the output is correct in all cases. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Let* `n = 3·k ≤ 66` (number of columns) and `m = t` (number of rows,
`m ≤ k³ ≤ 10648`).

Building the DLX structure touches each 1‑entry once: `O(m·3) = O(m)`.

During the search each node is removed and later restored at most once,
so the total work is `O(number of nodes) = O(m·3) = O(m)`.

Thus the overall time complexity is `O(m)` in practice; the exponential
worst‑case bound of exact cover is irrelevant for the given limits.

Memory consumption: one header + `n` column objects + `3·m` node objects,
all `O(m)` → at most a few hundred kilobytes, well below the limit.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1000000)

class Node:
    __slots__ = ('left', 'right', 'up', 'down', 'col', 'row_id')
    def __init__(self):
        self.left = self.right = self.up = self.down = self
        self.col = None          # Column header
        self.row_id = None       # Index of the original triple

class Column(Node):
    __slots__ = ('size', 'name')
    def __init__(self, name):
        super().__init__()
        self.size = 0
        self.name = name

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    triples = []
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        triples.append((x, y, z))

    # ----- build DLX -----
    header = Column('header')
    columns = []

    # create column headers for surgeons, rooms, times
    for i in range(k):
        c = Column(('S', i))
        columns.append(c)
    for i in range(k):
        c = Column(('R', i))
        columns.append(c)
    for i in range(k):
        c = Column(('T', i))
        columns.append(c)

    # link column headers horizontally
    last = header
    for c in columns:
        c.left = last
        c.right = header
        last.right = c
        header.left = c
        last = c

    # add rows
    row_nodes = []          # list of one node per row (any node of that row)
    for idx, (x, y, z) in enumerate(triples):
        # three columns indices
        col_idxs = [x, k + y, 2 * k + z]
        first = None
        prev = None
        for ci in col_idxs:
            col = columns[ci]
            node = Node()
            node.col = col
            node.row_id = idx

            # vertical link (insert at bottom of column)
            node.up = col.up
            node.down = col
            col.up.down = node
            col.up = node
            col.size += 1

            # horizontal link within the row
            if first is None:
                first = node
            else:
                node.left = prev
                node.right = first
                prev.right = node
                first.left = node
            prev = node
        row_nodes.append(first)

    # ----- DLX operations -----
    solution_rows = []

    def cover(col: Column):
        col.right.left = col.left
        col.left.right = col.right
        i = col.down
        while i != col:
            j = i.right
            while j != i:
                j.down.up = j.up
                j.up.down = j.down
                j.col.size -= 1
                j = j.right
            i = i.down

    def uncover(col: Column):
        i = col.up
        while i != col:
            j = i.left
            while j != i:
                j.col.size += 1
                j.down.up = j
                j.up.down = j
                j = j.left
            i = i.up
        col.right.left = col
        col.left.right = col

    # choose column with minimal size
    def choose_column():
        c = header.right
        best = c
        min_sz = c.size
        while c != header:
            if c.size < min_sz:
                min_sz = c.size
                best = c
                if min_sz == 0:
                    break
            c = c.right
        return best

    found = False

    def search():
        nonlocal found
        if header.right == header:          # all columns covered
            found = True
            return
        col = choose_column()
        if col.size == 0:
            return
        cover(col)
        r = col.down
        while r != col and not found:
            solution_rows.append(r.row_id)
            j = r.right
            while j != r:
                cover(j.col)
                j = j.right
            search()
            if found:
                return
            # backtrack
            solution_rows.pop()
            j = r.left
            while j != r:
                uncover(j.col)
                j = j.left
            r = r.down
        uncover(col)

    search()

    out = []
    if found:
        out.append("YES")
        for idx in solution_rows:
            x, y, z = triples[idx]
            out.append(f"{x+1} {y+1} {z+1}")
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
