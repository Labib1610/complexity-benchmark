**Solution Explanation**

For every protocol we have to choose a triple  

```
(a , b , c)      1 ≤ a , b , c ≤ k
```

All chosen triples have to satisfy  

* each value `1 … k` appears exactly once as a primary channel `a`,
* each value `1 … k` appears exactly once as a backup channel `b`,
* each value `1 … k` appears exactly once as a diagnostic channel `c`.

Consequently the three multisets `{a}` , `{b}` , `{c}` are all equal to `{1,…,k}` and the
required sum condition is automatically fulfilled.
So the problem is:

*pick `k` triples among the given ones such that every number `1…k` is used
once in each coordinate.*

--------------------------------------------------------------------

#### 1.   Reformulation as an exact‑cover problem  

Create three groups of columns

```
A1 … Ak          (primary channel)
B1 … Bk          (backup   channel)
C1 … Ck          (diagnostic channel)
```

Altogether `3·k ( ≤ 66 )` columns.
Each given triple `(a,b,c)` becomes a row that covers exactly three columns
`Aa , Bb , Cc`.

Now we have to select rows so that every column is covered **exactly once**.
That is the classical *exact cover* problem.

--------------------------------------------------------------------

#### 2.   Solving exact cover with backtracking (Algorithm X)

`k ≤ 22`, therefore the solution contains at most 22 rows.
A simple depth‑first search with good pruning solves the instance instantly.

* representation  

```
mask[i]   – bitmask (Python int) of the three columns covered by row i
col_rows[j] – list of rows that contain column j
```

`mask[i]` has at most three bits set, the whole universe fits into one
integer because `3·k ≤ 66`.

* recursive routine  

```
dfs(current_mask):
    if current_mask == full_mask:                     # all columns covered
           success
    choose an uncovered column having the fewest
           still possible rows (minimum branching)
    for every still possible row r that contains this column:
           add r to the partial solution
           if dfs(current_mask | mask[r]) succeeds -> return success
           remove r from the partial solution
    return failure
```

* why it is fast  

  * depth ≤ 22
  * at each recursion step we branch only over rows that
    do **not** intersect the already chosen columns,
    and we always pick the column with the smallest number of such rows.
    In practice the branching factor becomes 1–3, never exploding.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
During the search `current_mask` always equals the union of the masks of the
already selected rows.

**Proof.**  
`current_mask` is initialised with `0`. When a row `r` is added, the
recursive call receives `current_mask | mask[r]`; when the call returns,
the row is removed and the mask is restored.
∎



##### Lemma 2  
A recursive call `dfs(M)` is entered only with a mask `M` that contains
no column twice, i.e. the selected rows are pairwise disjoint.

**Proof.**  
Rows are added only if `mask[r] & M == 0`, i.e. none of their columns
is already set in `M`. Hence after the addition the new mask
still has each column at most once. By induction over the recursion depth
the statement holds for every call. ∎



##### Lemma 3  
If `dfs` reaches `current_mask == full_mask`, the rows stored in the
solution list form a valid deployment.

**Proof.**  
`full_mask` contains exactly the `3·k` different columns.
By Lemma&nbsp;2 the rows are pairwise disjoint, therefore each column appears
once. The three groups of columns correspond to the three coordinates,
hence each number `1…k` occurs once in each coordinate. The number of rows
is `k` because each row contributes three distinct columns. ∎



##### Lemma 4  
If a valid deployment exists, the search will eventually find it.

**Proof.**  
Consider any fixed valid solution **S** (a set of `k` rows).
During the recursion the algorithm always chooses an uncovered column.
That column belongs to some row of **S** that is still unused,
because **S** covers every column exactly once.
The algorithm tries *all* rows that contain the chosen column and are
compatible with the already selected rows.
Since the rows of **S** are pairwise compatible, the branch that picks the
row of **S** is never pruned.
Thus there exists a path of recursive calls that successively picks the
`k` rows of **S**, reaching `full_mask`. ∎



##### Lemma 5  
If the algorithm outputs “NO”, no valid deployment exists.

**Proof.**  
The algorithm explores the whole search tree, backtracking whenever a
partial assignment cannot be extended (either because an uncovered column
has no compatible rows, or because all possibilities were tried without
success). By Lemma&nbsp;4, if a solution existed, at least one leaf of the
tree would be a success and the algorithm would have terminated earlier.
Therefore reaching the root without success means that the tree contains
no leaf with `full_mask`, i.e. no solution exists. ∎



##### Theorem  
The program prints  

* “YES” followed by `k` triples that satisfy all requirements **iff**
  such a set of triples exists; otherwise it prints “NO”.

**Proof.**  

*If the program prints “YES”.*  
It happened after `dfs` returned success, therefore by Lemma&nbsp;3 the
printed triples are a valid deployment.

*If a valid deployment exists.*  
By Lemma&nbsp;4 the backtracking will find it, consequently the program
prints “YES”.  

If the program prints “NO”, by Lemma&nbsp;5 no deployment exists. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*`n = t` rows, `c = 3·k ≤ 66` columns.*

*Pre‑processing*  
building masks and column lists: `O(n)` time, `O(n + c)` memory.

*Search*  

Depth ≤ `k ≤ 22`.  
At each level we examine at most all rows that contain the chosen column,
but only those compatible with the current mask.
In the worst case the algorithm may try every combination of `k` rows:

```
time ≤ Σ_{i=0}^{k}  (branch_i)          (branch_i ≤ n)
```

With the given limits (`k ≤ 22`, `n ≤ 10648`) this upper bound is far
below the allowed 5 seconds; in practice the heuristic column‑with‑fewest
rows makes the search extremely fast (milliseconds).

Memory consumption  

* masks: `n` integers,
* column lists: each row appears three times ⇒ `3n` integers,
* recursion stack depth `k`.

All together well under the 256 MiB limit.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    triples = []
    for _ in range(t):
        a = int(next(it)) - 1          # 0‑based
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        triples.append((a, b, c))

    cols = 3 * k
    full_mask = (1 << cols) - 1

    masks = []               # mask of each row
    col_rows = [[] for _ in range(cols)]   # rows that contain column j

    for idx, (a, b, c) in enumerate(triples):
        m = (1 << a) | (1 << (k + b)) | (1 << (2 * k + c))
        masks.append(m)
        col_rows[a].append(idx)
        col_rows[k + b].append(idx)
        col_rows[2 * k + c].append(idx)

    solution = []            # indices of chosen rows
    used = set()             # for quick test if a row already taken (optional)

    sys.setrecursionlimit(10000)

    def dfs(cur_mask: int) -> bool:
        if cur_mask == full_mask:
            return True

        # choose uncovered column with fewest compatible rows
        uncovered = (~cur_mask) & full_mask
        best_col = -1
        best_cand = None

        while uncovered:
            lsb = uncovered & -uncovered
            col = (lsb.bit_length() - 1)
            uncovered ^= lsb

            cand = []
            for r in col_rows[col]:
                if masks[r] & cur_mask == 0:
                    cand.append(r)
            if not cand:
                return False          # dead end
            if best_cand is None or len(cand) < len(best_cand):
                best_cand = cand
                best_col = col
                if len(best_cand) == 1:
                    break

        for r in best_cand:
            solution.append(r)
            if dfs(cur_mask | masks[r]):
                return True
            solution.pop()
        return False

    if dfs(0):
        out_lines = ["YES"]
        for idx in solution:
            a, b, c = triples[idx]
            out_lines.append(f"{a+1} {b+1} {c+1}")
        sys.stdout.write("\n".join(out_lines))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
