We need to solve a 3-dimensional matching problem with constraints, where:

- We have **k** items in each of three sets (chassis, cores, payloads).
- We have a list of viable triples.
- We need to find exactly **k** triples covering each element exactly once.

This is a **3D matching** problem, which is NP-hard in general, but here k ≤ 22, meaning we might still be able to do something feasible with careful bitmask DP, especially since splitting into exact cover with constraints.

However, the problem can be transformed: Assign each of three types a bitmask, combine into a single mask for **used** triple-stamps)Skip all solutions that don’t find one.

---

### Approach

We can solve with **backtracking with pruning** or **DP over bitmasks**.

- k ≤ 22, so each type has ≤22 items.  
- Total configurations t ≤ k³ = 10648 at maximum.

A direct recursion over triplets could blow up, but we can use **bitmask matching**:

Since we must cover all three sets, every triple corresponds to a combination of a bit from each set.

We can model as:  
- Choose triples so that every bit in all three sets is used exactly once.

Let’s denote triplets as `(c, e, g)`.

We can represent used state as a bitmask: `used_mask = (used_c << (2*k)) | (used_e << k) | used_g` — total bits 3k ≤ 66, fits in Python int.

We can then DFS over **remaining unused chassis** and try only triples with a given chassis index.

---

### Implementation plan:

1. Map triples into three arrays indexed by chassis:  
   `by_chassis[c] = list of (e,g)`  
   Also store in list format for easy access.

2. Recursive function:  
   Input: `chassis_remaining_mask`, `core_mask`, `payload_mask`, and collected solution list.  
   At each step, pick the **lowest unused chassis** (smallest index not used). Find triples starting with that chassis where `e` and `g` are still unused)Skip.

3. Return first found solution.

We have to be careful with early fail conditions (like if a core or payload count doesn't match, etc.). But with k ≤ 22 and t up to 10k, backtracking should be manageable.

---

### Time complexity:

Worst-case branching is high, but pruning by masks helps. Usually, exact cover with small constraints works. We'll implement with bit tricks and memoization if needed.

---

Let’s code:

```python
import sys
sys.setrecursionlimit(1000000)

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    k = int(input_data[0])
    t = int(input_data[1])
    triples = []
    idx = 2
    by_chassis = [[] for _ in range(k)]
    for _ in range(t):
        c = int(input_data[idx]) - 1
        e = int(input_data[idx+1]) - 1
        g = int(input_data[idx+2]) - 1
        idx += 3
        triples.append((c,e,g))
        by_chassis[c].append((e,g))
    
    # Prepare bit masks per chassis: develop list of (core_mask, payload_mask)
    chassis_options = []
    for c in range(k):
        options = []
        for e,g in by_chassis[c]:
            options.append((1 << e, 1 << g))
        chassis_options.append(options)
    
    full_mask = (1 << k) - 1
    solution = []
    
    def dfs(chassis_mask, core_mask, payload_mask):
        if chassis_mask == 0:
            return core_mask == 0 and payload_mask == 0
        # pick first unused chassis
        # get lowest set bit
        c = (chassis_mask & -chassis_mask).bit_length() - 1
        rem_chassis = chassis_mask & ~(1 << c)
        for cmask, pmask in chassis_options[c]:
            if core_mask & cmask == 0 and payload_mask & pmask == 0:
                solution.append((c, cmask.bit_length()-1, pmask.bit_length()-1))
                if dfs(rem_chassis, core_mask | cmask, payload_mask | pmask):
                    return True
                solution.pop()
        return False
    
    if dfs(full_mask, 0, 0):
        print("YES")
        for c,e,g in solution:
            print(c+1, e+1, g+1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
