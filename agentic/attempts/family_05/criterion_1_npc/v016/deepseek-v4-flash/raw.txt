 We need to find a perfect matching in a 3-partite hypergraph where each part has size k, and we need to select k hyperedges such that each vertex appears exactly once.

Since k ≤ 22, we can use a backtracking approach with pruning, or reduce it to a bipartite matching problem by fixing one dimension and matching the other two.

A common approach:
- Fix the assignment of satellites to channels (i.e., try all permutations of satellites).
- For each permutation, check if there exists a perfect matching between frequencies and keys using only the allowed triples.

But k=22 means 22! permutations is too large. Instead, we can use a recursive backtracking that assigns satellites one by one, and for each satellite, tries all possible (frequency, key) pairs that are compatible and not yet used. This is essentially a DFS with pruning.

We can also use a bipartite matching approach:  
- For each satellite, we have a set of (frequency, key) pairs.  
- We need to select one pair per satellite such that all frequencies and keys are used exactly once.  
This is equivalent to finding a perfect matching in a bipartite graph where left side = frequencies, right side = keys, and edges are labeled by which satellites can use them. But we need each satellite to be used exactly once, so it's a 3D matching problem.

Given the constraints (k ≤ 22, t ≤ k³ = 10648), a backtracking with pruning should work if we order the satellites by the number of available pairs (most constrained first).

We'll implement:
1. Read input.
2. Build a list of possible (freq, key) pairs for each satellite.
3. Sort satellites by the number of pairs (ascending).
4. Use DFS: assign pairs to satellites, keeping track of used frequencies and keys.
5. If we assign all satellites, output YES and the triples.

We also need to handle the case where t=0 → NO.

Let's write the code.

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))
    
    # pairs_by_sat[x] = list of (y, z)
    pairs_by_sat = [[] for _ in range(k+1)]
    for _ in range(t):
        x = int(next(it))
        y = int(next(it))
        z = int(next(it))
        pairs_by_sat[x].append((y, z))
    
    # Sort satellites by number of pairs (ascending)
    order = list(range(1, k+1))
    order.sort(key=lambda x: len(pairs_by_sat[x]))
    
    used_freq = [False]*(k+1)
    used_key = [False]*(k+1)
    assignment = [None]*(k+1)  # assignment[sat] = (y, z)
    
    def dfs(idx):
        if idx == k:
            return True
        sat = order[idx]
        for y, z in pairs_by_sat[sat]:
            if not used_freq[y] and not used_key[z]:
                used_freq[y] = True
                used_key[z] = True
                assignment[sat] = (y, z)
                if dfs(idx+1):
                    return True
                used_freq[y] = False
                used_key[z] = False
                assignment[sat] = None
        return False
    
    if dfs(0):
        print("YES")
        for sat in range(1, k+1):
            y, z = assignment[sat]
            print(sat, y, z)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
