**Solution Explanation**

For every resource we create one column:

* satellites `S1 … Sk`
* frequencies `F1 … Fk`
* keys `K1 … Kk`

A compatible configuration `(x , y , z)` is a *row* that covers exactly the three
columns `Sx , Fy , Kz`.

The task is to choose `k` rows so that every column is covered **once**.
That is exactly the *exact cover* problem and can be solved with
Donald Knuth’s **Algorithm X** (DLX – dancing links).  
The instance size is tiny:

* columns ≤ `3·22 = 66`
* rows ≤ `k³ ≤ 10648`

so DLX finishes instantly.

--------------------------------------------------------------------

#### Algorithm
```
read k , t
for each of the t triples (x,y,z)
        create a row containing the three column indices
run DLX (Algorithm X) on the matrix
if a solution is found
        print YES and the k triples belonging to the chosen rows
else
        print NO
```

**DLX details**

* Each column header stores the number of rows still containing it (`size`).
* The heuristic: always pick the column with the smallest `size`
  (minimum branching factor).
* When a row is chosen we
    * remove its three columns,
    * and for every other row that also uses any of those columns we
      remove that row from all columns it appears in.
* Recursion stops when no columns are left – a complete exact cover is built.
* Because every row uses exactly three columns, a solution always contains
  exactly `k` rows.

The implementation follows the classic pointer‑based dancing‑links structure,
but uses Python lists for simplicity – still O(1) operations.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` with a valid set of `k` triples
iff such a set exists.

---

##### Lemma 1  
In the constructed matrix a set of rows covers each column exactly once
iff the corresponding triples use every satellite, frequency and key exactly once.

**Proof.**  
Columns are in one‑to‑one correspondence with the three kinds of resources.
A row contains the three columns of its triple, therefore covering a column
means using the associated resource.  Covering each column exactly once means
each resource appears in exactly one chosen row. ∎



##### Lemma 2  
Algorithm X (DLX) returns a set of rows **iff** an exact cover exists.

**Proof.**  
Algorithm X is a depth‑first search that explores all possible subsets of rows.
*If* it reaches a state with no remaining columns, the selected rows cover every
column exactly once – an exact cover is found and the algorithm returns it.  
*If* an exact cover exists, the recursive search can follow the choices of its
rows; at each step the needed columns are still present, so the recursion never
fails and finally reaches the empty‑column state, thus returning a solution. ∎



##### Lemma 3  
If the algorithm outputs `YES` and the printed triples, they form a valid
configuration.

**Proof.**  
`YES` is printed only when DLX succeeded, i.e. it returned a set of rows that
covers all columns. By Lemma&nbsp;1 the corresponding triples use each satellite,
frequency and key exactly once, which is precisely the required configuration. ∎



##### Lemma 4  
If a valid configuration exists, the algorithm outputs `YES`.

**Proof.**  
A valid configuration corresponds (Lemma&nbsp;1) to an exact cover of the matrix.
By Lemma&nbsp;2 DLX will find such a cover, therefore the program prints `YES`. ∎



##### Theorem  
The program prints `YES` followed by a correct set of `k` triples
iff such a set exists; otherwise it prints `NO`.

**Proof.**  
*If* the program prints `YES`, by Lemma&nbsp;3 the printed triples are a valid
configuration.  
*Only if* a valid configuration exists, Lemma&nbsp;4 guarantees DLX finds an
exact cover, so the program prints `YES`.  
When no configuration exists, DLX explores all possibilities and fails,
hence the program prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*`C = 3k ≤ 66` columns, `R = t ≤ 10648` rows.*

Construction of the DLX structure: `O(R·3)`.

During the search each removal or restoration touches at most the three
columns of a row, i.e. `O(1)` work per row processed.
The worst‑case number of recursive calls is bounded by the number of
different subsets of rows, but with the given limits the total running time
is far below the 5 s limit (empirically well under a second).

Memory consumption: one node per 1‑entry → `3R ≤ 31944` nodes,
plus column headers → `O(C)`. All fit easily into the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1000000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    # column indices: 0..k-1 satellites, k..2k-1 frequencies, 2k..3k-1 keys
    rows = []          # list of (col1, col2, col3, original triple)
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        rows.append((x, k + y, 2 * k + z, (x + 1, y + 1, z + 1)))

    # ---------- DLX structures ----------
    n_cols = 3 * k
    # header node 0, column headers 1..n_cols
    size = [0] * (n_cols + 1)          # number of nodes in column
    col = [0] * (3 * t + n_cols + 1)   # column of each node
    up = [0] * (3 * t + n_cols + 1)
    down = [0] * (3 * t + n_cols + 1)
    left = [0] * (3 * t + n_cols + 1)
    right = [0] * (3 * t + n_cols + 1)

    # initialise column headers linked list
    for i in range(n_cols + 1):
        up[i] = down[i] = i
        left[i] = i - 1
        right[i] = i + 1
    left[0] = n_cols
    right[n_cols] = 0

    node_id = n_cols + 1
    row_head = []          # first node id of each row
    for r_idx, (c1, c2, c3, triple) in enumerate(rows):
        first = None
        for c in (c1, c2, c3):
            nid = node_id
            node_id += 1
            col[nid] = c + 1          # shift by 1 because header is 0
            # vertical links
            up[nid] = up[col[nid]]
            down[nid] = col[nid]
            down[up[nid]] = nid
            up[col[nid]] = nid
            size[col[nid]] += 1
            # horizontal links
            if first is None:
                left[nid] = right[nid] = nid
                first = nid
            else:
                left[nid] = left[first]
                right[nid] = first
                right[left[first]] = nid
                left[first] = nid
        row_head.append(first)

    solution_rows = []

    def cover(c):
        # remove column header
        right[left[c]] = right[c]
        left[right[c]] = left[c]
        i = down[c]
        while i != c:
            j = right[i]
            while j != i:
                down[up[j]] = down[j]
                up[down[j]] = up[j]
                size[col[j]] -= 1
                j = right[j]
            i = down[i]

    def uncover(c):
        i = up[c]
        while i != c:
            j = left[i]
            while j != i:
                size[col[j]] += 1
                down[up[j]] = j
                up[down[j]] = j
                j = left[j]
            i = up[i]
        right[left[c]] = c
        left[right[c]] = c

    def search():
        if right[0] == 0:          # all columns covered
            return True
        # choose column with minimal size
        c = right[0]
        min_sz = size[c]
        cc = c
        while cc != 0:
            if size[cc] < min_sz:
                min_sz = size[cc]
                c = cc
                if min_sz == 0:
                    break
            cc = right[cc]
        if min_sz == 0:
            return False

        cover(c)
        r = down[c]
        while r != c:
            solution_rows.append(r)
            j = right[r]
            while j != r:
                cover(col[j])
                j = right[j]
            if search():
                return True
            # backtrack
            solution_rows.pop()
            j = left[r]
            while j != r:
                uncover(col[j])
                j = left[j]
            r = down[r]
        uncover(c)
        return False

    found = search()
    out = []
    if found:
        out.append("YES")
        # translate node ids back to original triples
        used = set()
        for node in solution_rows:
            # any node of the row gives the row index
            # we can find the row by walking left until header column changes
            # easier: store mapping from first node id to row index
            # we stored row_head list, so find which row contains this node
            # Build a dict once
            pass
    else:
        out.append("NO")
        sys.stdout.write("\n".join(out))
        return

    # Build mapping node->row index
    node_to_row = {}
    for idx, head in enumerate(row_head):
        nid = head
        while True:
            node_to_row[nid] = idx
            nid = right[nid]
            if nid == head:
                break

    for node in solution_rows:
        rid = node_to_row[node]
        triple = rows[rid][3]
        out.append(f"{triple[0]} {triple[1]} {triple[2]}")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
