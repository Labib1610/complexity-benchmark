We can model this as a 3D matching problem, but since k ≤ 22, we can use a backtracking approach with pruning, or reduce it to a bipartite matching problem by fixing one dimension.

A common trick: fix the source order, then for each source, try to match a transformer and destination. This becomes a perfect matching problem in a bipartite graph between transformers and destinations, but we must also ensure each source is used exactly once.

We can solve it with DFS + bitmask DP over sources, maintaining which transformers and destinations are used. Since k ≤ 22, a bitmask of size 2^22 is too large for full DP, but we can use backtracking with pruning and early exit.

Here’s an efficient approach:

- Store routes in a list per source.
- Use recursion: for each source index, try each route, mark transformer and destination as used, recurse.
- If we reach the end and all used, output the routes.

We also add pruning: if at any point the number of remaining sources is greater than the number of unused transformers or unused destinations, fail early.

Let’s implement it.

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    routes_by_source = [[] for _ in range(k)]
    for _ in range(t):
        x, y, z = map(int, input().split())
        routes_by_source[x-1].append((x, y, z))
    
    used_trans = [False] * k
    used_dest = [False] * k
    chosen = []
    
    def dfs(src_idx):
        if src_idx == k:
            return True
        # Prune: if not enough unused transformers/destinations for remaining sources
        remaining = k - src_idx
        if sum(1 for v in used_trans if not v) < remaining:
            return False
        if sum(1 for v in used_dest if not v) < remaining:
            return False
        for route in routes_by_source[src_idx]:
            x, y, z = route
            if not used_trans[y-1] and not used_dest[z-1]:
                used_trans[y-1] = True
                used_dest[z-1] = True
                chosen.append(route)
                if dfs(src_idx + 1):
                    return True
                chosen.pop()
                used_trans[y-1] = False
                used_dest[z-1] = False
        return False
    
    if dfs(0):
        print("YES")
        for r in chosen:
            print(*r)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
