**Solution Explanation**

For every pocket we are given a triple  

```
(x , y , z) ,   1 ≤ x , y , z ≤ k
```

We have to choose exactly `k` triples such that

* all `x` values are different,
* all `y` values are different,
* all `z` values are different.

Because there are `k` different values on each axis, a feasible set must contain **each**
value `1 … k` once on every axis.  
So we have to cover the following `3·k` items

```
X1 … Xk ,   Y1 … Yk ,   Z1 … Zk
```

by `k` triples, each triple covering exactly three items (`Xi , Yj , Zℓ`).

That is exactly the **exact cover** problem.  
`k ≤ 22` ⇒ at most `66` items, while the number of triples (`t`) is at most `k³ ≤ 10648`.  
Exact cover with this size is easily solved by Donald Knuth’s *Algorithm X* (DLX).

--------------------------------------------------------------------

#### 1.   DLX data structure

*Columns* – one for each item (`X1…Xk , Y1…Yk , Z1…Zk`).  
*Rows* – one for each given triple, containing the three columns belonging to it.

The classic doubly‑linked list representation is used:

```
U, D, L, R   – up, down, left, right links
C            – column header of a node
S[col]       – number of nodes in a column (size)
```

The header node `head` links all column headers horizontally.

All operations are `O(1)`:

* **cover(col)** – removes a column and all rows that contain it.
* **uncover(col)** – restores them (exact inverse).

--------------------------------------------------------------------

#### 2.   Search

```
search():
    if head.R == head:               # no columns left → solution found
        return True
    choose column c with minimal S[c]   # heuristic
    cover(c)
    for each row r in column c (downwards):
        add r to current solution
        for each node j in row r (rightwards):
            cover( C[j] )
        if search(): return True
        # backtrack
        for each node j in row r (leftwards):
            uncover( C[j] )
        remove r from solution
    uncover(c)
    return False
```

The recursion depth never exceeds `k ≤ 22`.

--------------------------------------------------------------------

#### 3.   Building the matrix

For a triple `(x, y, z)` we map its three coordinates to column indices

```
colX = x-1                     (0 … k-1)
colY = k + (y-1)                (k … 2k-1)
colZ = 2k + (z-1)               (2k … 3k-1)
```

If a column receives no rows, the problem is impossible immediately.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints “YES” and a correct set of `k` triples
iff such a set exists.

---

##### Lemma 1  
During the execution of `search` the set of uncovered columns is exactly the set of items that are still not covered by the rows already chosen in the current partial solution.

**Proof.**  
Initially all columns are uncovered, no items are covered – true.  
When a row `r` is added to the partial solution, `cover` is called for each column appearing in `r`. `cover` removes that column and all rows that contain it, i.e. marks the corresponding item as covered. No other columns are affected.  
When backtracking, `uncover` restores exactly those columns, undoing the covering. ∎



##### Lemma 2  
If `search` reaches the line `if head.R == head` then the rows stored in the solution list form a set of `k` triples that covers every `X`, `Y` and `Z` exactly once.

**Proof.**  
`head.R == head` means no column remains uncovered. By Lemma&nbsp;1 all items are covered.  
Each chosen row covers three distinct columns (its three coordinates).  
Because a column is removed after the first row that contains it, no later row can contain the same column – therefore each item appears in exactly one chosen row.  
Exactly `k` rows are needed to cover `3k` items, and the recursion depth equals the number of chosen rows, so we have `k` rows. ∎



##### Lemma 3  
If a set of `k` non‑interfering triples exists, `search` will eventually find it and return `True`.

**Proof.**  
Consider any such solution `S`.  
At the first recursive level the algorithm chooses a column `c`.  
Since `S` covers all columns, `c` belongs to some row `r∈S`.  
`cover(c)` does not delete `r` (rows are deleted only if they contain `c`, which `r` does).  
The loop iterates over all rows of column `c`, therefore it will try `r`.  
When `r` is selected, all other columns of `r` are covered, exactly as in `S`.  
Inductively, after selecting the first `i` rows of `S`, the remaining uncovered columns are precisely those covered by the still‑unselected rows of `S`.  
Thus the recursive call will again have a column belonging to some remaining row of `S`, and the algorithm can continue following `S`.  
Consequently the recursion can follow the whole solution and reaches the base case, returning `True`. ∎



##### Lemma 4  
If `search` returns `False`, no set of `k` non‑interfering triples exists.

**Proof.**  
`search` explores *all* possible exact covers: for the currently uncovered columns it tries every row that contains the chosen column, and recurses after covering the corresponding columns.  
If a complete cover existed, Lemma&nbsp;3 shows that there is a path in this search tree leading to the base case, which would make the function return `True`.  
Since it returns `False`, the tree contains no such leaf, i.e. no exact cover exists. ∎



##### Theorem  
The program outputs  

* “YES” and a list of `k` triples **iff** a non‑interfering selection of `k` pockets exists;  
* otherwise it outputs “NO”.

**Proof.**  

*If the program prints “YES”.*  
It did so only after `search` succeeded. By Lemma&nbsp;2 the printed triples form a set covering each `X`, `Y`, `Z` exactly once, i.e. a valid non‑interfering selection.

*If a valid selection exists.*  
The corresponding exact cover exists, therefore by Lemma&nbsp;3 `search` finds it and returns `True`. The program then prints “YES” and that selection.

*If the program prints “NO”.*  
That happens only when `search` returns `False`. By Lemma&nbsp;4 no exact cover (hence no valid selection) exists.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Let* `n = 3k ≤ 66` (columns) and `m = t ≤ k³ ≤ 10648` (rows).

* Building the structure: `O(m·3)` = `O(m)`.
* Each recursive step covers at most `k` columns and removes at most `m` nodes,
  but thanks to the DLX constant‑time operations the total work is proportional
  to the number of nodes visited.
* In the worst case the algorithm may explore many branches, but with `k ≤ 22`
  the search space is tiny; the program easily fits into the 5 s limit.

Memory consumption: one node per 1‑entry → `3·m ≤ 32000` nodes,
each storing a few integers → well below the 256 MB limit.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    triples = []
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        triples.append((x, y, z))

    ncol = 3 * k                     # columns: X0..Xk-1, Y0..Yk-1, Z0..Zk-1
    # DLX structures
    max_nodes = 3 * t + ncol + 1     # + header
    U = [0] * max_nodes
    D = [0] * max_nodes
    L = [0] * max_nodes
    R = [0] * max_nodes
    C = [0] * max_nodes
    S = [0] * (ncol + 1)             # column sizes, 0..ncol-1, header at ncol

    head = ncol                      # index of header node
    # initialise column headers
    for i in range(ncol):
        U[i] = D[i] = i
        L[i] = i - 1 if i > 0 else head
        R[i] = i + 1 if i + 1 < ncol else head
        C[i] = i
    L[head] = ncol - 1
    R[head] = 0
    U[head] = D[head] = head
    C[head] = head

    node_cnt = ncol + 1  # next free index

    row_id_of_node = [0] * max_nodes   # to retrieve original triple
    # add rows
    for rid, (x, y, z) in enumerate(triples):
        cols = [x, k + y, 2 * k + z]
        first = -1
        for col in cols:
            nd = node_cnt
            node_cnt += 1
            C[nd] = col
            row_id_of_node[nd] = rid

            # vertical links
            U[nd] = U[col]
            D[nd] = col
            D[U[col]] = nd
            U[col] = nd
            S[col] += 1

            # horizontal links
            if first == -1:
                L[nd] = R[nd] = nd
                first = nd
            else:
                L[nd] = L[first]
                R[nd] = first
                R[L[first]] = nd
                L[first] = nd

    # if any column has size 0, impossible
    for col in range(ncol):
        if S[col] == 0:
            print("NO")
            return

    solution_rows = []

    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    found = False

    def search():
        nonlocal found
        if R[head] == head:
            found = True
            return True
        # choose column with minimal size
        c = R[head]
        min_s = S[c]
        col = c
        j = R[c]
        while j != head:
            if S[j] < min_s:
                min_s = S[j]
                col = j
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(col)
        r = D[col]
        while r != col:
            solution_rows.append(row_id_of_node[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search():
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution_rows.pop()
            r = D[r]
        uncover(col)
        return False

    if search():
        print("YES")
        for rid in solution_rows:
            x, y, z = triples[rid]
            print(x + 1, y + 1, z + 1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to the required input‑output format.
