**Solution Explanation**

For every specialist `x (1 … k)`, every machine `y (1 … k)` and every time slot `z (1 … k)` we create a
column in an exact‑cover matrix  

```
column 0 … k‑1           – specialist x
column k … 2k‑1          – machine     y
column 2k … 3k‑1         – time slot   z
```

For every allowed triple `(x , y , z)` we create one row that contains the three
columns belonging to this triple.
Choosing `k` rows that cover each column exactly once is *exactly* the required
set of crews.

The classic algorithm for exact cover is **Algorithm X** (Donald Knuth) together
with the **Dancing Links** data structure.  
`k ≤ 22`, therefore the matrix has at most `3·k ≤ 66` columns and at most
`k³ ≤ 10648` rows – tiny for DLX, the search finishes instantly.

The algorithm

```
search()
    if no column left → all columns covered → solution found
    choose column c with the smallest number of rows (heuristic)
    for each row r that contains c
        add r to the partial solution
        cover all columns of r   (remove them and all rows that intersect them)
        if search() succeeds → propagate success
        uncover the columns again (backtrack)
    return failure
```

Because every recursive level fixes one crew, the recursion depth never exceeds
`k`.  The worst case is exponential, but with the small limits it easily fits
into the time limit.

If a solution is found we output the stored rows, i.e. the triples
`(x , y , z)`.  Otherwise we output `NO`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of crews iff such a
set exists.

---

##### Lemma 1  
A set `S` of allowed triples is a valid crew assignment **iff** the rows
corresponding to `S` form an exact cover of the `3k` columns.

**Proof.**  
*If*: each specialist, machine and time slot appears in exactly one triple of
`S`. Hence each column (one per element) is covered exactly once – an exact
cover.

*Only‑if*: an exact cover uses every column exactly once, therefore each
specialist, each machine and each time slot occurs in exactly one selected row,
i.e. in exactly one chosen triple. ∎



##### Lemma 2  
During the execution of `search` the set of rows already chosen always forms a
partial exact cover: no two chosen rows share a column.

**Proof.**  
When a row `r` is chosen, `cover` removes **all** columns of `r` from the matrix,
and also removes every other row that contains any of those columns.
Consequently no later chosen row can contain a column already used.
∎



##### Lemma 3  
If `search` reaches the line “no column left”, the rows stored in the current
partial solution constitute a complete exact cover.

**Proof.**  
“No column left” means every column has been removed by previous `cover`
operations. By Lemma&nbsp;2 the chosen rows never overlap, therefore each column
has been removed exactly once, i.e. is covered exactly once. The number of
chosen rows is `k` because each row covers three distinct columns and there are
`3k` columns. ∎



##### Lemma 4  
If a complete exact cover exists, `search` will eventually find it.

**Proof.**  
Consider any exact cover `C`. The first recursive call chooses a column `c`.
Since `c` belongs to some row `r∈C`, that row is among the rows iterated in the
loop. When the algorithm tries `r`, it covers exactly the columns of `r`,
removing all rows that conflict with `r`. All remaining rows of `C` are still
present because they are disjoint from `r`. The recursive call now works on a
smaller exact‑cover instance (size `k‑1`). By induction the algorithm will
eventually follow the choices of `C` and reach the leaf where no column remains.
∎



##### Lemma 5  
If `search` reports failure, no exact cover exists.

**Proof.**  
Assume the contrary: an exact cover `C` exists but the algorithm backtracks
from the current state without success. The algorithm tries **every** row that
covers the selected column `c`. One of those rows belongs to `C` (as in Lemma 4).
Choosing that row leads to a recursive call that, by the same argument,
must succeed because the remaining part of `C` is still present.
Thus the algorithm cannot backtrack past that choice – contradiction. ∎



##### Theorem  
The program outputs  

* `YES` followed by `k` triples that use every specialist, machine and time
  slot exactly once **iff** such a set of triples exists;
* otherwise it outputs `NO`.

**Proof.**  

*If the program prints `YES`*: it printed the rows stored when `search`
terminated with “no column left”. By Lemma 3 these rows form a complete exact
cover, and by Lemma 1 they correspond to a valid crew assignment.

*If a valid crew assignment exists*: by Lemma 1 there is an exact cover.
Lemma 4 guarantees that `search` will find it, therefore the program reaches the
successful leaf and prints `YES` and the corresponding triples.

*If the program prints `NO`*: `search` terminated with failure.
By Lemma 5 no exact cover exists, and by Lemma 1 no valid crew assignment
exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*`C = 3k ≤ 66` columns, `R ≤ k³ ≤ 10648` rows.*

Construction of the DLX structure: `O(C + R)`.

During the search each recursive level removes at most `k` rows and `3`
columns, and the total work over the whole recursion tree is bounded by the
number of visited nodes times `O(k)`.  
In the worst case the tree size is exponential, but with the given limits the
actual running time is far below the 5 s limit (empirically well under a few
milliseconds).

Memory consumption: the DLX nodes are `4·R` (four pointers per 1‑entry) →  
`O(R) ≤ 4·10⁴` nodes, well under the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    # columns: 0..k-1   specialists
    #          k..2k-1  machines
    #          2k..3k-1 time slots
    ncol = 3 * k

    rows = []          # list of triples (x,y,z)
    row_cols = []      # list of column indices for each row

    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        cols = [x, k + y, 2 * k + z]
        rows.append((x + 1, y + 1, z + 1))
        row_cols.append(cols)

    # ---------- DLX structures ----------
    # header node is 0, column nodes are 1..ncol
    max_nodes = 1 + ncol + len(row_cols) * 3 + 5
    U = [0] * max_nodes
    D = [0] * max_nodes
    L = [0] * max_nodes
    R = [0] * max_nodes
    C = [0] * max_nodes          # column of a node
    S = [0] * (ncol + 1)         # size of column (only for column headers)

    # initialise column headers linked horizontally
    for i in range(ncol + 1):
        U[i] = D[i] = i
        L[i] = i - 1
        R[i] = i + 1
    L[0] = ncol
    R[ncol] = 0

    node_id = ncol + 1

    # add rows
    for r, cols in enumerate(row_cols):
        first = -1
        for col in cols:
            col_node = col + 1          # column header index (1‑based)
            # create node
            C[node_id] = col_node
            # vertical links
            U[node_id] = U[col_node]
            D[node_id] = col_node
            D[U[col_node]] = node_id
            U[col_node] = node_id
            S[col_node] += 1
            # horizontal links within the row
            if first == -1:
                first = node_id
                L[node_id] = R[node_id] = node_id
            else:
                L[node_id] = L[first]
                R[node_id] = first
                R[L[first]] = node_id
                L[first] = node_id
            node_id += 1

    solution_rows = []

    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    found = False

    def search():
        nonlocal found
        if R[0] == 0:          # no columns left
            found = True
            return True
        # choose column with minimal size
        c = R[0]
        min_s = S[c]
        j = R[c]
        while j != 0:
            if S[j] < min_s:
                min_s = S[j]
                c = j
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(c)
        r = D[c]
        while r != c:
            solution_rows.append(r)   # store a node belonging to the row
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search():
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution_rows.pop()
            r = D[r]
        uncover(c)
        return False

    if search():
        # translate stored nodes back to row indices
        # each stored node belongs to a row; we can retrieve the row by walking left until column header
        output = []
        for node in solution_rows:
            cols = []
            j = node
            while True:
                col = C[j] - 1
                cols.append(col)
                j = R[j]
                if j == node:
                    break
            # cols contains three column indices
            # map back to (x,y,z)
            x = cols[0] if cols[0] < k else (cols[1] if cols[1] < k else cols[2])
            # find which is specialist, machine, time
            spec = next(c for c in cols if c < k)
            mach = next(c for c in cols if k <= c < 2 * k) - k
            tim  = next(c for c in cols if 2 * k <= c) - 2 * k
            output.append((spec + 1, mach + 1, tim + 1))
        sys.stdout.write("YES\n")
        for triple in output:
            sys.stdout.write(f"{triple[0]} {triple[1]} {triple[2]}\n")
    else:
        sys.stdout.write("NO\n")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
