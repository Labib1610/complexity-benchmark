Looking at this problem, we need to find a perfect matching in a 3-partite 3-uniform hypergraph where each part has k vertices. This is the 3-dimensional matching problem.

**Key observations:**
- k ≤ 22, so we can use bitmask DP over one dimension (e.g., shifts)
- The constraint "sum of three identifiers ≤ 66" and "no specialist in more than 484 configurations" are hints about the problem structure but the core approach is bitmask DP
- For each subset of shifts (bitmask), we track which (specialist, machinery) pairs are achievable
- We need to find if the full mask (all k shifts) can be achieved with all k specialists and k machinery units used exactly once

**Approach:**
- Group configurations by shift
- For each shift, precompute the set of (specialist, machinery) pairs available
- DP: `dp[mask]` = set of bitmasks representing which (specialist, machinery) pair combinations are achievable using exactly the shifts in `mask`
- For efficiency, represent the (specialist, machinery) state as a bitmask of size k² where bit `i*k + j` means specialist i+1 is paired with machinery j+1
- But we need both specialists and machinery to be fully covered, so we track which specialists and which machinery are used
- Use a dictionary mapping (used_specialists_mask, used_machinery_mask) to the actual assignment for reconstruction

Since k ≤ 22, the specialist and machinery masks are each up to 2^22, but the number of reachable states is limited by the problem constraints.

Let me implement a cleaner approach: iterate over shifts, and for each shift, try all valid (specialist, machinery) pairs from its configurations, maintaining a set of reachable (specialist_mask, machinery_mask) states.

```python
import sys
from collections import defaultdict

def solve():
    input_data = sys.stdin.read().split()
    idx = 0
    k = int(input_data[idx]); idx += 1
    t = int(input_data[idx]); idx += 1
    
    # Group configurations by shift
    by_shift = defaultdict(list)
    for _ in range(t):
        x = int(input_data[idx]); idx += 1
        y = int(input_data[idx]); idx += 1
        z = int(input_data[idx]); idx += 1
        by_shift[z].append((x, y))
    
    full = (1 << k) - 1
    
    # DP: state = (spec_mask, mach_mask) -> list of (shift, x, y) for reconstruction
    # We process shifts 1..k
    # dp maps (spec_mask, mach_mask) -> parent info for reconstruction
    
    # Use iterative approach
    # dp is a dict: (spec_mask, mach_mask) -> (prev_spec_mask, prev_mach_mask, shift, x, y)
    
    dp = {}
    dp[(0, 0)] = None  # initial state
    
    for shift in range(1, k + 1):
        configs = by_shift.get(shift, [])
        if not configs:
            # This shift has no configurations, impossible
            print("NO")
            return
        
        new_dp = {}
        for (spec_mask, mach_mask), _ in dp.items():
            for (x, y) in configs:
                si = x - 1
                mi = y - 1
                if (spec_mask >> si) & 1:
                    continue
                if (mach_mask >> mi) & 1:
                    continue
                new_spec = spec_mask | (1 << si)
                new_mach = mach_mask | (1 << mi)
                key = (new_spec, new_mach)
                if key not in new_dp:
                    new_dp[key] = (spec_mask, mach_mask, shift, x, y)
        dp = new_dp
        if not dp:
            print("NO")
            return
    
    # Check if full state is reachable
    target = (full, full)
    if target not in dp:
        print("NO")
        return
    
    # Reconstruct
    result = []
    cur = target
    while dp[cur] is not None:
        prev_spec, prev_mach, shift, x, y = dp[cur]
        result.append((x, y, shift))
        cur = (prev_spec, prev_mach)
    
    print("YES")
    for x, y, z in result:
        print(x, y, z)

solve()
```
