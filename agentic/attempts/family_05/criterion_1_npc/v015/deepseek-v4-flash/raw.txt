We need to deploy exactly k triples using each compute node, image, and shard exactly once.

This is a **3-dimensional matching** problem, which is NP-hard in general, but here k ≤ 22, so we can use a smart backtracking + pruning approach or dynamic programming with bitmasks.

Since k is small (≤ 22), we can use recursion with memoization.  
We represent the state as a bitmask of used compute nodes, used images, and used shards, but that’s too large (2^22 * 2^22 * 2^22 impossible).

Better:  
We fix one dimension (say compute nodes) and match the other two as a bipartite matching problem, but we need all three to match exactly.

We can use recursion + bitmask on compute nodes, and maintain used images and shards via bitmasks as well.

Because k ≤ 22, we can do:

- Precompute for each compute node, a list of (image, shard) pairs.
- Recursively assign each compute node one valid pair, ensuring no image or shard is reused.
- Use bitmask on images (k bits) and shards (k bits) to track usage.

We memoize on (compute node index, image_mask, shard_mask) — but image_mask and shard_mask are each up to 2^22, too large if combined. However we can prune heavily and search with backjumping.

Alternative: Use bipartite matching to test feasibility, and then greedily assign when possible.  
Actually, since k ≤ 22, we can do DFS with pruning and it should be fast.

Let’s implement:

- We have `options[x]` = list of (y, z) for compute node x.
- We try to assign compute nodes in order.
- We keep `used_img` and `used_shard` bitmasks.
- At each step, for each (y, z) in options[x], if not used, mark, recurse, unmark.
- If we reach k assignment → success.

To speed up, we can sort compute nodes by number of options (smallest degree first) for branch pruning.

We must also check if every resource is used exactly once: each compute node gets 1 instance, each image gets 1 instance, each shard gets 1 → exactly k instances.

Let’s code it.

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    k = int(next(it))
    t = int(next(it))
    
    options = [[] for _ in range(k)]
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        options[x].append((y, z))
    
    # Sort nodes by degree for better backtracking
    order = sorted(range(k), key=lambda i: len(options[i]))
    
    used_img = 0
    used_shard = 0
    assignment = [None] * k
    
    # Memoization dictionary
    memo = {}
    
    def dfs(idx):
        if idx == k:
            return True
        node = order[idx]
        for y, z in options[node]:
            img_bit = 1 << y
            shard_bit = 1 << z
            if (used_img & img_bit) or (used_shard & shard_bit):
                continue
            used_img |= img_bit
            used_shard |= shard_bit
            assignment[node] = (node + 1, y + 1, z + 1)
            state = (idx + 1, used_img, used_shard)
            if state not in memo:
                memo[state] = dfs(idx + 1)
            if memo[state]:
                return True
            used_img ^= img_bit
            used_shard ^= shard_bit
        return False
    
    if dfs(0):
        print("YES")
        for ans in assignment:
            print(*ans)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
