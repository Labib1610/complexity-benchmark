 We need to select exactly k triples from the approved list such that each x, y, and z from 1..k appears exactly once. This is a 3-dimensional matching problem, but with k ≤ 22, we can use a backtracking approach with pruning.

We can model it as:  
- We have k appetizers, k mains, k desserts.  
- We need to pick k triples, each using distinct x, y, z.

We can solve with recursive backtracking, choosing an appetizer in order, and trying all possible mains and desserts for it that are still unused.

Since k ≤ 22, worst-case backtracking could be heavy, but with pruning and the fact that we only need one solution, it should be fine.

We'll store approved triples in a dictionary: for each x, a list of (y, z) pairs.

We'll also keep track of used y and z.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    # Map from x -> list of (y, z)
    options = [[] for _ in range(k+1)]
    for _ in range(t):
        x, y, z = map(int, input().split())
        options[x].append((y, z))
    
    used_y = [False] * (k+1)
    used_z = [False] * (k+1)
    result = []
    
    def dfs(x):
        if x > k:
            return True
        for y, z in options[x]:
            if not used_y[y] and not used_z[z]:
                used_y[y] = True
                used_z[z] = True
                result.append((x, y, z))
                if dfs(x+1):
                    return True
                result.pop()
                used_y[y] = False
                used_z[z] = False
        return False
    
    if dfs(1):
        print("YES")
        for x, y, z in result:
            print(x, y, z)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
