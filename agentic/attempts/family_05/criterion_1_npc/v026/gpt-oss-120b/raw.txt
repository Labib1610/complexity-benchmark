**Solution Explanation**

For every stable linkage we have a triple  

```
(array x , target y , band z)      1 ≤ x , y , z ≤ k
```

We have to choose exactly `k` triples so that each number `1 … k` appears
once in the first coordinate, once in the second coordinate and once in the
third coordinate.
That is an *exact cover* problem:

* columns – one column for every possible element  
  `A1 … Ak` (arrays), `T1 … Tk` (targets), `B1 … Bk` (bands) – altogether `3·k`
  columns;
* rows – one row for every given triple, containing the three columns that
  correspond to its three numbers.

We have to select a set of rows that covers every column exactly once.

`k ≤ 22`, therefore at most `66` columns and at most `k³ ≤ 10648` rows.
The classic algorithm **DLX** (Dancing Links, Donald Knuth) solves exact cover
instances of this size easily.

--------------------------------------------------------------------

#### Algorithm
```
read k , t
for each of the t triples (x,y,z)
        create a row containing columns  x-1,
                                      k + (y-1),
                                      2k + (z-1)

run DLX (Algorithm X with dancing‑links)
        if a solution of exactly k rows is found
                output YES and the stored triples
        else   output NO
```

**DLX details**

* Each column header stores the number of rows still containing this column
  (`size`).  
* The column with the smallest `size` is chosen (heuristic – reduces branching).
* When a row is chosen, the row and all columns it covers are *removed*,
  together with every other row that also uses any of those columns.
* The recursion continues until all columns are removed – a complete cover.
* Backtracking restores the removed nodes.

The recursion depth never exceeds `k` (we need exactly `k` rows), therefore the
search tree is tiny for the given limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of `k` linkages
iff such a set exists.

---

##### Lemma 1  
In the constructed exact‑cover instance, a set of rows covers all columns
exactly once **iff** the corresponding triples use every array, every target
and every band exactly once.

**Proof.**  
Columns are in one‑to‑one correspondence with the three kinds of IDs.
A row contains precisely the three columns belonging to its triple.
Thus a column is covered exactly once ⇔ the ID belonging to that column
appears in exactly one selected triple. ∎



##### Lemma 2  
If the DLX search returns a collection `S` of rows, then `S` is a set of
`k` rows that covers all columns exactly once.

**Proof.**  
DLX stops only when the header list of columns is empty – every column has
been removed, i.e. covered.  
During the search a column is removed only together with the chosen row that
covers it, and all other rows containing that column are also removed.
Therefore no column can be covered by two different rows.
The recursion depth equals the number of chosen rows; when all columns are
gone the depth is exactly `k` because there are `3k` columns and each row
covers three of them. ∎



##### Lemma 3  
If a perfect synthesis of `k` linkages exists, DLX will find one.

**Proof.**  
Consider any exact cover `C` (exists by Lemma&nbsp;1).  
Algorithm X explores the search tree that contains **all** possible
subsets of rows; it never discards a branch that could still lead to a
complete cover.  
Since `C` is a leaf of this tree, the depth‑first search will eventually
reach it and return success. ∎



##### Lemma 4  
If DLX reports failure, no perfect synthesis exists.

**Proof.**  
DLX exhaustively enumerates every possible subset of rows that could cover
all columns (again because it only prunes a branch when a column has no
remaining rows, i.e. the branch cannot be completed).  
If none of the leaves is a full cover, then no exact cover exists.
By Lemma&nbsp;1 this means no set of `k` triples with the required property
exists. ∎



##### Theorem  
The program outputs  

* `YES` followed by `k` triples that use each array, each target and each
  band exactly once **iff** such a set exists;
* otherwise it outputs `NO`.

**Proof.**  

*If the program prints `YES`.*  
It printed the rows returned by DLX. By Lemma&nbsp;2 they form an exact cover,
hence by Lemma&nbsp;1 the printed triples satisfy the required condition.

*If a valid set exists.*  
By Lemma&nbsp;3 DLX finds an exact cover, therefore the program prints `YES`
and a correct set.

*If the program prints `NO`.*  
That happens only when DLX fails, and by Lemma&nbsp;4 no exact cover (hence
no valid set) exists.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*`C = 3k ≤ 66` columns, `R = t ≤ 10648` rows.*

Construction: `O(R)`.

DLX operations are `O(1)` per node; the total number of nodes is `3R`.
The search explores at most the number of recursive calls equal to the
solution size `k` plus backtracking steps. In the worst case it could be
exponential, but with `C ≤ 66` and the strong heuristic (choose column with
fewest rows) the practical running time is far below the limit.

Memory consumption: one node per 1‑entry → `3R ≤ 31944` nodes,
each node stores four integer links → well under the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(1000000)

class DLXNode:
    __slots__ = ('left', 'right', 'up', 'down', 'col', 'row_id')
    def __init__(self):
        self.left = self.right = self.up = self.down = self
        self.col = None          # Column header
        self.row_id = -1         # index of the original row (triple)

class ColumnNode(DLXNode):
    __slots__ = ('size', 'name')
    def __init__(self, name):
        super().__init__()
        self.size = 0
        self.name = name

class DLX:
    def __init__(self, n_cols):
        self.header = ColumnNode('header')
        self.cols = [ColumnNode(i) for i in range(n_cols)]
        # link column headers horizontally
        last = self.header
        for c in self.cols:
            c.left = last
            c.right = self.header
            last.right = c
            self.header.left = c
            last = c
        self.solution = []          # list of chosen row nodes
        self.row_nodes = []         # keep reference to any node of each row

    def add_row(self, row_id, columns):
        first = None
        for col_idx in columns:
            col = self.cols[col_idx]
            node = DLXNode()
            node.col = col
            node.row_id = row_id
            # vertical links
            node.up = col.up
            node.down = col
            col.up.down = node
            col.up = node
            col.size += 1
            # horizontal links
            if first is None:
                first = node
                node.left = node.right = node
            else:
                node.left = first.left
                node.right = first
                first.left.right = node
                first.left = node
        self.row_nodes.append(first)

    # cover a column
    def cover(self, col):
        col.right.left = col.left
        col.left.right = col.right
        i = col.down
        while i != col:
            j = i.right
            while j != i:
                j.down.up = j.up
                j.up.down = j.down
                j.col.size -= 1
                j = j.right
            i = i.down

    # uncover a column (reverse of cover)
    def uncover(self, col):
        i = col.up
        while i != col:
            j = i.left
            while j != i:
                j.col.size += 1
                j.down.up = j
                j.up.down = j
                j = j.left
            i = i.up
        col.right.left = col
        col.left.right = col

    def search(self, k):
        if self.header.right == self.header:   # all columns covered
            return True
        # choose column with minimal size
        c = self.header.right
        min_sz = c.size
        col = c
        while c != self.header:
            if c.size < min_sz:
                min_sz = c.size
                col = c
                if min_sz == 0:
                    break
            c = c.right
        if min_sz == 0:
            return False
        self.cover(col)
        r = col.down
        while r != col:
            self.solution.append(r)
            j = r.right
            while j != r:
                self.cover(j.col)
                j = j.right
            if self.search(k + 1):
                return True
            # backtrack
            self.solution.pop()
            j = r.left
            while j != r:
                self.uncover(j.col)
                j = j.left
            r = r.down
        self.uncover(col)
        return False

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        triples.append((x, y, z))

    n_cols = 3 * k
    dlx = DLX(n_cols)
    for idx, (x, y, z) in enumerate(triples):
        dlx.add_row(idx, [x, k + y, 2 * k + z])

    if dlx.search(0):
        out = ['YES']
        for node in dlx.solution:
            rid = node.row_id
            x, y, z = triples[rid]
            out.append(f"{x+1} {y+1} {z+1}")
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
