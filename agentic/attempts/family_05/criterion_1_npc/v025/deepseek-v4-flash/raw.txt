We can model this as a 3‑dimensional matching problem, but with the given constraints (k ≤ 22, t ≤ 10648), we can use a backtracking approach with pruning, or reduce it to a flow problem.

A practical approach is to use **recursive backtracking with bitmasks** for sources and detectors, and a matching for reflection nodes. Since k is small (≤ 22), we can try to assign each source a reflection node and detector.

We’ll implement a backtracking that:
- Tries to match each source in order.
- For each source, tries all viable combinations.
- Uses bitmasks to track used detectors and reflection nodes.
- Prunes when impossible.

Here’s the code:

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    k = int(next(it))
    t = int(next(it))
    
    # Store viable combinations per source
    combos = [[] for _ in range(k)]
    for _ in range(t):
        x = int(next(it)) - 1
        y = int(next(it)) - 1
        z = int(next(it)) - 1
        combos[x].append((y, z))
    
    # Sort combos for deterministic behavior
    for i in range(k):
        combos[i].sort()
    
    used_ref = [False] * k
    used_det = [False] * k
    chosen = [None] * k
    
    # Precompute for pruning: for each source, list of possible (ref, det) pairs
    # We'll do backtracking
    
    def backtrack(src_idx):
        if src_idx == k:
            return True
        for y, z in combos[src_idx]:
            if not used_ref[y] and not used_det[z]:
                used_ref[y] = True
                used_det[z] = True
                chosen[src_idx] = (src_idx + 1, y + 1, z + 1)
                if backtrack(src_idx + 1):
                    return True
                used_ref[y] = False
                used_det[z] = False
        return False
    
    if backtrack(0):
        print("YES")
        for x, y, z in chosen:
            print(x, y, z)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
