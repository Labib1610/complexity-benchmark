We need to pick exactly k triples (x, y, z) such that :  

- Each processor number 1…k appears exactly once.
- Each sensor number 1…k appears exactly once.
- Each transmitter number 1…k appears exactly once.

This is a **3D matching** problem, which is NP-hard in general.  
With k up to 22, brute force over all permutations is impossible.  
But here each coordinate set size is only k, so we can model as a **bipartite matching** after fixing one dimension.

A known approach:  
- Fix the permutation of processors (or sensors).  
- Then we need to match sensors to transmitters, using allowed triples, given the processor already used.

But we can't try all k! permutations for k=22.

Better: use **maximum matching with backtracking** on small k=22 with pruning:

We can treat it as **exact cover** problem and solve via backtracking with bitmask DP:

We store for each processor a bitmask of (sensor, transmitter) pairs possible.

Use recursion:  
- Pick an unused processor (prefer the one with fewest options).  
- Try each (sensor, transmitter) for it and mark them used.

Since k <= 22, this backtracking works if pruning is effective.

We'll implement:

```
maskP: used processors
maskS: used sensors
maskT: used transmitters
```

Recursion with memoization (bitmask states) will be fast because each state is 3 bitmasks of size k = up to 22 bits = ~4 million states worst-case, but most will be pruned.

Let's code it.

```python
import sys
sys.setrecursionlimit(1000000)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    k = int(data[0])
    t = int(data[1])
    triples = []
    idx = 2
    # store for each processor: list of (sensor, transmitter)
    options = [[] for _ in range(k)]
    for _ in range(t):
        x = int(data[idx]) - 1
        y = int(data[idx+1]) - 1
        z = int(data[idx+2]) - 1
        idx += 3
        options[x].append((y, z))
    
    full_mask = (1 << k) - 1
    memo = {}
    chosen = []
    
    def dfs(pmask, smask, tmask):
        if pmask == full_mask:
            return True
        key = (pmask, smask, tmask)
        if key in memo:
            return False  # already failed
        # pick processor with fewest options
        best = -1
        best_len = 10**9
        for i in range(k):
            if not (pmask >> i) & 1:
                cnt = 0
                for y, z in options[i]:
                    if not (smask >> y) & 1 and not (tmask >> z) & 1:
                        cnt += 1
                if cnt < best_len:
                    best_len = cnt
                    best = i
                    if cnt == 0:
                        break
        if best_len == 0:
            memo[key] = True
            return False
        # try options
        for y, z in options[best]:
            if not (smask >> y) & 1 and not (tmask >> z) & 1:
                chosen.append((best, y, z))
                if dfs(pmask | (1 << best), smask | (1 << y), tmask | (1 << z)):
                    return True
                chosen.pop()
        memo[key] = True
        return False
    
    if dfs(0, 0, 0):
        print("YES")
        for x, y, z in chosen:
            print(x+1, y+1, z+1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
