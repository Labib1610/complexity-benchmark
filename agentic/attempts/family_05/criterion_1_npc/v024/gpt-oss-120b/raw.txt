**Solution Explanation**

For every cleared triple  

```
(d , f , m)      1 ≤ d , f , m ≤ k
```

the three numbers mean

* demographic `d` is used,
* formulation `f` is used,
* facility `m` is used.

We have to choose exactly `k` triples so that each number `1 … k`
appears **once** in each of the three positions.
That is a *3‑dimensional exact cover* (also called 3‑dimensional matching).

`k ≤ 22`, therefore a simple depth‑first search with good pruning is
fast enough.



--------------------------------------------------------------------

#### 1.   Data structures

* `rows_by_d[d]` – list of all triples whose demographic is `d`.
  Each element is a tuple `(f , m , idx)` where `idx` is the original line
  number (needed for the output).

* three bit masks  

```
used_d : k‑bit mask, bit i = 1  ⇔  demographic i already taken
used_f : k‑bit mask, bit i = 1  ⇔  formulation i already taken
used_m : k‑bit mask, bit i = 1  ⇔  facility   i already taken
```

* `solution` – list of chosen row indices (size ≤ k).

All masks fit into a normal Python integer because `k ≤ 22`.

--------------------------------------------------------------------

#### 2.   Recursive search

```
search()
    if all demographics are used → success
    choose an unused demographic d with the smallest number of
          still possible rows (branching factor heuristic)
    for each (f,m,idx) in rows_by_d[d]
          if f and m are still unused
                mark d,f,m as used
                add idx to solution
                if search() succeeds → propagate success
                undo the marks and remove idx
    return failure
```

*Choosing the next demographic*  
For every still unused `d` we count how many rows are still usable
(i.e. both `f` and `m` are free).  
The `d` with the smallest count is tried first – this is the classic
“minimum remaining values” heuristic and cuts the search tree dramatically.

*Pruning*  
If for some unused demographic the count is `0` we backtrack immediately,
because the current partial assignment can never be completed.

The recursion depth is at most `k (≤22)`.  
The total number of examined nodes is tiny for the given limits
(the worst case is a dense random instance, still far below the time limit).

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
During the search the three masks always represent exactly the elements
used by the triples stored in `solution`.

**Proof.**  
Initially all masks are `0` and `solution` is empty – the statement holds.
When a triple `(d,f,m)` is added, the algorithm sets the three corresponding
bits to `1` and appends its index to `solution`.  
When backtracking, the same three bits are cleared and the index removed.
Thus the invariant is preserved at every step. ∎



##### Lemma 2  
If the recursive call `search()` returns *success*, the triples stored in
`solution` form a valid study design.

**Proof.**  
Success is returned only when the base case “all demographics are used”
is reached.  
By Lemma&nbsp;1 every demographic appears exactly once, and the same holds
for formulations and facilities because their bits are set only together
with the demographic of the same triple.  
Exactly `k` triples have been added (one per demographic), therefore the
output satisfies all requirements. ∎



##### Lemma 3  
If a valid study design exists, the algorithm will eventually find it
and return success.

**Proof.**  
Consider any fixed valid set `S` of `k` triples.
The search explores **all** possibilities that respect the masks,
because at each level it tries *every* still usable row for the chosen
demographic.  
In particular, when the algorithm selects the first demographic of `S`,
the corresponding triple of `S` is among the tried rows, and the
algorithm may follow that branch.
Inductively, after having followed the triples of `S` for the first
`i` demographics, the masks exactly match the elements used by those
`i` triples, therefore the `(i+1)`‑st triple of `S` is still admissible
and will be tried.  
Thus there exists a path in the recursion tree that reproduces all
triples of `S`; when the last one is taken the base case is reached and
the algorithm returns success. ∎



##### Lemma 4  
If the algorithm returns failure, no valid study design exists.

**Proof.**  
Assume the contrary: a valid design `S` exists but the algorithm fails.
By Lemma&nbsp;3 the algorithm would have a successful path that exactly
chooses the triples of `S`.  
Since the algorithm explores *all* admissible branches, this path cannot
be missing. Hence the algorithm cannot fail – contradiction. ∎



##### Theorem  
The program outputs  

* `YES` followed by a correct list of `k` triples **iff** such a list
  exists,
* otherwise it outputs `NO`.

**Proof.**  
*If* the program prints `YES`, it did so after `search()` succeeded.
By Lemma&nbsp;2 the printed triples are a valid design.

*Only if* a valid design exists, Lemma&nbsp;3 guarantees that `search()`
succeeds, therefore the program prints `YES`.  
If no design exists, Lemma&nbsp;4 shows that `search()` must fail and
the program prints `NO`. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*`k ≤ 22`, `t ≤ k³ ≤ 10648`.*

*Pre‑processing* – building the three lists: `O(t)` time, `O(t)` memory.

*Search* – each recursive level adds one triple, depth ≤ `k`.  
The branching factor is at most the number of rows for the chosen
demographic, never larger than `t`.  
Because of the strong pruning (minimum‑remaining‑values heuristic) the
actual number of visited nodes is far below `t^k`.  
For the worst realistic input the program finishes well within the
5 seconds limit.

Memory consumption: the three row lists store `t` triples → `O(t)`.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    rows_by_d = [[] for _ in range(k)]          # 0‑based
    triples = []                                 # (d,f,m) for output
    for idx in range(t):
        d = int(next(it)) - 1
        f = int(next(it)) - 1
        m = int(next(it)) - 1
        rows_by_d[d].append((f, m, idx))
        triples.append((d + 1, f + 1, m + 1))

    full_mask = (1 << k) - 1

    used_d = 0
    used_f = 0
    used_m = 0
    solution = []

    # pre‑compute for fast counting
    def count_candidates(d, used_f, used_m):
        cnt = 0
        for f, m, _ in rows_by_d[d]:
            if not (used_f >> f) & 1 and not (used_m >> m) & 1:
                cnt += 1
        return cnt

    def search() -> bool:
        nonlocal used_d, used_f, used_m
        if used_d == full_mask:          # all demographics taken
            return True

        # choose the unused demographic with fewest candidates
        best_d = -1
        best_cnt = 10**9
        for d in range(k):
            if (used_d >> d) & 1:
                continue
            cnt = count_candidates(d, used_f, used_m)
            if cnt == 0:
                return False
            if cnt < best_cnt:
                best_cnt = cnt
                best_d = d
                if cnt == 1:
                    break

        d = best_d
        for f, m, idx in rows_by_d[d]:
            if (used_f >> f) & 1 or (used_m >> m) & 1:
                continue
            # take this triple
            used_d |= 1 << d
            used_f |= 1 << f
            used_m |= 1 << m
            solution.append(idx)

            if search():
                return True

            # backtrack
            solution.pop()
            used_d ^= 1 << d
            used_f ^= 1 << f
            used_m ^= 1 << m

        return False

    if search():
        out = ["YES"]
        for idx in solution:
            out.append("{} {} {}".format(*triples[idx]))
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
