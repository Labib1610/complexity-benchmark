We need to choose exactly k triples (x, y, z) such that each x, y, z from 1..k appears exactly once. This is a 3D matching problem, which is NP-hard in general, but k ≤ 22 allows a meet-in-the-middle or bitmask DP approach.

We can model it as:  
- For each specialist x, we have a set of possible (y, z) pairs.  
- We need to assign each x a distinct y and z.

This is equivalent to finding a perfect matching in a 3-partite hypergraph. Since k ≤ 22, we can use DP over subsets of machines and time slots.

**Approach:**  
We use bitmask DP:  
`dp[maskY][maskZ]` = true if we can assign the first `popcount(maskY)` specialists (or some subset) using exactly the machines in `maskY` and time slots in `maskZ`.  
But k=22 means 2^22 * 2^22 is too large. Instead, we can do DP over specialists one by one, storing possible (maskY, maskZ) pairs.

We can use a dictionary or set of reachable states after processing each specialist.  
Start with `{(0,0)}`. For each specialist x, for each allowed (y,z) for that x, we add (maskY | (1<<(y-1)), maskZ | (1<<(z-1))) if not already used.

At the end, check if ( (1<<k)-1, (1<<k)-1 ) is reachable.

Since k ≤ 22, the number of states can blow up, but with pruning and the fact that t ≤ k^3 ≤ 10648, it's feasible.

We also need to reconstruct the solution. We can store for each state the previous state and the triple used.

Let's implement this.

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    allowed = [[] for _ in range(k)]
    for _ in range(t):
        x, y, z = map(int, input().split())
        allowed[x-1].append((y-1, z-1))
    
    full_mask = (1 << k) - 1
    # dp: dict mapping (maskY, maskZ) -> (prev_maskY, prev_maskZ, x, y, z)
    dp = {(0, 0): None}
    
    for x in range(k):
        new_dp = {}
        for (maskY, maskZ), prev in dp.items():
            for y, z in allowed[x]:
                if not (maskY >> y) & 1 and not (maskZ >> z) & 1:
                    new_maskY = maskY | (1 << y)
                    new_maskZ = maskZ | (1 << z)
                    if (new_maskY, new_maskZ) not in new_dp:
                        new_dp[(new_maskY, new_maskZ)] = (maskY, maskZ, x, y, z)
        dp = new_dp
        if not dp:
            print("NO")
            return
    
    if (full_mask, full_mask) not in dp:
        print("NO")
        return
    
    # Reconstruct
    state = (full_mask, full_mask)
    crews = []
    while state != (0, 0):
        prev_maskY, prev_maskZ, x, y, z = dp[state]
        crews.append((x+1, y+1, z+1))
        state = (prev_maskY, prev_maskZ)
    
    print("YES")
    for crew in reversed(crews):
        print(*crew)

if __name__ == "__main__":
    solve()
```
