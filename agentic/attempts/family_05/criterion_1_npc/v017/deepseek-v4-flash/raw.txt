We can model this as a 3D matching problem, but since k ≤ 22, we can use a backtracking approach with pruning, or reduce it to a bipartite matching problem by fixing one dimension and trying all possibilities for the third.

A common approach:  
- Fix the assignment of arms to sensors via bipartite matching, then check if modules can be matched.

We can do it like this:

1. For each arm, store which (sensor, module) pairs are possible.
2. Try all permutations of arms (or use backtracking with pruning) to assign sensors, then check if the remaining modules can be matched.

Since k ≤ 22, backtracking with pruning is feasible if we use bitmasks and early termination.

```python
        arm_options[x-1].append((y-1, z-1))
```

But the above doesn't store the module assignment. Let's fix that by storing both sensor and module during backtracking.

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    arm_options = [[] for _ in range(k)]
    for _ in range(t):
        x, y, z = map(int, input().split())
        arm_options[x-1].append((y-1, z-1))
    
    arm_sensor_modules = [[0]*k for _ in range(k)]
    for arm in range(k):
        for sensor, module in arm_options[arm]:
            arm_sensor_modules[arm][sensor] |= (1 << module)
    
    used_sensors = 0
    used_modules = 0
    sensor_assignment = [-1]*k
    module_assignment = [-1]*k
    
    def backtrack(arm_idx):
        nonlocal used_sensors, used_modules
        if arm_idx == k:
            return True
        for sensor in range(k):
            if (used_sensors >> sensor) & 1:
                continue
            possible_modules = arm_sensor_modules[arm_idx][sensor] & ~used_modules
            if possible_modules == 0:
                continue
            mod_mask = possible_modules
            while mod_mask:
                lsb = mod_mask & -mod_mask
                module = (lsb.bit_length() - 1)
                mod_mask ^= lsb
                used_sensors |= (1 << sensor)
                used_modules |= (1 << module)
                sensor_assignment[arm_idx] = sensor
                module_assignment[arm_idx] = module
                if backtrack(arm_idx + 1):
                    return True
                used_sensors ^= (1 << sensor)
                used_modules ^= (1 << module)
                sensor_assignment[arm_idx] = -1
                module_assignment[arm_idx] = -1
        return False
    
    if backtrack(0):
        print("YES")
        for i in range(k):
            print(i+1, sensor_assignment[i]+1, module_assignment[i]+1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
