We can model this as a matching problem.  
Since each protein enzyme is already paired with a unique guide RNA, we can reduce each viable combination `(x, y, z)` to just `(x, z)` — because `y` is determined by `x`.  

Then the problem becomes:  
We have `k` proteins (left side) and `k` cell cultures (right side), and we need a perfect matching using the given edges.  

We can solve this with a standard bipartite matching algorithm (e.g., Hopcroft–Karp or DFS-based Kuhn's algorithm).  
Since `k ≤ 1200`, Kuhn's algorithm with adjacency lists is fast enough.

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    adj = [[] for _ in range(k)]
    for _ in range(t):
        x, y, z = map(int, input().split())
        adj[x-1].append(z-1)
    
    match_to = [-1] * k  # which protein is matched to each cell culture
    
    def dfs(protein, visited):
        for cell in adj[protein]:
            if not visited[cell]:
                visited[cell] = True
                if match_to[cell] == -1 or dfs(match_to[cell], visited):
                    match_to[cell] = protein
                    return True
        return False
    
    for p in range(k):
        visited = [False] * k
        if not dfs(p, visited):
            print("NO")
            return
    
    # Reconstruct the y (guide RNA) for each protein
    # Since protein i is paired with guide RNA i (1-indexed)
    print("YES")
    for cell, protein in enumerate(match_to):
        print(protein + 1, protein + 1, cell + 1)

if __name__ == "__main__":
    solve()
```
