**Solution Explanation**

For every pilot `p` there is exactly one aircraft `a(p)` that he can fly.
All given clearances for this pilot contain the same aircraft, therefore the
aircrafts are already fixed – we only have to choose a departure window.

The problem becomes:

*We have a bipartite graph with left side = pilots `1 … k`,
right side = windows `1 … k`.  
There is an edge `p – w` iff the clearance `(p , a(p) , w)` exists.
Is there a perfect matching? If yes, output one matching together with the
known aircraft `a(p)`.*

A perfect matching uses every pilot once and every window once, exactly what
the statement requires.

`k ≤ 1200`, `t ≤ k² ≤ 1 440 000`.  
Hopcroft‑Karp finds a maximum matching in `O(E·√V)`  
`≈ 1.5·10⁶·35  < 5·10⁷` operations – easily fast enough.



--------------------------------------------------------------------

#### Algorithm
```
read k , t
adj[p] = list of windows that pilot p can use          (0‑based)
aircraft[p] = the aircraft of pilot p (unknown yet)

for each of the t clearances (p,a,w)
        p-- ; w--
        if aircraft[p] not set: aircraft[p] = a
        add w to adj[p]

run Hopcroft‑Karp on the bipartite graph (pilots ↔ windows)
        pairU[p] = matched window or -1
        pairV[w] = matched pilot   or -1
        BFS builds distance layers,
        DFS augments along shortest alternating paths

if size of matching == k
        output "YES"
        for every pilot p (0 … k‑1)
                print  p+1 , aircraft[p] , pairU[p]+1
else
        output "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints “YES” with a correct schedule
iff such a schedule exists.

---

##### Lemma 1  
For each pilot `p` all given clearances use the same aircraft.
Therefore any schedule that contains a clearance for `p` must use that
aircraft.

**Proof.** Directly from the statement of the problem. ∎



##### Lemma 2  
A set `S` of `k` clearances satisfies all three “exactly once” conditions
(pilots, aircrafts, windows) **iff** the windows chosen for each pilot form a
perfect matching in the pilots‑windows graph constructed by the algorithm.

**Proof.**  
*If part*: a perfect matching gives each pilot a distinct window.
Together with Lemma&nbsp;1 each pilot uses his unique aircraft,
hence every pilot, aircraft and window appears exactly once.

*Only‑if part*: assume a valid schedule `S`.  
Each pilot occurs once in `S`, thus we can map the pilot to the window that
appears together with his clearance. Because windows are also all distinct,
this mapping is a bijection – a perfect matching. ∎



##### Lemma 3  
Hopcroft‑Karp returns a matching of maximum cardinality.

**Proof.** Classic property of the Hopcroft‑Karp algorithm. ∎



##### Lemma 4  
If the algorithm outputs “YES”, the printed clearances form a valid schedule.

**Proof.**  
“YES” is printed only when the matching size equals `k`.  
Thus every pilot `p` is matched to a window `w = pairU[p]`.  
The algorithm prints `(p , aircraft[p] , w)`.  
The edge `(p,w)` exists in the graph, i.e. the clearance was approved.
By Lemma&nbsp;1 the aircraft is correct for the pilot.
All windows are distinct because a matching never uses a vertex twice,
and all pilots are distinct by construction.
Therefore the printed `k` clearances satisfy all required conditions. ∎



##### Lemma 5  
If a valid schedule exists, the algorithm outputs “YES”.

**Proof.**  
A valid schedule yields, by Lemma&nbsp;2, a perfect matching of size `k`.
Maximum matching size is at least the size of any matching,
hence by Lemma&nbsp;3 Hopcroft‑Karp also finds a matching of size `k`.
Consequently the algorithm prints “YES”. ∎



##### Theorem  
The algorithm prints “YES” and a correct schedule **iff** such a schedule
exists; otherwise it prints “NO”.

**Proof.**  
- “YES” ⇒ correct schedule – Lemma&nbsp;4.  
- Existence of a schedule ⇒ “YES” – Lemma&nbsp;5.  
If no schedule exists, the maximum matching size is `< k`,
so the algorithm prints “NO”. ∎

#### Complexity Analysis  

*Reading input* : `O(t)`  
*Hopcroft‑Karp* : `O(E·√V) = O(t·√k)`  
With `k ≤ 1200, t ≤ k²` this is `< 5·10⁷` operations.  

*Memory* :

- adjacency lists: `O(t)` integers  
- a few arrays of size `k`  

Overall `O(k²)` ≤ 1.5 MB, well inside the limits.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    k = next(it)
    t = next(it)

    adj = [[] for _ in range(k)]          # pilot -> list of windows (0‑based)
    aircraft = [0] * k
    have_aircraft = [False] * k

    for _ in range(t):
        p = next(it) - 1
        a = next(it)
        w = next(it) - 1
        if not have_aircraft[p]:
            aircraft[p] = a
            have_aircraft[p] = True
        adj[p].append(w)

    # quick impossibility test
    for p in range(k):
        if not adj[p]:
            print("NO")
            return

    # ---------- Hopcroft‑Karp ----------
    INF = 10 ** 9
    pairU = [-1] * k          # pilot -> window
    pairV = [-1] * k          # window -> pilot
    dist = [0] * k

    def bfs() -> bool:
        q = deque()
        for u in range(k):
            if pairU[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        found = False
        while q:
            u = q.popleft()
            for v in adj[u]:
                pu = pairV[v]
                if pu != -1 and dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    q.append(pu)
                elif pu == -1:
                    found = True
        return found

    sys.setrecursionlimit(10000)

    def dfs(u: int) -> bool:
        for v in adj[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(k):
            if pairU[u] == -1 and dfs(u):
                matching += 1

    # ---------- output ----------
    if matching == k:
        out_lines = ["YES"]
        for p in range(k):
            out_lines.append(f"{p+1} {aircraft[p]} {pairU[p]+1}")
        sys.stdout.write("\n".join(out_lines))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
