**Solution Explanation**

For every chassis `x` the welding step already fixed the navigation unit `y`.
The input guarantees  

* all schematics that contain the same `x` have the same `y`;
* different `x` never share the same `y`.

Therefore a schematic is completely described by the pair `(x , z)` – the
battery `z` that can be used together with the already fixed `(x , y)`.

The problem becomes:

*We have a bipartite graph with left part `X = {1 … k}` (chassis) and right part
`Z = {1 … k}` (batteries).  
Edge `x – z` exists iff the catalogue contains a schematic `(x , y[x] , z)`.  
Choose `k` edges so that each vertex of both sides is incident to exactly one
chosen edge.*

That is exactly the problem of finding a **perfect matching** in a bipartite
graph.

--------------------------------------------------------------------

#### Algorithm
1. Read the input.  
   For each chassis `x` store its navigation unit `y[x]` (the first time we see
   `x`) and add every battery `z` that appears together with `x` to the adjacency
   list `adj[x]`.
2. Run the Hopcroft‑Karp algorithm (maximum bipartite matching in  
   `O(E·√V)`).  
   It returns the size of the maximum matching and the partner of every
   vertex on the right side (`matchZ[z] = x`).
3. If the matching size is `k` we have a perfect matching.
   For every matched pair `(x , z)` output the schematic
   `x  y[x]  z`.
   Otherwise output `NO`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of schematics
iff such a set exists.

---

##### Lemma 1  
For each chassis `x` all schematics in the input have the same navigation unit
`y[x]`, and different chassis have different navigation units.

*Proof.* This is exactly the welding guarantee given in the statement. ∎



##### Lemma 2  
A set of `k` schematics uses every chassis, navigation unit and battery exactly
once **iff** the set of pairs `(x , z)` formed by those schematics is a perfect
matching of the bipartite graph `X – Z`.

*Proof.*  
*If* the schematics use each component once, then each chassis `x` appears in
exactly one schematic, giving exactly one battery `z`. No two schematics can
share the same battery, otherwise that battery would be used twice. Hence the
pairs `(x , z)` are disjoint and cover all vertices – a perfect matching.

*Only‑if* we have a perfect matching, each `x` is matched to a unique `z`.
Because of Lemma&nbsp;1 the navigation unit belonging to `x` is uniquely
determined (`y[x]`). The catalogue contains the schematic `(x , y[x] , z)` –
otherwise the edge would not exist. Using all matched pairs yields `k`
schematics that cover every component exactly once. ∎



##### Lemma 3  
Hopcroft‑Karp returns a matching of maximum cardinality.

*Proof.* Standard property of the Hopcroft‑Karp algorithm. ∎



##### Lemma 4  
If the algorithm outputs `YES`, the printed schematics form a valid solution.

*Proof.* `YES` is printed only when the matching size equals `k`.  
By Lemma&nbsp;3 the matching is maximum, therefore it is a perfect matching.
By Lemma&nbsp;2 the corresponding schematics (using the stored `y[x]`) use each
component exactly once, i.e. they are a valid selection. ∎



##### Lemma 5  
If a valid selection of `k` schematics exists, the algorithm outputs `YES`.

*Proof.* From a valid selection we obtain a perfect matching (Lemma&nbsp;2).
Hence the graph possesses a matching of size `k`.  
Hopcroft‑Karp finds a maximum matching, whose size is at least `k`; but a
matching cannot be larger than `k` because there are only `k` vertices on each
side. Therefore the algorithm finds a matching of size exactly `k` and prints
`YES`. ∎



##### Theorem  
The algorithm prints `YES` and a correct list of schematics **iff** such a
list exists; otherwise it prints `NO`.

*Proof.* Directly from Lemma&nbsp;4 (soundness) and Lemma&nbsp;5 (completeness). ∎



--------------------------------------------------------------------

#### Complexity Analysis  

* `V = 2k ≤ 2400`
* `E = t ≤ k·k ≤ 1 440 000`

Hopcroft‑Karp runs in `O(E·√V)`  
`≤ 1.44·10⁶ · √2400 ≈ 1.44·10⁶ · 49 ≈ 7·10⁷` operations, well inside the limits.  
Memory consumption: adjacency lists `O(E)` plus a few arrays `O(V)` → ≤
~20 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def hopcroft_karp(adj, n_left, n_right):
    # vertices are 1..n_left on left, 1..n_right on right
    INF = 10 ** 9
    pair_u = [0] * (n_left + 1)   # matched right vertex for left u
    pair_v = [0] * (n_right + 1)  # matched left vertex for right v
    dist = [0] * (n_left + 1)

    def bfs():
        q = deque()
        for u in range(1, n_left + 1):
            if pair_u[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while q:
            u = q.popleft()
            if dist[u] < dist[0]:
                for v in adj[u]:
                    if pair_v[v] == 0:
                        if dist[0] == INF:
                            dist[0] = dist[u] + 1
                    elif dist[pair_v[v]] == INF:
                        dist[pair_v[v]] = dist[u] + 1
                        q.append(pair_v[v])
        return dist[0] != INF

    def dfs(u):
        if u == 0:
            return True
        for v in adj[u]:
            if pair_v[v] == 0 or (dist[pair_v[v]] == dist[u] + 1 and dfs(pair_v[v])):
                pair_u[u] = v
                pair_v[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, n_left + 1):
            if pair_u[u] == 0 and dfs(u):
                matching += 1
    return matching, pair_u, pair_v

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    adj = [[] for _ in range(k + 1)]
    y_of = [0] * (k + 1)          # navigation unit for each chassis
    for _ in range(t):
        x = int(next(it))
        y = int(next(it))
        z = int(next(it))
        if y_of[x] == 0:
            y_of[x] = y
        # else y_of[x] already set, guaranteed equal
        adj[x].append(z)

    # quick impossibility check: any chassis without edges
    for x in range(1, k + 1):
        if not adj[x]:
            print("NO")
            return

    match_size, pair_u, _ = hopcroft_karp(adj, k, k)

    if match_size != k:
        print("NO")
        return

    print("YES")
    out_lines = []
    for x in range(1, k + 1):
        z = pair_u[x]
        out_lines.append(f"{x} {y_of[x]} {z}")
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```
