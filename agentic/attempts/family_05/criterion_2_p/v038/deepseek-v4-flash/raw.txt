We can model this as a bipartite matching problem: we need to assign each sensor cluster (which uniquely determines its relay station) a control frequency, using only the viable protocols.

Because each sensor appears with exactly one relay station)Skip.

We can build the graph between sensor clusters and control frequencies: for each viable protocol (u, v, w), add edge from u to w flagged with relay v. Then the condition for a valid assignment is:

- Each sensor gets a distinct relay (guaranteed by input).
- We perform matching from sensors to frequencies: each sensor matched to a distinct frequency, and only via its fixed relay.

This is simply a bipartite matching problem between sensors (u) and frequencies (w), where each protocol gives an edge.

Let’s implement with Hopcroft–Karp for efficiency.

import sys
from collections import deque

input = sys.stdin.readline

def hopcroft_karp(graph, n_left, n_right):
    INF = 10**9
    pair_u = [-1] * n_left
    pair_v = [-1] * n_right
    dist = [0] * n_left

    def bfs():
        q = deque()
        for u in range(n_left):
            if pair_u[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        found = False
        while q:
            u = q.popleft()
            for v in graph[u]:
                u2 = pair_v[v]
                if u2 == -1:
                    found = True
                elif dist[u2] == INF:
                    dist[u2] = dist[u] + 1
                    q.append(u2)
        return found

    def dfs(u):
        for v in graph[u]:
            u2 = pair_v[v]
            if u2 == -1 or (dist[u2] == dist[u] + 1 and dfs(u2)):
                pair_u[u] = v
                pair_v[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(n_left):
            if pair_u[u] == -1 and dfs(u):
                matching += 1
    return matching, pair_u
