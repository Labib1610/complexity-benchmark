**Solution Explanation**

For every specialist `x`

* all feasible crews use the same machine `y[x]`
* the only freedom is the time slot `z`

Choosing a crew for a specialist therefore means choosing a time slot for him.
If we pick a different time slot for each specialist, the machines are already
different (the mapping `x → y[x]` is a permutation) and we obtain a valid set
of `k` crews.

So the whole problem is:

*left side* – specialists `1 … k`  
*right side* – time slots `1 … k`  

There is an edge `x – z` iff the triple `x y[x] z` is given.
We have to know whether this bipartite graph contains a **perfect matching**
(i.e. a matching of size `k`) and we have to output one.

The classic algorithm for maximum bipartite matching in  
`O(E·√V)` time is **Hopcroft‑Karp**.  
With `k ≤ 1200` and `E ≤ k·k` it easily fits into the limits.



--------------------------------------------------------------------

#### Algorithm
```
read k, t
for each of the t triples (x, y, z):
        store y as machine[x]          # the same for all triples of x
        add z to adjacency list adj[x]

run Hopcroft‑Karp on the graph (left = 1..k, right = 1..k)
        get arrays matchL[x] (matched time slot) and matchR[z]

if size of matching == k:
        print "YES"
        for x = 1 .. k:
                print x, machine[x], matchL[x]
else:
        print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct schedule
iff a feasible schedule exists.

---

##### Lemma 1  
For any specialist `x` all feasible crews contain the same machine
`machine[x]`.  

*Proof.* This is given in the statement. ∎



##### Lemma 2  
A set of `k` crews satisfies the problem requirements **iff**
the corresponding set of `k` edges `(x , z)` is a perfect matching
in the bipartite graph.

*Proof.*  

*If* the crews satisfy the requirements, each specialist appears exactly
once, each machine appears exactly once and each time slot appears exactly
once. By Lemma&nbsp;1 the machine of a specialist is uniquely determined,
hence the crews correspond to `k` distinct pairs `(x , z)`. No two pairs share
the same `x` (different specialists) and no two share the same `z`
(different time slots). Thus they form a perfect matching.

*Only‑if* we have a perfect matching. Every left vertex `x` is incident
to exactly one chosen edge, therefore we pick exactly one crew for each
specialist. Because the matching uses each right vertex `z` once,
all time slots are distinct. Machines are distinct automatically,
again by Lemma&nbsp;1. Hence the `k` selected triples form a valid schedule. ∎



##### Lemma 3  
Hopcroft‑Karp returns a matching of maximum cardinality.

*Proof.* Classical property of Hopcroft‑Karp. ∎



##### Lemma 4  
If the algorithm prints `YES`, the printed triples form a feasible schedule.

*Proof.*  
`YES` is printed only when the algorithm found a matching of size `k`.
For every specialist `x` the algorithm outputs the triple
`(x, machine[x], matchL[x])`.  
`matchL[x]` is the time slot matched to `x`, therefore the triples correspond
exactly to the edges of the perfect matching.
By Lemma&nbsp;2 they satisfy all requirements. ∎



##### Lemma 5  
If a feasible schedule exists, the algorithm prints `YES`.

*Proof.*  
A feasible schedule gives, by Lemma&nbsp;2, a perfect matching of size `k`.
Because Hopcroft‑Karp finds a maximum matching (Lemma&nbsp;3),
its size is at least `k`. It cannot be larger than `k` (there are only `k`
left vertices), therefore it equals `k` and the algorithm prints `YES`. ∎



##### Theorem  
The algorithm outputs `YES` and a correct set of `k` crews
iff such a set exists; otherwise it outputs `NO`.

*Proof.* Directly from Lemma&nbsp;4 (soundness) and Lemma&nbsp;5 (completeness). ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*`V = 2k ≤ 2400`*  
*`E = t ≤ k·k ≤ 1 440 000`*

Hopcroft‑Karp runs in `O(E·√V) = O(t·√k)`.  
With the maximal values this is below `2·10⁷` operations, easily inside the
2 s limit.

Memory consumption:

* adjacency lists – `O(E)`
* a few integer arrays of size `O(k)`

Altogether `O(t + k)` ≤ about 12 MB, well under the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    adj = [[] for _ in range(k + 1)]          # 1‑based
    machine = [0] * (k + 1)                   # machine[x]

    for _ in range(t):
        x = int(next(it))
        y = int(next(it))
        z = int(next(it))
        machine[x] = y                         # all same for given x
        adj[x].append(z)

    # ---------- Hopcroft‑Karp ----------
    INF = 10 ** 9
    matchL = [0] * (k + 1)    # specialist -> time slot
    matchR = [0] * (k + 1)    # time slot -> specialist
    dist = [0] * (k + 1)

    def bfs() -> bool:
        q = deque()
        for x in range(1, k + 1):
            if matchL[x] == 0:
                dist[x] = 0
                q.append(x)
            else:
                dist[x] = INF
        reachable_free = False
        while q:
            x = q.popleft()
            for z in adj[x]:
                y = matchR[z]
                if y == 0:
                    reachable_free = True
                elif dist[y] == INF:
                    dist[y] = dist[x] + 1
                    q.append(y)
        return reachable_free

    sys.setrecursionlimit(10000)
    def dfs(x: int) -> bool:
        for z in adj[x]:
            y = matchR[z]
            if y == 0 or (dist[y] == dist[x] + 1 and dfs(y)):
                matchL[x] = z
                matchR[z] = x
                return True
        dist[x] = INF
        return False

    matching = 0
    while bfs():
        for x in range(1, k + 1):
            if matchL[x] == 0 and dfs(x):
                matching += 1

    # ---------- Output ----------
    out = []
    if matching == k:
        out.append(b"YES")
        for x in range(1, k + 1):
            out.append(f"{x} {machine[x]} {matchL[x]}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
