We need to select exactly k complexes such that each protein chain, receptor site, and catalyst enzyme appears exactly once.  

Given the constraints, we can model this as a matching problem. Since each protein chain is uniquely paired with a receptor site, we can reduce the problem to selecting one enzyme per protein chain, with all enzymes distinct.  

We can use a bipartite matching approach: left side = protein chains (or equivalently receptor sites), since they are in one-to-one correspondence), right side = enzymes. Each observed complex gives an edge from its protein chain to its enzyme. We need a perfect matching covering all k protein chains with distinct enzymes.  

We can solve this with a standard DFS-based bipartite matching (Kuhn's algorithm), which is efficient enough for k ≤ 1200.  

Implementation steps:
1. Read k, t.
2. Map each protein chain to its receptor site (given by input).
3. Build adjacency list: for each protein chain x, list of enzymes z from observed complexes.
4. Run bipartite matching to assign each protein chain a distinct enzyme.
5. If matching size == k, output YES and the k complexes (x, receptor[x], assigned_enzyme[x])). Otherwise output NO.

```python
import sys

def solve():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    receptor = [0] * (k + 1)
    adj = [[] for _ in range(k + 1)]
    for _ in range(t):
        x, y, z = map(int, input().split())
        receptor[x] = y
        adj[x].append(z)
    # bipartite matching: left = protein chains 1..k, right = enzymes 1..k
    match_right = [-1] * (k + 1)  # which protein chain is matched to enzyme z
    def dfs(u, visited):
        for v in adj[u]:
            if not visited[v]:
                visited[v] = True
                if match_right[v] == -1 or dfs(match_right[v], visited):
                    match_right[v] = u
                    return True
        return False

    for u in range(1, k+1):
        visited = [False] * (k + 1)
        if not dfs(u, visited):
            # cannot match all
            print("NO")
            return

    # check if all matched
    if all(match_right[1:] != -1):
        print("YES")
        # build output
        for z in range(1, k+1):
            x = match_right[z]
            y = receptor[x]
            print(f"{x} {y} {z}")
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
