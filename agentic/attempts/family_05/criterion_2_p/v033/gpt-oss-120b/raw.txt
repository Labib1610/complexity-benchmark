**Solution Explanation**

For every specialist `x` all allowed triples have the same machine `y`
(the statement guarantees it).  
The same holds for machines – a machine appears only together with one
specialist.
Therefore the allowed triples are of the form  

```
(x , f(x) , z)          (1)
```

where `f` is a bijection between the set `{1 … k}` of specialists and the
set `{1 … k}` of machines.
For a fixed pair `(x , f(x))` many different time slots `z` can be used.
Let  

```
Zx = { z | (x , f(x) , z) is given }                (2)
```

The task becomes

*choose for every specialist `x` exactly one time slot `z ∈ Zx`
such that all chosen time slots are different.*

That is exactly a **perfect matching** problem in a bipartite graph

* left side – the `k` specialists (or the `k` pairs `(x , f(x))`);
* right side – the `k` time slots `1 … k`;
* edge `x – z` exists iff `z ∈ Zx`.

If a perfect matching exists we output the triples
`(x , f(x) , matched_z)`; otherwise the answer is `NO`.

The graph has at most `k` vertices on each side and at most `t` edges
(`t ≤ k·k ≤ 1 440 000`).  
Hopcroft‑Karp runs in `O(E·√V)` – easily fast enough.



--------------------------------------------------------------------

#### Algorithm
```
read k , t
x_to_y[1…k] = 0                # mapping specialist → machine
y_to_x[1…k] = 0                # mapping machine    → specialist
Z[1…k] = empty list            # allowed time slots for each specialist

for each of the t triples (x , y , z):
        if x_to_y[x] == 0: x_to_y[x] = y
        else if x_to_y[x] != y: impossible (contradiction – never happens)
        if y_to_x[y] == 0: y_to_x[y] = x
        else if y_to_x[y] != x: impossible
        append z to Z[x]

# check that every specialist and every machine occurs exactly once
if any x_to_y[x] == 0 or any y_to_x[y] == 0:
        print "NO" and stop
# (the consistency checks above already guarantee that the mapping is a bijection)

# build bipartite graph: left vertices = specialists 1…k,
# right vertices = time slots 1…k, edges = Z[x]
run Hopcroft‑Karp, obtain matching pairU[x] (matched time slot) and pairV[z]

if size of matching < k:
        print "NO"
else:
        print "YES"
        for x = 1 … k:
                y = x_to_y[x]
                z = pairU[x]
                print x y z
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` with a correct set of crews
iff such a set exists.

---

##### Lemma 1  
For every specialist `x` all allowed triples contain the same machine,
and for every machine `y` all allowed triples contain the same specialist.
Consequently the pairs `(x , y)` occurring in the input form a bijection
between the set of specialists and the set of machines.

**Proof.** This is exactly the condition given in the statement.
If a specialist `x` appeared with two different machines,
the condition would be violated, which the input never does.
The same holds for machines.
Because each specialist appears with at most one machine and each
machine with at most one specialist, the relation is a matching.
If every specialist and every machine appears at least once,
the matching is perfect, i.e. a bijection. ∎



##### Lemma 2  
A set of `k` allowed triples uses each specialist, each machine and each
time slot exactly once **iff** the triples correspond to a perfect matching
in the bipartite graph `G = (X , Z , E)` defined by (2).

**Proof.**  
*If* we have such a set of triples, by Lemma&nbsp;1 each specialist `x`
appears together with exactly one machine `f(x)`.  
The chosen triple for `x` contains a time slot `z`.  
All `z` are different, therefore the mapping `x ↦ z` is a bijection between
`X` and `Z`. Because `z ∈ Zx`, the edge `x–z` belongs to `E`. Hence the
chosen edges form a perfect matching of `G`.

*Conversely*, a perfect matching of `G` gives for every specialist `x`
a distinct time slot `z`. The triple `(x , f(x) , z)` is allowed
(because `z ∈ Zx`) and all triples together use each specialist,
each machine (via `f`) and each time slot exactly once. ∎



##### Lemma 3  
Hopcroft‑Karp returns a matching of maximum cardinality in `G`.

**Proof.** Standard property of the Hopcroft‑Karp algorithm. ∎



##### Lemma 4  
If the algorithm prints `YES`, the printed triples form a valid crew
assembly.

**Proof.**  
Printing `YES` means the algorithm found a matching of size `k`.
By Lemma&nbsp;3 this matching is perfect, i.e. each specialist `x`
is matched to a unique time slot `z = pairU[x]` and every time slot is
matched to exactly one specialist.
The printed triple for `x` is `(x , x_to_y[x] , pairU[x])`.
`x_to_y[x]` is the unique machine paired with `x` (Lemma&nbsp;1) and
`pairU[x] ∈ Zx` because edges of `G` are exactly the allowed triples.
Thus every printed triple is allowed, all specialists, machines and
time slots appear exactly once. ∎



##### Lemma 5  
If a valid crew assembly exists, the algorithm prints `YES`.

**Proof.**  
A valid assembly yields, by Lemma&nbsp;2, a perfect matching of `G`.
Therefore the maximum matching size in `G` is `k`.
Hopcroft‑Karp (Lemma&nbsp;3) finds a matching of size `k`,
so the algorithm reaches the `YES` branch. ∎



##### Theorem  
The algorithm outputs `YES` and a correct list of crews
iff such a list exists; otherwise it outputs `NO`.

**Proof.**  
*If* the algorithm outputs `YES`, Lemma&nbsp;4 guarantees the list is
correct.  
*Only if* a correct list exists, Lemma&nbsp;5 guarantees the algorithm
finds a perfect matching and therefore outputs `YES`.  
If no correct list exists, the algorithm cannot find a perfect matching,
hence prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Reading input* – `O(t)`.

*Building the graph* – `O(t)` edges stored.

*Hopcroft‑Karp* – `O(E·√V) = O(t·√k)`.  
With `k ≤ 1200` and `t ≤ k² ≤ 1 440 000` this is well below the limits
(≈ 5·10⁷ elementary operations).

*Memory* – adjacency lists store each edge once: `O(t)` integers,
plus a few arrays of size `k`.  
Maximum memory ≈ a few tens of megabytes, inside the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def hopcroft_karp(adj, n_left, n_right):
    """adj[u] = list of right vertices (1‑based) reachable from left vertex u (1‑based)
       returns pairU[1..n_left], pairV[1..n_right], size of matching
    """
    INF = 10 ** 9
    pairU = [0] * (n_left + 1)
    pairV = [0] * (n_right + 1)
    dist = [0] * (n_left + 1)

    def bfs():
        q = deque()
        for u in range(1, n_left + 1):
            if pairU[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while q:
            u = q.popleft()
            if dist[u] < dist[0]:
                for v in adj[u]:
                    if pairV[v] == 0:
                        if dist[0] == INF:
                            dist[0] = dist[u] + 1
                    elif dist[pairV[v]] == INF:
                        dist[pairV[v]] = dist[u] + 1
                        q.append(pairV[v])
        return dist[0] != INF

    def dfs(u):
        if u == 0:
            return True
        for v in adj[u]:
            if pairV[v] == 0 or (dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v])):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, n_left + 1):
            if pairU[u] == 0 and dfs(u):
                matching += 1
    return pairU, pairV, matching


def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    x_to_y = [0] * (k + 1)
    y_to_x = [0] * (k + 1)
    Z = [[] for _ in range(k + 1)]          # Z[x] = list of allowed time slots

    for _ in range(t):
        x = int(next(it))
        y = int(next(it))
        z = int(next(it))
        if x_to_y[x] == 0:
            x_to_y[x] = y
        elif x_to_y[x] != y:
            # contradictory input – not possible per statement
            print("NO")
            return
        if y_to_x[y] == 0:
            y_to_x[y] = x
        elif y_to_x[y] != x:
            print("NO")
            return
        Z[x].append(z)

    # every specialist and every machine must appear
    for i in range(1, k + 1):
        if x_to_y[i] == 0 or y_to_x[i] == 0:
            print("NO")
            return

    # build adjacency for Hopcroft‑Karp
    adj = [[] for _ in range(k + 1)]   # 1‑based left side (specialists)
    for x in range(1, k + 1):
        adj[x] = Z[x]

    pairU, pairV, match_sz = hopcroft_karp(adj, k, k)

    if match_sz != k:
        print("NO")
        return

    out_lines = ["YES"]
    for x in range(1, k + 1):
        y = x_to_y[x]
        z = pairU[x]
        out_lines.append(f"{x} {y} {z}")
    sys.stdout.write("\n".join(out_lines))


if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
