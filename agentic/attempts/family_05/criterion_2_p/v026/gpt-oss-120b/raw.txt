**Solution Explanation**

For every sensor `s` the processor is already fixed by Phase I.
Let  

```
proc[s] = the processor that is locked to sensor s
```

The only freedom left in Phase II is to choose, for each sensor `s`,
an antenna `a` such that the triple `(s, proc[s], a)` is present in the
input, and each antenna must be used exactly once.
So we have to find a *perfect matching* between the set of sensors
`{1 … k}` and the set of antennas `{1 … k}`.

The input triples give exactly the edges of a bipartite graph:

```
sensor s  –– edge ––>  antenna a    iff   (s, proc[s], a) is listed
```

The task is therefore:

*Does this bipartite graph contain a matching of size `k`?*  
If yes, output any such matching together with the already known processor
for each sensor.

The classic algorithm for maximum bipartite matching in
`O(E·√V)` time is Hopcroft‑Karp, which easily fits the limits
(`k ≤ 1200`, `E ≤ k² ≤ 1.44·10⁶`).

--------------------------------------------------------------------

#### Algorithm
1. Read `k, t`.
2. For each of the `t` triples `(s, p, a)`  
   * store `proc[s] = p` (the first time we see `s`; all later triples
     have the same `p` by the statement).  
   * add edge `s → a` to the adjacency list.
3. Run Hopcroft‑Karp on the bipartite graph `S = {1..k}` (left side) and
   `A = {1..k}` (right side).
4. If the size of the maximum matching is `k`  
   * print `YES`.  
   * for every sensor `s` output `s  proc[s]  match[s]`,
     where `match[s]` is the antenna matched to `s`.
5. Otherwise print `NO`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` with a valid set of channels
iff such a set exists.

---

##### Lemma 1  
For any sensor `s` all input triples containing `s` have the same processor,
and this processor is stored in `proc[s]`.

**Proof.** Directly given by the problem statement (Phase I guarantee). ∎



##### Lemma 2  
A set of `k` channels satisfying Phase II exists **iff**
the bipartite graph defined in step 2 contains a perfect matching.

**Proof.**  
*If* we have a feasible set of channels, each sensor appears exactly once,
each antenna appears exactly once, and the processor of a sensor is fixed.
Thus for every sensor `s` the channel uses some antenna `a` with a listed
triple `(s, proc[s], a)`, i.e. edge `s‑a` exists. The collection of those
edges matches every sensor to a distinct antenna – a perfect matching.

*Only‑if* we have a perfect matching `M`. For each matched pair `(s,a)` the
edge exists, therefore the triple `(s, proc[s], a)` is listed.
Using exactly those `k` triples gives a feasible selection:
each sensor, each processor (by Lemma 1), and each antenna appears once. ∎



##### Lemma 3  
Hopcroft‑Karp returns a matching of maximum cardinality.

**Proof.** Standard property of the Hopcroft‑Karp algorithm. ∎



##### Lemma 4  
If the algorithm prints `YES`, the printed channels form a valid Phase II
selection.

**Proof.** `YES` is printed only when the matching size equals `k`.
By Lemma 3 the matching is maximum, thus it is a perfect matching.
For each sensor `s` we output `(s, proc[s], match[s])`.
The edge `s‑match[s]` exists, so the triple is in the input.
All sensors are distinct, all antennas `match[s]` are distinct (property of a
matching), and processors are distinct because the mapping `s → proc[s]`
is a bijection (Phase I). Hence the output satisfies all requirements. ∎



##### Lemma 5  
If a valid Phase II selection exists, the algorithm prints `YES`.

**Proof.** By Lemma 2 a valid selection yields a perfect matching in the
graph. Therefore the maximum matching size is at least `k`. Since the graph
has only `k` vertices on each side, the maximum size cannot exceed `k`,
so it is exactly `k`. Hopcroft‑Karp finds a matching of this size,
the algorithm prints `YES`. ∎



##### Theorem  
The algorithm outputs `YES` and a correct list of `k` channels
iff such a list exists; otherwise it outputs `NO`.

**Proof.**  
- If the algorithm outputs `YES`, Lemma 4 guarantees correctness.  
- If a correct list exists, Lemma 5 guarantees the algorithm outputs `YES`.  
- In all other cases the algorithm outputs `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building the graph*: `O(t)` time, `O(k + t)` memory.  
*Hopcroft‑Karp*: `O(E·√V) = O(t·√k)` ≤ `1.44·10⁶·√1200` ≈ `5·10⁷` operations,
well within 2 seconds.  
*Output*: `O(k)`.

Overall memory ≤ `O(k + t)` ≤ about 2 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    proc = [0] * (k + 1)          # processor for each sensor
    adj = [[] for _ in range(k + 1)]   # sensor -> list of antennas

    for _ in range(t):
        s = int(next(it))
        p = int(next(it))
        a = int(next(it))
        if proc[s] == 0:
            proc[s] = p
        # else: guaranteed equal, ignore
        adj[s].append(a)

    # Hopcroft‑Karp
    INF = 10 ** 9
    pair_u = [0] * (k + 1)   # sensor -> antenna
    pair_v = [0] * (k + 1)   # antenna -> sensor
    dist = [0] * (k + 1)

    def bfs() -> bool:
        q = deque()
        for u in range(1, k + 1):
            if pair_u[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while q:
            u = q.popleft()
            if dist[u] < dist[0]:
                for v in adj[u]:
                    if pair_v[v] == 0:
                        if dist[0] == INF:
                            dist[0] = dist[u] + 1
                    elif dist[pair_v[v]] == INF:
                        dist[pair_v[v]] = dist[u] + 1
                        q.append(pair_v[v])
        return dist[0] != INF

    def dfs(u: int) -> bool:
        if u == 0:
            return True
        for v in adj[u]:
            pu = pair_v[v]
            if pu == 0 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pair_u[u] = v
                pair_v[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, k + 1):
            if pair_u[u] == 0 and dfs(u):
                matching += 1

    if matching != k:
        sys.stdout.write("NO\n")
        return

    out_lines = ["YES"]
    for s in range(1, k + 1):
        a = pair_u[s]
        out_lines.append(f"{s} {proc[s]} {a}")
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
