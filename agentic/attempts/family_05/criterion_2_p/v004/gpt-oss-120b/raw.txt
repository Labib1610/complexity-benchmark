**Solution Explanation**

For every specialist `x` all allowed triples  

```
(x , y , z)
```

contain the same machine `y`.  
Different specialists use different machines, therefore the mapping  

```
M[x] = y
```

is a permutation of `{1 … k}`.

If we choose a triple for specialist `x` we automatically use his (unique)
machine `M[x]`.  
Consequently the whole problem is reduced to the following one.

*Choose for every specialist `x` exactly one allowed time slot `z`
so that all chosen time slots are different.*

That is a **perfect matching** problem in a bipartite graph

* left side   : specialists `1 … k`
* right side  : time slots `1 … k`
* edge `x – z` exists iff the triple `(x , M[x] , z)` is allowed.

The answer is **YES** iff the bipartite graph contains a matching of size `k`.

The graph has at most `k·k ≤ 1 440 000` edges (`k ≤ 1200`), therefore the
Hopcroft‑Karp algorithm (`O(E·√V)`) easily fits into the limits.

--------------------------------------------------------------------

#### Algorithm
```
read k , t
M[1…k] = 0                               // machine of each specialist
adj[1…k] = empty list                    // allowed time slots for each specialist

for each of the t triples (x , y , z):
        if M[x]==0:   M[x]=y               // first occurrence of specialist x
        else: assert M[x]==y               // guaranteed by the statement
        adj[x].append(z)

if some M[x]==0 or adj[x] empty:
        output NO and stop                 // specialist has no allowed triple

run Hopcroft‑Karp on graph (adj)
let matchL[x] = matched time slot of specialist x   (0 if unmatched)

if number of matched pairs < k:
        output NO
else
        output YES
        for x = 1 … k:
                print  x  M[x]  matchL[x]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` with a valid crew set
iff such a set exists.

---

##### Lemma 1  
For every specialist `x` all allowed triples use the same machine `M[x]`
and different specialists use different machines.

**Proof.** Directly given in the statement. ∎



##### Lemma 2  
Choosing a set `C` of allowed triples uses each machine exactly once
iff `C` contains exactly one triple for each specialist.

**Proof.**  
Because of Lemma&nbsp;1, the machine belonging to a specialist `x` is fixed
to `M[x]`.  
If `C` has one triple for every specialist, then all `k` distinct machines
`M[1] … M[k]` appear exactly once.  
Conversely, if a machine appeared twice, two different specialists would
use the same machine, contradicting Lemma&nbsp;1. ∎



##### Lemma 3  
A set `C` of `k` allowed triples satisfies all three “exactly once”
requirements **iff** the set of edges `{ (x , z) | (x , M[x] , z) ∈ C }`
is a perfect matching between specialists and time slots.

**Proof.**  
*If* `C` satisfies the requirements, by Lemma&nbsp;2 it contains exactly one
triple for every specialist, thus exactly one edge incident to each left
vertex.  
All time slots must also be used exactly once, therefore each right vertex
has degree 1 in the edge set. Hence it is a perfect matching.

*Only‑if* the edge set is a perfect matching, each specialist appears in
exactly one edge, i.e. we pick one allowed triple for him.
All time slots appear exactly once by definition of a perfect matching.
By Lemma&nbsp;2 the machines are also used exactly once. ∎



##### Lemma 4  
Hopcroft‑Karp returns a matching of maximum cardinality.

**Proof.** Standard property of the Hopcroft‑Karp algorithm. ∎



##### Lemma 5  
If the algorithm outputs `YES`, the printed triples form a valid crew set.

**Proof.**  
`YES` is printed only when the matching size returned by Hopcroft‑Karp is `k`.
Thus for every specialist `x` we have a matched time slot `z = matchL[x]`,
and the edge `(x , z)` belongs to the graph, i.e. the triple
`(x , M[x] , z)` is allowed.
The collection of those `k` triples corresponds, by Lemma&nbsp;3, to a perfect
matching, therefore satisfies all three “exactly once” constraints. ∎



##### Lemma 6  
If a valid crew set exists, the algorithm outputs `YES`.

**Proof.**  
From a valid crew set we obtain, by Lemma&nbsp;3, a perfect matching of size `k`
in the bipartite graph.
Since Hopcroft‑Karp finds a maximum matching (Lemma&nbsp;4), its size is at
least `k`. It cannot be larger than `k` (there are only `k` specialists), so it
equals `k`. Consequently the algorithm prints `YES`. ∎



##### Theorem  
The algorithm prints `YES` together with a correct collection of crews
iff such a collection exists; otherwise it prints `NO`.

**Proof.**  
*If* the algorithm prints `YES`, Lemma&nbsp;5 guarantees correctness.  
*Only‑if* a correct collection exists, Lemma&nbsp;6 guarantees the algorithm
prints `YES`. The complementary case yields `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Construction* : `O(t)` time, `O(k + t)` memory.  
*Hopcroft‑Karp* : `O(E·√V) = O(t·√(2k))`.  
With `k ≤ 1200` and `t ≤ k² ≤ 1.44·10⁶` this is below 7·10⁷ operations,
well within the 2 s limit.  
Memory consumption ≤ `O(k + t)` ≈ a few MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def hopcroft_karp(adj, n, m):
    """adj: list (1..n) of list of right vertices (1..m)
       returns matchL (size n+1) where matchL[u]=v or 0
    """
    INF = 10 ** 9
    matchL = [0] * (n + 1)
    matchR = [0] * (m + 1)
    dist = [0] * (n + 1)

    def bfs():
        q = deque()
        for u in range(1, n + 1):
            if matchL[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while q:
            u = q.popleft()
            if dist[u] < dist[0]:
                for v in adj[u]:
                    if matchR[v] == 0:
                        if dist[0] == INF:
                            dist[0] = dist[u] + 1
                    elif dist[matchR[v]] == INF:
                        dist[matchR[v]] = dist[u] + 1
                        q.append(matchR[v])
        return dist[0] != INF

    sys.setrecursionlimit(10000)
    def dfs(u):
        if u == 0:
            return True
        for v in adj[u]:
            if matchR[v] == 0 or (dist[matchR[v]] == dist[u] + 1 and dfs(matchR[v])):
                matchL[u] = v
                matchR[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, n + 1):
            if matchL[u] == 0 and dfs(u):
                matching += 1
    return matchL, matching

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    M = [0] * (k + 1)          # machine of each specialist
    adj = [[] for _ in range(k + 1)]

    for _ in range(t):
        x = int(next(it)); y = int(next(it)); z = int(next(it))
        if M[x] == 0:
            M[x] = y
        # else: guaranteed y == M[x]
        adj[x].append(z)

    # check every specialist has at least one allowed triple
    for x in range(1, k + 1):
        if M[x] == 0 or not adj[x]:
            print("NO")
            return

    matchL, size = hopcroft_karp(adj, k, k)

    if size != k:
        print("NO")
        return

    out_lines = ["YES"]
    for x in range(1, k + 1):
        out_lines.append(f"{x} {M[x]} {matchL[x]}")
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```
