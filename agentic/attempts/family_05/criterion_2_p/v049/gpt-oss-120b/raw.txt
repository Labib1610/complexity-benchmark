**Solution Explanation**

For every operator `x` all recorded tests use the same rig `y`.
Therefore the pair `(x , y)` is fixed – it is a *bijection* between the
`k` operators and the `k` rigs.

The only freedom left is the choice of the zone `z`.
For each operator we may choose **one** of the zones that appear together
with his (unique) rig.
The schedule is valid iff we can choose the zones so that every zone
`1 … k` is used exactly once.

So we have a bipartite graph  

* left side : operators `1 … k`  
* right side: zones `1 … k`  

and an edge `x – z` exists iff the log contains a record `(x , y_x , z)`.
We have to find a *perfect matching* – a matching that covers all `k`
operators (and consequently all `k` zones).

The problem is reduced to a standard maximum bipartite matching problem.
`k ≤ 1200`, `t ≤ k·k ≤ 1 440 000`.  
Hopcroft‑Karp runs in `O(E·√V)` and easily fits into the limits.



--------------------------------------------------------------------

#### Algorithm
```
read k, t
for each operator x store its rig y_x (the first y seen)
build adjacency list adj[x] = list of zones z reachable from x
store for every pair (x , z) the whole record (x , y_x , z)

run Hopcroft‑Karp on the graph (operators ↔ zones)
if size of maximum matching < k:
        print "NO"
else:
        print "YES"
        for each operator x:
                let z = matched zone of x
                output the stored record (x , y_x , z)
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct schedule
iff such a schedule exists.

---

##### Lemma 1  
For any operator `x` all records containing `x` have the same rig `y`.
*Proof.* This is given in the statement (hardware binding). ∎



##### Lemma 2  
A set `S` of `k` records is a valid schedule **iff**
the set of pairs `{ (x , z) | (x , y_x , z) ∈ S }` is a perfect matching
in the bipartite graph defined above.

*Proof.*  
*If* `S` is a schedule, each operator appears exactly once, each zone
exactly once and each rig exactly once.
Because of Lemma&nbsp;1 the rig of an operator is uniquely determined,
so the records of `S` give exactly one incident edge for every operator
and for every zone – a perfect matching.

*Only‑if* we have a perfect matching `M`.  
For each matched edge `(x , z)` we take the (unique) record
`(x , y_x , z)` from the log.
All operators are distinct (left side of matching), all zones are
distinct (right side), and rigs are distinct because the mapping
`x → y_x` is a bijection. Hence the `k` chosen records form a valid
schedule. ∎



##### Lemma 3  
Hopcroft‑Karp returns a matching of maximum cardinality.

*Proof.* Standard property of the Hopcroft‑Karp algorithm. ∎



##### Lemma 4  
If the algorithm prints `YES`, the printed records form a valid schedule.

*Proof.*  
`YES` is printed only when the matching size equals `k`.
By Lemma&nbsp;3 the matching is maximum, thus it is a perfect matching.
By Lemma&nbsp;2 the corresponding records constitute a valid schedule. ∎



##### Lemma 5  
If a valid schedule exists, the algorithm prints `YES`.

*Proof.*  
From a valid schedule we obtain a perfect matching (Lemma&nbsp;2).
Therefore the maximum matching size is at least `k`.
Hopcroft‑Karp finds a matching of size `k`, so the algorithm prints
`YES`. ∎



##### Theorem  
The algorithm outputs `YES` and a correct schedule exactly when such a
schedule exists; otherwise it outputs `NO`.

*Proof.* Directly from Lemma&nbsp;4 (soundness) and Lemma&nbsp;5
(completeness). ∎



--------------------------------------------------------------------

#### Complexity Analysis  

* `V = 2k ≤ 2400`
* `E = t ≤ k² ≤ 1 440 000`

Hopcroft‑Karp: `O(E·√V) = O(k²·√k)`.  
With `k = 1200` this is below `2·10⁷` operations, well inside the 2 s limit.

Memory:

* adjacency lists: `O(E)`
* matching arrays, queues, etc.: `O(V)`

Total ≤ a few tens of MB, below the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    rig_of = [0] * (k + 1)          # y_x
    adj = [[] for _ in range(k + 1)]
    rec = {}                        # (x,z) -> (x,y,z)

    for _ in range(t):
        x = int(next(it)); y = int(next(it)); z = int(next(it))
        if rig_of[x] == 0:
            rig_of[x] = y
        # else: y must equal rig_of[x] by problem guarantee
        adj[x].append(z)
        rec[(x, z)] = (x, y, z)

    # ---------- Hopcroft‑Karp ----------
    INF = 10 ** 9
    pair_u = [0] * (k + 1)   # operator -> zone
    pair_v = [0] * (k + 1)   # zone -> operator
    dist = [0] * (k + 1)

    def bfs() -> bool:
        q = deque()
        for u in range(1, k + 1):
            if pair_u[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while q:
            u = q.popleft()
            if dist[u] < dist[0]:
                for v in adj[u]:
                    if pair_v[v] == 0:
                        if dist[0] == INF:
                            dist[0] = dist[u] + 1
                    elif dist[pair_v[v]] == INF:
                        dist[pair_v[v]] = dist[u] + 1
                        q.append(pair_v[v])
        return dist[0] != INF

    def dfs(u: int) -> bool:
        if u == 0:
            return True
        for v in adj[u]:
            pu = pair_v[v]
            if pu == 0 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pair_u[u] = v
                pair_v[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, k + 1):
            if pair_u[u] == 0 and dfs(u):
                matching += 1

    # ---------- Output ----------
    if matching < k:
        sys.stdout.write("NO\n")
        return

    out_lines = ["YES"]
    for x in range(1, k + 1):
        z = pair_u[x]
        out_lines.append("{} {} {}".format(*rec[(x, z)]))
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
