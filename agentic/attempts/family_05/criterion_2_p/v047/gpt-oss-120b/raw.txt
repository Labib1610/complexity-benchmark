**Solution Explanation**

For every pilot `x` all feasible assignments contain the same mech `y`.
Therefore a schedule that uses each pilot exactly once automatically uses each
mech exactly once – the mech is forced by the pilot.

Consequently we only have to decide **which phase `z` is given to which pilot
`x`**.
For every input line `(x , y , z)` we create an edge `x – z`.
A schedule of `k` assignments is exactly a *perfect matching* in this
bipartite graph (left side = pilots, right side = phases).

If a perfect matching exists we output for every pilot the edge
`(x , mech[x] , matchedPhase[x])`.  
If not, the answer is `NO`.

The additional requirements  

* “sum of pilot ids = k(k+1)/2”  
* “sum of phase ids = k(k+1)/2”

are automatically fulfilled, because a perfect matching uses each pilot and
each phase exactly once.



--------------------------------------------------------------------

#### Algorithm
```
read k , t
mech[1 … k] = 0
adj[1 … k] = empty list

for each of the t lines (x , y , z):
        if mech[x] == 0: mech[x] = y          # first occurrence fixes the mech
        add z to adj[x]

run Hopcroft–Karp on the bipartite graph (pilots ↔ phases)
        matchL[x] = phase matched to pilot x   (0 = unmatched)
        matchR[z] = pilot matched to phase z   (0 = unmatched)

if number of matched pairs == k:
        print "YES"
        for x = 1 … k:
                print x, mech[x], matchL[x]
else:
        print "NO"
```

`Hopcroft–Karp` runs in `O(E·√V)` (`V = 2·k ≤ 2400`, `E ≤ t ≤ k²`) – easily fast
enough for `k ≤ 1200`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints a correct schedule iff one exists.

---

##### Lemma 1  
If the algorithm outputs “YES”, the printed assignments use each pilot,
each mech and each phase exactly once.

**Proof.**  
`matchL` is a perfect matching, i.e. for every pilot `x` `matchL[x] ≠ 0` and
different pilots get different phases.  
Thus every pilot appears once and every phase appears once.
For each pilot `x` the printed mech is `mech[x]`. By the statement of the
task all feasible assignments of pilot `x` contain this same mech, therefore
the printed triple `(x, mech[x], matchL[x])` is a feasible assignment.
Because pilots are distinct, also the mechs (which are uniquely attached to
pilots) are distinct. ∎



##### Lemma 2  
If the algorithm outputs “YES”, the sum of pilot ids and the sum of phase
ids in the printed schedule both equal `k(k+1)/2`.

**Proof.**  
Every pilot id `1 … k` appears exactly once (Lemma&nbsp;1), hence their sum is
the required arithmetic series. The same holds for the phases. ∎



##### Lemma 3  
If a schedule satisfying the statement exists, the bipartite graph contains a
perfect matching.

**Proof.**  
From a feasible schedule take the `k` triples `(x, y, z)`.  
All pilots are different, all phases are different, and for each pilot the
edge `x – z` belongs to the graph (the triple was feasible).  
Consequently the `k` edges form a perfect matching. ∎



##### Lemma 4  
If the bipartite graph contains a perfect matching, the algorithm outputs
“YES”.

**Proof.**  
Hopcroft–Karp finds a maximum matching.  
If a perfect matching exists, its size is `k`.  
The algorithm therefore obtains a matching of size `k` and prints “YES”. ∎



##### Theorem  
The algorithm prints “YES” and a correct schedule **iff** such a schedule
exists; otherwise it prints “NO”.

**Proof.**

*If* part:  
Assume a schedule exists.  
By Lemma&nbsp;3 the graph has a perfect matching, thus by Lemma&nbsp;4 the
algorithm finds one and prints “YES”.  
By Lemma&nbsp;1 and Lemma&nbsp;2 the printed assignments satisfy all required
properties.

*Only‑if* part:  
If the algorithm prints “YES”, Lemma&nbsp;1 gives a schedule using each pilot,
mech, and phase exactly once, and Lemma&nbsp;2 shows the sum conditions hold.
Hence a required schedule exists. ∎

#### Complexity Analysis  

*Building the graph* : `O(t)`  
*Hopcroft–Karp*       : `O(E·√V) = O(t·√k)` , with `k ≤ 1200` and `t ≤ k²`
                         ≤ `1.44·10⁶·35` ≈ `5·10⁷` elementary operations.  
*Output*              : `O(k)`

Both time and memory (`O(k + t)`) respect the limits.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    mech = [0] * (k + 1)          # mech[x]
    adj = [[] for _ in range(k + 1)]   # pilot -> list of phases

    for _ in range(t):
        x = int(next(it))
        y = int(next(it))
        z = int(next(it))
        if mech[x] == 0:
            mech[x] = y
        # otherwise y is guaranteed to be the same, no need to check
        adj[x].append(z)

    # ---------- Hopcroft–Karp ----------
    INF = 10 ** 9
    matchL = [0] * (k + 1)   # pilot -> phase
    matchR = [0] * (k + 1)   # phase -> pilot
    dist = [0] * (k + 1)

    def bfs() -> bool:
        q = deque()
        for u in range(1, k + 1):
            if matchL[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        reach_nil = INF
        while q:
            u = q.popleft()
            if dist[u] >= reach_nil:
                continue
            for v in adj[u]:
                mu = matchR[v]
                if mu == 0:
                    reach_nil = dist[u] + 1
                elif dist[mu] == INF:
                    dist[mu] = dist[u] + 1
                    q.append(mu)
        return reach_nil != INF

    sys.setrecursionlimit(10000)

    def dfs(u: int) -> bool:
        for v in adj[u]:
            mu = matchR[v]
            if mu == 0 or (dist[mu] == dist[u] + 1 and dfs(mu)):
                matchL[u] = v
                matchR[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, k + 1):
            if matchL[u] == 0 and dfs(u):
                matching += 1

    # ---------- Output ----------
    if matching == k:
        out_lines = ["YES"]
        for x in range(1, k + 1):
            out_lines.append(f"{x} {mech[x]} {matchL[x]}")
        sys.stdout.write("\n".join(out_lines))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```
