We can model this as a matching problem.  
The operational rule means that the relation between specialists and machines is a partial matching: each specialist is linked to at most one machine, and each machine to at most one specialist.  

So the allowed triples can be grouped by the (x, y) pair. For each such pair, we have a set of possible z values.  
We need to pick exactly one triple per specialist and per machine, and also cover all time slots exactly once.

This becomes:  
- Build a bipartite graph between (x, y) pairs and time slots z.  
- Each (x, y) pair can be used at most once (since each specialist and machine can be used once).  
- Each time slot must be used exactly once.  
- We need to match k pairs to k time slots.

Since the rule ensures each specialist and machine appear in at most one pair, the number of distinct (x, y) pairs is at most k.  
We can solve this as a bipartite matching problem.

Here’s the implementation:

```python
import sys
from collections import defaultdict, deque

def main():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    pairs = {}
    for _ in range(t):
        x, y, z = map(int, input().split())
        pairs.setdefault((x, y), []).append(z)
    
    # Build bipartite graph: left = (x,y) pairs, right = time slots
    pair_list = list(pairs.keys())
    n = len(pair_list)
    if n < k:
        print("NO")
        return
    
    # Map pair index to time slots
    adj = [[] for _ in range(n)]
    for i, (x, y) in enumerate(pair_list):
        for z in pairs[(x, y)]:
            adj[i].append(z - 1)  # 0-based time slot
    
    # Hopcroft-Karp for maximum bipartite matching
    match_right = [-1] * k
    match_left = [-1] * n
    dist = [0] * n
    
    def bfs():
        q = deque()
        for u in range(n):
            if match_left[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = -1
        found = False
        while q:
            u = q.popleft()
            for v in adj[u]:
                mu = match_right[v]
                if mu == -1:
                    found = True
                elif dist[mu] == -1:
                    dist[mu] = dist[u] + 1
                    q.append(mu)
        return found
    
    def dfs(u):
        for v in adj[u]:
            mu = match_right[v]
            if mu == -1 or (dist[mu] == dist[u] + 1 and dfs(mu)):
                match_left[u] = v
                match_right[v] = u
                return True
        dist[u] = -1
        return False
    
    matching = 0
    while bfs():
        for u in range(n):
            if match_left[u] == -1 and dfs(u):
                matching += 1
    
    if matching < k:
        print("NO")
        return
    
    # Build output
    print("YES")
    for i, (x, y) in enumerate(pair_list):
        if match_left[i] != -1:
            z = match_left[i] + 1
            print(x, y, z)

if __name__ == "__main__":
    main()
```
