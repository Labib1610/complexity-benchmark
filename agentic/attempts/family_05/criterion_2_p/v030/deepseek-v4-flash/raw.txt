We can model this as a bipartite matching problem.  
Each reaction is a triple `(x, y, z)`.  
Because of the lab rules, each catalyst `x` is always paired with the same solvent `y`.  
So we can first group by catalyst, and for each catalyst we know its fixed solvent.  

Then the problem reduces to:  
- We have `k` catalysts, each with a fixed solvent.  
- For each catalyst, we have a set of possible temperatures `z` from the log.  
- We need to assign each catalyst a distinct temperature `z` (1..k), such that each temperature is used exactly once.  

This is exactly a bipartite matching between catalysts and temperatures.  
If a perfect matching exists, we output the corresponding reactions.  

We can solve it with DFS-based augmenting path (Kuhn’s algorithm) since `k ≤ 1200`.  

Here’s the implementation:  

```python
import sys

def main():
    input = sys.stdin.readline
    k, t = map(int, input().split())
    
    # Map catalyst -> fixed solvent
    cat_solvent = {}
    # Map catalyst -> list of temperatures
    cat_temps = [[] for _ in range(k + 1)]
    
    for _ in range(t):
        x, y, z = map(int, input().split())
        if x not in cat_solvent:
            cat_solvent[x] = y
        # Since input is guaranteed consistent, we don't need to check mismatch
        cat_temps[x].append(z)
    
    # Build matching: temperature -> catalyst
    match_temp = [0] * (k + 1)  # match_temp[z] = catalyst assigned to temp z
    
    def dfs(cat, visited):
        for z in cat_temps[cat]:
            if not visited[z]:
                visited[z] = True
                if match_temp[z] == 0 or dfs(match_temp[z], visited):
                    match_temp[z] = cat
                    return True
        return False
    
    for cat in range(1, k + 1):
        visited = [False] * (k + 1)
        if not dfs(cat, visited):
            print("NO")
            return
    
    # If we reach here, perfect matching exists
    print("YES")
    for z in range(1, k + 1):
        cat = match_temp[z]
        y = cat_solvent[cat]
        print(cat, y, z)

if __name__ == "__main__":
    main()
```
