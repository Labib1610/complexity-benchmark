**Solution Explanation**

For every emitter `x (1 … k)` all given triplets contain the same filter `y`.
Thus a triplet is completely described by the pair `(x , z)` – the filter is
determined by `x`.

We have to choose exactly one triplet for each emitter, using every detector
once.  
So we need a *perfect matching* between the set of emitters `X = {1…k}`
and the set of detectors `Z = {1…k}` using the allowed edges
`(x , z)` that appear in the input.

The problem is therefore:

*Given a bipartite graph `X – Z` (|X| = |Z| = k) with up to `k·k` edges,
does it contain a perfect matching? If yes, output one.*

The classic algorithm for maximum bipartite matching in `O(E·√V)` is
**Hopcroft‑Karp**. With `k ≤ 1200` it easily fits into the limits.



--------------------------------------------------------------------

#### Algorithm
```
read k, t
for each emitter x store its filter y[x] (the same for all its edges)
build adjacency list adj[x] = list of detectors z reachable from x
run Hopcroft‑Karp on the graph (X side = 1..k, Z side = 1..k)
if size of matching == k:
        print "YES"
        for each x = 1..k:
                z = matchX[x]          # detector matched to x
                print x, y[x], z
else:
        print "NO"
```

**Hopcroft‑Karp details**

* `matchX[x]` – detector matched to emitter `x` (0 = unmatched)  
* `matchZ[z]` – emitter matched to detector `z` (0 = unmatched)  

Repeatedly:

1. **BFS** from all free emitters, building distance layers.
   Unmatched detectors are treated as the sink; BFS stops when they are
   reached. Distances are stored in `dist[x]`. If no free detector is reachable,
   the algorithm stops.

2. **DFS** from each free emitter, following only edges that respect the
   layering (`dist[next] == dist[cur] + 1`). Whenever an augmenting path is
   found, the matching is updated.

Complexity: `O(E·√V)` time, `O(E + V)` memory.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a valid basis iff such a basis
exists.

---

##### Lemma 1  
For each emitter `x` all input triplets containing `x` have the same filter
`y`. The algorithm stores this filter as `y[x]`. Any selected triplet
`(x, y[x], z)` is valid exactly when the edge `(x, z)` exists in the input.

*Proof.* Directly from the problem statement. ∎



##### Lemma 2  
A set of `k` triplets forms a valid basis **iff** the corresponding edges
form a perfect matching between emitters and detectors.

*Proof.*  
- If we have a basis, each emitter appears once → each emitter matched to
  exactly one detector. Each detector appears once → each detector matched
  to exactly one emitter. Hence edges constitute a perfect matching.  
- Conversely, a perfect matching gives for each emitter a unique detector.
  Using Lemma&nbsp;1 we can attach the unique filter `y[x]`, obtaining `k`
  triplets that use every emitter, filter and detector exactly once. ∎



##### Lemma 3  
After the Hopcroft‑Karp procedure finishes, `matchX`/`matchZ` is a maximum
matching of the bipartite graph.

*Proof.* Standard property of Hopcroft‑Karp: it repeatedly augments along
shortest augmenting paths until none exist; at that point the matching is
maximum (Kőnig’s theorem). ∎



##### Lemma 4  
If the algorithm outputs `YES`, the printed `k` triplets constitute a valid
basis.

*Proof.* `YES` is printed only when the matching size equals `k`. By
Lemma&nbsp;3 the matching is maximum, thus perfect. For each emitter `x`,
the algorithm outputs `(x, y[x], matchX[x])`. Edge `(x, matchX[x])` belongs to
the input, so the triplet is valid (Lemma&nbsp;1). By Lemma&nbsp;2 the set of
triplets is a basis. ∎



##### Lemma 5  
If a valid basis exists, the algorithm outputs `YES`.

*Proof.* Existence of a basis implies existence of a perfect matching
(Lemma&nbsp;2). A perfect matching has size `k`, therefore the maximum
matching size is at least `k`. Hopcroft‑Karp finds a maximum matching,
so its size is `k`. Consequently the algorithm prints `YES`. ∎



##### Theorem  
The algorithm prints `YES` and a correct basis exactly when such a basis
exists; otherwise it prints `NO`.

*Proof.* Directly from Lemma&nbsp;4 (soundness) and Lemma&nbsp;5 (completeness). ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`V = 2k ≤ 2400`, `E ≤ t ≤ k·k ≤ 1.44·10⁶`.

Hopcroft‑Karp runs in `O(E·√V) = O(k·k·√k)`. With `k ≤ 1200` this is well
below the 2 s limit. Memory consumption is `O(E + V)` (adjacency lists and
matching arrays), also within the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    y_of = [0] * (k + 1)          # filter for each emitter
    adj = [[] for _ in range(k + 1)]

    for _ in range(t):
        x = int(next(it))
        y = int(next(it))
        z = int(next(it))
        if y_of[x] == 0:
            y_of[x] = y
        # else y must be same, guaranteed by statement
        adj[x].append(z)

    # Hopcroft‑Karp
    INF = 10 ** 9
    matchX = [0] * (k + 1)   # emitter -> detector
    matchZ = [0] * (k + 1)   # detector -> emitter
    dist = [0] * (k + 1)

    def bfs() -> bool:
        q = deque()
        for x in range(1, k + 1):
            if matchX[x] == 0:
                dist[x] = 0
                q.append(x)
            else:
                dist[x] = INF
        reachable = False
        while q:
            x = q.popleft()
            for z in adj[x]:
                nx = matchZ[z]
                if nx == 0:
                    reachable = True
                elif dist[nx] == INF:
                    dist[nx] = dist[x] + 1
                    q.append(nx)
        return reachable

    sys.setrecursionlimit(10000)
    def dfs(x: int) -> bool:
        for z in adj[x]:
            nx = matchZ[z]
            if nx == 0 or (dist[nx] == dist[x] + 1 and dfs(nx)):
                matchX[x] = z
                matchZ[z] = x
                return True
        dist[x] = INF
        return False

    matching = 0
    while bfs():
        for x in range(1, k + 1):
            if matchX[x] == 0 and dfs(x):
                matching += 1

    out = []
    if matching == k:
        out.append("YES")
        for x in range(1, k + 1):
            out.append(f"{x} {y_of[x]} {matchX[x]}")
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
