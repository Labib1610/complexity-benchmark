**Solution Explanation**

For every primary module `x` all allowed triples have the same secondary module `y`.
Different primary modules have different secondary modules, therefore the pairing
`x → y` is already fixed and does not influence the problem any more.

The only remaining decision is which access token `z` is taken together with each
`x`.  
For each `x` we know the set `E[x] = { z | (x, y[x], z) is allowed }`.

We have to choose exactly one `z` for every `x` and every `z` must be used once.
That is exactly a *perfect matching* in the bipartite graph

```
left side :   X = {1 … k}
right side:   Z = {1 … k}
edge x–z :    if (x, y[x], z) is allowed
```

So the task reduces to checking whether this graph has a matching of size `k`
and, if it exists, output one.

`k ≤ 1200`, `|E| ≤ k·k ≤ 1.44·10⁶`.  
Hopcroft‑Karp runs in `O(E·√V)` → well below the limits.



--------------------------------------------------------------------

#### Algorithm
```
read k, t
for each triple (x, y, z):
        store y_of_x[x] = y          # same y for all triples of this x
        add edge x → z

run Hopcroft‑Karp on the bipartite graph (X, Z, edges)

if size of matching == k:
        print "YES"
        for each x = 1 … k:
                z = matched_z_of_x[x]
                print x, y_of_x[x], z
else:
        print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints a correct answer.

---

**Lemma 1**  
For any selection of `k` allowed triples that uses each `x`, each `y`, each `z`
exactly once, the set of pairs `(x, z)` forms a perfect matching of the graph
defined above.

*Proof.*  
Each selected triple contains a distinct `x` (by requirement) and a distinct
`z`. Because the triple is allowed, the edge `x–z` exists. Hence the `k` pairs
are `k` disjoint edges covering all vertices of both sides – a perfect matching. ∎



**Lemma 2**  
Conversely, any perfect matching `M` of the graph can be turned into a valid
selection of `k` triples.

*Proof.*  
For each matched edge `x–z` the input guarantees that the triple
`(x, y_of_x[x], z)` is allowed (the edge exists only for allowed triples).
All `x` are distinct, all `z` are distinct, and the `y` values are distinct
because different `x` have different `y`. Thus the `k` triples satisfy the
requirements. ∎



**Lemma 3**  
Hopcroft‑Karp returns a matching of maximum cardinality.

*Proof.*  
Standard property of the Hopcroft‑Karp algorithm. ∎



**Theorem**  
The algorithm outputs  

* “YES” and a list of `k` triples **iff** a valid selection exists;  
* otherwise it outputs “NO”.

*Proof.*  

*If part.*  
Assume a valid selection exists. By Lemma&nbsp;1 its `(x,z)` pairs form a perfect
matching, i.e. a matching of size `k`. By Lemma&nbsp;3 Hopcroft‑Karp finds a
matching of size at least `k`, but the graph has only `k` vertices on each side,
so the size is exactly `k`. The algorithm therefore prints “YES” and, using the
matching, the corresponding triples, which are valid by Lemma&nbsp;2.

*Only‑if part.*  
If the algorithm prints “YES”, the matching found has size `k`. By Lemma&nbsp;2
the printed triples constitute a valid selection.  

If the algorithm prints “NO”, the maximum matching size is `< k`. If a valid
selection existed, Lemma&nbsp;1 would give a perfect matching of size `k`,
contradiction. Hence no valid selection exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

* `V = 2k ≤ 2400`
* `E ≤ k·k ≤ 1.44·10⁶`

Hopcroft‑Karp: `O(E·√V) = O(k²·√k)`.  
With `k = 1200` this is below `2·10⁷` operations, easily fitting into the
2 s limit.

Memory: adjacency lists store each edge once → `O(E)` integers, well under the
256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    y_of_x = [0] * (k + 1)          # 1‑based
    adj = [[] for _ in range(k + 1)]

    for _ in range(t):
        x = int(next(it))
        y = int(next(it))
        z = int(next(it))
        y_of_x[x] = y               # same y for all triples of this x
        adj[x].append(z)

    # Hopcroft‑Karp
    INF = 10 ** 9
    pair_u = [0] * (k + 1)   # x -> z
    pair_v = [0] * (k + 1)   # z -> x
    dist = [0] * (k + 1)

    def bfs() -> bool:
        q = deque()
        for u in range(1, k + 1):
            if pair_u[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while q:
            u = q.popleft()
            if dist[u] < dist[0]:
                for v in adj[u]:
                    if pair_v[v] == 0:
                        if dist[0] == INF:
                            dist[0] = dist[u] + 1
                    elif dist[pair_v[v]] == INF:
                        dist[pair_v[v]] = dist[u] + 1
                        q.append(pair_v[v])
        return dist[0] != INF

    def dfs(u: int) -> bool:
        if u == 0:
            return True
        for v in adj[u]:
            if pair_v[v] == 0 or (dist[pair_v[v]] == dist[u] + 1 and dfs(pair_v[v])):
                pair_u[u] = v
                pair_v[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, k + 1):
            if pair_u[u] == 0 and dfs(u):
                matching += 1

    if matching != k:
        sys.stdout.write("NO")
        return

    out_lines = ["YES"]
    for x in range(1, k + 1):
        z = pair_u[x]
        out_lines.append(f"{x} {y_of_x[x]} {z}")
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```
