**Solution Explanation**

For every driver `x` all listed plans contain the same truck `y`.  
Different drivers never share a truck.  
Therefore the truck of a driver is *fixed* and does not influence the
choice of plans – it is enough to decide which route `z` each driver will
take.

So the problem becomes:

*left side* – drivers `1 … k`  
*right side* – routes `1 … k`  

There is an edge `x – z` iff a plan `(x , y , z)` exists  
(`y` is the (unique) truck of driver `x`).

We have to select `k` edges so that every driver and every route is used
once – i.e. we need a **perfect matching** in this bipartite graph.
If it exists we output the corresponding triples
`(x , truck_of_x , matched_route_of_x)`.

The classic algorithm for maximum bipartite matching in
`O(E·√V)` is Hopcroft‑Karp, fast enough for `k ≤ 1200` and
`E ≤ k·k ≤ 1.44·10⁶`.

--------------------------------------------------------------------

#### Algorithm
```
read k, t
driver_truck[1…k] = 0
adj[1…k] = empty lists
for each of the t lines (x, y, z):
        if driver_truck[x] == 0: driver_truck[x] = y   # first occurrence
        # (the input guarantees consistency, no need to check)
        adj[x].append(z)

run Hopcroft‑Karp on the graph (drivers ↔ routes) using adj
let matchU[x] = route matched to driver x   (0 if unmatched)
let matchV[z] = driver matched to route z

if number of matched pairs == k:
        print "YES"
        for x = 1 … k:
                y = driver_truck[x]
                z = matchU[x]
                print x, y, z
else:
        print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct schedule
iff such a schedule exists.

---

##### Lemma 1  
For every driver `x` all plans in the input have the same truck,
denoted `truck[x]`.  
Consequently a schedule uses truck `truck[x]` exactly when it uses driver
`x`.

*Proof.* Directly given in the statement. ∎



##### Lemma 2  
A set of `k` plans uses each driver, each truck and each route exactly
once **iff** the set of driver–route pairs extracted from the plans is a
perfect matching of the bipartite graph defined above.

*Proof.*  
*If* the plans form a schedule, each driver appears once, each route
once, and by Lemma&nbsp;1 each driver’s truck appears once as well.
Thus the driver–route pairs are pairwise distinct and cover all drivers
and all routes – a perfect matching.

*Only‑if* we have a perfect matching `M`. For each driver `x` let
`z` be the route matched to it. Because `(x , truck[x] , z)` is an input
plan (edge existence), the `k` triples built from the matching use every
driver once, every route once, and, by Lemma&nbsp;1, every truck once.
Hence they form a valid schedule. ∎



##### Lemma 3  
Hopcroft‑Karp returns a matching of maximum cardinality.

*Proof.* Standard property of the Hopcroft‑Karp algorithm. ∎



##### Lemma 4  
If the algorithm outputs `YES`, the printed `k` triples form a valid
schedule.

*Proof.*  
`YES` is printed only when the matching size equals `k`.  
By Lemma&nbsp;3 the matching is maximum, therefore it is a perfect
matching.  
For each driver `x` we output the triple
`(x , driver_truck[x] , matchU[x])`.  
The edge `(x , matchU[x])` exists, so the triple is an input plan.
All drivers are distinct, all routes are distinct (property of a
matching), and trucks are distinct because each driver has a distinct
truck (input guarantee).  
Thus the printed triples satisfy the schedule requirements. ∎



##### Lemma 5  
If a valid schedule exists, the algorithm outputs `YES`.

*Proof.*  
From a schedule we obtain a perfect matching (Lemma&nbsp;2).  
Therefore the graph contains a matching of size `k`.  
Hopcroft‑Karp finds a maximum matching, whose size is at least `k`,
hence exactly `k`. The algorithm therefore prints `YES`. ∎



##### Theorem  
The algorithm prints `YES` and a correct list of `k` plans
iff such a list exists; otherwise it prints `NO`.

*Proof.*  
- If the algorithm prints `YES`, Lemma&nbsp;4 guarantees the printed
  plans are valid.
- If a valid schedule exists, Lemma&nbsp;5 guarantees the algorithm
  prints `YES`.  
Consequently the algorithm prints `NO` exactly when no schedule exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`V = 2k ≤ 2400`, `E = t ≤ k·k ≤ 1.44·10⁶`.

Hopcroft‑Karp runs in `O(E·√V)` :

```
O( t * sqrt(k) )  ≤  O( 1.44·10⁶ * sqrt(1200) )  <  5·10⁷
```

well inside the 2 s limit.

Memory consumption:

- adjacency lists: `O(E)`
- a few integer arrays of size `O(k)`

Total ≤ a few megabytes, far below 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    k = int(next(it))
    t = int(next(it))

    driver_truck = [0] * (k + 1)          # 1‑based
    adj = [[] for _ in range(k + 1)]     # routes reachable from driver

    for _ in range(t):
        x = int(next(it))
        y = int(next(it))
        z = int(next(it))
        if driver_truck[x] == 0:
            driver_truck[x] = y
        # edge driver x -> route z
        adj[x].append(z)

    # ---------- Hopcroft‑Karp ----------
    INF = 10 ** 9
    pairU = [0] * (k + 1)   # driver -> route
    pairV = [0] * (k + 1)   # route  -> driver
    dist = [0] * (k + 1)

    def bfs() -> bool:
        q = deque()
        for u in range(1, k + 1):
            if pairU[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while q:
            u = q.popleft()
            if dist[u] < dist[0]:
                for v in adj[u]:
                    if pairV[v] == 0:
                        if dist[0] == INF:
                            dist[0] = dist[u] + 1
                    elif dist[pairV[v]] == INF:
                        dist[pairV[v]] = dist[u] + 1
                        q.append(pairV[v])
        return dist[0] != INF

    sys.setrecursionlimit(10000)
    def dfs(u: int) -> bool:
        if u == 0:
            return True
        for v in adj[u]:
            pu = pairV[v]
            if pu == 0 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, k + 1):
            if pairU[u] == 0 and dfs(u):
                matching += 1

    # ---------- Output ----------
    out = []
    if matching == k:
        out.append(b"YES")
        for x in range(1, k + 1):
            y = driver_truck[x]
            z = pairU[x]
            out.append(f"{x} {y} {z}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
