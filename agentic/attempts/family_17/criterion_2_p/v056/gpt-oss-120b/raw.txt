**Solution Explanation**

For every isotope we have a fixed identifier

* Alpha – `1 … q`
* Beta  – `q+1 … 2q`

The required sums are exactly the sums of all identifiers of the two groups, therefore a feasible plan must use **each Alpha once and each Beta once**.  
Consequently the problem is only:

> Does the given bipartite graph (Alphas on the left, Betas on the right) contain a perfect matching?
> If yes, output one.

So we have to find a maximum matching in a bipartite graph with  

* `|L| = |R| = q   ( ≤ 100 000 )`
* `|E| = t        ( ≤ 400 000 )`

The classic Hopcroft‑Karp algorithm runs in `O(E·√V)` and is fast enough
(`≈ 4·10⁵·316 ≈ 1.3·10⁸` elementary operations).  
Implementation details are tuned for Python speed.

--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[0 … q-1]   # left side (Alpha)
    for each edge (a,b):
        a ← a-1                     # 0‑based
        b ← b-(q+1)                 # 0‑based on right side
        G[a].append(b)

# Hopcroft‑Karp
pairU[0 … q-1] = -1   # matched right vertex for each left vertex
pairV[0 … q-1] = -1   # matched left vertex for each right vertex
dist[0 … q-1]

BFS():
    queue all free left vertices, set their dist = 0
    others dist = -1
    while queue not empty:
        u = pop
        for v in G[u]:
            if pairV[v] != -1 and dist[pairV[v]] == -1:
                dist[pairV[v]] = dist[u] + 1
                push(pairV[v])
    return True if there exists a free vertex on the right reachable
           (i.e. we found at least one augmenting path)

DFS(u):
    for v in G[u]:
        pu = pairV[v]
        if pu == -1 or (dist[pu] == dist[u] + 1 and DFS(pu)):
            pairU[u] = v
            pairV[v] = u
            return True
    dist[u] = -1          # dead end
    return False

repeat:
    if not BFS(): break
    for each free left vertex u:
        DFS(u)

matching size = number of u with pairU[u] != -1
if size == q:
    print YES and the pairs (u+1 , q+1+pairU[u])
else:
    print NO
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` with a valid set of pairs
iff such a set exists.

---

##### Lemma 1  
If the algorithm finishes with `matching size = q`, the printed pairs use
each Alpha and each Beta exactly once and all pairs are present in the
registry.

**Proof.**  
`pairU[u] = v` is set only when the edge `(u,v)` is traversed in `DFS`,
which iterates over `G[u]`, i.e. over registry edges.  
`pairU` and `pairV` are inverse bijections between the left and right
vertices, therefore each vertex appears in exactly one pair. ∎



##### Lemma 2  
During the algorithm `pairU`/`pairV` is always a matching (no two edges share
an endpoint).

**Proof.**  
Initially all are `-1` – empty matching.  
When `DFS` adds an edge `(u,v)`, it first ensures that `v` is either free
or its current partner `pu` will be reassigned recursively.
Thus after the recursive call `pu` is matched to a different vertex,
and `v` becomes matched only to `u`. No vertex obtains two partners. ∎



##### Lemma 3  
Each phase (one BFS + subsequent DFS calls) increases the size of the
matching by the number of vertex‑disjoint augmenting paths found in that
phase.

**Proof.**  
Standard property of Hopcroft‑Karp: BFS builds the layered graph of
shortest augmenting paths. DFS searches only along edges that respect the
layering, therefore each successful DFS discovers a vertex‑disjoint
shortest augmenting path and augments the matching along it.
Different DFS calls cannot share vertices because after a vertex is used
its distance is set to `-1`. ∎



##### Lemma 4  
If after a phase BFS returns `False` (no free right vertex reachable),
the current matching is maximum.

**Proof.**  
BFS explores all alternating paths starting from free left vertices.
If no free right vertex is reachable, there is no augmenting path at all,
hence by Berge’s theorem the matching is maximum. ∎



##### Lemma 5  
If a perfect matching exists, the algorithm will eventually obtain a
matching of size `q`.

**Proof.**  
Assume a perfect matching `M*` exists.
While the algorithm’s matching `M` is not perfect, there is an augmenting
path (take the symmetric difference of `M` and `M*`).  
Hopcroft‑Karp always finds a set of vertex‑disjoint shortest augmenting
paths and augments along all of them, strictly increasing the size.
Since the size is bounded by `q`, after finitely many phases it reaches
size `q`. ∎



##### Lemma 6  
If the algorithm ends with size `< q`, no perfect matching exists.

**Proof.**  
By Lemma 4 the final matching is maximum.
If its size is `< q`, a matching of size `q` (i.e. a perfect matching)
cannot exist. ∎



##### Theorem  
The program outputs  

* `YES` and a list of `q` pairs satisfying all requirements **iff**
  such a list exists,
* otherwise outputs `NO`.

**Proof.**  

*If the program prints `YES`*: by Lemma 1 the printed pairs are a
bijection between Alphas and Betas using only allowed edges, therefore a
valid stabilization plan.

*If a valid plan exists*: it is a perfect matching, so by Lemma 5 the
algorithm will find a matching of size `q` and output `YES`.

*If the program prints `NO`*: the matching size is `< q`; by Lemma 6
no perfect matching exists, thus no valid plan exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency*: `O(t)` memory and time.  
*Hopcroft‑Karp*: `O(E·√V) = O(t·√q)` ≤ `4·10⁵·316 ≈ 1.3·10⁸` elementary
operations.  
*Output*: `O(q)`.

Memory: adjacency list `O(t)`, plus a few arrays of size `q` → ≤ `~5·10⁵`
integers, well below the limit.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    G = [[] for _ in range(q)]          # left side: 0..q-1
    for _ in range(t):
        a = int(next(it)) - 1           # 0‑based Alpha
        b = int(next(it)) - (q + 1)     # 0‑based Beta
        if 0 <= a < q and 0 <= b < q:
            G[a].append(b)

    pairU = [-1] * q   # left -> right
    pairV = [-1] * q   # right -> left
    dist = [-1] * q

    INF = 10 ** 9

    def bfs() -> bool:
        dq = deque()
        for u in range(q):
            if pairU[u] == -1:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = -1
        found = False
        while dq:
            u = dq.popleft()
            for v in G[u]:
                pu = pairV[v]
                if pu != -1 and dist[pu] == -1:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
                elif pu == -1:
                    found = True
        return found

    sys.setrecursionlimit(1 << 25)

    def dfs(u: int) -> bool:
        for v in G[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = -1
        return False

    matching = 0
    while bfs():
        for u in range(q):
            if pairU[u] == -1 and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(q):
            v = pairU[u]
            out.append(f"{u+1} {q+1+v}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
