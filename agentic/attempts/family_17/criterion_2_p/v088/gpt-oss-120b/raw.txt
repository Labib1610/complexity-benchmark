**Solution Explanation**

We have a bipartite graph  

* left side – transmitters `1 … q`  
* right side – receivers `q+1 … 2q`  

` t` edges are given, each connects one left vertex with one right vertex.
We have to choose exactly `q` edges so that every vertex (both sides) is incident to
exactly one chosen edge – i.e. we need a *perfect matching*.

The classic algorithm for maximum bipartite matching in `O(E·√V)` is
**Hopcroft‑Karp**.  
`V = 2·q ≤ 2·10⁵`, `E ≤ 4·10⁵`, therefore it easily fits into the limits.

If the size of the maximum matching equals `q` we output any such matching,
otherwise we output `NO`.

--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list adj[1…q]   // only left vertices store edges
for each edge (a,b):
        adj[a].append(b)

pairU[1…q] = 0          // matched right vertex for left a, 0 = free
pairV[q+1…2q] = 0       // matched left vertex for right b, 0 = free
dist[1…q]

function bfs():
        queue = empty
        for each u in 1…q:
                if pairU[u] == 0:   // free left vertex
                        dist[u] = 0
                        push u
                else:
                        dist[u] = INF
        dist0 = INF
        while queue not empty:
                u = pop
                if dist[u] < dist0:
                        for v in adj[u]:
                                if pairV[v] == 0:          // free right vertex
                                        dist0 = dist[u] + 1
                                else if dist[pairV[v]] == INF:
                                        dist[pairV[v]] = dist[u] + 1
                                        push pairV[v]
        return dist0 != INF          // is there an augmenting path?

function dfs(u):
        for v in adj[u]:
                if pairV[v] == 0 or (dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v])):
                        pairU[u] = v
                        pairV[v] = u
                        return True
        dist[u] = INF
        return False

matching = 0
while bfs():
        for each u in 1…q:
                if pairU[u] == 0 and dfs(u):
                        matching += 1

if matching == q:
        print "YES"
        for u = 1 … q:
                print u, pairU[u]
else:
        print "NO"
```

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of bridges
iff such a set exists.

---

**Lemma 1**  
During the execution of Hopcroft‑Karp, `pairU` and `pairV` always describe a
matching (no vertex is incident to more than one matched edge).

*Proof.*  
Initially all pairs are `0` – empty matching, property holds.
Both `bfs` and `dfs` never modify the arrays.
`dfs` changes `pairU[u] = v` and `pairV[v] = u` only when `u` and `v` were
previously free (`pairU[u]==0` and `pairV[v]==0`) or when `v` was matched to
some `u'` and `dfs` recursively re‑matches `u'` elsewhere. In both cases the
old edge incident to `v` is removed before the new one is added, preserving
the matching property. ∎



**Lemma 2**  
Each iteration of the outer `while bfs()` loop increases the size of the
matching by the number of vertex‑disjoint shortest augmenting paths found by the
subsequent DFS calls.

*Proof.*  
`bfs` computes the layered graph consisting of all shortest augmenting paths
(starting from a free left vertex and ending at a free right vertex).  
`dfs` searches only along edges that respect these layers, therefore each
successful `dfs` finds a vertex‑disjoint augmenting path of that minimal length
and augments the matching along it. Different `dfs` calls start from different
free left vertices, and because they only use edges of the layered graph,
the paths cannot share vertices. Hence the matching size grows exactly by the
number of such paths. ∎



**Lemma 3**  
When `bfs` returns `False` there is no augmenting path in the current graph.

*Proof.*  
`bfs` explores the layered graph reachable from any free left vertex.
If it cannot reach any free right vertex, then no alternating path
(starting with a free left vertex, alternating unmatched/matched edges,
ending at a free right vertex) exists – i.e. no augmenting path exists. ∎



**Lemma 4**  
When the algorithm terminates, the matching is maximum.

*Proof.*  
The algorithm stops exactly when `bfs` returns `False`. By Lemma&nbsp;3 at that
moment there is no augmenting path, and by the classic theorem of
Berge a matching without augmenting paths is maximum. ∎



**Lemma 5**  
If the algorithm outputs `YES`, the printed edges form a perfect matching.

*Proof.*  
`YES` is printed only when `matching == q`. By Lemma&nbsp;1 the stored edges are a
matching; its size `q` equals the number of left vertices, therefore every left
vertex is matched. Because the matching size also equals the number of right
vertices, every right vertex is matched as well. Hence the printed edges cover
all `2q` terminals exactly once – a perfect matching. ∎



**Lemma 6**  
If a perfect matching exists, the algorithm outputs `YES`.

*Proof.*  
Assume a perfect matching exists. Then the maximum matching size is `q`.
By Lemma&nbsp;4 the algorithm finds a maximum matching, therefore its size is `q`,
so the condition `matching == q` holds and `YES` is printed. ∎



**Theorem**  
The program prints `YES` followed by a valid set of `q` bridges
iff such a set exists; otherwise it prints `NO`.

*Proof.*  
- If the program prints `YES`, by Lemma&nbsp;5 the printed edges are a perfect
  matching, thus a valid set exists.
- If a valid set exists, by Lemma&nbsp;6 the algorithm prints `YES`.
- In all other cases it prints `NO`.

Thus the statement holds. ∎

#### Complexity Analysis  

`E = t ≤ 4·10⁵`, `V = 2·q ≤ 2·10⁵`.

Hopcroft‑Karp runs in `O(E·√V)` time:

```
√V ≤ √2·10⁵ ≈ 447
E·√V ≤ 4·10⁵·447 ≈ 1.8·10⁸   (well within 2 s in Python with efficient code)
```

Memory consumption:

- adjacency list: `O(E)`
- several arrays of size `O(V)`

Overall `O(E + V)` ≤ about 5·10⁵ integers → well below 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    adj = [[] for _ in range(q + 1)]          # 1‑based left vertices
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        adj[a].append(b)

    pairU = [0] * (q + 1)                     # left -> right
    pairV = [0] * (2 * q + 1)                 # right -> left
    dist = [0] * (q + 1)
    INF = 10 ** 9

    def bfs() -> bool:
        dq = deque()
        for u in range(1, q + 1):
            if pairU[u] == 0:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        found = False
        while dq:
            u = dq.popleft()
            for v in adj[u]:
                pu = pairV[v]
                if pu == 0:
                    found = True          # we reached a free right vertex
                elif dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
        return found

    sys.setrecursionlimit(1 << 25)

    def dfs(u: int) -> bool:
        for v in adj[u]:
            pu = pairV[v]
            if pu == 0 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, q + 1):
            if pairU[u] == 0 and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(1, q + 1):
            out.append(f"{u} {pairU[u]}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
