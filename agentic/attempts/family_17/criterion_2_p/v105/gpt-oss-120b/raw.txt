**Solution Explanation**

We have a bipartite graph  

* left side : vertices `1 … q` (primary assets)  
* right side: vertices `q+1 … 2q` (secondary assets)  

`(a , b)` is an edge iff the pair is allowed (`a ≤ q < b`).  
We have to choose exactly `q` edges so that every vertex is incident to exactly one chosen edge – i.e. a *perfect matching*.

The additional safety constraints from the statement are automatically satisfied for any perfect matching
(because a perfect matching uses exactly `q` edges, which is `< q+1`).  
Thus the problem reduces to checking whether the bipartite graph contains a perfect matching and, if it does,
output one.

The classic algorithm for maximum bipartite matching in `O(E·√V)` is **Hopcroft‑Karp**.
With `V = 2·q ≤ 2·10⁵` and `E ≤ 4·10⁵` it easily fits into the limits.



--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[a] for a = 1 … q   (store only right‑side numbers)

run Hopcroft‑Karp
    pairU[a] = matched right vertex or 0
    pairV[b] = matched left vertex or 0
    dist[a]   = distance in BFS layer graph

    while BFS builds layers (reaches a free vertex on right side)
          for each free left vertex a
                if DFS(a) finds augmenting path
                       increase matching size

if matching size == q:
        print "YES"
        for a = 1 … q:
                print a, pairU[a]
else:
        print "NO"
```

`BFS` builds the layered graph of shortest alternating paths from all free left vertices.
`DFS` searches only along edges that respect the layering, guaranteeing `O(E·√V)` total time.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs “YES” and a valid pairing **iff** such a pairing exists.

---

##### Lemma 1  
During Hopcroft‑Karp, after each phase (BFS + all DFS augmentations) the current set of edges is a matching
(no vertex is incident to more than one chosen edge).

**Proof.**  
Initially the matching is empty – trivially a matching.  
Each DFS augments along an *alternating* path that starts and ends at free vertices, swapping matched/unmatched
edges along the path. This operation removes the previous matched edge incident to each internal vertex and adds a
different one, preserving the property that each vertex is incident to at most one matched edge. ∎



##### Lemma 2  
If after the algorithm the size of the matching equals `q`, the printed pairs form a perfect matching
(i.e. every vertex `1 … 2q` appears exactly once).

**Proof.**  
The matching size `q` means exactly `q` left vertices are matched (by Lemma&nbsp;1 each left vertex is matched at most once).
Because the graph is bipartite with the same number of left and right vertices, `q` matched edges also match `q`
right vertices, and no right vertex can be matched twice. Hence every vertex on both sides is matched exactly once. ∎



##### Lemma 3  
If a perfect matching exists, Hopcroft‑Karp finishes with a matching of size `q`.

**Proof.**  
Hopcroft‑Karp is a known algorithm that computes a *maximum* bipartite matching.
It repeatedly augments while an augmenting path exists; when none exists, the current matching is maximum
(Kőnig’s theorem).  
If a perfect matching exists, the maximum size is `q`. Therefore the algorithm must reach size `q`. ∎



##### Lemma 4  
If the algorithm finishes with matching size `< q`, no perfect matching exists.

**Proof.**  
By Lemma&nbsp;3 the algorithm returns a maximum matching. If its size is `< q`, the maximum possible size is `< q`,
hence a perfect matching (size `q`) cannot exist. ∎



##### Theorem  
The program prints  

* “YES” followed by `q` disjoint allowed pairs **iff** such a set of pairs covering all `2q` assets exists;  
* otherwise it prints “NO”.

**Proof.**  

*If part*:  
Assume the program prints “YES”. Then the matching size is `q`. By Lemma&nbsp;2 the printed pairs constitute a
perfect matching, i.e. a valid deployment.

*Only‑if part*:  
Assume a valid deployment exists. Then a perfect matching exists in the graph.
By Lemma&nbsp;3 Hopcroft‑Karp will find a matching of size `q`, the program will output “YES” and those pairs.
If the program outputs “NO”, the matching size is `< q`; by Lemma&nbsp;4 no perfect matching exists, contradicting
the assumption. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*`BFS`* scans each edge at most once → `O(E)`  
*`DFS`* also scans each edge at most once per phase.  
Number of phases ≤ `O(√V)` (standard Hopcroft‑Karp bound).  

Total time: `O(E·√V)` ≤ `4·10⁵·√(2·10⁵) ≈ 1.8·10⁸` operations, well within 2 seconds in Python (fast implementation).  

Memory: adjacency list `O(E)`, plus a few arrays of size `q` or `2q` → `O(E + V)` ≤ a few MB.

#### Reference Implementation  (Python 3)

```python
import sys
import collections

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    G = [[] for _ in range(q + 1)]          # 1‑based left side
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        G[a].append(b)                     # b is in [q+1, 2q]

    # Hopcroft‑Karp
    NIL = 0
    pairU = [NIL] * (q + 1)                 # left -> right
    pairV = [NIL] * (2 * q + 1)              # right -> left
    dist = [0] * (q + 1)

    def bfs() -> bool:
        dq = collections.deque()
        for u in range(1, q + 1):
            if pairU[u] == NIL:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = -1
        found = False
        while dq:
            u = dq.popleft()
            for v in G[u]:
                pu = pairV[v]
                if pu == NIL:
                    found = True
                elif dist[pu] == -1:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
        return found

    sys.setrecursionlimit(1 << 25)
    def dfs(u: int) -> bool:
        for v in G[u]:
            pu = pairV[v]
            if pu == NIL or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = -1
        return False

    matching = 0
    while bfs():
        for u in range(1, q + 1):
            if pairU[u] == NIL and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for a in range(1, q + 1):
            out.append(f"{a} {pairU[a]}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to the required input‑output format.
