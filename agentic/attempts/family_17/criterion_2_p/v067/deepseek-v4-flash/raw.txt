We need to find a perfect matching in a bipartite graph where controllers are on one side and platforms on the other.  
We can solve this using **Kuhn’s algorithm** for maximum bipartite matching, or Hopcroft–Karp for better performance.

Given constraints:
- q up to 100,000
- t up to 400,000

We should use an efficient matching algorithm. Hopcroft–Karp runs in O(E√V), which is fine.

We’ll:
1. Build adjacency list for controllers → platforms.
2. Run Hopcroft–Karp to find maximum matching.
3. If matching size == q, output YES and the pairs; otherwise NO.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

q, t = map(int, input().split())
adj = [[] for _ in range(q + 1)]

for _ in range(t):
    a, b = map(int, input().split())
    adj[a].append(b)

# Hopcroft–Karp
INF = 10**9
matchU = [0] * (q + 1)
matchV = [0] * (2 * q + 1)
dist = [0] * (q + 1)

def bfs():
    dq = deque()
    for u in range(1, q + 1):
        if matchU[u] == 0:
            dist[u] = 0
            dq.append(u)
        else:
            dist[u] = INF
    dist[0] = INF
    while dq:
        u = dq.popleft()
        if dist[u] < dist[0]:
            for v in adj[u]:
                if dist[matchV[v]] == INF:
                    dist[matchV[v]] = dist[u] + 1
                    dq.append(matchV[v])
    return dist[0] != INF

def dfs(u):
    if u != 0:
        for v in adj[u]:
            if dist[matchV[v]] == dist[u] + 1 and dfs(matchV[v]):
                matchV[v] = u
                matchU[u] = v
                return True
        dist[u] = INF
        return False
    return True

matching = 0
while bfs():
    for u in range(1, q + 1):
        if matchU[u] == 0 and dfs(u):
            matching += 1

if matching == q:
    print("YES")
    for u in range(1, q + 1):
        print(u, matchU[u])
else:
    print("NO")
```
