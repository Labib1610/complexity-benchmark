**Solution Explanation**

The assets form a bipartite graph  

* left side – controllers `1 … q`  
* right side – platforms `q+1 … 2q`

Each certified pair is an edge between its controller and its platform.
We have to decide whether the graph contains a *perfect matching* (a set of
`q` pairwise‑disjoint edges covering all vertices) and output one such matching.

The classic algorithm for maximum bipartite matching in
`O(E·√V)` time is **Hopcroft‑Karp**.
With `V = 2q ≤ 2·10⁵` and `E ≤ 4·10⁵` it easily fits the limits.

--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[1…q]   // only from controllers to platforms

// Hopcroft‑Karp
pairU[0…q] = 0          // matched platform for each controller (0 = NIL)
pairV[0…2q] = 0         // matched controller for each platform
dist[0…q]

function bfs():
    queue = empty
    for u = 1 … q:
        if pairU[u] == 0:          // free vertex
            dist[u] = 0
            enqueue u
        else:
            dist[u] = INF
    dist[0] = INF
    while queue not empty:
        u = dequeue
        if dist[u] < dist[0]:
            for v in G[u]:
                if dist[pairV[v]] == INF:
                    dist[pairV[v]] = dist[u] + 1
                    enqueue pairV[v]
    return dist[0] != INF          // there exists an augmenting path

function dfs(u):
    if u != 0:
        for v in G[u]:
            if dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v]):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False
    return True

matching = 0
while bfs():
    for u = 1 … q:
        if pairU[u] == 0 and dfs(u):
            matching += 1

if matching == q:
    print "YES"
    for u = 1 … q:
        print u, pairU[u]
else:
    print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a valid roster **iff**
a perfect matching exists.

---

##### Lemma 1  
During Hopcroft‑Karp, `pairU` and `pairV` always represent a matching
(no two edges share an endpoint).

**Proof.**  
Initially all are `0` – empty matching.  
Each time `dfs` succeeds, it sets `pairU[u]=v` and `pairV[v]=u`.  
Before that, `u` and `v` were free (`pairU[u]==0` and `pairV[v]==0`) because
`dfs` is only called for free `u` and follows only edges to the partner of `v`,
which is also free at that moment. Hence the new edge does not conflict with
existing ones. ∎



##### Lemma 2  
`bfs` computes the length of the shortest augmenting paths from any free
controller to any free platform and stores it in `dist`.  
It returns `True` iff at least one augmenting path exists.

**Proof.**  
The BFS explores the layered graph used by Hopcroft‑Karp:
edges `U → V` (original) and `V → U` (matched edges).  
All free controllers are sources (distance 0).  
Whenever we traverse an unmatched edge `u–v`, we continue from the
matched partner of `v` (`pairV[v]`). This exactly follows alternating
paths. The first time we reach the NIL node (`0`) we have found the
shortest possible augmenting path length; `dist[0]` records it.
If `dist[0]` stays INF, no augmenting path exists. ∎



##### Lemma 3  
Each call of `dfs` finds a vertex‑disjoint augmenting path of length
`dist[0]` (the current shortest length) and augments the matching.

**Proof.**  
`dfs` proceeds only along edges that respect the layering (`dist[pairV[v]] == dist[u]+1`),
therefore any path it builds is alternating and has exactly the length
found by `bfs`.  
If it reaches NIL (`u==0`) it succeeded; the recursion unwinds,
flipping the matched/unmatched status of every edge on the path,
which is precisely the augmentation operation. ∎



##### Lemma 4  
After each outer `while` iteration, the size of the matching increases
by at least one and no augmenting path of length ≤ current `dist[0]`
remains.

**Proof.**  
`bfs` finds the current shortest augmenting length `L = dist[0]`.  
All `dfs` calls that start from free controllers find vertex‑disjoint
augmenting paths of length `L` (Lemma 3).  
Each successful `dfs` augments the matching, increasing its size.
Because the paths are vertex‑disjoint, they do not interfere.
When `bfs` is run again, any remaining augmenting path must be longer,
otherwise it would have been discovered in the previous BFS. ∎



##### Lemma 5  
When the algorithm terminates, the matching is maximum.

**Proof.**  
Termination happens when `bfs` finds no augmenting path, i.e. the
current matching admits none. By the classical theorem of
Berge, a matching without augmenting paths is maximum. ∎



##### Lemma 6  
If the algorithm outputs `YES`, the printed pairs form a perfect
matching.

**Proof.**  
`YES` is printed only when `matching == q`.  
By Lemma 1 the stored edges are a matching; having `q` edges in a bipartite
graph with `q` vertices on each side forces every vertex to be incident
to exactly one edge – a perfect matching. The output lists exactly those
edges. ∎



##### Lemma 7  
If a perfect matching exists, the algorithm outputs `YES`.

**Proof.**  
A perfect matching has size `q`.  
By Lemma 5 the algorithm finds a maximum matching; its size is at least the
size of any matching, thus ≥ `q`. Since the graph has only `q` left vertices,
the maximum size cannot exceed `q`. Hence the algorithm obtains size `q`
and prints `YES`. ∎



##### Theorem  
The program prints `YES` followed by a valid roster **iff** the given
certification list admits a roster that uses every controller and every
platform exactly once; otherwise it prints `NO`.

**Proof.**  
*If* part: by Lemma 6.  
*Only‑if* part: by Lemma 7. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

* `bfs` scans each edge at most once → `O(E)`.
* Each phase of `dfs` also scans each edge at most once → `O(E)`.
* Number of phases ≤ `√V` (standard Hopcroft‑Karp bound).

Total time `O(E·√V) ≤ 4·10⁵·√2·10⁵ ≈ 1.8·10⁸` operations, well within 2 s in Python
with an efficient implementation.

Memory:

* adjacency list: `O(E)`
* arrays `pairU`, `pairV`, `dist`: `O(V)`

Overall ≤ ~ 5 MB, far below the limit.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    G = [[] for _ in range(q + 1)]          # 1‑based controllers
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        # a is controller (1..q), b is platform (q+1..2q)
        G[a].append(b)

    NIL = 0
    INF = 10 ** 9

    pairU = [NIL] * (q + 1)                 # controller -> platform
    pairV = [NIL] * (2 * q + 1)             # platform -> controller
    dist = [0] * (q + 1)

    def bfs() -> bool:
        dq = deque()
        for u in range(1, q + 1):
            if pairU[u] == NIL:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        dist[NIL] = INF

        while dq:
            u = dq.popleft()
            if dist[u] < dist[NIL]:
                for v in G[u]:
                    pu = pairV[v]
                    if dist[pu] == INF:
                        dist[pu] = dist[u] + 1
                        dq.append(pu)
        return dist[NIL] != INF

    sys.setrecursionlimit(1 << 25)

    def dfs(u: int) -> bool:
        if u != NIL:
            for v in G[u]:
                pu = pairV[v]
                if dist[pu] == dist[u] + 1 and dfs(pu):
                    pairU[u] = v
                    pairV[v] = u
                    return True
            dist[u] = INF
            return False
        return True

    matching = 0
    while bfs():
        for u in range(1, q + 1):
            if pairU[u] == NIL and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(1, q + 1):
            out.append(f"{u} {pairU[u]}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
