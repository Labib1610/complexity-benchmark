**Solution Explanation**

We have a bipartite graph  

* left side – controllers `1 … q`  
* right side – platforms `q+1 … 2q`

An edge `(a,b)` (with `a ≤ q < b`) means the controller `a` can be paired with the platform `b`.

We have to decide whether a *perfect matching* exists (every vertex is matched) and, if it exists, output one such matching.

The classic algorithm for maximum bipartite matching in `O(E·√V)` is **Hopcroft‑Karp**.
With `q ≤ 10⁵` and `t ≤ 4·10⁵` it easily fits into the limits.



--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[0 … q-1]               # left vertices 0‑based
for each edge a,b:
        u = a-1                                 # left index
        v = b-(q+1)                             # right index 0‑based
        G[u].append(v)

run Hopcroft‑Karp on G
if size of matching == q:
        print "YES"
        for each left vertex u (0 … q-1):
                v = pairU[u]                    # matched right vertex
                print (u+1) (v+q+1)              # back to original ids
else:
        print "NO"
```

**Hopcroft‑Karp details**

* `pairU[u]` – right partner of left vertex `u` (`-1` if free)  
* `pairV[v]` – left partner of right vertex `v` (`-1` if free)  
* `dist[u]` – distance label used in BFS

```
while BFS() finds at least one free vertex on the right:
        for each free left vertex u:
                if DFS(u):
                        increase matching size
```

*BFS* builds layers of the alternating graph starting from all free left vertices.
*DFS* searches augmenting paths respecting the layer order.

Complexities: `O(E·√V)` time, `O(V+E)` memory.



--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs “YES” with a valid perfect matching
iff such a matching exists.

---

##### Lemma 1  
During Hopcroft‑Karp, after each BFS/DFS phase the current matching is
maximum among all matchings that use only edges of length ≤ current layer
distance.

**Proof.** Standard property of Hopcroft‑Karp: BFS defines the shortest
alternating path length `L`. DFS finds a maximal set of vertex‑disjoint
alternating paths of length `L` and augments along them. After augmentation,
no augmenting path of length `≤ L` remains, therefore the matching is
maximum with respect to those lengths. ∎



##### Lemma 2  
If after a BFS phase no free right vertex is reached, the current matching
is a maximum matching of the whole graph.

**Proof.** If BFS cannot reach a free right vertex, there is no augmenting
path at all (any augmenting path would start at a free left vertex, follow
alternating edges, and end at a free right vertex, thus would be discovered
by BFS). By Berge’s theorem, a matching without augmenting paths is maximum. ∎



##### Lemma 3  
When the algorithm terminates, the size of the matching equals the size of a
maximum matching in the input graph.

**Proof.** The algorithm stops exactly when a BFS finds no free right vertex.
By Lemma&nbsp;2 the current matching is then maximum. ∎



##### Lemma 4  
If the algorithm outputs “YES”, the printed pairs form a perfect matching.

**Proof.** “YES” is printed only when the matching size equals `q`.
The matching contains exactly one partner for each left vertex (by definition
of `pairU`) and each right vertex (because the size equals the number of
right vertices). Converting the 0‑based indices back to original identifiers
does not change the pairing property. Hence every controller and every
platform appears exactly once – a perfect matching. ∎



##### Lemma 5  
If a perfect matching exists, the algorithm outputs “YES”.

**Proof.** Let `M*` be a perfect matching, size `q`. By Lemma&nbsp;3 the
algorithm finds a maximum matching `M`. Since `|M| ≥ |M*| = q` and a matching
cannot be larger than `q`, we have `|M| = q`. Consequently the algorithm
prints “YES”. ∎



##### Theorem  
The algorithm prints “YES” and a correct roster iff a roster satisfying the
maximum‑utilisation protocol exists; otherwise it prints “NO”.

**Proof.**  
*If* part: by Lemma&nbsp;5 a perfect matching ⇒ algorithm prints “YES”.  
*Only‑if* part: by Lemma&nbsp;4 printing “YES” yields a perfect matching,
hence a feasible roster exists. If no perfect matching exists, the maximum
matching size is `< q`, so the algorithm prints “NO”. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

* `V = 2q ≤ 2·10⁵`  
* `E = t ≤ 4·10⁵`

Hopcroft‑Karp runs in `O(E·√V) = O(4·10⁵·√2·10⁵) ≈ 1.8·10⁸` elementary
operations, well inside the 2 s limit in Python (the constant is small).

Memory: adjacency list `O(E)`, plus arrays `O(V)`. Total ≤ a few MB,
well below 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    nL = q
    nR = q
    G = [[] for _ in range(nL)]
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        u = a - 1               # 0‑based left
        v = b - (q + 1)         # 0‑based right
        G[u].append(v)

    # Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [-1] * nL
    pairV = [-1] * nR
    dist = [0] * nL

    def bfs() -> bool:
        dq = deque()
        for u in range(nL):
            if pairU[u] == -1:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        found = False
        while dq:
            u = dq.popleft()
            for v in G[u]:
                pu = pairV[v]
                if pu != -1 and dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
                elif pu == -1:
                    found = True
        return found

    sys.setrecursionlimit(1 << 25)
    def dfs(u: int) -> bool:
        for v in G[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(nL):
            if pairU[u] == -1 and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(nL):
            v = pairU[u]
            out.append(f"{u+1} {v+q+1}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
