**Solution Explanation**

The problem asks for a perfect matching in a bipartite graph  

* left side – outdated modules `1 … q`  
* right side – new nodes `q+1 … 2q`  

An edge `(a , b)` (with `a ≤ q < b`) means module `a` can run on node `b`.  
We have to decide whether a matching that covers **all** `q` left vertices exists and, if it does, output one such matching.

The classic algorithm for maximum bipartite matching in `O(E·√V)` is **Hopcroft‑Karp**.
With `q ≤ 10⁵` and `t ≤ 4·10⁵` it easily fits into the limits.



--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[1…q]   // only left side vertices store their neighbours

// Hopcroft‑Karp
pairU[1…q] = 0          // matched right vertex for each left vertex (0 = free)
pairV[q+1…2q] = 0       // matched left vertex for each right vertex
dist[1…q]

function bfs():
    queue = empty
    for u = 1 … q:
        if pairU[u] == 0:
            dist[u] = 0
            push u into queue
        else:
            dist[u] = INF
    dist0 = INF
    while queue not empty:
        u = pop queue
        if dist[u] < dist0:
            for v in G[u]:
                if pairV[v] == 0:          // free right vertex -> possible augmenting path end
                    dist0 = dist[u] + 1
                else if dist[pairV[v]] == INF:
                    dist[pairV[v]] = dist[u] + 1
                    push pairV[v] into queue
    return dist0 != INF          // true if there exists a free vertex on the right reachable

function dfs(u):
    for v in G[u]:
        if pairV[v] == 0 or (dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v])):
            pairU[u] = v
            pairV[v] = u
            return True
    dist[u] = INF          // no augmenting path from u in this layer
    return False

matching = 0
while bfs():
    for u = 1 … q:
        if pairU[u] == 0 and dfs(u):
            matching += 1

if matching == q:
    print "YES"
    for u = 1 … q:
        print u, pairU[u]
else:
    print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct perfect matching
iff such a matching exists.

---

##### Lemma 1  
During the execution of Hopcroft‑Karp, `pairU` and `pairV` always describe a
matching (no two edges share an endpoint).

**Proof.**  
Initially all are `0` – empty matching, trivially valid.  
In `dfs`, when we set `pairU[u]=v` we also set `pairV[v]=u`.  
Before that assignment both `u` and `v` were free (`pairU[u]==0` and either
`pairV[v]==0` or `v` is matched to some `u'` that will be unmatched by the
recursive call). The recursive call removes the previous match of `v`
(if any) before adding the new one, therefore the invariant holds. ∎



##### Lemma 2  
Each successful call of `dfs` augments the current matching by exactly one
edge.

**Proof.**  
`dfs` returns `True` only when it finds a path that ends at a free right
vertex. Along that path edges are flipped: matched edges become unmatched,
the previously unmatched edge becomes matched. This changes the size of the
matching by `+1`. No other edges are altered. ∎



##### Lemma 3  
`bfs` computes the length `L` of the shortest augmenting paths (if any) and
stores in `dist` the distance from each free left vertex to the layer
where it appears in such a shortest path. Vertices not on any shortest
augmenting path get `dist = INF`.

**Proof.**  
The BFS starts from all free left vertices (distance `0`). It follows
alternating edges: left → right (any edge), then right → its matched left
(if exists). This exactly reproduces the structure of alternating paths.
When a free right vertex is first reached, its distance `dist0` is the
shortest possible length of an augmenting path. The BFS stops expanding
layers beyond `dist0`, therefore `dist` records distances only up to that
minimum length. Vertices farther away keep `INF`. ∎



##### Lemma 4  
All augmenting paths found by the subsequent `dfs` calls have length `L`
(the minimum possible) and are vertex‑disjoint.

**Proof.**  
`dfs` only follows edges that respect the layering (`dist[pairV[v]] == dist[u]+1`),
so any discovered augmenting path respects the BFS layers and therefore has
length `L`.  
When `dfs` succeeds, it flips the whole path, making all its vertices matched.
Later `dfs` calls see those vertices with `dist = INF` (set at the end of the
failed search) and cannot use them, guaranteeing vertex‑disjointness. ∎



##### Lemma 5  
After each outer `while bfs()` iteration, the matching size increases by the
maximum possible number of vertex‑disjoint shortest augmenting paths.

**Proof.**  
By Lemma&nbsp;4 each successful `dfs` adds one such path, and they are
disjoint, so the number of augmentations equals the number of paths found.
If a shortest augmenting path existed that was not used, its first free
left vertex would still have `dist = 0` and `dfs` starting there would find
it (standard property of Hopcroft‑Karp). Hence all shortest augmenting paths
are taken. ∎



##### Lemma 6  
When `bfs` returns `False` there is **no** augmenting path left, i.e. the
current matching is maximum.

**Proof.**  
`bfs` returns `False` exactly when it cannot reach any free right vertex,
meaning no alternating path from a free left to a free right exists.
By definition such a path is an augmenting path, so none exists. ∎



##### Theorem  
The algorithm outputs `YES` and a set of `q` pairwise compatible
module‑node assignments **iff** a perfect matching exists; otherwise it
outputs `NO`.

**Proof.**  

*If the algorithm prints `YES`.*  
It printed `YES` only when `matching == q`. By Lemma&nbsp;1 the stored edges
form a matching of size `q`. Since there are exactly `q` left vertices, the
matching is perfect and respects all given compatibility edges (they are the
only edges stored). Hence a perfect matching exists.

*If a perfect matching exists.*  
A perfect matching has size `q`. Hopcroft‑Karp always finds a maximum
matching (Lemmas&nbsp;5 and&nbsp;6). Therefore after termination the algorithm
has a matching of size `q` and prints `YES`.  

*If the algorithm prints `NO`.*  
Then `matching < q`. By Lemma&nbsp;6 the final matching is maximum, so no
matching of size `q` exists, i.e. a perfect matching is impossible. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*`bfs`* runs in `O(E)` time.  
*`dfs`* over one phase visits each edge at most once, also `O(E)`.  
The number of phases is `O(√V)` (standard Hopcroft‑Karp bound).  

```
Time   : O(E·√V) ≤ 4·10⁵ · √(2·10⁵)  < 3·10⁷   (well inside 2 s)
Memory : O(V + E)  ≤  (2·10⁵ + 4·10⁵) integers  ≈ 5 MB
```

Both satisfy the limits.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    G = [[] for _ in range(q + 1)]          # 1‑based left vertices
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        G[a].append(b)

    N_left = q
    N_right = q
    pairU = [0] * (N_left + 1)               # left -> right
    pairV = [0] * (2 * q + 1)                # right -> left (indices up to 2q)
    dist = [0] * (N_left + 1)
    INF = 10 ** 9

    def bfs() -> bool:
        qd = deque()
        for u in range(1, N_left + 1):
            if pairU[u] == 0:
                dist[u] = 0
                qd.append(u)
            else:
                dist[u] = INF
        found = False
        while qd:
            u = qd.popleft()
            for v in G[u]:
                pu = pairV[v]
                if pu == 0:
                    found = True          # we reached a free right vertex
                elif dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    qd.append(pu)
        return found

    sys.setrecursionlimit(1 << 25)

    def dfs(u: int) -> bool:
        for v in G[u]:
            pu = pairV[v]
            if pu == 0 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, N_left + 1):
            if pairU[u] == 0 and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(1, q + 1):
            out.append(f"{u} {pairU[u]}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
