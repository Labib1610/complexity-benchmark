**Solution Explanation**

We have a bipartite graph  

* left part – stations `1 … q` (low‑band)  
* right part – stations `q+1 … 2q` (high‑band)  

` t ` edges are given, each connects a left vertex with a right vertex.
We have to choose `q` edges so that every vertex is incident to exactly one chosen
edge – i.e. we need a *perfect matching*.

The classic algorithm for maximum bipartite matching in `O(E·√V)` is
**Hopcroft‑Karp**.  
`V = 2·q ≤ 2·10⁵`, `E ≤ 4·10⁵`, therefore it easily fits into the limits.

If the size of the maximum matching equals `q` we output it,
otherwise we output `NO`.

--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[1…q]   // only left side vertices
for each edge a b:
        G[a].append(b - q)    // store right vertex as 1…q

pairU[0…q] = 0   // matched right vertex for each left vertex (0 = NIL)
pairV[0…q] = 0   // matched left vertex for each right vertex
dist[0…q]

function bfs():
        queue = empty
        for u = 1 … q:
                if pairU[u] == 0:   // free vertex
                        dist[u] = 0
                        push u
                else:
                        dist[u] = INF
        dist[0] = INF
        while queue not empty:
                u = pop
                if dist[u] < dist[0]:
                        for v in G[u]:
                                if dist[pairV[v]] == INF:
                                        dist[pairV[v]] = dist[u] + 1
                                        push pairV[v]
        return dist[0] != INF          // there exists an augmenting path

function dfs(u):
        if u != 0:
                for v in G[u]:
                        if dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v]):
                                pairU[u] = v
                                pairV[v] = u
                                return True
                dist[u] = INF
                return False
        return True

matching = 0
while bfs():
        for u = 1 … q:
                if pairU[u] == 0 and dfs(u):
                        matching += 1

if matching == q:
        print "YES"
        for u = 1 … q:
                v = pairU[u]          // 1…q
                print u, v + q
else:
        print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of channels
iff a perfect matching exists.

---

**Lemma 1**  
`bfs` computes the layered graph of all shortest augmenting paths
with respect to the current matching.

*Proof.*  
Standard property of Hopcroft‑Karp: starting from all free left vertices,
BFS follows alternating edges (unmatched left→right, matched right→left)
and records distances. The first time a free right vertex is reached,
its distance is the length of a shortest augmenting path.
All vertices reachable with distance `< dist[0]` lie on some shortest
alternating path. ∎



**Lemma 2**  
`dfs` finds a vertex‑disjoint set of augmenting paths that are
shortest (i.e. respect the layering built by the last `bfs`).

*Proof.*  
`dfs` only follows edges that go from a layer `d` to layer `d+1`
(Lemma 1). When it reaches the NIL vertex (`u==0`) it has found an
alternating path of minimal length and flips the matching along it.
Because after a successful augmentation the matched edges are removed
from further consideration, the paths found in one `dfs` round are
vertex‑disjoint. ∎



**Lemma 3**  
After each outer iteration (`while bfs(): …`) the size of the matching
increases by the maximum possible number of vertex‑disjoint shortest
augmenting paths.

*Proof.*  
By Lemma 2 we augment along a maximal set of vertex‑disjoint shortest
paths. Any augmenting path not using these vertices must be longer,
otherwise it would have been discovered by the same BFS layer.
Thus no additional augmenting path of the same (shortest) length exists,
so the increase is maximal for this distance. ∎



**Lemma 4**  
When the algorithm terminates, the matching is maximum.

*Proof.*  
The algorithm stops when `bfs` finds no augmenting path, i.e. there is
no alternating path from a free left vertex to a free right vertex.
By König’s theorem this is equivalent to the current matching being
maximum. ∎



**Lemma 5**  
If the algorithm outputs `YES`, the printed edges form a perfect
matching.

*Proof.*  
`YES` is printed only when `matching == q`. The matching size equals the
number of left vertices, therefore every left vertex is matched.
Because the matching is bipartite, each matched right vertex is unique,
hence all `q` right vertices are also matched. The printed edges are
exactly the pairs `(u, pairU[u]+q)`, i.e. the edges of the matching. ∎



**Lemma 6**  
If a perfect matching exists, the algorithm outputs `YES`.

*Proof.*  
A perfect matching has size `q`. By Lemma 4 the algorithm finds a maximum
matching; its size cannot be smaller than any existing matching, thus
it also has size `q`. Consequently the condition `matching == q` holds
and `YES` is printed. ∎



**Theorem**  
The program prints `YES` followed by a valid set of `q` channels
iff such a set exists; otherwise it prints `NO`.

*Proof.*  
- If the program prints `YES`, by Lemma 5 the printed edges are a perfect
  matching, hence a valid set exists.
- If a valid set exists, by Lemma 6 the algorithm finds a matching of size
  `q` and prints `YES`.  
If neither case holds, the algorithm prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`E = t ≤ 4·10⁵`, `V = 2·q ≤ 2·10⁵`.

Hopcroft‑Karp runs in `O(E·√V)` time:

```
O(4·10⁵ * sqrt(2·10⁵))  <  4·10⁵ * 450  ≈ 1.8·10⁸   (well within 2 s in PyPy)
```

Memory consumption:

- adjacency list: `O(E)`
- several arrays of size `q+1`: `O(q)`

Total ≤ a few megabytes, far below the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    G = [[] for _ in range(q + 1)]          # 1‑based left side
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        G[a].append(b - q)                  # right side indexed 1..q

    NIL = 0
    INF = 10 ** 9
    pairU = [0] * (q + 1)   # left -> right (0 if free)
    pairV = [0] * (q + 1)   # right -> left
    dist = [0] * (q + 1)

    def bfs() -> bool:
        dq = deque()
        for u in range(1, q + 1):
            if pairU[u] == NIL:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        dist[NIL] = INF
        while dq:
            u = dq.popleft()
            if dist[u] < dist[NIL]:
                for v in G[u]:
                    if dist[pairV[v]] == INF:
                        dist[pairV[v]] = dist[u] + 1
                        dq.append(pairV[v])
        return dist[NIL] != INF

    sys.setrecursionlimit(1 << 25)
    def dfs(u: int) -> bool:
        if u != NIL:
            for v in G[u]:
                if dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v]):
                    pairU[u] = v
                    pairV[v] = u
                    return True
            dist[u] = INF
            return False
        return True

    matching = 0
    while bfs():
        for u in range(1, q + 1):
            if pairU[u] == NIL and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(1, q + 1):
            v = pairU[u]
            out.append(f"{u} {v + q}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
