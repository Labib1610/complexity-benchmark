**Solution Explanation**

The assets form a bipartite graph  

* left side – controllers `1 … q`  
* right side – platforms `q+1 … 2q`  

An edge `(a,b)` (with `a ≤ q < b`) means that this controller may be paired with that platform.
We have to decide whether the graph contains a *perfect matching* – a set of `q` edges that
covers every vertex exactly once – and output one such matching.

The classic algorithm for maximum bipartite matching in `O(E·√V)` is **Hopcroft‑Karp**.
With `V = 2q ≤ 2·10⁵` and `E ≤ 4·10⁵` it easily fits the limits.

--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[1…q]   // only from controllers to platforms (store platform‑id-q)
run Hopcroft‑Karp on G
if size of matching == q:
        print "YES"
        for each controller u (1…q):
                v = pairU[u]          // matched platform (original id)
                print u, v
else:
        print "NO"
```

**Hopcroft‑Karp details**

* `pairU[u]` – platform matched to controller `u` (0 = unmatched)  
* `pairV[v]` – controller matched to platform `v` (0 = unmatched)  
* `dist[u]` – BFS distance label

```
BFS():
        queue all free controllers, set their dist = 0
        others dist = INF
        dist[0] = INF
        while queue not empty:
                u = pop
                if dist[u] < dist[0]:
                        for each v in G[u]:
                                if dist[pairV[v]] == INF:
                                        dist[pairV[v]] = dist[u] + 1
                                        push(pairV[v])
        return dist[0] != INF          // there exists an augmenting path

DFS(u):
        if u != 0:
                for each v in G[u]:
                        if dist[pairV[v]] == dist[u] + 1 and DFS(pairV[v]):
                                pairU[u] = v
                                pairV[v] = u
                                return True
                dist[u] = INF
                return False
        return True
```

The main loop repeats BFS + DFS until no augmenting path exists.
The number of augmentations is `O(√V)`, each BFS/DFS scans each edge at most once,
hence total `O(E·√V)`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs “YES” with a valid perfect matching
iff such a matching exists.

---

**Lemma 1**  
After each BFS/DFS phase, `pairU`/`pairV` represent a matching (no vertex appears in two edges).

*Proof.*  
Initially all pairs are `0` – empty matching.  
During DFS we only assign `pairU[u]=v` and `pairV[v]=u` simultaneously.
Before the assignment `u` and `v` are unmatched (otherwise `pairV[v]` would not be the
next vertex on the augmenting path). Hence each vertex gets at most one partner. ∎



**Lemma 2**  
If BFS returns `True`, there exists an augmenting path of length `dist[0]`.

*Proof.*  
BFS builds the layered graph consisting of edges that go from a layer `i`
to layer `i+1` (alternating unmatched/matched).  
`dist[0]` is set when a free vertex on the right side is reached.
The predecessor chain from a free left vertex to this free right vertex
gives an alternating path whose first and last vertices are free,
i.e. an augmenting path. ∎



**Lemma 3**  
DFS finds a set of vertex‑disjoint augmenting paths covering all free left vertices
that are reachable in the layered graph built by the last BFS.

*Proof.*  
Standard property of Hopcroft‑Karp: DFS follows only edges respecting the
layering (`dist[pairV[v]] == dist[u]+1`).  
Whenever DFS succeeds for a left vertex, it flips the edges of one augmenting
path, making that vertex matched. Because after a successful DFS the used
vertices get `dist = INF`, they cannot be part of another DFS call in the same phase,
ensuring vertex‑disjointness. All reachable free left vertices are tried,
so all such paths are found. ∎



**Lemma 4**  
Each phase (BFS + all DFS calls) increases the size of the matching by at least
one and by at most `O(√V)` phases are needed to reach a maximum matching.

*Proof.*  
If BFS returns `True`, Lemma 2 guarantees at least one augmenting path,
and Lemma 3 flips at least one of them, increasing the matching size.
Hopcroft‑Karp analysis shows that the length of the shortest augmenting path
strictly increases after each phase, and the length can increase at most
`√V` times before exceeding `V`. Hence at most `√V` phases. ∎



**Lemma 5** (Optimality)  
When BFS returns `False`, the current matching is maximum.

*Proof.*  
If BFS cannot reach a free right vertex, there is no augmenting path
in the whole graph (the layered graph contains all shortest alternating
paths). By Berge’s theorem, a matching without augmenting paths is maximum. ∎



**Theorem**  
The algorithm outputs “YES” and a set of `q` pairs that forms a perfect matching
iff the input graph contains a perfect matching; otherwise it outputs “NO”.

*Proof.*  

*If part.*  
Assume the algorithm prints “YES”. Then the final matching size is `q`.
By Lemma 1 it is a matching, covering all `q` controllers and `q` platforms,
hence a perfect matching.

*Only‑if part.*  
Assume a perfect matching exists. The maximum matching size is `q`.
Hopcroft‑Karp always computes a maximum matching (Lemmas 4, 5).  
Therefore after termination the algorithm’s matching size is `q`,
so it prints “YES”.  

If no perfect matching exists, the maximum size is `< q`; the algorithm
terminates with a smaller matching and prints “NO”. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

* `V = 2q ≤ 2·10⁵`  
* `E = t ≤ 4·10⁵`

Hopcroft‑Karp: `O(E·√V)` ≤ `4·10⁵·√2·10⁵` ≈ `1.8·10⁸` elementary operations,
well inside the 2 s limit in CP‑Python (fast adjacency lists).  
Memory: adjacency list `O(E)`, plus a few arrays of size `O(V)` → < 10 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def hopcroft_karp(adj, n_left, n_right):
    # vertices: left 1..n_left, right 1..n_right (we will store original ids)
    pair_u = [0] * (n_left + 1)
    pair_v = [0] * (n_right + 1)
    dist = [0] * (n_left + 1)

    INF = 10 ** 9

    def bfs():
        q = deque()
        for u in range(1, n_left + 1):
            if pair_u[u] == 0:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while q:
            u = q.popleft()
            if dist[u] < dist[0]:
                for v in adj[u]:
                    if dist[pair_v[v]] == INF:
                        dist[pair_v[v]] = dist[u] + 1
                        q.append(pair_v[v])
        return dist[0] != INF

    sys.setrecursionlimit(1 << 25)
    def dfs(u):
        if u == 0:
            return True
        for v in adj[u]:
            if dist[pair_v[v]] == dist[u] + 1 and dfs(pair_v[v]):
                pair_u[u] = v
                pair_v[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, n_left + 1):
            if pair_u[u] == 0 and dfs(u):
                matching += 1
    return matching, pair_u

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    n_left = q
    n_right = q
    adj = [[] for _ in range(n_left + 1)]
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        # map platform id to 1..q
        adj[a].append(b - q)
    matching, pair_u = hopcroft_karp(adj, n_left, n_right)
    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(1, q + 1):
            v = pair_u[u] + q  # restore original platform id
            out.append(f"{u} {v}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to the required I/O format.
