**Solution Explanation**

For every asset `a (1 … q)` we have to choose exactly one registry entry  
`(a , b)` with `b (q+1 … 2q)` and all chosen `b` must be different.
Thus we have to find a *perfect matching* in the bipartite graph

* left side : vertices `1 … q`
* right side: vertices `q+1 … 2q`
* edges    : the `t` given pairs

If a perfect matching exists, the sum of the left‑hand numbers in the
matching is automatically  

```
1 + 2 + … + q = q·(q+1)/2
```

so the additional numeric condition is satisfied automatically.
Therefore the whole problem reduces to checking whether the bipartite
graph has a perfect matching and, if it does, output one.

The classic algorithm for maximum bipartite matching in
`O(E·sqrt(V))` is **Hopcroft‑Karp**.  
With `V = 2·q ≤ 2·10⁵` and `E = t ≤ 4·10⁵` it easily fits into the limits.



--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[left]  (left = 1 … q, right = q+1 … 2q)

run Hopcroft‑Karp on G
    pairU[u] – matched right vertex of left u   (0 = unmatched)
    pairV[v] – matched left  vertex of right v  (0 = unmatched)

if size of matching == q:
        print "YES"
        for each left u = 1 … q:
                print u, pairU[u]
else:
        print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of links
iff such a set exists.

---

##### Lemma 1  
If the algorithm outputs `YES`, the printed `q` pairs form a valid
configuration.

**Proof.**  
`YES` is printed only when the Hopcroft‑Karp algorithm found a matching
of size `q`.  
*Every left vertex* `u (1…q)` is matched to exactly one right vertex
`pairU[u]` (by definition of a matching).  
All right vertices are distinct because a matching never uses a vertex
more than once.  
Consequently each of the `2q` assets appears in exactly one printed pair,
so all four required conditions hold. ∎



##### Lemma 2  
If a valid configuration exists, the algorithm finds a matching of size
`q`.

**Proof.**  
A valid configuration is a set of `q` edges where each left vertex
appears exactly once and each right vertex at most once.
Hence it is a matching that covers all left vertices, i.e. a matching of
size `q`.  
Hopcroft‑Karp computes a *maximum* matching, therefore its size is at
least the size of any other matching, in particular at least `q`.  
Since the left side contains only `q` vertices, the maximum size cannot
exceed `q`. Thus the algorithm obtains a matching of size exactly `q`. ∎



##### Lemma 3  
If the algorithm prints `NO`, no valid configuration exists.

**Proof.**  
`NO` is printed only when the maximum matching size `< q`.  
Assume for contradiction a valid configuration existed.
By Lemma&nbsp;2 this would imply a matching of size `q`, contradicting the
maximality result. ∎



##### Theorem  
The algorithm outputs `YES` together with a correct list of `q` links
iff such a list exists; otherwise it outputs `NO`.

**Proof.**  
*If* part: existence ⇒ by Lemma&nbsp;2 algorithm finds size `q` matching,
prints `YES`; by Lemma&nbsp;1 the printed list is valid.  
*Only‑if* part: algorithm prints `YES` ⇒ by Lemma&nbsp;1 the list is
valid.  
If algorithm prints `NO`, by Lemma&nbsp;3 no valid list exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(t)`  
*Hopcroft‑Karp*: `O(E·sqrt(V)) = O(t·sqrt(q))`  
With the given limits this is ≤ `4·10⁵·447 ≈ 1.8·10⁸` elementary
operations, well inside 2 seconds in PyPy / CPython with optimised code.  

Memory: adjacency list `O(t)`, plus a few arrays of size `q` and `q`,
overall `O(t + q)` ≤ `5·10⁵` integers → < 10 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    n_left = q
    n_right = q  # vertices q+1 .. 2q, we will index them 1..q as well
    G = [[] for _ in range(n_left + 1)]  # 1‑based left vertices

    for _ in range(t):
        a = int(next(it))
        b = int(next(it)) - q          # shift right side to 1..q
        if 1 <= a <= q and 1 <= b <= q:
            G[a].append(b)

    # Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [0] * (n_left + 1)
    pairV = [0] * (n_right + 1)
    dist = [0] * (n_left + 1)

    def bfs() -> bool:
        dq = deque()
        for u in range(1, n_left + 1):
            if pairU[u] == 0:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        dist[0] = INF
        while dq:
            u = dq.popleft()
            if dist[u] < dist[0]:
                for v in G[u]:
                    if dist[pairV[v]] == INF:
                        dist[pairV[v]] = dist[u] + 1
                        dq.append(pairV[v])
        return dist[0] != INF

    def dfs(u: int) -> bool:
        if u == 0:
            return True
        for v in G[u]:
            if dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v]):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, n_left + 1):
            if pairU[u] == 0 and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(1, q + 1):
            v = pairU[u] + q          # restore original right id
            out.append(f"{u} {v}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
