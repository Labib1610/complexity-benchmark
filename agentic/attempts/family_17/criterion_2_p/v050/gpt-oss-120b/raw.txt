**Solution Explanation**

The problem asks for a *perfect matching* in a bipartite graph  

* left side : vertices `1 … q` (command units)  
* right side: vertices `q+1 … 2q` (response units)  

Only the given `t` edges may be used.  
A perfect matching uses exactly `q` edges, each vertex exactly once.

So we only have to decide whether a perfect matching exists and, if it does,
output one.  
The classic algorithm for this is **Hopcroft‑Karp** – `O(E·√V)` which easily
fits the limits (`q ≤ 10⁵ , E ≤ 4·10⁵`).

--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[1…q]          // left → list of right indices (1…q)
    for each edge a b:
        G[a].append(b - q)           // store right side as 1‑based index

run Hopcroft‑Karp on G
    pairU[1…q] = 0   // matched right vertex for each left (0 = free)
    pairV[1…q] = 0   // matched left vertex for each right
    dist[1…q]

    BFS():   compute distance layers from all free left vertices
    DFS(u):  try to find augmenting paths using the layers

while BFS finds at least one free vertex reachable:
    for every free left vertex u:
        if DFS(u): increase matching size

if matching size == q:
    print "YES"
    for u = 1 … q:
        v = pairU[u]                // 1‑based right index
        print u, v + q              // convert back to original identifiers
else:
    print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of links
iff such a set exists.

---

##### Lemma 1  
During Hopcroft‑Karp, `pairU` and `pairV` always represent a matching
(i.e. no vertex appears in more than one edge).

**Proof.**  
Initially all pairs are `0` – empty matching.  
Both BFS and DFS never modify the pairs except when an augmenting path
is found; then the algorithm flips the edges along that path.
Flipping a path replaces each matched edge by an unmatched one and vice
versa, preserving the property that each vertex is incident to at most one
matched edge. ∎



##### Lemma 2  
Each iteration of the outer `while` loop increases the size of the matching
by the number of vertex‑disjoint shortest augmenting paths found by the
DFS calls.

**Proof.**  
BFS builds layers of the graph consisting of all shortest augmenting paths
(starting from free left vertices).  
DFS searches only along edges that respect these layers, therefore any
found augmenting path is shortest.  
DFS never re‑uses a left vertex that has already been matched in the same
iteration, so the found paths are vertex‑disjoint.  
Flipping each of them increases the matching size by one. ∎



##### Lemma 3  
When BFS returns *false* (no free left vertex reaches a free right vertex)
the current matching is maximum.

**Proof.**  
If BFS cannot reach a free right vertex, there is **no** augmenting path
(at all, because any augmenting path must start at a free left vertex,
follow alternating edges, and end at a free right vertex, thus would be
found by BFS).  
By the classic theorem of Berge, a matching without augmenting paths is
maximum. ∎



##### Lemma 4  
If the algorithm finishes with matching size `q`, the printed edges form a
perfect matching of the original graph.

**Proof.**  
Size `q` means every left vertex is matched (there are exactly `q` left
vertices). By Lemma&nbsp;1 the matching is valid, i.e. each right vertex is
matched at most once. Because the total number of matched edges equals the
number of left vertices, all right vertices are also matched.  
The printed edges are exactly the pairs `(u, pairU[u])` converted back to
original identifiers, therefore they are edges of the input graph and
constitute a perfect matching. ∎



##### Lemma 5  
If a perfect matching exists, the algorithm ends with size `q`.

**Proof.**  
Hopcroft‑Karp is a known algorithm that always returns a *maximum* matching
in any bipartite graph.  
If a perfect matching exists, the maximum size is `q`. Hence the algorithm
must reach size `q`. ∎



##### Theorem  
The program outputs  

* `YES` followed by a list of `q` edges **iff** a perfect matching exists,  
* otherwise outputs `NO`.

**Proof.**  

*If part*:  
Assume the program prints `YES`. Then matching size is `q`. By Lemma&nbsp;4
the printed edges are a perfect matching, therefore such a configuration
exists.

*Only‑if part*:  
Assume a perfect matching exists. By Lemma&nbsp;5 the algorithm obtains a
matching of size `q`. Consequently it prints `YES` and the edges of that
matching. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency*: `O(t)`  
*Hopcroft‑Karp*: `O(E·√V) = O(t·√q)` ≤ `4·10⁵·√10⁵` ≈ `1.3·10⁸` operations,
well inside the 2 s limit in CP‑optimized Python.  
*Memory*: adjacency list `O(t)`, plus a few arrays of size `q` → `O(q + t)`
≤ `5·10⁵` integers → < 10 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    G = [[] for _ in range(q + 1)]          # 1‑based left vertices
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        G[a].append(b - q)                  # right index 1..q

    # Hopcroft‑Karp
    pairU = [0] * (q + 1)   # left -> right
    pairV = [0] * (q + 1)   # right -> left
    dist = [0] * (q + 1)

    INF = 10 ** 9

    def bfs() -> bool:
        dq = deque()
        for u in range(1, q + 1):
            if pairU[u] == 0:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        found = False
        while dq:
            u = dq.popleft()
            for v in G[u]:
                pu = pairV[v]
                if pu == 0:
                    found = True          # we can reach a free right vertex
                elif dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
        return found

    sys.setrecursionlimit(1 << 25)

    def dfs(u: int) -> bool:
        for v in G[u]:
            pu = pairV[v]
            if pu == 0 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, q + 1):
            if pairU[u] == 0 and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(1, q + 1):
            v = pairU[u]
            out.append(f"{u} {v + q}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
