**Solution Explanation**

We have a bipartite graph  

* left side – the `q` cores `1 … q`  
* right side – the `q` dissipators `q+1 … 2q`  

An edge `(a , b)` ( `a ≤ q < b` ) means that core `a` can be linked to dissipator `b`.  
We have to decide whether a *perfect matching* (every vertex of both sides is matched) exists and, if it does, output one such matching.

The constraints  

* `q ≤ 100 000`  
* `t ≤ 400 000`  

allow an `O(E·√V)` algorithm – the classic **Hopcroft‑Karp** algorithm for bipartite matching.

--------------------------------------------------------------------

#### 1.   Data representation  

* Left vertices are numbered `0 … q‑1` (core `a` → `a‑1`).  
* Right vertices are numbered `0 … q‑1` (dissipator `b` → `b‑q‑1`).  

`adj[u]` – list of right neighbours of left vertex `u`.

Two arrays store the current matching  

* `pairU[u]` – right vertex matched with left `u` (`-1` if free)  
* `pairV[v]` – left vertex matched with right `v` (`-1` if free)

`dist[u]` – BFS distance used by Hopcroft‑Karp.

--------------------------------------------------------------------

#### 2.   Hopcroft‑Karp  

```
while BFS finds at least one augmenting path:
        for every free left vertex u:
                if DFS(u) succeeds: increase matching size
```

*BFS* builds layers of the alternating graph, stopping at the first free right vertex.
*DFS* searches augmenting paths respecting the layer order.

Complexity: `O(E·√V)` – well inside the limits.

--------------------------------------------------------------------

#### 3.   Building the answer  

After the algorithm finishes, if the size of the matching equals `q`,
we output `YES` and for each left vertex `u` print the original numbers:

```
core = u + 1
dissipator = pairU[u] + q + 1
```

Otherwise we output `NO`.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct perfect matching
iff such a matching exists.

---

##### Lemma 1  
During Hopcroft‑Karp, `pairU` and `pairV` always represent a matching
(no vertex is incident to more than one selected edge).

**Proof.**  
Initially all entries are `-1` – empty matching.  
Both BFS and DFS never modify the arrays.  
Only when DFS finds an augmenting path it *flips* the edges along the path:
for each edge `(u, v)` on the path we set `pairU[u]=v` and `pairV[v]=u`.  
Because the path is alternating (matched / unmatched) and starts/ends at free
vertices, after flipping each vertex on the path is incident to exactly one
matched edge. Vertices not on the path keep their previous status.
∎



##### Lemma 2  
If BFS returns `True`, there exists an augmenting path of length `dist`
from some free left vertex to a free right vertex.

**Proof.**  
BFS starts from all free left vertices, assigning distance `0`.  
It traverses only edges that respect the current matching:
* from a left vertex via an **unmatched** edge to a right vertex,
* from a right vertex via its **matched** edge back to a left vertex.
Thus any discovered right vertex at distance `d` is reachable by an alternating
path of length `d`.  
If a free right vertex is reached, BFS stops and returns `True`. ∎



##### Lemma 3  
DFS called only on vertices that satisfy `dist[u]` (layer) finds a
vertex‑disjoint augmenting path of the minimal length found by BFS,
or returns `False` if none exists from that start vertex.

**Proof.**  
DFS follows only edges that go to a right vertex `v` with
`pairV[v] == -1` (free) **or** to a left vertex `pairV[v]` whose distance is
`dist[u] + 1`. This exactly respects the layering built by BFS, therefore
any path discovered by DFS is alternating and has the minimal possible length.
If DFS cannot continue, no augmenting path respecting the layers exists
starting from that `u`. ∎



##### Lemma 4  
Each outer iteration of Hopcroft‑Karp increases the size of the matching
by the number of vertex‑disjoint augmenting paths found in that iteration.

**Proof.**  
BFS guarantees that all augmenting paths found by DFS have the same minimal
length and are vertex‑disjoint because after a successful DFS the involved
left vertices become matched and are never used again in the same phase.
Flipping each such path adds exactly one matched edge, therefore the total
matching size grows by the number of successful DFS calls. ∎



##### Lemma 5  
When Hopcroft‑Karp terminates, the matching is maximum.

**Proof.**  
The algorithm stops when BFS cannot reach a free right vertex, i.e. there
is **no** augmenting path in the current graph. By the classic theorem of
Berge, a matching without augmenting paths is maximum. ∎



##### Lemma 6  
If the algorithm outputs `YES`, the printed pairs form a perfect matching.

**Proof.**  
`YES` is printed only when the final matching size equals `q`.  
By Lemma&nbsp;1 the matching is valid (no vertex repeated).  
Having `q` edges and `q` vertices on each side forces every vertex to be
matched, i.e. a perfect matching. The printed pairs are exactly those edges. ∎



##### Lemma 7  
If a perfect matching exists, the algorithm outputs `YES`.

**Proof.**  
A perfect matching is a matching of size `q`.  
By Lemma&nbsp;5 the algorithm finds a *maximum* matching; its size is at least
the size of any other matching, therefore at least `q`.  
Since the graph has only `q` left vertices, the size cannot exceed `q`,
hence the algorithm obtains size `q` and prints `YES`. ∎



##### Theorem  
The program prints `YES` followed by a correct assignment
iff such an assignment exists; otherwise it prints `NO`.

**Proof.**  
*If* part – Lemma&nbsp;6.  
*Only‑if* part – Lemma&nbsp;7. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

* `V = 2q ≤ 200 000`  
* `E = t ≤ 400 000`

Hopcroft‑Karp: `O(E·√V) = O(4·10⁵·√2·10⁵) ≈ 1.8·10⁸` operations – fast enough in
2 seconds in Python (well‑optimized implementation).  

Memory: adjacency list `O(E)`, plus a few `O(V)` arrays – well below 256 MB.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def hopcroft_karp(adj, n):
    """adj: list of lists, left side size n, right side also n.
       returns pairU (size n) where pairU[u] = matched right index or -1,
               and size of matching."""
    INF = 10 ** 9
    pairU = [-1] * n
    pairV = [-1] * n
    dist = [0] * n

    def bfs():
        q = deque()
        for u in range(n):
            if pairU[u] == -1:
                dist[u] = 0
                q.append(u)
            else:
                dist[u] = INF
        found = False
        while q:
            u = q.popleft()
            for v in adj[u]:
                pu = pairV[v]
                if pu != -1 and dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    q.append(pu)
                if pu == -1:
                    found = True
        return found

    sys.setrecursionlimit(1 << 25)
    def dfs(u):
        for v in adj[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(n):
            if pairU[u] == -1 and dfs(u):
                matching += 1
    return pairU, matching

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    adj = [[] for _ in range(q)]
    for _ in range(t):
        a = int(next(it)) - 1          # left 0‑based
        b = int(next(it)) - (q + 1)    # right 0‑based
        if 0 <= a < q and 0 <= b < q:
            adj[a].append(b)

    pairU, size = hopcroft_karp(adj, q)
    out = []
    if size == q:
        out.append(b"YES")
        for u in range(q):
            v = pairU[u]
            out.append(f"{u+1} {v+q+1}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
