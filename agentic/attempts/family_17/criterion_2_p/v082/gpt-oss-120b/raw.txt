**Solution Explanation**

The problem asks for a set of `q` edges that connects every vertex on the left side  
(`1 … q`) with a distinct vertex on the right side (`q+1 … 2q`).  
That is exactly a *perfect matching* in a bipartite graph.

We have to decide whether a perfect matching exists and, if it does, output one.
The classic algorithm for maximum bipartite matching in `O(E·√V)` is
**Hopcroft‑Karp**.  
With `V = 2·q ≤ 2·10⁵` and `E ≤ 4·10⁵` it easily fits into the limits.

--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[1…q]   // left vertices, store right index = b-q (1…q)

Hopcroft‑Karp:
    matchL[1…q] = 0          // matched right vertex, 0 = free
    matchR[1…q] = 0          // matched left vertex
    dist[1…q]

    while BFS() finds at least one free left vertex reachable:
        for each left vertex u that is free:
            if DFS(u) succeeds: increase matching size

    // BFS builds layers of the alternating graph
    // DFS searches augmenting paths respecting the layers

if size of matching == q:
    print "YES"
    for u = 1 … q:
        print u, matchL[u] + q   // convert right index back to original id
else:
    print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs “YES” with a correct set of conduits
iff such a set exists.

---

##### Lemma 1  
During Hopcroft‑Karp, `matchL` and `matchR` always represent a matching
(no vertex is incident to more than one selected edge).

**Proof.**  
Initially all entries are `0` → empty matching.  
Both BFS and DFS never modify the arrays.  
Only when an augmenting path is found, the algorithm flips the edges along
the path: each vertex on the path switches from matched to unmatched or vice
versa, preserving the property that each vertex is incident to at most one
selected edge. ∎



##### Lemma 2  
Each iteration of the outer `while` loop increases the size of the matching
by at least one, and after the loop finishes the matching is maximum.

**Proof.**  
BFS builds the layered graph consisting of all shortest alternating paths
(starting at a free left vertex and ending at a free right vertex).
If BFS finds no free right vertex, there is no augmenting path at all,
hence the current matching is maximum (classical theorem of Berge).

Otherwise, DFS finds a set of vertex‑disjoint shortest augmenting paths
inside this layered graph and augments along each of them.
Each augmenting path strictly increases the matching size by one,
so the size grows by at least one per outer iteration. ∎



##### Lemma 3  
If the algorithm finishes with matching size `q`, the printed edges connect
every left vertex with a distinct right vertex, i.e. they satisfy both
requirements of the problem.

**Proof.**  
Size `q` means every left vertex is matched (there are exactly `q` left
vertices). By Lemma&nbsp;1 each left vertex is matched to a unique right
vertex, therefore every right vertex is also matched (otherwise more than
`q` left vertices would be needed). The printed pairs are exactly those
matched edges, so each component appears in exactly one conduit. ∎



##### Lemma 4  
If a perfect matching exists, the algorithm ends with matching size `q`.

**Proof.**  
Hopcroft‑Karp always computes a *maximum* matching (Lemma&nbsp;2).  
If a perfect matching exists, the maximum size is `q`. Hence the algorithm
must reach size `q`. ∎



##### Theorem  
The program outputs  

* “YES” followed by a valid list of `q` conduits **iff** such a list exists;  
* otherwise it outputs “NO”.

**Proof.**  

*If* the program prints “YES”, by Lemma&nbsp;3 the printed edges form a
perfect matching, therefore a valid list exists.

*Only‑if*: assume a valid list exists. By Lemma&nbsp;4 the algorithm finds a
matching of size `q` and therefore prints “YES”. If no perfect matching
exists, the maximum size is `< q`; the algorithm terminates with a smaller
matching and prints “NO”. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*`BFS`* runs in `O(E)` time, `DFS` in `O(E)` as well.
The number of outer iterations is `O(√V)` for Hopcroft‑Karp.
Hence total time `O(E·√V) ≤ 4·10⁵·√2·10⁵ ≈ 1.8·10⁸` operations, well within
2 seconds in Python.

Memory usage: adjacency list `O(E)`, plus several arrays of size `O(V)`.  
All together `O(E + V) ≤ 5·10⁵` integers → far below 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys
import collections

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    G = [[] for _ in range(q + 1)]          # 1‑based left side
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        G[a].append(b - q)                  # map right vertex to 1..q

    INF = 10 ** 9
    matchL = [0] * (q + 1)
    matchR = [0] * (q + 1)
    dist = [0] * (q + 1)

    def bfs() -> bool:
        dq = collections.deque()
        for u in range(1, q + 1):
            if matchL[u] == 0:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        found = False
        while dq:
            u = dq.popleft()
            for v in G[u]:
                w = matchR[v]
                if w == 0:
                    found = True          # free right vertex reachable
                elif dist[w] == INF:
                    dist[w] = dist[u] + 1
                    dq.append(w)
        return found

    sys.setrecursionlimit(1 << 25)
    def dfs(u: int) -> bool:
        for v in G[u]:
            w = matchR[v]
            if w == 0 or (dist[w] == dist[u] + 1 and dfs(w)):
                matchL[u] = v
                matchR[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, q + 1):
            if matchL[u] == 0 and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(1, q + 1):
            v = matchL[u] + q
            out.append(f"{u} {v}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
