**Solution Explanation**

The problem asks for a *perfect matching* in a bipartite graph  

* left side : vertices `1 … q` (surface modules)  
* right side: vertices `q+1 … 2q` (orbital modules)  

` t ` edges are given, each connects one left vertex with one right vertex.
We have to decide whether a set of `q` edges exists that matches every vertex
exactly once, and output any such set.

The classic algorithm for maximum bipartite matching in
`O(E·√V)` is **Hopcroft‑Karp**.  
With `V = 2·q ≤ 2·10⁵` and `E ≤ 4·10⁵` it easily fits into the limits.

--------------------------------------------------------------------

#### Algorithm
```
read q, t
for each edge (a,b):
        store b in adjacency list of a
        also remember original right vertex (b) for output

run Hopcroft‑Karp
        pairU[u] – right vertex matched to left u   (0 = unmatched)
        pairV[v] – left vertex matched to right v   (0 = unmatched)
        dist[u]  – BFS distance layer

if size of matching == q:
        print "YES"
        for each left vertex u = 1 … q:
                v = pairU[u]                # internal index 1 … q
                print u, v+q                # restore original right label
else:
        print "NO"
```

**Hopcroft‑Karp details**

*BFS* builds distance layers from all currently free left vertices.
If a free right vertex is reachable, an augmenting path exists.

*DFS* (called `dfs(u)`) tries to extend the alternating path from a left vertex
`u` following only edges that respect the BFS layers.
When it reaches a free right vertex, the path is augmented.

The BFS/DFS loop repeats until BFS cannot reach any free right vertex,
i.e. no augmenting path exists any more. The obtained matching is maximum.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs “YES” and a correct set of corridors
iff such a set exists.

---

##### Lemma 1  
After each iteration of the Hopcroft‑Karp loop, `pairU`/`pairV` represent a
matching (no vertex is incident to more than one selected edge).

**Proof.**  
Initially all pairs are `0` → empty matching.  
During DFS, an augmenting path is found that alternates between unmatched
and matched edges, starting and ending with unmatched vertices.
Flipping the status of all edges on this path preserves the matching
property: every internal vertex loses one incident matched edge and gains
another one, endpoints gain their first matched edge. ∎



##### Lemma 2  
If BFS returns *false* (no free right vertex reachable), the current matching
is maximum.

**Proof.**  
Standard Hopcroft‑Karp theory: BFS builds the layered graph consisting of
all shortest augmenting paths. If none exists, there is no augmenting path at
all, therefore the matching cannot be enlarged → it is maximum. ∎



##### Lemma 3  
If the algorithm finishes with matching size `q`, the selected edges form a
perfect matching (every left and every right vertex is matched exactly once).

**Proof.**  
Size `q` means all `q` left vertices are matched (matching size ≤ number of
left vertices). By Lemma&nbsp;1 each right vertex is incident to at most one
matched edge. Since there are exactly `q` right vertices, all of them must be
matched as well. Hence each vertex on both sides is matched exactly once. ∎



##### Lemma 4  
If a perfect matching exists, the algorithm will find a matching of size `q`.

**Proof.**  
Hopcroft‑Karp always computes a *maximum* matching (Lemma&nbsp;2).  
If a perfect matching exists, the maximum size is at least `q`. Because the
graph has only `q` vertices on each side, the maximum size cannot exceed `q`.
Thus the maximum size equals `q`, and the algorithm will obtain it. ∎



##### Theorem  
The program prints  

* “YES” followed by `q` corridors that use every module exactly once  
  **iff** such a set exists; otherwise it prints “NO”.

**Proof.**  

*If* the program prints “YES”, it did so only when the matching size is `q`.
By Lemma&nbsp;3 the printed edges constitute a perfect matching, satisfying the
requirement.

*Only‑if*: assume a feasible set exists. By Lemma&nbsp;4 the algorithm finds a
matching of size `q`, therefore prints “YES”. If no feasible set exists,
the maximum matching size is `< q`; the algorithm ends with size `< q` and
prints “NO”. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

* `BFS` scans each edge at most once → `O(E)`.
* Each `DFS` also scans each edge at most once per phase.
* Number of phases ≤ `√V` (standard Hopcroft‑Karp bound).

Total time: `O(E·√V) ≤ 4·10⁵·√2·10⁵ ≈ 1.8·10⁸` operations, well below 2 s in Python
with efficient implementation.

Memory:

* adjacency list: `O(E)`
* several arrays of length `q` or `q+1`: `O(q)`

Overall ≤ a few tens of MB, inside the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys
import collections

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    # adjacency from left 1..q to right 1..q (internal)
    adj = [[] for _ in range(q + 1)]
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        adj[a].append(b - q)          # store right index shifted to 1..q

    # Hopcroft‑Karp
    NIL = 0
    pairU = [NIL] * (q + 1)          # left -> right
    pairV = [NIL] * (q + 1)          # right -> left
    dist = [0] * (q + 1)

    def bfs() -> bool:
        dq = collections.deque()
        for u in range(1, q + 1):
            if pairU[u] == NIL:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = -1
        found = False
        while dq:
            u = dq.popleft()
            for v in adj[u]:
                pu = pairV[v]
                if pu == NIL:
                    found = True          # we can reach a free right vertex
                elif dist[pu] == -1:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
        return found

    sys.setrecursionlimit(1 << 25)
    def dfs(u: int) -> bool:
        for v in adj[u]:
            pu = pairV[v]
            if pu == NIL or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = -1
        return False

    matching = 0
    while bfs():
        for u in range(1, q + 1):
            if pairU[u] == NIL and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(1, q + 1):
            v = pairU[u]
            out.append(f"{u} {v + q}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
