**Solution Explanation**

We have a bipartite graph  

* left side – acidic agents `1 … q`  
* right side – alkaline agents `q+1 … 2q` (renumbered to `1 … q` for the algorithm)

An edge `(a , b)` is usable **iff**

* it is listed in the registry,
* `a + b ≤ 3q` (thermal limit).

The condition `|a‑b| ≥ 1` is always true because `a ≤ q < b`.

The task is to decide whether the graph contains a *perfect matching* (matching of size `q`) and, if it does, output one.

The classic algorithm for maximum bipartite matching in `O(E·√V)` is **Hopcroft‑Karp**.
With `V = 2q ≤ 2·10⁵` and `E ≤ 4·10⁵` it easily fits into the limits.



--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[1…q]   // left → list of right vertices (1‑based)
for each of the t registry lines (a,b):
        if a+b <= 3*q:                     // edge respects the sum limit
                G[a].append(b - q)          // store right vertex as 1…q

run Hopcroft‑Karp on G
if size of maximum matching == q:
        print "YES"
        for each left vertex a (1…q):
                b = matched_right[a] + q
                print a, b
else:
        print "NO"
```

**Hopcroft‑Karp sketch**

* `pairU[u]` – right vertex matched with left `u` (`0` = free)  
* `pairV[v]` – left vertex matched with right `v` (`0` = free)  
* BFS builds distance layers from all free left vertices; unreachable vertices get `INF`.  
* DFS (called `dfs(u)`) tries to find augmenting paths respecting the layers.  
* Repeat BFS+DFS while BFS reaches a free right vertex.

Complexities: `O(E·√V)` time, `O(E+V)` memory.



--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs “YES” with a valid set of mixtures
iff such a set exists.

---

##### Lemma 1  
After filtering, every remaining edge `(a,b)` satisfies all problem
constraints.

**Proof.**  
The input guarantees `1 ≤ a ≤ q < b ≤ 2q`.  
We keep the edge only if `a+b ≤ 3q`.  
Thus the sum constraint holds, and the difference is at least `1`
because `a < b`. ∎



##### Lemma 2  
Any perfect matching in the filtered graph corresponds to a feasible
neutralisation plan.

**Proof.**  
A perfect matching pairs each left vertex `a` with a distinct right vertex
`b`. By Lemma&nbsp;1 each pair respects the sum limit and the required
acid‑alkali orientation. All agents appear exactly once, so the plan
fulfills every condition of the statement. ∎



##### Lemma 3  
If the algorithm prints “YES”, the printed pairs form a perfect matching
in the filtered graph.

**Proof.**  
The Hopcroft‑Karp routine returns a matching `M` of maximum cardinality.
The algorithm checks `|M| = q`. When this holds, `M` matches every left
vertex to a distinct right vertex. The output iterates over all left
vertices and prints the matched partner, therefore reproducing exactly
the edges of `M`. ∎



##### Lemma 4  
If a feasible neutralisation plan exists, the algorithm prints “YES”.

**Proof.**  
A feasible plan is, by Lemma&nbsp;2, a perfect matching in the filtered
graph. Hence the maximum matching size is at least `q`. Hopcroft‑Karp
computes a maximum matching, so it will also have size `q`. The algorithm
therefore enters the “YES” branch. ∎



##### Lemma 5  
If the algorithm prints “NO”, no feasible neutralisation plan exists.

**Proof.**  
Printing “NO” means the maximum matching size found is `< q`. If a feasible
plan existed, Lemma&nbsp;2 would give a perfect matching of size `q`,
contradicting maximality. Hence no such plan exists. ∎



##### Theorem  
The algorithm outputs “YES” together with a valid set of `q` mixtures
iff such a set exists; otherwise it outputs “NO”.

**Proof.**  
*If* part: by Lemma&nbsp;4.  
*Only‑if* part: by Lemma&nbsp;5 and Lemma&nbsp;3 (the printed pairs are
valid). ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Filtering*: `O(t)` time, `O(E)` memory (`E` = number of kept edges ≤ t).  
*Hopcroft‑Karp*: `O(E·√V)` time, `O(E+V)` memory.  
With `V = 2q ≤ 2·10⁵`, `E ≤ 4·10⁵` this is well below the limits
(≈ 2·10⁷ operations).  
Overall memory ≤ a few MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    G = [[] for _ in range(q + 1)]          # 1‑based left side
    limit = 3 * q
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        if a + b <= limit:
            G[a].append(b - q)               # right vertex in 1..q

    # Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [0] * (q + 1)    # left -> right
    pairV = [0] * (q + 1)    # right -> left
    dist = [0] * (q + 1)

    def bfs() -> bool:
        dq = deque()
        for u in range(1, q + 1):
            if pairU[u] == 0:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        reachable = False
        while dq:
            u = dq.popleft()
            for v in G[u]:
                pu = pairV[v]
                if pu == 0:
                    reachable = True
                elif dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
        return reachable

    sys.setrecursionlimit(1 << 25)
    def dfs(u: int) -> bool:
        for v in G[u]:
            pu = pairV[v]
            if pu == 0 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, q + 1):
            if pairU[u] == 0 and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for a in range(1, q + 1):
            b = pairU[a] + q
            out.append(f"{a} {b}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```
