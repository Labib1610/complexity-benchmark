**Solution Explanation**

For every input terminal `a (1 … q)` we have a set of output terminals `b (q+1 … 2q)` that can be connected to it.
We have to choose exactly `q` connections so that

* each input terminal is used once,
* each output terminal is used once.

That is exactly a *perfect matching* in a bipartite graph  
left side = inputs `1 … q` , right side = outputs `1 … q` (we renumber `b → b‑q`).

The graph has  

* `|L| = |R| = q   ( ≤ 100 000 )`
* `|E| = t ≤ 400 000`.

We must decide whether a perfect matching exists and, if it does, output one.

The classic algorithm for maximum bipartite matching in this size range is **Hopcroft‑Karp**,
running in `O(|E|·√|V|)` which is well below the limits.



--------------------------------------------------------------------

#### Algorithm
```
read q, t
if t < q:          # not enough edges for a perfect matching
    print NO and exit

build adjacency list G[1…q]   # left → list of right indices (b-q)

run Hopcroft‑Karp on G
    pairU[1…q] = matched right vertex or 0 (unmatched)
    pairV[1…q] = matched left vertex or 0
    matching_size = number of matched pairs

if matching_size == q:
    print YES
    for a = 1 … q:
        b = pairU[a] + q          # restore original output id
        print a, b
else:
    print NO
```

**Hopcroft‑Karp details**

* `dist[u]` – distance layer of left vertex `u` in the BFS.
* BFS builds layers from all currently free left vertices, following alternating
  unmatched‑matched edges, and stops when it reaches a free right vertex.
* DFS (called `dfs(u)`) tries to find augmenting paths inside the layered graph.
* Each BFS/DFS round increases the matching size by at least one, and the number
  of rounds is `O(√|V|)`.

All indices are 1‑based; `0` means “nil”.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of `q` pathways
iff such a set exists.

---

##### Lemma 1  
After the Hopcroft‑Karp procedure finishes, `pairU`/`pairV` describe a **maximum**
matching of the bipartite graph.

**Proof.** Hopcroft‑Karp is a known algorithm; its invariant is that after each
phase (BFS + many DFS) the current matching is maximal among all matchings that
do not use any augmenting path of length ≤ the current BFS distance.
When BFS finds no free right vertex, there is **no augmenting path** at all,
hence the current matching is maximum. ∎



##### Lemma 2  
If the algorithm outputs `YES`, the printed `q` edges form a perfect matching.

**Proof.** `YES` is printed only when `matching_size == q`.  
The matching size equals the number of left vertices that have a non‑zero
`pairU`. Because there are exactly `q` left vertices, all of them are matched.
By definition of a matching, each right vertex appears at most once; the size
`q` also forces every right vertex to be matched (otherwise size would be `< q`).
Thus every input and every output terminal appears exactly once – a perfect
matching. The printed edges are exactly those pairs. ∎



##### Lemma 3  
If a perfect matching exists, the algorithm prints `YES`.

**Proof.** Let `M*` be a perfect matching, size `q`. By Lemma&nbsp;1 the algorithm
computes a *maximum* matching `M`. Since `|M| ≥ |M*|` (maximum ≥ any matching),
`|M| ≥ q`. But a matching cannot be larger than `q` (only `q` vertices on each
side), therefore `|M| = q`. Consequently the algorithm prints `YES`. ∎



##### Lemma 4  
If the algorithm prints `NO`, no perfect matching exists.

**Proof.** `NO` is printed only when `matching_size < q`. By Lemma&nbsp;1 the
computed matching is maximum, so every matching has size `< q`. A perfect
matching would have size `q`, contradiction. Hence none exists. ∎



##### Theorem  
The program outputs `YES` followed by a valid set of `q` pathways
iff such a set exists; otherwise it outputs `NO`.

**Proof.**  
*If* part: existence ⇒ by Lemma&nbsp;3 algorithm prints `YES`; by Lemma&nbsp;2
the printed edges are a perfect matching.  
*Only‑if* part: algorithm prints `YES` ⇒ by Lemma&nbsp;2 the edges are a perfect
matching, so a solution exists.  
If algorithm prints `NO`, by Lemma&nbsp;4 no perfect matching exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(t)` time, `O(t + q)` memory.  
*Hopcroft‑Karp*: `O(t·√q)` time, `O(t + q)` additional memory.  
With `q ≤ 10⁵, t ≤ 4·10⁵` this is well under the limits (≈ 2·10⁷ operations).  

Overall:  

*Time* `O(t·√q)` ≤ `O(4·10⁵·316) ≈ 1.3·10⁸` worst‑case, fast in C/PyPy; in CPython
still comfortably below 2 s.  
*Memory* `O(t + q)` ≤ about 5 · 10⁵ integers ≈ 4 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    if t < q:
        print("NO")
        return

    G = [[] for _ in range(q + 1)]          # 1‑based left side
    for _ in range(t):
        a = int(next(it))
        b = int(next(it)) - q                # map to 1..q
        if 1 <= a <= q and 1 <= b <= q:
            G[a].append(b)

    # Hopcroft‑Karp
    NIL = 0
    pairU = [NIL] * (q + 1)
    pairV = [NIL] * (q + 1)
    dist = [0] * (q + 1)

    def bfs() -> bool:
        dq = deque()
        for u in range(1, q + 1):
            if pairU[u] == NIL:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = -1
        found = False
        while dq:
            u = dq.popleft()
            for v in G[u]:
                pu = pairV[v]
                if pu == NIL:
                    found = True          # we can reach free right vertex
                elif dist[pu] == -1:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
        return found

    sys.setrecursionlimit(1 << 25)

    def dfs(u: int) -> bool:
        for v in G[u]:
            pu = pairV[v]
            if pu == NIL or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = -1
        return False

    matching = 0
    while bfs():
        for u in range(1, q + 1):
            if pairU[u] == NIL and dfs(u):
                matching += 1

    if matching == q:
        out_lines = ["YES"]
        for a in range(1, q + 1):
            b = pairU[a] + q
            out_lines.append(f"{a} {b}")
        sys.stdout.write("\n".join(out_lines))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
