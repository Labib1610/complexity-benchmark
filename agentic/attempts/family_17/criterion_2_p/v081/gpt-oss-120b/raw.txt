**Solution Explanation**

The problem asks for a *perfect matching* in a bipartite graph:

* left side – originators `1 … q`
* right side – endpoints `q+1 … 2q`
* an edge `(a,b)` (with `a ≤ q < b`) means the tested link can be used.

We have to decide whether a set of `q` edges exists that matches every vertex exactly once,
and output one such set.

The classic algorithm for maximum bipartite matching in `O(E·√V)` is **Hopcroft‑Karp**.
With `V = 2·q ≤ 2·10⁵` and `E ≤ 4·10⁵` it easily fits into the limits.



--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[1…q]   // only left vertices store their neighbours (right ids shifted to 1…q)

run Hopcroft‑Karp
    pairU[u] – matched right vertex (0 = free)
    pairV[v] – matched left vertex  (0 = free)
    dist[u]  – BFS distance layer

if size of matching == q
        print YES
        for each left u = 1 … q
                print u, pairU[u] + q          // restore original right id
else
        print NO
```

*Why it works*  
Hopcroft‑Karp repeatedly finds a maximal set of shortest augmenting paths
using BFS/DFS and augments along all of them.
It is proven to return a maximum matching.
If the maximum size equals `q`, a perfect matching exists,
otherwise it is impossible.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs `YES` with a valid set of links
iff such a set exists.

---

**Lemma 1**  
After the Hopcroft‑Karp procedure finishes, `pairU`/`pairV` describe a
maximum matching of the bipartite graph.

*Proof.* Hopcroft‑Karp is a known algorithm; its correctness proof shows that
when the BFS phase cannot reach a free right vertex, no augmenting path exists,
hence the current matching is maximum. ∎



**Lemma 2**  
If the algorithm prints `YES`, the printed `q` pairs form a perfect matching.

*Proof.* `YES` is printed only when the matching size returned by Hopcroft‑Karp
equals `q`. Then every left vertex `u` is matched (`pairU[u] ≠ 0`),
and because the matching is bipartite, each right vertex is matched to at most
one left vertex. Since there are exactly `q` left vertices, exactly `q` right
vertices are matched as well, i.e. all vertices are covered exactly once.
The output restores the original right identifiers, so each printed pair is an
edge of the input graph. ∎



**Lemma 3**  
If a perfect matching exists, the algorithm prints `YES`.

*Proof.* Let `M*` be a perfect matching, size `q`. By Lemma&nbsp;1 the algorithm
computes a maximum matching `M`. Because `|M| ≥ |M*| = q`, we have `|M| = q`.
Consequently the algorithm prints `YES`. ∎



**Theorem**  
The algorithm outputs `YES` followed by a valid selection of links
iff such a selection exists; otherwise it outputs `NO`.

*Proof.*  
- If the algorithm outputs `YES`, by Lemma&nbsp;2 the printed links are a perfect
  matching, therefore a valid selection exists.
- If a valid selection exists, a perfect matching exists, and by Lemma&nbsp;3
  the algorithm outputs `YES`.  
If neither case holds, the algorithm reaches the `NO` branch. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

* `E = t ≤ 4·10⁵`, `V = 2·q ≤ 2·10⁵`.
* Hopcroft‑Karp runs in `O(E·√V)`  
  ≤ `4·10⁵ · √2·10⁵` ≈ `4·10⁵ · 447` ≈ `1.8·10⁸` elementary operations,
  well within 2 seconds in Python (the constant is small).
* Memory: adjacency list `O(E)`, plus a few arrays of size `O(V)`.  
  Total ≤ a few megabytes, far below 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    # adjacency for left vertices 1..q, store right ids shifted to 1..q
    G = [[] for _ in range(q + 1)]
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        G[a].append(b - q)          # right side index 1..q

    # Hopcroft‑Karp
    pairU = [0] * (q + 1)   # left -> right (0 = free)
    pairV = [0] * (q + 1)   # right -> left
    dist = [0] * (q + 1)

    INF = 10 ** 9

    def bfs() -> bool:
        dq = deque()
        for u in range(1, q + 1):
            if pairU[u] == 0:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        reachable_free = False
        while dq:
            u = dq.popleft()
            for v in G[u]:
                pu = pairV[v]
                if pu == 0:
                    reachable_free = True
                elif dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
        return reachable_free

    sys.setrecursionlimit(1 << 25)

    def dfs(u: int) -> bool:
        for v in G[u]:
            pu = pairV[v]
            if pu == 0 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, q + 1):
            if pairU[u] == 0 and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(1, q + 1):
            v = pairU[u] + q
            out.append(f"{u} {v}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
