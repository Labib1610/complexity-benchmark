**Solution Explanation**

The problem asks for a *perfect matching* in a bipartite graph:

* left part – initiators `1 … q`
* right part – responders `q+1 … 2q`
* each given pair connects one left vertex with one right vertex

We have to decide whether a set of `q` edges exists that covers every vertex exactly once and, if it exists, output one such set.

The classic algorithm for maximum bipartite matching in `O(E·√V)` is **Hopcroft‑Karp**.
With `V = 2·q ≤ 2·10⁵` and `E ≤ 4·10⁵` it easily fits into the limits.

--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[1…q]   // only left side vertices
for each edge (a,b):
        G[a].append(b - q)    // store right vertex as 1…q

pairU[1…q] = 0   // matched right vertex for each left (0 = free)
pairV[1…q] = 0   // matched left vertex for each right
dist[1…q]

function bfs():
        queue = empty
        for u = 1 … q:
                if pairU[u] == 0:   // free left vertex
                        dist[u] = 0
                        push u
                else:
                        dist[u] = INF
        dist0 = INF
        while queue not empty:
                u = pop
                if dist[u] < dist0:
                        for v in G[u]:
                                if pairV[v] == 0:
                                        dist0 = dist[u] + 1          // found free right
                                elif dist[pairV[v]] == INF:
                                        dist[pairV[v]] = dist[u] + 1
                                        push pairV[v]
        return dist0 != INF          // there exists an augmenting path

function dfs(u):
        for v in G[u]:
                if pairV[v] == 0 or (dist[pairV[v]] == dist[u] + 1 and dfs(pairV[v])):
                        pairU[u] = v
                        pairV[v] = u
                        return True
        dist[u] = INF
        return False

matching = 0
while bfs():
        for u = 1 … q:
                if pairU[u] == 0 and dfs(u):
                        matching += 1

if matching == q:
        print "YES"
        for u = 1 … q:
                print u, pairU[u] + q
else:
        print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs “YES” with a perfect matching iff such a matching exists.

---

**Lemma 1**  
`bfs` returns *true* exactly when there exists an augmenting path (with respect to the current matching) from some free left vertex to a free right vertex.

*Proof.*  
The BFS explores the layered graph used by Hopcroft‑Karp: edges from left to right are traversed forward, edges from right to its matched left are traversed backward.  
`dist[u]` is the length of the shortest alternating path from a free left vertex to `u`.  
If a free right vertex is reached, `dist0` records the length of the shortest augmenting path, and the function returns true.  
If no free right vertex is reachable, no alternating path ends in a free right vertex, i.e. no augmenting path exists. ∎



**Lemma 2**  
During one phase (one `while bfs()` iteration) the DFS finds a set of vertex‑disjoint augmenting paths of minimum possible length, and after augmenting along all of them the size of the matching increases by exactly the number of found paths.

*Proof.*  
The layered graph guarantees that any augmenting path found by `dfs` has length `dist0` (the minimal length).  
`dfs` only follows edges that respect the layering (`dist[pairV[v]] == dist[u] + 1`), therefore it never uses a vertex already matched in the current phase except as the unique predecessor on the alternating path.  
When a path is found, the recursion flips the matched/unmatched status along it, increasing the matching size by one.  
Because after a successful `dfs` the left endpoint becomes matched, it will not be used again in the same phase, ensuring vertex‑disjointness. ∎



**Lemma 3**  
After each phase the length of the shortest augmenting path strictly increases.

*Proof.*  
All augmenting paths of the current minimal length are eliminated (they become matched). Any remaining augmenting path must be longer, otherwise it would have been discovered in the current BFS layer. ∎



**Lemma 4**  
When the algorithm terminates, the matching is maximum.

*Proof.*  
Termination happens when `bfs` finds no augmenting path, i.e. there is none in the current graph. By the classic theorem of Berge, a matching without augmenting paths is maximum. ∎



**Lemma 5**  
If the algorithm outputs “YES”, the printed edges form a perfect matching.

*Proof.*  
“YES” is printed only when `matching == q`. The matching size equals the number of left vertices, therefore every left vertex is matched. Because the graph is bipartite with equal sides, the same number of right vertices are matched, and each vertex appears exactly once. The output translates internal right indices back to original IDs (`+ q`). ∎



**Lemma 6**  
If a perfect matching exists, the algorithm outputs “YES”.

*Proof.*  
A perfect matching has size `q`. Hopcroft‑Karp computes a *maximum* matching (Lemma 4). Hence the algorithm will obtain a matching of size at least `q`. Since the graph has only `q` left vertices, the size cannot exceed `q`; therefore it equals `q` and “YES” is printed. ∎



**Theorem**  
The algorithm prints “YES” and a valid set of `q` pairs iff such a set exists; otherwise it prints “NO”.

*Proof.*  
- If the algorithm prints “YES”, by Lemma 5 the printed pairs are a perfect matching, so a solution exists.  
- If a solution exists, by Lemma 6 the algorithm reaches matching size `q` and prints “YES”.  
- In all other cases the algorithm finishes with matching size `< q` and prints “NO”. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

* `BFS` scans each edge at most once → `O(E)`.
* Each `DFS` also scans edges, but each edge participates in at most one successful DFS per phase.
* Number of phases ≤ `√V` (standard Hopcroft‑Karp bound).

Total time: `O(E·√V) ≤ 4·10⁵·√2·10⁵ ≈ 1.8·10⁸` operations, well within 2 s in Python with fast I/O.

Memory:

* adjacency list: `O(E)`
* several arrays of size `q` → `O(q)`

Overall ≤ a few tens of MB, below the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    G = [[] for _ in range(q + 1)]          # 1‑based left vertices
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        G[a].append(b - q)                  # store right as 1..q

    pairU = [0] * (q + 1)   # left -> right (0 = free)
    pairV = [0] * (q + 1)   # right -> left
    dist = [0] * (q + 1)
    INF = 10 ** 9

    def bfs() -> bool:
        dq = deque()
        for u in range(1, q + 1):
            if pairU[u] == 0:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        found = False
        while dq:
            u = dq.popleft()
            for v in G[u]:
                pu = pairV[v]
                if pu == 0:
                    found = True          # we can reach a free right
                elif dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
        return found

    sys.setrecursionlimit(1 << 25)

    def dfs(u: int) -> bool:
        for v in G[u]:
            pu = pairV[v]
            if pu == 0 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, q + 1):
            if pairU[u] == 0 and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(1, q + 1):
            out.append(f"{u} {pairU[u] + q}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```
