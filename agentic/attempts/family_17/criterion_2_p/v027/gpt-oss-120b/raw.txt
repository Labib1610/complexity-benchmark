**Solution Explanation**

The problem asks for a *perfect matching* in a bipartite graph  

* left part – satellites `1 … q`  
* right part – sectors `q+1 … 2q` (renumbered to `1 … q` for convenience)  

An edge `(a , b)` is given only if the pair is allowed.  
We have to decide whether a matching that covers **all** `q` vertices on each side exists and, if it does, output one such matching.

The classic algorithm for maximum bipartite matching in large sparse graphs is **Hopcroft‑Karp**.
Its complexity is `O(E·√V)` which is easily fast enough for  

```
V = 2·q ≤ 2·10^5
E = t   ≤ 4·10^5
```

--------------------------------------------------------------------

#### Algorithm
1. **Read input**.  
   For every edge `(a , b)` store `b‑q` (1‑based) in the adjacency list of left vertex `a`.
2. **Hopcroft‑Karp**
   * `pairU[u]` – right vertex matched to left `u` (0 = free)  
   * `pairV[v]` – left vertex matched to right `v` (0 = free)  
   * `dist[u]` – BFS distance layer of left vertex `u`
   * **BFS** builds layers of the alternating graph starting from all free left vertices.
   * **DFS** (actually recursive `dfs(u)`) tries to find augmenting paths respecting the layers.
   * Repeat BFS+DFS while BFS discovers at least one free right vertex.
3. After the algorithm finishes, `matchingSize = number of matched left vertices`.
   * If `matchingSize == q` → perfect matching exists.
   * Otherwise → impossible.
4. **Output**
   * `YES` and for each left vertex `u = 1 … q` print `u  (pairU[u] + q)`.
   * Or just `NO`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs `YES` with a valid perfect matching iff such a matching exists.

---

##### Lemma 1  
During Hopcroft‑Karp, after each BFS/DFS phase the set of matched edges is a matching (no vertex incident to two matched edges).

**Proof.**  
Initially all vertices are free, trivially a matching.  
Each DFS augments along vertex‑disjoint augmenting paths found in the current BFS layering.  
Flipping the matched/unmatched status along a single augmenting path preserves the matching property, and because the paths are vertex‑disjoint, simultaneous flips also preserve it. ∎



##### Lemma 2  
If BFS returns *false* (no free right vertex reachable), the current matching is maximum.

**Proof.**  
Standard Hopcroft‑Karp theory: the BFS builds the shortest‑length alternating graph from free left vertices.  
If no free right vertex is reachable, there is no augmenting path at all, therefore the matching cannot be increased – it is maximum. ∎



##### Lemma 3  
If the algorithm terminates with `matchingSize = q`, the produced set of edges matches every left and every right vertex exactly once.

**Proof.**  
`matchingSize = q` means every left vertex is matched (there are `q` left vertices).  
Because the matching is a bijection between left and right sets (Lemma 1) the number of matched right vertices equals the number of matched left vertices, i.e. also `q`.  
Thus each right vertex is matched exactly once as well. ∎



##### Lemma 4  
If a perfect matching exists, Hopcroft‑Karp finishes with `matchingSize = q`.

**Proof.**  
Hopcroft‑Karp always finds a *maximum* matching (Lemma 2).  
A perfect matching has size `q`; therefore the maximum size is at least `q`.  
Since the graph has only `q` vertices on each side, the maximum size cannot exceed `q`.  
Hence the algorithm must reach size `q`. ∎



##### Theorem  
The program prints  

* `YES` followed by a list of `q` pairings that form a perfect matching **iff** such a matching exists,  
* otherwise prints `NO`.

**Proof.**  

*If the program prints `YES`.*  
It did so only when `matchingSize = q`. By Lemma 3 the printed edges constitute a perfect matching, which is a feasible solution.

*If a perfect matching exists.*  
By Lemma 4 the algorithm ends with `matchingSize = q`, therefore the program prints `YES` and a valid matching.

*If no perfect matching exists.*  
Then the maximum matching size is `< q`. Hopcroft‑Karp stops with that size, the program prints `NO`.  

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency lists*: `O(t)`  
*Hopcroft‑Karp*: `O(t·√q)`  
With the given limits this is ≤ `4·10^5·√10^5 ≈ 1.3·10^8` elementary operations, well inside the 2 s limit in Python (the constant factor is small).  

Memory usage: adjacency list `O(t)`, plus a few arrays of size `q` → `O(q + t)` ≤ about 5 · 10^5 integers → < 10 MB.

#### Reference Implementation  (Python 3)

```python
import sys
import collections

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    adj = [[] for _ in range(q + 1)]          # 1‑based left vertices
    for _ in range(t):
        a = int(next(it))
        b = int(next(it)) - q                 # map right side to 1..q
        if 1 <= a <= q and 1 <= b <= q:
            adj[a].append(b)

    # Hopcroft‑Karp
    INF = 10 ** 9
    pairU = [0] * (q + 1)   # left -> right
    pairV = [0] * (q + 1)   # right -> left
    dist = [0] * (q + 1)

    def bfs() -> bool:
        qd = collections.deque()
        for u in range(1, q + 1):
            if pairU[u] == 0:
                dist[u] = 0
                qd.append(u)
            else:
                dist[u] = INF
        found = False
        while qd:
            u = qd.popleft()
            for v in adj[u]:
                pu = pairV[v]
                if pu == 0:
                    found = True          # free right reachable
                elif dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    qd.append(pu)
        return found

    sys.setrecursionlimit(1 << 25)
    def dfs(u: int) -> bool:
        for v in adj[u]:
            pu = pairV[v]
            if pu == 0 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, q + 1):
            if pairU[u] == 0 and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(1, q + 1):
            v = pairU[u] + q
            out.append(f"{u} {v}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to the required input‑output format.
