**Solution Explanation**

The problem asks for a perfect matching in a bipartite graph  

* left part – nodes `1 … q` (low‑band)  
* right part – nodes `q+1 … 2q` (high‑band)  

Only edges given in the input may be used.  
We have to decide whether a perfect matching (size `q`) exists and, if it does,
output one such matching.

The classic algorithm for maximum bipartite matching in `O(E·√V)` is
**Hopcroft‑Karp**.  
With `V = 2·q ≤ 2·10⁵` and `E ≤ 4·10⁵` it easily fits into the limits.



--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[1…q]   // only left side vertices
for each edge a b:
        // a is in [1,q], b in [q+1,2q]
        G[a].append(b - q)    // store right index 1…q

Hopcroft‑Karp:
        matchL[1…q] = 0   // 0 = unmatched, otherwise right index
        matchR[1…q] = 0
        while BFS builds distance layers from all free left vertices:
                for each free left vertex u:
                        if DFS(u) found augmenting path:
                                increase matching size
        // after the loop matching size = size of maximum matching

if matching size == q:
        print "YES"
        for left = 1 … q:
                print left, matchL[left] + q
else:
        print "NO"
```

*BFS* creates distance `dist[u]` for left vertices; unmatched left vertices start
with distance `0`. It stops when a free right vertex is reached – this gives the
shortest augmenting path length.

*DFS* tries to extend an augmenting path only along edges that respect the
layering (`dist[next] == dist[u] + 1`). When it reaches an unmatched right
vertex it flips the path (updates `matchL` / `matchR`) and returns `True`.

The algorithm repeats BFS/DFS phases until no augmenting path exists, i.e. the
matching is maximum.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs “YES” with a valid perfect matching
iff such a matching exists.

---

##### Lemma 1  
During Hopcroft‑Karp, after each BFS/DFS phase the current matching is
maximum among all matchings that use only augmenting paths of length
strictly less than the length found by the BFS.

**Proof.**  
BFS discovers the length `L` of the shortest augmenting path in the current
graph. DFS only augments along paths of exactly this length `L`. After all
such shortest augmenting paths are saturated, no augmenting path of length `L`
remains. Therefore any remaining augmenting path must be longer than `L`. ∎



##### Lemma 2  
If after a phase BFS cannot reach any free right vertex, the current matching
is a maximum matching.

**Proof.**  
Absence of a reachable free right vertex means there is **no** augmenting
path at all (otherwise its first free right vertex would be reachable). By
the classic theorem of Berge, a matching without augmenting paths is maximum. ∎



##### Lemma 3  
When the algorithm terminates, `matchL` and `matchR` describe a matching of
size equal to the size of a maximum matching in the input graph.

**Proof.**  
The algorithm stops exactly when BFS fails to find a free right vertex.
By Lemma&nbsp;2 the current matching is maximum. The arrays store exactly the
edges of this matching, hence its size equals the maximum possible. ∎



##### Lemma 4  
If the algorithm outputs “YES”, the printed edges form a perfect matching
(i.e. every node `1 … 2q` appears exactly once).

**Proof.**  
“YES” is printed only when the matching size equals `q`.  
`matchL` contains for each left vertex a distinct right vertex (by definition
of a matching). Thus every left vertex appears once, and every right vertex
appears at most once. Because there are `q` left vertices and the matching size
is `q`, exactly `q` right vertices are matched, i.e. all of them. Translating
right indices back to original IDs (`+ q`) yields `q` disjoint edges covering
all `2q` nodes. ∎



##### Lemma 5  
If a perfect matching exists, the algorithm will output “YES”.

**Proof.**  
A perfect matching has size `q`. By Lemma&nbsp;3 the algorithm finds a maximum
matching; its size cannot be smaller than the optimum, therefore it is also
`q`. Consequently the algorithm prints “YES”. ∎



##### Theorem  
The program prints “YES” followed by a correct set of `q` locks
iff such a set exists; otherwise it prints “NO”.

**Proof.**  
*If* part: by Lemma&nbsp;5 a perfect matching forces the algorithm to output
“YES”, and Lemma&nbsp;4 guarantees the printed edges are a perfect matching.  

*Only‑if* part: if the algorithm prints “YES”, Lemma&nbsp;4 shows the printed
edges are a perfect matching, hence such a set exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

* `E = t ≤ 4·10⁵`, `V = 2·q ≤ 2·10⁵`.
* Hopcroft‑Karp runs in `O(E·√V)` time:  
  `√V ≤ √2·10⁵ ≈ 447`, so worst‑case operations ≈ `1.8·10⁸`, well inside 2 s
  in CP‑Python (the constant is small).
* Memory: adjacency list `O(E)`, plus a few `O(V)` arrays → ≤ a few MB,
  far below the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    G = [[] for _ in range(q + 1)]          # 1‑based left side
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        G[a].append(b - q)                  # store right index 1..q

    # Hopcroft‑Karp
    INF = 10 ** 9
    matchL = [0] * (q + 1)   # left -> right (0 = free)
    matchR = [0] * (q + 1)   # right -> left
    dist = [0] * (q + 1)

    def bfs() -> bool:
        dq = deque()
        for u in range(1, q + 1):
            if matchL[u] == 0:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        found = False
        while dq:
            u = dq.popleft()
            for v in G[u]:
                w = matchR[v]
                if w == 0:
                    found = True          # reachable free right vertex
                elif dist[w] == INF:
                    dist[w] = dist[u] + 1
                    dq.append(w)
        return found

    sys.setrecursionlimit(1 << 25)
    def dfs(u: int) -> bool:
        for v in G[u]:
            w = matchR[v]
            if w == 0 or (dist[w] == dist[u] + 1 and dfs(w)):
                matchL[u] = v
                matchR[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, q + 1):
            if matchL[u] == 0 and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(1, q + 1):
            out.append(f"{u} {matchL[u] + q}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
