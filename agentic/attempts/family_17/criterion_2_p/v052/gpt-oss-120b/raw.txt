**Solution Explanation**

The problem asks for a perfect matching in a bipartite graph  

* left part – vertices `1 … q`  
* right part – vertices `q+1 … 2q`  

Only edges given in the input may be used.  
If a perfect matching exists we have to output one such matching.

The classic algorithm for maximum bipartite matching in `O(E·√V)` is
**Hopcroft‑Karp**.  
With `V = 2·q ≤ 2·10⁵` and `E ≤ 4·10⁵` it easily satisfies the limits.



--------------------------------------------------------------------

#### Algorithm
```
read q, t
build adjacency list G[1…q]   // neighbours are right‑side indices 0…q-1
run Hopcroft‑Karp
if size of matching == q:
        print YES
        for each left vertex u (1…q):
                v = pairU[u]          // right index 0…q-1
                print u, v+q+1
else:
        print NO
```

**Hopcroft‑Karp details**

* `pairU[u]` – matched right vertex of left `u` (or -1)
* `pairV[v]` – matched left vertex of right `v` (or -1)
* `dist[u]` – distance in the BFS layering graph

```
BFS():
        queue all free left vertices, set their dist = 0
        others dist = INF
        dist_nil = INF
        while queue not empty:
                u = pop
                if dist[u] < dist_nil:
                        for each v in G[u]:
                                if pairV[v] == -1:          // free right vertex
                                        dist_nil = dist[u] + 1
                                else if dist[pairV[v]] == INF:
                                        dist[pairV[v]] = dist[u] + 1
                                        push(pairV[v])
        return dist_nil != INF

DFS(u):
        for each v in G[u]:
                if pairV[v] == -1 or (dist[pairV[v]] == dist[u]+1 and DFS(pairV[v])):
                        pairU[u] = v
                        pairV[v] = u
                        return True
        dist[u] = INF
        return False
```

The outer loop repeats BFS + DFS augmentations while BFS finds an
augmenting path. The total complexity is `O(E·√V)`.



--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs `YES` and a correct perfect matching
iff such a matching exists.

---

##### Lemma 1  
After each BFS phase, `dist[u]` equals the length of the shortest
alternating path (edges alternating unmatched / matched) from a free
left vertex to `u`. Vertices unreachable get `INF`.

**Proof.** BFS starts from all free left vertices with distance `0`.
Whenever it traverses an edge `u‑v`:
* if `v` is free on the right, we have reached the end of an alternating
  path, recording its length in `dist_nil`.
* otherwise `v` is matched to some `u'`; the algorithm enqueues `u'`
  with distance `dist[u]+1`.  
Thus every discovered vertex receives the length of the shortest
alternating path leading to it. Unvisited vertices have none, so `INF`. ∎



##### Lemma 2  
If BFS returns `True` (i.e. `dist_nil != INF`), there exists an
augmenting path of length `dist_nil`.

**Proof.** By Lemma&nbsp;1 `dist_nil` is set exactly when an edge from a
layered left vertex reaches a free right vertex, forming an alternating
path from a free left vertex to that right vertex of length
`dist_nil`. ∎



##### Lemma 3  
Each DFS call finds a vertex‑disjoint augmenting path of length
`dist_nil` (if one exists from its start vertex) and augments the
matching along it.

**Proof.** DFS follows only edges that respect the layering:
it moves from a left vertex `u` to a right neighbor `v` and, if `v` is
matched, continues to the matched left vertex `pairV[v]` whose distance
is exactly `dist[u]+1`. Therefore any path built by DFS is alternating
and respects the BFS layers, hence its length is `dist_nil`.  
When a free right vertex is reached, the recursion unwinds, flipping
matched/unmatched status along the path – a standard augmenting step. ∎



##### Lemma 4  
After each outer iteration (BFS + all possible DFS augmentations) the
matching size increases by at least one, and no augmenting path of
length ≤ current `dist_nil` remains.

**Proof.** BFS guarantees existence of an augmenting path (Lemma 2).
DFS finds a maximal set of vertex‑disjoint augmenting paths of that
minimal length (Lemma 3). Each such path increases the matching size by
one, so the size grows. After removing all those shortest augmenting
paths, no augmenting path of the same length can remain (otherwise it
would be vertex‑disjoint from the found ones and DFS would have found it). ∎



##### Lemma 5  
When the algorithm terminates, the matching is maximum.

**Proof.** The algorithm stops when BFS finds no augmenting path,
i.e. `dist_nil = INF`. By the classic theorem of Hopcroft‑Karp,
absence of augmenting paths implies maximality, thus the current
matching is maximum. ∎



##### Lemma 6  
If the algorithm outputs `YES`, the printed edges form a perfect
matching.

**Proof.** `YES` is printed only when the matching size equals `q`,
the number of left vertices. Because the graph is bipartite with equal
part sizes, a matching of size `q` necessarily matches every left and
every right vertex exactly once – a perfect matching. The output uses the
stored `pairU` array, therefore each printed pair is indeed an edge of
the matching. ∎



##### Lemma 7  
If a perfect matching exists, the algorithm outputs `YES`.

**Proof.** A perfect matching has size `q`. By Lemma 5 the algorithm finds a
maximum matching; its size cannot be smaller than any existing matching,
hence it also has size `q`. Consequently the algorithm prints `YES`. ∎



##### Theorem  
The program prints `YES` followed by a valid set of `q` links
iff such a set exists; otherwise it prints `NO`.

**Proof.**  
*If* the program prints `YES`, by Lemma 6 the printed links constitute a
perfect matching, satisfying the problem requirements.  
*Only‑if*: if a perfect matching exists, Lemma 7 guarantees the
algorithm finds a matching of size `q` and therefore prints `YES`.  
If no perfect matching exists, the maximum matching size is `< q`,
so the program prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(t)`  
*Hopcroft‑Karp*: `O(E·√V) = O(t·√q)`  
With `t ≤ 4·10⁵` and `q ≤ 10⁵` this is well below the 2 s limit.  

Memory: adjacency list `O(t)`, plus a few arrays of size `q` – all within
256 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    # left vertices: 0 .. q-1   (original ids 1..q)
    # right vertices: 0 .. q-1  (original ids q+1..2q)
    G = [[] for _ in range(q)]
    for _ in range(t):
        a = int(next(it)) - 1          # 0‑based left
        b = int(next(it)) - (q + 1)    # 0‑based right
        if 0 <= a < q and 0 <= b < q:
            G[a].append(b)

    INF = 10 ** 9
    pairU = [-1] * q
    pairV = [-1] * q
    dist = [0] * q

    def bfs() -> bool:
        dq = deque()
        for u in range(q):
            if pairU[u] == -1:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        found = False
        while dq:
            u = dq.popleft()
            for v in G[u]:
                pu = pairV[v]
                if pu == -1:
                    found = True          # we can reach a free right vertex
                elif dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
        return found

    sys.setrecursionlimit(1 << 25)

    def dfs(u: int) -> bool:
        for v in G[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(q):
            if pairU[u] == -1 and dfs(u):
                matching += 1

    out = []
    if matching == q:
        out.append(b"YES")
        for u in range(q):
            v = pairU[u]
            out.append(f"{u+1} {v+q+1}".encode())
    else:
        out.append(b"NO")
    sys.stdout.buffer.write(b"\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
