We need to select exactly q links, each transmitter used once, each receiver used once, and satisfy the sum constraints.  
The sum constraint says: for each selected link (a, b), we need q+1 < a+b < 3q+1.  
Also, the grand sum of all 2q node identifiers must be q(2q+1).  

Let’s analyze:  
The sum of all transmitter identifiers 1..q is q(q+1)/2.  
The sum of all receiver identifiers q+1..2q is q(3q+1)/2.  
Total sum = q(q+1)/2 + q(3q+1)/2 = q(4q+2)/2 = q(2q+1).  
So the grand sum condition is automatically satisfied if we use each node exactly once.  

Thus, the problem reduces to:  
Find a perfect matching in a bipartite graph (transmitters to receivers) such that for each edge (a,b), q+1 < a+b < 3q+1.  

We can try to construct such a matching greedily.  
Notice: For a given transmitter a, the valid receivers b must satisfy:  
q+1 - a < b < 3q+1 - a  
Since b is in [q+1, 2q], we intersect:  
max(q+1, q+1-a) < b < min(2q+1, 3q+1-a)  
But b is integer, so:  
lower = max(q+1, q+2-a)  
upper = min(2q, 3q - a)  
We need lower <= upper.  

Let’s check:  
lower = max(q+1, q+2-a) = q+2-a if a>=2, else q+1 if a=1.  
upper = min(2q, 3q - a).  

For a=1: lower = q+1, upper = min(2q, 3q-1) = 2q (since 3q-1 >= 2q for q>=1). So valid b in [q+1, 2q] all work.  
For a>=2: lower = q+2-a, upper = min(2q, 3q-a).  
We need q+2-a <= 2q => 2-a <= q => always true for a>=1.  
And q+2-a <= 3q-a => 2 <= 2q => true for q>=1.  
So the only restriction is upper >= lower, which is always true.  

Thus, for every a, the valid b range is non-empty.  
So a perfect matching always exists? Not necessarily, because the graph may not have all edges. But if the given edges allow, we can find one.  

We can model as bipartite matching. Since q up to 100000, we need an efficient algorithm.  
We can use Hopcroft-Karp for maximum bipartite matching. If max matching size == q, then YES.  

But we also need to output the matching.  

Let’s implement Hopcroft-Karp.  

Edge case: t can be 0, then no edges, so NO unless q=0 (but q>=1).  

Let's code.  

We'll read q, t, build adjacency list for transmitters (1..q) to receivers (q+1..2q).  
Run Hopcroft-Karp.  

If matching size == q, output YES and the pairs.  
Else NO.  

Let's write the code.```python
import sys
from collections import deque

def hopcroft_karp(n, m, adj):
    # n: number of left nodes (transmitters) 1..n
    # m: number of right nodes (receivers) 1..m, but we'll use 0..m-1 internally
    # adj[u] = list of v (0-indexed right nodes)
    INF = 10**9
    pairU = [-1] * (n + 1)
    pairV = [-1] * (m + 1)
    dist = [0] * (n + 1)

    def bfs():
        dq = deque()
        for u in range(1, n + 1):
            if pairU[u] == -1:
                dist[u] = 0
                dq.append(u)
            else:
                dist[u] = INF
        found = False
        while dq:
            u = dq.popleft()
            for v in adj[u]:
                pu = pairV[v]
                if pu != -1 and dist[pu] == INF:
                    dist[pu] = dist[u] + 1
                    dq.append(pu)
                elif pu == -1:
                    found = True
        return found

    def dfs(u):
        for v in adj[u]:
            pu = pairV[v]
            if pu == -1 or (dist[pu] == dist[u] + 1 and dfs(pu)):
                pairU[u] = v
                pairV[v] = u
                return True
        dist[u] = INF
        return False

    matching = 0
    while bfs():
        for u in range(1, n + 1):
            if pairU[u] == -1 and dfs(u):
                matching += 1
    return matching, pairU

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))

    adj = [[] for _ in range(q + 1)]
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        # b is in [q+1, 2q], convert to 0-indexed right node: b - (q+1)
        adj[a].append(b - (q + 1))

    # Run Hopcroft-Karp
    matching_size, pairU = hopcroft_karp(q, q, adj)

    if matching_size != q:
        print("NO")
        return

    print("YES")
    # pairU[u] gives the matched receiver index (0-based) for transmitter u
    for u in range(1, q + 1):
        b = pairU[u] + q + 1
        print(u, b)

if __name__ == "__main__":
    main()
