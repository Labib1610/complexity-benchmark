We can model this as an exact cover problem: we have \(3q\) items (artifacts) and \(t\) possible triples (approved groups). We need to pick \(q\) triples that cover all items exactly once.

Since \(q \le 200\), \(3q \le 600\), and \(t \le 20000\), we can use a backtracking algorithm with pruning, or a more efficient approach like Algorithm X (Dancing Links). However, a simpler backtracking with bitmasks and good ordering can work within the time limit.

We'll:
- Represent each triple as a bitmask of 3 artifacts.
- Use recursion: pick the artifact with the fewest available triples, try each triple containing it, and recurse.
- Use bitmask for covered artifacts.

Here's the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    q, t = map(int, input().split())
    n = 3 * q
    triples = []
    for _ in range(t):
        a, b, c = map(int, input().split())
        triples.append((a-1, b-1, c-1))
    
    # For each artifact, list of triples containing it
    by_artifact = [[] for _ in range(n)]
    for idx, (a, b, c) in enumerate(triples):
        by_artifact[a].append(idx)
        by_artifact[b].append(idx)
        by_artifact[c].append(idx)
    
    # Precompute bitmask for each triple
    masks = []
    for a, b, c in triples:
        masks.append((1 << a) | (1 << b) | (1 << c))
    
    full_mask = (1 << n) - 1
    chosen = []
    
    # Recursive backtracking
    def dfs(covered):
        if covered == full_mask:
            return True
        # Find uncovered artifact with fewest options
        best_artifact = -1
        best_options = None
        for i in range(n):
            if not (covered >> i) & 1:
                options = [idx for idx in by_artifact[i] if not (covered & masks[idx])]
                if best_artifact == -1 or len(options) < len(best_options):
                    best_artifact = i
                    best_options = options
                    if len(options) == 0:
                        return False
                    if len(options) == 1:
                        break
        # Try each option
        for idx in best_options:
            chosen.append(idx)
            if dfs(covered | masks[idx]):
                return True
            chosen.pop()
        return False
    
    if dfs(0):
        print("YES")
        for idx in chosen:
            a, b, c = triples[idx]
            print(a+1, b+1, c+1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
