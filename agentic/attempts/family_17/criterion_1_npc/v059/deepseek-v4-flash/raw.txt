We need to determine if we can select exactly \( q \) triples from the given formulas such that all materials used are distinct and cover \( 3q \) materials.

This is essentially a **3-dimensional matching** problem, which is NP-hard in general. However, the constraints are small enough for a backtracking or maximum matching approach.

We can model it as a **3-uniform hypergraph matching** problem. Since \( q \le 200 \), we can use a recursive backtracking with pruning, or reduce it to a flow/matching problem.

A common approach:  
- Treat each formula as a hyperedge.  
- We need to pick \( q \) disjoint hyperedges covering all \( 3q \) vertices.

We can use **recursive backtracking with bitmask** if \( 3q \) is small, but here \( 3q \) can be up to 600, so bitmask is not feasible.

Instead, we can use **maximum matching in a 3-partite graph** if we can partition the vertices into 3 sets. But the formulas are arbitrary, not necessarily 3-partite.

Given the constraints, a **backtracking with pruning** is acceptable if we order formulas and vertices smartly. We can also use **Dancing Links** (Algorithm X) for exact cover.

We'll implement **Algorithm X** (exact cover) with a sparse matrix representation.

Here's the plan:
- Universe: all \( 3q \) materials.
- Sets: each formula is a set of 3 materials.
- We need to cover all \( 3q \) materials with exactly \( q \) sets.

We'll implement Algorithm X with dancing links or a simple recursive exact cover with pruning.

Since \( t \) can be up to 20000, we need to be efficient. We'll use a recursive exact cover with column selection heuristic (choose column with fewest candidates).

Let's code it.

```python
import sys
sys.setrecursionlimit(1000000)

def solve():
    input = sys.stdin.readline
    q, t = map(int, input().split())
    formulas = []
    for _ in range(t):
        a, b, c = map(int, input().split())
        formulas.append((a-1, b-1, c-1))  # 0-indexed

    n = 3 * q
    # Build mapping from material to list of formula indices
    material_to_formulas = [[] for _ in range(n)]
    for idx, (a, b, c) in enumerate(formulas):
        material_to_formulas[a].append(idx)
        material_to_formulas[b].append(idx)
        material_to_formulas[c].append(idx)

    # Algorithm X exact cover
    # We'll use a simple recursive approach with column selection
    # State: remaining materials set, remaining formulas list
    # But we need to be efficient.

    # We'll use a boolean array for used materials and used formulas
    used_material = [False] * n
    used_formula = [False] * t
    selected = []

    # Precompute formula materials as list
    formula_mats = formulas

    # For pruning: count how many materials each formula covers that are still unused
    # We'll implement recursive search with heuristic: choose material with fewest available formulas

    def backtrack(remaining_count):
        if remaining_count == 0:
            return True
        # Find material with fewest available formulas
        best_mat = -1
        best_count = 10**9
        for mat in range(n):
            if not used_material[mat]:
                cnt = 0
                for fidx in material_to_formulas[mat]:
                    if not used_formula[fidx]:
                        cnt += 1
                if cnt < best_count:
                    best_count = cnt
                    best_mat = mat
                    if cnt == 0:
                        break
        if best_count == 0:
            return False
        # Try each formula for this material
        for fidx in material_to_formulas[best_mat]:
            if used_formula[fidx]:
                continue
            a, b, c = formula_mats[fidx]
            if used_material[a] or used_material[b] or used_material[c]:
                continue
            # Choose this formula
            used_formula[fidx] = True
            used_material[a] = used_material[b] = used_material[c] = True
            selected.append(fidx)
            if backtrack(remaining_count - 1):
                return True
            # Backtrack
            selected.pop()
            used_material[a] = used_material[b] = used_material[c] = False
            used_formula[fidx] = False
        return False

    if backtrack(q):
        print("YES")
        for fidx in selected:
            a, b, c = formula_mats[fidx]
            print(a+1, b+1, c+1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
