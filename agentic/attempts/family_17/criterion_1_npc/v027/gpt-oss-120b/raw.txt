**Solution Explanation**

The problem asks for an *exact cover* of the set `{1,…,3q}` by `q` triples taken from a given list.
Exactly one triple must contain each element, no element may be used twice and no element may be left uncovered.

This is the classic *exact cover* problem and can be solved efficiently for the given limits
(`3q ≤ 600`, `t ≤ 20000`) with Donald Knuth’s **Algorithm X** together with the
**Dancing Links** data structure (DLX).

The algorithm works as follows  

* each element `1 … 3q` is a *column*,
* each given triple is a *row* that contains three columns,
* we repeatedly choose a column, try each row that covers it,
  recursively continue on the reduced matrix,
* backtrack when a dead end is reached.

The heuristic “choose the column with the smallest number of rows” makes the
search very fast for the given sizes.

When the recursion depth reaches `q` rows, all columns are covered – we have found a solution.

If the recursion finishes without success, the answer is `NO`.

The implementation below is a compact, pointer‑free version of DLX using
integer arrays (`U,D,L,R, C, row_id, col_size`).  
It stops at the first found solution and prints it.

---

**Correctness Proof**

We prove that the algorithm outputs `YES` with a valid set of `q` chords
iff such a set exists.

*Lemma 1*  
During the execution, the data structure always represents the current
sub‑matrix consisting of the columns not yet covered and the rows that are still
compatible with the already chosen rows.

*Proof.*  
Initially the structure contains all columns and all rows.
When a row `r` is chosen, the algorithm removes every column `c` that `r` covers
(and all rows that contain `c`). This is exactly the definition of “covering”
a column in exact‑cover terminology.
When backtracking, the same operations are undone, restoring the previous
matrix. ∎



*Lemma 2*  
If the recursive routine reaches depth `k` (i.e. has already selected `k` rows)
then the selected rows are pairwise disjoint and cover exactly the `k·3`
columns that have been removed from the matrix.

*Proof.*  
By Lemma&nbsp;1 each selected row removes all its three columns.
Because a column is removed only once, no later selected row can contain it.
Thus the rows are disjoint and together cover precisely the removed columns. ∎



*Lemma 3* (Soundness)  
If the algorithm prints `YES` and outputs the collected rows,
they form a valid solution of the original problem.

*Proof.*  
Printing occurs only when the recursion reaches depth `q`.
By Lemma&nbsp;2 the `q` selected rows are disjoint and cover `3q` columns,
i.e. every frequency `1…3q` appears in exactly one selected triple.
Therefore the printed triples satisfy all constraints. ∎



*Lemma 4* (Completeness)  
If a valid set of `q` triples exists, the algorithm will eventually find one
and output `YES`.

*Proof.*  
Consider any exact cover `S`.  
Algorithm X explores the search tree where each node corresponds to a partial
selection of rows.  
At each step it chooses a column `c`. Since `S` covers all columns, `c` is
covered by some row `r∈S`. The algorithm iterates over **all** rows that cover `c`,
therefore it will eventually try `r`. After choosing `r` the remaining
sub‑problem is exactly the cover of the still uncovered columns by the rows of
`S\{r}`. By induction on the number of uncovered columns, the recursive call
will eventually follow the remaining rows of `S` and reach depth `q`. Hence the
algorithm finds a solution. ∎



*Theorem*  
The program prints `YES` followed by a correct collection of `q` chords
iff such a collection exists; otherwise it prints `NO`.

*Proof.*  
*If* part follows from Lemma&nbsp;3.  
*Only‑if* part follows from Lemma&nbsp;4: when a solution exists the algorithm
finds it and prints `YES`; when none exists the search exhausts all possibilities
and returns `NO`. ∎



---

**Complexity Analysis**

Let `n = 3q ≤ 600` (columns) and `m = t ≤ 20000` (rows).

*Construction* takes `O(m·3)` time and `O(n + m·3)` memory.

During the search each covering/uncovering operation touches exactly the nodes
of the involved rows, i.e. `O(3)` per row.  
The total work is proportional to the number of visited nodes in the search
tree. For the given limits the heuristic column choice keeps this number
well below the time limit; in the worst theoretical case it is exponential,
which is unavoidable for NP‑complete problems.

Memory consumption: one node per 1‑entry → `3m ≤ 60000` nodes,
plus `n` column headers → well under the 256 MiB limit.

**Reference Implementation (Python 3)**

```python
import sys
sys.setrecursionlimit(1000000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    n = 3 * q                     # number of columns
    rows = []                     # list of triples (as ints)
    for _ in range(t):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        rows.append((a, b, c))

    # ---------- DLX construction ----------
    max_nodes = 3 * t + n + 1      # +1 for header
    U = [0] * max_nodes
    D = [0] * max_nodes
    L = [0] * max_nodes
    R = [0] * max_nodes
    C = [0] * max_nodes           # column of node
    row_id = [0] * max_nodes      # which original row this node belongs to
    col_size = [0] * (n + 1)      # size of each column, 1..n

    header = 0
    # link header with column headers 1..n
    for i in range(n + 1):
        L[i] = i - 1
        R[i] = i + 1
        U[i] = D[i] = i
    L[0] = n
    R[n] = 0

    node_cnt = n + 1  # next free index

    for rid, (a, b, c) in enumerate(rows, 1):
        first = None
        for col in (a, b, c):
            col += 1                     # shift to 1..n
            node = node_cnt
            node_cnt += 1
            C[node] = col
            row_id[node] = rid

            # insert into column (at bottom, before header)
            U[node] = U[col]
            D[node] = col
            D[U[col]] = node
            U[col] = node
            col_size[col] += 1

            # link row horizontally
            if first is None:
                first = node
                L[node] = R[node] = node
            else:
                L[node] = L[first]
                R[node] = first
                R[L[first]] = node
                L[first] = node

    solution = []

    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                col_size[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                col_size[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    def search(k):
        if R[header] == header:          # all columns covered
            return True
        # choose column with minimal size
        c = R[header]
        min_sz = col_size[c]
        col = c
        j = R[c]
        while j != header:
            if col_size[j] < min_sz:
                min_sz = col_size[j]
                col = j
                if min_sz == 0:
                    break
            j = R[j]
        if min_sz == 0:
            return False
        cover(col)
        r = D[col]
        while r != col:
            solution.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution.pop()
            r = D[r]
        uncover(col)
        return False

    ok = search(0)
    out = sys.stdout
    if not ok:
        out.write("NO")
        return
    out.write("YES\n")
    # output triples in any order
    for rid in solution:
        a, b, c = rows[rid - 1]
        out.write(f"{a+1} {b+1} {c+1}\n")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
