We need to solve the exact cover problem: choose exactly q triples from the given list so that every number from 1 to 3q appears exactly once.

We can model this as exact cover and solve with backtracking (Algorithm X / DLX) or with recursion + bitmasking since q ≤ 200, but 3q ≤ 600, so bitmask over all numbers is too large. However, we can use recursion with pruning: pick the smallest uncovered number, try triples containing it, and recurse.

We’ll implement a backtracking solution with:

- Store triples in a list.
- For each number, store indices of triples containing it.
- Use a `used` boolean array for triples.
- Use a `covered` boolean array for numbers.
- Recursively pick the uncovered number with the fewest candidate triples (MRV heuristic).

Since t ≤ 20000, we must be efficient. We'll precompute candidate lists and use recursion with early exit.

Let's write the code.

```python
import sys

def solve():
    input = sys.stdin.readline
    q, t = map(int, input().split())
    triples = []
    for _ in range(t):
        a, b, c = map(int, input().split())
        triples.append((a, b, c))
    
    n = 3 * q
    # For each number, list of triple indices containing it
    num_to_triples = [[] for _ in range(n + 1)]
    for idx, (a, b, c) in enumerate(triples):
        num_to_triples[a].append(idx)
        num_to_triples[b].append(idx)
        num_to_triples[c].append(idx)
    
    used = [False] * t
    covered = [False] * (n + 1)
    chosen = []
    
    def backtrack():
        if len(chosen) == q:
            return True
        # Find uncovered number with fewest candidate triples
        best_num = -1
        best_candidates = None
        for num in range(1, n + 1):
            if not covered[num]:
                cand = [idx for idx in num_to_triples[num] if not used[idx]]
                if not cand:
                    return False
                if best_candidates is None or len(cand) < len(best_candidates):
                    best_candidates = cand
                    best_num = num
                    if len(cand) == 1:
                        break
        if best_num == -1:
            return False
        
        for idx in best_candidates:
            a, b, c = triples[idx]
            # Check if all numbers are uncovered
            if covered[a] or covered[b] or covered[c]:
                continue
            # Use this triple
            used[idx] = True
            covered[a] = covered[b] = covered[c] = True
            chosen.append((a, b, c))
            
            if backtrack():
                return True
            
            # Backtrack
            chosen.pop()
            covered[a] = covered[b] = covered[c] = False
            used[idx] = False
        
        return False
    
    if backtrack():
        print("YES")
        for a, b, c in chosen:
            print(a, b, c)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
