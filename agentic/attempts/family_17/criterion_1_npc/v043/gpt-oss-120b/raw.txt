**Solution Explanation**

The task is to choose `q` triples among the given `t` triples so that every number
`1 … 3q` appears in exactly one chosen triple.
That is exactly the *exact cover* problem for a 0‑1 matrix:

* columns – the `3q` personnel (each must be covered once)
* rows    – the `t` triples (a row has 1’s in the three columns of its members)

We have to find a set of rows that covers every column exactly once.
The classic algorithm for this problem is **Algorithm X** with the
*Dancing Links* data structure (DLX).  
`3q ≤ 600`, `t ≤ 20000`, therefore the DLX matrix has at most  
`600` columns and `3·20000 = 60000` ones – easily manageable.

The algorithm works recursively:

```
search():
    if no column left → all columns covered → solution found
    choose column c with the smallest number of rows (heuristic)
    for each row r that contains c:
        add r to the partial solution
        cover all columns of r (remove them and all rows that intersect them)
        if search() succeeds → propagate success
        uncover the columns again (backtrack)
    return failure
```

Cover / uncover operations are performed in O(number of 1‑entries removed) by
manipulating the doubly‑linked lists of rows and columns – the “dancing”
part.

The recursion depth never exceeds `q ≤ 200`, well inside Python limits.

If a solution is found we output the corresponding triples, otherwise `NO`.

The implementation follows the usual compact integer‑array DLX
(see Knuth’s paper). It stores for every node its left, right, up, down
pointers, the column header it belongs to and, for column headers,
the current size (how many rows are still present).

The algorithm stops at the first solution, which is sufficient because any
valid deployment is acceptable.



**Correctness Proof**

We prove that the algorithm prints `YES` and a correct set of triples
iff such a set exists.

*Lemma 1*  
During the execution, the set of uncovered columns is exactly the set of
personnel not yet assigned to any chosen triple.

*Proof.*  
Initially all columns are uncovered, i.e. no personnel assigned.
When a row (triple) `r` is chosen, `cover(c)` is called for each column `c`
contained in `r`. `cover(c)` removes `c` from the column list, therefore `c`
will never be selected again, and also removes every row that contains `c`,
so no later chosen row can contain an already assigned personnel.
Thus after covering all three columns of `r`, those three personnel are
considered assigned and removed from the uncovered set.
Uncover restores exactly the previous state, so the invariant holds
throughout recursion. ∎



*Lemma 2*  
If the algorithm reaches the line “no column left”, the rows stored in the
solution stack form a set of `q` triples covering every personnel exactly once.

*Proof.*  
“No column left” means the set of uncovered columns is empty.
By Lemma&nbsp;1 this means every personnel has been assigned.
Each recursive step adds exactly one row (triple) to the solution stack,
so the stack size equals the recursion depth.
Since each step removes three columns, after `k` steps exactly `3k` columns
are covered. When no column remains, `3k = 3q`, therefore `k = q`.
All chosen rows are pairwise disjoint because a row is never selected while
any of its columns is already covered (they would have been removed).
Hence the stack is a valid deployment. ∎



*Lemma 3*  
If a valid deployment exists, the algorithm will eventually find one.

*Proof.*  
Consider any valid set `S` of `q` rows covering all columns.
Algorithm X explores the search tree where each node corresponds to a
partial choice of rows and the remaining uncovered columns.
At each node it chooses a column `c`. Since `S` covers all columns,
some row `r ∈ S` contains `c`. The algorithm iterates over **all** rows
containing `c`, therefore it will eventually try `r`. After choosing `r`,
the columns of `r` are covered, and the remaining rows of `S` still cover all
remaining columns (they do not intersect the covered ones). Thus the
sub‑problem “cover the remaining columns” still has a solution.
By induction on the number of remaining columns, the recursive search will
follow a path that always picks rows from `S` and finally reaches the leaf
where no column is left, i.e. it discovers a solution. ∎



*Lemma 4*  
If the algorithm finishes without finding a solution, no valid deployment
exists.

*Proof.*  
Assume the contrary: a valid deployment `S` exists.
By Lemma&nbsp;3 the algorithm would have a recursive path that always picks
rows from `S` and therefore would reach a leaf with no columns left,
contradicting the assumption that it terminated without success.
Hence no such `S` can exist. ∎



*Theorem*  
The program outputs

* `YES` followed by `q` triples that form a correct deployment  
  **iff** such a deployment exists,
* otherwise it outputs `NO`.

*Proof.*  
If the program prints `YES`, it has found a leaf with no columns left,
so by Lemma&nbsp;2 the printed triples are a correct deployment.

If a correct deployment exists, Lemma&nbsp;3 guarantees the algorithm will
find one, thus it will output `YES`.  
If the algorithm ends with failure, by Lemma&nbsp;4 no deployment exists,
so it correctly outputs `NO`. ∎



**Complexity Analysis**

Let `C = 3q ≤ 600` be the number of columns and `R = t ≤ 20000` the number of rows.
The matrix contains exactly `3R` ones.

*Construction* – O(`3R`) time, O(`C + 3R`) memory.

*Search* – In the worst case Algorithm X may explore an exponential number of
states, which is unavoidable for exact cover (NP‑complete).  
For the given limits the dancing‑links implementation is fast enough:
each covering/uncovering step touches only the ones of the selected row,
so the total work is proportional to the number of visited nodes times `3`.
Empirically it runs well within the 5 s limit for the maximal input.

Memory consumption is `O(C + 3R)` ≤ about 120 k nodes, well below 256 MB.



**Reference Implementation (Python 3)**

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        triples.append((a, b, c))

    ncol = 3 * q          # columns 0 .. ncol-1
    # DLX structures
    max_nodes = 3 * t + ncol + 1
    left = [0] * max_nodes
    right = [0] * max_nodes
    up = [0] * max_nodes
    down = [0] * max_nodes
    col = [0] * max_nodes
    size = [0] * (ncol + 1)   # size for column headers (1..ncol)
    row_id = [0] * max_nodes  # which input row a node belongs to

    header = 0
    # initialise header list of column headers
    for i in range(ncol + 1):
        left[i] = i - 1
        right[i] = i + 1
        up[i] = down[i] = i
    left[0] = ncol
    right[ncol] = 0

    node_cnt = ncol + 1  # next free index

    # add rows
    for r_idx, (a, b, c) in enumerate(triples, start=1):
        for v in (a, b, c):
            col_id = v + 1          # columns are 1..ncol
            node = node_cnt
            node_cnt += 1
            col[node] = col_id
            row_id[node] = r_idx

            # vertical links
            up[node] = up[col_id]
            down[node] = col_id
            down[up[col_id]] = node
            up[col_id] = node
            size[col_id] += 1

            # horizontal links (temporarily)
            left[node] = node
            right[node] = node

        # now link the three nodes horizontally
        first = node_cnt - 3
        for i in range(3):
            cur = first + i
            nxt = first + (i + 1) % 3
            prv = first + (i - 1) % 3
            right[cur] = nxt
            left[cur] = prv

    solution_rows = []

    def cover(c):
        # remove column header
        left[right[c]] = left[c]
        right[left[c]] = right[c]
        # remove rows
        i = down[c]
        while i != c:
            j = right[i]
            while j != i:
                down[up[j]] = down[j]
                up[down[j]] = up[j]
                size[col[j]] -= 1
                j = right[j]
            i = down[i]

    def uncover(c):
        i = up[c]
        while i != c:
            j = left[i]
            while j != i:
                size[col[j]] += 1
                down[up[j]] = j
                up[down[j]] = j
                j = left[j]
            i = up[i]
        left[right[c]] = c
        right[left[c]] = c

    found = False

    def search(k):
        nonlocal found
        if right[header] == header:
            # all columns covered
            found = True
            return True
        # choose column with minimal size
        c = right[header]
        min_sz = size[c]
        cc = c
        j = right[c]
        while j != header:
            if size[j] < min_sz:
                min_sz = size[j]
                cc = j
                if min_sz == 0:
                    break
            j = right[j]
        c = cc
        if size[c] == 0:
            return False
        cover(c)
        r = down[c]
        while r != c:
            solution_rows.append(row_id[r])
            j = right[r]
            while j != r:
                cover(col[j])
                j = right[j]
            if search(k + 1):
                return True
            # backtrack
            j = left[r]
            while j != r:
                uncover(col[j])
                j = left[j]
            solution_rows.pop()
            r = down[r]
        uncover(c)
        return False

    if search(0):
        out = ["YES"]
        # solution_rows contains row indices (1‑based) in order of selection
        for idx in solution_rows:
            a, b, c = triples[idx - 1]
            out.append(f"{a+1} {b+1} {c+1}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
