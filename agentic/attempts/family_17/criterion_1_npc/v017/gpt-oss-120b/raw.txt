**Solution Explanation**

The problem is an *exact cover* problem:

* there are `3·q` elements (operators `1 … 3q`);
* each pre‑cleared cell is a 3‑element subset of these elements;
* we have to choose exactly `q` cells so that every element appears in **exactly one** chosen cell.

This is the classic *exact cover* problem and can be solved efficiently with
Donald Knuth’s **Dancing Links (DLX)** algorithm.  
`q ≤ 200`, `t ≤ 20000`, therefore the DLX search space is small enough for the
5 s limit.

--------------------------------------------------------------------

#### 1.   DLX data structure

*Columns* – one for each operator (`1 … 3q`).  
*Rows* – one for each given cell, containing three `1`s in the columns of its
operators.

The structure consists of doubly linked lists:

```
header <-> column0 <-> column1 <-> … <-> column(3q-1)
```

Each column node stores the number of rows currently covering it (`size`).
Every `1` in the matrix is a node linked left/right inside its row and up/down
inside its column.

Removing a column (`cover`) deletes the column header and all rows that contain
a `1` in this column, together with all other `1`s of those rows.
Restoring (`uncover`) reverses the operation – this is the “dancing links”.

--------------------------------------------------------------------

#### 2.   Search

Recursive depth‑first search:

```
search(k):
    if header.right == header:   # all columns covered
         solution found (k rows selected)
    choose column c with minimal size
    cover(c)
    for each row r in column c:
         add r to solution
         for each node j in row r (rightwards):
                cover(j.column)
         if search(k+1): return True
         # backtrack
         for each node j in row r (leftwards):
                uncover(j.column)
    uncover(c)
    return False
```

Because each row has exactly three `1`s, the recursion depth never exceeds `q`
(≤ 200). The heuristic “column with smallest size” dramatically prunes the
search tree.

--------------------------------------------------------------------

#### 3.   Building the structure

* Create column nodes `C[1 … 3q]`.
* For each input cell `(a,b,c)` create three data nodes, link them horizontally,
  and insert each into the bottom of its column’s vertical list, updating the
  column size.

The row index (its position in the input list) is stored in the first node of
the row – this allows us to output the original triple when the row is chosen.

--------------------------------------------------------------------

#### 4.   Output

If the search succeeds, we have a list of `q` row indices.
Print `YES` and the corresponding triples (in any order).
Otherwise print `NO`.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` with a valid schedule iff such a
schedule exists.

---

##### Lemma 1  
During the search, the set of uncovered columns is exactly the set of
operators not yet assigned to any selected row.

**Proof.**  
Initially all columns are uncovered, i.e. no operator is assigned.  
`cover(c)` removes column `c` and all rows containing `c`. Removing a row also
removes all its other columns, meaning those operators become assigned to that
row. No other operation changes column membership. Hence after any sequence
of covers, the remaining columns are precisely the unassigned operators. ∎



##### Lemma 2  
When the algorithm selects a row `r` (adds it to the partial solution) all three
operators of `r` become covered and cannot be covered again later.

**Proof.**  
Selecting `r` triggers `cover` on each of its three columns (including the
initial column `c`). By Lemma&nbsp;1 those columns are removed from the header,
so they will never be chosen again. ∎



##### Lemma 3  
If the algorithm reaches the state `header.right == header` (no columns left),
the selected rows form a set of `q` disjoint triples covering every operator
exactly once.

**Proof.**  
No columns left ⇒ every operator is covered (Lemma&nbsp;1).  
Each selected row covers three distinct operators, and by Lemma&nbsp;2 no
operator appears in two selected rows. The total number of covered operators is
`3·|solution|`. Since there are `3q` operators, `|solution| = q`. ∎



##### Lemma 4  
If a perfect schedule exists, the search will eventually find it.

**Proof.**  
Consider any perfect schedule `S`. At each recursion level the algorithm
chooses a column `c`. Since `S` covers all columns, `c` belongs to exactly one
row `r∈S`. That row is present in the column’s list, therefore the algorithm
has a branch that selects `r`. Following that branch recursively repeats the
argument for the reduced instance (all columns of `r` removed). By induction
the branch that always picks the rows of `S` reaches the empty‑column state,
so the algorithm will find a solution. ∎



##### Lemma 5  
If the algorithm reports `NO`, no perfect schedule exists.

**Proof.**  
`NO` is printed only when the recursive search exhausts all possibilities
without reaching the empty‑column state. The search explores **all** subsets of
rows that respect the exact‑cover constraints (any row not compatible with the
already chosen rows is never considered). Hence no subset of rows covers all
columns exactly once, i.e. no perfect schedule exists. ∎



##### Theorem  
The program outputs `YES` followed by a collection of `q` triples that
constitutes a valid deployment plan **iff** such a plan exists; otherwise it
outputs `NO`.

**Proof.**  
*If* the program outputs `YES`, the triples are exactly the rows stored in the
solution list. By Lemma&nbsp;3 they cover every operator once, so the plan is
valid.

*Only‑if*:  
- If a valid plan exists, Lemma&nbsp;4 guarantees the search finds a solution,
  thus the program prints `YES`.
- If no valid plan exists, Lemma&nbsp;5 shows the search cannot succeed,
  therefore the program prints `NO`.

Thus the output is correct in both directions. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

`n = 3q ≤ 600`, `m = t ≤ 20000`.

*Building the structure*: `O(m·3)` = `O(m)`.

*Search*: Each recursive level removes at most 3 columns and at most the rows
containing them. In the worst case DLX explores an exponential number of nodes,
but with the minimal‑size heuristic and the small problem size (`q ≤ 200`,
each row size = 3) it runs comfortably within the limits.  
Memory consumption: one node per `1` → `3·m ≤ 60000` nodes, each with a few
integers → well below 256 MB.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        triples.append((a, b, c))

    ncol = 3 * q                     # columns 1..ncol
    # DLX structures
    max_nodes = 3 * t + ncol + 5
    U = [0] * max_nodes
    D = [0] * max_nodes
    L = [0] * max_nodes
    R = [0] * max_nodes
    C = [0] * max_nodes               # column header for each node
    S = [0] * (ncol + 1)              # column sizes
    row_id = [0] * max_nodes          # store original row index (1‑based)

    header = 0
    # create column headers 1..ncol
    for i in range(ncol + 1):
        U[i] = D[i] = i
        L[i] = i - 1
        R[i] = i + 1
    L[0] = ncol
    R[ncol] = 0

    node_cnt = ncol
    # add rows
    for idx, (a, b, c) in enumerate(triples, 1):
        cols = [a, b, c]
        first = None
        for col in cols:
            node_cnt += 1
            C[node_cnt] = col
            row_id[node_cnt] = idx
            # vertical links (insert at bottom of column)
            D[node_cnt] = col
            U[node_cnt] = U[col]
            D[U[col]] = node_cnt
            U[col] = node_cnt
            S[col] += 1
            # horizontal links
            if first is None:
                first = node_cnt
                L[node_cnt] = R[node_cnt] = node_cnt
            else:
                # insert to the right of first
                L[node_cnt] = L[first]
                R[node_cnt] = first
                R[L[first]] = node_cnt
                L[first] = node_cnt

    solution = []

    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    found = False

    def search(k):
        nonlocal found
        if R[header] == header:
            # all columns covered
            found = True
            return True
        # choose column with minimal size
        c = R[header]
        min_s = S[c]
        j = R[c]
        while j != header:
            if S[j] < min_s:
                c = j
                min_s = S[j]
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(c)
        r = D[c]
        while r != c:
            solution.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution.pop()
            r = D[r]
        uncover(c)
        return False

    if search(0):
        out = ["YES"]
        for idx in solution:
            a, b, c = triples[idx - 1]
            out.append(f"{a} {b} {c}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to
the required input‑output format.
