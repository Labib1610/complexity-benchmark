We can model this as a 3-uniform hypergraph matching problem.  
We have up to \(3q\) vertices and \(t\) hyperedges (triples).  
We need to find a perfect matching of size \(q\).

Since \(q \le 200\), the number of vertices is at most 600.  
We can use a backtracking with pruning or a maximum matching algorithm for 3-uniform hypergraphs.  
A common approach is to use **recursive backtracking with bitmask** for small sizes, but here \(3q\) can be up to 600, so bitmask over all vertices is too large.

Instead, we can use **recursive matching with pruning**:

- Keep track of used vertices.
- At each step, pick the first unused vertex, try all triples containing it, and recurse.
- If we find a full matching, output it.

We need to be careful with time: \(t\) up to 20000, but we only try triples containing the chosen vertex, so it's manageable.

We'll store triples in a list per vertex.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    q, t = map(int, input().split())
    n = 3 * q
    triples = []
    adj = [[] for _ in range(n + 1)]
    for _ in range(t):
        a, b, c = map(int, input().split())
        triples.append((a, b, c))
        adj[a].append(len(triples) - 1)
        adj[b].append(len(triples) - 1)
        adj[c].append(len(triples) - 1)

    used = [False] * (n + 1)
    chosen = []

    def dfs(count):
        if count == q:
            return True
        # find first unused vertex
        start = 1
        while start <= n and used[start]:
            start += 1
        if start > n:
            return False
        # try all triples containing start
        for idx in adj[start]:
            a, b, c = triples[idx]
            if used[a] or used[b] or used[c]:
                continue
            used[a] = used[b] = used[c] = True
            chosen.append((a, b, c))
            if dfs(count + 1):
                return True
            chosen.pop()
            used[a] = used[b] = used[c] = False
        return False

    if dfs(0):
        print("YES")
        for a, b, c in chosen:
            print(a, b, c)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
