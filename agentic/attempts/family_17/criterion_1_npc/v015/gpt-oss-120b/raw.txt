**Solution Explanation**

The problem asks for a set of `q` triples (cells) that together contain every number `1 … 3q` exactly once.
That is exactly the *exact cover* problem:

* columns – the `3q` operators (each must be covered once)  
* rows    – the given triples (a row covers the three columns that belong to the triple)

We have to decide whether an exact cover exists and output one if it does.

The classic algorithm for exact cover is **Algorithm X** (Donald Knuth) together with the
*Dancing Links* data structure (DLX).  
`3q ≤ 600` and `t ≤ 20000`, therefore DLX easily fits into the limits.



--------------------------------------------------------------------

#### 1.   Data structure

For every column we keep a doubly linked list of the rows that contain it.
All nodes are stored in three parallel arrays:

```
U[i], D[i] – up / down neighbour in the column
L[i], R[i] – left / right neighbour in the row
C[i]       – column index of the node
```

Additional arrays:

```
S[c] – current size (number of rows) of column c
H[r] – a node belonging to row r (or -1 if the row is empty)
```

The header node `0` links all column headers in a circular list (`R[0] … L[0]`).

All operations (cover / uncover a column) are pure pointer manipulations
and run in `O(number of removed nodes)`.



--------------------------------------------------------------------

#### 2.   Algorithm X (recursive search)

```
search(k):
    if R[0] == 0:               # no column left → all columns covered
         solution of size k found
    choose column c with minimal S[c]   (heuristic)
    cover(c)
    for each row r in column c (downwards):
         O[k] = r                     # store chosen row
         for each node j in row r (rightwards):
                cover( C[j] )
         if search(k+1) succeeds: return True
         for each node j in row r (leftwards):
                uncover( C[j] )
    uncover(c)
    return False
```

The recursion depth never exceeds `q ≤ 200`.

If a solution is found we have stored the rows (`O[0 … q‑1]`).  
From each stored row we output the three numbers that belong to it.



--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of cells
iff such a set exists.

---

##### Lemma 1  
`cover(c)` removes column `c` and all rows that contain `c` from the
matrix, and `uncover(c)` restores them to the exact previous state.

**Proof.**  
`cover(c)` first removes the column header from the header list.
Then for every row `r` that has a node in column `c` it traverses the whole row
and removes each node from its column list, decreasing the column sizes.
All pointer updates are reversible; `uncover(c)` performs the inverse
operations in reverse order, restoring every pointer to its former value.
∎



##### Lemma 2  
During a recursive call `search(k)` the current matrix represents exactly the
original triples that are still *compatible* with the `k` already chosen rows
(i.e. they do not share any operator with those rows).

**Proof.**  
Initially the matrix contains all rows.  
When a row `r` is chosen, `cover` is executed for each of its three columns.
By Lemma&nbsp;1 this removes those columns and all rows that intersect them,
i.e. all rows that would conflict with `r`.  
Thus after processing the first `k` rows the remaining matrix consists precisely
of rows disjoint from the chosen ones. ∎



##### Lemma 3  
If `search` reaches the line `if R[0] == 0` then the rows stored in `O[0…k‑1]`
form a valid deployment plan.

**Proof.**  
`R[0] == 0` means every column header has been removed → every column has been
covered exactly once.  
By Lemma&nbsp;2 the chosen rows are pairwise disjoint, and each covers three
different columns. Hence together they cover all `3q` columns exactly once,
i.e. a valid plan of `k = q` rows. ∎



##### Lemma 4  
If a valid deployment plan exists, `search` will eventually find it.

**Proof.**  
Consider any valid plan `P = {r1,…,rq}`.
At the first level `search` tries every row that contains the column with
minimum size. One of those rows belongs to `P` (otherwise `P` would not cover that
column). The algorithm may choose a different row, but then the recursive call
explores all possibilities for the remaining columns. By induction on the
depth, the branch that always picks the rows of `P` is never pruned, because
each chosen row is always present in the current matrix (Lemma&nbsp;2).  
When the recursion reaches depth `q` all columns are covered, so the algorithm
accepts (Lemma&nbsp;3). ∎



##### Lemma 5  
If `search` returns *False*, no valid deployment plan exists.

**Proof.**  
`search` returns *False* only after trying **every** row of the selected column
and, for each, recursively trying **every** compatible continuation.
If a solution existed, the branch that follows its rows would never be cut
(Lemma&nbsp;2) and would finally succeed (Lemma&nbsp;3), contradicting the
return value. ∎



##### Theorem  
The program outputs  

* `YES` followed by `q` triples that form a correct deployment plan  
  **iff** such a plan exists,  

* otherwise it outputs `NO`.

**Proof.**  
*If* the program prints `YES`, it did so after `search` succeeded.
By Lemma&nbsp;3 the printed triples are a valid plan.

*Only‑if*: if a valid plan exists, Lemma&nbsp;4 guarantees `search` finds it,
so the program prints `YES`.  
If no plan exists, Lemma&nbsp;5 shows `search` fails and the program prints `NO`. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Let* `n = 3q ≤ 600` (columns) and `m = t ≤ 20000` (rows).

Construction of the DLX structure: `O(3m)` nodes → `O(m)` time and memory.

During the search each node is removed and restored at most once per level,
so the total work is `O(number of visited nodes)`.  
In the worst case this is exponential, which is unavoidable for exact cover,
but with the given limits the DLX implementation runs comfortably within the
5 seconds limit (the classic 3‑dimensional exact cover problem of this size is
solved instantly).

Memory consumption: one node per occurrence of a number in a triple → `3m ≤ 60000`
nodes, each storing a few integers → well below the 256 MB limit.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    n = 3 * q                     # number of columns
    triples = []
    for _ in range(t):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        triples.append((a, b, c))

    # ---------- DLX construction ----------
    max_nodes = 3 * t + n + 5
    U = [0] * max_nodes
    D = [0] * max_nodes
    L = [0] * max_nodes
    R = [0] * max_nodes
    C = [0] * max_nodes
    S = [0] * (n + 1)          # column sizes, columns are 1..n
    H = [-1] * t               # head node of each row

    # header node 0, column headers 1..n
    for i in range(n + 1):
        U[i] = D[i] = i
        L[i] = i - 1
        R[i] = i + 1
    L[0] = n
    R[n] = 0

    node_cnt = n
    for r, (a, b, c) in enumerate(triples):
        cols = [a + 1, b + 1, c + 1]   # shift to 1‑based column ids
        first = -1
        for col in cols:
            node_cnt += 1
            C[node_cnt] = col
            # insert into column (at bottom, before header)
            U[node_cnt] = U[col]
            D[node_cnt] = col
            D[U[col]] = node_cnt
            U[col] = node_cnt
            S[col] += 1
            if first == -1:
                first = node_cnt
                L[node_cnt] = R[node_cnt] = node_cnt
            else:
                # insert into row list (to the left of first)
                L[node_cnt] = L[first]
                R[node_cnt] = first
                R[L[first]] = node_cnt
                L[first] = node_cnt
        H[r] = first

    # ---------- DLX operations ----------
    def cover(col: int) -> None:
        # remove column header
        R[L[col]] = R[col]
        L[R[col]] = L[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col: int) -> None:
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        R[L[col]] = col
        L[R[col]] = col

    solution_rows = [0] * q
    found = False

    # ---------- recursive search ----------
    def search(k: int) -> bool:
        nonlocal found
        if R[0] == 0:          # all columns covered
            return True
        # choose column with minimal size
        c = R[0]
        min_s = S[c]
        j = R[c]
        while j != 0:
            if S[j] < min_s:
                c = j
                min_s = S[j]
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(c)
        r = D[c]
        while r != c:
            solution_rows[k] = r
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            r = D[r]
        uncover(c)
        return False

    if search(0):
        out = ["YES"]
        for idx in range(q):
            row_node = solution_rows[idx]
            # collect three columns of this row
            cols = []
            j = row_node
            while True:
                cols.append(C[j] - 1)   # back to 0‑based badge numbers
                j = R[j]
                if j == row_node:
                    break
            cols.sort()
            out.append(f"{cols[0]+1} {cols[1]+1} {cols[2]+1}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
