**Solution Explanation**

The problem asks for an *exact cover* of the set  

```
U = { 1 , 2 , … , 3·q }
```

by some of the given triples.  
An exact cover is a collection of triples such that every element of `U`
appears in **exactly one** chosen triple.

The classical algorithm for this problem is *Algorithm X* (Donald Knuth)
implemented with *Dancing Links* (DLX).  
The universe size is at most `3·q ≤ 600`, the number of triples at most
`20000`. DLX works easily within the limits.

--------------------------------------------------------------------

#### 1.   Data structure

For every triple we create three nodes, one for each element it contains.
All nodes are linked in four directions:

```
left  right   – horizontal links inside the same row (triple)
up    down    – vertical links inside the same column (element)
column        – pointer to the column‑header node of the element
```

Each column header stores the current number of nodes in the column
(`size`). The header of the whole structure is a dummy node whose
right‑links enumerate all still‑uncovered columns.

All links are stored in plain Python lists (`int` indices) – this is
much faster than objects.

--------------------------------------------------------------------

#### 2.   Operations

*Cover a column* (element `c`)

```
remove column header from the header list
for each row r in column c:
        for each node n in row r (traverse right):
                remove n from its column list
                decrement column size
```

*Uncover* does the inverse in reverse order – it restores the structure
exactly as it was before the cover.

Both operations are `O(number of removed nodes)`.

--------------------------------------------------------------------

#### 3.   Search (Algorithm X)

```
search(k):
        if no columns left → solution found (k rows chosen)
        choose column c with smallest size   (heuristic)
        cover(c)
        for each row r in column c:
                answer[k] = r
                for each node n in row r (right):
                        cover( column of n )
                if search(k+1) succeeds → propagate success
                for each node n in row r (left, reverse order):
                        uncover( column of n )
        uncover(c)
        return failure
```

Because each recursive step removes at least one column, the depth never
exceeds `q ≤ 200`. The heuristic (minimum column size) keeps the branching
factor tiny for typical inputs, and the worst‑case size (`600·20000`)
fits easily into the 5 s limit.

--------------------------------------------------------------------

#### 4.   Building the structure

* columns: one for each element `1 … 3·q`
* rows: one for each input triple (ignore triples that contain an element
  outside the range – they never appear, but the statement guarantees
  validity)

While inserting a row we link its three nodes horizontally and insert each
node at the bottom of the corresponding column list, updating the column
size.

--------------------------------------------------------------------

#### 5.   Output

If the search succeeds we have `q` rows (their original indices).  
We print `YES` and the three numbers of each chosen triple in any order.
Otherwise we print `NO`.

--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct deployment plan
iff such a plan exists.

---

##### Lemma 1  
At any moment of the search, the DLX structure represents exactly the
sub‑instance consisting of the still uncovered elements and all triples
that use only those elements.

**Proof.**  
Initially this is true by construction.  
Covering a column `c` removes `c` from the header list, therefore `c`
is no longer considered uncovered. For every row `r` that contains `c`
the algorithm removes all other nodes of `r` from their columns,
which eliminates every triple that uses `c`. No other nodes are touched.
Thus the remaining structure corresponds precisely to the sub‑instance
with `c` removed. Uncover restores the previous state, so the invariant
holds inductively. ∎



##### Lemma 2  
When the recursive call `search(k)` reaches the line “if no columns left”
the set of rows stored in `answer[0 … k‑1]` is an exact cover of the whole
original universe.

**Proof.**  
“No columns left” means every element has been covered, i.e. removed from
the header list. By Lemma&nbsp;1 each removal of a column was caused by
choosing a row that contains this element, and that row’s other elements
were also covered (their columns were removed). Because a column is never
covered twice, no element appears in two chosen rows. The recursion depth
`k` equals the number of chosen rows, and each chosen row is a triple,
hence the rows form a partition of the universe – an exact cover. ∎



##### Lemma 3  
If the algorithm outputs a set of `q` triples, they form a valid deployment
plan.

**Proof.**  
The algorithm stops only when the “no columns left” condition is met,
therefore by Lemma&nbsp;2 the selected rows cover every element exactly
once. The number of elements is `3·q`, each row has size 3, so exactly `q`
rows are selected. Hence the printed triples satisfy all requirements. ∎



##### Lemma 4  
If a valid deployment plan exists, the algorithm will eventually find one
and return `YES`.

**Proof.**  
Consider any exact cover `C`. During the search, at each level the
algorithm tries **all** rows that contain the currently chosen column
(`c`). Since `C` contains exactly one row covering `c`, that row is among
the tried rows. When the algorithm picks that row, all columns of that row
are covered, and the remaining uncovered columns are exactly those that
must be covered by `C \ {row}`. By induction on the number of remaining
columns, the recursive call will eventually follow the remaining rows of
`C` and reach the “no columns left” state. Therefore the search cannot
fail if a solution exists. ∎



##### Lemma 5  
If the algorithm prints `NO`, no valid deployment plan exists.

**Proof.**  
`NO` is printed only after the complete search tree has been explored
without reaching the “no columns left” state. By Lemma&nbsp;4, any existing
exact cover would correspond to a path in this tree leading to that
state. Since no such path exists, no exact cover exists. ∎



##### Theorem  
The program prints `YES` followed by a correct list of `q` triples
iff such a list exists; otherwise it prints `NO`.

**Proof.**  
*If* part: by Lemma&nbsp;4 the algorithm finds a solution when one exists,
and by Lemma&nbsp;3 the printed triples are a valid plan.  
*Only‑if* part: by Lemma&nbsp;5, printing `NO` implies that no plan exists. ∎



--------------------------------------------------------------------

#### 7.   Complexity Analysis  

*Let* `n = 3·q ≤ 600` (number of columns) and `m = t ≤ 20000` (rows).

* Building the structure: `O(3·m)` time, `O(n + 3·m)` memory.
* Each cover/uncover touches each removed node once.
  In the worst case every node can be removed and restored at most once per
  recursion level, giving a theoretical bound `O( n·m )`, but the
  heuristic keeps the explored part tiny.
* Depth of recursion ≤ `q ≤ 200`.

Both time and memory comfortably satisfy the limits (well below the 5 s
and 256 MiB constraints).

--------------------------------------------------------------------

#### 8.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        triples.append((a, b, c))

    n = 3 * q                     # number of columns (elements)
    # DLX arrays
    max_nodes = 1 + n + 3 * t + 5   # header + column headers + all nodes
    left = [0] * max_nodes
    right = [0] * max_nodes
    up = [0] * max_nodes
    down = [0] * max_nodes
    col = [0] * max_nodes          # column header of each node
    row_id = [0] * max_nodes       # which input triple this node belongs to
    size = [0] * (n + 1)           # column sizes, index 1..n

    header = 0
    # initialise header list (circular)
    for i in range(n + 1):
        left[i] = i - 1
        right[i] = i + 1
        up[i] = down[i] = i
    left[0] = n
    right[n] = 0

    node_cnt = n + 1               # next free index
    # insert rows
    for rid, (a, b, c) in enumerate(triples):
        # create three nodes
        first = node_cnt
        nodes = []
        for elem in (a, b, c):
            nd = node_cnt
            node_cnt += 1
            col[nd] = elem
            row_id[nd] = rid
            # vertical link: insert at bottom of column
            up[nd] = up[elem]
            down[nd] = elem
            down[up[elem]] = nd
            up[elem] = nd
            size[elem] += 1
            nodes.append(nd)
        # horizontal links (circular)
        for i in range(3):
            left[nodes[i]] = nodes[(i - 1) % 3]
            right[nodes[i]] = nodes[(i + 1) % 3]

    answer_rows = [0] * q
    found = False

    def cover(c):
        # remove column header
        left[right[c]] = left[c]
        right[left[c]] = right[c]
        # remove rows
        i = down[c]
        while i != c:
            j = right[i]
            while j != i:
                down[up[j]] = down[j]
                up[down[j]] = up[j]
                size[col[j]] -= 1
                j = right[j]
            i = down[i]

    def uncover(c):
        i = up[c]
        while i != c:
            j = left[i]
            while j != i:
                size[col[j]] += 1
                down[up[j]] = j
                up[down[j]] = j
                j = left[j]
            i = up[i]
        left[right[c]] = c
        right[left[c]] = c

    def search(k):
        nonlocal found
        if right[header] == header:   # all columns covered
            found = True
            return True
        # choose column with minimal size
        c = right[header]
        min_sz = size[c]
        cc = c
        j = right[c]
        while j != header:
            if size[j] < min_sz:
                min_sz = size[j]
                cc = j
                if min_sz == 0:
                    break
            j = right[j]
        if min_sz == 0:
            return False
        cover(cc)
        r = down[cc]
        while r != cc:
            answer_rows[k] = row_id[r]
            j = right[r]
            while j != r:
                cover(col[j])
                j = right[j]
            if search(k + 1):
                return True
            # backtrack
            j = left[r]
            while j != r:
                uncover(col[j])
                j = left[j]
            r = down[r]
        uncover(cc)
        return False

    if search(0):
        out = ["YES"]
        for rid in answer_rows:
            a, b, c = triples[rid]
            out.append(f"{a} {b} {c}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
