We need to select exactly q triplets covering all pages from 1 to 3q exactly once.  
We can model this as a matching problem on a DAG: each triplet is an edge from a to c, with b in between.  
We process pages in increasing order, and for each unassigned page, we must pick a triplet starting at that page.

A greedy approach with backtracking might work because q ≤ 200, but t can be up to 20000.  
We can use a recursive backtracking with pruning, or better, a bipartite matching / flow approach.

Since each page must be the smallest in exactly one triplet, we can think of it as:  
For each page i, if it is not yet used, we must choose a triplet (i, b, c) and mark b and c used.  
We can do DFS with memoization on the set of used pages, but that’s too large.

Instead, we can use a greedy + backtracking with pruning:  
- Sort triplets by their first element.  
- At each step, find the smallest unused page, and try all triplets starting with that page.  
- Use recursion to see if a full cover is possible.

Because q ≤ 200, the number of pages is at most 600, and t ≤ 20000, but the branching factor is limited because we always pick the smallest unused page, so the recursion depth is at most q.

We can also use a bipartite matching:  
- Left side: each page that must be the smallest in a triplet (i.e., all pages 1..3q).  
- Right side: each triplet.  
But that’s not a standard matching because each triplet uses 3 pages.

Better: Use maximum flow in a network:  
- Source → each page (capacity 1)  
- Each page → each triplet that starts with that page (capacity 1)  
- Each triplet → its b and c pages (capacity 1)  
- Each page → sink (capacity 1)  
But that’s not correct because a triplet uses 3 pages, not 2.

Actually, we can model it as exact cover with 3-sets, which is NP-hard in general, but here the structure is special: the sets are ordered triples (a<b<c) and we must cover all elements exactly once. This is equivalent to finding a perfect matching in a 3-uniform hypergraph that is "convex" (intervals). This can be solved greedily:  
- Process pages from 1 to 3q.  
- Maintain a list of available triplets starting at the current page.  
- Use a priority queue to pick the one with the smallest end (c) to leave more room.

This is similar to interval scheduling. Since each triplet is an interval [a,c] with a middle b, we can treat it as an interval covering a, b, c.  
We can use a greedy algorithm:  
- Sort triplets by their first element.  
- Use a min-heap keyed by the third element.  
- For each page i from 1 to 3q:  
  - If i is already used, skip.  
  - Add all triplets starting at i to the heap.  
  - Pop the triplet with smallest c.  
  - If its b or c is already used, discard and pop next.  
  - Otherwise, select it, mark a, b, c used, and continue.

This greedy works for interval covering when intervals are sorted by start and we pick the one with earliest end.

But we can use a different state: since we always pick the smallest unused page, the state can be represented by the set of used pages, but that’s too large.  
However, we can use a greedy + backtracking with pruning:  
- At each step, find smallest unused page.  
- Try triplets starting with that page, sorted by c (earliest end first).  
- Recurse.  
This should be fast because the branching factor is limited, and we prune early.

Given q ≤ 200, the recursion depth is at most 200. The number of triplets starting at a given page is at most t, but usually small. Worst-case might be large, but with pruning it should pass.

Let’s implement backtracking with sorting triplets by first element, and for each page, keep a list of triplets starting there.  
We’ll also keep a used array of size 3q+1.

Algorithm:
1. Read q, t.
2. Store triplets in a list, and also group by first element.
3. Sort each group by third element (c) to try earliest end first.
4. Use recursive function solve(start):
   - Find the smallest unused page i from start to 3q.
   - If i > 3q, return True (all used).
   - For each triplet (a,b,c) in group[i]:
     - If not used[b] and not used[c]:
       - Mark a,b,c used.
       - Recurse from i+1.
       - If success, return True.
       - Unmark.
   - Return False.

But we need to pass the current position to avoid scanning from 1 each time.  
We can maintain a pointer to the smallest unused page.

Implementation details:
- Use a list `used` of size 3q+1, False initially.
- Use a function `find_next(pos)` to find next unused page.
- In recursion, we find next unused page, then try triplets.

We also need to output the selected triplets. We can store them in a list when we find a solution.

Let’s code it.

Potential issue: recursion depth up to 200 is fine.

Let’s test with example.

We’ll also add a check: if total number of pages is not divisible by 3, but it’s given as 3q.

import sys

def solve():
    input = sys.stdin.readline
    q, t = map(int, input().split())
    n = 3 * q
    triplets_by_start = [[] for _ in range(n + 1)]
    triplets = []
    for _ in range(t):
        a, b, c = map(int, input().split())
        triplets_by_start[a].append((a, b, c))
        triplets.append((a, b, c))
    
    # Sort each group by c (third element) to try earliest end first
    for i in range(1, n + 1):
        triplets_by_start[i].sort(key=lambda x: x[2])
    
    used = [False] * (n + 1)
    selected = []
    
    # Find the smallest unused page from start
    def find_next(start):
        for i in range(start, n + 1):
            if not used[i]:
                return i
        return n + 1
    
    def dfs(pos):
        # pos is the current smallest unused page
        if pos > n:
            return True
        if used[pos]:
            return dfs(find_next(pos + 1))
        
        for a, b, c in triplets_by_start[pos]:
            if not used[b] and not used[c]:
                used[a] = used[b] = used[c] = True
                selected.append((a, b, c))
                nxt = find_next(pos + 1)
                if dfs(nxt):
                    return True
                selected.pop()
                used[a] = used[b] = used[c] = False
        return False
    
    if dfs(1):
        print("YES")
        for a, b, c in selected:
            print(a, b, c)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
