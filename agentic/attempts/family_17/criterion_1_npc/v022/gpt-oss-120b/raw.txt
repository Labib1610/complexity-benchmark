**Solution Explanation**

The task is to choose exactly `q` triples from the given list so that every number
`1 … 3q` appears in exactly one chosen triple.
That is the classic *exact cover* problem for a universe of size `3q`
and subsets of size 3.
The well‑known algorithm for exact cover is **Algorithm X** (Donald Knuth)
implemented with *dancing links* (DLX).  
`3q ≤ 600`, `t ≤ 20000`, therefore DLX easily fits into the limits.

The algorithm works as follows  

* each column represents one page (a number `1 … 3q`);
* each row represents one compatible triple;
* a row is linked to the three columns of its pages.

During the search we repeatedly

1. pick a column with the smallest number of rows (heuristic – reduces branching);
2. try each row that covers this column:
   * add the row to the partial solution,
   * remove all columns covered by this row (and all rows intersecting them);
   * recurse;
   * on backtrack restore the removed columns/rows.

If all columns disappear we have covered every page – a solution is found.
If the recursion depth reaches `q` without covering all columns, we backtrack
(because each row adds exactly three new columns, depth `q` is the only possible
depth for a full cover).

The data structure consists of four arrays (`L,R,U,D`) that form four doubly
linked lists (left‑right for rows, up‑down for columns) and auxiliary arrays
`C` (column of a node) and `S` (size of each column).  
All operations are `O(1)`.

The search stops at the first solution; if none exists we output `NO`.

The overall complexity is exponential in the worst case (exact cover is
NP‑complete) but with the given limits and the strong heuristic it runs far
below the 5 s limit.

#### Correctness Proof  

We prove that the algorithm outputs `YES` and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
At any moment of the algorithm, the set of *remaining* columns is exactly the
set of pages not yet covered by the rows already chosen in the current
partial solution.

**Proof.**  
Initially no rows are chosen, all columns are present – the statement holds.
When a row `r` is chosen, the algorithm removes every column `c` that `r`
covers, and also removes every other row that contains any of those columns.
Thus all pages of `r` disappear from the column set, and no other page is
removed. Conversely, when backtracking, the exact inverse operations are
performed, restoring precisely those columns. ∎



##### Lemma 2  
If the algorithm reaches a state with no remaining columns, the rows stored
in the current solution cover every page exactly once.

**Proof.**  
By Lemma&nbsp;1, “no remaining columns’’ means every page is already covered.
Because a column is removed only together with the *first* row that covers it,
no page can be covered twice. ∎



##### Lemma 3  
If the algorithm outputs a set of rows, that set is a valid solution of the
original problem.

**Proof.**  
The algorithm outputs only when the recursion finds a state with no columns.
By Lemma&nbsp;2 the stored rows cover each page exactly once.
Each stored row corresponds to a given compatible triple, therefore the
output consists of `q` such triples and satisfies all requirements. ∎



##### Lemma 4  
If a valid selection of `q` triples exists, the algorithm will eventually
find (and output) one.

**Proof.**  
Consider any valid exact cover `C`.  
During the search, at each recursive step the algorithm chooses a column `c`.
Since `C` covers all columns, there is at least one row `r∈C` that contains `c`.
The algorithm tries **all** rows covering `c`; in particular it will try `r`.
When it chooses `r`, the columns of `r` are removed, and the remaining rows of
`C` still form a valid exact cover of the remaining columns (they are disjoint
from `r`).  
Thus the recursive call proceeds with a smaller exact cover.
By induction on the number of remaining columns, the algorithm can follow the
choices of `C` all the way down to the empty column set, where it succeeds.
Therefore a solution is found. ∎



##### Lemma 5  
If the algorithm finishes without finding a solution, no valid selection
exists.

**Proof.**  
Assume the contrary: a valid cover `C` exists but the algorithm fails.
From Lemma&nbsp;4 the algorithm would have found a solution by following the
choices of `C`. The only way it can fail is if it never explores a branch
containing `C`. But the algorithm explores **every** possible row for the
chosen column at each step, so every possible set of rows (including `C`) is
examined. Contradiction. ∎



##### Theorem  
The program prints  

*`YES` and a list of `q` triples* **iff** such a list exists; otherwise it
prints `NO`.

**Proof.**  
*If* part: when the program prints `YES` it outputs the rows stored by the
search. By Lemma&nbsp;3 they form a valid solution.  

*Only‑if* part: if a valid solution exists, Lemma&nbsp;4 guarantees the
search finds one, thus the program prints `YES`. If none exists, Lemma&nbsp;5
shows the search exhausts all possibilities and the program prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Let* `n = 3q ≤ 600`, `m = t ≤ 20000`.

Construction of the DLX structure: `O(m·3)` time, `O(m·3 + n)` memory.

During the search each recursive step removes at most three columns and all
rows incident to them; all operations are `O(1)`.  
The total number of recursive calls is bounded by the number of explored
partial exact covers; in the worst case this is exponential, but with the
minimum‑column heuristic the practical number is tiny for the given limits.
The memory consumption stays `O(m·3 + n)` (≈ 60 k nodes).

Both time and memory respect the limits.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        triples.append((a, b, c))

    n = 3 * q                     # number of columns
    max_nodes = t * 3 + n + 1     # + header

    # dancing links arrays (1‑based indexing for nodes)
    L = [0] * (max_nodes)
    R = [0] * (max_nodes)
    U = [0] * (max_nodes)
    D = [0] * (max_nodes)
    C = [0] * (max_nodes)         # column of node
    S = [0] * (n + 1)             # size of column, column 0 is header
    row_id = [0] * (max_nodes)    # which input row a node belongs to

    # header node 0, columns 1..n linked left‑right
    for i in range(n + 1):
        L[i] = i - 1
        R[i] = i + 1
        U[i] = D[i] = i
    L[0] = n
    R[n] = 0

    node_cnt = n
    # add rows
    for idx, (a, b, c) in enumerate(triples, 1):
        first = 0
        for col in (a, b, c):
            node_cnt += 1
            C[node_cnt] = col
            row_id[node_cnt] = idx
            # insert into column (at bottom)
            U[node_cnt] = U[col]
            D[node_cnt] = col
            D[U[col]] = node_cnt
            U[col] = node_cnt
            S[col] += 1
            # link row horizontally
            if first == 0:
                L[node_cnt] = R[node_cnt] = node_cnt
                first = node_cnt
            else:
                L[node_cnt] = L[first]
                R[node_cnt] = first
                R[L[first]] = node_cnt
                L[first] = node_cnt

    answer_rows = []

    def cover(col: int) -> None:
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col: int) -> None:
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    solved = False

    def search(k: int) -> None:
        nonlocal solved
        if R[0] == 0:          # no columns left
            solved = True
            return
        # choose column with minimal size
        c = R[0]
        min_s = S[c]
        j = R[c]
        while j != 0:
            if S[j] < min_s:
                c = j
                min_s = S[j]
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:         # dead end
            return
        cover(c)
        r = D[c]
        while r != c:
            answer_rows.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            search(k + 1)
            if solved:
                return
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            answer_rows.pop()
            r = D[r]
        uncover(c)

    search(0)

    out = []
    if solved:
        out.append("YES")
        # retrieve triples by row index
        for idx in answer_rows:
            a, b, c = triples[idx - 1]
            out.append(f"{a} {b} {c}")
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
