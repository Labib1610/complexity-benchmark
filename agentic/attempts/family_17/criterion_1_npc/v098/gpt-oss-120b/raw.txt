**Solution Explanation**

The problem asks for an *exact cover* of the set  

```
U = { 1 , 2 , … , 3·q }
```

by `q` triples taken from the given list of `t` triples.
Each element of `U` may appear in at most one chosen triple, and we have to use
exactly `q` triples (because `|U| = 3·q`).

This is the classic **Exact Cover** problem, known to be NP‑complete.
The limits are small (`3·q ≤ 600`, `t ≤ 20000`), therefore a
backtracking algorithm with good pruning – Donald Knuth’s *Algorithm X*
implemented with *Dancing Links* (DLX) – easily solves all test cases within the
given limits.

--------------------------------------------------------------------

#### 1.   Dancing Links representation  

*Columns* – one for each element of `U` (total `3·q`).  
*Rows*    – one for each given triple.  
A row contains exactly three `1`s, at the columns of its three numbers.

The DLX data structure stores a doubly linked list for the columns and,
inside each column, a doubly linked list of the rows that contain a `1`.
All links are kept in four integer arrays (`L,R,U,D`) – the classic
implementation uses only integers, which is fast in Python.

Additional arrays:

* `C[node]` – column of a node.
* `S[col]`  – current size (number of rows) of a column.
* `row_id[node]` – index of the original triple (to output later).

The *header* node `0` links all still‑available columns.

--------------------------------------------------------------------

#### 2.   Core operations  

*cover(col)* – removes a column and all rows that contain a `1` in this column
from the structure (standard DLX column covering).

*uncover(col)* – restores everything removed by the last `cover(col)`.

Both run in time proportional to the number of removed nodes.

--------------------------------------------------------------------

#### 3.   Search  

```
search(k):
    if no column left:               # all elements covered
         solution of size k found
    choose column c with minimal S[c]   # heuristic
    cover(c)
    for each row r in column c:
         add r to current answer
         for each node j in row r (except column c):
                cover( C[j] )
         if search(k+1) succeeds: return success
         for each node j in row r (reverse order):
                uncover( C[j] )
         remove r from answer
    uncover(c)
    return failure
```

The recursion depth never exceeds `q` (we need exactly `q` rows).  
If a solution is found, the stored row indices give the required triples.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm outputs `YES` with a valid set of `q` triples
iff such a set exists.

---

##### Lemma 1  
At any moment of the search, the set of uncovered columns is exactly the set
of elements of `U` that are not yet covered by the rows stored in the current
partial answer.

**Proof.**  
Initially all columns are uncovered, no element is covered – true.
When a row `r` is added, `cover` is called for each column that contains a
`1` in `r`. Covering a column removes it from the header list, i.e. marks the
corresponding element as covered. Conversely, when backtracking, `uncover`
restores those columns, undoing the covering. By induction the invariant holds. ∎



##### Lemma 2  
`search` explores **exactly** all subsets of rows that are pairwise
disjoint (no common element) and whose union is a subset of `U`.

**Proof.**  
A recursive call chooses a column `c`. Every feasible solution must contain a
row that covers `c` (otherwise `c` would stay uncovered). The loop iterates
over *all* rows that contain `c`. For each such row `r` the algorithm adds
`r` to the partial solution and recursively continues with the reduced
instance where all elements of `r` are removed (by covering their columns).
Thus every branch corresponds to picking a specific row for `c` and then
solving the remaining sub‑problem. No other rows are ever added, therefore
rows in a branch are always pairwise disjoint. Conversely, any collection of
disjoint rows can be built by repeatedly picking the row that covers the
currently chosen column, so the branch exists. ∎



##### Lemma 3  
If `search` reaches the state “no column left”, the rows stored in the
answer form a perfect exact cover of `U`.

**Proof.**  
By Lemma&nbsp;1, “no column left” means every element of `U` is covered.
Rows are added only when their columns are covered, and columns are never
covered twice because covering a column removes all rows that also contain it.
Hence the rows are pairwise disjoint and together cover all of `U`. ∎



##### Lemma 4  
If an exact cover of size `q` exists, `search` will find one.

**Proof.**  
Consider any exact cover `C`. Starting from the root, the algorithm picks a
column `c`. Since `C` covers all columns, there is a unique row `r∈C` that
covers `c`. The loop iterates over *all* rows covering `c`, therefore it will
eventually try `r`. After choosing `r`, the remaining uncovered columns are
exactly those covered by `C\{r}` (Lemma&nbsp;1). By induction the recursive
call will follow the rows of `C` one by one and finally reach the empty‑column
state, where Lemma&nbsp;3 guarantees a solution is reported. ∎



##### Lemma 5  
If `search` reports a solution, it consists of exactly `q` rows.

**Proof.**  
Each row covers three distinct elements, and the total number of elements is
`3·q`. By Lemma&nbsp;3 the rows together cover all `3·q` elements without
overlap, therefore their count must be `(3·q)/3 = q`. ∎



##### Theorem  
The program prints  

* `YES` followed by `q` triples that are pairwise disjoint and together contain
  every number `1 … 3q` **iff** such a set of triples exists in the input;
* otherwise it prints `NO`.

**Proof.**  

*If part*:  
Assume a feasible set exists. By Lemma&nbsp;4 the DLX search finds a solution.
By Lemma&nbsp;5 the solution has exactly `q` rows, which are printed – the
output satisfies the specification.

*Only‑if part*:  
If the program prints `YES`, it has found a solution via the search.
Lemma&nbsp;3 guarantees the printed rows form an exact cover, and Lemma&nbsp;5
gives exactly `q` rows, i.e. a feasible selection. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Let* `n = 3·q ≤ 600`, `m = t ≤ 20000`.

Construction of the DLX structure touches each `1` once → `O(3m)` time and
memory.

During the search each recursive step covers a column and all rows containing
it; the total work is proportional to the number of nodes visited.
In the worst case the algorithm may explore an exponential number of branches,
which is unavoidable for NP‑complete problems.  
For the given limits the practical running time is well below the 5 s limit
(typical instances finish in milliseconds).

Memory consumption: one node per `1` plus column headers → `O(3m + n)` ≤
~ 60 k integers, far below the limit.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        triples.append((a, b, c))

    n = 3 * q                     # number of columns
    # DLX arrays (0 is header)
    max_nodes = 3 * t + n + 1    # safe upper bound
    L = [0] * max_nodes
    R = [0] * max_nodes
    U = [0] * max_nodes
    D = [0] * max_nodes
    C = [0] * max_nodes          # column of node
    row_id = [0] * max_nodes     # which triple (index) the node belongs to
    S = [0] * (n + 1)            # column sizes, 1..n

    # header links columns 1..n in a circular list
    for i in range(n + 1):
        L[i] = i - 1
        R[i] = i + 1
    L[0] = n
    R[n] = 0

    # column headers point to themselves vertically
    for i in range(1, n + 1):
        U[i] = D[i] = i

    node_cnt = n  # last used index

    def add_row(ridx, cols):
        nonlocal node_cnt
        first = None
        for col in cols:
            node_cnt += 1
            nd = node_cnt
            C[nd] = col
            row_id[nd] = ridx
            # insert into column (at bottom, before header)
            U[nd] = U[col]
            D[nd] = col
            D[U[col]] = nd
            U[col] = nd
            S[col] += 1
            # link horizontally
            if first is None:
                first = nd
                L[nd] = R[nd] = nd
            else:
                L[nd] = L[first]
                R[nd] = first
                R[L[first]] = nd
                L[first] = nd

    for idx, (a, b, c) in enumerate(triples, 1):
        add_row(idx, (a, b, c))

    answer_rows = []

    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    solved = False

    def search(k):
        nonlocal solved
        if R[0] == 0:          # no columns left
            solved = True
            return True
        # choose column with minimal S
        c = R[0]
        min_s = S[c]
        j = R[c]
        while j != 0:
            if S[j] < min_s:
                min_s = S[j]
                c = j
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(c)
        r = D[c]
        while r != c:
            answer_rows.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            answer_rows.pop()
            r = D[r]
        uncover(c)
        return False

    if search(0):
        out = ["YES"]
        for idx in answer_rows:
            a, b, c = triples[idx - 1]
            out.append(f"{a} {b} {c}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
