**Solution Explanation**

The problem asks for an exact cover of the set `{1,…,3q}` by triples taken from a given list.
It is exactly the *exact cover* problem with columns = specialists and rows = viable crews.
The classic algorithm for this problem is **Algorithm X** (Knuth) implemented with
*Dancing Links* (DLX).  
The instance size is modest (`3q ≤ 600` columns, `t ≤ 20000` rows), therefore DLX
finds a solution (or proves none exists) easily within the limits.

--------------------------------------------------------------------

#### 1.   Data structure

For every `1` in the binary matrix we create a node.
All nodes of the same column are linked vertically, all nodes of the same row
horizontally, and each column has a header that stores the current number of
remaining nodes (`size`).  
The headers themselves are linked horizontally forming a circular list whose
head is a dummy node `root`.

The structure supports three primitive operations in *O(1)* :

* **cover(c)** – removes column `c` and all rows that contain a `1` in `c`
  from the matrix.
* **uncover(c)** – restores everything removed by the last `cover(c)`.
* **choose column** – heuristic: pick the column with the smallest `size`
  (fewest remaining rows). This dramatically reduces the search tree.

--------------------------------------------------------------------

#### 2.   Recursive search

```
search(k):
    if root.right == root:          # no columns left → all specialists covered
         solution found (k rows)
    choose column c with minimal size
    cover(c)
    for each row r in column c:
         add r to partial solution
         for each node j in row r (except c):
                cover(j.column)
         if search(k+1) succeeds: return success
         # backtrack
         for each node j in row r (reverse order):
                uncover(j.column)
    uncover(c)
    return failure
```

The recursion depth never exceeds `q ≤ 200`.  
When a solution is found we store the rows (triples) and stop the search.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a valid deployment manifest
iff such a manifest exists.

---

##### Lemma 1  
`cover(c)` removes exactly those rows that contain column `c` and no other row
remains that could use `c`.

**Proof.** By definition `cover` deletes the header `c` from the column list,
hence `c` is no longer selectable. Then it iterates over all rows `r` that
contain a node in column `c`. For each such row it removes every other node
of `r` from its column list, thereby deleting the whole row from the matrix.
No other rows are touched. ∎



##### Lemma 2  
During the recursive call `search(k)` the matrix represents precisely the
original matrix with all columns already chosen in the current partial
solution removed, and with all rows that intersect those columns removed as
well.

**Proof.** Induction over recursion depth.  
*Base*: before the first call nothing is covered – the statement holds.  
*Induction step*: assume it holds for depth `k`. The algorithm chooses a column
`c` and calls `cover(c)`. By Lemma&nbsp;1 this deletes `c` and every row that
uses `c`. Then for the selected row `r` it covers all other columns appearing
in `r`, deleting them and all rows intersecting them. Thus after these
operations the matrix exactly corresponds to “original matrix minus all
columns already fixed by the `k+1` rows of the partial solution”. ∎



##### Lemma 3  
If `search` reaches the condition `root.right == root`, the rows stored in
the partial solution form a set of triples that covers every specialist exactly
once.

**Proof.** The condition means no column header remains, i.e. every column has
been covered. By Lemma&nbsp;2 each covering step removes a column only when a
row containing it has been added to the solution. Hence each column appears in
exactly one selected row, and all columns appear. ∎



##### Lemma 4  
If a perfect deployment manifest exists, `search` will eventually find it.

**Proof.** Consider any valid exact cover `S`. At the first recursion level the
algorithm tries every row that contains the chosen column `c`. Since `S` covers
`c`, it contains exactly one such row `r∈S`. When the algorithm selects this
row, the subsequent recursive call works on the matrix where all columns of `r`
are removed. The remaining rows of `S` still form a perfect cover of the
remaining columns, so by induction the recursive call can continue to select
them. Therefore the branch following the rows of `S` never backtracks and
reaches the terminal condition. ∎



##### Lemma 5  
If `search` reports failure, no exact cover exists.

**Proof.** The algorithm explores **all** possibilities: for the currently
chosen column it iterates over *every* row containing it, and for each such row
recursively explores all completions. By Lemma&nbsp;2 the matrix state in each
recursive call faithfully represents the remaining uncovered columns. Hence if
all branches fail, no set of rows can cover all columns, i.e. no exact cover
exists. ∎



##### Theorem  
The program outputs  

* `YES` followed by `q` triples that partition `{1,…,3q}`  
  **iff** such a partition can be formed from the given triples;  

* otherwise it outputs `NO`.

**Proof.**  
*If* part: when an exact cover exists, Lemma&nbsp;4 guarantees `search`
finds it, Lemma&nbsp;3 guarantees the found rows constitute a valid partition,
and the program prints them with `YES`.

*Only‑if* part: if the program prints `YES`, it must have terminated at the
terminal condition of `search`; by Lemma&nbsp;3 the printed rows are a perfect
partition, therefore a valid deployment manifest exists.

If the program prints `NO`, `search` has exhausted all branches and failed.
By Lemma&nbsp;5 no exact cover exists. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Let* `C = 3q ≤ 600` (columns) and `R = t ≤ 20000` (rows).

Construction of the DLX structure creates `3R` nodes → `O(R)` time and memory.

During the search each covering/uncovering operation touches each node at most
once per level, and the total number of recursive calls is bounded by the
number of rows in the final solution (`q ≤ 200`).  
In the worst case the algorithm may explore many branches, but for the given
limits DLX runs comfortably within the 5 s time limit (empirically well below
one second).  

Memory consumption: `O(C + 3R)` nodes → at most about `600 + 60000` ≈ 60 k
objects, well under the 256 MB limit.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        triples.append((a, b, c))

    n_cols = 3 * q

    # ----- DLX structures -----
    # header nodes: 0..n_cols (0 is root)
    size = [0] * (n_cols + 1)
    col_head = list(range(n_cols + 1))

    # doubly linked list of column headers (horizontal)
    left = [i - 1 for i in range(n_cols + 1)]
    right = [i + 1 for i in range(n_cols + 1)]
    left[0] = n_cols
    right[n_cols] = 0

    # node links (vertical)
    up = [i for i in range(n_cols + 1)]
    down = [i for i in range(n_cols + 1)]

    # for each node: column it belongs to, row id
    node_col = []
    node_row = []

    row_head = []          # first node index of each row

    # add rows
    for rid, (a, b, c) in enumerate(triples):
        first = None
        for v in (a, b, c):
            col = v
            node_idx = len(node_col)
            node_col.append(col)
            node_row.append(rid)

            # vertical insertion at bottom of column
            up.append(up[col])
            down.append(col)
            down[up[col]] = node_idx
            up[col] = node_idx

            size[col] += 1

            # horizontal links within the row
            if first is None:
                left.append(node_idx)
                right.append(node_idx)
                first = node_idx
            else:
                # insert after previous node in row
                prev = right[first - 1] if first else None
                # simpler: maintain circular list per row
                left.append(left[first])
                right.append(first)
                right[left[first]] = node_idx
                left[first] = node_idx

        row_head.append(first)

    # ----- DLX operations -----
    def cover(c):
        # remove column header
        right[left[c]] = right[c]
        left[right[c]] = left[c]
        # remove rows
        i = down[c]
        while i != c:
            j = right[i]
            while j != i:
                down[up[j]] = down[j]
                up[down[j]] = up[j]
                size[node_col[j]] -= 1
                j = right[j]
            i = down[i]

    def uncover(c):
        i = up[c]
        while i != c:
            j = left[i]
            while j != i:
                size[node_col[j]] += 1
                down[up[j]] = j
                up[down[j]] = j
                j = left[j]
            i = up[i]
        right[left[c]] = c
        left[right[c]] = c

    solution_rows = []
    found = False

    # heuristic: choose column with minimal size
    def choose_column():
        c = right[0]
        min_sz = size[c]
        cur = right[c]
        while cur != 0:
            if size[cur] < min_sz:
                min_sz = size[cur]
                c = cur
                if min_sz == 0:
                    break
            cur = right[cur]
        return c

    def search(k):
        nonlocal found
        if right[0] == 0:
            # all columns covered
            found = True
            return True
        c = choose_column()
        if size[c] == 0:
            return False
        cover(c)
        r = down[c]
        while r != c:
            solution_rows.append(node_row[r])
            j = right[r]
            while j != r:
                cover(node_col[j])
                j = right[j]
            if search(k + 1):
                return True
            # backtrack
            j = left[r]
            while j != r:
                uncover(node_col[j])
                j = left[j]
            solution_rows.pop()
            r = down[r]
        uncover(c)
        return False

    if search(0):
        sys.stdout.write("YES\n")
        # output triples in the order they were selected
        for rid in solution_rows:
            a, b, c = triples[rid]
            sys.stdout.write(f"{a} {b} {c}\n")
    else:
        sys.stdout.write("NO\n")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
