**Solution Explanation**

The problem asks for a set of triples (called *protocols*) that together contain every number `1 … 3q` exactly once.
That is the classic *exact cover* problem.
We have at most  

* `n = 3q ≤ 600` columns (the numbers)  
* `m ≤ 20000` rows (the given triples)

The well‑known algorithm for exact cover is **Algorithm X** with the
*Dancing Links* data structure (DLX).  
It works fast for the given limits (the search tree is heavily pruned by
always picking the column with the smallest remaining degree).

The algorithm:

```
search():
    if no column left → all numbers are covered → success
    choose column c with minimal size
    for each row r that contains c:
        add r to the partial solution
        cover all columns of r (removing rows that intersect them)
        if search() succeeds → propagate success
        uncover columns of r   (undo the removal)
    return failure
```

The covering / uncovering operations are O(number of 1‑entries) and are
implemented by the linked‑list structure of DLX.

If a solution is found we output the `q` selected triples, otherwise `NO`.

The implementation follows the classic DLX layout:

* a header node `head`
* one column node per number `1 … 3q`
* for each triple a row node linked horizontally, and each of its three
  cells linked vertically into the corresponding column list.

All operations are pointer manipulations on integer indices, which is
fast in Python.

The recursion depth never exceeds `q ≤ 200`, well inside the limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of protocols
iff such a set exists.

---

##### Lemma 1  
During the execution of `search`, the set of *uncovered* columns is exactly
the set of numbers that are not yet covered by the rows already chosen
in the current partial solution.

**Proof.**  
Initially no column is covered, matching the empty partial solution.
When a row `r` is chosen, `cover` is called for each column `c` that
contains `r`. `cover(c)` removes `c` from the header list, therefore `c`
is no longer considered uncovered. All rows that intersect `c` are also
removed, which means they cannot be chosen later (they would reuse `c`).
Thus after covering all columns of `r`, the uncovered columns are precisely
those not covered by any chosen row. The inverse `uncover` restores the
previous state, so the invariant holds inductively. ∎



##### Lemma 2  
If `search` reaches the line “no column left”, the rows stored in the
solution list form a set of triples that covers every number exactly once.

**Proof.**  
“No column left” means the header list is empty, i.e. every column has been
covered. By Lemma&nbsp;1 each covered column corresponds to a number that
appears in some chosen row, and a column can be covered only once because
after it is covered all rows containing it are removed and can never be
chosen again. Hence each number appears in exactly one chosen row. ∎



##### Lemma 3  
If there exists a collection `S` of `q` triples that covers all numbers,
`search` will eventually find a solution.

**Proof.**  
Consider the recursive search tree. At each step the algorithm picks a
column `c`. Since `S` covers all numbers, `c` belongs to exactly one row
`r∈S`. That row is among the rows iterated over for column `c`. When the
algorithm tries `r`, it covers all columns of `r`. The remaining uncovered
columns are exactly those covered by `S\{r}`. By induction on the number of
remaining columns, the recursive call can continue to pick the rows of
`S\{r}` and finally reaches the empty‑column state. Therefore the branch
corresponding to `S` is explored and yields success. ∎



##### Lemma 4  
If `search` returns failure, no exact cover exists.

**Proof.**  
Assume contrary that an exact cover `S` exists. By Lemma&nbsp;3 the branch
that repeatedly chooses the rows of `S` is explored by the algorithm.
When that branch is taken, the algorithm reaches the empty‑column state
and would return success, contradicting the returned failure. ∎



##### Theorem  
The program outputs  

* `YES` followed by `q` triples that together contain each number
  `1 … 3q` exactly once **iff** such a set of triples exists; otherwise it
  outputs `NO`.

**Proof.**  

*If the program prints `YES`.*  
It printed the rows stored when `search` terminated with “no column left”.
By Lemma&nbsp;2 these rows form a valid exact cover, and exactly `q` rows
are printed because each row covers three distinct numbers and there are
`3q` numbers total.

*If a valid exact cover exists.*  
By Lemma&nbsp;3 `search` will find one, thus will terminate with success,
and the program prints `YES` and that cover.

*If the program prints `NO`.*  
That means `search` returned failure. By Lemma&nbsp;4 no exact cover exists.

Hence the output is correct in all cases. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Let `n = 3q ≤ 600`, `m ≤ 20000`.*

Construction of the DLX structure touches each 1‑entry once: `O(m·3) = O(m)`.

During the search each covering/uncovering of a row touches exactly its
three cells, therefore the total work is proportional to the number of
nodes visited in the search tree. In the worst case this is exponential,
but for the given limits DLX solves typical instances quickly (well under
the 5 s limit). Memory consumption is `O(n + m·3)` ≤ about `60 000` nodes,
well below the limit.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        triples.append((a, b, c))

    n = 3 * q                     # number of columns
    # DLX structures using integer indices
    # node 0 is the header
    size = 1                      # current number of nodes
    max_nodes = 1 + n + t * 3 + 5

    U = [0] * max_nodes
    D = [0] * max_nodes
    L = [0] * max_nodes
    R = [0] * max_nodes
    C = [0] * max_nodes           # column of a node (for data nodes)
    S = [0] * (n + 1)             # column sizes, index 1..n
    row_id = [0] * max_nodes      # which input row a node belongs to

    # header links
    for i in range(n + 1):
        L[i] = i - 1
        R[i] = i + 1
        U[i] = D[i] = i
    L[0] = n
    R[n] = 0

    # add rows
    for idx, (a, b, c) in enumerate(triples, start=1):
        first = None
        for col in (a, b, c):
            node = size
            size += 1
            C[node] = col
            row_id[node] = idx
            # vertical links
            U[node] = U[col]
            D[node] = col
            D[U[col]] = node
            U[col] = node
            S[col] += 1
            # horizontal links
            if first is None:
                first = node
                L[node] = R[node] = node
            else:
                L[node] = L[first]
                R[node] = first
                R[L[first]] = node
                L[first] = node

    solution = []

    def cover(col: int) -> None:
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col: int) -> None:
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    def search(k: int) -> bool:
        if R[0] == 0:          # no columns left
            return True
        # choose column with minimal size
        c = R[0]
        min_s = S[c]
        j = R[c]
        while j != 0:
            if S[j] < min_s:
                c = j
                min_s = S[j]
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(c)
        r = D[c]
        while r != c:
            solution.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution.pop()
            r = D[r]
        uncover(c)
        return False

    ok = search(0)
    out = []
    if ok:
        out.append("YES")
        # solution contains row indices, need to output the triples
        for idx in solution:
            a, b, c = triples[idx - 1]
            out.append(f"{a} {b} {c}")
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
