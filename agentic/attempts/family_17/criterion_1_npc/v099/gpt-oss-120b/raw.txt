**Solution Explanation**

The task is to choose exactly `q` triples (each triple contains three distinct component IDs) so that every ID from `1 … 3q` appears in exactly one chosen triple.
That is the *exact cover* problem for a universe of `3q` elements and `t` subsets of size 3.
`q ≤ 200` → at most `600` elements, `t ≤ 20000` rows.
The classic algorithm for exact cover is **Algorithm X** with the **Dancing Links** data structure (DLX).  
Its recursive backtracking with a good column‑selection heuristic solves the given limits easily.

--------------------------------------------------------------------

#### 1.   DLX data structure  

*Columns* – one for each element `1 … 3q`.  
*Rows* – one for each given triple.  
A node exists for every `(row, column)` where the triple contains the element.

The structure consists of doubly linked lists:

```
header <-> C1 <-> C2 <-> … <-> C_{3q}
each column header points to its vertical list of nodes
each node is linked left/right inside its row and up/down inside its column
```

Additional fields:

* `size[c]` – number of nodes currently in column `c` (how many rows still contain this element)
* `row_id[node]` – index of the original triple (to output later)

--------------------------------------------------------------------

#### 2.   Algorithm X (recursive search)

```
search(k):
    if all columns are covered -> solution found (k rows chosen)
    choose column c with minimal size   (heuristic)
    cover(c)
    for each row r in column c:
        add r to partial solution
        for each node j in row r (rightwards):
            cover(column of j)
        if search(k+1) succeeds -> propagate success
        for each node j in row r (leftwards):
            uncover(column of j)
    uncover(c)
    return failure
```

*Cover* removes a column and all rows that contain it from the matrix, updating the linked lists.
*Uncover* restores them – the operations are exact inverses, therefore backtracking is cheap.

The recursion depth never exceeds `q ≤ 200`.  
The branching factor is limited by the smallest column size, which is usually small in practice.  
With at most `600` columns and `20000` rows the algorithm finishes well within the limits.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the program prints `YES` and a valid schedule iff such a schedule exists.

---

##### Lemma 1  
During execution, the DLX structure always represents the set of rows that are still compatible with the already chosen rows.

**Proof.**  
Initially all rows are present.  
When a row `r` is chosen, `cover` is called on every column of `r`.  
Covering a column removes that column and all rows that contain the column, i.e. all rows that would intersect `r`.  
Thus after covering all columns of `r`, exactly the rows disjoint from `r` remain.  
Uncover restores the previous state, so the invariant holds at every recursion level. ∎



##### Lemma 2  
If the recursive procedure reaches the state “no columns left”, the set of chosen rows forms a perfect exact cover of the universe.

**Proof.**  
“No columns left” means every element column has been covered exactly once.
A column is covered only when a row containing that element is selected (the covering step).  
Because a column is removed permanently after the first such selection, each element appears in exactly one chosen row.
All rows are size 3, therefore the number of chosen rows is `|universe| / 3 = q`. ∎



##### Lemma 3  
If there exists a perfect exact cover, the algorithm will eventually find it.

**Proof.**  
Consider any existing exact cover `S`.  
At each recursion level the algorithm picks a column `c`.  
Since `S` covers all columns, `c` belongs to some row `r∈S`.  
`r` is present in the column list of `c` (by Lemma 1).  
The algorithm iterates over **all** rows of `c`; therefore it will try `r`.  
Choosing `r` and recursing keeps the invariant that the remaining uncovered columns are exactly those covered by `S \ {r}` (Lemma 1).  
Induction on the number of uncovered columns shows that the recursion can follow the choices of `S` down to the empty matrix, where it succeeds (Lemma 2). ∎



##### Lemma 4  
If the algorithm reports failure (outputs `NO`), no perfect exact cover exists.

**Proof.**  
Assume a perfect cover existed. By Lemma 3 the algorithm would find it, contradicting failure. ∎



##### Theorem  
The program outputs  

* `YES` followed by `q` triples that together contain each number `1 … 3q` exactly once, **iff** such a collection of triples exists; otherwise it outputs `NO`.

**Proof.**  

*If the program outputs `YES`*: it has found a recursion leaf with no columns left. By Lemma 2 the printed triples form a perfect exact cover.

*If a perfect exact cover exists*: by Lemma 3 the search will reach the leaf and output `YES`.  

If the program outputs `NO`, by Lemma 4 no perfect cover exists. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Construction* – `O(t·3)` nodes, i.e. `O(t)` time and memory.

*Search* – each covering/uncovering operation touches only the nodes of the removed rows/columns, total work proportional to the number of nodes visited in the search tree.  
In the worst case this is exponential (exact cover is NP‑complete), but with the given limits (`≤600` columns, `≤20000` rows) and the minimum‑size column heuristic the practical running time is well below the 5 s limit.  
Memory consumption: one node per matrix entry → at most `3·t ≤ 60000` nodes, each storing a few integers → far below 256 MB.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        triples.append((a, b, c))

    ncol = 3 * q                     # columns are 1..ncol
    # DLX structures
    max_nodes = 3 * t + ncol + 5
    U = [0] * max_nodes
    D = [0] * max_nodes
    L = [0] * max_nodes
    R = [0] * max_nodes
    C = [0] * max_nodes              # column of node
    row_id = [0] * max_nodes         # which triple (index) the node belongs to
    S = [0] * (ncol + 1)             # size of each column

    header = 0
    # create column headers 1..ncol
    for i in range(ncol + 1):
        U[i] = D[i] = i
        L[i] = i - 1
        R[i] = i + 1
    L[0] = ncol
    R[ncol] = 0

    node_cnt = ncol
    # add rows
    for idx, (a, b, c) in enumerate(triples, 1):
        first = 0
        for col in (a, b, c):
            node_cnt += 1
            col_head = col
            # vertical links
            U[node_cnt] = U[col_head]
            D[node_cnt] = col_head
            D[U[col_head]] = node_cnt
            U[col_head] = node_cnt
            C[node_cnt] = col_head
            row_id[node_cnt] = idx
            S[col_head] += 1
            # horizontal links
            if first == 0:
                L[node_cnt] = R[node_cnt] = node_cnt
                first = node_cnt
            else:
                L[node_cnt] = L[first]
                R[node_cnt] = first
                R[L[first]] = node_cnt
                L[first] = node_cnt

    solution = []

    def cover(col):
        # remove column header
        R[L[col]] = R[col]
        L[R[col]] = L[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                D[U[j]] = D[j]
                U[D[j]] = U[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                D[U[j]] = j
                U[D[j]] = j
                j = L[j]
            i = U[i]
        R[L[col]] = col
        L[R[col]] = col

    found = False

    def search(k):
        nonlocal found
        if R[header] == header:   # all columns covered
            found = True
            return True
        # choose column with minimal size
        c = R[header]
        min_s = S[c]
        col = c
        j = R[c]
        while j != header:
            if S[j] < min_s:
                min_s = S[j]
                col = j
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(col)
        r = D[col]
        while r != col:
            solution.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution.pop()
            r = D[r]
        uncover(col)
        return False

    if search(0):
        out = ["YES"]
        # solution contains indices of triples, need to output the triples themselves
        for idx in solution:
            a, b, c = triples[idx - 1]
            out.append(f"{a} {b} {c}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to the required input‑output format.
