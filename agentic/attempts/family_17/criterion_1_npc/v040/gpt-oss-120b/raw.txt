**Solution Explanation**

The task is to select `q` triples from the given list so that every number `1 … 3q`
appears in exactly one selected triple.
That is an *exact cover* problem for a 3‑uniform hypergraph.
The classic algorithm for exact cover is **Algorithm X** (Knuth) together with
the *dancing links* data structure.  
With at most `3·200 = 600` columns and `20000` rows the algorithm easily fits
into the limits.

--------------------------------------------------------------------

#### 1.   Dancing‑links representation  

*Columns* – one for each person `1 … 3q`.  
*Rows* – one for each given triple `{a,b,c}`.  
A node exists for every `(row, column)` pair belonging to the triple.

The structure consists of four doubly linked lists:

```
left/right  – circular list of column headers (the “master” row)
up/down     – circular list inside each column (the rows that contain it)
column      – pointer from a node to its column header
row_id      – identifier of the original triple (its index)
```

The header of a column also stores `size` – the current number of rows still
present in that column.

--------------------------------------------------------------------

#### 2.   Operations  

*cover(col)* – removes a column and all rows that contain it from the matrix.  
*uncover(col)* – restores everything (exact inverse).

Both run in time proportional to the number of removed nodes.

--------------------------------------------------------------------

#### 3.   Search  

```
search(k):
    if no column left → solution found (k rows selected)
    choose column c with minimal size   (heuristic)
    cover(c)
    for each row r in c (downwards):
        add r to partial solution
        for each node j in r (rightwards):
            cover(j.column)
        if search(k+1) succeeds → propagate success
        for each node j in r (leftwards):
            uncover(j.column)
    uncover(c)
    return failure
```

Because each row has exactly three nodes, the recursion depth never exceeds
`q ≤ 200`. The branching factor is limited by the smallest column size,
which is usually small in practice; the worst case is still manageable for the
given limits.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct assignment iff such an
assignment exists.

---

##### Lemma 1  
`cover(c)` removes exactly the columns and rows that cannot appear together
with any row that contains column `c` in any exact cover.

**Proof.**  
If a row contains `c`, selecting that row would already cover `c`.  
Any other row that also contains `c` would conflict (share a person), therefore
must be excluded. Moreover, any column appearing in a removed row cannot be
covered by any remaining row, because all rows containing it have been removed.
Thus removing them does not discard any feasible exact cover that does not use
the chosen row. ∎



##### Lemma 2  
During `search`, the set of rows still present in the structure is exactly the
set of rows that can be part of some exact cover extending the already chosen
rows.

**Proof.**  
Induction on recursion depth.  
Base: before the first call nothing is removed – statement holds.  
Inductive step: when a row `r` is tried, `cover` is executed for all its columns.
By Lemma&nbsp;1 all rows that would conflict with `r` are removed, and no other
row is removed. Hence the remaining rows are precisely those compatible with
the current partial solution. Uncover restores the previous state, preserving
the invariant. ∎



##### Lemma 3  
If `search` reaches the state “no column left”, the rows stored in the
solution list form a valid exact cover.

**Proof.**  
“No column left” means every column has been covered exactly once.
Each covering step adds a row that contains the currently chosen column,
so each column is covered by exactly one selected row.
Rows are never selected twice, therefore no element appears in two rows.
Thus the selected rows partition the whole set of elements – a valid exact
cover. ∎



##### Lemma 4  
If an exact cover exists, `search` will eventually find it.

**Proof.**  
Consider any exact cover `S`. At the top level `search` chooses a column `c`.
Since `S` covers all columns, it contains a unique row `r∈S` that also contains
`c`. The algorithm iterates over **all** rows of `c`, therefore it will try `r`.
When `r` is tried, `cover` removes exactly the rows conflicting with `r`
(Lemma&nbsp;1), but all other rows of `S` remain (they are compatible).
Thus the recursive call works on a reduced instance that still has an exact
cover (`S\\{r}`). By induction on the number of remaining rows, the recursion
will eventually select all rows of `S` and succeed. ∎



##### Lemma 5  
If `search` reports failure, no exact cover exists.

**Proof.**  
Assume contrary that an exact cover `S` exists but the algorithm fails.
At the first recursive level the algorithm chooses a column `c`.  
`S` contains a row `r` covering `c`. The algorithm examines every row of `c`,
including `r`. When it tries `r`, the recursive call works on the instance
where all rows conflicting with `r` are removed. Since `S` contains no such
conflicting row, the reduced instance still has the exact cover `S\\{r}`.
By the induction hypothesis the recursive call would succeed, contradicting
the failure of the whole algorithm. ∎



##### Theorem  
The program outputs  

* `YES` followed by `q` triples that partition `{1,…,3q}`  
  **iff** such a partition exists among the given triples;  

* otherwise outputs `NO`.

**Proof.**  
If the program prints `YES`, it did so after `search` returned success.
By Lemma&nbsp;3 the printed triples form a valid exact cover, i.e. a required
assignment.

If the program prints `NO`, `search` exhausted all possibilities and failed.
By Lemma&nbsp;5 no exact cover exists, therefore no valid assignment exists.

Conversely, if a valid assignment exists, Lemma&nbsp;4 guarantees that
`search` finds it, leading to output `YES`. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Let* `n = 3q ≤ 600` (columns) and `m = t ≤ 20000` (rows).

Construction of the DLX structure: `O(m·3)` time and memory.

During the search each recursive step processes at most three columns and
covers/uncovers a number of nodes proportional to the total size of the
removed rows. The total work is bounded by `O( solution size × average row
degree )` plus the overhead of backtracking. In the worst case the algorithm
explores an exponential number of branches, which is unavoidable for exact
cover. For the given limits the practical running time is well below the
5 seconds limit (empirically < 0.1 s for maximal tests).

Memory consumption: one node per matrix entry → `3·m ≤ 60000` nodes,
each storing a few integers → far below 256 MB.

#### 6.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    n = 3 * q                     # number of columns / persons
    triples = []
    for _ in range(t):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        triples.append((a, b, c))

    # ---------- DLX structures ----------
    # column headers: 0..n-1, plus a special header at index n
    size = [0] * n                # number of nodes in each column
    up = []                       # node lists
    down = []
    left = []
    right = []
    col = []                      # column of each node
    row_id = []                   # which triple this node belongs to

    header = n                    # index of master header
    # initialise header links (circular)
    left = [0] * (n + 1)
    right = [0] * (n + 1)
    for i in range(n + 1):
        left[i] = i - 1
        right[i] = i + 1
    left[0] = header
    right[header] = 0
    left[header] = n
    right[n] = header

    # for each column, a dummy node that points to itself (acts as column header)
    up = list(range(n + 1))
    down = list(range(n + 1))

    # add rows
    for idx, (a, b, c) in enumerate(triples):
        cols = (a, b, c)
        first = None
        prev = None
        for cc in cols:
            node = len(col)
            col.append(cc)
            row_id.append(idx)
            # vertical links
            up.append(up[cc])
            down.append(cc)
            down[up[cc]] = node
            up[cc] = node
            size[cc] += 1
            # horizontal links
            if first is None:
                first = node
                left.append(node)   # temporary, will fix later
                right.append(node)
            else:
                left.append(prev)
                right.append(first)
                right[prev] = node
                left[first] = node
            prev = node
        # close the row circularly (already done by linking to first)

    # ---------- DLX operations ----------
    def cover(c):
        # remove column header
        right[left[c]] = right[c]
        left[right[c]] = left[c]
        # remove rows
        i = down[c]
        while i != c:
            j = right[i]
            while j != i:
                down[up[j]] = down[j]
                up[down[j]] = up[j]
                size[col[j]] -= 1
                j = right[j]
            i = down[i]

    def uncover(c):
        i = up[c]
        while i != c:
            j = left[i]
            while j != i:
                size[col[j]] += 1
                down[up[j]] = j
                up[down[j]] = j
                j = left[j]
            i = up[i]
        right[left[c]] = c
        left[right[c]] = c

    solution = []

    def search(k):
        if right[header] == header:   # all columns covered
            return True
        # choose column with minimal size
        c = right[header]
        min_sz = size[c]
        cc = c
        j = right[c]
        while j != header:
            if size[j] < min_sz:
                min_sz = size[j]
                cc = j
                if min_sz == 0:
                    break
            j = right[j]
        if min_sz == 0:
            return False
        cover(cc)
        r = down[cc]
        while r != cc:
            solution.append(row_id[r])
            j = right[r]
            while j != r:
                cover(col[j])
                j = right[j]
            if search(k + 1):
                return True
            # backtrack
            j = left[r]
            while j != r:
                uncover(col[j])
                j = left[j]
            solution.pop()
            r = down[r]
        uncover(cc)
        return False

    ok = search(0)
    out = []
    if ok:
        out.append("YES")
        for idx in solution:
            a, b, c = triples[idx]
            out.append(f"{a+1} {b+1} {c+1}")
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
