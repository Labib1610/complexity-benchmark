We can model this as an exact cover problem: we have \(3q\) elements (operators) and a collection of trios (sets of size 3). We need to select disjoint trios covering all elements.

Since \(q \le 200\), the total number of operators is at most 600. The number of trios can be up to 20,000.  
We can solve this with backtracking + pruning, or with Algorithm X (Dancing Links), but a simpler recursive approach with bitmasks works well here.

We’ll represent each trio as a bitmask of 3 bits set. We’ll try to cover all elements.

**Approach:**
- Represent each operator as a bit position (0 to 3q-1).
- Convert each trio to a bitmask.
- Use recursion: pick the first uncovered operator, try all trios containing it, and recurse.
- Use memoization on the remaining mask to avoid repeated states.

Since \(3q \le 600\), a Python integer bitmask is fine.

Let’s implement it.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    q = int(next(it))
    t = int(next(it))
    n = 3 * q
    trios = []
    for _ in range(t):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        mask = (1 << a) | (1 << b) | (1 << c)
        trios.append((mask, a, b, c))
    
    # For each operator, list indices of trios containing it
    by_operator = [[] for _ in range(n)]
    for idx, (mask, a, b, c) in enumerate(trios):
        by_operator[a].append(idx)
        by_operator[b].append(idx)
        by_operator[c].append(idx)
    
    full_mask = (1 << n) - 1
    memo = {}
    chosen = []
    
    def dfs(remaining):
        if remaining == 0:
            return True
        if remaining in memo:
            return False
        # find first uncovered operator
        # lowest set bit
        lsb = remaining & -remaining
        op = (lsb.bit_length() - 1)
        for idx in by_operator[op]:
            mask, a, b, c = trios[idx]
            if mask & remaining == mask:  # all three still available
                chosen.append((a+1, b+1, c+1))
                if dfs(remaining ^ mask):
                    return True
                chosen.pop()
        memo[remaining] = False
        return False
    
    if dfs(full_mask):
        print("YES")
        for a, b, c in chosen:
            print(a, b, c)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
