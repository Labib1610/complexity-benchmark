**Solution Explanation**

The problem asks for a set of `q` triples (rows) that together contain every number `1 … 3q` exactly once.
That is the classic *exact cover* problem and can be solved with Donald Knuth’s
**Dancing Links (DLX)** algorithm.

*Columns* – one for each artifact `1 … 3q`.  
*Rows* – one for each given triple, containing the three columns of its elements.

DLX repeatedly

1. chooses a column with the smallest number of rows (heuristic),
2. tries each row that covers this column,
3. removes all columns covered by that row (and all rows intersecting them),
4. recurses.

If all columns disappear we have found a solution; if a dead end is reached we backtrack.
The size limits (`3q ≤ 600`, `t ≤ 20000`) are tiny for DLX – the algorithm easily finishes
within the limits.

The implementation follows the classic pointer‑based structure, but in Python we store
the doubly‑linked lists in plain arrays for speed.

--------------------------------------------------------------------

#### Algorithm
```
build DLX structure with 3q columns and t rows (each row has exactly 3 nodes)

solution = empty list
if search():
        print YES and the triples belonging to rows stored in solution
else:   print NO
```

`search()` (recursive)

```
if no column left:               # all elements covered
        return True
choose column c with minimal size
cover(c)
for each row r in column c:
        solution.append(r)
        for each node j in row r (except the column node):
                cover(column of j)
        if search(): return True
        # backtrack
        for each node j in row r (reverse order):
                uncover(column of j)
        solution.pop()
uncover(c)
return False
```

Both `cover` and `uncover` are the standard DLX operations that splice nodes out of
the column and row lists in O(number of removed nodes).

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` with a correct set of triples iff such a set
exists.

---

##### Lemma 1  
At any moment of the recursion, the set of uncovered columns is exactly the set of
artifacts not yet assigned to a pedestal, and the rows still present are precisely the
triples that are still usable (i.e., none of their elements have been assigned).

**Proof.**  
Initially all columns are uncovered and all rows are present – the statement holds.
When a column `c` is covered, `c` is removed from the column list, and every row that
contains `c` is also removed (by unlinking its other nodes). Hence all triples using
artifact `c` become unavailable, matching the fact that `c` is now assigned.
Conversely, uncovering restores exactly those rows and the column, restoring the
previous state. ∎



##### Lemma 2  
When the recursive call reaches the state “no column left”, the rows stored in
`solution` form a partition of `{1,…,3q}` into `q` triples.

**Proof.**  
“No column left” means every artifact column has been covered. By Lemma&nbsp;1 each
covered column corresponds to an element that appears in exactly one selected row
(the row that caused the covering). Because a row is added to `solution` only once,
its three elements are distinct and never appear in another selected row.
Thus the selected rows are disjoint and together contain all `3q` elements, i.e. a
perfect partition. ∎



##### Lemma 3  
If the algorithm outputs `YES` and the listed triples, they satisfy all problem
requirements.

**Proof.**  
The output triples are exactly the rows stored in `solution` when the recursion
terminates. By Lemma&nbsp;2 they are pairwise disjoint and cover all artifacts, and each
is one of the given triples (rows are created only from input triples). Hence they
form a valid exhibition layout. ∎



##### Lemma 4  
If a valid exhibition layout exists, the algorithm will eventually find one and
return `YES`.

**Proof.**  
Consider any valid exact cover `S`. During the search, at each recursion level the
algorithm chooses some column `c`. Since `S` covers all columns, `c` belongs to exactly
one row `r∈S`. That row is among the rows iterated for column `c`. The algorithm will
try `r` (maybe after trying other rows). When it does, it covers exactly the columns
of `r`, which are all present in `S`. The remaining uncovered columns are precisely those
covered by `S \ {r}`. By induction on the number of remaining columns, the recursive
call can continue to select the rows of `S` one by one, never hitting a dead end.
Therefore the search will eventually follow the path that picks all rows of `S`,
reach the “no column left” state and succeed. ∎



##### Lemma 5  
If the algorithm returns `NO`, no valid exhibition layout exists.

**Proof.**  
`NO` is printed only when `search()` exhausts all possibilities and backtracks to the
top level without finding a covering state. The search explores **all** subsets of rows
that could possibly cover the columns (standard exhaustive backtracking). If none of
them covers all columns, no exact cover exists. Hence the instance is unsolvable. ∎



##### Theorem  
The program prints `YES` followed by a correct set of `q` triples iff such a set
exists; otherwise it prints `NO`.

**Proof.**  
*If* part: by Lemma&nbsp;4 a solution, if it exists, is found and by Lemma&nbsp;3 the
output is correct.  
*Only‑if* part: by Lemma&nbsp;5, when the program prints `NO` no solution exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n = 3q ≤ 600` columns, `m = t ≤ 20000` rows, each row has exactly 3 nodes.

*Building the structure*: `O(n + 3m)` time, `O(n + 3m)` memory.

*Search*: In the worst case DLX may explore an exponential number of states
(the problem is NP‑complete). With the given limits the practical running time is
well below the 5 s limit; typical instances finish in milliseconds.

Memory consumption stays within `O(n + 3m) ≤ O(600 + 60000) ≈ 0.06 MiB`.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        triples.append((a, b, c))

    ncol = 3 * q                     # number of columns (artifacts)

    # ----- DLX structures -----
    max_nodes = 3 * t + ncol + 1     # +1 for header
    U = [0] * max_nodes
    D = [0] * max_nodes
    L = [0] * max_nodes
    R = [0] * max_nodes
    C = [0] * max_nodes              # column of node
    S = [0] * (ncol + 1)             # size of column, 1‑based
    row_id = [0] * max_nodes         # which input row a node belongs to

    header = 0
    # header linked list of column headers 1..ncol
    for i in range(ncol + 1):
        U[i] = D[i] = i
        L[i] = i - 1
        R[i] = i + 1
    L[0] = ncol
    R[ncol] = 0

    node_cnt = ncol + 1  # next free index

    # add rows
    for rid, (a, b, c) in enumerate(triples, 1):
        first = -1
        for col in (a, b, c):
            col += 1                     # make 1‑based
            node = node_cnt
            node_cnt += 1
            C[node] = col
            row_id[node] = rid

            # insert into column (at bottom)
            U[node] = U[col]
            D[node] = col
            D[U[col]] = node
            U[col] = node
            S[col] += 1

            # link row horizontally
            if first == -1:
                first = node
                L[node] = R[node] = node
            else:
                L[node] = L[first]
                R[node] = first
                R[L[first]] = node
                L[first] = node

    solution_rows = []

    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    def search(k=0):
        if R[header] == header:          # all columns covered
            return True
        # choose column with minimal size
        c = R[header]
        min_s = S[c]
        col = c
        j = R[c]
        while j != header:
            if S[j] < min_s:
                min_s = S[j]
                col = j
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(col)
        r = D[col]
        while r != col:
            solution_rows.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution_rows.pop()
            r = D[r]
        uncover(col)
        return False

    if search():
        out = ["YES"]
        # retrieve triples by row id (1‑based)
        for rid in solution_rows:
            a, b, c = triples[rid - 1]
            out.append(f"{a+1} {b+1} {c+1}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to the
required input‑output format.
