We need to select exactly \( q \) triples from the given list so that every number from 1 to \( 3q \) appears exactly once.  

This is essentially an exact cover problem, but with a special structure: each triple has size 3, and we need to cover all \( 3q \) elements.  

We can model it as a matching problem in a 3-uniform hypergraph, but since \( q \leq 200 \), the total number of elements is at most 600, and the number of triples is at most 20000.  

A direct backtracking with pruning might work if we choose the next uncovered element with the fewest possible triples.  

We can also think of it as a bipartite matching if we split each triple into three edges, but that doesn’t directly solve exact cover.  

Given constraints, a recursive backtracking with bitmask for covered elements is feasible:  
- \( 3q \leq 600 \), so we can use Python integers as bitmasks (up to 600 bits).  
- We precompute for each element the list of triples containing it.  
- At each step, pick the smallest uncovered element, try each triple containing it, mark covered, recurse.  

We must also ensure we pick exactly \( q \) triples.  

Let’s implement that.  

We’ll store triples as tuples, and also store a bitmask for each triple.  

We’ll use a recursive function that takes the current mask and the list of chosen triples.  

To speed up, we can sort triples by the smallest uncovered element they cover, but the main pruning is picking the element with fewest options.  

Let’s code it.  

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        triples.append((a, b, c))
    
    n = 3 * q
    # For each element, list of triple indices
    elem_to_triples = [[] for _ in range(n)]
    for idx, (a, b, c) in enumerate(triples):
        elem_to_triples[a].append(idx)
        elem_to_triples[b].append(idx)
        elem_to_triples[c].append(idx)
    
    # Precompute bitmask for each triple
    triple_mask = []
    for a, b, c in triples:
        mask = (1 << a) | (1 << b) | (1 << c)
        triple_mask.append(mask)
    
    full_mask = (1 << n) - 1
    
    chosen = []
    
    # Recursive backtracking
    def dfs(mask):
        if mask == full_mask:
            return True
        # Find first uncovered element
        # We can find the lowest zero bit
        # Python trick: ~mask & full_mask gives uncovered bits
        uncovered = (~mask) & full_mask
        # lowest set bit
        low = uncovered & -uncovered
        elem = low.bit_length() - 1
        # Try each triple containing elem
        for idx in elem_to_triples[elem]:
            if mask & triple_mask[idx] == 0:
                chosen.append(idx)
                if dfs(mask | triple_mask[idx]):
                    return True
                chosen.pop()
        return False
    
    if dfs(0):
        print("YES")
        for idx in chosen:
            a, b, c = triples[idx]
            print(a+1, b+1, c+1)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
