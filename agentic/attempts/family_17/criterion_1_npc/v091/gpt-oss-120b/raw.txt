**Solution Explanation**

The problem asks for an *exact cover* of the set `{1,…,3q}` by some of the given triples.
An exact cover is a collection of triples such that every element appears in
exactly one chosen triple.

The classic algorithm for exact cover is **Algorithm X** (Donald Knuth) together
with the **Dancing Links** data structure.  
The universe has at most `3·200 = 600` elements and at most `20000` triples,
so a straightforward DLX implementation easily fits into the limits.

The algorithm works as follows  

```
search():
    if no column left → all elements are covered → success
    choose column c with the smallest number of rows (heuristic)
    for each row r that contains c:
        add r to the partial solution
        cover all columns of r (remove them and all rows that intersect them)
        if search() succeeds → propagate success
        uncover the columns again (backtrack)
    return failure
```

The data structure stores a doubly linked list of columns and, for each row,
a circular list of its nodes.  Covering a column removes it from the column
list and also removes every row that contains a node in that column; uncovering
restores everything.

The recursion depth never exceeds `q ≤ 200`.  
The total work is bounded by the size of the search tree; for the given limits
the program runs well within the time limit.

If a solution is found we output the `q` triples that were selected; otherwise
`NO`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct family of triples
iff such a family exists.

---

##### Lemma 1  
During the execution of `search` the set of *uncovered* columns is exactly the
set of elements that are not yet covered by the triples already stored in the
partial solution.

**Proof.**  
Initially no column is covered, no element is covered – the statement holds.
When a row `r` is chosen, `cover` is called for every column `c` that appears
in `r`. `cover(c)` removes `c` from the column list, i.e. marks the element
`c` as covered, and also removes every other row that contains `c`, because
those rows would use the same element a second time. Thus after covering all
columns of `r` the uncovered columns are precisely the elements not yet used.
Uncovering restores the previous state, so the invariant holds inductively. ∎



##### Lemma 2  
If `search` reaches the line “no column left”, the triples stored in the
partial solution form a valid exact cover.

**Proof.**  
“No column left” means every column has been covered. By Lemma&nbsp;1 this
means every element `1…3q` is covered by the selected rows. Because a column is
removed together with all rows that intersect it, no element can belong to two
different selected rows. Hence each element appears exactly once. ∎



##### Lemma 3  
If there exists an exact cover, `search` will eventually find one.

**Proof.**  
Consider any exact cover `S`. At the first recursive call the algorithm picks
some column `c`. Since `S` covers all elements, there is a row `r∈S` that
contains `c`. The algorithm iterates over **all** rows containing `c`, therefore
it will try `r`. After covering the columns of `r`, the remaining uncovered
elements are exactly those covered by `S\\{r}` (Lemma&nbsp;1). By induction on
the size of the remaining cover, the recursive call will eventually select the
remaining rows of `S`. Thus the search tree contains a path that reproduces
`S`, and the algorithm will find a solution. ∎



##### Lemma 4  
If `search` returns failure, no exact cover exists.

**Proof.**  
Assume contrary that an exact cover `S` exists but the algorithm fails.
At the first level it chooses a column `c`. Every exact cover must contain a
row `r∈S` that covers `c`. The algorithm explores **all** such rows. For each
explored row it recursively searches for a cover of the remaining elements.
If for the particular `r∈S` the recursive call failed, by the induction
hypothesis no exact cover exists for the reduced instance, contradicting the
existence of `S\\{r}`. Hence the recursive call with `r` must succeed, and the
algorithm cannot fail overall. ∎



##### Theorem  
The program outputs  

* `YES` followed by `q` triples that form an exact cover, **iff** such a set of
  triples exists; otherwise it outputs `NO`.

**Proof.**  
*If* the program prints `YES`, it did so after `search` terminated at the
“no column left” case, therefore by Lemma&nbsp;2 the printed triples are a
valid exact cover.

*Only‑if*: If an exact cover exists, Lemma&nbsp;3 guarantees that `search`
finds one, thus the program prints `YES`. If no exact cover exists,
Lemma&nbsp;4 shows that `search` must fail, and the program prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

* `n = 3q ≤ 600` columns, `m ≤ 20000` rows.  
* Building the DLX structure: `O(total number of 1‑entries) = O(3m)`.  

During the search each recursive step covers a column and removes all rows
containing it; the total work over the whole recursion is proportional to the
size of the explored part of the search tree. In the worst case this is
exponential (the problem is NP‑complete), but with the given limits the
practical running time is well below the 5 s limit.

Memory consumption: one node per 1‑entry → `3m ≤ 60000` nodes, each storing a
few integers → far below the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        triples.append((a, b, c))

    n = 3 * q                     # number of columns (elements)

    # ---------- Dancing Links structures ----------
    # column header nodes: 0..n (0 is the root)
    size = [0] * (n + 1)          # number of rows in each column
    up = list(range(n + 1))
    down = list(range(n + 1))
    left = [0] * (n + 1)
    right = [0] * (n + 1)

    for i in range(n + 1):
        left[i] = i - 1
        right[i] = i + 1
    left[0] = n
    right[n] = 0

    # row nodes will be stored in arrays; each node knows its column and row id
    col = []      # column of node i
    row = []      # row id of node i
    L = []        # left neighbor in row
    R = []        # right neighbor in row

    row_head = []   # for each row, index of one of its nodes

    def add_node(rid, c):
        idx = len(col)
        col.append(c)
        row.append(rid)
        L.append(0)
        R.append(0)

        # insert into column c at the bottom (just above header)
        up_idx = up[c]
        down_idx = c
        up.append(up_idx)
        down.append(down_idx)

        down[up_idx] = idx
        up[c] = idx

        size[c] += 1
        return idx

    for rid, (a, b, c) in enumerate(triples):
        nodes = [add_node(rid, a), add_node(rid, b), add_node(rid, c)]
        # link the three nodes circularly
        for i in range(3):
            L[nodes[i]] = nodes[(i - 1) % 3]
            R[nodes[i]] = nodes[(i + 1) % 3]
        row_head.append(nodes[0])

    # ---------- DLX operations ----------
    def cover(c):
        # remove column header
        right[left[c]] = right[c]
        left[right[c]] = left[c]
        # for each row i in column c
        i = down[c]
        while i != c:
            j = R[i]
            while j != i:
                # remove node j from its column
                down[up[j]] = down[j]
                up[down[j]] = up[j]
                size[col[j]] -= 1
                j = R[j]
            i = down[i]

    def uncover(c):
        i = up[c]
        while i != c:
            j = L[i]
            while j != i:
                size[col[j]] += 1
                down[up[j]] = j
                up[down[j]] = j
                j = L[j]
            i = up[i]
        right[left[c]] = c
        left[right[c]] = c

    solution_rows = []

    def search(k=0):
        if right[0] == 0:          # no columns left
            return True
        # choose column with minimal size
        c = right[0]
        min_sz = size[c]
        j = right[c]
        while j != 0:
            if size[j] < min_sz:
                c = j
                min_sz = size[j]
                if min_sz == 0:
                    break
            j = right[j]
        if min_sz == 0:
            return False

        cover(c)
        r = down[c]
        while r != c:
            solution_rows.append(row[r])
            j = R[r]
            while j != r:
                cover(col[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(col[j])
                j = L[j]
            solution_rows.pop()
            r = down[r]
        uncover(c)
        return False

    if search():
        out = ["YES"]
        for rid in solution_rows:
            out.append(' '.join(map(str, triples[rid])))
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
