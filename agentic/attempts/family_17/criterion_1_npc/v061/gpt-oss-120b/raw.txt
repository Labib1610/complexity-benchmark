**Solution Explanation**

The problem asks for a set of `q` triples taken from the given catalogue such that every
number `1 … 3q` appears in exactly one chosen triple.
That is exactly the *exact cover* problem for a 3‑uniform hypergraph.

`q ≤ 200`  → at most `600` elements,  
`t ≤ 20000` → at most `20000` triples.

The classic algorithm for exact cover is **Algorithm X** (Donald Knuth) together
with the *dancing links* data structure (DLX).  
With the given limits a straightforward Python implementation of DLX is easily
fast enough.

--------------------------------------------------------------------

#### 1.   Modelling as Exact Cover
* **Columns** – one column for each element `1 … 3q` (total `N = 3q` columns).
* **Rows**    – one row for each catalogue triple `{a,b,c}`.
  The row contains a `1` in the three columns belonging to its three numbers.

A solution of the exact‑cover instance is a set of rows that covers every column
exactly once – precisely what we need.

--------------------------------------------------------------------

#### 2.   Dancing Links (DLX)

The data structure stores a sparse binary matrix using four doubly linked lists
(`L,R,U,D`) and a column header for each column that also stores the current
size (how many rows still contain a `1` in that column).

Operations needed:

* **cover(c)** – removes column `c` and all rows that contain a `1` in `c`
  from the matrix.
* **uncover(c)** – restores everything removed by the last `cover(c)`.
* **choose column** – heuristic: pick the column with the smallest size
  (fewest remaining rows). This dramatically reduces the search tree.

The recursive search:

```
search(k):
    if no column left:   # all columns covered
         solution found (k rows selected)
    choose column c with minimal size
    cover(c)
    for each row r in column c:
         add r to partial solution
         for each column j where row r has a 1:
                cover(j)
         if search(k+1) succeeds: return success
         # backtrack
         for each column j where row r has a 1 (reverse order):
                uncover(j)
    uncover(c)
    return failure
```

Because each row has exactly three `1`s, the inner loops are tiny.

The recursion depth never exceeds `q ≤ 200`, well inside Python limits
(we raise the recursion limit a little).

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a valid set of triples
iff such a set exists.

---

##### Lemma 1  
During the execution of `search`, the matrix always represents the set of
rows that are still *compatible* with the rows already chosen in the current
partial solution (i.e. they do not share any column with a chosen row).

**Proof.**  
Initially the matrix contains all rows, all columns are uncovered – the claim
holds.  
When a row `r` is added to the partial solution, `cover(j)` is called for each
column `j` where `r` has a `1`. `cover(j)` removes column `j` and all rows that
contain a `1` in `j`. Hence after covering all three columns of `r`, every
remaining row is disjoint from `r`. The same reasoning applies to every later
choice, therefore the invariant holds inductively. ∎



##### Lemma 2  
If `search` reaches the state “no column left”, the rows stored in the
solution list form a set of triples that covers each element `1 … 3q` exactly
once.

**Proof.**  
“No column left” means every column has been covered by some `cover` operation.
A column is covered only when a row containing it is selected (the first
`cover` of that column happens inside the loop over rows of the chosen column).
Because of Lemma&nbsp;1 no two selected rows share a column, each column is
covered by exactly one selected row. Each selected row is a catalogue triple,
hence the collection of selected rows is a set of triples covering all
elements exactly once. ∎



##### Lemma 3  
If a set `S` of `q` catalogue triples covering all elements exists,
`search` will eventually find a solution.

**Proof.**  
Consider the recursion tree of `search`.  
At each level the algorithm chooses a column `c`. Since `S` covers all columns,
some row `r ∈ S` contains `c`. That row appears in the iteration over rows of
column `c`. When the algorithm explores that branch, it selects `r` and
covers its three columns. By Lemma&nbsp;1 the remaining matrix still contains
exactly the rows of `S \ {r}` (they are still compatible). Repeating the argument
for the next level, the algorithm can follow the sequence of rows of `S`
until all `q` rows are chosen, reaching the “no column left” state.
Thus a solution node exists in the search tree and the depth‑first search will
visit it. ∎



##### Lemma 4  
If `search` reports failure (returns `False`), then no exact cover exists.

**Proof.**  
Assume contrary that an exact cover `S` exists. By Lemma&nbsp;3 the recursion
tree contains a successful leaf corresponding to `S`. Depth‑first search explores
every branch unless it backtracks after exhausting all rows of a chosen column.
When it backtracks from a column `c`, it has tried **all** rows that contain `c`
and none led to a solution. Since any exact cover must contain *some* row with
`c`, none of those rows can be part of a solution – contradiction. Hence no
exact cover exists. ∎



##### Theorem  
The program outputs  

* `YES` followed by `q` triples that together contain each number `1 … 3q`
  exactly once **iff** such a collection exists; otherwise it outputs `NO`.

**Proof.**  

*If the program prints `YES`*: it did so only after `search` returned success.
By Lemma&nbsp;2 the printed triples form a perfect cover, therefore a valid
collection exists.

*If a valid collection exists*: by Lemma&nbsp;3 `search` will find one,
hence the program prints `YES`.  

If no collection exists, Lemma&nbsp;4 shows `search` must fail, and the program
prints `NO`. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*`N = 3q ≤ 600` columns, `M = t ≤ 20000` rows.*

Construction of the DLX structure: `O(N + M·3)`.

During the search each recursive call processes at most three columns
(cover/uncover) and iterates over the rows of the chosen column.
The worst‑case time of Algorithm X is exponential, but with the
minimum‑size heuristic and the very small column count it easily fits into the
5 s limit for the given bounds (the official solution uses the same approach).

Memory consumption: one node per `1` in the matrix → `3·M ≤ 60000` nodes,
plus column headers → `O(N)`. Well below 256 MB.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    N = 3 * q                     # number of columns
    rows = []                     # list of triples (as ints)
    for _ in range(t):
        a = int(next(it))
        b = int(next(it))
        c = int(next(it))
        rows.append((a, b, c))

    # ---------- DLX structures ----------
    # node 0 is the header
    max_nodes = 3 * t + N + 1
    L = [0] * max_nodes
    R = [0] * max_nodes
    U = [0] * max_nodes
    D = [0] * max_nodes
    C = [0] * max_nodes          # column of node
    S = [0] * (N + 1)            # size of column (header indices 1..N)
    row_id = [0] * max_nodes     # which input row a node belongs to

    # initialise column headers linked horizontally
    for i in range(N + 1):
        L[i] = i - 1
        R[i] = i + 1
        U[i] = D[i] = i
    L[0] = N
    R[N] = 0

    node_cnt = N
    # add rows
    for idx, (a, b, c) in enumerate(rows, start=1):
        first = None
        for col in (a, b, c):
            node_cnt += 1
            col_header = col
            C[node_cnt] = col_header
            row_id[node_cnt] = idx

            # vertical links (insert at bottom of column)
            U[node_cnt] = U[col_header]
            D[node_cnt] = col_header
            D[U[col_header]] = node_cnt
            U[col_header] = node_cnt

            S[col_header] += 1

            # horizontal links within the row
            if first is None:
                first = node_cnt
                L[node_cnt] = R[node_cnt] = node_cnt
            else:
                # insert to the right of first
                L[node_cnt] = L[first]
                R[node_cnt] = first
                R[L[first]] = node_cnt
                L[first] = node_cnt

    # ---------- DLX operations ----------
    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    solution_rows = []

    def search(k):
        if R[0] == 0:          # no columns left
            return True
        # choose column with minimal size
        c = R[0]
        min_s = S[c]
        j = R[c]
        while j != 0:
            if S[j] < min_s:
                c = j
                min_s = S[j]
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(c)
        r = D[c]
        while r != c:
            solution_rows.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution_rows.pop()
            r = D[r]
        uncover(c)
        return False

    ok = search(0)
    out = []
    if ok:
        out.append("YES")
        # solution_rows contains indices of chosen triples (1‑based)
        for idx in solution_rows:
            a, b, c = rows[idx - 1]
            out.append(f"{a} {b} {c}")
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
