We can model this as a matching problem: we need to select exactly \( q \) triples from the given configurations such that every component from 1 to \( 3q \) appears exactly once.

This is equivalent to finding a perfect matching in a 3-uniform hypergraph, which is NP-hard in general. However, the constraints are small enough for a backtracking approach with pruning.

We’ll use recursion with bitmask to track used components, and try configurations in order. Since \( q \le 200 \), \( 3q \le 600 \), a bitmask of 600 bits is too large for a single integer, but we can use a Python `int` for bitmask (Python supports big integers). We’ll also pre-filter configurations that contain already used components.

Here’s the implementation:

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    q = int(input_data[0])
    t = int(input_data[1])
    triples = []
    idx = 2
    for _ in range(t):
        a = int(input_data[idx])
        b = int(input_data[idx+1])
        c = int(input_data[idx+2])
        idx += 3
        triples.append((a-1, b-1, c-1))  # 0-based

    n = 3 * q
    full_mask = (1 << n) - 1

    # Sort triples by first element for better pruning
    triples.sort()

    # We'll do backtracking
    used = 0
    chosen = []

    # Precompute for each triple a bitmask
    triple_masks = []
    for a,b,c in triples:
        triple_masks.append((1 << a) | (1 << b) | (1 << c))

    # Recursive search
    def dfs(count, used_mask):
        if count == q:
            return used_mask == full_mask
        # Try triples
        for i, (a,b,c) in enumerate(triples):
            mask = triple_masks[i]
            if used_mask & mask == 0:
                chosen.append((a+1,b+1,c+1))
                if dfs(count+1, used_mask | mask):
                    return True
                chosen.pop()
        return False

    if dfs(0, 0):
        print("YES")
        for a,b,c in chosen:
            print(a,b,c)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
