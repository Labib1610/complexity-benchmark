**Solution Explanation**

The problem asks for a *perfect tiling* of the set `{1,…,3q}` by triples taken from a given list.
In other words we need an **exact cover** of the `3q` elements with some of the given triples,
each element appearing in exactly one chosen triple.

The classic algorithm for exact cover is **Algorithm X** (Donald Knuth) together with the
*Dancing Links* data structure (DLX).  
With at most `3·200 = 600` columns and `20000` rows the DLX implementation easily fits
into the limits.

The algorithm works as follows

```
search()
    if no column left → all elements are covered → success
    choose a column c with the smallest number of rows (heuristic)
    for each row r that contains c
        add r to the partial solution
        cover all columns of r (remove them from the matrix)
        if search() succeeds → propagate success
        uncover the columns of r (backtrack)
    return failure
```

Cover / uncover operations are performed in O(number of 1‑entries) by manipulating
four doubly‑linked lists (up, down, left, right).  
The implementation below follows the standard textbook version.

If a solution is found we output the triples belonging to the selected rows,
otherwise we output `NO`.

The algorithm is guaranteed to find a solution if one exists, and its running time
is exponential in the worst case (the problem is NP‑complete), but for the given
bounds it runs comfortably within the limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
During the execution of `search` the set of uncovered columns is exactly the set
of elements that are not yet covered by the triples already stored in the current
partial solution.

**Proof.**  
Initially no column is covered, i.e. all elements are uncovered – true.
When a row `r` (a triple) is added to the partial solution, `cover` is called for
every column `c` that contains a `1` in that row. `cover(c)` removes `c` from the
matrix, therefore `c` will never be chosen again and cannot be covered a second
time. Conversely, all other columns stay untouched. Hence after covering all columns
of `r`, exactly the elements of `r` become covered and the invariant holds.
Uncover restores the previous state, so the invariant also holds after backtracking. ∎



##### Lemma 2  
If `search` reaches the line “no column left”, the triples stored in the partial
solution form a perfect tiling of the whole roster.

**Proof.**  
“No column left” means every column has been covered. By Lemma&nbsp;1 this is
equivalent to every element `1…3q` being covered by some selected triple.
Because a column is removed only when a row containing it is chosen, and a column
cannot be removed twice, each element is covered exactly once. ∎



##### Lemma 3  
If there exists a perfect tiling, `search` will eventually find it.

**Proof.**  
Consider any exact cover `S`. At the first recursive call the algorithm chooses a
column `c`. Since `S` covers all columns, there is a row `r∈S` that contains `c`.
The algorithm iterates over **all** rows containing `c`; therefore it will try
`r`. After covering `r` the remaining uncovered columns are exactly those not
covered by `r`. The restriction of `S` to those columns is again an exact cover.
By induction on the number of remaining columns the recursive call will eventually
select the remaining rows of `S`. Hence the algorithm can follow a path that
exactly reproduces `S` and will succeed. ∎



##### Lemma 4  
If `search` returns failure, no perfect tiling exists.

**Proof.**  
Assume a perfect tiling existed. By Lemma&nbsp;3 the algorithm would have a
recursive path that selects exactly its rows and reaches the “no column left”
state, which returns success. Therefore the algorithm cannot return failure while a
solution exists. Contraposition gives the claim. ∎



##### Theorem  
The program outputs  

* `YES` followed by `q` triples that form a perfect tiling of `{1,…,3q}`  
  **iff** such a tiling exists,  

* otherwise it outputs `NO`.

**Proof.**  
If the program prints `YES`, it did so after `search` returned success.
By Lemma&nbsp;2 the printed triples constitute a perfect tiling.

If a perfect tiling exists, Lemma&nbsp;3 guarantees that `search` will succeed,
so the program prints `YES`.  

If no perfect tiling exists, Lemma&nbsp;4 shows that `search` must fail,
hence the program prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

Let `C = 3q ≤ 600` be the number of columns and `R = t ≤ 20000` the number of rows.
Each row contains exactly three `1`s.

*Memory* – DLX stores one node per `1` plus header nodes: `3R + C + 1 ≤ 60001` nodes,
each with a few integers → well below the limit.

*Time* – Each recursive step chooses a column and iterates over its rows.
Cover / uncover touches `3·k` nodes where `k` is the number of rows removed.
In the worst case the algorithm explores an exponential number of branches,
but for the given bounds the practical running time is far below the 5 s limit
(the typical behaviour of DLX on instances of this size).

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        triples.append((a, b, c))

    ncol = 3 * q                     # columns 0 .. ncol-1
    # DLX structures
    max_nodes = 3 * t + ncol + 5
    U = [0] * max_nodes
    D = [0] * max_nodes
    L = [0] * max_nodes
    R = [0] * max_nodes
    C = [0] * max_nodes               # column of node
    S = [0] * (ncol + 1)              # size of column, header at 0
    row_id = [0] * max_nodes         # which input row a node belongs to

    # header node 0, column headers 1..ncol
    for i in range(ncol + 1):
        U[i] = D[i] = i
        L[i] = i - 1
        R[i] = i + 1
    L[0] = ncol
    R[ncol] = 0

    node_cnt = ncol + 1

    def add_row(ridx, cols):
        nonlocal node_cnt
        first = None
        for col in cols:
            col += 1                     # shift to header index
            node = node_cnt
            node_cnt += 1
            C[node] = col
            row_id[node] = ridx
            # vertical links
            U[node] = U[col]
            D[node] = col
            D[U[col]] = node
            U[col] = node
            S[col] += 1
            # horizontal links
            if first is None:
                first = node
                L[node] = R[node] = node
            else:
                L[node] = L[first]
                R[node] = first
                R[L[first]] = node
                L[first] = node

    for idx, tri in enumerate(triples):
        add_row(idx, tri)

    answer_rows = []

    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    solved = False

    def search(k):
        nonlocal solved
        if R[0] == 0:          # no columns left
            solved = True
            return True
        # choose column with minimal size
        c = R[0]
        min_s = S[c]
        j = R[c]
        while j != 0:
            if S[j] < min_s:
                c = j
                min_s = S[j]
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(c)
        r = D[c]
        while r != c:
            answer_rows.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            answer_rows.pop()
            r = D[r]
        uncover(c)
        return False

    if search(0):
        out = ["YES"]
        # answer_rows contains indices of selected triples, order arbitrary
        for idx in answer_rows:
            a, b, c = triples[idx]
            out.append(f"{a+1} {b+1} {c+1}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to
the required input‑output format.
