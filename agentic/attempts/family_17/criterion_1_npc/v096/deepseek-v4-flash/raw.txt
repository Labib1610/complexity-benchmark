We can model this as a matching problem. Each agent must be in exactly one team, and each team uses exactly 3 agents. Since the number of agents is `3q`, we need exactly `q` teams.

A direct brute force over all combinations is impossible. But the constraints and the special structure (IDs from 1 to 3q, teams of size 3) allow a greedy or matching approach.

We can treat it as a 3-dimensional matching problem, which is NP-hard in general, but here the structure is special: the teams are given, and we need to select exactly `q` disjoint triples covering all agents.

A practical approach:  
- Use a backtracking with pruning, or  
- Use a maximum matching in a hypergraph (3-uniform) — but that's hard.  
- Since `q ≤ 200`, we can try a greedy + backtracking with bitmask for small q, but 600 agents is too large for bitmask.

Better: We can model as a flow problem? Not directly.

Given the constraints, a common trick:  
We can sort teams and try to assign agents in increasing order. Since each agent must be used exactly once, we can do a recursive search with pruning: pick the smallest unused agent, try all teams containing it, and recurse.

Because each team has exactly 3 agents, and we need to cover all, the search space is manageable if we prune well.

Let's implement a backtracking with:
- Keep a list of teams.
- Keep an array `used` for agents.
- Recursively pick the smallest unused agent, try all teams containing it, and recurse.

We'll also precompute for each agent the list of teams containing it.

Complexity: In worst case, t=20000, but the search will be fast because we always pick the smallest unused agent, and each team has 3 agents, so branching is limited.

Let's code it.

```python
import sys
sys.setrecursionlimit(1000000)

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    teams = []
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        teams.append((a,b,c))
    
    # Precompute teams per agent
    agent_teams = [[] for _ in range(3*q+1)]
    for idx, (a,b,c) in enumerate(teams):
        agent_teams[a].append(idx)
        agent_teams[b].append(idx)
        agent_teams[c].append(idx)
    
    used = [False]*(3*q+1)
    chosen = []
    
    def backtrack(count):
        if count == q:
            return True
        # find smallest unused agent
        first = 1
        while first <= 3*q and used[first]:
            first += 1
        if first > 3*q:
            return False
        # try teams containing first
        for tidx in agent_teams[first]:
            a,b,c = teams[tidx]
            if used[a] or used[b] or used[c]:
                continue
            # use this team
            used[a] = used[b] = used[c] = True
            chosen.append((a,b,c))
            if backtrack(count+1):
                return True
            chosen.pop()
            used[a] = used[b] = used[c] = False
        return False
    
    if backtrack(0):
        print("YES")
        for a,b,c in chosen:
            print(a,b,c)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
