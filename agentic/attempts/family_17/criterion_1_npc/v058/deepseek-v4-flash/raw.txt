We need to determine if we can partition the set {1, 2, …, 3q} into q triples, each triple being one of the given certified records.

This is essentially a **3-dimensional matching** problem, which is NP-hard in general. However, the constraints are small enough (q ≤ 200, t ≤ 20000) that we can use a backtracking approach with pruning.

We can model it as:  
- We have 3q items.  
- We have t possible triples.  
- We need to select q disjoint triples covering all items.

A standard approach is to use **recursive backtracking** with bitmask or boolean arrays to track used items. Since q ≤ 200, we can use a boolean array of size 3q+1.

We can also sort triples or use heuristics to speed up.

Here’s the plan:

1. Read q, t.
2. Store triples in a list.
3. Use a boolean array `used` of size 3q+1.
4. Recursively try to pick triples:
   - Find the first unused person (smallest index).
   - Try all triples that contain that person and whose other two members are unused.
   - If we find a full cover, output YES and the triples.
5. If no solution, output NO.

We must be careful with recursion depth: q ≤ 200, so depth ≤ 200, which is fine.

We also need to output the triples in any valid order.

Let’s implement it.

```python
import sys

def solve():
    input = sys.stdin.readline
    q, t = map(int, input().split())
    triples = []
    for _ in range(t):
        a, b, c = map(int, input().split())
        triples.append((a, b, c))
    
    # Sort triples by first element for better pruning
    triples.sort()
    
    used = [False] * (3*q + 1)
    chosen = []
    
    # Precompute for each person the list of triples containing them
    by_person = [[] for _ in range(3*q + 1)]
    for idx, (a, b, c) in enumerate(triples):
        by_person[a].append(idx)
        by_person[b].append(idx)
        by_person[c].append(idx)
    
    def backtrack(count):
        if count == q:
            return True
        # Find first unused person
        first = 1
        while first <= 3*q and used[first]:
            first += 1
        if first > 3*q:
            return False
        
        # Try triples containing first
        for idx in by_person[first]:
            a, b, c = triples[idx]
            if not used[a] and not used[b] and not used[c]:
                used[a] = used[b] = used[c] = True
                chosen.append((a, b, c))
                if backtrack(count + 1):
                    return True
                chosen.pop()
                used[a] = used[b] = used[c] = False
        return False
    
    if backtrack(0):
        print("YES")
        for a, b, c in chosen:
            print(a, b, c)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
