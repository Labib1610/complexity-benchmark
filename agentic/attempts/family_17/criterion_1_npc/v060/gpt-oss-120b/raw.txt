**Solution Explanation**

The problem asks for an exact cover of the set `{1,…,3q}` by `q` triples taken from a given list.
It is exactly the *exact cover* problem for a 3‑uniform hypergraph.
The classic algorithm for this problem is **Algorithm X** (Donald Knuth) together with the
*Dancing Links* data structure (DLX).  
The constraints are modest (`3q ≤ 600`, `t ≤ 20000`, `q ≤ 200`), therefore a well‑implemented DLX
search finishes easily within the limits.

--------------------------------------------------------------------

#### 1.   Model as an exact‑cover matrix  

* columns : one column for each fragment `1 … 3q` (total `n = 3q` columns)  
* rows    : one row for each catalogued triple `{a,b,c}` – the row has a `1` in the three
  columns `a,b,c` and `0` elsewhere.

Finding `q` rows that cover every column exactly once is precisely the required
assembly.

--------------------------------------------------------------------

#### 2.   Dancing Links (DLX)

DLX stores the sparse 0/1 matrix as a doubly linked structure.
For every `1` we keep four pointers (`U,D,L,R`) and the column header it belongs to.
Additionally each column header stores the current number of `1`s in the column
(`size`) – this is used for the heuristic *choose the column with the smallest size*.

Operations needed:

* **cover(c)** – removes column `c` and all rows that contain a `1` in `c`
  from the matrix (by unlinking the corresponding nodes).
* **uncover(c)** – restores everything removed by the last `cover(c)`.
* **search(k)** – recursive backtracking:
  * if no columns remain → all fragments are covered → success.
  * choose column `c` with minimal `size`.
  * for each row `r` that contains a `1` in `c`
        * add `r` to the partial solution,
        * cover all other columns of `r`,
        * recurse,
        * on backtrack uncover them again.

Because each row has exactly three `1`s, the recursion depth never exceeds `q ≤ 200`.

--------------------------------------------------------------------

#### 3.   Implementation details

* Nodes are stored in plain Python lists (`U`, `D`, `L`, `R`, `C`) indexed by integers.
  Index `0` is the special header node whose right links iterate over the remaining columns.
* For each row we remember the list of its three column numbers – needed to output the answer.
* The search stops at the first complete solution (any solution is acceptable).
* Recursion limit is increased (`sys.setrecursionlimit(10000)`) to be safe.

Complexities  

*Memory* – one node per `1` (three per row) → `O(t)` ≤ 60 000 nodes, well inside limits.  
*Time* – worst‑case exponential (the problem is NP‑complete), but with the
minimum‑column heuristic DLX solves all test data quickly; typical running time
is far below the 5 s limit.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct set of triples
iff such a set exists.

---

##### Lemma 1  
During the execution of `search`, the matrix represented by the DLX structure
contains exactly the rows and columns that are still *available* (i.e. not yet
chosen and not yet covered).

**Proof.**  
`cover(c)` removes column `c` and every row that has a `1` in `c`.  
All those rows are impossible to use later because column `c` is already covered.
`uncover(c)` restores exactly the nodes removed by the matching `cover(c)`.  
Thus after any sequence of `cover`/`uncover` calls the structure represents precisely
the set of rows/columns that have not been eliminated. ∎



##### Lemma 2  
When `search` reaches the state “no columns left”, the rows stored in the
solution list form a collection of triples that covers each fragment exactly once.

**Proof.**  
If no columns remain, every original column has been covered by some `cover`
operation. A column is covered only when a row containing it is selected
(and all its other columns are subsequently covered). Because a column is
removed from the matrix after the first such covering, it can never be covered
again. Hence each fragment appears in exactly one selected row. ∎



##### Lemma 3  
If there exists a set `S` of `q` catalogued triples covering all fragments,
`search` will eventually find a solution.

**Proof.**  
Consider the execution tree of `search`.  
At each recursive call a column `c` is chosen. Since `S` covers all columns,
some row `r ∈ S` contains `c`. The algorithm iterates over **all** rows that
contain `c`; therefore the branch that picks this particular `r` is explored.
After picking `r`, all columns of `r` are covered, exactly matching the effect
of adding `r` to `S`. Repeating the argument, the recursion can follow the
sequence of rows of `S` and never gets pruned, because every step respects the
remaining uncovered columns. Consequently the leaf where all columns are gone
(and thus the solution `S`) is reached. ∎



##### Lemma 4  
If `search` reports failure (returns `False`), no exact cover exists.

**Proof.**  
Assume an exact cover `S` existed. By Lemma&nbsp;3 the recursive search would have a
branch that selects exactly the rows of `S` and reaches the “no columns left”
state, which returns success. Therefore the algorithm could not return failure.
Contradiction. ∎



##### Theorem  
The program outputs  

* `YES` followed by `q` triples that partition `{1,…,3q}` **iff**
  such a partition exists in the input catalog; otherwise it outputs `NO`.

**Proof.**  

*If the program prints `YES`*: it did so after `search` succeeded.
By Lemma&nbsp;2 the printed rows form a partition, hence a valid solution exists.

*If a valid solution exists*: by Lemma&nbsp;3 `search` will find one,
so the program prints `YES`.  

If no solution exists, Lemma&nbsp;4 shows `search` cannot succeed,
hence the program prints `NO`. ∎

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    n = 3 * q                     # number of columns
    rows = []                     # list of triples (as tuple)
    # DLX structures
    max_nodes = t * 3 + n + 1     # + header
    U = [0] * max_nodes
    D = [0] * max_nodes
    L = [0] * max_nodes
    R = [0] * max_nodes
    C = [0] * max_nodes           # column of node
    S = [0] * (n + 1)             # size of column (header 0 unused)
    # column headers are 1..n, header node is 0
    for i in range(n + 1):
        U[i] = D[i] = i
        L[i] = i - 1
        R[i] = i + 1
    L[0] = n
    R[n] = 0

    node_cnt = n + 1  # next free index

    # add a row (list of columns)
    def add_row(cols, row_id):
        nonlocal node_cnt
        first = None
        for col in cols:
            nd = node_cnt
            node_cnt += 1
            C[nd] = col
            # vertical links
            U[nd] = U[col]
            D[nd] = col
            D[U[col]] = nd
            U[col] = nd
            S[col] += 1
            # horizontal links
            if first is None:
                first = nd
                L[nd] = R[nd] = nd
            else:
                L[nd] = L[first]
                R[nd] = first
                R[L[first]] = nd
                L[first] = nd
        # store row id in first node (optional)
        # we can map node -> row later via a separate array if needed
        row_of_node[first] = row_id

    row_of_node = {}

    for idx in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        rows.append((a, b, c))
        add_row([a, b, c], idx)

    solution = []

    sys.setrecursionlimit(10000)

    def cover(col):
        # remove column header
        R[L[col]] = R[col]
        L[R[col]] = L[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        R[L[col]] = col
        L[R[col]] = col

    found = False

    def search(k):
        nonlocal found
        if R[0] == 0:          # no columns left
            found = True
            return True
        # choose column with minimal size
        c = R[0]
        min_s = S[c]
        j = R[c]
        while j != 0:
            if S[j] < min_s:
                c = j
                min_s = S[j]
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(c)
        r = D[c]
        while r != c:
            solution.append(row_of_node[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution.pop()
            r = D[r]
        uncover(c)
        return False

    if search(0):
        out = ["YES"]
        for rid in solution:
            a, b, c = rows[rid]
            out.append(f"{a} {b} {c}")
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to the required input‑output format.
