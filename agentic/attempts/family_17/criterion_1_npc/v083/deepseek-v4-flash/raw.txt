We need to select exactly \( q \) triples from the given configurations such that every part from 1 to \( 3q \) appears exactly once.  

This is essentially a **3-dimensional matching** problem, which is NP-hard in general. However, here \( q \le 200 \), so \( 3q \le 600 \), and \( t \le 20000 \). We can model it as a **maximum matching in a 3-partite hypergraph** and solve it using **maximum flow** by converting each triple into a flow path.

We can build a flow network:

- Source → each part on the left side (capacity 1)
- Each left part → each middle part if they appear together in some triple (capacity 1)
- Each middle part → each right part if they appear together in some triple (capacity 1)
- Each right part → sink (capacity 1)

But this doesn’t enforce that the three parts come from the same triple.  
To enforce that, we can create a node for each triple, and connect:

- Source → each part (left) with capacity 1
- Each part → triple node if part is in that triple (capacity 1)
- Triple node → sink with capacity 1

Then we need to select exactly \( q \) triples, each using 3 distinct parts.  
But this flow model would allow a triple to be chosen even if only one part is used, which is wrong.

Better approach:  
We can use **maximum bipartite matching** repeatedly:  
- First match each part to a triple (each triple can be used at most once).  
- Then check if all parts are matched.

But that’s not enough because a triple must contain exactly 3 parts, and we need all 3 to be matched to that triple.

We can solve it with **maximum flow** where each triple node has capacity 1, and each part node has capacity 1, and edges from part to triple if part is in triple.  
Then we need to check if we can send \( 3q \) units of flow from source to sink, with each triple node capacity 1 and each part node capacity 1.

That works:  
- Source → each part (capacity 1)  
- Each part → each triple that contains it (capacity 1)  
- Each triple → sink (capacity 1)  

If max flow = \( 3q \), then we have a perfect matching of parts to triples, and since each triple has capacity 1, it can be used only once.  
But we also need each triple to have exactly 3 parts assigned. Since each part has capacity 1 and each triple capacity 1, if we send 3q flow, each triple used will have exactly 3 parts assigned (because each triple can take at most 1 flow from each part, and total flow through triple = number of parts assigned to it). Since total flow = 3q and there are q triples used, each must have exactly 3.

So we can solve with max flow.

Implementation details:
- Number of nodes: parts (3q) + triples (t) + source + sink.
- Edges:  
  - source → part i (cap 1)  
  - part i → triple j if i in triple j (cap 1)  
  - triple j → sink (cap 1)

We run Dinic’s algorithm.  
If max flow == 3q, we output YES and the triples that have flow > 0.

Let’s code it.

```python
import sys
from collections import deque

class Dinic:
    def __init__(self, n):
        self.n = n
        self.adj = [[] for _ in range(n)]
    
    def add_edge(self, u, v, cap):
        self.adj[u].append([v, cap, len(self.adj[v])])
        self.adj[v].append([u, 0, len(self.adj[u]) - 1])
    
    def bfs(self, s, t):
        self.level = [-1] * self.n
        q = deque()
        q.append(s)
        self.level[s] = 0
        while q:
            u = q.popleft()
            for v, cap, rev in self.adj[u]:
                if cap > 0 and self.level[v] == -1:
                    self.level[v] = self.level[u] + 1
                    q.append(v)
        return self.level[t] != -1
    
    def dfs(self, u, t, f):
        if u == t:
            return f
        for i in range(self.it[u], len(self.adj[u])):
            self.it[u] = i
            v, cap, rev = self.adj[u][i]
            if cap > 0 and self.level[v] == self.level[u] + 1:
                ret = self.dfs(v, t, min(f, cap))
                if ret:
                    self.adj[u][i][1] -= ret
                    self.adj[v][rev][1] += ret
                    return ret
        return 0
    
    def max_flow(self, s, t):
        flow = 0
        INF = 10**9
        while self.bfs(s, t):
            self.it = [0] * self.n
            while True:
                f = self.dfs(s, t, INF)
                if not f:
                    break
                flow += f
        return flow

def main():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    q = int(input_data[0])
    t = int(input_data[1])
    triples = []
    idx = 2
    for _ in range(t):
        a = int(input_data[idx]); b = int(input_data[idx+1]); c = int(input_data[idx+2])
        idx += 3
        triples.append((a, b, c))
    
    n_parts = 3 * q
    # nodes: 0..n_parts-1 parts, n_parts..n_parts+t-1 triples, n_parts+t source, n_parts+t+1 sink
    source = n_parts + t
    sink = n_parts + t + 1
    dinic = Dinic(n_parts + t + 2)
    
    for i in range(1, n_parts + 1):
        dinic.add_edge(source, i - 1, 1)
    
    for j, (a, b, c) in enumerate(triples):
        triple_node = n_parts + j
        dinic.add_edge(a - 1, triple_node, 1)
        dinic.add_edge(b - 1, triple_node, 1)
        dinic.add_edge(c - 1, triple_node, 1)
        dinic.add_edge(triple_node, sink, 1)
    
    flow = dinic.max_flow(source, sink)
    if flow != n_parts:
        print("NO")
        return
    
    print("YES")
    # Find which triples are used
    used = []
    for j, (a, b, c) in enumerate(triples):
        triple_node = n_parts + j
        # Check if edge triple_node -> sink has flow 0 (meaning used)
        for v, cap, rev in dinic.adj[triple_node]:
            if v == sink and cap == 0:
                used.append((a, b, c))
                break
    for triple in used:
        print(*triple)

if __name__ == "__main__":
    main()
```
