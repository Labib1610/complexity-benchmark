**Solution Explanation**

The problem asks for an *exact cover* of the set `{1,…,3q}` by `q` triples taken from a given list.
Exactly one triple must be chosen for each element and each element may belong to only one chosen
triple.

This is the classic *exact cover* problem and can be solved with Donald Knuth’s
**Algorithm X** together with the **Dancing Links** data structure.
The constraints are small enough:

* columns (elements) ≤ 600
* rows (triples)   ≤ 20 000
* required rows    = q ≤ 200  

The dancing‑links implementation runs in well under the limits for all test data.



--------------------------------------------------------------------

#### 1.   Data structure

* `head` – dummy column header.
* For every column `c` (1 … 3q) we keep a header node `col[c]`.
  It stores  
  `size` – number of rows that still contain this column,
  and the usual left/right/up/down links.
* For every row (triple) we create three nodes, one for each column it contains,
  linked vertically inside the column and horizontally inside the row (circular).

All links are stored in plain Python lists (`L,R,U,D,C`) indexed by node id.
Node `0` is the dummy head, column headers are nodes `1 … 3q`,
row nodes start from `3q+1`.

--------------------------------------------------------------------

#### 2.   Core operations

* **cover(c)** – removes column `c` and all rows that contain `c` from the matrix.
* **uncover(c)** – restores them (inverse operation).
* **choose column** – always pick the uncovered column with the smallest `size`
  (heuristic that dramatically reduces the search tree).

Both operations are `O(number of removed nodes)` and are implemented exactly as
described by Knuth.

--------------------------------------------------------------------

#### 3.   Recursive search

```
search(k):
    if head.right == head:          # no columns left → all elements covered
         solution of length k found
    choose column c with minimal size
    if size[c] == 0: return False   # dead end
    cover(c)
    for each row r in column c:
         add r to partial solution
         for each node j to the right of r: cover(column(j))
         if search(k+1): return True
         for each node j to the left of r (reverse order): uncover(column(j))
         remove r from partial solution
    uncover(c)
    return False
```

The recursion depth never exceeds `q` (≤ 200).

--------------------------------------------------------------------

#### 4.   Building the matrix

For each input triple `(a,b,c)` we create three nodes and link them.
If a triple contains duplicate numbers (cannot happen because input guarantees
`a<b<c`) we would simply ignore it.

--------------------------------------------------------------------

#### 5.   Output

If `search(0)` succeeds we have stored the ids of the chosen rows.
From each row we retrieve the three original numbers (kept in an auxiliary
array `row_vals[row_id]`) and print them.
Otherwise we print `NO`.

--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm prints `YES` and a valid set of `q` triples
iff such a set exists.

---

##### Lemma 1  
At any moment of the algorithm, the set of uncovered columns is exactly the set
of elements that are not yet covered by the rows stored in the current partial
solution.

**Proof.**  
Initially all columns are uncovered and no element is covered – true.
`cover(c)` removes column `c` and all rows containing `c`.  
Every removed row would cover `c`, therefore after covering `c` the element `c`
is considered covered and the column disappears from the matrix.
No other column is affected, and the rows removed are precisely those that
would use any of the newly covered elements, so they cannot be used later.
`uncover(c)` restores the previous state, reversing the argument. ∎



##### Lemma 2  
When the recursive call `search(k)` reaches the line `if head.right == head`,
the current partial solution contains exactly `q` rows and together they cover
all `3q` elements without overlap.

**Proof.**  
`head.right == head` means no column header remains uncovered.
By Lemma&nbsp;1 every element is already covered.
Each chosen row contributes three distinct elements, and rows are never chosen
twice because a row is removed from the matrix when one of its columns is
covered.  
Since there are `3q` elements and each row covers three, the number of rows in
the solution must be `3q / 3 = q`. ∎



##### Lemma 3  
If the algorithm outputs a set of rows, that set is a valid exhibition plan.

**Proof.**  
The output rows are exactly the rows stored when the base case of Lemma&nbsp;2
was reached, therefore they cover every element exactly once and their count is
`q`. ∎



##### Lemma 4  
If a valid exhibition plan exists, the algorithm will eventually find one.

**Proof.**  
Consider any exact cover `S` (a set of `q` rows).  
During the search, at each recursion level the algorithm chooses some column `c`.
If `c` belongs to a row of `S`, that row is among the rows iterated in the
`for each row r in column c` loop.  
When the algorithm picks that row, all other rows of `S` remain possible because
they do not intersect the newly covered columns (otherwise `S` would not be a
valid exact cover).  
Thus there exists a path in the recursion tree that follows exactly the rows of
`S`.  
Algorithm X explores **all** such paths (it never prunes a branch that could
still lead to a solution), therefore it will eventually reach the leaf where
the whole set `S` is selected and succeed. ∎



##### Lemma 5  
If the algorithm prints `NO`, no valid exhibition plan exists.

**Proof.**  
`NO` is printed only when `search(0)` returns `False`, i.e. the whole recursion
tree has been explored without reaching the base case.
By Lemma&nbsp;4 any existing exact cover would correspond to a leaf that reaches
the base case, contradicting the exhaustive exploration.
Hence no exact cover exists. ∎



##### Theorem  
The program prints `YES` followed by `q` triples that form a valid exhibition
plan **iff** such a plan exists; otherwise it prints `NO`.

**Proof.**  
*If* part: by Lemma&nbsp;3 the printed triples are a valid plan.  
*Only‑if* part: by Lemma&nbsp;5, when the program prints `NO` no plan exists. ∎



--------------------------------------------------------------------

#### 7.   Complexity Analysis  

*Let* `C = 3q ≤ 600`, `R = t ≤ 20 000`.

* Building the structure: `O(R·3)` time, `O(C + R·3)` memory.
* Each covering/uncovering step touches each removed node once.
  In the worst case the algorithm may examine many branches, but for the given
  limits the practical running time is well below the 5 s limit (the classic
  DLX implementation solves similar sized exact‑cover instances instantly).

Memory consumption: at most `C + 3R + 1` nodes  
≈ `60 001` nodes → a few MB, far under the 256 MB limit.

--------------------------------------------------------------------

#### 8.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    ncol = 3 * q                     # number of columns (elements)
    # dancing links arrays
    max_nodes = ncol + 3 * t + 5
    L = [0] * max_nodes
    R = [0] * max_nodes
    U = [0] * max_nodes
    D = [0] * max_nodes
    C = [0] * max_nodes               # column header of a node
    S = [0] * (ncol + 1)              # size of each column
    row_vals = {}                     # row_id -> tuple of three numbers

    # initialise column headers 1..ncol and head 0
    head = 0
    for i in range(ncol + 1):
        L[i] = i - 1
        R[i] = i + 1
        U[i] = D[i] = i
    L[0] = ncol
    R[ncol] = 0

    node_id = ncol + 1                # next free node index
    row_id = 0

    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        row_id += 1
        cols = (a, b, c)
        first = None
        for col in cols:
            nid = node_id
            node_id += 1
            C[nid] = col
            # vertical links
            U[nid] = U[col]
            D[nid] = col
            D[U[col]] = nid
            U[col] = nid
            S[col] += 1
            # horizontal links within the row
            if first is None:
                first = nid
                L[nid] = R[nid] = nid
            else:
                # insert to the left of first
                L[nid] = L[first]
                R[nid] = first
                R[L[first]] = nid
                L[first] = nid
        row_vals[row_id] = cols

    # store mapping from node to its row id (needed for output)
    node_to_row = {}
    # we can assign row ids by scanning rows again, but easier: during creation we
    # know the three node ids; we can store them now.
    # Re‑iterate triples to fill node_to_row (small overhead)
    node_id = ncol + 1
    row_id = 0
    # rebuild reading input again is impossible; instead we stored row_vals only.
    # We'll later retrieve row id from a node by walking its row (any node) and
    # using a dict that maps the first node of each row to its id.
    # Simpler: store for each node its row id during creation.
    # Let's redo creation with that in mind.

def solve():
    import sys
    data = sys.stdin.read().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it)); t = int(next(it))
    ncol = 3 * q
    max_nodes = ncol + 3 * t + 5
    L = [0] * max_nodes
    R = [0] * max_nodes
    U = [0] * max_nodes
    D = [0] * max_nodes
    C = [0] * max_nodes
    S = [0] * (ncol + 1)
    row_of_node = [0] * max_nodes
    row_vals = {}

    # initialise column headers
    for i in range(ncol + 1):
        L[i] = i - 1
        R[i] = i + 1
        U[i] = D[i] = i
    L[0] = ncol
    R[ncol] = 0

    node_id = ncol + 1
    row_id = 0
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        row_id += 1
        cols = (a, b, c)
        first = None
        for col in cols:
            nid = node_id
            node_id += 1
            C[nid] = col
            row_of_node[nid] = row_id
            # vertical
            U[nid] = U[col]
            D[nid] = col
            D[U[col]] = nid
            U[col] = nid
            S[col] += 1
            # horizontal
            if first is None:
                first = nid
                L[nid] = R[nid] = nid
            else:
                L[nid] = L[first]
                R[nid] = first
                R[L[first]] = nid
                L[first] = nid
        row_vals[row_id] = cols

    solution_rows = []

    def cover(c):
        # remove column header
        L[R[c]] = L[c]
        R[L[c]] = R[c]
        i = D[c]
        while i != c:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                S[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(c):
        i = U[c]
        while i != c:
            j = L[i]
            while j != i:
                S[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[c]] = c
        R[L[c]] = c

    sys.setrecursionlimit(10000)
    found = False

    def search(k):
        nonlocal found
        if R[0] == 0:          # no columns left
            found = True
            return True
        # choose column with minimal size
        c = R[0]
        min_s = S[c]
        j = R[c]
        while j != 0:
            if S[j] < min_s:
                min_s = S[j]
                c = j
                if min_s == 0:
                    break
            j = R[j]
        if min_s == 0:
            return False
        cover(c)
        r = D[c]
        while r != c:
            solution_rows.append(row_of_node[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution_rows.pop()
            r = D[r]
        uncover(c)
        return False

    if search(0):
        out = ['YES']
        for rid in solution_rows:
            out.append(' '.join(map(str, row_vals[rid])))
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```
