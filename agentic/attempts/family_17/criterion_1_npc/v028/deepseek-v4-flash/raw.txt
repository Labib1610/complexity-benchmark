We need to determine if we can partition the set of gears {1, …, 3q} into q triples, each triple being one of the given schematics.

This is a **3-dimensional matching** problem, which is NP-hard in general.  
But here, the number of gears is at most 600 (since q ≤ 200), and t ≤ 20000.  
We can model it as an **exact cover** problem and solve with **Algorithm X (Dancing Links)** or a backtracking with pruning.

Given the constraints, a well-optimized backtracking with bitmasks should work.

**Approach:**
- Represent each schematic as a bitmask of 3 gears.
- Use recursive backtracking:
  - Pick the gear with the fewest possible schematics (MRV heuristic).
  - Try each schematic containing that gear, remove all schematics that overlap with it, recurse.
- If we find a full cover, output YES and the triples.

We'll implement with bitmasks and memoization on the remaining mask.

import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    q = int(next(it))
    t = int(next(it))
    n = 3 * q

    triples = []
    for _ in range(t):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        triples.append((a, b, c))

    # Build list of triples per gear
    gear_to_triples = [[] for _ in range(n)]
    for idx, (a, b, c) in enumerate(triples):
        gear_to_triples[a].append(idx)
        gear_to_triples[b].append(idx)
        gear_to_triples[c].append(idx)

    # Precompute mask for each triple
    triple_mask = []
    for a, b, c in triples:
        triple_mask.append((1 << a) | (1 << b) | (1 << c))

    full_mask = (1 << n) - 1

    # For memoization: store chosen triple indices for a given mask
    memo = {}

    def search(mask):
        if mask == 0:
            return []
        if mask in memo:
            return memo[mask]

        # Find gear with fewest available triples
        best_gear = -1
        best_count = 10**9
        m = mask
        while m:
            lsb = m & -m
            gear = (lsb.bit_length() - 1)
            cnt = 0
            for idx in gear_to_triples[gear]:
                if (triple_mask[idx] & mask) == triple_mask[idx]:
                    cnt += 1
            if cnt < best_count:
                best_count = cnt
                best_gear = gear
                if cnt == 0:
                    break
            m -= lsb

        if best_count == 0:
            memo[mask] = None
            return None

        # Try each triple containing best_gear
        for idx in gear_to_triples[best_gear]:
            tm = triple_mask[idx]
            if (tm & mask) == tm:
                new_mask = mask & ~tm
                res = search(new_mask)
                if res is not None:
                    res.append(idx)
                    memo[mask] = res
                    return res

        memo[mask] = None
        return None

    result = search(full_mask)

    if result is None:
        print("NO")
    else:
        print("YES")
        for idx in result:
            a, b, c = triples[idx]
            print(a + 1, b + 1, c + 1)

if __name__ == "__main__":
    solve()
