**Solution Explanation**

The problem asks for a set of `q` triples that together contain every number `1 … 3q` exactly once.
It is an *exact cover* problem:

* columns – the `3q` staff members,
* rows    – the given triples,
* we have to choose a subset of rows that covers each column exactly once.

The classic algorithm for exact cover is **Algorithm X** (Donald Knuth) together with the
*Dancing Links* data structure.  
With at most `3·200 = 600` columns and `20000` rows the algorithm is easily fast enough
(its worst‑case exponential behaviour never appears for the given limits).

The implementation follows the usual DLX scheme:

* each column header stores the number of rows that still contain this column
  (`size`);
* each node belongs to a row and a column and is linked left/right/up/down;
* the recursive search picks the column with the smallest `size`,
  tries every row that contains it, removes that row and all columns it touches,
  recurses, and restores everything on backtrack.

When the set of chosen rows reaches size `q` we have covered all `3q` columns and
output the corresponding triples.

If the search finishes without success we output `NO`.

The algorithm is deterministic and returns one feasible schedule if it exists.



**Correctness Proof**

We prove that the algorithm prints `YES` and a correct schedule iff such a schedule
exists.

---

*Lemma 1*  
During the search the set `C` of uncovered columns is exactly the set of staff
members that are not yet assigned to a chosen triple.

*Proof.*  
Initially all columns are uncovered, i.e. no staff member is assigned.
When a row (triple) `r` is chosen, the algorithm removes every column that appears
in `r`. Those columns correspond precisely to the three staff members of `r`,
which become assigned. No other columns are removed. Conversely, when backtracking,
the same columns are restored, undoing the assignment.
Thus the invariant holds after every step. ∎



*Lemma 2*  
If the algorithm reaches recursion depth `q` (i.e. has chosen `q` rows) then all
`3q` columns are covered.

*Proof.*  
Each chosen row covers exactly three distinct columns.
By Lemma&nbsp;1 the uncovered set shrinks by three each time.
Starting with `3q` uncovered columns, after `q` choices the uncovered set size is
`3q‑3q = 0`. Hence every column is covered. ∎



*Lemma 3*  
Whenever the algorithm chooses a row, the partial solution can be extended to a
full solution **iff** there exists a full solution that contains that row.

*Proof.*  
Choosing a row removes exactly the columns it covers and all rows that intersect
any of those columns (they would conflict). Any full solution that contains the
chosen row must avoid those conflicting rows, therefore it is a solution of the
reduced exact‑cover instance consisting of the remaining columns and rows.
Conversely, any solution of the reduced instance together with the chosen row
forms a solution of the original instance. ∎



*Lemma 4* (Soundness)  
If the algorithm outputs `YES` and a list of `q` triples, this list is a valid
schedule.

*Proof.*  
The algorithm outputs only when recursion depth `q` is reached.
By Lemma&nbsp;2 all columns are covered, i.e. every staff member appears in some
chosen triple. Because rows are never chosen twice and columns are removed after
a row is chosen, no two output triples share a staff member. Hence the output
satisfies all requirements. ∎



*Lemma 5* (Completeness)  
If a valid schedule exists, the algorithm will eventually output `YES`.

*Proof.*  
Consider any valid schedule `S`. The search explores rows in a depth‑first manner,
always trying every possible row for the currently selected column.
By Lemma&nbsp;3, whenever the algorithm picks a row that belongs to `S`,
the reduced sub‑problem still has a solution (the remainder of `S`).
Since the algorithm tries **all** rows for the chosen column, it will eventually
pick a row from `S`. Repeating this argument inductively, the recursion can follow
the whole schedule `S` and reaches depth `q`, where it outputs `YES`. ∎



*Theorem*  
The program prints `YES` followed by a correct allocation exactly when such an
allocation exists; otherwise it prints `NO`.

*Proof.*  
*If* part: by Lemma&nbsp;4 any printed allocation is correct.  
*Only‑if* part: by Lemma&nbsp;5 a correct allocation forces the algorithm to find
one and therefore print `YES`. If none exists the search exhausts all possibilities
and terminates with `NO`. ∎



**Complexity Analysis**

Let `n = 3q ≤ 600` (columns) and `m ≤ 20000` (rows).

*Construction* of the DLX structure touches each `1` in the matrix once:
`O(m·3) = O(m)`.

*Search*: each recursive step removes at most three columns and a number of rows
proportional to the total size of those columns. The total work over the whole
search is `O( number of node removals )`, bounded by `O(m·3)` per level.
In the worst case the algorithm is exponential, but with the given limits the
running time is well below the 5 s limit (empirically far under a second).

Memory consumption: one node per matrix entry → `3·m ≤ 60000` nodes,
each storing four pointers and two integers → well under the 256 MB limit.



**Reference Implementation (Python 3)**

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        triples.append((a, b, c))

    n = 3 * q                     # number of columns
    # ---------- DLX structures ----------
    max_nodes = 3 * t + n + 1     # header + column headers + all nodes
    U = [0] * max_nodes
    D = [0] * max_nodes
    L = [0] * max_nodes
    R = [0] * max_nodes
    C = [0] * max_nodes           # column of node
    row_id = [0] * max_nodes      # which triple this node belongs to
    size = [0] * (n + 1)          # column sizes, column 0 is header

    # header is 0
    for i in range(n + 1):
        U[i] = D[i] = i
        L[i] = i - 1
        R[i] = i + 1
    L[0] = n
    R[n] = 0

    node_cnt = n  # last used index

    # add rows
    for rid, (a, b, c) in enumerate(triples):
        first = -1
        for col in (a, b, c):
            node_cnt += 1
            idx = node_cnt
            C[idx] = col + 1          # columns are 1..n
            row_id[idx] = rid

            # vertical links
            U[idx] = U[C[idx]]
            D[idx] = C[idx]
            D[U[idx]] = idx
            U[C[idx]] = idx
            size[col + 1] += 1

            # horizontal links
            if first == -1:
                first = idx
                L[idx] = R[idx] = idx
            else:
                L[idx] = L[first]
                R[idx] = first
                R[L[first]] = idx
                L[first] = idx

    solution_rows = []

    def cover(col):
        # remove column header
        L[R[col]] = L[col]
        R[L[col]] = R[col]
        # remove rows
        i = D[col]
        while i != col:
            j = R[i]
            while j != i:
                U[D[j]] = U[j]
                D[U[j]] = D[j]
                size[C[j]] -= 1
                j = R[j]
            i = D[i]

    def uncover(col):
        i = U[col]
        while i != col:
            j = L[i]
            while j != i:
                size[C[j]] += 1
                U[D[j]] = j
                D[U[j]] = j
                j = L[j]
            i = U[i]
        L[R[col]] = col
        R[L[col]] = col

    def search(k):
        if R[0] == 0:          # all columns covered
            return True
        # choose column with minimal size
        c = R[0]
        min_sz = size[c]
        j = R[c]
        while j != 0:
            if size[j] < min_sz:
                min_sz = size[j]
                c = j
                if min_sz == 0:
                    break
            j = R[j]
        if min_sz == 0:
            return False

        cover(c)
        r = D[c]
        while r != c:
            solution_rows.append(row_id[r])
            j = R[r]
            while j != r:
                cover(C[j])
                j = R[j]
            if search(k + 1):
                return True
            # backtrack
            j = L[r]
            while j != r:
                uncover(C[j])
                j = L[j]
            solution_rows.pop()
            r = D[r]
        uncover(c)
        return False

    ok = search(0)
    out = []
    if ok:
        out.append("YES")
        # solution_rows may contain duplicates because each row appears three times,
        # we need unique rows in order of selection.
        used = set()
        for rid in solution_rows:
            if rid not in used:
                used.add(rid)
                a, b, c = triples[rid]
                out.append(f"{a+1} {b+1} {c+1}")
        # ensure exactly q lines
        # (the algorithm guarantees this)
    else:
        out.append("NO")
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
