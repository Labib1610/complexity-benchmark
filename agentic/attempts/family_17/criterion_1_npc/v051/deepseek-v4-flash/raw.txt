We need to determine if we can partition the set {1, 2, …, 3q} into q triples, each triple being one of the given safe triples. This is a 3-dimensional matching problem, which is NP-hard in general. However, q ≤ 200, so we need a clever approach.

We can model this as an exact cover problem. Since each element must be covered exactly once, and each triple covers 3 elements, we can use Algorithm X (Dancing Links) or a backtracking with pruning. With q up to 200, naive backtracking might be too slow, but we can use bitmask representation and recursion with heuristics.



Let’s implement a backtracking solver:

- Represent each triple as a bitmask of 3 bits (since 3q ≤ 600, we can use Python integers for bitmasks).
- Use a recursive function that picks an uncovered element with the fewest available triples covering it, then tries each such triple.

We also need to output the chosen triples. We can store the original indices.

Let’s write the code.```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    q = int(next(it))
    t = int(next(it))
    n = 3 * q
    triples = []
    for _ in range(t):
        a = int(next(it)) - 1
        b = int(next(it)) - 1
        c = int(next(it)) - 1
        triples.append((a, b, c))
    
    # Build list of triples covering each element
    cover = [[] for _ in range(n)]
    for idx, (a, b, c) in enumerate(triples):
        cover[a].append(idx)
        cover[b].append(idx)
        cover[c].append(idx)
    
    # Precompute bitmask for each triple
    masks = []
    for a, b, c in triples:
        masks.append((1 << a) | (1 << b) | (1 << c))
    
    # For each element, list of triple indices that cover it
    # We'll use a recursive backtracking with bitmask of used elements.

    
    full_mask = (1 << n) - 1
    used = 0
    chosen = []
    
    # To speed up, we can sort triples by size? Not needed.
 We'll use recursion.

    
    # We'll implement a recursive function that returns True if a solution is found.

    def dfs(used_mask, chosen_list):
        if used_mask == full_mask:
            return True
        # Find an uncovered element with fewest candidate triples
        best_elem = -1
        best_candidates = None
        # We can iterate over all elements, but that's O(n) each call.
 n ≤ 600, fine.

        # To speed up, we can precompute for each element the list of triples that cover it,
        # and filter by used_mask.
 But we can also just iterate over all elements and check if not used.

        # However, we can do better: pick the element with smallest number of available triples.

        # We'll compute candidates on the fly.

        for e in range(n):
            if not (used_mask >> e) & 1:
                cand = []
                for idx in cover[e]:
                    if (used_mask & masks[idx]) == 0:
                        cand.append(idx)
                if best_elem == -1 or len(cand) < len(best_candidates):
                    best_elem = e
                    best_candidates = cand
                    if len(cand) == 0:
                        return False
                    if len(cand) == 1:
                        break
        # Try each candidate triple
        for idx in best_candidates:
            new_mask = used_mask | masks[idx]
            chosen_list.append(idx)
            if dfs(new_mask, chosen_list):
                return True
            chosen_list.pop()
        return False
    
    if dfs(0, chosen):
        sys.stdout.write("YES\n")
        for idx in chosen:
            a, b, c = triples[idx]
            sys.stdout.write(f"{a+1} {b+1} {c+1}\n")
    else:
        sys.stdout.write("NO\n")

if __name__ == "__main__":
    solve()
