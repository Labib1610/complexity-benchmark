We need to select exactly q disjoint triples covering all 3q people.  
The constraints are tight: q up to 200, t up to 20000, and each triple has sum < 1800 and range < 600.  

A common approach for such exact cover problems is to use a matching or flow model.  
Since each person appears in at most one triple, we can model it as a 3-dimensional matching problem, which is NP-hard in general, but the constraints here allow a specialized approach.

We can use a **maximum matching in a hypergraph** via **backtracking with pruning** or **Dancing Links (Algorithm X)**.  
Given the constraints, we can try a recursive search with bitmask or set representation.

We’ll implement a backtracking solution:

- Represent each triple as a tuple.
- Keep a list of triples that contain each person.
- Use recursion: pick the person with the fewest available triples, try each triple containing that person, remove all triples that intersect it, and recurse.
- If we find q triples, output them.

We must be careful with performance: t up to 20000, but the constraints on sum and range limit the number of triples per person.

Let’s implement it.

```python
import sys
sys.setrecursionlimit(1000000)

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    q = int(next(it))
    t = int(next(it))
    triples = []
    for _ in range(t):
        a = int(next(it)); b = int(next(it)); c = int(next(it))
        triples.append((a, b, c))
    
    n = 3 * q
    # For each person, list of triple indices containing them
    person_to_triples = [[] for _ in range(n + 1)]
    for idx, (a, b, c) in enumerate(triples):
        person_to_triples[a].append(idx)
        person_to_triples[b].append(idx)
        person_to_triples[c].append(idx)
    
    used = [False] * t
    chosen = []
    
    # Precompute for each triple the set of people it covers
    triple_people = [set(tr) for tr in triples]
    
    # Recursive search
    def backtrack(remaining):
        if remaining == 0:
            return True
        # Find person with fewest available triples
        best_person = -1
        best_options = None
        for p in range(1, n + 1):
            # Check if p is already covered
            covered = False
            for tr_idx in chosen:
                if p in triple_people[tr_idx]:
                    covered = True
                    break
            if covered:
                continue
            options = [idx for idx in person_to_triples[p] if not used[idx]]
            if not options:
                return False
            if best_person == -1 or len(options) < len(best_options):
                best_person = p
                best_options = options
                if len(options) == 1:
                    break
        # Try each option
        for idx in best_options:
            # Mark used
            used[idx] = True
            chosen.append(idx)
            # Mark all triples that intersect this one as used temporarily
            # Actually we just check used flag, so we don't need to mark intersecting ones
            # But we need to ensure disjointness: we already check that when picking options
            # We'll just recurse
            if backtrack(remaining - 1):
                return True
            chosen.pop()
            used[idx] = False
        return False
    
    if backtrack(q):
        print("YES")
        for idx in chosen:
            a, b, c = triples[idx]
            print(a, b, c)
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
