The problem asks us to find the lexicographically smallest triple $(a, b, c)$ with $1 \le a < b < c \le n$ such that the pairs $(a, b)$, $(a, c)$, and $(b, c)$ are all in a given list of prohibited pairs. We are guaranteed that at least one such triple exists.

The constraints are $n \le 2000$ and $m \le 2 \cdot 10^5$. The time limit is 2 seconds.

Let's represent the prohibited pairs as a graph where each substance is a vertex and each prohibited pair is an edge. We are looking for a triangle (a clique of size 3) in this graph. Among all triangles, we need to find the one where the vertices $(a, b, c)$ sorted increasingly form the lexicographically smallest tuple.

Lexicographical comparison of $(a, b, c)$ and $(a', b', c')$ where $a < b < c$ and $a' < b' < c'$ means:
1. Minimize $a$.
2. If $a$ is same, minimize $b$.
3. If $a, b$ are same, minimize $c$.

So, we need to iterate through possible values of $a$, then $b$, then $c$, and stop at the first valid triangle we find.

Since $n$ is up to 2000, an $O(n^3)$ algorithm might be too slow. $2000^3 = 8 \cdot 10^9$, which is definitely too slow for 2 seconds.
However, we are looking for the *lexicographically smallest* triple. This suggests we can iterate in the order of priority.

The algorithm would look like this:
Iterate $a$ from $1$ to $n-2$.
  Iterate $b$ from $a+1$ to $n-1$.
    If $(a, b)$ is a prohibited pair (i.e., edge exists):
      Iterate $c$ from $b+1$ to $n$.
        If $(a, c)$ and $(b, c)$ are prohibited pairs:
          We found the answer $(a, b, c)$. Terminate.

To make this efficient, we need fast lookups for edges. A set of edges or an adjacency matrix could work.
Since $n \le 2000$, an adjacency matrix `adj[n+1][n+1]` is possible. The size would be $2000 \times 2000 \approx 4 \cdot 10^6$ booleans/ints. This fits easily in memory (256 MB).
Using an adjacency matrix allows $O(1)$ edge lookup.

import sys

# Increase recursion depth just in case, though not needed here
sys.setrecursionlimit(200000)

def solve():
    # Read all input from stdin
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency mask for fast intersection and checking
    # adj_mask[u] will have the v-th bit set if (u, v) is an edge
    adj_mask = [0] * (n + 1)
    
    # Adjacency list for iteration in order
    # adj_list[u] will store neighbors v such that v > u, sorted
    adj_list = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        
        # Update full adjacency mask
        adj_mask[u] |= (1 << v)
        adj_mask[v] |= (1 << u)
        
        # Update filtered adjacency list
        if u < v:
            adj_list[u].append(v)
        else:
            adj_list[v].append(u)
            
    # Sort adjacency lists to ensure we check b in increasing order
    # Since we only added v > u, these are valid candidates for b given a = u
    for i in range(1, n + 1):
        adj_list[i].sort()
        
    # Iterate to find the lexicographically smallest triple (a, b, c)
    # a < b < c
    # We iterate a from 1 to n.
    # For each a, we iterate b from adj_list[a] (which contains b > a sorted).
    # For each pair (a, b), we look for the smallest c > b that is a common neighbor.
    
    for a in range(1, n + 1):
        # Optimization: if adj_list[a] is empty, no neighbors > a
        if not adj_list[a]:
            continue
            
        for b in adj_list[a]:
            # We need to find smallest c > b such that (a, c) and (b, c) are edges.
            # This means c must be a common neighbor of a and b.
            # We use bitwise AND to find common neighbors.
            
            # common bits represent neighbors shared by a and b
            common = adj_mask[a] & adj_mask[b]
            
            # We only care about neighbors c > b.
            # We shift the common mask right by b + 1 to remove bits 0 to b.
            # The lowest set bit in the result corresponds to the smallest c > b.
            shifted = common >> (b + 1)
            
            if shifted > 0:
                # shifted > 0 implies there exists at least one common neighbor c > b.
                # We need the smallest such c.
                # The operation (shifted & -shifted) isolates the lowest set bit.
                # (shifted & -shifted).bit_length() gives the position of that bit + 1 (1-based index).
                # Since we shifted by b + 1, the bit position k in 'shifted' corresponds to bit b + 1 + k in 'common'.
                # The bit at index 0 in 'shifted' corresponds to c = b + 1.
                # bit_length() of 2^k is k + 1. So if lowest bit is at k, bit_length is k + 1.
                # Thus c = (bit_length - 1) + b + 1 = bit_length + b.
                
                c = (shifted & -shifted).bit_length() + b
                
                # Found the answer
                print(f"{a} {b} {c}")
                return

            # We need to find the smallest 'c' > b such that (a, c) and (b, c) are prohibited pairs.
            # This corresponds to finding the smallest bit set in the intersection of masks of a and b,
            # at a position greater than b.
            
            # Intersection of neighbors
            common = adj_mask[a] & adj_mask[b]
            
            # Shift right to ignore bits <= b
            # We want the smallest bit at index c > b.
            # In the shifted value, the bit at index 0 corresponds to c = b + 1.
            shifted = common >> (b + 1)
            
            if shifted > 0:
                # Find the position of the lowest set bit in 'shifted'
                # (shifted & -shifted) isolates the lowest set bit (as a power of 2)
                # .bit_length() returns the number of bits required to represent the integer
                # For a power of 2, say 2^k, bit_length is k + 1.
                # The bit index in 'shifted' is k.
                # So c = (b + 1) + k = b + 1 + (bit_length - 1) = b + bit_length
                c = (shifted & -shifted).bit_length() + b
                
                # Output the result and terminate
                print(f"{a} {b} {c}")
                return
