We can solve this by iterating through the chemicals in lexicographic order, checking each possible triple efficiently.  

Here’s the implementation:  

```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
edges = set()
adj = [set() for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    edges.add((u, v))
    edges.add((v, u))
    adj[u].add(v)
    adj[v].add(u)

for a in range(1, n + 1):
    for b in sorted(adj[a]):
        if b <= a:
            continue
        for c in sorted(adj[a] & adj[b]):
            if c <= b:
                continue
            if c in adj[a] and c in adj[b]:
                print(a, b, c)
                sys.exit()
```
