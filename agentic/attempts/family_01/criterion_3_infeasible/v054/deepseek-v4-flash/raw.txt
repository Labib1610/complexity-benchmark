We need to find a triangle (3 mutually connected vertices) in an undirected graph, with the lexicographically smallest triple.

A direct brute force over all triples would be too slow for \( n = 2000 \).  
We can instead iterate over each possible smallest vertex `a`, then over possible `b > a`, and check if there is a `c > b` connected to both.  
To make this efficient, we can store adjacency as sets for O(1) lookups.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
    
    for a in range(n):
        for b in adj[a]:
            if b <= a:
                continue
            # Find common neighbors > b
            common = adj[a] & adj[b]
            for c in sorted(common):
                if c > b:
                    print(a + 1, b + 1, c + 1)
                    return

if __name__ == "__main__":
    solve()
```
