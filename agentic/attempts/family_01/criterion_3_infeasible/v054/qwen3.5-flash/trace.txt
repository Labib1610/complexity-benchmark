The problem asks us to find the lexicographically smallest triplet $(a, b, c)$ such that $1 \le a < b < c \le n$ and the pairs $(a, b)$, $(b, c)$, and $(a, c)$ all exist in the given set of interference pairs. We are guaranteed that at least one such triplet exists.

The constraints are:
$n \le 2000$
$m \le \min(n(n-1)/2, 2 \cdot 10^5)$
Time limit: 2 seconds.

This is essentially finding the lexicographically smallest triangle in a graph with $n$ vertices and $m$ edges. The vertices are labeled $1$ to $n$.
Since we want the lexicographically smallest triplet $(a, b, c)$, we should iterate through possible values of $a$ from $1$ to $n$. For a fixed $a$, we want the smallest possible $b > a$, and then the smallest possible $c > b$.

A naive approach would be to iterate through all triplets $(a, b, c)$ with $a < b < c$ and check if they form a triangle. This would take $O(n^3)$ time, which is too slow for $n=2000$. $2000^3 = 8 \cdot 10^9$, well beyond the limit.

We can optimize by using the adjacency matrix or adjacency lists. Since $n$ is up to 2000, an adjacency matrix of booleans (or bitsets) would take $O(n^2)$ space, which is $4 \cdot 10^6$ bits/bytes, perfectly fine for 256MB.
Let's denote the adjacency matrix as `adj`, where `adj[u][v]` is true if $u$ and $v$ interfere.

To find the lexicographically smallest triangle $(a, b, c)$:
We can iterate $a$ from $1$ to $n$.
  For each $a$, we iterate $b$ from $a+1$ to $n$.
    If $(a, b)$ is an edge:
      We need to find the smallest $c > b$ such that $(a, c)$ is an edge and $(b, c)$ is an edge.
      This is equivalent to finding the smallest $c$ in the intersection of neighbors of $a$ and neighbors of $b$ that is greater than $b$.

If we store the neighbors of each vertex as a sorted list or a boolean array (adjacency matrix), finding such a $c$ is relatively fast.
Using an adjacency matrix `adj[n+1][n+1]`, checking if an edge exists is $O(1)$.
The loops would look like:
```python
for a in range(1, n + 1):
    for b in range(a + 1, n + 1):
        if not adj[a][b]: continue
        for c in range(b + 1, n + 1):
            if adj[a][c] and adj[b][c]:
                print(a, b, c)
                return
```
This is still $O(n^3)$ in the worst case (e.g., a complete graph). We need something faster.

```python
import sys

# Increase recursion depth just in case
sys.setrecursionlimit(2000)

def solve():
    # Read all input from stdin efficiently
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency masks
    # Using 1-based indexing for vertices, so size n+1
    # adj_mask[u] will have bit v set if u and v interfere
    adj_mask = [0] * (n + 1)
    
    # Adjacency lists for iteration
    # adj_list[u] will contain neighbors of u
    adj_list = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        
        adj_mask[u] |= (1 << v)
        adj_mask[v] |= (1 << u)
        
        adj_list[u].append(v)
        adj_list[v].append(u)
        
    # Sort adjacency lists to ensure we process neighbors in increasing order
    # This is crucial for finding the lexicographically smallest triplet
    for i in range(1, n + 1):
        adj_list[i].sort()
        
    # Iterate to find the lexicographically smallest triplet (a, b, c)
    # a < b < c
    # We iterate a from 1 to n
    # Then iterate b in neighbors of a such that b > a
    # Then find smallest c in neighbors of a such that c > b and c is neighbor of b
    
    for a in range(1, n + 1):
        # Optimization: if a has no neighbors, skip
        if not adj_list[a]:
            continue
            
        mask_a = adj_mask[a]
        
        for b in adj_list[a]:
            if b <= a:
                continue
            
            # We need a common neighbor c > b
            # common = adj_mask[a] & adj_mask[b]
            # We only care about bits > b
            
            mask_b = adj_mask[b]
            common = mask_a & mask_b
            
            # Clear bits 0..b from common to find c > b
            # -(1 << (b + 1)) has 0s at positions 0..b and 1s elsewhere
            # This effectively masks out bits <= b
            valid = common & -(1 << (b + 1))
            
            if valid:
                # Find the lowest set bit in valid
                # (valid & -valid) isolates the lowest set bit
                # bit_length() - 1 gives the index of that bit
                c = (valid & -valid).bit_length() - 1
                print(f"{a} {b} {c}")
                return

if __name__ == '__main__':
    solve()
```
