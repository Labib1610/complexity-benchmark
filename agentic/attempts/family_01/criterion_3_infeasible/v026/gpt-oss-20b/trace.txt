Lexicographic order: a<b<c. We can iterate a from 1..n, b from a+1..n, c from b+1..n. But that would be O(n^3)=8e9 impossible. Instead we can find triangles efficiently but also find smallest lexicographically.

Observation: Lexicographically smallest triangle means minimal a. So we can iterate a from 1..n. For each a, find all triangles involving a. Among those, we need minimal b and c. So for each a, we can consider neighbors of a. For each pair of neighbors (b,c) with b<c, check if edge between them exists. The minimal triangle with a will have minimal b; and for that b minimal c. Since we iterate a ascending, the first triangle found will be lexicographically smallest.

for a in range(1,n+1):
    neigh = [b for b in range(a+1,n+1) if adjacency[a][b]]
    # We'll iterate over pairs in order of b ascending, then c ascending
    # For each b index i, we can iterate j from i+1...
    for i in range(len(neigh)):
        b = neigh[i]
        # For c > b: we can iterate over neigh[j] where j>i
        # But we also need c > b; since neigh sorted ascending, j>i ensures c > b
        for j in range(i+1, len(neigh)):
            c = neigh[j]
            if adjacency[b][c]:
                print(a,b,c)
                return

Because we process a ascending, and within a we process b ascending due to neigh order, and c ascending due to j order, we guarantee lexicographic minimality.

import sys

def solve():
    import sys
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it))
    bitset = [0]*(n+1)
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        bitset[u] |= 1 << (v-1)
        bitset[v] |= 1 << (u-1)
    for a in range(1, n+1):
        for b in range(a+1, n+1):
            if (bitset[a] >> (b-1)) & 1:
                inter = bitset[a] & bitset[b]
                # find any bit > b
                mask = inter >> b  # shift right by b bits to drop bits 0..b-1
                if mask:
                    lsb = mask & -mask
                    offset = lsb.bit_length() - 1
                    c = b + 1 + offset
                    print(a, b, c)
                    return
    # Should never reach here due to guarantee
if __name__ == "__main__":
    solve()
