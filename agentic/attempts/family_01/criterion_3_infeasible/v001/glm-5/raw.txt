Looking at this problem, I need to find a triangle (3-clique) in an undirected graph and output the lexicographically smallest one.

**Approach:**
For each vertex `a` (from smallest to largest), I look at all its neighbors `b > a`. For each such `b`, I check if any neighbor `c` of `b` (where `c > b`) is also a neighbor of `a`. The first such triangle found is lexicographically smallest since we iterate `a` from smallest, then `b` from smallest, then `c` from smallest.

**Optimization:** To make the inner check fast, I use bitsets (Python integers) to represent neighbor sets. For each `a`, I precompute a bitset of neighbors greater than `a`. Then for each neighbor `b > a`, I AND `a`'s bitset with `b`'s bitset and find the lowest set bit, which gives the smallest valid `c`.

This gives O(n²/w) per vertex in the worst case, but with early termination it's efficient enough.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(data[idx]); idx += 1
    m = int(data[idx]); idx += 1
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(data[idx]); idx += 1
        v = int(data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    # Sort neighbors for each vertex
    for i in range(1, n + 1):
        adj[i].sort()
    
    # Build bitsets for neighbors > vertex
    bits = [0] * (n + 1)
    for i in range(1, n + 1):
        b = 0
        for nb in adj[i]:
            if nb > i:
                b |= (1 << nb)
        bits[i] = b
    
    for a in range(1, n + 1):
        a_bits = bits[a]
        if a_bits == 0:
            continue
        for b in adj[a]:
            if b < a:
                continue
            # c must be > b and neighbor of both a and b
            mask = a_bits & bits[b]
            # Clear bits <= b
            mask &= ~((1 << (b + 1)) - 1)
            if mask:
                c = (mask & -mask).bit_length() - 1
                print(f"{a} {b} {c}")
                return
    
    # Should not reach here per problem guarantee
    print("-1 -1 -1")

main()
```
