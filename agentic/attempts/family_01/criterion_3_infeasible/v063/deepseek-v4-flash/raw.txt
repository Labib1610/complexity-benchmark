We need to find a triangle in an undirected graph, with a specific tie-breaking rule:  
- Choose the triangle with the smallest first vertex, then smallest second, then smallest third.

Since \( n \leq 2000 \) and \( m \leq 2 \cdot 10^5 \), we can afford an \( O(n^2) \) approach if we are careful.

**Approach:**

1. Read the graph as an adjacency matrix (boolean) for fast lookups.
2. Iterate over all possible first vertices `a` from 1 to n.
3. For each `a`, iterate over all possible second vertices `b` > `a` that are connected to `a`.
4. For each such `b`, iterate over all possible third vertices `c` > `b` that are connected to both `a` and `b`.
5. The first such triple found in this order will be the lexicographically smallest triangle.

Since we iterate in increasing order of `a`, then `b`, then `c`, the first found is the required one.

**Complexity:**  
Worst case is \( O(n^3) \) if we naively loop all triples, but we can break early.  
With \( n=2000 \), \( n^3 \) is too large. But we can use adjacency lists to reduce.

We can do:
- For each `a`, for each `b` in adj[a] with b > a, for each `c` in adj[b] with c > b, check if `c` is in adj[a].  
This is still \( O(m \cdot \text{degree})\) but with m up to 2e5, it's fine.

Let's implement:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n+1)]
    adj_set = [set() for _ in range(n+1)]
    
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].append(v)
        adj[v].append(u)
        adj_set[u].add(v)
        adj_set[v].add(u)
    
    # Sort adjacency lists for deterministic order
    for i in range(1, n+1):
        adj[i].sort()
    
    # Search for triangle
    for a in range(1, n+1):
        for b in adj[a]:
            if b <= a:
                continue
            for c in adj[b]:
                if c <= b:
                    continue
                if c in adj_set[a]:
                    print(a, b, c)
                    return

if __name__ == "__main__":
    solve()
```
