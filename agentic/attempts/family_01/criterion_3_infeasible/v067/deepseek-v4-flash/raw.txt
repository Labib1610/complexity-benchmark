We can solve this by checking each camera in increasing order and looking for a triangle that includes it.  
Since we need the lexicographically smallest triangle, we iterate `a` from 1 to n, then `b` from `a+1` to n, and check if `c` exists such that all three edges are present.

We can use an adjacency matrix (or set) for O(1) edge lookups.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[False] * (n + 1) for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u][v] = adj[v][u] = True

    for a in range(1, n + 1):
        for b in range(a + 1, n + 1):
            if adj[a][b]:
                for c in range(b + 1, n + 1):
                    if adj[a][c] and adj[b][c]:
                        print(a, b, c)
                        return

if __name__ == "__main__":
    main()
```
