We need to find lexicographically smallest triangle in an undirected simple graph with up to n=2000, m up to 200k. Need efficient enumeration.

We can store adjacency lists and also adjacency bitsets to test existence quickly. Since n <= 2000, we can use bitset of 2000 bits, which fits in Python's int bit operations or use Python's built-in set. But bitset with ints: each node's adjacency represented as bitset of length n. Then triangle detection: iterate a from 1..n, for each neighbor b > a, we can compute intersection of adjacency[a] & adjacency[b] to find common neighbors c > b. We need lexicographically smallest triple (a,b,c). Since we iterate a increasing, then b increasing, then find minimal c. So algorithm:

- Build adjacency as list of int bitset. For node i, bitset has bit j-1 set if edge (i,j). Use 0-based indices.

- For a in 0..n-1:
    neighbors = adjacency[a]
    iterate b from a+1..n-1 where bit set in neighbors. For each such b:
        common = adjacency[a] & adjacency[b]
        # need c > b; we can mask off lower bits <= b.
        mask = common >> (b+1)  # shift right by b+1 bits so that bit 0 corresponds to node b+1
        if mask != 0:
            c = (b+1) + (mask.bit_length() - 1)  # find lowest set bit in mask? Actually mask.bit_length()-1 gives index of highest set bit, but we need lowest. Use (mask & -mask) gives lowest set bit.
            # compute lowest set bit index:
            lowbit = mask & -mask
            c = (b+1) + (lowbit.bit_length() -1)
            output a+1,b+1,c+1; exit.

But we need lexicographically smallest triple: for each a, we iterate b in increasing order. For each b, we find smallest c > b that is adjacent to both. Since we use lowest set bit, we get smallest c. So first found triangle will be lexicographically smallest.

- adjacency_bit = [0]*n
- adjacency_list = [[] for _ in range(n)]
- For each edge u,v: convert to 0-based. Set bit: adjacency_bit[u] |= 1 << v; adjacency_bit[v] |= 1 << u; adjacency_list[u].append(v); adjacency_list[v].append(u)
- After reading, sort each adjacency_list[u] ascending to allow iteration.

- For a in range(n):

        common = adjacency_bit[a] & adjacency_bit[b]
