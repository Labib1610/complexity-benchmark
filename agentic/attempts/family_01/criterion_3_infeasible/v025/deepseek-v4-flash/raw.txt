We can solve this by checking all triples in increasing order and stopping at the first valid triangle.  
Since \( n \leq 2000 \), a naive \( O(n^3) \) check would be too slow, but we can optimize using adjacency sets.

```python
import sys

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)

    for a in range(n):
        for b in range(a + 1, n):
            if b not in adj[a]:
                continue
            for c in range(b + 1, n):
                if c in adj[a] and c in adj[b]:
                    print(a + 1, b + 1, c + 1)
                    return

if __name__ == "__main__":
    main()
```
