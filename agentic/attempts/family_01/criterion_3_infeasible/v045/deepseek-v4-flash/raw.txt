We need to find a triangle in an undirected graph.  
The graph has up to 2000 nodes and 200,000 edges, so we need an efficient approach.

A simple approach:  
- For each edge (u, v), check if there is a common neighbor w such that (u, w) and (v, w) are edges.  
- To do this efficiently, we can store adjacency as sets for O(1) neighbor checks.  
- We iterate over edges, and for each edge, we check the smaller adjacency list to find common neighbors.  
- Since we need the lexicographically smallest triangle, we can sort the vertices and check in order.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [set() for _ in range(n)]
    edges = []
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].add(v)
        adj[v].add(u)
        edges.append((u, v))
    
    # Sort edges by vertex order for lexicographic smallest triangle
    edges.sort()
    
    for u, v in edges:
        # Check common neighbors
        # Iterate over smaller adjacency list
        if len(adj[u]) > len(adj[v]):
            u, v = v, u
        for w in adj[u]:
            if w in adj[v]:
                # Found triangle
                a, b, c = sorted([u, v, w])
                print(a+1, b+1, c+1)
                return
    print(-1)

if __name__ == "__main__":
    solve()
```
