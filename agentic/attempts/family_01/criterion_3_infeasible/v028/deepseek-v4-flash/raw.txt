We need to find the lexicographically smallest triangle (3-clique) in an undirected graph.  
Since \( n \leq 2000 \), we can use an adjacency matrix for \( O(1) \) edge checks and iterate over all triples in sorted order until we find the first triangle.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[False] * n for _ in range(n)]

for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u][v] = adj[v][u] = True

for a in range(n):
    for b in range(a + 1, n):
        if not adj[a][b]:
            continue
        for c in range(b + 1, n):
            if adj[a][c] and adj[b][c]:
                print(a + 1, b + 1, c + 1)
                exit()
```
