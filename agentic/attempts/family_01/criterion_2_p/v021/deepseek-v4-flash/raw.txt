We can model this as a bipartite graph problem: each field is a node, and each comparator is an edge requiring the two endpoints to have different values (1 or 2). This is exactly a 2-coloring problem. If the graph is not bipartite, output `NO`. Otherwise, we need the lexicographically smallest coloring.

To get the lexicographically smallest assignment, we can run BFS/DFS and assign colors greedily, starting with color 1 for the first uncolored node in each component, and propagate alternating colors. This ensures the smallest possible values at the earliest indices.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
