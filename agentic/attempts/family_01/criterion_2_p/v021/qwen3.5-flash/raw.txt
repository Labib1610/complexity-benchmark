The problem asks us to assign one of two channels (1 or 2) to each of $n$ nodes such that no two interfering nodes share the same channel. If multiple valid assignments exist, we need to find the one that is lexicographically smallest. If no valid assignment exists, we should output "NO".

This is a classic graph coloring problem. We have a graph where nodes are vertices and interference pairs are edges. We need to 2-color the graph. A graph is 2-colorable if and only if it is bipartite.

The lexicographically smallest requirement means we want the sequence $s_1, s_2, \dots, s_n$ to be as small as possible in dictionary order. Since $s_i \in \{1, 2\}$, we prefer $s_i = 1$ over $s_i = 2$. To achieve this, we generally want to set $s_1=1$, then $s_2=1$ if possible, and so on. However, the choice for $s_i$ might be constrained by previous choices or future constraints.

Let's consider the connected components of the graph. If the graph is not bipartite, no solution exists. If it is bipartite, for each connected component, there are exactly two possible ways to color it (assuming the component is non-empty). Let's say a component has vertices $V_c$. If we fix the color of one vertex $u \in V_c$ to be 1, the colors of all other vertices in $V_c$ are determined uniquely because it's a bipartite graph. Let's call this assignment $A_1$. If we fix the color of $u$ to be 2, the colors of all other vertices in $V_c$ are flipped relative to $A_1$. Let's call this assignment $A_2$.

To find the lexicographically smallest sequence, we can iterate from $i = 1$ to $n$. However, simply deciding $s_i$ greedily might be tricky because $s_i$ depends on the component it belongs to. If node $i$ is in a component where we haven't determined colors yet, we can choose to assign $s_i = 1$. This choice forces the colors of all other uncolored nodes in that component. If node $i$ is in a component where some nodes have already been colored (because they appeared earlier in our sequence or were processed), we must respect those colors.

We need to process nodes $1, \dots, n$.
We maintain an array `color` of size $n+1$, initialized to 0 (uncolored).

So, when we encounter an uncolored node $i$, we start a traversal (BFS or DFS) of its connected component. Since we want $s_i = 1$ (because $1 < 2$), we tentatively assign `color[i] = 1`. Then we propagate this assignment to all other nodes in the component. If during propagation we find a conflict (an edge connects two nodes of the same color), then the graph is not bipartite, so output "NO".
If there is no conflict, this component is colored. Since we forced `color[i] = 1`, and $s_i$ is the first node in this component (in terms of index order) to be encountered as uncolored, this is the best we can do for this component relative to the lexicographical requirement. If we chose `color[i] = 2`, then all colors in the component would be flipped. Since $i$ appears before any other uncolored node in this component, setting `color[i]=1` is strictly better than `color[i]=2` for the lexicographical order. def solve():

    input_data = sys.stdin.read().split()

        return

    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Build the graph adjacency list
    # Using 1-based indexing for nodes
    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
        
    # Array to store colors: 0 = uncolored, 1 = channel 1, 2 = channel 2
    color = [0] * (n + 1)
    
    # Iterate through each node to handle connected components
    # This ensures we process nodes in increasing order of index
    for i in range(1, n + 1):
        if color[i] == 0:
            # Node i is uncolored, so it's the start of a new component (or a new part of a component)
            # To achieve lexicographically smallest assignment, we assign channel 1 to the first node encountered.
            color[i] = 1
            q = deque([i])
            
            while q:
                u = q.popleft()
                current_color = color[u]
                next_color = 2 if current_color == 1 else 1
                
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = next_color
                        q.append(v)
                    elif color[v] == current_color:
                        # Conflict: adjacent nodes have the same color
                        print("NO")
                        return
    
    # If we reach here, a valid assignment exists
    print("YES")
    # Output the colors for nodes 1 to n
    # Using join for efficient string conversion and output
    print(' '.join(map(str, color[1:])))
