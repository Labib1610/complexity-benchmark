The problem asks us to assign one of two values (1 or 2) to each of $n$ units such that for $m$ given pairs $(u, v)$, the units $u$ and $v$ must have different values. If a valid assignment exists, we need to output "YES" and the assignment sequence that is lexicographically smallest. Otherwise, we output "NO".

This problem can be modeled as a graph problem. We have $n$ nodes (units) and $m$ edges (interference pairs). We want to check if the graph is bipartite (2-colorable). If it is bipartite, we need to find the lexicographically smallest coloring.

The condition "two units in any such pair must not be assigned the same operational setting" means if $u$ and $v$ are connected by an edge, $s_u \neq s_v$. This is the definition of a valid 2-coloring. Since the values are restricted to $\{1, 2\}$, this is exactly checking if the graph is bipartite.

The input size is up to $n, m \le 2 \cdot 10^5$. The time limit is 1 second. A standard BFS or DFS for bipartite checking runs in $O(n+m)$, which is well within the limits.

However, there is a specific requirement: the assignment must be the *lexicographically smallest*.
A lexicographically smallest sequence $(s_1, s_2, \dots, s_n)$ means we want $s_1$ to be as small as possible. If $s_1$ is fixed, we want $s_2$ to be as small as possible, and so on.
The values are 1 and 2. So we prefer 1 over 2.

Let's consider the connected components of the graph. Within a connected component, once the value of one node is fixed, the values of all other nodes in that component are determined (up to swapping 1 and 2). Since we want the lexicographically smallest sequence, we should process nodes in increasing order of their indices $1, \dots, n$.

```python
from collections import deque

def solve():

    if not input_data:

    iterator = iter(input_data)
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    adj = [[] for _ in range(n + 1)]

        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
```

```python
import sys
from collections import deque

def solve():
    # Read all input from stdin at once
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency list for the graph
    # Nodes are 1-indexed, so size n + 1
    adj = [[] for _ in range(n + 1)]
    
    # Parse m edges
    for _ in range(m):
        try:
            u = int(next(iterator))
            v = int(next(iterator))
            adj[u].append(v)
            adj[v].append(u)
        except StopIteration:
            break
            
    # Array to store the color/setting of each unit
    # 0 indicates unvisited
    colors = [0] * (n + 1)
    
    # We iterate from 1 to n.
    # This ensures that when we encounter an unvisited node i,
    # it is the smallest index in its connected component.
    # To achieve the lexicographically smallest assignment, we must assign setting 1 to this smallest index.
    # Since the graph is bipartite (if valid), setting 1 is always possible for the root.
    for i in range(1, n + 1):
        if colors[i] == 0:
            # Start BFS for the new component
            colors[i] = 1
            q = deque([i])
            
            while q:
                u = q.popleft()
                current_color = colors[u]
                next_color = 3 - current_color # 1 -> 2, 2 -> 1
                
                for v in adj[u]:
                    if colors[v] == 0:
                        colors[v] = next_color
                        q.append(v)
                    else:
                        if colors[v] != next_color:
                            # Conflict detected: adjacent nodes have the same color
                            print("NO")
                            return

    # If we successfully colored all components
    print("YES")
    # Output the assignment sequence
    # Using sys.stdout.write for potentially faster output
    sys.stdout.write(" ".join(map(str, colors[1:])) + "\n")

if __name__ == '__main__':
    solve()
```

Is it possible that within a component, there are multiple valid colorings?
For a connected bipartite graph, the 2-coloring is unique up to swapping colors (1 and 2).
So there are exactly 2 valid assignments for the component.
My logic compares these 2 assignments.
Let the two assignments be $C_1$ and $C_2$.
$C_2$ is obtained by swapping 1 and 2 in $C_1$.
Let $r$ be the smallest index in the component.
$C_1[r]$ is either 1 or 2.
If $C_1[r] = 1$, then $C_2[r] = 2$.
Comparing $C_1$ and $C_2$ lexicographically:
At index $r$, $C_1$ has 1, $C_2$ has 2.
So $C_1 < C_2$.
We choose the assignment where $C[r] = 1$.
Since we can always choose to start BFS with `colors[i] = 1` (where $i=r$), we effectively choose $C_1$ (if $C_1[r]=1$) or generate the assignment that has 1 at $r$.
Basically, starting BFS with color 1 at the root generates one of the two valid colorings.
Does it generate the one with 1 at root?
Yes, `colors[i] = 1`.
So we are explicitly choosing the assignment with 1 at the root.
Since 1 < 2, this is the lexicographically smaller of the two choices for this component.
And since components are independent, this greedy choice per component yields the global lexicographically smallest sequence.
Wait, independent components mean that the choice for component A does not affect validity of component B.
And the indices of A are disjoint from indices of B.
So the value at any index $k$ depends only on the choice for the component containing $k$.
To minimize the sequence $s_1, s_2, \dots, s_n$:
We look at $s_1$. It belongs to some component $C_1$.
We want to minimize $s_1$.
$s_1$ can be 1 or 2 (if valid).
If $s_1=1$ is possible (i.e. valid coloring exists), we must pick it.
If $s_1=1$ is not possible, we must pick 2.
But if valid coloring exists, we can always swap colors in $C_1$ to make $s_1=1$.
So we always pick $s_1=1$.
This fixes the coloring for $C_1$ (since $s_1$ is fixed, all other nodes in $C_1$ are fixed).
Then we look at $s_2$.
If 2 is in $C_1$, $s_2$ is already fixed.
If 2 is in $C_2$ (a different component), then $s_2$ is determined by choice for $C_2$.
We want to minimize $s_2$.
Again, if valid coloring exists, we can choose the one that sets $s_2=1$.
This logic holds for all $i$.
My algorithm iterates $i$ from 1 to $n$.
If $i$ is unvisited, it means $i$ is the first node of a new component we are seeing (since previous nodes $<i$ were either visited or in other components).
Wait, if $i$ is unvisited, it means no node $j < i$ was connected to $i$.
So $i$ is indeed the smallest index in its component.
So we set $s_i=1$. This minimizes $s_i$ for the component.
This matches the global greedy strategy.
