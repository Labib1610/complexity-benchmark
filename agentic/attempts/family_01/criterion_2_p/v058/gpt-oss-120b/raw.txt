**Solution Explanation**

For every recorded altercation we have an undirected edge  
`u – v`.  
The rule *“two workers that fought must be on different shifts”* means that
the whole graph has to be **bipartite** – every edge must connect vertices of
different colours (shifts).

If the graph is not bipartite there is no feasible assignment.

If it is bipartite, each connected component has exactly two possible
colourings – the two colour classes can be swapped.
We have to choose, for every component, which class receives shift **1**
and which receives shift **2** so that the whole sequence

```
s1 , s2 , … , sn          (si ∈ {1,2})
```

is lexicographically minimal.

--------------------------------------------------------------------

#### 1.   Lexicographically minimal choice

Consider one connected component `C`.  
Let `p = min(C)` – the smallest vertex index inside this component.
All vertices with index `< p` belong to other components, therefore their
shifts are already fixed when we decide about `C`.

*If we give shift 1 to vertex `p`, the value of `sp` becomes `1`,
the smallest possible value at the first still‑free position.
Any other decision would give `sp = 2` and would be lexicographically larger,
independently of all later positions.*

Hence the optimal rule is:

*For each component give shift 1 to the colour class that contains its
smallest vertex.*

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n , m
build adjacency list

visited[1…n] = false
side[1…n]    = 0/1   (temporary bipartition)
answer[1…n]  = 0

for every vertex v = 1 … n
    if not visited[v]
        run DFS/BFS from v
            - colour vertices with side 0/1
            - collect all vertices of this component in list comp
            - while traversing, if an edge connects two vertices with the
              same side → graph is not bipartite → print "NO" and exit
        min_v = minimum element of comp
        # which side gets shift 1 ?
        if side[min_v] == 0 : side_one = 0
        else                : side_one = 1
        for each x in comp
            if side[x] == side_one : answer[x] = 1
            else                    : answer[x] = 2

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `"NO"` iff no feasible assignment exists,
otherwise it prints the lexicographically smallest feasible assignment.

---

##### Lemma 1  
During the DFS/BFS of a component the algorithm detects a conflict
(`side[u] == side[v]` for an edge `u‑v`) **iff** the component is not bipartite.

**Proof.**  
The algorithm colours the start vertex arbitrarily with side 0 and always
assigns the opposite side to an unvisited neighbour.
If later an edge connects two already coloured vertices with the same side,
the parity along the two different paths from the start vertex to the ends
differs, which is exactly the definition of an odd cycle, i.e. non‑bipartite.
Conversely, if the component is non‑bipartite it contains an odd cycle,
and the above situation inevitably appears. ∎



##### Lemma 2  
If the algorithm finishes without printing `"NO"`, the produced `answer`
is a feasible shift assignment.

**Proof.**  
By Lemma&nbsp;1 every component is bipartite, therefore the temporary
`side` values give a proper 2‑colouring of the component.
The algorithm assigns shift 1 to one whole side and shift 2 to the other,
so every edge connects vertices of different shifts. ∎



##### Lemma 3  
For a component `C` let `p = min(C)`.  
Among all feasible assignments of the whole graph, any assignment that gives
shift 2 to `p` is lexicographically larger than an assignment that gives
shift 1 to `p`.

**Proof.**  
All vertices with index `< p` belong to other components, therefore they have
identical shifts in both assignments.
At position `p` the first assignment has value `2`, the second has value `1`.
Since `1 < 2`, the second assignment is lexicographically smaller,
independent of later positions. ∎



##### Lemma 4  
For each component the algorithm’s choice (shift 1 to the side containing
its smallest vertex) yields the smallest possible prefix of the final
sequence among all feasible assignments.

**Proof.**  
Consider component `C` and its smallest vertex `p`.  
By Lemma&nbsp;3 any feasible assignment that gives shift 2 to `p` is worse
than one that gives shift 1 to `p`.  
The algorithm always gives shift 1 to `p` (by construction of `side_one`),
hence no feasible assignment can have a smaller value at position `p`,
and consequently cannot have a smaller prefix up to `p`. ∎



##### Lemma 5  
The assignment produced by the algorithm is the lexicographically smallest
feasible assignment of the whole graph.

**Proof.**  
Process vertices in increasing order.
Whenever the first vertex of a not‑yet‑oriented component appears,
the algorithm (by Lemma&nbsp;4) chooses the smallest possible value (`1`) for
that position.
All earlier positions are already fixed and cannot be improved.
Thus after handling each vertex the current prefix is minimal among all
feasible assignments.
Induction over the vertices gives that the complete sequence is minimal. ∎



##### Theorem  
The algorithm outputs  

* `"NO"` **iff** no shift assignment satisfying the rule exists;  

* otherwise `"YES"` and the lexicographically smallest feasible assignment.

**Proof.**  

*If part*:  
If the algorithm prints `"NO"`, a conflict was detected inside some component.
By Lemma&nbsp;1 that component is not bipartite, therefore no 2‑colouring exists,
hence no feasible assignment exists.

*Only‑if part*:  
Assume a feasible assignment exists. Then every component is bipartite,
so the algorithm never meets a conflict and does not print `"NO"`.
By Lemma&nbsp;2 the produced `answer` is feasible.
By Lemma&nbsp;5 it is the lexicographically smallest feasible assignment.
Thus the algorithm prints `"YES"` and this assignment. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*DFS/BFS over all vertices*: each vertex and edge is processed once →  
`O(n + m)` time, `O(n)` additional memory for the temporary lists.  

Overall  

```
Time   : O(n + m)   ≤ 4·10⁵ operations
Memory : O(n + m)   ≤ 4·10⁵ integers
```

Both satisfy the limits.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    visited = [False] * (n + 1)
    side = [0] * (n + 1)          # temporary bipartition 0/1
    answer = [0] * (n + 1)

    from collections import deque

    for start in range(1, n + 1):
        if visited[start]:
            continue
        # BFS for this component
        q = deque([start])
        visited[start] = True
        side[start] = 0
        comp = [start]
        while q:
            u = q.popleft()
            for v in adj[u]:
                if not visited[v]:
                    visited[v] = True
                    side[v] = side[u] ^ 1
                    q.append(v)
                    comp.append(v)
                elif side[v] == side[u]:
                    # not bipartite
                    sys.stdout.write("NO")
                    return

        # decide orientation: smallest vertex gets shift 1
        min_v = min(comp)
        side_one = side[min_v]          # side that will become shift 1
        for v in comp:
            answer[v] = 1 if side[v] == side_one else 2

    # all components processed, feasible
    out = ["YES", " ".join(str(answer[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
