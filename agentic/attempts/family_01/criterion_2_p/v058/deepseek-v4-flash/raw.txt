We can model this as a bipartite graph problem.  
Each edge means the two workers must be on different shifts.  
If the graph is not bipartite, output `NO`.  
Otherwise, we need the lexicographically smallest assignment.

We can do a BFS/DFS over each connected component, assigning shifts greedily:  
- Start with shift 1 for the first unassigned node in each component.  
- Alternate shifts along edges.  
- If a conflict occurs, the graph is not bipartite.

This greedy approach gives the lexicographically smallest assignment because we always try to assign the smallest possible shift (1) to the smallest-index unassigned worker.

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * n

    for i in range(n):
        if color[i] == -1:
            color[i] = 0
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 1 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return

    print("YES")
    print(" ".join(str(c + 1) for c in color))

if __name__ == "__main__":
    solve()
```
