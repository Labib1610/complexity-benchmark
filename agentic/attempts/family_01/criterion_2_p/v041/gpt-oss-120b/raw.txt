**Solution Explanation**

For every pair `(u , v)` the two servers must obtain different windows.
Thus the graph formed by the `m` pairs has to be *bipartite*.
If it is bipartite we have two possible colourings for each connected component
(the two colour classes can be swapped).

We need the lexicographically smallest sequence  
` s1 , s2 , … , sn ` where each `si` is `1` or `2`.

*Observation*  
Consider one connected component.
Let `c1 < c2 < …` be its vertices in increasing order.
If we swap the two colour classes, the first vertex `c1` changes from `1` to `2`
or vice‑versa, while all later vertices keep the same relative order.
Therefore the lexicographically smallest assignment for the whole graph is
obtained by forcing **the smallest indexed vertex of every component to be `1`**.
All other vertices of that component are then forced uniquely.

So we only have to

1. check bipartiteness,
2. while traversing a component, start the BFS/DFS from its smallest vertex
   and colour it `1`.

If a conflict appears (an edge whose ends already have the same colour) the
graph is not bipartite → answer `NO`.

Otherwise we output the obtained colours.

The algorithm runs in `O(n + m)` time and `O(n + m)` memory.



---

#### Algorithm
```
read n, m
build adjacency list G[1..n]

colour[1..n] = 0          # 0 = uncoloured, 1 or 2 otherwise
for v = 1 .. n:
    if colour[v] == 0:
        colour[v] = 1                # smallest vertex of this component gets 1
        queue = [v]
        while queue not empty:
            x = pop queue
            for each y in G[x]:
                if colour[y] == 0:
                    colour[y] = 3 - colour[x]   # opposite colour
                    push y into queue
                elif colour[y] == colour[x]:
                    print "NO" and exit

print "YES"
print colour[1] … colour[n] separated by spaces
```

---

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no valid deployment exists,
and otherwise prints the lexicographically smallest valid assignment.

---

##### Lemma 1  
During the BFS of a component, the algorithm always assigns opposite colours
to the two ends of every processed edge.

**Proof.**  
When an edge `(x, y)` is examined:
* if `y` is uncoloured, we set `colour[y] = 3 - colour[x]`, i.e. the opposite.
* if `y` is already coloured, we check `colour[y] != colour[x]`.  
  If they were equal we would abort with `NO`. ∎



##### Lemma 2  
If the algorithm finishes without aborting, the produced colouring is a
proper 2‑colouring of the whole graph.

**Proof.**  
By Lemma&nbsp;1 every edge examined inside a component connects vertices of
different colours. All edges belong to exactly one component, therefore all
edges satisfy the condition. ∎



##### Lemma 3  
If the algorithm aborts with `NO`, the graph is not bipartite.

**Proof.**  
Abortion happens only when an edge `(x, y)` is found with
`colour[x] == colour[y]`. Both ends already received colours during the same
BFS, i.e. they lie on a common path where colours alternate. Adding the edge
creates an odd cycle, which makes the component non‑bipartite, hence the whole
graph non‑bipartite. ∎



##### Lemma 4  
For each connected component the algorithm assigns colour `1` to its smallest
indexed vertex.

**Proof.**  
The outer loop visits vertices in increasing order.
When the first vertex `v` of a component is encountered, it is still uncoloured,
so the algorithm sets `colour[v] = 1`. No later step changes `v`’s colour. ∎



##### Lemma 5  
Among all proper 2‑colourings, the colouring produced by the algorithm is
lexicographically minimal.

**Proof.**  
Consider the components in order of their smallest vertex.
By Lemma&nbsp;4 the algorithm forces that vertex to colour `1`.
Any other proper colouring either gives the same colour `1` to that vertex,
or gives it colour `2`. In the latter case the whole sequence is lexicographically
larger, because the first position where the two sequences differ is that vertex.
Thus no colouring can be lexicographically smaller than the algorithm’s
colouring. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no assignment satisfying the constraints exists;  
* otherwise `YES` and the lexicographically smallest valid assignment.

**Proof.**  
*If the algorithm prints `NO`*: by Lemma&nbsp;3 the graph is not bipartite,
hence no 2‑colouring exists, so no assignment exists.

*If the algorithm prints `YES`*: it terminated without conflict, therefore by
Lemma&nbsp;2 the output is a proper assignment. By Lemma&nbsp;5 it is the
lexicographically smallest among all proper assignments.

Conversely, if a proper assignment exists, the graph is bipartite, so no
conflict can appear and the algorithm will not abort, thus prints `YES`. ∎



---

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and each edge is processed once →  
`O(n + m)` time, `O(n)` additional memory for the colour array and the queue.

Overall: **Time `O(n + m)`, Memory `O(n + m)`**, well within limits.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        g[u].append(v)
        g[v].append(u)

    colour = [0] * (n + 1)          # 0 = uncoloured, 1 or 2 otherwise

    for v in range(1, n + 1):
        if colour[v]:
            continue
        colour[v] = 1               # smallest vertex of this component gets 1
        q = deque([v])
        while q:
            x = q.popleft()
            cx = colour[x]
            nx = 3 - cx
            for y in g[x]:
                if colour[y] == 0:
                    colour[y] = nx
                    q.append(y)
                elif colour[y] == cx:
                    sys.stdout.write("NO")
                    return

    out = ["YES\n"]
    out.append(' '.join(str(colour[i]) for i in range(1, n + 1)))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```
