We can model this as a bipartite graph problem.  
Each employee is a node, and each link is an edge.  
Since shift codes are 1 and 2, the difference must be exactly 1, meaning connected employees must be in different groups.  

So we need to check if the graph is bipartite.  
If it is, we assign 1 or 2 accordingly, and to get the lexicographically smallest assignment, we try to assign 1 whenever possible during BFS/DFS.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(color[i]) for i in range(n)))
```
