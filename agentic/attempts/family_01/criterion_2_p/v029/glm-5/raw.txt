Final solutionLooking at this problem:

- It's a 2-coloring (bipartiteness) problem: assign roles 1/2 so adjacent vertices differ.
- For lexicographic smallest: each connected component of a bipartite graph has exactly **two** valid colorings (a coloring and its complement), so the choices per component are independent. To get the lexicographically smallest string, each component's smallest-indexed vertex should get role 1 (then everything else in that component is forced).
- Algorithm: iterate vertices 1..n; for each unvisited vertex (which is the minimum of its component), color it 1 and propagate colors via DFS/BFS, checking for conflicts (same-color edge → NO, including self-loops which are naturally detected).

Complexity: O(n + m), well within limits using fast I/O and iterative DFS.

Verified against both examples: example 1 gives `1 2 1 2`, example 2 (triangle, odd cycle) gives `NO`.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    m = int(data[1])
    vals = list(map(int, data[2:2 + 2 * m]))
    g = [[] for _ in range(n + 1)]
    it = iter(vals)
    for u, v in zip(it, it):
        g[u].append(v)
        g[v].append(u)
    color = [0] * (n + 1)
    stack = []
    push = stack.append
    pop = stack.pop
    write = sys.stdout.write
    for s in range(1, n + 1):
        if color[s]:
            continue
        color[s] = 1
        push(s)
        while stack:
            u = pop()
            nc = color[u] ^ 3  # opposite color (1<->2)
            for v in g[u]:
                cv = color[v]
                if cv == nc:
                    continue
                if cv == 0:
                    color[v] = nc
                    push(v)
                else:
                    # cv == color[u] -> conflict (also catches self-loops)
                    write("NO\n")
                    return
    write("YES\n")
    write(" ".join(map(str, color[1:])))
    write("\n")

main()
```
