```python
    input_data = sys.stdin.read().split()

                        print("NO")
```

Double check the problem statement "If multiple valid shift schedules exist, determine the lexicographically smallest sequence of shift assignments."
My logic:
Lexicographically smallest means minimizing $s_1$, then $s_2$, etc.
My algorithm:
Iterates $i$ from 1 to $n$.
If $s_i$ is determined by previous choices, keep it.
If $s_i$ is not determined (start of component), set $s_i = 1$.
This minimizes $s_i$ at the earliest possible position where a choice exists.
Is it possible that setting $s_i=1$ forces some $s_k$ ($k > i$) to be 2, but setting $s_i=2$ would allow $s_k=1$?
If $s_i=1$ is valid, then the component is bipartite.
If $s_i=2$ is also valid, then the component is bipartite.
In a bipartite component, the coloring is unique up to swapping colors.
So if $s_i=1$ forces $s_k=2$, then $s_i=2$ would force $s_k=1$.
Comparing $(s_1, \dots, s_i=1, \dots, s_k=2, \dots)$ vs $(s_1, \dots, s_i=2, \dots, s_k=1, \dots)$.
Since $i < k$, the first difference is at index $i$.
$1 < 2$. So the first sequence is lexicographically smaller.
Thus, we must pick $s_i=1$ if possible.
Since $s_i$ is the first node of the component, we are free to pick 1 or 2.
So picking 1 is always correct for lexicographical minimality.
The logic holds.

```python
import sys
from collections import deque

def solve():
    # Use fast I/O
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return
    
    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    adj = [[] for _ in range(n + 1)]
    
    # Parse edges
    for _ in range(m):
        try:
            u = int(next(iterator))
            v = int(next(iterator))
            adj[u].append(v)
            adj[v].append(u)
        except StopIteration:
            break
            
    shift = [0] * (n + 1)
    
    # Process each connected component
    for i in range(1, n + 1):
        if shift[i] == 0:
            # Assign the smallest possible shift (1) to the first node of the component
            shift[i] = 1
            q = deque([i])
            
            while q:
                u = q.popleft()
                current_shift = shift[u]
                # Neighbors must have the opposite shift (3 - shift)
                needed_shift = 3 - current_shift
                
                for v in adj[u]:
                    if shift[v] == 0:
                        shift[v] = needed_shift
                        q.append(v)
                    elif shift[v] != needed_shift:
                        # Conflict found
                        print("NO")
                        return

    print("YES")
    # Format output
    sys.stdout.write(" ".join(map(str, shift[1:])) + "\n")

if __name__ == '__main__':
    solve()
```

Final check on logic again:
"lexicographically smallest sequence of shift assignments"
Sequence is $(s_1, s_2, \dots, s_n)$.
We want smallest $s_1$. If multiple, smallest $s_2$, etc.
My code:
Iterates $i=1..n$.
If $s_i$ is free (unassigned), set $s_i=1$.
If $s_i$ is fixed, keep it.
Is it possible that $s_i$ is free, but setting $s_i=1$ is invalid?
If $s_i$ is free, it means no neighbor $j < i$ has been assigned.
So no constraint from $j < i$.
Constraints only come from neighbors.
If setting $s_i=1$ leads to conflict later in the component traversal, then the component is not bipartite.
In that case, setting $s_i=2$ would also lead to conflict (since bipartite property doesn't depend on which color you start with).
So if $s_i=1$ fails, no solution exists.
If $s_i=1$ succeeds, it is valid.
Since $s_i=1 < s_i=2$, we prefer $s_i=1$.
What if $s_i$ is constrained by a neighbor $j > i$?
We process $i$ before $j$. So when we are at $i$, $j$ is unassigned.
We assign $s_i=1$, then visit $j$ (if connected) and assign $s_j=2$.
This is consistent with the traversal order.
Later when we reach $j$ in the loop $1..n$, it is already assigned.
So the logic holds perfectly.

```python
import sys
from collections import deque

def solve():
    # Read all input from standard input efficiently
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return
    
    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Build the graph using adjacency list
    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
        
    # Array to store the shift for each person (1 or 2), 0 means unassigned
    shift = [0] * (n + 1)
    
    # Iterate through all personnel to handle disconnected components
    # The loop order 1 to n ensures we process the lexicographically smallest
    # unassigned node first for each component.
    for i in range(1, n + 1):
        if shift[i] == 0:
            # Start a new component traversal (BFS)
            # To ensure lexicographically smallest assignment, we assign shift 1
            # to the first node encountered in this component.
            shift[i] = 1
            q = deque([i])
            
            while q:
                u = q.popleft()
                current_shift = shift[u]
                # Neighbors must have the opposite shift (3 - shift)
                target_shift = 3 - current_shift
                
                for v in adj[u]:
                    if shift[v] == 0:
                        shift[v] = target_shift
                        q.append(v)
                    elif shift[v] != target_shift:
                        # Incompatible pair assigned the same shift -> Impossible
                        print("NO")
                        return

    # If we successfully assigned shifts to all personnel
    print("YES")
    # Print the assignments separated by spaces
    sys.stdout.write(" ".join(map(str, shift[1:])) + "\n")

if __name__ == '__main__':
    solve()
```
