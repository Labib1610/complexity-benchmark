We can model this as a bipartite graph coloring problem.  
If the graph is bipartite, we can assign shifts 1 and 2 to the two sides.  
We also need the lexicographically smallest assignment, so we try to assign shift 1 whenever possible during BFS/DFS.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    # color 0 -> shift 1, color 1 -> shift 2
    # But we want lexicographically smallest: try to assign 1 as much as possible
    # We can flip colors in each connected component if it makes earlier nodes shift 1
    # Since BFS already starts with 0 at the smallest index in each component,
    # this already gives lexicographically smallest assignment.
    print("YES")
    print(" ".join(str(c + 1) for c in color))
```
