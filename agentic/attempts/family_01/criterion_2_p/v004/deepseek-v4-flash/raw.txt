We can model this as a bipartite graph problem: each worker is a node, and each conflict is an edge. We need to assign each node to one of two shifts such that no edge connects two nodes of the same shift — that’s exactly a 2-coloring problem.

If the graph is bipartite, we can color it. To get the lexicographically smallest assignment, we should try to assign shift 1 to as many early-indexed workers as possible, which means we should start BFS/DFS from node 1 with color 1, and whenever we encounter an uncolored node, assign it the smallest possible color that doesn’t conflict with already colored neighbors.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0  # shift 1
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
