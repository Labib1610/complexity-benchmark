**Solution Explanation**

For every worker we have to choose one of two shifts `1` or `2`.
Pairs given in the input are *conflicts*: the two workers of a pair must obtain
different shifts.

The conflict graph is an undirected graph with `n` vertices and `m` edges.
The task is exactly the problem of 2‑colouring this graph.

* If the graph is not bipartite → no assignment exists.
* If it is bipartite we have to output the **lexicographically smallest**
  colour sequence `s1 … sn` (each `si ∈ {1,2}`).

--------------------------------------------------------------------

#### 1.   Observations  

* In a connected component of a bipartite graph there are exactly two
  possible 2‑colourings – they differ by swapping the two colours.
* Different components are independent, we may choose the orientation
  (which colour is called “1”) for each component separately.
* Lexicographic order compares the sequence from vertex `1` upwards.
  The first vertex that belongs to a component decides the order for this
  whole component, because all earlier vertices are already fixed.
  Therefore, for a component we should orient it so that its **smallest
  vertex gets colour 1**.  
  This choice is optimal for the whole sequence.

--------------------------------------------------------------------

#### 2.   Algorithm  

```
read n, m
build adjacency list

colour = array of size n, filled with -1   # -1 = unvisited, 0/1 = provisional colour
answer = array of size n                  # final 1/2 values

for v = 0 … n-1:
    if colour[v] != -1: continue          # already processed component
    # start BFS for a new component
    queue = [v]; colour[v] = 0
    component_vertices = [v]
    while queue not empty:
        x = pop queue
        for each neighbour y of x:
            if colour[y] == -1:
                colour[y] = colour[x] ^ 1
                queue.append(y)
                component_vertices.append(y)
            elif colour[y] == colour[x]:
                print "NO" and exit        # not bipartite

    # decide orientation
    min_vertex = min(component_vertices)   # 0‑based index
    if colour[min_vertex] == 1:            # min vertex would be colour 2
        # flip whole component
        for u in component_vertices:
            colour[u] ^= 1

    # store final 1/2 values
    for u in component_vertices:
        answer[u] = colour[u] + 1          # 0→1, 1→2

print "YES"
print answer as space separated integers
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest assignment.

---

##### Lemma 1  
During BFS, if an edge `(x,y)` is discovered with `colour[x] == colour[y]`,
the graph is not bipartite.

**Proof.** In any 2‑colouring adjacent vertices must have different colours.
If BFS already assigned the same colour to both ends of an edge,
any extension of this partial colouring would keep the conflict.
Thus no 2‑colouring exists. ∎



##### Lemma 2  
If the algorithm finishes all BFS traversals without triggering Lemma 1,
the graph is bipartite and the provisional colours (`0/1`) form a proper
2‑colouring of each component.

**Proof.** BFS colours neighbours with opposite colour, therefore every
explored edge connects vertices of different provisional colours.
All vertices are visited, so every edge is examined and satisfies the
property. Hence the provisional colouring is a valid 2‑colouring. ∎



##### Lemma 3  
For a processed component `C`, after the possible flip
the smallest vertex of `C` receives colour 1 in the final answer.

**Proof.** Let `v_min` be the smallest index in `C`.  
If its provisional colour is `0`, we keep the colours – `v_min` gets `0`
→ final `1`.  
If its provisional colour is `1`, we flip all colours in `C`; then
`v_min` becomes `0` → final `1`. ∎



##### Lemma 4  
The assignment produced by the algorithm is lexicographically minimal
among all valid assignments.

**Proof.** Consider vertices in increasing order.
When the first vertex `i` belonging to a component `C` is reached,
all earlier vertices belong to components already fixed.
By Lemma 3 the algorithm forces `i` to colour 1 (if possible) – the smallest
value allowed for a valid assignment of `C`.  
Any other valid global assignment must give the same colours to earlier
vertices and can only differ inside `C`.  
If it gave colour 2 to `i`, its whole sequence would be lexicographically
larger at position `i`.  
Thus no other valid assignment is lexicographically smaller. ∎



##### Lemma 5  
If the algorithm outputs `NO`, no valid assignment exists.

**Proof.** `NO` is printed only when Lemma 1 detects a same‑colour edge.
By Lemma 1 the graph is not bipartite, therefore no 2‑colouring (hence no
assignment) exists. ∎



##### Theorem  
The algorithm

* prints `NO` iff the instance has no feasible assignment,
* otherwise prints `YES` followed by the lexicographically smallest
  feasible assignment.

**Proof.**  
*If `NO` is printed*: by Lemma 5 no assignment exists.  
*If the algorithm finishes*: by Lemma 2 the graph is bipartite, so a
feasible assignment exists. The produced assignment is a valid 2‑colouring
(and therefore feasible). By Lemma 4 it is lexicographically minimal.
Thus the output satisfies the specification. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)`.  
*Flipping and writing answer*: total `O(n)`.

Overall time `O(n + m)` ≤ `4·10⁵`, memory `O(n + m)` ≤ `~4·10⁵` integers,
well inside the limits.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * n          # provisional 0/1
    answer = [0] * n           # final 1/2

    for start in range(n):
        if colour[start] != -1:
            continue
        # BFS for this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        while q:
            x = q.popleft()
            cx = colour[x]
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = cx ^ 1
                    q.append(y)
                    comp.append(y)
                elif colour[y] == cx:
                    sys.stdout.write("NO")
                    return

        # orient component so that its smallest vertex gets colour 0
        min_v = min(comp)
        if colour[min_v] == 1:
            for v in comp:
                colour[v] ^= 1

        for v in comp:
            answer[v] = colour[v] + 1   # 0->1, 1->2

    out = ["YES", " ".join(map(str, answer))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
