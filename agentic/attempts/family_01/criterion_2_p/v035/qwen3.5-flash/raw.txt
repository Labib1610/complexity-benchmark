The employees are nodes, and an incompatibility constraint between employee $u$ and employee $v$ corresponds to an edge between $u$ and $v$. We want to color the nodes with two colors (shifts 1 and 2) such that no two adjacent nodes have the same color. This is exactly the definition of a bipartite graph.

Final verification of logic.
The problem is essentially 2-coloring a graph.
Lexicographically smallest means $s_1$ is min, then $s_2$ is min, etc.
My algorithm iterates $i=1 \dots n$.
If $i$ is uncolored, it starts a new component.
Since $i$ is the smallest index in this component (all $j < i$ are colored), minimizing $s_i$ is the priority for this component's contribution to the lexicographical order.
Minimal value is 1.
So we set $s_i = 1$.
This determines the rest of the component.
If valid, we continue.
If invalid, NO.
This ensures the global lexicographically smallest assignment because for any component, we chose the smallest possible value for its smallest-indexed node, which is the earliest node in the sequence affected by this component.
Any other valid assignment for this component would have $s_i = 2$ (since only 2 choices exist in a bipartite component), which is larger.
Since components are disjoint, choices in one component don't affect validity of others.
So greedy per component is optimal for global lexicographical order.
Logic is solid.
