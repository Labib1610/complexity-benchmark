**Solution Explanation**

For every constraint `{u , v}` we need  

```
value[u] + value[v] = 3
```

The only possible pairs are `(1,2)` and `(2,1)`.  
Therefore the two satellites must receive *different* values.
The whole set of constraints is a graph whose edges demand different
values → the graph must be **bipartite**.

If the graph is not bipartite there is no assignment (`NO`).

If it is bipartite we have two possible colourings for each connected
component – we may swap the two colour classes.
To obtain the lexicographically smallest sequence `s1 … sn`
we simply make the **smallest indexed vertex of the component receive `1`**,
the other colour class receives `2`.  
All earlier vertices are then as small as possible, which is exactly the
lexicographically minimal solution.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list G
colour[1…n] = -1          # -1 = unvisited, 0/1 = two colour classes
answer[1…n] = 0

for v = 1 … n:
    if colour[v] != -1: continue
    # start a new component
    queue = [v]; colour[v] = 0
    component_vertices = [v]
    while queue not empty:
        x = pop queue
        for y in G[x]:
            if colour[y] == -1:
                colour[y] = colour[x] ^ 1
                queue.append(y)
                component_vertices.append(y)
            elif colour[y] == colour[x]:
                print "NO" and exit          # not bipartite

    # decide orientation: smallest index gets value 1
    min_vertex = min(component_vertices)
    if colour[min_vertex] == 0:
        # colour 0 -> 1, colour 1 -> 2
        for u in component_vertices:
            answer[u] = 1 if colour[u] == 0 else 2
    else:
        # colour 1 -> 1, colour 0 -> 2   (swap)
        for u in component_vertices:
            answer[u] = 1 if colour[u] == 1 else 2

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no valid configuration exists,
otherwise prints the lexicographically smallest valid configuration.

---

**Lemma 1**  
If the algorithm detects an edge whose endpoints have the same colour,
the graph is not bipartite, hence no configuration satisfies all constraints.

*Proof.*  
During BFS we assign opposite colours to the ends of every processed edge.
If later we encounter an edge `(x,y)` with `colour[x] == colour[y]`,
any 2‑colouring would need `x` and `y` in different colour classes,
contradiction. Therefore the graph is not bipartite and no assignment
with different values on each edge exists. ∎



**Lemma 2**  
If the algorithm finishes without contradiction, the produced `answer`
satisfies every constraint.

*Proof.*  
For each component we performed a proper 2‑colouring, i.e. every edge joins
vertices of opposite colours. Afterwards we map one colour class to value 1
and the other to value 2 (possibly swapping). Hence for every edge the
two incident vertices receive different values, and their sum is `1+2=3`. ∎



**Lemma 3**  
For a connected component, among all valid assignments the one where the
smallest indexed vertex receives `1` is lexicographically minimal for that
component.

*Proof.*  
Inside a component the only freedom is swapping the two colour classes.
If the smallest vertex gets `2`, swapping makes it `1` and does not affect
any vertex with a smaller index (there is none). Therefore any assignment
with the smallest vertex equal to `2` is lexicographically larger than the
assignment with it equal to `1`. ∎



**Lemma 4**  
The algorithm’s assignment is lexicographically minimal among all global
assignments.

*Proof.*  
Consider the vertices in increasing order.
Take the first vertex `i` where the algorithm’s assignment could differ
from another valid assignment `A`.  
`i` belongs to some component `C`. By construction the algorithm gives
value `1` to the smallest index of `C`. Since `i` is the smallest index of
`C`, the algorithm sets `i = 1`. Any other valid assignment must also give
`i` either `1` or `2`. If it gives `2`, it is lexicographically larger.
If it gives `1`, the two assignments coincide up to `i`. Thus no assignment
is lexicographically smaller than the algorithm’s. ∎



**Theorem**  
The program outputs  

* `NO` iff no configuration satisfying all constraints exists;  
* otherwise `YES` and the lexicographically smallest configuration.

*Proof.*  
- If the program prints `NO`, by Lemma&nbsp;1 the graph is not bipartite,
  hence no configuration exists.
- If a configuration exists, the graph is bipartite, so the BFS never
  encounters a same‑colour edge; the program proceeds to output a
  configuration. By Lemma&nbsp;2 it satisfies all constraints.
  By Lemma&nbsp;4 it is lexicographically minimal.
Thus the theorem holds. ∎

#### Complexity Analysis  

`BFS` visits each vertex once and each edge twice.

```
Time   :  O(n + m)   ≤ 4·10⁵
Memory :  O(n + m)   adjacency list + arrays
```

Both fit easily into the limits.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        g[u].append(v)
        g[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 colours
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS for this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        while q:
            x = q.popleft()
            cx = colour[x]
            for y in g[x]:
                if colour[y] == -1:
                    colour[y] = cx ^ 1
                    q.append(y)
                    comp.append(y)
                elif colour[y] == cx:
                    print("NO")
                    return
        # orientation: smallest vertex gets value 1
        min_v = min(comp)
        if colour[min_v] == 0:
            for v in comp:
                ans[v] = 1 if colour[v] == 0 else 2
        else:
            for v in comp:
                ans[v] = 1 if colour[v] == 1 else 2

    # all done
    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
