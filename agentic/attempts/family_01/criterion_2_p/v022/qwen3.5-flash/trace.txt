The problem asks us to assign one of two channels (1 or 2) to each of $n$ transmitters such that no two transmitters connected by an interference condition share the same channel. We need to find the lexicographically smallest assignment if one exists. If no assignment exists, output "NO". Otherwise, output "YES" followed by the assignment.

This is a classic graph coloring problem. We have a graph where transmitters are vertices and interference conditions are edges. We need to 2-color the graph. A graph is 2-colorable if and only if it is bipartite. If the graph is bipartite, we need to find the lexicographically smallest 2-coloring.

Let's represent the transmitters as nodes $1$ to $n$. The interference conditions form edges between these nodes.
We need to assign $s_i \in \{1, 2\}$ to each node $i$.
Constraints: For every edge $(u, v)$, $s_u \neq s_v$.

Since we want the lexicographically smallest sequence $(s_1, s_2, \dots, s_n)$, we want $s_1$ to be as small as possible (i.e., 1), then $s_2$ to be as small as possible given $s_1$, and so on.

However, simply trying to set $s_i=1$ greedily might not work because earlier choices constrain later choices. For example, if node 1 is connected to node 2, setting $s_1=1$ forces $s_2=2$. If we had set $s_1=2$, $s_2$ could be 1. But lexicographically, $(1, 2, \dots)$ is smaller than $(2, 1, \dots)$. So, for $s_1$, we should prefer 1. If setting $s_1=1$ leads to a valid coloring later, that is the choice. If it leads to a contradiction (i.e., the graph component containing 1 is not bipartite, or the choice forces a contradiction elsewhere), then maybe $s_1=2$ is required, or maybe no solution exists.

Wait, the problem is about bipartiteness.
If a connected component is not bipartite, then no solution exists, so we output NO.
If a connected component is bipartite, there are exactly two valid colorings for that component (swapping the sets of vertices assigned to channel 1 and channel 2).
Let a component be $C$. The vertices in $C$ can be partitioned into two sets $A$ and $B$ such that all edges are between $A$ and $B$.
One valid assignment is $s_i = 1$ for $i \in A$ and $s_i = 2$ for $i \in B$.
The other is $s_i = 2$ for $i \in A$ and $s_i = 1$ for $i \in B$.

To minimize the sequence $(s_1, \dots, s_n)$ lexicographically, we need to make decisions for $s_1$, then $s_2$, etc.
