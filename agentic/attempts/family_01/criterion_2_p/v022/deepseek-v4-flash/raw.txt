We can model this as a bipartite graph problem: each node must be assigned 1 or 2, and connected nodes must have different values. This is exactly checking if the graph is bipartite, and if so, finding the lexicographically smallest assignment.

We can do a BFS/DFS coloring, but to get the lexicographically smallest assignment, we should try to assign `1` whenever possible, starting from node 1.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

# Now we have a valid bipartition.
# To get lexicographically smallest, we try to set each node to 1 if possible.
# Since we already have a valid 2-coloring, we can flip colors in each connected component
# to make the smallest-index node in that component be 1.

visited = [False] * n
for i in range(n):
    if visited[i]:
        continue
    # BFS to collect component
    comp = []
    q = deque([i])
    visited[i] = True
    while q:
        u = q.popleft()
        comp.append(u)
        for v in adj[u]:
            if not visited[v]:
                visited[v] = True
                q.append(v)
    # If the smallest node in this component is color 1, keep; else flip
    if color[comp[0]] == 1:
        for u in comp:
            color[u] ^= 1

print("YES")
print(" ".join(str(c + 1) for c in color))
```
