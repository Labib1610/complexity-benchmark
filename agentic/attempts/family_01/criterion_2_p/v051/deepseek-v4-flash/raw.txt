We can model this as a **bipartite graph** problem:  
- Each animal is a node.  
- Each foraging pair is an edge.  
- We need to color the graph with two colors (frequencies 1 and 2) such that no two connected nodes share the same color.  
- If the graph is not bipartite, output `NO`.  
- If it is bipartite, we want the lexicographically smallest assignment, meaning we try to assign `1` whenever possible, starting from node 1.

We can do this with BFS/DFS, but to get the lexicographically smallest assignment, we should process nodes in order and assign `1` if possible, otherwise `2`.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 1
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]  # alternate 1 <-> 2
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

# Try to assign colors, but for lexicographic smallest,
# we process nodes in order and assign 1 if uncolored.
for i in range(n):
    if color[i] == -1:
        # Try to color with 1 first
        color[i] = 1
        q = deque([i])
        ok = True
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break
            if not ok:
                break
        if not ok:
            print("NO")
            sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
