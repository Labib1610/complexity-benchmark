We need to solve a bipartite graph problem: assign each node to shift 1 or 2 such that no edge connects nodes with the same shift. This is equivalent to checking if the graph is bipartite.

If it is bipartite, we need the lexicographically smallest assignment. That means we try to assign node 1 to shift 1 as early as possible, and then each subsequent node gets the smallest available shift compatible with previously assigned neighbors.

We can do this with BFS/DFS coloring, but with a twist: we assign greedily starting from lowest index, ensuring lexicographic smallest.

Here’s the algorithm:

1. Build adjacency list.
2. Initialize `color` array with 0 (unassigned).
3. For each node `i` from 1 to n:
   - If unassigned, start BFS from it with color 1 (to keep lexicographically smallest).
   - For neighbors, assign opposite color; if a conflict is found (neighbor already colored with same color), output `NO`.
4. Output `YES` and color array.

Time complexity `O(n + m)` which is fine for constraints.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)

color = [0] * (n + 1)

for i in range(1, n + 1):
    if color[i] == 0:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == 0:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(map(str, color[1:])))
```
