We can model this as a bipartite graph problem.  
If the graph is not bipartite, output `NO`.  
Otherwise, we need the lexicographically smallest assignment of `1`/`2` to each node.

A simple approach:

- Build adjacency list.
- BFS/DFS to color the graph with two colors (1 and 2).
- If a conflict occurs, output `NO`.
- To get lexicographically smallest assignment, we can try to assign `1` to as many early nodes as possible.  
  One way: run BFS from each unvisited node, but when coloring, try to assign `1` to the starting node if possible, and propagate.  
  However, because the graph may have multiple components, we must choose the starting color for each component to minimize the sequence.

A known trick:  
For each component, we can try both colorings (start with `1` or start with `2`), and pick the one that gives the smaller sequence for that component.  
But since we process nodes in order, we can decide per component by comparing the two possible colorings.

Implementation plan:

1. Read input.
2. Build adjacency.
3. `color = [-1] * (n+1)`
4. For each node `i` from 1 to n:
   - If not visited, BFS to color the component.
   - During BFS, we can generate two possible colorings: one starting with `1`, one starting with `2`.
   - Check both for validity (no conflicts).
   - If both valid, pick the one that gives lexicographically smaller sequence for the nodes in this component.
   - If only one valid, use it.
   - If none valid, output `NO`.
5. After processing all components, output `YES` and the color array.

We must be careful: BFS from a node may visit nodes with indices both smaller and larger than the start.  
But since we process nodes in increasing order, when we start a new component at node `i`, all nodes in that component have index >= i (because smaller ones would have been visited already).  
So we can compare the two colorings for that component directly.

Let's implement.

```python
from collections import deque
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * (n+1)
    
    for i in range(1, n+1):
        if color[i] != -1:
            continue
        # BFS to get component nodes
        # Try two colorings
        comp_nodes = []
        q = deque([i])
        color[i] = 1
        comp_nodes.append(i)
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    comp_nodes.append(v)
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    return
        # Now we have a valid coloring for this component starting with 1.
        # Try starting with 2: we can flip all colors in this component.
        # But we must check if flipping causes conflict? Flipping all colors in a bipartite component is always valid.
        # So both are valid. Choose lexicographically smaller.
        # Since we process in increasing index order, we can compare.
        # We'll store the component nodes sorted (they are already in BFS order, but we need sorted by index)
        comp_nodes.sort()
        # Option A: current color (start with 1)
        # Option B: flip
        # Compare sequences for these nodes
        # We'll build both sequences
        seqA = [color[node] for node in comp_nodes]
        seqB = [3 - color[node] for node in comp_nodes]
        if seqB < seqA:
            # flip
            for node in comp_nodes:
                color[node] = 3 - color[node]
    
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n+1)))

if __name__ == "__main__":
    solve()
```
