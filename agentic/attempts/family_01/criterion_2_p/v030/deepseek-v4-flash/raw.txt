We can model this as a bipartite graph problem.  
Each employee is a node, and each constraint is an edge requiring the two endpoints to be in different branches.  
If the graph is not bipartite, it’s impossible → output `NO`.  

If it is bipartite, we need to assign branch numbers (1 or 2) with the lexicographically smallest assignment starting from employee 1.  

We can do this by running BFS/DFS on each connected component, assigning colors, and for each component, decide which color gets branch 1 based on the smallest employee index in that component.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        comp = [i]
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    comp.append(v)
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
        if not possible:
            break

        # Decide orientation for this component
        min_idx = min(comp)
        if color[min_idx] == 1:
            # flip colors in this component
            for node in comp:
                color[node] ^= 1

if not possible:
    print("NO")
else:
    print("YES")
    print(' '.join(str(c + 1) for c in color))
```
