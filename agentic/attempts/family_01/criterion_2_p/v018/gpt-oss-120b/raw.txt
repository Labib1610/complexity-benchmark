**Solution Explanation**

For every pair `(u , v)` the two workers must work in different shifts.
If we write `1` for shift 1 and `2` for shift 2, the condition is exactly the
definition of a *bipartite* graph:

* vertices = workers  
* edges = incompatible pairs  

The graph is bipartite **iff** we can colour its vertices with two colours
(`0` and `1`) so that adjacent vertices have different colours.

If the graph is bipartite we have to output the *lexicographically smallest*
sequence `s1 … sn` (`si ∈ {1,2}`).

--------------------------------------------------------------------

#### 1.   Observations

* In a connected component of a bipartite graph there are exactly two
  possible colourings – they are each other’s colour swap.
* The components are independent, i.e. the choice made in one component does
  not influence any other component.
* Lexicographic order compares the first position where two sequences differ.
  Because the values are only `1` or `2`, we want the **earliest possible `1`**.
* In a component the smallest numbered vertex is the first position where the
  component can influence the whole answer.
  By swapping the two colourings we can always give this vertex shift 1.

Therefore the lexicographically smallest assignment is obtained by the
following rule:

> For every connected component give shift 1 to its smallest numbered vertex,
> and propagate the colours inside the component.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n , m
build adjacency list

colour[1…n] = -1          # -1 = not visited yet
answer[1…n] = 0

for v = 1 … n
    if colour[v] == -1                # new component, v is its smallest vertex
        start DFS/BFS from v
        colour[v] = 0                 # arbitrary start colour
        stack = [v]
        component_vertices = [v]

        while stack not empty
            x = stack.pop()
            for each neighbour y of x
                if colour[y] == -1
                    colour[y] = colour[x] xor 1
                    stack.append(y)
                    component_vertices.append(y)
                else if colour[y] == colour[x]
                    print "NO" and exit   # not bipartite

        # now the component is coloured, v is its smallest vertex
        flip = colour[v]                # 0 → keep, 1 → swap colours
        for each vertex u in component_vertices
            answer[u] = (colour[u] xor flip) + 1   # 0→1 , 1→2

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible assignment exists,
otherwise it prints `YES` and the lexicographically smallest feasible
assignment.

---

##### Lemma 1  
During the search of a component the algorithm assigns colours `0/1`
exactly as a proper 2‑colouring of that component, and detects a conflict
iff the component is not bipartite.

**Proof.**  
The search starts with an arbitrary vertex coloured `0`.  
Whenever an edge `(x , y)` is examined, the algorithm forces `y` to have the
opposite colour of `x`. This is exactly the rule of a 2‑colouring.
If later the same edge is examined again and both ends already have the same
colour, the component contains an odd cycle, i.e. it is not bipartite.
Conversely, if the component is bipartite, a proper 2‑colouring exists and
the algorithm never meets the conflict situation. ∎



##### Lemma 2  
If the algorithm finishes without printing `NO`, the produced `answer`
satisfies the requirement “incompatible workers are in different shifts”.

**Proof.**  
By Lemma&nbsp;1 every edge connects vertices of opposite *colour*.
`answer[u]` is obtained from `colour[u]` possibly after a global xor (`flip`)
inside the component. Xor with the same value for the whole component does
not change equality/inequality of two colours, therefore adjacent vertices
still obtain different shift numbers (`1` or `2`). ∎



##### Lemma 3  
For each connected component the algorithm assigns shift 1 to its smallest
indexed vertex.

**Proof.**  
When the outer loop reaches the smallest vertex `v` of a component,
`v` is still uncoloured, therefore a new component search starts.
`flip` is set to `colour[v]`.  
If `colour[v] = 0` then `flip = 0` and `answer[v] = (0 xor 0)+1 = 1`.  
If `colour[v] = 1` then `flip = 1` and `answer[v] = (1 xor 1)+1 = 1`. ∎



##### Lemma 4  
Among all feasible assignments, the one produced by the algorithm is
lexicographically smallest.

**Proof.**  
Consider the vertices in increasing order.
Let `v` be the first vertex where the algorithm’s assignment could differ from
some other feasible assignment `B`.

`v` belongs to a component `C`.  
All vertices `< v` are in earlier components, already fixed by the algorithm,
and both assignments coincide on them (otherwise `v` would not be the first
difference).

By Lemma&nbsp;3 the algorithm gives shift 1 to `v`.  
Any feasible assignment must also give shift 1 or shift 2 to `v`.  
If it gave shift 2, the algorithm’s sequence would be lexicographically
smaller at position `v`.  
If it gave shift 1, then inside component `C` the two assignments are identical
(because the whole component is determined by the colour of its smallest
vertex). Hence they cannot differ at `v`.  
Thus no feasible assignment can be lexicographically smaller. ∎



##### Lemma 5  
If the algorithm prints `NO`, no feasible assignment exists.

**Proof.**  
`NO` is printed only when Lemma&nbsp;1 detects a conflict, i.e. a component
contains an odd cycle and is not bipartite.  
In a non‑bipartite component it is impossible to colour vertices with two
colours respecting all edges, which is exactly the requirement of the
problem. Hence no global assignment exists. ∎



##### Theorem  
The algorithm outputs  

* `NO` **iff** the required distribution of workers to two shifts does not exist;  
* otherwise `YES` and the lexicographically smallest valid shift sequence.

**Proof.**  
*If* the algorithm prints `NO`, by Lemma&nbsp;5 no feasible assignment exists.  

*If* the algorithm finishes with `YES`, Lemma&nbsp;2 guarantees the printed
sequence is feasible, and Lemma&nbsp;4 guarantees it is the lexicographically
smallest among all feasible ones.  

Conversely, if a feasible assignment exists, every component is bipartite,
so Lemma&nbsp;1 never triggers a conflict and the algorithm never prints `NO`. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*DFS/BFS over all components*: each vertex and edge is processed once →  
`O(n + m)` time, `O(n)` additional memory for colour, answer and stack.

Overall  

* **Time** `O(n + m)` ≤ `4·10⁵` operations, well inside the limit.  
* **Memory** `O(n + m)` ≤ about 3 MB for edges + arrays, far below 256 MB.

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0/1 = colour
    answer = [0] * (n + 1)

    stack = []
    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # new component, start is its smallest vertex
        colour[start] = 0
        stack.append(start)
        component = [start]

        while stack:
            v = stack.pop()
            cv = colour[v]
            for nb in adj[v]:
                if colour[nb] == -1:
                    colour[nb] = cv ^ 1
                    stack.append(nb)
                    component.append(nb)
                elif colour[nb] == cv:
                    sys.stdout.write("NO")
                    return

        flip = colour[start]          # make start (the smallest) colour 0
        for v in component:
            answer[v] = (colour[v] ^ flip) + 1   # 0->1 , 1->2

    out = ["YES\n", " ".join(str(answer[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
