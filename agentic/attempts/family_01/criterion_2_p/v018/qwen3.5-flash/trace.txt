The problem asks us to assign each of $n$ individuals to one of two work blocks (1 or 2) such that no incompatible pair ends up in the same block. We are given $m$ pairs of incompatible individuals.
If it's impossible to satisfy the condition, we should output "NO". If it is possible, we should output "YES" followed by the lexicographically smallest sequence of block assignments.

This problem can be modeled as a graph problem. Let each individual be a vertex in a graph. The $m$ incompatible pairs represent edges between vertices. The condition "no incompatible pair works in the same block" means that if there is an edge between vertex $u$ and vertex $v$, they must be assigned different blocks.
If we assign block 1 as color A and block 2 as color B, then for every edge $(u, v)$, $color(u) \neq color(v)$.
This is exactly the definition of a **2-coloring** problem (or checking if a graph is **bipartite**).

So, the first step is to check if the graph is bipartite. If it is not bipartite, then no valid assignment exists, and we output "NO".
If it is bipartite, a valid assignment exists. We need to find the assignment that is lexicographically smallest.
A sequence $s_1, s_2, \dots, s_n$ is lexicographically smaller than $t_1, t_2, \dots, t_n$ if at the first index $i$ where they differ, $s_i < t_i$. Since the values are 1 and 2, we want to minimize $s_1$, then minimize $s_2$, and so on. Specifically, we prefer $s_i=1$ over $s_i=2$.

Let's analyze the constraints. $n, m \le 2 \cdot 10^5$. This suggests an $O(n+m)$ or $O((n+m) \log n)$ solution. Standard BFS or DFS for bipartiteness checking runs in $O(n+m)$.

The graph might not be connected. It consists of several connected components.
For a connected component, once we fix the color of one node, the colors of all other nodes in that component are determined (up to swapping 1 and 2).
Let's say we pick a node $u$ in a component. We can assign it block 1 or block 2.
If we assign $u$ block 1, then all neighbors must be block 2, their neighbors block 1, etc. This corresponds to a specific 2-coloring (let's call it coloring $C_1$).
If we assign $u$ block 2, then all neighbors must be block 1, etc. This corresponds to the swapped coloring $C_2$.
Since we want the lexicographically smallest sequence $s_1, s_2, \dots, s_n$, we process nodes $i$ from 1 to $n$.
However, the decisions for nodes in a component are coupled.
If we process nodes $1, \dots, n$ in order, we might encounter a node $i$ that has already been assigned a block due to a previous node $j < i$ being processed. If not, we must decide the block for the component containing $i$.
To make the sequence lexicographically smallest, for the first node $i$ in a component we encounter (which will be the smallest index in that component), we should assign it block 1. Why?
Because if we assign it block 2, then $s_i=2$. If we assign it block 1, $s_i=1$. Since $1 < 2$, assigning 1 is better for the lexicographical order at index $i$.
The subsequent nodes $j$ in the same component will have their colors determined by the bipartite structure relative to $i$. Changing the color of $i$ to 2 would flip all colors in the component, which would increase $s_i$ from 1 to 2. Since $i$ is the smallest index in the component, this is the most significant position to minimize. So, fixing the smallest index node in a component to 1 is the correct greedy strategy.

Let the component nodes be $c_1, c_2, \dots, c_k$ where $c_1 < c_2 < \dots < c_k$.

```python
import sys
```

```python
def solve():
    # Read all input from stdin efficiently
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency list for the graph
    # Nodes are 1-indexed, so size is n + 1
    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
        
    # Color array: 0 = unvisited, 1 = block 1, 2 = block 2
    color = [0] * (n + 1)
    
    # Process each component
    # Iterate from 1 to n. If a node is unvisited, it belongs to a new component.
    # To achieve the lexicographically smallest sequence, the first node encountered 
    # in a component (which is the smallest index in that component) should be assigned block 1.
    for i in range(1, n + 1):
        if color[i] == 0:
            # Assign block 1 to the starting node
            color[i] = 1
            
            # BFS queue
            q = [i]
            head = 0
            
            while head < len(q):
                u = q[head]
                head += 1
                current_c = color[u]
                next_c = 3 - current_c # 1 -> 2, 2 -> 1
                
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = next_c
                        q.append(v)
                    elif color[v] != next_c:
                        # Conflict detected: graph is not bipartite
                        print("NO")
                        return

    # If valid assignment exists
    print("YES")
    # Print the assignment sequence s_1 ... s_n
    # Using sys.stdout.write and join for performance
    sys.stdout.write(" ".join(map(str, color[1:])) + "\n")
```

```python
import sys

def solve():
    # Read all input from standard input at once
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Build the graph using an adjacency list
    # Nodes are 1-indexed
    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
        
    # Array to store the block assignment for each individual
    # 0: unassigned, 1: block 1, 2: block 2
    assignment = [0] * (n + 1)
    
    # Iterate through all individuals to handle potentially disconnected components
    # We process individuals in increasing order of their labels (1 to n).
    # For each unassigned individual, we start a traversal (BFS) to assign blocks.
    # To ensure the lexicographically smallest result, we always assign the first 
    # encountered node in a component (which is the smallest index in that component)
    # to block 1. The rest of the component is then determined by the bipartite constraint.
    for i in range(1, n + 1):
        if assignment[i] == 0:
            assignment[i] = 1
            # Use a list as a queue for BFS
            queue = [i]
            head = 0
            
            while head < len(queue):
                u = queue[head]
                head += 1
                
                current_block = assignment[u]
                next_block = 3 - current_block  # Switch between 1 and 2
                
                for v in adj[u]:
                    if assignment[v] == 0:
                        assignment[v] = next_block
                        queue.append(v)
                    elif assignment[v] != next_block:
                        # Incompatible pair assigned to the same block
                        print("NO")
                        return
    
    # If we successfully assigned blocks to everyone
    print("YES")
    # Output the assignments for individuals 1 to n
    # Using sys.stdout.write for faster I/O
    sys.stdout.write(" ".join(map(str, assignment[1:])) + "\n")

if __name__ == '__main__':
    solve()
```
