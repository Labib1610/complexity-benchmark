We can model the gears as an undirected graph.  
The condition “engaged gears must spin in opposite directions” means the graph must be bipartite.  
If it’s not bipartite, output `NO`.  

If it is bipartite, we want the lexicographically smallest assignment of `1` and `2`.  
We can do a BFS/DFS coloring, but to get lexicographically smallest, we should try to assign `1` whenever possible, starting from the smallest index.  

A simple approach:  
- Initialize all nodes as uncolored.  
- For each node from 1 to n, if uncolored, start BFS and color it `1`.  
- For each neighbor, assign the opposite color.  
- If conflict → `NO`.  

This gives the lexicographically smallest because we always start with `1` for the smallest uncolored node and propagate.

```python
from collections import deque
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    
    for i in range(n):
        if color[i] == -1:
            color[i] = 1
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 3 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
    
    print("YES")
    print(" ".join(str(color[i]) for i in range(n)))

if __name__ == "__main__":
    solve()
```
