We can model this as a bipartite graph problem: each worker is a node, and each conflict is an edge. We need to 2-color the graph (assign shifts 1 and 2) such that no edge connects two nodes of the same color. If the graph is not bipartite, output `NO`. Otherwise, we need the lexicographically smallest assignment.

To get the lexicographically smallest assignment, we can run BFS/DFS coloring, but when we start a new component, we should try assigning color 1 to the smallest-index node in that component, and propagate. This ensures the smallest possible values in the final sequence.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    # Convert 0/1 to 1/2
    print(' '.join(str(c + 1) for c in color))
```
