**Solution Explanation**

For every worker we have to choose one of two schedules `1` or `2`.
Incompatible pairs must obtain different schedules.
The incompatibility relation is an undirected graph.
The task is exactly the *2‑colouring* (bipartite) problem.

If the graph is not bipartite no assignment exists.
If it is bipartite there are two possible colourings for each connected
component – they are obtained from each other by swapping the two colours.
Among all valid colourings we have to output the lexicographically smallest
sequence `s1 … sn`.

--------------------------------------------------------------------

#### 1.   Observations  

* In a connected component the two colourings differ only by a global swap.
* The first position where two colourings can differ is the smallest vertex
  index belonging to that component.
* To obtain the lexicographically smallest whole sequence we must give
  schedule `1` to that smallest index (if possible).  
  Because any other choice would put a `2` there and would be larger
  lexicographically, independent of the rest of the component.

Therefore we can treat each component independently:

* start a BFS/DFS from the smallest not yet visited vertex `v`
* colour `v` with colour `0`
* propagate colours (`0/1`) through the component
* if a conflict appears → graph is not bipartite → answer `NO`
* after the BFS finish, colour `0` corresponds to schedule `1`,
  colour `1` to schedule `2`.  
  Since the root `v` (the smallest index of the component) has colour `0`,
  it automatically receives schedule `1`, which is optimal.

Isolated vertices are a component of size `1`; they receive schedule `1`
as well – also optimal.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n, m
build adjacency list

colour[1…n] = -1          # -1 = unvisited, 0/1 = temporary colours
schedule[1…n] = 0

for v = 1 … n:
    if colour[v] == -1:               # new component, v is its smallest vertex
        queue ← {v}
        colour[v] = 0
        while queue not empty:
            u ← pop queue
            for each neighbour w of u:
                if colour[w] == -1:
                    colour[w] = colour[u] xor 1
                    push w into queue
                else if colour[w] == colour[u]:
                    print "NO" and exit

# graph is bipartite
for i = 1 … n:
    schedule[i] = colour[i] + 1       # 0 → 1, 1 → 2

print "YES"
print schedule[1] … schedule[n] separated by blanks
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible assignment exists,
otherwise it prints the lexicographically smallest feasible assignment.

---

##### Lemma 1  
During the BFS of a component, if the algorithm never detects a conflict,
the obtained `colour` array is a proper 2‑colouring of that component.

**Proof.**  
The BFS starts with a vertex coloured `0`.  
Whenever an edge `(u,w)` is examined, the algorithm assigns `w` the opposite
colour of `u`. Therefore every processed edge connects vertices of different
temporary colours. If later the same edge is examined from the other side,
the colours are already different, so no conflict occurs.
Thus all edges of the component join vertices of different colours. ∎



##### Lemma 2  
If the algorithm prints `NO`, the input graph is not bipartite.

**Proof.**  
`NO` is printed only when an edge `(u,w)` with `colour[u] == colour[w]` is
found. By Lemma&nbsp;1 all previously processed edges respect the colouring,
so the current edge creates an odd cycle, which is a well‑known certificate
that a graph is not bipartite. ∎



##### Lemma 3  
If the input graph is bipartite, the algorithm never prints `NO`.

**Proof.**  
Assume the graph is bipartite. For any component there exists a proper
2‑colouring. The BFS starts with an arbitrary vertex coloured `0`.  
Because a proper 2‑colouring exists, we can rename its two colour classes so
that the start vertex receives colour `0`. Then the BFS rule (always give
the opposite colour to neighbours) reproduces exactly that proper colouring,
hence no conflict can appear. ∎



##### Lemma 4  
For each component the algorithm assigns schedule `1` to the smallest
vertex index of that component.

**Proof.**  
Components are processed in increasing order of their smallest vertex `v`
(because we iterate `v = 1 … n` and start a BFS only when `v` is still
unvisited). The BFS colours `v` with temporary colour `0`.  
Finally we output `schedule = colour + 1`, therefore `v` receives schedule
`1`. ∎



##### Lemma 5  
Let `S` be the schedule sequence produced by the algorithm and `T` any
other feasible schedule sequence. Then `S` is lexicographically not larger
than `T`.

**Proof.**  
Consider the first index `i` where `S` and `T` differ.
All vertices `< i` belong to components already processed earlier,
hence by Lemma&nbsp;4 both `S` and `T` give them schedule `1` (the only
possible value for the smallest vertex of each component).  
Thus `i` is the smallest vertex of its component `C`.  
In `S` this vertex receives schedule `1` (Lemma&nbsp;4).  
In `T` it must receive either `1` or `2`.  
If it were `1`, `S` and `T` would be equal at position `i`, contradicting
the choice of `i`. Hence `T[i] = 2`. Consequently `S[i] = 1 < 2 = T[i]`,
so `S` is lexicographically smaller than `T`. ∎



##### Lemma 6  
If the graph is bipartite, the schedule sequence `S` output by the algorithm
is feasible.

**Proof.**  
By Lemma&nbsp;1 each component is properly 2‑coloured.
Changing temporary colours `0/1` to schedules `1/2` preserves the property
that adjacent vertices receive different schedules.
Thus all incompatibility constraints are satisfied. ∎



##### Theorem  
The algorithm

* prints `NO` **iff** no feasible assignment exists,
* otherwise prints `YES` followed by the lexicographically smallest feasible
  assignment.

**Proof.**  

*If the algorithm prints `NO`*: by Lemma&nbsp;2 the graph is not bipartite,
hence no feasible assignment exists.

*If a feasible assignment does not exist*: the graph is not bipartite,
so during processing some component must contain an odd cycle.
Any BFS of that component inevitably discovers an edge whose ends already
have the same colour, therefore the algorithm prints `NO`.

*If the algorithm prints `YES`*: by Lemma&nbsp;3 the graph is bipartite,
by Lemma&nbsp;6 the produced schedule is feasible,
and by Lemma&nbsp;5 it is lexicographically minimal among all feasible
schedules.

Thus the theorem holds. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and each edge is processed once,
`O(n + m)` time.  
*Overall*:  

- **Time** `O(n + m)` ≤ `4·10⁵` operations, well inside the limit.  
- **Memory** `O(n + m)` for adjacency list, colour and schedule arrays,
  ≤ 256 MB.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = next(it)
        v = next(it)
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0/1 = temporary colours

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # start new component, start is its smallest vertex
        dq = deque([start])
        colour[start] = 0
        while dq:
            u = dq.popleft()
            cu = colour[u]
            for w in adj[u]:
                cw = colour[w]
                if cw == -1:
                    colour[w] = cu ^ 1
                    dq.append(w)
                elif cw == cu:
                    sys.stdout.write("NO")
                    return

    # feasible, build schedule (1/2) from temporary colours
    schedule = [str(colour[i] + 1) for i in range(1, n + 1)]
    sys.stdout.write("YES\n")
    sys.stdout.write(" ".join(schedule))

if __name__ == "__main__":
    solve()
```
