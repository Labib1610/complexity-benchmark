We can model this as a bipartite graph problem.  
Each employee is a node, and each workstation is an edge between two employees who must be in different periods.  
This is exactly a 2-coloring problem (checking if the graph is bipartite).  

To get the lexicographically smallest assignment, we should try to assign period `1` to as many early-numbered employees as possible.  
We can do a BFS/DFS coloring, but when we start a new component, we try assigning the smallest-index node in that component to period `1` first.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        # BFS from i, try color 1 first
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # alternate
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
