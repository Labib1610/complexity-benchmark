We can model this as a bipartite graph problem.  
Each person is a node, and each separation rule is an edge that must connect nodes of different periods (1 or 2).  
This is exactly checking if the graph is bipartite, and if so, we need the lexicographically smallest assignment.

To get the lexicographically smallest assignment, we can use BFS/DFS coloring, but we must try to assign period 1 to the smallest-index node whenever possible.  
We can do this by iterating nodes from 1 to n, and if a node is uncolored, start a BFS/DFS from it with color 1, and color neighbors with the opposite color.  
If a conflict occurs, output `NO`.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0  # 0 means period 1, 1 means period 2
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(' '.join(str(c + 1) for c in color))
```
