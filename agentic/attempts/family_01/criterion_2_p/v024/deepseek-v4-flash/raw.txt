We can model this as a bipartite graph problem: each instance is a node, and each constraint is an edge that must connect nodes of different colors (windows). If the graph is not bipartite, output `NO`. Otherwise, we need the lexicographically smallest assignment.

To get the lexicographically smallest assignment, we can use BFS/DFS coloring, but we must be careful: if we simply color greedily from node 1, we might not get the smallest lexicographic sequence because some components may be disconnected. For each connected component, we can choose which color to assign to the first node in that component (the smallest index in that component) to minimize the overall lexicographic order.

Here’s the plan:

1. Build adjacency list.
2. For each unvisited node, run BFS to color the component with two colors.
3. If conflict → `NO`.
4. For each component, we have two possible colorings (swap colors). Choose the one that gives the smaller lexicographic sequence for the nodes in that component, considering the global order.
5. Output the result.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        # BFS to color component
        color[i] = 0
        q = deque([i])
        comp_nodes = [i]
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                    comp_nodes.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
        if not possible:
            break

        # Now decide orientation for this component
        # comp_nodes sorted by index
        comp_nodes.sort()
        # Try both orientations: color[comp_nodes[0]] = 0 or 1
        # We'll compare the resulting assignments for this component
        # Orientation A: keep as is
        # Orientation B: flip all colors in this component
        # Choose lexicographically smaller for the whole array
        # Since components are independent, we can decide per component
        # But we need to compare only within this component's nodes
        # Because other components are not yet decided, but they will be decided later.
        # For lexicographic smallest overall, we should choose the orientation
        # that gives smaller value at the smallest index in this component.
        # If tie, move to next index, etc.
        # So we compare the two sequences for this component's sorted nodes.
        seqA = [color[x] for x in comp_nodes]
        seqB = [color[x] ^ 1 for x in comp_nodes]
        if seqB < seqA:
            for x in comp_nodes:
                color[x] ^= 1

if not possible:
    print("NO")
else:
    print("YES")
    print(' '.join(str(c + 1) for c in color))
```
