The problem asks us to determine if a graph with $N$ nodes and $M$ edges is bipartite. If it is, we need to output a valid 2-coloring of the nodes (using colors 1 and 2) such that connected nodes have different colors. Specifically, we need the lexicographically smallest sequence of colors $s_1, s_2, \dots, s_N$. If it's not bipartite, we output "NO".

Input constraints: $N, M \le 200,000$.
Time limit: 1 second.
Memory limit: 256 MB.

This is a classic graph problem.
1. **Bipartite Check:** A graph is bipartite if and only if it contains no odd cycles. This can be checked using BFS or DFS.
2. **Lexicographically Smallest:** We want the sequence $s_1, s_2, \dots, s_N$ to be as small as possible in lexicographical order. This means we want $s_1$ to be 1 if possible. If $s_1$ is fixed, we want $s_2$ to be 1 if possible, and so on. However, the constraints link the values. If nodes are in the same connected component, once the color of one node is chosen, the colors of all other nodes in that component are determined (assuming the component is bipartite). If the component is not bipartite, no solution exists.

Let's break down the components. The graph consists of several connected components. For each connected component, we can pick an arbitrary starting node and assign it a color (say 1). Then we propagate the coloring. For a specific component, there are exactly two valid colorings (assuming it's bipartite): one where the starting node is 1, and one where the starting node is 2.
Wait, if we want the sequence $s_1, s_2, \dots, s_N$ to be lexicographically smallest, we need to be careful.
Consider a connected component containing nodes $\{u, v, w, \dots\}$. The relative colors are fixed. Let the two possible colorings be $C_1$ and $C_2$. $C_2$ is just the bitwise negation of $C_1$ (swapping 1 and 2).
We need to decide for each component whether to use $C_1$ or $C_2$.
Since we want the sequence $s_1, s_2, \dots, s_N$ to be lexicographically smallest, we should iterate from $i = 1$ to $N$. If node $i$ is uncolored, it belongs to some component. We have two choices for this component: assign 1 to node $i$ (which propagates to others) or assign 2 to node $i$. Since we want the smallest $s_i$, we should prefer 1.

import sys
from collections import deque

# Increase recursion depth just in case, though not using recursion.
# It's a good practice in competitive programming in Python.
sys.setrecursionlimit(300000)

def main():
    # Read all input at once
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        N = int(next(iterator))
        M = int(next(iterator))
    except StopIteration:
        return

    # Adjacency list
    adj = [[] for _ in range(N + 1)]

    for _ in range(M):
        try:
            u = int(next(iterator))
            v = int(next(iterator))
            adj[u].append(v)
            adj[v].append(u)
        except StopIteration:
            break
            
    colors = [0] * (N + 1)
    
    # Iterate through all nodes to handle disconnected components
    for i in range(1, N + 1):
        if colors[i] == 0:
            # Found a new component
            # We want the lexicographically smallest sequence, so for the first node 
            # in the component (which is i), we assign color 1.
            colors[i] = 1
            queue = deque([i])

                u = queue.popleft()
                current_color = colors[u]
                next_color = 3 - current_color

                        colors[v] = next_color
                        queue.append(v)
                    elif colors[v] == current_color:
                        # Conflict found, not bipartite
                        print("NO")
                        return

    # If we reach here, a valid assignment exists
    print("YES")
    # Using sys.stdout.write for faster output
    sys.stdout.write(" ".join(map(str, colors[1:])) + "\n")
