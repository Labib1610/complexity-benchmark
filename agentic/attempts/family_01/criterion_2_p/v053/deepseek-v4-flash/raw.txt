We can model the gears as nodes in a graph, where each edge means the two nodes must have different values (1 or 2).  
This is a bipartite checking problem. If the graph is not bipartite, output `NO`.  
If it is bipartite, we assign values to get the lexicographically smallest sequence.

We can do a BFS/DFS over each connected component, assigning alternating values.  
To get the lexicographically smallest result, we try to assign `1` to the smallest-index node in each component when possible.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
res = [1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0
    res[start] = 1
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                res[v] = color[v] + 1
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(map(str, res)))
```
