**Solution Explanation**

For every gear we have to choose one of the two modes `1` or `2`.
For each given pair `(u , v)` the two gears must have *different* modes.
So the whole set of gears together with the pairs is an undirected graph and we
have to colour its vertices with two colours such that adjacent vertices obtain
different colours – exactly the *bipartite* graph problem.

If the graph is not bipartite no assignment exists.

If it is bipartite there are usually two possible colourings for each
connected component (the two colour classes can be swapped).
Among all global colourings we need the lexicographically smallest
sequence `s1 … sn` (`1 < 2`).  
The first position where two colourings differ decides which one is smaller,
therefore we want the smallest possible value for the earliest gear,
then for the next one, and so on.

Observation  
Consider one connected component.
Let `v` be the smallest index vertex belonging to this component.
If we can colour the component so that `v` receives colour `1`,
any other valid colouring of the same component would give `v` colour `2`
(because the two colourings are exactly the swap of the colour classes).
Since `1 < 2`, the former is always lexicographically better, independent of
the colours of later vertices.
Hence **the optimal global colouring is obtained by, for every component,
forcing its smallest‑index vertex to colour `1`.**  
All other vertices of the component are then forced.

Algorithm
---------

```
read n, m
build adjacency list
answer[1…n] = 0
visited[1…n] = false
colour[1…n] = 0/1   (temporary bipartite colour)

for v = 1 … n:
    if not visited[v]:
        # explore this component
        queue = [v]
        visited[v] = true
        colour[v] = 0
        comp_vertices = [v]
        ok = true
        while queue not empty:
            x = pop queue
            for each neighbour y of x:
                if not visited[y]:
                    visited[y] = true
                    colour[y] = colour[x] ^ 1
                    queue.append(y)
                    comp_vertices.append(y)
                else:
                    if colour[y] == colour[x]:
                        print "NO" and exit   # not bipartite
        # component is bipartite
        # decide orientation
        min_vertex = min(comp_vertices)          # actually v itself
        if colour[min_vertex] == 0:
            # keep mapping: colour 0 -> 1, colour 1 -> 2
            for u in comp_vertices:
                answer[u] = 1 if colour[u] == 0 else 2
        else:
            # swap mapping
            for u in comp_vertices:
                answer[u] = 1 if colour[u] == 1 else 2

print "YES"
print answer[1] … answer[n]
```

Correctness Proof
-----------------

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest valid assignment.

### Lemma 1  
If during BFS an edge `(x, y)` with `colour[x] == colour[y]` is found,
the graph is not bipartite, therefore no assignment exists.

*Proof.* In a bipartite graph every edge connects vertices of opposite colour.
Finding an edge whose ends have equal colour contradicts bipartiteness.
∎



### Lemma 2  
If the algorithm finishes all BFS traversals without triggering Lemma 1,
the graph is bipartite and the produced `answer` satisfies all constraints.

*Proof.* Each component is coloured with two temporary colours `0`/`1`
so that adjacent vertices differ (standard BFS property).
Afterwards we possibly swap the two colour classes, which still keeps
adjacent vertices different.
Thus every edge connects vertices with different final values (`1` vs `2`).
∎



### Lemma 3  
For a fixed connected component `C`, let `v` be its smallest index vertex.
Among all valid colourings of `C` the one that gives `v` colour `1`
is lexicographically minimal when considering only the positions of `C`.

*Proof.* Any valid colouring of `C` uses exactly the two colour classes,
so the only other possibility is the colour swap, which gives `v` colour `2`.
Since `1 < 2`, the colouring with `v = 1` is strictly smaller at position `v`,
and all earlier positions belong to other components and are identical.
∎



### Lemma 4  
The algorithm assigns colour `1` to the smallest index vertex of every
component.

*Proof.* In each component we start BFS from the first unvisited vertex `v`,
which is exactly the smallest index vertex of that component
(because all smaller indices have already been visited in previous components).
We set its temporary colour to `0`.  
If after BFS `colour[v] == 0` we keep the mapping `0 → 1`.  
Otherwise we swap, making temporary colour `1` map to `1`.  
Hence in both cases `v` receives final colour `1`. ∎



### Lemma 5  
The assignment produced by the algorithm is the lexicographically smallest
among all valid assignments.

*Proof.* Consider the vertices in increasing order.
Take the first vertex `p` where the algorithm’s assignment could differ from
some other valid assignment `A`.  
`p` belongs to some component `C`.  
By Lemma 4 the algorithm gives `p` colour `1`.  
If `A` gave `p` colour `2`, then by Lemma 3 `A` is not optimal for component
`C`, contradicting the assumption that `A` is lexicographically minimal.
Therefore any other valid assignment must coincide with the algorithm on
every position, i.e. the algorithm’s assignment is the unique lexicographically
smallest one. ∎



### Theorem  
The program outputs

* `NO` iff no assignment satisfying all pairs exists;
* otherwise `YES` and the lexicographically smallest satisfying assignment.

*Proof.*  
If the program prints `NO`, it must have detected a same‑colour edge,
hence by Lemma 1 the graph is not bipartite and no assignment exists.
Conversely, if the graph is not bipartite, any BFS will encounter such an
edge, so the program will print `NO`.

If the program prints `YES`, by Lemma 2 the printed assignment is valid.
By Lemma 5 it is the lexicographically smallest among all valid assignments.
∎



Complexity Analysis
-------------------

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge processed once → `O(n + m)` time.  
*Overall*: `O(n + m)` time, `O(n + m)` memory, well within limits (`n,m ≤ 2·10⁵`).

Reference Implementation (Python 3)
------------------------------------*/

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    visited = [False] * (n + 1)
    col = [0] * (n + 1)          # temporary 0/1 colour
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if visited[start]:
            continue
        # BFS this component
        q = deque([start])
        visited[start] = True
        col[start] = 0
        comp = [start]
        while q:
            x = q.popleft()
            cx = col[x]
            for y in adj[x]:
                if not visited[y]:
                    visited[y] = True
                    col[y] = cx ^ 1
                    q.append(y)
                    comp.append(y)
                elif col[y] == cx:
                    print("NO")
                    return
        # decide orientation: smallest index vertex gets final colour 1
        min_v = min(comp)   # actually start, but keep for clarity
        if col[min_v] == 0:
            for v in comp:
                ans[v] = 1 if col[v] == 0 else 2
        else:
            for v in comp:
                ans[v] = 1 if col[v] == 1 else 2

    # all good
    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
