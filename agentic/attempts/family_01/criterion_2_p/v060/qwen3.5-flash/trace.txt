The problem asks us to determine if we can assign $N$ chemical compounds to two vaults (let's call them Vault 1 and Vault 2) such that no two compounds that are "mutually volatile" are placed in the same vault. We are given $M$ pairs of mutually volatile compounds. If a valid assignment exists, we need to output "YES" followed by the assignment sequence $s_1, \dots, s_N$ which is lexicographically smallest. If no such assignment exists, we output "NO".

This problem can be modeled as a graph problem. Let the compounds be vertices in a graph $G = (V, E)$, where $V = \{1, \dots, N\}$. The volatile pairs correspond to edges in $E$. The condition that no two compounds in a volatile pair are in the same vault means that the graph $G$ must be bipartite. In a bipartite graph, the vertices can be divided into two disjoint sets $V_1$ and $V_2$ such that every edge connects a vertex in $V_1$ to one in $V_2$. Here, $V_1$ corresponds to compounds in Vault 1 and $V_2$ corresponds to compounds in Vault 2.

If the graph is not bipartite (i.e., it contains an odd cycle), then no valid assignment exists, and we should output "NO".
If the graph is bipartite, there might be multiple valid assignments. Specifically, for each connected component of the graph, if we fix the color (vault assignment) of one vertex, the colors of all other vertices in that component are determined. However, we have a choice: for a connected component, we can flip all colors (swap Vault 1 and Vault 2). Since the graph might have multiple connected components, we have $2^k$ possible valid assignments, where $k$ is the number of connected components.

We want the lexicographically smallest sequence $s_1, s_2, \dots, s_N$. This means we want $s_1$ to be 1 if possible. If $s_1$ is fixed to 1 by the constraints of its component, great. If it's not fixed (i.e., it's part of a component where we can choose), we should try to set $s_1=1$. Then, given $s_1$, we want $s_2$ to be 1 if possible, and so on. However, simply iterating $i$ from 1 to $N$ and greedily setting $s_i=1$ might not be straightforward because setting $s_i$ might constrain $s_j$ for $j < i$ (which are already fixed) or $j > i$. Actually, the standard approach for lexicographically smallest assignment in this context involves processing components or nodes in a specific order.

Wait, let's refine the greedy strategy. We want the sequence $s_1, s_2, \dots, s_N$ to be lexicographically smallest. This means we prioritize $s_1$, then $s_2$, etc.
Since the assignment for a connected component is determined by the assignment of any single node in it (up to a global flip of the component), the decision for $s_i$ depends on the component $i$ belongs to.

Since we want to minimize $s_1$, we look at the component containing node 1. Let this be component $C_x$. We check the two possible assignments for $C_x$. import sys
```python
from collections import deque

def solve():
    # Increase recursion depth just in case, though we use iterative BFS
    sys.setrecursionlimit(200005)
    
    input_data = sys.stdin.read().split()
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
        
    s = [0] * (n + 1)
    
    for i in range(1, n + 1):
        if s[i] == 0:
            # Start BFS for this component
            # We want to assign s[i] = 1 to minimize lexicographically
            s[i] = 1
            queue = deque([i])
            
            while queue:
                u = queue.popleft()
                current_color = s[u]
                next_color = 3 - current_color
                
                for v in adj[u]:
                    if s[v] == 0:
                        s[v] = next_color
                        queue.append(v)
                    elif s[v] != next_color:
                        # Conflict found
                        print("NO")
                        return

    print("YES")
    # s[1:] contains the assignments for 1 to N
    print(*(s[1:]))
```

```python
import sys
from collections import deque

# Increase recursion depth just in case, though we use iterative BFS
sys.setrecursionlimit(200005)

def solve():
    # Read all input from standard input
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency list for the graph
    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
        
    # Array to store the assignment (1 or 2)
    # 0 indicates unassigned
    s = [0] * (n + 1)
    
    # Iterate through all nodes to handle disconnected components
    for i in range(1, n + 1):
        if s[i] == 0:
            # Start BFS for the connected component containing i
            # To ensure lexicographically smallest sequence, we assign s[i] = 1
            
            s[i] = 1
            queue = deque([i])
            
            while queue:
                u = queue.popleft()
                current_color = s[u]
                next_color = 3 - current_color  # If current is 1, next is 2; if 2, next is 1
                
                for v in adj[u]:
                    if s[v] == 0:
                        s[v] = next_color
                        queue.append(v)
                    elif s[v] != next_color:
                        # Conflict detected: adjacent nodes have same color
                        print("NO")
                        return

    # If no conflicts were found
    print("YES")
    # Print the assignments for nodes 1 to N
    print(" ".join(map(str, s[1:])))

if __name__ == '__main__':
    solve()
```

We assign $s_i = 1$.
This determines the assignment for the whole component.
Why is this optimal?
Suppose the optimal assignment has $s_i = 2$.
Then the sequence starts with ... 1 ... 2 ... (at index $i$).
Our assignment starts with ... 1 ... 1 ... (at index $i$).
Since $1 < 2$, our assignment is lexicographically smaller at the first differing position (which is $i$, assuming $s_j$ are fixed for $j < i$).
Wait, do we assume $s_j$ are fixed for $j < i$?
Yes, because we iterate $1 \dots N$. When we are at $i$, $s_1 \dots s_{i-1}$ are already determined.
Actually, $s_j$ for $j < i$ might have been determined by a previous component processing.
If $j$ and $i$ are in the same component, then $j$ would have been processed before $i$, so $i$ would have been assigned already.
So if we are at $i$ and $s_i == 0$, it implies $i$ is the first node of its component encountered in the loop order.
So $i$ is indeed the smallest index in its component.
Thus, minimizing $s_i$ is the correct greedy step.
And since $s_i$ can be 1 or 2 (in a bipartite component), choosing 1 is always best for lexicographical order.
So the logic holds perfectly.

```python
import sys
from collections import deque

def solve():
    # Read all input from standard input efficiently
    input_data = sys.stdin.read().split()
    
    if not input_data:
        return

    iterator = iter(input_data)
    
    try:
        n = int(next(iterator))
        m = int(next(iterator))
    except StopIteration:
        return

    # Adjacency list for the graph
    # Using 1-based indexing for convenience
    adj = [[] for _ in range(n + 1)]
    
    for _ in range(m):
        u = int(next(iterator))
        v = int(next(iterator))
        adj[u].append(v)
        adj[v].append(u)
        
    # Array to store the assignment (1 or 2)
    # 0 indicates unassigned
    s = [0] * (n + 1)
    
    # Iterate through all nodes 1 to N
    for i in range(1, n + 1):
        if s[i] == 0:
            # Start BFS for the connected component containing i
            # To ensure lexicographically smallest sequence, we assign s[i] = 1
            # This is valid because i is the smallest index in its component
            # (since all j < i have been processed and would have assigned this component if i was connected)
            
            s[i] = 1
            queue = deque([i])
            
            while queue:
                u = queue.popleft()
                current_color = s[u]
                next_color = 3 - current_color  # Flip color: 1->2, 2->1
                
                for v in adj[u]:
                    if s[v] == 0:
                        s[v] = next_color
                        queue.append(v)
                    elif s[v] != next_color:
                        # Conflict detected: adjacent nodes have same color
                        print("NO")
                        return

    # If no conflicts were found
    print("YES")
    # Print the assignments for nodes 1 to N
    print(" ".join(map(str, s[1:])))

if __name__ == '__main__':
    solve()
```
