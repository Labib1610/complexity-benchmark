We can model this as a graph problem: each technician is a node, and each constraint is an edge meaning “these two must be in different shifts.” That means the graph must be bipartite. If any connected component is not bipartite, the answer is NO.

When the graph is bipartite, we need the lexicographically smallest assignment, i.e., prefer shift 1 for smaller indices whenever possible格雷.

We can do BFS/DFS per component and assign greedily: start with 1 for the smallest uncolored node in each componentanding, then alternate, but if any already colored neighbor conflicts, we handle by flipping to maintain bipartiteness and lexicographic minimality. Since each component is independently colored, we can choose the starting color for each component to minimize the sequence without breaking constraints.

We’ll use iterative BFS with two possible colorings; pick the one that gives lower lexicographic order.

```python
import sys
from collections import deque

input = sys.stdin.readline

def solve():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * n
    ans = [0] * n

    for start in range(n):
        if color[start] != -1:
            continue
        # BFS component
        color[start] = 0
        q = deque([start])
        comp = [start]
        ok = True
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                    comp.append(v)
                elif color[v] == color[u]:
                    ok = False
        if not ok:
            print("NO")
            return

        # Now we have one component colored, but we need to see if flipping
        # the component gives a lexicographically smaller assignment.
        # Build the two possible color assignments for this component.
        # color1: start with 0 at start, color2: start with 1 at start
        # We'll just check which gives smaller result.
        color1 = [0] * n
        color2 = [0] * n
        # color1 is already in `color` for this component
        # For color2 we flip
        for u in comp:
            color1[u] = color[u] + 1  # convert to 1/2 shift
            color2[u] = (color[u] ^ 1) + 1

        # Only compare within the component, outside we keep other components fixed
        # But since we process in increasing start order, earlier components fixed.
        # We can decide after the whole BFS if we want better lexicographic order.
        # Standard trick: decide now based on smallest node in component.
        # For lexicographically smallest, we want smallest index in this component
        # to get shift 1 if possible.
        min_node = min(comp)
        if color1[min_node] == 2:
            # flip to make min_node shift 1
            for u in comp:
                color[u] ^= 1

    # Now color has 0/1; convert to 1/2
    for i in range(n):
        ans[i] = color[i] + 1

    print("YES")
    print(" ".join(map(str, ans)))

if __name__ == "__main__":
    solve()
```
