We can model this as a bipartite graph problem: each worker is a node, and each constraint is an edge between two nodes that must have different shift values (1 or 2).  

If the graph is bipartite, a valid assignment exists. To get the lexicographically smallest assignment, we can run BFS/DFS and assign the smallest possible value (1) whenever possible, starting from node 1.

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n  # 0 = uncolored, 1 or 2
for i in range(n):
    if color[i] == 0:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == 0:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
