We can model the employees and conflicts as an undirected graph.  
The problem is essentially checking if the graph is bipartite, and if so, producing the lexicographically smallest 2-coloring (with colors 1 and 2).

The structural properties given in the problem are not needed for the solution itself — they just guarantee that the graph is sparse enough for our approach to run in time.

We’ll do a BFS/DFS over each connected component, assigning colors alternately.  
To get the lexicographically smallest assignment, we always try to assign color 1 to the smallest-indexed uncolored vertex when starting a new component, and during BFS we process neighbors in increasing order.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
