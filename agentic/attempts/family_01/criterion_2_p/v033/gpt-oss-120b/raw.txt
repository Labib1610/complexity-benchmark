**Solution Explanation**

For every incompatibility rule `(u , v)` the two workers must work in different
shifts.  
Thus we have to 2‑colour the graph whose vertices are the workers and whose
edges are the rules.  
If the graph is not bipartite the answer is `NO`.  
Otherwise there are exactly two colourings for each connected component
(the two colour classes can be swapped).  
To obtain the *lexicographically smallest* sequence `s1 … sn`
we choose, for every component, the colouring in which the smallest indexed
vertex of this component receives colour `1`.  
All other vertices of the component are forced then.

The algorithm is therefore:

```
for every vertex not visited yet
        run BFS/DFS, colour with 0/1
        if a conflict appears → not bipartite → NO
        collect all vertices of this component
        let v0 = minimum vertex index in the component
        if colour[v0] == 1          # i.e. it would become shift 2
                flip colours of the whole component
output YES and (colour[i] + 1) for i = 1..n
```

The flip is cheap – we just remember a boolean `flip` for the component and
apply it when writing the answer.

`n, m ≤ 2·10⁵`, so an `O(n+m)` BFS/DFS with adjacency lists easily fits into the
limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible assignment exists,
and otherwise prints the lexicographically smallest feasible assignment.

---

##### Lemma 1  
During the traversal of a connected component the algorithm assigns colours
`0` and `1` such that every processed edge connects vertices of different colours
*iff* the component is bipartite.

**Proof.** The standard BFS/DFS bipartite test: we start with an arbitrary
vertex coloured `0`. Whenever we traverse an edge `(x, y)` we set `colour[y]`
to `1‑colour[x]`. If later we encounter an already coloured vertex and the
required colour differs from the stored one, an odd cycle exists, i.e. the
component is not bipartite. Conversely, if no conflict occurs, the obtained
2‑colouring is a proper bipartition. ∎



##### Lemma 2  
If a component is bipartite, the algorithm can (and does) produce a colouring
where the smallest indexed vertex of the component receives colour `1`.

**Proof.** After the BFS we have some 2‑colouring `c`. Let `v₀` be the smallest
index in the component. If `c[v₀] = 0` we keep the colouring.
If `c[v₀] = 1` we flip every colour in the component (`c' = 1‑c`).  
Flipping preserves the property “adjacent vertices have different colours”.
Now `c'[v₀] = 0`. Finally we output `c+1`, i.e. colour `0` becomes shift `1`. ∎



##### Lemma 3  
Among all feasible assignments, the one produced by the algorithm is
lexicographically smallest.

**Proof.** Consider the vertices in increasing order.
Take the first vertex `i` whose shift differs between the algorithm’s output
and any other feasible assignment `A`.  
Vertex `i` belongs to some component `C`. By construction of the algorithm,
`i` is the smallest index of `C`. Lemma&nbsp;2 guarantees that the algorithm
assigns shift `1` to `i`. Any other feasible assignment must assign either `1`
or `2` to `i`. If it assigned `2`, its sequence would be lexicographically larger
at position `i`. If it assigned `1`, then the two assignments coincide at `i`,
contradicting the choice of `i`. Hence no feasible assignment can be smaller,
so the algorithm’s assignment is lexicographically minimal. ∎



##### Lemma 4  
If the algorithm prints `NO` then no feasible assignment exists.

**Proof.** The algorithm prints `NO` only when Lemma&nbsp;1 detects a conflict,
i.e. some component is not bipartite. A non‑bipartite graph cannot be coloured with
two colours respecting all edges, therefore no assignment satisfies all rules. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff the given incompatibility graph has no valid 2‑shift assignment;  

* otherwise `YES` followed by the lexicographically smallest valid assignment.

**Proof.**  
*If part*: By Lemma&nbsp;4, printing `NO` implies impossibility.  

*Only‑if part*: If the algorithm finishes without conflict, every component is
bipartite (Lemma&nbsp;1), thus a valid assignment exists. The algorithm outputs a
colouring that respects all edges. By Lemma&nbsp;2 each component’s smallest
vertex gets shift `1`; by Lemma&nbsp;3 the whole sequence is lexicographically
minimal among all feasible assignments. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency lists*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)`  
*Flipping & output*: `O(n)`.

Total time `O(n + m)`, total memory `O(n + m)`, well within the limits.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # 0 or 1
    comp_vertices = []               # temporary list for current component
    from collections import deque

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp_vertices.clear()
        comp_vertices.append(start)
        ok = True
        while q:
            u = q.popleft()
            cu = colour[u]
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = 1 - cu
                    q.append(v)
                    comp_vertices.append(v)
                elif colour[v] == cu:
                    # conflict -> not bipartite
                    print("NO")
                    return
        # make smallest index vertex colour 0 (shift 1)
        min_v = min(comp_vertices)
        if colour[min_v] == 1:
            # flip whole component
            for v in comp_vertices:
                colour[v] ^= 1

    # all good
    out = ['YES']
    shifts = [str(colour[i] + 1) for i in range(1, n + 1)]
    out.append(' '.join(shifts))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```
