**Solution Explanation**

For every conflict `(u , v)` the two workers must belong to different shifts.
Thus we have to 2‑colour the undirected graph whose vertices are the workers
and whose edges are the conflicts.

The graph is *bipartite* iff such a colouring exists.
If it is not bipartite we output `NO`.

If it is bipartite there are usually two possible colourings for each
connected component – we may exchange the two colour classes.
Among all global colourings we have to output the lexicographically smallest
sequence  

`c1 c2 … cn`  (`ci ∈ {1,2}`).

--------------------------------------------------------------------

#### 1.   Lexicographically smallest colouring

Consider one connected component.
Let `v` be the smallest numbered vertex of this component.
All vertices with a smaller index belong to earlier components and are already
fixed, therefore the colour of `v` decides the lexicographic order for the
whole component.

*If we can colour `v` with `1`, we must do it* – otherwise the whole answer would
start with a larger number at position `v`.

In a bipartite component the vertices are split into two colour classes
(`class 0` and `class 1`) by any BFS/DFS that respects the edge constraint.
Exactly one of those classes contains `v`.  
We simply give colour `1` to that class and colour `2` to the other one.
This yields the smallest possible prefix, and because later components start
only after all vertices of the current component, the whole sequence becomes
lexicographically minimal.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n , m
build adjacency list

colour[1..n] = 0          # 0 = not visited, 1 or 2 = final shift
temp[1..n]   = -1         # temporary 0/1 during BFS of one component

for i = 1 .. n
    if colour[i] == 0                # new component, i is its smallest vertex
        BFS starting from i
            assign temp values 0/1
            if we ever need to assign a vertex both 0 and 1 -> NOT bipartite
        after BFS:
            if component is not bipartite -> print NO and exit
            # decide final colours
            if temp[i] == 0:
                give final colour 1 to all vertices with temp == 0
                give final colour 2 to all vertices with temp == 1
            else:
                give final colour 1 to all vertices with temp == 1
                give final colour 2 to all vertices with temp == 0
print YES and the array colour[1..n]
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible schedule exists,
otherwise prints `YES` and the lexicographically smallest feasible schedule.

---

##### Lemma 1  
During the BFS of a component the algorithm assigns a temporary value
`temp[v] ∈ {0,1}` to every visited vertex such that for every edge `(x,y)`
`temp[x] ≠ temp[y]`.  
If this is impossible (an edge connects two vertices already having the same
temporary value) the component is not bipartite.

**Proof.**  
BFS starts with `temp[start]=0`. Whenever we traverse an edge `(u,v)` we set
`temp[v]=1‑temp[u]`. If `v` was already visited we check the condition.
If it fails we have found an odd cycle, i.e. the component is not bipartite.
Otherwise all processed edges satisfy the condition, therefore after the BFS
the invariant holds for the whole component. ∎



##### Lemma 2  
If the algorithm finishes a component without reporting a conflict,
the component is bipartite and the two sets  
`A = { v | temp[v]=0 }` , `B = { v | temp[v]=1 }` form a valid bipartition.

**Proof.** Directly from Lemma&nbsp;1: all edges go between `A` and `B`. ∎



##### Lemma 3  
For a bipartite component whose smallest vertex is `s`,
the algorithm assigns shift `1` to `s`.

**Proof.**  
`s` is the start vertex of the BFS, therefore `temp[s]` is either `0` or `1`.
The algorithm afterwards gives shift `1` to the whole set that contains `s`
(and shift `2` to the other set). Hence `s` receives shift `1`. ∎



##### Lemma 4  
Let `C1 , C2 , … , Ck` be the connected components ordered by their smallest
vertex (the order in which the outer loop processes them).  
The schedule produced by the algorithm is lexicographically minimal among all
feasible schedules.

**Proof.**  
Consider the first component `C1`.  
By Lemma&nbsp;3 its smallest vertex `v1` gets shift `1`. Any feasible schedule
must assign either `1` or `2` to `v1`. If it assigned `2`, the whole sequence
would be lexicographically larger at position `v1`. Hence every lexicographically
minimal schedule must also give `v1` shift `1`.  
With `v1` fixed, the colours of the remaining vertices of `C1` are forced
(because the two colour classes are complementary). Thus the prefix up to the
largest index of `C1` is uniquely determined and equal to the algorithm’s
output.

Now remove `C1`. The same argument applied to `C2` (its smallest vertex is the
first still‑free position) shows that any lexicographically minimal schedule
must coincide with the algorithm on `C2` as well, and so on for all components.
Therefore the whole sequence is the unique lexicographically smallest feasible
one. ∎



##### Lemma 5  
If the algorithm prints `NO` then no feasible schedule exists.

**Proof.**  
`NO` is printed only when some component is detected as non‑bipartite
(Lemma&nbsp;1). A non‑bipartite graph cannot be 2‑coloured, therefore no
schedule satisfies all constraints. ∎



##### Lemma 6  
If the algorithm prints `YES` then the printed schedule satisfies all
constraints.

**Proof.**  
For every component the algorithm used the bipartition from Lemma&nbsp;2 and
assigned different final shifts to the two sides, so every edge connects workers
with different shifts. All workers receive exactly one shift, hence the schedule
is feasible. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff the instance has no feasible schedule;  

* otherwise `YES` and the lexicographically smallest feasible schedule.

**Proof.**  
*If* the algorithm outputs `NO`, by Lemma&nbsp;5 no schedule exists.  

*If* a feasible schedule exists, the graph is bipartite, therefore every
component passes the BFS test and the algorithm reaches the `YES` branch.
By Lemma&nbsp;6 the produced schedule is feasible.
By Lemma&nbsp;4 it is the lexicographically smallest among all feasible ones. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)` time.  
Overall time `O(n + m)` ≤ `4·10⁵`, well inside the limit.  
Memory: adjacency list (`2m` integers) + a few arrays of size `n` → `O(n + m)` ≤
`~ 5·10⁵` integers ≈ a few MB, below 256 MB.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    final = [0] * (n + 1)          # 0 = unassigned, 1 or 2 = answer
    temp = [-1] * (n + 1)         # temporary 0/1 during BFS

    for start in range(1, n + 1):
        if final[start]:
            continue
        # BFS of this component
        q = deque([start])
        temp[start] = 0
        comp = [start]
        bip = True
        while q and bip:
            u = q.popleft()
            for v in adj[u]:
                if temp[v] == -1:
                    temp[v] = 1 - temp[u]
                    q.append(v)
                    comp.append(v)
                elif temp[v] == temp[u]:
                    bip = False
                    break
        if not bip:
            print("NO")
            return
        # decide final colours: give 1 to the side containing 'start'
        side_start = temp[start]
        for v in comp:
            if temp[v] == side_start:
                final[v] = 1
            else:
                final[v] = 2
        # reset temp for next component
        for v in comp:
            temp[v] = -1

    print("YES")
    out = ' '.join(str(final[i]) for i in range(1, n + 1))
    sys.stdout.write(out)

if __name__ == "__main__":
    solve()
```
