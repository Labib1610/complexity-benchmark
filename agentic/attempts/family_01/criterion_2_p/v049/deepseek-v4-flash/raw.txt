We can model this as a graph coloring problem with two colors, which is equivalent to checking if the graph is bipartite.  
If it is bipartite, we can assign states 1 and 2 to the two partitions.  
To get the lexicographically smallest assignment, we should try to assign state 1 to as many low-index nodes as possible, which means we should start BFS/DFS from each unvisited node and assign it state 1 if possible.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
