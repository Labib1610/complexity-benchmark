We can model this as a bipartite graph problem: each tower is a node, and each interfering pair is an edge. We need to color the graph with two colors (frequencies 1 and 2) such that no two adjacent nodes share the same color. This is possible if and only if the graph is bipartite.

We also need the lexicographically smallest assignment, so we should try to assign frequency 1 to node 1 if possible, and then proceed in order, using BFS/DFS and assigning the smallest possible color at each step.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 1
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]  # alternate 1 <-> 2
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
