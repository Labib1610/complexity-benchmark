We can model this as a bipartite graph problem: each technician is a node, and each shared-tool pair is an edge. We need to assign each node to one of two phases (1 or 2) such that no edge connects two nodes in the same phase. This is exactly checking if the graph is bipartite and finding a valid 2-coloring.

To get the lexicographically smallest schedule, we assign phase 1 to the smallest possible node first, then propagate the coloring using BFS/DFS, and if a conflict occurs, it’s impossible.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

# Convert 0/1 to 1/2
res = [1 if c == 0 else 2 for c in color]
print("YES")
print(" ".join(map(str, res)))
```
