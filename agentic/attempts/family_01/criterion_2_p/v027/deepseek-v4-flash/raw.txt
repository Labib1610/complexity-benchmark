We can model this as a **bipartite graph** problem:  
Each satellite is a node, and each hazard is an edge.  
We need to assign each node a color (1 or 2) such that no edge connects two nodes of the same color.  
This is possible only if the graph is bipartite.

To get the **lexicographically smallest** assignment, we process nodes in order from 1 to n.  
For each uncolored node, we start a BFS/DFS and try to assign color 1 if possible;  
if that leads to a conflict, we backtrack and try color 2.  
But since the graph is bipartite, we can simply do BFS and assign the smallest possible color at each step.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0  # try 0 first (will output as 1)
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
