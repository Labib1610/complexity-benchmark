We can model this as a graph problem: each emitter is a node, and each intersection is an edge.  
We need to assign each node a value of 1 or 2 such that adjacent nodes have different values — that’s exactly a **bipartite graph check** with 2-coloring.

To get the **lexicographically smallest** assignment, we should try to assign `1` whenever possible, which means we should start BFS/DFS from the smallest unvisited node and assign it color `1`.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * (n + 1)

for start in range(1, n + 1):
    if color[start] == -1:
        color[start] = 1
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # alternate 1 <-> 2
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(1, n + 1)))
```
