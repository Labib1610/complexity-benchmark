We need to check if the graph is bipartite and output the lexicographically smallest coloring.

Since the problem asks for lexicographically smallest, we should try assigning shifts in order of workers 1..n with preference to 1 unless impossible.

Here’s the approach:
- Build adjacency list.
- Run BFS/DFS coloring, but when assigning colors, always try to use color 1 first if possible; if that causes a conflict, then use 2.
- If conflict occurs, print NO.

However, standard bipartite check with colors 1 and 2 will give some assignment. For lexicographically smallest, during BFS/DFS from each unvisited node, try to color with 1 first)Skip? Actually when exploring, if a neighbor already has a color, check consistency quantity of input does not matter — if the graph is bipartite, the coloring is unique up to flipping connected component.  
Lexicographically smallest means we want smallest possible colors for indices 1,2,... in ordermk.

The trick: For each component, we may choose which side is 1 and which is 2, because flipping an entire component changes the global lexicographic order. So we should pick the orientation that makes earlier-labeled nodes get 1 when possible.

So algorithm:
1. BFS/DFS to color each component.
2. For each component, collect the two color classes.
3. For each component independently, decide orientation: put color 1 on the set that contains the smallest index in that component (since that minimizes lexicographic order).
4. Assign based on oriented coloring.

Implementation:

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * n
    for start in range(n):
        if color[start] != -1:
            continue
        # BFS to color component
        color[start] = 0
        q = deque([start])
        comp_nodes = []
        while q:
            u = q.popleft()
            comp_nodes.append(u)
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    return
        # Now we have coloring 0/1 in this component
        # We need to decide if we flip this component to make lexicographically smallest
        # Find min index in component
        min_node = min(comp_nodes)
        if color[min_node] == 1:
            # flip colors in this component
            for node in comp_nodes:
                color[node] = 1 - color[node]

    # Output
    ans = [1 if c == 0 else 2 for c in color]
    print("YES")
    print(" ".join(map(str, ans)))

if __name__ == "__main__":
    solve()
```
