We need to check if the graph is bipartite and if the conditions hold.  

The condition  
\[
\sum_{x \in P_1} c_x + \sum_{y \in P_2} c_y = 2m
\]  
is always true if every edge connects different periods, because each edge contributes 1 to the sum from each endpoint.  

The condition \(k = m\) means every edge must be between different periods — i.e., the graph must be bipartite.  

So the problem reduces to:  
- Check if the graph is bipartite.  
- If yes, output the lexicographically smallest 2-coloring (with 1 and 2).  

To get lexicographically smallest, we assign period 1 to the smallest possible vertex in each component, then BFS/DFS color.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
edges = []
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)
    edges.append((u, v))

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
