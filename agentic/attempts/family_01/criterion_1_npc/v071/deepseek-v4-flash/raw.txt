We need to assign each node one of three colors (1, 2, 3) such that no two adjacent nodes share the same color, and the sequence of colors is lexicographically smallest.

Since \( n \leq 40 \), we can use a backtracking search with pruning.  
We’ll try to assign colors from 1 to 3 for each node in order, and check constraints with already assigned neighbors.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in range(1, 4):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
