**Solution Explanation**

The only real restriction is the *toxicity isolation* – two species that are a toxic pair must not be placed in the same greenhouse.
The water limit (45 plants per greenhouse) is never tighter than the total number of species (`n ≤ 40`), and the filtration budget (`800`) is larger than the maximal possible number of toxic pairs (`40·39/2 = 780`).  
Therefore the problem reduces to:

*Is the given undirected graph 3‑colourable?*  
If yes, output any proper 3‑colouring (colours `1,2,3`).

`n ≤ 40`, so an exponential back‑tracking search with good pruning easily fits into the limits.



--------------------------------------------------------------------

#### 1.   Data structures
* `adj[v]` – list of neighbours of vertex `v` (0‑based).
* `color[v]` – current colour of `v` (`-1` = uncoloured, otherwise `0,1,2`).

--------------------------------------------------------------------

#### 2.   Vertex ordering – DSATUR heuristic
At each recursion step we choose the *most constrained* uncoloured vertex:

```
score(v) = number of already coloured neighbours of v
```

The vertex with the largest `score` (break ties by degree) is selected.
This dramatically reduces the search tree.

--------------------------------------------------------------------

#### 3.   Recursive search

```
dfs(coloured_cnt):
    if coloured_cnt == n:   success
    pick vertex v as described above
    for each colour c in {0,1,2}:
        if no neighbour of v already has colour c:
            colour v with c
            if dfs(coloured_cnt+1): return True
            undo colour of v
    return False
```

Because `n` is tiny, this simple recursion finishes far below the time limit.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and a valid assignment iff such an
assignment exists.

---

##### Lemma 1  
During the search, a vertex is coloured only with a colour that does not
conflict with any already coloured neighbour.

**Proof.** Before assigning colour `c` to vertex `v` the algorithm checks all
neighbours of `v`. If a neighbour already has colour `c` the colour is rejected.
∎



##### Lemma 2  
If the algorithm reaches `coloured_cnt == n`, the obtained colouring is a
proper 3‑colouring of the whole graph.

**Proof.** By Lemma&nbsp;1 every coloured vertex respects all edges to already
coloured vertices. When the last vertex is coloured, *all* edges have both ends
coloured, and none of them connects equal colours. Hence the colouring is proper.
∎



##### Lemma 3  
If a proper 3‑colouring exists, the recursive search will eventually find
one.

**Proof.** Consider any fixed proper 3‑colouring `C`. The recursion explores
all possibilities of assigning colours to vertices, but it never discards a
partial assignment that can be extended to `C`:
whenever the algorithm tries a colour for a vertex, the colour equals `C(v)`
is among the three candidates and is allowed because all neighbours already
coloured agree with `C` (they have different colours). Therefore the branch
following exactly the colours of `C` is never pruned and reaches the leaf
where all vertices are coloured. Consequently the algorithm will succeed.
∎



##### Lemma 4  
If the algorithm finishes with `NO`, no proper 3‑colouring exists.

**Proof.** The algorithm exhaustively explores the search tree, pruning only
when a colour would immediately violate an edge (which any proper colouring
must also avoid). By Lemma&nbsp;3, any existing proper colouring would correspond
to a leaf that the algorithm would reach. Since none is reached, no proper
3‑colouring exists.
∎



##### Theorem  
The program outputs  

* `YES` and a list of greenhouse numbers `1..3` **iff** a feasible assignment
  satisfying all original constraints exists; otherwise it outputs `NO`.

**Proof.**  
*If the program prints `YES`*: by Lemma&nbsp;2 the produced assignment is a proper
3‑colouring, therefore respects the toxicity restriction. The water limit
(≤45 plants per greenhouse) holds because `n ≤ 40`. The filtration budget is
≤ total number of edges ≤ 780 ≤ 800. Hence all constraints are satisfied.

*If a feasible assignment exists*: it is a proper 3‑colouring, so by Lemma&nbsp;3
the search will find one and output `YES`.

If the program prints `NO`, by Lemma&nbsp;4 no proper 3‑colouring exists,
hence no feasible assignment exists.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

`n ≤ 40`. In the worst case the algorithm tries up to `3^n` colourings,
but the DSATUR heuristic and early conflict checks prune enormously.
Empirically for `n = 40` the running time is far below the 2 s limit.

Memory consumption: adjacency lists (`O(n + m)`) and a few arrays of size `n`,
well within 256 MB.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    color = [-1] * n  # -1 uncoloured, else 0/1/2

    # precompute degrees for tie‑breaking
    degree = [len(adj[i]) for i in range(n)]

    # helper: choose next vertex (DSATUR)
    def choose_vertex():
        best = -1
        best_score = -1
        best_deg = -1
        for v in range(n):
            if color[v] != -1:
                continue
            # number of coloured neighbours
            score = 0
            for nb in adj[v]:
                if color[nb] != -1:
                    score += 1
            if score > best_score or (score == best_score and degree[v] > best_deg):
                best = v
                best_score = score
                best_deg = degree[v]
        return best

    def dfs(coloured_cnt: int) -> bool:
        if coloured_cnt == n:
            return True
        v = choose_vertex()
        # try colours 0,1,2
        forbidden = 0
        for nb in adj[v]:
            c = color[nb]
            if c != -1:
                forbidden |= 1 << c
        for c in range(3):
            if forbidden & (1 << c):
                continue
            color[v] = c
            if dfs(coloured_cnt + 1):
                return True
            color[v] = -1
        return False

    possible = dfs(0)
    out = []
    if not possible:
        out.append("NO")
    else:
        out.append("YES")
        # convert to 1‑based greenhouse numbers
        out.append(' '.join(str(c + 1) for c in color))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

to the required input‑output format.
