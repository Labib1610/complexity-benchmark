We can model this as a graph coloring problem with 3 colors (shifts 1, 2, 3), but with extra constraints:

- Sum of all shift labels ≤ 3n  
- For each conflict edge (u, v), product of their shift labels ≥ 2.

Let’s analyze the constraints:

- Product ≥ 2 means we cannot have both workers on shift 1 (since 1×1=1 < 2).  
- All other combinations are allowed: (1,2), (1,3), (2,1), (2,2), (2,3), (3,1), (3,2), (3,3).

So the only forbidden pair is (1,1) for a conflict edge.

The sum constraint:  
If all workers are on shift 1, sum = n ≤ 3n, so that’s fine.  
If all on shift 3, sum = 3n, also fine.  
So the sum constraint is automatically satisfied for any assignment in {1,2,3} because max sum = 3n.  
Thus the sum constraint is redundant.

So the problem reduces to:  
Assign each vertex a label in {1,2,3} such that no edge has both endpoints labeled 1.  
We want the lexicographically smallest assignment.

This is a graph coloring with 3 colors, but with the special restriction that color 1 cannot be adjacent to color 1.  
We can solve with backtracking + pruning, since n ≤ 40.

We can also think:  
- If we assign a vertex color 1, all its neighbors must be 2 or 3.  
- We want lexicographically smallest, so we try color 1 first, then 2, then 3.

We can use recursive backtracking with forward checking.

Let’s implement:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n  # 0 = unassigned, 1,2,3
    
    # Precompute neighbors for speed
    adj_set = [set(adj[i]) for i in range(n)]
    
    def backtrack(idx):
        if idx == n:
            return True
        # Try colors in order 1,2,3
        for c in (1,2,3):
            # Check conflict: if c == 1, no neighbor can be 1
            ok = True
            if c == 1:
                for nb in adj[idx]:
                    if color[nb] == 1:
                        ok = False
                        break
            # Also if neighbor is 1, we cannot be 1 (already covered)
            # No other restrictions
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
