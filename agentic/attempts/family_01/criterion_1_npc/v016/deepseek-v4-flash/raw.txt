We need to assign each worker one of three schedules (1, 2, or 3) such that:

- No incompatible pair shares the same schedule.
- The sum of schedule IDs is between n and 3n (this is always true since each is 1, 2, or 3, so sum is between n and 3n automatically).
- The headcount per schedule ≤ n (also automatically true since total is n).

So the only real constraint is the graph coloring with 3 colors, where colors are 1, 2, 3.

We have n ≤ 40, so we can use backtracking with pruning.

We can also use the fact that the average number of incompatibilities per worker is < n, which means m < n²/2. But that’s not directly needed for the algorithm.

We'll implement a backtracking search:

- Try assigning colors 1, 2, 3 to each worker in order.
- Check compatibility with already assigned neighbors.
- If we reach the end, output the assignment.

We can also add a simple heuristic: order workers by degree (most constrained first) to speed up.

Here’s the code:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    # Order vertices by degree descending for better pruning
    order = sorted(range(n), key=lambda x: len(adj[x]), reverse=True)
    pos = [0] * n
    for idx, v in enumerate(order):
        pos[v] = idx
    
    color = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        v = order[idx]
        used = [False] * 4
        for u in adj[v]:
            if color[u] != 0:
                used[color[u]] = True
        for c in (1, 2, 3):
            if not used[c]:
                color[v] = c
                if backtrack(idx + 1):
                    return True
                color[v] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(color[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
