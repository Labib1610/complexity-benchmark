We can solve this by sorting the jobs in a specific order.  
The optimal order is to sort by the **Phase B duration in descending order** when the Phase A durations are equal, but more generally, we should sort by **Phase A duration in ascending order** if we want to minimize the makespan for two-machine flow shop scheduling.  

Actually, the classic Johnson’s rule applies here:  
- Split jobs into two sets:  
  - Set 1: jobs where `p1 <= p2`  
  - Set 2: jobs where `p1 > p2`  
- Sort Set 1 by `p1` ascending.  
- Sort Set 2 by `p2` descending.  
- Concatenate Set 1 then Set 2.  

Then simulate the schedule to compute the finish time.

```python
n = int(input())
jobs = [tuple(map(int, input().split())) for _ in range(n)]

set1 = [job for job in jobs if job[0] <= job[1]]
set2 = [job for job in jobs if job[0] > job[1]]

set1.sort(key=lambda x: x[0])
set2.sort(key=lambda x: -x[1])

order = set1 + set2

time_a = 0
time_b = 0
for a, b in order:
    time_a += a
    time_b = max(time_a, time_b) + b

print(time_b)
```
