We need to schedule effects through two stages: first a geometry solver, then a light tracer. Each effect has a processing time on each stage, and the order of effects is the same for both stages (a permutation). The goal is to minimize the total completion time.

This is a classic **two-machine flow shop scheduling** problem, which can be solved optimally using **Johnson's rule**.

**Johnson's rule:**
- Split jobs into two groups:
  - Group 1: jobs where time on solver ≤ time on tracer.
  - Group 2: jobs where time on solver > time on tracer.
- Sort Group 1 by increasing solver time.
- Sort Group 2 by decreasing tracer time.
- The optimal order is Group 1 followed by Group 2.

Then simulate the schedule to compute the makespan.

Here’s the implementation:

```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n = int(data[0])
    jobs = []
    idx = 1
    for _ in range(n):
        a = int(data[idx])
        b = int(data[idx+1])
        idx += 2
        jobs.append((a, b))
    
    # Johnson's rule
    group1 = []
    group2 = []
    for a, b in jobs:
        if a <= b:
            group1.append((a, b))
        else:
            group2.append((a, b))
    
    group1.sort(key=lambda x: x[0])
    group2.sort(key=lambda x: x[1], reverse=True)
    
    order = group1 + group2
    
    # Simulate
    time_solver = 0
    time_tracer = 0
    for a, b in order:
        time_solver += a
        if time_tracer < time_solver:
            time_tracer = time_solver
        time_tracer += b
    
    print(time_tracer)

if __name__ == "__main__":
    solve()
```
