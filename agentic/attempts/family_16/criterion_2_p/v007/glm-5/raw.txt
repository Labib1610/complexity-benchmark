Looking at this problem, I need to find the optimal ordering of jobs for a two-machine flow shop to minimize makespan, with the constraint that the first job must finish on machine 1 by time 1,000,000.

**Johnson's Rule** minimizes makespan for two-machine flow shop:
- Partition jobs into two sets: Set 1 where p1 ≤ p2, Set 2 where p1 > p2
- Sort Set 1 by increasing p1, Sort Set 2 by decreasing p2
- Process Set 1 first, then Set 2

**Constraint handling**: The first job must have p1 ≤ 1,000,000. Since all p1 ≤ 1,000,000 by input constraints, this is automatically satisfied.

**Verification with examples**:
- Example 1: Jobs (3,2), (2,4), (1,3). Set1 (p1≤p2): (1,3),(2,4). Set2 (p1>p2): (3,2). Order: (1,3),(2,4),(3,2). M1: 1,3,6. M2: 4,7,10. Makespan=10 ✓
- Example 2: Single job (5,3). M1:5, M2:8. Makespan=8 ✓
- Example 3: All (2,2). Set1 sorted by p1: any order. M1:2,4,6. M2:4,6,8. Makespan=8 ✓

**Complexity**: O(j log j) for sorting, which is fine for j ≤ 200,000.

```python
import sys

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    j = int(input_data[idx]); idx += 1
    
    set1 = []  # p1 <= p2, sort by p1 ascending
    set2 = []  # p1 > p2, sort by p2 descending
    
    for _ in range(j):
        p1 = int(input_data[idx]); idx += 1
        p2 = int(input_data[idx]); idx += 1
        if p1 <= p2:
            set1.append((p1, p2))
        else:
            set2.append((p1, p2))
    
    set1.sort(key=lambda x: x[0])
    set2.sort(key=lambda x: -x[1])
    
    order = set1 + set2
    
    m1_time = 0
    m2_time = 0
    
    for p1, p2 in order:
        m1_time += p1
        if m1_time > m2_time:
            m2_time = m1_time + p2
        else:
            m2_time += p2
    
    print(m2_time)

solve()
```
