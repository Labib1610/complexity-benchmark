We need to schedule jobs on two machines in a specific order: first all jobs on machine 1, then all jobs on machine 2. The goal is to minimize the makespan (total completion time).  

This is essentially a two-machine flow shop scheduling problem where the order is fixed: all jobs go through machine 1 first, then machine 2. The optimal solution for minimizing makespan in this case is to sort jobs by Johnson's rule, but here the order is fixed (we cannot reorder).  

However, the problem statement says we process jobs in a given order on machine 1, then machine 2. We just need to compute the completion time of the last job on machine 2.  

We can simulate:  
- Machine 1 processes jobs sequentially.  
- Machine 2 starts a job only after it finishes on machine 1 and machine 2 is free.  

We just need to compute the finish time of the last job on machine 2.  

Let’s write the solution.  

```python
import sys

def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    n = int(data[0])
    jobs = []
    idx = 1
    for _ in range(n):
        a = int(data[idx])
        b = int(data[idx+1])
        idx += 2
        jobs.append((a, b))
    
    # Simulate
    time_m1 = 0
    time_m2 = 0
    for a, b in jobs:
        time_m1 += a
        if time_m2 < time_m1:
            time_m2 = time_m1
        time_m2 += b
    
    print(time_m2)

if __name__ == "__main__":
    main()
```
