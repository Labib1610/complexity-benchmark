We can solve this using **Johnson’s rule** for two-machine flow shop scheduling.  
The idea is:

- Split jobs into two groups:
  - Group A: jobs where `p1 <= p2`
  - Group B: jobs where `p1 > p2`
- Sort Group A by `p1` ascending.
- Sort Group B by `p2` descending.
- Concatenate Group A + Group B to get the optimal order.
- Simulate the schedule to compute the finish time.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    j = int(data[0])
    jobs = []
    idx = 1
    for _ in range(j):
        p1 = int(data[idx])
        p2 = int(data[idx + 1])
        idx += 2
        jobs.append((p1, p2))

    group_a = []
    group_b = []
    for p1, p2 in jobs:
        if p1 <= p2:
            group_a.append((p1, p2))
        else:
            group_b.append((p1, p2))

    group_a.sort(key=lambda x: x[0])
    group_b.sort(key=lambda x: x[1], reverse=True)

    order = group_a + group_b

    time_m1 = 0
    time_m2 = 0
    for p1, p2 in order:
        time_m1 += p1
        if time_m2 < time_m1:
            time_m2 = time_m1
        time_m2 += p2

    print(time_m2)

if __name__ == "__main__":
    main()
```
