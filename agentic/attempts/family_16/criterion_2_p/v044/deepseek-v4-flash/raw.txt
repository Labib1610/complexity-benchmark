We need to minimize the makespan for a two-machine flow shop with **j** jobs, where each job has processing times \( p_1 \) (scan) and \( p_2 \) (load), and the order is a single permutation.  

This is a classic **two-machine flow shop scheduling problem** (Johnson’s rule).  

The optimal schedule minimizes the total completion time, so we can sort the jobs using Johnson’s rule:  
- If \( p_1 < p_2 \), put it in the first group, sorted by \( p_1 \) ascending.  
- If \( p_1 \ge p_2 \), put it in the second group, sorted by \( p_2 \) descending.  
Then concatenate group 1 and group 2.  

After ordering, simulate the schedule:  
- Time when scan of job i finishes: `time_scan += p1`  
- Time when load of job i finishes: `time_load = max(time_load, time_scan) + p2`  

At the end, `time_load` is the answer.

```python
import sys

def main():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    j = int(input_data[0])
    jobs = []
    idx = 1
    for _ in range(j):
        p1 = int(input_data[idx])
        p2 = int(input_data[idx + 1])
        idx += 2
        jobs.append((p1, p2))
    
    group1 = []  # p1 < p2
    group2 = []  # p1 >= p2
    
    for p1, p2 in jobs:
        if p1 < p2:
            group1.append((p1, p2))
        else:
            group2.append((p1, p2))
    
    group1.sort(key=lambda x: x[0])          # ascending p1
    group2.sort(key=lambda x: -x[1])         # descending p2
    
    order = group1 + group2
    
    scan_time = 0
    load_time = 0
    for p1, p2 in order:
        scan_time += p1
        if load_time < scan_time:
            load_time = scan_time
        load_time += p2
    
    print(load_time)

if __name__ == "__main__":
    main()
```
