We can model this as a scheduling problem with precedence constraints and solve it using a search over possible start times, or more simply, use a dynamic programming / branch-and-bound approach since the number of jobs is small (≤10) and total operations ≤50.

A straightforward approach:  
- Represent each job as a list of (machine, duration).  
- Use a priority queue (min-heap) to simulate time, but since we need the minimal makespan, we can use a **branch and bound** or **state-space search** over possible orderings of operations on each machine.

Given the constraints, we can use **recursive search with pruning**:

- State: current time for each job (next operation index), and for each machine, the earliest time it becomes free.
- At each step, pick a job whose next operation can start (machine free and previous op done), try starting it, and recurse.
- Keep track of the best makespan found so far to prune.

We can also use **dynamic programming over subsets** if we treat each job as a chain, but since operations are sequential and machines shared, the search is simpler.

Let’s implement the recursive search with memoization on (job_progress, machine_free_times) — but machine_free_times can be large, so we can instead use a time-sorted event simulation with backtracking.

Here’s the code:

```python
import sys
from functools import lru_cache

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    j = int(next(it))
    m = int(next(it))
    jobs = []
    for _ in range(j):
        o = int(next(it))
        ops = []
        for _ in range(o):
            machine = int(next(it)) - 1
            dur = int(next(it))
            ops.append((machine, dur))
        jobs.append(ops)
    
    # Precompute total duration of each job
    total_dur = [sum(d for _, d in job) for job in jobs]
    
    best = [sum(total_dur)]  # upper bound: run all jobs sequentially
    
    # State: progress[i] = number of operations done for job i
    # machine_free[m] = time when machine m becomes free
    # current_time = max of all job next start times? We'll track current time as max of machine_free and job progress times.
    
    # We'll do DFS with pruning.
    # To avoid huge state space, we'll use branch and bound.
    
    def dfs(progress, machine_free, current_time):
        # If all jobs done
        if all(p == len(jobs[i]) for i, p in enumerate(progress)):
            best[0] = min(best[0], current_time)
            return
        
        # Prune: if current_time >= best[0], stop
        if current_time >= best[0]:
            return
        
        # Try to start next operation for each job
        for i in range(j):
            if progress[i] < len(jobs[i]):
                machine, dur = jobs[i][progress[i]]
                start_time = max(current_time, machine_free[machine])
                # Actually start_time should be max of when job i can start (previous op done) and machine free
                # We need to know when job i's previous op finished. We can track job_ready[i].
                # We'll pass job_ready as well.
                pass
    
    # Better: track job_ready[i] = time when job i's next op can start (after previous op)
    # machine_free[m] = time when machine m is free
    # current_time = max over all job_ready and machine_free? Actually we can just use max of job_ready for scheduling.
    
    def dfs(progress, job_ready, machine_free):
        # progress: list of next op index for each job
        # job_ready: list of earliest start time for next op of each job
        # machine_free: list of earliest free time for each machine
        
        # If all done
        if all(progress[i] == len(jobs[i]) for i in range(j)):
            best[0] = min(best[0], max(job_ready))
            return
        
        # Prune
        if max(job_ready) >= best[0]:
            return
        
        # Find candidate jobs that can start now
        for i in range(j):
            if progress[i] < len(jobs[i]):
                machine, dur = jobs[i][progress[i]]
                start_time = max(job_ready[i], machine_free[machine])
                # We can start this job's next op at start_time
                # Update state
                old_prog = progress[i]
                old_ready = job_ready[i]
                old_mfree = machine_free[machine]
                
                progress[i] += 1
                job_ready[i] = start_time + dur
                machine_free[machine] = start_time + dur
                
                dfs(progress, job_ready, machine_free)
                
                # backtrack
                progress[i] = old_prog
                job_ready[i] = old_ready
                machine_free[machine] = old_mfree
    
    # Initial state
    progress = [0]*j
    job_ready = [0]*j
    machine_free = [0]*m
    dfs(progress, job_ready, machine_free)
    
    print(best[0])

if __name__ == "__main__":
    solve()
```
