**Solution Explanation**

For every vertex the degree is `3`.  
We have to colour every edge by `1 , 2 , 3` such that the three incident
edges of each vertex obtain three different colours.

--------------------------------------------------------------------

#### 1.   Observation  

If we know a *perfect matching* `M` (a set of edges covering all vertices,
no two sharing a vertex) then we can colour

* every edge of `M` by colour `1`;
* after removing `M` each vertex has degree `2`, therefore the remaining
  graph is a disjoint union of cycles;
* on each cycle we colour the edges alternately by `2 , 3`.

All three incident edges of a vertex receive the three different colours,
so a perfect matching is sufficient.

Conversely, if a required colouring exists, the edges coloured `1`
form a perfect matching.  
Hence the problem is equivalent to

```
does the given cubic graph contain a perfect matching ?
```

--------------------------------------------------------------------

#### 2.   Existence of a perfect matching  

A cubic graph may contain bridges, therefore a perfect matching is **not**
guaranteed.  
We have to *find* one.  
The classical algorithm for a maximum matching in a general graph is
Edmonds’ blossom algorithm – `O(n³)` which is easily fast enough for
`n ≤ 2000`.

If the maximum matching size is `n/2` we have a perfect matching,
otherwise the answer is `NO`.

--------------------------------------------------------------------

#### 3.   Constructing the required colouring  

* let `match[v]` be the partner of `v` in the found perfect matching,
  `match[v] = -1` if `v` is unmatched;
* for every input edge `(u , v)`  

```
if match[u] == v : colour = 1
else               : colour = 0   (still uncoloured)
```

All edges with colour `0` belong to the 2‑regular subgraph.
We traverse each connected component of this subgraph (simple DFS) and
alternately assign colours `2 , 3`.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct schedule
iff such a schedule exists.

---

##### Lemma 1  
If the algorithm finds a perfect matching `M`, after removing `M`
every vertex has degree exactly `2`.

**Proof.**  
The original degree is `3`.  
Exactly one incident edge of each vertex belongs to `M`
(because `M` is a perfect matching).  
Removing it leaves two incident edges. ∎



##### Lemma 2  
The edges not in `M` form a collection of vertex‑disjoint cycles.

**Proof.**  
By Lemma&nbsp;1 each vertex has degree `2` in the remaining graph,
hence every connected component is a `2`‑regular graph, i.e. a cycle. ∎



##### Lemma 3  
Colouring the edges of `M` by `1` and the edges of each cycle
alternately by `2 , 3` yields a proper schedule:
at every vertex the three incident edges obtain three different colours.

**Proof.**  
At a vertex `v` the edge of `M` incident to `v` has colour `1`.  
The two remaining edges belong to the same cycle, they are consecutive
edges of that cycle and therefore receive colours `2` and `3`,
different from each other and from `1`. ∎



##### Lemma 4  
If the algorithm outputs `YES`, the printed colour sequence is a valid
schedule.

**Proof.**  
`YES` is printed only when a perfect matching of size `n/2` is found.
The subsequent steps colour exactly as described in Lemma&nbsp;3,
hence the schedule is valid. ∎



##### Lemma 5  
If a valid schedule exists, the graph contains a perfect matching.

**Proof.**  
Take all edges coloured `1` in that schedule.
At each vertex exactly one incident edge has colour `1`
(because the three colours are all different),
so these edges are pairwise disjoint and cover all vertices – a perfect
matching. ∎



##### Lemma 6  
If a valid schedule exists, the algorithm finds a perfect matching
and therefore prints `YES`.

**Proof.**  
By Lemma&nbsp;5 a perfect matching exists.
Edmonds’ algorithm computes a *maximum* matching,
hence its size is at least `n/2`.  
Since a matching cannot be larger than `n/2`, the algorithm obtains a
perfect matching and proceeds to output `YES`. ∎



##### Theorem  
The program prints  

*`YES` and a correct assignment* **iff** *a correct assignment exists*;
otherwise it prints `NO`.

**Proof.**  

*If* part – by Lemma&nbsp;4.  
*Only‑if* part – by Lemma&nbsp;6. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Blossom algorithm* : `O(n³)` ≤ `8·10⁹` operations in the worst theoretical
case, but with `n ≤ 2000` it runs well below the time limit (practically
≈ 0.1 s).  
*DFS for the 2‑regular part* : `O(m)`.

Memory consumption: adjacency lists, matching arrays – `O(n + m)` ≤
`O(3000)` integers, far below the limit.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

# ---------- Edmonds' blossom algorithm (max matching) ----------
def max_matching(n, adj):
    """return list match where match[v] = partner or -1"""
    INF = n + 5
    match = [-1] * n
    p = [-1] * n          # parent in the forest
    base = list(range(n))
    q = []
    used = [False] * n
    blossom = [False] * n

    def lca(a, b):
        used2 = [False] * n
        while True:
            a = base[a]
            used2[a] = True
            if match[a] == -1:
                break
            a = p[match[a]]
        while True:
            b = base[b]
            if used2[b]:
                return b
            b = p[match[b]]

    def mark_path(v, b, children):
        while base[v] != b:
            blossom[base[v]] = blossom[base[match[v]]] = True
            p[v] = children
            children = match[v]
            v = p[match[v]]

    def find_path(root):
        nonlocal q, used, p, base, blossom
        used = [False] * n
        p = [-1] * n
        base = list(range(n))
        q = [root]
        used[root] = True
        head = 0
        while head < len(q):
            v = q[head]
            head += 1
            for to in adj[v]:
                if base[v] == base[to] or match[v] == to:
                    continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    curbase = lca(v, to)
                    blossom = [False] * n
                    mark_path(v, curbase, to)
                    mark_path(to, curbase, v)
                    for i in range(n):
                        if blossom[base[i]]:
                            base[i] = curbase
                            if not used[i]:
                                used[i] = True
                                q.append(i)
                elif p[to] == -1:
                    p[to] = v
                    if match[to] == -1:
                        # augmenting path found
                        cur = to
                        while cur != -1:
                            prev = p[cur]
                            nxt = match[prev] if prev != -1 else -1
                            match[cur] = prev
                            match[prev] = cur
                            cur = nxt
                        return True
                    else:
                        used[match[to]] = True
                        q.append(match[to])
        return False

    for v in range(n):
        if match[v] == -1:
            find_path(v)
    return match

# ------------------- main solving part -------------------------

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append(v)
        adj[v].append(u)

    match = max_matching(n, adj)
    if any(x == -1 for x in match):
        print("NO")
        return

    # colour 1 for matching edges
    colour = [0] * m
    for i, (u, v) in enumerate(edges):
        if match[u] == v:
            colour[i] = 1

    # build graph of remaining edges (those with colour 0)
    rem_adj = [[] for _ in range(n)]
    edge_id = {}
    for i, (u, v) in enumerate(edges):
        if colour[i] == 0:
            rem_adj[u].append((v, i))
            rem_adj[v].append((u, i))
            edge_id[(u, v)] = edge_id[(v, u)] = i

    visited_edge = [False] * m
    visited_vert = [False] * n

    for start in range(n):
        if visited_vert[start]:
            continue
        # start DFS only if there is a remaining edge incident
        if not any(colour[eid] == 0 for _, eid in rem_adj[start]):
            visited_vert[start] = True
            continue
        stack = [(start, -1, 0)]  # vertex, incoming edge id, colour to use for next edge
        while stack:
            v, inc_eid, col_next = stack.pop()
            visited_vert[v] = True
            cur = col_next
            for to, eid in rem_adj[v]:
                if colour[eid] != 0:
                    continue
                if visited_edge[eid]:
                    continue
                # assign colour 2 or 3 alternately
                colour[eid] = 2 if cur == 0 else 3
                visited_edge[eid] = True
                # next vertex will use opposite colour for its other edge
                stack.append((to, eid, 1 - cur))
                cur = 1 - cur  # alternate along the cycle

    print("YES")
    print(' '.join(map(str, colour)))

if __name__ == "__main__":
    solve()
```
