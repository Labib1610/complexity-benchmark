We can model this as a **3-edge-coloring** problem on a **3-regular graph** (each vertex has degree 3).  
The conditions imply:

- Each vertex has its 3 incident edges colored with all 3 different colors (1, 2, 3).
- Each color class has exactly **n/2** edges (since total edges = 3n/2, each color gets n/2).

This is equivalent to finding a **proper 3-edge-coloring** of a cubic graph, which exists if and only if the graph is **3-edge-colorable**.  
By **Kőnig's line coloring theorem**, every cubic graph with no bridges is 3-edge-colorable.  
But here, the graph may have bridges, so we need to check.

We can solve it by:

1. Build the graph.
2. Try to find a 3-edge-coloring using backtracking with heuristics (since n ≤ 2000, m ≤ 3000, we can do it efficiently).
3. If found, check that each color appears exactly n/2 times.

We can use a **greedy + backtracking** approach with constraint propagation.
