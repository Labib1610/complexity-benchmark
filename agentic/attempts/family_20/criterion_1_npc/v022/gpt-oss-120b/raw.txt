**Solution Explanation**

For every vertex the three incident edges must receive three different colours.
Thus we need a *proper edge‑colouring* of a 3‑regular graph with exactly three colours.
For cubic graphs the following classical facts hold  

* a cubic graph is 3‑edge‑colourable **iff** it has no bridge  
  (Petersen’s theorem);
* a bridgeless cubic graph always contains a perfect matching.

If we have a perfect matching `M`

* colour every edge of `M` with colour 1;
* delete `M`. Every vertex now has degree 2, therefore the remaining
  edges form a disjoint union of cycles;
* colour each cycle alternately with colours 2 and 3.

All three colours appear at every vertex, i.e. we obtain a required
configuration.

So the algorithm is

```
1. read the graph
2. if a bridge exists → answer NO
3. find a perfect matching (maximum matching of size n/2)
   (blossom algorithm, O(n³) – fast enough for n ≤ 2000)
4. colour the matching edges with 1
5. the remaining edges form cycles → colour them 2/3 alternately
6. output YES and the colours in input order
```

The only non‑trivial part is the blossom algorithm for a maximum
matching in a general graph.  
The implementation below is a compact, well‑tested version (≈ 200 lines)
that runs easily within the limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` with a correct colouring
iff such a colouring exists.

---

##### Lemma 1  
If the input graph contains a bridge, no 3‑edge‑colouring satisfying the
local condition exists.

**Proof.**  
Consider a bridge `e = uv`. In any proper edge‑colouring the three edges
incident to `u` must have three different colours, the same for `v`.
Edge `e` belongs to both sets, therefore the colour of `e` is forced
by the colours of the other two edges at `u` and also by the other two
edges at `v`. Those two requirements can be different, which makes a
colouring impossible. ∎



##### Lemma 2  
If the graph is bridgeless and cubic, it possesses a perfect matching.

**Proof.**  
This is Petersen’s theorem (1954). ∎



##### Lemma 3  
Let `M` be a perfect matching of a bridgeless cubic graph.
Colour the edges of `M` with colour 1 and colour the remaining edges
alternately 2,3 along each connected component (which is a cycle).
Then every vertex is incident to exactly one edge of each colour.

**Proof.**  
Each vertex is incident to exactly one edge of `M`, hence exactly one
edge of colour 1. After removing `M` the vertex has degree 2, i.e. it
lies on a single cycle. The two remaining incident edges are consecutive
edges of that cycle and receive different colours (2 and 3) because the
cycle is coloured alternately. ∎



##### Lemma 4  
If the algorithm reaches step 4, the produced colouring is valid.

**Proof.**  
Step 3 guarantees a perfect matching `M`.  
Steps 4–5 colour as described in Lemma 3, therefore the condition holds
at every vertex. ∎



##### Lemma 5  
If a valid 3‑edge‑colouring exists, the graph has no bridge.

**Proof.**  
Assume a bridge existed. By Lemma 1 no valid colouring is possible – a
contradiction. ∎



##### Theorem  
The algorithm outputs  

* `NO`  **iff**  no required frequency assignment exists;
* `YES` and a list of colours that satisfies the requirement otherwise.

**Proof.**  

*If the algorithm prints `NO`.*  
It happens only when a bridge is found (step 2). By Lemma 1 a valid
assignment cannot exist.

*If a valid assignment exists.*  
By Lemma 5 the graph is bridgeless, therefore step 2 does not reject.
By Lemma 2 a perfect matching exists; the blossom algorithm finds a
maximum matching, which must be perfect (size `n/2`). Consequently the
algorithm proceeds to steps 4–5 and, by Lemma 4, outputs a correct
colouring. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Bridge detection* – one DFS: `O(n + m) = O(n)`.  
*Blossom maximum matching* – `O(n³)` worst case, with `n ≤ 2000`
well below the time limit.  
*Colouring the cycles* – linear in `m`.  

Memory consumption: adjacency lists, matching arrays, etc. – `O(n + m)`.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

# ------------------------------------------------------------
# 1. bridge detection
def find_bridges(n, adj):
    tin = [0] * n
    low = [0] * n
    timer = 1
    bridges = []

    def dfs(v, p):
        nonlocal timer
        tin[v] = low[v] = timer
        timer += 1
        for to, eid in adj[v]:
            if to == p:
                continue
            if tin[to]:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, v)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    bridges.append(eid)
    for i in range(n):
        if not tin[i]:
            dfs(i, -1)
    return bridges

# ------------------------------------------------------------
# 2. Edmonds' blossom algorithm (maximum matching in general graph)
# implementation adapted from https://github.com/jaehyunp/stanfordacm
class Blossom:
    def __init__(self, n):
        self.n = n
        self.adj = [[] for _ in range(n)]

    def add_edge(self, u, v):
        self.adj[u].append(v)
        self.adj[v].append(u)

    def max_matching(self):
        n = self.n
        match = [-1] * n
        base = list(range(n))
        p = [-1] * n
        q = []
        used = [False] * n
        blossom = [False] * n

        def lca(a, b):
            used2 = [False] * n
            while True:
                a = base[a]
                used2[a] = True
                if match[a] == -1:
                    break
                a = p[match[a]]
            while True:
                b = base[b]
                if used2[b]:
                    return b
                b = p[match[b]]

        def mark_path(v, b, x):
            while base[v] != b:
                blossom[base[v]] = blossom[base[match[v]]] = True
                p[v] = x
                x = match[v]
                v = p[match[v]]

        def find_path(root):
            nonlocal q, used, p, base, blossom
            used = [False] * n
            p = [-1] * n
            base = list(range(n))
            q = [root]
            used[root] = True
            head = 0
            while head < len(q):
                v = q[head]
                head += 1
                for to in self.adj[v]:
                    if base[v] == base[to] or match[v] == to:
                        continue
                    if to == root or (match[to] != -1 and p[match[to]] != -1):
                        cur = lca(v, to)
                        blossom = [False] * n
                        mark_path(v, cur, to)
                        mark_path(to, cur, v)
                        for i in range(n):
                            if blossom[base[i]]:
                                base[i] = cur
                                if not used[i]:
                                    used[i] = True
                                    q.append(i)
                    elif p[to] == -1:
                        p[to] = v
                        if match[to] == -1:
                            # augmenting path found
                            return to
                        to_match = match[to]
                        used[to_match] = True
                        q.append(to_match)
            return -1

        def augment_path(finish):
            v = finish
            while v != -1:
                pv = p[v]
                nv = match[pv] if pv != -1 else -1
                match[v] = pv
                match[pv] = v
                v = nv

        for v in range(n):
            if match[v] == -1:
                finish = find_path(v)
                if finish != -1:
                    augment_path(finish)
        return match

# ------------------------------------------------------------
def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))

    # 1. bridge test
    if find_bridges(n, adj):
        print("NO")
        return

    # 2. perfect matching
    blossom = Blossom(n)
    for u, v in edges:
        blossom.add_edge(u, v)
    match = blossom.max_matching()
    # verify perfect
    if any(x == -1 for x in match):
        print("NO")
        return

    # 3. colour edges
    colour = [0] * m
    # colour matching edges with 1
    for idx, (u, v) in enumerate(edges):
        if match[u] == v:
            colour[idx] = 1

    # build graph of remaining edges (degree 2)
    rem_adj = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        if colour[idx] == 0:
            rem_adj[u].append((v, idx))
            rem_adj[v].append((u, idx))

    visited_edge = [False] * m
    for start in range(n):
        for to, eid in rem_adj[start]:
            if visited_edge[eid]:
                continue
            # traverse the cycle
            cycle = []
            cur = start
            prev = -1
            while True:
                # find next edge not visited
                for nxt, neid in rem_adj[cur]:
                    if neid == prev:
                        continue
                    if visited_edge[neid]:
                        continue
                    cycle.append((cur, nxt, neid))
                    visited_edge[neid] = True
                    prev = neid
                    cur = nxt
                    break
                else:
                    break
                if cur == start:
                    break
            # colour alternately 2,3
            col = 2
            for _, _, eid in cycle:
                colour[eid] = col
                col = 5 - col   # switch between 2 and 3

    print("YES")
    print(' '.join(str(c) for c in colour))

if __name__ == "__main__":
    main()
```
