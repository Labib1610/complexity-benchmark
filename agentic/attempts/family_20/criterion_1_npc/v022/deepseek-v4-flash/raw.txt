We can model this as a graph problem where each node has degree 3, and we need to 3-color the edges such that at each vertex, all three incident edges have distinct colors.

This is equivalent to finding a **proper 3-edge-coloring** of a **3-regular graph**.  
By **Petersen’s theorem**, every bridgeless cubic graph has a perfect matching, and by **Vizing’s theorem**, every cubic graph is 3-edge-colorable if it is bridgeless.  
However, if the graph has a bridge, it may not be 3-edge-colorable.

Since **n ≤ 2000**, we can use a constructive algorithm:

- Find a **perfect matching** (if exists) and color those edges with color 3.
- The remaining edges form a 2-regular graph (disjoint cycles), which can be 2-colored alternately with colors 1 and 2.

If no perfect matching exists, output `NO`.

We can find a perfect matching in a cubic graph using standard matching algorithms (e.g., Blossom algorithm), but since n is small, we can use a simple backtracking or network flow approach.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(10000)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))
    
    # Try to find a perfect matching using backtracking
    match = [-1] * n
    used = [False] * m
    matched_edges = []
    
    # Simple backtracking for perfect matching in cubic graph
    def backtrack(node):
        if node == n:
            return True
        if match[node] != -1:
            return backtrack(node + 1)
        for v, eidx in adj[node]:
            if not used[eidx]:
                used[eidx] = True
                if match[v] == -1:
                    match[node] = v
                    match[v] = node
                    matched_edges.append(eidx)
                    if backtrack(node + 1):
                        return True
                    matched_edges.pop()
                    match[node] = -1
                    match[v] = -1
                else:
                    # Try to reassign
                    prev = match[v]
                    match[node] = v
                    match[v] = node
                    match[prev] = -1
                    if backtrack(node):
                        return True
                    match[prev] = v
                    match[v] = prev
                    match[node] = -1
                used[eidx] = False
        return False
    
    if not backtrack(0):
        print("NO")
        return
    
    color = [0] * m
    for eidx in matched_edges:
        color[eidx] = 3
    
    # Remaining edges form cycles, color alternately 1 and 2
    remaining_adj = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        if color[idx] == 0:
            remaining_adj[u].append((v, idx))
            remaining_adj[v].append((u, idx))
    
    visited = [False] * n
    for i in range(n):
        if not visited[i] and remaining_adj[i]:
            # traverse cycle
            start = i
            prev = -1
            cur = start
            c = 1
            while True:
                visited[cur] = True
                # find next
                for nxt, eidx in remaining_adj[cur]:
                    if nxt != prev:
                        color[eidx] = c
                        c = 3 - c  # switch 1<->2
                        prev = cur
                        cur = nxt
                        break
                if cur == start:
                    break
    
    print("YES")
    print(" ".join(map(str, color)))

if __name__ == "__main__":
    solve()
```
