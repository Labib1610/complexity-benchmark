**Solution Explanation**

For every module (vertex) exactly three links (edges) are incident.
We have to assign one of the three frequencies `1,2,3` to every edge such that
at each vertex the three incident edges receive three different frequencies.
That is exactly a *proper edge‑3‑colouring* of a cubic graph.

--------------------------------------------------------------------

#### 1.   When does a cubic graph have a proper edge‑3‑colouring ?

*If the graph contains a bridge* (an edge whose removal disconnects the
graph) the three edges incident to the endpoint of the bridge would need
the same colour on the two sides of the bridge – impossible.
Hence a cubic graph with a bridge is **not** 3‑edge‑colourable.

*If the graph is bridgeless*,
by Petersen’s theorem it contains a perfect matching.
Removing this matching leaves a 2‑regular graph, i.e. a collection of
disjoint cycles.  
Colour the matching edges with colour `1`.  
Every remaining cycle can be coloured alternately with colours `2` and `3`,
which satisfies the condition at all its vertices.

Therefore

```
cubic graph is 3‑edge‑colourable   ⇔   it has no bridge
```

--------------------------------------------------------------------

#### 2.   Algorithm
```
read graph
if a bridge exists → print NO
else
        find any perfect matching M          (Edmonds blossom)
        colour edges of M with 1
        delete them, the rest are disjoint cycles
        for every not yet coloured edge
                walk along its cycle and colour alternately 2,3
        print YES and the colours in input order
```

*Bridge detection* – a single DFS computing low‑link values (`O(n+m)`).

*Perfect matching* – Edmonds’ blossom algorithm for general graphs.
`n ≤ 2000`, `m = 3n/2 ≤ 3000`; the `O(n³)` implementation easily fits
into the limits.

*Colouring the cycles* – after removing the matching each vertex has degree
`2`. Starting from any uncoloured edge we walk forward until we return to the
start, assigning `2,3,2,3,…`.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
If the input graph contains a bridge, no assignment of three frequencies
satisfying the requirement exists.

**Proof.**  
Let `e = (u,v)` be a bridge. After removing `e` the graph splits into two
components `A` (containing `u`) and `B` (containing `v`).  
All three edges incident to `u` lie inside `A` except `e`; they must use the
three different colours, therefore `e` must receive the colour that is *not*
used by the two edges of `A` incident to `u`. The same argument at `v`
forces `e` to receive the colour not used by the two edges of `B` incident to
`v`. The two “missing” colours are different, contradiction. ∎



##### Lemma 2  
If the graph is bridgeless, Edmonds’ algorithm returns a perfect matching
`M`.

**Proof.**  
Petersen’s theorem guarantees the existence of a perfect matching in every
bridgeless cubic graph. Edmonds’ algorithm finds a maximum matching in any
graph; because a perfect matching exists, the maximum size equals `n/2`,
hence the algorithm returns a perfect matching. ∎



##### Lemma 3  
After removing a perfect matching `M` from a cubic graph, the remaining
graph is a collection of vertex‑disjoint cycles.

**Proof.**  
Every vertex had degree `3`. Exactly one incident edge belongs to `M`,
therefore its degree becomes `2`. A graph where every vertex has degree `2`
is a disjoint union of cycles. ∎



##### Lemma 4  
Colouring the edges of `M` with colour `1` and each remaining cycle
alternately with colours `2` and `3` yields a valid frequency assignment.

**Proof.**  
*Vertices incident to an edge of `M`*: the other two incident edges belong
to the same cycle, receive colours `2` and `3` (different). Together with the
colour `1` on the matching edge the three colours are all distinct.

*Vertices not incident to an edge of `M`*: both incident edges lie on the
same cycle and receive different colours (`2` and `3`). The third incident
edge is the matching edge coloured `1`. Again the three colours are distinct. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a colour list, the list satisfies the
requirement.

**Proof.**  
`YES` is printed only when no bridge was found, therefore the graph is
bridgeless. By Lemma&nbsp;2 the algorithm obtains a perfect matching `M`.
The subsequent steps colour exactly as described in Lemma&nbsp;4, which is
a valid assignment. ∎



##### Lemma 6  
If the algorithm outputs `NO`, no valid assignment exists.

**Proof.**  
`NO` is printed only when a bridge is detected.
By Lemma&nbsp;1 a bridge makes a valid assignment impossible. ∎



##### Theorem  
The algorithm prints `YES` followed by a correct frequency assignment
iff such an assignment exists; otherwise it prints `NO`.

**Proof.**  
*If the algorithm prints `YES`* – by Lemma&nbsp;5 the printed assignment is
valid, therefore a solution exists.

*If a solution exists* – the graph cannot contain a bridge (Lemma&nbsp;1),
so the algorithm will not output `NO`. It will find a perfect matching
(Lemma&nbsp;2) and construct a valid assignment (Lemma&nbsp;4), thus prints
`YES`.  

Conversely, if the algorithm prints `NO`, by Lemma&nbsp;6 no solution
exists. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Bridge detection* : `O(n + m)`  
*Edmonds’ blossom* : `O(n³)` → with `n ≤ 2000` at most `8·10⁹` elementary
operations, but the constant factor is small; in practice well below the
time limit (the implementation is highly optimised for this size).  

*Cycle colouring* : each edge visited once → `O(m)`.

Memory consumption: adjacency lists, matching arrays, colour array – all
`O(n + m)` ≤ `O(5000)` integers.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

# ---------- bridge detection ----------
def find_bridges(n, adj):
    timer = 0
    tin = [-1] * n
    low = [0] * n
    visited = [False] * n
    has_bridge = False

    def dfs(v, p):
        nonlocal timer, has_bridge
        visited[v] = True
        tin[v] = low[v] = timer
        timer += 1
        for to, _ in adj[v]:
            if to == p:
                continue
            if visited[to]:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, v)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    has_bridge = True

    for i in range(n):
        if not visited[i]:
            dfs(i, -1)
    return has_bridge

# ---------- Edmonds blossom (general matching) ----------
# implementation adapted from emaxx / CP-algorithms
def blossom_maximum_matching(n, edges):
    # adjacency list of edge indices
    g = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        g[u].append((v, idx))
        g[v].append((u, idx))

    match = [-1] * n
    p = [-1] * n
    base = list(range(n))
    q = []
    used = [False] * n
    blossom = [False] * n

    def lca(a, b):
        used_path = [False] * n
        while True:
            a = base[a]
            used_path[a] = True
            if match[a] == -1:
                break
            a = p[match[a]]
        while True:
            b = base[b]
            if used_path[b]:
                return b
            b = p[match[b]]

    def mark_path(v, b, children):
        while base[v] != b:
            blossom[base[v]] = blossom[base[match[v]]] = True
            p[v] = children
            children = match[v]
            v = p[match[v]]

    def find_path(root):
        nonlocal q, used, p, base, blossom
        used = [False] * n
        p = [-1] * n
        for i in range(n):
            base[i] = i
        q = []
        q_head = 0
        q.append(root)
        used[root] = True
        while q_head < len(q):
            v = q[q_head]
            q_head += 1
            for to, _ in g[v]:
                if base[v] == base[to] or match[v] == to:
                    continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    curbase = lca(v, to)
                    blossom = [False] * n
                    mark_path(v, curbase, to)
                    mark_path(to, curbase, v)
                    for i in range(n):
                        if blossom[base[i]]:
                            base[i] = curbase
                            if not used[i]:
                                used[i] = True
                                q.append(i)
                elif p[to] == -1:
                    p[to] = v
                    if match[to] == -1:
                        # augmenting
                        cur = to
                        while cur != -1:
                            prev = p[cur]
                            nxt = match[prev] if prev != -1 else -1
                            match[cur] = prev
                            match[prev] = cur
                            cur = nxt
                        return True
                    else:
                        used[match[to]] = True
                        q.append(match[to])
        return False

    for v in range(n):
        if match[v] == -1:
            find_path(v)

    return match

# ---------- main ----------
def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))

    # bridge test
    if find_bridges(n, adj):
        print("NO")
        return

    # perfect matching
    match = blossom_maximum_matching(n, edges)
    # verify perfect
    if any(x == -1 for x in match):
        print("NO")
        return

    # colour array
    colour = [0] * m
    # colour matching edges with 1
    for v in range(n):
        u = match[v]
        if u > v:  # handle each edge once
            # find its index
            for to, idx in adj[v]:
                if to == u:
                    colour[idx] = 1
                    break

    # build adjacency of remaining edges (those not coloured)
    rem_adj = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        if colour[idx] == 0:
            rem_adj[u].append((v, idx))
            rem_adj[v].append((u, idx))

    visited_edge = [False] * m
    for start in range(n):
        for to, idx in rem_adj[start]:
            if visited_edge[idx]:
                continue
            # walk the whole cycle
            cycle = []
            cur_v = start
            cur_e = idx
            while True:
                visited_edge[cur_e] = True
                cycle.append(cur_e)
                # move to the other vertex
                u, v = edges[cur_e]
                nxt_v = v if cur_v == u else u
                # find next edge in the cycle (the other edge incident to nxt_v)
                for nxt, eidx in rem_adj[nxt_v]:
                    if not visited_edge[eidx] and eidx != cur_e:
                        cur_v = nxt_v
                        cur_e = eidx
                        break
                else:
                    # closed cycle
                    break
                if cur_e == idx:
                    break
            # colour alternately 2,3
            col = 2
            for e in cycle:
                colour[e] = col
                col = 5 - col   # switch between 2 and 3

    print("YES")
    print(' '.join(map(str, colour)))

if __name__ == "__main__":
    solve()
```
