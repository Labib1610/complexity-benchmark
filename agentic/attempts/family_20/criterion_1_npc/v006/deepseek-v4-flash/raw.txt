We can model this as a graph problem.  
Each junction has degree exactly 3, and we need a proper 3-edge-coloring of the graph.  
Since every vertex has degree 3, this is a cubic graph. By **Vizing’s theorem**, every cubic graph is 3-edge-colorable if it is bridgeless, but here we may have bridges.  
However, the problem guarantees that the graph is a “trunk grid” with all degrees 3, and we can use a constructive approach:  

- Use a backtracking or greedy edge-coloring with constraint propagation.  
- Since n ≤ 2000, m ≤ 3000, we can do a simple backtracking with pruning.

We’ll implement a backtracking that assigns colors 1,2,3 to edges, ensuring at each vertex the three incident edges get distinct colors.

```python
import sys
sys.setrecursionlimit(10000)

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))
    
    color = [-1] * m
    # For each vertex, track used colors
    used_at_vertex = [set() for _ in range(n)]
    
    # Sort edges by degree of endpoints for better pruning
    order = list(range(m))
    order.sort(key=lambda e: len(adj[edges[e][0]]) + len(adj[edges[e][1]]), reverse=True)
    
    def backtrack(pos):
        if pos == m:
            return True
        e = order[pos]
        u, v = edges[e]
        # Try colors 1,2,3
        for c in (1,2,3):
            if c not in used_at_vertex[u] and c not in used_at_vertex[v]:
                color[e] = c
                used_at_vertex[u].add(c)
                used_at_vertex[v].add(c)
                if backtrack(pos + 1):
                    return True
                used_at_vertex[u].remove(c)
                used_at_vertex[v].remove(c)
                color[e] = -1
        return False
    
    if backtrack(0):
        sys.stdout.write("YES\n")
        sys.stdout.write(" ".join(str(color[i]) for i in range(m)) + "\n")
    else:
        sys.stdout.write("NO\n")

if __name__ == "__main__":
    solve()
```
