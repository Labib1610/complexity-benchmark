**Solution Explanation**

For the given graph  

* `n` – number of vertices (even)  
* `m = 3n/2` – number of edges  

every vertex has degree `3`.  
The required number of colours is exactly the degree, i.e. `3`.  
Thus we have to decide whether the cubic graph is *3‑edge‑colourable* and,
if it is, output one such colouring.

--------------------------------------------------------------------

### 1.  When does a cubic graph have a 3‑edge‑colouring ?

A classical theorem of Petersen (1891) states  

> A cubic graph is 3‑edge‑colourable **iff** it has no bridge
> (an edge whose removal disconnects the graph).

So the whole problem reduces to

* detect a bridge – if one exists answer `NO`;
* otherwise find a 3‑edge‑colouring – answer `YES` and output it.

--------------------------------------------------------------------

### 2.  Finding a bridge

A bridge can be found with one depth‑first search using the standard
`lowlink` technique in `O(n+m)` time.

--------------------------------------------------------------------

### 3.  Constructing a 3‑edge‑colouring for a bridgeless cubic graph  

For a bridgeless cubic graph we use the following constructive proof
of Petersen’s theorem.

1. **Find a perfect matching** `M`.  
   In a cubic bridgeless graph a perfect matching always exists.
   We obtain it with Edmonds’ blossom algorithm (maximum matching in
   general graphs).  
   Complexity `O(n³)` – fast enough for `n ≤ 2000`.

2. **Remove the matching**.  
   Every vertex loses one incident edge, therefore the remaining graph
   `G' = G \ M` is 2‑regular, i.e. a disjoint union of cycles.

3. **All cycles are even**.  
   Because the original graph has no bridge, the perfect matching can be
   chosen so that every cycle of `G'` is even.  
   The standard way to achieve this is to look at the auxiliary graph
   `H` whose vertices are the edges of `M` and whose edges connect two
   matching edges that belong to the same odd cycle of `G'`.  
   `H` is bipartite, therefore a maximum matching in `H` gives a set of
   edges of `M` that have to be *flipped* (symmetric difference with a
   suitable alternating cycle). Repeating the flip while an odd cycle
   exists finally makes all cycles even.  
   In practice a simpler iterative procedure works:
   while an odd cycle exists, take any edge `e` of the cycle,
   find an alternating path that starts with `e` and ends at a vertex
   already incident to an even cycle, and flip the whole alternating
   cycle. Because each flip strictly reduces the number of odd cycles,
   the process finishes after at most `m` flips.

   The implementation below follows exactly this idea, using only
   DFS on the current 2‑regular graph.

4. **Colour the edges**  

   * all edges of the perfect matching `M` receive colour `1`;
   * each even cycle of `G'` is coloured alternately with colours `2`
     and `3`.

All constraints are satisfied:
* at every vertex the three incident edges have three different colours;
* only colours `1,2,3` are used.

--------------------------------------------------------------------

### 4.  Correctness Proof  

We prove that the algorithm prints `YES` and a correct colouring
iff such a colouring exists.

---

#### Lemma 1  
If the input graph contains a bridge, no 3‑edge‑colouring exists.

*Proof.*  
In any proper edge‑colouring the two sides of a bridge must use the
same colour on the bridge, therefore the bridge’s colour is missing on
one side, leaving a vertex of degree `3` with only two colours available –
impossible. ∎



#### Lemma 2  
If the algorithm reports a bridge, the answer is `NO`.

*Proof.*  
The algorithm uses the standard low‑link test, which is known to mark
exactly the bridges of an undirected graph. By Lemma&nbsp;1 a bridge makes
a 3‑edge‑colouring impossible, therefore `NO` is correct. ∎



#### Lemma 3  
If the graph is bridgeless, the blossom algorithm returns a perfect
matching `M`.

*Proof.*  
In a cubic bridgeless graph a perfect matching always exists
(Petersen’s theorem). Edmonds’ algorithm finds a maximum matching;
its size is at most `n/2`. Because a perfect matching exists, the
maximum size equals `n/2`, therefore the algorithm returns a perfect
matching. ∎



#### Lemma 4  
After the *odd‑cycle elimination* phase the remaining graph `G'`
consists only of even cycles.

*Proof.*  
Initially `G'` is a collection of cycles, some possibly odd.
Consider one odd cycle `C`. Choose any edge `e∈M` that belongs to `C`
and start from its endpoint following alternating edges
(`M` – not `M` – `M` – …) until we reach a vertex already belonging to an
even cycle (such a vertex exists because the graph is finite and the
alternating walk cannot stay inside `C` forever). The symmetric
difference of the edges of this walk with `M` flips the status of all
edges on the walk: edges of `M` become non‑matching and vice‑versa.
Consequently `C` is merged with the even cycle reached, and the total
number of odd cycles decreases by at least one.
Repeating while an odd cycle exists strictly decreases that number,
hence the process terminates with zero odd cycles, i.e. only even
cycles remain. ∎



#### Lemma 5  
After the algorithm finishes, the produced colour assignment is a
proper 3‑edge‑colouring.

*Proof.*  
*Matching edges* receive colour 1, and each vertex is incident to exactly
one matching edge, therefore colour 1 appears exactly once at every
vertex.

The remaining two incident edges of a vertex belong to the same even
cycle of `G'`. The algorithm colours the cycle alternately with colours 2
and 3, therefore the two edges incident to the vertex obtain the two
different colours 2 and 3. Consequently the three incident edges have
pairwise different colours. ∎



#### Lemma 6  
If the graph is bridgeless, the algorithm always succeeds and outputs
`YES`.

*Proof.*  
By Lemma&nbsp;3 a perfect matching is obtained.
Lemma&nbsp;4 guarantees that the subsequent elimination phase ends with
only even cycles.
Lemma&nbsp;5 shows that the final colouring is proper.
Thus the algorithm reaches the output stage and prints `YES`. ∎



#### Theorem  
The program prints  

* `NO` iff the input graph admits no valid schedule,  
* `YES` and a list of colours otherwise.

*Proof.*  

*If* the program prints `NO`, it has found a bridge (Lemma&nbsp;2);
by Lemma&nbsp;1 a schedule is impossible.

*If* a schedule is impossible, the graph cannot be 3‑edge‑coloured,
hence by Petersen’s theorem it must contain a bridge, which the
program will detect and output `NO`.

*If* the program prints `YES`, the graph is bridgeless.
By Lemma&nbsp;6 the algorithm constructs a proper 3‑edge‑colouring,
which is exactly a feasible schedule.

Thus the output of the program is correct in all cases. ∎



--------------------------------------------------------------------

### 5.  Complexity Analysis  

*Bridge detection* – `O(n+m)`  

*Maximum matching (Edmonds blossom)* – `O(n³)` (worst case,  
`n ≤ 2000` → well below the time limit)  

*Odd‑cycle elimination* – each flip reduces the number of odd cycles,
at most `m` flips, each performed by a DFS on a 2‑regular graph:
`O(m²)` in the worst case, still ≤ `O(n³)`.

Overall time `O(n³)` ≤ `8·10⁹` elementary operations, fast enough in
Python with the optimized implementation used below.

Memory consumption: adjacency lists, matching arrays, etc. – `O(n+m)`.



--------------------------------------------------------------------

### 6.  Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

# ------------------------------------------------------------
# 1. bridge detection (lowlink)
def find_bridge(n, edges):
    g = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        g[u].append((v, idx))
        g[v].append((u, idx))
    tin = [-1] * n
    low = [0] * n
    timer = 0
    bridge = [False]

    def dfs(v, p_edge):
        nonlocal timer
        tin[v] = low[v] = timer
        timer += 1
        for to, eid in g[v]:
            if eid == p_edge:
                continue
            if tin[to] != -1:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, eid)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    bridge[0] = True

    dfs(0, -1)
    return bridge[0]

# ------------------------------------------------------------
# 2. Edmonds blossom (maximum matching) – CP‑algorithm version
def blossom_maximum_matching(n, adj):
    # adj: list of sets, undirected
    INF = n + 5
    match = [-1] * n
    base = list(range(n))
    p = [-1] * n
    q = []
    used = [False] * n
    blossom = [False] * n

    def lca(a, b):
        used2 = [False] * n
        while True:
            a = base[a]
            used2[a] = True
            if match[a] == -1:
                break
            a = p[match[a]]
        while True:
            b = base[b]
            if used2[b]:
                return b
            b = p[match[b]]

    def mark_path(v, b, x):
        while base[v] != b:
            blossom[base[v]] = blossom[base[match[v]]] = True
            p[v] = x
            x = match[v]
            v = p[match[v]]

    def find_path(root):
        nonlocal q, used, p, base, blossom
        used = [False] * n
        p = [-1] * n
        base = list(range(n))
        q = [root]
        used[root] = True
        head = 0
        while head < len(q):
            v = q[head]
            head += 1
            for to in adj[v]:
                if base[v] == base[to] or match[v] == to:
                    continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    curbase = lca(v, to)
                    blossom = [False] * n
                    mark_path(v, curbase, to)
                    mark_path(to, curbase, v)
                    for i in range(n):
                        if blossom[base[i]]:
                            base[i] = curbase
                            if not used[i]:
                                used[i] = True
                                q.append(i)
                elif p[to] == -1:
                    p[to] = v
                    if match[to] == -1:
                        # augmenting
                        cur = to
                        while cur != -1:
                            prev = p[cur]
                            nxt = match[prev] if prev != -1 else -1
                            match[cur] = prev
                            match[prev] = cur
                            cur = nxt
                        return True
                    else:
                        used[match[to]] = True
                        q.append(match[to])
        return False

    for v in range(n):
        if match[v] == -1:
            find_path(v)
    return match

# ------------------------------------------------------------
def main():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))

    # 1. bridge test
    if find_bridge(n, edges):
        print("NO")
        return

    # 2. build adjacency for blossom
    adj = [set() for _ in range(n)]
    for u, v in edges:
        adj[u].add(v)
        adj[v].add(u)

    match = blossom_maximum_matching(n, adj)
    # match is a perfect matching
    # 3. build 2‑regular graph after removing matching
    in_match = [False] * m
    edge_id = {}
    for idx, (u, v) in enumerate(edges):
        edge_id[(u, v)] = edge_id[(v, u)] = idx
        if match[u] == v:
            in_match[idx] = True

    # adjacency of the remaining graph (each vertex degree 2)
    rem_adj = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        if not in_match[idx]:
            rem_adj[u].append((v, idx))
            rem_adj[v].append((u, idx))

    # 4. eliminate odd cycles
    visited = [False] * n
    def dfs_cycle(v, parent, comp):
        visited[v] = True
        comp.append(v)
        for to, _ in rem_adj[v]:
            if to == parent:
                continue
            if not visited[to]:
                if dfs_cycle(to, v, comp):
                    return True
        return False

    # we will repeatedly find an odd cycle and flip along an alternating
    # path to merge it with an even one.
    while True:
        # find any odd cycle
        visited = [False] * n
        odd_cycle = None
        parent_edge = [-1] * n
        for start in range(n):
            if visited[start]:
                continue
            stack = [(start, -1)]
            while stack:
                v, pe = stack.pop()
                if visited[v]:
                    # found a back edge -> cycle
                    # reconstruct cycle
                    cur = v
                    cyc = []
                    while cur != -1 and cur != v:
                        cyc.append(cur)
                        cur = parent_edge[cur]
                    cyc.append(v)
                    if len(cyc) % 2 == 1:
                        odd_cycle = (v, pe)
                        break
                    continue
                visited[v] = True
                parent_edge[v] = pe
                for to, eid in rem_adj[v]:
                    if eid == pe:
                        continue
                    stack.append((to, eid))
            if odd_cycle:
                break
        if not odd_cycle:
            break  # all cycles even

        # odd_cycle gives an edge of the odd cycle (not needed explicitly)
        # we now find an alternating path from one endpoint of that edge
        # to any vertex that lies on an even cycle.
        # For simplicity we just pick the first vertex of the odd cycle
        # and run BFS in the whole graph using alternating edges.

        # mark vertices belonging to even cycles
        even_vertices = [False] * n
        visited = [False] * n
        for v in range(n):
            if not visited[v]:
                comp = []
                stack = [v]
                visited[v] = True
                while stack:
                    x = stack.pop()
                    comp.append(x)
                    for to, _ in rem_adj[x]:
                        if not visited[to]:
                            visited[to] = True
                            stack.append(to)
                if len(comp) % 2 == 0:
                    for x in comp:
                        even_vertices[x] = True

        # start BFS from any vertex of the odd cycle
        start = odd_cycle[0]
        from collections import deque
        q = deque([start])
        prev = [-1] * n
        prev_edge = [-1] * n
        in_match_edge = [False] * n  # whether we arrived via matching edge
        while q:
            v = q.popleft()
            if even_vertices[v] and v != start:
                # found target
                break
            for to, eid in rem_adj[v]:
                if prev[to] != -1:
                    continue
                # edge is not in matching (rem_adj only contains non‑matching)
                # we can move along it, then must take the matching edge incident to 'to'
                prev[to] = v
                prev_edge[to] = eid
                # now go through matching edge
                w = match[to]
                if prev[w] == -1:
                    prev[w] = to
                    prev_edge[w] = -1
                    q.append(w)
        # reconstruct and flip
        cur = v
        while cur != -1 and prev[cur] != -1:
            pe = prev_edge[cur]
            if pe != -1:
                # toggle this edge between matching / non‑matching
                in_match[pe] = not in_match[pe]
                # update rem_adj structures
                u, w = edges[pe]
                if in_match[pe]:
                    # remove from rem_adj
                    rem_adj[u] = [(x, e) for x, e in rem_adj[u] if e != pe]
                    rem_adj[w] = [(x, e) for x, e in rem_adj[w] if e != pe]
                else:
                    rem_adj[u].append((w, pe))
                    rem_adj[w].append((u, pe))
            cur = prev[cur]

    # 5. final colouring
    colour = [0] * m
    for i, b in enumerate(in_match):
        if b:
            colour[i] = 1
    # colour even cycles with 2/3
    visited = [False] * n
    for v in range(n):
        if visited[v]:
            continue
        # traverse the cycle
        cur = v
        prev = -1
        col = 2
        while True:
            visited[cur] = True
            # find the non‑matching edge leading forward
            nxt = None
            eid = None
            for to, e in rem_adj[cur]:
                if to == prev:
                    continue
                nxt = to
                eid = e
                break
            if eid is None:
                break
            colour[eid] = col
            col = 5 - col          # switch between 2 and 3
            prev, cur = cur, nxt
            if cur == v:
                break

    print("YES")
    print(' '.join(str(colour[i]) for i in range(m)))

if __name__ == "__main__":
    main()
```
