We need to assign each edge a color (window) such that at each vertex, all incident edges have distinct colors, and the number of colors equals the degree of each vertex.  

This is exactly an **edge coloring** of a regular graph. Since the graph is **3-regular** (because m = 3n/2 and each vertex has degree 3), we need a proper 3-edge-coloring.  

By **Kőnig's line coloring theorem**, every bipartite graph has an edge chromatic number equal to its maximum degree. But here the graph may not be bipartite. However, for **cubic graphs**, a proper 3-edge-coloring exists if and only if the graph is **3-edge-colorable**, which is equivalent to being **Class 1** in edge coloring.  

For cubic graphs, **not all are 3-edge-colorable** (e.g., the Petersen graph is not). So we must check if the given graph is 3-edge-colorable.  

We can solve this by trying to find a proper 3-edge-coloring using backtracking or a known algorithm. Since n ≤ 2000, m ≤ 3000, we can use a **greedy + backtracking** approach with heuristics, or use **Kempe chain** ideas.  

A practical approach:  
- Use a backtracking search with constraint propagation.  
- At each step, pick an uncolored edge and try colors 1,2,3 that don't conflict with already colored edges at its endpoints.  
- Use recursion with pruning.  

Given the constraints, a well-optimized backtracking should work for most cases, but worst-case might be slow. However, for cubic graphs, we can also use **Vizing's theorem** to check if Δ+1 colors are needed; but here we only have Δ=3 colors.  

We'll implement a backtracking with MRV (minimum remaining values) heuristic.  

Here’s the code:  

```python
import sys
sys.setrecursionlimit(1000000)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))
    
    # Check if graph is 3-regular
    for i in range(n):
        if len(adj[i]) != 3:
            print("NO")
            return
    
    color = [-1] * m
    # For each vertex, track used colors
    used_at_vertex = [set() for _ in range(n)]
    
    # Order edges by degree of endpoints (most constrained first)
    edge_order = list(range(m))
    edge_order.sort(key=lambda e: len(adj[edges[e][0]]) + len(adj[edges[e][1]]), reverse=True)
    
    def backtrack(idx):
        if idx == m:
            return True
        e = edge_order[idx]
        u, v = edges[e]
        # Try colors 1,2,3
        for c in range(1, 4):
            if c not in used_at_vertex[u] and c not in used_at_vertex[v]:
                color[e] = c
                used_at_vertex[u].add(c)
                used_at_vertex[v].add(c)
                if backtrack(idx + 1):
                    return True
                used_at_vertex[u].remove(c)
                used_at_vertex[v].remove(c)
                color[e] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(color[i]) for i in range(m)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
