We can model this as a graph problem. Each hub has degree exactly 3, and each rod must be assigned one of three colors such that at each hub, the three incident rods have all different colors.

This is equivalent to a **3-edge-coloring** of a **3-regular graph**. By a known theorem (Kőnig’s line coloring theorem for bipartite graphs, and for general cubic graphs, the existence of a 3-edge-coloring is equivalent to the graph being **3-edge-colorable**, which is always true for bridgeless cubic graphs by the Four Color Theorem equivalent — but here we can solve it directly).

Since each vertex has degree 3, we can use a constructive approach:  
- Find a perfect matching, remove it, leaving a 2-regular graph (disjoint cycles).  
- Color the matching with color 1, then 2-color the remaining cycles with colors 2 and 3.

A perfect matching exists in any 3-regular graph (by Petersen’s theorem). We can find it via a simple greedy or blossom algorithm, but since n ≤ 2000, we can use a simple DFS-based matching.

Let’s implement:

```python
import sys
sys.setrecursionlimit(10000)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    edges = []
    adj = [[] for _ in range(n)]
    for i in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edges.append((u, v))
        adj[u].append((v, i))
        adj[v].append((u, i))
    
    # Find a perfect matching using greedy + augmenting paths
    match_edge = [-1] * n  # which edge index is used to match this vertex
    match_to = [-1] * n    # matched partner vertex
    
    def augment(u, visited):
        for v, ei in adj[u]:
            if visited[v]:
                continue
            visited[v] = True
            if match_to[v] == -1 or augment(match_to[v], visited):
                match_to[u] = v
                match_to[v] = u
                match_edge[u] = ei
                match_edge[v] = ei
                return True
        return False
    
    for u in range(n):
        if match_to[u] == -1:
            visited = [False] * n
            visited[u] = True
            augment(u, visited)
    
    # Check if perfect matching found
    if any(match_to[i] == -1 for i in range(n)):
        print("NO")
        return
    
    color = [0] * m
    # Color matching edges with 1
    for i in range(n):
        if match_edge[i] != -1:
            color[match_edge[i]] = 1
    
    # Build graph of remaining edges (degree 2)
    rem_adj = [[] for _ in range(n)]
    for i, (u, v) in enumerate(edges):
        if color[i] == 0:
            rem_adj[u].append((v, i))
            rem_adj[v].append((u, i))
    
    # 2-color the cycles
    visited = [False] * n
    for start in range(n):
        if not visited[start] and rem_adj[start]:
            # traverse cycle
            u = start
            prev = -1
            while True:
                visited[u] = True
                # pick next edge not going back to prev
                for v, ei in rem_adj[u]:
                    if v != prev:
                        break
                # assign color 2 or 3 alternating
                if color[ei] == 0:
                    # determine color based on previous edge color
                    if prev != -1:
                        # find previous edge color
                        for vv, eprev in rem_adj[prev]:
                            if vv == u:
                                color[ei] = 2 if color[eprev] == 3 else 3
                                break
                    else:
                        color[ei] = 2
                prev = u
                u = v
                if u == start:
                    break
    
    # Verify
    for u in range(n):
        cols = set()
        for v, ei in adj[u]:
            cols.add(color[ei])
        if len(cols) != 3:
            print("NO")
            return
    
    print("YES")
    print(" ".join(str(c) for c in color))

if __name__ == "__main__":
    solve()
```
