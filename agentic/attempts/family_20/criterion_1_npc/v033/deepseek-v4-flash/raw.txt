We can model this as a **3-edge-coloring** problem on a **3-regular graph** (each vertex has degree 3).  

By **Kőnig’s line coloring theorem**, every bipartite graph has edge chromatic number equal to its maximum degree. But here the graph is not necessarily bipartite.  

However, for **cubic graphs**, a 3-edge-coloring exists if and only if the graph is **bridgeless** (by the **Petersen’s theorem**).  
If the graph has a bridge, 3-edge-coloring is impossible.  

So the algorithm is:
1. Check if the graph is bridgeless (no edge whose removal disconnects the graph).
2. If it has a bridge → output `NO`.
3. Otherwise, find a 3-edge-coloring.

We can find a 3-edge-coloring for a bridgeless cubic graph using a constructive method:  
- Find a perfect matching (1-factor) and remove it → remaining graph is 2-regular (disjoint cycles).  
- Color the matching edges with color 1, then color the cycles alternately with colors 2 and 3.

Finding a perfect matching in a cubic bridgeless graph can be done via **Tutte’s theorem** or using a simple algorithm:  
- Since the graph is cubic and bridgeless, it has a perfect matching.  
- We can find one by repeatedly taking an edge and checking if the remaining graph still has a perfect matching (using blossom algorithm or simpler for n ≤ 2000).

Given constraints (n ≤ 2000, m ≤ 3000), we can implement a simple **augmenting path** matching algorithm for general graphs (Edmonds’ blossom) or use a simpler approach:  
- Since degree is 3, we can greedily find a perfect matching by picking edges and removing vertices, but we must ensure we don’t get stuck.  
- A safe method: use **Kőnig’s theorem** for bipartite? Not guaranteed bipartite.  
- We can use **Tutte’s reduction** or just use a known library-like implementation.

Here’s a working approach:

1. Check for bridges using DFS.
2. If no bridge, find a perfect matching using a simple DFS-based augmenting path for general graphs (Edmonds’ blossom is complex but we can implement a simpler version for small n).
3. Color matching edges with 1.
4. Remaining edges form disjoint cycles → color alternately 2 and 3.

Let’s implement it.

```python
import sys
sys.setrecursionlimit(10000)

def find_bridges(n, edges):
    g = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        g[u].append((v, idx))
        g[v].append((u, idx))
    visited = [False]*n
    tin = [-1]*n
    low = [-1]*n
    timer = 0
    bridges = set()
    
    def dfs(v, p_edge):
        nonlocal timer
        visited[v] = True
        tin[v] = low[v] = timer
        timer += 1
        for to, eid in g[v]:
            if eid == p_edge:
                continue
            if visited[to]:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, eid)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    bridges.add(eid)
    for i in range(n):
        if not visited[i]:
            dfs(i, -1)
    return bridges

def perfect_matching(n, edges):
    # Build adjacency with edge ids
    adj = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        adj[u].append((v, idx))
        adj[v].append((u, idx))
    match = [-1]*n
    match_edge = [-1]*n  # edge id used for matched vertex
    
    def augment(u, visited):
        for v, eid in adj[u]:
            if visited[v]:
                continue
            visited[v] = True
            if match[v] == -1 or augment(match[v], visited):
                match[u] = v
                match[v] = u
                match_edge[u] = eid
                match_edge[v] = eid
                return True
        return False
    
    for i in range(n):
        if match[i] == -1:
            visited = [False]*n
            visited[i] = True
            augment(i, visited)
    return match, match_edge

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    for _ in range(m):
        u = int(next(it))-1
        v = int(next(it))-1
        edges.append((u, v))
    
    # Check bridges
    bridges = find_bridges(n, edges)
    if bridges:
        print("NO")
        return
    
    # Find perfect matching
    match, match_edge = perfect_matching(n, edges)
    if any(x == -1 for x in match):
        print("NO")
        return
    
    color = [0]*m
    # Color matching edges with 1
    for i in range(n):
        if match_edge[i] != -1:
            color[match_edge[i]] = 1
    
    # Remaining edges form cycles
    # Build graph of remaining edges
    rem_adj = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        if color[idx] == 0:
            rem_adj[u].append((v, idx))
            rem_adj[v].append((u, idx))
    
    visited = [False]*n
    for start in range(n):
        if not visited[start] and rem_adj[start]:
            # traverse cycle
            cycle_edges = []
            prev = -1
            cur = start
            while True:
                visited[cur] = True
                # pick next unvisited neighbor
                nxt = None
                nxt_eid = None
                for to, eid in rem_adj[cur]:
                    if eid != prev:
                        nxt = to
                        nxt_eid = eid
                        break
                if nxt is None:
                    break
                cycle_edges.append(nxt_eid)
                prev = nxt_eid
                cur = nxt
                if cur == start:
                    break
            # color alternately 2 and 3
            for i, eid in enumerate(cycle_edges):
                color[eid] = 2 if i % 2 == 0 else 3
    
    # Check all colored
    if any(c == 0 for c in color):
        print("NO")
        return
    
    print("YES")
    print(" ".join(str(c) for c in color))

if __name__ == "__main__":
    solve()
```
