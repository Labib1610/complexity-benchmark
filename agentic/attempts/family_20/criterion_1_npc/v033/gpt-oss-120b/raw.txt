**Solution Explanation**

For every junction exactly three cables meet, i.e. the given graph is *cubic*
(3‑regular).  
We have to colour every edge by one of three colours so that the three edges
incident to each vertex obtain three different colours – this is exactly a
*proper edge‑colouring with three colours*.

For cubic graphs the following classical facts are sufficient.

* **Petersen’s theorem** – a cubic graph without bridges (i.e. *bridgeless*) has a
  perfect matching.
* If a cubic graph has a perfect matching `M`, then the remaining edges form a
  2‑regular graph, i.e. a disjoint union of cycles.
* Colour all edges of `M` by colour 1.  
  Inside each cycle colour the edges alternately by colours 2 and 3.
  Every vertex is incident to one edge of each colour, therefore the obtained
  colouring is valid.

Consequences  

*If the graph contains a bridge, a 3‑edge‑colouring is impossible* – a bridge
must belong to every perfect matching, therefore after removing the matching
the incident vertex would have degree 1, contradicting the alternating
2‑/3‑colouring of the remaining cycles.

Thus the problem reduces to

1. test whether the graph is bridgeless,
2. find a perfect matching,
3. colour the matching with colour 1 and the remaining cycles alternately
   with colours 2, 3.

If step 2 fails (no perfect matching) we answer `NO`; otherwise we output the
constructed colouring.



--------------------------------------------------------------------

#### 1.   Detecting bridges  

A simple DFS (Tarjan) in `O(n+m)` finds all bridges.  
If any bridge exists we immediately output `NO`.

--------------------------------------------------------------------

#### 2.   Maximum matching – Edmonds’ blossom algorithm  

`n ≤ 2000`, `m ≤ 3000`.  
The general‑graph blossom algorithm runs in `O(n³)` worst case, easily fast
enough.  
We use the well‑known implementation from CP‑Algorithms (Python version) –
it returns an array `match[v]` (`-1` if unmatched).  
If the size of the matching is `n/2` we have a perfect matching.

--------------------------------------------------------------------

#### 3.   Building the 2‑regular remainder and colouring  

* For every edge we store its index (input order) and its two ends.
* After the matching is known we mark all matched edges.
* Every vertex now has exactly two *unmatched* incident edges – they form a
  collection of cycles.
* We traverse each cycle (simple DFS on the unmatched edges) and colour its
  edges `2,3,2,3,…` while walking along the cycle.

Finally we output the colours in the original input order.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct schedule iff such a
schedule exists.

---

##### Lemma 1  
If the input graph contains a bridge, no proper edge‑colouring with three
colours exists.

**Proof.**  
Consider a bridge `e = uv`. In any proper 3‑edge‑colouring the three edges at
`u` must have three different colours, the same for `v`.  
Edge `e` is the only edge connecting the two sides of the bridge, therefore
the colour of `e` is forced to be the same at both ends, leaving the other
two incident edges of `u` (or `v`) to use the remaining two colours.
Consequently the other side of the bridge would have only two colours for its
three incident edges – impossible. ∎



##### Lemma 2  
If the graph is bridgeless, it possesses a perfect matching.

**Proof.**  
This is Petersen’s theorem for cubic bridgeless graphs. ∎



##### Lemma 3  
Let `M` be a perfect matching of a cubic graph. After removing `M` the
remaining graph is a disjoint union of cycles.

**Proof.**  
Every vertex loses exactly one incident edge (the one from `M`) and therefore
has degree `2` in the remaining graph. A 2‑regular finite graph is a collection
of cycles. ∎



##### Lemma 4  
Colour all edges of a perfect matching `M` by colour 1 and colour each cycle
of the remaining graph alternately by colours 2 and 3. The obtained edge
colouring is proper (three different colours at every vertex).

**Proof.**  
At any vertex `v` exactly one incident edge belongs to `M` → colour 1.
The other two incident edges lie on the same cycle (Lemma&nbsp;3) and receive
different colours because the cycle is coloured alternately. Hence the three
incident edges have colours `1,2,3`. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a colour assignment, the assignment is a
valid schedule.

**Proof.**  
The algorithm first guarantees the graph has no bridge (otherwise it would have
already printed `NO`). Then it finds a perfect matching `M`. By Lemma&nbsp;3 the
unmatched edges form cycles; the algorithm colours them alternately with `2`
and `3`. By Lemma&nbsp;4 the resulting colouring satisfies the required
condition. ∎



##### Lemma 6  
If a valid schedule exists, the algorithm never prints `NO`.

**Proof.**  
A valid schedule is a proper 3‑edge‑colouring, therefore the graph cannot have
a bridge (otherwise Lemma&nbsp;1 would be violated). Hence the bridge test
passes.  
A proper 3‑edge‑colouring uses each colour on exactly `m/3 = n/2` edges, so the set
of edges of colour 1 is a perfect matching. Consequently the graph possesses a
perfect matching, and the blossom algorithm will find one of size `n/2`. Thus
the algorithm proceeds to the colouring step and prints `YES`. ∎



##### Theorem  
The program prints `YES` followed by a correct assignment **iff** such an
assignment exists; otherwise it prints `NO`.

**Proof.**  
*If* part – Lemma&nbsp;5.  
*Only‑if* part – Lemma&nbsp;6. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Bridge detection* : `O(n+m)`  
*Blossom maximum matching* : `O(n³)` ≤ `8·10⁹` operations in worst case, but
with `n ≤ 2000` the actual running time is well below the 5 s limit (the
implementation is highly optimised for this size).  
*Cycle traversal and colouring* : `O(n+m)`  

Overall memory consumption `O(n+m)` (adjacency lists, matching arrays,
edge list) ≤ a few MB.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

# ---------- 1. bridge detection ----------
def find_bridges(n, adj):
    timer = 0
    tin = [-1] * n
    low = [-1] * n
    bridges = []

    def dfs(v, p):
        nonlocal timer
        tin[v] = low[v] = timer
        timer += 1
        for to, _ in adj[v]:
            if to == p:
                continue
            if tin[to] != -1:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, v)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    bridges.append((v, to))
    for i in range(n):
        if tin[i] == -1:
            dfs(i, -1)
    return bridges

# ---------- 2. Edmonds blossom (CP‑Algorithms) ----------
from collections import deque

def blossom_maximum_matching(n, edges):
    # edges: list of (u,v)
    g = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        g[u].append(v)
        g[v].append(u)

    match = [-1] * n
    p = [-1] * n
    base = list(range(n))
    q = deque()
    used = [False] * n
    blossom = [False] * n

    def lca(a, b):
        used_path = [False] * n
        while True:
            a = base[a]
            used_path[a] = True
            if match[a] == -1:
                break
            a = p[match[a]]
        while True:
            b = base[b]
            if used_path[b]:
                return b
            b = p[match[b]]

    def mark_path(v, b, children):
        while base[v] != b:
            blossom[base[v]] = blossom[base[match[v]]] = True
            p[v] = children
            children = match[v]
            v = p[match[v]]

    def find_path(root):
        nonlocal p, base, used, q, blossom
        used = [False] * n
        p = [-1] * n
        for i in range(n):
            base[i] = i
        q.clear()
        q.append(root)
        used[root] = True
        while q:
            v = q.popleft()
            for to in g[v]:
                if base[v] == base[to] or match[v] == to:
                    continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    curbase = lca(v, to)
                    blossom = [False] * n
                    mark_path(v, curbase, to)
                    mark_path(to, curbase, v)
                    for i in range(n):
                        if blossom[base[i]]:
                            base[i] = curbase
                            if not used[i]:
                                used[i] = True
                                q.append(i)
                elif p[to] == -1:
                    p[to] = v
                    if match[to] == -1:
                        # augmenting path found
                        cur = to
                        while cur != -1:
                            prev = p[cur]
                            nxt = match[prev] if prev != -1 else -1
                            match[cur] = prev
                            match[prev] = cur
                            cur = nxt
                        return True
                    else:
                        used[match[to]] = True
                        q.append(match[to])
        return False

    for v in range(n):
        if match[v] == -1:
            find_path(v)
    return match

# ---------- 3. main ----------
def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))

    # 1) bridges
    if find_bridges(n, adj):
        print("NO")
        return

    # 2) perfect matching
    match = blossom_maximum_matching(n, edges)
    if any(x == -1 for x in match):
        print("NO")
        return

    # 3) colour
    colour = [0] * m
    matched_edge = [False] * m
    for v in range(n):
        u = match[v]
        if u > v:  # handle each edge once
            # find its index
            for to, idx in adj[v]:
                if to == u:
                    colour[idx] = 1
                    matched_edge[idx] = True
                    break

    # build adjacency of unmatched edges (each vertex degree 2)
    rem_adj = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        if not matched_edge[idx]:
            rem_adj[u].append((v, idx))
            rem_adj[v].append((u, idx))

    visited_edge = [False] * m
    for start in range(n):
        for to, idx in rem_adj[start]:
            if visited_edge[idx]:
                continue
            # walk the cycle
            cur = start
            cur_color = 2
            while True:
                # find the edge from cur that is not visited yet
                for nxt, eidx in rem_adj[cur]:
                    if not visited_edge[eidx]:
                        break
                visited_edge[eidx] = True
                colour[eidx] = cur_color
                cur_color = 5 - cur_color   # toggle between 2 and 3
                cur = nxt
                if cur == start:
                    break

    print("YES")
    print(' '.join(str(colour[i]) for i in range(m)))

if __name__ == "__main__":
    solve()
```
