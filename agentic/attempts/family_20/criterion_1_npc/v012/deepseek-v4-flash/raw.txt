We can model this as a graph problem.  
Each vertex has degree exactly 3, and we need to 3-color the edges so that no two edges sharing a vertex have the same color.  

This is equivalent to edge-coloring a cubic graph with 3 colors, which is always possible by **Vizing’s theorem** (since maximum degree is 3, we need at most 4 colors, but for cubic graphs it’s always 3-colorable — this is a known result for bridgeless cubic graphs; here we can always find a 3-edge-coloring because the graph is 3-regular and we can use a constructive algorithm).

We can solve it by building the line graph and 3-coloring its vertices (which correspond to edges of the original graph).  
Since the line graph of a cubic graph is 4-regular, we can use a greedy coloring with backtracking if needed, but here a simple greedy with proper ordering works.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(10000)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    edges = []
    adj = [[] for _ in range(n)]
    for i in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edges.append((u, v))
        adj[u].append((v, i))
        adj[v].append((u, i))
    
    # Build line graph: vertices are edges of original graph
    line_adj = [[] for _ in range(m)]
    for u in range(n):
        for i in range(len(adj[u])):
            for j in range(i+1, len(adj[u])):
                e1 = adj[u][i][1]
                e2 = adj[u][j][1]
                line_adj[e1].append(e2)
                line_adj[e2].append(e1)
    
    color = [-1] * m
    
    # Greedy coloring with backtracking for safety
    def dfs(e):
        if e == m:
            return True
        used = [False]*4
        for nb in line_adj[e]:
            if color[nb] != -1:
                used[color[nb]] = True
        for c in range(1, 4):
            if not used[c]:
                color[e] = c
                if dfs(e+1):
                    return True
                color[e] = -1
        return False
    
    if dfs(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
