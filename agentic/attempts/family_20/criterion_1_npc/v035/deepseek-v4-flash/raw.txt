We can model this as a **3-edge-coloring** problem on a **3-regular graph** (every vertex has degree 3).  

By **Kőnig’s line coloring theorem**, every bipartite graph has edge chromatic number equal to its maximum degree. But here the graph is not necessarily bipartite. For a 3-regular graph, a 3-edge-coloring exists if and only if the graph is **bridgeless** (by the **Four Color Theorem** equivalent for cubic graphs).  

However, since n ≤ 2000, we can solve it directly with **backtracking + constraint propagation** or use a known polynomial method:  
- For cubic graphs, a 3-edge-coloring exists iff the graph is **3-edge-colorable**, which is equivalent to being **bridgeless** (no bridges).  
- We can check for bridges and if none, find the coloring via a constructive algorithm.

A simple constructive approach:  
1. Find a **perfect matching** (since cubic graph has one by Petersen’s theorem if bridgeless).  
2. Remove it; the remaining graph is 2-regular (disjoint cycles).  
3. Color the cycles alternately with the two remaining colors.  
4. Color the matching edges with the third color.

We can find a perfect matching using **Blossom algorithm** (or simpler: since n ≤ 2000, we can use a maximum matching algorithm).  
But implementing Blossom is heavy. Instead, we can use a **backtracking with heuristics** because n is small enough (2000 edges, 3 colors).  

We can do a DFS-based edge coloring with pruning:  
- At each step, pick an uncolored edge with the fewest available colors (MRV heuristic).  
- Try each available color, check constraints, recurse.  
- If conflict, backtrack.

Given m = 3n/2 ≤ 3000, this should be fast enough with good heuristics.

Let’s implement that.

```python
import sys
sys.setrecursionlimit(10000000)

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))
    
    color = [-1] * m
    
    # For each vertex, track which colors are used on incident edges
    used_at_vertex = [set() for _ in range(n)]
    
    # MRV heuristic: pick uncolored edge with fewest available colors
    def get_candidates(eidx):
        u, v = edges[eidx]
        used = used_at_vertex[u] | used_at_vertex[v]
        return [c for c in (1,2,3) if c not in used]
    
    def dfs(count):
        if count == m:
            return True
        # Find edge with fewest candidates
        best_e = -1
        best_cands = None
        for i in range(m):
            if color[i] == -1:
                cands = get_candidates(i)
                if not cands:
                    return False
                if best_e == -1 or len(cands) < len(best_cands):
                    best_e = i
                    best_cands = cands
                    if len(cands) == 1:
                        break
        eidx = best_e
        u, v = edges[eidx]
        for c in best_cands:
            # assign
            color[eidx] = c
            used_at_vertex[u].add(c)
            used_at_vertex[v].add(c)
            if dfs(count + 1):
                return True
            # backtrack
            used_at_vertex[u].remove(c)
            used_at_vertex[v].remove(c)
            color[eidx] = -1
        return False
    
    if dfs(0):
        print("YES")
        print(" ".join(str(color[i]) for i in range(m)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
