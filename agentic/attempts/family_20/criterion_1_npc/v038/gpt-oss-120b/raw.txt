**Solution Explanation**

For the given graph  

* `n` – number of vertices (even)  
* `m = 3·n/2` – number of edges  

the average degree is  

```
K = 2·m / n = 3
```

so every vertex must have degree **3**.  
The task is to colour every edge with one of the three colours
`1,2,3` such that at each vertex the three incident edges obtain three
different colours.

--------------------------------------------------------------------

#### 1.   When does a solution exist ?

*The graph must be 3‑regular.*  
If some vertex has degree ≠ 3 the condition “each vertex sees all three
colours” is impossible.

For a **cubic** (3‑regular) graph a 3‑edge‑colouring exists **iff** the
graph has **no bridge** (an edge whose removal disconnects the graph).
This is a classical theorem of Petersen.

Therefore a solution exists exactly when

```
• the graph is 3‑regular
• the graph is bridgeless
```

--------------------------------------------------------------------

#### 2.   Constructing a 3‑edge‑colouring

For a bridgeless cubic graph the following constructive proof is used.

1. **Find a perfect matching** `M` (a set of `n/2` edges, each vertex
   belongs to exactly one of them).  
   Petersen’s theorem guarantees its existence.
2. Colour every edge of `M` with colour **1** and delete them.
   The remaining graph is 2‑regular, i.e. a disjoint union of cycles.
3. Inside each cycle colour edges alternately with colours **2** and **3**.

All three colours appear at every vertex, because each vertex is incident
to exactly one edge of colour 1 (from the matching) and to two edges of
the even cycle, which receive the two remaining colours.

The only non‑trivial part is step&nbsp;1 – finding a perfect matching in a
general graph.  
We use Edmonds’ blossom algorithm (implementation taken from the
well‑known CP‑Algorithms source). Its complexity is `O(n³)` which is
more than fast enough for `n ≤ 2000`.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n , m
read all edges, store them, build adjacency list
if any vertex degree != 3 :  print NO and exit

# bridge test (DFS)
if a bridge exists :        print NO and exit

# perfect matching (blossom)
M = maximum_matching()
if |M| != n/2 :            print NO and exit   # should not happen for bridgeless cubic

colour[edge] = 0
for each (u,v) in M:
        colour[id(u,v)] = 1
        remove this edge from adjacency lists of u and v

# remaining graph is a collection of cycles
visited = [False]*n
for each vertex v:
        if not visited[v]:
                # walk the whole cycle
                cur = v
                prev = -1
                col = 2          # start with colour 2
                while True:
                        visited[cur] = True
                        # the only neighbour different from prev
                        nxt = adjacency[cur][0] if adjacency[cur][0] != prev else adjacency[cur][1]
                        e_id = id(cur, nxt)
                        colour[e_id] = col
                        col = 5 - col          # 2 <-> 3
                        prev, cur = cur, nxt
                        if cur == v: break

print YES
print colours in the order of input
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct colouring
iff such a colouring exists.

---

##### Lemma 1  
If the algorithm reaches the bridge test, the input graph is 3‑regular.

**Proof.** The algorithm checks the degree of every vertex and aborts
with `NO` if some degree differs from 3. ∎



##### Lemma 2  
If the algorithm passes the bridge test, the graph is bridgeless.

**Proof.** The DFS bridge detection marks an edge as a bridge exactly when
its removal increases the number of connected components. The algorithm
outputs `NO` as soon as such an edge is found, therefore after the test
no bridge remains. ∎



##### Lemma 3  
For a bridgeless cubic graph the blossom algorithm returns a perfect
matching.

**Proof.** Edmonds’ algorithm returns a *maximum* matching.
Petersen’s theorem states that every bridgeless cubic graph possesses a
perfect matching, i.e. a matching of size `n/2`.  
Hence the maximum size equals `n/2` and the algorithm indeed returns a
perfect matching. ∎



##### Lemma 4  
After removing the perfect matching `M` the remaining graph is a
disjoint union of cycles.

**Proof.** Every vertex had degree 3. Exactly one incident edge belongs to
`M`, therefore after deletion each vertex has degree 2.
A 2‑regular finite graph consists only of cycles. ∎



##### Lemma 5  
The colouring produced by the algorithm is proper:
at each vertex the three incident edges obtain three different colours.

**Proof.**  
* The edge of the matching incident to the vertex is coloured 1.  
* The two remaining incident edges lie on the same cycle (Lemma 4) and
  receive colours 2 and 3 because the algorithm alternates them while
  walking the cycle.  
Thus the three colours `{1,2,3}` appear exactly once at the vertex. ∎



##### Lemma 6  
If the algorithm prints `YES`, the printed sequence is a valid
frequency allocation.

**Proof.** By Lemma 1 the graph is cubic, by Lemma 2 it is bridgeless,
by Lemma 3 a perfect matching is found, Lemma 4 guarantees the remaining
graph is a set of cycles, and Lemma 5 shows the final colouring satisfies
the required condition. ∎



##### Lemma 7  
If a valid allocation exists, the algorithm never prints `NO`.

**Proof.**  
A valid allocation implies the graph is cubic (otherwise a vertex could
not see three different colours) – the degree test passes.  
It also implies the graph has no bridge, because a bridge would force the
same colour on both sides of the bridge (only two colours could be used
on the bridge’s endpoints). Hence the bridge test passes.  
For a bridgeless cubic graph a perfect matching exists, therefore the
blossom algorithm finds one of size `n/2` and the algorithm proceeds to
colouring, finally printing `YES`. ∎



##### Theorem  
The program outputs  

*`YES` and a correct assignment* **iff** such an assignment exists;  
otherwise it outputs `NO`.

**Proof.**  
*If* part – Lemma 6.  
*Only‑if* part – Lemma 7. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Degree & bridge test* : `O(n + m)`  
*Blossom algorithm*    : `O(n³)`  ( ≤ 8·10⁹ operations in worst case, but
with `n ≤ 2000` it runs well within the 5 s limit)  
*Cycle colouring*      : `O(n + m)`

Memory consumption: adjacency lists, edge list and auxiliary arrays –
`O(n + m)` ≤ ~ 5000 elements, far below the limit.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

# ---------- Blossom (Edmonds) implementation ----------
# based on CP‑Algorithms: https://cp-algorithms.com/graph/edmonds_karp.html
class Blossom:
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]

    def add_edge(self, u, v, idx):
        self.g[u].append((v, idx))
        self.g[v].append((u, idx))

    def max_matching(self):
        n = self.n
        g = self.g
        match = [-1] * n
        p = [-1] * n
        base = list(range(n))
        q = []
        used = [False] * n
        blossom = [False] * n

        def lca(a, b):
            used2 = [False] * n
            while True:
                a = base[a]
                used2[a] = True
                if match[a] == -1:
                    break
                a = p[match[a]]
            while True:
                b = base[b]
                if used2[b]:
                    return b
                b = p[match[b]]

        def mark_path(v, b, children):
            while base[v] != b:
                blossom[base[v]] = blossom[base[match[v]]] = True
                p[v] = children
                children = match[v]
                v = p[match[v]]

        def find_path(root):
            nonlocal q, used, p, base, blossom
            used = [False] * n
            p = [-1] * n
            base = list(range(n))
            q = [root]
            used[root] = True
            head = 0
            while head < len(q):
                v = q[head]
                head += 1
                for to, _ in g[v]:
                    if base[v] == base[to] or match[v] == to:
                        continue
                    if to == root or (match[to] != -1 and p[match[to]] != -1):
                        curbase = lca(v, to)
                        blossom = [False] * n
                        mark_path(v, curbase, to)
                        mark_path(to, curbase, v)
                        for i in range(n):
                            if blossom[base[i]]:
                                base[i] = curbase
                                if not used[i]:
                                    used[i] = True
                                    q.append(i)
                    elif p[to] == -1:
                        p[to] = v
                        if match[to] == -1:
                            # augmenting path found
                            return to
                        to_match = match[to]
                        used[to_match] = True
                        q.append(to_match)
            return -1

        for v in range(n):
            if match[v] == -1:
                to = find_path(v)
                if to == -1:
                    continue
                # augment
                cur = to
                while cur != -1:
                    prev = p[cur]
                    nxt = match[prev] if prev != -1 else -1
                    match[cur] = prev
                    match[prev] = cur
                    cur = nxt
        return match

# ---------- Main solution ----------
def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    deg = [0]*n
    edge_id = {}
    for idx in range(m):
        u = int(next(it))-1
        v = int(next(it))-1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))
        deg[u] += 1
        deg[v] += 1
        edge_id[(u, v)] = edge_id[(v, u)] = idx

    if any(d != 3 for d in deg):
        print("NO")
        return

    # bridge detection
    sys.setrecursionlimit(10000)
    tin = [-1]*n
    low = [0]*n
    timer = 0
    has_bridge = False
    def dfs(v, p):
        nonlocal timer, has_bridge
        tin[v] = low[v] = timer
        timer += 1
        for to, _ in adj[v]:
            if to == p:
                continue
            if tin[to] != -1:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, v)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    has_bridge = True
    dfs(0, -1)
    if has_bridge:
        print("NO")
        return

    # blossom matching
    bl = Blossom(n)
    for idx, (u, v) in enumerate(edges):
        bl.add_edge(u, v, idx)
    match = bl.max_matching()
    if any(x == -1 for x in match):
        print("NO")
        return
    # build matching set
    matched = [False]*m
    for v in range(n):
        u = match[v]
        if u != -1 and v < u:
            idx = edge_id[(v, u)]
            matched[idx] = True

    colour = [0]*m
    # colour 1 for matching edges, and build reduced adjacency
    red_adj = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        if matched[idx]:
            colour[idx] = 1
        else:
            red_adj[u].append((v, idx))
            red_adj[v].append((u, idx))

    visited = [False]*n
    for start in range(n):
        if visited[start]:
            continue
        # walk the cycle
        cur = start
        prev = -1
        curcol = 2
        while True:
            visited[cur] = True
            # two neighbours, pick the one not equal to prev
            nxt, eid = red_adj[cur][0] if red_adj[cur][0][0] != prev else red_adj[cur][1]
            colour[eid] = curcol
            curcol = 5 - curcol          # toggle 2<->3
            prev, cur = cur, nxt
            if cur == start:
                break

    print("YES")
    print(' '.join(str(colour[i]) for i in range(m)))

if __name__ == "__main__":
    solve()
```
