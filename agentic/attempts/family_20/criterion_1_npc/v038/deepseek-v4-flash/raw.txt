 We need to check if the graph is K-edge-colorable, where K = 2m/n.  
Since every vertex has degree K, and the graph is K-regular, we need to see if it has a proper K-edge-coloring.  

For K-regular graphs, a proper K-edge-coloring exists if and only if the graph is 1-factorable, which is true for all regular bipartite graphs, but for general regular graphs it’s not always true.  
However, here K = 3 because m = 3n/2, so each vertex has degree 3.  
A cubic graph has a proper 3-edge-coloring if and only if it is bridgeless (by Vizing’s theorem and the fact that 3-edge-coloring is equivalent to being 3-edge-colorable, which for cubic graphs is equivalent to being bridgeless).  

So the problem reduces to checking if the given cubic graph is bridgeless.  
If yes, output YES and a valid 3-edge-coloring.  
If not, output NO.  

We can find a 3-edge-coloring using a standard algorithm:  
- Find a perfect matching (1-factor) in the cubic graph, remove it, leaving a 2-regular graph (disjoint cycles), then color the cycles alternately with the two remaining colors.  

But finding a perfect matching in a general cubic graph is nontrivial.  
However, since n ≤ 2000 and m ≤ 3000, we can use a simple approach:  
- Use a backtracking or heuristic to find a 3-edge-coloring.  
- Since cubic graphs with bridges are not 3-edge-colorable, we can first check for bridges.  
- If no bridges, we can use a known constructive method:  
  - Find a perfect matching using a standard algorithm (e.g., Blossom algorithm) or use a simpler approach because the graph is cubic and small.  

Given the constraints, we can implement a simple backtracking edge-coloring with pruning, which should work for n ≤ 2000 and m ≤ 3000 if the graph is 3-edge-colorable.  

Let’s implement:  
1. Read input.  
2. Build adjacency list with edge indices.  
3. Check if graph is bridgeless (using DFS to find bridges).  
4. If bridges exist, print NO.  
5. Else, find a 3-edge-coloring using backtracking with forward checking.  

We’ll use a simple backtracking that tries colors 1,2,3 for each edge, ensuring no two incident edges share the same color.  

Since the graph is cubic and bridgeless, a solution exists, and backtracking should find it quickly.  

Let’s write the code.```python
import sys
sys.setrecursionlimit(1000000)

def main():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))
    
    K = 2 * m // n  # should be 3 for this problem
    
    # Check if graph is bridgeless
    # Find bridges using DFS
    disc = [-1] * n
    low = [0] * n
    time = 0
    bridges = set()
    
    def dfs(u, parent_edge):
        nonlocal time
        disc[u] = low[u] = time
        time += 1
        for v, eid in adj[u]:
            if eid == parent_edge:
                continue
            if disc[v] == -1:
                dfs(v, eid)
                low[u] = min(low[u], low[v])
                if low[v] > disc[u]:
                    bridges.add(eid)
            else:
                low[u] = min(low[u], disc[v])
    
    for i in range(n):
        if disc[i] == -1:
            dfs(i, -1)
    
    if bridges:
        print("NO")
        return
    
    # Now find a proper 3-edge-coloring using backtracking
    color = [-1] * m
    # For each vertex, which colors are used
    used_at_vertex = [set() for _ in range(n)]
    
    # Sort edges by degree of endpoints to improve backtracking
    edge_order = list(range(m))
    edge_order.sort(key=lambda e: len(adj[edges[e][0]]) + len(adj[edges[e][1]]), reverse=True)
    
    def backtrack(eidx):
        if eidx == m:
            return True
        e = edge_order[eidx]
        u, v = edges[e]
        # Try colors 1..K
        for c in range(1, K+1):
            if c not in used_at_vertex[u] and c not in used_at_vertex[v]:
                color[e] = c
                used_at_vertex[u].add(c)
                used_at_vertex[v].add(c)
                if backtrack(eidx + 1):
                    return True
                used_at_vertex[u].remove(c)
                used_at_vertex[v].remove(c)
                color[e] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(color[i]) for i in range(m)))
    else:
        print("NO")

if __name__ == "__main__":
    main()
