We can model this as a **3‑edge-coloring** problem on a **3‑regular graph** (each vertex has degree 3).  
By **Vizing’s theorem** and the fact that the graph is 3‑regular, a proper 3‑edge-coloring always exists if the graph is **bridgeless** (no edge whose removal disconnects the graph).  
If the graph has a bridge, a 3‑edge-coloring may not exist.

We can solve it by:
1. Checking if the graph is bridgeless.
2. If yes, find a 3‑edge-coloring using a standard algorithm (e.g., based on finding a 1‑factorization or using a backtracking/flow approach).

Since n ≤ 2000, m = 3n/2 ≤ 3000, we can use a constructive algorithm based on **Kőnig’s line-coloring theorem** for bipartite graphs, but here the graph is not necessarily bipartite.  
However, for 3‑regular bridgeless graphs, we can use **Tait’s theorem**: a 3‑edge-coloring corresponds to a partition of edges into three perfect matchings.

We can find a perfect matching, remove it, and the remaining graph is 2‑regular (a union of cycles), which is 2‑edge-colorable.  
But finding a perfect matching in a general graph can be done with **Edmonds’ blossom algorithm**, which is complex but feasible for n=2000.

Let’s implement a simpler approach:  
We can use a **backtracking with pruning** because m ≤ 3000, but that might be too slow in worst case.  
Better: Use **network flow** to find a 3‑edge-coloring by reducing to edge-coloring of a 3‑regular graph.

Actually, a known constructive method:  
- Find a **1‑factor** (perfect matching) using Edmonds’ algorithm.  
- Remove it; the remaining graph is 2‑regular → cycles.  
- Color the matching edges with color 1.  
- Color each cycle alternately with colors 2 and 3.

We need to implement Edmonds’ blossom for general graph matching.

Let’s code it.

import sys
sys.setrecursionlimit(1000000)

def find_matching(n, edges):
    # Edmonds' blossom algorithm for maximum matching
    # n: number of vertices (0-indexed)
    # edges: list of (u,v) pairs
    adj = [[] for _ in range(n)]
    for idx, (u,v) in enumerate(edges):
        adj[u].append((v, idx))
        adj[v].append((u, idx))
    match = [-1] * n
    p = [-1] * n
    base = [-1] * n
    used = [False] * n
    blossom = [False] * n
    from collections import deque

    def lca(a, b):
        used_path = [False] * n
        while True:
            a = base[a]
            used_path[a] = True
            if match[a] == -1:
                break
            a = p[match[a]]
        while True:
            b = base[b]
            if used_path[b]:
                return b
            b = p[match[b]]

    def mark_path(v, b, children):
        while base[v] != b:
            blossom[base[v]] = blossom[base[match[v]]] = True
            p[v] = children
            children = match[v]
            v = p[match[v]]

    def find_path(root):
        nonlocal p, base, used, blossom
        used = [False] * n
        p = [-1] * n
        for i in range(n):
            base[i] = i
        q = deque([root])
        used[root] = True
        while q:
            v = q.popleft()
            for to, eid in adj[v]:
                if base[v] == base[to] or match[v] == to:
                    continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    curbase = lca(v, to)
                    blossom = [False] * n
                    mark_path(v, curbase, to)
                    mark_path(to, curbase, v)
                    for i in range(n):
                        if blossom[base[i]]:
                            base[i] = curbase
                            if not used[i]:
                                used[i] = True
                                q.append(i)
                elif p[to] == -1:
                    p[to] = v
                    if match[to] == -1:
                        return to
                    used[match[to]] = True
                    q.append(match[to])
        return -1

    for i in range(n):
        if match[i] == -1:
            v = find_path(i)
            if v == -1:
                continue
            while v != -1:
                pv = p[v]
                nv = match[pv] if pv != -1 else -1
                match[v] = pv
                match[pv] = v
                v = nv
    # Return matched edges
    matching = []
    for u in range(n):
        if match[u] != -1 and u < match[u]:
            matching.append((u, match[u]))
    return matching

        nonlocal timer

        if not visited[i]:
            dfs(i, -1)
    
    if bridges:

    # Find a perfect matching (1-factor)

    if len(matching) != n//2:
        print("NO")

    match_set = set()

        if (u,v) in match_set:
            color[idx] = 1

        if color[idx] == 0:

            rem_adj[v].append((u, idx))
    
    # Color cycles alternately 2 and 3
    visited_cycle = [False]*n
    for start in range(n):
        if not visited_cycle[start] and rem_adj[start]:
            # traverse cycle
            stack = [(start, -1, -1)]  # node, parent, edge_id
            cycle_edges = []
            while stack:
                v, p, eid = stack.pop()
                if visited_cycle[v]:

                visited_cycle[v] = True
                if eid != -1:
                    cycle_edges.append(eid)
                for to, eid2 in rem_adj[v]:
                    if to == p:

            # Now color cycle edges alternately
            # Find a cycle start
            # Actually we need to walk the cycle properly
            # Let's do a simple BFS to get the cycle order
            # Since it's 2-regular, each component is a cycle
            # Find a starting edge
            start_node = start
            # find an edge
            if not rem_adj[start_node]:
                continue
            prev = -1
            cur = start_node

            while True:

    # Verify each vertex has one of each color

            return
