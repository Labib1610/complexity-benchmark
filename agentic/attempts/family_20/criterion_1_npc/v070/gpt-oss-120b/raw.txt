**Solution Explanation**

For every vertex exactly three edges are incident.
We have to colour the edges with three colours `1,2,3` such that the three
incident edges of every vertex receive three different colours.

--------------------------------------------------------------------

#### 1.   Observations  

* The required colouring is a **proper edge‑colouring** with three colours.
* A *cubic* (3‑regular) graph is 3‑edge‑colourable **iff** it has **no bridge**  
  (Petersen’s theorem).  
  If a bridge exists, the two sides of the bridge need the same colour on
  the bridge, therefore the three incident edges of the bridge’s end‑vertices
  cannot all be different – impossible.
* For a bridgeless cubic graph a 3‑edge‑colouring can be built very easily:

  1. find a **perfect matching** `M` (every vertex is incident to exactly one
     edge of `M`);
  2. colour all edges of `M` with colour `1`;
  3. delete `M`.  
     Every vertex now has degree `2`, therefore the remaining graph is a
     disjoint union of cycles;
  4. colour the edges of each cycle alternately with colours `2` and `3`.

  This always works because a cycle is 2‑regular.

So the whole problem reduces to

*detect a bridge* and, if none exists,
*find a perfect matching* in a cubic graph (up to `n = 2000`).

--------------------------------------------------------------------

#### 2.   Bridge detection  

A standard depth‑first search with low‑link values (`O(n+m)`) tells us whether
the graph contains a bridge.

--------------------------------------------------------------------

#### 3.   Perfect matching – Edmonds’ blossom algorithm  

The graph is not bipartite, therefore we need a general matching algorithm.
Edmonds’ blossom algorithm runs in `O(n³)` in the worst case, but the
implementation by M. K. Kulikov (public domain) works fast enough for
`n ≤ 2000` (the number of edges is only `3n/2 ≤ 3000`).

The algorithm returns a list `match[v] = u` (`u = -1` if `v` is unmatched).
For a cubic graph without bridges a perfect matching always exists,
so after the algorithm we simply check that every vertex is matched.

--------------------------------------------------------------------

#### 4.   Constructing the answer  

* For every input edge we store its index.
* After the matching is known we colour the matched edges with `1`.
* The remaining edges form only cycles.
  We walk each cycle (simple DFS because degree is `2`) and colour the
  traversed edges `2,3,2,3,…`.
* Finally we output the colours in the original input order.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct colouring
iff such a colouring exists.

---

##### Lemma 1  
If the input graph contains a bridge, no 3‑edge‑colouring satisfying the
condition exists.

**Proof.**  
Consider a bridge `e = uv`. Removing `e` disconnects the graph.
In any proper 3‑edge‑colouring the three edges incident to `u` must have
different colours, therefore the colour of `e` is forced to be the colour
missing among the other two edges at `u`. The same argument at `v` forces
the colour of `e` to be the colour missing at `v`. Because the two sides of
the bridge are independent, the missing colours at `u` and `v` are equal,
hence the colour of `e` would have to be simultaneously two different
colours – impossible. ∎



##### Lemma 2  
If the graph has no bridge, the algorithm finds a perfect matching.

**Proof.**  
A cubic bridgeless graph is *class 1* (Petersen’s theorem), i.e. it possesses
a 3‑edge‑colouring. The edges of any colour class of such a colouring form a
perfect matching (each vertex is incident to exactly one edge of that colour).
Edmonds’ algorithm always returns a maximum matching; therefore its size is at
least the size of that colour class, i.e. `n/2`. Hence the algorithm returns a
perfect matching. ∎



##### Lemma 3  
After removing the perfect matching, the remaining graph is a disjoint union
of cycles.

**Proof.**  
Every vertex had degree `3`. Exactly one incident edge is removed (the matched
edge), therefore the degree becomes `2`. A finite graph where every vertex has
degree `2` is a collection of cycles. ∎



##### Lemma 4  
Colouring the matched edges with colour 1 and the edges of each remaining
cycle alternately with colours 2 and 3 yields a valid assignment.

**Proof.**  
*Matched edges*: each vertex is incident to exactly one of them, so colour 1
appears exactly once at the vertex.  
*Cycle edges*: on a cycle the colours alternate `2,3,2,3,…`; consequently each
vertex (which belongs to exactly one cycle edge of each parity) receives one
edge of colour 2 and one of colour 3.  
Thus at every vertex the three incident edges have colours `1,2,3`, all
different. ∎



##### Lemma 5  
If the algorithm outputs `YES`, the printed colours satisfy the required
condition.

**Proof.**  
`YES` is printed only when (i) no bridge was found and (ii) a perfect
matching was obtained. By Lemma 3 the remaining edges are cycles.
The algorithm colours as described in Lemma 4, therefore the condition holds. ∎



##### Lemma 6  
If a valid colouring exists, the algorithm outputs `YES`.

**Proof.**  
A valid colouring implies the graph is 3‑edge‑colourable, consequently it has
no bridge (otherwise Lemma 1 would be violated). The algorithm therefore does
not reject at the bridge test. By Lemma 2 it finds a perfect matching, so it
does not reject at the matching step and finally prints `YES`. ∎



##### Theorem  
The algorithm prints `YES` and a correct edge‑colouring **iff** such a
colouring exists; otherwise it prints `NO`.

**Proof.**  
*If* part – Lemma 5.  
*Only‑if* part – Lemma 6. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Bridge detection* : `O(n + m)`  
*Edmonds’ blossom* : `O(n³)` worst case, here `n ≤ 2000` → well below the
time limit.  
*Cycle processing* : `O(n + m)`  

Memory consumption: adjacency lists, matching array, colour array – all
`O(n + m)` ≤ `O(3000)` integers.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

# ---------- 1. bridge detection ----------
def has_bridge(n, adj):
    tin = [0] * n
    low = [0] * n
    timer = 1
    visited = [False] * n
    def dfs(v, p):
        nonlocal timer
        visited[v] = True
        tin[v] = low[v] = timer
        timer += 1
        for to, _ in adj[v]:
            if to == p:
                continue
            if visited[to]:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, v)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    raise StopIteration  # bridge found
    try:
        for i in range(n):
            if not visited[i]:
                dfs(i, -1)
        return False
    except StopIteration:
        return True

# ---------- 2. Edmonds blossom (general matching) ----------
# implementation adapted from https://github.com/jaehyunp/stanfordacm
def blossom(adj, n):
    INF = n + 5
    match = [-1] * n
    p = [-1] * n
    base = list(range(n))
    q = []
    used = [False] * n
    blossom = [False] * n

    def lca(a, b):
        used2 = [False] * n
        while True:
            a = base[a]
            used2[a] = True
            if match[a] == -1:
                break
            a = p[match[a]]
        while True:
            b = base[b]
            if used2[b]:
                return b
            b = p[match[b]]

    def mark_path(v, b, children):
        while base[v] != b:
            blossom[base[v]] = blossom[base[match[v]]] = True
            p[v] = children
            children = match[v]
            v = p[match[v]]

    def find_path(root):
        nonlocal q, used, p, base, blossom
        used = [False] * n
        p = [-1] * n
        base = list(range(n))
        q = []
        q_head = 0
        q.append(root)
        used[root] = True
        while q_head < len(q):
            v = q[q_head]
            q_head += 1
            for to in adj[v]:
                if base[v] == base[to] or match[v] == to:
                    continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    curbase = lca(v, to)
                    blossom = [False] * n
                    mark_path(v, curbase, to)
                    mark_path(to, curbase, v)
                    for i in range(n):
                        if blossom[base[i]]:
                            base[i] = curbase
                            if not used[i]:
                                used[i] = True
                                q.append(i)
                elif p[to] == -1:
                    p[to] = v
                    if match[to] == -1:
                        # augmenting path found
                        return to
                    to_match = match[to]
                    used[to_match] = True
                    q.append(to_match)
        return -1

    for v in range(n):
        if match[v] == -1:
            to = find_path(v)
            if to != -1:
                # augment
                cur = to
                while cur != -1:
                    prev = p[cur]
                    nxt = match[prev] if prev != -1 else -1
                    match[cur] = prev
                    match[prev] = cur
                    cur = nxt
    return match

# ---------- 3. main ----------
def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))

    # bridge test
    if has_bridge(n, adj):
        print("NO")
        return

    # build simple adjacency list for blossom (only neighbours)
    simple_adj = [[] for _ in range(n)]
    for u, v in edges:
        simple_adj[u].append(v)
        simple_adj[v].append(u)

    match = blossom(simple_adj, n)
    if any(x == -1 for x in match):
        print("NO")
        return

    # colour array
    colour = [0] * m
    # colour matched edges with 1
    matched_edge = {}
    for v in range(n):
        u = match[v]
        if v < u:
            # find edge index
            for to, idx in adj[v]:
                if to == u:
                    colour[idx] = 1
                    matched_edge[(v, u)] = idx
                    matched_edge[(u, v)] = idx
                    break

    # remaining edges form cycles, colour alternately 2/3
    visited_edge = [False] * m
    for idx, c in enumerate(colour):
        if c == 1:
            visited_edge[idx] = True

    for start in range(n):
        # each vertex has exactly two unvisited incident edges now
        for to, idx in adj[start]:
            if visited_edge[idx]:
                continue
            # start a new cycle from this edge
            cur = start
            prev = -1
            cur_colour = 2
            while True:
                # find the unvisited edge from cur that is not the one we came from
                for nxt, eidx in adj[cur]:
                    if visited_edge[eidx]:
                        continue
                    if nxt == prev:
                        continue
                    # this is the next edge in the cycle
                    colour[eidx] = cur_colour
                    visited_edge[eidx] = True
                    # move forward
                    prev, cur = cur, nxt
                    cur_colour = 5 - cur_colour   # switch between 2 and 3
                    break
                else:
                    break
                # if we returned to start and the edge back to start is already visited, cycle finished
                if cur == start and prev != -1:
                    # check if there is still an unvisited edge from start (the other side of the cycle)
                    # it will be handled when we iterate other vertices
                    pass

    print("YES")
    print(' '.join(str(colour[i]) for i in range(m)))

if __name__ == "__main__":
    solve()
```
