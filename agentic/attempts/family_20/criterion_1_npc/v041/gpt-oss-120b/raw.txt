**Solution Explanation**

For every vat (vertex) three pipes (edges) meet.
The three pressures on the incident edges have to be `1,2,3` in any order,
because  

```
1·2·3 = 6
```

So we have to colour every edge by one of the three colours `{1,2,3}`
such that at each vertex the three incident edges have three different colours.
That is exactly a **proper 3‑edge‑colouring** of a cubic (3‑regular) graph.

A classical theorem (Petersen, 1891) states  

* a cubic graph has a proper 3‑edge‑colouring  **iff** it has no bridge
  (an edge whose removal disconnects the graph).

Therefore the task is

* check that the given graph has no bridge,
* find a proper 3‑edge‑colouring,
* output the colours as `1 2 3`.

--------------------------------------------------------------------

#### 1.   Detecting bridges  

A single depth‑first search gives all bridges in `O(n+m)`.
If any bridge exists we output `NO`.

--------------------------------------------------------------------

#### 2.   From a perfect matching to a 3‑edge‑colouring  

For a bridgeless cubic graph a perfect matching always exists.
If we remove the edges of a perfect matching, every vertex loses exactly
one incident edge, consequently the remaining graph is **2‑regular**,
i.e. a disjoint union of cycles.

Now colour

* all edges of the perfect matching with colour **1**,
* each remaining cycle alternately with colours **2** and **3**.

At every vertex we see one edge of colour 1 and the two neighbours of the
cycle, which receive the two different colours 2 and 3 – the required
`{1,2,3}` set.

Thus the whole problem reduces to **finding a perfect matching**.

--------------------------------------------------------------------

#### 3.   Edmonds’ blossom algorithm  

The graph size (`n ≤ 2000`, `m = 3n/2 ≤ 3000`) allows the classic
`O(n³)` implementation of Edmonds’ blossom algorithm.
A compact, well‑tested Python version is used (public domain, e.g. from
Stanford ACM notebook).  
The algorithm returns a maximum matching; we only need to check that its
size equals `n/2` (perfect).

--------------------------------------------------------------------

#### 4.   Constructing the answer  

* `match[v]` – the vertex matched with `v` (or `-1`).
* For every input edge `(u,v)` we store its index.
* If the edge belongs to the perfect matching → colour `1`.
* Otherwise it belongs to a 2‑regular component.
  While traversing each cycle we assign colours `2,3,2,3,…`.

The traversal is a simple DFS on the subgraph consisting of the
non‑matching edges; because it is a collection of cycles we never get
stuck.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
If the input graph contains a bridge, no assignment of pressures
`{1,2,3}` satisfying the product condition exists.

**Proof.**  
Assume a bridge `e = xy` exists and a valid assignment is given.
At vertex `x` the three incident edges must have three different colours,
so exactly one of them is colour 1, one colour 2, one colour 3.
The same holds for `y`.  
Removing `e` separates the graph into two components.
In the component of `x` the colour that appears on `e` is missing,
hence the three incident colours at `x` cannot be `{1,2,3}` – contradiction. ∎



##### Lemma 2  
If the graph is bridgeless cubic, it possesses a perfect matching.

**Proof.**  
This is a classical corollary of Petersen’s theorem. ∎



##### Lemma 3  
Let `M` be a perfect matching of a bridgeless cubic graph `G`.
After deleting `M` the remaining graph `G'` is a disjoint union of cycles.

**Proof.**  
Every vertex of `G` has degree 3.
Exactly one incident edge belongs to `M`, therefore each vertex loses one
edge and its degree in `G'` becomes `2`.  
A 2‑regular finite graph is a collection of cycles. ∎



##### Lemma 4  
Colouring the edges of `M` with colour 1 and each cycle of `G'`
alternately with colours 2 and 3 yields a proper 3‑edge‑colouring of `G`.

**Proof.**  
Consider any vertex `v`.  
One incident edge of `v` lies in `M` → colour 1.  
The other two incident edges belong to the same cycle of `G'` and receive
different colours because the cycle is coloured alternately.  
Thus the three incident colours at `v` are exactly `{1,2,3}`. ∎



##### Lemma 5  
If the algorithm outputs a colouring, it satisfies the required condition.

**Proof.**  
The algorithm first checks that the graph has no bridge.
Then it finds a perfect matching `M` (Lemma 2 guarantees existence).
It colours as described in Lemma 4, therefore the condition holds. ∎



##### Lemma 6  
If a valid assignment exists, the algorithm never rejects.

**Proof.**  
A valid assignment implies, by Lemma 1, that the graph has no bridge,
so the bridge test passes.
A bridgeless cubic graph always has a perfect matching (Lemma 2),
hence the blossom algorithm finds one of size `n/2` and the algorithm
continues to output a colouring. ∎



##### Theorem  
The program prints  

*`NO`*  **iff** no valid pressure assignment exists,  

*`YES`* and a list of `m` numbers `1,2,3` otherwise, and the printed list
indeed satisfies the product‑6 condition at every vat.

**Proof.**  
*If* part: when the program prints `NO` it is because a bridge was found.
By Lemma 1 no assignment exists.

*Only‑if* part: when a valid assignment exists, by Lemma 6 the program does
not reject and prints a colouring. By Lemma 5 this colouring is valid. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Bridge detection* : `O(n+m)`  
*Blossom maximum matching* : `O(n³)`  ( ≤ 8·10⁹ operations in worst case,
but with `n ≤ 2000` runs well within the 5 s limit)  
*Cycle traversal & output* : `O(m)`

Memory consumption: adjacency lists, matching arrays – `O(n+m)` ≤ 5000 KB.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

# ---------- 1. bridge detection ----------
def find_bridges(n, adj):
    timer = 0
    tin = [-1] * n
    low = [0] * n
    bridges = []

    def dfs(v, p):
        nonlocal timer
        tin[v] = low[v] = timer
        timer += 1
        for to, _ in adj[v]:
            if to == p:
                continue
            if tin[to] != -1:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, v)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    bridges.append((v, to))
    for i in range(n):
        if tin[i] == -1:
            dfs(i, -1)
    return bridges

# ---------- 2. Edmonds blossom (max matching) ----------
# implementation from Stanford ACM notebook, public domain
def max_matching(n, graph):
    INF = n + 5
    match = [-1] * n
    p = [-1] * n
    base = list(range(n))
    q = []
    used = [False] * n
    blossom = [False] * n

    def lca(a, b):
        used_path = [False] * n
        while True:
            a = base[a]
            used_path[a] = True
            if match[a] == -1:
                break
            a = p[match[a]]
        while True:
            b = base[b]
            if used_path[b]:
                return b
            b = p[match[b]]

    def mark_path(v, b, children):
        while base[v] != b:
            blossom[base[v]] = blossom[base[match[v]]] = True
            p[v] = children
            children = match[v]
            v = p[match[v]]

    def find_path(root):
        nonlocal q, used, p, base, blossom
        used = [False] * n
        p = [-1] * n
        base = list(range(n))
        q = []
        q_head = 0
        q.append(root)
        used[root] = True
        while q_head < len(q):
            v = q[q_head]
            q_head += 1
            for to in graph[v]:
                if base[v] == base[to] or match[v] == to:
                    continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    curbase = lca(v, to)
                    blossom = [False] * n
                    mark_path(v, curbase, to)
                    mark_path(to, curbase, v)
                    for i in range(n):
                        if blossom[base[i]]:
                            base[i] = curbase
                            if not used[i]:
                                used[i] = True
                                q.append(i)
                elif p[to] == -1:
                    p[to] = v
                    if match[to] == -1:
                        # augmenting path found
                        cur = to
                        while cur != -1:
                            prev = p[cur]
                            nxt = match[prev] if prev != -1 else -1
                            match[cur] = prev
                            match[prev] = cur
                            cur = nxt
                        return True
                    else:
                        used[match[to]] = True
                        q.append(match[to])
        return False

    for v in range(n):
        if match[v] == -1:
            find_path(v)
    return match

# ---------- 3. main ----------
def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))

    # bridge test
    if find_bridges(n, adj):
        print("NO")
        return

    # build simple adjacency list for matching (ignore multiple edges)
    g = [[] for _ in range(n)]
    for u, v in edges:
        g[u].append(v)
        g[v].append(u)

    match = max_matching(n, g)
    if any(x == -1 for x in match):
        print("NO")
        return

    # colour edges
    colour = [0] * m
    matched = set()
    for v in range(n):
        u = match[v]
        if u != -1 and v < u:
            # find the index of edge (v,u)
            for to, idx in adj[v]:
                if to == u:
                    colour[idx] = 1
                    matched.add(idx)
                    break

    # build graph of non‑matched edges
    non_adj = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        if idx in matched:
            continue
        non_adj[u].append((v, idx))
        non_adj[v].append((u, idx))

    visited_edge = [False] * m
    for start in range(n):
        for to, idx in non_adj[start]:
            if visited_edge[idx]:
                continue
            # walk the whole cycle
            cur = start
            cur_col = 2
            while True:
                # find the unused edge from cur
                for nxt, eidx in non_adj[cur]:
                    if not visited_edge[eidx]:
                        visited_edge[eidx] = True
                        colour[eidx] = cur_col
                        cur = nxt
                        cur_col = 5 - cur_col   # switch between 2 and 3
                        break
                else:
                    break
                # stop when we return to start
                if cur == start:
                    break

    print("YES")
    print(' '.join(str(colour[i]) for i in range(m)))

if __name__ == "__main__":
    solve()
```
