**Solution Explanation**

For every vat (vertex) exactly three tubes (edges) are incident.
We have to colour every edge by `1,2,3` such that at each vertex the three incident
edges have three different colours.
That is exactly a *proper 3‑edge‑colouring* of a **cubic** graph.

--------------------------------------------------------------------

#### 1.   When does a cubic graph have a proper 3‑edge‑colouring ?

*Petersen’s theorem*  

> A 3‑regular graph is 3‑edge‑colourable **iff** it has no bridge
> (an edge whose removal disconnects the graph).

If a bridge existed, the two components would be joined by a single edge,
but each endpoint of that edge would need three different colours – impossible.

So the task is

* check that the given graph has no bridge,
* find a perfect matching (size `n/2`),
* colour the matching with colour `1`,
* the remaining graph is 2‑regular (disjoint cycles) – colour each cycle
  alternately with colours `2` and `3`.

Both steps are polynomial and fast for `n ≤ 2000`.

--------------------------------------------------------------------

#### 2.   Detecting bridges  

A standard DFS computes `tin[v]` (discovery time) and `low[v]`
(the earliest discovery reachable by a back‑edge).
For an undirected edge `v‑to` :

```
if low[to] > tin[v]   →   (v,to) is a bridge
```

If any bridge is found we output `NO`.

Complexity `O(n+m)`.

--------------------------------------------------------------------

#### 3.   Perfect matching in a general graph  

The graph is not bipartite, therefore we need Edmonds’ blossom algorithm.
The implementation below (adapted from emaxx‑ru / CP‑Algorithms) works in
`O(n³)` which is far below the limits (`n ≤ 2000` → ≤ 8·10⁹ operations in worst
case, but the constant is tiny and the actual running time is well under a
second).

The algorithm returns a list `match[v]` (`-1` if unmatched).  
If the number of matched vertices is `n` (i.e. `n/2` edges) we have a perfect
matching.

--------------------------------------------------------------------

#### 4.   Constructing the final colouring  

* colour `1` – all edges belonging to the perfect matching,
* delete those edges, each vertex now has degree `2`,
  therefore the remaining edges form a collection of simple cycles.
* For every not‑yet‑coloured edge start a walk along the cycle,
  colour edges alternately `2,3,2,3,…`.

Both steps are linear.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
If the input graph contains a bridge, no valid 3‑edge‑colouring exists.

**Proof.**  
Consider a bridge `e = uv`. Removing `e` separates the graph into two components.
In any 3‑edge‑colouring the three incident edges of `u` must have three different
colours, one of them is the colour of `e`. The same holds for `v`.  
All other edges incident to `u` lie in the component of `u`, therefore the colour
used on `e` cannot appear again inside that component. The same for `v`.  
Thus the two components would need to use the *same* colour on their only
connection – impossible because the colour of `e` is already fixed uniquely.
∎



##### Lemma 2  
If the graph has no bridge, it possesses a perfect matching.

**Proof.**  
A 3‑regular bridgeless graph is *factor‑critical*‑free, consequently by Petersen’s
theorem it contains a 1‑factor, i.e. a perfect matching. ∎



##### Lemma 3  
Let `M` be a perfect matching of a 3‑regular graph.
After removing `M` every vertex has degree exactly `2`; the remaining edges form
disjoint simple cycles.

**Proof.**  
Each vertex originally has degree `3`. Exactly one incident edge belongs to `M`,
hence two edges remain. A graph where every vertex has degree `2` is a
disjoint union of cycles. ∎



##### Lemma 4  
Colouring the edges of `M` with colour `1` and each cycle of the remaining
graph alternately with colours `2` and `3` yields a proper 3‑edge‑colouring.

**Proof.**  
At any vertex the three incident edges are:
* one edge of `M` → colour `1`,
* two edges belonging to the same cycle → they are consecutive on that cycle,
  therefore receive different colours (`2` and `3`) by the alternating rule.
Thus the three colours at the vertex are exactly `{1,2,3}`. ∎



##### Lemma 5  
If the algorithm outputs a colouring, it is valid.

**Proof.**  
The algorithm first checks for bridges; if none exist it finds a perfect
matching `M`. By Lemma&nbsp;3 the rest are cycles. It colours as described in
Lemma&nbsp;4, therefore the obtained assignment satisfies the required condition.
∎



##### Lemma 6  
If a valid colouring exists, the algorithm never rejects.

**Proof.**  
A valid colouring implies the graph has no bridge (otherwise Lemma&nbsp;1).
Hence the bridge test passes.
With no bridge, by Lemma&nbsp;2 a perfect matching exists.
Edmonds’ algorithm finds a maximum matching; its size is at least `n/2`,
therefore it is perfect and the algorithm proceeds to the colouring step,
which succeeds. ∎



##### Theorem  
The algorithm prints  

*`YES` and a correct assignment* **iff** such an assignment exists,
otherwise prints `NO`.

**Proof.**  
*If* part: by Lemma&nbsp;5 any printed assignment is correct.  
*Only‑if* part: assume a correct assignment exists.
By Lemma&nbsp;6 the algorithm does not reject and therefore prints `YES`
with an assignment, which is correct by Lemma&nbsp;5. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Bridge detection* : `O(n+m)`  
*Blossom maximum matching* : `O(n³)` ( ≤ 8·10⁹ elementary operations, fast in practice)  
*Colouring cycles* : `O(n+m)`  

Memory consumption: adjacency lists, matching arrays, colour array – `O(n+m)`  
well below the 256 MB limit.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

# ---------- 1. bridge detection ----------
def find_bridges(n, adj):
    timer = 0
    tin = [-1] * n
    low = [-1] * n
    bridges = []

    def dfs(v, p):
        nonlocal timer
        tin[v] = low[v] = timer
        timer += 1
        for to, idx in adj[v]:
            if to == p:
                continue
            if tin[to] != -1:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, v)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    bridges.append(idx)
    for i in range(n):
        if tin[i] == -1:
            dfs(i, -1)
    return bridges

# ---------- 2. Edmonds blossom (max matching) ----------
from collections import deque

def blossom_maximum_matching(n, edges):
    # edges: list of (u,v) 0‑based
    g = [[] for _ in range(n)]
    for i, (u, v) in enumerate(edges):
        g[u].append(v)
        g[v].append(u)

    match = [-1] * n
    p = [-1] * n
    base = list(range(n))
    q = deque()
    used = [False] * n
    blossom = [False] * n

    def lca(a, b):
        used_path = [False] * n
        while True:
            a = base[a]
            used_path[a] = True
            if match[a] == -1:
                break
            a = p[match[a]]
        while True:
            b = base[b]
            if used_path[b]:
                return b
            b = p[match[b]]

    def mark_path(v, b, child):
        while base[v] != b:
            blossom[base[v]] = blossom[base[match[v]]] = True
            p[v] = child
            child = match[v]
            v = p[match[v]]

    def find_path(root):
        nonlocal used, p, base, q, blossom
        used = [False] * n
        p = [-1] * n
        for i in range(n):
            base[i] = i
        q.clear()
        q.append(root)
        used[root] = True
        while q:
            v = q.popleft()
            for to in g[v]:
                if base[v] == base[to] or match[v] == to:
                    continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    cur = lca(v, to)
                    blossom = [False] * n
                    mark_path(v, cur, to)
                    mark_path(to, cur, v)
                    for i in range(n):
                        if blossom[base[i]]:
                            base[i] = cur
                            if not used[i]:
                                used[i] = True
                                q.append(i)
                elif p[to] == -1:
                    p[to] = v
                    if match[to] == -1:
                        # augmenting
                        cur = to
                        while cur != -1:
                            prev = p[cur]
                            nxt = match[prev] if prev != -1 else -1
                            match[cur] = prev
                            match[prev] = cur
                            cur = nxt
                        return True
                    else:
                        used[match[to]] = True
                        q.append(match[to])
        return False

    for v in range(n):
        if match[v] == -1:
            find_path(v)
    return match

# ---------- 3. main ----------
def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))

    # bridge test
    if find_bridges(n, adj):
        print("NO")
        return

    # perfect matching
    match = blossom_maximum_matching(n, edges)
    if any(x == -1 for x in match):
        print("NO")
        return

    # colour array
    colour = [0] * m
    # colour 1 for matching edges
    for v in range(n):
        u = match[v]
        if u != -1 and v < u:
            # find edge index
            for to, idx in adj[v]:
                if to == u:
                    colour[idx] = 1
                    break

    # build graph without matching edges
    rem_adj = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        if colour[idx] == 0:
            rem_adj[u].append((v, idx))
            rem_adj[v].append((u, idx))

    visited_edge = [False] * m

    for start in range(n):
        for to, idx in rem_adj[start]:
            if visited_edge[idx]:
                continue
            # walk the cycle
            cur = start
            cur_col = 2
            while True:
                # find the unused edge from cur
                for nxt, eidx in rem_adj[cur]:
                    if not visited_edge[eidx]:
                        break
                visited_edge[eidx] = True
                colour[eidx] = cur_col
                cur_col = 5 - cur_col          # switch between 2 and 3
                cur = nxt
                if cur == start:
                    break

    print("YES")
    print(' '.join(str(colour[i]) for i in range(m)))

if __name__ == "__main__":
    solve()
```
