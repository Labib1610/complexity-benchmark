We can model this as a **3-edge-coloring** problem on a **3-regular graph** (each vertex has degree 3).  

By **Kőnig’s line coloring theorem**, every bipartite graph has an edge coloring with Δ colors, but here the graph is not necessarily bipartite. However, for **3-regular graphs**, a 3-edge-coloring exists if and only if the graph is **bridgeless** (by the **Petersen’s theorem**).  

So the algorithm is:

1. Check if the graph is 3-regular (given).
2. Check if the graph is bridgeless (no bridges).  
   - If there is a bridge, output `NO`.
3. If bridgeless, find a 3-edge-coloring using a constructive method:
   - Use a **hierholzer**-style approach to decompose into cycles, then color alternately.
   - Or use a backtracking/DFS-based edge coloring.

Since n ≤ 2000, we can implement a constructive algorithm.

Here’s the Python solution:

```python
import sys
sys.setrecursionlimit(10000)

def solve():
    input_data = sys.stdin.read().strip().split()
    n, m = int(input_data[0]), int(input_data[1])
    edges = []
    adj = [[] for _ in range(n)]
    for i in range(m):
        u = int(input_data[2 + 2*i]) - 1
        v = int(input_data[3 + 2*i]) - 1
        edges.append((u, v))
        adj[u].append((v, i))
        adj[v].append((u, i))

    # Check bridgeless using DFS low-link
    visited = [False] * n
    tin = [-1] * n
    low = [-1] * n
    timer = 0
    has_bridge = False

    def dfs(v, p_edge):
        nonlocal timer, has_bridge
        visited[v] = True
        tin[v] = low[v] = timer
        timer += 1
        for to, eid in adj[v]:
            if eid == p_edge:
                continue
            if visited[to]:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, eid)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    has_bridge = True

    dfs(0, -1)
    # Check connectivity
    if not all(visited):
        print("NO")
        return
    if has_bridge:
        print("NO")
        return

    # Now find 3-edge-coloring
    color = [-1] * m

    # Use a known constructive method: 
    # Since graph is cubic and bridgeless, we can find a perfect matching, remove it, 
    # the remaining is 2-regular (cycles), color cycles alternately with 2 colors, 
    # and the matching with the third color.

    # Find a perfect matching using simple greedy (since cubic bridgeless has one)
    matched = [False] * n
    matching_edges = []
    for u in range(n):
        if not matched[u]:
            for v, eid in adj[u]:
                if not matched[v]:
                    matched[u] = matched[v] = True
                    matching_edges.append(eid)
                    color[eid] = 3
                    break

    # Now remaining edges form disjoint cycles
    # Build adjacency for remaining edges
    rem_adj = [[] for _ in range(n)]
    for eid, (u, v) in enumerate(edges):
        if color[eid] == -1:
            rem_adj[u].append((v, eid))
            rem_adj[v].append((u, eid))

    # Color cycles alternately with 1 and 2
    visited_cycle = [False] * n
    for start in range(n):
        if not visited_cycle[start] and rem_adj[start]:
            # walk the cycle
            cur = start
            prev_e = -1
            c = 1
            while True:
                visited_cycle[cur] = True
                # pick next edge not prev
                nxt = None
                for to, eid in rem_adj[cur]:
                    if eid != prev_e:
                        nxt = (to, eid)
                        break
                if nxt is None:
                    break
                to, eid = nxt
                color[eid] = c
                c = 3 - c  # switch 1<->2
                prev_e = eid
                cur = to
                if cur == start:
                    break

    # Output
    print("YES")
    print(" ".join(str(color[i]) for i in range(m)))

if __name__ == "__main__":
    solve()
```
