We can model this as a **3-edge-coloring** problem on a 3-regular graph.  
Since every node has degree exactly 3 impurities: we need to color the edges so that no two edges sharing a vertex have the same color.

A known theorem: every bridgeless cubic graph is 3-edge-colorable — but our graph may have bridgesgallore, so we need a constructive approach.

We can reduce the problem to checking if the graph is bipartite:  
In a cubic graph, **a 3-edge-coloring exists iff the graph is bridgeless and has no component requiring 4 colors**, but a simpler check: a 3-regular graph is 3-edge-colorable if and only if it is **bipartite** or somewhat special—but *not* all cubic graphs are 3-edge-colorable (snarks exist). Since n ≤ 2000, we can try a **backtracking with constraint propagation** since m ≤ 3000.

We'll do:

1. Build adjacency lists with edge indices.
2. Try to assign colors 1..3 to edges via DFS with pruning.  
   At each node, its 3 incident edges must all be different, so if two are already colored, the third is forced.
3. If we assign an edge and find a conflict, backtrack.

This should be fast enough: With degree 3, the constraint is strong, and we can propagate forced choices quickly.

Here's the code:

```python
import sys
sys.setrecursionlimit(1000000)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    edges = []
    adj = [[] for _ in range(n)]
    for i in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edges.append((u, v))
        adj[u].append((v, i))
        adj[v].append((u, i))
    
    color = [0] * m  # 0 = uncolored, 1..3 = colors

    # For each vertex, keep list of (edge_index, neighbor)
    # We want to color edges so that at each vertex, the three incident edges have distinct colors.

    # Backtracking with propagation
    # At any step, pick an uncolored edge, try colors 1..3
    
    # Pre-check to speed: if vertex already has 3 distinct colored edges, no choice.
    
    def vertex_possible(v):
        cols = [color[e] for (u, e) in adj[v] if color[e] != 0]
        # Must be all distinct
        return len(cols) == len(set(cols))
    
    def dfs(edge_idx):
        if edge_idx == m:
            return True
        if color[edge_idx] != 0:
            return dfs(edge_idx + 1)
        u, v = edges[edge_idx]
        # Get used colors at u and v
        used_u = [color[e] for (x, e) in adj[u] if color[e] != 0]
        used_v = [color[e] for (x, e) in adj[v] if color[e] != 0]
        used = set(used_u + used_v)
        for c in (1, 2, 3):
            if c not in used:
                color[edge_idx] = c
                # Check both endpoints still valid
                if vertex_possible(u) and vertex_possible(v):
                    if dfs(edge_idx + 1):
                        return True
                color[edge_idx] = 0
        return False

    if dfs(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
