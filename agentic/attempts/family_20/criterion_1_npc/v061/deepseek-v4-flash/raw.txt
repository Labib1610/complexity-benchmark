We can model this as an edge-coloring problem.  
Each artifact (vertex) has degree exactly 3 (since m = 3n/2 and each vertex has the same degree, so degree = 3).  
We have exactly 3 colors available (frequencies), and we need to color the edges so that no two edges at the same vertex share a color.  
This is equivalent to a proper 3-edge-coloring of a 3-regular graph.

By **Petersen’s theorem**, every bridgeless cubic graph has a perfect matching.  
But here, the graph may have bridges. However, for a cubic graph, a proper 3-edge-coloring exists if and only if the graph is **3-edge-colorable**, which is equivalent to being **bridgeless** and having no **snark** (non-3-edge-colorable cubic graph).  
For n ≤ 2000, we can try a constructive approach:  
- Use a backtracking or heuristic to find a 3-edge-coloring.

Since the graph is cubic, we can use a known algorithm:  
1. Find a perfect matching (1-factor) using Edmonds' blossom algorithm or a simpler approach for small n.  
2. Remove it; the remaining graph is 2-regular (disjoint cycles), which is 2-edge-colorable.  
3. Combine the 3 colors.

But implementing blossom is heavy.  
Given constraints (n ≤ 2000, m ≤ 3000), we can use a simple backtracking with pruning, or use a greedy + repair approach.

We can also use **Kőnig's line coloring theorem** for bipartite graphs, but our graph is not necessarily bipartite.

A simpler approach:  
- Since degree is 3, we can try to color edges one by one using DFS with backtracking.  
- With n=2000, worst-case might be heavy, but in practice cubic graphs are often easy to color.

We'll implement a backtracking that tries colors 1,2,3 for each edge, ensuring no conflict at endpoints.  
We'll also add a heuristic: process edges in order of most constrained first.

Let's code it.

```python
import sys
sys.setrecursionlimit(1000000)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    edges = []
    adj = [[] for _ in range(n)]
    for i in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        edges.append((u, v))
        adj[u].append((v, i))
        adj[v].append((u, i))
    
    color = [-1] * m
    # degree is 3 for all vertices
    # We'll try backtracking with MRV heuristic
    
    # Precompute for each edge the two vertices
    # We'll order edges by degree of endpoints (all 3, so no difference)
    # But we can order by number of already colored neighbors
    
    # We'll use a recursive backtracking
    # Since n <= 2000, m <= 3000, worst-case might be okay if we prune well.
    
    # Check if graph is 3-edge-colorable using backtracking
    # We'll try to color edges in order
    
    # For each vertex, keep track of used colors
    used = [0]*n  # bitmask of used colors (bits 0,1,2)
    
    # Sort edges by some heuristic: maybe by degree of endpoints (all same)
    # We'll just use input order but with MRV: choose edge with fewest available colors
    
    def backtrack(idx):
        if idx == m:
            return True
        # Find uncolored edge with fewest available colors
        best_edge = -1
        best_avail = 4
        best_mask = 0
        for i in range(m):
            if color[i] == -1:
                u, v = edges[i]
                mask = used[u] | used[v]
                avail = 3 - bin(mask).count("1")
                if avail < best_avail:
                    best_avail = avail
                    best_edge = i
                    best_mask = mask
                    if avail == 0:
                        break
        if best_avail == 0:
            return False
        i = best_edge
        u, v = edges[i]
        for c in range(3):
            if not (used[u] & (1<<c)) and not (used[v] & (1<<c)):
                color[i] = c
                used[u] |= (1<<c)
                used[v] |= (1<<c)
                if backtrack(idx+1):
                    return True
                used[u] ^= (1<<c)
                used[v] ^= (1<<c)
                color[i] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(c+1) for c in color))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
