**Solution Explanation**

For the given graph

* `n` – even, `m = 3 n / 2`
* every vertex has degree `3`

so the graph is a *cubic* (3‑regular) graph.
The required frequencies are exactly `3` (the degree) and we have to give a
proper edge‑colouring with these three colours.

--------------------------------------------------------------------

#### 1.   When is a 3‑edge‑colouring possible ?

A theorem of Petersen (1891) :

*Every bridgeless cubic graph is 3‑edge‑colourable.*

If the graph contains a bridge, any proper edge‑colouring needs at least
four colours, therefore the answer is **NO**.

Consequently we have to

* detect a bridge – if one exists → `NO`
* otherwise find a 3‑edge‑colouring.

--------------------------------------------------------------------

#### 2.   From a perfect matching to a 3‑colouring  

For a bridgeless cubic graph a perfect matching always exists.
Take any perfect matching `M`.

* colour all edges of `M` with colour **1**
* delete `M`.  
  Every vertex loses one incident edge, therefore the remaining graph is
  2‑regular – a disjoint union of cycles.
* each cycle can be coloured alternately with colours **2** and **3**.

Thus a perfect matching is enough to construct the required colouring.

--------------------------------------------------------------------

#### 3.   Finding a perfect matching – Edmonds’ blossom  

`n ≤ 2000`, `m ≤ 3000`.  
A classic implementation of Edmonds’ blossom algorithm runs in  
`O(n³)` – well inside the limits.

The algorithm returns a maximum matching.
If its size is `n/2` we have a perfect matching, otherwise the graph
cannot be 3‑coloured (this can only happen when a bridge exists, but we
check it explicitly as well).

--------------------------------------------------------------------

#### 4.   Whole algorithm  

```
read graph
if a bridge exists:               # simple DFS, lowlink
        print NO
        exit

M = maximum_matching_by_blossom()
if |M| != n/2:
        print NO
        exit

colour[edge] = 0
for each (u,v) in M:
        colour[edge] = 1

# build adjacency of the remaining graph (degree 2)
for each vertex:
        store the two incident non‑matched edges

visited = [False]*n
for each vertex not visited:
        walk along its cycle using the two stored edges
        assign colours 2,3,2,3,… to the traversed edges
        mark vertices visited
print YES and the colours in input order
```

All steps are linear except the blossom routine (`O(n³)`).

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `YES` with a valid colouring
iff such a colouring exists.

---

##### Lemma 1  
If the input graph contains a bridge, no proper edge‑colouring with three
colours exists.

**Proof.**  
Remove a bridge `e`. The two components become disconnected.
All edges incident to the endpoint in the first component need three
different colours, but the colour of `e` is forced to be the same at both
endpoints – impossible with only three colours. ∎



##### Lemma 2  
If the graph is bridgeless and cubic, it possesses a perfect matching.

**Proof.**  
This is a classical corollary of Petersen’s theorem. ∎



##### Lemma 3  
Let `M` be a perfect matching of a cubic graph.
After deleting `M` the remaining graph is a collection of vertex‑disjoint
cycles.

**Proof.**  
Every vertex had degree 3, one incident edge is removed, therefore its
remaining degree is `2`. A 2‑regular finite graph is a disjoint union of
cycles. ∎



##### Lemma 4  
Colouring the edges of `M` with colour 1 and each cycle of the remaining
graph alternately with colours 2 and 3 yields a proper 3‑edge‑colouring.

**Proof.**  
*Edges of `M`* are pairwise non‑adjacent (matching), so colour 1 never
appears twice at a vertex.  
Inside a cycle every vertex is incident to exactly one edge of colour 2
and one of colour 3 (alternation).  
Thus at each vertex the three incident edges have three different colours. ∎



##### Lemma 5  
If the algorithm outputs `YES`, the printed colours form a proper
3‑edge‑colouring.

**Proof.**  
The algorithm first guarantees the graph is bridgeless, therefore by
Lemma&nbsp;2 a perfect matching `M` of size `n/2` is found.
Steps described in Lemma&nbsp;3 and Lemma&nbsp;4 are performed
exactly, hence the resulting assignment satisfies the required property. ∎



##### Lemma 6  
If a proper 3‑edge‑colouring exists, the algorithm never prints `NO`.

**Proof.**  
A proper 3‑edge‑colouring implies the graph is 3‑regular and has no bridge
(otherwise Lemma&nbsp;1 would be violated).  
Consequently the bridge test passes.
For a bridgeless cubic graph a perfect matching exists (Lemma&nbsp;2), so
the blossom algorithm finds a matching of size `n/2`.  
Therefore the algorithm reaches the `YES` branch. ∎



##### Theorem  
The algorithm prints `YES` and a correct colouring **iff** such a
colouring exists; otherwise it prints `NO`.

**Proof.**  
*If* part – Lemma&nbsp;5.  
*Only‑if* part – Lemma&nbsp;6. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

*Bridge detection* – `O(n + m)`  
*Blossom maximum matching* – `O(n³)` ( ≤ 8·10⁹ operations for n=2000, fast in practice)  
*Colouring the cycles* – `O(n + m)`  

Memory consumption: adjacency lists, matching arrays – `O(n + m)` ≤
~5 KB.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

# ------------------------------------------------------------
# 1. bridge detection (Tarjan)
def find_bridges(n, adj):
    timer = 0
    tin = [0] * n
    low = [0] * n
    visited = [False] * n
    has_bridge = False

    def dfs(v, p):
        nonlocal timer, has_bridge
        visited[v] = True
        timer += 1
        tin[v] = low[v] = timer
        for to, _ in adj[v]:
            if to == p:
                continue
            if visited[to]:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, v)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    has_bridge = True

    for i in range(n):
        if not visited[i]:
            dfs(i, -1)
    return has_bridge

# ------------------------------------------------------------
# 2. Edmonds' blossom (implementation from emaxx)
class Blossom:
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]

    def add_edge(self, u, v, idx):
        self.g[u].append((v, idx))
        self.g[v].append((u, idx))

    def max_matching(self):
        n = self.n
        g = self.g
        match = [-1] * n
        p = [-1] * n
        base = list(range(n))
        q = []
        used = [False] * n
        blossom = [False] * n

        def lca(a, b):
            used2 = [False] * n
            while True:
                a = base[a]
                used2[a] = True
                if match[a] == -1:
                    break
                a = p[match[a]]
            while True:
                b = base[b]
                if used2[b]:
                    return b
                b = p[match[b]]

        def mark_path(v, b, children):
            while base[v] != b:
                blossom[base[v]] = blossom[base[match[v]]] = True
                p[v] = children
                children = match[v]
                v = p[match[v]]

        def find_path(root):
            nonlocal q, used, p, base, blossom
            used = [False] * n
            p = [-1] * n
            for i in range(n):
                base[i] = i
            q = []
            q_head = 0
            q.append(root)
            used[root] = True
            while q_head < len(q):
                v = q[q_head]
                q_head += 1
                for to, _ in g[v]:
                    if base[v] == base[to] or match[v] == to:
                        continue
                    if to == root or (match[to] != -1 and p[match[to]] != -1):
                        curbase = lca(v, to)
                        blossom = [False] * n
                        mark_path(v, curbase, to)
                        mark_path(to, curbase, v)
                        for i in range(n):
                            if blossom[base[i]]:
                                base[i] = curbase
                                if not used[i]:
                                    used[i] = True
                                    q.append(i)
                    elif p[to] == -1:
                        p[to] = v
                        if match[to] == -1:
                            # augmenting
                            v = to
                            while v != -1:
                                pv = p[v]
                                nv = match[pv] if pv != -1 else -1
                                match[v] = pv
                                match[pv] = v
                                v = nv
                            return True
                        else:
                            used[match[to]] = True
                            q.append(match[to])
            return False

        for v in range(n):
            if match[v] == -1:
                find_path(v)
        return match

# ------------------------------------------------------------
def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))

    # 1) bridge test
    if find_bridges(n, adj):
        print("NO")
        return

    # 2) perfect matching
    bl = Blossom(n)
    for idx, (u, v) in enumerate(edges):
        bl.add_edge(u, v, idx)
    match = bl.max_matching()
    matched_edges = set()
    for v in range(n):
        if match[v] != -1 and v < match[v]:
            # find edge index between v and match[v]
            for to, idx in adj[v]:
                if to == match[v]:
                    matched_edges.add(idx)
                    break

    if len(matched_edges) != n // 2:
        print("NO")
        return

    # 3) colour assignment
    colour = [0] * m
    for idx in matched_edges:
        colour[idx] = 1

    # build remaining adjacency (each vertex degree 2)
    rem = [[] for _ in range(n)]
    for idx, (u, v) in enumerate(edges):
        if colour[idx] == 0:
            rem[u].append((v, idx))
            rem[v].append((u, idx))

    visited = [False] * n
    for start in range(n):
        if visited[start]:
            continue
        # walk the cycle
        v = start
        prev_edge = -1
        cur_colour = 2
        while True:
            visited[v] = True
            # pick the edge not equal to prev_edge
            for to, idx in rem[v]:
                if idx != prev_edge:
                    nxt = to
                    eidx = idx
                    break
            colour[eidx] = cur_colour
            cur_colour = 5 - cur_colour          # toggle 2<->3
            prev_edge = eidx
            v = nxt
            if visited[v]:
                break

    print("YES")
    print(' '.join(str(colour[i]) for i in range(m)))

if __name__ == "__main__":
    solve()
```
