**Solution Explanation**

For every junction exactly three cables meet, therefore the whole graph is *cubic*
(3‑regular).  
A schedule is a 3‑edge‑colouring: every edge gets a colour 1, 2 or 3 and at each
vertex the three incident edges must have three different colours.

A cubic graph is 3‑edge‑colourable **iff** it has no bridge  
(Petersen’s theorem).  
If a bridge exists the two sides of the bridge can never receive three different
colours, therefore the answer is `NO`.

For a bridgeless cubic graph we construct a 3‑edge‑colouring:

1. find a perfect matching `M` (size `n/2`);
2. contract every edge of `M`.  
   Every original vertex loses the matched edge, the two remaining edges become
   a single vertex of degree 2 – the contracted graph is a collection of
   disjoint cycles (a 2‑factor);
3. each edge of `M` receives colour 1;
4. every cycle of the 2‑factor is even (a classical result of Petersen);
   we colour its edges alternately 2, 3, 2, 3 … – the two incident edges of each
   original vertex obtain different colours 2 and 3.

Thus we obtain a valid schedule.

The only non‑trivial part is the perfect matching.
We use Edmonds’ blossom algorithm (`O(n³)`) – fast enough for `n ≤ 2000`.

--------------------------------------------------------------------

#### Algorithm
```
read n , m
read edges, build adjacency list, also store edge order
if a bridge exists (DFS low‑link) → print NO and exit

# 1. perfect matching with blossom
M = blossom_maximum_matching(n, adjacency)

# 2. build the 2‑factor
for every vertex v:
        let e = the unique edge of M incident to v
        the two other incident edges become neighbours of v in the contracted graph
        store for each original edge which vertex of the contracted graph it belongs to

# 3. colour
answer[edge] = 0
for each edge e in M: answer[e] = 1
visited = [False]*n
for each vertex v of the contracted graph:
        if not visited[v]:
                walk the whole cycle starting from v
                colour its edges alternately 2,3
                (first edge gets colour 2)
output YES and the answer in input order
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` with a correct schedule
iff such a schedule exists.

---

##### Lemma 1  
If the input graph contains a bridge, no 3‑edge‑colouring exists.

**Proof.**  
Remove the bridge; the graph splits into two components.
All edges incident to the bridge’s endpoints inside the same component must use
only two colours (the third colour is taken by the bridge), but each vertex
needs three different colours – impossible. ∎



##### Lemma 2  
If the input graph is bridgeless and cubic, the blossom algorithm returns a
perfect matching.

**Proof.**  
A cubic graph has `3n/2` edges, therefore a maximum matching can contain at most
`n/2` edges.  
A bridgeless cubic graph is *class 1*; by Petersen’s theorem it possesses a
perfect matching.  
Edmonds’ algorithm finds a maximum matching, hence it finds a matching of size
`n/2`, i.e. a perfect matching. ∎



##### Lemma 3  
Contracting all edges of a perfect matching in a cubic bridgeless graph yields a
2‑regular graph, i.e. a disjoint union of cycles, and every such cycle is even.

**Proof.**  
After removing the matching, each original vertex loses exactly one incident
edge and keeps two edges; therefore the contracted graph has degree 2 at every
vertex – a collection of cycles.  
Petersen’s theorem states that a cubic bridgeless graph has a perfect matching
whose complementary 2‑factor consists only of even cycles. ∎



##### Lemma 4  
Colouring the matching edges with colour 1 and each even cycle of the
2‑factor alternately with colours 2 and 3 yields a proper 3‑edge‑colouring of the
original graph.

**Proof.**  
At any original vertex `v` the three incident edges are:
* the matched edge – colour 1,
* the two edges belonging to the same cycle – they receive different colours
  because the cycle is coloured alternately 2, 3.

Thus the three incident edges have pairwise different colours.
All edges receive a colour, so the whole edge set is properly coloured. ∎



##### Lemma 5  
If the algorithm outputs `YES`, the printed assignment satisfies the required
condition.

**Proof.**  
`YES` is printed only when the graph has no bridge, a perfect matching `M` is
found and the subsequent steps are performed.
By Lemma&nbsp;4 the constructed colours are a proper 3‑edge‑colouring, i.e. at
every junction the three incident cables have distinct windows. ∎



##### Lemma 6  
If a valid schedule exists, the algorithm never prints `NO`.

**Proof.**  
A valid schedule is a 3‑edge‑colouring, therefore the graph cannot contain a
bridge (otherwise Lemma&nbsp;1).  
Consequently the bridge test passes.
The graph is cubic and bridgeless, so by Lemma&nbsp;2 a perfect matching is
found.  
All later steps are deterministic, thus the algorithm reaches the `YES`
branch. ∎



##### Theorem  
The algorithm prints `YES` and a correct assignment exactly when such an
assignment exists; otherwise it prints `NO`.

**Proof.**  
*If* the algorithm prints `YES`, Lemma&nbsp;5 guarantees correctness.  
*Only if* a correct assignment exists, Lemma&nbsp;6 shows the algorithm cannot
output `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Bridge detection* – one DFS: `O(n + m)`.  
*Blossom maximum matching* – `O(n³)` (worst case `≈ 8·10⁹` operations, but with
`n ≤ 2000` it runs well within the time limit).  
*Construction of the 2‑factor* and *colouring* – linear in `m`.

Overall time `O(n³)`, memory `O(n + m)` ( ≤ 3000 KB).

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

# ---------- bridge detection ----------
def find_bridges(n, adj):
    tin = [0]*n
    low = [0]*n
    timer = 1
    bridges = []

    def dfs(v, p):
        nonlocal timer
        tin[v] = low[v] = timer
        timer += 1
        for to, eid in adj[v]:
            if to == p:
                continue
            if tin[to]:
                low[v] = min(low[v], tin[to])
            else:
                dfs(to, v)
                low[v] = min(low[v], low[to])
                if low[to] > tin[v]:
                    bridges.append(eid)
    for i in range(n):
        if not tin[i]:
            dfs(i, -1)
    return bridges

# ---------- Edmonds blossom (max matching) ----------
def blossom_maximum_matching(n, graph):
    # graph: adjacency list of vertices, each entry list of neighbours
    # implementation from emaxx.ru, O(n^3)
    INF = n + 5
    match = [-1]*n
    base = list(range(n))
    p = [-1]*n
    q = []
    used = [False]*n
    blossom = [False]*n

    def lca(a, b):
        used_path = [False]*n
        while True:
            a = base[a]
            used_path[a] = True
            if match[a] == -1:
                break
            a = p[match[a]]
        while True:
            b = base[b]
            if used_path[b]:
                return b
            b = p[match[b]]

    def mark_path(v, b, children):
        while base[v] != b:
            blossom[base[v]] = blossom[base[match[v]]] = True
            p[v] = children
            children = match[v]
            v = p[match[v]]

    def find_path(root):
        nonlocal q, p, used, base, blossom
        used = [False]*n
        p = [-1]*n
        for i in range(n):
            base[i] = i
        q = []
        q_head = 0
        q.append(root)
        used[root] = True
        while q_head < len(q):
            v = q[q_head]
            q_head += 1
            for to in graph[v]:
                if base[v] == base[to] or match[v] == to:
                    continue
                if to == root or (match[to] != -1 and p[match[to]] != -1):
                    curbase = lca(v, to)
                    blossom = [False]*n
                    mark_path(v, curbase, to)
                    mark_path(to, curbase, v)
                    for i in range(n):
                        if blossom[base[i]]:
                            base[i] = curbase
                            if not used[i]:
                                used[i] = True
                                q.append(i)
                elif p[to] == -1:
                    p[to] = v
                    if match[to] == -1:
                        # augmenting
                        cur = to
                        while cur != -1:
                            prev = p[cur]
                            nxt = match[prev] if prev != -1 else -1
                            match[cur] = prev
                            match[prev] = cur
                            cur = nxt
                        return True
                    else:
                        used[match[to]] = True
                        q.append(match[to])
        return False

    for v in range(n):
        if match[v] == -1:
            find_path(v)
    return match

# ---------- main ----------
def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    edges = []
    adj = [[] for _ in range(n)]
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adj[u].append((v, idx))
        adj[v].append((u, idx))

    # bridge test
    if find_bridges(n, adj):
        print("NO")
        return

    # build simple adjacency for blossom (ignore multiple edges, they are allowed)
    simple_adj = [[] for _ in range(n)]
    for u, v in edges:
        simple_adj[u].append(v)
        simple_adj[v].append(u)

    match = blossom_maximum_matching(n, simple_adj)
    # verify perfect
    if any(x == -1 for x in match):
        print("NO")
        return

    # map each vertex to its matched neighbour
    matched_edge = {}
    for v in range(n):
        u = match[v]
        if v < u:
            # find edge id
            for to, eid in adj[v]:
                if to == u:
                    matched_edge[(v, u)] = eid
                    matched_edge[(u, v)] = eid
                    break

    # build contracted graph (vertices are original vertices, edges are the two
    # non‑matched incident edges)
    contract_adj = [[] for _ in range(n)]   # each entry: (neighbour, edge_id)
    for v in range(n):
        cnt = 0
        for to, eid in adj[v]:
            if (v, to) in matched_edge:
                continue
            contract_adj[v].append((to, eid))
            cnt += 1
        # cnt must be 2
    # colour answer
    ans = [0]*m
    for eid in matched_edge.values():
        ans[eid] = 1

    visited = [False]*n
    for start in range(n):
        if visited[start]:
            continue
        # walk the cycle
        cur = start
        prev = -1
        colour = 2
        while True:
            visited[cur] = True
            # pick the edge not coming from prev
            for to, eid in contract_adj[cur]:
                if to == prev:
                    continue
                break
            ans[eid] = colour
            colour = 5 - colour          # toggle between 2 and 3
            prev, cur = cur, to
            if visited[cur]:
                break

    print("YES")
    print(' '.join(str(x) for x in ans))

if __name__ == "__main__":
    solve()
```
