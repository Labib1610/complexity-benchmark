Looking at this problem, we need to edge-color a bipartite graph using exactly Δ colors (where Δ is the maximum degree), which is guaranteed to be achievable by König's theorem.

**Approach:**
- Compute Δ = max degree over all ports.
- For each color c from 1 to Δ, find a maximal matching among uncolored edges and assign color c to those edges.
- A maximal matching can be found greedily: iterate edges, match if both endpoints are free.

This greedy approach works because after removing a maximal matching, the maximum degree drops by at least 1 (every vertex that had degree ≥ 1 in the remaining graph is incident to some edge in the maximal matching, so its degree decreases by at least 1). Thus after Δ iterations all edges are colored.

**Complexity:** O(Δ · m) in the worst case, but with early termination when all edges are colored. Since Δ ≤ m and typically much smaller, this is efficient enough.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    nA = int(data[idx]); idx += 1
    nB = int(data[idx]); idx += 1
    m = int(data[idx]); idx += 1
    
    edges = []
    degA = [0] * (nA + 1)
    degB = [0] * (nB + 1)
    
    for i in range(m):
        u = int(data[idx]); idx += 1
        v = int(data[idx]); idx += 1
        edges.append((u, v))
        degA[u] += 1
        degB[v] += 1
    
    D = 0
    for i in range(1, nA + 1):
        if degA[i] > D:
            D = degA[i]
    for i in range(1, nB + 1):
        if degB[i] > D:
            D = degB[i]
    
    color = [0] * m
    usedA = bytearray(nA + 1)
    usedB = bytearray(nB + 1)
    remaining = list(range(m))
    
    c = 1
    while remaining and c <= D:
        usedA = bytearray(nA + 1)
        usedB = bytearray(nB + 1)
        new_remaining = []
        for ei in remaining:
            u, v = edges[ei]
            if not usedA[u] and not usedB[v]:
                color[ei] = c
                usedA[u] = 1
                usedB[v] = 1
            else:
                new_remaining.append(ei)
        remaining = new_remaining
        c += 1
    
    out = ['YES']
    out.append(' '.join(map(str, color)))
    sys.stdout.write('\n'.join(out) + '\n')

main()
```
