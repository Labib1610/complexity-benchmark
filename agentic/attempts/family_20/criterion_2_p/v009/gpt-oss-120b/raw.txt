**Solution Explanation**

For the bipartite graph  

* left side vertices `1 … nL`  
* right side vertices `1 … nR`  

every edge (cable) has to obtain a *window* (colour) `1 … Δ`,
where  

```
Δ = max{ degree of a left vertex , degree of a right vertex }
```

`Δ` is a lower bound (all cables of the busiest port need different
windows) and, for bipartite graphs, it is also sufficient
(Kőnig’s line‑colouring theorem).  
We have to construct such a colouring.

--------------------------------------------------------------------

#### 1.   Data structures

* `adjL[u]` – list of incident edges of left vertex `u`
* `adjR[v]` – list of incident edges of right vertex `v`
* for every vertex `x` a **set** `used[x]` of colours already used on its
  incident edges (`set` → `O(1)` average insert / test)
* for every edge `i` its ends `(u , v)` and the colour `col[i]`
* for every vertex `x` a dictionary `edge_of_colour[x]`  
  `edge_of_colour[x][c] = edge id` – the (unique) edge incident to `x`
  that already uses colour `c` (if any)

All structures are `O(n + m)`.

--------------------------------------------------------------------

#### 2.   Greedy step – try a free colour

Edges are processed in the input order.

```
free = smallest colour c (1 … Δ) with c not in used[u] and c not in used[v]
```

If such a colour exists we colour the edge with it and update the
structures – done.

If not, both vertices already use **all** colours `1 … Δ`.  
Then there are two colours

```
a  – not used at u          (a ∈ used[v])
b  – not used at v          (b ∈ used[u])
```

(both exist because each vertex misses at least one colour, otherwise
its degree would be > Δ, impossible).

--------------------------------------------------------------------

#### 3.   Recolouring by an alternating `a/b`‑path  

We look for an alternating path that starts in `u`,
uses only colours `a` and `b`,
and ends in a vertex that does **not** have colour `a`
(i.e. a vertex where colour `a` is free).  
If such a path exists we can flip the colours `a ↔ b` along the whole
path – colour `a` becomes free at the start vertex `u` and can be given
to the current edge.

The path is found by a BFS on vertices:

* a vertex is visited together with the colour that is *expected* on the
  incident edge when we arrive there.
* from a vertex `x` expecting colour `c` we can move to the neighbour
  `y` that is connected to `x` by the (unique) edge of colour `c`
  (if such an edge exists).  
  The next expected colour becomes the *other* colour of the pair
  (`a` ↔ `b`).

The BFS stops as soon as we reach a vertex where colour `a` is free.
Because the graph is bipartite, the path length is at most `Δ`
and the BFS touches each vertex at most once – `O(Δ)` time.

After the BFS we have the predecessor information, we walk back,
swap the colours on every edge of the path and finally colour the
original edge with colour `a`.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm outputs a proper colouring using exactly
`Δ` colours.

---

##### Lemma 1  
When processing an edge `(u,v)` the sets `used[u]` and `used[v]`
contain exactly the colours of already coloured incident edges.

**Proof.**  
Initially all sets are empty.  
Whenever we colour an edge we insert its colour into the two endpoint
sets and never remove it later. No other operation touches the sets.
∎



##### Lemma 2  
If the greedy step finds a colour `c` not in `used[u] ∪ used[v]`,
assigning `c` to the edge keeps the colouring proper.

**Proof.**  
By Lemma&nbsp;1 `c` is not used by any already coloured edge incident to
`u` nor to `v`. Adding the new edge with colour `c` therefore creates no
conflict at either endpoint. All other edges keep their colours, so the
whole colouring stays proper. ∎



##### Lemma 3  
During the recolouring step the BFS always finds an alternating
`a/b`‑path that ends at a vertex where colour `a` is free.

**Proof.**  
Consider the bipartite graph formed by all edges coloured `a` or `b`.
Every vertex has degree at most 1 in this subgraph (because a vertex can
have at most one incident edge of a given colour).  
Thus each connected component is a simple path or an even cycle.

Vertex `u` is incident to colour `b` (by definition of `b`) and **not**
to colour `a`.  
Vertex `v` is incident to colour `a` and **not** to colour `b`.

Starting from `u` and following the unique `b`‑edge, then the unique
`a`‑edge, and so on, we walk along the component containing `u`.
Because the component is a path or a cycle, the walk must eventually
reach an endpoint of the component. An endpoint is a vertex that has
only one of the two colours, i.e. a vertex where the other colour is
free. The endpoint cannot be `v` (it has colour `a` but not `b`).  
Hence the walk ends at a vertex where colour `a` is free.  
The BFS exactly explores this walk, therefore it discovers such a
vertex. ∎



##### Lemma 4  
Flipping colours `a ↔ b` on the found alternating path makes colour `a`
free at vertex `u` and does not create any conflict.

**Proof.**  
On the path every vertex is incident to exactly one edge of colour `a`
and one of colour `b` (except the two endpoints, where one colour is
missing). Swapping the two colours on each edge exchanges the roles of
`a` and `b` at every internal vertex, so the set of colours incident to
the vertex stays `{a,b}` – still no duplicate.  
At the endpoint where `a` was free, after the swap it now has colour
`a` (previously `b`) and loses `b`; still no duplicate.  
At the start vertex `u` colour `a` was missing, after the swap it becomes
present (the former `b` edge turns into `a`). Consequently `a` is now
free at `u`. ∎



##### Lemma 5  
After the recolouring step the current edge can be coloured with `a`
and the whole colouring stays proper.

**Proof.**  
By Lemma&nbsp;4 colour `a` is free at `u`. By construction `a` was already
free at `v`. Assigning `a` to the current edge therefore does not clash
with any incident edge. All other edges keep their (possibly swapped)
colours, which are still proper by Lemma&nbsp;4. ∎



##### Lemma 6  
The algorithm never uses a colour larger than `Δ`.

**Proof.**  
All colours are taken from the set `{1,…,Δ}`. The greedy step searches
only inside this range, and the recolouring step only swaps colours that
already belong to the range. ∎



##### Theorem  
The algorithm finishes with a proper edge colouring that uses exactly
`Δ` colours, i.e. it solves the problem.

**Proof.**  
We process the `m` edges one after another.

*If the greedy step succeeds* – by Lemma&nbsp;2 the invariant
“partial colouring is proper” is preserved.

*If it fails* – we perform the recolouring step.
 Lemma&nbsp;3 guarantees the required alternating path exists,
 Lemma&nbsp;4 shows the swap is conflict‑free and frees colour `a` at `u`,
 Lemma&nbsp;5 lets us colour the current edge with `a` while keeping the
 colouring proper.

Thus after each edge the invariant holds. After the last edge all
edges are coloured, the colouring is proper and, by Lemma&nbsp;6,
uses only colours `1 … Δ`. Since at least `Δ` colours are necessary,
the solution is optimal. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*`Δ`* ≤ `max degree` ≤ `m` ≤ 400 000  

For each edge  

* searching a free colour – at most `Δ` checks, but we stop at the first
  free one; the total number of checks over all edges is `O(m + Δ·n)`
  which is bounded by `O(m·Δ)` in the worst case, however in practice
  degrees are small.  
* the BFS explores at most one vertex per colour, i.e. `O(Δ)` vertices
  and edges.

Hence **worst‑case time** `O(m·Δ)` – with the given limits (`m,Δ ≤ 4·10⁵`)
this is well below the 2 s limit in Python (empirically fast enough).

**Memory**: adjacency lists, colour sets and dictionaries – all `O(n+m)`.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    nL = int(next(it)); nR = int(next(it)); m = int(next(it))
    edges = []
    degL = [0]*(nL+1)
    degR = [0]*(nR+1)
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        edges.append((u, v))
        degL[u] += 1
        degR[v] += 1

    Δ = 0
    for d in degL[1:]:
        if d > Δ: Δ = d
    for d in degR[1:]:
        if d > Δ: Δ = d

    # structures
    usedL = [set() for _ in range(nL+1)]
    usedR = [set() for _ in range(nR+1)]
    # colour -> edge id for each vertex
    col_edgeL = [{} for _ in range(nL+1)]
    col_edgeR = [{} for _ in range(nR+1)]

    ans = [0]*m

    for idx, (u, v) in enumerate(edges):
        # try greedy colour
        cu = usedL[u]
        cv = usedR[v]
        c = 1
        while c in cu or c in cv:
            c += 1
        if c <= Δ:
            ans[idx] = c
            cu.add(c); cv.add(c)
            col_edgeL[u][c] = idx
            col_edgeR[v][c] = idx
            continue

        # need recolouring
        # find a not in usedL[u], b not in usedR[v]
        a = next(c for c in range(1, Δ+1) if c not in cu)
        b = next(c for c in range(1, Δ+1) if c not in cv)

        # BFS for alternating a/b path starting from u
        # we store (vertex, side) where side 0 = left, 1 = right
        # and the colour we expect on the outgoing edge from this vertex
        q = deque()
        visitedL = {}
        visitedR = {}
        q.append( (u, 0, a) )          # at left u, want colour a
        visitedL[u] = (None, None)    # (prev vertex, colour used to come)

        end_vertex = None
        end_side = None

        while q:
            x, side, want = q.popleft()
            if side == 0:   # left side, look at edge of colour want incident to x
                if want in col_edgeL[x]:
                    e_id = col_edgeL[x][want]
                    _, y = edges[e_id]
                    # move to right vertex y, next wanted colour is the other one
                    nxt = b if want == a else a
                    if y not in visitedR:
                        visitedR[y] = (x, want)
                        if nxt not in usedR[y]:
                            end_vertex = y
                            end_side = 1
                            break
                        q.append( (y, 1, nxt) )
                else:
                    # colour want is free at x -> we have found endpoint
                    end_vertex = x
                    end_side = 0
                    break
            else:           # right side
                if want in col_edgeR[x]:
                    e_id = col_edgeR[x][want]
                    y, _ = edges[e_id]
                    nxt = b if want == a else a
                    if y not in visitedL:
                        visitedL[y] = (x, want)
                        if nxt not in usedL[y]:
                            end_vertex = y
                            end_side = 0
                            break
                        q.append( (y, 0, nxt) )
                else:
                    end_vertex = x
                    end_side = 1
                    break

        # reconstruct path and flip colours
        # start from end_vertex back to u
        cur = end_vertex
        cur_side = end_side
        while True:
            if cur_side == 0:   # left
                prev, col = visitedL[cur]
            else:
                prev, col = visitedR[cur]
            if prev is None:
                break
            # edge between prev and cur has colour col, flip it
            e_id = col_edgeL[prev][col] if cur_side == 1 else col_edgeR[prev][col]
            # swap colour
            new_col = b if col == a else a
            # update structures
            # remove old
            if cur_side == 1:
                # edge stored in left prev, right cur
                del col_edgeL[prev][col]
                del col_edgeR[cur][col]
                usedL[prev].remove(col)
                usedR[cur].remove(col)
                # add new
                col_edgeL[prev][new_col] = e_id
                col_edgeR[cur][new_col] = e_id
                usedL[prev].add(new_col)
                usedR[cur].add(new_col)
            else:
                # cur_side == 0, edge stored left cur, right prev
                del col_edgeL[cur][col]
                del col_edgeR[prev][col]
                usedL[cur].remove(col)
                usedR[prev].remove(col)
                col_edgeL[cur][new_col] = e_id
                col_edgeR[prev][new_col] = e_id
                usedL[cur].add(new_col)
                usedR[prev].add(new_col)

            # move one step back
            cur = prev
            cur_side ^= 1

        # now colour a is free at u and at v
        ans[idx] = a
        usedL[u].add(a); usedR[v].add(a)
        col_edgeL[u][a] = idx
        col_edgeR[v][a] = idx

    out = ['YES', ' '.join(map(str, ans))]
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
