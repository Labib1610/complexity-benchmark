 We can solve this by edge coloring a bipartite multigraph.  
Since the graph is bipartite, we can color its edges with exactly Δ colors, where Δ is the maximum degree.  

Here’s the Python implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

nL, nR, m = map(int, input().split())
edges = []
adj = [[] for _ in range(nL + nR + 1)]
deg = [0] * (nL + nR + 1)

for i in range(m):
    u, v = map(int, input().split())
    v += nL
    edges.append((u, v))
    adj[u].append((v, i))
    adj[v].append((u, i))
    deg[u] += 1
    deg[v] += 1

Delta = max(deg) if deg else 0
color = [-1] * m
# For each vertex, keep track of used colors
used = [set() for _ in range(nL + nR + 1)]

# Simple greedy coloring for bipartite multigraph
# Since it's bipartite, greedy with smallest available color works
for u in range(1, nL + nR + 1):
    for v, idx in adj[u]:
        if color[idx] != -1:
            continue
        # find smallest color not used by u or v
        c = 1
        while c in used[u] or c in used[v]:
            c += 1
        color[idx] = c
        used[u].add(c)
        used[v].add(c)

print("YES")
print(" ".join(str(c) for c in color))
```
