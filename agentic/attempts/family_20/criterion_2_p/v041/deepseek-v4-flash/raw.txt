We can model this as an edge-coloring problem on a bipartite graph.  
The actuators and sensors are the two partitions, and each test is an edge.  
The maximum degree \( K \) is the number of sessions needed.  

A known theorem (Kőnig’s line coloring theorem) guarantees that a bipartite graph can be edge-colored with exactly \( \Delta \) colors, where \( \Delta \) is the maximum degree.  

We can implement an \( O(m \Delta) \) algorithm, but since \( m \) can be up to 400,000 and \( \Delta \) up to 100,000, we need an efficient approach.  
A standard method is to use a greedy algorithm with color swapping, which runs in \( O(m \Delta) \) worst-case but is usually fast enough for this constraint if implemented carefully.  

Here’s the Python solution:  

```python
import sys
from collections import defaultdict

input = sys.stdin.readline

nA, nB, m = map(int, input().split())
edges = []
degA = [0] * (nA + 1)
degB = [0] * (nB + 1)

for _ in range(m):
    u, v = map(int, input().split())
    edges.append((u, v))
    degA[u] += 1
    degB[v] += 1

K = max(max(degA), max(degB))

# color[u][v] = color of edge (u, v)
colorA = [dict() for _ in range(nA + 1)]
colorB = [dict() for _ in range(nB + 1)]

# For each edge, assign a color
for idx, (u, v) in enumerate(edges):
    # find smallest free color for u
    usedA = set(colorA[u].values())
    usedB = set(colorB[v].values())
    c = 1
    while c in usedA or c in usedB:
        c += 1
    colorA[u][v] = c
    colorB[v][u] = c

# Now fix conflicts by color swapping
for u in range(1, nA + 1):
    # For each color, track which neighbor uses it
    color_to_v = {}
    for v, c in colorA[u].items():
        if c in color_to_v:
            # conflict: two edges from u have same color c
            # resolve by swapping colors along alternating path
            v1 = color_to_v[c]
            v2 = v
            # find free color for v2 in B side
            usedB = set(colorB[v2].values())
            c2 = 1
            while c2 in usedB or c2 == c:
                c2 += 1
            # swap colors along path
            cur_u, cur_v = u, v2
            cur_c = c
            next_c = c2
            while True:
                # assign next_c to (cur_u, cur_v)
                old_c = colorA[cur_u][cur_v]
                colorA[cur_u][cur_v] = next_c
                colorB[cur_v][cur_u] = next_c
                # find if next_c is used by another edge from cur_v
                # find the other u' that has color next_c with cur_v
                other_u = None
                for uu, cc in colorB[cur_v].items():
                    if cc == next_c and uu != cur_u:
                        other_u = uu
                        break
                if other_u is None:
                    break
                # move to that edge
                cur_u, cur_v = other_u, cur_v
                next_c, cur_c = cur_c, next_c
        else:
            color_to_v[c] = v

# Output
out = []
for u, v in edges:
    out.append(str(colorA[u][v]))
print("YES")
print(" ".join(out))
```
