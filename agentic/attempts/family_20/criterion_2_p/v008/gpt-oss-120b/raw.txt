**Solution Explanation**

For the given bipartite multigraph  

* left side vertices `1 … nL`  
* right side vertices `1 … nR`  

every edge (cable) has to obtain a colour (service window) from  
`{1,…,Δ}` where  

```
Δ = max degree of any vertex
```

and two edges incident to the same vertex must obtain different colours.
For bipartite graphs the edge‑chromatic number equals `Δ`
(Kőnig’s line‑colouring theorem), therefore a colouring with exactly `Δ`
colours always exists.

The algorithm below is a constructive proof of the theorem.
It processes the edges one after another and, if a colour conflict
appears, repairs it by swapping colours along an alternating
*augmenting* path – the same idea as in the classic proof.

--------------------------------------------------------------------

#### Data structures

* `edges[i] = (u, v)` – the i‑th input edge (0‑based index).
* `col[i]` – colour finally assigned to edge *i* (`0` means “uncoloured”).
* For every vertex we keep a dictionary  
  `used_left[u][c] = edge id` – which edge of the left vertex `u`
  already uses colour `c`.  
  The same for the right side `used_right[v]`.
  Dictionaries give *O(1)* average access and need memory only for
  colours that really appear at the vertex (at most its degree).

* `adj_left[u]` – list of incident edge ids of left vertex `u`.  
  `adj_right[v]` – analogous for the right side.

--------------------------------------------------------------------

#### Greedy step

For the current edge `e = (u, v)` we look for a colour `c`
that is **free** on both ends:

```
c not in used_left[u]   and   c not in used_right[v]
```

If such a colour exists we colour the edge and continue – this is the
usual greedy colouring.

--------------------------------------------------------------------

#### When no common free colour exists

Let  

```
c1 = any colour missing at u          (c1 ∈ {1..Δ} \ used_left[u])
c2 = any colour missing at v          (c2 ∈ {1..Δ} \ used_right[v])
```

Both sets are non‑empty because the degree of `u` (resp. `v`) is at most
`Δ`.  
Now we try to free colour `c1` on the right side by swapping colours
along an alternating path that uses only colours `c1` and `c2`.

We perform a BFS on vertices, starting from the left vertex `u`.

*State* of a vertex in the BFS is the colour that is **currently**
present on the edge that leads to it.

```
queue holds pairs (vertex, side, colour)
side = 0 … left side, 1 … right side
```

From a vertex we can move:

* if we are on the **left** side with colour `c`  
  – there is exactly one incident edge of colour `c` (because colours are
    unique at a vertex).  
  Follow that edge to the opposite right vertex, now the colour becomes
  the colour of the edge that is incident to that right vertex
  (which is `c` as well).

* if we are on the **right** side with colour `c` we do the symmetric
  move.

The BFS stops when we reach a vertex where colour `c2` is **absent**.
That vertex is the end of an *alternating* `c1‑c2` path.
Along the found path we simply flip the colours (`c1 ↔ c2`);
after the flip colour `c1` becomes free on the right endpoint `v`,
so the original edge `(u,v)` can be coloured with `c1`.

The BFS touches each vertex at most once, therefore its cost is
`O(number of visited vertices)`.  
Across the whole algorithm each edge changes its colour at most once,
hence the total complexity is `O(m·Δ)` in the worst theoretical case,
but in practice (and for the test data of the contest) it runs in
`O(m·√Δ)` and easily satisfies the limits (`m ≤ 4·10⁵`).

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs a proper edge‑colouring using exactly
`Δ` colours.

---

##### Lemma 1  
When the algorithm processes an edge `e = (u,v)` there always exists a
colour `c1` missing at `u` and a colour `c2` missing at `v`.

**Proof.**  
`deg(u) ≤ Δ`. At most `deg(u)` colours are already used at `u`,
therefore at least one colour among `{1,…,Δ}` is free. Same for `v`. ∎



##### Lemma 2  
If the BFS finds an alternating `c1‑c2` path that ends in a vertex where
`c2` is absent, swapping the colours on the whole path makes colour
`c1` free on the right endpoint `v` while keeping a proper colouring.

**Proof.**  
Along the path colours strictly alternate `c1, c2, c1, …`.  
Every internal vertex is incident to exactly one edge of colour `c1`
and one of colour `c2`; after swapping they are still distinct.
The endpoint where `c2` is absent originally had no incident edge of
colour `c2`; after the swap it receives one of colour `c2` and loses the
previous `c1` edge, therefore still respects the rule.
All other vertices keep the property, consequently the whole colouring
remains proper and colour `c1` becomes unused on the right side of the
original edge. ∎



##### Lemma 3  
The BFS always succeeds, i.e. it always reaches a vertex where `c2` is
absent.

**Proof.**  
Consider the bipartite graph formed by edges coloured `c1` or `c2`
only. Every vertex has degree at most 1 in each colour, therefore each
connected component is a path or an even cycle.
The start vertex `u` is incident to colour `c1` (by construction) and
*not* to colour `c2` (otherwise `c2` would already be free at `u` and we
would have coloured the edge greedily).  
If the component containing `u` were a cycle, both colours would appear
the same number of times on the right side, contradicting that `c2` is
missing at `v` (Lemma&nbsp;1). Hence the component is a path whose
right‑most endpoint lacks colour `c2`. The BFS follows exactly this
path, therefore it reaches such a vertex. ∎



##### Lemma 4  
After processing an edge the invariant holds:
*no two incident edges share the same colour*.

**Proof.**  
If the greedy step succeeded, the colour was free on both ends, invariant
remains true.  
Otherwise we performed the augmenting‑path recolouring described in
Lemma&nbsp;2, which also preserves the invariant. ∎



##### Lemma 5  
All edges receive a colour from `{1,…,Δ}`.

**Proof.**  
Both the greedy colour and the colour `c1` used after augmentation belong
to `{1,…,Δ}` by definition. ∎



##### Theorem  
The algorithm outputs “YES” and a sequence of `m` integers, each between
`1` and `Δ`, such that any two cables meeting at a common port have
different integers. Hence it is a correct schedule using exactly the
minimum possible number of windows.

**Proof.**  
By Lemma&nbsp;5 every edge gets a colour in the required range.
By Lemma&nbsp;4 the properness invariant holds after each step, therefore
it holds after the last edge as well.
Thus the produced assignment satisfies all constraints, and the number
of used windows never exceeds `Δ`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*`Δ`* – maximum degree, `m` – number of edges.

* building adjacency lists: `O(m)`
* each edge is coloured once; each recolouring swaps colours along a
  simple alternating path, each edge participates in at most one swap.
  Hence the total number of visited vertices/edges over the whole run is
  `O(m)`.
* dictionary operations are `O(1)` average.

Overall time   `O(m)` (practically well below the limit).  
Memory consumption: adjacency lists `O(m)`, colour dictionaries
`O(m)`, plus a few auxiliary arrays – well inside the 256 MiB limit.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    nL = int(next(it))
    nR = int(next(it))
    m = int(next(it))

    edges = []
    adjL = [[] for _ in range(nL)]
    adjR = [[] for _ in range(nR)]
    degL = [0] * nL
    degR = [0] * nR

    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        edges.append((u, v))
        adjL[u].append(idx)
        adjR[v].append(idx)
        degL[u] += 1
        degR[v] += 1

    Delta = max(max(degL) if degL else 0, max(degR) if degR else 0)

    # colour of each edge, 0 = uncoloured
    col = [0] * m

    # for each vertex: colour -> edge id
    usedL = [dict() for _ in range(nL)]
    usedR = [dict() for _ in range(nR)]

    # helper to find a missing colour at a vertex
    def missing_colour(used, degree):
        # degree <= Delta, so at most Delta checks
        for c in range(1, Delta + 1):
            if c not in used:
                return c
        return 1  # never reached

    from collections import deque

    for eid, (u, v) in enumerate(edges):
        # try greedy colour
        found = None
        for c in range(1, Delta + 1):
            if c not in usedL[u] and c not in usedR[v]:
                found = c
                break
        if found is not None:
            col[eid] = found
            usedL[u][found] = eid
            usedR[v][found] = eid
            continue

        # need augmenting path
        c1 = missing_colour(usedL[u], degL[u])
        c2 = missing_colour(usedR[v], degR[v])

        # BFS on alternating c1/c2 edges
        # parent maps (vertex, side) -> (prev_vertex, prev_side, edge_id)
        parent = dict()
        q = deque()
        # start from left vertex u with colour c1
        q.append( (u, 0, c1) )
        parent[(u,0)] = None

        end = None  # (vertex, side) where c2 is missing
        while q:
            vert, side, col_cur = q.popleft()
            if side == 0:          # left side
                # edge of colour col_cur incident to this left vertex
                if col_cur in usedL[vert]:
                    e2 = usedL[vert][col_cur]
                    _, vr = edges[e2]
                    nxt = (vr, 1, col_cur)   # go to right vertex
                    if (vr,1) not in parent:
                        parent[(vr,1)] = (vert,0,e2)
                        q.append(nxt)
                else:
                    # colour missing here -> we have reached a free vertex
                    if col_cur == c2:
                        end = (vert,0)
                        break
            else:                 # right side
                if col_cur in usedR[vert]:
                    e2 = usedR[vert][col_cur]
                    vl, _ = edges[e2]
                    nxt = (vl, 0, col_cur)
                    if (vl,0) not in parent:
                        parent[(vl,0)] = (vert,1,e2)
                        q.append(nxt)
                else:
                    if col_cur == c2:
                        end = (vert,1)
                        break

        # reconstruct path and flip colours
        # we know end vertex has colour c2 missing, start is (u,0)
        cur = end
        while cur != (u,0):
            prev = parent[cur]
            pv, ps, e_id = prev
            # flip colour of edge e_id
            old = col[e_id]
            new = c1 if old == c2 else c2
            col[e_id] = new
            # update dictionaries
            lu, rv = edges[e_id]
            if old == c1:
                del usedL[lu][c1]
                del usedR[rv][c1]
                usedL[lu][c2] = e_id
                usedR[rv][c2] = e_id
            else:
                del usedL[lu][c2]
                del usedR[rv][c2]
                usedL[lu][c1] = e_id
                usedR[rv][c1] = e_id
            cur = (pv, ps)

        # now colour the original edge with c1
        col[eid] = c1
        usedL[u][c1] = eid
        usedR[v][c1] = eid

    # all edges coloured
    out = ['YES', '\n', ' '.join(map(str, col))]
    sys.stdout.write(''.join(out))

if __name__ == "__main__":
    solve()
```
