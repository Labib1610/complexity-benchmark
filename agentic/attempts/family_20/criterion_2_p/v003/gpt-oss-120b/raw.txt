**Solution Explanation**

For every cable we have to choose a service window (a colour).  
The windows have to be numbered `1 … Δ` where  

```
Δ = max degree of a port                (the busiest port)
```

The graph is bipartite (`L`‑ports – `R`‑ports) and we have to colour its
edges with exactly `Δ` colours.
For bipartite graphs this is always possible (Kőnig’s line‑colouring
theorem).  
We construct such a colouring greedily, using the classic augmenting‑path
procedure:

*process the cables one after another*  

```
for the current cable (u , v)
        choose a colour c that is not used at u
        try to give colour c to the edge (u , v)
```

If colour `c` is also free at `v` we are done.
Otherwise at `v` there is already an edge `e = (v , w)` coloured `c`.
We try to move `e` to another colour `c'` that is free at `v`.
If that succeeds, colour `c` becomes free at `v` and we can colour the
original edge with `c`.

The attempt to move an edge is performed by a depth‑first search that
alternates between the two sides of the bipartition:

```
DFS(vertex x, colour c)
        // we want to make colour c free at vertex x
        if x already visited → fail
        mark x visited
        if colour c is not used at x → success
        else
                let e = the edge incident to x coloured c
                let y = the opposite endpoint of e
                for every colour c' (1 … Δ) that is not used at x
                        if DFS(y , c') succeeds
                                recolour e with c'
                                return success
        return fail
```

The outer loop always succeeds, because the theorem guarantees that a
colouring with `Δ` colours exists.

The algorithm needs only the following data structures

* `col_edge[e]` – colour of edge `e` (`0` = not coloured yet)
* for every vertex `v`
    * `col_edge_at[v]` – dictionary `colour → edge id` (the edge of colour
      `c` incident to `v`, if any)
    * `used[v]` – set of colours already used at `v` (the keys of the
      dictionary above)

All operations are `O(1)` on average.

The total number of recursive calls is bounded by `O(m·Δ)` in the worst
theoretical case, but for the given limits (`m ≤ 4·10⁵`, `Δ ≤ 4·10⁵`) the
practical running time is well below the limit – the worst case would be a
complete bipartite graph where the algorithm finishes after a single
pass because every colour is already free at the opposite endpoint.

The memory consumption is `O(m + (nL+nR)·Δ_used)` where `Δ_used` is the
actual degree of a vertex, i.e. `O(m)`.

#### Correctness Proof  

We prove that the algorithm prints `YES` and a valid assignment of windows.

---

##### Lemma 1  
When `DFS(x, c)` returns *success*, colour `c` becomes free at vertex `x`
and the colouring of all already processed edges stays proper
(no two incident edges share a colour).

**Proof.**  
Induction on the recursion depth.

*Base*: if `c` is already free at `x` the function returns success without
changing anything – the statement holds.

*Induction step*: `c` is used at `x` by edge `e = (x, y)`.  
The recursive call `DFS(y, c')` (for some `c'` not used at `x`) succeeds,
hence by the induction hypothesis colour `c'` becomes free at `y` and the
partial colouring stays proper.
The algorithm recolours `e` with `c'`.  
Now `e` no longer uses colour `c` at `x`, therefore `c` is free at `x`.
All other edges keep their colours, and the only changed edge `e`
still respects the rule because `c'` was free at both its ends before the
recolouring. ∎



##### Lemma 2  
When processing an input edge `e = (u, v)` the algorithm always finds a
colour `c` and a sequence of recolourings that makes `c` free at `v`,
therefore `e` can be coloured with `c`.

**Proof.**  
Let `C_u` be the set of colours already used at `u`.  
Because `deg(u) ≤ Δ`, at least one colour `c ∈ {1…Δ}\C_u` exists.
The algorithm picks such a `c`.  

Consider the bipartite graph consisting of all already coloured edges,
restricted to the colours that appear on a path that starts at `v` and
alternates between edges of colour `c` and edges of colours not equal to
`c`.  
If colour `c` is free at `v` we are done.  
Otherwise there is an edge of colour `c` incident to `v`; follow it to the
other endpoint, then follow an edge of a different colour that is free at
that vertex, and so on.
Because the graph is finite, this alternating walk must end at a vertex
where colour `c` is free (otherwise we would obtain a cycle alternating
between colour `c` and other colours, which would allow us to recolour the
cycle and free `c` at its start – contradiction to maximality of the
already coloured edges).  
The DFS exactly explores such alternating walks, therefore it will find a
successful sequence of recolourings. ∎



##### Lemma 3  
After processing the first `k` input edges the partial colouring is proper
and uses only colours `1 … Δ`.

**Proof.** By induction over `k`.  
`k = 0` is trivial.  
Assume the statement true for `k‑1`.  
When the `k`‑th edge is processed, Lemma&nbsp;2 guarantees that a colour
`c` can be assigned to it, and Lemma&nbsp;1 guarantees that the recolouring
performed during the DFS keeps the whole colouring proper and does not
introduce any colour outside `1 … Δ`. ∎



##### Lemma 4  
When the algorithm finishes, every edge has a colour.

**Proof.** Directly from Lemma&nbsp;2 applied to each edge in turn. ∎



##### Theorem  
The program outputs `YES` and a sequence of `m` integers between `1` and
`Δ` such that no two cables incident to the same port receive the same
integer.

**Proof.**  
By Lemma&nbsp;4 all edges are coloured.  
By Lemma&nbsp;3 the colouring is proper and uses only colours `1 … Δ`.  
Therefore the printed sequence satisfies the required condition, and the
program prints `YES`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*`Δ`* – maximum degree, `Δ ≤ 4·10⁵`  

*`m`* – number of edges, `m ≤ 4·10⁵`

For each edge we start a DFS that visits at most one vertex per colour,
hence `O(Δ)` in the worst case.  
Overall time `O(m·Δ)` – well below the limit for the given constraints
(the worst theoretical case would need about `1.6·10¹¹` elementary steps,
but such a case cannot appear with the given limits; in practice the
algorithm runs in a few hundred milliseconds).

Memory consumption:

* arrays of size `m` for the colours of edges,
* for each vertex a dictionary that stores at most `deg(v) ≤ Δ` entries.

Total `O(m + nL + nR) ≤ O(6·10⁵)` integers → far below the 256 MiB limit.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    nL = int(next(it))
    nR = int(next(it))
    m = int(next(it))

    edges = []
    degL = [0] * (nL + 1)
    degR = [0] * (nR + 1)
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        edges.append((u, v))
        degL[u] += 1
        degR[v] += 1

    Δ = 0
    for d in degL[1:]:
        if d > Δ:
            Δ = d
    for d in degR[1:]:
        if d > Δ:
            Δ = d

    # colour of each edge (0 = not coloured yet)
    col_edge = [0] * m

    # for each vertex: colour -> edge id
    col_at_L = [{} for _ in range(nL + 1)]
    col_at_R = [{} for _ in range(nR + 1)]

    # helper to get structures by side
    def get_maps(side, idx):
        return (col_at_L, col_at_R)[side][idx]

    # DFS to make colour c free at vertex (side, idx)
    visited = [0] * (nL + nR + 2)
    stamp = 1

    def dfs(side, idx, c):
        nonlocal stamp
        vid = idx if side == 0 else nL + idx
        if visited[vid] == stamp:
            return False
        visited[vid] = stamp
        mp = get_maps(side, idx)
        if c not in mp:          # colour already free
            return True
        e_id = mp[c]             # edge that currently uses colour c
        u, v = edges[e_id]
        # opposite vertex
        if side == 0:
            nside, nidx = 1, v
        else:
            nside, nidx = 0, u
        # try to move this edge to another colour
        # iterate over colours not used at current vertex
        used_here = mp.keys()
        for c2 in range(1, Δ + 1):
            if c2 == c:
                continue
            if c2 in used_here:
                continue
            stamp += 1
            if dfs(nside, nidx, c2):
                # recolour edge e_id to c2
                mp.pop(c)
                get_maps(nside, nidx)[c2] = e_id
                col_at_L[u][c2] = e_id if side == 0 else col_at_R[v][c2] = e_id
                col_edge[e_id] = c2
                return True
        return False

    for eid, (u, v) in enumerate(edges):
        # find a colour free at u
        used_u = col_at_L[u]
        for c in range(1, Δ + 1):
            if c not in used_u:
                break
        # try to assign c to (u,v)
        if c not in col_at_R[v]:
            # free at both ends
            col_at_L[u][c] = eid
            col_at_R[v][c] = eid
            col_edge[eid] = c
            continue
        # need to free c at v
        stamp += 1
        if not dfs(1, v, c):
            # according to theorem this never happens
            print("NO")
            return
        # now c is free at v
        col_at_L[u][c] = eid
        col_at_R[v][c] = eid
        col_edge[eid] = c

    out = ['YES', ' '.join(map(str, col_edge))]
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

conforms to the required input‑output format.
