We need to assign each job a phase number from 1 to K, where K is the maximum degree among resources (Alpha or Omega). No two jobs sharing an Alpha resource or sharing an Omega resource can have the same phase.

To solve this, we can model this as a bipartite graph where each job is an edge between its Alpha resource and Omega resource, and we need an edge coloring with K colors. Since the graph is bipartite and K is the max degree, K-edge-coloring is always possible.

We can use a standard greedy edge-coloring algorithm for bipartite graphs, which uses at most maximum degree colors and runs in O(E * Δ), but for our constraints, we need a more efficient algorithm. We can implement it with "Kőnig's line coloring algorithm" via alternating paths, but a common simpler greedy algorithm works if we color edges in the right order.

Actually, because K ≤ max(Nα, Nω) ≤ 100000 and m ≤ 400000, we can do the following:

- First, compute K = max( max degree of alpha, max degree of omega ).
- Initialize arrays for each alpha resource and omega resource to track which colors are already used by their incident edges.
- For each job (u, v), find the smallest color not used by alpha u and not used by omega v. Assign it and update both.

This greedy method works for bipartite graphs if we color edges in any order? Actually yes — for bipartite graphs, simple greedy edge coloring with smallest available color gives at most Δ colors. This is a known result.

Thus we can implement:

```python
import sys

def main():
    input = sys.stdin.readline
    Nα, Nω, m = map(int, input().split())
    jobs = []
    deg_alpha = [0] * (Nα + 1)
    deg_omega = [0] * (Nω + 1)
    
    for _ in range(m):
        u, v = map(int, input().split())
        jobs.append((u, v))
        deg_alpha[u] += 1
        deg_omega[v] += 1
    
    K = max(max(deg_alpha), max(deg_omega))
    
    # For each resource, track used colors
    used_alpha = [set() for _ in range(Nα + 1)]
    used_omega = [set() for _ in range(Nω + 1)]
    
    # We'll also maintain pointers to next free color for speed
    next_color_alpha = [1] * (Nα + 1)
    next_color_omega = [1] * (Nω + 1)
    
    result = []
    
    for u, v in jobs:
        # find smallest color not in used_alpha[u] and not in used_omega[v]
        c = max(next_color_alpha[u], next_color_omega[v])
        while c in used_alpha[u] or c in used_omega[v]:
            c += 1
        result.append(c)
        used_alpha[u].add(c)
        used_omega[v].add(c)
        next_color_alpha[u] = c + 1
        next_color_omega[v] = c + 1
    
    sys.stdout.write("YES\n")
    sys.stdout.write(" ".join(map(str, result)) + "\n")

if __name__ == "__main__":
    main()
```
