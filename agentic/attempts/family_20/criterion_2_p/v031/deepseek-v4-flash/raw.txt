We can model this as an edge-coloring problem on a bipartite graph.  
Since it's bipartite, the chromatic index equals the maximum degree, so we can always color the edges using exactly `Δ` colors (time slots).

Here's the implementation using a greedy Kuhn-style edge coloring:
