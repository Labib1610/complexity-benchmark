**Solution Explanation**

For every test we have a lock `u ( 1 … nL )` and a key `v ( 1 … nR )`.
All tests together form a bipartite graph `G = (L,R,E)`.
For a vertex `x` let  

```
deg(x) = number of incident edges
```

`Δ = max   deg(x)` (over all locks and keys) is the *peak load* given in the
statement.  
Kőnig’s theorem tells us that a bipartite graph can be edge‑coloured with exactly
`Δ` colours, i.e. the edges can be split into `Δ` matchings.
We have to output one such colouring.

--------------------------------------------------------------------

#### 1.   Data structures

* `adjL[u]` – list of incident edges (their indices) of lock `u`
* `adjR[v]` – list of incident edges of key `v`
* `col[e]` – colour already assigned to edge `e` (`0` = not coloured yet)
* `usedL[u]` – set of colours already used on lock `u`
* `usedR[v]` – set of colours already used on key `v`

`usedL` / `usedR` are stored as Python `set`s – all operations are `O(1)` on
average.

--------------------------------------------------------------------

#### 2.   Greedy step + recolouring (alternating path)

Edges are processed in the input order.

```
try to give the smallest colour c (1 … Δ) that is free on both ends
if such c exists → colour the edge, continue
otherwise we have
        a = a colour missing on the left end
        b = a colour missing on the right end
        (both a and b exist because each vertex misses at least one colour,
         otherwise its degree would be Δ+1)
        we recolour along an alternating a‑b path starting at the left vertex
```

**alternating a‑b path**

Consider only edges coloured `a` or `b`.  
Starting from the left vertex `u` we walk:

```
u --(colour a)--> v --(colour b)--> u' --(a)--> …
```

The walk always alternates the two colours.
Because the graph is finite, the walk either

* reaches a vertex that does **not** have an incident edge of the colour we
  would need next – then we can flip the colours on the whole visited path,
  freeing colour `a` on the start vertex, or
* returns to a previously visited vertex – this cannot happen, because the
  two colours form a collection of disjoint even cycles, therefore the walk
  must stop at a vertex missing one of the two colours.

The walk is found by a simple BFS/DFS that stores the predecessor edge.
Its length is at most `Δ`, therefore the whole recolouring of one edge costs
`O(Δ)` in the worst case, but the total work over all edges is `O(m·Δ)` only
in pathological graphs. In practice (and for the given limits) it is fast
enough – the worst case (`Δ = m = 4·10⁵`) is a star, for which the greedy
step already succeeds without any recolouring.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs a proper edge‑colouring using exactly
`Δ` colours.

---

##### Lemma 1  
For every vertex `x` at any moment the set `usedX[x]` contains exactly the
colours of edges already coloured incident to `x`.

**Proof.**  
When an edge receives a colour `c` we insert `c` into `usedL[u]` and
`usedR[v]`. When we later recolour an edge, we first remove its old colour
from the two sets and afterwards insert the new colour. No other operation
touches the sets. ∎



##### Lemma 2  
When the algorithm processes an edge `(u,v)` and finds a colour `c`
that is free on both ends, assigning `c` keeps the colouring proper.

**Proof.**  
By Lemma&nbsp;1 `c ∉ usedL[u]` and `c ∉ usedR[v]`. After insertion `c` becomes
present exactly once on each of the two vertices, therefore no vertex has two
incident edges of colour `c`. ∎



##### Lemma 3  
Let `a` be a colour missing on `u` and `b` a colour missing on `v`.
The alternating `a‑b` walk starting from `u` always ends at a vertex that
misses the colour needed for the next step.

**Proof.**  
Consider the subgraph consisting only of edges coloured `a` or `b`.  
Every vertex has degree `0`, `1` or `2` in this subgraph:
* degree `0` – the colour is missing,
* degree `1` – the vertex is incident to exactly one of the two colours,
* degree `2` – one incident edge of colour `a` and one of colour `b`.

Thus each connected component is either a path whose ends miss one colour,
or an even cycle alternating `a,b`.  
The walk starts at `u`, which misses `a`. While we follow the alternating
pattern we can never enter a cycle, because entering a cycle would require
the start vertex to have both colours, contradicting the fact that `u` misses
`a`. Consequently the walk must finish at a path end that misses the colour
required for the next step. ∎



##### Lemma 4  
After recolouring along the alternating `a‑b` walk the colour `a` becomes
available on `u` and colour `b` becomes available on `v`, while all vertices
still have at most one incident edge of each colour.

**Proof.**  
Flipping colours on the walk exchanges `a` and `b` on every visited edge.
All internal vertices of the walk had both colours before the flip, therefore
after the exchange they still have both colours (just swapped).  
The start vertex `u` originally missed `a` and had `b` (otherwise the walk
could not leave `u`). After the flip it gains `a` and loses `b`, thus `a`
becomes present exactly once on `u`.  
Analogously the end vertex `v` gains `b` and loses `a`. No vertex obtains a
second edge of the same colour. ∎



##### Lemma 5  
When the algorithm finishes processing an edge, the partial colouring is
proper and uses only colours `1 … Δ`.

**Proof.**  
Induction over the processed edges.

*Base.* No edge coloured – trivially proper.

*Step.* Assume the invariant holds before processing edge `e = (u,v)`.  
If the greedy colour `c` exists, Lemma&nbsp;2 shows the invariant stays true.  
Otherwise we perform the recolouring described above.
By Lemma&nbsp;4 the resulting colouring is proper.
All colours involved are `a` or `b`, both belong to `{1,…,Δ}`,
hence the colour set does not grow. ∎



##### Lemma 6  
The algorithm always finds a colour `a` missing on `u` and a colour `b`
missing on `v`.

**Proof.**  
`deg(u) ≤ Δ`. If all `Δ` colours were already used on `u`, its degree would be
`Δ+1`, impossible. Same for `v`. ∎



##### Theorem  
The algorithm outputs a colouring of all `m` edges with colours
`1 … Δ` such that no two edges sharing a lock or a key obtain the same colour.

**Proof.**  
By Lemma&nbsp;5 the invariant holds after each edge, therefore after the last
edge all `m` edges are coloured properly and only colours `1 … Δ` appear.
The first output line is required to be `YES`, which we print. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*`Δ`* – maximum degree, `m` – number of edges.

* building adjacency lists: `O(m)`
* processing each edge  
  * greedy search for a free colour – at most `Δ` checks, but we stop at the
    first free colour, average `O(1)`
  * recolouring (only when greedy fails) – walks at most `Δ` edges,
    each step constant time.

In the worst theoretical case `O(m·Δ)`, but for the given limits
(`m ≤ 4·10⁵`) the algorithm runs easily within the 2 s limit (the pathological
case is a star, where greedy always succeeds).

Memory consumption:

* adjacency lists – `2·m` integers
* colour array – `m` integers
* two sets per vertex – total at most `2·m` stored colour entries

Overall `O(nL + nR + m)` ≤ `9·10⁵` integers → well below 256 MB.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    nL = int(next(it))
    nR = int(next(it))
    m = int(next(it))

    edges = [(int(next(it)) - 1, int(next(it)) - 1) for _ in range(m)]

    # degree to obtain Δ
    degL = [0] * nL
    degR = [0] * nR
    for u, v in edges:
        degL[u] += 1
        degR[v] += 1
    Delta = max(max(degL) if degL else 0, max(degR) if degR else 0)

    # adjacency: for each vertex store (edge_index, neighbour)
    adjL = [[] for _ in range(nL)]
    adjR = [[] for _ in range(nR)]
    for idx, (u, v) in enumerate(edges):
        adjL[u].append((idx, v))
        adjR[v].append((idx, u))

    col = [0] * m                     # 0 = uncoloured
    usedL = [set() for _ in range(nL)]
    usedR = [set() for _ in range(nR)]

    # helper to find a missing colour for a vertex
    def missing_colour(used_set):
        # used_set size <= Delta, so linear scan is fine
        for c in range(1, Delta + 1):
            if c not in used_set:
                return c
        return None  # never happens

    for idx, (u, v) in enumerate(edges):
        # try greedy colour
        found = None
        # iterate over smaller used set to speed up
        if len(usedL[u]) < len(usedR[v]):
            for c in range(1, Delta + 1):
                if c not in usedL[u] and c not in usedR[v]:
                    found = c
                    break
        else:
            for c in range(1, Delta + 1):
                if c not in usedR[v] and c not in usedL[u]:
                    found = c
                    break
        if found is not None:
            col[idx] = found
            usedL[u].add(found)
            usedR[v].add(found)
            continue

        # need recolouring
        a = missing_colour(usedL[u])
        b = missing_colour(usedR[v])

        # BFS on alternating a/b edges, starting from u (left side)
        from collections import deque
        q = deque()
        q.append(('L', u))
        parent = {}          # key: (side, vertex) -> (prev_side, prev_vertex, edge_idx)
        visitedL = set()
        visitedR = set()
        visitedL.add(u)

        end = None  # where we stop (vertex, side)

        while q:
            side, x = q.popleft()
            if side == 'L':
                # edges of colour a from this left vertex
                for e_idx, nb in adjL[x]:
                    if col[e_idx] != a:
                        continue
                    if nb in visitedR:
                        continue
                    visitedR.add(nb)
                    parent[('R', nb)] = ('L', x, e_idx)
                    # check if nb misses colour b
                    if b not in usedR[nb]:
                        end = ('R', nb)
                        q.clear()
                        break
                    # continue with colour b edge from this right vertex
                    for e2, nb2 in adjR[nb]:
                        if col[e2] != b:
                            continue
                        if nb2 in visitedL:
                            continue
                        visitedL.add(nb2)
                        parent[('L', nb2)] = ('R', nb, e2)
                        q.append(('L', nb2))
            else:  # side == 'R'
                # edges of colour b from this right vertex
                for e_idx, nb in adjR[x]:
                    if col[e_idx] != b:
                        continue
                    if nb in visitedL:
                        continue
                    visitedL.add(nb)
                    parent[('L', nb)] = ('R', x, e_idx)
                    if a not in usedL[nb]:
                        end = ('L', nb)
                        q.clear()
                        break
                    for e2, nb2 in adjL[nb]:
                        if col[e2] != a:
                            continue
                        if nb2 in visitedR:
                            continue
                        visitedR.add(nb2)
                        parent[('R', nb2)] = ('L', nb, e2)
                        q.append(('R', nb2))

        # flip colours along the found alternating path
        cur = end
        while cur != ('L', u):
            prev_side, prev_vertex, e_idx = parent[cur]
            # flip colour of edge e_idx
            if col[e_idx] == a:
                col[e_idx] = b
                # update used sets
                lu, rv = edges[e_idx]
                usedL[lu].remove(a)
                usedL[lu].add(b)
                usedR[rv].remove(a)
                usedR[rv].add(b)
            else:
                col[e_idx] = a
                lu, rv = edges[e_idx]
                usedL[lu].remove(b)
                usedL[lu].add(a)
                usedR[rv].remove(b)
                usedR[rv].add(a)
            cur = (prev_side, prev_vertex)

        # now colour the original edge with a
        col[idx] = a
        usedL[u].add(a)
        usedR[v].add(a)

    # output
    out = ['YES\n']
    out.append(' '.join(str(c) for c in col))
    sys.stdout.write('\n'.join(out))

if __name__ == '__main__':
    solve()
```

to the required input‑output format.
