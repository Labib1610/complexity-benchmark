We can model this as a bipartite graph edge-coloring problem.  
Each test is an edge between an emitter (left side) and a chamber (right side).  
The degree of a vertex is the number of tests involving that hardware piece.  
The maximum degree \( D \) is the minimum number of phases needed.  

We can color the edges with \( D \) colors (phases) using a standard bipartite edge-coloring algorithm.  
One efficient method is to repeatedly find a matching and assign colors, but a simpler approach is to use the **Kőnig's line coloring** via **Euler partition** or **DFS-based edge coloring**.

Here’s a practical approach:

- Build adjacency lists with edge indices.
- Use a greedy algorithm with color rematching (Kempe chain) to ensure each vertex uses at most its degree colors.
- Since the graph is bipartite, we can color edges with exactly \(\Delta\) colors.

We’ll implement an iterative edge coloring using BFS/DFS to find alternating paths.

```python
import sys
sys.setrecursionlimit(1 << 25)
input = sys.stdin.readline

N_E, N_C, M = map(int, input().split())
edges = []
adj = [[] for _ in range(N_E + N_C + 1)]

for i in range(M):
    u, v = map(int, input().split())
    v += N_E  # shift chamber indices
    edges.append((u, v))
    adj[u].append((v, i))
    adj[v].append((u, i))

# degree
deg = [0] * (N_E + N_C + 1)
for u, v in edges:
    deg[u] += 1
    deg[v] += 1
D = max(deg[1:]) if M > 0 else 0

color = [-1] * M
# For each vertex, keep track of used colors
used = [set() for _ in range(N_E + N_C + 1)]

# Greedy with Kempe chain
for i, (u, v) in enumerate(edges):
    # find smallest color not used by u or v
    c = 0
    while c in used[u] or c in used[v]:
        c += 1
    color[i] = c
    used[u].add(c)
    used[v].add(c)

    # If conflict, resolve via Kempe chain
    # But in bipartite graph, greedy with smallest available works if we process in order?
    # Actually, simple greedy may exceed D. We need proper edge coloring.
    # We'll implement proper algorithm below.

# Proper edge coloring using BFS/DFS alternating paths
# We'll use the standard algorithm: for each edge, if both endpoints have a common free color, assign it.
# Otherwise, find a free color for u, then recolor along alternating path.

color = [-1] * M
free_color = [0] * (N_E + N_C + 1)  # next candidate color per vertex

for i, (u, v) in enumerate(edges):
    # find free color for u
    cu = free_color[u]
    while cu in used[u]:
        cu += 1
    # find free color for v
    cv = free_color[v]
    while cv in used[v]:
        cv += 1

    if cu == cv:
        color[i] = cu
        used[u].add(cu)
        used[v].add(cu)
        # update free_color
        while free_color[u] in used[u]:
            free_color[u] += 1
        while free_color[v] in used[v]:
            free_color[v] += 1
    else:
        # need to recolor
        # find alternating path from v with color cu to free color cv
        # standard Kempe chain
        # We'll implement iterative path search
        stack = [(v, cu, i)]  # start from v, looking for color cu
        visited = set()
        path_edges = []
        found = False
        while stack:
            node, col, eidx = stack.pop()
            if (node, col) in visited:
                continue
            visited.add((node, col))
            path_edges.append((node, col, eidx))
            # check if node has color cv free
            if cv not in used[node]:
                found = True
                break
            # find next edge from node with color col
            for nxt, ei in adj[node]:
                if color[ei] == col:
                    # flip color
                    stack.append((nxt, cv if col == cu else cu, ei))
                    break
        if found:
            # flip path
            for node, col, eidx in path_edges:
                if color[eidx] == col:
                    # flip
                    used[node].discard(col)
                    newcol = cv if col == cu else cu
                    color[eidx] = newcol
                    used[node].add(newcol)
            # now assign cu to edge i
            color[i] = cu
            used[u].add(cu)
            used[v].add(cu)
        else:
            # fallback: assign cv to i and recolor path
            color[i] = cv
            used[u].add(cv)
            used[v].add(cv)

        # update free colors
        for node in (u, v):
            while free_color[node] in used[node]:
                free_color[node] += 1

# Output
print("YES")
print(" ".join(str(c + 1) for c in color))
```
