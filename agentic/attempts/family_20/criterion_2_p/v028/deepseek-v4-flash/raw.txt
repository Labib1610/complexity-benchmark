We can model this as an edge-coloring problem on a bipartite graph.  
The vessels are on one side, docks on the other, and each transfer is an edge.  
The minimum number of days needed is the maximum degree of any vertex, which is guaranteed to be achievable for bipartite graphs.

We can solve it using a greedy edge-coloring algorithm that runs in \(O(m \Delta)\), but since \(\Delta\) can be large, we need a more efficient approach.  
A known method is to use the **Kőnig’s line coloring** algorithm for bipartite graphs, which runs in \(O(m \log m)\) or \(O(m \Delta)\) but with small constants.

Here’s an implementation using the standard bipartite edge-coloring algorithm:

```python
import sys
from collections import deque

input = sys.stdin.readline

nV, nD, m = map(int, input().split())
edges = []
adjV = [[] for _ in range(nV)]
adjD = [[] for _ in range(nD)]

for i in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    edges.append((u, v))
    adjV[u].append((v, i))
    adjD[v].append((u, i))

# Compute maximum degree
degV = [len(adjV[i]) for i in range(nV)]
degD = [len(adjD[i]) for i in range(nD)]
Delta = max(max(degV) if nV > 0 else 0, max(degD) if nD > 0 else 0)

# Edge coloring using bipartite graph algorithm
color = [0] * m

# We'll use the standard algorithm:
# For each edge, find free colors for both endpoints, if conflict, shift colors along alternating path.

# adjacency in terms of edge indices
adjV_edges = [[] for _ in range(nV)]
adjD_edges = [[] for _ in range(nD)]
for i, (u, v) in enumerate(edges):
    adjV_edges[u].append(i)
    adjD_edges[v].append(i)

# colorV[u] = set of colors used by edges incident to vessel u
# colorD[v] = set of colors used by edges incident to dock v
colorV = [set() for _ in range(nV)]
colorD = [set() for _ in range(nD)]

for i in range(m):
    u, v = edges[i]
    # find smallest free color for u
    c = 1
    while c in colorV[u] or c in colorD[v]:
        c += 1
    color[i] = c
    colorV[u].add(c)
    colorD[v].add(c)

    # Now resolve conflicts if any (shouldn't happen with this simple greedy? Actually can happen)
    # We'll implement the full algorithm: if conflict, recolor along alternating path.

# Actually the simple greedy above may fail because we might pick a color that conflicts later.
# We need the proper algorithm: for each edge, if both endpoints have a free common color, use it.
# Else, find a color free at u, color free at v, and recolor along alternating path.

# Let's implement the standard algorithm properly.

color = [0] * m
colorV = [0] * (nV)  # color used by edge from vessel? Actually we need per-edge color.
# We'll store color per edge and also track used colors per vertex.

usedV = [set() for _ in range(nV)]
usedD = [set() for _ in range(nD)]

for i in range(m):
    u, v = edges[i]
    # find smallest color not used by u or v
    c = 1
    while c in usedV[u] or c in usedD[v]:
        c += 1
    color[i] = c
    usedV[u].add(c)
    usedD[v].add(c)

# The above greedy may still fail because later edges might force a recolor.
# But for bipartite graphs, the greedy with smallest available color works if we process edges in a certain order?
# Actually it's not guaranteed. We need the full algorithm.

# Let's implement the standard algorithm using alternating paths.

color = [0] * m
# For each vertex, store which color is used by which edge
edge_colorV = [dict() for _ in range(nV)]
edge_colorD = [dict() for _ in range(nD)]

for i in range(m):
    u, v = edges[i]
    # find smallest free color for u
    cu = 1
    while cu in edge_colorV[u]:
        cu += 1
    cv = 1
    while cv in edge_colorD[v]:
        cv += 1
    if cu == cv:
        c = cu
        color[i] = c
        edge_colorV[u][c] = i
        edge_colorD[v][c] = i
    else:
        # Need to recolor along alternating path
        # Start from v with color cu, find edge at v with color cu, recolor it to cv, and continue
        # Standard algorithm:
        c1 = cu
        c2 = cv
        # We'll do the path from v
        current_vertex = v
        current_side = 'D'
        current_color = c1
        path_edges = []
        while True:
            if current_side == 'D':
                # find edge at dock current_vertex with color current_color
                if current_color in edge_colorD[current_vertex]:
                    e = edge_colorD[current_vertex][current_color]
                    path_edges.append(e)
                    # move to vessel side
                    u2, v2 = edges[e]
                    current_vertex = u2
                    current_side = 'V'
                    # switch color
                    current_color = c2 if current_color == c1 else c1
                else:
                    break
            else:
                if current_color in edge_colorV[current_vertex]:
                    e = edge_colorV[current_vertex][current_color]
                    path_edges.append(e)
                    u2, v2 = edges[e]
                    current_vertex = v2
                    current_side = 'D'
                    current_color = c2 if current_color == c1 else c1
                else:
                    break
        # Now recolor path edges
        for e in path_edges:
            old = color[e]
            new = c2 if old == c1 else c1
            u2, v2 = edges[e]
            # remove old
            del edge_colorV[u2][old]
            del edge_colorD[v2][old]
            # add new
            color[e] = new
            edge_colorV[u2][new] = e
            edge_colorD[v2][new] = e
        # Now assign current edge
        color[i] = c1
        edge_colorV[u][c1] = i
        edge_colorD[v][c1] = i

# Output
print("YES")
print(" ".join(map(str, color)))
```
