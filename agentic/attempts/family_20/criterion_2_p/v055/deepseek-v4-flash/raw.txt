 We can model this as a bipartite graph edge-coloring problem.  
The probes are on the left, ground stations on the right, and each transfer is an edge.  
We need to color the edges with the minimum number of colors (which equals the maximum degree of the graph), and that is guaranteed to be possible.

We can use a standard algorithm for edge-coloring a bipartite graph in \(O(m \log \Delta)\) or \(O(m \Delta)\) time.  
Given the constraints, we can implement an efficient version using the **Kőnig’s line coloring** approach with alternating paths.

        edges.append((u, v))

    if m == 0:

    adj = [[] for _ in range(nL + nR + 1)]

        adj[v + nL].append((u, i))

    # Find max degree
    deg = [0] * (nL + nR + 1)
    for u, v in edges:
        deg[u] += 1
        deg[v + nL] += 1
    K = max(deg[1:])

    # Edge coloring using the algorithm from cp-algorithms
    # https://cp-algorithms.com/graph/edge_coloring.html

    color = [0] * m
    # For each vertex, store color -> edge index
    color_to_edge = [dict() for _ in range(nL + nR + 1)]

    for idx, (u, v) in enumerate(edges):
        vv = v + nL
        # find free color for u
        c1 = 1
        while c1 in color_to_edge[u]:
            c1 += 1
        # find free color for vv
        c2 = 1
        while c2 in color_to_edge[vv]:
            c2 += 1

        if c1 == c2:
            color[idx] = c1
            color_to_edge[u][c1] = idx
            color_to_edge[vv][c1] = idx
        else:
            # Need to recolor path
            # We'll use the standard algorithm:
            # Start from vv, try to find a path with colors c1, c2 alternating
            # We'll use iterative DFS.

            # We'll implement the function to flip colors along path
            # We'll use a stack: (vertex, color_to_find, path_edges)
            stack = [(vv, c1, [])]
            visited = set()
            path_edges = None
            while stack:
                vertex, col, path = stack.pop()
                if vertex in visited:
                    continue
                visited.add(vertex)
                if col not in color_to_edge[vertex]:
                    # found free color
                    path_edges = path
                    break
                # find the edge with color col
                eidx = color_to_edge[vertex][col]
                # get other endpoint
                a, b = edges[eidx]
                nxt = b + nL if a == vertex else a
                new_col = c2 if col == c1 else c1
