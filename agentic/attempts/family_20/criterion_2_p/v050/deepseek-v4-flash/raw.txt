We can solve this by modeling the connections as edges of a bipartite graph between transmitters and receivers.  
The maximum degree \( K \) is the number of time windows needed.  
We can assign each edge a color (time window) from 1 to \( K \) such that no two edges sharing a vertex have the same color.  

Since the graph is bipartite, we can use a greedy edge-coloring algorithm that works in \( O(M \cdot K) \) worst-case, but with careful implementation using adjacency lists and color tracking, it’s efficient enough for the given limits.

Here’s the Python solution:

```python
import sys
from collections import defaultdict

def solve():
    input = sys.stdin.readline
    N_T, N_R, M = map(int, input().split())
    edges = []
    adj_t = [[] for _ in range(N_T + 1)]
    adj_r = [[] for _ in range(N_R + 1)]
    
    for i in range(M):
        u, v = map(int, input().split())
        edges.append((u, v))
        adj_t[u].append((v, i))
        adj_r[v].append((u, i))
    
    # Compute K = max degree
    K = 0
    for i in range(1, N_T + 1):
        K = max(K, len(adj_t[i]))
    for i in range(1, N_R + 1):
        K = max(K, len(adj_r[i]))
    
    color = [0] * M
    # For each transmitter, keep track of used colors
    used_t = [set() for _ in range(N_T + 1)]
    used_r = [set() for _ in range(N_R + 1)]
    
    # Greedy coloring
    for idx, (u, v) in enumerate(edges):
        # Find smallest color not used by u or v
        c = 1
        while c in used_t[u] or c in used_r[v]:
            c += 1
        color[idx] = c
        used_t[u].add(c)
        used_r[v].add(c)
    
    print("YES")
    print(" ".join(map(str, color)))

if __name__ == "__main__":
    solve()
```
