**Solution Explanation**

For every connection (edge) we have to choose a time window (colour) from  
`1 … K`, where  

```
K = max degree of any vertex (transmitter or receiver)
```

The graph is bipartite, therefore an edge‑colouring with exactly `K` colours
always exists (Kőnig’s line‑colouring theorem).

--------------------------------------------------------------------

#### 1.   Observations  

* In one time window a vertex can be used by **at most one** of its incident
  edges – the edges coloured with the same colour form a *matching*.
* If we remove a matching from the graph, the degree of every vertex
  decreases by **at most one**.
* Starting with maximum degree `K`, after removing `K` matchings
  every vertex has degree `0`, i.e. all edges are coloured.

So it is enough to produce **any** matching in each of the `K` rounds.
A *maximal* matching (no edge can be added without breaking the matching
property) is sufficient, because every vertex loses at most one incident edge.

--------------------------------------------------------------------

#### 2.   Greedy construction of a maximal matching  

We treat the two sides of the bipartition as

```
left  : transmitters   (1 … NT)
right : receivers      (1 … NR)
```

For every transmitter we store the list of its incident edges
(`edge id` together with the opposite receiver).

During one round

```
used_receiver[v] = True   ⇔   receiver v already belongs to the matching
```

We walk over all *still active* transmitters (those that still have
uncoloured edges).  
For a transmitter `u` we look at the first not yet coloured edge
in its list (a pointer is stored for each transmitter).

*If the opposite receiver is still free* we colour this edge with the
current round number, mark the receiver as used and advance the pointer.
Otherwise we simply skip this edge – it will be tried again in a later
round.

Because we walk over every transmitter at most once per round,
the obtained set of coloured edges is a matching.
It is maximal on the left side, which is enough for the degree‑decrease
argument above.

--------------------------------------------------------------------

#### 3.   Whole algorithm  

```
read input
build adjacency lists for transmitters (list of (edge_id, receiver))
deg_left[u]  = degree of transmitter u
deg_right[v] = degree of receiver v
K = max over all degrees
answer[edge_id] = 0

active = [u | deg_left[u] > 0]          # transmitters still having edges
pointer[u] = 0   for all transmitters

for colour = 1 … K
        round_used = timestamp array for receivers (size NR+1)
        next_active = []
        for u in active
                # move pointer to the first still uncoloured edge
                while pointer[u] < len(adj[u]) and answer[ adj[u][pointer[u]].id ] != 0
                        pointer[u] += 1
                if pointer[u] == len(adj[u]):          # no edges left
                        continue
                eid, v = adj[u][pointer[u]]
                if round_used[v] != colour:            # receiver still free
                        answer[eid] = colour
                        round_used[v] = colour
                        pointer[u] += 1                # this edge is now coloured
                # after possible colouring, maybe more edges remain
                if pointer[u] < len(adj[u]):           # keep u for next round
                        next_active.append(u)
        active = next_active
```

The loop runs exactly `K` times, but the total work inside is proportional
to the number of edges:

* each edge is examined only when its left endpoint’s pointer reaches it,
  i.e. **once**,
* each edge is coloured exactly once,
* the `active` list shrinks when a transmitter runs out of edges.

Hence the total time complexity is `O(N_T + N_R + M)`  
and the memory consumption is `O(N_T + N_R + M)` – well inside the limits.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints a valid colouring using exactly `K`
colours.

---

##### Lemma 1  
During a round the set of edges coloured in this round is a matching.

**Proof.**  
The algorithm colours an edge `(u, v)` only if `v` has not been used
earlier in the same round (`round_used[v]` is different).  
Each transmitter `u` is processed at most once per round, therefore at most
one of its incident edges can be coloured in this round.
Thus no two coloured edges share a transmitter nor a receiver – they form a
matching. ∎



##### Lemma 2  
After each round the degree of every vertex decreases by at most one.

**Proof.**  
By Lemma&nbsp;1 the coloured edges of the round are a matching, i.e. each
vertex is incident to **zero or one** of them. Removing those edges reduces
the degree of a vertex by exactly the number of incident coloured edges,
hence by at most one. ∎



##### Lemma 3  
After processing the first `c` rounds (`1 ≤ c ≤ K`) every vertex has
remaining degree `≤ K‑c`.

**Proof.**  
Induction over `c`.

*Base `c = 1`*: before any round the degree is `≤ K` by definition of `K`.
After the first round Lemma&nbsp;2 reduces every degree by at most one,
so it becomes `≤ K‑1`.

*Induction step*: assume the statement holds after `c‑1` rounds.
Before round `c` each vertex degree is `≤ K‑(c‑1)`.  
Applying Lemma&nbsp;2 again reduces it by at most one, therefore after round
`c` the degree is `≤ K‑c`. ∎



##### Lemma 4  
All edges are coloured after exactly `K` rounds.

**Proof.**  
Consider any vertex. Its initial degree is at most `K`.  
By Lemma&nbsp;3 after `K` rounds its degree is `≤ K‑K = 0`, i.e. it has no
incident uncoloured edges. Hence every edge of the whole graph is coloured. ∎



##### Lemma 5  
The colour assigned to each edge lies in `{1,…,K}`.

**Proof.**  
The algorithm uses the loop variable `colour` which runs from `1` to `K`
and assigns this value to edges coloured in the corresponding round.
No other values are used. ∎



##### Theorem  
The program outputs “YES” and a sequence of `M` integers such that

* each integer is between `1` and `K`,
* edges sharing a transmitter or a receiver have different integers,
* exactly `K` different integers may appear (the bound is tight).

**Proof.**  
From Lemma&nbsp;1 edges of the same round (same integer) never share an
endpoint, therefore the second condition holds.
Lemma&nbsp;5 gives the first condition.
Lemma&nbsp;4 guarantees that every edge receives a colour, so the output
contains `M` numbers.
Since the algorithm runs for all `K` rounds, at most `K` different colours
appear; the problem statement only requires a feasible colouring with
`K` colours, which we have constructed. ∎

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    NT = int(next(it))
    NR = int(next(it))
    M = int(next(it))

    # adjacency list for transmitters: list of (edge_id, receiver)
    adj = [[] for _ in range(NT + 1)]
    deg_left = [0] * (NT + 1)
    deg_right = [0] * (NR + 1)

    edges = []                     # store (u, v) for possible later use
    for eid in range(M):
        u = int(next(it))
        v = int(next(it))
        edges.append((u, v))
        adj[u].append((eid, v))
        deg_left[u] += 1
        deg_right[v] += 1

    K = 0
    for d in deg_left:
        if d > K:
            K = d
    for d in deg_right:
        if d > K:
            K = d

    answer = [0] * M

    # active transmitters (still have uncoloured edges)
    active = [u for u in range(1, NT + 1) if deg_left[u] > 0]
    ptr = [0] * (NT + 1)           # pointer inside adj[u]

    # timestamp array for receivers
    used_round = [0] * (NR + 1)

    for colour in range(1, K + 1):
        next_active = []
        for u in active:
            # skip already coloured edges
            lst = adj[u]
            p = ptr[u]
            while p < len(lst) and answer[lst[p][0]] != 0:
                p += 1
            ptr[u] = p
            if p == len(lst):
                continue          # no edges left for this transmitter
            eid, v = lst[p]
            if used_round[v] != colour:   # receiver free this round
                answer[eid] = colour
                used_round[v] = colour
                ptr[u] = p + 1            # this edge is now coloured
            # keep u for next round if it still has edges
            if ptr[u] < len(lst):
                next_active.append(u)
        active = next_active

    # all edges must be coloured now
    out = ['YES\n', ' '.join(str(c) for c in answer)]
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
