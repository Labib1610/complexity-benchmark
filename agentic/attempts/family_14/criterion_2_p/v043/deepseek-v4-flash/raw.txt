We are given a tree (m = n − 1, and no redundancy means it’s a tree).  
We need to connect all critical workstations with minimal total cost.  
That means we can discard any subtree that doesn’t contain critical nodes.  
If we remove all unnecessary branches, we get the minimal connected subgraph containing all critical nodes.  

Here’s a direct approach:  
1. Mark all critical nodes.  
2. Do a DFS/BFS from any critical node (or just traverse the tree) to determine which edges are needed.  
3. The total cost is the sum of weights of edges that are part of the minimal subtree spanning all critical nodes.

We can implement this as follows:  

- Read the tree.  
- If t == 1, answer is 0.  
- Otherwise, find which nodes are critical.  
- We do DFS from a critical node)Skip subtrees that contain no critical nodes.  
- Sum up the edges that lead to critical-containing subtrees.

Here’s the code:  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    critical = set(map(int, input().split()))
    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    if t == 1:
        print(0)
        return
    
    # DFS to mark nodes that lead to critical
    important = [False] * (n + 1)
    parent = [0] * (n + 1)
    parent_w = [0] * (n + 1)
    
    stack = [(next(iter(critical)), -1)]
    order = []
    while stack:
        u, p = stack.pop()
        parent[u] = p
        order.append(u)
        for v, w in adj[u]:
            if v != p:
                parent[v] = u
                parent_w[v] = w
                stack.append((v, u))
    
    # Determine importance
    for u in reversed(order):
        if u in critical:
            important[u] = True
            continue
        for v, w in adj[u]:
            if v != parent[u] and important[v]:
                important[u] = True
                break
    
    total = 0
    for u in range(2, n + 1):
        if important[u]:
            total += parent_w[u]
    
    print(total)

if __name__ == "__main__":
    solve()
```
