 We are given a tree (n nodes, n−1 edges) and a set of required nodes.  
We need the minimum total cost to connect all required nodes.  
In a tree, the minimal subgraph connecting a set of nodes is the **Steiner tree**, which is simply the union of all paths between the required nodes.  
The cost is the sum of edge weights in that minimal subtree.

A standard way:  
- Mark required nodes.  
- Do a DFS/BFS from any required node, and compute the total weight of edges that are on paths between required nodes.  
- This can be done by removing all leaves that are not required iteratively, or by a DFS that returns whether a subtree contains any required node.

We'll use DFS:  
For each edge, if both sides contain at least one required node, then that edge must be included.

Implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    required = set(map(int, input().split()))
    adj = [[] for _ in range(n+1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    # DFS to count required nodes in subtree
    visited = [False] * (n+1)
    count = [0] * (n+1)
    
    def dfs(u):
        visited[u] = True
        cnt = 1 if u in required else 0
        for v, w in adj[u]:
            if not visited[v]:
                cnt += dfs(v)
        count[u] = cnt
        return cnt
    
    # start from any required node
    start = next(iter(required))
    dfs(start)
    
    total_cost = 0
    for u, v, w in edges:
        # if one side has required nodes and the other side also has required nodes
        # then this edge is on the Steiner tree
        if count[u] > 0 and count[u] < t:
            total_cost += w
        elif count[v] > 0 and count[v] < t:
            total_cost += w
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
