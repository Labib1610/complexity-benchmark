We are given a tree (n nodes, n−1 edges) and a set of required nodes.  
We need the minimum total cost to connect all required nodes.  

Since it’s a tree, the minimal subgraph connecting a set of nodes is the **Steiner tree** on those nodes, which in a tree is simply the union of all paths between the required nodes.  
The cost is the sum of edge weights in that minimal connected subgraph.

**Approach:**
1. Root the tree at any required node (or any node).
2. Mark all required nodes.
3. Perform a DFS to determine which edges are needed: an edge is needed if the subtree below it contains at least one required node.
4. Sum the weights of all needed edges.

This works in O(n).

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    required = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    # Root at any required node
    root = next(iter(required))
    
    visited = [False] * (n + 1)
    total_cost = 0
    
    def dfs(u):
        visited[u] = True
        has_required = u in required
        for v, w in adj[u]:
            if not visited[v]:
                child_has = dfs(v)
                if child_has:
                    total_cost += w
                has_required = has_required or child_has
        return has_required
    
    dfs(root)
    print(total_cost)

if __name__ == "__main__":
    solve()
```
