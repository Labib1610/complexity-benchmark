**Solution Explanation**

For a tree the cheapest way to connect a set of vertices is unique:  
take all edges that lie on at least one simple path between two of the
required vertices.  
The obtained sub‑tree is called the *minimal Steiner tree on a tree*.

For an edge `e = (parent , child)` let  

* `cnt[child]` – number of contaminated vats in the subtree of `child`
  (including `child` itself).

If `0 < cnt[child] < t` then there is at least one contaminated vat
inside the subtree and at least one outside, therefore any connection of
all contaminated vats must use `e`.  
Otherwise all contaminated vats are on the same side of `e` and the edge
is unnecessary.

So the answer is

```
sum of w(e) over all edges with 0 < cnt[child] < t
```

--------------------------------------------------------------------

#### Algorithm
```
read n , m , t
read list S of t contaminated vats, store in a boolean array is_special[]

build adjacency list of the tree (undirected, weighted)

root the tree at vertex 1
iterative DFS:
    parent[v]            – parent of v in the rooted tree
    w_to_parent[v]       – weight of edge (parent[v] , v)
    order[]              – vertices in preorder (later processed backwards)

cnt[v] = 0 for all v
answer = 0

process vertices in reverse order (postorder):
    cnt[v] = is_special[v] ? 1 : 0
    for each child c of v (parent[c] == v):
        cnt[v] += cnt[c]
        if 0 < cnt[c] < t:
            answer += w_to_parent[c]

output answer
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs the minimum total cost.

---

##### Lemma 1  
For any edge `e = (parent, child)` the edge belongs to every connected
subgraph that contains all contaminated vats **iff**
`0 < cnt[child] < t`.

**Proof.**  
If `0 < cnt[child] < t` there is at least one contaminated vat in the
subtree of `child` and at least one outside it.
Any connected subgraph containing both must contain a path between those
two vats, and every such path uses the unique tree edge `e`.  
Hence `e` is mandatory.

Conversely, if `cnt[child] = 0` (no contaminated vat below) or
`cnt[child] = t` (all contaminated vats below) then all contaminated vats
lie on the same side of `e`. A connected subgraph containing them can stay
entirely on that side, never needing `e`. ∎



##### Lemma 2  
The set of edges selected by the algorithm (those with
`0 < cnt[child] < t`) connects all contaminated vats.

**Proof.**  
Consider any two contaminated vats `a` and `b`.  
If we walk from `a` to `b` along the unique tree path, each traversed edge
has one endpoint in the subtree of the other endpoint and at least one
contaminated vat on both sides of the edge (the vat `a` is on one side,
`b` on the other). Thus for every edge on that path the condition of
Lemma&nbsp;1 holds, therefore the algorithm includes it. Hence the whole
path is present, so `a` and `b` are connected. ∎



##### Lemma 3  
No proper subset of the edges selected by the algorithm connects all
contaminated vats.

**Proof.**  
Assume we remove an edge `e` that the algorithm selected.
By Lemma&nbsp;1 we have `0 < cnt[child] < t`.  
Thus there exist contaminated vats `x` in `child`'s subtree and `y` outside.
Any path between `x` and `y` must contain `e`; after removing `e` they become
disconnected. Hence the remaining edges cannot connect all contaminated vats. ∎



##### Theorem  
The algorithm outputs the minimum possible total cost.

**Proof.**  
Let `E_alg` be the set of edges chosen by the algorithm and `C_alg` its total
weight.

*By Lemma&nbsp;2* `E_alg` connects all contaminated vats, so a feasible
solution of cost `C_alg` exists.

*By Lemma&nbsp;3* every feasible solution must contain **all** edges of
`E_alg`. Therefore any feasible solution has total weight at least `C_alg`.

Thus `C_alg` is both achievable and optimal. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n)`  
*Iterative DFS and post‑order processing*: each edge and vertex is visited
a constant number of times → `O(n)` time.  

Memory consumption: adjacency list (`2·(n‑1)` entries), several
`O(n)` integer arrays → `O(n)` memory, well within limits (`n ≤ 2·10⁵`).

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    it = iter(data)
    n = int(next(it))
    m = int(next(it))          # = n-1, not used separately
    t = int(next(it))

    special = [False] * (n + 1)
    for _ in range(t):
        v = int(next(it))
        special[v] = True

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    # iterative DFS to obtain parent, edge weight to parent, and order
    parent = [0] * (n + 1)
    w_parent = [0] * (n + 1)
    order = []
    stack = [1]
    parent[1] = -1  # root marker
    while stack:
        v = stack.pop()
        order.append(v)
        for to, w in adj[v]:
            if to != parent[v]:
                parent[to] = v
                w_parent[to] = w
                stack.append(to)

    cnt = [0] * (n + 1)
    ans = 0
    # process in reverse order = postorder
    for v in reversed(order):
        c = 1 if special[v] else 0
        # accumulate children's counts
        for to, _ in adj[v]:
            if parent[to] == v:          # to is child
                c += cnt[to]
                if 0 < cnt[to] < t:      # edge (v,to) is necessary
                    ans += w_parent[to]
        cnt[v] = c

    print(ans)


if __name__ == "__main__":
    sys.setrecursionlimit(1 << 25)
    solve()
```

conforms to the required input‑output format.
