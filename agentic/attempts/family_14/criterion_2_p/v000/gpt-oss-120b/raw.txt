**Solution Explanation**

For a tree `T` ( `n` vertices, `n‑1` weighted edges ) let `R` be the set of
required vertices, `|R| = t`.

For an edge `e = (u , v)` remove it – the tree splits into two components.
If both components contain at least one required vertex,
any connection of all required vertices **must** contain `e`,
otherwise the two groups could never be linked.
If one side contains no required vertex, `e` is useless.

Therefore the minimum total cost equals the sum of the weights of all
edges whose two sides both contain required vertices.

So we only have to know, for every edge, how many required vertices lie
in one side of it.

--------------------------------------------------------------------

#### 1.   Counting required vertices in sub‑trees  

Root the tree at an arbitrary vertex (e.g. `1`).

For every vertex `x`

```
cnt[x] = number of required vertices in the subtree of x (including x)
```

`cnt` can be computed in one post‑order traversal.

For the edge that connects a child `c` with its parent `p`

```
required vertices on child side = cnt[c]
required vertices on parent side = t - cnt[c]
```

The edge is needed **iff** `0 < cnt[c] < t`.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read input
required[v] = 1 if v ∈ R else 0
build adjacency list

# 1. iterative DFS to obtain parent of each vertex and a traversal order
stack = [(root, 0)]
order = []                     # vertices in visiting order
while stack:
        v, p = stack.pop()
        parent[v] = p
        order.append(v)
        for (to, w) in adj[v]:
                if to != p:
                        stack.append((to, v))

# 2. post‑order processing
answer = 0
for v in reversed(order):
        cnt[v] = required[v]
        for (to, w) in adj[v]:
                if parent[to] == v:               # to is a child
                        cnt[v] += cnt[to]
                        if 0 < cnt[to] < t:       # edge v‑to is needed
                                answer += w

print answer
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total cost.

---

##### Lemma 1  
For any edge `e` whose removal separates the tree into components `A` and
`B`, `e` belongs to every feasible solution **iff**
both `A` and `B` contain at least one required vertex.

**Proof.**  
*If*: suppose each side has a required vertex.
Any set of edges that connects all required vertices must provide a path
between those two vertices, and any such path must cross the cut `{A,B}`,
hence must contain `e` (the tree contains exactly one `A‑B` path).  

*Only‑if*: if one side, say `A`, contains no required vertex, all required
vertices lie in `B`. Then they are already mutually connected inside `B`,
so a solution that omits `e` is feasible. ∎



##### Lemma 2  
Rooting the tree, for a child `c` of parent `p` let `cnt[c]` be the number
of required vertices in the subtree of `c`.  
Edge `(p,c)` is needed **iff** `0 < cnt[c] < t`.

**Proof.**  
Removing `(p,c)` separates the tree into the subtree of `c` and the rest.
The first component contains exactly `cnt[c]` required vertices,
the second contains `t - cnt[c]`.  
By Lemma&nbsp;1 the edge is needed precisely when both numbers are positive,
i.e. `0 < cnt[c] < t`. ∎



##### Lemma 3  
During the post‑order loop the algorithm adds the weight of an edge
exactly when the edge is needed.

**Proof.**  
When processing vertex `v` all its children `c` have already been processed,
so `cnt[c]` is known.
The algorithm checks the condition `0 < cnt[c] < t` (Lemma&nbsp;2) and,
iff true, adds the stored weight `w(v,c)`. Thus each needed edge contributes
its weight once, and no unnecessary edge does. ∎



##### Theorem  
The value `answer` printed by the algorithm equals the minimum possible total
cost of cabling that connects all required sites.

**Proof.**  
*Soundness*:  
By Lemma&nbsp;3 the algorithm sums the weights of exactly the edges that are
necessary in **every** feasible solution (Lemma&nbsp;1). Hence any feasible
solution must have total cost ≥ `answer`.

*Optimality*:  
Consider the subgraph consisting of exactly those edges summed by the
algorithm. By Lemma&nbsp;1 each of them is necessary, and together they form a
connected subgraph containing all required vertices (they are precisely the
union of all paths between required vertices). Therefore this subgraph is a
feasible solution whose total cost is `answer`.

Since no feasible solution can be cheaper and a solution of cost `answer`
exists, `answer` is the minimum possible cost. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list* : `O(n)`  
*DFS to get order*        : `O(n)`  
*Post‑order processing*   : `O(n)`  

Memory usage: adjacency list (`2·(n‑1)` edges) + a few integer arrays,
all `O(n)`.

Both limits satisfy the constraints (`n ≤ 200 000`).

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)          # = n-1, not used separately
    t = next(it)

    required = [0] * (n + 1)
    for _ in range(t):
        required[next(it)] = 1

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = next(it)
        v = next(it)
        w = next(it)
        adj[u].append((v, w))
        adj[v].append((u, w))

    root = 1
    parent = [0] * (n + 1)
    order = []
    stack = [(root, 0)]
    while stack:
        v, p = stack.pop()
        parent[v] = p
        order.append(v)
        for to, w in adj[v]:
            if to != p:
                stack.append((to, v))

    cnt = [0] * (n + 1)
    answer = 0
    for v in reversed(order):
        cnt[v] = required[v]
        for to, w in adj[v]:
            if parent[to] == v:          # to is child
                cnt[v] += cnt[to]
                if 0 < cnt[to] < t:      # edge v‑to is needed
                    answer += w

    print(answer)


if __name__ == "__main__":
    solve()
```
