We are given a tree with \( n \) nodes, \( m = n - 1 \) edges, and a set of \( t \) core nodes.  
We need to connect all core nodes with minimum total edge weight.  

This is equivalent to finding the **minimum Steiner tree** for the given terminals in a tree — but since the graph is already a tree, the minimal connected subgraph containing all terminals is the union of all simple paths between them crouched into one minimal subtree. The cost is simply the sum of weights of all edges that lie on any path between any two terminalscj.  

A standard approach: mark all core nodes, do DFS to find which edges lie on paths between core nodes-menu. We can compute it by walking from each core node in a post-order and only keeping edges that lead to at least one core node in both directions.  

Simpler approach:  
- With just 1 core, answer is 0.  
- Otherwise, “compress” the tree: remove non-core leaves recursively until only the minimal subtree connecting all cores remains News. The sum of remaining edges is the answer.  

Since \( n \) can be up to 200,000, O(n) is needed.  

Implementation details:  
- Build adjacency list.  
- Compute degrees.  
- Use a queue to remove leaves that are **not** core nodes.  
- When a leaf is removed, decrement degree of its neighbor. If that neighbor becomes a leaf and is non-core, push it too.  
- Remaining edges (original total minus removed edges) compose the minimal subtree. Sum of remaining edges = answer.  

We need to be careful: when we remove an edge, we add its weight to a `removed` sum; answer = total_weight - removed_sum.  

Let’s code.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m, t = map(int, input().split())
core = set(map(int, input().split()))

adj = [[] for _ in range(n + 1)]
total_weight = 0
deg = [0] * (n + 1)

for _ in range(m):
    u, v, w = map(int, input().split())
    adj[u].append((v, w))
    adj[v].append((u, w))
    total_weight += w
    deg[u] += 1
    deg[v] += 1

if t == 1:
    print(0)
    sys.exit()

removed = 0
in_queue = [False] * (n + 1)
q = deque()

for i in range(1, n + 1):
    if deg[i] == 1 and i not in core:
        q.append(i)
        in_queue[i] = True

while q:
    u = q.popleft()
    for v, w in adj[u]:
        if not in_queue[v]:
            removed += w
            deg[v] -= 1
            if deg[v] == 1 and v not in core:
                q.append(v)
                in_queue[v] = True

print(total_weight - removed)
```
