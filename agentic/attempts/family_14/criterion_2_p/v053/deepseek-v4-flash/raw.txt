We are given a tree (since m = n - 1 and all nodes are connected if all edges are used).  
We need the minimum total weight such that all marked nodes (`t` of them) are in the same connected component.

This is the **Steiner tree problem on a tree**, which can be solved simply:  
- Take all marked nodes.  
- The minimal subgraph connecting them is the union of all edges on the paths between them.  
- Equivalent: **find the minimal subtree that connects all terminals** — which is the full tree restricted to the minimal set of edges that connect those terminals.

We can solve this by:
1. Removing all “useless” leaves that are not marked nodes, iteratively.
2. Sum the weights of the remaining edges.

This is O(n) with a queue (leaf pruning).

Implementation approach:
- Build adjacency with edge weights.
- deg[i] = degree.
- is_terminal[i] = True if fragment is one of the special ones.
- Put all leaf nodes that are *not* terminal into queue.
- While queue not empty:
  - pop leaf
  - mark as removed
  - subtract 1 from neighbor degree, and add edge weight to answer when removing (since we are cutting that edge).
  - if neighbor becomes a leaf and is not terminal, push to queue.
- At the end, `ans` is total weight of edges we removed (from the pruned part). But we want the remaining tree cost, so total_weight_all_edges - removed_weight.

Actually easier: start with all edges in the tree, remove all edges that are pruned, answer is sum of weights of edges that remain.  
We can start `total_weight = sum(all edges)` and subtract weights as we prune. Let's do that.

Careful: We should not count edges that connect to removed nodes twice — but since each edge is considered only when we remove one endpoint (the leaf being removed) and because we don't revisit, it's fine.

Let’s code.

```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    terminals = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    total_weight = 0
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        total_weight += w

    deg = [len(adj[i]) for i in range(n+1)]
    removed = [False]*(n+1)
    q = deque()
    for i in range(1, n+1):
        if deg[i] == 1 and i not in terminals:
            q.append(i)
    
    removed_weight = 0
    while q:
        node = q.popleft()
        if removed[node]:
            continue
        removed[node] = True
        # This node was not a terminal, so it can be removed
        for nb, w in adj[node]:
            if not removed[nb]:
                removed_weight += w
                deg[nb] -= 1
                if deg[nb] == 1 and nb not in terminals:
                    q.append(nb)
    
    print(total_weight - removed_weight)

if __name__ == "__main__":
    solve()
```
