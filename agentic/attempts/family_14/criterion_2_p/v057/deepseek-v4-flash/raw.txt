We can solve this by finding the minimal subtree that connects all flagged nodes.  
Since the graph is a tree, the minimal connected subgraph containing all flagged nodes is the union of paths between them, which is the **Steiner tree** in a tree — and that’s simply the minimal subtree spanning all flagged nodes.

We can compute it as follows:

1. Mark all flagged nodes.
2. Do a DFS from any flagged node to find the farthest flagged node (this gives one endpoint of the diameter of the flagged set).
3. From that endpoint, do another DFS to find the total weight of the minimal subtree spanning all flagged nodes.  
   The minimal subtree weight = (sum of weights of all edges in the minimal subtree) = (total weight of all edges in the tree that are on paths between flagged nodes).

A known efficient method:  
- Root the tree at any node.  
- For each edge, it is included in the minimal subtree if and only if both sides contain at least one flagged node.  
- So we can compute subtree flagged counts via DFS and sum weights of edges where `count > 0` and `t - count > 0`.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    flagged = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    # DFS to count flagged nodes in subtree and sum weights of necessary edges
    parent = [0] * (n + 1)
    parent_weight = [0] * (n + 1)
    order = []
    stack = [1]
    parent[1] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v != parent[u]:
                parent[v] = u
                parent_weight[v] = w
                stack.append(v)
    
    sub_count = [0] * (n + 1)
    for u in flagged:
        sub_count[u] = 1
    
    total = 0
    for u in reversed(order):
        if u != 1:
            if sub_count[u] > 0 and t - sub_count[u] > 0:
                total += parent_weight[u]
            if parent[u] != -1:
                sub_count[parent[u]] += sub_count[u]
    
    print(total)

if __name__ == "__main__":
    solve()
```
