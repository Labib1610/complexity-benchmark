We are given a tree (since m = n − 1 and it’s connected), and we need to connect all required nodes.  
The minimal subgraph connecting a set of required nodes in a tree is the **Steiner tree** on those nodes, which in a tree is simply the union of all edges on paths between required nodes.  

So the solution is:

1. Mark required nodes.
2. Do a DFS/BFS from any required node to compute the total weight of edges that are on paths between required nodes.
3. The minimal cost is the sum of weights of edges that have required nodes in both sides when removed.

We can do this with a DFS that returns whether a subtree contains any required node, and add edge weight if both sides contain required nodes.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    required = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    # pick any required node as root
    root = next(iter(required))
    
    total_cost = 0
    
    def dfs(u, parent):
        nonlocal total_cost
        has_required = u in required
        for v, w in adj[u]:
            if v == parent:
                continue
            child_has = dfs(v, u)
            if child_has and (t - child_has > 0):
                total_cost += w
            has_required |= child_has
        return has_required
    
    dfs(root, -1)
    print(total_cost)

if __name__ == "__main__":
    solve()
```
