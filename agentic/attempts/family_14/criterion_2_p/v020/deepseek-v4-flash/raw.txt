We are given a tree (since m = n − 1 and the structure is connected with exactly one path between any two nodes).  
We need to connect all **t** marked nodes into one connected subgraph, minimizing the total edge weight used.

This is equivalent to finding the **minimum Steiner tree** for the marked nodes in a tree.  
In a tree, the minimal Steiner tree is simply the union of all paths between the marked nodes.  
The total weight of that union can be computed as:

- Take the whole tree’s total weight.
- Remove the edges that are **not** on any path between marked nodes.

A standard way:  
1. Mark the required nodes.  
2. Do a DFS from any marked node, and compute for each edge whether it is needed (i.e., both sides contain at least one marked node).  
3. Sum the weights of needed edges.

Implementation plan:
- Build adjacency list.
- DFS from any marked node (say first in list).
- For each edge, if the subtree below contains at least one marked node and the rest of the tree also contains at least one marked node, then this edge is needed.
- Sum weights of needed edges.

Complexity: O(n).

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    marked = set(map(int, input().split()))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    if t <= 1:
        print(0)
        return
    
    # DFS to count marked nodes in subtree and sum needed edges
    visited = [False] * n
    total = 0
    
    def dfs(u, parent):
        nonlocal total
        visited[u] = True
        cnt = 1 if u in marked else 0
        for v, w in adj[u]:
            if v == parent:
                continue
            child_cnt = dfs(v, u)
            if child_cnt > 0 and (t - child_cnt) > 0:
                total += w
            cnt += child_cnt
        return cnt
    
    start = next(iter(marked))
    dfs(start, -1)
    print(total)

if __name__ == "__main__":
    solve()
```
