We are given a tree (since \( m = n-1 \) and all nodes are connected when all edges are on).  
We need to connect all *critical* nodes with the minimum total edge weight.  
This is exactly the **Steiner tree** problem on a tree, which has a simple solution:  
Take the minimal subtree that connects all critical nodes, and sum the weights of its edges.

**Approach:**
1. Mark critical nodes.
2. Do a DFS/BFS from any critical node to find which edges are necessary.
3. An edge is necessary if removing it separates at least one critical node from the others — equivalently, if both sides of the edge contain at least one critical node.
4. Sum weights of all such edges.

We can do this with a DFS that returns the number of critical nodes in the subtree.  
If a subtree contains at least one critical node and the rest of the tree also contains at least one critical node, then the edge to that subtree is needed.

**Implementation details:**
- Use iterative DFS to avoid recursion depth issues (n up to 200,000).
- Build adjacency list with (neighbor, weight).
- Root the tree at any critical node.
- Compute subtree critical counts.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    critical = set(map(int, input().split()))
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    # Root at any critical node
    root = next(iter(critical))
    
    parent = [0]*(n+1)
    parent_edge_weight = [0]*(n+1)
    order = []
    stack = [root]
    parent[root] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v != parent[u]:
                parent[v] = u
                parent_edge_weight[v] = w
                stack.append(v)
    
    # Count critical nodes in subtree
    sub_crit = [0]*(n+1)
    for u in order[::-1]:
        if u in critical:
            sub_crit[u] += 1
        if parent[u] > 0:
            sub_crit[parent[u]] += sub_crit[u]
    
    total_cost = 0
    for u in range(2, n+1):
        if sub_crit[u] > 0 and sub_crit[u] < t:
            total_cost += parent_edge_weight[u]
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
