We are given a tree (since m = n - 1 and it's connected), and we need to connect all priority nodes.  
The minimal subgraph connecting a set of nodes in a tree is the **Steiner tree** for those nodes, which in a tree is simply the union of all edges on paths between the priority nodes.

A standard way to compute this is:

1. Mark all priority nodes.
2. Do a DFS/BFS from any priority node, and count edges that are on a path between two priority nodes.
3. An edge is needed if removing it separates the tree into two parts, each containing at least one priority node.

We can compute this efficiently using a DFS that returns the number of priority nodes in the subtree. If a subtree contains at least one priority node and the rest of the tree also contains at least one priority node, then the edge connecting them is needed.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    priority = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    if t <= 1:
        print(0)
        return
    
    visited = [False] * (n + 1)
    total_cost = 0
    
    def dfs(u):
        visited[u] = True
        cnt = 1 if u in priority else 0
        for v, w in adj[u]:
            if not visited[v]:
                sub = dfs(v)
                if sub > 0 and sub < t:
                    total_cost += w
                cnt += sub
        return cnt
    
    # start from any priority node
    start = next(iter(priority))
    dfs(start)
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
