We are given a tree (since \( m = n-1 \) and there is exactly one path between any two endpoints).  
We need to connect all essential nodes into one connected component, minimizing the sum of edge weights we keep.

This is equivalent to finding the **minimum Steiner tree** in a tree, where the terminals are the essential nodes.  
In a tree, the minimal Steiner tree is simply the union of all paths between the essential nodes.  
That means we keep an edge if and only if it lies on the path between at least two essential nodes.

So the algorithm is:

1. Root the tree at any essential node.
2. Perform DFS to compute for each node whether its subtree contains any essential node.
3. An edge (parent → child) is needed if the child’s subtree contains at least one essential node **and** there is at least one essential node outside that subtree.  
   Equivalently, if the child’s subtree contains at least one essential node and the total number of essential nodes is greater than the number in that subtree.
4. Sum the weights of all such edges.

If there is only one essential node, the answer is 0.

Let’s implement this efficiently with iterative DFS to avoid recursion depth issues.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    essential = set(map(int, input().split()))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    if t == 1:
        print(0)
        return
    
    # Root at any essential node
    root = next(iter(essential))
    
    parent = [-1] * n
    parent_edge_weight = [0] * n
    order = []
    stack = [root]
    parent[root] = root
    
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            parent_edge_weight[v] = w
            stack.append(v)
    
    essential_count = [0] * n
    for e in essential:
        essential_count[e] = 1
    
    total_cost = 0
    # Process in reverse order (post-order)
    for u in reversed(order):
        if u != root:
            if essential_count[u] > 0 and essential_count[u] < t:
                total_cost += parent_edge_weight[u]
            # propagate count to parent
            if u != root:
                essential_count[parent[u]] += essential_count[u]
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
