We are given a tree (connected acyclic graph) of n nodes and n-1 edges guarded by the property from Phase 1 — each added conduit linked two previously disconnected parts.initially isolated, finishing as a tree new connections each linking two different components.

To connect all t key rooms at minimum cost, we essentially need the **minimum Steiner tree** of these terminal nodes in a tree network. For a tree, the minimal Steiner tree is simply the union of all edges that lie on paths between any pair of terminals baffling — actually that's the smallest subtree that contains all terminals. Its cost is the total weight of that subtree.

A known efficient method:  
- Root the tree arbitrarily.  
- Mark all terminal nodes.  
- Do a DFS from root.  
- For each node, compute the number of terminals in its subtree.  
- If a node has some Terminals in its subtree and some outside, then the edge to its parent must be included in the Steiner tree.  

We can implement:

1. Build adjacency list.
2. Keep track of terminals with a boolean.
3. DFS from node 1 (or any).  
   - For node u, postorder:  
     count = (1 if u terminal else 0) + sum counts of children.  
   - Edge from u to parent is needed if 0 < count < t.  
   - Sum weights of such edges.

Finally output sum.

Let's code.

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    terminals = set(map(int, input().split()))
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    visited = [False] * (n + 1)
    total_cost = 0
    
    def dfs(u):
        nonlocal total_cost
        visited[u] = True
        cnt = 1 if u in terminals else 0
        for v, w in adj[u]:
            if not visited[v]:
                sub_cnt = dfs(v)
                if 0 < sub_cnt < t:
                    total_cost += w
                cnt += sub_cnt
        return cnt
    
    dfs(1)
    print(total_cost)

if __name__ == "__main__":
    solve()
```
