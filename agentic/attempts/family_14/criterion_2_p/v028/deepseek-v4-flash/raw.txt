We are given a tree (since m = n − 1 and exactly one path between any two nodes).  
We need to connect all spore-containing nodes with minimal total edge cost.  
This is equivalent to finding the **minimum Steiner tree** for the set of terminals (spore nodes) in a tree, which is simply the union of all paths between terminals.  

A known efficient method:  
- Mark all spore nodes.  
- Do a DFS/BFS to remove all subtrees that contain no spore nodes.  
- The remaining edges are exactly those needed.  
- Sum their weights.  

We can implement this with a post-order traversal to check if a subtree contains any spore node.  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    spores = set(map(int, input().split()))
    
    adj = [[] for _ in range(n)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    # If only one spore, no edges needed
    if t == 1:
        print(0)
        return
    
    visited = [False] * n
    has_spore = [False] * n
    total_cost = 0
    
    # DFS to mark which nodes are in the minimal subtree
    def dfs(u, parent):
        nonlocal total_cost
        visited[u] = True
        if u in spores:
            has_spore[u] = True
        for v, w in adj[u]:
            if v == parent:
                continue
            dfs(v, u)
            if has_spore[v]:
                has_spore[u] = True
                total_cost += w
    
    # Start from any spore node
    start = next(iter(spores))
    dfs(start, -1)
    
    print(total_cost)

if __name__ == "__main__":
    solve()
```
