We can solve this by noting the graph is a tree.  
We only need to connect the marked nodes (organic signatures).  
The minimal set of edges to connect them is the **Steiner tree** on those nodes, which in a tree reduces to the union of all paths between marked nodes.  

We can find the minimal subtree by:

1. Mark the required nodes.
2. Do a DFS from any marked node to find the farthest marked node (call it A).
3. Do a DFS from A to find the farthest marked node (call it B) and also compute the total weight of the path between A and B.
4. The minimal total weight is the sum of all edges in the minimal subtree, which equals:  
   `total_weight_of_all_edges_in_subtree = (sum_of_edges_in_path_A_B + sum_of_edges_in_path_A_B) / 2`?  
   Actually, the correct formula:  
   The minimal subtree is the union of all paths between marked nodes.  
   Its total edge weight = `(sum of all edges in the tree that are in the minimal subtree)`.  
   We can compute it by doing DFS from A, summing edges that lead to any marked node, but excluding the path to B?  
   A simpler method:  
   - Find the diameter of the set of marked nodes (in terms of edge weight).  
   - The minimal subtree weight = `total_weight_of_all_edges_in_original_tree_that_are_in_subtree`.  
   But we can compute directly:  
   - Do DFS from A, sum all edges that are on paths to marked nodes, but subtract the path A–B once (since it's counted twice in the DFS sum).  

Let’s implement:

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    marked = set(map(int, input().split()))
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    if t == 1:
        print(0)
        return
    
    # DFS to find farthest marked node and distance
    def dfs(u, parent):
        farthest_node = u
        farthest_dist = 0
        for v, w in adj[u]:
            if v == parent:
                continue
            fn, fd = dfs(v, u)
            if fd + w > farthest_dist:
                farthest_dist = fd + w
                farthest_node = fn
        return farthest_node, farthest_dist
    
    # First DFS from any marked node
    start = next(iter(marked))
    A, _ = dfs(start, -1)
    
    # Second DFS from A to find B and also compute total subtree weight
    # We'll compute sum of all edges that are in the minimal subtree.
    # Approach: DFS from A, sum all edges that lead to any marked node.
    # But we need to avoid double counting the path A-B.
    # So we'll do: total = sum of all edges in minimal subtree.
    # We can compute by DFS from A, summing edges that are on paths to marked nodes,
    # then subtract the path A-B once.
    
    # First, find B and the distance A-B
    parent = [-1]*(n+1)
    dist = [0]*(n+1)
    stack = [(A, -1, 0)]
    while stack:
        u, p, d = stack.pop()
        parent[u] = p
        dist[u] = d
        for v, w in adj[u]:
            if v == p:
                continue
            stack.append((v, u, d+w))
    
    B = A
    maxd = 0
    for node in marked:
        if dist[node] > maxd:
            maxd = dist[node]
            B = node
    
    # Now compute total weight of minimal subtree.
    # We'll do DFS from A, sum edges that lead to marked nodes.
    # But we need to subtract the path A-B once.
    # We can compute sum of all edges in minimal subtree = 
    # (sum of distances from A to all marked nodes) * 2 - (sum of distances between marked nodes in a certain way)
    # Actually easier: 
    # The minimal subtree is the union of paths from A to all marked nodes.
    # Its total weight = sum of distances from A to all marked nodes * 2 - sum of distances between consecutive marked nodes in DFS order? 
    # That's for general graphs, but for tree we can do:
    # total = sum of all edges in minimal subtree.
    # We can compute by DFS from A, summing edges that are on paths to marked nodes.
    # Then subtract the path A-B once (since it's counted twice in the DFS sum).
    
    # Let's do DFS from A, sum edges that lead to marked nodes.
    total = 0
    def dfs2(u, p):
        nonlocal total
        has_marked = u in marked
        for v, w in adj[u]:
            if v == p:
                continue
            child_has = dfs2(v, u)
            if child_has:
                total += w
            has_marked = has_marked or child_has
        return has_marked
    
    dfs2(A, -1)
    
    # Now subtract the path A-B once
    # We can compute path A-B weight
    path_weight = 0
    node = B
    while node != A:
        p = parent[node]
        # find weight between node and p
        for v, w in adj[node]:
            if v == p:
                path_weight += w
                break
        node = p
    
    result = total - path_weight
    print(result)

if __name__ == "__main__":
    solve()
```
