 We need the minimum total weight of edges to connect all given priority nodes.  
Since the graph is a tree, the minimal subgraph connecting a set of nodes is the **Steiner tree** in a tree, which is simply the union of all paths between the priority nodes.  

The total weight of that union can be computed as:  
- Take the whole tree, sum all edge weights.  
- Remove all edges that are not on any path between two priority nodes.  

A standard way:  
- Mark all priority nodes.  
- Do a DFS from any node, count how many priority nodes are in each subtree.  
- An edge is needed if both sides contain at least one priority node.  

If `t == 1`, the answer is `0` because no links are needed.  

Here’s the implementation:  

```python
import sys
sys.setrecursionlimit(300000)

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    priority = set(map(int, input().split()))
    
    adj = [[] for _ in range(n + 1)]
    edges = []
    for _ in range(m):
        u, v, w = map(int, input().split())
        adj[u].append((v, w))
        adj[v].append((u, w))
        edges.append((u, v, w))
    
    if t == 1:
        print(0)
        return
    
    parent = [0] * (n + 1)
    parent_weight = [0] * (n + 1)
    order = []
    stack = [1]
    parent[1] = -1
    while stack:
        u = stack.pop()
        order.append(u)
        for v, w in adj[u]:
            if v != parent[u]:
                parent[v] = u
                parent_weight[v] = w
                stack.append(v)
    
    count = [0] * (n + 1)
    for node in priority:
        count[node] = 1
    
    total = 0
    for u in reversed(order):
        if u != 1:
            if count[u] > 0 and (t - count[u]) > 0:
                total += parent_weight[u]
            if parent[u] != -1:
                count[parent[u]] += count[u]
    
    print(total)

if __name__ == "__main__":
    solve()
```
