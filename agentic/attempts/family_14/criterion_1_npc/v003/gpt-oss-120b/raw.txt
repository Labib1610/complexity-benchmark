**Solution Explanation**

For the given undirected weighted graph we have to connect a set `R` of  
`t ≤ 10` *required* vertices.  
Other vertices may be used – they are ordinary *Steiner* vertices.
The task is the classical **Steiner Tree in graphs** with a very small
terminal set, therefore a DP over subsets of terminals works fast enough.

--------------------------------------------------------------------

#### 1.   Notation  

* `n` – number of vertices, indexed `0 … n‑1`
* `adj[v]` – list of pairs `(to , w)` : undirected edges
* `term[i]` – the `i`‑th required vertex (`i = 0 … t‑1`)
* `FULL = (1<<t)‑1` – bitmask with all required vertices set
* `dp[mask][v]` – minimal total cost of a connected sub‑graph

  * that contains **all terminals whose bits are set in `mask`**
  * and whose **rightmost (chosen) vertex is `v`**  
    (the whole sub‑graph is allowed to contain more vertices).

The answer is `min_v dp[FULL][v]`.

--------------------------------------------------------------------

#### 2.   Initialisation  

For a mask that contains exactly one terminal `i`

```
dp[ 1<<i ][ term[i] ] = 0          # no edge needed
```

All other entries are `INF`.

--------------------------------------------------------------------

#### 3.   DP transition – merging two already built parts  

Assume we already know optimal sub‑graphs for two disjoint masks
`sub` and `mask ^ sub` which end at the **same** vertex `v`.  
Joining those two sub‑graphs at `v` yields a sub‑graph for `mask`.

```
dp[mask][v] = min( dp[sub][v] + dp[mask^sub][v] )
```

All proper non‑empty sub‑masks are examined.
The loop

```
sub = (mask-1) & mask
while sub:
        other = mask ^ sub
        …
        sub = (sub-1) & mask
```

enumerates each of them exactly once.

--------------------------------------------------------------------

#### 4.   DP transition – travelling through ordinary edges  

After the merging step `dp[mask][*]` may still be improved by adding
ordinary edges.  
That is a **multi‑source Dijkstra**: every vertex `v` with a finite
`dp[mask][v]` is a source with distance `dp[mask][v]`.

Running Dijkstra gives the cheapest way to move the end vertex over
the graph, i.e. the optimal `dp[mask][*]` for this mask.

Because all `dp[sub][*]` for smaller masks are already final
(the algorithm processes masks in increasing order), the result of
the Dijkstra step is also final.

--------------------------------------------------------------------

#### 5.   Whole algorithm  

```
for mask = 1 … FULL:
        # 1) merge two smaller masks
        for every proper non‑empty submask of mask:
                for every vertex v:
                        dp[mask][v] = min( dp[mask][v],
                                           dp[sub][v] + dp[mask^sub][v] )
        # 2) propagate through edges (multi‑source Dijkstra)
        run Dijkstra with initial distances dp[mask][*]
answer = min_v dp[FULL][v]
```

`n ≤ 100`, `t ≤ 10`

* Number of masks: `2^t ≤ 1024`
* Number of submask pairs for a fixed mask: `2^{|mask|-1}` → total
  `O(3^t)` ≈ 59 k for `t = 10`
* Dijkstra per mask: `O( (n+m) log n )`, with `n = 100` tiny.

Overall well below the limits.

--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total cost.

---

##### Lemma 1  
For every mask and vertex `v` after the Dijkstra step
`dp[mask][v]` equals the minimum cost of a connected sub‑graph that

* contains all terminals of `mask`,
* its **rightmost** (chosen) vertex is `v`.

**Proof.**  
Induction over the order in which masks are processed.

*Base* (`mask` is a power of two).  
Only one terminal `r` belongs to the mask.
Before Dijkstra `dp[mask][r]=0`, all other vertices are `INF`.  
Running multi‑source Dijkstra computes exactly the shortest paths
from `r` to every vertex, i.e. the cheapest way to connect `r` with `v`
using any intermediate vertices – precisely the definition.

*Induction step.*  
Assume the statement holds for all proper sub‑masks of `mask`.  
Before Dijkstra the algorithm performed the merging step.
For any vertex `v`

```
dp_merge = min_{sub} ( dp[sub][v] + dp[mask^sub][v] )
```

By induction hypothesis each term is the cheapest cost of a sub‑graph
realising the respective sub‑mask and ending at `v`.  
The union of those two sub‑graphs (they share `v`) is a connected
sub‑graph that realises the whole `mask` and ends at `v`,
hence `dp_merge` is an upper bound on the optimum.

Conversely, let `S` be an optimal sub‑graph for `mask` ending at `v`.
Remove vertex `v`; the remaining edges split into two (possibly empty)
connected components whose terminal sets form a partition of `mask`
into `sub` and `mask^sub`.  
Both components end at `v` as well (they are attached to `v` by at least
one edge). Hence their costs are at least `dp[sub][v]` and
`dp[mask^sub][v]`.  
So `cost(S) ≥ dp[sub][v] + dp[mask^sub][v]` for that partition,
and consequently `cost(S) ≥ dp_merge`.  
Thus `dp_merge` is exactly the optimum *before* expanding through edges.

Now Dijkstra starts from every vertex `v` with distance `dp_merge[v]`
and relaxes edges with their weights.  
The standard correctness of Dijkstra shows that after it finishes,
for every vertex `u` the stored distance is the cheapest
**path** that starts at some vertex `v` (paying `dp_merge[v]`) and ends at
`u`. Adding that path to the optimal sub‑graph for `mask` ending at `v`
produces a connected sub‑graph for `mask` ending at `u` with exactly the
new distance, and no cheaper one exists.
∎



##### Lemma 2  
After processing all masks, for the full mask `FULL` and any vertex `v`,
`dp[FULL][v]` equals the minimum possible cost of a connected sub‑graph
that contains **all required vertices** and whose rightmost vertex is `v`.

**Proof.** Directly Lemma&nbsp;1 with `mask = FULL`. ∎



##### Lemma 3  
`min_v dp[FULL][v]` equals the minimum possible total cost of a set of
edges that connects all required vertices (the Steiner tree cost).

**Proof.**  
Any feasible solution is a connected sub‑graph containing all required
vertices; pick any vertex of this sub‑graph as the rightmost vertex `v`.
Its cost is at least `dp[FULL][v]` by Lemma&nbsp;2, therefore at
least `min_v dp[FULL][v]`.

Conversely, for the vertex `v*` attaining the minimum,
Lemma&nbsp;2 guarantees a connected sub‑graph of cost `dp[FULL][v*]`
that contains all required vertices, i.e. a feasible solution of that
cost. ∎



##### Theorem  
The algorithm outputs the minimum total cost needed to integrate all
required sites.

**Proof.**  
By Lemma&nbsp;3 the algorithm’s output equals the optimum cost.
∎



--------------------------------------------------------------------

#### 7.   Complexity Analysis  

*`T = 2^t ≤ 1024`*, `n ≤ 100`, `m ≤ n·(n‑1)/2 ≤ 4950`

* Merging step:  
  `∑_{mask} ( number of submasks ) · n = O(3^t · n) ≤ 6·10^6`
* Dijkstra per mask: `O( (n+m) log n )`  
  ≈ `O(5·10^3 log 100)` ≈ `3·10^4` operations per mask →  
  total `≈ 3·10^7`, well inside 5 s.

Memory: `dp` array – `T · n ≤ 1.0·10^5` integers.

--------------------------------------------------------------------

#### 8.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10 ** 18

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))

    required = [int(next(it)) - 1 for _ in range(t)]

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    full = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    # initialise single‑terminal masks
    for i, v in enumerate(required):
        dp[1 << i][v] = 0

    # process masks increasingly
    for mask in range(1, full + 1):
        # combine two smaller masks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other:
                row_sub = dp[sub]
                row_oth = dp[other]
                row_mask = dp[mask]
                for v in range(n):
                    val = row_sub[v] + row_oth[v]
                    if val < row_mask[v]:
                        row_mask[v] = val
            sub = (sub - 1) & mask

        # multi‑source Dijkstra for this mask
        heap = []
        row = dp[mask]
        for v in range(n):
            if row[v] < INF:
                heap.append((row[v], v))
        heapq.heapify(heap)

        while heap:
            d, v = heapq.heappop(heap)
            if d != row[v]:
                continue
            for to, w in adj[v]:
                nd = d + w
                if nd < row[to]:
                    row[to] = nd
                    heapq.heappush(heap, (nd, to))

    ans = min(dp[full])
    print(ans)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
