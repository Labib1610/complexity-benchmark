**Solution Explanation**

For the given undirected weighted graph we have to choose a set of edges (the hired
experts) of minimum total weight such that all `t` *terminal* vertices (the focal
dialects) become connected.
The problem is exactly the **Steiner Tree** problem with a very small number of
terminals (`t ≤ 10`).  
The classic DP over subsets solves it in `O( 3^t · n + 2^t · (n log n + m) )`,
which is easily fast for `n ≤ 100`.

--------------------------------------------------------------------

#### 1.   Notation  

* `n` – number of vertices, numbered `1 … n`  
* `m` – number of edges, each edge `u‑v` has weight `w`  
* `term[0 … t-1]` – the terminal vertices (all different)  
* `FULL = (1<<t) - 1` – bitmask with all terminals set  

`adj[v]` – list of pairs `(to, weight)`.

--------------------------------------------------------------------

#### 2.   DP definition  

`dp[mask][v]` – minimal total weight of a sub‑graph that

* connects exactly the terminals whose bits are set in `mask`,
* and **ends** at vertex `v` (i.e. `v` belongs to that sub‑graph).

The answer will be  

```
min_v dp[FULL][v]
```

--------------------------------------------------------------------

#### 3.   Initialisation  

For every terminal `i` (its vertex `term[i]`)  

```
dp[1<<i][ term[i] ] = 0
```

All other entries are initialised with `INF`.

--------------------------------------------------------------------

#### 4.   DP transition – merging two smaller masks  

For a fixed `mask` and a vertex `v`

```
dp[mask][v] = min over non‑empty proper submask s of mask
              ( dp[s][v] + dp[mask ^ s][v] )
```

Both sub‑trees already end in the same vertex `v`; joining them does not need
any extra edge.

The loop over all submasks of a mask runs in `O(2^popcount(mask))`.  
Overall complexity of this part is `O(3^t · n)` – well below the limits.

--------------------------------------------------------------------

#### 5.   DP transition – spreading through the graph  

After the merging step `dp[mask][*]` contains the best costs **when the tree
already ends at each vertex**.  
Now we have to allow the tree to *grow* along graph edges.

For a fixed `mask` we run a multi‑source Dijkstra:

* every vertex `v` is inserted into the priority queue with initial distance
  `dp[mask][v]`;
* usual relaxation `dist[u] + w < dist[v]` updates `dp[mask][v]`.

After Dijkstra finishes, `dp[mask][v]` is the cheapest cost of a tree that
connects the terminals of `mask` and ends at `v`, possibly using any other
vertices as intermediate Steiner points.

Complexity per mask: `O( (n+m) log n )`.  
With at most `2^t ≤ 1024` masks this is easily fast.

--------------------------------------------------------------------

#### 6.   Whole algorithm  

```
read input
build adjacency list
if t == 1: print 0 and exit

INF = 10**18
dp = [ [INF]* (n+1) for _ in range(1<<t) ]

# 1) initialise single terminals
for i, v in enumerate(term):
    dp[1<<i][v] = 0

# 2) iterate over all masks increasing
for mask in range(1, 1<<t):
    # 2a) merge smaller masks
    sub = (mask-1) & mask
    while sub:
        other = mask ^ sub
        # both sub and other are non‑empty
        for v in range(1, n+1):
            cand = dp[sub][v] + dp[other][v]
            if cand < dp[mask][v]:
                dp[mask][v] = cand
        sub = (sub-1) & mask

    # 2b) Dijkstra to propagate through edges
    # multi‑source: start distances = dp[mask][*]
    import heapq
    heap = []
    dist = dp[mask]          # we will update this list in‑place
    for v in range(1, n+1):
        heapq.heappush(heap, (dist[v], v))

    while heap:
        d, v = heapq.heappop(heap)
        if d != dist[v]:
            continue
        for to, w in adj[v]:
            nd = d + w
            if nd < dist[to]:
                dist[to] = nd
                heapq.heappush(heap, (nd, to))

# 3) answer
ans = min(dp[FULL][1:])   # vertices are 1‑based
print(ans)
```

All operations use 64‑bit integers (`int` in Python is unbounded).

--------------------------------------------------------------------

#### 7.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total funding.

---

##### Lemma 1  
For any `mask` and vertex `v`, after the Dijkstra step finishes,
`dp[mask][v]` equals the minimum weight of a connected subgraph that

* contains all terminals of `mask`,
* contains vertex `v`,
* and whose total weight is the sum of its edges.

**Proof.**  
Initially (before Dijkstra) `dp[mask][v]` is the minimum weight of a tree that
already ends at `v` (by induction on `mask`, see Lemma 2).  
Running Dijkstra with these values as sources computes, for every vertex `x`,
the shortest path distance from any source `v` to `x` **plus** the source’s
current value. Adding a path corresponds exactly to extending the tree by that
path, therefore the resulting value is the cheapest tree that ends at `x`. ∎



##### Lemma 2  
After processing a mask `M` (i.e. after both merging and Dijkstra),
for every vertex `v` the invariant holds:

`dp[M][v]` = minimum weight of a tree that connects exactly the terminals of `M`
and ends at `v`.

**Proof by induction over the number of bits in `M`.**

*Base* – `|M| = 1`.  
`dp[1<<i][term[i]] = 0` (empty tree) and all other vertices are `INF`.  
The statement is true.

*Induction step.*  
Assume the statement true for all proper non‑empty subsets of `M`.  
First we consider the merging loop. For any split `M = A ∪ B` with `A∩B=∅`,
the tree formed by the optimal tree for `A` ending at `v` and the optimal tree
for `B` ending at the same `v` has total weight `dp[A][v] + dp[B][v]`.  
Taking the minimum over all splits yields the cheapest tree that connects all
terminals of `M` **and already ends at `v`** (but possibly uses extra edges
inside the two parts). Thus after the merging loop the invariant holds *before*
spreading through the graph.

Applying Lemma 1 (Dijkstra) expands the tree by arbitrary paths, which is exactly
the operation of allowing additional vertices and edges while still ending at
`v`. Consequently the invariant also holds after Dijkstra. ∎



##### Lemma 3  
For the full mask `FULL`, `min_v dp[FULL][v]` equals the weight of a minimum
Steiner tree connecting all terminals.

**Proof.**  
By Lemma 2, for each vertex `v` the value `dp[FULL][v]` is the cheapest tree
that connects all terminals and ends at `v`. Any Steiner tree has some vertex
as its “last” vertex, therefore its weight appears among those values.
Conversely, the minimum of those values is a feasible tree, hence its weight
cannot be larger than the optimum. ∎



##### Theorem  
The algorithm outputs the minimum possible total funding required to unify all
focal dialects.

**Proof.**  
The algorithm computes `dp` exactly as described. By Lemma 3 the printed value
is the weight of a minimum Steiner tree, which corresponds precisely to the
minimum total cost of hiring experts that make all focal dialects mutually
translatable. ∎



--------------------------------------------------------------------

#### 8.   Complexity Analysis  

*Number of masks*: `2^t ≤ 1024`  

*Merge step*: `O(3^t · n) ≤ 6·10^4 · 100 = 6·10^6` operations.  

*Dijkstra per mask*: `O((n+m) log n)` → at most `O( (100+4950)·7 ) ≈ 3.5·10^4`.  
Times `2^t` masks → ≤ `3.5·10^7`.  

Both time and memory (`dp` array size `2^t·(n+1) ≤ 1024·101 ≈ 1e5`) fit easily
into the limits.

#### 9.   Reference Implementation  (Python 3)

```python
import sys
import heapq

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    terminals = [int(next(it)) for _ in range(t)]

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it)); w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    if t == 1:
        print(0)
        return

    FULL = (1 << t) - 1
    INF = 10 ** 18
    dp = [[INF] * (n + 1) for _ in range(1 << t)]

    # initialise single terminals
    for i, v in enumerate(terminals):
        dp[1 << i][v] = 0

    # iterate over all masks
    for mask in range(1, 1 << t):
        # merge smaller subsets
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other:  # both non‑empty
                dpm = dp[mask]
                dps = dp[sub]
                dpo = dp[other]
                for v in range(1, n + 1):
                    cand = dps[v] + dpo[v]
                    if cand < dpm[v]:
                        dpm[v] = cand
            sub = (sub - 1) & mask

        # Dijkstra to propagate through edges
        dist = dp[mask]
        heap = [(dist[v], v) for v in range(1, n + 1)]
        heapq.heapify(heap)

        while heap:
            d, v = heapq.heappop(heap)
            if d != dist[v]:
                continue
            for to, w in adj[v]:
                nd = d + w
                if nd < dist[to]:
                    dist[to] = nd
                    heapq.heappush(heap, (nd, to))

    answer = min(dp[FULL][1:])
    print(answer)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to
the required input‑output format.
