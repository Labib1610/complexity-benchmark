 We can solve this by using a **minimum Steiner tree** approach, but since \( t \leq 10 \), we can use a **DP over subsets** combined with shortest paths.

Here’s the plan:

1. Compute all-pairs shortest paths between all nodes (Floyd–Warshall or Dijkstra from each node).
2. Let the primary nodes be indexed 0..t-1.
3. Use DP:  
   `dp[mask][i]` = minimum cost to connect the primary nodes in `mask`, with the tree rooted at node `i` (which can be any node, primary or secondary).
4. Initialize `dp[1<<k][primary[k]] = 0` for each primary.
5. Transition:
   - Merge two subsets: `dp[mask][i] = min(dp[mask][i], dp[sub][i] + dp[mask^sub][i])`
   - Extend to another node: `dp[mask][j] = min(dp[mask][j], dp[mask][i] + dist[i][j])`
6. Answer is `min(dp[(1<<t)-1][i])` for any `i`.

We’ll implement it efficiently.

```python
import sys
import heapq

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    primaries = list(map(int, input().split()))
    primaries = [p-1 for p in primaries]
    
    INF = 10**18
    dist = [[INF]*n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append((v, w))
        adj[v].append((u, w))
    
    # Dijkstra from each node to get all-pairs shortest paths
    for s in range(n):
        d = [INF]*n
        d[s] = 0
        pq = [(0, s)]
        while pq:
            du, u = heapq.heappop(pq)
            if du != d[u]:
                continue
            for v, w in adj[u]:
                nd = du + w
                if nd < d[v]:
                    d[v] = nd
                    heapq.heappush(pq, (nd, v))
        dist[s] = d
    
    # DP over subsets
    full_mask = (1 << t) - 1
    dp = [[INF]*n for _ in range(1 << t)]
    
    for i in range(t):
        dp[1 << i][primaries[i]] = 0
    
    for mask in range(1 << t):
        # Merge subsets
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if sub < other:  # avoid double work
                for i in range(n):
                    dp[mask][i] = min(dp[mask][i], dp[sub][i] + dp[other][i])
            sub = (sub - 1) & mask
        
        # Extend to other nodes
        for i in range(n):
            if dp[mask][i] < INF:
                for j in range(n):
                    if dist[i][j] < INF:
                        nd = dp[mask][i] + dist[i][j]
                        if nd < dp[mask][j]:
                            dp[mask][j] = nd
    
    ans = min(dp[full_mask])
    print(ans)

if __name__ == "__main__":
    solve()
```
