We can solve this by treating it as a **Steiner tree** problem, but since the number of anchors is small (≤ 10), we can use a **bitmask DP** approach.

We first compute the shortest paths between all pairs of nodes using Floyd–Warshall.  
Then we use DP over subsets of anchors:

- `dp[mask][v]` = minimum cost to connect all anchors in `mask` and end at node `v`.
- Initialize: for each anchor `a`, `dp[1 << i][a] = 0`.
- Transition:  
  1. Merge two subsets: `dp[mask1 | mask2][v] = min(dp[mask1][v] + dp[mask2][v])`  
  2. Extend from `v` to `u`: `dp[mask][u] = min(dp[mask][u], dp[mask][v] + dist[v][u])`

Finally, answer is `min(dp[(1<<t)-1][v])` for all `v`.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    anchors = list(map(int, input().split()))
    anchors = [a - 1 for a in anchors]  # 0-based

    INF = 10**18
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w

    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    # DP over subsets
    full_mask = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    for i, a in enumerate(anchors):
        dp[1 << i][a] = 0

    for mask in range(1 << t):
        # Merge subsets
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other < sub:  # avoid duplicate work
                for v in range(n):
                    dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[other][v])
            sub = (sub - 1) & mask

        # Extend to other nodes
        for v in range(n):
            if dp[mask][v] < INF:
                for u in range(n):
                    if dist[v][u] < INF:
                        nd = dp[mask][v] + dist[v][u]
                        if nd < dp[mask][u]:
                            dp[mask][u] = nd

    ans = min(dp[full_mask])
    print(ans)

if __name__ == "__main__":
    solve()
```
