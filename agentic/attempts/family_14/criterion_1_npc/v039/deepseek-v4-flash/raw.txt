We can solve this by treating it as a **Steiner tree** problem, but since the number of critical substations is small (≤ 10), we can use **bitmask DP** over the critical nodes.

Here’s the approach:

1. Run **Floyd–Warshall** to get shortest paths between all pairs of nodes.
2. Let `k = t` (number of critical nodes).  
   We want the minimum cost to connect all `k` critical nodes, possibly using other nodes as relays.
3. Use DP:  
   `dp[mask][v]` = minimum cost to connect the critical nodes in `mask`, ending at node `v` (where `v` can be any node).
4. Initialize `dp[1 << i][critical[i]] = 0` for each critical node.
5. Transition:
   - Combine two disjoint masks: `dp[mask1 | mask2][v] = min(dp[mask1][v] + dp[mask2][v])`
   - Extend from `v` to `u`: `dp[mask][u] = min(dp[mask][u], dp[mask][v] + dist[v][u])`
6. Answer is `min(dp[(1<<k)-1][v])` over all `v`.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    critical = [int(next(it)) - 1 for _ in range(t)]
    
    INF = 10**18
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w
    
    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]
    
    k = t
    full_mask = (1 << k) - 1
    dp = [[INF] * n for _ in range(1 << k)]
    
    for i in range(k):
        dp[1 << i][critical[i]] = 0
    
    for mask in range(1 << k):
        # Combine two submasks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if sub < other:  # avoid double work
                for v in range(n):
                    if dp[sub][v] + dp[other][v] < dp[mask][v]:
                        dp[mask][v] = dp[sub][v] + dp[other][v]
            sub = (sub - 1) & mask
        
        # Relax edges
        for v in range(n):
            if dp[mask][v] < INF:
                for u in range(n):
                    if dist[v][u] < INF:
                        nd = dp[mask][v] + dist[v][u]
                        if nd < dp[mask][u]:
                            dp[mask][u] = nd
    
    ans = min(dp[full_mask])
    print(ans)

if __name__ == "__main__":
    solve()
```
