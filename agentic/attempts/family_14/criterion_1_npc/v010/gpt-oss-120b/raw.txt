**Solution Explanation**

For the given undirected weighted graph we have to choose a set of edges of minimum total
weight such that all *primary* vertices (terminals) become connected.
Vertices that are not terminals may be used – they are ordinary Steiner vertices.
The problem is the classic **Steiner Tree in graphs** with at most  

```
t ≤ 10   terminals
n ≤ 100  vertices
```

The well‑known exact algorithm uses dynamic programming over subsets of terminals
together with Dijkstra’s shortest‑path relaxation.
Its complexity is `O( 3^t · n + 2^t · m log n )`, easily fast for the limits.



--------------------------------------------------------------------

#### 1.   DP definition  

```
mask … bitmask of terminals, 0 … (1<<t)-1
v    … vertex (0‑based)
dp[mask][v] = minimum total weight of a connected subgraph
              that
              • contains vertex v
              • connects exactly the terminals whose bits are set in mask
```

The answer we need is  

```
min_v dp[fullMask][v]          (fullMask = (1<<t)-1)
```

--------------------------------------------------------------------

#### 2.   Initialisation  

For every terminal `i` (its vertex = `term[i]`)  

```
dp[1<<i][ term[i] ] = 0
```

All other entries are `INF`.

--------------------------------------------------------------------

#### 3.   Subset combination  

For a fixed `mask` we may split it into two non‑empty disjoint parts `sub` and `mask^sub`.
If both parts already have optimal trees ending in the same vertex `v`,
their union is a feasible tree for the whole `mask` (still ending in `v`).

```
dp[mask][v] = min over sub ⊂ mask, sub≠0, sub≠mask
              ( dp[sub][v] + dp[mask^sub][v] )
```

The loop over all proper sub‑masks of `mask` is `O(3^t)` overall.

--------------------------------------------------------------------

#### 4.   Propagation through ordinary edges  

After the combination step `dp[mask][*]` is optimal **only for trees that end
exactly at the vertex where the two parts met**.
A cheaper tree may end at a different vertex, reachable via ordinary edges.
Therefore we run a multi‑source Dijkstra for the current `mask`:

* all vertices `v` with current finite `dp[mask][v]` are inserted into the heap
  with distance `dp[mask][v]`;
* normal Dijkstra relaxations are performed,
  updating `dp[mask][to]` with `dist + w(edge)`.

After the Dijkstra finishes, `dp[mask][*]` contains the optimum for this mask.

--------------------------------------------------------------------

#### 5.   Whole algorithm  

```
read input
build adjacency list
term[] = list of terminal vertices (0‑based)

dp = [ [INF]*n for _ in range(1<<t) ]
for i, v in enumerate(term):
        dp[1<<i][v] = 0

for mask from 1 to fullMask:
        # 3. combine smaller subsets
        sub = (mask-1) & mask
        while sub:
                other = mask ^ sub
                if other:
                        for v in range(n):
                                cand = dp[sub][v] + dp[other][v]
                                if cand < dp[mask][v]:
                                        dp[mask][v] = cand
                sub = (sub-1) & mask

        # 4. Dijkstra for this mask
        heap = []
        for v in range(n):
                if dp[mask][v] < INF:
                        heap.append( (dp[mask][v], v) )
        heapify(heap)
        while heap:
                d, v = heappop(heap)
                if d != dp[mask][v]:
                        continue
                for to, w in graph[v]:
                        nd = d + w
                        if nd < dp[mask][to]:
                                dp[mask][to] = nd
                                heappush(heap, (nd, to))

answer = min(dp[fullMask])
print(answer)
```

Complexities  

* Number of masks: `2^t ≤ 1024`.
* Subset combination: `O(3^t · n) ≤ 59049·100 ≈ 6·10⁶`.
* Dijkstra per mask: `O(m log n)` → at most `1024·5000·log100` ≈ `5·10⁶`.
* Memory: `2^t · n` integers ≈ `1024·100 = 1e5`.

Both time (well below 5 s) and memory (far under 256 MiB) satisfy the limits.

--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total expense.

---

##### Lemma 1  
For any mask and vertex `v`, after the Dijkstra step finishes,
`dp[mask][v]` equals the minimum weight of a connected subgraph that

* connects exactly the terminals of `mask`,
* contains vertex `v`.

**Proof.**  
Induction over the order in which masks are processed.

*Base.* For a mask that is a single terminal `{i}` the initialization sets
`dp[mask][term[i]] = 0` and all other vertices are `INF`.  
Running Dijkstra on this mask computes the shortest paths from the terminal
to every vertex, i.e. the cheapest way to connect the terminal and vertex `v`
(just a single path). Hence the statement holds.

*Induction step.* Assume the statement true for all proper sub‑masks of `mask`.
Before Dijkstra, the combination loop sets for every `v`

```
dp[mask][v] = min_{sub} ( optimal tree for sub ending at v
                         + optimal tree for mask\sub ending at v )
```

By the induction hypothesis each term inside the min is exactly the optimum
for its sub‑mask ending at `v`. Their union is a feasible tree for `mask`
still ending at `v`, therefore `dp[mask][v]` is **not larger** than the true optimum.

Conversely, take an optimal tree `T` for `mask` that contains `v`.
Pick any edge of `T` whose removal separates the terminals into two non‑empty
sets `sub` and `mask\sub`. The two resulting components are trees for those
sub‑masks and both contain `v`. Their costs sum to the cost of `T`,
hence the combination step will consider exactly this split and set
`dp[mask][v]` to at most the cost of `T`. So `dp[mask][v]` is **not smaller** than
the optimum. Therefore after combination it already equals the optimum
*restricted to trees that end at v*.

Running Dijkstra can only improve distances by adding ordinary edges,
i.e. it finds the cheapest way to move the “ending point” from `v` to any other
vertex while keeping the same set of terminals connected.
Thus after Dijkstra the value becomes the optimum over **all** trees for `mask`
that contain the vertex in question. ∎



##### Lemma 2  
After processing all masks, for the full mask `F` we have  

```
min_v dp[F][v] = weight of a minimum Steiner tree connecting all terminals.
```

**Proof.**  
By Lemma&nbsp;1, for each vertex `v` `dp[F][v]` is the minimum weight of a
connected subgraph that connects all terminals and contains `v`.  
Any Steiner tree connects all terminals and contains at least one vertex,
so its weight appears among the values `dp[F][v]`.  
Taking the minimum over `v` therefore yields exactly the weight of a minimum
Steiner tree. ∎



##### Lemma 3  
The algorithm terminates.

**Proof.**  
The outer loop iterates over a finite set of masks (`2^t`).  
Inside, the combination loop iterates over a finite number of sub‑masks,
and Dijkstra terminates because edge weights are positive. ∎



##### Theorem  
The algorithm outputs the minimum possible total expense required to make all
primary facilities mutually reachable.

**Proof.**  
By Lemma&nbsp;3 the algorithm finishes.  
By Lemma&nbsp;1, after each mask’s Dijkstra step the DP table holds the exact
optimum for that mask.  
Consequently after the last mask (`fullMask`) is processed,
Lemma&nbsp;2 shows that `min_v dp[fullMask][v]` equals the weight of a minimum
Steiner tree for the given terminals.  
The algorithm prints this value, which is therefore the required minimum
expense. ∎

#### 7.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10**18

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    terminals = [int(next(it)) - 1 for _ in range(t)]

    graph = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        graph[u].append((v, w))
        graph[v].append((u, w))

    if t == 1:
        print(0)
        return

    full_mask = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    for i, v in enumerate(terminals):
        dp[1 << i][v] = 0

    # iterate masks in increasing order
    for mask in range(1, full_mask + 1):
        # combine smaller subsets
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other:
                dps = dp[sub]
                dpo = dp[other]
                dpm = dp[mask]
                for v in range(n):
                    cand = dps[v] + dpo[v]
                    if cand < dpm[v]:
                        dpm[v] = cand
            sub = (sub - 1) & mask

        # Dijkstra for this mask
        heap = []
        dpm = dp[mask]
        for v in range(n):
            if dpm[v] < INF:
                heap.append((dpm[v], v))
        heapq.heapify(heap)

        while heap:
            d, v = heapq.heappop(heap)
            if d != dpm[v]:
                continue
            for to, w in graph[v]:
                nd = d + w
                if nd < dpm[to]:
                    dpm[to] = nd
                    heapq.heappush(heap, (nd, to))

    answer = min(dp[full_mask])
    print(answer)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
