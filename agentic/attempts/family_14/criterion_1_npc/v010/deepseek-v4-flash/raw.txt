 We can solve this by treating it as a **Steiner tree** problem, but since the number of primary facilities is small (t ≤ 10), we can use a **bitmask DP over subsets of primary nodes** combined with shortest paths.

Here’s the plan:

1. Compute all-pairs shortest paths between all nodes (Floyd–Warshall or Dijkstra from each node).
2. Let `dp[mask][v]` = minimum cost to connect the primary nodes in `mask` with the tree rooted at node `v`.
3. Initialize `dp[1 << i][primary[i]] = 0` for each primary node.
4. For each mask, try merging two submasks at the same node.
5. Then run a relaxation step: for each node, try moving the tree root to a neighbor via the shortest path (like running Dijkstra over the DP states).
6. The answer is `min(dp[(1<<t)-1][v])` for any `v`.

We’ll implement it efficiently.

```python
import sys
import heapq

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    primaries = list(map(int, input().split()))
    primaries = [p-1 for p in primaries]
    
    INF = 10**18
    dist = [[INF]*n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    
    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w
    
    # Floyd-Warshall
    for k in range(n):
        dk = dist[k]
        for i in range(n):
            dik = dist[i][k]
            if dik == INF:
                continue
            di = dist[i]
            for j in range(n):
                nd = dik + dk[j]
                if nd < di[j]:
                    di[j] = nd
    
    full_mask = (1 << t) - 1
    dp = [[INF]*n for _ in range(1 << t)]
    
    for i, p in enumerate(primaries):
        dp[1 << i][p] = 0
    
    # DP over subsets
    for mask in range(1 << t):
        # Merge submasks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if sub < other:  # avoid duplicate work
                for v in range(n):
                    dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[other][v])
            sub = (sub - 1) & mask
        
        # Dijkstra-like relaxation for this mask
        pq = []
        for v in range(n):
            if dp[mask][v] < INF:
                heapq.heappush(pq, (dp[mask][v], v))
        while pq:
            d, u = heapq.heappop(pq)
            if d != dp[mask][u]:
                continue
            for v in range(n):
                nd = d + dist[u][v]
                if nd < dp[mask][v]:
                    dp[mask][v] = nd
                    heapq.heappush(pq, (nd, v))
    
    ans = min(dp[full_mask])
    print(ans)

if __name__ == "__main__":
    solve()
```
