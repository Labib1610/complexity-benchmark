We can approach this by noting that we only need to connect the given `t` terminals.  
This is a **Steiner tree** problem on a graph, but with small `t` (≤ 10), we can solve it via dynamic programming over subsets of terminals.

**Plan:**
1. Compute all-pairs shortest paths (Floyd–Warshall) because `n ≤ 100`.
2. Use a bitmask DP:
   - `dp[mask][v]` = minimum cost to connect terminals in `mask` with a tree whose root is at node `v`.
   - Initialize for single-terminal masks: `dp[1<<i][terminal_i] = 0`.
   - Combine masks via subset DP: for each `mask`, try splitting into submasks and merging at same node.
   - Relax with shortest paths: from node `v` to `u` using `dist[v][u]`.
3. Answer is `min over v of dp[full_mask][v]`.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    terminals = list(map(int, input().split()))
    terminals = [x - 1 for x in terminals]  # zero-index

    INF = 10**18
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w

    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    full_mask = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    for i in range(t):
        dp[1 << i][terminals[i]] = 0

    for mask in range(1 << t):
        # subset DP
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if sub < other:
                for v in range(n):
                    dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[other][v])
            sub = (sub - 1) & mask

        # relax using shortest paths
        for v in range(n):
            if dp[mask][v] < INF:
                for u in range(n):
                    if dist[v][u] < INF:
                        if dp[mask][v] + dist[v][u] < dp[mask][u]:
                            dp[mask][u] = dp[mask][v] + dist[v][u]

    ans = min(dp[full_mask])
    print(ans)

if __name__ == "__main__":
    solve()
```
