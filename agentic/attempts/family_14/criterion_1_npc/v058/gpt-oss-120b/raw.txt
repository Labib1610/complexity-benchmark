**Solution Explanation**

For the given undirected weighted graph we have to choose a set of edges of minimum total
weight such that all `t ( ≤ 10 )` special vertices (generators) become connected.
All other vertices may be used as intermediate relay stations.
The problem is exactly the **Steiner Tree** problem for a small number of terminals.

--------------------------------------------------------------------

#### 1.   Pre‑processing – all‑pairs shortest paths  

Only the total weight of the chosen edges matters, not the concrete paths.
If we know the cheapest distance between every pair of vertices,
any tree can be replaced by the same tree where every edge is a shortest
path – the total weight does not increase.
Therefore we first compute `dist[u][v]` – the length of a cheapest path
between any two vertices.

`n ≤ 100`, so Floyd‑Warshall (`O(n³) = 10⁶`) is fast enough.

--------------------------------------------------------------------

#### 2.   DP over subsets of terminals (Dreyfus‑Wagner)

`mask` – bitmask of terminals already connected (`0 … (1<<t)-1`)  
`dp[mask][v]` – minimum total weight of a sub‑tree that

* connects **exactly** the terminals of `mask`
* its **root** (any chosen vertex of the tree) is `v`

The answer will be `min_v dp[ALL][v]` where `ALL = (1<<t)-1`.

--------------------------------------------------------------------
##### 2.1   Initialisation  

For a single terminal `i` (`mask = 1<<i`) the cheapest tree that ends in `v`
is simply the shortest path from that terminal to `v` :

```
dp[1<<i][v] = dist[ terminal_i ][ v ]
```

--------------------------------------------------------------------
##### 2.2   Merging two already built sub‑trees  

For a general mask we split it into two non‑empty disjoint parts `sub` and
`mask ^ sub`.  
If both parts already end in the same vertex `v`, we can unite the two
sub‑trees without adding any extra edge (they already meet in `v`).

```
dp[mask][v] = min over proper non‑empty sub ⊂ mask
              ( dp[sub][v] + dp[mask^sub][v] )
```

The loop over sub‑masks runs in `O(3^t)` overall, which is tiny (`t ≤ 10`).

--------------------------------------------------------------------
##### 2.3   Propagation through shortest paths  

After the merge step `dp[mask][v]` is known only for trees whose root is exactly `v`.
The root may be moved to any other vertex `u` by adding the cheapest path
`dist[v][u]`.  
Thus we relax the whole row with the pre‑computed distances:

```
new_dp[mask][u] = min_v ( dp[mask][v] + dist[v][u] )
```

That is a simple `O(n²)` min‑convolution for each mask.

--------------------------------------------------------------------
##### 2.4   Order of processing  

All masks are processed in increasing order of their integer value.
For each mask we first perform the merge step (using already finished
sub‑masks) and afterwards the propagation step.

--------------------------------------------------------------------
#### 3.   Result  

`answer = min_v dp[ALL][v]` – the cheapest Steiner tree connecting all terminals.

The algorithm runs in  

* Floyd‑Warshall: `O(n³)`  
* DP: `O( 2^t * n² + 3^t * n )`  

With the given limits (`n ≤ 100`, `t ≤ 10`) this is far below the limits.

--------------------------------------------------------------------
#### 4.   Correctness Proof  

We prove that the algorithm outputs the weight of a minimum
phase‑stable configuration.

---

##### Lemma 1  
For any two vertices `a, b` the value `dist[a][b]` computed by Floyd‑Warshall
equals the minimum possible total impedance of a path between `a` and `b`.

**Proof.** Floyd‑Warshall is a classic all‑pairs shortest‑path algorithm for
non‑negative weights, which is correct by induction on the allowed
intermediate vertices. ∎



##### Lemma 2  
For a single terminal `i` and any vertex `v`,
`dp[1<<i][v] = dist[terminal_i][v]` equals the minimum total impedance of a
sub‑tree that connects only terminal `i` and whose root is `v`.

**Proof.** With only one terminal the tree must be a simple path from the
terminal to the root. By Lemma&nbsp;1 the cheapest such path has weight
`dist[terminal_i][v]`. No cheaper sub‑tree exists. ∎



##### Lemma 3  
Assume for a mask `M` and every vertex `v` the value `dp[M][v]` equals the
minimum weight of a tree that

* connects exactly the terminals of `M`,
* has root `v`.

Then after the **merge step** the updated `dp[M][v]` equals the minimum weight
of a tree with the same properties that can be obtained by joining two
already optimal sub‑trees whose terminal sets partition `M`.

**Proof.** Any tree `T` for mask `M` rooted at `v` can be split at `v`
into two sub‑trees `T1, T2` whose terminal sets form a partition
`sub , M\sub`. Their weights are at least `dp[sub][v]` and `dp[M\sub][v]`
by the induction hypothesis, therefore  
`weight(T) ≥ dp[sub][v] + dp[M\sub][v]`.  
Taking the minimum over all possible `sub` gives a lower bound for the
optimal tree. Conversely, for the `sub` attaining the minimum we can
concatenate the optimal sub‑trees (they already meet in `v`) and obtain a
tree of exactly that weight. Hence the formula yields the optimum. ∎



##### Lemma 4  
After the **propagation step** (`new_dp[mask][u] = min_v dp[mask][v] + dist[v][u]`)
the value `new_dp[mask][u]` equals the minimum weight of a tree that

* connects exactly the terminals of `mask`,
* has root `u`.

**Proof.** Any tree with root `u` can be seen as a tree with some root `v`
plus the shortest path from `v` to `u`. Its weight is at least
`dp[mask][v] + dist[v][u]`. Minimising over `v` gives a lower bound.
Conversely, choose `v` achieving the minimum; take an optimal tree for
`dp[mask][v]` and attach the shortest path `v→u`. The result is a valid
tree rooted at `u` with exactly that weight. ∎



##### Lemma 5  
For every mask processed by the algorithm, after both steps
`dp[mask][v]` equals the optimum defined in Lemma&nbsp;3/4.

**Proof.** Induction over the number of bits in `mask`.  
*Base*: masks with a single bit – Lemma&nbsp;2.  
*Induction*: assume the statement true for all proper sub‑masks.
The merge step uses only those sub‑masks, therefore by Lemma&nbsp;3 the
result is optimal among trees that meet at the root.
The subsequent propagation step makes the root arbitrary, preserving
optimality by Lemma&nbsp;4. ∎



##### Lemma 6  
`answer = min_v dp[ALL][v]` equals the weight of a minimum Steiner tree
connecting all terminals.

**Proof.** By Lemma&nbsp;5, for each vertex `v` the value `dp[ALL][v]` is the
minimum weight of a tree connecting all terminals and rooted at `v`.
The cheapest among all possible roots is therefore the overall optimum. ∎



##### Theorem  
The algorithm outputs the minimum possible total impedance of a
phase‑stable configuration.

**Proof.** A phase‑stable configuration is exactly a Steiner tree spanning
all generators. By Lemma&nbsp;6 the algorithm returns the weight of a minimum
such tree, which is the required optimum. ∎

#### 5.   Reference Implementation  (Python 3)

```python
import sys
import math

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    terminals = [int(next(it)) - 1 for _ in range(t)]

    INF = 10**18
    # distance matrix
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        if w < dist[u][v]:
            dist[u][v] = dist[v][u] = w

    # Floyd‑Warshall
    for k in range(n):
        dk = dist[k]
        for i in range(n):
            di = dist[i]
            ik = di[k]
            if ik == INF:
                continue
            for j in range(n):
                nd = ik + dk[j]
                if nd < di[j]:
                    di[j] = nd

    full = 1 << t
    dp = [[INF] * n for _ in range(full)]

    # initialise singletons
    for idx, term in enumerate(terminals):
        mask = 1 << idx
        drow = dist[term]
        dp[mask] = drow[:]   # copy list

    # iterate over masks
    for mask in range(1, full):
        # skip singletons (already optimal)
        if mask & (mask - 1) == 0:
            continue

        # merge submasks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            # combine only once per unordered pair
            if sub < other:
                dp_sub = dp[sub]
                dp_other = dp[other]
                for v in range(n):
                    val = dp_sub[v] + dp_other[v]
                    if val < dp[mask][v]:
                        dp[mask][v] = val
            sub = (sub - 1) & mask

        # propagation through shortest paths
        # new_dp[u] = min_v dp[mask][v] + dist[v][u]
        new_row = [INF] * n
        cur = dp[mask]
        for v in range(n):
            cv = cur[v]
            if cv == INF:
                continue
            dv = dist[v]
            for u in range(n):
                nd = cv + dv[u]
                if nd < new_row[u]:
                    new_row[u] = nd
        dp[mask] = new_row

    ans = min(dp[full - 1])
    print(ans)

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
