**Solution Explanation**

For the given undirected weighted graph we have to choose a set of edges whose total
weight is minimum and that makes all *t* special vertices (terminals) mutually reachable.
Vertices that are not terminals may be used as intermediate relays.
The problem is exactly the **Steiner Tree** problem in graphs.
With  

* `n ≤ 100`  
* `t ≤ 10`

the classic DP over subsets of terminals (`O( 3^t · n + 2^t · m log n )`) is easily fast enough.



--------------------------------------------------------------------

#### 1.   DP definition  

`mask` – bitmask of terminals already connected,  
`v`    – a vertex of the whole graph (terminal or not).

```
dp[mask][v] = minimum total weight of a sub‑graph
              that
              * connects all terminals whose bits are 1 in mask,
              * is a tree,
              * the tree contains vertex v
```

The answer will be  

```
min_v dp[ALL][v]          (ALL = (1<<t)-1)
```

--------------------------------------------------------------------

#### 2.   Initialisation  

For every terminal `i`

```
mask = 1 << i
dp[mask][terminal_i] = 0
all other dp[mask][*] = INF
```

--------------------------------------------------------------------

#### 3.   Combine two already built sub‑trees  

If a tree already connects the terminals of `sub` **and** a (maybe different) tree
connects the terminals of `mask ^ sub`, both rooted in the *same* vertex `v`,
they can be merged into a tree for `mask`.

```
dp[mask][v] = min( dp[sub][v] + dp[mask^sub][v] )
```

All non‑empty proper sub‑masks `sub` of `mask` are tried.
The inner loop over all vertices is `O(n)`.

--------------------------------------------------------------------

#### 4.   Relax distances through graph edges  

After the combination step `dp[mask][*]` contains the cheapest tree that **ends**
in each vertex, but perhaps a cheaper tree exists that first goes through other
vertices.
This is exactly a shortest‑path problem with many sources:
use Dijkstra (or a priority queue based BFS because all weights are positive).

```
dist = dp[mask]               # copy as current distances
push every vertex with dist[v] < INF into a heap
standard Dijkstra relaxing edges (u,w) → (v, w+edgeWeight)
dp[mask] = dist                # store the improved values
```

Complexity per mask: `O( (n+m) log n )`.

--------------------------------------------------------------------

#### 5.   Whole algorithm  

```
for mask = 1 … (1<<t)-1
        # 1) combine smaller masks
        for each non‑empty proper submask sub of mask
                other = mask ^ sub
                for v = 0 … n-1
                        dp[mask][v] = min(dp[mask][v],
                                          dp[sub][v] + dp[other][v])
        # 2) run multi‑source Dijkstra to propagate through edges
        dijkstra(mask)
answer = min_v dp[ALL][v]
```

The number of masks is `2^t ≤ 1024`.  
The number of submask pairs examined for one mask is `O(2^{popcount(mask)})`,
overall `O(3^t)`.  
With `t ≤ 10` this is far below the limits.

--------------------------------------------------------------------

#### 6.   Correctness Proof  

We prove that the algorithm outputs the weight of a minimum Steiner tree.

---

##### Lemma 1  
For every mask and vertex `v`, after the Dijkstra step of that mask  

`dp[mask][v]` equals the minimum weight of **any** tree that

* connects exactly the terminals of `mask`,
* contains vertex `v`.

**Proof.**  
Induction over the order of masks (by increasing number of bits).

*Base* (`mask` has exactly one bit):  
The only tree satisfying the conditions is the trivial tree consisting of `v`
itself, possible only when `v` is the terminal itself, weight `0`.  
All other vertices are unreachable → `INF`.  
Dijkstra does not improve anything because there is no edge with negative weight.
Thus the statement holds.

*Induction step.*  
Assume the statement true for all proper submasks of `mask`.

Before Dijkstra, the algorithm performed the combination step.
For any vertex `v` and any partition `mask = sub ∪ other` (disjoint, non‑empty)  
`dp[sub][v] + dp[other][v]` is, by induction hypothesis, the weight of the
cheapest tree `Ts` connecting `sub` and ending at `v` plus the cheapest tree
`To` connecting `other` and also ending at `v`.  
The union `Ts ∪ To` is a tree (they share only vertex `v`) that connects all
terminals of `mask` and contains `v`. Its weight is exactly that sum.
Taking the minimum over all partitions yields the cheapest **tree whose
*root* is `v`** (i.e. all edges lie inside the tree, and `v` is a distinguished
vertex of the tree).  

Now Dijkstra expands the set of allowed trees: any tree that contains `v`
can be transformed into a tree that **ends** at any other vertex `u` by
adding the (unique) shortest path from `v` to `u` (edges may be reused, but the
result is still a tree because the added path attaches at `v`).  
Conversely, any tree ending at `u` can be seen as a tree ending at `v`
plus the shortest path `v→u`.  
Therefore the shortest‑path relaxation computes exactly the minimum weight of a
tree that connects `mask` and contains `u`. ∎



##### Lemma 2  
After processing every mask, `dp[mask][v]` is the minimum possible weight of a
Steiner tree for terminals `mask` **that contains vertex `v`**.

*Proof.* Directly Lemma&nbsp;1, because a Steiner tree is defined as any tree
connecting the required terminals (extra vertices allowed). ∎



##### Lemma 3  
`answer = min_v dp[ALL][v]` equals the weight of a minimum Steiner tree for all
terminals.

*Proof.*  
Any optimal Steiner tree `T*` connects all terminals, thus it contains at least
one vertex `r`. By Lemma&nbsp;2 the value `dp[ALL][r]` is **not larger** than the
weight of `T*`. Consequently `answer ≤ weight(T*)`.

On the other hand, pick `v` attaining the minimum. By Lemma&nbsp;2 there exists a
tree of weight `dp[ALL][v]` that connects all terminals, i.e. a feasible Steiner
tree. Therefore `weight(T*) ≤ answer`. ∎



##### Theorem  
The algorithm outputs the minimum total power required to make all critical
modules mutually reachable.

*Proof.*  
By Lemma&nbsp;3 the printed value equals the weight of a minimum Steiner tree,
which is precisely the minimum total weight of a set of edges that
connects all terminals (possibly via other vertices). ∎



--------------------------------------------------------------------

#### 7.   Complexity Analysis  

```
S = 2^t   ( ≤ 1024 )
N = n     ( ≤ 100 )
M = m     ( ≤ n·(n-1)/2 ≤ 4950 )
```

*Combination over submasks* : `O( 3^t · N )`  
(standard bound for subset DP, here ≤ 59049·100 ≈ 6·10⁶)

*Dijkstra for each mask*   : `O( S · (M log N) )`  
≈ 1024·4950·log100  < 6·10⁶ operations.

Memory: `dp` array `S·N` `≈ 10⁵` integers.

Both time and memory are well inside the limits.

#### 8.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10 ** 18

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))

    terminals = [int(next(it)) - 1 for _ in range(t)]

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    full_mask = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    # initialise single terminals
    for i, node in enumerate(terminals):
        dp[1 << i][node] = 0

    # iterate masks
    for mask in range(1, full_mask + 1):
        # combine two smaller masks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            # only need each unordered partition once (optional optimization)
            if sub < other:   # ensures each pair processed once
                for v in range(n):
                    val = dp[sub][v] + dp[other][v]
                    if val < dp[mask][v]:
                        dp[mask][v] = val
            sub = (sub - 1) & mask

        # multi‑source Dijkstra to propagate through edges
        dist = dp[mask][:]
        heap = [(dist[v], v) for v in range(n) if dist[v] < INF]
        heapq.heapify(heap)

        while heap:
            d, v = heapq.heappop(heap)
            if d != dist[v]:
                continue
            nd = d
            for to, w in adj[v]:
                nd2 = nd + w
                if nd2 < dist[to]:
                    dist[to] = nd2
                    heapq.heappush(heap, (nd2, to))
        dp[mask] = dist

    ans = min(dp[full_mask])
    print(ans)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to
the required input‑output format.
