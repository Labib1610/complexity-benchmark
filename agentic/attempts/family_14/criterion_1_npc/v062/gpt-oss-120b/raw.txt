**Solution Explanation**

For every expert we have an undirected edge  

`u – v` with weight `w` (the money we have to pay for this expert).

For a set `S` of *focal* dialects we have to choose a set of edges such that
all vertices of `S` become connected.
The total price is the sum of the chosen edges (an edge is paid only once
even if it is used by many communication routes).

The problem is exactly the **Steiner Tree** problem with  
*terminals* = focal dialects.
The number of terminals `t` is at most `10`, therefore a classic
dynamic programming over subsets of terminals is fast enough.



--------------------------------------------------------------------

#### 1.   Pre‑processing – all‑pairs shortest paths  

Only the cheapest way to travel between two vertices matters.
If several edges exist between the same pair we keep the cheapest one.
With `n ≤ 100` we can run Floyd‑Warshall in `O(n³) = 10⁶` operations.

`dist[i][j]` – length of the cheapest path between `i` and `j` in the whole
graph (edges may be used many times, they are not paid yet).

--------------------------------------------------------------------

#### 2.   DP definition  

```
dp[mask][v] = minimal total weight of a set of edges
              that connects all terminals whose bits are set in mask,
              and that contains vertex v (v is the “root” of the tree).
```

`mask` – bitmask of size `t` (`0 … 2^t‑1`),  
`v` – vertex (`0 … n‑1`).

The answer will be  

```
min_v dp[fullMask][v]          (fullMask = (1<<t)‑1)
```

--------------------------------------------------------------------

#### 3.   Initialisation  

For every terminal `i` (its graph vertex is `term[i]`)

```
dp[1<<i][ term[i] ] = 0
```

All other entries are `+∞`.

--------------------------------------------------------------------

#### 4.   DP transition  

For a mask that contains at least two terminals we split it into two
non‑empty disjoint sub‑masks `sub` and `mask ^ sub`.

If both sub‑trees already end in the same vertex `v`,
they can be united without paying anything extra:

```
dp[mask][v] = min( dp[sub][v] + dp[mask^sub][v] )
```

All proper sub‑masks are enumerated (`sub = (mask-1) & mask` loop).

After the merging step the tree may end in any vertex.
We are allowed to move the root along a cheapest path,
paying exactly the length of that path (the edges of the path are added to
the tree).  
Using the pre‑computed `dist` matrix this is a simple relaxation:

```
dp[mask][v] = min_u ( dp[mask][u] + dist[u][v] )
```

Both steps are performed for every mask in increasing order
(`mask = 1 … fullMask`).  
Complexities  

* merging sub‑masks: `O( 3^t * n )`   ( ≤ 6·10⁶ )
* relaxation with distances: `O( 2^t * n² )` ( ≤ 1·10⁷ )

Both are easily fast enough.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm returns the weight of a cheapest set of
experts that connects all focal dialects.

---

##### Lemma 1  
For every mask and vertex `v` after the relaxation step  

```
dp[mask][v] = minimum weight of a tree that
              connects the terminals of mask
              and whose vertex set contains v.
```

**Proof.**  
Induction over the order in which masks are processed.

*Base* (`mask` contains a single terminal `i`).  
`dp[1<<i][term[i]] = 0` – a tree consisting of the single vertex,
weight `0`.  
All other vertices obtain after relaxation the cheapest path from the
terminal, i.e. the cheapest tree that contains that vertex – exactly the
definition.

*Induction step.*  
Assume the statement true for all proper sub‑masks of `mask`.  
Take any optimal tree `T` for `mask` that contains `v`.  
Remove `v` from `T` and look at the connected components that contain
terminals of a sub‑mask `sub`. Their union is a tree for `sub` that also
contains `v`; its weight is at least `dp[sub][v]` by induction hypothesis.
The same holds for the complementary sub‑mask.
Therefore  

```
weight(T) ≥ dp[sub][v] + dp[mask^sub][v]
```

Taking the minimum over all splittings gives a lower bound for `dp[mask][v]`.

Conversely, for any splitting `sub` we can take optimal trees
`T₁ , T₂` for the two sub‑masks that both contain `v`
(their existence follows from the induction hypothesis) and unite them.
The union is a feasible tree for `mask` containing `v` with weight
`dp[sub][v] + dp[mask^sub][v]`.  
Taking the minimum over all splittings yields a feasible tree whose
weight equals the value assigned to `dp[mask][v]` **before** relaxation.

Finally the relaxation step replaces `dp[mask][v]` by the cheapest
value `dp[mask][u] + dist[u][v]`.  
Appending a cheapest path from `u` to `v` to the tree for `u`
produces a feasible tree for `mask` that contains `v` and has exactly that
weight. No cheaper tree can exist, otherwise its restriction to the
vertex `u` (the first vertex of the path) would contradict the optimality
of `dp[mask][u]`. ∎



##### Lemma 2  
After processing all masks, for the full mask `F`  

```
min_v dp[F][v] = weight of a cheapest Steiner tree connecting all terminals.
```

**Proof.**  
By Lemma&nbsp;1 each `dp[F][v]` equals the cheapest tree that connects all
terminals and contains `v`.  
The minimum over all possible `v` is therefore the cheapest tree that
connects all terminals (the root vertex is irrelevant). ∎



##### Lemma 3  
The algorithm never assigns a value larger than the weight of an optimal
solution to any `dp[mask][v]`.

**Proof.**  
The construction in Lemma&nbsp;1 shows that for every transition we can
explicitly build a feasible tree whose weight equals the value we write
into the table. Hence the table never exceeds the optimum. ∎



##### Theorem  
The algorithm outputs the minimum possible total funding needed to hire
experts that make all focal dialects mutually reachable.

**Proof.**  
From Lemma&nbsp;2 the algorithm outputs the minimum over `dp[F][v]`.  
Lemma&nbsp;1 guarantees each `dp[F][v]` is the weight of some feasible
solution, therefore the output is **at most** the optimum.  
Lemma&nbsp;3 guarantees no entry ever exceeds the optimum, thus the
minimum cannot be smaller than the optimum.  
Consequently the output equals the optimum. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

* Floyd‑Warshall: `O(n³) ≤ 10⁶`
* DP merging sub‑masks: `O(3^t · n) ≤ 6·10⁶`
* DP relaxation with distances: `O(2^t · n²) ≤ 1·10⁷`
* Memory: `dp` table `2^t · n ≤ 1024·100 = 1.0·10⁵` integers.

Both time (well below the 5 s limit) and memory (far below 256 MB) are
satisfied.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))

    terminals = [int(next(it)) - 1 for _ in range(t)]

    INF = 10 ** 18
    # distance matrix
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        if w < dist[u][v]:
            dist[u][v] = dist[v][u] = w

    # Floyd‑Warshall
    for k in range(n):
        dk = dist[k]
        for i in range(n):
            dik = dist[i][k]
            if dik == INF:
                continue
            di = dist[i]
            for j in range(n):
                nd = dik + dk[j]
                if nd < di[j]:
                    di[j] = nd

    full = 1 << t
    dp = [[INF] * n for _ in range(full)]

    for idx, node in enumerate(terminals):
        dp[1 << idx][node] = 0

    # DP over masks
    for mask in range(1, full):
        # combine two proper sub‑masks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            # both sub and other are non‑empty
            dps = dp[sub]
            dpo = dp[other]
            dpm = dp[mask]
            for v in range(n):
                val = dps[v] + dpo[v]
                if val < dpm[v]:
                    dpm[v] = val
            sub = (sub - 1) & mask

        # relaxation with all‑pairs shortest paths
        dpm = dp[mask]
        # new values after relaxation
        new = [INF] * n
        for v in range(n):
            best = dpm[v]          # staying at v
            for u in range(n):
                nd = dpm[u] + dist[u][v]
                if nd < best:
                    best = nd
            new[v] = best
        dp[mask] = new

    answer = min(dp[full - 1])
    print(answer)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input / output format.
