**Solution Explanation**

For every pair of forks we know the amount of silver that is needed to solder them.
All amounts are positive.
Among the `n` forks a set `T` of at most `10` forks is *primary*.
We have to solder a set of edges whose total amount of silver is minimum,
but after soldering every primary fork must be reachable from every other primary
fork (the whole set `T` becomes connected).

The problem is exactly the **Steiner Tree** problem in an undirected,
positively weighted graph with at most `10` terminals.
`n ≤ 100`, therefore the classical DP over subsets of terminals
(`Dreyfus‑Wagner` algorithm) is easily fast enough.



--------------------------------------------------------------------

#### 1.   State

```
dp[mask][v] = minimal total weight of a tree
              that connects all terminals whose bits are set in mask,
              and that contains vertex v (v is the “root” of the tree).
```

`mask` – bitmask of size `t` (`0 … 2^t‑1`)  
`v`     – vertex index (`0 … n‑1`)

The answer will be  

```
min_v dp[fullMask][v]          (fullMask = (1<<t)‑1)
```

--------------------------------------------------------------------

#### 2.   Initialization  

For each terminal `Ti` (its index in the list of terminals is `i`)

```
dp[ 1<<i ][ Ti ] = 0
```

All other values are `INF`.

--------------------------------------------------------------------

#### 3.   Transitions  

Two kinds of transitions are needed.

*3.1   Merging two already built sub‑trees*  

Take a non‑empty proper submask `sub` of `mask`.

```
dp[mask][v] = min( dp[mask][v] , dp[sub][v] + dp[mask ^ sub][v] )
```

Both parts already contain `v`, therefore the union is a tree that also
contains `v` and connects all terminals of `mask`.

The loop over all sub‑masks of a mask visits each partition twice,
but the factor is tiny (`t ≤ 10`).

*3.2   Extending the tree by ordinary graph edges*  

After the merging step `dp[mask][v]` is known for every `v`,
but the tree may be improved by adding a cheapest path from any vertex `v`
to another vertex `u`.  
That is exactly a *single‑source shortest‑path* problem where all vertices
with a finite `dp[mask][·]` are sources with their current distance.

We run Dijkstra (positive edge weights) with the whole array `dp[mask]`
as the initial distance vector.  
After the Dijkstra finishes, `dp[mask][v]` equals the cheapest tree that
connects the terminals of `mask` and ends in `v`.

--------------------------------------------------------------------

#### 4.   Order of processing  

All masks are processed in increasing numeric order.
When handling a mask, every proper sub‑mask is already completely solved,
therefore the merging transition can be applied safely.
After merging we run Dijkstra – the result is the final `dp[mask][·]`.

Complexities  

```
number of masks                : 2^t   ≤ 1024
sub‑mask loop per mask         : O( 2^{popcount(mask)} )   → total 3^t ≈ 59049
for every sub‑mask we scan all n vertices (n ≤ 100)

Dijkstra for every mask        : O( (n+m) log n )  ≤  (100+4950)·log100
```

Overall well below the limits (far under one second).

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm outputs the weight of a minimum Steiner tree.

---

##### Lemma 1  
For every mask and vertex `v` after the Dijkstra of this mask finishes,
`dp[mask][v]` equals the minimum weight of a **connected** subgraph
that

* contains `v`,
* connects all terminals whose bits are set in `mask`.

**Proof.**  
Initially (`dp` after merging step) the value is the minimum weight of a
tree that already satisfies the two conditions *except possibly* that
the tree may be disconnected from other vertices via edges not yet used.
Running Dijkstra with all vertices as sources means we are allowed to
add any path (a sequence of edges) whose total weight is the sum of its
edges. Dijkstra computes the cheapest way to reach every vertex from the
set of sources, i.e. the cheapest additional path that may be appended to
the already built tree. Adding such a cheapest path cannot destroy
connectivity and can only improve the total weight.
Because Dijkstra explores **all** possibilities of adding paths,
the final distance is the optimum among all connected subgraphs that
contain `v` and the required terminals. ∎



##### Lemma 2  
After processing a mask, for every vertex `v`
`dp[mask][v]` is the optimum value described in Lemma&nbsp;1.

**Proof by induction over the number of bits in `mask`.**

*Base*: `mask` with a single bit.
The only terminal `Ti` with that bit has `dp = 0` at `Ti` and `INF` elsewhere.
Merging step does nothing (no proper submask).
Running Dijkstra computes the shortest paths from `Ti`, which are exactly the
cheapest connected subgraphs that contain `Ti` and end at any vertex.
Thus Lemma&nbsp;1 holds.

*Induction step*: assume statement true for all masks with fewer bits.
Take a mask with at least two bits.
Consider any optimal connected subgraph `S` for this mask ending in vertex `v`.
Remove from `S` all edges of a spanning tree that connect the terminals of
some non‑empty proper submask `sub`; the remaining part still connects all
terminals of `mask \ sub` and also contains `v`.  
Consequently the weight of `S` equals

```
weight( optimal tree for sub ending in v )
+ weight( optimal tree for mask^sub ending in v )
```

By induction hypothesis the two summands are exactly
`dp[sub][v]` and `dp[mask^sub][v]`.  
Therefore `dp[sub][v] + dp[mask^sub][v]` is a candidate value for
`dp[mask][v]` before Dijkstra. The merging loop evaluates **all**
proper submasks, hence after it finishes we have

```
dp[mask][v] ≤ optimum weight of any connected subgraph ending in v.
```

Now run Dijkstra. By Lemma&nbsp;1 the Dijkstra result is the cheapest
connected subgraph that can be obtained from those candidates by adding
paths, i.e. the overall optimum. Thus after Dijkstra the inequality becomes
equality, completing the induction. ∎



##### Lemma 3  
For the full mask `F = (1<<t)-1` the value  

```
ans = min_v dp[F][v]
```

equals the weight of a minimum Steiner tree connecting all terminals.

**Proof.**  
Any Steiner tree `T` connects all terminals, therefore its vertex set
contains at least one vertex `v`. `T` is a connected subgraph that ends in
`v`, so by Lemma&nbsp;2 `dp[F][v] ≤ weight(T)`. Taking the minimum over all
`v` gives `ans ≤ weight(T)`.  
Conversely, let `v*` be a vertex achieving the minimum.
`dp[F][v*]` corresponds (Lemma&nbsp;2) to a connected subgraph that connects
all terminals – exactly a Steiner tree – thus its weight is at least the
optimal Steiner weight. Hence `ans` is both ≤ and ≥ optimum, i.e. equal. ∎



##### Theorem  
The algorithm prints the minimum possible total amount of silver needed to
connect all primary tuning forks.

**Proof.**  
By Lemma&nbsp;3 the printed value equals the weight of a minimum Steiner
tree for the given terminals, which is precisely the required minimum
total silver. ∎

#### 6.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10**18

def solve() -> None:
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))

    terminals = [int(next(it)) - 1 for _ in range(t)]

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    if t <= 1:
        print(0)
        return

    full = 1 << t
    dp = [[INF] * n for _ in range(full)]

    # initialization for single terminals
    for i, node in enumerate(terminals):
        dp[1 << i][node] = 0

    # process all masks
    for mask in range(1, full):
        # merging submasks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            # combine only if both parts have been computed (they are,
            # because sub < mask)
            dsub = dp[sub]
            doth = dp[other]
            dcur = dp[mask]
            for v in range(n):
                val = dsub[v] + doth[v]
                if val < dcur[v]:
                    dcur[v] = val
            sub = (sub - 1) & mask

        # Dijkstra to propagate through graph edges
        dist = dp[mask]
        pq = [(dist[v], v) for v in range(n) if dist[v] < INF]
        heapq.heapify(pq)

        while pq:
            d, v = heapq.heappop(pq)
            if d != dist[v]:
                continue
            for to, w in adj[v]:
                nd = d + w
                if nd < dist[to]:
                    dist[to] = nd
                    heapq.heappush(pq, (nd, to))

    answer = min(dp[full - 1])
    print(answer)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input / output format.
