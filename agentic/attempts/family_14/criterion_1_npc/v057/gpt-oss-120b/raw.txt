**Solution Explanation**

For every commodity we have a vertex `1 … n`.
Each hedge agreement is an undirected edge `u – v` with cost `w`.

For a given set `T` of `t ( ≤ 10 )` *core* vertices we have to buy a set of edges
with minimum total cost such that all vertices of `T` become connected.
Vertices that are not in `T` may be used as intermediate (Steiner) vertices.

The problem is the **Steiner Tree** problem in graphs.
Because the number of terminals `t` is tiny we can solve it exactly with the
classical DP over subsets of terminals.



--------------------------------------------------------------------

#### 1.   DP definition  

```
dp[mask][v] = minimum cost of a tree
              that connects all terminals whose bits are set in mask
              and whose *root* (any vertex of the tree) is v
```

`mask` is a bitmask of length `t` (`0 … (1<<t)-1`), `v` is a vertex (`0 … n-1`).

The answer we need is  

```
min_v dp[ALL][v]          where ALL = (1<<t)-1
```

--------------------------------------------------------------------

#### 2.   Initialisation  

For every terminal `Ti` (index `i` in `0 … t-1`)

```
dp[1<<i][Ti] = 0          # a tree consisting of a single terminal costs nothing
dp[1<<i][v] = INF        # all other vertices are unreachable at the moment
```

--------------------------------------------------------------------

#### 3.   Transition  

For a mask that contains at least two terminals we can build a tree in two
steps  

*1) combine two already built sub‑trees*  

```
mask = sub  ∪  other          (sub , other are non‑empty, disjoint)
dp[mask][v] = min( dp[sub][v] + dp[other][v] )
```

The combination is performed for **every vertex `v`** – the two sub‑trees are
joined at the same vertex `v`.

*2) enlarge the tree through graph edges*  

After the combination step `dp[mask][v]` is a correct cost **if the tree ends
in `v`**, but maybe we can reach a cheaper cost for another vertex by walking
along edges.  
That is exactly a single‑source shortest‑path problem with many sources:
all vertices `v` with current distance `dp[mask][v]` are inserted into a
priority queue and Dijkstra’s algorithm is run.

The two steps are repeated for every mask in increasing order
(`mask = 1 … (1<<t)-1`).  
All sub‑masks are already completely processed, therefore the combination
uses final values.

Complexities  

* number of masks: `2^t   ≤ 1024`
* for each mask we iterate over its proper sub‑masks – at most `2^{|mask|-1}`
  of them → total `O(3^t)` combinations (`≈ 6·10^4` for `t = 10`)
* each combination touches all `n ≤ 100` vertices
* Dijkstra for a mask costs `O( (n+m) log n )` → at most `≈ 5·10^3 log 100`
  per mask, still tiny.

Overall well below the limits.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm outputs the minimum possible total capital.

---

##### Lemma 1  
For every mask and vertex `v` after the Dijkstra step of that mask,
`dp[mask][v]` equals the minimum cost of a tree that

* connects exactly the terminals of `mask`,
* contains vertex `v`,
* and whose edges are a subset of the given graph.

**Proof.**  
Induction over the order in which masks are processed.

*Base* – masks with a single bit.  
Only vertex `Ti` has distance `0`, all others are `INF`.  
The only tree that connects the single terminal and contains `Ti` is the empty
tree, cost `0`. No other tree exists, therefore the statement holds.

*Induction step.*  
Assume the statement true for all proper sub‑masks of `mask`.  
Before Dijkstra we set  

```
dp'[v] = min_{sub ⊂ mask} ( dp[sub][v] + dp[mask\sub][v] )
```

By induction hypothesis each term `dp[sub][v]` (resp. `dp[mask\sub][v]`) is the
optimal cost of a tree that connects the terminals of `sub` (resp. `mask\sub`)
and contains `v`. Their union is a tree that connects all terminals of `mask`
and also contains `v`; its cost is the sum of the two optimal costs.
Taking the minimum over all possible `sub` yields the cheapest such tree
*that is forced to contain `v` as a joining point*.
Thus `dp'[v]` is the optimum among all trees that already contain `v`.

Running Dijkstra with all vertices as sources spreads these optimal costs
through graph edges: for any vertex `u` the algorithm may take a cheapest
tree that ends in some `v` (cost `dp'[v]`) and then follow a shortest path
`v → u`. The total cost is exactly the cost of the cheapest tree that
contains `u`. Dijkstra never creates a cheaper cost than the true optimum,
because any tree containing `u` can be split at the first vertex `v` on the
path from `v` to `u`; the part up to `v` is a feasible tree for `v`,
hence its cost is at least `dp'[v]`. Adding the shortest path from `v` to `u`
cannot be cheaper than the actual part of the tree from `v` to `u`.  
Consequently after Dijkstra finishes, `dp[mask][u]` equals the optimum
described in the lemma. ∎



##### Lemma 2  
After processing all masks, for the full mask `ALL` and any vertex `v`,
`dp[ALL][v]` equals the minimum possible total cost of a set of agreements
that makes all core commodities mutually coupled (i.e. connects all terminals).

**Proof.**  
By Lemma&nbsp;1 the invariant holds for every mask, in particular for `ALL`.
A tree that connects all terminals is exactly a set of agreements that couples
them, possibly using other commodities as intermediate nodes.
Therefore `dp[ALL][v]` is the optimum among all such sets whose vertex set
contains `v`. ∎



##### Lemma 3  
`answer = min_v dp[ALL][v]` equals the minimum total capital required.

**Proof.**  
Any feasible set of agreements connects all terminals, thus its edge set
forms a connected subgraph containing some vertex `v`. Its cost is at least
`dp[ALL][v]` by Lemma&nbsp;2, consequently at least the minimum over all `v`.  
Conversely, let `v*` be a vertex attaining the minimum.
`dp[ALL][v*]` corresponds to a concrete set of edges (the tree built by the DP)
that connects all terminals, so this cost is achievable.
Hence the minimum over `v` is exactly the optimum. ∎



##### Theorem  
The algorithm outputs the minimum total capital required to couple all core
commodities.

**Proof.**  
By Lemma&nbsp;3 the value printed by the algorithm equals the optimum.
Therefore the algorithm is correct. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

```
states          : 2^t * n   ≤ 1024 * 100 = 1.0·10^5
combination    : O(3^t * n) ≤ 6·10^4 * 100 = 6·10^6
Dijkstra per mask: O((n+m) log n) ≤ (100+4950)·7 ≈ 3.5·10^4
total Dijkstra : 2^t * that ≤ 1024 * 3.5·10^4 ≈ 3.6·10^7
```

All operations are well below the 5 seconds limit, memory consumption is
about `dp` array → `≈ 1 MB`.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
import heapq

INF = 10 ** 18

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    t = int(next(it))
    terminals = [int(next(it)) - 1 for _ in range(t)]

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        adj[u].append((v, w))
        adj[v].append((u, w))

    full = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    for i, node in enumerate(terminals):
        dp[1 << i][node] = 0

    # iterate masks in increasing order
    for mask in range(1, full + 1):
        # combine two already computed sub‑masks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other:
                # to avoid doing the same partition twice, enforce sub < other
                if sub < other:
                    dps = dp[sub]
                    dpo = dp[other]
                    dpm = dp[mask]
                    for v in range(n):
                        val = dps[v] + dpo[v]
                        if val < dpm[v]:
                            dpm[v] = val
            sub = (sub - 1) & mask

        # Dijkstra to propagate through edges
        heap = [(dp[mask][v], v) for v in range(n) if dp[mask][v] < INF]
        heapq.heapify(heap)
        while heap:
            d, v = heapq.heappop(heap)
            if d != dp[mask][v]:
                continue
            for to, w in adj[v]:
                nd = d + w
                if nd < dp[mask][to]:
                    dp[mask][to] = nd
                    heapq.heappush(heap, (nd, to))

    ans = min(dp[full])
    print(ans)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input / output format.
