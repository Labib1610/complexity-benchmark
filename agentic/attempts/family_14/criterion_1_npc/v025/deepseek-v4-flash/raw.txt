We can solve this by treating it as a **Steiner tree** problem, but since the number of core departments is small (≤ 10), we can use **bitmask DP** over subsets of core departments.

Here’s the approach:

1. Run **Floyd-Warshall** to get shortest paths between all pairs of nodes.
2. Use **DP over subsets**:
   - `dp[mask][v]` = minimum cost to connect the core departments in `mask`, ending at node `v`.
   - Initialize for each core node `c`: `dp[1 << index_of_c][c] = 0`.
3. For each mask:
   - Try merging two submasks: `dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[mask ^ sub][v])`.
   - Then relax using shortest paths: for each `u`, `dp[mask][u] = min(dp[mask][u], dp[mask][v] + dist[v][u])`.
4. The answer is `min(dp[(1 << t) - 1][v])` over all `v`.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    core = list(map(int, input().split()))
    core_index = {node: i for i, node in enumerate(core)}

    INF = 10**15
    dist = [[INF] * n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w

    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    full_mask = (1 << t) - 1
    dp = [[INF] * n for _ in range(1 << t)]

    for i, node in enumerate(core):
        dp[1 << i][node] = 0

    for mask in range(1 << t):
        # Merge submasks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if other < sub:  # avoid duplicate work
                sub = (sub - 1) & mask
                continue
            for v in range(n):
                if dp[sub][v] + dp[other][v] < dp[mask][v]:
                    dp[mask][v] = dp[sub][v] + dp[other][v]
            sub = (sub - 1) & mask

        # Relax via shortest paths
        for v in range(n):
            if dp[mask][v] < INF:
                for u in range(n):
                    if dist[v][u] < INF:
                        nd = dp[mask][v] + dist[v][u]
                        if nd < dp[mask][u]:
                            dp[mask][u] = nd

    ans = min(dp[full_mask])
    print(ans)

if __name__ == "__main__":
    solve()
```
