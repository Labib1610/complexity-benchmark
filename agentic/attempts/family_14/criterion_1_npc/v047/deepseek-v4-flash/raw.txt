 We can solve this by treating it as a **Steiner tree** problem, but since the number of critical facilities is small (≤ 10), we can use a **bitmask DP** approach.

Here’s the plan:

1. Use Floyd–Warshall to compute shortest paths between all pairs of nodes.
2. Let `dp[mask][v]` = minimum cost to connect the critical nodes in `mask` and end at node `v`.
3. Initialize for each critical node `i`: `dp[1<<i][i] = 0`.
4. For each mask, try:
   - Merging two submasks at the same node.
   - Extending from a node to another via shortest path.
5. The answer is `min(dp[(1<<t)-1][v])` for any `v`.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m, t = map(int, input().split())
    critical = list(map(int, input().split()))
    critical = [x-1 for x in critical]  # 0-based

    INF = 10**15
    dist = [[INF]*n for _ in range(n)]
    for i in range(n):
        dist[i][i] = 0

    for _ in range(m):
        u, v, w = map(int, input().split())
        u -= 1
        v -= 1
        if w < dist[u][v]:
            dist[u][v] = w
            dist[v][u] = w

    # Floyd-Warshall
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] = dist[i][k] + dist[k][j]

    full_mask = (1 << t) - 1
    dp = [[INF]*n for _ in range(1 << t)]

    for i in range(t):
        dp[1 << i][critical[i]] = 0

    for mask in range(1 << t):
        # Merge submasks
        sub = (mask - 1) & mask
        while sub:
            other = mask ^ sub
            if sub < other:  # avoid duplicate work
                for v in range(n):
                    dp[mask][v] = min(dp[mask][v], dp[sub][v] + dp[other][v])
            sub = (sub - 1) & mask

        # Relax via shortest paths
        for u in range(n):
            if dp[mask][u] < INF:
                for v in range(n):
                    if dist[u][v] < INF:
                        nd = dp[mask][u] + dist[u][v]
                        if nd < dp[mask][v]:
                            dp[mask][v] = nd

    ans = min(dp[full_mask][v] for v in range(n))
    print(ans)

if __name__ == "__main__":
    solve()
```
