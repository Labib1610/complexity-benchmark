**Solution Explanation**

For every corridor we know a *shared* capacity – the total number of crates of **all**
contracts that may use this corridor.
For contract `i` we know its source `s_i`, its sink `t_i` and the required amount
`d_i`.

--------------------------------------------------------------------

#### 1.   From many commodities to one circulation  

For a node `v`

```
balance[v] =  Σ d_i   (over contracts with s_i = v)   –   Σ d_i   (over contracts with t_i = v)
```

`balance[v] > 0` : `v` has to **send** that many crates to the rest of the network  
`balance[v] < 0` : `v` has to **receive** `-balance[v]` crates.

If we can find a *single* flow that

* respects every corridor capacity,
* sends exactly `balance[v]` units out of every node `v` (i.e. a feasible **circulation**),

then the flow already contains enough crates to satisfy all contracts
(because the total out‑flow of all sources equals the total in‑flow of all sinks).

The existence of such a circulation is a standard single‑commodity flow problem:

```
super source S, super sink T
if balance[v] > 0 : edge S → v   capacity = balance[v]
if balance[v] < 0 : edge v → T   capacity = -balance[v]
original corridors keep their given capacities
```

A max‑flow from `S` to `T` that saturates all edges incident to `S`
(and therefore also all edges incident to `T`) is exactly a feasible circulation.
If the max‑flow value equals `total = Σ max(0, balance[v])`
the circulation exists, otherwise it is impossible.

The max‑flow is computed with Dinic – `O( sqrt(V)·E )` in practice, easily fast
for the given limits.

--------------------------------------------------------------------

#### 2.   Splitting the circulation into the `k` contracts  

After the max‑flow we know, for every original corridor `e`,
how many crates `flow[e]` travel through it (integral, because all capacities are integral).

Now we have to *assign* these crates to the individual contracts.
Because the circulation already satisfies all node balances,
it is always possible to decompose it into `k` collections of
`d_i` unit‑paths from `s_i` to `t_i`.  
A constructive way:

```
remaining[e] = flow[e]          # still unused crates on corridor e
for each contract i = 1 … k
        need = d_i
        while need > 0
                find any directed path P from s_i to t_i using only edges with remaining > 0
                (simple BFS, capacities are the current remaining values)
                push = min( need , min_{e in P} remaining[e] )
                for every e in P
                        remaining[e] -= push
                        answer[i][e] += push
                need -= push
```

The loop always terminates because the total amount of remaining flow
equals the total still‑unserved demand of the not‑yet‑processed contracts,
and each iteration sends a positive amount.

The BFS runs on at most `m` edges, the number of iterations is bounded by
`k + Σ d_i` (each iteration sends at least one crate).  
With the problem constraints this is easily fast enough.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct routing
iff such a routing exists.

---

##### Lemma 1  
The max‑flow construction (section&nbsp;1) has a feasible circulation
iff the max‑flow value equals `total = Σ_{v} max(0, balance[v])`.

**Proof.**  
Adding the super source/sink transforms the circulation problem into a
standard `S‑T` flow problem: any flow that saturates all edges out of `S`
(and consequently all edges into `T`) respects every original capacity
and supplies exactly `balance[v]` net outflow for each node `v`.
Conversely, any feasible circulation can be extended with the same amounts
on the added edges and becomes a flow of value `total`. ∎



##### Lemma 2  
If the algorithm reports `NO` then no feasible routing exists.

**Proof.**  
`NO` is printed only when the max‑flow value is **smaller** than `total`.
By Lemma&nbsp;1 a circulation would give a flow of value `total`,
contradiction. Hence no circulation – and therefore no routing – exists. ∎



##### Lemma 3  
Assume the max‑flow succeeded, i.e. we have a circulation `flow[e]`.
The decomposition loop (section&nbsp;2) always succeeds in sending the whole
demand `d_i` for every contract `i`.

**Proof.**  
Induction over the contracts processed.

*Induction hypothesis*: before handling contract `i`,
`remaining[e]` is a feasible circulation for the **remaining** demands
`{ d_j | j ≥ i }`.

*Base*: before the first contract the hypothesis holds because `remaining`
equals the original circulation.

*Step*: while `need > 0` we find a path `P` from `s_i` to `t_i`
using only edges with positive `remaining`. Such a path exists:
otherwise `s_i` would be separated from `t_i` in the residual graph,
which would mean the current circulation cannot supply the required net
outflow `balance[s_i]` (still at least `need`) – contradicting the hypothesis.
Sending `push` units along `P` reduces `remaining` exactly on the edges of `P`,
preserving flow conservation for all intermediate vertices,
and reduces the net outflow of `s_i` and net inflow of `t_i` by the same amount.
Thus after the push the invariant (circulation for the still unsatisfied
contracts) still holds, and `need` decreases.
When `need` becomes zero the whole demand of contract `i` is satisfied,
and the invariant is true for the next contract. ∎



##### Lemma 4  
After all contracts are processed, `answer[i][e]` satisfies every
requirement of the problem statement.

**Proof.**  
*Capacity*: each time we add `push` to `answer[i][e]` we also subtract the same
`push` from `remaining[e]`. `remaining[e]` never becomes negative,
hence the total sum over all contracts on edge `e` never exceeds the original
`flow[e]`, which itself does not exceed the corridor capacity.  

*Conservation per contract*: the decomposition uses only paths,
so for every intermediate vertex the amount entering equals the amount leaving
for that contract. At its source `s_i` exactly `d_i` units leave (the loop ends
when `need = 0`), and at its sink `t_i` exactly `d_i` units arrive.  

*Integral*: all numbers are integers, because capacities and demands are
integers and we always push an integer amount. ∎



##### Lemma 5  
If a feasible routing exists, the algorithm prints `YES`.

**Proof.**  
From a feasible routing we can sum the flows of all contracts;
the sum is a circulation that respects all corridor capacities,
hence by Lemma&nbsp;1 the max‑flow value equals `total`.  
The algorithm therefore finds a circulation and proceeds to the decomposition.
By Lemma&nbsp;3 the decomposition succeeds, producing a valid per‑contract plan,
so the algorithm outputs `YES`. ∎



##### Theorem  
The algorithm outputs  

* `NO` **iff** no routing satisfying all contracts exists;  
* otherwise `YES` followed by a correct matrix of per‑contract corridor usages.

**Proof.**  
*If* part: Lemma&nbsp;2.  
*Only‑if* part: Lemma&nbsp;5 together with Lemma&nbsp;4 guarantees that when the
algorithm prints `YES` the printed matrix is a feasible routing. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Dinic* on a graph with `n + 2` vertices and `m + n` edges  

```
Time   : O( sqrt(n) * (m + n) )   (well below the 5 s limit)
Memory : O( m + n )
```

*Decomposition*  

```
Each BFS   : O(m)
Number of augmentations ≤ k + Σ d_i   (each sends ≥1 crate)
Total time : O( (k + Σ d_i) * m )
Memory     : O( k·m ) for the answer matrix
```

Both parts satisfy the given limits.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))

    contracts = []
    balance = [0] * (n + 1)
    for _ in range(k):
        s = int(next(it)); t = int(next(it)); d = int(next(it))
        contracts.append((s, t, d))
        balance[s] += d
        balance[t] -= d

    edges = []                     # (u,v,cap)
    for _ in range(m):
        u = int(next(it)); v = int(next(it)); cap = int(next(it))
        edges.append((u, v, cap))

    # ---------- Dinic ----------
    N = n + 2
    S = 0
    T = n + 1

    class Edge:
        __slots__ = ('to', 'rev', 'cap', 'idx')
        def __init__(self, to, rev, cap, idx=-1):
            self.to = to
            self.rev = rev
            self.cap = cap
            self.idx = idx          # original edge index, -1 for super edges

    graph = [[] for _ in range(N)]

    def add_edge(fr, to, cap, idx=-1):
        fwd = Edge(to, len(graph[to]), cap, idx)
        rev = Edge(fr, len(graph[fr]), 0, -1)
        graph[fr].append(fwd)
        graph[to].append(rev)

    total_need = 0
    for v in range(1, n + 1):
        if balance[v] > 0:
            add_edge(S, v, balance[v])
            total_need += balance[v]
        elif balance[v] < 0:
            add_edge(v, T, -balance[v])

    for idx, (u, v, cap) in enumerate(edges):
        add_edge(u, v, cap, idx)

    level = [0] * N
    it_ptr = [0] * N

    def bfs():
        for i in range(N):
            level[i] = -1
        q = deque([S])
        level[S] = 0
        while q:
            v = q.popleft()
            for e in graph[v]:
                if e.cap and level[e.to] < 0:
                    level[e.to] = level[v] + 1
                    q.append(e.to)
        return level[T] >= 0

    def dfs(v, f):
        if v == T:
            return f
        for i in range(it_ptr[v], len(graph[v])):
            e = graph[v][i]
            if e.cap and level[v] < level[e.to]:
                ret = dfs(e.to, min(f, e.cap))
                if ret:
                    e.cap -= ret
                    graph[e.to][e.rev].cap += ret
                    return ret
            it_ptr[v] += 1
        return 0

    flow = 0
    INF = 10 ** 18
    while bfs():
        it_ptr = [0] * N
        while True:
            pushed = dfs(S, INF)
            if not pushed:
                break
            flow += pushed

    if flow != total_need:
        print("NO")
        return

    # retrieve flow on original edges
    flow_on_edge = [0] * m
    for u in range(N):
        for e in graph[u]:
            if e.idx >= 0:          # original edge
                used = graph[e.to][e.rev].cap   # reverse edge holds the flow sent
                flow_on_edge[e.idx] = used

    # ---------- decomposition ----------
    # adjacency list of edges that still have remaining flow
    adj = [[] for _ in range(n + 1)]
    for idx, (u, v, _) in enumerate(edges):
        if flow_on_edge[idx] > 0:
            adj[u].append([v, idx])   # mutable list to allow updating remaining

    remaining = flow_on_edge[:]          # mutable copy
    answer = [[0] * m for _ in range(k)]

    for ci, (s, t, d) in enumerate(contracts):
        need = d
        while need:
            # BFS to find any path with remaining >0
            prev = [-1] * (n + 1)
            prev_edge = [-1] * (n + 1)
            q = deque([s])
            prev[s] = s
            while q and prev[t] == -1:
                v = q.popleft()
                for nb, eidx in adj[v]:
                    if remaining[eidx] > 0 and prev[nb] == -1:
                        prev[nb] = v
                        prev_edge[nb] = eidx
                        q.append(nb)
            if prev[t] == -1:
                # should never happen
                print("NO")
                return
            # reconstruct path
            path = []
            cur = t
            bottleneck = need
            while cur != s:
                eidx = prev_edge[cur]
                bottleneck = min(bottleneck, remaining[eidx])
                path.append((prev[cur], cur, eidx))
                cur = prev[cur]
            push = bottleneck
            # apply push
            for u, v, eidx in path:
                remaining[eidx] -= push
                answer[ci][eidx] += push
            need -= push

    # output
    out_lines = ["YES"]
    for i in range(k):
        out_lines.append(" ".join(str(x) for x in answer[i]))
    sys.stdout.write("\n".join(out_lines))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
