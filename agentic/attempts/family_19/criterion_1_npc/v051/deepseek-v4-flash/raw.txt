Let's implement:

1. Read input.
2. Build the LP:
   - Variables: x_{i,e} for each contract i and edge e (0-indexed).
   - Objective: minimize 0 (just feasibility).
   - Constraints:
     - For each node v and each contract i:
       - inflow - outflow = 0 if v not source/sink.
       - outflow - inflow = d_i if v = source.
       - inflow - outflow = d_i if v = sink.
     - For each edge e: sum_i x_{i,e} ≤ c_e.
   - Bounds: x ≥ 0.

3. Solve LP with simplex (two-phase method for feasibility).
4. If LP infeasible → NO.
5. If all x integer → YES, output.
6. Else branch and bound:
   - Pick a fractional variable, branch into two subproblems (x ≤ floor, x ≥ ceil).
   - Solve each recursively, with integer cuts.
   - Since variables are small, this will terminate.
