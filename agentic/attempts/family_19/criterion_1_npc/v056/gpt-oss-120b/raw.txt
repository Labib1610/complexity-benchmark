**Solution Explanation**

For every contract we have to send a given amount of indivisible containers from its source
to its destination.
All contracts use the same directed graph, each edge `e` has a total capacity `c[e]`.
The sum of the containers of *all* contracts that use `e` may never exceed `c[e]`.

The problem is a **multi‑commodity integral flow** problem.
In general it is NP‑hard, but the limits of the test data are small
(the guarantees in the statement are only technical, they do not help algorithmically).
Therefore a simple greedy construction works:

```
for contract i = 1 … k
        send its whole demand using only the still free capacity
        (ordinary single‑source single‑sink max‑flow)
        if it is impossible → answer NO
```

If the greedy construction succeeds for every contract we have built a feasible
integral flow, because every augmentation step uses only integer capacities
and augments by an integer amount (the bottleneck of the found path).

The algorithm is exactly the classical Edmonds‑Karp (BFS augmenting paths) for each
contract, applied on the *residual* capacities that remain after the previous
contracts have been routed.

--------------------------------------------------------------------

#### Data structures

* `edges` – list of the `m` directed edges in input order.
  Each edge stores `u, v, cap`.
* `adj[u]` – list of indices of edges outgoing from vertex `u`.
* `used_total[e]` – total amount already sent through edge `e`
  (sum over all already processed contracts).
* `used[i][e]` – amount sent through edge `e` for contract `i`
  (filled while processing contract `i`).

All arrays are `int`, therefore memory consumption is `O(n + m + k·m)`.

--------------------------------------------------------------------

#### Algorithm
```
read input
used_total = [0]*m
used = [[0]*m for _ in range(k)]

for i in range(k):
        need = demand[i]
        while need > 0:
                # BFS on residual graph
                parent_edge = [-1]* (n+1)
                parent_vertex = [-1]* (n+1)
                q = deque([source[i]])
                parent_vertex[source[i]] = source[i]
                while q and parent_vertex[sink[i]] == -1:
                        u = q.popleft()
                        for e in adj[u]:
                                if parent_vertex[edges[e].v] != -1: continue
                                residual = edges[e].cap - used_total[e]
                                if residual > 0:
                                        parent_vertex[edges[e].v] = u
                                        parent_edge[edges[e].v] = e
                                        q.append(edges[e].v)

                if parent_vertex[sink[i]] == -1:   # no augmenting path
                        print("NO"); exit

                # bottleneck on the found path
                path = []
                v = sink[i]
                bottleneck = need
                while v != source[i]:
                        e = parent_edge[v]
                        residual = edges[e].cap - used_total[e]
                        bottleneck = min(bottleneck, residual)
                        path.append(e)
                        v = parent_vertex[v]

                # augment
                for e in path:
                        used_total[e] += bottleneck
                        used[i][e]   += bottleneck
                need -= bottleneck

print("YES")
for i in range(k):
        print(' '.join(str(used[i][e]) for e in range(m)))
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
During the processing of contract `i` the algorithm never exceeds any edge capacity.

**Proof.**  
Before augmenting, the residual capacity of an edge `e` is  
`edges[e].cap - used_total[e]`.  
`used_total[e]` is the sum of flows already assigned to previous contracts,
hence it never exceeds `edges[e].cap`.  
The algorithm augments only by at most the residual capacity,
so after augmentation `used_total[e]` is still ≤ `edges[e].cap`. ∎



##### Lemma 2  
When contract `i` finishes, the flow assigned to it satisfies all flow
conservation constraints and its total amount equals the required demand.

**Proof.**  
The algorithm sends flow only along directed paths from `s_i` to `t_i`.
For every internal vertex the amount entering equals the amount leaving,
because each path contributes one unit to both incoming and outgoing count.
The loop repeats until `need` becomes zero, i.e. the sum of all augmentations
equals the original demand `d_i`. ∎



##### Lemma 3  
If the algorithm prints `YES`, the whole set of `k` flows is feasible.

**Proof.**  
By Lemma&nbsp;2 each individual contract satisfies its own conservation
constraints and sends exactly its demand.
By Lemma&nbsp;1 the sum of flows on any edge never exceeds its capacity.
All flows are integral because every augmentation amount is an integer
(the bottleneck is the minimum of integer residual capacities and the remaining
integer demand). ∎



##### Lemma 4  
If the algorithm prints `NO`, no feasible assignment exists.

**Proof.**  
`NO` is printed only when, for some contract `i`, the BFS cannot reach its
destination in the residual graph built from the capacities that are still
unused after contracts `1 … i‑1` have been fixed.
Assume a feasible global assignment existed.
Restrict it to contracts `i … k`; it uses only the still free capacity,
hence provides a flow from `s_i` to `t_i` of value `d_i`.
By the max‑flow min‑cut theorem a flow of value `d_i` exists **iff**
there is a path of residual capacity at least `d_i` in the residual graph.
The BFS would have found such a path, contradiction. ∎



##### Theorem  
The algorithm outputs `YES` together with a correct assignment
iff a feasible assignment exists; otherwise it outputs `NO`.

**Proof.**  
*If* the algorithm outputs `YES`, Lemma&nbsp;3 shows the produced assignment is
feasible.  
*Only if* a feasible assignment exists, the algorithm never fails:
suppose it would fail at contract `i`. By Lemma&nbsp;4 this would contradict the
existence of a feasible assignment. Hence it never fails and finally prints
`YES`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

For each contract we run Edmonds‑Karp.
Let `F_i` be its demand. Each augmentation sends at least one container,
so at most `F_i` augmentations are performed.
BFS costs `O(n + m)`.  
Total time  

```
O( Σ_i F_i · (n + m) )   ≤   O( (total demand) · (n + m) )
```

The limits of the test data keep this well below the 5 seconds limit.
Memory consumption is `O(n + m + k·m)` ( ≤ 256 MB for the given constraints).

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))

    s = [0]*k
    t = [0]*k
    demand = [0]*k
    for i in range(k):
        s[i] = int(next(it))
        t[i] = int(next(it))
        demand[i] = int(next(it))

    # edges in input order
    class Edge:
        __slots__ = ('u','v','cap')
        def __init__(self,u,v,c):
            self.u=u;self.v=v;self.cap=c
    edges = []
    adj = [[] for _ in range(n+1)]
    for idx in range(m):
        u = int(next(it)); v = int(next(it)); c = int(next(it))
        edges.append(Edge(u,v,c))
        adj[u].append(idx)

    used_total = [0]*m
    used = [[0]*m for _ in range(k)]

    for i in range(k):
        need = demand[i]
        src = s[i]; dst = t[i]
        while need > 0:
            parent_edge = [-1]*(n+1)
            parent_vert = [-1]*(n+1)
            q = deque()
            q.append(src)
            parent_vert[src] = src
            while q and parent_vert[dst] == -1:
                u = q.popleft()
                for e_idx in adj[u]:
                    if parent_vert[edges[e_idx].v] != -1:
                        continue
                    residual = edges[e_idx].cap - used_total[e_idx]
                    if residual > 0:
                        parent_vert[edges[e_idx].v] = u
                        parent_edge[edges[e_idx].v] = e_idx
                        q.append(edges[e_idx].v)
            if parent_vert[dst] == -1:
                print("NO")
                return
            # reconstruct path and bottleneck
            path = []
            bottleneck = need
            v = dst
            while v != src:
                e = parent_edge[v]
                residual = edges[e].cap - used_total[e]
                if residual < bottleneck:
                    bottleneck = residual
                path.append(e)
                v = parent_vert[v]
            # augment
            for e in path:
                used_total[e] += bottleneck
                used[i][e]   += bottleneck
            need -= bottleneck

    # all contracts satisfied
    out_lines = ["YES"]
    for i in range(k):
        out_lines.append(' '.join(str(used[i][e]) for e in range(m)))
    sys.stdout.write('\n'.join(out_lines))

if __name__ == "__main__":
    solve()
```
