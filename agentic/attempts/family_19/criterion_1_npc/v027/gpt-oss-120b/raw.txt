**Solution Explanation**

For every tube we know a maximal total number of pods that may use it.
All syndicates have to send their required number of pods simultaneously.
If we send the pods of the first syndicate, we permanently occupy part of the
capacity of the tubes that are used.  
After that we send the pods of the second syndicate on the *remaining*
capacity, and so on.

Because all capacities and all required numbers of pods are integers,
a standard integer max‑flow algorithm (Dinic) always returns an integer flow.
If for some syndicate the maximal flow is smaller than its quota,
no feasible routing exists – any routing would need at least that many
pods on the same set of tubes, which is impossible because the remaining
capacity is already exhausted by the previous syndicates.

Thus a simple greedy order works:

```
for i = 1 … k
        run max‑flow from s_i to t_i on the current residual capacities
        if flow < d_i → answer = NO
        otherwise store the flow on every tube
                (this is the number of pods of syndicate i using that tube)
                and decrease the residual capacity of the tube by that amount
answer = YES
```

The algorithm is correct because:

* **Feasibility ⇒ greedy succeeds**  
  Assume a feasible global routing exists.
  Consider the first syndicate in our order.
  Its pods use some set of tubes, each respecting the global capacity.
  Those tubes still have at least the same amount of free capacity before we
  start, therefore the max‑flow for the first syndicate can send at least its
  quota.  
  After we fix its flow, the remaining capacities are exactly the global
  capacities minus the pods of the first syndicate – still enough for the
  remaining syndicates (they use the same tubes as in the feasible routing,
  just with reduced free space). Repeating the argument for every step shows
  the greedy never fails when a feasible solution exists.

* **Greedy succeeds ⇒ feasible**  
  The flows we compute respect all tube capacities (we never exceed the
  residual capacity) and each syndicate’s flow conserves pods at every
  intermediate junction. Therefore the collection of all computed flows is a
  valid routing.

The algorithm runs `k` times a Dinic max‑flow on a graph with `n` vertices
and `m` edges. Dinic’s complexity is `O(m·sqrt(n))` for unit capacities,
and `O(m·n)` in the general case. With the given limits (`n,m ≤ 500`,
`k ≤ 50`) the total running time easily fits into the 5 s limit.

--------------------------------------------------------------------

#### Algorithm
```
read n, m, k
read syndicates (s[i], t[i], d[i])   i = 0 … k-1
read edges (u[j], v[j], cap[j])       j = 0 … m-1

resCap[j] = cap[j]                     # remaining capacity of each tube
answer = matrix k × m filled with 0

for i = 0 … k-1
        build a Dinic graph using only edges with residual capacity > 0
                edge j becomes a directed edge (u[j] → v[j]) with capacity resCap[j]
        flow, edgeFlow = Dinic.max_flow(s[i], t[i])
        if flow < d[i] : print "NO" and exit
        # edgeFlow[j] is the amount of flow of syndicate i on tube j
        for each tube j
                answer[i][j] = edgeFlow[j]
                resCap[j] -= edgeFlow[j]

print "YES"
print the matrix `answer` (one line per syndicate)
```

`Dinic.max_flow` also returns for every original edge how much flow was sent
through it (by storing the index of the original tube in the edge object).

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct routing iff such a
routing exists.

---

**Lemma 1**  
When the algorithm starts the iteration for syndicate `i`,
the residual capacities `resCap` equal the original capacities minus the
pods already assigned to syndicates `0 … i‑1`.

*Proof.* By construction we subtract exactly the flow of each previous
syndicate from the corresponding tube capacity and never modify any other
value. ∎



**Lemma 2**  
If a feasible global routing exists, then in the iteration of syndicate `i`
the max‑flow computed by Dinic has value at least `d_i`.

*Proof.* Take the feasible global routing and look at the pods of syndicate
`i`. They use some amount `f_j` on each tube `j`. By Lemma&nbsp;1 the residual
capacity of tube `j` before the iteration is `cap[j] – Σ_{p<i} flow_p[j]`,
which is at least `f_j` because the global routing never exceeds the original
capacity. Hence the residual network contains a flow of value `d_i`
(the same as in the feasible routing). The max‑flow is at least that
value. ∎



**Lemma 3**  
If the algorithm finishes all `k` iterations without failure,
the collection of stored flows satisfies all problem constraints.

*Proof.*  
*Capacity*: after each iteration we subtract the used amount from `resCap`,
so the sum of stored flows on any tube never exceeds its original capacity.  
*Conservation*: each iteration computes a flow from `s_i` to `t_i`,
therefore for syndicate `i` the inflow equals outflow at every intermediate
junction.  
*Demands*: the algorithm only continues when the flow value equals `d_i`,
hence each syndicate sends exactly its required number of pods. ∎



**Lemma 4**  
If the algorithm prints `NO`, no feasible routing exists.

*Proof.* The algorithm prints `NO` only when for some syndicate `i`
the max‑flow value is `< d_i`. By Lemma&nbsp;2, if a feasible routing existed,
the max‑flow would be at least `d_i`. Contradiction. ∎



**Theorem**  
The algorithm outputs `YES` and a correct routing **iff** a feasible routing
exists; otherwise it outputs `NO`.

*Proof.*  
*If* part: assume a feasible routing exists. By Lemma&nbsp;2 every iteration
succeeds, thus the algorithm never prints `NO`. After the last iteration,
by Lemma&nbsp;3 the stored flows form a valid routing, and the algorithm
outputs `YES` and this routing.

*Only‑if* part: if the algorithm outputs `YES`, it succeeded in all
iterations, therefore by Lemma&nbsp;3 the produced flows are a feasible
routing. If it outputs `NO`, Lemma&nbsp;4 shows that no feasible routing
exists. ∎

#### Complexity Analysis  

Let `N = n`, `M = m`.

One Dinic run: `O(M·N)` in the worst case.  
We run it `k` times.

```
Time   : O(k · M · N)
Memory : O(N + M)   (graph + residual capacities + answer matrix)
```

With the given limits this easily fits into the limits.

```python
import sys
from collections import deque

class Dinic:
    __slots__ = ('n', 'g', 'level', 'it')
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]

    def add_edge(self, fr, to, cap, idx=-1):
        # idx is the original tube index, stored only in forward edge
        f = [to, cap, None, idx]
        b = [fr, 0, f, -1]
        f[2] = b
        self.g[fr].append(f)
        self.g[to].append(b)

    def bfs(self, s, t):
        level = [-1]*self.n
        q = deque([s])
        level[s] = 0
        while q:
            v = q.popleft()
            for to, cap, rev, _ in self.g[v]:
                if cap and level[to] < 0:
                    level[to] = level[v] + 1
                    q.append(to)
        self.level = level
        return level[t] >= 0

    def dfs(self, v, t, f):
        if v == t:
            return f
        for i in range(self.it[v], len(self.g[v])):
            self.it[v] = i
            to, cap, rev, _ = e = self.g[v][i]
            if cap and self.level[v] < self.level[to]:
                ret = self.dfs(to, t, min(f, cap))
                if ret:
                    e[1] -= ret
                    rev[1] += ret
                    return ret
        return 0

    def max_flow(self, s, t):
        flow = 0
        INF = 10**18
        while self.bfs(s, t):
            self.it = [0]*self.n
            while True:
                f = self.dfs(s, t, INF)
                if not f:
                    break
                flow += f
        return flow

    def edge_flows(self, m):
        # return list of length m with flow on each original edge
        res = [0]*m
        for v in range(self.n):
            for to, cap, rev, idx in self.g[v]:
                if idx >= 0:
                    # original capacity - remaining capacity = flow sent
                    used = rev[1]
                    res[idx] = used
        return res
```
