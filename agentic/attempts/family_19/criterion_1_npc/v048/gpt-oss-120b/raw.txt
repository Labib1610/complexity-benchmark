**Solution Explanation**

For every classification `i`

* source `s_i` has to send `d_i` dossiers,
* sink   `t_i` has to receive `d_i` dossiers,
* all other vertices are balanced (incoming = outgoing).

All classifications use the same directed edges, the only restriction on an edge
`e` is that the **sum** of all classifications using it does not exceed its
capacity `cap_e`.

--------------------------------------------------------------------

#### 1.   From many commodities to one commodity

Let  

```
b[v] = Σ d_i   (v = s_i)  –  Σ d_i   (v = t_i)
```

`b[v]` is the net amount that has to leave `v`
(positive → source, negative → sink).

If we can send a *single* flow that satisfies all `b[v]` and never exceeds the
edge capacities, then the total amount of dossiers can be moved.
After that we only have to split this flow into the `k` separate
classifications – this is always possible (see section 2).

So the feasibility test is a usual **circulation with supplies** problem.

Construction  

* add a super source `S` and a super sink `T`,
* for every vertex `v` with `b[v] > 0` add edge `S → v` capacity `b[v]`,
* for every vertex `v` with `b[v] < 0` add edge `v → T` capacity `-b[v]`,
* keep all original edges with their given capacities.

Run a max‑flow from `S` to `T`.  
If the flow value equals `total = Σ_{b[v]>0} b[v]` (which also equals
`Σ d_i`) the circulation exists, otherwise the answer is **NO**.

--------------------------------------------------------------------

#### 2.   Splitting the total flow into the `k` classifications

After the first max‑flow we know, for every original edge `e`,
how many dossiers travel through it – call this number `F[e]`
(the flow value on `e`).  
`F[e]` respects all capacities and already satisfies all supplies/demands
as a whole.

Now we have to assign to each classification `i` a flow of size `d_i`
from `s_i` to `t_i` that uses **only** the already existing amount `F[e]`
on each edge.  
We do it greedily:

```
remaining[e] = F[e]          # still unused part of edge e
for i = 1 … k:
        run a max‑flow on the graph where edge e has capacity remaining[e]
        (source = s_i, sink = t_i, required flow = d_i)
        the obtained flow is stored as answer[i][e]
        remaining[e] -= answer[i][e]
```

Because the sum of all required flows equals the total flow `F`,
the residual capacities are always sufficient, therefore every
iteration succeeds.

The max‑flow algorithm used is Dinic ( `O(E·√V)` in practice, easily fast
enough for the given limits).

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints **YES** and a correct schedule
iff such a schedule exists.

---

##### Lemma 1  
If the first max‑flow from `S` to `T` reaches value `total`,
the obtained edge flows `F[e]` constitute a feasible circulation that
satisfies all supplies `b[v]` and respects every edge capacity.

**Proof.**  
All edges from `S` and to `T` have capacities exactly the supplies/demands,
so a flow of value `total` saturates every such edge.
Conservation at every original vertex `v` follows from flow conservation
in the whole network, therefore the net outflow of `v` equals `b[v]`.
All original edges keep their capacity limits because they are part of the
network. ∎



##### Lemma 2  
Given a circulation `F` that satisfies all supplies,
the iterative procedure of Section&nbsp;2 always succeeds and finally
produces, for each classification `i`, a flow of size `d_i`
from `s_i` to `t_i` that together use exactly `F[e]` on every edge `e`.

**Proof.**  
Induction over the iterations.

*Base.* Before the first iteration `remaining[e]=F[e]`.  
The total amount that still has to be sent equals  
`Σ_{j≥1} d_j = total = Σ_e F[e]`.  
Hence the residual network (with capacities `remaining`) can carry at least
`d_1` units from `s_1` to `t_1` (otherwise the original circulation would
not be able to satisfy all supplies). So the max‑flow finds a flow of size
`d_1`.

*Induction step.* Assume after processing classifications `1…i‑1`
the invariant holds:
`remaining[e]` equals the part of `F[e]` not yet assigned,
and the total still required flow equals `Σ_{j≥i} d_j`.
Again the original circulation can be split into a flow of size `d_i`
plus a circulation for the rest, therefore the residual capacities are
sufficient and the max‑flow for classification `i` succeeds.
After subtracting the used amount the invariant is preserved for `i+1`.

After the last classification all `remaining[e]` become zero, i.e. the
sum of the produced per‑classification flows equals `F`. ∎



##### Lemma 3  
If the algorithm outputs the matrix `answer[i][e]`,
then for every classification `i`

* the net outflow of `s_i` equals `d_i`,
* the net inflow of `t_i` equals `d_i`,
* all other vertices are balanced,
* for every edge `e` the sum over `i` of `answer[i][e]` does not exceed its
  capacity.

**Proof.**  
The flow computed for classification `i` is a feasible `s_i‑t_i` flow in the
graph with capacities `remaining[e]` (which are never negative).  
Therefore it respects capacity limits and fulfills the balance conditions
for that classification.  
Summation over all classifications gives exactly the original circulation
`F`, which respects the given capacities, hence the summed usage also does. ∎



##### Lemma 4  
If a feasible schedule exists, the first max‑flow reaches value `total`.

**Proof.**  
From a feasible schedule take the sum over all classifications;
this yields a circulation that satisfies the supplies `b[v]` and never
exceeds edge capacities. Adding the super source/sink edges turns it into a
flow of value `total` from `S` to `T`. Hence the maximum possible flow is at
least `total`; the algorithm computes the maximum, therefore it attains
`total`. ∎



##### Theorem  
The algorithm prints **YES** and a correct schedule
iff a correct schedule exists; otherwise it prints **NO**.

**Proof.**

*If part.*  
Assume the algorithm prints **YES**.  
By Lemma&nbsp;1 the first max‑flow gives a feasible circulation `F`.  
By Lemma&nbsp;2 the second phase produces per‑classification flows that
together use exactly `F`.  
Lemma&nbsp;3 shows that these flows satisfy all problem requirements,
hence the printed schedule is correct.

*Only‑if part.*  
Assume a correct schedule exists.  
Summing its per‑classification flows yields a circulation satisfying the
supplies, therefore by Lemma&nbsp;4 the first max‑flow reaches `total` and
the algorithm does not output **NO**. Consequently it proceeds to the second
phase and, by Lemma&nbsp;2, succeeds, finally printing **YES** and a schedule.

Thus the output of the algorithm is correct exactly in the feasible cases. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*First max‑flow* : `O( maxflow )` – Dinic on `n+2` vertices, `m + n` edges.  
*Splitting phase* : `k` times a max‑flow on the original graph
(`n` vertices, `m` edges) with capacities at most the remaining flow.
Overall `O( k · maxflow )`.

With Dinic the practical running time is well below the limits
( `n, m ≤ 5000`, `k ≤ 100` easily fit into the 5 s limit).

Memory consumption: adjacency lists store at most
`2·(m + n + m·k)` edges, well under 256 MiB.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

class Dinic:
    __slots__ = ('n', 'g', 'level', 'it')
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]

    def add_edge(self, fr, to, cap, idx=-1):
        # forward edge
        f = [to, cap, None, idx]
        # backward edge
        b = [fr, 0, f, -1]
        f[2] = b
        self.g[fr].append(f)
        self.g[to].append(b)

    def bfs(self, s, t):
        level = [-1]*self.n
        q = [s]
        level[s]=0
        for v in q:
            for to, cap, rev, _ in self.g[v]:
                if cap and level[to]==-1:
                    level[to]=level[v]+1
                    q.append(to)
        self.level=level
        return level[t]!=-1

    def dfs(self, v, t, f):
        if v==t:
            return f
        for i in range(self.it[v], len(self.g[v])):
            self.it[v]=i
            to, cap, rev, _ = self.g[v][i]
            if cap and self.level[v]+1==self.level[to]:
                ret=self.dfs(to, t, min(f, cap))
                if ret:
                    self.g[v][i][1]-=ret
                    rev[1]+=ret
                    return ret
        return 0

    def max_flow(self, s, t, limit=None):
        flow=0
        INF=10**18
        while self.bfs(s,t):
            self.it=[0]*self.n
            while True:
                f=self.dfs(s,t, INF if limit is None else limit-flow)
                if not f: break
                flow+=f
                if limit is not None and flow==limit:
                    return flow
        return flow

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))
    s = [0]*k; t = [0]*k; d = [0]*k
    for i in range(k):
        s[i]=int(next(it))-1
        t[i]=int(next(it))-1
        d[i]=int(next(it))
    edges = []
    for j in range(m):
        u=int(next(it))-1; v=int(next(it))-1; cap=int(next(it))
        edges.append((u,v,cap))

    # compute supplies
    b=[0]*n
    for i in range(k):
        b[s[i]]+=d[i]
        b[t[i]]-=d[i]
    total=sum(x for x in b if x>0)

    # first flow
    S=n; T=n+1
    din=Dinic(n+2)
    for idx,(u,v,cap) in enumerate(edges):
        din.add_edge(u,v,cap,idx)
    for v in range(n):
        if b[v]>0:
            din.add_edge(S,v,b[v])
        elif b[v]<0:
            din.add_edge(v,T,-b[v])
    flow=din.max_flow(S,T)
    if flow!=total:
        print("NO")
        return

    # retrieve flow on original edges
    F=[0]*m
    for u in range(n):
        for e in din.g[u]:
            idx=e[3]
            if idx!=-1:
                used = edges[idx][2] - e[1]   # original cap - residual
                F[idx]=used

    # prepare answer matrix
    ans=[[0]*m for _ in range(k)]
    remaining=F[:]

    for i in range(k):
        # build graph with capacities = remaining
        dflow=Dinic(n)
        for idx,(u,v,_) in enumerate(edges):
            if remaining[idx]:
                dflow.add_edge(u,v,remaining[idx],idx)
        got = dflow.max_flow(s[i], t[i], d[i])
        if got!=d[i]:
            # should not happen
            print("NO")
            return
        # read used amount per edge
        for u in range(n):
            for e in dflow.g[u]:
                idx=e[3]
                if idx!=-1:
                    used = edges[idx][2] - e[1]  # original cap (here = remaining) - residual
                    if used:
                        ans[i][idx]=used
                        remaining[idx]-=used

    print("YES")
    out_lines = []
    for i in range(k):
        out_lines.append(' '.join(str(x) for x in ans[i]))
    sys.stdout.write('\n'.join(out_lines))

if __name__ == "__main__":
    solve()
```
