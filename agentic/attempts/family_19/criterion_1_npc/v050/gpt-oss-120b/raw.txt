**Solution Explanation**

For every conduit (directed edge) we know a capacity `cap`.  
For every mandate `i` we have a source `s_i`, a sink `t_i` and a demand
`d_i` (how many units of this mandate have to travel from `s_i` to `t_i`).

All units are identical, only the total amount that uses a conduit is limited.
Therefore we may first forget the individual mandates and only look at the
**total** amount of flow that has to be sent through the network.

--------------------------------------------------------------------

#### 1.   From many commodities to one circulation

For a vertex `v`

```
supply(v) = Σ d_i   over all mandates i with s_i = v
demand(v) = Σ d_i   over all mandates i with t_i = v
balance(v) = supply(v) – demand(v)
```

`balance(v) > 0` : `v` has to send `balance(v)` units to the rest of the
network (it is a source of the *total* flow)  
`balance(v) < 0` : `v` has to receive `-balance(v)` units (it is a sink).

If we can send exactly these amounts through the original conduits without
exceeding their capacities, then a feasible allocation for all mandates exists.
Indeed, after such a **single‑commodity flow** is found we can split it into
paths and assign each path to a concrete mandate – the classic flow
decomposition argument.

So we only have to solve a standard max‑flow problem:

* add a super source `S` and a super sink `T`
* for every vertex `v` with `balance(v) > 0` add edge `S → v` of capacity
  `balance(v)`
* for every vertex `v` with `balance(v) < 0` add edge `v → T` of capacity
  `-balance(v)`
* keep all original edges with their given capacities

If the maximum flow from `S` to `T` equals the total positive balance,
the required total flow exists, otherwise the answer is `NO`.

--------------------------------------------------------------------

#### 2.   Recovering the per‑mandate assignment

After the max‑flow we know, for every original edge `e`,
how many units of *total* flow go through it (`flow[e]`).

Now we have to distribute this flow among the `k` mandates.
We do it one mandate after another:

```
need = d_i
while need > 0:
        find any S‑T path P from s_i to t_i that uses only edges
        with remaining flow > 0
        let delta = min( need , min_{e in P} remaining_flow[e] )
        subtract delta from remaining_flow of every edge of P
        add delta to answer[i][e]   (the amount of mandate i on edge e)
        need -= delta
```

Because the total flow equals the sum of all `d_i`, such a path always exists
until `need` becomes zero.  
The search for a path can be a simple DFS/BFS because the graph is small
enough (the whole algorithm is `O( (k·m)·(n+m) )` in the worst case, well
within the limits).

The decomposition automatically yields integer numbers because all
capacities and demands are integers.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct allocation
iff such an allocation exists.

---

##### Lemma 1  
If the max‑flow from `S` to `T` equals the total positive balance,
the flow on the original edges satisfies every vertex balance.

**Proof.**  
All flow that leaves `S` must go through edges `S→v` (capacity = balance(v) >0)
and then through the original network, finally reaching some vertex `u` with
`balance(u) < 0` and using edge `u→T`. Conservation of flow at every internal
vertex implies that the net outflow of a vertex `v` equals the amount that
entered from `S` (i.e. `balance(v)`) minus the amount that left to `T`
(if `balance(v) < 0`). Hence the net outflow of `v` in the original network
is exactly `balance(v)`. ∎



##### Lemma 2  
Given a flow on the original edges that satisfies all balances,
the iterative decomposition described in Section&nbsp;2 always succeeds
and finally consumes exactly the whole flow.

**Proof.**  
Consider the multiset of unit‑flows (paths) that constitute the given flow
(standard flow decomposition theorem). Each such unit‑flow starts at a vertex
with positive balance and ends at a vertex with negative balance.
Take any mandate `i`. Its source `s_i` has positive balance, its sink `t_i`
negative balance, and the total amount that still has to be assigned to `i`
(`need`) is at most the amount of flow that currently leaves `s_i`
(because the sum of all still unassigned needs equals the total remaining
flow). Therefore there exists at least one `s_i → t_i` path consisting only of
edges that still carry unused flow. The algorithm picks one, sends `delta`,
and reduces both the remaining flow on those edges and `need`. Repeating,
`need` finally becomes zero. After processing all mandates, the sum of all
`delta` equals the original total flow, so no flow remains unused. ∎



##### Lemma 3  
The numbers `answer[i][e]` produced by the algorithm satisfy all
mandate constraints.

**Proof.**  
For a fixed mandate `i` the algorithm only sends flow from `s_i` to `t_i`
and never creates or destroys flow elsewhere, therefore the conservation
conditions at intermediate vertices hold.
At `s_i` the total amount sent out minus amount arriving equals the sum of
all `delta` sent for this mandate, i.e. `d_i`. At `t_i` the opposite holds.
All `answer[i][e]` are non‑negative integers because `delta` is integer. ∎



##### Lemma 4  
If the algorithm prints `YES`, the printed allocation is feasible.

**Proof.**  
`YES` is printed only if the max‑flow equals the total positive balance.
By Lemma&nbsp;1 the obtained flow respects all balances.
The subsequent decomposition (Lemma&nbsp;2) yields numbers `answer[i][e]`
that together reproduce exactly this flow.
By Lemma&nbsp;3 each mandate satisfies its own flow constraints.
Finally, for every original edge `e` the sum over all mandates of
`answer[i][e]` equals the flow on `e`, which never exceeds `cap(e)`.
Thus all problem requirements are fulfilled. ∎



##### Lemma 5  
If a feasible allocation exists, the algorithm prints `YES`.

**Proof.**  
From a feasible allocation we can sum over all mandates; the resulting
total flow respects every vertex balance and never exceeds capacities.
Therefore it is a feasible flow for the network with super source/sink,
so the maximum flow value is at least the total positive balance.
Since capacities are unchanged, the max flow cannot be larger.
Hence the max flow equals the required amount and the algorithm will
detect this and continue to the decomposition step, finally printing `YES`. ∎



##### Theorem  
The algorithm outputs `YES` and a correct per‑mandate allocation
iff such an allocation exists; otherwise it outputs `NO`.

**Proof.**  
*If* part: by Lemma&nbsp;5 a feasible allocation forces the algorithm to
reach the decomposition stage and, by Lemma&nbsp;4, the printed allocation
is feasible.  
*Only‑if* part: if the algorithm prints `YES`, Lemma&nbsp;4 guarantees the
produced allocation is feasible. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Dinic max‑flow* on a graph with `n+2` vertices and `m + n` edges:  
`O( sqrt(V) * E )` in practice, well below `5 s` for the given limits.

*Decomposition*: each unit of demand is sent once, each sending traverses a
path of length at most `n`. The total number of sent units is `Σ d_i ≤
Σ cap ≤ m·max_cap`. In the worst case the algorithm performs `O(k·m·n)`
edge inspections, which is easily fast enough for the limits (memory 256 MB).

Memory consumption: adjacency lists store at most `2·(m + n)` edge objects,
plus the `k × m` answer matrix (integers). Fits into the limit.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

class Edge:
    __slots__ = ('to', 'rev', 'cap', 'orig_cap', 'idx')
    def __init__(self, to, rev, cap, idx=-1):
        self.to = to          # target vertex
        self.rev = rev        # index of reverse edge in graph[to]
        self.cap = cap        # residual capacity
        self.orig_cap = cap   # original capacity (only for original edges)
        self.idx = idx        # original edge index, -1 for auxiliary edges

def add_edge(g, fr, to, cap, idx=-1):
    fwd = Edge(to, len(g[to]), cap, idx)
    rev = Edge(fr, len(g[fr]), 0, -1)
    g[fr].append(fwd)
    g[to].append(rev)
    return fwd, rev

def dinic(g, s, t):
    n = len(g)
    level = [0]*n
    it = [0]*n
    INF = 10**18

    from collections import deque
    def bfs():
        for i in range(n):
            level[i] = -1
        q = deque([s])
        level[s] = 0
        while q:
            v = q.popleft()
            for e in g[v]:
                if e.cap and level[e.to] < 0:
                    level[e.to] = level[v] + 1
                    q.append(e.to)
        return level[t] >= 0

    def dfs(v, f):
        if v == t:
            return f
        for i in range(it[v], len(g[v])):
            e = g[v][i]
            if e.cap and level[v] < level[e.to]:
                ret = dfs(e.to, min(f, e.cap))
                if ret:
                    e.cap -= ret
                    g[e.to][e.rev].cap += ret
                    return ret
            it[v] += 1
        return 0

    flow = 0
    while bfs():
        it = [0]*n
        while True:
            f = dfs(s, INF)
            if not f:
                break
            flow += f
    return flow

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))
    mandates = []
    balance = [0]* (n+1)
    for _ in range(k):
        s = int(next(it)); t = int(next(it)); d = int(next(it))
        mandates.append((s, t, d))
        balance[s] += d
        balance[t] -= d
    edges = []
    for idx in range(m):
        u = int(next(it)); v = int(next(it)); cap = int(next(it))
        edges.append((u, v, cap))

    S = 0
    T = n + 1
    G = [[] for _ in range(n+2)]
    edge_objs = []          # forward edge objects of original edges, in input order
    for idx, (u, v, cap) in enumerate(edges):
        fwd, rev = add_edge(G, u, v, cap, idx)
        edge_objs.append(fwd)

    total_pos = 0
    for v in range(1, n+1):
        if balance[v] > 0:
            add_edge(G, S, v, balance[v])
            total_pos += balance[v]
        elif balance[v] < 0:
            add_edge(G, v, T, -balance[v])

    maxflow = dinic(G, S, T)
    if maxflow != total_pos:
        print("NO")
        return

    # remaining flow on original edges = original capacity - residual capacity
    rem = [e.orig_cap - e.cap for e in edge_objs]   # list of ints, length m

    # adjacency for decomposition (only original edges, with mutable remaining flow)
    adj = [[] for _ in range(n+1)]
    for idx, (u, v, _) in enumerate(edges):
        if rem[idx]:
            adj[u].append((v, idx))

    # answer matrix
    ans = [[0]*m for _ in range(k)]

    from collections import deque
    for i, (src, dst, need) in enumerate(mandates):
        while need:
            # BFS to find any path with remaining flow
            prev_v = [-1]*(n+1)
            prev_e = [-1]*(n+1)
            q = deque([src])
            prev_v[src] = src
            while q and prev_v[dst] == -1:
                v = q.popleft()
                for to, eidx in adj[v]:
                    if rem[eidx] > 0 and prev_v[to] == -1:
                        prev_v[to] = v
                        prev_e[to] = eidx
                        q.append(to)
            # reconstruct path
            path = []
            v = dst
            bottleneck = need
            while v != src:
                eidx = prev_e[v]
                bottleneck = min(bottleneck, rem[eidx])
                path.append(eidx)
                v = prev_v[v]
            delta = bottleneck
            # apply delta
            for eidx in path:
                rem[eidx] -= delta
                ans[i][eidx] += delta
                if rem[eidx] == 0:
                    # remove edge from adjacency to speed up later searches
                    u = edges[eidx][0]
                    # lazy removal: we keep it, BFS will just skip because rem==0
                    pass
            need -= delta

    print("YES")
    out_lines = []
    for i in range(k):
        out_lines.append(' '.join(str(x) for x in ans[i]))
    sys.stdout.write('\n'.join(out_lines))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
