**Solution Explanation**

For every stream `i`

* `s_i` – source vertex  
* `t_i` – sink vertex  
* `d_i` – required amount of flow (integer)

All streams share the same directed edges.  
Edge `e = (u → v)` has a capacity `cap[e]`.  
The sum of the flows of **all** streams on `e` must not exceed `cap[e]`.

The problem is a *multicommodity* flow problem, but the commodities are
*identical* – they are only distinguished by their source‑sink pair.
Therefore we can first solve a **single‑commodity** flow problem that
contains all streams together and afterwards split the obtained flow into
the individual streams.

--------------------------------------------------------------------

#### 1.   Reducing to a single source‑sink flow

Create a super source `S` and a super sink `T`.

```
S ──(capacity d_i)──► s_i          for every stream i
t_i ──(capacity d_i)──► T          for every stream i
```

All original edges keep their given capacities.
Now we have a usual network with one source `S` and one sink `T`.

If the maximum `S‑T` flow equals `D = Σ d_i`,
then there exists a feasible routing for all streams.
The flow on the original edges is exactly the total amount of blocks
that all streams together send through the edge, therefore respects the
capacity constraints.

The flow is integral because all capacities are integral and we use a
standard integral max‑flow algorithm (Dinic).

--------------------------------------------------------------------

#### 2.   Decomposing the flow into per‑stream assignments

The integral `S‑T` flow can be written as a sum of **paths**
`S → s_i → … → t_i → T`.  
Each such path carries some integer amount `x`.  
All flow that leaves `S` through the edge `S → s_i` belongs to stream `i`,
hence the whole path belongs to that stream.

We repeatedly extract any `S‑T` path with positive flow
(using a simple DFS on the residual graph that stores the *actual* flow,
not the residual capacities).  
Let `δ` be the minimum flow on the edges of the found path.
We subtract `δ` from the stored flow of every edge of the path and
add `δ` to the answer matrix for the corresponding stream
(the stream is known from the first edge `S → s_i`).

Because the total flow is at most `Σ d_i` and every subtraction reduces
the total remaining flow, the procedure finishes after at most
`Σ d_i` iterations.  
All numbers are integral, therefore the produced per‑stream edge
assignments are integral as required.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct assignment
iff such an assignment exists.

---

##### Lemma 1  
If the algorithm’s max‑flow value equals `D = Σ d_i`,
the flow on every original edge respects its capacity.

**Proof.**  
The max‑flow algorithm never exceeds the capacity of any edge
(including the original ones) by construction.
∎



##### Lemma 2  
If the algorithm’s max‑flow value equals `D`,
the flow can be decomposed into a multiset of `S‑T` paths,
each path starting with `S → s_i` and ending with `t_i → T`,
such that the sum of the path amounts equals the flow on every edge.

**Proof.**  
Standard flow decomposition theorem: any integral flow can be written as a
sum of integral `S‑T` paths and cycles.  
Because the only edges incident to `S` are the `S → s_i` edges,
every `S‑T` path must start with one of them, and analogously end with a
`t_i → T` edge.  
Cycles do not contain `S` or `T`; removing them does not affect the
decomposition of the `S‑T` flow. ∎



##### Lemma 3  
The decomposition procedure of the algorithm produces, for each stream
`i` and each original edge `e`, exactly the amount of flow of stream `i`
that the decomposition of Lemma&nbsp;2 assigns to `e`.

**Proof.**  
The algorithm repeatedly finds an `S‑T` path with positive remaining flow.
The first edge of the path is `S → s_i`; therefore the whole path belongs
to stream `i`.  
The algorithm subtracts the minimum flow `δ` on the path from the stored
flow of every edge, i.e. it removes exactly the contribution of that
path from the global flow.  
Simultaneously it adds `δ` to the answer matrix entry
`ans[i][e]` for every original edge `e` on the path.
Thus after the subtraction the remaining stored flow equals the original
flow minus the contribution of the extracted path, and the answer matrix
contains precisely the contribution of the extracted path.
Induction over the number of extracted paths yields the claim. ∎



##### Lemma 4  
If the algorithm prints `YES` and the matrix `ans`,
then for every stream `i` the matrix satisfies all flow conservation
constraints and the total amount sent from `s_i` to `t_i` equals `d_i`.

**Proof.**  
By Lemma&nbsp;3 the matrix `ans` is exactly the decomposition of a feasible
`S‑T` flow.  
For a fixed stream `i` consider the subgraph consisting of the edges with
positive `ans[i][·]`.  
All those edges belong to paths that start at `s_i` and end at `t_i`,
hence at every intermediate vertex the amount entering equals the amount
leaving – the conservation law holds.
The total amount leaving `s_i` (and entering `t_i`) is the sum of the
`δ` values of all extracted paths of stream `i`, which equals the total
flow sent through edge `S → s_i`, i.e. `d_i`. ∎



##### Lemma 5  
If a feasible routing exists, the algorithm’s max‑flow value equals `D`.

**Proof.**  
From a feasible routing we can construct an `S‑T` flow:
send `d_i` units on edge `S → s_i`, follow the routing of stream `i`,
and finally send `d_i` units on edge `t_i → T`.  
All edge capacities are respected, therefore this is a feasible flow of
value `D`.  
The max‑flow value is at least the value of any feasible flow, hence
≥ `D`. It cannot exceed `D` because the total capacity of edges out of `S`
is exactly `D`. Thus the max‑flow value equals `D`. ∎



##### Theorem  
The algorithm outputs  

*`YES` and a correct per‑stream assignment* **iff** a feasible assignment
exists; otherwise it outputs `NO`.

**Proof.**  

*If part*:  
Assume the algorithm outputs `YES`.  
Then the max‑flow value equals `D`.  
By Lemma&nbsp;1 capacities are respected.
By Lemma&nbsp;4 each stream satisfies the required conservation and demand.
Hence the printed matrix is a feasible assignment.

*Only‑if part*:  
Assume a feasible assignment exists.
By Lemma&nbsp;5 the max‑flow value computed by the algorithm equals `D`,
so the algorithm does not output `NO`.  
Consequently it proceeds to the decomposition step and finally prints
`YES` together with a matrix that, by Lemma&nbsp;4, is feasible. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*`N = n + 2`* (original vertices plus `S` and `T`)  
*`M = m + 2k`* (original edges plus the added source/sink edges)

Dinic runs in `O( M * sqrt(N) )` for integral capacities, well below the
limits (`N ≤ 5000`, `M ≤ 20000` in typical contest constraints).  
The decomposition extracts at most `D = Σ d_i` paths; each DFS scans at
most `M` edges, therefore `O( D * M )`.  
All other work is linear.  
Memory consumption: `O( M )`.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

class Edge:
    __slots__ = ('to', 'rev', 'cap', 'orig')
    def __init__(self, to, rev, cap, orig=False):
        self.to = to          # target vertex
        self.rev = rev        # index of reverse edge in adjacency list of 'to'
        self.cap = cap        # residual capacity
        self.orig = orig      # True for original graph edges (not super source/sink)

def add_edge(g, fr, to, cap, orig=False):
    g[fr].append(Edge(to, len(g[to]), cap, orig))
    g[to].append(Edge(fr, len(g[fr]) - 1, 0, False))

def dinic(g, s, t):
    n = len(g)
    level = [0] * n
    it = [0] * n

    from collections import deque
    def bfs():
        for i in range(n):
            level[i] = -1
        q = deque([s])
        level[s] = 0
        while q:
            v = q.popleft()
            for e in g[v]:
                if e.cap and level[e.to] < 0:
                    level[e.to] = level[v] + 1
                    q.append(e.to)
        return level[t] >= 0

    def dfs(v, f):
        if v == t:
            return f
        for i in range(it[v], len(g[v])):
            e = g[v][i]
            if e.cap and level[v] < level[e.to]:
                ret = dfs(e.to, min(f, e.cap))
                if ret:
                    e.cap -= ret
                    g[e.to][e.rev].cap += ret
                    return ret
            it[v] += 1
        return 0

    flow = 0
    INF = 10**18
    while bfs():
        it = [0] * n
        while True:
            f = dfs(s, INF)
            if not f:
                break
            flow += f
    return flow

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); k = int(next(it))
    streams = []
    for _ in range(k):
        s = int(next(it)) - 1
        t = int(next(it)) - 1
        d = int(next(it))
        streams.append((s, t, d))
    edges = []
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        cap = int(next(it))
        edges.append((u, v, cap))

    S = n
    T = n + 1
    G = [[] for _ in range(n + 2)]

    # original edges, remember their order
    edge_refs = []          # (from, index in G[from]) for each original edge
    for idx, (u, v, cap) in enumerate(edges):
        add_edge(G, u, v, cap, orig=True)
        edge_refs.append( (u, len(G[u]) - 1) )   # last added edge

    total_d = 0
    for i, (s, t, d) in enumerate(streams):
        total_d += d
        add_edge(G, S, s, d)          # super source to s_i
        add_edge(G, t, T, d)          # t_i to super sink

    maxflow = dinic(G, S, T)
    if maxflow != total_d:
        print("NO")
        return

    # Build a structure that stores the *actual* flow on original edges
    # after maxflow, the residual capacities are in G, but we need the flow value.
    # For each original edge we can compute flow = original_cap - residual_cap
    flow_on_edge = [0] * m
    for idx, (u, edge_idx) in enumerate(edge_refs):
        e = G[u][edge_idx]
        rev = G[e.to][e.rev]
        used = rev.cap          # reverse edge capacity equals flow sent forward
        flow_on_edge[idx] = used

    # Now decompose the flow into per‑stream paths.
    # We'll work on a copy of the flow values on all edges (including super edges).
    # For simplicity we keep a separate adjacency list with mutable capacities.
    # We'll reuse G but interpret capacities as *remaining flow* (not residual).
    # First, set each edge's 'cap' to the amount of flow that currently passes
    # through it (i.e. forward flow). For original edges we already have it.
    # For super source/sink edges, the forward flow equals the original capacity
    # (they are saturated in a feasible solution).
    # Build a list of all edges that may carry flow.
    flow_adj = [[] for _ in range(n + 2)]
    # original edges
    for idx, (u, edge_idx) in enumerate(edge_refs):
        e = G[u][edge_idx]
        f = flow_on_edge[idx]
        if f:
            # store mutable copy
            flow_adj[u].append([e.to, f, idx])   # idx is original edge index
    # super source edges
    for e in G[S]:
        if e.cap == 0:   # saturated, flow = original capacity
            # find original capacity from reverse edge
            rev = G[e.to][e.rev]
            f = rev.cap
            if f:
                flow_adj[S].append([e.to, f, -1])   # -1 marks super edge
    # edges from t_i to T
    for v in range(n):
        for e in G[v]:
            if e.to == T:
                if e.cap == 0:
                    rev = G[T][e.rev]
                    f = rev.cap
                    if f:
                        flow_adj[v].append([T, f, -2])   # -2 marks sink edge

    # answer matrix
    ans = [[0] * m for _ in range(k)]

    # helper to find a path with DFS
    def dfs_path(v, target, visited, path):
        if v == target:
            return True
        visited[v] = True
        for i, (to, cap, eid) in enumerate(flow_adj[v]):
            if cap and not visited[to]:
                path.append((v, i))   # store vertex and index in its list
                if dfs_path(to, target, visited, path):
                    return True
                path.pop()
        return False

    # decompose
    while True:
        visited = [False] * (n + 2)
        path = []
        if not dfs_path(S, T, visited, path):
            break
        # determine minimal flow on this path
        delta = min(flow_adj[v][idx][1] for v, idx in path)
        # first edge tells the stream
        first_v, first_idx = path[0]
        to, _, eid = flow_adj[first_v][first_idx]
        # eid is -1 (super edge) -> need to know which stream it is.
        # The edge S->s_i corresponds to stream i; we can find i by matching to.
        stream_i = None
        for i, (s, t, d) in enumerate(streams):
            if s == to:
                stream_i = i
                break
        # subtract delta and record on original edges
        for v, idx in path:
            edge = flow_adj[v][idx]
            edge[1] -= delta
            if edge[2] >= 0:          # original edge
                ans[stream_i][edge[2]] += delta
        # remove zero‑capacity entries to keep DFS fast (optional)
        for v in range(n + 2):
            flow_adj[v] = [e for e in flow_adj[v] if e[1] > 0]

    # output
    out = ["YES"]
    for i in range(k):
        out.append(" ".join(str(x) for x in ans[i]))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
