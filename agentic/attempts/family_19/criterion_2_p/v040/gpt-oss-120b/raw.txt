**Solution Explanation**

For every agreement we have a directed edge  

```
u ──(capacity c)──► v
```

We have to send exactly `d` units from the source `s` to the sink `t`.
All intermediate vertices must satisfy flow‑conservation, i.e. the amount
entering equals the amount leaving.  
That is exactly the definition of a feasible **s‑t flow** of value `d`.

So the problem is reduced to

*find a flow of value `d` in a directed network with given capacities*.

If such a flow exists we also have to output the amount sent on every
original edge.



--------------------------------------------------------------------

#### 1.   Max‑flow algorithm (Dinic)

Dinic’s algorithm works in `O(E·√V)` for the given limits and is easy to
implement.

The algorithm maintains for each edge

* `to` – destination vertex
* `rev` – index of the reverse edge in the adjacency list of `to`
* `cap` – remaining capacity
* `orig_cap` – original capacity (only needed for debugging)

During the construction we also store, for every original agreement
(edge of the input), the index of the forward edge inside the adjacency
list. After the algorithm finishes the flow on that agreement is

```
flow = original_capacity - remaining_capacity_of_forward_edge
```

The algorithm is stopped as soon as the total sent flow reaches `d`,
therefore we never compute a flow larger than required.



--------------------------------------------------------------------

#### 2.   Correctness Proof  

We prove that the program prints **YES** and a correct allocation
iff such an allocation exists.

---

##### Lemma 1  
During Dinic’s execution the variable `total_flow` always equals the
value of the current `s‑t` flow (sum of flows on edges leaving `s`).

**Proof.**  
`total_flow` is increased only when augmenting a blocking flow.
Each augmentation adds the same amount `f` to every edge of the found
`s‑t` path, therefore the net flow out of `s` grows by exactly `f`.
No other operation changes `total_flow`. ∎



##### Lemma 2  
When Dinic terminates because `total_flow == d`, the residual network
contains **no** `s‑t` path with positive residual capacity.

**Proof.**  
Dinic stops only after a BFS/DFS phase fails to find an augmenting
path. The BFS builds the level graph using only edges with positive
residual capacity. If it fails, no such edge exists, i.e. no
`s‑t` path in the residual network. ∎



##### Lemma 3  
If the algorithm finishes with `total_flow == d`, the flow values stored
in the forward edges constitute a feasible flow of value `d`.

**Proof.**  
*Capacity*: a forward edge never carries more than its original capacity,
because we only push flow while residual capacity `> 0`.  
*Conservation*: for every internal vertex the amount added on incoming
edges equals the amount subtracted on outgoing edges – this is exactly the
definition of residual capacities and holds for any flow constructed by
augmenting paths.  
*Value*: by Lemma&nbsp;1 the net flow out of `s` equals `d`. ∎



##### Lemma 4  
If the algorithm finishes with `total_flow < d`, **no** feasible flow of
value `d` exists.

**Proof.**  
When Dinic stops because the BFS cannot reach `t`, the residual network
has no `s‑t` path (Lemma&nbsp;2). By the Max‑flow Min‑cut theorem the
value of any `s‑t` flow is bounded by the capacity of the cut
`(S, V\\S)` where `S` is the set of vertices reachable from `s` in the
residual graph. This capacity equals `total_flow`. Hence any feasible flow
has value ≤ `total_flow < d`. ∎



##### Lemma 5  
If a feasible flow of value `d` exists, Dinic will reach `total_flow = d`.

**Proof.**  
The classic Dinic algorithm computes a *maximum* flow.
Since a flow of value `d` exists, the maximum flow value is at least `d`.
Our implementation stops early once `total_flow` reaches `d`; therefore
it will certainly achieve that amount. ∎



##### Theorem  
The program outputs  

* `YES` and a list of `m` integers that satisfy all constraints  
  **iff** a feasible allocation exists,  

* otherwise it outputs `NO`.

**Proof.**  

*If part*:  
Assume the program prints `YES`. This happens only when Dinic ends with
`total_flow == d`. By Lemma&nbsp;3 the stored edge flows form a feasible
flow of value `d`. The printed numbers are exactly those flows, thus all
requirements are met.

*Only‑if part*:  
Assume a feasible allocation exists. By Lemma&nbsp;5 Dinic will obtain a
flow of value `d` and stop with `total_flow == d`. Consequently the
program prints `YES`.  

If no feasible allocation exists, Lemma&nbsp;4 shows that Dinic cannot
reach flow `d`; it terminates with `total_flow < d` and the program prints
`NO`. ∎



--------------------------------------------------------------------

#### 3.   Complexity Analysis  

*`V = n`*, `E = m` (original edges) → Dinic works on a graph with `2m`
directed edges (forward + reverse).

* **Time**: `O(E·√V)` ≤ `O(2·10^5·√10^5)` well below the 2 s limit.
* **Memory**: adjacency lists store `2E` edges → `O(E)` ≤ a few MB,
  far below 256 MB.



--------------------------------------------------------------------

#### 4.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

class Dinic:
    __slots__ = ('n', 'g', 'level', 'it')
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]

    def add_edge(self, fr, to, cap):
        fwd = [to, cap, None]          # to, cap, rev will be set later
        rev = [fr, 0, fwd]
        fwd[2] = rev
        self.g[fr].append(fwd)
        self.g[to].append(rev)
        return fwd                     # return forward edge object

    def bfs(self, s, t):
        level = [-1] * self.n
        q = [s]
        level[s] = 0
        for v in q:
            for to, cap, rev in self.g[v]:
                if cap and level[to] == -1:
                    level[to] = level[v] + 1
                    q.append(to)
        self.level = level
        return level[t] != -1

    def dfs(self, v, t, f):
        if v == t:
            return f
        for i in range(self.it[v], len(self.g[v])):
            self.it[v] = i
            to, cap, rev = self.g[v][i]
            if cap and self.level[v] + 1 == self.level[to]:
                ret = self.dfs(to, t, f if f < cap else cap)
                if ret:
                    self.g[v][i][1] -= ret
                    rev[1] += ret
                    return ret
        return 0

    def max_flow(self, s, t, limit):
        flow = 0
        INF = 10**18
        while flow < limit and self.bfs(s, t):
            self.it = [0] * self.n
            while flow < limit:
                pushed = self.dfs(s, t, limit - flow)
                if not pushed:
                    break
                flow += pushed
        return flow


def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    _ = next(it)          # the problem statement had a stray '1', ignore
    s = int(next(it)) - 1
    t = int(next(it)) - 1
    d = int(next(it))

    dinic = Dinic(n)
    edge_refs = []          # forward edge objects in input order
    caps = []               # original capacities for later output

    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        c = int(next(it))
        fwd = dinic.add_edge(u, v, c)
        edge_refs.append(fwd)
        caps.append(c)

    flow = dinic.max_flow(s, t, d)

    if flow != d:
        print("NO")
        return

    # compute flow on each original edge
    ans = []
    for fwd, cap in zip(edge_refs, caps):
        used = cap - fwd[1]   # original capacity minus remaining capacity
        ans.append(str(used))

    print("YES")
    print(" ".join(ans))


if __name__ == "__main__":
    solve()
```
