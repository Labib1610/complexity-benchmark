**Solution Explanation**

For every lane we know a maximal number of containers that may be sent through it.
We have to decide how many containers to send on each lane (non‑negative integer,
not larger than the lane’s ceiling) such that

* at every intermediate hub the amount arriving equals the amount leaving,
* at the origin `s` the net outflow equals the required amount `d`,
* at the destination `t` the net inflow equals `d`.

That is exactly the definition of a **feasible flow of value `d`** in a directed
network with capacities `ceil`.  
So the problem is reduced to the classic *maximum flow* problem:
if the maximum possible flow from `s` to `t` is at least `d`,
a feasible flow of value `d` exists; otherwise it does not.

We have to output one feasible flow of value exactly `d`.  
While computing the flow we stop as soon as the accumulated flow reaches `d`,
and we never push more than the still missing amount.  
Thus the obtained flow has value exactly `d`.

The algorithm used is **Dinic’s algorithm** – `O(E·√V)` in practice, easily fast
enough for the given limits.

--------------------------------------------------------------------

#### Algorithm
```
read n, m, dummy   (the third number is always 1 and unused)
read s, t, d
for each of the m lanes (u, v, cap):
        add a directed edge u → v with capacity = cap
        remember its position in the input (its index)

run Dinic(s, t, limit = d)               # stop when flow == d
if total_flow < d:
        print "NO"
else:
        for each original lane i (in input order):
                flow_i = original_capacity_i - remaining_capacity_i
        print "YES"
        print all flow_i separated by blanks
```

`Dinic(source, sink, limit)`  

```
flow = 0
while flow < limit and there exists a level graph (BFS):
        build level array
        initialise next edge pointer for each vertex
        while flow < limit:
                pushed = DFS(source, limit - flow, INF)
                if pushed == 0: break
                flow += pushed
return flow
```

The DFS never pushes more than the still missing amount (`limit - flow`), so the
final flow is exactly `d` when the algorithm succeeds.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct dispatch plan iff such a
plan exists.

---

##### Lemma 1  
During Dinic’s execution the residual network always respects the original
capacities: for every original edge `e` the flow on `e` never exceeds its ceiling.

**Proof.**  
An edge is added with capacity `c`. The algorithm only pushes flow through an
edge if the residual capacity (`cap` field) is positive, i.e. current flow
`f` satisfies `f < c`. After pushing `Δ`, the residual capacity becomes
`c - (f+Δ) ≥ 0`. Hence `f+Δ ≤ c`. ∎



##### Lemma 2  
When Dinic terminates with total flow `F`, the flow satisfies flow
conservation at every vertex except `s` and `t`.

**Proof.**  
Dinic maintains a residual graph; the only way flow is changed is by sending
`Δ` units along an `s‑t` path and simultaneously decreasing the reverse edges.
For every internal vertex the amount entering equals the amount leaving on that
path, therefore the net change of its excess is zero. Starting from zero excess,
the excess stays zero for all internal vertices. ∎



##### Lemma 3  
If the algorithm outputs `YES`, the printed numbers constitute a feasible flow
of value exactly `d`.

**Proof.**  
`YES` is printed only when Dinic returned a total flow `F = d`.  
By Lemma&nbsp;1 each edge’s flow respects its ceiling.  
By Lemma&nbsp;2 flow conservation holds at all intermediate vertices.  
The net outflow of `s` equals the total flow sent, i.e. `d`; similarly the net
inflow of `t` equals `d`.  
The printed numbers are exactly the amounts sent on the original edges
(`original capacity – remaining capacity`). Hence they describe a feasible flow
of value `d`. ∎



##### Lemma 4  
If a feasible flow of value `d` exists, Dinic will find a flow of value `d`
(and therefore the program prints `YES`).

**Proof.**  
Let `F_max` be the value of a maximum `s‑t` flow in the network.
Any feasible flow of value `d` shows that `F_max ≥ d`.  
Standard properties of Dinic guarantee that it computes a flow of value
`F_max`. Our implementation stops early once the accumulated flow reaches the
required limit `d`. Since `F_max ≥ d`, the algorithm will reach `d` before
exhausting all augmenting possibilities, and therefore returns flow `d`. ∎



##### Lemma 5  
If the program prints `NO`, no feasible flow of value `d` exists.

**Proof.**  
`NO` is printed only when Dinic terminates with total flow `F < d`.  
Dinic terminates only when no augmenting `s‑t` path exists in the residual
graph, i.e. the current flow is a maximum flow. Hence `F = F_max`.  
If `F_max < d`, a flow of value `d` cannot exist. ∎



##### Theorem  
The program outputs

* `YES` followed by a correct dispatch plan **iff** such a plan exists,
* otherwise `NO`.

**Proof.**  
*If* part: by Lemma&nbsp;4 a feasible plan implies Dinic reaches flow `d`,
so the program prints `YES`. By Lemma&nbsp;3 the printed plan is correct.

*Only‑if* part: if the program prints `YES`, Lemma&nbsp;3 gives a correct plan,
hence a plan exists. If it prints `NO`, Lemma&nbsp;5 shows no plan exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n` – number of hubs, `m` – number of lanes.

Dinic’s algorithm runs in `O(E·√V)` in the worst case, here `O(m·√n)`.  
All other work is linear.  
Memory consumption: adjacency lists store at most `2·m` edge objects → `O(m)`.



--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

class Edge:
    __slots__ = ('to', 'rev', 'cap', 'orig_cap', 'idx')
    def __init__(self, to, rev, cap, idx=-1):
        self.to = to          # target vertex
        self.rev = rev        # index of reverse edge in graph[to]
        self.cap = cap        # residual capacity
        self.orig_cap = cap   # original capacity (only for forward edges)
        self.idx = idx        # input index for original edges, -1 otherwise

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); _ = next(it)  # third number unused
    s = int(next(it)) - 1
    t = int(next(it)) - 1
    d = int(next(it))

    graph = [[] for _ in range(n)]
    edge_refs = [None] * m          # will store forward Edge objects

    def add_edge(fr, to, cap, idx=-1):
        fwd = Edge(to, len(graph[to]), cap, idx)
        rev = Edge(fr, len(graph[fr]), 0)
        graph[fr].append(fwd)
        graph[to].append(rev)
        return fwd

    for i in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        c = int(next(it))
        e = add_edge(u, v, c, i)
        edge_refs[i] = e

    # Dinic
    INF = 10**18
    level = [0] * n
    it_ptr = [0] * n

    from collections import deque

    def bfs():
        for i in range(n):
            level[i] = -1
        q = deque()
        level[s] = 0
        q.append(s)
        while q:
            v = q.popleft()
            for e in graph[v]:
                if e.cap > 0 and level[e.to] < 0:
                    level[e.to] = level[v] + 1
                    q.append(e.to)
        return level[t] >= 0

    def dfs(v, upTo):
        if v == t:
            return upTo
        for i in range(it_ptr[v], len(graph[v])):
            it_ptr[v] = i
            e = graph[v][i]
            if e.cap > 0 and level[e.to] == level[v] + 1:
                pushed = dfs(e.to, min(upTo, e.cap))
                if pushed:
                    e.cap -= pushed
                    graph[e.to][e.rev].cap += pushed
                    return pushed
        return 0

    flow = 0
    limit = d
    while flow < limit and bfs():
        it_ptr = [0] * n
        while flow < limit:
            pushed = dfs(s, limit - flow)
            if not pushed:
                break
            flow += pushed

    if flow < d:
        print("NO")
        return

    # retrieve flows on original edges
    res = [0] * m
    for i, e in enumerate(edge_refs):
        used = e.orig_cap - e.cap
        res[i] = used

    print("YES")
    print(' '.join(map(str, res)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
