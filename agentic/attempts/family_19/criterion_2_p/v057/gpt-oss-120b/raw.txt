**Solution Explanation**

For every corridor we have a capacity `cap`.  
We have to send exactly `d` pallets from the source yard `s` to the
destination yard `t`.  
All intermediate yards must satisfy flow conservation, i.e. the total
incoming flow equals the total outgoing flow.

The problem is exactly the classic *maximum s‑t flow* problem,
only we have to know whether a flow of value `d` exists and we have to
output one concrete flow.

--------------------------------------------------------------------

#### 1.   Flow model
* vertices – yards `1 … n`
* directed edges – corridors, capacity = given `cap`
* source – `s`
* sink   – `t`

A feasible routing is a feasible `s‑t` flow of value `d`.

--------------------------------------------------------------------

#### 2.   Algorithm
1. Build a flow network and run a **Dinic** maximum‑flow algorithm
   from `s` to `t`.  
   Let `f` be the obtained flow value.
2. If `f < d` → impossible, output `NO`.
3. Otherwise `f ≥ d`.  
   We already have a flow of value `f`.  
   To obtain exactly `d` we have to *remove* `f‑d` units of flow.
   This can be done by sending `f‑d` units **backwards**,
   i.e. run another Dinic from `t` to `s` on the *residual* network,
   limiting the amount to `f‑d`.  
   After that the net flow from `s` to `t` equals `d`.
4. Read the flow on every original corridor:
   `used = original_capacity – residual_capacity_of_forward_edge`.
5. Output `YES` and the list `used` in the input order.

Both Dinic runs are `O(E·√V)` in practice, easily fast enough for the
given limits (`2 s`, `256 MB`).

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct flow
iff a feasible routing of exactly `d` pallets exists.

---

##### Lemma 1  
After the first Dinic run the residual network represents all
augmenting possibilities for the current flow, and the flow value is
the maximum possible `s‑t` flow value `f_max`.

**Proof.** Dinic is a correct maximum‑flow algorithm. ∎



##### Lemma 2  
If `f_max < d` then no feasible routing of value `d` exists.

**Proof.** Any feasible routing is an `s‑t` flow of value `d`.  
The maximum possible flow value is `f_max`; therefore a flow of value
`d` cannot exist when `d > f_max`. ∎



##### Lemma 3  
Assume `f_max ≥ d`.  
After the second Dinic run (from `t` to `s`) sending exactly `Δ = f_max‑d`
units, the resulting flow from `s` to `t` has value `d`.

**Proof.**  
The second run works on the residual network of the first flow.
Sending one unit from `t` to `s` in that residual network corresponds to
decreasing the original `s‑t` flow by one unit (using a reverse edge).
Sending `Δ` units therefore reduces the original flow value from
`f_max` to `f_max‑Δ = d`. ∎



##### Lemma 4  
All edge capacities are respected after both runs.

**Proof.**  
Both Dinic executions maintain the invariant that for every edge
`0 ≤ flow ≤ capacity`.  
The second run only uses reverse edges of the residual network,
which never increase the flow on a forward edge beyond its capacity.
Thus capacities stay respected. ∎



##### Lemma 5  
The numbers reported for the original corridors equal the final flow
on those edges.

**Proof.** For an original edge we store the forward edge object.
Its residual capacity after both runs is `cap_res`.  
The original capacity is `cap`.  
The flow sent through the edge is `cap – cap_res`, which is exactly the
definition of flow value on that edge. ∎



##### Theorem  
The algorithm outputs  

* `NO` **iff** no feasible routing of exactly `d` pallets exists;  
* otherwise `YES` and a list of non‑negative integers that constitute a
  feasible routing of exactly `d` pallets respecting all capacities.

**Proof.**  

*If part.*  
If the algorithm prints `NO`, then `f_max < d` (step 2).  
By Lemma&nbsp;2 a flow of value `d` cannot exist, therefore no feasible
routing exists.

*Only‑if part.*  
Assume a feasible routing of value `d` exists.
Then the maximum flow value `f_max` is at least `d`.  
The algorithm proceeds to step 3, computes `Δ = f_max‑d` and runs the
second Dinic.  
By Lemma&nbsp;3 the final flow value is exactly `d`.  
Lemmas&nbsp;4 and&nbsp;5 guarantee that this flow respects capacities and
the reported numbers are its edge values.  
Thus the algorithm prints `YES` followed by a correct routing. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

Let `V = n`, `E = m`.

*First Dinic*: `O(E·√V)` (standard bound)  
*Second Dinic*: at most the same, but limited to `Δ ≤ f_max ≤ Σ cap`,
  still `O(E·√V)`.

Memory consumption: adjacency lists store two directed edges per
original edge → `O(E)`.

Both limits satisfy the problem constraints.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

class Edge:
    __slots__ = ('to', 'rev', 'cap', 'idx')
    def __init__(self, to, rev, cap, idx):
        self.to = to          # target vertex
        self.rev = rev        # index of reverse edge in graph[to]
        self.cap = cap        # residual capacity
        self.idx = idx        # original edge index or -1 for auxiliary edges

class Dinic:
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]

    def add_edge(self, fr, to, cap, idx=-1):
        fwd = Edge(to, len(self.g[to]), cap, idx)
        rev = Edge(fr, len(self.g[fr]), 0, -1)
        self.g[fr].append(fwd)
        self.g[to].append(rev)
        return fwd  # reference to forward edge

    def bfs(self, s, t, level):
        from collections import deque
        level[:] = [-1] * self.n
        q = deque([s])
        level[s] = 0
        while q:
            v = q.popleft()
            for e in self.g[v]:
                if e.cap and level[e.to] < 0:
                    level[e.to] = level[v] + 1
                    q.append(e.to)
        return level[t] >= 0

    def dfs(self, v, t, f, level, it):
        if v == t:
            return f
        for i in range(it[v], len(self.g[v])):
            it[v] = i
            e = self.g[v][i]
            if e.cap and level[v] + 1 == level[e.to]:
                ret = self.dfs(e.to, t, min(f, e.cap), level, it)
                if ret:
                    e.cap -= ret
                    self.g[e.to][e.rev].cap += ret
                    return ret
        return 0

    def max_flow(self, s, t, limit=None):
        flow = 0
        level = [0] * self.n
        INF = 10**18
        while self.bfs(s, t, level):
            it = [0] * self.n
            while True:
                f = self.dfs(s, t, INF if limit is None else limit - flow,
                             level, it)
                if not f:
                    break
                flow += f
                if limit is not None and flow >= limit:
                    return flow
        return flow

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); _ = int(next(it))  # third number is always 1
    s = int(next(it)) - 1
    t = int(next(it)) - 1
    d = int(next(it))

    dinic = Dinic(n)
    orig_edges = [None] * m          # store forward Edge reference
    caps = [0] * m

    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        cap = int(next(it))
        caps[idx] = cap
        e = dinic.add_edge(u, v, cap, idx)
        orig_edges[idx] = e

    f = dinic.max_flow(s, t)
    if f < d:
        print("NO")
        return

    # Reduce excess flow if needed
    excess = f - d
    if excess:
        dinic.max_flow(t, s, excess)

    # Retrieve flows
    res = []
    for idx, e in enumerate(orig_edges):
        used = caps[idx] - e.cap
        res.append(str(used))

    print("YES")
    print(' '.join(res))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
