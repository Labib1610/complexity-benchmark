**Solution Explanation**

The problem is exactly the classic *maximum flow* problem with a required amount `d`.

*   vertices – waystations,
*   directed edges – corridors,
*   edge capacity – physical size limit,
*   flow conservation – no storage in intermediate vertices,
*   source `s`, sink `t`,
*   we have to send **exactly** `d` units.

If the maximum possible flow from `s` to `t` is at least `d`, we can take any flow of value `d`
(e.g. the flow produced by a max‑flow algorithm while we stop as soon as `d` units are sent).
Otherwise the task is impossible.

So we only need a fast max‑flow algorithm.  
`n ≤ 10⁴`, `m ≤ 10⁵` (typical limits for this kind of problem) – Dinic’s algorithm
(`O(E·√V)` in practice) easily fits into the 2 s limit.

--------------------------------------------------------------------

#### Algorithm
```
read n, m, _
read s, t, d
for each of the m input edges (u, v, cap) keep its order index i
    add a directed edge u → v with capacity cap to the flow network
    remember the position of this edge inside the adjacency list

run Dinic(s, t, limit = d)          # stop once d units are sent
if total_flow < d:
        print "NO"
else:
        for each original edge i (in input order)
                flow_i = original_capacity_i - remaining_capacity_i
        print "YES"
        print all flow_i separated by blanks
```

`Dinic` works with the usual BFS level graph and DFS blocking flow.
The only modification is that the outer loop stops when the accumulated flow
reaches the required amount `d`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
During Dinic’s execution the amount of flow sent from `s` to `t` never exceeds the
capacity of any edge.

**Proof.**  
Dinic only pushes flow through residual edges whose residual capacity is positive.
When `x` units are pushed through an original edge, its residual capacity decreases
by `x`. Hence the total pushed flow on that edge is at most its original capacity. ∎



##### Lemma 2  
When Dinic terminates, the obtained flow `F` is a feasible flow
(i.e. respects capacities and flow conservation).

**Proof.**  
*Capacities*: by Lemma&nbsp;1.  
*Conservation*: the algorithm only adds flow along `s → … → t` paths.
For every internal vertex the amount added to its incoming edges equals the amount
added to its outgoing edges, therefore the net balance stays zero. ∎



##### Lemma 3  
If the algorithm prints `YES` and the list of edge values, those values constitute
a feasible flow of value exactly `d`.

**Proof.**  
`YES` is printed only when Dinic stopped after sending at least `d` units.
The algorithm stops **immediately** after reaching `d`, therefore the total
sent flow equals `d`.  
By Lemma&nbsp;2 the flow is feasible, and the printed numbers are exactly the
amount sent on each original edge (original capacity minus remaining capacity). ∎



##### Lemma 4  
If the algorithm prints `NO`, no feasible flow of value `d` exists.

**Proof.**  
`NO` is printed only when Dinic finishes (no augmenting path in the residual
graph) with total flow `< d`. At that moment the residual graph contains no
` s‑t ` path, i.e. the current flow is a **maximum** flow.
If a flow of value `d` existed, the maximum flow value would be at least `d`,
contradiction. ∎



##### Theorem  
The algorithm outputs

* `YES` and a correct allocation of cargo on the corridors **iff** such an
  allocation exists,
* otherwise outputs `NO`.

**Proof.**  
*If part*: existence ⇒ max flow ≥ d ⇒ Dinic reaches flow `d` ⇒ algorithm prints
`YES` and, by Lemma&nbsp;3, a correct allocation.

*Only‑if part*: algorithm prints `YES` ⇒ by Lemma&nbsp;3 a feasible flow of value
`d` is produced ⇒ allocation exists.  
If algorithm prints `NO` ⇒ by Lemma&nbsp;4 no feasible flow of value `d` exists. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n` vertices, `m` edges.

Dinic runs in `O(E·√V)` in practice; with the early stop after `d` units it is
even faster.  
Memory consumption: adjacency list stores two directed edges per input edge,
`O(n + m)`.

Both limits satisfy the given constraints.

--------------------------------------------------------------------

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

class Dinic:
    __slots__ = ('n', 'g', 'level', 'it')
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]

    def add_edge(self, fr, to, cap, idx=-1):
        # forward edge
        fwd = [to, cap, None, idx]   # to, cap, rev, idx
        # backward edge
        rev = [fr, 0, fwd, -1]
        fwd[2] = rev
        self.g[fr].append(fwd)
        self.g[to].append(rev)

    def bfs(self, s, t):
        level = [-1] * self.n
        q = [s]
        level[s] = 0
        for v in q:
            for to, cap, rev, _ in self.g[v]:
                if cap and level[to] < 0:
                    level[to] = level[v] + 1
                    q.append(to)
        self.level = level
        return level[t] >= 0

    def dfs(self, v, t, f):
        if v == t:
            return f
        for i in range(self.it[v], len(self.g[v])):
            self.it[v] = i
            to, cap, rev, _ = self.g[v][i]
            if cap and self.level[v] + 1 == self.level[to]:
                ret = self.dfs(to, t, min(f, cap))
                if ret:
                    self.g[v][i][1] -= ret
                    rev[1] += ret
                    return ret
        return 0

    def max_flow(self, s, t, limit):
        flow = 0
        INF = 10**18
        while flow < limit and self.bfs(s, t):
            self.it = [0] * self.n
            while flow < limit:
                pushed = self.dfs(s, t, limit - flow)
                if not pushed:
                    break
                flow += pushed
        return flow

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); _ = next(it)  # the third number is always 1
    s = int(next(it)) - 1
    t = int(next(it)) - 1
    d = int(next(it))

    dinic = Dinic(n)
    # store reference to the forward edge for each original edge
    edge_refs = [None] * m
    caps = [0] * m

    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        cap = int(next(it))
        caps[idx] = cap
        # add edge and keep reference to forward edge list object
        dinic.add_edge(u, v, cap, idx)
        edge_refs[idx] = dinic.g[u][-1]   # the forward edge just added

    flow = dinic.max_flow(s, t, d)
    if flow < d:
        print("NO")
        return

    # retrieve flows
    res = []
    for idx in range(m):
        fwd = edge_refs[idx]
        used = caps[idx] - fwd[1]   # original capacity minus remaining capacity
        res.append(str(used))

    print("YES")
    print(' '.join(res))

if __name__ == "__main__":
    solve()
```

the required input‑output format.
