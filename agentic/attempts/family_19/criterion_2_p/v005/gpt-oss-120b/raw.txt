**Solution Explanation**

The problem is a classic single‑commodity flow problem.

* there are `n` vertices, `m` directed edges,
* edge `j` has capacity `bays_j`,
* we have a source `s`, a sink `t` and a required amount `d`.

We have to decide whether a flow of value at least `d` exists and, if it does,
output one feasible flow (any flow of exactly `d` units).

The constraints are small enough for a standard max‑flow algorithm
(Dinic, Edmonds‑Karp, …).  
We use Dinic because it is fast and easy to stop once the required amount
`d` is reached.

--------------------------------------------------------------------

#### Algorithm
```
read input
build adjacency list, for every original edge store also a reference
    to the forward edge object (to read its flow later)

run Dinic(s, t, limit = d)          # stop as soon as total flow == d
if total_flow < d:
        print "NO"
else:
        for each original edge in input order:
                flow = original_capacity - forward_edge.remaining_capacity
        print "YES"
        print the m flows separated by blanks
```

**Dinic with early stop**

```
while total_flow < limit and bfs builds level graph:
        reset ptr array
        while total_flow < limit:
                pushed = dfs(s, INF)
                if pushed == 0: break
                total_flow += pushed
                if total_flow >= limit: break
```

`dfs` respects the remaining capacity of each edge and the level graph.
All operations are `O(m)` per BFS, total complexity `O(min(d, maxflow) * m)`
which is easily below the limits (`n ≤ 10^5` is not given, but 2 s is fine).

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
During Dinic execution each edge never carries more flow than its capacity
and flow conservation holds at every intermediate vertex.

**Proof.**  
The algorithm only pushes flow through an edge `e` by the amount
`δ ≤ e.cap` (the residual capacity). After the push the residual capacity
is decreased by `δ` and the reverse edge’s capacity is increased by `δ`,
exactly the standard residual‑graph update. Therefore the invariant
“flow ≤ capacity” is preserved.  
Every push adds `δ` to the out‑flow of the current vertex and `δ` to the
in‑flow of the next vertex, so the net excess of any internal vertex
remains unchanged. ∎



##### Lemma 2  
When Dinic terminates, the total amount of flow sent from `s` to `t`
equals the value `total_flow` returned by the algorithm.

**Proof.**  
`total_flow` is increased only when `dfs` returns a positive `pushed`
value, i.e. when `pushed` units are sent from `s` to `t` along an augmenting
path. By Lemma&nbsp;1 this augments a feasible flow, therefore the flow
value grows exactly by `pushed`. No other operation changes the flow value.
∎



##### Lemma 3  
If the algorithm finishes with `total_flow = d`, the flow values printed
for the original edges constitute a feasible flow of value `d`.

**Proof.**  
For each original edge we output  
`used = capacity - residual_capacity`.  
By construction of the residual graph this equals the amount of flow that
has been sent through that edge, which never exceeds its capacity
(Lemma&nbsp;1).  
All intermediate vertices keep zero excess (Lemma&nbsp;1), the source
has excess `d` (Lemma&nbsp;2) and the sink receives exactly `d`. Hence the
printed numbers describe a feasible flow of value `d`. ∎



##### Lemma 4  
If the algorithm finishes with `total_flow < d`, then **no** feasible flow
of value `d` exists.

**Proof.**  
Dinic stops only when the BFS can no longer reach `t` in the residual
graph, i.e. there is no augmenting path. By the Max‑Flow Min‑Cut theorem,
the current flow is a maximum flow. Its value is `total_flow < d`,
therefore a flow of value `d` cannot exist. ∎



##### Theorem  
The program outputs  

* “YES” and a correct flow of value `d` **iff** such a flow exists,
* otherwise it outputs “NO”.

**Proof.**  

*If the program prints “YES”.*  
It did so only when `total_flow ≥ d`. The algorithm stops as soon as
`total_flow` reaches `d`, therefore `total_flow = d`. By Lemma&nbsp;3 the
printed numbers form a feasible flow of value `d`.

*If a feasible flow of value `d` exists.*  
The maximum flow value is at least `d`. Dinic computes a maximum flow,
stopping early once `d` units have been sent, so it will reach `total_flow = d`
and output “YES”.

*If the program prints “NO”.*  
Then `total_flow < d`. By Lemma&nbsp;4 no flow of value `d` exists.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`BFS` builds the level graph in `O(m)`.  
Each `DFS` traverses each edge at most once per level graph, also `O(m)`.  
The number of BFS phases is `O(√V)` in the worst case, but we stop after
sending at most `d` units, so the total work is `O(min(d, maxflow) * m)`.  
With the given limits this easily fits into the 2 s time limit.

Memory consumption: adjacency list stores two directed edges per original
edge → `O(m)` edges, each with a few integers → `O(m)` memory, well below
256 MB.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

class Edge:
    __slots__ = ('to', 'rev', 'cap')
    def __init__(self, to, rev, cap):
        self.to = to          # target vertex
        self.rev = rev        # index of reverse edge in graph[to]
        self.cap = cap        # residual capacity

def add_edge(g, fr, to, cap):
    fwd = Edge(to, len(g[to]), cap)
    rev = Edge(fr, len(g[fr]), 0)
    g[fr].append(fwd)
    g[to].append(rev)
    return fwd  # reference to forward edge

def dinic(g, s, t, limit):
    n = len(g)
    level = [0] * n
    it = [0] * n

    from collections import deque

    def bfs():
        for i in range(n):
            level[i] = -1
        q = deque([s])
        level[s] = 0
        while q:
            v = q.popleft()
            for e in g[v]:
                if e.cap and level[e.to] < 0:
                    level[e.to] = level[v] + 1
                    q.append(e.to)
        return level[t] >= 0

    def dfs(v, f):
        if v == t:
            return f
        for i in range(it[v], len(g[v])):
            e = g[v][i]
            if e.cap and level[v] < level[e.to]:
                ret = dfs(e.to, f if f < e.cap else e.cap)
                if ret:
                    e.cap -= ret
                    g[e.to][e.rev].cap += ret
                    return ret
            it[v] += 1
        return 0

    flow = 0
    INF = 10**18
    while flow < limit and bfs():
        it = [0] * n
        while flow < limit:
            pushed = dfs(s, limit - flow)
            if not pushed:
                break
            flow += pushed
    return flow

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    _ = next(it)  # the third number on line 1 is unused in statement (maybe version)
    s = int(next(it)) - 1
    t = int(next(it)) - 1
    d = int(next(it))

    g = [[] for _ in range(n)]
    orig_edges = []          # (forward_edge_ref, capacity)
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        cap = int(next(it))
        fwd = add_edge(g, u, v, cap)
        orig_edges.append((fwd, cap))

    maxflow = dinic(g, s, t, d)
    if maxflow < d:
        sys.stdout.write("NO")
        return

    # retrieve flows
    flows = []
    for fwd, cap in orig_edges:
        used = cap - fwd.cap
        flows.append(str(used))
    sys.stdout.write("YES\n")
    sys.stdout.write(" ".join(flows))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
