We can model this as a **flow with lower bounds** problem.  
Each edge has capacity \( c_j \) and lower bound 0.  
We need to check if there is a feasible flow of value \( d \) from \( s \) to \(t\).

We can transform it into a **max-flow with lower bounds** problem:

- Add a super source \( S' \) and super sink \( T' \).
- For each node, compute \( \text{balance} = \text{incoming lower bound sum} - \text{outgoing lower bound sum} \). Since all lower bounds are 0, balance is 0 for all nodes initially.
- But we need to force flow \( d \) from \( s \) to \( t \).  
  We add an edge from \( t \) to \( s \) with capacity \( \infty \) (or \( d \)) to make it a circulation problem.
- Then we check feasibility of circulation with lower bounds.

However, since lower bounds are all 0, this reduces to:  
Is there a flow of value \( d \) from \( s \) to \( t \) in a directed graph with capacities?

We can solve by:
1. Add edge \( t \to s \) with capacity \( d \) (or large).
2. Add super source \( S' \) and super sink \( T' \).
3. For each node, compute net demand:  
   \( \text{demand}[v] = \text{incoming capacity sum} - \text{outgoing capacity sum} \).  
   If demand > 0, add edge \( S' \to v \) with capacity demand.  
   If demand < 0, add edge \( v \to T' \) with capacity -demand.
4. Run max flow from \( S' \) to \( T' \).  
   If all edges from \( S' \) are saturated, then a feasible circulation exists.
5. The flow on original edges plus the flow on \( t \to s \) gives the final flow.  
   The flow on \( t \to s \) must equal \( d \) for the demand to be satisfied.

We can implement using Dinic's algorithm.

Let's write the code.

import sys
from collections import deque

input = sys.stdin.readline

class Dinic:
    def __init__(self, n):
        self.n = n
        self.graph = [[] for _ in range(n)]
    
    def add_edge(self, u, v, cap):
        self.graph[u].append([v, cap, len(self.graph[v])])
        self.graph[v].append([u, 0, len(self.graph[u]) - 1])
    
    def bfs(self, s, t):
        self.level = [-1] * self.n
        q = deque()
        q.append(s)
        self.level[s] = 0
        while q:
            u = q.popleft()
            for v, cap, rev in self.graph[u]:
                if cap > 0 and self.level[v] < 0:
                    self.level[v] = self.level[u] + 1
                    q.append(v)
        return self.level[t] >= 0
    
    def dfs(self, u, t, f):
        if u == t:
            return f
        for i in range(self.it[u], len(self.graph[u])):
            v, cap, rev = self.graph[u][i]
            if cap > 0 and self.level[v] == self.level[u] + 1:
                ret = self.dfs(v, t, min(f, cap))
                if ret > 0:
                    self.graph[u][i][1] -= ret
                    self.graph[v][rev][1] += ret
                    return ret
            self.it[u] += 1
        return 0
    
    def max_flow(self, s, t):
        flow = 0
        INF = 10**18
        while self.bfs(s, t):
            self.it = [0] * self.n
            while True:
                f = self.dfs(s, t, INF)
                if f == 0:
                    break
                flow += f
        return flow

        elif diff < 0:

        # We'll find the edge object.

        # Simpler: store edge index in add_edge.

    # We'll rewrite with edge index tracking.
    
    class Dinic2:

    # Extract flow on each edge
    result = [0] * m

            if eid != -1 and eid < m:

    # After max flow, residual cap for original edge is cap in graph[u][i][1]

    result = [0] * m
