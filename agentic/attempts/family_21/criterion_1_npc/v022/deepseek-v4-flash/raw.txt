We need to isolate all root servers from each other by removing edges, with total cost ≤ B.  
This is essentially a **minimum cut** problem where we want to separate a set of terminals (root servers) from each other.  

A standard approach is to build a **multiway cut** problem, but since the graph is small enough (n, m up to maybe a few hundred), we can use a **minimum s-t cut** repeatedly.

A known method:  
- Add a super source connected to one root server with infinite capacity.  
- For each other root server, compute the min cut to separate it from the super source.  
- The minimum over all such cuts gives the cheapest set of edges to isolate that root from all others.  
- Repeat for all roots, but we need to isolate **all** roots from each other, not just one.

Actually, the problem is: remove edges so that no two roots are connected. This is the **multiway cut** problem, which is NP-hard in general.  
But here, the constraints are small enough that we can try a **brute-force over subsets** or use a **minimum cut tree** (Gomory-Hu tree) to find the minimum cost to separate all terminals.

A simpler approach:  
- Build a Gomory-Hu tree of the graph.  
- The minimum cost to separate all terminals is the sum of the minimum edge weights in the tree that separate the terminals.  
- We can then find the actual edges to remove by taking the cuts corresponding to those tree edges.

3. Compute Gomory-Hu tree using max-flow (Dinic’s).
4. In the Gomory-Hu tree, find the minimum cut that separates all root servers.  
   This is done by finding the minimum weight edge in the tree that, when removed, separates the roots into two non-empty sets.  
   We need to remove edges so that all roots are in different components.  
   The minimum cost is the sum of the smallest edges that separate the roots in the tree.

Actually, the multiway cut in a graph can be solved by taking the **minimum cut tree** and then finding the minimum set of edges to separate the terminals.  
The optimal solution is to take, for each pair of terminals, the minimum cut between them, but that’s not simply sum of min cuts.

The multiway cut on a tree: remove edges so that all terminals are separated.  
The optimal is to remove the minimum weight edge on each path between terminals, but we can do DP on tree.

Actually, the multiway cut on a tree is:  
- Root the tree at any node.  
- For each node, if it has terminals in more than one child subtree, we must cut some edges.  
- The optimal is to cut the minimum weight edge among the edges connecting the subtrees that contain terminals.

But we need the actual edges to remove, not just cost.

Let’s implement:

- Compute Gomory-Hu tree.
- The tree has n nodes, n-1 edges, each with a capacity equal to the min cut between the two sides.
- Now we need to find the minimum set of edges to remove so that all root servers are in different components.
- This is a multiway cut on a tree, which can be solved by DP.

DP on tree:
- Root the tree at any node (say 1).
- For each node, we compute the minimum cost to separate all terminals in its subtree, given that the component containing this node may or may not contain a terminal.

But we also need to output the edges.

Let’s do a recursive DP:

State: dp[u][mask] = minimum cost to separate terminals in subtree of u, where mask indicates which terminals are in the same component as u (but we only care about whether u's component contains a terminal or not, and which one).

Since k is small (maybe ≤ 10), we can use bitmask.

Let’s implement:

1. Build Gomory-Hu tree.
2. Root the tree at 0.
3. For each node, we have children.
4. For each child, we can either keep the edge (u-child) or cut it.
   - If we keep it, the child's component merges with u's component.
   - If we cut it, we pay the edge weight and the child's component is separate.

We need to ensure that no two terminals end up in the same component.

We can do DP with bitmask of terminals in the component containing u.

Let’s define:
- term_mask[u] = bitmask of terminals that are exactly at node u (if u is a terminal).
- For each node, we compute dp[u][mask] = min cost to handle subtree of u, where mask is the set of terminals in the component containing u (after processing subtree).  
  The mask must be a subset of terminals in subtree of u.

Transition:
- Start with dp[u][term_mask[u]] = 0.
- For each child v:
  - We have two options:
    1. Cut edge (u,v): pay w, and child's component must have no terminals? Actually, child's component can have terminals, but they must be separated from u's component. So we need to ensure that the child's component's terminal set is disjoint from u's mask.  
       So we take dp_child[child_mask] for any child_mask, and add w, and combine: new_mask = mask (since child's terminals are separate).
    2. Keep edge (u,v): then child's component merges with u's, so we need child_mask to be disjoint from mask, and new_mask = mask | child_mask. Cost = dp_child[child_mask].

We take min over all.

At the end, the answer is min over dp[root][mask] where mask has at most 1 terminal? Actually, the root's component can contain at most one terminal, because if it contains more than one, they are connected. So we need mask to have at most 1 bit set.

But we also need to ensure that all terminals are separated globally. The DP ensures that within each subtree, terminals are separated unless they are in the same component as u. At the root, we require that the root's component contains at most one terminal.

So answer = min(dp[root][mask] for mask with popcount ≤ 1).

We also need to output the edges. We can store the decisions.

Let’s implement carefully.

We need max-flow for Gomory-Hu tree. Use Dinic.

```python
import sys
from collections import deque

INF = 10**15

class Dinic:
    def __init__(self, n):
        self.n = n
        self.adj = [[] for _ in range(n)]
    
    def add_edge(self, u, v, cap):
        self.adj[u].append([v, cap, len(self.adj[v])])
        self.adj[v].append([u, 0, len(self.adj[u])-1])
    
    def bfs(self, s, t):
        self.level = [-1]*self.n
        q = deque([s])
        self.level[s] = 0
        while q:
            u = q.popleft()
            for v, cap, rev in self.adj[u]:
                if cap > 0 and self.level[v] == -1:
                    self.level[v] = self.level[u] + 1
                    q.append(v)
        return self.level[t] != -1
    
    def dfs(self, u, t, f):
        if u == t:
            return f
        for i in range(self.it[u], len(self.adj[u])):
            self.it[u] = i
            v, cap, rev = self.adj[u][i]
            if cap > 0 and self.level[v] == self.level[u] + 1:
                ret = self.dfs(v, t, min(f, cap))
                if ret > 0:
                    self.adj[u][i][1] -= ret
                    self.adj[v][rev][1] += ret
                    return ret
        return 0
    
    def max_flow(self, s, t):
        flow = 0
        while self.bfs(s, t):
            self.it = [0]*self.n
            while True:
                f = self.dfs(s, t, INF)
                if f == 0:
                    break
                flow += f
        return flow

def gomory_hu(n, edges):
    # edges: list of (u, v, w)
    parent = [0]*n
    capacity = [0]*n
    tree_edges = []
    for s in range(1, n):
        t = parent[s]
        dinic = Dinic(n)
        for u, v, w in edges:
            dinic.add_edge(u, v, w)
            dinic.add_edge(v, u, w)
        flow = dinic.max_flow(s, t)
        # find reachable nodes from s in residual graph
        visited = [False]*n
        q = deque([s])
        visited[s] = True
        while q:
            u = q.popleft()
            for v, cap, rev in dinic.adj[u]:
                if cap > 0 and not visited[v]:
                    visited[v] = True
                    q.append(v)
        # update parent for nodes in visited side
        for i in range(n):
            if i != s and visited[i] and parent[i] == t:
                parent[i] = s
        if visited[parent[t]]:
            parent[s] = parent[t]
            parent[t] = s
            capacity[s] = capacity[t]
            capacity[t] = flow
        else:
            capacity[s] = flow
        tree_edges.append((s, t, flow))
    # build tree adjacency
    tree = [[] for _ in range(n)]
    for u, v, w in tree_edges:
        tree[u].append((v, w))
        tree[v].append((u, w))
    return tree

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))
    B = int(next(it))
    roots = [int(next(it))-1 for _ in range(k)]
    edges = []
    for _ in range(m):
        u = int(next(it))-1
        v = int(next(it))-1
        w = int(next(it))
        edges.append((u, v, w))
    
    # Build Gomory-Hu tree
    tree = gomory_hu(n, edges)
    
    # Now solve multiway cut on tree
    # Root the tree at 0
    parent = [-1]*n
    children = [[] for _ in range(n)]
    order = [0]
    parent[0] = 0
    for u in order:
        for v, w in tree[u]:
            if v == parent[u]:
                continue
            parent[v] = u
            children[u].append((v, w))
            order.append(v)
    
    # term_mask for each node
    term_mask = [0]*n
    for idx, r in enumerate(roots):
        term_mask[r] |= (1 << idx)
    
    # DP
    # dp[u] = dict mapping mask -> (cost, decisions)
    # decisions: list of edges to cut in subtree
    dp = [None]*n
    
    # process in reverse order
    for u in reversed(order):
        # start with term_mask[u]
        cur = {term_mask[u]: (0, [])}
        for v, w in children[u]:
            new_cur = {}
            for mask_u, (cost_u, cuts_u) in cur.items():
                for mask_v, (cost_v, cuts_v) in dp[v].items():
                    # option 1: cut edge (u,v)
                    if mask_u & mask_v == 0:
                        new_mask = mask_u
                        new_cost = cost_u + cost_v + w
                        new_cuts = cuts_u + cuts_v + [(u, v)]
                        if new_mask not in new_cur or new_cost < new_cur[new_mask][0]:
                            new_cur[new_mask] = (new_cost, new_cuts)
                    # option 2: keep edge (u,v)
                    if mask_u & mask_v == 0:
                        new_mask = mask_u | mask_v
                        new_cost = cost_u + cost_v
                        new_cuts = cuts_u + cuts_v
                        if new_mask not in new_cur or new_cost < new_cur[new_mask][0]:
                            new_cur[new_mask] = (new_cost, new_cuts)
            cur = new_cur
        dp[u] = cur
    
    # find best at root
    best_cost = INF
    best_cuts = None
    for mask, (cost, cuts) in dp[0].items():
        if bin(mask).count('1') <= 1 and cost < best_cost:
            best_cost = cost
            best_cuts = cuts
    
    if best_cost > B:
        print("NO")
    else:
        print("YES")
        print(len(best_cuts))
        for u, v in best_cuts:
            print(u+1, v+1)

if __name__ == "__main__":
    solve()
```
