**Solution Explanation**

For every pipe we have to decide whether it stays open or is capped.
All catalyst units (the *special* vertices) must end up in different
connected components of the remaining open pipes.

--------------------------------------------------------------------

#### 1.   Reformulation

Let  

* `E` – the set of all pipes, each pipe `e` has a capping cost `w(e)`.
* `S` – the set of special vertices.

If we **keep** a pipe we do **not** pay its cost,
if we **remove** (cap) it we pay `w(e)`.

```
total_cost_of_capping = Σ w(e)   (e removed)
```

`Σ w(e)` over all pipes is a constant `W`.  
Therefore

```
total_cost_of_capping ≤ B    ⇔    Σ w(e) (kept) ≥ W – B
```

So we have to **keep** a set of pipes with maximum possible total weight,
subject to the only restriction:

*in the graph formed by the kept pipes no component may contain two
different special vertices.*

If we can keep pipes of total weight `K` with `K ≥ W‑B`,
the answer is *YES* and we cap all other pipes.

--------------------------------------------------------------------

#### 2.   Greedy choice – maximum weight feasible forest

Consider any set of kept pipes that satisfies the restriction.
It is a **forest** (acyclic), because adding a cycle would not help
the weight and would never violate the restriction.
Thus the kept pipes form a forest where each tree contains **at most one**
special vertex.

The family of such forests is a **matroid** (the graphic matroid
intersected with a partition matroid that forbids two specials in one
tree).  
For a matroid the greedy algorithm that processes elements in
*decreasing* order of weight and adds an element whenever it does not
break independence is optimal for the maximum‑weight independent set
problem.

Consequences  

* sort all edges by decreasing `w`
* scan them, try to add the current edge to the forest
* we may add it **iff** its two endpoints belong to different components
  **and** those two components do **not both already contain a special
  vertex**.

The test is performed with a Disjoint Set Union (DSU) that also stores
for each component a boolean `has_special`.

The edges that are added are the **kept** edges, all others will be
capped.

The algorithm is `O(m log m)` because of the sorting, DSU operations are
inverse‑Ackermann.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
During the algorithm the set `F` of kept edges is always a forest in
which each connected component contains at most one special vertex.

**Proof.**  
Initially `F` is empty – the statement holds.
When an edge `e = (u,v)` is considered, we add it only if the DSU
components of `u` and `v` are different **and** not both already have a
special vertex.  
If the components are different, adding `e` cannot create a cycle,
hence `F` stays a forest.
The additional condition guarantees that after the union the new
component still contains at most one special vertex. ∎



##### Lemma 2  
Let `E_desc` be the edges sorted by non‑increasing weight.
When the algorithm finishes, `F` is a **maximum‑weight** set of edges
that satisfies the condition of Lemma&nbsp;1.

**Proof.**  
The family of admissible edge sets (forests with ≤1 special per component)
is a matroid:
* hereditary – any subset of an admissible set is admissible,
* exchange property – standard for graphic matroid, the extra
  “≤1 special per component” is a partition matroid, the intersection of
  two matroids is a matroid.

For any matroid, the greedy algorithm that scans elements in decreasing
weight and inserts an element whenever it keeps independence yields a
maximum‑weight independent set (standard matroid theorem).  
Our algorithm is exactly this greedy procedure, therefore `F` is
maximum‑weight. ∎



##### Lemma 3  
Let `K = Σ w(e)` over edges `e ∈ F`.  
If `K ≥ W – B` then capping all edges not in `F` costs at most `B`.

**Proof.**  
`W` is the sum of weights of **all** edges.

```
cost_of_capping = W – K
```

If `K ≥ W – B` then `W – K ≤ B`. ∎



##### Lemma 4  
If the algorithm outputs **YES**, the printed set of capped edges indeed
separates every pair of special vertices.

**Proof.**  
The kept edges are exactly `F`.  
By Lemma&nbsp;1 each component of `F` contains at most one special vertex,
hence no two specials are connected by uncapped pipes.
All other edges are capped, therefore the printed set satisfies the
requirement. ∎



##### Lemma 5  
If there exists *any* feasible capping plan with total cost ≤ `B`,
the algorithm will output **YES**.

**Proof.**  
Any feasible plan corresponds to a set `K` of kept edges that satisfies
the condition of Lemma&nbsp;1, and its total kept weight is at least
`W – B`.  
By Lemma&nbsp;2 our greedy set `F` has weight `K_max ≥ weight(K) ≥ W – B`.  
Thus `K_max ≥ W – B` and by Lemma&nbsp;3 the algorithm will deem the
budget sufficient and answer **YES**. ∎



##### Theorem  
The program prints

* “YES” and a correct list of pipes to cap **iff** such a list exists
  with total cost ≤ `B`;
* otherwise prints “NO”.

**Proof.**  
*If the program prints YES*: by Lemma&nbsp;4 the printed set is feasible,
and by Lemma&nbsp;3 its total cost does not exceed `B`.

*If a feasible solution exists*: by Lemma&nbsp;5 the algorithm will find
`K ≥ W – B` and therefore print YES.

If the algorithm prints NO, the condition `K ≥ W – B` is false,
hence any feasible set would have weight `< W – B`, i.e. cost `> B`,
so no solution respecting the budget exists. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Sorting* `m` edges: `O(m log m)`  
*DSU* operations: `O(m α(n))` (inverse Ackermann)  

Memory: the edge list, DSU arrays and a boolean array – `O(n + m)`.

Both limits satisfy the given constraints.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    k = int(next(it))
    B = int(next(it))
    specials = set(int(next(it)) - 1 for _ in range(k))  # zero‑based
    edges = []
    total = 0
    for idx in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        edges.append((w, u, v, idx))
        total += w

    # DSU with special flag
    parent = list(range(n))
    rank = [0] * n
    has_special = [i in specials for i in range(n)]

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(x, y):
        rx, ry = find(x), find(y)
        if rx == ry:
            return False
        # cannot unite if both components already have a special
        if has_special[rx] and has_special[ry]:
            return False
        # union by rank
        if rank[rx] < rank[ry]:
            rx, ry = ry, rx
        parent[ry] = rx
        if rank[rx] == rank[ry]:
            rank[rx] += 1
        has_special[rx] = has_special[rx] or has_special[ry]
        return True

    # greedy maximum weight forest
    edges.sort(key=lambda x: -x[0])          # descending weight
    kept = [False] * m
    kept_weight = 0
    for w, u, v, idx in edges:
        if union(u, v):
            kept[idx] = True
            kept_weight += w

    if total - kept_weight <= B:
        # feasible
        out = []
        out.append("YES")
        # edges to cap = those not kept
        cap = [(u+1, v+1) for w, u, v, idx in edges if not kept[idx]]
        out.append(str(len(cap)))
        out.extend(f"{a} {b}" for a, b in cap)
        sys.stdout.write("\n".join(out))
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
