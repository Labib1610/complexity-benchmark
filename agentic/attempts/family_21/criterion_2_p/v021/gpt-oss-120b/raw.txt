**Solution Explanation**

The problem asks for any set of edges whose removal disconnects `s` from `t`
and whose total cost does not exceed `B`.
The cheapest possible set is exactly the *minimum s‑t cut* of the undirected
graph where each edge has capacity equal to its cost.
If the value of this minimum cut is `≤ B` we can output the edges of that cut,
otherwise the answer is impossible.

The minimum cut of an undirected graph can be found by any max‑flow algorithm
after replacing every undirected edge by two opposite directed edges of the same
capacity.  
We use Dinic’s algorithm (`O(E·√V)` in practice) which easily fits the limits.

After the max‑flow finishes we run a DFS/BFS in the *residual* network starting
from `s`.  
All vertices reached belong to the source side `S` of the minimum cut,
the remaining vertices belong to the sink side `T`.  
Every original edge with one endpoint in `S` and the other in `T` belongs to the
cut; the sum of their capacities equals the max‑flow value.

---

#### Algorithm
```
read n, m, s, t, B
store the list of original edges (u, v, w)

build a directed flow graph:
    for each undirected edge (u,v,w):
        add directed edge u→v capacity w
        add directed edge v→u capacity w
        remember the index of the original edge for later output

run Dinic(s, t) → maxflow = value of minimum cut

if maxflow > B:
        print "NO"
else:
        bfs/dfs in residual graph from s → reachable set S
        cut_edges = []
        for each original edge (u,v,w):
                if (u in S) xor (v in S):
                        cut_edges.append((u,v))
        print "YES"
        print len(cut_edges)
        for (u,v) in cut_edges: print u, v
```

The algorithm is correct because:

* Max‑flow = minimum s‑t cut (Max‑Flow Min‑Cut Theorem).
* The reachable set after the flow gives exactly the source side of *some*
  minimum cut; the edges crossing the partition are a minimum‑cost set whose
  total weight equals the max‑flow value.
* If this value ≤ `B` we have found a feasible solution; otherwise no cut with
  total weight ≤ `B` exists.

Complexities  

*Time* – Dinic `O(E·√V)` (well within 2 s for typical constraints).  
*Memory* – `O(E)` for the flow graph and the original edge list.

#### Reference Implementation (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

class Dinic:
    __slots__ = ('n', 'g', 'level', 'it')
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]

    def add_edge(self, fr, to, cap):
        # forward edge
        fwd = [to, cap, None]
        # backward edge
        rev = [fr, 0, fwd]
        fwd[2] = rev
        self.g[fr].append(fwd)
        self.g[to].append(rev)

    def bfs(self, s, t):
        level = [-1] * self.n
        q = [s]
        level[s] = 0
        for v in q:
            for to, cap, rev in self.g[v]:
                if cap and level[to] < 0:
                    level[to] = level[v] + 1
                    q.append(to)
        self.level = level
        return level[t] >= 0

    def dfs(self, v, t, f):
        if v == t:
            return f
        for i in range(self.it[v], len(self.g[v])):
            self.it[v] = i
            to, cap, rev = self.g[v][i]
            if cap and self.level[v] + 1 == self.level[to]:
                ret = self.dfs(to, t, min(f, cap))
                if ret:
                    self.g[v][i][1] -= ret
                    rev[1] += ret
                    return ret
        return 0

    def max_flow(self, s, t):
        flow = 0
        INF = 10**18
        while self.bfs(s, t):
            self.it = [0] * self.n
            while True:
                f = self.dfs(s, t, INF)
                if not f:
                    break
                flow += f
        return flow

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it)); m = int(next(it)); s = int(next(it))-1; t = int(next(it))-1; B = int(next(it))
    edges = []
    dinic = Dinic(n)
    for _ in range(m):
        u = int(next(it))-1; v = int(next(it))-1; w = int(next(it))
        edges.append((u, v, w))
        dinic.add_edge(u, v, w)
        dinic.add_edge(v, u, w)

    min_cut = dinic.max_flow(s, t)

    if min_cut > B:
        print("NO")
        return

    # find reachable vertices in residual graph
    from collections import deque
    q = deque([s])
    reachable = [False]*n
    reachable[s] = True
    while q:
        v = q.popleft()
        for to, cap, rev in dinic.g[v]:
            if cap and not reachable[to]:
                reachable[to] = True
                q.append(to)

    cut_edges = []
    for u, v, w in edges:
        if reachable[u] ^ reachable[v]:
            cut_edges.append((u+1, v+1))

    print("YES")
    print(len(cut_edges))
    out = sys.stdout
    for u, v in cut_edges:
        out.write(f"{u} {v}\n")

if __name__ == "__main__":
    solve()
```
