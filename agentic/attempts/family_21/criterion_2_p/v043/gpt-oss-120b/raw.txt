**Solution Explanation**

The problem asks for a set of edges whose total removal cost does not exceed `B` and after removing them there is no path from `s` to `t`.
That is exactly the *minimum s‑t cut* problem in an undirected graph where the
capacity of an edge equals its removal cost.
If the value of the minimum cut is larger than `B` the task is impossible,
otherwise any minimum cut (or any cut whose value ≤ `B`) is a valid answer.

So we have to

1. compute the value of a minimum `s‑t` cut,
2. if it is ≤ `B` output the edges that belong to this cut.

The classic way to obtain a minimum cut is to run a maximum flow algorithm
(e.g. Dinic) and then look at the vertices reachable from `s` in the residual
network.  
All original edges that go from a reachable vertex to a non‑reachable vertex
form a minimum cut.

The graph is undirected, therefore each input edge `(u,v,w)` is replaced by
two directed edges `u→v` and `v→u` both with capacity `w`.  
The cut value is the sum of capacities of the original undirected edges that
cross the partition, which is exactly the total cost of removing those edges.

`n ≤ 10⁵` is not given, but the limits (2 s, 256 MiB) allow a standard Dinic
implementation (`O(E·√V)` in practice) for typical contest constraints.

--------------------------------------------------------------------

#### Algorithm
```
read n, m, s, t, B
store all original edges in a list orig = [(u,v,w), ...]

build a directed graph:
    for each (u,v,w):
        add_edge(u, v, w)   // forward edge
        add_edge(v, u, w)   // backward edge (capacity w as well)

run Dinic(s, t) → maxflow = value of minimum cut

if maxflow > B:
    print "NO"
    exit

// retrieve the cut
BFS/DFS from s in the residual graph using only edges with remaining capacity > 0
let reachable = set of visited vertices

cut_edges = []
for each (u,v,w) in orig:
    if (u in reachable) xor (v in reachable):
        cut_edges.append((u,v))

print "YES"
print len(cut_edges)
for (u,v) in cut_edges:
    print u, v
```

#### Correctness Proof  

We prove that the algorithm prints a correct answer.

---

**Lemma 1**  
In the constructed directed graph, the capacity of any `s‑t` cut equals the sum
of removal costs of the undirected edges that cross the corresponding partition
of vertices.

*Proof.*  
For each undirected edge `{u,v}` with cost `w` we added two directed edges
`u→v` and `v→u`, each of capacity `w`.  
Consider a partition `(S, V\S)` with `s∈S`, `t∉S`.  
Exactly one of the two directed edges goes from `S` to `V\S`; its capacity is
`w`. The opposite directed edge goes from `V\S` to `S` and does **not** belong
to the cut (cut edges are only those directed from `S` to `V\S`).  
Hence the total capacity contributed by this original edge to the cut is `w`,
the same as its removal cost. Summing over all edges gives the claim. ∎



**Lemma 2**  
The value returned by Dinic equals the minimum possible total removal cost of
edges whose deletion separates `s` from `t`.

*Proof.*  
By the Max‑Flow Min‑Cut theorem, the maximum flow value equals the minimum
capacity of an `s‑t` cut in the directed graph. By Lemma&nbsp;1 this capacity
is exactly the total removal cost of the corresponding set of undirected
edges. Therefore the maximum flow value is the minimum possible total removal
cost. ∎



**Lemma 3**  
After the flow finishes, let `R` be the set of vertices reachable from `s`
in the residual graph (edges with positive residual capacity).  
Then the set `C = { (u,v) ∈ orig | u∈R, v∉R or v∈R, u∉R }` is an `s‑t` cut whose
total cost equals the maximum flow value.

*Proof.*  
Standard property of residual graphs: no edge with positive residual capacity
goes from `R` to `V\R`; otherwise its head would also be reachable.  
Thus every original undirected edge crossing the partition contributes its full
capacity to the cut (its directed counterpart from `R` to `V\R` is saturated,
i.e. residual capacity 0). Consequently the cut capacity equals the sum of
capacities of saturated forward edges, which is exactly the flow value. ∎



**Lemma 4**  
If the algorithm outputs the edges in `C`, their total cost does not exceed `B`.

*Proof.*  
From Lemma&nbsp;3 the total cost of `C` equals the maximum flow value.
The algorithm checks `maxflow ≤ B` before outputting, therefore the cost is ≤ `B`. ∎



**Theorem**  
The algorithm prints `NO` iff it is impossible to separate `s` from `t` by
removing edges of total cost at most `B`; otherwise it prints `YES` and a set of
edges whose total cost ≤ `B` that indeed separates `s` from `t`.

*Proof.*  

*If part.*  
If the algorithm prints `NO`, then `maxflow > B`. By Lemma&nbsp;2 any set of
edges separating `s` and `t` has total cost at least `maxflow`, thus > `B`. So
separation within budget is impossible.

*Only‑if part.*  
Assume there exists a set `E'` of edges with total cost ≤ `B` separating `s`
from `t`. Its cost is a feasible `s‑t` cut, therefore by Lemma&nbsp;2
`maxflow ≤` cost(`E'`) ≤ `B`. The algorithm will not output `NO`.  
It then outputs the cut `C` from Lemma&nbsp;3. By Lemma&nbsp;4 its total cost
≤ `B`. Because `C` consists exactly of edges crossing the partition `(R,
V\R)`, removing them disconnects `s` from `t`. Hence the printed set is a
valid solution. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

Let `V = n`, `E = m`.

* Building the graph: `O(E)`.
* Dinic: `O(E·√V)` in typical cases, well within the limits for the given
  constraints (2 seconds, 256 MiB).
* BFS for reachable vertices: `O(E)`.
* Scanning original edges to build the answer: `O(E)`.

Memory consumption: adjacency list stores two directed edges per original edge,
each with a few integers → `O(E)`.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

class Dinic:
    __slots__ = ('n', 'g', 'level', 'it')
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]

    def add_edge(self, fr, to, cap):
        fwd = [to, cap, None]          # to, cap, rev
        rev = [fr, 0, fwd]
        fwd[2] = rev
        self.g[fr].append(fwd)
        self.g[to].append(rev)

    def bfs(self, s, t):
        level = [-1] * self.n
        q = [s]
        level[s] = 0
        for v in q:
            for to, cap, rev in self.g[v]:
                if cap and level[to] == -1:
                    level[to] = level[v] + 1
                    q.append(to)
        self.level = level
        return level[t] != -1

    def dfs(self, v, t, f):
        if v == t:
            return f
        for i in range(self.it[v], len(self.g[v])):
            self.it[v] = i
            to, cap, rev = self.g[v][i]
            if cap and self.level[v] + 1 == self.level[to]:
                ret = self.dfs(to, t, min(f, cap))
                if ret:
                    self.g[v][i][1] -= ret
                    rev[1] += ret
                    return ret
        return 0

    def max_flow(self, s, t):
        flow = 0
        INF = 10**18
        while self.bfs(s, t):
            self.it = [0] * self.n
            while True:
                f = self.dfs(s, t, INF)
                if not f:
                    break
                flow += f
        return flow

    def reachable_from(self, s):
        seen = [False] * self.n
        stack = [s]
        seen[s] = True
        while stack:
            v = stack.pop()
            for to, cap, rev in self.g[v]:
                if cap and not seen[to]:
                    seen[to] = True
                    stack.append(to)
        return seen


def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    s = int(next(it)) - 1
    t = int(next(it)) - 1
    B = int(next(it))

    edges = []
    dinic = Dinic(n)
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        edges.append((u, v, w))
        dinic.add_edge(u, v, w)
        dinic.add_edge(v, u, w)

    min_cut = dinic.max_flow(s, t)

    if min_cut > B:
        print("NO")
        return

    reachable = dinic.reachable_from(s)
    cut_edges = []
    total = 0
    for u, v, w in edges:
        if reachable[u] ^ reachable[v]:
            cut_edges.append((u + 1, v + 1))
            total += w

    # total should be equal to min_cut (sanity)
    print("YES")
    print(len(cut_edges))
    out = sys.stdout
    for a, b in cut_edges:
        out.write(f"{a} {b}\n")

if __name__ == "__main__":
    solve()
```
