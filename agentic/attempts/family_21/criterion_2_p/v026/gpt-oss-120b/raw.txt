**Solution Explanation**

For the given undirected graph each edge has a cost `w`.  
We have to delete a set of edges whose total cost does not exceed `B` and after
deleting them there is no path between `s` and `t`.

The cheapest possible set of edges that separates `s` from `t` is exactly the
*minimum s‑t cut* of the graph where every edge capacity equals its cost.
If the weight of this minimum cut is `C`

* if `C ≤ B` we can delete the edges of this cut – they are cheap enough,
  and any cut with weight `≤ B` is a valid answer.
* otherwise no cut with total weight `≤ B` exists, because the minimum one is
  already heavier than `B`.

So the problem reduces to

```
find the minimum s‑t cut in an undirected weighted graph
```

and then output the edges that belong to this cut.

--------------------------------------------------------------------

#### 1.   Max‑flow / Min‑cut

For a directed graph the value of a maximum `s‑t` flow equals the capacity of
a minimum `s‑t` cut (Max‑flow Min‑cut theorem).  
An undirected edge of capacity `w` can be replaced by two opposite directed
edges each of capacity `w`. The minimum cut of the resulting directed graph
has the same weight as the minimum cut of the original undirected graph.

We therefore run a standard max‑flow algorithm (Dinic) on the directed
representation.

Complexities  

* `O(E·√V)` in practice, well below the limits for the given constraints.  
* Memory `O(E)`.

--------------------------------------------------------------------

#### 2.   Recovering the cut edges

After the max‑flow finishes we run a BFS/DFS in the **residual** network
starting from `s` and follow only edges with positive residual capacity.
All vertices reached belong to the *source side* `S` of the minimum cut,
the remaining vertices belong to the *sink side* `T`.

For every original undirected edge `{u,v}`

```
if (u in S and v in T) or (v in S and u in T):
        edge belongs to the cut
```

The sum of their costs equals the flow value (the minimum cut weight).

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints a correct answer.

---

##### Lemma 1  
Replacing each undirected edge of capacity `w` by two opposite directed edges
of capacity `w` does not change the value of a minimum `s‑t` cut.

**Proof.**  
Consider any cut `(S,T)` in the undirected graph. Its weight is the sum of
`w` over edges with one endpoint in `S` and the other in `T`.  
In the directed version exactly one of the two opposite arcs crosses the cut,
contributing `w` to the directed cut capacity. Hence the directed cut weight
equals the undirected one. Conversely, any directed cut corresponds to the same
undirected cut. ∎



##### Lemma 2  
After Dinic finishes, the set `R` of vertices reachable from `s` in the
residual network is exactly the source side `S` of a minimum `s‑t` cut.

**Proof.**  
Standard property of any max‑flow algorithm: after reaching a maximum flow,
no augmenting `s‑t` path exists, i.e. there is no residual edge from `R` to
`V\R`. Therefore `(R, V\R)` is an `s‑t` cut. Its capacity equals the flow
value (max‑flow min‑cut theorem), thus it is a minimum cut. ∎



##### Lemma 3  
An original undirected edge `{u,v}` belongs to the minimum cut iff exactly one
of `u,v` is in `R`.

**Proof.**  
By Lemma&nbsp;2 `R` is the source side of a minimum cut. By definition of a cut,
an edge is crossing the cut precisely when its endpoints lie on opposite
sides. ∎



##### Lemma 4  
The algorithm outputs a set of edges whose total cost equals the minimum
`s‑t` cut weight.

**Proof.**  
The algorithm selects exactly the edges described in Lemma&nbsp;3, therefore
their total weight is the capacity of the cut `(R, V\R)`. By Lemma&nbsp;2 this
capacity equals the minimum cut weight. ∎



##### Lemma 5  
If the algorithm prints `YES`, the printed edges separate `s` and `t` and their
total cost does not exceed `B`.

**Proof.**  
`YES` is printed only when `flow ≤ B`. By Lemma&nbsp;4 the printed edges have
total weight `flow`. Removing them disconnects `s` from `t` because they are
exactly the edges of a cut separating the two sides. Hence the weight is
`≤ B`. ∎



##### Lemma 6  
If the algorithm prints `NO`, no set of edges with total cost `≤ B` can separate
`s` and `t`.

**Proof.**  
`NO` is printed only when `flow > B`. `flow` is the weight of a minimum cut
(Lemmas&nbsp;1‑2). Any set of edges that separates `s` and `t` must contain a cut,
hence its total weight is at least the minimum cut weight `flow`. Since
`flow > B`, no such set can have weight `≤ B`. ∎



##### Theorem  
The algorithm always outputs a correct answer to the problem.

**Proof.**  
Two cases:

*If a feasible solution exists.*  
Then the minimum cut weight `C ≤ B`. Dinic computes `flow = C`. The algorithm
prints `YES` and, by Lemma&nbsp;5, a valid set of edges.

*If no feasible solution exists.*  
Then every cut has weight `> B`, in particular the minimum cut weight `C > B`.
Dinic returns `flow = C > B`, the algorithm prints `NO`. By Lemma&nbsp;6 this
is correct.

Thus the output is correct in all cases. ∎

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

class Dinic:
    __slots__ = ('n', 'g', 'level', 'it')
    def __init__(self, n):
        self.n = n
        self.g = [[] for _ in range(n)]

    def add_edge(self, fr, to, cap):
        forward = [to, cap, None]   # to, cap, rev
        backward = [fr, 0, forward]
        forward[2] = backward
        self.g[fr].append(forward)
        self.g[to].append(backward)

    def bfs(self, s, t):
        level = [-1] * self.n
        q = [s]
        level[s] = 0
        for v in q:
            for to, cap, rev in self.g[v]:
                if cap and level[to] < 0:
                    level[to] = level[v] + 1
                    q.append(to)
        self.level = level
        return level[t] >= 0

    def dfs(self, v, t, f):
        if v == t:
            return f
        for i in range(self.it[v], len(self.g[v])):
            self.it[v] = i
            to, cap, rev = self.g[v][i]
            if cap and self.level[v] + 1 == self.level[to]:
                ret = self.dfs(to, t, min(f, cap))
                if ret:
                    self.g[v][i][1] -= ret
                    rev[1] += ret
                    return ret
        return 0

    def max_flow(self, s, t):
        flow = 0
        INF = 10**18
        while self.bfs(s, t):
            self.it = [0] * self.n
            while True:
                f = self.dfs(s, t, INF)
                if not f:
                    break
                flow += f
        return flow

    def reachable_from(self, s):
        seen = [False] * self.n
        stack = [s]
        seen[s] = True
        while stack:
            v = stack.pop()
            for to, cap, rev in self.g[v]:
                if cap and not seen[to]:
                    seen[to] = True
                    stack.append(to)
        return seen


def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    s = int(next(it)) - 1
    t = int(next(it)) - 1
    B = int(next(it))

    edges = []
    dinic = Dinic(n)
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        w = int(next(it))
        edges.append((u, v, w))
        # undirected -> two directed edges
        dinic.add_edge(u, v, w)
        dinic.add_edge(v, u, w)

    min_cut = dinic.max_flow(s, t)

    if min_cut > B:
        print("NO")
        return

    reachable = dinic.reachable_from(s)
    cut_edges = []
    for u, v, w in edges:
        if reachable[u] ^ reachable[v]:
            cut_edges.append((u + 1, v + 1))

    print("YES")
    print(len(cut_edges))
    out = sys.stdout
    for u, v in cut_edges:
        out.write(f"{u} {v}\n")

if __name__ == "__main__":
    solve()
```
