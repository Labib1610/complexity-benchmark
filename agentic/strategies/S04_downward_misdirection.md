id: S04
summary: Make a hard problem present as if it had an easy shortcut.
classes: NPC
perturbation_family: misleading_cue (complexity-directed)

TRUTH CONSTRAINT (non-negotiable): every claim you make about the problem must be
factually correct. You are shaping emphasis, salience, and expectation — never facts. A
statement that is misleading because it is false is invalid and will be rejected.

Frame the problem so its surface features resemble a tractable variant: emphasise
regularity, suggest the data is well behaved, foreground properties that would matter if
a shortcut existed. Every constraint must remain exactly as in the seed. A model that
reasons carefully will still see the real difficulty.
