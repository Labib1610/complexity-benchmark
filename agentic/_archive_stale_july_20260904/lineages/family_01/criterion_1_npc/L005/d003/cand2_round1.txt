<STATEMENT>
# Problem A — Phase Resonance Protocol

Time limit: 2 s
Memory limit: 256 MB

You are tasked with calibrating a quantum communication grid comprising $n$ signal emitters, uniquely identified by integers from 1 to $n$. Calibration requires tuning each emitter to one of three discrete phase states, denoted by the values 1, 2, and 3. 

The emitters are interconnected by $m$ bidirectional physical conduits. To prevent a catastrophic resonance cascade, any two emitters linked by a conduit must operate at different phase states (i.e., the absolute difference between their phase state values must be strictly greater than zero). Your objective is to find a valid phase state assignment for the entire grid.

If multiple safe configurations are possible, the protocol mandates selecting the lexicographically smallest assignment sequence. (A sequence $A$ is lexicographically smaller than sequence $B$ if $A$ contains a smaller phase state value at the first emitter index where they differ). If no such safe configuration exists, you must report that initialization is impossible.

Please note: The evaluation suite deliberately includes complex grid topologies at the maximum emitter count. These test cases are specifically designed so that fixed-order, step-by-step assignment testing will evaluate an excessive number of partial configurations and exceed the time limit.

## Input
The first line provides two integers $n$ and $m$ — the number of emitters and the number of conduits. 
The mainframe controlling the grid possesses exactly 40 processing cores. Since each emitter requires an exclusive core, $n$ is at least 1 and at most the total core count. The number of conduits $m$ ranges from zero up to the theoretical maximum where every distinct pair of emitters is directly linked.

The following $m$ lines each contain two integers $u$ and $v$, representing the identifiers of two emitters bridged by a conduit. As they are valid identifiers, they correspond to the assigned sequence starting from 1 up to the given count of emitters. There is at most one conduit between any specific pair of emitters, and no conduit links an emitter to itself.

## Output
If the grid cannot be initialized without a resonance cascade, output a single line containing `NO`.
If a safe assignment exists, output `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the phase state for each emitter from 1 to $n$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit numeric bounds with physical constraints derived from a 40-core mainframe and the structural limits of distinct pairs, forcing the model to deduce $N \le 40$ and $M \le N(N-1)/2$. Additionally, I added a warning that fixed-order step-by-step assignment testing will exceed the time limit on complex topologies, which targets and discourages naive sequential backtracking implementations without using forbidden algorithmic terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The core logic of finding a valid assignment from the set {1, 2, 3} where connected entities differ, and selecting the lexicographically smallest sequence, remains identical.
</PRESERVED_ANSWER>
