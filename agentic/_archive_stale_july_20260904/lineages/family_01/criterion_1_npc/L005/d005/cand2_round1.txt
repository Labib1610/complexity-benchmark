<STATEMENT>
# Problem A — Resonance Tuning Protocol

Time limit: 2 s
Memory limit: 256 MB

A quantum communication grid is composed of $n$ active signal emitters, identified by integers from 1 up to $n$. The installation is physically constrained to a maximum of 40 emitter bays. 

During the initialization phase, every emitter must be calibrated with a specific tuning frequency. The available frequency parameters are exactly 1, 2, and 3.

The grid utilizes $m$ direct transmission conduits, which can range in quantity from 0 up to $n(n-1)/2$. Each conduit links exactly two distinct emitters. To maintain stability, there is a critical safety threshold based on the symmetric phase coupling of the conduit's endpoints. Whenever a conduit links two emitters with assigned tuning frequencies $p$ and $q$, their phase state is governed by the following system of equations:

$p \cdot x + q \cdot y = 1$  
$q \cdot x + p \cdot y = 1$

The conduit is considered stable if and only if this system yields exactly one unique simultaneous solution for the real variables $x$ and $y$. If the system lacks a unique solution (for instance, if it has infinitely many valid solutions for $x$ and $y$), a resonance cascade will occur. Your task is to find a frequency calibration for all $n$ emitters that avoids a cascade.

Should the grid be impossible to safely initialize, your program must report this failure. Given that multiple stable calibrations might exist, the system demands the lexicographically smallest sequence of frequencies. (A frequency sequence $A$ is lexicographically smaller than sequence $B$ if $A$ contains a lower frequency value at the first emitter index where the two sequences differ).

## Input
The first line provides two integers $n$ and $m$ (1 ≤ $n$ ≤ 40, 0 ≤ $m$ ≤ $n(n−1)/2$) — the number of active emitters and the number of active conduits.
The following $m$ lines each provide two integers $u$ and $v$ (1 ≤ $u, v$ ≤ $n$, $u \neq v$), indicating the identifiers of two emitters connected by a conduit.

## Output
If it is impossible to initialize the grid without causing a resonance cascade, output a single line containing `NO`.
If a valid calibration sequence exists, output `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the assigned frequency for each emitter from 1 to $n$. This sequence must be the lexicographically smallest valid calibration.

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
1 4
2 4
```
**Output:**
```
YES
1 2 3 3
```

## Example 2
**Input:**
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
**Output:**
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the explicit "product is not a perfect square" condition with a symmetric system of linear equations that has a unique solution if and only if the two frequencies are distinct. This removes the surface-level competitive programming trope that instantly gives away the graph coloring nature, forcing the model to algebraically deduce the $p \neq q$ constraint before it can apply the intended backtracking algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The linear system has a unique solution exactly when its determinant $p^2 - q^2$ is non-zero, which for strictly positive frequencies $p, q \in \{1, 2, 3\}$ is mathematically identical to $p \neq q$, preserving all valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest valid 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might overthink the real variables $x$ and $y$ and attempt to build an equation solver inside their search loop instead of simplifying the condition to $p \neq q$ beforehand, which could lead to Time Limit Exceeded, though competent models should easily evaluate the determinant.
</RISK>
