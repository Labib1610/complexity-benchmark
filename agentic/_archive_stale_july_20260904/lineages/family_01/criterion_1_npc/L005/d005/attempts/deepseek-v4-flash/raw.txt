 We need to assign each vertex a value from {1, 2, 3} such that for every edge (u, v),  
p_u + p_v does not divide p_u² + p_v².

Let’s analyze the condition:

We have:  
p_u + p_v | p_u² + p_v²  

We can rewrite:  
p_u² + p_v² = (p_u + p_v)² - 2 p_u p_v  

So the condition becomes:  
p_u + p_v | (p_u + p_v)² - 2 p_u p_v  
⟹ p_u + p_v | 2 p_u p_v  

Since p_u, p_v ∈ {1, 2, 3}, we can check all pairs:

- (1,1): sum=2, 2*1*1=2 → 2 divides 2 → invalid  
- (1,2): sum=3, 2*1*2=4 → 3 does not divide 4 → valid  
- (1,3): sum=4, 2*1*3=6 → 4 does not divide 6 → valid  
- (2,2): sum=4, 2*2*2=8 → 4 divides 8 → invalid  
- (2,3): sum=5, 2*2*3=12 → 5 does not divide 12 → valid  
- (3,3): sum=6, 2*3*3=18 → 6 divides 18 → invalid  

So the only invalid pairs are (1,1), (2,2), (3,3).  
That means: **No edge can connect two vertices with the same value.**

Thus the problem reduces to:  
Given a graph, can we 3-color it so that no two adjacent vertices share the same color?  
And we need the lexicographically smallest assignment.

This is exactly graph 3-coloring, which is NP-hard in general, but n ≤ 40, so we can use backtracking with pruning.

We'll assign values 1, 2, 3 in order, trying smallest first, and backtrack if conflict.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def dfs(idx):
    if idx == n:
        return True
    for c in (1, 2, 3):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if dfs(idx + 1):
                return True
            color[idx] = 0
    return False

if dfs(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
