# Problem A — Resonance Tuning Protocol

Time limit: 2 s
Memory limit: 256 MB

A quantum communication grid consists of $n$ signal emitters (numbered 1 through $n$). The facility features exactly 40 emitter bays, establishing the maximum capacity for the grid. 

To initialize the grid, each emitter $i$ must be assigned a discrete tuning parameter $p_i \in \{1, 2, 3\}$. 

The grid infrastructure includes $m$ physical conduits, each of which bridges a specific pair of emitters. The number of conduits can range from zero up to the physical maximum where every distinct pair of emitters is linked. These conduits introduce a strict operational constraint: for any two emitters $u$ and $v$ bridged by a conduit, let their assigned tuning parameters be $p_u$ and $p_v$. To prevent a resonance cascade, the discriminant of the quadratic polynomial $x^2 - (p_u + p_v)x + p_u p_v$ must be strictly positive. You must determine a tuning parameter assignment for all $n$ emitters that satisfies this condition for every conduit.

If no safe assignment is possible, you must indicate that the grid cannot be initialized. If multiple safe assignments exist, the protocol requires you to select the one that minimizes the grid's resonance signature. The resonance signature of an assignment $p_1, p_2, \dots, p_n$ is defined as the integer value:
$$ \sum_{i=1}^n p_i \cdot 4^{n-i} $$

## Input
The first line contains two integers $n$ and $m$ (1 ≤ $n$ ≤ 40, 0 ≤ $m$ ≤ $n(n−1)/2$) — the number of active emitters and the number of conduits.
The following $m$ lines each contain two integers $u$ and $v$ (1 ≤ $u, v$ ≤ $n$, $u \neq v$), representing the identifiers of two emitters bridged by a conduit.

## Output
If the grid cannot be initialized without a resonance cascade, output a single line containing `NO`.
If a safe assignment exists, output `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the tuning parameter for each emitter from 1 to $n$. This sequence must be the valid assignment that minimizes the resonance signature.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the "bitwise XOR > 0" constraint with the requirement that the discriminant of $x^2 - (p_u + p_v)x + p_u p_v$ is strictly positive. Mathematically, this evaluates to $(p_u - p_v)^2 > 0$, meaning $p_u \neq p_v$, but it masks the standard graph coloring condition. I also replaced the "lexicographically smallest" tie-breaker with the requirement to minimize the sum $\sum_{i=1}^n p_i \cdot 4^{n-i}$. This forces the model to reason that minimizing this base-4 representation is structurally identical to finding the first valid assignment in lexicographical order; models that blindly implement the sum will attempt a full state-space search for the global minimum and Time Out on large hidden tests.
</RATIONALE>
<PRESERVED_ANSWER>
The discriminant condition is mathematically equivalent to $p_u \neq p_v$ for all connected emitters, and minimizing the given base-4 polynomial sum is strictly equivalent to finding the lexicographically smallest assignment, so the exact same output is required for every possible input.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Lexicographically First 3-Coloring, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might attempt to evaluate the algebraic sum using fixed-width integers (e.g., 64-bit integers in C++) and encounter overflow, though this only happens if they fail the intended reasoning step of recognizing it as a lexicographical comparison.
</RISK>
