We can model this as a graph coloring problem with 3 colors (frequencies 1, 2, 3), where the constraint is that adjacent vertices cannot have a product that is a perfect square.  

The only perfect squares possible from {1,2,3} are:  
- 1×1 = 1  
- 2×2 = 4  
- 3×3 = 9  

So the forbidden pairs are (1,1), (2,2), (3,3).  
That means: **adjacent vertices must have different frequencies**.  

Thus, the problem reduces to:  
- Can we 3-color the graph?  
- If yes, find the lexicographically smallest coloring.

Since n ≤ 40, we can use backtracking with pruning.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    n, m = int(input_data[0]), int(input_data[1])
    adj = [[] for _ in range(n)]
    idx = 2
    for _ in range(m):
        u = int(input_data[idx]) - 1
        v = int(input_data[idx+1]) - 1
        idx += 2
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n  # 0 = uncolored, 1,2,3 = frequencies
    
    def backtrack(pos):
        if pos == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[pos]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[pos] = c
                if backtrack(pos + 1):
                    return True
                color[pos] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
