<STATEMENT>
# Problem A — Hydro-Pneumatic System

Time limit: 2 s
Memory limit: 256 MB

You are configuring a hydro-pneumatic network consisting of $n$ pressure nodes, numbered 1 through $n$. Each node must be set to a stable pressure state. There are exactly three allowed pressure states for any node: 1, 2, or 3.

The network contains $m$ capillary tubes, each establishing a direct fluid connection between a specific pair of nodes. To prevent fluid stagnation, every capillary tube requires a strict pressure differential across it. This means that for the two nodes connected by any tube, one node must have a strictly higher pressure state than the other.

You must determine if there is a way to assign a pressure state to all $n$ nodes such that every capillary tube maintains a strict pressure differential.

If no valid assignment is possible, the network cannot be activated. If multiple valid assignments exist, you must choose the one that is lexicographically smallest. An assignment $A$ is lexicographically smaller than assignment $B$ if, at the lowest node index where they differ, assignment $A$ uses a lower pressure state than assignment $B$.

## Input
The first line contains two integers $n$ and $m$ — the number of nodes and the number of capillary tubes (1 ≤ $n$ ≤ 40, 0 ≤ $m$ ≤ $n(n−1)/2$).
The following $m$ lines each contain two integers $u$ and $v$, representing the identifiers of two nodes that are connected by a capillary tube.

## Output
If the network cannot be activated safely, output a single line with `NO`.
If a valid state assignment exists, output `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the assigned pressure state for each node $i$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The scenario has been entirely reframed from mechanical dials locking to a hydro-pneumatic network requiring pressure differentials. The core "not equal" constraint (which previously gave away the 3-coloring nature) is now disguised as a requirement that "one node must have a strictly higher pressure state than the other". This forces models to deduce that a strict inequality in either direction is mathematically equivalent to simply forbidding equal values.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed states remain 1, 2, and 3, and the constraint that one node's state must be strictly higher than the other's is equivalent to $u \neq v$, preserving all valid assignments and the lexicographical tie-breaker perfectly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Lexicographically First 3-Coloring, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "one node must have a strictly higher pressure state than the other" as a directed constraint (e.g., $u > v$ based on input order), although the phrasing explicitly applies symmetrically to "the two nodes connected by any tube".
</RISK>
