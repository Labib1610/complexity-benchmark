# Problem A — Harmonic Grid Calibration

Time limit: 2 s
Memory limit: 256 MB

A quantum communication grid is composed of $n$ active signal emitters, identified by integers from 1 up to $n$. The installation is physically constrained to a maximum of 40 emitter bays. 

During the initialization phase, every emitter must be calibrated with a specific tuning frequency. The available frequency parameters are exactly 1, 2, and 3.

The grid utilizes $m$ direct transmission conduits, which can range in quantity from 0 up to $n(n-1)/2$. Each conduit links exactly two emitters. To maintain stability, there is a critical safety threshold: whenever two emitters $u$ and $v$ are linked by a conduit, their frequencies $p_u$ and $p_v$ must not cause a resonance cascade. 

A cascade is avoided if and only if the characteristic polynomial of the conduit, defined as 
$$f(x) = x^3 - (p_u + p_v + 4)x^2 + (p_u p_v + 4p_u + 4p_v)x - 4p_u p_v$$
has exactly three distinct roots. Your task is to find a frequency calibration for all $n$ emitters that avoids a cascade on every conduit.

Should the grid be impossible to safely initialize, your program must report this failure. Given that multiple stable calibrations might exist, the system requires the configuration that minimizes the total energy footprint $E$. The energy footprint is calculated as $E = \sum_{i=1}^n p_i \cdot W_i$, where the weights are defined by $W_n = 1$ and $W_i = 4 \cdot W_{i+1}$ for $1 \le i < n$. It can be shown that if valid calibrations exist, exactly one will strictly minimize $E$.

## Input
The first line provides two integers $n$ and $m$ (1 ≤ $n$ ≤ 40, 0 ≤ $m$ ≤ $n(n−1)/2$) — the number of active emitters and the number of active conduits.
The following $m$ lines each provide two integers $u$ and $v$ (1 ≤ $u, v$ ≤ $n$, $u \neq v$), indicating the identifiers of two emitters connected by a conduit.

## Output
If it is impossible to initialize the grid without causing a resonance cascade, output a single line containing `NO`.
If a valid calibration sequence exists, output `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the assigned frequency for each emitter from 1 to $n$. This sequence must be the unique valid calibration that minimizes the energy footprint $E$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The Vandermonde determinant was replaced with a cubic polynomial that expands from $(x-p_u)(x-p_v)(x-4)$, which has exactly three distinct roots if and only if $p_u \neq p_v$. The "lexicographically smallest" tie-break was replaced with a mathematically equivalent objective: minimizing an exponentially weighted sum $E$ with a base of 4. Because the base is strictly greater than the maximum possible frequency value (3), the configuration that minimizes $E$ is identical to the lexicographically smallest sequence. Models relying on surface-level pattern matching will likely attempt to compute $E$ and exhaustively search the valid configurations to find the global minimum, leading to a Time Limit Exceeded (TLE) on 40-vertex graphs. Models that genuinely reason about algorithmic structure will recognize the equivalence and implement an optimal early-exit greedy DFS.
