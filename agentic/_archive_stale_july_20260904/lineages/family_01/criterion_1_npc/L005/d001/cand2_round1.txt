<STATEMENT>
# Problem A — The Tri-State Vault

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a vault secured by a network of $n$ sequential dials. Each dial incorporates a triangular core, meaning it must be configured to rest at exactly one of three distinct angles (designated by the values 1, 2, and 3). 

The vault's interior contains $m$ rigid interference bars. Each bar spans between a specific pair of dials. If the two dials connected by a bar are configured to the exact same angle, the bar binds and the entire system locks up permanently. Opening the vault requires assigning an angle to every dial such that no interference bar binds. 

The interference bars are arranged in dense, interlocking patterns where many dials mutually constrain each other. Because a configuration choice for one dial ripples through the system and constrains distant dials, the layouts contain deep interdependencies.

The vault's control panel has a total surface area of 400 square centimeters, and each dial requires exactly 10 square centimeters of space, strictly capping the maximum number of dials. The vault always features at least one dial. The number of interference bars can be as low as zero, or as high as the physical limit where every unique pair of dials is connected by exactly one bar.

You must determine a valid configuration of angles for all $n$ dials that avoids binding, or report that the system is permanently locked. 

## Input
The first line contains two integers $n$ and $m$ — the number of dials and the number of interference bars.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ — the identifiers of two dials connected by an interference bar. Dials are identified by integers starting from 1 up to $n$.

## Output
If there is no configuration of dial angles that avoids binding, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), with $p_i$ representing the angle of dial $i$. Among all successful configurations, you must output the one that is lexicographically smallest. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index where they differ, sequence $A$ has a smaller angle value than sequence $B$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The numeric bounds ($n \le 40$ and $m \le n(n-1)/2$) have been removed from the Input section and replaced with physical constraints in the scenario description (a 400 cm² panel with 10 cm² per dial, and the maximum possible pairs). This forces the model to read and comprehend the scenario text to derive the problem's scale, disrupting basic pattern-matching on standard input constraint formats. Additionally, structural descriptions of "dense, interlocking patterns" and "deep interdependencies" have been added to warn against naive unoptimized backtracking without using banned complexity vocabulary.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still asks for the lexicographically smallest valid assignment of values {1,2,3} to $n$ variables such that no two variables connected by an edge share the same value, which is mathematically identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the 3-Coloring problem on a general graph, which is NP-complete, and the requirement for the lexicographically smallest valid assignment is unchanged.
</PRESERVED_CLASS>
<RISK>
Models could theoretically misinterpret "every unique pair of dials is connected by exactly one bar" as meaning the graph must be a clique, but the phrasing explicitly states this is only the *upper limit* for $m$, which should prevent ambiguity for a careful reader.
</RISK>
