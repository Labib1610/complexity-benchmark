<STATEMENT>
# Problem A — Harmonic Grid Calibration

Time limit: 2 s
Memory limit: 256 MB

A quantum communication grid is composed of $n$ active signal emitters, identified by integers from 1 up to $n$. The grid is built on a standard hardware chassis that reserves exactly enough bays for a $5 \times 8$ rectangular array of emitters. The number of active emitters $n$ will never exceed this physical bay limit.

During the initialization phase, every emitter must be calibrated with a specific tuning frequency. The available frequency parameters are exactly 1, 2, and 3.

The grid utilizes $m$ direct transmission conduits. The conduits are deployed from a finite spool containing exactly enough material to establish one direct connection between every distinct pair of active emitters (the theoretical maximum). The actual number of active conduits $m$ can be anything from 0 up to this limit. Each conduit links exactly two distinct emitters. 

To maintain stability, the system imposes a critical safety threshold on every conduit based on the assigned frequencies. For any conduit linking emitter $u$ and emitter $v$, the system constructs a $2 \times 2$ calibration matrix:
$$ C_{u,v} = \begin{bmatrix} u & v \\ u \cdot p_u & v \cdot p_v \end{bmatrix} $$
where $p_u$ and $p_v$ are the tuning frequencies selected for emitters $u$ and $v$, respectively. A resonance cascade will occur if this matrix is singular (i.e., if its determinant is exactly zero). Your task is to find a frequency calibration for all $n$ emitters such that every conduit's calibration matrix is non-singular.

Should the grid be impossible to safely initialize, your program must report this failure. Given that multiple stable calibrations might exist, the system demands the lexicographically smallest sequence of frequencies. (A frequency sequence $A$ is lexicographically smaller than sequence $B$ if $A$ contains a lower frequency value at the first emitter index where the two sequences differ).

## Input
The first line provides two integers $n$ and $m$ — the number of active emitters and the number of active conduits. (Based on the hardware constraints described above, $n \ge 1$ and $m \ge 0$, and neither will exceed their respective maximum capacities).
The following $m$ lines each provide two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating the identifiers of two emitters connected by a conduit.

## Output
If it is impossible to initialize the grid without causing a resonance cascade, output a single line containing `NO`.
If a valid calibration sequence exists, output `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2, 3\}$), representing the assigned frequency for each emitter from 1 to $n$. This sequence must be the lexicographically smallest valid calibration.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit divisibility constraint with a requirement that a 2x2 matrix built from the endpoints and their frequencies must be non-singular. I also applied Strategy S07, hiding the explicit $n \le 40$ bound behind a physical description of a $5 \times 8$ hardware chassis. This forces the model to mathematically deduce that the determinant evaluates to a non-zero value if and only if the frequencies are unequal, while simultaneously removing the small explicit N bound that usually triggers a backtracking template.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the calibration matrix is $uv(p_v - p_u)$, which, since emitter indices $u$ and $v$ are strictly positive, equals zero if and only if $p_u = p_v$; this is mathematically identical to the original problem's constraint that connected emitters must have different frequencies.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains Lexicographically Smallest 3-Coloring on a general graph, which is NP-complete.
</PRESERVED_CLASS>
