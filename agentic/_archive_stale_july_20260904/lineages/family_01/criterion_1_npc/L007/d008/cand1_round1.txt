<STATEMENT>
# Problem A — Security Clearance Resolution

Time limit: 2 s   Memory limit: 256 MB

A secure facility is configuring the access levels for a network of $n$ interdependent modules. Each module must receive exactly one access level from the set $\{1, 2, 3\}$.

To prevent critical vulnerabilities, the facility evaluates the entire network's configuration using a harmonic tuning model based on $m$ separation protocols. Each protocol specifies a pair of interacting modules. 

When a module $u$ is assigned an access level $c_u \in \{1, 2, 3\}$ and a module $v$ is assigned an access level $c_v \in \{1, 2, 3\}$, their pairwise harmonic resonance $H(u, v)$ across a separation protocol is calculated as the sum of their access level ratios:
$$ H(u, v) = \frac{c_u}{c_v} + \frac{c_v}{c_u} $$

A separation protocol is considered perfectly tuned if its harmonic resonance is strictly a non-integer value (i.e., it evaluates to a number with a non-zero fractional component). 

The entire network is deemed completely stable if and only if all $m$ separation protocols are perfectly tuned.

The test suite contains maximum-size adversarial instances. Naive generation of all assignments will result in an astronomical number of dead ends and will exceed the time limit before a stable state is found or proven impossible.

Your task is to determine if there exists a complete access assignment that makes the network completely stable. If at least one valid assignment exists, you must identify the one that is lexicographically smallest.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). These represent the total number of modules and the number of separation protocols, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that module $u$ and module $v$ are linked by a separation protocol.

## Output
If no completely stable assignment can be found, print `NO` on a single line.
If a stable assignment is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$) representing the access level assigned to each respective module. Among all valid stable configurations, the sequence of access levels you output must be the lexicographically smallest (i.e., comparing the access level of module 1 first, then module 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The previous problem statement used 3D polarization vectors and a global dot-product sum of $-3m$ to encode the constraint $c_u \neq c_v$. Models recognized this specific energy-minimization framing and mapped it directly to standard 3-coloring. By changing the constraint to a local harmonic ratio ($c_u/c_v + c_v/c_u$) that must be strictly non-integer, the model is forced to algebraically evaluate the 9 possible pairs to deduce that the property holds if and only if $c_u \neq c_v$. This prevents surface-level pattern matching on the global sum while preserving the exact underlying logic.
</RATIONALE>
<PRESERVED_ANSWER>
For $x, y \in \{1, 2, 3\}$, the expression $x/y + y/x$ evaluates to exactly 2 (an integer) if $x = y$, and evaluates to 2.5, 3.33..., or 2.166... (strictly non-integers) if $x \neq y$, meaning a protocol is perfectly tuned if and only if its modules have different access levels.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly lexicographically-smallest proper 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
