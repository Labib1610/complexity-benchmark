# Problem A — Security Clearance Resolution

Time limit: 2 s   Memory limit: 256 MB

A secure facility is configuring the access levels for a network of $n$ interdependent modules. Each module must receive exactly one access level from the set $\{1, 2, 3\}$.

To prevent critical vulnerabilities, the facility evaluates the entire network's configuration using an algebraic stability model based on $m$ separation protocols. Each protocol specifies a pair of interacting modules. 

When a module $u$ is assigned an access level $c_u \in \{1, 2, 3\}$, it is associated with a characteristic monomial:
$$ P_u(x) = x^{c_u} $$

For any two modules $u$ and $v$ linked by a separation protocol, their pairwise interference resonance $\Delta E(u, v)$ is calculated as the degree of the greatest common divisor (GCD) of the polynomial $x^3 - 1$ and the difference of their characteristic monomials:
$$ \Delta E(u, v) = \deg\left( \gcd(x^3 - 1, P_u(x) - P_v(x)) \right) $$
*(Note: The GCD of two polynomials is taken over the field of real numbers. For any non-zero polynomial $A(x)$, $\gcd(A(x), 0)$ is defined as $A(x)$.)*

The total interference resonance of the network is defined as the sum of $\Delta E(u, v)$ across all $m$ separation protocols. The network is deemed completely stable if and only if its total interference resonance is exactly $m$.

The test suite contains maximum-size adversarial instances. Naive generation of all assignments will result in an astronomical number of dead ends and will exceed the time limit before a stable state is found or proven impossible.

Your task is to determine if there exists a complete access assignment that makes the network completely stable. If at least one valid assignment exists, you must identify the one that is lexicographically smallest.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). These represent the total number of modules and the number of separation protocols, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that module $u$ and module $v$ are linked by a separation protocol.

## Output
If no completely stable assignment can be found, print `NO` on a single line.
If a stable assignment is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$) representing the access level assigned to each respective module. Among all valid stable configurations, the sequence of access levels you output must be the lexicographically smallest (i.e., comparing the access level of module 1 first, then module 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the vector dot-product formulation with an algebraic condition based on the degree of a polynomial GCD. This forces models to analytically evaluate $\gcd(x^3-1, x^{c_u}-x^{c_v})$ to deduce the underlying discrete constraint, preventing them from relying on superficial pattern matching to graph coloring while ensuring naive code translations (like using `sympy` in a backtracking loop) will time out.
</RATIONALE>
<PRESERVED_ANSWER>
The pairwise resonance evaluates to 1 when the assigned values differ and 3 when they are the same, meaning the total sum is exactly $m$ if and only if all interacting modules have distinct assignments, mathematically preserving the original stability condition.
</PRESERVED_ANSWER>

The problem remains mathematically equivalent to finding the lexicographically smallest proper 3-coloring of a graph, perfectly preserving its NP-complete complexity.
</PRESERVED_CLASS>
