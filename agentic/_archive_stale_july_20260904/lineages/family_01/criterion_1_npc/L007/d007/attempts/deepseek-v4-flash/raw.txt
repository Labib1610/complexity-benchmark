 We can model this as a graph coloring problem with 3 colors, where each edge must connect two nodes with different colors.  
The condition that the total energy is exactly \(-3m\) means every edge must contribute \(-1\), which happens only when the two endpoints have different colors.  

So the task reduces to:  
- Check if the graph is 3-colorable.  
- If yes, output the lexicographically smallest 3-coloring (colors 1, 2, 3).  

We can solve it with backtracking, trying colors in order 1, 2, 3 for each node, and pruning when a conflict occurs.

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def is_safe(node, c):
    for nei in adj[node]:
        if color[nei] == c:
            return False
    return True

def solve(node):
    if node == n:
        return True
    for c in range(1, 4):
        if is_safe(node, c):
            color[node] = c
            if solve(node + 1):
                return True
            color[node] = 0
    return False

if solve(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
