<STATEMENT>
# Problem A — Channel Separation Configuration

Time limit: 2 s   Memory limit: 256 MB

A data center needs to assign a channel $c_u \in \{1, 2, 3\}$ to each of $n$ communication nodes.
There are $m$ interference links, each connecting a pair of nodes.

To evaluate the configuration, the hardware computes a global interference energy $E$. 
First, each node $u$ generates a baseline emission $U_u$ defined by its assigned channel:
$U_u = c_u^4 - 5c_u^2$

Second, each link connecting node $u$ and node $v$ generates a cross-modulation $X_{u,v}$ based on their channels:
$X_{u,v} = c_u c_v (6 c_u c_v - 4 c_u^2 - 4 c_v^2 + 10)$

The total interference energy $E$ is calculated by summing the baseline emission of each node multiplied by its degree (the number of links connected to it), and then adding the cross-modulation of all $m$ links:
$E = \sum_{u=1}^n (d_u \times U_u) + \sum_{\text{links } (u,v)} X_{u,v}$
where $d_u$ is the degree of node $u$.

The overall network is considered fully separated if and only if the total interference energy $E$ is exactly $-4m$.

Your task is to determine if there exists a channel assignment that makes the network fully separated. If at least one valid assignment exists, you must identify the one that is lexicographically smallest.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). These represent the total number of nodes and the number of interference links, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that node $u$ and node $v$ are connected by an interference link.

## Output
If no fully separated assignment can be found, print `NO` on a single line.
If a valid assignment is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$) representing the channel assigned to each respective node. Among all valid configurations, the sequence of channels you output must be the lexicographically smallest (i.e., comparing the channel of node 1 first, then node 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous models succeeded by evaluating the edge condition on all 9 possible channel pairs, observing that valid edges always yielded a constant extreme value, and deducing that the problem was exactly proper 3-coloring. This allowed them to deploy optimized graph-coloring DFS algorithms with domain pruning.
To remove this affordance, the condition is rewritten using a global polynomial decomposition. The polynomial $(c_u - c_v)^4 - 5(c_u - c_v)^2$, which evaluates to $-4$ for any valid edge and $0$ for an invalid edge, is algebraically expanded and separated into node-wise degree-weighted terms ($U_u$) and edge-wise cross terms ($X_{u,v}$). Models can no longer evaluate a single edge independently without first performing the symbolic reconstruction of the global sum back into independent edge terms. If they fail to reconstruct it, they must use the global energy function as a black-box check in their DFS, which will Time Limit Exceed.
</RATIONALE>
<PRESERVED_ANSWER>
The global energy $E$ mathematically simplifies to $\sum_{(u,v)} ((c_u - c_v)^4 - 5(c_u - c_v)^2)$, which evaluates to exactly $-4m$ if and only if $c_u \neq c_v$ for all links, making the valid assignments identical to the seed's proper 3-colorings.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the lexicographically smallest proper 3-coloring problem, preserving its NP-complete complexity class.
</PRESERVED_CLASS>
