# Problem A — Security Clearance Resolution

Time limit: 2 s   Memory limit: 256 MB

In a secure distributed architecture, permissions must be carefully allocated across a network of $n$ modules. You must assign exactly one security tier to each module, choosing from the available tiers $\{1, 2, 3\}$.

The system's integrity is maintained by $m$ strict isolation policies. Each policy dictates that a specific pair of modules, $u$ and $v$, cannot share the same security tier. While a single policy only limits two modules, the overlapping nature of these rules creates complex, system-wide dependencies. 

To ensure minimal overhead, the overall assignment must minimize the structural footprint, defined mathematically as the value $F = \sum_{i=1}^n c_i \cdot 4^{n-i}$, where $c_i$ is the tier assigned to module $i$. You must find a valid configuration that minimizes $F$.

Be warned: the evaluation scenarios contain explicit adversarial instances. The module numbering is an adversarial permutation: maximum-size inputs are selected so that any solver that commits modules in increasing numerical order (including prefix-based enumerations with ascending tiers and basic local propagation) will explore an astronomical number of partial assignments. The minimal-footprint answer must be obtained by a more robust global resolution method rather than by enumerating index prefixes.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), denoting the number of modules and the number of isolation policies.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), representing a policy that prevents module $u$ and module $v$ from operating at the same security tier.

## Output
If it is impossible to assign tiers without breaking a policy, output `NO` on a single line.
If a valid assignment can be made, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$ (where $c_i \in \{1, 2, 3\}$) representing the assigned security tier for each module. This sequence must be the one that minimizes the structural footprint $F$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit "lexicographically smallest" tie-breaker with a mathematically equivalent objective function (minimizing a base-4 sum). Combined with a strong warning that sequential index assignment will explore an astronomical number of states, this forces models to abandon the simple left-to-right DFS (which implicitly satisfies the objective) and instead attempt complex global heuristics or branch-and-bound searches that are highly prone to bugs or failing the tie-breaker.
</RATIONALE>
<PRESERVED_ANSWER>
Because 4 is strictly greater than the maximum tier value (3), minimizing the sum $F = \sum c_i 4^{n-i}$ is mathematically identical to finding the lexicographically smallest sequence of tiers.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-COLORING on a graph with an identical tie-breaking rule, preserving its NP-complete status.
</PRESERVED_CLASS>
<RISK>
Models using languages with fixed-width integers (like C++) might attempt to explicitly calculate $F$ and encounter integer overflow since $4^{39}$ exceeds 64-bit limits, though the mathematical definition itself is completely unambiguous.
</RISK>

</METHOD_DESCRIPTION>
