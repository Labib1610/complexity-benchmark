<METHOD_DESCRIPTION>Replaces the algebraic polynomial that enforced $c_u \neq c_v$ with a microscopic combinatorial condition. The problem now requires that it be impossible to form a perfect one-to-one correspondence between sets of sizes $c_u$ and $c_v$. This forces the model to logically deduce that stability means $c_u \neq c_v$ (since bijections only exist between sets of equal size), breaking pattern-matching on inequality constraints or zero-sum energy formulas.</METHOD_DESCRIPTION>

# Problem A — Security Clearance Resolution

Time limit: 2 s   Memory limit: 256 MB

A secure facility is configuring the security tiers for a network of interdependent modules. Each module must receive exactly one tier assignment from the set $\{1, 2, 3\}$.

The facility's mainframe cabinet contains exactly 8 shelves, with each shelf holding exactly 5 hardware slots. The number of interdependent modules, $n$, must be at least 1 and cannot exceed the total slot capacity of this cabinet.

To prevent critical vulnerabilities, the facility evaluates the network's configuration using $m$ separation protocols. The number of protocols $m$ can be as low as zero, and will not exceed the maximum number of unique pairs that can be formed from the $n$ modules. Each protocol specifies a pair of interacting modules.

For any two modules $u$ and $v$ linked by a protocol, a synchronization check is performed based on their assigned tiers $c_u$ and $c_v$. Imagine that module $u$ emits exactly $c_u$ distinct synchronization pulses, and module $v$ opens exactly $c_v$ receiving windows. The check fails if it is mathematically possible to establish a perfect one-to-one correspondence between the set of pulses and the set of windows. That is, the check fails if you can pair every pulse with exactly one unique window such that no two pulses share a window, and absolutely no window is left without a pulse.

The entire network is deemed completely stable if and only if not a single synchronization check fails.

Please take note: the test suite contains instances specifically designed to be adversarial. Maximum-size test cases are structured such that attempting to resolve the configuration by simply generating all possible assignments and validating them at the end will result in an astronomical number of dead ends before a stable state is found or proven impossible.

Your task is to determine if there exists a complete tier assignment that makes the network completely stable. If at least one valid assignment exists, you must identify the one that prioritizes the lowest tier values sequentially. Specifically, if multiple stable configurations exist, you must output the one that assigns the lowest possible tier to module 1. If there are still ties, select the one with the lowest tier for module 2, continuing this sequential tie-breaking up to module $n$.

## Input
The first line of the input provides two integers $n$ and $m$. These represent the total number of modules and the number of separation protocols, respectively.
The following $m$ lines each contain two integers $u$ and $v$ (where $u$ and $v$ are distinct module identifiers from $1$ to $n$), indicating that module $u$ and module $v$ are linked by a separation protocol.

## Output
If no completely stable assignment can be found, print `NO` on a single line.
If a stable assignment is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$) representing the tier assigned to each respective module. Among all valid stable configurations, the sequence of tiers you output must be the one that satisfies the sequential tie-breaking rule described above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
To defeat models that recognize the pairwise energy polynomial as a simple $c_u \neq c_v$ constraint, I invented Combinatorial Bijection Framing. The explicit polynomial is replaced with a rule stating a check fails if a perfect one-to-one correspondence can be formed between sets of sizes $c_u$ and $c_v$. The model must deduce that a bijection is only possible when sizes are equal, meaning a stable network requires $c_u \neq c_v$. I additionally applied Strategy S07 to strip bare inequalities from the bounds, expressing $n \le 40$ via an 8-by-5 hardware rack capacity.
</RATIONALE>
<PRESERVED_ANSWER>
A perfect one-to-one correspondence between sets of size $c_u$ and $c_v$ exists if and only if $c_u = c_v$; thus, requiring no checks to fail is mathematically identical to requiring $c_u \neq c_v$ for every protocol, preserving the exact same valid state space and tie-breaker.
</PRESERVED_ANSWER>
