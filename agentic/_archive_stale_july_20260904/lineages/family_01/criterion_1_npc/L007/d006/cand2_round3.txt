<STATEMENT>
# Problem A — Asymmetric Flow Configuration

Time limit: 2 s   Memory limit: 256 MB

A fluid distribution network consists of $n$ pumping stations. To regulate the pressure across the system, each station must be assigned a base flow capacity of exactly 1, 2, or 3 units.

The network contains $m$ bidirectional pipes, each connecting a pair of stations. To prevent fluid stagnation within any pipe, the system must maintain a strict pressure differential across every connected pair. Specifically, for any pipe connecting station $u$ and station $v$, the absolute difference between their assigned flow capacities must be at least 1 (i.e., $|c_u - c_v| \ge 1$). This guarantees a pressure gradient that forces the fluid to move.

Your task is to determine whether there exists a valid capacity configuration for all $n$ stations such that every pipe maintains a strict gradient.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). These represent the total number of pumping stations and the number of bidirectional pipes, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that a pipe connects station $u$ and station $v$.

## Output
If no valid configuration can be found, print `NO` on a single line.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), representing the capacity assigned to each respective station. Among all valid configurations, you must output the lexicographically smallest sequence $c_1, c_2, \dots, c_n$ (compare $c_1$ first, then $c_2$, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

Semantic Domain Shift to Network Flow
</METHOD_NAME>
<METHOD_DESCRIPTION>
The problem is reframed using terminology strongly associated with Network Flow and gradient problems ("flow capacity", "pressure differential", "bidirectional pipes"). Models relying on surface pattern matching will likely misclassify the problem as a network flow or continuous gradient optimization task and apply incorrect algorithms, while models that genuinely analyze the discrete domain ({1, 2, 3}) and the absolute difference constraint will correctly deduce it is a graph coloring problem.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<RATIONALE>
Following the expert critique, I completely removed the contrived polynomial energy formulation and replaced it with a direct, plain-language absolute difference constraint. I framed the scenario around a fluid distribution network. This forces the model to look past the misleading "network flow" vocabulary and deduce that an absolute difference of at least 1 on the domain {1, 2, 3} is mathematically identical to a simple categorical inequality, preventing pattern-matching on flow algorithms while remaining completely natural to read.
</RATIONALE>
<PRESERVED_ANSWER>
Since the domain is restricted to integers {1, 2, 3}, the condition $|c_u - c_v| \ge 1$ is satisfied if and only if $c_u \neq c_v$, which is the exact same requirement as the original zero-energy condition, leaving all valid configurations and their lexicographical order identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains a direct mapping of the NP-complete 3-COLORING problem on an undirected graph.
</PRESERVED_CLASS>
