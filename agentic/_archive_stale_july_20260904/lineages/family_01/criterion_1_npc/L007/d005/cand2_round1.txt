<STATEMENT>
# Problem A — Security Clearance Resolution

Time limit: 2 s   Memory limit: 256 MB

A secure facility is configuring the access levels for a network of interdependent modules. The facility operates using a standardized server rack that contains exactly 40 physical hardware slots. A valid configuration involves at least one module, and the total number of modules $n$ can never exceed the physical capacity of the rack.

Each module must receive exactly one access level from the set $\{1, 2, 3\}$.

To prevent critical vulnerabilities, the facility has established $m$ separation protocols. The number of protocols can range from zero up to the theoretical maximum where every distinct pair of modules is entangled. Each protocol specifies two distinct modules, $u$ and $v$ (identified by their integer slot IDs starting from 1 up to $n$), which are entangled. 

For any two entangled modules $u$ and $v$, their assigned access levels $c_u$ and $c_v$ must satisfy a specific algebraic safety condition. Specifically, the value $c_u^2 + c_u c_v + c_v^2$ must not be a multiple of 3. If this value is divisible by 3, the interacting frequencies of the two modules will cause a resonance cascade, which is strictly forbidden.

Your task is to determine if there exists a complete access assignment that respects all separation protocols. If at least one valid assignment exists, you must identify the one that is lexicographically smallest.

## Input
The first line of the input provides two integers $n$ and $m$. These represent the total number of modules and the number of separation protocols, respectively.
The following $m$ lines each contain two integers $u$ and $v$, indicating that module $u$ and module $v$ are entangled and their access levels must satisfy the algebraic safety condition described above.

## Output
If no valid assignment can satisfy all protocols, print `NO` on a single line.
If a valid assignment is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$) representing the access level assigned to each respective module. Among all valid configurations, the sequence of access levels you output must be the lexicographically smallest (i.e., comparing the access level of module 1 first, then module 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I removed the explicit warning about adversarial test cases and disguised the inequality constraint $c_u \neq c_v$ as the algebraic condition $c_u^2 + c_u c_v + c_v^2 \not\equiv 0 \pmod 3$. This prevents the model from recognizing the problem as 3-coloring and deploying graph-coloring optimizations like domain-mask propagation. Furthermore, all numeric bounds have been rewritten indirectly into the scenario text to comply with Strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
For values restricted to {1, 2, 3}, the polynomial $c_u^2 + c_u c_v + c_v^2$ evaluates to a multiple of 3 if and only if $c_u = c_v$, making the new algebraic condition mathematically identical to the original separation protocol.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
The phrase "theoretical maximum where every distinct pair of modules is entangled" could be deemed slightly verbose, but "distinct pair" unambiguously implies the standard upper bound of $n(n-1)/2$ for undirected edges.
</RISK>
