 We need to assign each node a value from {1, 2, 3} such that for every edge, the energy contribution is zero.  

The energy for an edge is:  
\[
(c_u - c_v)^4 - 5(c_u - c_v)^2 + 4
\]  
Let \( d = c_u - c_v \). Then:  
\[
d^4 - 5d^2 + 4 = (d^2 - 1)(d^2 - 4) = (d-1)(d+1)(d-2)(d+2)
\]  
This is zero when \( d \in \{-2, -1, 1, 2\} \).  

Since values are from {1, 2, 3}, possible differences are:  
- 1 and 2 → diff = 1  
- 1 and 3 → diff = 2  
- 2 and 3 → diff = 1  
- Same values → diff = 0 (not allowed, since 0 doesn't make it zero)  

So the allowed pairs are:  
(1,2), (2,1), (1,3), (3,1), (2,3), (3,2).  
The only forbidden pair is (1,1), (2,2), (3,3) — i.e., same value on both ends.  

Thus, the problem reduces to: assign each node a value from {1,2,3} such that no edge connects two nodes with the same value. This is exactly a graph 3-coloring problem.  

We need the lexicographically smallest 3-coloring, or report NO if impossible.  

We can solve with backtracking + pruning, since n ≤ 40.  

Here’s the implementation:  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n
    # Precompute adjacency sets for fast check
    adj_sets = [set(adj[i]) for i in range(n)]
    
    def backtrack(idx):
        if idx == n:
            return True
        # Try colors 1,2,3 in order for lexicographic smallest
        for c in (1, 2, 3):
            ok = True
            for nb in adj_sets[idx]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[idx] = c
                if backtrack(idx + 1):
                    return True
                colors[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
