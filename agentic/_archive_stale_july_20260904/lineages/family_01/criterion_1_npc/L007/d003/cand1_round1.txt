# Problem A — Security Clearance Resolution

Time limit: 2 s   Memory limit: 256 MB

You are tasked with configuring a secure distributed network consisting of $n$ modules. Each module must be assigned exactly one security tier from the set $\{1, 2, 3\}$.

To preserve system integrity, the network enforces $m$ strict isolation policies. Each policy specifies two distinct modules, $u$ and $v$, and prohibits them from operating at the identical security tier. Although each individual rule only restricts a pair of modules, their overlapping constraints produce intricate dependencies across the entire network.

Be heavily warned regarding the evaluation data: the test suite includes explicitly adversarial maximum-size scenarios. These inputs are mathematically constructed so that any search routine which simply assigns modules in increasing index order while trying tiers sequentially (1, then 2, then 3) will evaluate an astronomical number of dead ends. Such approaches will inevitably exceed the time limit before either finding a configuration or proving that none exists. You must employ a more resilient mechanism to avoid this exhaustive overhead, despite the requirement that your final answer must be the lexicographically smallest valid configuration.

Your goal is to determine if there is any complete tier assignment that respects all isolation policies. If a valid configuration exists, you must output the lexicographically smallest one.

## Input
The first line provides two integers $n$ and $m$ (1 ≤ $n$ ≤ 40, 0 ≤ $m$ ≤ $n(n−1)/2$), which represent the total number of modules and the number of isolation policies, respectively.
The following $m$ lines each contain two integers $u$ and $v$ (1 ≤ $u, v$ ≤ $n$, $u \neq v$), indicating a policy that forbids module $u$ and module $v$ from sharing the same security tier.

## Output
If no valid tier assignment can be achieved without violating a policy, print `NO` on a single line.
If a valid configuration is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ ($c_i \in \{1, 2, 3\}$), representing the security tier assigned to each respective module. This sequence must be the lexicographically smallest valid assignment (meaning you first minimize the tier for module 1, then module 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
