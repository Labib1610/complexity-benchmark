**Solution Explanation**

We have to colour the vertices `1 … n` of an undirected graph with three colours
`{1,2,3}` such that adjacent vertices receive different colours.
If a colouring exists we must output the *lexicographically smallest* one,
i.e. the smallest possible colour of vertex 1, then of vertex 2, …  

`n ≤ 40`, therefore a plain back‑tracking search with good pruning easily fits
into the limits.

--------------------------------------------------------------------

#### 1.   Data structures  

* `adj[v]` – list of neighbours of vertex `v` (0‑based indices are used inside the program).  
* `col[v]` – current colour of vertex `v` (`0` = uncoloured).  
* `mask[v]` – bitmask of still possible colours for `v`.  
  Bit `0` → colour 1, bit 1 → colour 2, bit 2 → colour 3.  
  Initially `mask[v] = 0b111` for all vertices.

--------------------------------------------------------------------

#### 2.   Backtracking  

Vertices are processed **in the natural order** `0,1,…,n‑1`.  
For the current vertex `v`

```
for colour c in 1,2,3 (in this order):
        if c is allowed by mask[v]:
                assign c
                temporarily delete c from the masks of all still uncoloured neighbours
                if no neighbour loses its last possible colour:
                        recurse to the next vertex
                undo the temporary deletions
```

The first complete assignment found is automatically the lexicographically
smallest one because we try colours in increasing order and we never skip a
vertex.

--------------------------------------------------------------------

#### 3.   Efficient undo  

During the assignment of colour `c` to vertex `v` we modify the masks of some
neighbours.  
All changes are stored in a list `changes = [(u, old_mask), …]`.  
When backtracking we simply restore `mask[u] = old_mask` for every stored pair.
The list is local to the recursive call, therefore undoing is `O(degree(v))`.

--------------------------------------------------------------------

#### 4.   Pruning (forward checking)

If after removing colour `c` from a neighbour `u` we obtain `mask[u] == 0`
*and* `col[u] == 0` (still uncoloured) the current partial assignment can never
be extended – we backtrack immediately.  
This simple forward checking eliminates huge parts of the search tree.

--------------------------------------------------------------------

#### 5.   Correctness Proof  

We prove that the algorithm prints `NO` iff the graph is not 3‑colourable,
otherwise it prints `YES` and the lexicographically smallest valid colouring.

---

##### Lemma 1  
During the search `mask[v]` always equals the set of colours that are still
compatible with the already coloured neighbours of `v`.

**Proof.**  
Initially all three colours are possible, i.e. the statement holds.
When a neighbour `u` receives colour `c`, the algorithm removes `c` from
`mask[v]` for every uncoloured neighbour `v`. No other operation changes
`mask[v]`. Hence after each assignment `mask[v]` contains exactly the colours
different from all already coloured neighbours. ∎



##### Lemma 2  
If the algorithm backtracks from a partial assignment, that partial assignment
cannot be extended to a full proper 3‑colouring.

**Proof.**  
Backtracking occurs only in two cases  

* (a) a vertex `v` has `mask[v] == 0` while still uncoloured – by Lemma&nbsp;1
  no colour is compatible with its coloured neighbours, therefore any extension
  would violate an edge.  

* (b) all three colours have been tried for the current vertex `v` and each
  trial led to a recursive call that eventually backtracked. By induction on
  recursion depth each of those recursive calls cannot be extended, thus no
  colour for `v` leads to a full colouring. ∎



##### Lemma 3  
Whenever the recursive routine reaches `idx == n` (all vertices coloured) the
produced colour array is a proper 3‑colouring.

**Proof.**  
All edges connect two vertices that have been coloured at some moment.
When the second endpoint of an edge received its colour, the algorithm had
removed that colour from the mask of the first endpoint (Lemma&nbsp;1), thus the
second endpoint could not be coloured with the same colour. Hence adjacent
vertices have different colours. ∎



##### Lemma 4  
The first complete colouring found by the algorithm is the lexicographically
smallest among all proper colourings.

**Proof.**  
Vertices are processed in order `1,2,…,n`.  
For each vertex the algorithm tries colours `1,2,3` in this order and only
proceeds to the next vertex after fixing the current colour.  
Therefore any other proper colouring that differs first at vertex `i` must have
a colour `c' > c_i` (otherwise the algorithm would have tried `c'` earlier and
found a solution). Consequently the first solution is lexicographically
minimal. ∎



##### Lemma 5  
If the graph is 3‑colourable, the algorithm will eventually find a complete
colouring.

**Proof.**  
Consider any proper 3‑colouring `C`. Follow the recursion: at vertex `v`
the algorithm tries colours `1,2,3`. Since `C(v)` is compatible with the already
coloured predecessors (they are the same as in `C`), `C(v)` is present in
`mask[v]` (Lemma&nbsp;1) and will be tried. When it is tried, the recursive call
receives a partial assignment that coincides with `C` on the first `v+1`
vertices, thus the call cannot backtrack (otherwise `C` would be impossible by
Lemma&nbsp;2). By induction the recursion can follow `C` all the way to `n`,
producing a complete colouring. ∎



##### Theorem  
The program outputs  

* `NO` iff the input graph is not 3‑colourable;  
* otherwise `YES` and the lexicographically smallest proper 3‑colouring.

**Proof.**  

*If the program prints `YES`*: by Lemma&nbsp;3 the printed assignment is a proper
colouring, and by Lemma&nbsp;4 it is lexicographically minimal.

*If the program prints `NO`*: this happens only after the whole search tree
has been explored without reaching `idx == n`. By Lemma&nbsp;2 every explored
partial assignment cannot be extended, therefore no proper colouring exists.
Conversely, if the graph were 3‑colourable, Lemma&nbsp;5 guarantees that the
search would find a complete colouring and would not output `NO`. ∎



--------------------------------------------------------------------

#### 6.   Complexity Analysis  

`n ≤ 40`.  
In the worst case the algorithm may explore all `3^n` colourings, but the
forward‑checking pruning reduces this dramatically for typical dense graphs.
The operations inside each recursive call are `O(deg(v))` (updating neighbours).

Memory consumption:  

* adjacency list – `O(n + m)`  
* arrays `col`, `mask` – `O(n)`  
* recursion depth – `O(n)`  

All well below the limits.

--------------------------------------------------------------------

#### 7.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    col = [0] * n               # 0 = uncoloured, else 1..3
    mask = [0b111] * n           # bits 0,1,2 correspond to colours 1,2,3
    solution = None

    def dfs(idx: int) -> bool:
        nonlocal solution
        if idx == n:
            solution = col.copy()
            return True
        # try colours 1..3
        for c in (1, 2, 3):
            bit = 1 << (c - 1)
            if mask[idx] & bit == 0:
                continue
            # assign
            col[idx] = c
            changes = []          # list of (vertex, old_mask)
            ok = True
            for nb in adj[idx]:
                if col[nb] == 0:          # only affect uncoloured neighbours
                    old = mask[nb]
                    new = old & ~bit
                    if new != old:
                        changes.append((nb, old))
                        mask[nb] = new
                        if new == 0:
                            ok = False
                            break
            if ok and dfs(idx + 1):
                return True
            # undo
            for v, old in changes:
                mask[v] = old
            col[idx] = 0
        return False

    if dfs(0):
        out = ["YES", " ".join(str(x) for x in solution)]
    else:
        out = ["NO"]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
