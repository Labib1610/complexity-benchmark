<STATEMENT>
# Problem A — Matrix Profile Configuration

Time limit: 2 s   Memory limit: 256 MB

A data center needs to assign a configuration profile $c_u \in \{1, 2, 3\}$ to each of $n$ communication nodes. The facility's cooling capacity restricts the deployment to a maximum of 40 nodes, and there must be at least 1 node to operate. There are $m$ bidirectional interference links, each connecting a pair of distinct nodes. The number of links $m$ can range from 0 up to the theoretical maximum where every distinct pair of nodes is directly linked.

To evaluate the configuration, each profile is associated with a $2 \times 2$ matrix $M$:
- Profile 1 uses $M_1 = \begin{pmatrix} -1 & 3 \\ 1 & 1 \end{pmatrix}$.
- Profile 2 uses $M_2 = \begin{pmatrix} -1 & -3 \\ -1 & 1 \end{pmatrix}$.
- Profile 3 uses $M_3 = \begin{pmatrix} 2 & 0 \\ 0 & -2 \end{pmatrix}$.

For each of the $m$ links connecting a pair of nodes $u$ and $v$, the link's interference score is defined as the trace of the matrix product $M_{c_u} M_{c_v}$ (note that the trace is identical regardless of the order of $u$ and $v$). The trace of a matrix is the sum of the elements on its main diagonal.

The overall network is considered fully separated if and only if the sum of the interference scores across all $m$ links is exactly $-4m$.

Your task is to determine if there exists a profile assignment that makes the network fully separated. If at least one valid assignment exists, you must identify the one that is lexicographically smallest.

## Input
The first line of the input provides two integers $n$ and $m$. These represent the total number of nodes and the number of interference links, respectively, bounded by the physical limits described above.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that node $u$ and node $v$ are connected by an interference link.

## Output
If no fully separated assignment can be found, print `NO` on a single line.
If a valid assignment is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$) representing the profile assigned to each respective node. Among all valid configurations, the sequence of profiles you output must be the lexicographically smallest (i.e., comparing the profile of node 1 first, then node 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was rewritten to replace the per-edge vector stress condition with a global sum over the traces of 2x2 matrix products. The matrices are carefully constructed so that the trace of $M_i M_j$ is exactly $-4$ when $i \neq j$, and $8$ when $i = j$. Since the target sum is exactly $-4m$, every edge must have a trace of $-4$, enforcing the proper 3-coloring constraint. Models that fail to algebraically deduce this local constraint will attempt unpruned backtracking over $3^{40}$ states, resulting in a Time Limit Exceeded error.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix trace condition evaluates to $-4$ for different profiles and $8$ for identical profiles, meaning the global sum is $-4m$ if and only if no two linked nodes share a profile; this is mathematically identical to the seed's stress condition, preserving all valid assignments and the lexicographical tie-breaker.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest proper 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
