<STATEMENT>
# Problem A — Security Clearance Resolution

Time limit: 2 s   Memory limit: 256 MB

In many distributed architectures, configuration rules must be resolved across the entire network. You are given a system of $n$ components. Each component must be assigned a clearance tier from the set of integers 1, 2, and 3.

To maintain strict compartmentalization, the system enforces $m$ separation rules. Each rule specifies two components $u$ and $v$ that must not share the same clearance tier. Although each rule explicitly restricts only two components, their combinations can create arbitrary global dependencies across the architecture.

The system is deployed across exactly 8 secure zones, each physically capable of hosting exactly 5 components. Consequently, the total number of components $n$ is at least 1 and at most the total capacity of all zones combined. The number of separation rules $m$ ranges from zero up to the theoretical maximum where every component has a rule with every other distinct component.

Your task is to determine whether a valid clearance assignment exists for all $n$ components. If the system can be configured safely, you must output the lexicographically smallest sequence of clearance tiers.

## Input
The first line contains two integers $n$ and $m$ — the number of components and the number of separation rules. The limits on $n$ and $m$ correspond exactly to the physical capacities detailed in the description.
Each of the following $m$ lines contains two integers $u$ and $v$ (valid component identifiers between 1 and $n$, with $u \neq v$) representing a separation rule between component $u$ and component $v$.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$) representing the clearance tier of each component. This sequence must be the lexicographically smallest among all valid assignments (comparing $c_1$ first, then $c_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit bounds for $n$ and $m$ were removed and replaced with indirect physical capacities (8 zones of 5 components) and theoretical maximums that the model must derive. The misleading affordance that described the constraints as "highly localized" was flipped to warn about "arbitrary global dependencies," forcing the model to evaluate the global structure of the problem rather than blindly trusting local backtracking.
</RATIONALE>
<PRESERVED_ANSWER>
The permissible clearance tiers, separation rules, and the requirement to find the lexicographically smallest valid sequence are mechanically identical, ensuring the exact same output for any valid input graph.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Lexicographically First 3-Coloring, preserving its NP-complete status and underlying graph-coloring structure.
</PRESERVED_CLASS>
<RISK>
Models might misread "theoretical maximum where every component has a rule with every other distinct component" as a requirement that instances are complete graphs, rather than the upper bound of $m$.
</RISK>
