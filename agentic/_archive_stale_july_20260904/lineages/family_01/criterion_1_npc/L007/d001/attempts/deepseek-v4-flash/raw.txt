 We need to assign each node a value from {1, 2, 3} such that no edge connects two nodes with the same value.  
This is equivalent to checking if the graph is 3-colorable, and if so, finding the lexicographically smallest coloring.

Since \( n \leq 40 \), we can use backtracking with pruning.  
We’ll try assigning colors in order 1, 2, 3 for each node, and check constraints.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n
found = False

def backtrack(idx):
    global found
    if idx == n:
        found = True
        return True
    for c in range(1, 4):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if backtrack(idx + 1):
                return True
            color[idx] = 0
    return False

if backtrack(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
