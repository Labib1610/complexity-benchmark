<METHOD_NAME>Global Matrix Determinant Sum</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit zero-diagonal check of S^T P S with a global sum of determinants of pairwise matrix sums. The chosen base matrix W has the property that det(W^a + W^b) is 1 if a != b, and 4 if a == b. The sum over m edges equals m if and only if all edges have distinct values. This global formulation prevents naive local pruning unless the model symbolically discovers the truth table of the matrix operations, forcing models that rely on surface pattern matching to write unpruned exponential-time searches.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — Resonant Loop Prevention

Time limit: 2 s
Memory limit: 256 MB

You are configuring a system of $n$ signal relays, numbered 1 to $n$. Each relay must be assigned a frequency multiplier $f_i$ chosen from the values 1, 2, and 3.

We define a $2 \times 2$ base transformation matrix $W$:
$$ W = \begin{pmatrix} 9 & -7 \\ 13 & -10 \end{pmatrix} $$

The assigned multiplier $f_i$ determines the state matrix of relay $i$, defined as $M_i = W^{f_i}$ (which denotes $W$ raised to the power of $f_i$ using standard matrix multiplication).

You are provided with a list of $m$ unique pairs of relays that are in physical proximity. For every pair of relays $u$ and $v$ in proximity, their combined interference matrix is given by the element-wise sum $C_{u,v} = M_u + M_v$.

The system is perfectly stable if and only if the sum of the determinants of $C_{u,v}$ over all $m$ proximity pairs is exactly equal to $m$. 

Your task is to determine if there exists a valid sequence of multipliers $f_1, f_2, \dots, f_n$ such that the system is perfectly stable. If such a sequence exists, you must output it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that relay $u$ and relay $v$ are in physical proximity.

## Output
If there is no valid sequence of multipliers that makes the system stable, print a single line containing `NO`.
If at least one such sequence exists, print `YES` on the first line. On the second line, print the $n$ integers $f_1, f_2, \dots, f_n$ representing the multipliers assigned to the relays. 
If there are multiple valid sequences, you must output the one that is lexicographically smallest. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit matrix product `S^T P S` from the seed problem was easily recognized as a proper 3-coloring constraint by the remaining models, allowing them to deploy highly optimized local-pruning DFS algorithms. By replacing this with a global sum of determinants over matrix exponentiations, the local constraint ($f_u \neq f_v$) is mathematically preserved but algorithmically obscured. Models that literally implement the global sum without deducing the underlying truth table will fail to prune their search trees, resulting in an exponential time-out.
</RATIONALE>
<PRESERVED_ANSWER>
The base matrix $W$ is constructed such that $W^3 = I$, and the determinant of $W^a + W^b$ evaluates to exactly 1 if $a \neq b$, and 4 if $a = b$; thus, the global sum over $m$ pairs equals exactly $m$ if and only if every pair has distinct multipliers, preserving the original answers identically.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The condition simplifies precisely to proper 3-coloring on the proximity graph, keeping the problem NP-complete and solvable by the intended lexicographically-ordered backtracking algorithm.
</PRESERVED_CLASS>
