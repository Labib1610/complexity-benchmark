We need to analyze the condition for stability.

For a pair \( (u, v) \), the cubic is:

\[
E(x) = x^3 - (f_u + f_v)x^2 + (f_u f_v)x
\]

Factor out \( x \):

\[
E(x) = x \big( x^2 - (f_u + f_v)x + f_u f_v \big)
\]

The quadratic part factors as:

\[
x^2 - (f_u + f_v)x + f_u f_v = (x - f_u)(x - f_v)
\]

So:

\[
E(x) = x (x - f_u)(x - f_v)
\]

The roots are \( 0, f_u, f_v \).  
For exactly three distinct real roots, we need \( 0, f_u, f_v \) all distinct.  
Since \( f_u, f_v \in \{1,2,3\} \), this means \( f_u \neq f_v \) and neither is 0 (which is automatic).  
So the condition is simply:

> For every edge \((u,v)\), we must have \( f_u \neq f_v \).

Thus the problem reduces to:  
Can we assign each vertex a value from {1,2,3} such that adjacent vertices have different values?  
That’s exactly a graph coloring problem with 3 colors.

We need the lexicographically smallest assignment.

---

**Approach:**

- \( n \le 40 \), so we can do backtracking with pruning.
- Try values 1, 2, 3 in order for each vertex, checking constraints with already assigned neighbors.
- If we reach the end, we have a valid assignment.
- If no assignment possible, output `NO`.

---

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[idx] = c
                if backtrack(idx + 1):
                    return True
                colors[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
