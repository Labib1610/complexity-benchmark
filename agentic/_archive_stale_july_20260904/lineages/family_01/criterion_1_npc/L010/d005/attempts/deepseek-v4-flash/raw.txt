We can model this as a graph coloring problem with 3 colors (1, 2, 3).  
The condition says: for an edge (u, v), we must avoid  
`(f_u + 2*f_v) % 3 == 0`.  

Let’s check what that means for each possible value of `f_v`:

- If `f_v = 1`, then `2*f_v = 2`, so we need `f_u + 2 ≠ 0 mod 3` → `f_u ≠ 1 mod 3` → `f_u ≠ 1`.
- If `f_v = 2`, then `2*f_v = 4 ≡ 1 mod 3`, so we need `f_u + 1 ≠ 0 mod 3` → `f_u ≠ 2 mod 3` → `f_u ≠ 2`.
- If `f_v = 3`, then `2*f_v = 6 ≡ 0 mod 3`, so we need `f_u ≠ 0 mod 3` → `f_u ≠ 3`.

So the rule is:  
If `f_v = 1`, then `f_u` cannot be 1.  
If `f_v = 2`, then `f_u` cannot be 2.  
If `f_v = 3`, then `f_u` cannot be 3.  

That means: for every edge, the two endpoints must have **different** values.  
So the problem reduces to: can we 3-color the graph such that adjacent vertices have different colors, and we want the lexicographically smallest assignment.

Since `n ≤ 40`, we can use backtracking with pruning.

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def dfs(idx):
    if idx == n:
        return True
    for c in (1, 2, 3):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if dfs(idx + 1):
                return True
            color[idx] = 0
    return False

if dfs(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
