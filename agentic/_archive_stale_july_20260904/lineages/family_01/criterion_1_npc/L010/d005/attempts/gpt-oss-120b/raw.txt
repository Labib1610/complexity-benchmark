**Solution Explanation**

For every relay we have to choose a value `f ∈ {1,2,3}`.
Write the values modulo 3 :

```
1 → 1 ,   2 → 2 ,   3 → 0
```

For an edge `{u,v}` a resonant loop appears exactly when  

```
(fu + 2·fv) mod 3 = 0                (1)
```

The condition is symmetric, therefore the same pair of residues is
*forbidden* for both directions.
All other pairs are allowed.

--------------------------------------------------------------------

#### 1.   Allowed pairs

```
r , s ∈ {0,1,2}
forbidden ⇔ (r + 2·s) % 3 == 0
```

The table of allowed pairs (ordered as (r,s)) is

| r\s | 0 | 1 | 2 |
|-----|---|---|---|
| 0   | ✗ | ✔ | ✔ |
| 1   | ✔ | ✗ | ✔ |
| 2   | ✔ | ✔ | ✗ |

So a vertex coloured `0` (i.e. value 3) may be adjacent only to vertices
coloured `1` or `2`, never to another `0`, etc.

--------------------------------------------------------------------

#### 2.   Problem restatement

We have a graph `G` ( `n ≤ 40` ) and a **binary constraint** on every edge:
the ordered pair of residues of its ends must belong to the allowed set above.
We have to find a feasible assignment, and among all feasible assignments
output the lexicographically smallest one (with the original values
`1,2,3`).

--------------------------------------------------------------------

#### 3.   Backtracking with forward checking

`n` is only 40, therefore a depth‑first search that tries the colours
`1,2,3` in this order is fast enough if we prune early.

*Data structures*

* `adj[v]` – list of neighbours of `v` (0‑based indices)
* `color[v]` – current residue (`-1` = unassigned)
* `possible[v]` – bitmask of still possible residues for `v`
  (`1<<0 | 1<<1 | 1<<2` initially)

*Recursive procedure* `dfs(pos)` – `pos` is the next vertex index
(`0 … n-1`).

```
if pos == n:   # all vertices assigned
        success
v = pos
for each residue r in 0,1,2 (in this order):
        if r not in possible[v]: continue
        # check compatibility with already coloured neighbours
        ok = True
        for each neighbour w of v:
                if color[w] != -1:
                        if (r, color[w]) is forbidden: ok = False; break
        if not ok: continue

        # forward checking: temporarily restrict neighbours' domains
        saved = []          # (w, old_mask)
        consistent = True
        for each neighbour w of v with color[w]==-1:
                old = possible[w]
                # remove residues that would conflict with r
                new = old & allowed_mask[r]          # allowed_mask[r] is a 3‑bit mask
                if new == 0: consistent = False; break
                if new != old:
                        saved.append((w, old))
                        possible[w] = new
        if not consistent:
                restore saved masks; continue

        # commit
        color[v] = r
        if dfs(pos+1): return True
        # backtrack
        color[v] = -1
        restore saved masks
return False
```

`allowed_mask[r]` is a 3‑bit mask containing exactly those residues `s`
for which the pair `(r,s)` is **allowed** (the table above).

Because we always try colours `0,1,2` (i.e. values `1,2,3`) in increasing
order, the first complete assignment found is the lexicographically
smallest one.

The forward checking step removes impossible colours from still
unassigned neighbours; if any neighbour loses all possibilities we backtrack
immediately – this cuts the search tree dramatically.

The recursion depth is at most 40, the work per step is `O(deg(v))`,
so the whole algorithm easily fits into the limits.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible assignment exists,
otherwise prints `YES` and the lexicographically smallest feasible
assignment.

---

##### Lemma 1  
During the search, `possible[v]` always contains exactly the residues that
can still be assigned to `v` without violating any edge whose other endpoint
is already coloured.

**Proof.**  
Initially all three residues are possible, which is correct.
When a vertex `u` gets colour `r`, for each uncoloured neighbour `w`
the algorithm intersects `possible[w]` with `allowed_mask[r]`,
i.e. removes precisely those residues that would create a forbidden pair
with `r`. No other edges are affected.
Thus after the update `possible[w]` contains exactly the residues compatible
with all already coloured neighbours. ∎



##### Lemma 2  
If the algorithm reaches `pos == n`, the current `color` array is a feasible
assignment.

**Proof.**  
All vertices are coloured. By construction, before assigning a colour to a
vertex we checked compatibility with every already coloured neighbour,
so every edge connects two vertices whose residues form an allowed pair.
Hence no edge violates condition (1). ∎



##### Lemma 3  
If the algorithm backtracks from a partial assignment, that partial
assignment cannot be extended to a full feasible assignment.

**Proof.**  
Backtracking occurs only in two cases.

*Case A* – a colour `r` for vertex `v` is rejected because it conflicts
with an already coloured neighbour. Any extension would keep that neighbour
colour, therefore the conflict persists; no extension is feasible.

*Case B* – after assigning `r` to `v`, forward checking discovers an
uncoloured neighbour `w` whose `possible[w]` becomes empty.
By Lemma&nbsp;1, `w` has no colour compatible with the already coloured
neighbourhood (which now includes `v` with colour `r`). Hence no extension
can colour `w`, and consequently no full feasible assignment exists that
extends the current partial one. ∎



##### Lemma 4  
If a feasible assignment exists, the recursive search eventually reaches
`pos == n`.

**Proof.**  
Consider any feasible assignment `C`. The search explores vertices in order
`0 … n-1`. At step `pos` the algorithm tries colours `0,1,2` in this order.
Because `C` is feasible, the colour `C[pos]` is compatible with all already
coloured neighbours, therefore it is not rejected by the compatibility test.
Furthermore, after assigning `C[pos]` forward checking cannot empty the
domain of any neighbour (otherwise `C` would be infeasible). Hence the
branch following `C[pos]` is never pruned. By induction the search can follow
the exact sequence of colours of `C` and reaches `pos == n`. ∎



##### Lemma 5  
The first complete assignment found by the algorithm is the lexicographically
smallest feasible assignment.

**Proof.**  
The recursion processes vertices in increasing index order.
For each vertex it tries colours `0,1,2` (i.e. values `1,2,3`) in increasing
order, and only proceeds to the next vertex after fixing the current one.
Therefore the search explores the space of assignments in lexicographic
order. The first leaf reached is the smallest leaf in that order, i.e. the
lexicographically smallest feasible assignment. ∎



##### Theorem  
The program outputs  

* `NO` iff the input graph admits no assignment avoiding resonant loops;  
* otherwise `YES` and the lexicographically smallest such assignment.

**Proof.**  

*If the program prints `YES`*: it has found a leaf of the search tree,
hence by Lemma&nbsp;2 the printed assignment is feasible.
By Lemma&nbsp;5 it is the lexicographically smallest feasible one.

*If the program prints `NO`*: the search exhausted all branches without
reaching `pos == n`. By Lemma&nbsp;3 every dead‑ended partial assignment
cannot be extended, therefore no feasible full assignment exists.
Conversely, if a feasible assignment existed, Lemma&nbsp;4 guarantees the
search would reach a leaf, contradicting the exhaustive failure.
Thus no feasible assignment exists. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

`n ≤ 40`, `m ≤ n·(n-1)/2`.

*Each recursive call*  
* checks at most `deg(v) ≤ n` neighbours,
* updates at most `deg(v)` neighbour domains (bit operations).

Hence `O(n)` work per level.

The worst‑case number of visited nodes is bounded by the number of
different partial colourings that survive pruning; in practice it is far
below `3^n`. With the given limits the program runs well within 2 seconds.

Memory usage: adjacency lists `O(n+m)`, arrays `O(n)`.  
Overall `O(n+m)` ≤ a few kilobytes.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    # residues: 0 -> value 3, 1 -> value 1, 2 -> value 2
    # allowed_mask[r] : bitmask of residues s such that (r, s) is allowed
    allowed_mask = [0] * 3
    for r in range(3):
        mask = 0
        for s in range(3):
            if (r + 2 * s) % 3 != 0:   # allowed
                mask |= 1 << s
        allowed_mask[r] = mask

    color = [-1] * n               # -1 = unassigned, else residue 0..2
    possible = [0b111] * n         # three bits set

    sys.setrecursionlimit(10000)

    def dfs(pos: int) -> bool:
        if pos == n:
            return True
        v = pos
        # try residues in order 0,1,2 (values 3,1,2) but we need lexicographic on values 1,2,3
        # mapping: residue 0 -> value 3, residue 1 -> value 1, residue 2 -> value 2
        # lexicographic on values means order 1,2,3 i.e. residues 1,2,0
        for r in (1, 2, 0):
            if not (possible[v] >> r) & 1:
                continue
            # compatibility with already coloured neighbours
            ok = True
            for w in adj[v]:
                cw = color[w]
                if cw != -1:
                    if (r + 2 * cw) % 3 == 0:
                        ok = False
                        break
            if not ok:
                continue

            saved = []
            consistent = True
            for w in adj[v]:
                if color[w] == -1:
                    old = possible[w]
                    new = old & allowed_mask[r]
                    if new == 0:
                        consistent = False
                        break
                    if new != old:
                        saved.append((w, old))
                        possible[w] = new
            if not consistent:
                for w, old in saved:
                    possible[w] = old
                continue

            color[v] = r
            if dfs(pos + 1):
                return True
            color[v] = -1
            for w, old in saved:
                possible[w] = old
        return False

    if dfs(0):
        # translate residues to required values 1,2,3
        out = []
        for r in color:
            if r == 0:
                out.append('3')
            elif r == 1:
                out.append('1')
            else:
                out.append('2')
        sys.stdout.write("YES\n")
        sys.stdout.write(' '.join(out))
    else:
        sys.stdout.write("NO\n")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
