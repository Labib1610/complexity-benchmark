<STATEMENT>
# Problem A — Waveform Stability

Time limit: 2 s
Memory limit: 256 MB

You are configuring a system of $n$ signal relays, numbered 1 to $n$. Each relay must be assigned a frequency multiplier chosen from the values 1, 2, and 3. This configuration is expressed as a sequence $f_1, f_2, \dots, f_n$, where $f_i \in \{1, 2, 3\}$ is the multiplier for relay $i$.

The facility has exactly 40 available mounting slots, establishing the absolute upper limit for the number of relays $n$ (which is at least 1). You are provided with a list of $m$ pairs of relays that are in physical proximity. The number of proximity pairs $m$ can be anything from 0 up to the theoretical maximum where every relay interacts with every other distinct relay.

When two relays $u$ and $v$ are in proximity, their signals interact. To evaluate the stability of their interaction, we model their combined waveform using the continuous function:
$W_{u,v}(x) = \frac{x^3}{3} - \frac{(f_u + f_v)x^2}{2} + f_u f_v x$

The two relays will create a destructive resonant loop if and only if the function $W_{u,v}(x)$ does not possess a local maximum anywhere on the real line.

Your task is to determine if there exists a valid sequence of multipliers such that absolutely no resonant loops are created among any of the given proximity pairs. If such a sequence exists, you must output it.

## Input
The first line contains two integers $n$ and $m$.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that relay $u$ and relay $v$ are in physical proximity.

## Output
If there is no valid sequence of multipliers that avoids all resonant loops, print a single line containing `NO`.
If at least one such sequence exists, print `YES` on the first line. On the second line, print the $n$ integers $f_1, f_2, \dots, f_n$ representing the multipliers assigned to the relays. 
If there are multiple valid sequences, you must output the one that is lexicographically smallest. (A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the vector cross-product equality check with a continuous calculus condition: a cubic function constructed from the relay multipliers lacks a local maximum if and only if the multipliers are equal. This forces the model to symbolically analyze the derivative of the polynomial to deduce the discrete constraint $f_u \neq f_v$, defeating models that only pattern-match explicit vector cross products or simple algebraic equalities. I also applied Strategy S07 by moving the explicit numeric bounds into the description as physical facility constraints.
</RATIONALE>
<PRESERVED_ANSWER>
The derivative of the cubic function is a parabola with roots at $f_u$ and $f_v$; it lacks a local maximum if and only if the roots are identical, meaning the forbidden condition remains exactly $f_u = f_v$ for adjacent relays, leaving all valid assignments and the lexicographical tie-breaker mathematically identical.
</PRESERVED_ANSWER>
