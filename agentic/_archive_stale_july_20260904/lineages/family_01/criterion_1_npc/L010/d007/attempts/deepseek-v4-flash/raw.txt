 We need to assign each relay a value from {1, 2, 3} such that for every pair of connected relays, their assigned values are different.  

This is exactly the **3-coloring problem** on an undirected graph.  
We can solve it with backtracking, trying colors in order 1, 2, 3 to get the lexicographically smallest solution.

Here’s the code:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

colors = [0] * n

def is_safe(node, color):
    for nei in adj[node]:
        if colors[nei] == color:
            return False
    return True

def solve(node):
    if node == n:
        return True
    for c in (1, 2, 3):
        if is_safe(node, c):
            colors[node] = c
            if solve(node + 1):
                return True
            colors[node] = 0
    return False

if solve(0):
    print("YES")
    print(" ".join(map(str, colors)))
else:
    print("NO")
```
