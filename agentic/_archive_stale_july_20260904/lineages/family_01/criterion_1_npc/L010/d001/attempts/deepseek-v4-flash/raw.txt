 We need to assign each specimen to one of three storage units such that no volatile pair is in the same unit.  
This is equivalent to a graph 3-coloring problem, where each specimen is a vertex and each volatile pair is an edge.  

Since \( n \leq 40 \), we can use backtracking with pruning.  
We’ll try to assign colors 1, 2, 3 in lexicographic order to get the smallest possible assignment.

Here’s the Python solution:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def backtrack(idx):
    if idx == n:
        return True
    for c in range(1, 4):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if backtrack(idx + 1):
                return True
            color[idx] = 0
    return False

if backtrack(0):
    print("YES")
    print(" ".join(str(c) for c in color))
else:
    print("NO")
```
