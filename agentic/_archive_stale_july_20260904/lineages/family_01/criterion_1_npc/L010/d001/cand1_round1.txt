<STATEMENT>
# Problem A — Reactive Storage

Time limit: 2 s   Memory limit: 256 MB

A research facility relies on three specialized containment units, designated as 1, 2, and 3. The facility needs to store $n$ volatile chemical specimens. Due to their properties, specific pairs of these specimens are reactive and will cause a hazard if placed into the identical containment unit. You must determine a safe distribution that routes each specimen into exactly one of the three units such that no two reactive specimens share a unit. If no such distribution is possible, you must report this.

Be aware that the evaluation datasets are adversarially designed to exhaust simple sequential assignment strategies. The numbering of the specimens has been intentionally arranged so that the most dense, restrictive, and potentially unsatisfiable reactive dependencies are concentrated among the highest-numbered specimens, late in the natural ordering $1, 2, \dots, n$.

## Input
The first line provides two integers $n$ and $m$ — representing the total number of specimens and the number of reactive pairs, respectively ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Following this are $m$ lines, each containing two integers $u$ and $v$, which identify a pair of specimens that are reactive with each other.

## Output
If it is impossible to safely store all specimens, output a single line with the word `NO`.
If a safe distribution is possible, output `YES` on the initial line. On the subsequent line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), with $s_i$ denoting the containment unit chosen for specimen $i$. If there are multiple safe distributions, you must output the one that produces the lexicographically smallest sequence (comparing the unit of specimen 1 first, then specimen 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
