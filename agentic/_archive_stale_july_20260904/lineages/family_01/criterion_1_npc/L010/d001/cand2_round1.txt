# Problem A — Reactive Storage

Time limit: 2 s   Memory limit: 256 MB

A laboratory manages three distinct isolation vaults, identified as vault 1, vault 2, and vault 3. The facility currently holds n chemical specimens. Certain pairs of these specimens are highly reactive with one another and will cause an explosion if stored in the same vault. Your task is to allocate each specimen to exactly one of the three vaults such that no two reactive specimens share the same vault, or determine that no such safe allocation is possible.

Specimen ID numbers are given sequentially based on their intake order. Because of the laboratory's testing schedule, the most dense and restrictive reactive dependencies consistently involve the highest-numbered specimens. Consequently, a basic sequential search that attempts to allocate specimens in order from 1 to n will waste time exploring vast numbers of doomed partial allocations before realizing a high-numbered specimen has no safe vault, and will exceed the time limit on the official evaluation cases.

## Input
The first line provides two integers n and m — representing the total number of specimens and the number of reactive dependencies, respectively (1 ≤ n ≤ 40, 0 ≤ m ≤ n·(n−1)/2).
The following m lines each contain two integers u and v, indicating that specimen u and specimen v are reactive and cannot be placed together.

## Output
If a safe allocation cannot be achieved, output a single line containing NO.
If a safe allocation is possible, output YES on the first line. On the second line, output n integers s₁ s₂ … sₙ (where each sᵢ ∈ {1, 2, 3}), representing the vault assigned to specimen i. If multiple safe allocations exist, you must output the one that is lexicographically smallest (i.e., compare the vault of specimen 1 first, then specimen 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
