    # Optimization: Precompute `forbidden` masks for B.
    # `forbidden_masks[v]` = bitmask of vertices in B that are neighbors of v (if v in A).
    # Actually, for each vertex `u` in A, let `mask_B[u]` be the neighbors of `u` in B.
    # When we assign `u` color `c`, we update `FB[c] |= mask_B[u]`.
    
    # Precompute `mask_B` for vertices in A.
    mask_B = [0] * n
    for u in range(mid):
        m_val = 0
        for v in adj[u]:
            if v >= mid:
                m_val |= (1 << (v - mid))
        mask_B[u] = m_val
        
    # Precompute `mask_A` for vertices in B (neighbors in A).
    # Useful for pruning: if a vertex v in B has neighbors in A of colors 1, 2, 3, then v is dead.
    # We can maintain `forbidden_count[v]` = number of forbidden colors for v.
    # Or simply check `FB1, FB2, FB3`.
    
    # We need to find the lex smallest solution.
    # We try to fill `ans` array.
    ans = [0] * n
    
    # We need a function to solve B given FB1, FB2, FB3.
    # Returns True if solvable, fills `ans[mid:]`.
    # We use a separate DFS for B.
    
    # To speed up B DFS:
    # We can precompute the subgraph of B.
    # `adj_B`: adjacency list for B (local indices 0..rem-1).
    adj_B = [[] for _ in range(rem)]
    for i in range(rem):
        u_global = i + mid
        for v_global in adj[u_global]:
            if v_global >= mid:
                adj_B[i].append(v_global - mid)
                
    # We also need `forbidden` masks for B.
    # Passed as arguments.
    
    # Let's write the solver.
    
    # `solve_A(idx)`:
    # Tries to color A[idx], A[idx+1], ...
    # Uses global `ans` for colors of 0..idx-1.
    # Maintains `FB1, FB2, FB3`.
    
    # `solve_B()`:
    # Called when A is colored.
    # Tries to color B.
    
    # To make it faster, we can integrate B solving into the main logic.
    # But separating is cleaner.
    
    # Pruning in `solve_A`:
    # After assigning color to `idx`, check if any vertex in B is fully forbidden.
    # `FB1 | FB2 | FB3` doesn't help directly.
    # We need: for each v in B, is it possible to color it?
    # v is impossible if (v in FB1) and (v in FB2) and (v in FB3).
    # i.e. (FB1 & FB2 & FB3) != 0.
    # We can check this.
    
    FB = [0, 0, 0] # FB[0], FB[1], FB[2] corresponding to colors 1, 2, 3.
    
    def solve_B_local():
        # We need to color vertices mid .. n-1.
        # Constraints: ans[i] is fixed for i < mid.
        # We have FB[0], FB[1], FB[2].
        # We use a recursive function.
        
        # To optimize, we can reorder vertices in B by degree or constraints.
        # But simple DFS might suffice given rem <= 20.
        
        # We need to find LEX SMALLEST solution for B.
        # So we try colors 1, 2, 3 for B[mid], then B[mid+1], etc.
        
        # Pruning:
        # If a vertex v in B has all colors forbidden, return False.
        # This is checked dynamically.
        
        # We can precompute `forbidden_by_A[v]` for v in B.
        # `forbidden_by_A[v]` is a mask of colors forbidden by A.
        # mask bit 0 -> color 1 forbidden, etc.
        # This is constant for the current A assignment.
        
        forbidden_by_A = [0] * rem
        for i in range(rem):
            # Check FB masks
            if (FB[0] >> i) & 1: forbidden_by_A[i] |= 1
            if (FB[1] >> i) & 1: forbidden_by_A[i] |= 2
            if (FB[2] >> i) & 1: forbidden_by_A[i] |= 4
            
        # Check if any vertex is already fully forbidden
        for i in range(rem):
            if forbidden_by_A[i] == 7: # 111
                return False
        
        # DFS for B
        # We can use a simple recursion.
        # To speed up, we can use a greedy choice if possible?
        # No, greedy might fail to find solution or find non-lex-smallest.
        # But we want lex smallest.
        # We try color 1, then 2, then 3.
        
        # Optimization: Order of vertices.
        # We must fill `ans` in order mid, mid+1, ...
        # So recursion index is local index 0..rem-1.
        
        # We can pass `forbidden_by_A` and update it?
        # No, `forbidden_by_A` is from A. We also have constraints from B.
        # Constraints from B: neighbors in B cannot have same color.
        
        # `color_B(local_idx, current_forbidden_by_A)`
        # This is slow.
        
        # Better: `color_B(local_idx)`
        # Check valid colors for `local_idx`.
        # Valid means:
        # 1. Not forbidden by A (check FB).
        # 2. Not used by any already-colored neighbor in B.
        
        # We can use a simple array `ans_B` for B part.
        # Actually `ans` is global.
        
        # Let's implement `color_B(idx)` where idx is local index in B.
        # We use closure over `ans`, `adj_B`, `FB`, `rem`.
        
        # To make it faster, we can use bitmasks for "colors used by neighbors in B".
        # But rem is small.
        
        # Let's try simple recursion.
        
        def dfs_b(k):
            if k == rem:
                return True
            
            # Vertex global index
            v = mid + k
            
            # Try colors 1, 2, 3
            for c in range(1, 4):
                # Check forbidden by A
                if (FB[c-1] >> k) & 1:
                    continue
                
                # Check neighbors in B (already colored)
                # Neighbors of v in B are adj_B[k]
                ok = True
                for neighbor_local in adj_B[k]:
                    if neighbor_local < k: # already colored
                        if ans[mid + neighbor_local] == c:
                            ok = False
                            break
                if not ok:
                    continue
                
                # Check neighbors in A (already colored)
                # We already checked FB, which covers this.
                # BUT, we must also check neighbors in A that are NOT in FB.
                # Wait. FB contains vertices in B that are forbidden.
                # Here we are checking if color c is valid for v.
                # v is in B.
                # Neighbors of v in A: we need to check if any neighbor u in A has color c.
                # This is EXACTLY what FB checks.
                # If u in A has color c, then v is in FB[c-1].
                # So if we pass FB check, we are good regarding A.
                
                ans[v] = c
                if dfs_b(k + 1):
                    return True
                ans[v] = 0 # backtrack
            
            return False

        return dfs_b(0)

    def solve_A(idx):
        if idx == mid:
            # Check if B is solvable
            return solve_B_local()
        
        # Try colors 1, 2, 3 for vertex idx
        # We need to check validity with previous vertices in A
        for c in range(1, 4):
            # Check neighbors in A
            ok = True
            for neighbor in adj[idx]:
                if neighbor < idx:
                    if ans[neighbor] == c:
                        ok = False
                        break
            if not ok:
                continue
            
            # Assign color
            ans[idx] = c
            
            # Update FB
            # We need to add neighbors of idx (in B) to FB[c-1]
            # Store old FB to backtrack
            old_fb = FB[c-1]
            FB[c-1] |= mask_B[idx]
            
            # Pruning: check if any vertex in B is fully forbidden
            # (FB[0] & FB[1] & FB[2]) != 0
            # This check is O(1) roughly.
            if (FB[0] & FB[1] & FB[2]) == 0:
                if solve_A(idx + 1):
                    return True
            
            # Backtrack
            FB[c-1] = old_fb
            ans[idx] = 0
        
        return False

    # Special case: n <= 20, mid = n // 2.
    # If n <= 20, mid could be 10. B has 10.
    # solve_A runs on 0..9. solve_B on 10..19.
    # This works.
    # If n=1, mid=0. solve_A returns True immediately. solve_B runs on 0..0.
    # Wait, if mid=0, solve_A(0) calls solve_B immediately.
    # mask_B is empty. FB is empty.
    # solve_B runs on all vertices.
    # This is correct.
    
    # What if n=40. mid=20.
    # solve_A runs on 20 vertices.
    # solve_B runs on 20 vertices.
    # This is the target.
    
    # One edge case: mid could be 0 if n=1?
    # n=1 -> mid=0. Loop range(0) is empty. mask_B empty.
    # solve_A(0) -> solve_B().
    # solve_B runs on 1 vertex.
    # Correct.
    
    # Optimization:
    # If mid == n (i.e. n=0, impossible by constraints), or n small.
    # If mid == n, then B is empty. solve_B should return True.
    # rem = n - mid = 0. solve_B returns True. Correct.
    
    # Is there any case where `solve_A` is slow?
    # Yes, if A has many valid colorings.
    # But as argued, if A has many colorings, it's sparse.
    # If A is sparse, B is likely solvable.
    # The only risk is if A is sparse and B is hard.
    # But if A is sparse, constraints on B are weak.
    # So B is solvable.
    
    # Let's add a heuristic: if A is empty, skip DFS_A.
    # A is empty if m=0 or all edges are in B.
    # Check if A has any edges.
    has_edges_A = False
    for i in range(mid):
        if adj[i]:
            has_edges_A = True
            break
    
    if not has_edges_A:
        # A is empty (independent set).
        # Lex smallest coloring for A is all 1s.
        for i in range(mid):
            ans[i] = 1
            # Update FB[0]
            FB[0] |= mask_B[i]
        
        # Check if B is solvable
        if solve_B_local():
            print("YES")
            print(" ".join(map(str, ans)))
            return
        else:
            # If A is empty, FB is empty. B is solvable iff B is 3-colorable.
            # If B is not 3-colorable, then NO solution.
            print("NO")
            return

    # General case
    if solve_A(0):
        print("YES")
        print(" ".join(map(str, ans)))
    else:
        print("NO")

solve()
