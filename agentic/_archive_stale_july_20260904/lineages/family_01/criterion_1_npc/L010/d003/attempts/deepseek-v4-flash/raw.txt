 We need to assign each vertex one of three colors (networks) such that no edge connects two vertices of the same color. This is exactly the 3-coloring problem, which is NP-complete in general, but here n ≤ 40, so we can use backtracking with pruning.

We can also use a simple backtracking that tries colors 1, 2, 3 for each vertex in order, checking constraints, and stops at the first valid assignment (which will be lexicographically smallest because we try colors in increasing order).

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in range(1, 4):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(c) for c in color))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
