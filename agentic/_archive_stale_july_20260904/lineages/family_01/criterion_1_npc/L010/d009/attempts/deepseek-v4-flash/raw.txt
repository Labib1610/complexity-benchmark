 We need to check the condition for each edge:

\[
f_u^3 + f_v^3 > (f_u + f_v) f_u f_v
\]

Let’s simplify:

\[
f_u^3 + f_v^3 > f_u^2 f_v + f_u f_v^2
\]
\[
f_u^3 + f_v^3 - f_u^2 f_v - f_u f_v^2 > 0
\]
\[
(f_u + f_v)(f_u^2 - f_u f_v + f_v^2) - f_u f_v (f_u + f_v) > 0
\]
\[
(f_u + f_v)(f_u^2 - 2 f_u f_v + f_v^2) > 0
\]
\[
(f_u + f_v)(f_u - f_v)^2 > 0
\]

Since \(f_u + f_v > 0\) always (values are 1, 2, 3), the condition reduces to:

\[
(f_u - f_v)^2 > 0
\]

Which means:

\[
f_u \neq f_v
\]

So the problem is: assign each node a value from {1, 2, 3} such that adjacent nodes have different values. This is exactly a graph coloring problem with 3 colors.

Since \(n \leq 40\), we can use backtracking with pruning to find the lexicographically smallest assignment.

We'll try values 1, 2, 3 in order for each node, and backtrack if conflict.

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def dfs(idx):
    if idx == n:
        return True
    for c in (1, 2, 3):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if dfs(idx + 1):
                return True
            color[idx] = 0
    return False

if dfs(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
