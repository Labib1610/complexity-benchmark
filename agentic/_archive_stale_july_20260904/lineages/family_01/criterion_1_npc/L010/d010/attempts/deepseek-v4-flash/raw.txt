We need to assign each relay a multiplier from {1, 2, 3} such that for any connected pair, the possible frequency intervals [f−1/3, f+1/3] are separated by more than 1/4 regardless of actual drift values.

Let’s check condition for two multipliers:

- Multipliers (1,1): intervals [2/3, 4/3] and [2/3, 4/3] — overlap clearly. NOT OK.
- Multipliers (1,2): [2/3,4/3] and [5/3,7/3]. Distance between intervals: 5/3 - 4/3 = 1/3 > 1/4 → OK.
- Multipliers (1,3): [2/3,4/3] and [8/3,10/3]. Distance: 8/3 - 4/3 = 4/3 > 1/4 → OK.
- Multipliers (2,3): [5/3,7/3] and [8/3,10/3]. Distance: 8/3 - 7/3 = 1/3 > 1/4 → OK.
- Multipliers (2,2): overlap → NOT OK.
- Multipliers (3,3): overlap → NOT OK.

So a pair is allowed only if their assigned multipliers differ by at least 1.  
That means valid assignments are exactly 3-colorings of the graph such that adjacent vertices get different colors (1, 2, 3).

Thus, we need to find lexicographically smallest proper 3-coloring (if it exists) for n ≤ 40.  
We can use backtracking with pruning.

We output `NO` if no coloring exists.  
If exists, output YES and the sequence.

---

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n  # 0 = uncolored, colors 1,2,3
    
    # Precompute adjacency sets for fast checking
    adj_set = [set(adj[i]) for i in range(n)]
    
    # Sort vertices by degree descending for better pruning
    order = sorted(range(n), key=lambda x: -len(adj[x]))
    pos = [0] * n
    for idx, v in enumerate(order):
        pos[v] = idx
    
    def backtrack(idx):
        if idx == n:
            return True
        v = order[idx]
        used = set()
        for nb in adj_set[v]:
            if color[nb] != 0:
                used.add(color[nb])
        for c in (1, 2, 3):
            if c not in used:
                color[v] = c
                if backtrack(idx + 1):
                    return True
                color[v] = 0
        return False
    
    # Try to get lexicographically smallest by assigning from 1..n
    # But backtracking order above is not lexicographic; we do a custom DFS
    # Let's instead do DFS by variable index 0..n-1 for lexicographic order.

    def dfs_lex(i):
        if i == n:
            return True
        for c in (1, 2, 3):
            # check neighbors
            ok = True
            for nb in adj_set[i]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[i] = c
                if dfs_lex(i + 1):
                    return True
                color[i] = 0
        return False
    
    if dfs_lex(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
