<STATEMENT>
# Problem A — Sequence Synthesis under Asymmetric-Form Constraints

Time limit: 2 s
Memory limit: 256 MB

You are designing an algorithmic generator to synthesize a valid sequence of $n$ integers, denoted as $A_1, A_2, \dots, A_n$.
The generator must construct this sequence such that:

1. Every element $A_i$ is chosen from the restricted domain $\{1, 2, 3\}$.
2. The sequence satisfies a provided list of $m$ structural rules. Each rule is defined by an ordered pair of 1-based indices $(u, v)$. To satisfy the rule, your sequence must ensure that the computed value $A_u + 2 A_v$ is not a multiple of 3.

Your objective is to determine whether at least one such sequence $A$ can be synthesized. The evaluation tests include highly restrictive rule sets, intentionally designed so that unoptimized sequential guessing will exceed the time limit. Your approach must efficiently navigate the search space.

If it is possible to synthesize one or more valid sequences, you must output the one that is lexicographically smallest. A sequence $A$ is lexicographically smaller than a sequence $B$ if, at the first index $i$ where they differ, $A_i < B_i$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$). This indicates a rule where the sequence values at indices $u$ and $v$ must satisfy the condition that $A_u + 2 A_v$ is not a multiple of 3.

## Output
If it is impossible to synthesize a valid sequence, print a single line containing the word `NO`.
If a valid sequence is achievable, print `YES` on the first line. On the second line, print the $n$ integers $A_1, A_2, \dots, A_n$ separated by spaces, representing the lexicographically smallest valid sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I changed the symmetric conflict condition (items cannot share a state) into a syntactically asymmetric mathematical condition ($A_u + 2A_v$ is not a multiple of 3). This forces the model to mathematically reason about the condition to realize it is equivalent to $A_u \neq A_v$ and thus symmetric; otherwise, naive translation combined with standard undirected graph templates will likely lead to buggy state-space traversal.
</RATIONALE>
<PRESERVED_ANSWER>
For values restricted to $\{1, 2, 3\}$, the condition $A_u + 2A_v \not\equiv 0 \pmod 3$ evaluates to false if and only if $A_u = A_v$, making it mathematically identical to the original "cannot share" constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest valid 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
