# Problem A — Bio-Hazard Routing Protocol

Time limit: 2 s
Memory limit: 256 MB

A containment facility manages three distinct atmospheric scrubbers, designated by the operational codes 1, 2, and 3. The facility contains $n$ separate biological sectors, indexed from 1 to $n$. Due to cross-contamination risks, certain pairs of sectors will trigger a bio-hazard cascade if they are vented into the exact same scrubber. To maintain quarantine protocols, every sector must be routed to one of the three scrubbers such that no two cross-contaminating sectors share the same scrubber.

You must evaluate whether a safe routing configuration exists for the $n$ sectors. If it does, you must output the valid configuration. Note that the evaluation tests include worst-case configurations intentionally constructed so that naive trial-and-error routing strategies will require an impractical number of steps. Your approach must efficiently handle these highly constrained scenarios.

## Input
The first line provides two integers, $n$ and $m$, which denote the number of biological sectors and the number of cross-contaminating pairs, respectively. The facility's telemetry system uses a 40-bit status register that allocates exactly one bit per sector, meaning the number of sectors $n$ can range from a single sector up to the full capacity of this register. The number of cross-contaminating pairs $m$ can be anything from zero up to the theoretical maximum where every distinct pair of sectors poses a contamination risk.
Each of the subsequent $m$ lines contains two distinct integers $u$ and $v$, representing the 1-based indices of two sectors that pose a cross-contamination risk.

## Output
If it is impossible to find a safe routing configuration, print a single line containing the word `NO`.
If a safe configuration is achievable, output `YES` on the first line. On the second line, output $n$ integers $g_1, g_2, \dots, g_n$ (each being 1, 2, or 3), where $g_i$ represents the scrubber code chosen for sector $i$.
In the event that more than one safe configuration is possible, you must select the one that minimizes the facility's total routing priority score $P$. The score is calculated using the formula:
$$P = \sum_{i=1}^{n} g_i \cdot 4^{n-i}$$
where $g_i$ is the scrubber code assigned to sector $i$. For example, if $n=4$, the score is $g_1 \cdot 64 + g_2 \cdot 16 + g_3 \cdot 4 + g_4 \cdot 1$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
