We need to check if we can assign each relay a value from {1, 2, 3} such that for every edge (u, v), the cross product of their configuration vectors is not zero.

The configuration vector is \( C_i = (1, f_i, f_i^2) \).  
The cross product of \( C_u \) and \( C_v \) is zero if and only if the two vectors are linearly dependent.  
Since the first component is always 1, the vectors are linearly dependent only if \( f_u = f_v \).  
So the condition reduces to: **no two connected relays can have the same multiplier**.

Thus, the problem becomes:  
Given a graph with n ≤ 40, can we 3-color it (with colors 1, 2, 3) such that adjacent vertices have different colors?  
We need the lexicographically smallest coloring.

We can solve this with backtracking + pruning, since n is small.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n
    # Precompute adjacency sets for faster checks
    adj_set = [set(adj[i]) for i in range(n)]
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj_set[idx]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[idx] = c
                if backtrack(idx + 1):
                    return True
                colors[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
