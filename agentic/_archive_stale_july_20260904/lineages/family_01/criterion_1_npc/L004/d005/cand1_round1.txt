<STATEMENT>
# Signal Separation Protocols

**Time limit:** 2 s  
**Memory limit:** 256 MB  

You manage an array of signal emitters, numbered from $1$ to $n$. Each emitter must operate on a single frequency mode. A valid frequency mode is defined as any positive integer whose factorial is at most its square.

Interference occurs if certain emitters share the same mode. You are provided with a list of $m$ critical pairs of emitters. For each critical pair $(u, v)$, their respective frequency modes $f_u$ and $f_v$ must satisfy the condition that their least common multiple is strictly greater than their greatest common divisor. The critical pairs can link any subsets of emitters in arbitrary arrangements, and all $m$ separation requirements must be simultaneously fulfilled.

Your task is to determine if a complete, valid mode configuration can be established for all $n$ emitters such that no critical pair violates the separation rule.

## Input
The first line consists of two integers $n$ and $m$. The number of emitters $n$ is at least 1 and is physically limited to at most the sum of the first four non-negative powers of 3. The number of critical pairs $m$ is non-negative and at most the maximum possible number of unique pairs among the $n$ emitters.
Each of the following $m$ lines provides two integers $u$ and $v$ (indices from $1$ to $n$), identifying a pair of emitters that are subject to the separation rule.

## Output
If there is no way to configure the emitters without violating the rules, output `NO` on a single line.
If a valid assignment is achievable, output `YES` on the first line. On the second line, provide a sequence of $n$ integers $f_1, f_2, \dots, f_n$ (where each $f_i$ is a valid frequency mode) representing the frequency mode for each emitter $i$. If more than one valid sequence exists, you must output the lexicographically smallest sequence (comparing the mode for emitter $1$ first, then emitter $2$, and so on up to emitter $n$).

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
1 4
2 4
```
**Output:**
```
YES
1 2 3 3
```

## Example 2
**Input:**
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
**Output:**
```
NO
```

<RATIONALE>
The explicit set of modes `{1, 2, 3}` was replaced with the mathematical condition $f_i! \le f_i^2$ for positive integers, which exactly evaluates to `{1, 2, 3}`. The separation condition $|f_u - f_v| \ge 1$ (equivalent to $f_u \neq f_v$) was replaced with $\text{lcm}(f_u, f_v) > \text{gcd}(f_u, f_v)$, which holds if and only if the two integers are distinct. The bounds were restated dynamically. This forces the model to deduce the available modes and the nature of the conflict rule through mathematical reasoning rather than recognizing straightforward 3-coloring terminology.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $f_i! \le f_i^2$ for positive integers restricts the modes to exactly `{1, 2, 3}`, and the LCM > GCD condition strictly enforces $f_u \neq f_v$, matching the original constraints perfectly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring, preserving its NP-complete complexity without using any graph terminology.
</PRESERVED_CLASS>
<RISK>
Models might struggle to correctly solve the inequality $x! \le x^2$ or mathematically prove that LCM > GCD is equivalent to $x \neq y$, potentially leading to incorrect domain extraction.
</RISK>
