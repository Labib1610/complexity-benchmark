# Sequence Separation Constraints

**Time limit:** 2 s  
**Memory limit:** 256 MB  

You are tasked with generating a sequence of $n$ integers, $F = (f_1, f_2, \dots, f_n)$, where each element must be chosen from the set $\{1, 2, 3\}$.

The sequence must satisfy a collection of $m$ separation constraints. Each constraint is defined by two sequence indices $u$ and $v$, requiring that the absolute difference between the values at these positions is strictly positive: $|f_u - f_v| \ge 1$. If this condition fails for any of the $m$ index pairs, the sequence is invalid.

Your objective is to determine whether there exists a valid sequence $F$ that satisfies all $m$ constraints simultaneously. The system of index constraints can be an arbitrary adversarial interconnection with no helpful structure, ordering, or sparsity. The constraints are globally entangled, meaning that configuring one position does not predictably restrict the available choices for others, and unoptimized sequential exploration will face severe exponential delays.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$), representing the length of the sequence and the number of separation constraints.
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that the sequence elements at indices $u$ and $v$ must satisfy the separation condition.

## Output
If no valid sequence exists, print `NO` on a single line.
If a valid sequence is possible, print `YES` on the first line. On the second line, output the $n$ integers $f_1, f_2, \dots, f_n$. Should multiple valid sequences exist, output the one that is lexicographically first (evaluating the choice for index 1 first, then index 2, and so on).

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
1 4
2 4
```
**Output:**
```
YES
1 2 3 3
```

## Example 2
**Input:**
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
**Output:**
```
NO
```

<RATIONALE>
Removed the claim that the pairs form a rigid structure and added wording that the network is an arbitrary adversarial interconnection lacking helpful structure or sparsity. Warned that unoptimized sequential exploration faces severe exponential delays. This deters the models from using the simple index-ordered backtracking that currently passes, pushing them toward heuristics (like dynamic variable ordering) that inadvertently violate the strict lexicographical tie-breaking requirement.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still asks for an assignment of values from {1, 2, 3} to $n$ variables such that specified pairs have an absolute difference of at least 1 (meaning they are simply unequal), and requires the lexicographically first valid assignment, which is mathematically identical to the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically first 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might interpret "unoptimized sequential exploration will face severe exponential delays" as a hint that a polynomial-time solution exists, though the NP-complete nature of the problem makes this impossible.
</RISK>
