<STATEMENT>
# Phase Array Calibration

**Time limit:** 2 s  
**Memory limit:** 256 MB  

A phase array system contains $n$ transmitters, labeled with integers from 1 to $n$. Each transmitter must be tuned to exactly one of three distinct frequency bands: Band 1, Band 2, or Band 3.

A transmitter operates safely if and only if, for every logged interference pair it belongs to, the other transmitter in that pair is tuned to a different frequency band. You are provided with a complete log of these interfering pairs. Your task is to determine whether there is a system-wide tuning where all transmitters operate safely.

The hidden tests include adversarial configurations of up to 40 transmitters that are designed to exceed the time limit if you rely on fixed-order sequential assignment without deduction.

## Input
The first line contains two integers $n$ and $m$. The hardware accommodates a transmitter count $n$ of at least 1, up to a rack capacity of 40. The interference log contains $m$ entries; this can be as low as 0 or as high as the maximum possible number of pairs, $n \cdot (n-1)/2$.
Each of the following $m$ lines contains two integers $u$ and $v$, specifying an interference pair between transmitter $u$ and transmitter $v$.

## Output
If no safe configuration exists, print `NO` on a single line.
If a valid configuration is possible, print `YES` on the first line. On the second line, output a sequence of $n$ integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2, 3\}$) representing the band assigned to transmitter $i$. If multiple valid configurations exist, output the assignment that is lexicographically first (comparing the band choice for transmitter 1 first, then transmitter 2, and so on).

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
1 4
2 4
```
**Output:**
```
YES
1 2 3 3
```

## Example 2
**Input:**
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
**Output:**
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was rewritten to describe the pair constraints as a local safety condition rather than a global network. I included an explicit warning about adversarial inputs to penalize models that rely on simple fixed-order backtracking patterns, forcing them to consider heuristic variable ordering or constraint propagation. Bounds were expressed indirectly through scenario capacities while retaining the exact digits for strict validation.
</RATIONALE>
<PRESERVED_ANSWER>
The core logic remains identical: assigning one of 3 values to $n$ items while avoiding identical assignments for any specified pair, with lexicographical tie-breaking.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is still isomorphic to 3-COLORING, which is NP-complete, requiring an exhaustive search with identical constraints.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the warning about adversarial tests as implying that a polynomial-time algorithm exists, though competent solvers will recognize it as a prompt for pruning/heuristics.
</RISK>
