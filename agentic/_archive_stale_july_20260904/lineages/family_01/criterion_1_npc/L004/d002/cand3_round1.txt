# Botanical Zoning

**Time limit:** 2 s  
**Memory limit:** 256 MB  

A research facility is cultivating $n$ experimental specimens, identified by integers from 1 to $n$. The facility operates exactly three distinct climate sectors: Sector 1, Sector 2, and Sector 3. Every specimen must be planted in exactly one of these three sectors.

Because of allelopathy—a biological phenomenon where organisms produce biochemicals that influence others—certain pairs of specimens will severely inhibit each other if they share the same soil environment. You will receive a complete log of these incompatible specimen pairs. You must figure out if there is a valid configuration that assigns each specimen to a sector without placing any incompatible pair in the same sector.

The specimens are cataloged in a way that scatters biologically related species across the numerical sequence. As a result, indirect allelopathic conflicts frequently span across widely separated IDs, meaning that a sequence of assignments might seem perfectly viable until distant interactions are exposed.

## Input
The first line provides two integers $n$ and $m$ — the total number of specimens and the total number of incompatible pairs ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$ representing a pair of specimens that are forbidden from sharing a sector.

## Output
If it is impossible to distribute the specimens safely, output a single line containing `NO`.
If a safe configuration is possible, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (each chosen from $\{1,2,3\}$), where $s_i$ represents the sector chosen for specimen $i$. If there are multiple valid configurations, you must output the sequence that is lexicographically smallest (comparing the choice for specimen 1 first, then specimen 2, and so forth).

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
1 4
2 4
```
**Output:**
```
YES
1 2 3 3
```

## Example 2
**Input:**
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
**Output:**
```
NO
```
