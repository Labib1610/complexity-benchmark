<STATEMENT>
# Orbital Power Routing

**Time limit:** 2 s  
**Memory limit:** 256 MB  

An orbital satellite relies on $n$ electronic modules, which are identified by integers from 1 to $n$. The satellite's power distribution system consists of exactly three isolated power buses: Bus 1, Bus 2, and Bus 3. Each module must be completely powered by exactly one of these three buses.

Because of electromagnetic interference, specific pairs of modules will suffer from critical crosstalk if they are connected to the identical bus. You are given $m$ interfering pairs. You must figure out if there is a valid configuration that assigns each module to a bus without placing any interfering pair on the same bus.

**Performance Note:** Module IDs may be permuted so that a numerical-order lexicographic DFS with buses tried in increasing order has exponentially many locally consistent prefixes before the decisive conflict. Solvers must use an effective variable-ordering or pruning strategy.

The bounds for the input are defined by the satellite's physical limits. The total count of modules $n$ is at least the smallest positive integer and at most the product of five and eight. The count of interfering pairs $m$ ranges from a minimum of zero up to the maximum number of distinct two-element combinations possible among the $n$ modules.

## Input
The first line provides two integers $n$ and $m$ — the total number of modules and the total number of interfering pairs.
The following $m$ lines each contain two integers $u$ and $v$ representing a pair of modules that are forbidden from sharing a bus.

## Output
If it is impossible to route the power safely, output a single line containing `NO`.
If a safe configuration is possible, output `YES` on the first line. On the second line, output $n$ integers $b_1, b_2, \dots, b_n$ (each chosen from $\{1,2,3\}$), where $b_i$ represents the bus chosen for module $i$. If there are multiple valid configurations, you must output the sequence that is lexicographically smallest (comparing the choice for module 1 first, then module 2, and so forth).

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
1 4
2 4
```
**Output:**
```
YES
1 2 3 3
```

## Example 2
**Input:**
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
**Output:**
```
NO
```
