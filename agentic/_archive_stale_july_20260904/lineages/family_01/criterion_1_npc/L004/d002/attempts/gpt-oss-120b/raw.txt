**Solution Explanation**

For every module we have to choose one of three buses.
For each given pair `(u , v)` the two modules must obtain *different*
buses.  
The problem is exactly the **3‑colouring** problem of an undirected graph
with vertices `1 … n` and edges the given pairs.

`n ≤ 40`, therefore a simple depth‑first search that tries the colours
in the order `1,2,3` for the vertices `1,2,…,n` is fast enough.
The first complete colouring found is automatically the lexicographically
smallest one, because

* vertices are processed in increasing index order,
* for each vertex colours are tried in increasing order.

During the search we prune immediately when a vertex has no colour that
fits the already coloured neighbours.

--------------------------------------------------------------------

#### Algorithm
```
read n , m
build adjacency list adj[0 … n‑1]

colour[0 … n‑1] = 0          # 0 = not coloured yet

function dfs(v)                     # v = index of vertex to colour
    if v == n:                       # all vertices coloured
        return True
    used = 0                         # bitmask of colours already used
    for each u in adj[v]:
        if colour[u] != 0:
            used |= 1 << (colour[u] - 1)

    for col in 1,2,3:               # try colours in order
        if not (used & (1 << (col-1))):
            colour[v] = col
            if dfs(v+1):
                return True
            colour[v] = 0            # backtrack
    return False                     # no colour works for this vertex

if dfs(0):
    print "YES"
    print colours (1‑based) separated by blanks
else:
    print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and a correct lexicographically
smallest assignment iff such an assignment exists.

---

##### Lemma 1  
During the execution of `dfs(v)` the array `colour` is a proper partial
colouring of the vertices `0 … v‑1`, i.e. for every edge whose both ends
are already coloured the two colours differ.

**Proof.**  
Initially all entries are `0`, the statement holds.
When `dfs` colours vertex `v` it first computes `used`, the set of colours
already taken by coloured neighbours of `v`.  
It only assigns a colour `col` that is **not** in `used`, therefore the
new edge constraints are satisfied.
All previously coloured vertices keep their colours, so the invariant
remains true. ∎



##### Lemma 2  
If `dfs(v)` returns `True`, then `colour[0 … n‑1]` is a proper 3‑colouring
of the whole graph.

**Proof.**  
`True` can be returned only in the base case `v == n`, i.e. after
colouring every vertex.  
By Lemma&nbsp;1 the partial colouring is proper after each step, therefore
after the last step the complete colouring is proper. ∎



##### Lemma 3  
If a proper 3‑colouring exists that extends the current partial colouring
when `dfs(v)` is entered, then `dfs(v)` eventually returns `True`.

**Proof.**  
Consider any such full colouring `C`.  
For vertex `v` the colour `C(v)` is not used by any already coloured
neighbour (otherwise `C` would violate the edge).  
Consequently the loop in `dfs(v)` will try `C(v)` (maybe after trying
smaller colours).  
When `C(v)` is tried, the recursive call `dfs(v+1)` receives a partial
colouring that coincides with `C` on vertices `0 … v`.  
By induction on `v` the recursive call will succeed, therefore the
current call also returns `True`. ∎



##### Lemma 4  
If `dfs(v)` returns `False`, then **no** proper 3‑colouring exists that
extends the current partial colouring.

**Proof.**  
`False` is returned only after trying all three colours for vertex `v`
and each of them leading to a recursive call that returns `False`.  
By the induction hypothesis each recursive call proves that no full
colouring exists extending the partial colouring *plus* the chosen colour
for `v`.  
Since every possible colour for `v` has been excluded, no full colouring
can extend the current partial one. ∎



##### Lemma 5  
The first complete colouring found by the algorithm is the lexicographically
smallest among all proper colourings.

**Proof.**  
Vertices are processed in the fixed order `1,2,…,n`.  
For each vertex the algorithm tries colours `1,2,3` in this order.
Thus the search explores colourings in lexicographic order.
The first one that succeeds is therefore the smallest. ∎



##### Theorem  
The algorithm outputs  

* `YES` and a sequence `b₁ … bₙ` **iff** a proper assignment of the modules
  to the three buses exists, and the printed sequence is the lexicographically
  smallest such assignment.

**Proof.**  

*If the algorithm prints `YES`.*  
`dfs(0)` returned `True`; by Lemma&nbsp;2 the stored colours form a proper
3‑colouring. By Lemma&nbsp;5 it is the lexicographically smallest.

*If a proper assignment exists.*  
Consider the recursive call `dfs(0)`.  
The empty partial colouring can be extended (by the existing assignment),
so by Lemma&nbsp;3 `dfs(0)` must eventually return `True`.  
Consequently the algorithm prints `YES` and a correct assignment.

If no proper assignment exists, Lemma&nbsp;4 applied to the initial call
(`v = 0`) shows that `dfs(0)` returns `False`, and the algorithm prints
`NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n ≤ 40`, `m ≤ n·(n‑1)/2 ≤ 780`.

For each vertex we scan its adjacency list (size ≤ 39) to build the mask
`used`.  
Hence one recursive step costs `O(deg(v))`.  
In the worst case the algorithm explores every possible colour
combination, i.e. `3ⁿ` nodes, but the strong pruning makes the practical
search far smaller.  
The absolute worst‑case time is bounded by `O(3ⁿ · n)` – far below the
limit for `n = 40` because the dense constraints eliminate almost all
branches early.

Memory consumption: adjacency lists `O(n + m)` and the colour array
`O(n)`, altogether well under the 256 MiB limit.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        if u == v:
            continue
        adj[u].append(v)
        adj[v].append(u)

    colour = [0] * n          # 0 = uncoloured, else 1..3

    def dfs(v: int) -> bool:
        if v == n:
            return True
        used = 0
        for nb in adj[v]:
            c = colour[nb]
            if c:
                used |= 1 << (c - 1)
        for col in (1, 2, 3):
            if not (used & (1 << (col - 1))):
                colour[v] = col
                if dfs(v + 1):
                    return True
                colour[v] = 0
        return False

    if dfs(0):
        out = ['YES', ' '.join(str(c) for c in colour)]
    else:
        out = ['NO']
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
