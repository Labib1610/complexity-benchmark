# Orbital Power Routing

**Time limit:** 2 s  
**Memory limit:** 256 MB  

An orbital satellite relies on $n$ electronic modules, which are identified by integers from 1 to $n$. The satellite's power distribution system consists of exactly three isolated power buses: Bus 1, Bus 2, and Bus 3. Each module must be completely powered by exactly one of these three buses.

Because of electromagnetic interference, specific pairs of modules will suffer from critical crosstalk if they are connected to the identical bus. You are given $m$ listed interfering pairs. You must figure out if there is a valid configuration that assigns each module to a bus without placing any interfering pair on the same bus.

The modules are numbered in a way that scatters deeply interconnected components across the numerical sequence. Be aware that in the test cases, module IDs are permuted such that evaluating assignments strictly in numerical order, while testing buses in increasing sequence, will generate exponentially many locally consistent prefixes before exposing a decisive structural conflict.

## Input
The first line provides two integers $n$ and $m$ — the total number of modules and the total number of listed interfering pairs ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$ representing a pair of modules that are forbidden from sharing a bus.

## Output
If it is impossible to route the power safely, output a single line containing `NO`.
If a safe configuration is possible, output `YES` on the first line. On the second line, output $n$ integers $b_1, b_2, \dots, b_n$ (each chosen from $\{1,2,3\}$), where $b_i$ represents the bus chosen for module $i$. If there are multiple valid configurations, you must output the sequence that is lexicographically smallest (comparing the choice for module 1 first, then module 2, and so forth).

## Example 1
**Input:**
```
4 5
1 2
1 3
2 3
1 4
2 4
```
**Output:**
```
YES
1 2 3 3
```

## Example 2
**Input:**
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
**Output:**
```
NO
```
