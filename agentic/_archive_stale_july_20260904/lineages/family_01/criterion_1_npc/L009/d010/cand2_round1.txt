<STATEMENT>
# Problem A — Compound Stability

Time limit: 2 s
Memory limit: 256 MB

You are tasked with determining the properties of a sequence of $n$ chemical additives. Each additive $i$ in the sequence must be assigned a concentration level $c_i$. Concentration levels are positive integers. Due to the valency limit of the base solvent, no concentration level can exceed 3.

You are provided with $m$ constraints. Each constraint is defined by a pair of distinct indices $(u, v)$, representing two additives that interact when mixed. 

The interaction energy between the additive at index $u$ and the additive at index $v$ is calculated using their assigned concentration levels:
$E(u, v) = (c_u - c_v)^4 - 5(c_u - c_v)^2 + 2$

For the sequence of additives to form a stable compound, the total interaction energy across all $m$ given constraints must reach its theoretical absolute minimum, which is exactly $-2m$. That is, the sum of $E(u, v)$ for all $m$ constraints must equal $-2m$. If this condition is not met, the compound will destabilize.

If there are multiple valid sequences of concentration levels that achieve this stable state, you must determine the one that is lexicographically smallest. A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index where they differ, sequence $A$ has a smaller concentration level than sequence $B$.
If no sequence can achieve the required total interaction energy, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ — the length of the sequence and the number of constraints, respectively. The number of additives $n$ is at least 1 and will not exceed the 40 available test tubes in the rack. The number of constraints $m$ ranges from zero up to the maximum possible number of unique pairs among the additives.
Each of the following $m$ lines contains two distinct integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$) — indicating a constraint between the additives at index $u$ and index $v$.

## Output
If no valid sequence exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$, representing the lexicographically smallest valid sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem has been completely reframed using a global energy minimum condition. The polynomial $E(u, v) = (c_u - c_v)^4 - 5(c_u - c_v)^2 + 2$ evaluates to exactly -2 when $c_u \neq c_v$ (since the difference is $\pm 1$ or $\pm 2$) and evaluates to 2 when $c_u = c_v$. Because the absolute minimum possible value for any pair is -2, the only way $m$ constraints can sum to exactly $-2m$ is if every single constraint evaluates to -2. This forces a reasoning step: models that blindly implement the condition as a global sum will be unable to prune their backtracking search tree and will Time Limit Exceed on $3^{40}$ states, whereas models that mathematically deduce the minimum is achieved if and only if $c_u \neq c_v$ for all constraints will reduce it to standard 3-coloring and succeed.
</RATIONALE>
<PRESERVED_ANSWER>
The polynomial is carefully constructed so that the sum condition $\sum E(u, v) = -2m$ holds if and only if $c_u \neq c_v$ for all constrained pairs, which is mathematically identical to the seed problem's divisibility condition, meaning the exact same sequences are valid.
</PRESERVED_ANSWER>
