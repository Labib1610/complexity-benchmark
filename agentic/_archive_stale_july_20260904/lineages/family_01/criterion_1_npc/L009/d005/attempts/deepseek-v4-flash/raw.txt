 We need to check the determinant condition for each pair.  

The matrix is:  

\[
\begin{vmatrix}
1 & 1 & 1 \\
c_u & c_v & 4 \\
c_u^2 & c_v^2 & 16
\end{vmatrix}
\]

This is a Vandermonde-like determinant.  
The determinant is:  

\[
(c_v - c_u)(4 - c_u)(4 - c_v)
\]

For it to be non-zero, we need:  
- \(c_u \neq c_v\)  
- \(c_u \neq 4\) (always true since values are 1,2,3)  
- \(c_v \neq 4\) (always true)  

So the only condition is \(c_u \neq c_v\).  

Thus, the problem reduces to: assign values from {1,2,3} to vertices such that for each given edge, the two endpoints have different values. This is a graph coloring problem with 3 colors.  

We can solve greedily: assign the smallest possible value to each vertex in order, checking constraints from already assigned neighbors. If at any point no value works, output `NO`.  

Here’s the implementation:  

```python
n, m = map(int, input().split())
edges = [tuple(map(int, input().split())) for _ in range(m)]

adj = [[] for _ in range(n)]
for u, v in edges:
    adj[u-1].append(v-1)
    adj[v-1].append(u-1)

colors = [0] * n

for i in range(n):
    used = set()
    for nb in adj[i]:
        if colors[nb] != 0:
            used.add(colors[nb])
    for c in (1, 2, 3):
        if c not in used:
            colors[i] = c
            break
    else:
        print("NO")
        break
else:
    print("YES")
    print(" ".join(map(str, colors)))
```
