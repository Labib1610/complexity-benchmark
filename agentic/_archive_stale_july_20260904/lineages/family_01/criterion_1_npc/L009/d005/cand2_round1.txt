<METHOD_DESCRIPTION>Hide the domain {1,2,3} behind a non-trivial integer inequality, and hide the adjacency constraint (c_u != c_v) behind a matrix determinant whose value mathematically simplifies to (u+v)(c_v-c_u). Because the matrix incorporates the edge indices u and v, the model is likely to interpret the constraint as edge-specific (a general CSP) rather than a uniform graph coloring constraint. This prevents the model from mapping the problem to its optimized 3-coloring templates, forcing it to fall back to generic backtracking which will TLE on n=40.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Network Configuration Parameters

Time limit: 2 s   Memory limit: 256 MB

You are tasked with assigning configuration parameters to a network of sensor nodes.

The network consists of a number of nodes, denoted as $n$. A single technician can configure at most 40 nodes in a workday, which sets the upper limit on $n$, while there is always a minimum of 1 node.
The number of interference links, $m$, can range from 0 up to the maximum possible number of unique unordered pairs of nodes in the network.

Each node $i$ (indexed from $1$ to $n$) must be assigned a configuration parameter $c_i$. This parameter must be a positive integer such that the sum of its first $c_i$ positive multiples (i.e., $1 \cdot c_i + 2 \cdot c_i + \dots + c_i \cdot c_i$) is at most 18.

You are provided with $m$ interference links. Each link is defined by a pair of distinct node indices $(u, v)$. For the network to operate correctly, every linked pair must satisfy a transformation stability condition. Specifically, their assigned parameters must form a valid transformation matrix $M$, defined as:
$$M = \begin{pmatrix} c_u & c_v & u \\ c_v & c_u & v \\ 1 & 1 & 0 \end{pmatrix}$$
To ensure no data is lost during transformation, this matrix must be invertible (i.e., its determinant must not be zero).

If there are multiple valid parameter assignments that satisfy all constraints, you must output the one that is lexicographically smallest. An assignment $A$ is lexicographically smaller than assignment $B$ if, at the first node index where they differ, assignment $A$ has a smaller parameter value than assignment $B$.
If no assignment can satisfy all constraints, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ — the number of nodes and the number of interference links.
Each of the following $m$ lines contains two distinct integers $u$ and $v$, indicating an interference link between the node at index $u$ and the node at index $v$.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$, representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The domain {1, 2, 3} is obfuscated by an inequality on the sum of multiples, forcing the model to deduce the valid values. The adjacency constraint (c_u != c_v) is hidden behind a 3x3 matrix determinant that evaluates to (u+v)(c_v-c_u). Because this matrix incorporates the edge indices u and v, models are likely to treat this as a complex, edge-specific CSP rather than recognizing the pure 3-coloring graph structure, thereby disrupting the deployment of optimized heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The domain restriction limits c_i to exactly {1, 2, 3}, and the matrix determinant is zero if and only if c_u = c_v, meaning all valid assignments are mathematically identical to those in the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Lexicographically First 3-Coloring, which is NP-complete, as the domain and inequality conditions strictly map 1:1 to the original constraints.
</PRESERVED_CLASS>
