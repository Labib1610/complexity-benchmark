 We need to check the condition for each pair.  
The energy function is:

\[
E(x) = x^2 - (c_u + c_v)x + c_u c_v
\]

This is a quadratic in \(x\) with a minimum at \(x = \frac{c_u + c_v}{2}\).  
The minimum value is:

\[
E_{\min} = c_u c_v - \frac{(c_u + c_v)^2}{4}
= -\frac{(c_u - c_v)^2}{4}
\]

For the minimum to be strictly negative, we need:

\[
-\frac{(c_u - c_v)^2}{4} < 0
\]
which means:
\[
(c_u - c_v)^2 > 0
\]
so:
\[
c_u \neq c_v
\]

Thus, every constraint means the two additives must have **different** concentration levels.

So the problem reduces to:  
We have \(n\) nodes, and edges between them mean the two nodes must have different values from \(\{1,2,3\}\).  
We need to find a valid assignment (if possible) that is lexicographically smallest.

This is a graph coloring problem with 3 colors. Since \(n \leq 40\), we can use backtracking with pruning.

We'll assign colors from 1 to 3 in order, trying smallest first, and check constraints.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

colors = [0] * n

def backtrack(idx):
    if idx == n:
        return True
    for c in range(1, 4):
        ok = True
        for nb in adj[idx]:
            if colors[nb] == c:
                ok = False
                break
        if ok:
            colors[idx] = c
            if backtrack(idx + 1):
                return True
            colors[idx] = 0
    return False

if backtrack(0):
    print("YES")
    print(" ".join(map(str, colors)))
else:
    print("NO")
```
