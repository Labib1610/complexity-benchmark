<METHOD_NAME>Global Triangular System Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced the local geometric condition with a global algebraic condition: a lower-triangular system of $m$ equations must have a unique solution. The diagonal coefficients are definite integrals of a carefully chosen linear function. The system has a unique solution iff all diagonal coefficients are non-zero, which occurs iff $c_u \neq c_v$. This defeats models that try to write a script to precompute local allowed pairs without first analytically reducing the global system.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem A — System of Sequences

Time limit: 2 s   Memory limit: 256 MB

You are tasked with finding an integer sequence $c_1, c_2, \dots, c_n$ where each element must be chosen from the set $\{1, 2, 3\}$.

You are provided with $m$ constraints. The constraints are numbered $1$ to $m$ in the order they are given in the input. The $k$-th constraint is defined by a pair of distinct indices $(u_k, v_k)$.

For a chosen sequence to be valid, it must satisfy the following algebraic property. Consider a system of $m$ linear equations in $m$ real variables $z_1, z_2, \dots, z_m$. For each $k$ from $1$ to $m$, the $k$-th equation in the system is defined as:
$$ z_k \cdot \int_{c_{u_k}}^{c_{v_k}} (21 - 10t) \, dt + \sum_{j=1}^{k-1} z_j = 1 $$
*(Note: For $k=1$, the sum $\sum_{j=1}^{k-1} z_j$ is empty and evaluates to $0$.)*

For the sequence $c_1, c_2, \dots, c_n$ to be valid, this system of $m$ linear equations must have **exactly one unique solution** for $(z_1, z_2, \dots, z_m)$.

If there are multiple valid sequences that satisfy this condition, you must determine the one that is lexicographically smallest. A sequence $A$ is lexicographically smaller than sequence $B$ if at the first index where they differ, sequence $A$ has a smaller value than sequence $B$.
If no sequence can satisfy the condition, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$) — the length of the sequence and the number of constraints.
Each of the following $m$ lines contains two distinct integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$) — indicating a constraint between the elements at index $u$ and index $v$.

## Output
If no valid sequence exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), representing the lexicographically smallest valid sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The local geometric condition (collinearity with the origin) was easily reduced to `c_u != c_v` by models, which then precomputed the allowed pairs or directly invoked a 3-coloring solver. By replacing it with a global algebraic property (uniqueness of solutions to a lower-triangular system), models are forced to analytically deduce that the system's determinant depends solely on its diagonal elements, and that the integral evaluating to zero is equivalent to equality of the sequence elements. This prevents script-based precomputation shortcuts.
</RATIONALE>
<PRESERVED_ANSWER>
The system is lower-triangular, so it has a unique solution if and only if all diagonal coefficients are non-zero; the $k$-th diagonal coefficient is an integral that evaluates to $F(c_{v_k}) - F(c_{u_k})$ for $F(t) = 21t - 5t^2$, which is injective on $\{1, 2, 3\}$, meaning the coefficient is non-zero if and only if $c_{u_k} \neq c_{v_k}$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The condition simplifies exactly to $c_{u_k} \neq c_{v_k}$ for all pairs $(u_k, v_k)$, preserving the core problem as finding the lexicographically smallest valid 3-coloring of a graph, which remains NP-complete.
</PRESERVED_CLASS>
