# Problem A — Sensor Network Telemetry

Time limit: 2 s   Memory limit: 256 MB

A research team is deploying a network of telemetry sensors. The central receivers require each sensor to be configured with a transmission shift. There are exactly three permitted shifts, denoted by the integers 1, 2, and 3.

Certain pairs of sensors are placed too close to each other. If both sensors in such a pair are configured with the identical transmission shift, their signals will overlap and corrupt the data. You will receive a comprehensive log of these overlapping pairs. You must assign a transmission shift to every sensor so that no two overlapping sensors share the same shift. If there is no way to assign the shifts safely, you must report this.

## Input
The first line contains two integers $n$ and $m$. The number of sensors $n$ is at least 1; its maximum value is dictated by the transport drone's payload capacity, which can carry exactly 40 sensors. The number of overlap conditions $m$ starts from 0 and cannot exceed the maximum number of unique pairs that can be formed from the $n$ sensors. The sensors are identified by integers from 1 to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ — denoting that sensor $u$ and sensor $v$ overlap and must not be assigned the same shift.

## Output
If no safe shift assignment is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), with $c_i$ representing the shift assigned to sensor $i$. Among all safe shift assignments, output the lexicographically smallest sequence (compare $c_1$ first, then $c_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
