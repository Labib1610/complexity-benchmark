# Problem A — Resonant Foundation

Time limit: 2 s   Memory limit: 256 MB

You are planning the foundation for a large structure, consisting of $n$ load-bearing pillars. For each pillar $i$, you must select a structural density rating $c_i$ from the options $\{1, 2, 3\}$.

To provide lateral stability, specific pairs of pillars are linked by rigid horizontal beams. A known engineering flaw is that if two linked pillars are constructed with identical density ratings, vibrations will resonate between them and cause structural failure. Therefore, a horizontal beam must never connect two pillars that share the exact same density rating.

You are given the layout of all horizontal beams. Determine a valid sequence of density ratings $c_1, c_2, \dots, c_n$ for the pillars. If multiple valid sequences exist, you must provide the one that is lexicographically smallest (comparing the rating for pillar 1 first, then pillar 2, and so on). If it is impossible to assign ratings without causing resonance, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$) — the number of pillars and the number of horizontal beams. The pillars are numbered from 1 to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ — indicating that a horizontal beam connects pillar $u$ and pillar $v$.

## Output
If no safe assignment of density ratings exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), representing the density rating assigned to each pillar. If there is more than one valid sequence, output the lexicographically smallest one.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
