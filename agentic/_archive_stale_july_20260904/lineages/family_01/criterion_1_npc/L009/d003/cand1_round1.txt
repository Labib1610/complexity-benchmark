# Problem A — Sensor Network Telemetry

Time limit: 2 s   Memory limit: 256 MB

A research team is configuring a network of telemetry sensors. Each sensor $i$ must be tuned to a frequency band $c_i$. The available bands are labeled 1, 2, and 3.

Certain pairs of sensors are in close enough physical proximity that their signals merge. If two interacting sensors are tuned to the exact same frequency band, their signals will overlap and cause severe data loss. To prevent this, the absolute difference between the band labels of any interacting pair must be strictly positive. You are provided with a complete inventory of these interacting pairs.

Your task is to determine a sequence of band assignments $c_1, c_2, \dots, c_n$ that avoids data loss. If no safe configuration is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$. The network size $n$ ranges from a minimum of a single sensor up to the central hub's maximum physical capacity of 40 sensors. The interaction count $m$ ranges from a completely isolated network of zero pairs up to a fully saturated network where every sensor interacts with every other sensor. The sensors are numbered from 1 to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$, indicating that sensor $u$ and sensor $v$ interact with each other.

## Output
If no valid sequence of band assignments exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), with $c_i$ representing the frequency band assigned to sensor $i$. If multiple valid sequences exist, output the one that is lexicographically smallest (comparing $c_1$ first, then $c_2$, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
