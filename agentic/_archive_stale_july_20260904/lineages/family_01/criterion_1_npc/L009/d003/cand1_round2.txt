# Problem A — Sensor Network Telemetry

Time limit: 2 s
Memory limit: 256 MB

A research team is deploying a telemetry network consisting of $n$ sensors. To ensure proper operation, each sensor $i$ must be allocated a transmission band $c_i$. The available bands are 1, 2, and 3.

Because the sensors are clustered in physical space, some pairs of sensors will interfere with one another. When two interfering sensors use the identical transmission band, their signals overlap and the data is corrupted. You are given a complete inventory of which sensor pairs interfere.

Your objective is to find an assignment of transmission bands $c_1, c_2, \dots, c_n$ for all sensors, ensuring that any two sensors that interfere are allocated distinct bands. If no such assignment avoids data corruption, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$. The integer $n$ is the number of sensors, constrained by a minimum of 1 and a hardware limit of 40. The integer $m$ is the number of interfering pairs, starting at a minimum of 0 and reaching up to a maximum of $n \cdot (n-1)/2$. The sensors are numbered from 1 to $n$.
Each of the following $m$ lines contains two integers $u$ and $v$ — denoting that sensor $u$ and sensor $v$ interfere with each other.

## Output
If no safe assignment avoids corruption, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), with $c_i$ being the transmission band allocated to sensor $i$. Among all such valid assignments, output the lexicographically smallest sequence (compare $c_1$ first, then $c_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
