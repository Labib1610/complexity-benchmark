# Problem A — Network Configuration

Time limit: 2 s   Memory limit: 256 MB

You are configuring a network of $n$ modules, numbered $1$ to $n$. Due to hardware limitations, the network supports a maximum of forty modules, and must contain at least one. Each module $i$ must be assigned an operating frequency $c_i$ chosen from the set $\{1, 2, 3\}$.

There are $m$ synchronization links between modules. The number of links $m$ can be anything from zero up to the maximum possible number of distinct pairs of modules. Each link is defined by a pair of distinct module indices $(u, v)$. For the network to be stable, every given pair must satisfy a specific algebraic property regarding their assigned frequencies. 

Specifically, for each link $(u, v)$, the cubic polynomial in $x$:
$$P(x) = x^3 - (c_u + c_v + 4)x^2 + (c_u c_v + 4c_u + 4c_v)x - 4c_u c_v$$
must have exactly three distinct real roots.

If there are multiple valid frequency assignments that satisfy all $m$ link requirements, you must determine the one that is lexicographically smallest. A sequence $A$ is lexicographically smaller than sequence $B$ if at the first index where they differ, sequence $A$ has a smaller value than sequence $B$. 
If no sequence can satisfy all requirements, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ — the number of modules and the number of synchronization links.
Each of the following $m$ lines contains two distinct integers $u$ and $v$, indicating a link between the module at index $u$ and the module at index $v$.

## Output
If no valid sequence exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), representing the lexicographically smallest valid sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
