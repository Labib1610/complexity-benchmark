<METHOD_DESCRIPTION>Replaced the separable quadratic energy function with the condition that $c_u^2 + c_u c_v + c_v^2$ must not be divisible by 3. By Fermat's Little Theorem, this is mathematically identical to $c_u \neq c_v$ for values in $\{1, 2, 3\}$, but it removes the obvious roots of the previous quadratic. This forces models to either algebraically deduce the equivalence or implement the constraint directly into a backtracking search, defeating those that rely on surface pattern matching to trigger a 3-coloring template.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Sequence Properties

Time limit: 2 s
Memory limit: 256 MB

You are tasked with determining the properties of a sequence of $n$ chemical additives. Each additive $i$ in the sequence must be assigned a concentration level $c_i \in \{1, 2, 3\}$.

You are provided with $m$ constraints. Each constraint is defined by a pair of distinct indices $(u, v)$, representing two additives that are reactive when mixed. For the sequence of additives to form a stable compound, every given pair must satisfy a specific compatibility condition regarding their assigned concentration levels. 

The interaction factor between the additive at index $u$ and the additive at index $v$ is calculated using the formula:
$F(u, v) = c_u^2 + c_u c_v + c_v^2$

To prevent destabilization, this interaction factor $F(u, v)$ must not be perfectly divisible by 3. If $F(u, v)$ is a multiple of 3, the pair will destabilize the sequence.

If there are multiple valid sequences of concentration levels that satisfy all $m$ constraints, you must determine the one that is lexicographically smallest. A sequence $A$ is lexicographically smaller than sequence $B$ if, at the first index where they differ, sequence $A$ has a smaller concentration level than sequence $B$.
If no sequence can satisfy all constraints, you must report that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$) — the length of the sequence and the number of constraints.
Each of the following $m$ lines contains two distinct integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$) — indicating a constraint between the additives at index $u$ and index $v$.

## Output
If no valid sequence exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), representing the lexicographically smallest valid sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Replaced the explicitly factorable quadratic formula with an algebraic modulo condition ($c_u^2 + c_u c_v + c_v^2 \not\equiv 0 \pmod 3$). This forces the model to either mathematically prove the condition equates to $c_u \neq c_v$ or implement the rule natively inside a search algorithm, neutralizing the shortcut of mapping quadratic roots directly to a graph coloring template.
</RATIONALE>
<PRESERVED_ANSWER>
For any $c_u, c_v \in \{1, 2, 3\}$, the expression $c_u^2 + c_u c_v + c_v^2$ evaluates to a multiple of 3 if and only if $c_u = c_v$ (yielding 3, 12, or 27), while distinct pairs yield 7, 13, or 19, meaning the required assignment constraints are identically preserved.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly lexicographically-smallest 3-coloring, which is NP-complete, as the underlying constraint graph and allowable assignments are completely unchanged.
</PRESERVED_CLASS>
