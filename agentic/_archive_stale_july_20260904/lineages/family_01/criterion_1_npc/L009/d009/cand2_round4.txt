<METHOD_NAME>Hessian Definiteness Masking</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces a 1D separable quadratic energy function whose minimum value explicitly depends on the difference of parameters with a 2D non-separable quadratic energy landscape. The new condition requires a unique global minimum, which mathematically corresponds to the Hessian matrix being strictly positive definite. For the given function, the Hessian determinant is proportional to (c_u^2 - c_v^2)^2, which evaluates to strictly positive if and only if c_u != c_v. This perfectly preserves the graph coloring constraint while completely hiding it from algebraic pattern matchers.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Sequence Properties

Time limit: 2 s   Memory limit: 256 MB

An experimental sequence of $n$ chemical additives is being designed. Every additive $i$ in this sequence requires a concentration level $c_i$ chosen from the set $\{1, 2, 3\}$.

The mixture is subject to $m$ reactive constraints. Each constraint is specified by two distinct indices $u$ and $v$ indicating that the additives at these positions interact. For the overall compound to remain stable, every interacting pair must satisfy a strict equilibrium condition based on their assigned concentration levels.

Specifically, the interaction between additives $u$ and $v$ generates an energy landscape defined over two continuous reaction variables $x$ and $y$:
$$E(x, y) = \frac{1}{2}(c_u x + c_v y)^2 + \frac{1}{2}(c_v x + c_u y)^2 - x - y$$

A stable equilibrium is only achieved if the global minimum of this energy landscape exists and is located at exactly one unique point $(x, y)$ in the real plane. If the energy function lacks a minimum, or if the minimum energy is achieved at infinitely many points, the interaction will destabilize the entire sequence.

Your task is to assign concentration levels to all $n$ additives such that no constraint destabilizes the sequence. If several valid assignments exist, you must find the lexicographically smallest one. (An assignment $A$ is lexicographically smaller than $B$ if $A$ has a smaller concentration level at the earliest index where they differ.) If no stable assignment is possible, you must determine that it is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$) — the length of the sequence and the number of constraints.
Each of the following $m$ lines contains two distinct integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$) — indicating a constraint between the additives at index $u$ and index $v$.

## Output
If no valid sequence exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), representing the lexicographically smallest valid sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous separable 1D energy function explicitly gave away the `c_u != c_v` condition via its discriminant. This was replaced with a 2D energy landscape whose unique minimum condition depends on the positive definiteness of its Hessian matrix. The determinant of the Hessian is exactly `(c_u^2 - c_v^2)^2`, which is strictly positive if and only if `c_u != c_v` (since all `c` are positive). This perfectly preserves the underlying graph coloring constraint while requiring models to perform genuine multivariate calculus reasoning to discover it.
</RATIONALE>
<PRESERVED_ANSWER>
The condition for a unique global minimum of the 2D energy function evaluates to `c_u != c_v`, which is exactly the same mathematical constraint on the concentration levels as the original 1D energy function.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Lexicographically First 3-Coloring, which is NP-complete, because the underlying constraint graph and allowed colors are unchanged.
</PRESERVED_CLASS>
<RISK>
Models might struggle to correctly evaluate the Hessian positive definiteness and fail to extract the `c_u != c_v` condition, but the mathematical wording is unambiguous and standard for optimization problems.
</RISK>
