# Problem A — System Stabilization

Time limit: 2 s   Memory limit: 256 MB

A distributed diagnostic network consists of $n$ processing modules. Each module must be assigned a load-balancing tier from the set $\{1, 2, 3\}$.

The network contains $m$ bidirectional monitoring links, each connecting a specific pair of modules. For a link connecting module $u$ and module $v$ to remain stable, their assigned tiers $t_u$ and $t_v$ must not produce a resonant frequency. The resonance value $R$ for the link is calculated using the formula:

$$R = (t_u^2 + t_v^2) \bmod (t_u \cdot t_v)$$

If $R = 0$, the link experiences resonance overlap and transmits an error flag. 

To achieve full network stability, every module must be assigned a tier such that no error flags are transmitted across any link.

Determine whether a stable assignment exists. If it does, find the valid assignment of tiers that is lexicographically smallest when listed from module 1 to module $n$.

## Input
The first line provides two integers $n$ and $m$ — the number of modules and the number of monitoring links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, specifying a monitoring link between module $u$ and module $v$.

## Output
If no stable assignment is possible, print a single line containing `NO`.
If a stable assignment exists, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each $s_i \in \{1, 2, 3\}$), representing the tier of each module $i$. If there are multiple stable assignments, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous version used a linear modulo-3 formula and explicitly noted its symmetry, which models immediately recognized as an equality check $c_u = c_v$ and mapped to standard graph 3-coloring. This was replaced with a non-linear integer arithmetic formula `(t_u^2 + t_v^2) mod (t_u * t_v)` that does not overtly resemble a color-conflict check, forcing models to either symbolically deduce or programmatically evaluate that it restricts adjacent nodes to differing values.
</RATIONALE>
<PRESERVED_ANSWER>
For any $t_u, t_v \in \{1, 2, 3\}$, the condition $(t_u^2 + t_v^2) \bmod (t_u \cdot t_v) = 0$ holds if and only if $t_u = t_v$, making the valid tier assignments exactly identical to the original configuration codes.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains identically equivalent to finding the lexicographically smallest valid 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
