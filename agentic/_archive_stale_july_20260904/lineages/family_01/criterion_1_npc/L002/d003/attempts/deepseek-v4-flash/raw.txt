 We need to check if the graph can be colored with 3 colors such that no two adjacent vertices share the same color, and then find the lexicographically smallest coloring.

The determinant condition means the matrix  
\[
\begin{pmatrix}
c_u & c_v \\
c_v & c_u
\end{pmatrix}
\]
has non-zero determinant:  
\[
c_u^2 - c_v^2 \neq 0 \quad \Rightarrow \quad c_u \neq c_v
\]
So it’s exactly a graph coloring problem with 3 colors.

Since \( n \leq 40 \), we can use backtracking with pruning to find the lexicographically smallest valid coloring.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

colors = [0] * n
found = False

def backtrack(idx):
    global found
    if idx == n:
        found = True
        return True
    for c in range(1, 4):
        ok = True
        for nb in adj[idx]:
            if colors[nb] == c:
                ok = False
                break
        if ok:
            colors[idx] = c
            if backtrack(idx + 1):
                return True
            colors[idx] = 0
    return False

if backtrack(0):
    print("YES")
    print(" ".join(map(str, colors)))
else:
    print("NO")
```
