 We need to assign each node a value from {1, 2, 3} such that for every edge (u, v):

\[
(c_u + 2 c_v) \bmod 3 \neq 0
\]
and also the symmetric condition holds (which is automatically true if the first holds for both directions).

Let’s analyze the condition.  
We can map the values {1, 2, 3} to {0, 1, 2} modulo 3 by subtracting 1.  
Let’s define \( x_i = c_i - 1 \), so \( x_i \in \{0, 1, 2\} \).

The condition becomes:

\[
(x_u + 1) + 2(x_v + 1) \equiv 0 \pmod{3}
\]
\[
x_u + 1 + 2x_v + 2 \equiv 0
\]
\[
x_u + 2x_v + 3 \equiv 0
\]
Since 3 ≡ 0 mod 3:
\[
x_u + 2x_v \equiv 0 \pmod{3}
\]

So the forbidden condition is:
\[
x_u \equiv -2x_v \equiv x_v \pmod{3}
\]
because -2 ≡ 1 mod 3.

Thus, the edge is invalid if \( x_u \equiv x_v \pmod{3} \).  
So valid edges require \( x_u \neq x_v \).

That means:  
We need to 3-color the graph such that adjacent nodes have different colors, where colors are 0, 1, 2.

This is exactly the graph 3-coloring problem.  
Since n ≤ 40, we can use backtracking with pruning.

We want the lexicographically smallest assignment in terms of original codes (1, 2, 3).  
Since mapping is \( c_i = x_i + 1 \), lexicographically smallest means smallest x_i first, i.e., try color 0 first, then 1, then 2.

We can do DFS with backtracking, assigning colors in order.

Let’s implement:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def dfs(node):
    if node == n:
        return True
    for c in range(3):
        ok = True
        for nb in adj[node]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[node] = c
            if dfs(node + 1):
                return True
            color[node] = -1
    return False

if dfs(0):
    print("YES")
    print(" ".join(str(c + 1) for c in color))
else:
    print("NO")
```
