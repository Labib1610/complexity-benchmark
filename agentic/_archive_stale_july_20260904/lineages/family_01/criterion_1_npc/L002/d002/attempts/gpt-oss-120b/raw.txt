**Solution Explanation**

For every module we have to choose a code `c ∈ {1,2,3}`.
For an edge `{u,v}` the link is *good* iff  

```
(cu + 2·cv) mod 3 ≠ 0
```

The condition is symmetric, therefore we can treat the edge as an
undirected constraint between the two endpoints.

--------------------------------------------------------------------

#### 1.   Reformulation

Write the codes modulo 3 :

```
1 → 1
2 → 2
3 → 0
```

Now every code is an element of `{0,1,2}`.
For two residues `a , b` the edge is allowed iff  

```
(a + 2·b) mod 3 ≠ 0                (1)
```

Because the condition is symmetric, the same inequality also holds after
swapping `a` and `b`.

All 9 ordered pairs can be checked once; the admissible unordered pairs
are:

```
{0,0}  {0,1}  {0,2}
{1,1}  {1,2}
{2,2}
```

(For example `{0,0}` is allowed because (0+2·0)%3 = 0 → *not* allowed,
so actually {0,0} is forbidden – the list above is the *allowed* ones.
The correct allowed pairs are:)
```
(0,1) (0,2) (1,0) (1,1) (1,2) (2,0) (2,1) (2,2)
```
i.e. the only forbidden unordered pair is `{0,0}` (both ends = 3).

Thus the whole problem is:

*colour the vertices with colours {0,1,2} (meaning 3,1,2) such that
no edge has both ends coloured 0.*

--------------------------------------------------------------------

#### 2.   Observations

* The restriction is very weak – only the pair (0,0) is forbidden.
* The graph size is tiny (`n ≤ 40`).  
  A simple depth‑first search that tries the three colours in the order
  `1,2,3` (i.e. residues `1,2,0`) and checks already coloured neighbours
  is fast enough.
* Because we try colours in increasing order, the first complete
  assignment found is lexicographically minimal.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n,m and the edge list
build adjacency list

col[1…n] = 0   // 0 = not assigned yet, otherwise 1,2,3

def dfs(v):
    if v == n+1:               # all vertices processed
        return True
    for code in (1,2,3):       # try smallest first
        ok = True
        for each neighbour u of v with col[u] != 0:
            if col[u] == 3 and code == 3:   # both residues 0 → forbidden
                ok = False; break
        if ok:
            col[v] = code
            if dfs(v+1): return True
            col[v] = 0          # backtrack
    return False

if dfs(1):
    print "YES" and the array col[1…n]
else:
    print "NO"
```

The only check needed is the forbidden case “both ends are 3”.
All other colour combinations are always allowed.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically
smallest valid assignment iff such an assignment exists.

---

##### Lemma 1  
For any edge `{u,v}` the assignment is valid **iff** it never assigns
both endpoints the value `3`.

**Proof.**  
Using the residue representation, `3` corresponds to `0`.  
From the exhaustive table of (1) the only unordered pair that makes the
left side `0` is `{0,0}`. Translating back, this is exactly the pair
`{3,3}`. ∎



##### Lemma 2  
During the depth‑first search, when a vertex `v` is assigned a colour,
all edges incident to already coloured neighbours satisfy Lemma 1.

**Proof.**  
The algorithm checks every already coloured neighbour `u`.  
If both `col[u]` and the candidate `code` equal `3`, the assignment is
rejected. Otherwise the edge is allowed by Lemma 1. ∎



##### Lemma 3  
If the algorithm reaches `v = n+1`, the whole array `col[1…n]` is a
valid configuration.

**Proof.**  
All vertices are assigned. By Lemma 2 every edge whose both ends have been
assigned (which is every edge) respects Lemma 1, therefore the
configuration is valid. ∎



##### Lemma 4  
If a valid configuration exists, the recursive search will eventually
find one.

**Proof.**  
Consider any valid configuration `C`.  
The recursion tries colours for vertex 1 in the order `1,2,3`.  
Since `C[1]` is one of them, the branch where `col[1]=C[1]` is explored.
Inductively, assume the recursion has followed the prefix
`C[1…v‑1]`. Because `C` is valid, assigning `col[v]=C[v]` does not create
a forbidden edge with any earlier vertex, so the algorithm will not
reject this colour and will continue with the prefix `C[1…v]`.  
Thus the whole configuration `C` is reachable and will be found. ∎



##### Lemma 5  
The first complete assignment found by the algorithm is lexicographically
minimal among all valid assignments.

**Proof.**  
The search processes vertices in increasing order and, for each vertex,
tries colours `1,2,3` in that order.
Therefore the recursion explores the space in lexicographic order:
any assignment `A` is visited before any assignment `B` that is larger
lexicographically.  
Consequently the first visited complete (and by Lemma 3 valid) assignment
is the smallest one. ∎



##### Theorem  
The program outputs  

* `NO` iff no valid configuration exists;  
* otherwise `YES` and the lexicographically smallest valid configuration.

**Proof.**  

*If the program prints `YES`.*  
It reached `v=n+1`, so by Lemma 3 the printed assignment is valid.
By Lemma 5 it is the smallest one.

*If the program prints `NO`.*  
The recursive search exhausted all possibilities without reaching
`v=n+1`. By Lemma 4, if a valid configuration existed it would have been
found, contradiction. Hence no valid configuration exists.

Thus the output is correct in both cases. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

`n ≤ 40`.  
In the worst case the recursion tries at most `3^n` branches, but the
only pruning is the forbidden pair `{3,3}`.
Even the full search is far below the limit (`3^40 ≈ 1.2·10^19`) is
theoretical; in practice the branching factor is close to 3 and the
search finishes instantly for `n = 40` (the constraint is extremely
weak, many assignments are valid, the first one is found quickly).

The work per recursive call is `O(deg(v))` to check neighbours.
Overall time is well under the 2 seconds limit, memory usage is `O(n+m)`.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    col = [0] * n          # 0 = unassigned, otherwise 1,2,3

    def dfs(v: int) -> bool:
        if v == n:
            return True
        for code in (1, 2, 3):          # try smallest first
            ok = True
            if code == 3:               # only need to check when both are 3
                for nb in adj[v]:
                    if col[nb] == 3:
                        ok = False
                        break
            # if code != 3, no forbidden pair can appear
            if ok:
                col[v] = code
                if dfs(v + 1):
                    return True
                col[v] = 0
        return False

    if dfs(0):
        out = ['YES', ' '.join(str(c) for c in col)]
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
