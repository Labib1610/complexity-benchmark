**Solution Explanation**

For every module we have to choose a code `1 … 3`.
A monitoring link `(u , v)` works correctly **iff** the two codes are different,
because the allowed ordered pairs are exactly all pairs with different numbers.
So we have to colour the given undirected graph with three colours,
adjacent vertices must obtain different colours.

`n ≤ 40`, therefore an exponential search with good pruning is easily fast enough.
The required lexicographically smallest assignment is obtained when we

* consider the vertices in the natural order `1,2,…,n`,
* for a vertex try the colours `1,2,3` in this order.

The first complete colouring found by such a depth‑first search is already the
lexicographically smallest one.

--------------------------------------------------------------------

#### 1.   Data structures

* `adj[v]` – list of neighbours of vertex `v` (0‑based indices).
* `col[v]` – current colour of `v` (`0` = not coloured yet, otherwise `1..3`).
* `dom[v]` – bit mask of still possible colours for `v`.  
  bit `0` → colour `1`, bit `1` → colour `2`, bit `2` → colour `3`.  
  Initially `dom[v] = 0b111` for every vertex.

--------------------------------------------------------------------

#### 2.   Forward checking

When we colour a vertex `v` with colour `c`

```
for every still uncoloured neighbour u of v
        if colour c is still possible for u
                delete it from dom[u]
                remember the previous mask of u (to be able to undo)
                if dom[u] becomes empty → contradiction
```

If no contradiction appears we continue recursively.
When the recursive call returns (whether it succeeded or not) we restore all
changed masks – this is the only backtracking work we have to do.

Forward checking removes a colour from a neighbour as soon as it becomes
impossible, therefore many dead branches are cut off early.

--------------------------------------------------------------------

#### 3.   Recursive search

```
dfs():
        find the first vertex v with col[v] == 0
        if none exists → all vertices coloured → success

        for colour c = 1,2,3 (in this order)
                if c is still allowed for v (bit present in dom[v])
                        assign c to v
                        forward‑check neighbours, remember changes
                        if no contradiction and dfs() succeeds → propagate success
                        undo all changes, unassign v
        return failure
```

Because vertices are examined in increasing index order and colours are tried
in increasing order, the first found solution is the lexicographically smallest
one.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically smallest
valid assignment iff such an assignment exists, otherwise prints `NO`.

---

##### Lemma 1  
During the execution of `dfs` the invariant holds:

*For every already coloured vertex `v` and every neighbour `u` that is still
uncoloured, colour `col[v]` is not present in `dom[u]`.*

**Proof.**  
When a vertex `v` receives colour `c`, the algorithm iterates over all uncoloured
neighbours `u` and removes `c` from `dom[u]`. No later step ever adds a colour
to a domain, only removals are performed. Hence the invariant is preserved. ∎



##### Lemma 2  
If the algorithm reaches a recursive call where all vertices are coloured,
the obtained colouring is proper (adjacent vertices have different colours).

**Proof.**  
Assume an edge `(x,y)` with `col[x] = col[y]`. Let the later of the two
assignments be the moment when the second vertex got its colour.
At that moment the first vertex was already coloured, therefore by Lemma&nbsp;1
its colour had been removed from the domain of the second vertex, making the
second colour impossible – contradiction. ∎



##### Lemma 3  
If a partial assignment can be extended to a full proper colouring,
`dfs` never backtracks from that partial assignment because of an empty domain.

**Proof.**  
Consider a vertex `u` whose domain becomes empty while processing a partial
assignment `P`. All colours removed from `dom[u]` belong to neighbours of `u`
that are already coloured in `P`. Any proper extension of `P` must give `u`
a colour different from each of those neighbours, i.e. a colour still present
in `dom[u]`. Since `dom[u]` is empty, no extension exists – contradiction. ∎



##### Lemma 4  
If a proper 3‑colouring exists, `dfs` eventually reaches a leaf where all
vertices are coloured and returns success.

**Proof.**  
Take any proper colouring `C`. Follow the recursion of `dfs`.  
Whenever the algorithm chooses a vertex `v` to colour, `C` assigns some colour
`c = C(v)`. Because `C` is proper, `c` is still allowed for `v` (otherwise a
neighbour already coloured with `c` would exist, contradicting propriety).  
Thus the branch where `dfs` tries colour `c` is never pruned by an empty
domain (Lemma&nbsp;3). Continuing recursively, the algorithm can follow the
choices of `C` all the way down to a leaf where every vertex has the colour of
`C`. Hence success is reached. ∎



##### Lemma 5  
The first complete colouring found by `dfs` is the lexicographically smallest
among all proper colourings.

**Proof.**  
`dfs` processes vertices in the fixed order `1,2,…,n`.  
For a vertex `v` it tries colours `1,2,3` in this order and explores the whole
subtree of a colour before trying the next colour.  
Therefore, for the smallest index where two proper colourings differ,
the algorithm will have tried the smaller colour first and will have explored
all colourings beginning with that prefix before ever trying a larger colour.
Consequently the first full solution encountered is exactly the lexicographically
minimum one. ∎



##### Lemma 6  
If the algorithm prints `NO`, the graph is not 3‑colourable.

**Proof.**  
`NO` is printed only when the initial call of `dfs` returns failure, i.e.
all possible colour choices for the first vertex lead to a dead end.
By Lemma&nbsp;3 a dead end means that the current partial assignment cannot be
extended to a full proper colouring. Hence no proper 3‑colouring exists. ∎



##### Theorem  
The program outputs  

* `YES` and the lexicographically smallest proper 3‑colouring of the given
  graph, **iff** such a colouring exists;
* otherwise it outputs `NO`.

**Proof.**  

*If a proper colouring exists*: by Lemma&nbsp;4 `dfs` succeeds, therefore the
program prints `YES`. By Lemma&nbsp;5 the returned colouring is the
lexicographically smallest one.

*If no proper colouring exists*: by Lemma&nbsp;6 `dfs` fails and the program
prints `NO`.

Both directions hold, completing the proof. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

`n ≤ 40`, `m ≤ n·(n‑1)/2`.

*Each recursive step*  
* scans the adjacency list of the currently coloured vertex – `O(deg(v))`,
* updates at most `deg(v)` domains,
* restores them on backtrack – the same work.

The total work is proportional to the number of visited nodes in the search
tree times the average degree ( ≤ 39 ).  
In the worst case the tree may contain `3^n` nodes, but for `n = 40` the
forward‑checking pruning makes the explored part tiny for all realistic test
data.  
Memory consumption:  

* adjacency lists – `O(n + m)`,
* colour array – `O(n)`,
* domain masks – `O(n)`,
* recursion stack – depth `n`.

All well below the limits (far less than 1 MiB).

#### 6.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    # 0 = uncoloured, 1..3 = colour
    col = [0] * n
    # domain masks, bit 0 -> colour 1, bit 1 -> colour 2, bit 2 -> colour 3
    dom = [0b111] * n

    # depth‑first search with forward checking
    def dfs() -> bool:
        # find first uncoloured vertex (lexicographic order)
        v = -1
        for i in range(n):
            if col[i] == 0:
                v = i
                break
        if v == -1:          # all coloured
            return True

        mask = dom[v]
        for c in (1, 2, 3):
            bit = 1 << (c - 1)
            if not (mask & bit):
                continue

            # assign colour c to v
            col[v] = c
            changed = []          # (vertex, previous_mask)
            conflict = False

            for u in adj[v]:
                if col[u] == 0 and (dom[u] & bit):
                    prev = dom[u]
                    dom[u] &= ~bit
                    changed.append((u, prev))
                    if dom[u] == 0:
                        conflict = True
                        break

            if not conflict:
                if dfs():
                    return True

            # undo changes
            for u, prev in reversed(changed):
                dom[u] = prev
            col[v] = 0

        return False

    if dfs():
        out = ['YES', ' '.join(str(c) for c in col)]
    else:
        out = ['NO']
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms to
the required input‑output format.
