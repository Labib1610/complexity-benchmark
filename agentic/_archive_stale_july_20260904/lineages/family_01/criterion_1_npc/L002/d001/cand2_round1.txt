# Problem A — System Stabilization

Time limit: 2 s   Memory limit: 256 MB

A diagnostic system consists of $n$ processing modules. Each module must be programmed with a state value chosen from $\{1, 2, 3\}$.

The system contains $m$ bidirectional monitoring links, each connecting a specific pair of modules. To achieve system stability, the state values assigned to any two modules connected by a link must form a compatible pair. Specifically, for every link connecting two modules, if their assigned state values are $a$ and $b$, the ordered pair $(a, b)$ must belong to the set of compatible pairs: $\{(1, 2), (1, 3), (2, 1), (2, 3), (3, 1), (3, 2)\}$. A configuration is stable if and only if every monitoring link satisfies this requirement.

Determine whether a stable configuration exists. If it does, find the valid assignment of state values that is lexicographically smallest when listed from module 1 to module $n$.

## Input
The first line provides two integers $n$ and $m$ — the number of modules and the number of monitoring links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$, specifying a monitoring link between module $u$ and module $v$.

## Output
If no stable configuration is possible, print a single line containing `NO`.
If a stable configuration exists, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (each $s_i \in \{1, 2, 3\}$), representing the state value of each module $i$. If there are multiple stable configurations, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

Removed the direct description of states triggering an error if they are identical. Instead, the compatibility relation is explicitly defined using the set of six valid ordered pairs, forcing models to process the constraint extensionally rather than immediately pattern-matching the inequality to graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The set of compatible pairs contains exactly all pairs of values from {1, 2, 3} where the two values are not equal, which is mathematically identical to the original constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a valid 3-coloring of a graph, keeping it NP-complete.
</PRESERVED_CLASS>
