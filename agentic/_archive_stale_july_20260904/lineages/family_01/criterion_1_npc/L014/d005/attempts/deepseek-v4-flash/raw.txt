We can model this as a constraint satisfaction problem.  
The dot products between the three signature vectors are:

- \( V_1 \cdot V_1 = 4 \)  
- \( V_1 \cdot V_2 = 0 \)  
- \( V_1 \cdot V_3 = 0 \)  
- \( V_2 \cdot V_2 = 4 \)  
- \( V_2 \cdot V_3 = 0 \)  
- \( V_3 \cdot V_3 = 4 \)  

So the score is 0 unless the two departments are assigned the same firm, in which case it contributes 4.  
Thus, the total sum is \( 4 \times (\text{number of edges with same firm}) \).  
For the sum to be 0, no edge may connect two departments with the same firm.

So the problem reduces to:  
Can we 3-color the graph such that no edge has the same color on both ends?  
We need the lexicographically smallest such coloring.

Since \( n \leq 40 \), we can use backtracking with pruning.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n  # 0 = unassigned, 1,2,3 = firms
    
    def backtrack(idx):
        if idx == n:
            return True
        # Try colors 1,2,3 in order for lexicographic smallest
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(str(x) for x in color))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
