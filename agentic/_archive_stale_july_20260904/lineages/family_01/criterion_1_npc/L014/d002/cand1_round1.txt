# Problem A — Independent Audits

Time limit: 2 s   Memory limit: 256 MB

You are directing the yearly compliance audit for $n$ corporate divisions. Every division must be allocated to exactly one of three independent auditing agencies, designated by the values 1, 2, and 3.

To avoid conflicts of interest, the audit must respect internal business overlaps. You are given $m$ active joint ventures, each connecting a specific pair of divisions. If two divisions that share a joint venture are evaluated by the same auditing agency, their mutual financial records cannot be adequately verified. Thus, for any joint venture, the two involved divisions must be allocated to entirely different auditing agencies.

Find out whether a valid agency allocation exists for all $n$ divisions under these compliance restrictions. Be aware that the joint ventures may be presented in an adversarial sequence. The evaluation system includes arbitrary, dense, and unsatisfiable configurations of 40 divisions that are specifically constructed to severely penalize and defeat naive exhaustive assignment searches.

## Input
The first line contains two integers $n$ and $m$ — the number of divisions and the total number of joint ventures ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
Each of the following $m$ lines provides two integers $u$ and $v$ — a pair of divisions participating in a joint venture.

## Output
If no valid allocation can be found, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $f_1, f_2, \dots, f_n$ (each chosen from $\{1, 2, 3\}$), where $f_i$ represents the auditing agency allocated to division $i$. If multiple valid allocations exist, you must output the one that is lexicographically smallest (comparing $f_1$ first, then $f_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
