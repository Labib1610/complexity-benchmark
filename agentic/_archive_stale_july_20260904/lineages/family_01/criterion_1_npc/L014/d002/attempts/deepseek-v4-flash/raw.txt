 We can solve this by trying all possible assignments of 3 colors to the nodes and checking if any valid assignment exists. Since n ≤ 40, brute force over 3^n is too large, but we can use backtracking with pruning.

Here’s the approach:
- Represent the graph as an adjacency list.
- Use backtracking to assign colors 1, 2, or 3 to each node in order.
- At each step, ensure the color is different from all already-colored neighbors.
- If we reach the end, we have a valid assignment.
- Since we try colors in increasing order, the first valid assignment found will be lexicographically smallest.

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def dfs(idx):
    if idx == n:
        return True
    for c in range(1, 4):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if dfs(idx + 1):
                return True
            color[idx] = 0
    return False

if dfs(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
