**Solution Explanation**

For every department we have to choose one of three agencies.
For an edge `{u,v}` the contribution to the total sum is the dot product of the
vectors of the chosen agencies.

```
W1 = (2,2,2)      W2 = (-2,2,-2)      W3 = (2,-2,-2)

dot(Wi,Wi) = 12                     (same agency)
dot(Wi,Wj) = -4   for i ≠ j          (different agencies)
```

For `m` edges let  

* `s` – number of edges whose ends have the **same** agency,
* `d = m‑s` – number of edges whose ends have **different** agencies.

The required total is `-4·m`, therefore

```
12·s + (-4)·d = -4·m
12·s -4·(m-s) = -4·m
16·s = 0   →   s = 0
```

So **no edge may connect two vertices with the same agency**.
The problem is exactly the classic *graph 3‑coloring* problem:
assign colors `{1,2,3}` to the vertices such that adjacent vertices have
different colors.

We also have to output the lexicographically smallest coloring
(1‑based vertex order, smallest possible color at the first position,
then second, …).

`n ≤ 40`, therefore a simple backtracking search is fast enough.
We try the vertices in the natural order `1 … n` and for each vertex
try colors `1,2,3` in this order.
Whenever a color conflicts with an already colored neighbour we skip it.
The first complete coloring found by this search is automatically the
lexicographically smallest one.

The algorithm:

```
read graph
color[1…n] = 0
DFS(v):
    if v == n+1:   # all vertices colored
        return True
    for c in 1..3:
        ok = True
        for each neighbour u of v:
            if color[u] == c: ok = False; break
        if ok:
            color[v] = c
            if DFS(v+1): return True
            color[v] = 0
    return False
```

If `DFS(1)` succeeds we output `YES` and the coloring,
otherwise `NO`.

The recursion depth is at most `40`; the work per call is `O(deg(v))`,
so the total running time is well within the limits.

---

**Correctness Proof**

We prove that the algorithm outputs `YES` with the lexicographically
smallest valid assignment iff such an assignment exists.

*Lemma 1*  
During the search, a partial assignment `color[1…v-1]` is always proper:
no edge whose both ends are already colored has equal colors.

*Proof.*  
The algorithm assigns a color to vertex `v` only after checking that none
of its already colored neighbours (all have index `< v`) uses the same
color. Hence after the assignment the invariant holds for all edges
with both ends ≤ `v`. By induction it holds for all visited vertices. ∎



*Lemma 2*  
If the algorithm reaches `v = n+1`, the produced full coloring is a
proper 3‑coloring of the whole graph.

*Proof.*  
By Lemma&nbsp;1 the invariant holds for all vertices `1…n`. Therefore every
edge connects vertices of different colors, i.e. the coloring is proper. ∎



*Lemma 3*  
If a proper 3‑coloring exists, the DFS will eventually find one.

*Proof.*  
Consider any proper coloring `C`. The DFS explores colors for vertex 1
in order `1,2,3`. Since `C(1)` is one of them, the branch where vertex 1
gets color `C(1)` is explored. Inductively, assuming the DFS has followed
the prefix `C(1)…C(v‑1)`, when processing vertex `v` the color `C(v)` is
allowed because all neighbours already colored have colors different from
`C(v)` (the coloring is proper). Hence the branch continues with the
prefix `C(1)…C(v)`. By induction the full coloring `C` is reached. ∎



*Lemma 4*  
The first complete coloring found by the DFS is the lexicographically
smallest among all proper colorings.

*Proof.*  
The DFS processes vertices in increasing index and tries colors
`1,2,3` in that order. It performs a depth‑first search, i.e. it fully
explores the subtree of the smallest possible color before trying a
larger one at the same vertex. Therefore any coloring that differs first
at position `i` with a larger color cannot be visited before the
coloring that uses the smallest feasible color at position `i`. ∎



*Theorem*  
The program outputs  

* `NO` iff the graph is not 3‑colorable;
* otherwise `YES` and the lexicographically smallest proper 3‑coloring.

*Proof.*  

- If the program outputs `YES`, by Lemma&nbsp;2 the returned assignment is a
  proper 3‑coloring, hence satisfies the required sum condition.

- If the program outputs `NO`, the DFS exhausted all possibilities
  without reaching `v=n+1`. By Lemma&nbsp;3 this can happen only if no proper
  3‑coloring exists.

- When a proper coloring exists, Lemma&nbsp;3 guarantees the DFS finds one,
  and Lemma&nbsp;4 guarantees the first found one is lexicographically
  smallest. The program outputs exactly this coloring. ∎



---

**Complexity Analysis**

`n ≤ 40`. In the worst case the backtracking explores all `3^n` assignments,
but typical graphs prune heavily; the theoretical upper bound is
`O(3^n)`. With `n=40` this is far below the time limit in practice
(the search stops as soon as a solution is found, and many branches are
cut early by adjacency constraints).  
Memory usage is `O(n + m)` for the adjacency lists and the color array,
well under 256 MB.

**Reference Implementation (Python 3)**

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    color = [0] * (n + 1)
    sys.setrecursionlimit(10000)

    def dfs(v: int) -> bool:
        if v == n + 1:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[v]:
                if nb < v and color[nb] == c:
                    ok = False
                    break
            if ok:
                color[v] = c
                if dfs(v + 1):
                    return True
                color[v] = 0
        return False

    if dfs(1):
        out = ['YES', ' '.join(str(color[i]) for i in range(1, n + 1))]
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```
