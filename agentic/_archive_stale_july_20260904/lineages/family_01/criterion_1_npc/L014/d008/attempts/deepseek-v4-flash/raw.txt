We can simplify the problem by analyzing the collaborative load formula.

For an edge \((u, v)\):

\[
f_u^2 + f_v^2 + 2(f_u - f_v)^4 - 10(f_u - f_v)^2 + 8
\]

The baseline risk for department \(i\) is:

\[
f_i^2 \times \deg(i)
\]

Total system risk = sum over all vertices of \(f_i^2 \cdot \deg(i)\).

Total collaborative load = sum over all edges of the above expression.

We need:

\[
\sum_{\text{edges}} \left[ f_u^2 + f_v^2 + 2(f_u - f_v)^4 - 10(f_u - f_v)^2 + 8 \right] = \sum_{i} f_i^2 \deg(i)
\]

Notice that \(\sum_{\text{edges}} (f_u^2 + f_v^2) = \sum_i f_i^2 \deg(i)\).  
So the equation reduces to:

\[
\sum_{\text{edges}} \left[ 2(f_u - f_v)^4 - 10(f_u - f_v)^2 + 8 \right] = 0
\]

Let \(d = f_u - f_v\). Possible values:  
- If \(f_u = f_v\), \(d=0\) → contribution = \(8\)  
- If \(|d|=1\), \(d^2=1, d^4=1\) → contribution = \(2 - 10 + 8 = 0\)  
- If \(|d|=2\), \(d^2=4, d^4=16\) → contribution = \(32 - 40 + 8 = 0\)

So the only nonzero contribution is when \(f_u = f_v\), giving \(+8\) per such edge.

Thus the condition becomes:

\[
8 \times (\text{number of edges with same label on both ends}) = 0
\]

So **no edge may have both endpoints with the same agency label**.

Thus the problem reduces to:  
Can we 3-color the graph (with labels 1,2,3) such that adjacent vertices have different labels?  
If yes, output the lexicographically smallest such coloring.

Since \(n \le 40\), we can do backtracking with pruning.

---

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in range(1, 4):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
