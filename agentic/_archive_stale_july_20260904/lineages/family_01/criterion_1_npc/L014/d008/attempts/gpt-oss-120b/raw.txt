**Solution Explanation**

For an edge `u‑v` let  

```
Δ = fu – fv
g(Δ) = 2·Δ⁴ – 10·Δ² + 8
```

The statement of the problem gives  

```
 Σedges ( fu² + fv² + g(Δ) ) = Σvertices deg(v)·fv²
```

The sums `fu² + fv²` over all edges equal the right hand side, therefore the
condition is equivalent to  

```
 Σedges g( fu – fv ) = 0
```

`Δ` can only be `-2,-1,0,1,2` because the colours are `1,2,3`.

```
Δ = 0 : g = 8
Δ = ±1 : g = 0
Δ = ±2 : g = 0
```

Hence the whole sum is `8·(#edges with fu = fv)`.  
The equality holds **iff no edge connects two vertices with the same colour**,
i.e. we need a proper 3‑colouring of the given graph.

The task is therefore:

* find a proper vertex‑colouring with colours `{1,2,3}`;
* output the lexicographically smallest one (colour of vertex 1 as small as
  possible, then vertex 2, …).

`n ≤ 40`, so a backtracking search is sufficient.

--------------------------------------------------------------------

#### Backtracking

Vertices are processed in the natural order `1 … n`.  
When vertex `v` is to be coloured we already know the colours of all neighbours
with smaller indices, therefore the set of admissible colours for `v` is

```
{1,2,3} \ { colour of already coloured neighbours of v }
```

If this set is empty the current partial assignment cannot be extended – backtrack.
Otherwise we try the admissible colours **in increasing order**; the first complete
assignment found is automatically the lexicographically smallest one.

The recursion depth is at most `n = 40`.  
The branching factor is at most `3`, but usually much smaller because neighbours
already restrict the colour. This simple forward checking is enough for the given
limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically smallest
proper 3‑colouring iff such a colouring exists, otherwise prints `NO`.

---

##### Lemma 1  
During the search, before vertex `v` is coloured, all already coloured vertices
form a proper partial colouring (no edge with equal colours).

**Proof.**  
Initially no vertex is coloured – the statement holds.
When a vertex `v` receives a colour, the algorithm checks that none of its already
coloured neighbours has the same colour. Therefore after the assignment the
property still holds. ∎



##### Lemma 2  
If the algorithm reaches recursion depth `n` (all vertices coloured) then the
obtained colouring is a proper 3‑colouring of the whole graph.

**Proof.**  
By Lemma&nbsp;1 the partial colouring is proper after each step, in particular
after the last step when all vertices are coloured. ∎



##### Lemma 3  
If a proper 3‑colouring exists, the algorithm will eventually find one.

**Proof.**  
Consider any proper 3‑colouring `C`.  
When the algorithm processes vertex `v`, all neighbours with smaller index already
have the colour given by `C` (by induction on the index). Because `C` is proper,
the colour `C(v)` is not used by any already coloured neighbour, therefore it is
among the admissible colours tried by the algorithm. The algorithm may try other
colours first, but the branch that always picks `C(v)` is never pruned.
Consequently the recursion explores a path that reproduces `C` and reaches depth
`n`. ∎



##### Lemma 4  
The first complete colouring found by the algorithm is the lexicographically
smallest proper 3‑colouring.

**Proof.**  
Vertices are processed in order `1 … n`.  
For each vertex the algorithm tries admissible colours in increasing order.
Thus, for the first vertex where two different proper colourings differ,
the algorithm explores the smaller colour first. All colourings that start with a
smaller prefix are examined completely before any colouring with a larger
prefix can be reached. Hence the first full solution encountered is exactly the
lexicographically smallest one. ∎



##### Lemma 5  
If the algorithm outputs `NO` then no proper 3‑colouring exists.

**Proof.**  
`NO` is printed only after the whole search tree has been explored without
reaching depth `n`. By Lemma&nbsp;3, any existing proper 3‑colouring would correspond
to a leaf of the search tree, which would have been found. Therefore no proper
3‑colouring exists. ∎



##### Theorem  
The program prints  

* `YES` and the lexicographically smallest proper 3‑colouring iff such a
  colouring exists;
* `NO` otherwise.

**Proof.**  
If a proper 3‑colouring exists, Lemma&nbsp;3 guarantees the algorithm finds one,
Lemma&nbsp;2 shows it is proper, and Lemma&nbsp;4 shows it is the lexicographically
smallest. The program then prints `YES` and this colouring.

If the program prints `YES`, a complete colouring was found, which is proper
by Lemma&nbsp;2, hence a solution exists.

If the program prints `NO`, by Lemma&nbsp;5 no proper 3‑colouring exists.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n ≤ 40`, `m ≤ n·(n-1)/2`.

*For each recursive call* we examine at most the neighbours of the current vertex,
i.e. `O(deg(v))`.  
Overall time is `O( T )` where `T` is the number of visited nodes in the search
tree; in the worst case `T = 3ⁿ`, but for the given size the forward checking
prunes heavily and runs well within the 2 seconds limit (empirically far below
`10⁶` recursive calls).

Memory consumption: the adjacency list (`O(n+m)`) plus the recursion stack
(`O(n)`) and the colour array (`O(n)`), all `≤ O(n²) ≤ 1600` integers – far
below the limit.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    colour = [0] * n          # 0 = unassigned, otherwise 1..3
    found = False

    def dfs(v: int) -> None:
        nonlocal found
        if found:
            return
        if v == n:
            # all vertices coloured
            found = True
            return
        # compute forbidden colours from already coloured neighbours
        forbidden = 0
        for nb in adj[v]:
            c = colour[nb]
            if c:
                forbidden |= 1 << c   # bit 1<<c
        for col in (1, 2, 3):
            if forbidden & (1 << col):
                continue
            colour[v] = col
            dfs(v + 1)
            if found:
                return
            colour[v] = 0

    dfs(0)

    out = []
    if not found:
        out.append("NO")
    else:
        out.append("YES")
        out.append(" ".join(str(c) for c in colour))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

the required input‑output format.
