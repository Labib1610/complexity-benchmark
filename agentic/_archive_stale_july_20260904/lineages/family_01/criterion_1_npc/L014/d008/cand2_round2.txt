# Problem A — Independent Audits

Time limit: 2 s   Memory limit: 256 MB

You are managing the annual compliance audit for a corporation with $n$ departments. The company requires each department to be audited by exactly one of three external agencies, labeled 1, 2, and 3.

Because departments collaborate, there are $m$ joint ventures between specific pairs of departments. The audit must be structured to meet a strict regulatory metric across these collaborations.

For every joint venture between two departments $u$ and $v$ (which are assigned agencies $f_u$ and $f_v$, respectively), an "interaction value" is computed using the following expression:
$$ 10(f_u^2 + f_v^2) - 11 f_u f_v $$

An assignment of agencies to all $n$ departments is legally compliant if and only if the total sum of the remainders, when each interaction value is divided by 3, equals exactly $m$.

The corporate network can be highly interconnected, and the list of joint ventures is provided in no particular order. You must determine whether a compliant assignment exists.

## Input
The first line provides $n$ and $m$ — the number of departments and joint ventures, respectively ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$, representing a joint venture between department $u$ and department $v$. Departments are indexed from 1 to $n$.

## Output
If there is no way to assign agencies to satisfy the compliance metric, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $f_1, f_2, \dots, f_n$ (where $f_i \in \{1, 2, 3\}$ is the agency for department $i$). If multiple valid assignments exist, you must provide the one that is lexicographically smallest (comparing the agency of department 1 first, then department 2, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

Modulo-Obfuscated Metric
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaced the extremal degree-4 polynomial sum with a modulo-3 remainder sum of a quadratic form $10(f_u^2 + f_v^2) - 11f_u f_v$. Modulo 3, this expression is equivalent to $(f_u - f_v)^2$, which evaluates to 1 for unequal assignments and 0 for equal ones. Requiring the sum of remainders to equal exactly $m$ perfectly enforces the 3-coloring constraint (all edges must have remainder 1) without triggering heuristic recognizers that look for negative extremal bounds or perfect squares.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<RATIONALE>
The seed problem used a degree-4 polynomial that evaluated to $-4$ for unequal agencies and $4$ for equal agencies, coupled with a target sum of $-4m$. Models recognized this extremal boundary and immediately reduced it to standard 3-coloring. By changing the mathematical condition to a modulo-3 remainder of a seemingly arbitrary quadratic form, the problem retains the exact same truth table (forcing $f_u \neq f_v$) but completely hides the underlying 3-coloring constraint from pattern-matching heuristics.
</RATIONALE>
<PRESERVED_ANSWER>
The expression $10(f_u^2 + f_v^2) - 11 f_u f_v$ is strictly positive and its remainder modulo 3 is exactly 0 when $f_u = f_v$ and 1 when $f_u \neq f_v$; thus, the sum of $m$ remainders equals $m$ if and only if every joint venture is assigned different agencies, preserving all exact valid assignments and the lexicographical tie-breaker.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
