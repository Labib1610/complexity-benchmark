We need to analyze the game first.  

The game is a two-pile Nim where the piles are the firm numbers (1, 2, or 3).  
The first player wins if and only if the XOR of the two pile sizes is non-zero.  

So for each edge (u, v), we need:  
`f[u] XOR f[v] != 0`  
That means `f[u] != f[v]`.  

So the problem reduces to:  
Can we 3-color the graph such that no two adjacent vertices have the same color?  
We need the lexicographically smallest such coloring.

Since n ≤ 40, we can use backtracking with pruning.  
We try colors 1, 2, 3 in order for each vertex, checking adjacency constraints.

Let’s implement that.  

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
