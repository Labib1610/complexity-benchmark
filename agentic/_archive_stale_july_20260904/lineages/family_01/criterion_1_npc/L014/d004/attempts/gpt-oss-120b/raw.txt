**Solution Explanation**

For a joint venture between departments `u , v` the game starts with two piles
containing `c[u]` and `c[v]` tokens (the numbers of the assigned firms).
In one move a player may remove any positive number of tokens from **exactly one**
pile.  
The game is the ordinary impartial game *Nim* with two heaps, therefore its
Grundy value is `c[u] xor c[v]`.  
The first player has a winning strategy **iff** this value is non‑zero, i.e.

```
c[u] xor c[v] != 0   ⇔   c[u] != c[v]
```

Hence a joint venture is compliant exactly when the two incident departments
receive **different** firms.  
All `m` ventures must be compliant simultaneously → we have to colour the
graph with three colours `1,2,3` such that adjacent vertices have different
colours.

The task is therefore:

*find a proper 3‑colouring of the given graph, and among all of them output the
lexicographically smallest one (colour of vertex 1 first, then 2, …).*

`n ≤ 40`, so a depth‑first search with backtracking is fast enough.
We colour the vertices **in the natural order 1 … n** and try the colours
`1,2,3` in this order – the first complete colouring found is automatically
lexicographically minimal.

During the search we keep for every vertex the set of already coloured
neighbours; a colour is admissible iff it differs from all those neighbours.
If a vertex has no admissible colour we backtrack immediately.

The algorithm is exponential in the worst case (3‑colourability is NP‑hard)
but with `n ≤ 40` it easily fits into the limits.

---

#### Algorithm
```
read n, m
build adjacency list adj[1…n]

col[1…n] = 0                     # 0 = uncoloured

def dfs(v):
    if v == n+1:                 # all vertices coloured
        return True
    for colour in (1,2,3):       # try colours in increasing order
        ok = True
        for to in adj[v]:
            if col[to] == colour:
                ok = False
                break
        if not ok: continue
        col[v] = colour
        if dfs(v+1):
            return True
        col[v] = 0                # undo
    return False                  # no colour works for this vertex

if dfs(1):
    print "YES"
    print colours col[1] … col[n]
else:
    print "NO"
```

---

#### Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
proper 3‑colouring iff such a colouring exists, otherwise prints `NO`.

---

##### Lemma 1  
During the execution of `dfs(v)` the array `col[1…v‑1]` is a proper colouring
of the induced subgraph on vertices `{1,…,v‑1}`.

**Proof.**  
Initially `v=1` and the statement is vacuously true.  
When `dfs` assigns a colour to vertex `v` it checks all already coloured
neighbours (`to < v`) and rejects a colour equal to any of them.
Thus after the assignment the property holds for `{1,…,v}`.
When backtracking the colour of `v` is reset to `0`, restoring the property
for `{1,…,v‑1}`. ∎



##### Lemma 2  
If `dfs(v)` returns `True`, then `col[1…n]` is a proper 3‑colouring of the whole
graph.

**Proof.**  
`True` is returned only when the recursive call reaches `v = n+1`,
i.e. all vertices have been assigned a colour.
By Lemma&nbsp;1 the partial colouring is proper after each assignment,
hence after the last assignment the whole colouring is proper. ∎



##### Lemma 3  
If a proper 3‑colouring exists, `dfs(1)` returns `True`.

**Proof.**  
Consider any proper colouring `C`.  
We show by induction on `v` that the search can follow `C`:
Assume vertices `1…v‑1` have already been coloured exactly as in `C`
(the induction hypothesis).  
When processing vertex `v`, colour `C(v)` is admissible because all neighbours
already coloured (they are among `1…v‑1`) have different colours in `C`.
The algorithm tries colours in order `1,2,3`; when it reaches `C(v)` it will
accept it and recurse to `v+1`.  
Thus the recursion can continue matching `C` up to `n`, reaching the success
state. ∎



##### Lemma 4  
If `dfs(1)` returns `True`, the produced colouring is the lexicographically
smallest proper 3‑colouring.

**Proof.**  
The search processes vertices in increasing order and, for each vertex,
tries colours `1,2,3` in that order.
The first colour that leads to a complete solution is kept, and the algorithm
does not explore any larger colour for that vertex afterwards.
Therefore any other proper colouring differs first at some vertex `k` where it
uses a larger colour than the one chosen by the algorithm.
Consequently the found colouring is lexicographically minimal. ∎



##### Lemma 5  
If no proper 3‑colouring exists, `dfs(1)` returns `False`.

**Proof.**  
Assume the contrary: `dfs(1)` would return `True` without a proper colouring.
By Lemma&nbsp;2 a proper colouring would then be produced – contradiction.
Hence it must return `False`. ∎



##### Theorem  
The program outputs  

* `YES` and the lexicographically smallest proper 3‑colouring  
  **iff** such a colouring exists;
* otherwise it outputs `NO`.

**Proof.**  
If a proper colouring exists, Lemma&nbsp;3 guarantees `dfs(1)` returns `True`,
Lemma&nbsp;2 gives a proper colouring, and Lemma&nbsp;4 shows it is the
lexicographically smallest – the program prints `YES` and that colouring.  

If no proper colouring exists, Lemma&nbsp;5 gives `dfs(1)` returns `False`,
so the program prints `NO`. ∎



---

#### Complexity Analysis  

`n ≤ 40`.  
In the worst case the recursion explores all `3^n` colourings, but the
pruning (rejecting a colour as soon as a neighbour already has it) cuts the
search dramatically.  
The work per recursive call is `O(deg(v))` to test neighbours, overall bounded
by `O(m·3^n)` in the worst theoretical case, which is acceptable for `n=40`
in practice.  
Memory consumption is `O(n + m)` for the adjacency lists and the colour array.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [0] * (n + 1)

    def dfs(v: int) -> bool:
        if v == n + 1:
            return True
        for c in (1, 2, 3):
            ok = True
            for to in adj[v]:
                if col[to] == c:
                    ok = False
                    break
            if not ok:
                continue
            col[v] = c
            if dfs(v + 1):
                return True
            col[v] = 0
        return False

    if dfs(1):
        out = ['YES', ' '.join(str(col[i]) for i in range(1, n + 1))]
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```
