<STATEMENT>
# Problem A — Independent Audits

Time limit: 2 s   Memory limit: 256 MB

You are coordinating the annual compliance review for $n$ corporate departments. Each department must be assigned to exactly one of three external auditing firms, which are identified by the integers 1, 2, and 3.

To prevent conflicts of interest, the review must account for internal dependencies. There are $m$ known joint ventures, each involving a distinct pair of departments. If two departments engaged in a joint venture are reviewed in a manner that creates overlapping financial trails, their shared financials cannot be properly cross-examined. 

To formalize this, each auditing firm $k \in \{1, 2, 3\}$ uses a specific audit signature vector, mathematically defined as the 2-dimensional column vector $\begin{pmatrix} 1 \\ k \end{pmatrix}$. For every joint venture, the audit signature vectors of the two participating departments must be linearly independent over the real numbers. 

Be aware that the test suite contains arbitrary, dense compliance networks, and the joint ventures may be presented in an adversarial sequence.

Determine if there is a valid firm assignment for all $n$ departments that satisfies these compliance rules.

## Input
The first line contains two integers $n$ and $m$ — the number of departments and the number of joint ventures. The maximum capacity of the network is such that the maximum possible number of distinct pairs of departments is exactly 780. You may assume $n$ is a positive integer that does not exceed this capacity. The number of joint ventures $m$ is bounded by the number of distinct pairs among the $n$ departments.

Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of departments involved in a joint venture. Departments are numbered 1 through $n$.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise print `YES` on the first line. On the second line print $n$ integers $f_1, f_2, \dots, f_n$ (each in $\{1, 2, 3\}$), where $f_i$ is the auditing firm assigned to department $i$. If multiple valid assignments exist, you must output the one that minimizes the value of the assignment when evaluated as the sum $\sum_{i=1}^{n} f_i \cdot 10^{n - i}$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The perfect-square condition was a well-known proxy for $x \neq y$, allowing models to quickly map the problem to standard 3-coloring. I replaced this with a requirement that the 2D column vectors $(1, f_u)^T$ and $(1, f_v)^T$ be linearly independent, which mathematically evaluates to exactly the same $f_u \neq f_v$ condition but requires reasoning through a matrix determinant or linear combination. I also removed the explicit $N \le 40$ bound, requiring the model to deduce it by solving $N(N-1)/2 = 780$; failing to do so may lead the model to assume $N$ is large and attempt a flawed greedy or 2-SAT approach instead of the necessary exponential backtracking. Finally, minimizing the base-10 polynomial perfectly preserves the lexicographical requirement but acts as an overflow trap for models that blindly implement the formula in C++ without recognizing its structural meaning.
</RATIONALE>
<PRESERVED_ANSWER>
The linear independence of vectors $(1, f_u)^T$ and $(1, f_v)^T$ is mathematically equivalent to $f_u \neq f_v$, ensuring identical valid assignments, and minimizing the base-10 sum is fundamentally identical to selecting the lexicographically smallest sequence.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest valid 3-coloring of a graph, keeping it NP-complete and solvable by the same intended backtracking algorithm.
</PRESERVED_CLASS>
<RISK>
Models or readers might incorrectly assume that the base-10 evaluation sum requires arbitrary-precision arithmetic libraries, though recognizing it as identical to lexicographical array comparison resolves this entirely.
</RISK>
