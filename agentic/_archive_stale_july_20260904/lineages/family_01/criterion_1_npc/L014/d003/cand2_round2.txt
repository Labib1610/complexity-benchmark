# Problem A — Independent Audits

Time limit: 2 s   Memory limit: 256 MB

You are orchestrating the annual compliance oversight for a corporate headquarters. The headquarters has exactly 40 operational suites, which imposes a physical limit on the number of departments $n$. Each department is required to undergo evaluation by exactly one of 3 available oversight agencies, designated by the integers 1, 2, and 3.

Certain pairs of departments share joint ventures. The number of such joint ventures $m$ can be as low as 0 or as high as the theoretical maximum where every department partners with every other distinct department. 

A critical compliance directive dictates that shared financials cannot be audited by the same agency. Thus, for any joint venture between two departments, the absolute difference between their assigned agency integers must be strictly greater than zero. 

Additionally, to satisfy the central compliance board's global reporting requirement, the total sum of the agency integers across all $n$ departments must strictly exceed $n - 1$. (Because every department receives an integer of at least 1, this global condition is naturally fulfilled by any fully assigned arrangement.)

Determine if there exists a valid agency allocation for all $n$ departments that satisfies these compliance directives.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$) — the number of departments and the number of joint ventures.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of departments involved in a joint venture. Departments are numbered 1 through $n$.

## Output
If no valid allocation exists, print a single line `NO`.
Otherwise print `YES` on the first line. On the second line print $n$ integers $f_1, f_2, \dots, f_n$ (each in $\{1, 2, 3\}$), where $f_i$ is the oversight agency assigned to department $i$. Among all valid allocations, output the one that is lexicographically smallest (compare $f_1$ first, then $f_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
