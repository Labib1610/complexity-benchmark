# Problem A — Synthetic Protein Tags

Time limit: 2 s   Memory limit: 256 MB

You are engineering a synthetic protein structure composed of $n$ distinct modules. To ensure correct behavior, each module must be functionalized with exactly one of three available isotope markers, labeled by the integers 1, 2, and 3.

When the protein folds, specific pairs of modules are brought into close proximity. You are provided with a record of $m$ such proximity linkages. If any two modules involved in a linkage carry the exact same isotope marker, they will interact destructively and cause the entire structure to misfold. Consequently, the two modules in any proximity linkage must always receive strictly different markers.

Your task is to determine whether it is possible to assign a marker to each of the $n$ modules in a way that avoids any destructive interactions.

*Performance Note:* The evaluation data includes adversarially numbered 40-module linkage layouts. These include sparse valid configurations and minimally unsatisfiable networks, specifically designed so that naive step-by-step assignment attempts in fixed numerical order will encounter an overwhelming number of dead ends.

## Input
The first line provides two integers $n$ and $m$ — the total number of modules and the number of proximity linkages ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$ — a proximity linkage between module $u$ and module $v$.

## Output
If a safe marker configuration cannot be achieved, output exactly one line containing `NO`.
If a safe configuration is possible, output `YES` on the first line. On the second line, output $n$ integers $t_1, t_2, \dots, t_n$ (each chosen from $\{1, 2, 3\}$), where $t_i$ represents the isotope marker assigned to module $i$. If multiple safe configurations exist, you must output the lexicographically smallest sequence (comparing the marker for module 1 first, then module 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
