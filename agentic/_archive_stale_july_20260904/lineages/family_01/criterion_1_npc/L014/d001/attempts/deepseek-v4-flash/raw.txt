 We need to assign each department one of three firms such that no two connected departments share the same firm.  
This is a graph 3-coloring problem, and since \( n \leq 40 \), we can use backtracking with pruning.

We’ll try colors in order 1, 2, 3 for each node to get the lexicographically smallest solution.

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def backtrack(node):
    if node == n:
        return True
    for c in range(1, 4):
        ok = True
        for nb in adj[node]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[node] = c
            if backtrack(node + 1):
                return True
            color[node] = 0
    return False

if backtrack(0):
    print("YES")
    print(" ".join(str(c) for c in color))
else:
    print("NO")
```
