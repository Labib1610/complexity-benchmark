# Problem A — Network Channel Assignment

Time limit: 2 s   Memory limit: 256 MB

You are configuring a communication network consisting of $n$ nodes and $m$ bidirectional links. Each node must be assigned exactly one channel from the set $\{1, 2, 3\}$.

For each link between node $u$ and node $v$, an interference score is computed based on their assigned channels $c_u$ and $c_v$. The score is defined by the following polynomial:
$$ \text{score}(u, v) = 4(c_u - c_v)^4 - 20(c_u - c_v)^2 + 12 $$

An assignment of channels to all $n$ nodes is valid if and only if the total sum of the interference scores over all $m$ links equals exactly $-4m$.

You are given the network topology. Determine whether a valid channel assignment exists.

## Input
The first line contains two integers $n$ and $m$ — the number of nodes and the number of links, respectively ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$, representing a link between node $u$ and node $v$. Nodes are indexed from 1 to $n$.

## Output
If there is no valid channel assignment, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$ (where $c_i \in \{1, 2, 3\}$ is the channel for node $i$). If multiple valid assignments exist, you must provide the one that is lexicographically smallest (comparing the channel of node 1 first, then node 2, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
