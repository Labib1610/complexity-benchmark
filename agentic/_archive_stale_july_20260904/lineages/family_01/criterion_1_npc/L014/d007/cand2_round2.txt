<STATEMENT>
# Problem A — Regulatory Compliance

Time limit: 2 s   Memory limit: 256 MB

A large corporation consists of $n$ distinct departments. To ensure proper oversight, every department must be assigned to exactly one of three external auditing firms, which are identified by the labels 1, 2, and 3.

Within the corporation, certain pairs of departments share resources, resulting in $m$ active joint ventures. The regulatory board requires that the overall auditing assignment across these joint ventures satisfies a specific mathematical threshold.

Each of the three auditing firms is characterized by a unique 3-dimensional signature vector:
- Firm 1 uses $V_1 = (1, 1, 1)$
- Firm 2 uses $V_2 = (1, -1, 0)$
- Firm 3 uses $V_3 = (1, 1, -2)$

For each joint venture between a department $u$ and a department $v$, we define the "venture score" as the standard dot product of the signature vectors belonging to their assigned firms, $V_{f_u} \cdot V_{f_v}$.

An assignment of the $n$ departments to the three firms is deemed strictly compliant if and only if the sum of the venture scores over all $m$ joint ventures is exactly $0$.

Given the network of joint ventures, your task is to determine if a strictly compliant assignment exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n \cdot (n-1)/2$) — the number of departments and the number of joint ventures.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating a joint venture between department $u$ and department $v$. The joint ventures are given in no particular order, and no pair is listed more than once.

## Output
If a strictly compliant assignment is impossible, print `NO` on a single line.
If it is possible, print `YES` on the first line. On the second line, print $n$ integers $f_1, f_2, \dots, f_n$, where $f_i \in \{1, 2, 3\}$ is the firm assigned to department $i$. If there are multiple compliant assignments, you must output the one that is lexicographically smallest. (An assignment $A$ is lexicographically smaller than $B$ if, at the first department index where they differ, assignment $A$ uses a smaller firm label than $B$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

Changed the signature vectors to a mutually orthogonal set where cross dot products are 0 and self dot products are strictly positive, and updated the target sum to exactly 0. This forces models to actually analyze the interaction matrix to discover that the sum can only be 0 if all edges are heterochromatic, preventing them from blindly pattern-matching the uniform negative sum from the seed problem.
</RATIONALE>

Since every distinct pair of vectors has a dot product of 0 and every identical pair has a positive dot product, a total sum of 0 is achieved if and only if every joint venture connects departments with different firms, making the valid assignments perfectly identical to proper 3-colorings.
</PRESERVED_ANSWER>
