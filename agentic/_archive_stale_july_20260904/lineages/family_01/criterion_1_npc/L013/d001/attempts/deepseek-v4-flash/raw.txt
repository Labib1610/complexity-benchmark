We need to solve a 3-coloring problem on a graph with up to 40 vertices, but we want the lexicographically smallest valid assignment (shift numbers 1, 2, 3).  

A naive backtracking over all assignments would be too slow for worst-case graphs (3^40).  
We can use a backtracking with constraint propagation and symmetry breaking, but still worst-case could be hard.  

However, since n ≤ 40, we can use a **maximum independent set / exact cover** style approach, or more practically, use a **branch and bound with forward checking** and **degree-based variable ordering**.  

Another approach: Since we only have 3 colors, we can use **backtracking with pruning** and choose the vertex with the most constraints first (MRV heuristic). This works well in practice for n=40.  

We also need lexicographically smallest: assign employee 1 first, then 2, etc., so we iterate colors in order 1,2,3 for each vertex.  

Let’s implement:  

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    # Convert to sets for fast conflict checking
    adj_set = [set(lst) for lst in adj]
    
    assignment = [0] * n  # 0 = unassigned, 1,2,3 = colors
    
    # MRV ordering: choose unassigned vertex with most constraints
    def select_unassigned():
        best = -1
        best_deg = -1
        for i in range(n):
            if assignment[i] == 0:
                # degree = number of unassigned neighbors
                deg = sum(1 for v in adj[i] if assignment[v] == 0)
                if deg > best_deg:
                    best_deg = deg
                    best = i
        return best
    
    # Backtracking search
    def backtrack():
        # Find next unassigned vertex
        v = select_unassigned()
        if v == -1:
            return True  # all assigned
        
        # Try colors in order 1,2,3 for lexicographic smallest
        for color in (1,2,3):
            # Check if color is valid
            conflict = False
            for u in adj[v]:
                if assignment[u] == color:
                    conflict = True
                    break
            if conflict:
                continue
            
            assignment[v] = color
            if backtrack():
                return True
            assignment[v] = 0
        
        return False
    
    if backtrack():
        print("YES")
        print(" ".join(str(x) for x in assignment))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
