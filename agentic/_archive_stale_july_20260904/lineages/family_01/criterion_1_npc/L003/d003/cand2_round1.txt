# Problem A — Compound Stabilization

Time limit: 2 s
Memory limit: 256 MB

A laboratory is synthesizing a complex molecule consisting of $n$ reactive functional groups. To prevent the molecule from degrading, each functional group must be stabilized by attaching one of three available chemical buffers, designated as buffer 1, buffer 2, and buffer 3. Every functional group must receive exactly one buffer.

However, spatial interference causes certain pairs of functional groups to destabilize if they are treated with the identical buffer. You are given a list of known interference interactions between distinct functional groups. If two groups interact, they cannot be stabilized using the same buffer.

Your task is to determine whether a stable configuration exists for all $n$ functional groups. If it does, you must identify the configuration that minimizes the overall thermodynamic penalty, modeled as $\sum_{i=1}^n b_i \cdot 4^{n-i}$, where $b_i$ is the buffer type (1, 2, or 3) applied to functional group $i$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$). The number of functional groups $n$ is at least 1 and capped at 40. The number of interference records $m$ ranges from 0 up to the maximum possible number of distinct pairs $n(n-1)/2$.
Each of the following $m$ lines contains two integers $u$ and $v$ — a pair of distinct functional groups that cannot share the same buffer.

## Output
If there is no valid way to stabilize the molecule, output a single line containing `NO`.
If a stable configuration is possible, output `YES` on the first line. On the second line, output $n$ integers $b_1, b_2, \dots, b_n$ ($b_i \in \{1, 2, 3\}$), where $b_i$ is the buffer assigned to functional group $i$. If multiple valid configurations exist, output the sequence $b_1, b_2, \dots, b_n$ that minimizes the value of $\sum_{i=1}^n b_i \cdot 4^{n-i}$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
