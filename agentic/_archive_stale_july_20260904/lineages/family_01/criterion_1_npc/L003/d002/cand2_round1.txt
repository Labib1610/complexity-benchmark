# Problem A — Secure Stream Multiplexing

Time limit: 2 s
Memory limit: 256 MB

A communications array transmits $n$ distinct data streams simultaneously. To secure the transmission, each stream must be encrypted using exactly one of three available cryptographic protocols, designated as Protocol 1, Protocol 2, and Protocol 3. 

Because of structural similarities in the payload, certain pairs of streams exhibit data correlation. If two correlated streams are encrypted using the identical protocol, the transmission becomes vulnerable to differential cryptanalysis. Therefore, to ensure total system security, correlated pairs must always be assigned different protocols.

You will be given the complete list of correlated stream pairs identified by a vulnerability scan. Your task is to determine whether it is possible to assign a protocol to every stream such that no two correlated streams share the same protocol.

If a secure configuration exists, the system automatically selects the one that minimizes computational overhead. Protocol 1 is the most hardware-efficient, while Protocol 3 is the most resource-intensive. Consequently, the system resolves any flexibility by preferring lower protocol numbers for the streams in sequential order. That is, the final configuration—expressed as a sequence of protocol numbers for stream 1 through stream $n$—must be the lexicographically smallest sequence among all valid secure assignments.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the number of data streams and the number of correlated pairs found by the scan.
Each of the following $m$ lines contains two integers $u$ and $v$ — a pair of distinct streams that are correlated and thus cannot be encrypted with the same protocol.

## Output
If there is no way to securely assign the protocols, output a single line containing `NO`.
If a secure assignment is possible, output `YES` on the first line. On the second line, output $n$ integers $p_1, p_2, \dots, p_n$ ($p_i \in \{1, 2, 3\}$), where $p_i$ is the protocol assigned to stream $i$. This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
