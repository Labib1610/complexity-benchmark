# Problem A — Shift Distribution

Time limit: 2 s
Memory limit: 256 MB

A manufacturing facility needs to schedule its workforce. There are $n$ employees, and to maintain continuous operations, the facility operates on three distinct daily shifts, designated as 1, 2, and 3. Each employee must be allocated to exactly one of these three shifts.

Due to past disagreements, certain pairs of distinct employees cannot be scheduled on the same shift. You will receive a log of these historical incompatibilities.

Your task is to establish whether a complete and valid shift schedule can be formed for all $n$ employees. If a valid schedule is possible, you must provide the one that is lexicographically smallest when represented as a sequence of the employees' designated shift numbers (meaning employee 1's shift is as small as possible; in the event of a tie, employee 2's shift is as small as possible, and so forth).

*Note on Evaluation:* The evaluation system includes adversarial incompatibility logs whose valid or invalid status requires testing an overwhelming number of combinations if your solution relies on a rigid sequence of trial-and-error assignments in fixed employee and shift order. Your approach must be optimized to bypass this bottleneck.

## Input
The first line contains two integers $n$ and $m$. The facility provides exactly one safety locker per employee and has a total of 40 lockers installed, which strictly caps the employee count $n$ (which is always at least 1). The value $m$ represents the number of recorded incompatibilities; it can be zero, or it can be as large as the total number of unique pairs formed by the $n$ employees.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ — representing a pair of distinct employees who are incompatible and must be placed on different shifts.

## Output
If a valid schedule is impossible, print `NO` on a single line.
If a valid schedule exists, print `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i$ is 1, 2, or 3), representing the shift assigned to each employee $i$. If multiple valid schedules exist, output the one that forms the lexicographically smallest sequence $s_1, s_2, \dots, s_n$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
