<STATEMENT>
# Problem A — Schedule Allocation

Time limit: 2 s
Memory limit: 256 MB

A manufacturing facility employs $n$ staff members. The workday is divided into three distinct shifts, numbered 1, 2, and 3. Management requires that every staff member be assigned to exactly one of these shifts.

Due to various operational and interpersonal constraints, management maintains a list of conflict records. Each record specifies two staff members who must not be assigned to the same shift. It is possible for a conflict record to list the same staff member twice. In such cases, the rule still applies: the staff member cannot share a shift with themselves, meaning it is impossible to assign them to any shift.

Your task is to determine whether there is a valid way to allocate shifts to all $n$ staff members without violating any conflict records. If a valid allocation exists, you must find the one that is lexicographically smallest when represented as a sequence of shift numbers (meaning the shift number for staff member 1 is minimized first, then staff member 2, and so forth).

## Input
The first line contains two integers $n$ and $m$ — the number of staff members and the number of conflict records ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the staff members involved in a conflict.

## Output
If there is no valid shift allocation, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), representing the shift assigned to staff member $i$. If there are multiple valid sequences, output the lexicographically smallest one.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I explicitly stated that conflict records can list the same staff member twice, and that this renders any valid assignment impossible for that staff member. This removes the affordance of assuming all input records represent edges between distinct vertices, forcing models to explicitly handle self-loops rather than blindly applying standard graph coloring recursion templates that ignore them.
</RATIONALE>
<PRESERVED_ANSWER>
The problem still requires finding the lexicographically smallest valid assignment of 3 states to $n$ entities with inequality constraints, and a self-loop naturally implies impossibility in both versions.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly the lexicographically smallest 3-coloring problem, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models or humans might find the bound $m \le n(n-1)/2$ slightly confusing if self-loops are allowed, as the theoretical maximum number of edges with self-loops is $n(n+1)/2$, but it remains a perfectly valid upper bound on the input size.
</RISK>
