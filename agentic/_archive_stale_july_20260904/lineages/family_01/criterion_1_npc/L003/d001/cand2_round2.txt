# Shift Assignment

Time limit: 2 s
Memory limit: 256 MB

A factory has a workforce of $n$ workers. Over time, friction has developed among the personnel, resulting in a documented list of conflicting worker pairs. The factory organizes its daily operations into three distinct shifts, identified by the numbers 1, 2, and 3. Company policy dictates that every worker must be placed into exactly one of these three shifts. Furthermore, any two workers who are documented as a conflicting pair must be placed in different shifts.

Your objective is to determine if a shift assignment satisfying these constraints is possible. If it is, you must identify the valid assignment that is lexicographically smallest when expressed as a sequence of shift numbers. This means you should prioritize minimizing the shift number assigned to worker 1; in the event of a tie, minimize the shift number for worker 2, and so forth.

## Input
The first line contains two integers $n$ and $m$ — the total number of workers and the number of conflicting pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the following $m$ lines contains two integers $u$ and $v$ — representing a pair of workers who are in conflict.

## Output
If no valid shift assignment can be made, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), indicating the shift assigned to worker $i$. If multiple valid assignments exist, output the one whose sequence $s_1, s_2, \dots, s_n$ is lexicographically smallest.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
