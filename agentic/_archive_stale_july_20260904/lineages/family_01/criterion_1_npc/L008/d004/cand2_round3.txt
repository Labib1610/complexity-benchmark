# Problem A — Phase Configurations

Time limit: 2 s   Memory limit: 256 MB

A high-tech manufacturing plant is preparing $n$ precision-machined modules for final integration into a single mechanism. Before they can be integrated, each module requires exactly one of three available phase configurations, labeled 1, 2, and 3.

Within the mechanism, certain pairs of distinct modules are designed to be in direct physical contact. If any two contacting modules are set to the identical phase configuration, their shared resonance will induce a catastrophic harmonic fusion. This fusion locks the mechanism and renders the entire unit defective. Consequently, no two contacting modules can ever be assigned the same phase configuration.

The plant's automated verification suite intentionally evaluates your logic against adversarial testing layouts on the full 40 modules. These include closely constrained and fundamentally incompatible layouts, engineered specifically to cause fixed-order, configuration-by-configuration trial-and-error approaches to exceed the time limit.

You must determine whether a non-reactive phase assignment exists for the given mechanism. If multiple valid assignments exist, you must select the one that minimizes the structural energy index, defined mathematically as $E = \sum_{i=1}^n s_i \cdot 4^{n-i}$, where $s_i \in \{1, 2, 3\}$ is the phase configuration assigned to module $i$.

## Input
The first line provides two integers $n$ and $m$ — the total number of modules and the number of contact pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two distinct integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), signifying that module $u$ and module $v$ are in direct physical contact. It is guaranteed that no unordered pair of modules $\{u, v\}$ appears more than once in the input.

## Output
If there is no way to configure the modules without inducing harmonic fusion, output a single line containing `NO`.
If a non-reactive assignment is achievable, output `YES` on the first line. On the second line, provide $n$ space-separated integers $s_1 s_2 \dots s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ represents the phase configuration applied to module $i$. If multiple non-reactive assignments exist, you must output the one that minimizes the structural energy index $E$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<PRESERVED_ANSWER>
Minimizing the base-4 polynomial with coefficients in {1, 2, 3} is mathematically identical to finding the lexicographically smallest sequence, so the exact same sequence is output for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-coloring on a simple undirected graph, preserving its NP-complete complexity class.
</PRESERVED_CLASS>
