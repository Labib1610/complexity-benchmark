<STATEMENT>
# Problem A — Sequence Generation Constraints

Time limit: 2 s   Memory limit: 256 MB

You are tasked with generating a sequence of $n$ integers, $S = (s_1, s_2, \dots, s_n)$.
Each element in the sequence must be chosen from the set $\{1, 2, 3\}$.

You are given a set of $m$ constraint pairs. Each constraint pair $(u, v)$ dictates that the sequence elements at indices $u$ and $v$ must not be equal (i.e., $s_u \neq s_v$).

Determine if it is possible to construct a sequence $S$ that satisfies all $m$ constraints.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the length of the sequence and the number of constraint pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a constraint pair requiring $s_u \neq s_v$.

## Output
If no such sequence can be constructed, output a single line containing `NO`.
If a valid sequence exists, output `YES` on the first line. On the second line, output the $n$ integers $s_1 s_2 \dots s_n$ of the sequence, separated by spaces. If there are multiple valid sequences, output the one that is lexicographically smallest (comparing $s_1$ first, then $s_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

The problem has been stripped of its physical manufacturing narrative and reframed as an abstract sequence generation task with index-pair inequality constraints. By removing all domain-specific storytelling and adversarial meta-commentary, the text avoids triggering pattern-matching to graph coloring heuristics, forcing the model to recognize and solve the underlying constraint satisfaction problem entirely on its own mathematical merits.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to assign values 1, 2, or 3 such that specified pairs are unequal is mathematically identical to 3-coloring a graph, meaning all valid assignments (and the lexicographically smallest one) remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem retains the exact structure of deciding if a graph is 3-colorable, which is a well-known NP-complete problem.
</PRESERVED_CLASS>
