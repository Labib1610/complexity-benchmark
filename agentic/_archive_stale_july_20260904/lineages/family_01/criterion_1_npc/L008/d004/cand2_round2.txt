# Problem A — Assembly Tolerances

Time limit: 2 s   Memory limit: 256 MB

A manufacturing facility is preparing to integrate $n$ precision elements into a consolidated mechanism. Each element requires the application of a chemical barrier. There are three distinct barrier types available, referenced by the numerical identifiers 1, 2, and 3. Every element $i$ (from 1 to $n$) must be assigned exactly one barrier type, denoted as $s_i$.

The mechanism's design specifies $m$ physical interfaces, each establishing direct contact between a specific pair of elements. The chemical properties of the barriers dictate that contacting elements must maintain a chemical potential difference. Specifically, to prevent a severe polymer fusion that would cause mechanical failure, the absolute difference between the numerical identifiers of the barrier types assigned to any two elements $u$ and $v$ sharing a physical interface must be strictly greater than zero (i.e., $|s_u - s_v| > 0$).

Your task is to evaluate the provided mechanism design and determine if a valid barrier assignment is possible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the number of elements and the number of physical interfaces, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that element $u$ and element $v$ share a physical interface.

## Output
If it is impossible to assign barrier types to all elements without violating the chemical potential difference requirement, output a single line containing `NO`.
If a valid assignment is possible, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ separated by spaces, where $s_i \in \{1, 2, 3\}$ indicates the barrier type assigned to element $i$. If there are multiple valid assignments, you must output the one that is lexicographically smallest (comparing the barrier type of element 1 first, then element 2, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
