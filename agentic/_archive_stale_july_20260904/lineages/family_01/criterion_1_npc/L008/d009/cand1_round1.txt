# Problem A — Network Synchronization

Time limit: 2 s   Memory limit: 256 MB

A synchronization facility operates a discrete number of precision oscillators. The facility is designed to support up to 40 oscillators in total, numbered sequentially starting from 1. Each oscillator must be assigned a frequency multiplier chosen from the set $\{1, 2, 3\}$.

Certain pairs of oscillators are connected by bidirectional coupling links. The number of such links can range from zero up to the theoretical maximum for a fully interconnected network. When oscillator $u$ and oscillator $v$ are linked, their interaction generates a localized resonance factor defined by the equation:
$R_{u,v} = 7 s_u s_v - 2 s_u^2 - 2 s_v^2$
where $s_u$ and $s_v$ are their assigned multipliers.

The overall stability of the facility depends on the aggregate behavior of these interactions. Specifically, the global network resonance $Z$ is defined as the product of the resonance factors across all active links:
$Z = \prod_{(u,v) \in E} R_{u,v}$
where $E$ is the set of all coupling links. 

The system is considered stable if and only if the global resonance $Z$ is a perfect power of 2 (i.e., $Z = 2^k$ for some non-negative integer $k$). If $Z$ contains any other prime factors, the network undergoes resonance collapse and fails. (If there are no links in the network, $Z$ is defined as 1, which is $2^0$ and therefore stable).

You must determine whether a stable configuration of multipliers exists for the given system.

## Input
The first line provides two integers $n$ and $m$ — the total number of oscillators and the number of coupling links.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), signifying that oscillator $u$ and oscillator $v$ are linked. It is guaranteed that each unordered pair of linked oscillators appears at most once in the input.

## Output
If there is no way to configure the multipliers without inducing resonance collapse, output a single line containing `NO`.
If a stable configuration is achievable, output `YES` on the first line. On the second line, provide $n$ integers $s_1 s_2 \dots s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ represents the multiplier assigned to oscillator $i$. 

If multiple stable configurations exist, you must output the one that minimizes the final system signature $V_n$. This signature is computed sequentially: starting with an initial value $V_0 = 0$, for each oscillator $i$ from $1$ to $n$ in order, the signature updates according to the rule $V_i = 4 \cdot V_{i-1} + s_i$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

I used a technique I call "Global Opaque Entanglement" combined with indirect bounds (S07). The problem's local constraint ($s_u \neq s_v$) has been replaced by a global product condition: the product of $7 s_u s_v - 2 s_u^2 - 2 s_v^2$ over all edges must be a power of 2. For $s \in \{1,2,3\}$, this polynomial evaluates to powers of 2 (1, 4, 16) if and only if $s_u \neq s_v$, and to multiples of 3 (3, 12, 27) if $s_u = s_v$. A model that relies on surface pattern matching will attempt to evaluate this global condition at the leaves of its backtracking search, failing to prune the tree and resulting in a Time Limit Exceeded error on the $3^{40}$ search space. To succeed, the model must mathematically deduce that the global product being a power of 2 implies every local term must be a power of 2, thus extracting the local $s_u \neq s_v$ constraint necessary for pruning.
