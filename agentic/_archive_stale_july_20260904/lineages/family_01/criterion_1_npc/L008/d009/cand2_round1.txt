<METHOD_NAME>Global Polynomial Root Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces a local pairwise inequality constraint with a global constraint requiring the sum of a specific polynomial over all edges to equal zero. The polynomial is carefully chosen to be non-negative on the domain, evaluating to 0 if the variables are unequal and >0 if they are equal. Models that literal-translate will fail to prune their search (TLE) because they won't recognize the terms are non-negative, while models that reason mathematically will deduce it's equivalent to standard 3-coloring. Additionally, the allowed values are presented in descending order to bait literal-translating models into a suboptimal search order.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Quantum Interference Alignment

Time limit: 2 s   Memory limit: 256 MB

A quantum computing array consists of $n$ qubits, numbered $1$ through $n$. To calibrate the array, you must assign each qubit an energy state $s_i$ chosen from the set $\{3, 2, 1\}$.

The array contains $m$ sensitive entanglement links between specific pairs of qubits. When qubit $u$ and qubit $v$ are linked, their energy difference $\Delta_{u,v} = s_u - s_v$ generates an interference scalar $I_{u,v}$, calculated as:
$$I_{u,v} = \Delta_{u,v}^4 - 5\Delta_{u,v}^2 + 4$$

To achieve system stability, the overall quantum array must have zero total interference. This means the sum of the interference scalars across all $m$ links must be exactly $0$. If the sum is strictly non-zero, the entanglement collapses.

You must determine whether a stable configuration of energy states exists for the given array.

## Input
The first line provides two integers $n$ and $m$ — the total number of qubits and the number of entanglement links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), signifying that qubit $u$ and qubit $v$ are linked. It is guaranteed that each unordered pair of linked qubits appears at most once in the input.

## Output
If there is no way to configure the energy states without inducing entanglement collapse, output a single line containing `NO`.
If a stable configuration is achievable, output `YES` on the first line. On the second line, provide $n$ integers $s_1 s_2 \dots s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ represents the energy state assigned to qubit $i$. 

If multiple stable configurations exist, you must output the one that minimizes the final footprint $F_n$. The footprint is computed sequentially: starting with an initial value $F_0 = 0$, for each qubit $i$ from $1$ to $n$ in order, the footprint updates according to the rule $F_i = 4 \cdot F_{i-1} + s_i$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the local pairwise inequality constraint with a global constraint requiring the sum of a specific polynomial over all edges to equal zero. I also presented the allowed state values in descending order `{3, 2, 1}`. This forces the model to mathematically deduce that the polynomial evaluates to exactly 0 for unequal states and >0 for equal ones; literal translations will fail to prune the search space and will TLE, especially if tricked into a descending search order.
</RATIONALE>
<PRESERVED_ANSWER>
The polynomial evaluates to 0 if the states are different and 4 if they are the same; since it is never negative on the allowed domain, a sum of 0 strictly requires every linked pair to have different states, exactly matching the original constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-coloring, which is NP-complete, as the global sum constraint is mathematically isomorphic to requiring all adjacent nodes to have distinct colors.
</PRESERVED_CLASS>
