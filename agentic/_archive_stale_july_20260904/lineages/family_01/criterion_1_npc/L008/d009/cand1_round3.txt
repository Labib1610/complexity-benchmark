<METHOD_DESCRIPTION>Instead of explicitly forbidding adjacent nodes from sharing a value, the problem defines a global condition: the sum of the sizes of the sets of distinct values on each edge must equal 2m. This is mathematically equivalent to the independent set condition, but presented as an aggregate property. This prevents simple pairwise extraction, forcing the model to either fail to prune (causing TLE) or perform the necessary mathematical deduction.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Generator Configuration

Time limit: 2 s   Memory limit: 256 MB

A power facility manages a network consisting of $n$ generators and $m$ cables. Each cable connects a pair of distinct generators.

You must assign a positive integer configuration state $s_i$ to each generator $i$. Due to hardware limitations, the state value cannot exceed 3 (so the available states are 1, 2, and 3).

For each cable connecting generator $u$ and generator $v$, we define the set of distinct active states on that cable as $S_{u,v} = \{s_u, s_v\}$. 
The entire network is considered stable if and only if the sum of the sizes of these sets over all $m$ cables is exactly $2m$.

You must determine whether a stable assignment of states exists for the given network.

## Input
The first line provides two integers $n$ and $m$ — the total number of generators and the number of cables. The facility requires at least one generator and has a maximum physical capacity of 40 generators. The number of cables $m$ can be anything from zero up to the maximum possible number of connections in a simple network of $n$ generators.
Each of the subsequent $m$ lines contains two integers $u$ and $v$, signifying that generator $u$ and generator $v$ are connected. The generators are numbered starting from 1 up to $n$, and a generator cannot be connected to itself. It is guaranteed that each unordered pair of connected generators appears at most once in the input.

## Output
If there is no way to assign the states to achieve network stability, output a single line containing `NO`.
If a stable assignment is achievable, output `YES` on the first line. On the second line, provide $n$ integers $s_1 s_2 \dots s_n$, where $s_i$ represents the state assigned to generator $i$. 

If multiple stable assignments exist, you must output the one that minimizes the final system signature $V_n$. This signature is computed sequentially: starting with an initial value $V_0 = 0$, for each generator $i$ from $1$ to $n$ in order, the signature updates according to the rule $V_i = 4 \cdot V_{i-1} + s_i$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the pairwise inequality constraint into a global aggregate condition: the sum of the sizes of the sets of distinct values on each edge must equal 2m. Removed contrived physics terminology to satisfy the gate, while stating the bounds indirectly as physical capacities (Strategy S07). This forces the model to mathematically deduce that the aggregate sum implies a local pairwise inequality in order to build an efficient pruning algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the sum of the sizes of the sets {s_u, s_v} equals 2m is satisfied if and only if every set has size exactly 2, meaning s_u != s_v for all edges, which perfectly preserves the original valid assignments and tie-breaker.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exact 3-coloring on a general graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret 'set of distinct active states' if they don't realize that standard mathematical sets automatically handle distinctness, though the word 'distinct' was explicitly added to prevent this.
</RISK>
