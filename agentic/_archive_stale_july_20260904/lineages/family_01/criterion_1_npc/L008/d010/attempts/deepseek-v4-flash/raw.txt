 We need to assign each node a value from {1, 2, 3} such that for every edge (u, v), the determinant of the given 3×3 matrix is non-zero.  

Let’s first compute the determinant condition.  

The matrix is:

\[
\begin{pmatrix}
s_u & s_v & s_u^2 + u + v + 10 \\
1 & 1 & s_v \\
s_v & s_u & s_u s_v
\end{pmatrix}
\]

Let’s denote \(a = s_u\), \(b = s_v\).  
The matrix becomes:

\[
\begin{pmatrix}
a & b & a^2 + u + v + 10 \\
1 & 1 & b \\
b & a & ab
\end{pmatrix}
\]

We compute the determinant. Using the formula for a 3×3 determinant:

\[
\det = a \cdot (1 \cdot ab - b \cdot a) - b \cdot (1 \cdot ab - b \cdot b) + (a^2 + u + v + 10) \cdot (1 \cdot a - 1 \cdot b)
\]

Simplify each term:

First term:  
\(a \cdot (ab - ab) = a \cdot 0 = 0\)

Second term:  
\(- b \cdot (ab - b^2) = -b \cdot b(a - b) = -b^2(a - b)\)

Third term:  
\((a^2 + u + v + 10) \cdot (a - b)\)

So determinant =  
\[
0 - b^2(a - b) + (a^2 + u + v + 10)(a - b)
\]
Factor out \((a - b)\):

\[
\det = (a - b) \cdot \left( -b^2 + a^2 + u + v + 10 \right)
\]

So the determinant is zero if either:

1. \(a = b\)  
2. \(a^2 - b^2 + u + v + 10 = 0\) → \((a-b)(a+b) + u + v + 10 = 0\)

But since we already have \(a-b\) factor, the second condition is:  
\(a^2 - b^2 + u + v + 10 = 0\) → \((a-b)(a+b) + u + v + 10 = 0\)

If \(a \neq b\), then we need \((a-b)(a+b) + u + v + 10 \neq 0\).  
But note: if \(a \neq b\), then \(a-b\) is ±1 or ±2 (since values are 1,2,3).  
We can check all possibilities.

Actually, the determinant is zero if either \(a = b\) or \(a^2 - b^2 = -(u+v+10)\).  
Since \(a,b \in \{1,2,3\}\), \(a^2 - b^2\) can be:  
- 1-1=0, 1-4=-3, 1-9=-8  
- 4-1=3, 4-4=0, 4-9=-5  
- 9-1=8, 9-4=5, 9-9=0  

So possible differences: -8, -5, -3, 0, 3, 5, 8.

Thus for an edge (u,v), we must avoid:  
- \(s_u = s_v\)  
- \(s_u^2 - s_v^2 = -(u+v+10)\)

Since \(u+v+10\) is at least 12 (since u,v ≥ 1), the negative of that is ≤ -12.  
But the smallest possible \(s_u^2 - s_v^2\) is -8. So \(s_u^2 - s_v^2 = -(u+v+10)\) is impossible because RHS ≤ -12, LHS ≥ -8.  

Thus the only forbidden case is \(s_u = s_v\).

So the problem reduces to:  
Assign each node a value from {1,2,3} such that no two adjacent nodes have the same value.  
This is a graph coloring problem with 3 colors. Since the graph may not be bipartite, but with 3 colors it's always possible if the graph is not complete with 4 vertices? Actually, any graph can be colored with 3 colors unless it contains K4. But here n ≤ 40, so we can try backtracking.

We need the lexicographically smallest assignment (in terms of the sequence s1, s2, ..., sn) that satisfies the constraint.  
We can do a DFS with pruning: assign values in order from 1 to n, trying 1, then 2, then 3, and check constraints with already assigned neighbors.

If we find a valid assignment, output it. If none, output NO.

Let's implement.

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def dfs(idx):
    if idx == n:
        return True
    for c in (1, 2, 3):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if dfs(idx + 1):
                return True
            color[idx] = 0
    return False

if dfs(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
