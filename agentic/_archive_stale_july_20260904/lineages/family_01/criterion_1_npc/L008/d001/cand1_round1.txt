# Problem A — Production Phases

Time limit: 2 s   Memory limit: 256 MB

A manufacturing plant organizes its daily schedule into three distinct production phases, designated 1, 2, and 3. The plant operates $n$ assembly stations. Due to limited cooling capacity, certain pairs of stations are connected to the same thermal exhaust system. If any such pair is active during the same production phase, the system will overheat. Your task is to allocate exactly one phase to each station in a way that avoids overheating any exhaust system, or determine if this cannot be done.

## Input
The first line contains two integers $n$ and $m$ — the number of assembly stations and the number of connected pairs. The facility comprises exactly 4 rooms, each built to accommodate exactly 10 stations, meaning $n$ is at least 1 and at most the facility's total station capacity. The value of $m$ is at least 0 and at most the maximum number of distinct two-station pairs possible among the $n$ stations. 

Each of the next $m$ lines provides two integers $u$ and $v$ — the identifiers of two stations sharing an exhaust system.

## Output
If there is no safe allocation, output a single line with NO.
Otherwise, output YES on the first line. On the second line, output $n$ integers $c_1, c_2, \dots, c_n$ (where each $c_i \in \{1, 2, 3\}$), with $c_i$ representing the phase assigned to station $i$. If multiple safe allocations exist, you must output the one that is lexicographically smallest (comparing the phase of station 1 first, then station 2, and so forth).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

</RATIONALE>
