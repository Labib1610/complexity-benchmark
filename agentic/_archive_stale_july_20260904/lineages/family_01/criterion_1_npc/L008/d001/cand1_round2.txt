# Problem A — Tri-Phase Operation

Time limit: 2 s   Memory limit: 256 MB

A manufacturing plant organizes its workload into three distinct operational phases, identified as 1, 2, and 3. The plant contains $n$ robotic stations. Due to structural vibrations, specific pairs of stations will cause critical damage if they are active simultaneously. Consequently, such pairs must never be scheduled in the identical phase. Your task is to allocate each robotic station to exactly one of the three phases in a way that prevents any vibrating pair from being active concurrently, or determine that no such allocation exists.

## Input
The first line contains two integers $n$ and $m$ — the number of robotic stations and the number of vibrating pairs. The number of stations $n$ is at least 1 and cannot exceed the plant's maximum capacity of 40 installation bays. The number of pairs $m$ is at least 0 and at most $n(n-1)/2$.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of stations that interfere with each other. Stations are numbered from 1 to $n$.

## Output
If no valid allocation exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \dots, c_n$ (each in $\{1, 2, 3\}$), where $c_i$ is the phase allocated to station $i$. Among all valid allocations, output the sequence that is lexicographically smallest (compare $c_1$ first, then $c_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
