We can model this as a graph coloring problem. We have a graph with up to 40 nodeshare; each edge means the two nodes cannot have the same color. We want a valid 3-coloring and among all valid ones, the lexicographically smallest assignment.

We can do a backtracking search with pruning. Since \( n \) is at most 40, we can use bitmasks to represent available colors and check conflicts quickly.  
We assign colors from 1 to 3 sequentially and always try the smallest possible color first courts to guarantee lexicographic minimality.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))

    adj = [0] * n
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)

    # colors: 0 = unassigned, 1,2,3 for sealants
    color = [0] * n
    # We'll store for each node a bitmask of colors already forbidden by colored neighbors.
    # But easier: we can just check neighbors on each assignment.
    
    def backtrack(i):
        if i == n:
            return True
        # Try colors 1,2,3 in order for lexicographic minimality
        for c in (1, 2, 3):
            ok = True
            # Check neighbors
            mask = adj[i]
            j = 0
            while mask:
                if mask & 1:
                    if color[j] == c:
                        ok = False
                        break
                mask >>= 1
                j += 1
            if ok:
                color[i] = c
                if backtrack(i + 1):
                    return True
                color[i] = 0
        return False

    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
