**Solution Explanation**

The parts and interlocking pairs form an undirected graph `G`.  
We have to colour every vertex with one of three colours `{1,2,3}` such that
adjacent vertices receive different colours.
Among all proper colourings we need the lexicographically smallest
sequence `(c1,…,cn)` (compare `c1` first, then `c2`, …).

`n ≤ 40`, therefore a simple depth‑first search with backtracking is fast
enough.  
If we colour the vertices **exactly in the order `1,2,…,n`** and always try
the colours `1,2,3` in this order, the first complete colouring we find is
already the lexicographically smallest one – any earlier vertex would have
received the smallest possible colour that still allows a full solution.

The algorithm:

```
read n,m
build adjacency list adj[1..n]

colour[1..n] = 0   # 0 = uncoloured

def dfs(v):
    if v == n+1:               # all vertices coloured
        return True
    for col in (1,2,3):        # try colours in increasing order
        ok = True
        for u in adj[v]:
            if colour[u] == col:
                ok = False
                break
        if not ok: continue
        colour[v] = col
        if dfs(v+1):
            return True
        colour[v] = 0          # backtrack
    return False                # no colour works for vertex v

if dfs(1):
    print "YES"
    print colours 1..n
else:
    print "NO"
```

The recursion depth is at most `n = 40`.  
In the worst case we try `3^n` colourings, but the adjacency constraints prune
the search heavily; for `n = 40` this easily fits into the 2 s limit.

The memory consumption is `O(n + m)` for the adjacency list and the colour
array.

---

**Correctness Proof**

We prove that the algorithm outputs `NO` iff the graph is not 3‑colourable,
and otherwise outputs the lexicographically smallest proper colouring.

*Lemma 1*  
During the execution of `dfs(v)` the array `colour[1..v-1]` contains a proper
colouring of the induced subgraph on vertices `{1,…,v-1}`.

*Proof.*  
Initially `v = 1` and the statement is vacuously true.  
Assume it holds for the current call `dfs(v)`.  
When we assign a colour `col` to vertex `v` we first check that no already
coloured neighbour (all of them are in `{1,…,v-1}`) has the same colour.
Thus after the assignment the invariant holds for `{1,…,v}`.
If later we backtrack, we reset `colour[v]` to `0`, restoring the invariant
for `{1,…,v-1}`. ∎



*Lemma 2*  
If `dfs(v)` returns `True`, then `colour[1..n]` is a proper 3‑colouring of the
whole graph.

*Proof.*  
`dfs(v)` returns `True` only when either `v = n+1` (all vertices coloured) or
a recursive call `dfs(v+1)` returned `True`.  
By Lemma&nbsp;1 the colour assignment is proper for all already processed
vertices, and the base case guarantees that every vertex receives a colour.
Hence the final array is a proper 3‑colouring. ∎



*Lemma 3*  
If the graph admits a proper 3‑colouring, then `dfs(1)` returns `True`.

*Proof.*  
Consider any proper colouring `C`.  
We show by induction on `v` that the recursive search can follow `C`:
for `v = 1` the colour `C(1)` is among `{1,2,3}` and is compatible with the
already empty set, so the loop will try it and recurse to `v=2`.  
Assume the search has reached `v` with `colour[i]=C(i)` for all `i<v`.  
All neighbours of `v` are among `{1,…,v-1}` and have colours different from
`C(v)`, therefore the test in the loop accepts `C(v)`. The loop tries colours
in order `1,2,3`; when it reaches `C(v)` it recurses to `v+1`. Thus the
search can continue following `C` until `v=n+1`, where it returns `True`. ∎



*Lemma 4*  
If `dfs(1)` returns `True`, the produced colouring is the lexicographically
smallest among all proper colourings.

*Proof.*  
The search processes vertices in increasing index order and, for each vertex,
tries colours `1,2,3` in that order.  
Suppose there exists another proper colouring `D` that is lexicographically
smaller than the one found. Let `k` be the first position where `D(k) <`
`colour[k]`. For vertices `1,…,k-1` both colourings coincide, therefore when
the algorithm processed vertex `k` the colour `D(k)` was admissible (no
conflict with earlier vertices). Since the loop tries colours in increasing
order, it would have selected `D(k)` before `colour[k]`, contradicting the
choice of `colour[k]`. Hence no such `D` exists. ∎



*Theorem*  
The algorithm outputs  

* `NO` iff the input graph is not 3‑colourable;  
* otherwise `YES` and the lexicographically smallest proper 3‑colouring.

*Proof.*  
If the algorithm prints `YES`, by Lemma&nbsp;2 the printed assignment is a
proper 3‑colouring, and by Lemma&nbsp;4 it is lexicographically minimal.  
If it prints `NO`, then `dfs(1)` returned `False`. By Lemma&nbsp;3 this can
happen only when no proper 3‑colouring exists. Conversely, if no proper
3‑colouring exists, Lemma&nbsp;3 tells us `dfs(1)` cannot succeed, so the
algorithm prints `NO`. ∎



---

**Complexity Analysis**

Let `d(v)` be the degree of vertex `v`.  
For each vertex we test at most three colours, each test scans its adjacency
list, costing `O(d(v))`.  
Hence the total work of one complete branch is `O( Σ d(v) ) = O(m)`.  
In the worst case all `3^n` branches are explored, giving time `O(3^n·m)`,
but with `n ≤ 40` and typical pruning this easily fits the 2 s limit.
Memory usage is `O(n + m)`.

**Reference Implementation (Python 3)**

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        if u == v:
            continue
        adj[u].append(v)
        adj[v].append(u)

    colour = [0] * (n + 1)  # 1‑based

    def dfs(v: int) -> bool:
        if v == n + 1:
            return True
        for col in (1, 2, 3):
            ok = True
            for nb in adj[v]:
                if colour[nb] == col:
                    ok = False
                    break
            if not ok:
                continue
            colour[v] = col
            if dfs(v + 1):
                return True
            colour[v] = 0
        return False

    if dfs(1):
        out = ['YES', ' '.join(str(colour[i]) for i in range(1, n + 1))]
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```
