 We need to assign each oscillator a value from {1, 2, 3} such that for every edge (u, v), the condition  

\[
(17 s_u^3 + 27 s_v^2) \bmod 64 \neq (17 s_v^3 + 27 s_u^2) \bmod 64
\]  

holds.  

We can brute-force all \(3^n\) assignments since \(n \leq 40\) is too large for full brute force, but we can use backtracking with pruning.  

However, note that the condition only depends on the values modulo 64, and the function is symmetric in a way. Let’s check possible pairs:  

For each pair of values (a, b) from {1,2,3}, compute:  
- left = (17*a^3 + 27*b^2) % 64  
- right = (17*b^3 + 27*a^2) % 64  

We can precompute which pairs are allowed.  

Then we can do backtracking: assign values to nodes in order, checking all edges to previously assigned nodes.  

Since n ≤ 40, but the graph may be sparse, backtracking with pruning should work for typical cases.  

Let’s implement:  

```python
n, m = map(int, input().split())
edges = [tuple(map(int, input().split())) for _ in range(m)]

# Precompute allowed pairs
allowed = {}
for a in (1,2,3):
    for b in (1,2,3):
        left = (17*a**3 + 27*b**2) % 64
        right = (17*b**3 + 27*a**2) % 64
        if left != right:
            allowed[(a,b)] = True

# Build adjacency list
adj = [[] for _ in range(n)]
for u,v in edges:
    u-=1; v-=1
    adj[u].append(v)
    adj[v].append(u)

assign = [0]*n
found = False

def dfs(idx):
    global found
    if found:
        return
    if idx == n:
        found = True
        return
    for val in (1,2,3):
        # Check all neighbors already assigned
        ok = True
        for nb in adj[idx]:
            if assign[nb] != 0:
                if (val, assign[nb]) not in allowed:
                    ok = False
                    break
        if ok:
            assign[idx] = val
            dfs(idx+1)
            if found:
                return
            assign[idx] = 0

dfs(0)

if not found:
    print("NO")
else:
    print("YES")
    print(" ".join(map(str, assign)))
```
