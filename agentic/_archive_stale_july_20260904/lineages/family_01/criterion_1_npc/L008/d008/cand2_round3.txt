<STATEMENT>
# Problem A — Oscillator Tuning

Time limit: 2 s   Memory limit: 256 MB

A control system consists of $n$ precision oscillators, each installed in a numbered slot from $1$ through $n$. Each oscillator requires a frequency multiplier to operate correctly. You must assign each oscillator a multiplier chosen from the set $\{1, 2, 3\}$.

Within the system, certain pairs of oscillators are connected by coupling links. The overall system stability is evaluated by calculating its global resonance score $G$. This score is determined by summing the local stability factors of all individual coupling links. 

For a coupling link connecting oscillator $u$ and oscillator $v$, its local stability factor is calculated using their assigned multipliers $s_u$ and $s_v$ as follows:
$$\lfloor \frac{(s_u - s_v)^2 + 3}{4} \rfloor$$

The global resonance score $G$ is the sum of these factors across all $m$ links in the system. To prevent resonance collapse, the system must achieve a global resonance score $G$ that is exactly equal to the total number of coupling links $m$. If $G$ is strictly less than $m$, the system fails.

You must determine whether a stable configuration of multipliers exists for the given system.

## Input
The first line provides two integers $n$ and $m$ — the total number of oscillators and the number of coupling links. The facility's power supply can support at most a single chassis of oscillators. A standard chassis contains exactly 40 slots, so $n$ is at least 1 and bounded by this maximum capacity. The number of links $m$ ranges from zero up to the theoretical maximum where every oscillator is linked to every other oscillator exactly once.

Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), signifying that oscillator $u$ and oscillator $v$ are linked. It is guaranteed that each unordered pair of linked oscillators appears at most once in the input.

## Output
If there is no way to configure the multipliers without inducing resonance collapse, output a single line containing `NO`.
If a stable configuration is achievable, output `YES` on the first line. On the second line, provide $n$ integers $s_1 s_2 \dots s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ represents the multiplier assigned to oscillator $i$. 

If multiple stable configurations exist, you must output the one that minimizes the final system signature $V_n$. This signature is computed sequentially: starting with an initial value $V_0 = 0$, for each oscillator $i$ from $1$ to $n$ in order, the signature updates according to the rule $V_i = 4 \cdot V_{i-1} + s_i$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I replaced the explicit edge-by-edge inequality constraint with a global energy function $G$ that sums local stability factors. Because the local factor uses a floor function that caps at 1 for the domain $\{1, 2, 3\}$, the condition $G = m$ mathematically forces every linked pair to have distinct multipliers. Models that blindly translate the global check will fail to prune their search space and time out, while models that reason mathematically will deduce the local $s_u \ne s_v$ constraint and implement efficient backtracking.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $G = m$ is mathematically identical to requiring $s_u \ne s_v$ for all links, so the set of valid configurations is unchanged, and the tie-breaker rule guarantees the exact same optimal configuration is chosen.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to 3-Coloring on a general graph, keeping it in the NP-complete complexity class.
</PRESERVED_CLASS>
<RISK>
The indirect bounds derived from "a standard chassis contains exactly 40 slots" could potentially be misinterpreted as a soft limit rather than a hard constraint $n \le 40$, though "bounded by this maximum capacity" clarifies it.
</RISK>
