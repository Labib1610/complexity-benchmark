<STATEMENT>
# Problem A — Asymptotic Stability

Time limit: 2 s   Memory limit: 256 MB

A quantum control system consists of $n$ precision nodes. Each node must be configured with an energy multiplier chosen from the set $\{1, 2, 3\}$.

Within the system, certain pairs of nodes are connected by entanglement links. When a link exists between node $u$ and node $v$, their multipliers $s_u$ and $s_v$ interact over time. This interaction is modeled by two energy sequences, $X_k$ and $Y_k$, generated by the link.

The initial energy states of the link are defined as:
$X_0 = s_u + s_v$
$X_1 = s_u \cdot u + s_v \cdot v$

$Y_0 = s_u + s_v$
$Y_1 = s_v \cdot u + s_u \cdot v$

For all time steps $k \ge 2$, both sequences evolve according to the link's characteristic recurrence:
$X_k = (u+v) X_{k-1} - u v X_{k-2}$
$Y_k = (u+v) Y_{k-1} - u v Y_{k-2}$

For the link to maintain stability, the asymptotic energy ratio $\lim_{k \to \infty} \frac{X_k}{Y_k}$ must be strictly not equal to $1$. If this limit evaluates to exactly $1$, the link undergoes resonance collapse and the entire system fails. 

You must determine whether a stable configuration of multipliers exists for the given system.

## Input
The first line provides two integers $n$ and $m$ — the total number of nodes and the number of entanglement links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), signifying that node $u$ and node $v$ are linked. It is guaranteed that each unordered pair of linked nodes appears at most once in the input.

## Output
If there is no way to configure the multipliers without inducing resonance collapse, output a single line containing `NO`.
If a stable configuration is achievable, output `YES` on the first line. On the second line, provide $n$ integers $s_1 s_2 \dots s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ represents the multiplier assigned to node $i$. If multiple stable configurations exist, you must output the one that minimizes the configuration value $C = \sum_{i=1}^n s_i \cdot 2^{2n - 2i}$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit power-of-2 condition with a pair of linear recurrence sequences whose asymptotic ratio must not equal 1. This forces the model to either symbolically solve the characteristic equation of the recurrence to realize it simplifies to $s_u \neq s_v$, or attempt to simulate the limit inside a backtracking loop, which will result in a Time Limit Exceeded due to large integer arithmetic. I also mathematically disguised the tie-breaker to prevent easy recognition of lexicographical order.
</RATIONALE>
<PRESERVED_ANSWER>
The closed-form solutions for the sequences are $X_k = s_u u^k + s_v v^k$ and $Y_k = s_v u^k + s_u v^k$; since $u \neq v$, the limit of their ratio as $k \to \infty$ is either $s_u/s_v$ or $s_v/s_u$, which equals 1 if and only if $s_u = s_v$, perfectly preserving the original graph coloring constraints and outputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a 3-coloring of a graph with a lexicographically smallest tie-breaker, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "asymptotic energy ratio" if they are unfamiliar with limits, but the mathematical notation $\lim_{k \to \infty} \frac{X_k}{Y_k}$ is standard and unambiguous.
</RISK>
