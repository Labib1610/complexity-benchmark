</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaced the explicit power-of-2 condition with a cross-weighted sum divisibility rule: the sum $s_u \cdot v + s_v \cdot u$ must not be a multiple of $u+v$. Because $s_u, s_v \in \{1, 2, 3\}$ and $u \neq v$, this condition mathematically simplifies exactly to $s_u \neq s_v$. However, the explicit dependence on the node indices $u$ and $v$ masks the uniform 3-coloring constraint, forcing models to genuinely implement and evaluate the condition rather than pattern-matching to standard graph coloring.
</METHOD_DESCRIPTION>

# Problem A — Phase Synchronizers

Time limit: 2 s   Memory limit: 256 MB

A communication network consists of $n$ phase synchronizers. Each synchronizer must be assigned a phase state chosen from the set $\{1, 2, 3\}$.

Within the network, certain pairs of synchronizers are connected by data channels. If synchronizers $u$ and $v$ are connected, and they are assigned phase states $s_u$ and $s_v$ respectively, they generate a combined signal load along the channel. The signal load is calculated as the cross-weighted sum: $L = s_u \cdot v + s_v \cdot u$.

To prevent data packet collisions, the channel must not be in a harmonic resonance state. A channel enters harmonic resonance if its signal load $L$ is an exact integer multiple of the channel's baseline capacity, which is defined as $u + v$. In other words, if there exists any integer $k$ such that $s_u \cdot v + s_v \cdot u = k \cdot (u + v)$, the channel fails and the network collapses.

You must determine whether a valid configuration of phase states exists for the given network such that no channel enters harmonic resonance.

## Input
The first line provides two integers $n$ and $m$ — the total number of synchronizers and the number of data channels ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), signifying that a data channel connects synchronizer $u$ and synchronizer $v$. It is guaranteed that each unordered pair of connected synchronizers appears at most once in the input.

## Output
If there is no way to configure the phase states without inducing harmonic resonance, output a single line containing `NO`.
If a valid configuration is achievable, output `YES` on the first line. On the second line, provide $n$ integers $s_1 s_2 \dots s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ represents the phase state assigned to synchronizer $i$. If multiple valid configurations exist, you must output the one that minimizes the structural signature $S = \sum_{i=1}^n s_i \cdot 4^{n-i}$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The power-of-2 resonance rule was replaced with a cross-weighted divisibility check: $s_u v + s_v u \neq k(u+v)$. Because $s_u, s_v \in \{1, 2, 3\}$ and $u \neq v$, this condition is mathematically identical to $s_u \neq s_v$, but the explicit dependence on the node indices $u$ and $v$ masks the uniform 3-coloring equivalence. This forces models to natively evaluate the constraint rather than recognizing the shortcut to a standard 3-coloring problem.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $s_u v + s_v u = k(u+v)$ simplifies to $v(s_u - k) = u(k - s_v)$, which for $s_u, s_v \in \{1, 2, 3\}$ and $u, v \ge 1, u \neq v$ has solutions if and only if $s_u = s_v = k$, meaning the forbidden pairs are exactly those where $s_u = s_v$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains identically 3-coloring on a general graph (NP-complete), and the tie-breaker still enforces finding the lexicographically smallest valid assignment.
</PRESERVED_CLASS>
