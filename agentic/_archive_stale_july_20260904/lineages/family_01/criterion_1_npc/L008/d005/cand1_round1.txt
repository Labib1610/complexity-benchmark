# Problem A — Harmonic Resonance Tolerances

Time limit: 2 s   Memory limit: 256 MB

A high-tech manufacturing plant is preparing a set of precision-machined elements for final integration into a single mechanism. Before they can be integrated, every element must be configured to operate at a specific harmonic tier, chosen from the values 1, 2, or 3.

Within the mechanism, certain pairs of distinct elements are designed to be in direct physical contact. When two contacting elements operate at tiers $x$ and $y$, their interaction is governed by the quadratic equation $z^2 - (x+y)z + (x \cdot y) = 0$. If this equation possesses a single repeated root, their frequencies perfectly align and induce a catastrophic standing wave. This standing wave locks the mechanism and renders the entire unit defective. Consequently, you must assign tiers such that no two contacting elements produce an equation with a repeated root.

The plant's testing chamber is arranged as an $8 \times 5$ grid of integration slots, meaning the maximum number of elements is bounded by the total number of slots in this grid. The automated verification suite intentionally evaluates your logic against adversarial testing configurations on this maximum capacity. These include closely constrained layouts, engineered specifically to cause fixed-order, tier-by-tier trial-and-error approaches to exceed the time limit.

You must determine whether a stable tier configuration exists for the given mechanism.

## Input
The first line provides two integers $n$ and $m$ — the total number of elements and the number of contact pairs. The number of elements $n$ is at least 1 and is bounded by the testing chamber's total slot capacity. The number of contact pairs $m$ ranges from zero up to the theoretical maximum where every distinct pair of the $n$ elements is in contact.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), signifying that element $u$ and element $v$ are in direct physical contact. It is guaranteed that each unordered pair of contacting elements appears at most once in the input.

## Output
If there is no way to configure the elements without inducing a standing wave, output a single line containing `NO`.
If a stable configuration is achievable, output `YES` on the first line. On the second line, provide $n$ integers $s_1 s_2 \dots s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ represents the tier applied to element $i$. If multiple stable configurations exist, you must output the one that minimizes the structural signature $S = \sum_{i=1}^n s_i \cdot 4^{n-i}$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit constraint that two contacting elements cannot share the same state has been replaced with an algebraic equivalent: the quadratic equation formed by their values having a single repeated root. This forces models to algebraically deduce that the roots are exactly `x` and `y`, meaning a repeated root occurs if and only if `x == y`. Additionally, the numerical bounds for `n` and `m` are now stated indirectly through physical capacities, requiring the reader to derive the explicit constraints $n \le 40$ and $m \le n(n-1)/2$.
</RATIONALE>
<PRESERVED_ANSWER>
The roots of the equation $z^2 - (x+y)z + xy = 0$ are exactly $x$ and $y$, so a repeated root exists if and only if $x = y$, making the constraint mathematically identical to the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 3-coloring on a graph, preserving its NP-complete status and requiring identical algorithmic performance to pass adversarial bounds.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret the quadratic equation as a system it needs to solve dynamically rather than a static property of the two chosen tiers, though the phrasing "governed by" and "possesses a single repeated root" strongly implies evaluating a mathematical condition.
</RISK>
