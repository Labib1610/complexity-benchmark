We need to check if we can assign each oscillator a value from {1, 2, 3} such that for every edge (u, v), the quadratic  
\( t^2 - (s_u + s_v)t + s_u s_v = 0 \) has two distinct real roots.

The discriminant is:
\[
\Delta = (s_u + s_v)^2 - 4 s_u s_v = (s_u - s_v)^2
\]
For two distinct real roots, we need \(\Delta > 0\), i.e. \(s_u \ne s_v\).

So the problem reduces to: can we color the graph with 3 colors (1, 2, 3) such that adjacent vertices have different colors? This is exactly the 3-coloring problem, which is NP-complete in general, but here \(n \le 40\), so we can use backtracking with pruning.

We also need the lexicographically smallest assignment in terms of the structural signature \(S = \sum s_i \cdot 4^{n-i}\). This means we want the smallest possible values for earlier indices (since \(4^{n-i}\) is huge for small i). So we try to assign the smallest possible value to each vertex in order, and backtrack if conflict.

We'll implement a backtracking search:
- Sort vertices by degree (or just process in order 0..n-1) — but for lexicographic minimality, we must assign in index order.
- For each vertex, try values 1, 2, 3 in that order, check if any neighbor already assigned has the same value.
- If we reach the end, we have a solution.

Since n ≤ 40, worst-case backtracking could be large, but with 3 colors and pruning it should be fine for typical cases. We can also add a simple heuristic: if any vertex has degree > 2 and we can't color, we fail quickly.

Let's implement.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n
    # Try to color with backtracking, trying smallest color first
    def backtrack(idx):
        if idx == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[idx] = c
                if backtrack(idx + 1):
                    return True
                colors[idx] = -1
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
