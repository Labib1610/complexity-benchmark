# Problem A — Quantum Flux Calibration

Time limit: 2 s   Memory limit: 256 MB

A quantum computing facility is calibrating $n$ temporal flux components for a new processing mainframe. Each component requires a calibration scalar $s_i$ chosen from the set $\{1, 2, 3\}$.

Within the mainframe, certain pairs of distinct components are linked via a quantum bridge. When two linked components $u$ and $v$ operate, they exchange energy according to their interaction matrix:

$$ M_{u,v} = \begin{pmatrix} s_u + s_v & s_u \cdot s_v \\ 4 & s_u + s_v \end{pmatrix} $$

If this matrix is singular (i.e., its determinant is exactly zero), the energy exchange collapses into a destructive cascade failure, rendering the entire mainframe defective. To maintain system integrity, no two linked components can ever produce a singular interaction matrix.

The facility's automated verification suite intentionally evaluates your logic against adversarial testing configurations on the full 40 components. These include closely constrained and fundamentally incompatible link architectures, engineered specifically to cause fixed-order, scalar-by-scalar trial-and-error approaches to exceed the time limit.

You must determine whether a stable calibration configuration exists for the given mainframe.

## Input
The first line provides two integers $n$ and $m$ — the total number of components and the number of quantum bridge links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), signifying that component $u$ and component $v$ are linked via a quantum bridge. It is guaranteed that each unordered pair of linked components appears at most once in the input.

## Output
If there is no way to calibrate the components without inducing a cascade failure, output a single line containing `NO`.
If a stable configuration is achievable, output `YES` on the first line. On the second line, provide $n$ integers $s_1 s_2 \dots s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ represents the calibration scalar applied to component $i$. If multiple stable configurations exist, you must output the one that minimizes the system signature $S = \sum_{i=1}^n s_i \cdot 4^{n-i}$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The problem was completely reframed from a chemical coating scenario to a quantum computing calibration setting. The direct inequality constraint (`s_u != s_v`) was replaced with a mathematically equivalent condition based on the singularity of a 2x2 matrix. To recognize this as a standard 3-coloring problem, the model must now symbolically evaluate the determinant `(s_u + s_v)^2 - 4 * s_u * s_v`, simplify it to `(s_u - s_v)^2`, and deduce that the matrix is singular if and only if `s_u == s_v`. This defeats models that rely solely on surface-level keyword matching to trigger graph-coloring heuristics.
</RATIONALE>

The determinant condition simplifies to `(s_u - s_v)^2 = 0`, which enforces `s_u != s_v` for all linked pairs, exactly preserving the original constraint logic, tie-breaker formula, and outputs.
</PRESERVED_ANSWER>
