# Problem A — Oscillator Tuning

Time limit: 2 s   Memory limit: 256 MB

A control system consists of $n$ precision oscillators. Each oscillator requires a frequency multiplier to operate correctly. You must assign each oscillator a multiplier chosen from the set $\{1, 2, 3\}$.

Within the system, certain pairs of oscillators are connected by coupling links. If oscillators $u$ and $v$ are linked, and they are assigned multipliers $s_u$ and $s_v$ respectively, their interaction is governed by the characteristic equation:
$$t^2 - (s_u + s_v)t + s_u s_v = 0$$

To ensure system stability, this equation must yield two distinct real roots for every linked pair. If any linked pair's characteristic equation has a repeated root, the system undergoes resonance collapse and fails. 

You must determine whether a stable configuration of multipliers exists for the given system.

## Input
The first line provides two integers $n$ and $m$ — the total number of oscillators and the number of coupling links ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), signifying that oscillator $u$ and oscillator $v$ are linked. It is guaranteed that each unordered pair of linked oscillators appears at most once in the input.

## Output
If there is no way to configure the multipliers without inducing resonance collapse, output a single line containing `NO`.
If a stable configuration is achievable, output `YES` on the first line. On the second line, provide $n$ integers $s_1 s_2 \dots s_n$ ($s_i \in \{1, 2, 3\}$), where $s_i$ represents the multiplier assigned to oscillator $i$. If multiple stable configurations exist, you must output the one that minimizes the structural signature $S = \sum_{i=1}^n s_i \cdot 4^{n-i}$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I removed the explicit inequality constraint ("cannot be treated with the same coating") and replaced it with a mathematical property: the characteristic equation $t^2 - (s_u + s_v)t + s_u s_v = 0$ must have two distinct real roots. Since the roots are exactly $s_u$ and $s_v$, this strictly enforces $s_u \neq s_v$. This forces the model to algebraically deduce the inequality constraint rather than pattern-matching a standard graph coloring problem. The exact bounds and tie-breaker formulation from the seed were restored to comply with strict I/O contracts.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the quadratic equation has distinct roots is mathematically equivalent to $s_u \neq s_v$, so all valid configurations and their tie-breaking scores are identical to the seed's 3-coloring constraints.
</PRESERVED_ANSWER>
