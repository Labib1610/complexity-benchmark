# Problem A — Assembly Tolerances

Time limit: 2 s   Memory limit: 256 MB

A specialized manufacturing facility produces a complex device made of $n$ machined parts. The production floor uses standard assembly pallets that hold exactly 40 components, and each device requires at most one full pallet of parts. Therefore, the number of parts $n$ is at least 1 and at most the capacity of a single pallet.

Before final assembly, every single part must be treated with exactly one of three available chemical sealants, designated as 1, 2, and 3.

Because of precise tolerances, certain pairs of parts interlock flush against each other. If two interlocking parts are treated with the exact same sealant, they undergo a cross-linking reaction that permanently fuses them, ruining the device's internal mechanics. To prevent this, any two parts that interlock must be treated with strictly different sealants.

The listed pair reactions define a three-state compatibility system. Be warned: the interlocking configurations can be highly adversarial, designed to defeat naive fixed-order exhaustive search. Finding a valid assignment may require aggressive branching, state propagation, or equivalent pruning.

You are given the number of parts and the full list of interlocking pairs. Determine if it is possible to assign a sealant to every part without causing any interlocking pairs to fuse. 

## Input
The first line contains two integers $n$ and $m$ — the number of machined parts and the number of interlocking pairs. As established, $n$ ranges from 1 up to the pallet capacity. The value of $m$ ranges from 0 up to the maximum possible number of distinct pairs among the $n$ parts.
Each of the next $m$ lines contains two integers $u$ and $v$ (valid part identifiers from 1 to $n$) — an interlocking pair of parts.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES on the first line. On the second line print $n$ integers $s_1 s_2 \dots s_n$ (each in $\{1, 2, 3\}$), where $s_i$ is the sealant applied to part $i$. Among all valid assignments, output the sequence that would appear first if all valid assignment sequences were sorted numerically (comparing the sealant of part 1 first, then part 2, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
