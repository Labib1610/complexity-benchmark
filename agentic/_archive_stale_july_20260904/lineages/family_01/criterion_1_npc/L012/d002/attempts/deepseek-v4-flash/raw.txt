We need to assign each microservice a tier (1, 2, or 3) such that no two connected microservices share the same tier, and we want the lexicographically smallest assignment.

This is essentially a graph coloring problem with 3 colors, where we want the lexicographically smallest valid coloring.

Since \( n \le 40 \), we can use backtracking with pruning.  
We will try to assign tiers in order from microservice 1 to n, always trying the smallest possible tier first, and backtrack if we hit a dead end.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)

    colors = [0] * n

    def backtrack(idx):
        if idx == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[idx] = c
                if backtrack(idx + 1):
                    return True
                colors[idx] = 0
        return False

    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
