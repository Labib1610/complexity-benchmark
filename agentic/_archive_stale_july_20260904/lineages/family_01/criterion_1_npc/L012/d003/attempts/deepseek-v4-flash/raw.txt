 We need to assign values 1, 2, or 3 to each node such that adjacent nodes have different values, and we want the lexicographically smallest assignment.

This is a graph coloring problem with 3 colors. Since the graph may not be connected, we handle each connected component separately.

We can solve it using backtracking with pruning, but since n ≤ 40, we can use a more efficient approach:  
- For each component, try to assign colors in order (1, 2, 3) for each node, using DFS with backtracking.  
- Since we want lexicographically smallest, we process nodes in order from 1 to n.  
- For each node, try color 1, then 2, then 3, and check if it conflicts with already colored neighbors.  

We also need to handle the case where no assignment is possible.

Here’s the implementation:

```python
import sys
sys.setrecursionlimit(10000)

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n  # 0 means uncolored, 1,2,3 are colors
    
    def dfs(node):
        # Try colors 1,2,3
        for c in (1, 2, 3):
            ok = True
            for nb in adj[node]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[node] = c
                # Find next uncolored node
                next_node = -1
                for i in range(n):
                    if color[i] == 0:
                        next_node = i
                        break
                if next_node == -1:
                    return True
                if dfs(next_node):
                    return True
                color[node] = 0
        return False
    
    # Start from node 0
    if not dfs(0):
        print("NO")
    else:
        print("YES")
        print(" ".join(str(c) for c in color))

if __name__ == "__main__":
    solve()
```
