**Solution Explanation**

For every transaction `i` we have to choose a risk tier `c_i ∈ {1,2,3}`.
For every given link `{u,v}` the determinant condition

```
| cu  cv |
| 1   1 |  ≠ 0
```

means `cu – cv ≠ 0`, i.e. the two endpoints must receive **different**
tiers.  
So the whole problem is exactly a *proper 3‑colouring* of the given
undirected graph.

If a proper colouring exists we have to output the one with the smallest
audit hash

```
H = Σ ci · 4^(n‑i)          (i = 1 … n)
```

`4^(n‑i)` are decreasing powers, therefore minimising `H` is the same as
minimising the *lexicographic* order of the colour sequence
`c1 c2 … cn` (most significant position is `c1`).  
Consequently we only have to find the lexicographically smallest proper
3‑colouring.

`n ≤ 40`, therefore a simple depth‑first search with backtracking is more
than fast enough:

```
try to colour vertex 1, then 2, …, n
    for colour in 1,2,3 (in this order)
        if colour is different from all already coloured neighbours
            assign it and recurse to the next vertex
            if recursion succeeded → propagate success
    if no colour works → backtrack (failure)
```

The recursion stops as soon as a complete colouring is found – because we
always try colours `1,2,3` in increasing order, the first complete solution
is exactly the lexicographically smallest one.

The algorithm explores at most `3^n` states, but the graph constraints
prune the search heavily. For the worst case (`n = 40`, complete graph) the
search fails after trying only a few colours, because a complete graph
needs `n` different colours and the algorithm stops after the first vertex
cannot be coloured with any of the three colours.

The total running time is far below the limits, memory consumption is
`O(n + m)` for the adjacency lists and the recursion stack.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff the graph is not 3‑colourable,
otherwise it prints `YES` and the lexicographically smallest proper
3‑colouring.

---

##### Lemma 1  
During the search, before recursing to vertex `i` all vertices
`1 … i‑1` are already coloured and the partial assignment is proper
(no edge has equal colours on its ends).

**Proof.**  
Induction over `i`.  
*Base*: before the first recursion (`i = 1`) no vertex is coloured – the
statement holds vacuously.  
*Step*: assume it holds for `i`. When we try a colour for vertex `i`,
we check all neighbours that are already coloured (they are among
`1 … i‑1`). The colour is accepted only if it differs from each of them,
hence the extended partial assignment stays proper. ∎



##### Lemma 2  
If the recursive procedure returns *success* at level `i`,
then vertices `i … n` can be coloured extending the already fixed colours
`1 … i‑1`.

**Proof.**  
Success is returned only when the recursion reaches `i = n+1`,
i.e. all vertices have been assigned a colour. By Lemma&nbsp;1 the whole
assignment is proper, therefore it is a valid extension. ∎



##### Lemma 3  
If a proper 3‑colouring exists, the algorithm will eventually return
success.

**Proof.**  
Consider any proper 3‑colouring `C`. The algorithm explores the colour
choices for each vertex in the order `1,2,3`. When it reaches vertex `i`,
all colours of vertices `1 … i‑1` are exactly those of `C` (by induction:
the algorithm never backtracks from a vertex whose colour matches `C`,
because that colour is always allowed).  
Since `C` is proper, the colour `C(i)` is allowed for vertex `i`,
so the algorithm will try it (maybe after trying smaller colours that
lead to dead ends). Consequently the search can follow the whole
colouring `C` and reaches success. ∎



##### Lemma 4  
The first complete colouring found by the algorithm is the lexicographically
smallest proper 3‑colouring.

**Proof.**  
The search processes vertices in increasing order and, for each vertex,
tries colours `1,2,3` in that order.  
Thus the recursion explores the space of colour sequences in exact
lexicographic order. The first sequence that satisfies all constraints
is therefore the smallest one. ∎



##### Lemma 5  
If the algorithm outputs `NO`, the graph is not 3‑colourable.

**Proof.**  
`NO` is printed only when the recursive search exhausts all possibilities
without success. By Lemma&nbsp;3, any existing proper 3‑colouring would lead
to success, therefore none exists. ∎



##### Lemma 6  
If the algorithm outputs `YES` and a sequence `c1 … cn`,
the sequence is a proper 3‑colouring and is lexicographically minimal.

**Proof.**  
`YES` is printed only after the recursion returned success, i.e. after a
complete assignment was built. By Lemma&nbsp;1 this assignment is proper.
By Lemma&nbsp;4 it is the lexicographically smallest among all proper
assignments. ∎



##### Theorem  
The program prints `NO` iff the given graph cannot be coloured with three
different colours on adjacent vertices; otherwise it prints `YES` and the
lexicographically smallest proper 3‑colouring.

**Proof.**  
Directly from Lemma&nbsp;5 (soundness of `NO`) and Lemma&nbsp;6
(soundness and optimality of `YES`). ∎



--------------------------------------------------------------------

#### Complexity Analysis  

Let `T` be the number of visited states of the depth‑first search.
Each state checks at most `deg(v) ≤ n‑1` neighbours, so the work per state
is `O(n)`.  
In the worst case `T ≤ 3^n`, but for `n ≤ 40` and the strong pruning by
edges this is far below the time limit.  
Memory consumption: adjacency lists `O(n+m)` and recursion stack `O(n)`.  

Both limits satisfy the required constraints.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    colour = [0] * n          # 0 = uncoloured, otherwise 1..3
    found = False

    def dfs(v: int) -> bool:
        """try to colour vertices v..n-1, return True on success"""
        if v == n:
            return True
        for col in (1, 2, 3):
            ok = True
            for nb in adj[v]:
                if nb < v and colour[nb] == col:
                    ok = False
                    break
            if not ok:
                continue
            colour[v] = col
            if dfs(v + 1):
                return True
            colour[v] = 0
        return False

    if dfs(0):
        print("YES")
        print(' '.join(map(str, colour)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
