<STATEMENT>
# Problem A — Phase-Shift Synchronization

Time limit: 2 s
Memory limit: 256 MB

You are configuring a network of $n$ phase-shift oscillators, indexed from $1$ to $n$.
Each oscillator $i$ must be assigned a discrete phase state $c_i$. The hardware supports exactly three phase states, represented by the integer values $1$, $2$, and $3$.

The network contains $m$ coupling links. Each link connects a specific pair of oscillators. To achieve destructive interference and prevent resonance loops, any two oscillators connected by a coupling link must be assigned phase states that satisfy the following phase-difference equation:
$$ \cos\left( \frac{2\pi}{3} (c_u - c_v) \right) = -0.5 $$
If this equation fails to hold for any coupled pair $(u, v)$, the network fails to synchronize.

Your objective is to determine a valid phase configuration for all $n$ oscillators. If there are multiple valid configurations, you must output the one that minimizes the network's final structural footprint $F_n$.
The structural footprint is calculated sequentially. Starting with an initial value $F_0 = 0$, the footprint after processing each oscillator $i$ (from $1$ to $n$ in increasing index order) is updated according to the recurrence:
$$ F_i = 4 \cdot F_{i-1} + c_i $$

If there is no way to assign the phase states without violating a coupling link, you must report that the configuration is impossible.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of oscillators and the number of coupling links.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating that a coupling link connects oscillator $u$ and oscillator $v$.

## Output
If a valid configuration is impossible, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers from the set $\{1, 2, 3\}$, representing the phase states $c_1, \dots, c_n$ for oscillators $1$ through $n$ that minimize $F_n$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was rewritten using two disguises to prevent surface pattern matching without changing the mathematical semantics. First, the standard graph coloring constraint ($c_u \neq c_v$) was replaced with a mathematically equivalent trigonometric equation: $\cos(2\pi/3 (c_u - c_v)) = -0.5$. Since $c_i \in \{1, 2, 3\}$, this holds if and only if the states are distinct. Second, the lexicographical objective (originally $\sum c_i 2^{2n-2i}$) was replaced by a sequential recurrence $F_i = 4F_{i-1} + c_i$. This evaluates to exactly the same base-4 integer. Reasoning models will unfold the recurrence, deduce it requires a lexicographically smallest sequence, and use efficient sequential backtracking. Pattern-matching models will likely misidentify it as a DP or full-state-space search problem and TLE, or fail to efficiently evaluate the trigonometric constraint.
</RATIONALE>
<PRESERVED_ANSWER>
The trigonometric equation holds strictly when $c_u \neq c_v$ for values in $\{1, 2, 3\}$, preserving the exact set of valid configurations, and the recurrence relation $F_n$ mathematically expands to $\sum_{i=1}^n c_i 4^{n-i}$, which is exactly equal to the seed's objective $\sum c_i 2^{2n-2i}$, ensuring the optimal configuration is identical.
</PRESERVED_ANSWER>
