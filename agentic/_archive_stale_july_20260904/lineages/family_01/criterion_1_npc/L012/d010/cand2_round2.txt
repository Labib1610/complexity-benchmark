<STATEMENT>
# Problem A — Orthogonal State Assignment

Time limit: 2 s
Memory limit: 256 MB

You are analyzing a system of $n$ quantum particles. Each particle $i$ (for $1 \le i \le n$) must be assigned a state vector $S_i$ from the standard basis in $\mathbb{R}^3$. Specifically, the allowed state vectors are $e_1 = (1,0,0)$, $e_2 = (0,1,0)$, and $e_3 = (0,0,1)$.

The system has $m$ entanglement constraints between specific pairs of particles. If particles $u$ and $v$ are entangled, their state vectors must be perfectly orthogonal to avoid interference. That is, the dot product of their state vectors must be zero: $S_u \cdot S_v = 0$. 

Your task is to assign a valid state vector to all $n$ particles. The output should be formatted as a sequence of integers $A = (a_1, a_2, \dots, a_n)$, where $a_i \in \{1, 2, 3\}$ corresponds to the index of the non-zero component of the state vector $S_i$ (i.e., $S_i = e_{a_i}$).

If multiple valid assignments exist, you must output the sequence $A$ that is lexicographically smallest. A sequence $A$ is lexicographically smaller than sequence $B = (b_1, b_2, \dots, b_n)$ if there exists an index $k$ ($1 \le k \le n$) such that $a_k < b_k$, and for all $i < k$, $a_i = b_i$.

If it is impossible to assign state vectors to all particles without violating at least one entanglement constraint, you must declare the assignment impossible. 

*Note: Naive enumeration of the up to $3^{40}$ possible state sequences will exceed the time limit. Your approach must efficiently bypass invalid configurations.*

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating an entanglement constraint between particle $u$ and particle $v$.

## Output
If no valid assignment can be formed, output exactly one line containing the word `NO`.
If a valid assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers from the set $\{1, 2, 3\}$, representing the sequence $A$ for the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<PRESERVED_ANSWER>
The condition that two standard basis vectors have a dot product of zero is mathematically identical to requiring that their indices are different, which exactly mirrors the original inequality constraint.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains identical to finding the lexicographically smallest 3-coloring of a graph, preserving its NP-complete nature.
