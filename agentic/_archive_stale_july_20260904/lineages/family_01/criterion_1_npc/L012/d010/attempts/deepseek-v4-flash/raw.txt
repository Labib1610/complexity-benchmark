 We need to assign each node a value from {1, 2, 3} such that adjacent nodes have different values, and among all valid assignments, we minimize the lexicographically weighted sum where earlier positions have much higher weight (4^(n-i)).  

This is essentially a graph coloring problem with 3 colors, and we want the lexicographically smallest coloring (since 4^(n-i) heavily prioritizes earlier positions).  

We can solve it with backtracking, trying smallest possible color for each node in order, and checking constraints. Since n ≤ 40, backtracking with pruning should be fine if the graph is not too dense, but worst-case could be heavy. However, 3-coloring is NP-hard in general, but with n=40 and constraints, we can use backtracking with forward checking.  

We'll implement a recursive function that tries colors 1, 2, 3 for each node in order, checking adjacency constraints, and backtracking if needed.  

Here’s the code:  

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n
found = False

def dfs(idx):
    global found
    if idx == n:
        return True
    for c in (1, 2, 3):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if dfs(idx + 1):
                return True
            color[idx] = 0
    return False

if dfs(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
