**Solution Explanation**

For every operation `i` we have to choose a tier `a_i ∈ {1,2,3}`.
For every given pair `(u,v)` the tiers must be different.
Among all feasible assignments we need the one with the smallest value  

```
P = a1·4^(n-1) + a2·4^(n-2) + … + an·4^0
```

`4` is larger than the maximal tier (`3`), therefore the value is
lexicographically ordered:
the earlier positions are far more important than the later ones.
Consequently we have to minimise the sequence `(a1,a2,…,an)` in the
usual lexicographic order.

--------------------------------------------------------------------

#### 1.   Observations  

* `n ≤ 40` – small enough for exponential backtracking with good pruning.
* The graph is arbitrary, 3‑colourability is NP‑complete, but for `n=40`
  a well‑pruned depth‑first search finishes instantly.
* Because we need the lexicographically smallest colour sequence,
  the vertices **must be coloured in the fixed order** `1,2,…,n`.
  We cannot reorder them (e.g. DSATUR) – otherwise we could obtain a
  different sequence.

--------------------------------------------------------------------

#### 2.   State kept during the search  

* `col[i]` – already fixed colour (`0` = not coloured yet, otherwise `1..3`).
* `mask[i]` – bitmask of still possible colours for vertex `i`
  (`bit 0 → colour 1`, `bit 1 → colour 2`, `bit 2 → colour 3`).
  Initially `mask[i] = 0b111` for all vertices.

When we assign colour `c` to vertex `v`

```
col[v] = c
for every neighbour u of v that is still uncoloured:
        if mask[u] contains c:
                remove c from mask[u]
                remember the old mask (for backtracking)
                if mask[u] becomes 0 → contradiction → backtrack
```

All changes are stored in a list `changes` so that they can be undone
when the recursion returns.

--------------------------------------------------------------------

#### 3.   Recursive search  

```
dfs(pos):
        # pos = next vertex index to colour (0‑based)
        if pos == n:   # all vertices coloured
                return True
        v = pos                     # vertex number = pos (0‑based)
        for colour c from 1 to 3 (in increasing order):
                if mask[v] allows c:
                        apply assignment (with propagation)
                        if dfs(pos+1):
                                return True
                        undo all changes of this trial
        return False
```

Because colours are tried in increasing order, the first complete
colouring found is the lexicographically smallest one.

The propagation described above is the only pruning used.
With `n = 40` it is more than enough: each step reduces the domain of
neighbours, many branches die early.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff the instance is not
3‑colourable, otherwise it prints `YES` and the lexicographically
minimum feasible colour sequence.

---

##### Lemma 1  
During the execution of `dfs(pos)` the arrays `col` and `mask`
always represent a **partial proper colouring** of the first `pos`
vertices:  
* every coloured vertex has a colour from its mask,  
* no edge whose both ends are already coloured has equal colours,
* every uncoloured vertex’s mask contains exactly the colours that are
  still possible respecting the already fixed colours.

**Proof.**  
Initially all masks are `{1,2,3}` and no vertex is coloured – the
statement holds.

Assume it holds before assigning colour `c` to vertex `v = pos`.
`c` is taken from `mask[v]`, therefore it is allowed.
For each neighbour `u` of `v` we delete `c` from `mask[u]`.  
If `u` is already coloured, it cannot have colour `c` because the edge
`(v,u)` would then be monochromatic – such a situation never occurs
(because we would have backtracked earlier).  
If `u` is uncoloured, removing `c` exactly reflects the new restriction
imposed by the colour of `v`. No other masks are changed.
Thus the invariant is preserved. ∎



##### Lemma 2  
If `dfs(pos)` returns `True`, the colours stored in `col` form a proper
3‑colouring of the whole graph.

**Proof.**  
`True` is returned only when the recursion reaches `pos == n`,
i.e. every vertex received a colour.
By Lemma&nbsp;1 the partial colouring is proper at each step, therefore
the final full colouring is proper. ∎



##### Lemma 3  
If a proper 3‑colouring exists that extends the already fixed colours
for vertices `0 … pos‑1`, then `dfs(pos)` will eventually return `True`.

**Proof.**  
Consider any such extension. Its colour for vertex `pos` is allowed by
`mask[pos]` (Lemma&nbsp;1). The algorithm tries colours in the order
`1,2,3`; when it reaches the colour used in the extension, the propagation
does not create a contradiction (because the extension itself is
consistent). Hence the recursive call `dfs(pos+1)` is invoked with a
state that still admits the remaining part of the extension.
By induction on `pos` the recursion finally reaches `pos = n` and returns
`True`. ∎



##### Lemma 4  
If `dfs(pos)` returns `False`, **no** proper 3‑colouring exists that
extends the already fixed colours for vertices `0 … pos‑1`.

**Proof.**  
`False` is returned only after trying every colour `c` allowed by
`mask[pos]`. For each such colour the algorithm either detects an
immediate contradiction (some neighbour mask becomes empty) or the
recursive call `dfs(pos+1)` returns `False`. By the induction hypothesis
the latter means that no extension exists after fixing that colour.
Thus for every possible colour of vertex `pos` no full extension exists,
hence none exists at all. ∎



##### Lemma 5  
The first complete colouring found by the algorithm is the
lexicographically smallest feasible colouring.

**Proof.**  
The algorithm processes vertices in order `0 … n‑1` and, for each
vertex, tries colours `1,2,3` in increasing order.
Because of Lemma&nbsp;3, as soon as a colour `c` leads to a feasible
completion, the recursion returns `True` and no larger colour for that
vertex is ever examined.
Therefore the colour chosen for vertex `0` is the smallest possible
among all feasible colourings; given that choice, the colour for vertex
`1` is the smallest possible, and so on.
Consequently the obtained full sequence is lexicographically minimal. ∎



##### Theorem  
The program outputs  

* `NO` **iff** the input graph is not 3‑colourable,  
* otherwise `YES` followed by the lexicographically smallest
  proper 3‑colouring.

**Proof.**  

*If the program prints `YES`.*  
It printed `YES` only after `dfs(0)` returned `True`.  
By Lemma&nbsp;2 the stored colours form a proper 3‑colouring.
By Lemma&nbsp;5 this colouring is lexicographically minimal.

*If the program prints `NO`.*  
It printed `NO` only because `dfs(0)` returned `False`.  
By Lemma&nbsp;4 no proper 3‑colouring exists extending the (empty) prefix,
i.e. no proper 3‑colouring exists at all.

Conversely, if the graph is not 3‑colourable, any execution of `dfs(0)`
must eventually explore all possibilities and return `False`
(Lemma&nbsp;3’s contrapositive), so the program prints `NO`. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

`n ≤ 40`, `m ≤ n·(n‑1)/2`.

*Each recursive step*  
* tries at most 3 colours,
* for the chosen colour touches all incident edges once,
  i.e. `O(deg(v))` work,
* stores at most `deg(v)` mask changes.

Overall work is bounded by the number of visited nodes in the search
tree times `O(m)`. In the worst case the tree size is `3^n`,
but the strong forward‑checking pruning makes the explored part tiny
for `n = 40`. Empirically the program finishes well within the limits.

Memory consumption:  
`col` (40 integers) + `mask` (40 integers) + adjacency list (`2m`
integers) + recursion stack (`n` levels) → far below 256 MB.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    col = [0] * n                     # 0 = uncoloured, else 1..3
    mask = [0b111] * n               # bits 0,1,2 correspond to colours 1,2,3

    # recursion
    def dfs(pos: int) -> bool:
        if pos == n:
            return True
        v = pos
        allowed = mask[v]
        for c in (1, 2, 3):
            bit = 1 << (c - 1)
            if not (allowed & bit):
                continue
            # apply colour c to v
            col[v] = c
            changes = []               # list of (vertex, old_mask)
            ok = True
            for nb in adj[v]:
                if col[nb]:
                    if col[nb] == c:   # already coloured same -> conflict
                        ok = False
                        break
                else:
                    if mask[nb] & bit:
                        old = mask[nb]
                        new = old & ~bit
                        if new == 0:
                            ok = False
                            break
                        mask[nb] = new
                        changes.append((nb, old))
            if ok and dfs(pos + 1):
                return True
            # undo
            for nb, old in reversed(changes):
                mask[nb] = old
            col[v] = 0
        return False

    if dfs(0):
        print("YES")
        print(' '.join(str(col[i]) for i in range(n)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
