<STATEMENT>
# Problem A — Risk Audit

Time limit: 2 s
Memory limit: 256 MB

You are conducting a regulatory review on a sequential ledger of financial operations. The ledger contains $n$ operations, indexed $1$ through $n$. Your task is to assign a security level $c_i$ to each operation $i$. The only permitted security levels are the integers $1$, $2$, and $3$.

The audit data provides $m$ regulatory constraints, each linking a specific pair of operations. To maintain strict compliance, no two operations connected by a constraint may be assigned the same security level. If any constrained pair shares a security level, the audit immediately fails.

Your objective is to determine a fully compliant security level assignment for all $n$ operations. If multiple compliant assignments exist, regulations require you to output the one that is lexicographically smallest. An assignment sequence $A = (a_1, a_2, \dots, a_n)$ is strictly lexicographically smaller than another sequence $B = (b_1, b_2, \dots, b_n)$ if, at the first index $k$ where they differ ($1 \le k \le n$), the condition $a_k < b_k$ holds (meaning $a_i = b_i$ for all $i < k$).

If no such compliant assignment is possible, you must declare the audit impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the total number of operations and the number of regulatory constraints, respectively.

**Performance Warning:** The constraints may form adversarial structures. Hidden tests include worst-case compliant and non-compliant configurations for which fixed-order brute-force search will time out. Solutions must use an approach with a worst-case guarantee within the stated limits.

Following this are $m$ lines. Each line provides two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating a regulatory constraint between operation $u$ and operation $v$.

## Output
If no compliant assignment can be formed, output exactly one line containing the word `NO`.
If a valid assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers from the set $\{1, 2, 3\}$, representing the security levels assigned to operations $1$ through $n$ in the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
