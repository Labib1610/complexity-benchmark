<STATEMENT>
# Problem A — Crystal Resonance

Time limit: 2 s
Memory limit: 256 MB

You are calibrating a network of $n$ synthetic crystals, indexed from $1$ to $n$. For each crystal $i$, you must assign a discrete harmonic state $p_i$. There are exactly three harmonic states available, represented by the integer values $1$, $2$, and $3$.

The network contains $m$ resonance channels, each connecting a pair of crystals $u$ and $v$. If two connected crystals are assigned harmonic states such that the product of their states ($p_u \cdot p_v$) has an odd number of positive integer divisors, they will create a standing wave and shatter. To maintain structural integrity, every pair of crystals connected by a resonance channel must have a harmonic state product that yields an even number of positive integer divisors.

Your objective is to find a valid calibration of harmonic states for the entire network that does not shatter any crystals. If multiple valid configurations exist, you must choose the one that minimizes the final thermal dissipation of the system. The thermal dissipation is computed sequentially. Let $D_i$ be the dissipation after calibrating the first $i$ crystals. The sequence is defined as follows:
- The initial state is $D_0 = 0$.
- For each crystal $i$ from $1$ to $n$, the dissipation updates according to the relation $D_i = 4 \cdot D_{i-1} + p_i$.

You must output the configuration that minimizes the final value $D_n$. If no valid configuration is possible without shattering crystals, you must report that it is impossible.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$) — the number of crystals and the number of resonance channels.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), indicating a resonance channel between crystal $u$ and crystal $v$.

## Output
If a valid configuration is impossible, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers from the set $\{1, 2, 3\}$, representing the harmonic states for crystals $1$ through $n$ that minimize the final thermal dissipation $D_n$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Changed the dependency constraint to a number-theoretic condition (odd number of positive integer divisors), which perfectly maps to $p_u = p_v$ since the only perfect squares formed by multiplying two values from $\{1, 2, 3\}$ are $1 \times 1$, $2 \times 2$, and $3 \times 3$. Changed the objective function to a recursive Horner's method evaluation ($D_i = 4 \cdot D_{i-1} + p_i$) and removed the explicit note about its closed form. This forces the model to deduce the lexicographical nature of the objective in order to implement the necessary early-exit pruning, preventing naive exhaustive search from passing within the time limit.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that $p_u \cdot p_v$ has an even number of positive integer divisors strictly enforces $p_u \neq p_v$, and the recursive sequence $D_n$ evaluates exactly to $\sum_{i=1}^n p_i 4^{n-i}$, which strictly minimizes the lexicographically first valid assignment just like the seed problem.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
