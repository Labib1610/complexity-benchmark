# Problem A — Deployment Tiers

Time limit: 2 s   Memory limit: 256 MB

You are configuring a system containing $n$ microservices, which are indexed from 1 to $n$. Every microservice must be assigned to a security tier. The available tiers are positive integers strictly less than 4.

System diagnostics have flagged certain pairs of microservices that suffer from parallel execution vulnerabilities. To maintain system stability, the two microservices in any flagged pair are forbidden from running at the exact same security tier. Note that a microservice is not guaranteed to be distinct from its paired counterpart. A flagged pair might list the same microservice twice ($u = v$). In such a scenario, the microservice would need to operate at a different tier from itself, meaning no valid configuration can be achieved.

Your job is to establish a secure tier configuration for the entire system. When multiple valid configurations are possible, you must prioritize the one that assigns the smallest possible tier number to microservice 1. Any subsequent ties must be resolved by minimizing the tier of microservice 2, and so forth in ascending index order up to $n$. If no valid configuration can be established, you must report the failure.

## Input
The initial line specifies $n$ (the number of microservices) and $m$ (the number of flagged pairs), with limits $1 \le n \le 40$ and $0 \le m \le n(n-1)/2$.
Each of the next $m$ lines contains two integers $u$ and $v$. This denotes a parallel execution vulnerability between microservice $u$ and microservice $v$. It is entirely possible that $u = v$.

## Output
If the system cannot be successfully configured, output the word NO on a single line.
If a configuration is possible, output YES on the first line. On the next line, output $n$ space-separated integers indicating the tiers assigned to microservices 1 through $n$, respectively, conforming to the specified tie-breaking sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
