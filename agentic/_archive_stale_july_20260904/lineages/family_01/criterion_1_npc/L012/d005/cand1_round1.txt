# Problem A — Resonant Frequencies

Time limit: 2 s   Memory limit: 256 MB

You are designing a pavilion supported by $n$ pillars. Each pillar is assigned a unique index from $1$ to $n$. The pillars must each be manufactured using one of three available density grades, represented by the integers $1$, $2$, and $3$.

The foundation ring is divided into $8$ structural sections, and each section can house exactly $5$ pillar anchor points. The total number of pillars $n$ will be between $1$ and the maximum total capacity of all structural sections combined.

The pavilion is reinforced by $m$ rigid cross-beams. Each cross-beam connects a distinct pair of pillars. The number of cross-beams $m$ ranges from $0$ up to the total number of possible pairs of pillars. Wind tunnel tests show that if two pillars connected by a cross-beam are assigned the identical density grade, they will resonate at the same frequency and cause the cross-beam to shatter. Consequently, any two pillars joined by a cross-beam must be assigned strictly different density grades.

Your task is to find a valid density assignment for all $n$ pillars. If multiple valid assignments exist, you must select the one that assigns the smallest possible grade to pillar $1$. If there are still multiple candidates, choose the one that minimizes the grade for pillar $2$, and so forth, checking pillar by pillar up to pillar $n$. If no valid assignment can be found, you must state that it is impossible.

Please note that the numbering of the pillars in the test data can be adversarial. The tests include configurations where evaluating assignments strictly according to the tie-breaking order will encounter a massive number of locally consistent partial assignments before reaching either a contradiction or a complete design.

## Input
The first line contains two integers $n$ and $m$ — the number of pillars and the number of cross-beams.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), representing a cross-beam connecting pillar $u$ and pillar $v$.

## Output
If no valid assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ space-separated integers from the set $\{1, 2, 3\}$, representing the density grades for pillars $1$ through $n$, adhering to the specified tie-breaking rule.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
