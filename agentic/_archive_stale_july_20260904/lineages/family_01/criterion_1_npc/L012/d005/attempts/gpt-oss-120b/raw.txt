**Solution Explanation**

For every column we have to choose a colour `1 … 3`.
For every strut `(u , v)` the two ends must obtain different colours.
Among all proper colourings we need the lexicographically smallest
sequence  

```
c1 c2 … cn          (c1 is the most significant digit)
```

because the given weight `4^{n‑i}` is a strictly decreasing power of `4`.
So we only have to find the smallest proper 3‑colouring in the natural
order `1 … n`.

The graph has at most `40` vertices – small enough for a back‑tracking
search with simple pruning.



--------------------------------------------------------------------

#### 1.   Data structures

* `adj[i]` – list of neighbours of vertex `i` (0‑based indices).
* `col[i]` – already fixed colour (`0` = not fixed yet, otherwise `1‑3`).
* `mask[i]` – bit mask of still possible colours for vertex `i`.
  bit `0` → colour `1`, bit `1` → colour `2`, bit `2` → colour `3`.

`mask[i]` is initialised with `0b111` (all three colours possible).

--------------------------------------------------------------------

#### 2.   Propagation after fixing a colour

When we set `col[v] = c`

```
for each neighbour w of v:
        delete colour c from mask[w]
        if mask[w] becomes 0 -> contradiction
```

The deletion is a simple bit operation.
If a neighbour loses its last possible colour we backtrack immediately.

--------------------------------------------------------------------

#### 3.   Recursive search  

`dfs(pos)` – try to colour vertices `pos … n‑1`
(`pos` is the first still uncoloured vertex, i.e. the smallest index).

```
if pos == n:   # all vertices coloured
        success
choose vertex v = pos                # forced by lexicographic order
for colour c = 1,2,3 (in this order):
        if c is allowed by mask[v]:
                remember current masks of all neighbours (to restore later)
                set col[v] = c
                delete c from neighbours' masks (propagation)
                if no contradiction:
                        if dfs(pos+1) succeeds -> propagate success
                restore masks of neighbours
                col[v] = 0
return failure
```

Because we always try colours `1,2,3` in increasing order,
the first complete assignment found is the lexicographically smallest
one.

The recursion depth is at most `40`.  
The only work inside a call is scanning the adjacency list of the
current vertex, i.e. `O(deg(v))`.  
Overall the algorithm is exponential in the worst case (3‑colourability
is NP‑complete) but with `n ≤ 40` it easily fits into the limits
(the search space is heavily pruned by the propagation).

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically
smallest proper colouring iff such a colouring exists.

---

##### Lemma 1  
During the search `mask[i]` always contains exactly the colours that can
still be assigned to vertex `i` without violating already fixed colours.

**Proof.**  
Initially all three colours are possible, so the statement holds.
When a vertex `v` gets colour `c`, the algorithm removes `c` from the
mask of every neighbour `w`. Any proper colouring extending the current
partial assignment cannot give `w` colour `c`, therefore `c` must be
removed. No other colours are removed, and no colour is added later.
Thus the invariant is preserved. ∎



##### Lemma 2  
If the algorithm reaches a contradiction (some `mask[w] = 0`) then the
current partial assignment cannot be extended to a proper full
colouring.

**Proof.**  
By Lemma&nbsp;1 `mask[w] = 0` means *no* colour is compatible with the
already fixed neighbours of `w`. Any extension would have to give `w`
some colour, which would conflict with a neighbour. Hence extension is
impossible. ∎



##### Lemma 3  
Whenever `dfs(pos)` returns *success*, the array `col` is a proper
3‑colouring of the whole graph.

**Proof.**  
Success is returned only when `pos == n`, i.e. every vertex received a
colour. While assigning a colour we never allowed a neighbour to keep
the same colour (propagation removed it). Therefore all edges connect
different colours – the colouring is proper. ∎



##### Lemma 4  
If a proper 3‑colouring exists, `dfs(0)` eventually returns success.

**Proof.**  
Consider any proper colouring `C`. The recursion explores vertices in
order `0,1,…`. For vertex `v` it tries colours `1,2,3` in this order.
Because `C` is proper, the colour `C(v)` is still present in `mask[v]`
when the call for `v` is entered (otherwise a neighbour would already
have the same colour, contradicting propriety). Hence the branch that
chooses exactly `C(v)` is not pruned. Following this branch for all
vertices reproduces `C`, reaches `pos == n` and returns success. ∎



##### Lemma 5  
The first complete colouring found by the algorithm is the
lexicographically smallest proper colouring.

**Proof.**  
The search is depth‑first and respects the vertex order.
At each vertex it tries colours `1,2,3` in increasing order.
Therefore the search enumerates all proper colourings in
lexicographic order and stops at the first one. ∎



##### Theorem  
The program outputs  

* `NO` iff the graph is not 3‑colourable;  
* otherwise `YES` and the lexicographically smallest proper colouring.

**Proof.**  

*If the program prints `YES`.*  
By Lemma&nbsp;3 the printed assignment is a proper colouring.
By Lemma&nbsp;5 it is the lexicographically smallest one.

*If the program prints `NO`.*  
That means `dfs(0)` failed. By Lemma&nbsp;4, if a proper colouring existed
`dfs(0)` would succeed. Hence no proper 3‑colouring exists.

Conversely, if the graph is not 3‑colourable, any search must fail,
so the program prints `NO`. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*`n ≤ 40`, `m ≤ n(n‑1)/2`.*

Let `d(v)` be the degree of vertex `v`.

* each recursive call processes vertex `v` and scans its adjacency list:
  `O(d(v))`.
* total work is `O( Σ d(v) ) = O(m)` per visited node of the search tree.

The size of the search tree is bounded by `3^n` in the worst case,
but strong pruning makes it tiny for the given limits.
Memory consumption:  

* adjacency lists `O(m)`,  
* arrays `col`, `mask` of size `n`.  

All well below the limits.

#### 6.   Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    col = [0] * n               # 0 = uncoloured, else 1..3
    mask = [0b111] * n          # three bits, 1<<0 -> colour 1, etc.

    # depth‑first search
    def dfs(pos: int) -> bool:
        if pos == n:
            return True
        v = pos
        allowed = mask[v]
        for c in (1, 2, 3):
            bit = 1 << (c - 1)
            if not (allowed & bit):
                continue
            # remember neighbours' masks to restore later
            changed = []
            ok = True
            for nb in adj[v]:
                if col[nb] == 0 and (mask[nb] & bit):
                    old = mask[nb]
                    new = old & ~bit
                    if new == 0:
                        ok = False
                        break
                    mask[nb] = new
                    changed.append((nb, old))
            if ok:
                col[v] = c
                if dfs(pos + 1):
                    return True
                col[v] = 0
            # restore
            for nb, old in changed:
                mask[nb] = old
        return False

    possible = dfs(0)
    out = []
    if not possible:
        out.append("NO")
    else:
        out.append("YES")
        out.append(" ".join(str(col[i]) for i in range(n)))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above
and conforms to the required input‑output format.
