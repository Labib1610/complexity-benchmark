 We need to assign each node a value from {1, 2, 3} such that adjacent nodes have different values, and we want the lexicographically smallest assignment.

This is essentially a graph coloring problem with 3 colors. Since n ≤ 40, we can use backtracking with pruning.

**Approach:**
1. Build adjacency list from input.
2. Use backtracking to assign colors to nodes in order 1..n.
3. At each step, try colors 1, 2, 3 in order, check if any neighbor already has that color.
4. If we reach the end, we have a valid coloring.
5. Since we try colors in increasing order, the first complete assignment is lexicographically smallest.

We also need to handle the case where no valid coloring exists.

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

colors = [0] * n

def backtrack(idx):
    if idx == n:
        return True
    for c in range(1, 4):
        ok = True
        for nb in adj[idx]:
            if colors[nb] == c:
                ok = False
                break
        if ok:
            colors[idx] = c
            if backtrack(idx + 1):
                return True
            colors[idx] = 0
    return False

if backtrack(0):
    print("YES")
    print(" ".join(map(str, colors)))
else:
    print("NO")
```
