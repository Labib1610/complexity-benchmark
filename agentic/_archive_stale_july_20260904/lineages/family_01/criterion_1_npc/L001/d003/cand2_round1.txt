<STATEMENT>
# Problem A — Uplink Frequency Allocation

Time limit: 2 s
Memory limit: 256 MB

A telecommunications operator manages a set of satellite uplinks. Each uplink is uniquely identified by an integer starting from $1$ up to the total number of uplinks in the system.

To ensure reliable data transmission, the operator must assign each uplink to exactly one of three available frequency bands, designated as Band 1, Band 2, and Band 3.

During field testing, engineers identified pairs of uplinks that have overlapping geographical footprints. If any two such uplinks broadcast on the same frequency band, critical signal cross-talk will occur. Consequently, these overlapping pairs must never share a band.

The network controller requires a complete configuration to initialize the system. A configuration specifies the band assigned to each uplink. The controller evaluates every possible collision-free configuration by writing down the band assigned to uplink 1, followed by the band for uplink 2, and so on, concatenating them into a single sequence of digits to form a large number. To guarantee a deterministic outcome, the system mandates the configuration that results in the smallest possible value for this large number. If no collision-free configuration is possible, the controller must trigger a deployment abort.

Your task is to determine the required configuration sequence or identify if the deployment must be aborted.

## Input
The first line contains two integers: the number of satellite uplinks (at least $1$, and at most the number of thieves in the classic tale of Ali Baba) and the number of overlapping pairs (from $0$ up to the maximum number of distinct pairs that can be formed from the given uplinks).
The following lines, one for each overlapping pair, contain two integers representing a pair of uplinks that share a footprint and cannot use the same frequency band.

## Output
If the deployment must be aborted because no collision-free configuration is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print the sequence of integers (each being 1, 2, or 3) separated by spaces, representing the band assigned to each uplink in order from 1 to the total number of uplinks, corresponding to the mandated configuration.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit numeric bounds were replaced with indirect references (Ali Baba's thieves for 40, and the maximum possible pairs for n(n-1)/2) to fulfill Strategy S07. The explicit "lexicographically smallest" affordance was removed and replaced by a policy that selects the configuration forming the smallest numerical value when concatenated as a single large number. This forces the model to deduce that sequential ordered backtracking is still the correct approach without being handed the exact algorithmic trigger words.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to find the smallest numerical value of the concatenated assignments exactly corresponds to finding the lexicographically smallest sequence of band assignments, ensuring the same unique valid output or "NO".
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 3-coloring of a graph, which is NP-complete, with a deterministic tie-breaking rule.
</PRESERVED_CLASS>
<RISK>
Models might overthink the "large number" phrasing and attempt to use big-integer libraries to evaluate complete sequences, leading to timeouts if they abandon the greedy backtracking approach.
</RISK>
