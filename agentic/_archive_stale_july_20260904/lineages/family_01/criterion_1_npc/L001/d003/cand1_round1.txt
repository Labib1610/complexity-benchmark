# Problem A — Uplink Frequency Allocation

Time limit: 2 s   Memory limit: 256 MB

An orbital communications network consists of $n$ satellite uplinks, numbered $1$ through $n$. Due to signal dispersion, $m$ specific pairs of uplinks have intersecting broadcast zones. If a pair with intersecting zones is tuned to the same frequency, destructive interference will occur. Therefore, it is strictly required that these pairs are tuned to different frequencies.

Each uplink must be tuned to exactly one of three operational frequencies, labeled 1, 2, and 3. A full initialization profile consists of $n$ integers, where the $i$-th value is the frequency assigned to the $i$-th uplink.

To guarantee a deterministic initialization, the automated system evaluates the set of all interference-free profiles. The system is programmed to mandate the single profile that would appear first if the entire set of valid profiles were sorted in standard dictionary order. If the set of interference-free profiles is empty, the system must abort the initialization.

Your task is to determine this mandated profile or report if an abort is strictly necessary.

## Input
The first line contains two integers $n$ and $m$ — the number of uplinks and the number of intersecting zones ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$, indicating that uplink $u$ and uplink $v$ have an intersecting broadcast zone and must use different frequencies.

## Output
If an abort is necessary because no interference-free profile exists, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $f_1, f_2, \dots, f_n$ (with each $f_i \in \{1, 2, 3\}$), representing the frequency assigned to the $i$-th uplink. This profile must be the one that appears first in dictionary order among all valid profiles.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The description of the lexicographical tie-breaker was rewritten to frame it as a global selection from the complete set of valid deployments, rather than an element-by-element sequential comparison. This removes the surface-level affordance that directly suggested an ordered sequential backtracking logic, forcing models to infer that an ordered DFS will still yield the globally optimal dictionary-ordered result.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to output the profile that appears first in dictionary order is mathematically identical to outputting the lexicographically smallest sequence, ensuring all answers remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
Models might interpret "standard dictionary order" as applying to strings rather than sequences of integers, though since the domain is {1, 2, 3}, string and integer lexicographical orders are identical.
</RISK>
