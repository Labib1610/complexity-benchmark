<METHOD_NAME>COMBINATORIAL_ISOMORPHISM_OBFUSCATION</METHOD_NAME>
<METHOD_DESCRIPTION>Translates a recursive arithmetic cascade (which trivially reveals positional power-of-four weights via symbolic execution) into an isomorphic combinatorial path-sum over subsets. The weights are mathematically identical ($4^{n-i}$), but models relying on shallow pattern matching will implement the path-sum literally in their backtracking search. Since they fail to recognize the lexicographical dominance, they will not early-exit and will consequently TLE on the search space.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Orbital Network Frequency Coordination

Time limit: 2 s   Memory limit: 256 MB

A telecommunications agency is configuring a network of $n$ satellite transmitters, numbered $1$ through $n$. Each transmitter must be assigned an operating band from the set $\{1, 2, 3\}$.

Geospatial analysis has identified $m$ pairs of transmitters with overlapping coverage areas. To prevent signal collision, any two transmitters in a listed pair must be assigned different operating bands.

A configuration is a sequence of $n$ band assignments, where the $i$-th value is the band assigned to transmitter $i$. The agency will only consider configurations that are completely free of signal collisions. If no such configuration exists, the setup is aborted.

If valid configurations do exist, the agency must deploy the single configuration that minimizes the network's total interference metric. 

The interference metric $M$ for a configuration is evaluated by calculating the baseline signal amplification. For each transmitter $i$, its amplification factor $H_i$ is the aggregate weight of all valid forward-cascading sequences starting at $i$.

A forward-cascading sequence starting at $i$ is a strictly increasing list of satellite indices $z_0, z_1, \dots, z_k$ such that $z_0 = i$ and $z_k \le n$. The number of jumps in the sequence is $k$. The weight of a sequence with $k$ jumps is $3^k$. Note that a sequence can have $k=0$ jumps (consisting only of the starting satellite $i$), which has a weight of $3^0 = 1$.

The amplification factor $H_i$ is the sum of the weights of all possible forward-cascading sequences that start at $i$. The total interference metric $M$ for the network is given by the sum of $b_i \times H_i$ for all $i$ from $1$ to $n$, where $b_i$ is the band assigned to transmitter $i$.

The agency operates a constellation of identical satellites. Due to orbital slot regulations, the maximum possible number of pairs that could theoretically overlap across the entire constellation is exactly 780. 

## Input
The first line contains two integers $n$ and $m$ — the number of satellite transmitters and the number of overlapping coverage pairs. The network consists of at least one transmitter, but $n$ will not exceed the constellation capacity derived from the 780 theoretical maximum overlaps. The number of pairs $m$ satisfies $0 \le m \le n(n-1)/2$.
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of transmitters that have overlapping coverage and must use different bands.

## Output
If no collision-free configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2, 3\}$), representing the band allocated to transmitter $i$. Output the configuration that minimizes the total interference metric.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I applied S07 by stating the upper bound for $n$ indirectly via the maximum number of theoretical overlaps (780 pairs implies $n=40$). I also used a novel aggressive technique to obfuscate the objective function: translating the recursive arithmetic cascade into an isomorphic combinatorial path-sum over subsets. This forces the model to either symbolically evaluate the subset sum to recognize the lexicographical dominance, or literally implement the path-sum in a backtracking search which will lead to a Time Limit Exceeded due to lacking early-exit pruning.
</RATIONALE>
<PRESERVED_ANSWER>
The combinatorial sum of weights for all forward-cascading sequences from $i$ evaluates exactly to $(1+3)^{n-i} = 4^{n-i}$, making the interference metric mathematically identical to the original problem for every possible configuration.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest valid 3-coloring of a graph, which is NP-complete.
</PRESERVED_CLASS>
<RISK>
The most likely way this could be judged ambiguous is if the definition of "forward-cascading sequence" is misunderstood, though the explicit mathematical notation $z_0 < z_1 < \dots < z_k \le n$ and the $k=0$ edge case clarify it precisely.
</RISK>
