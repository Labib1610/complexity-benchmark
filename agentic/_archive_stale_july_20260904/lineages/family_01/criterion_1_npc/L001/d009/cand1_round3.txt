# Problem A — Orbital Network Frequency Coordination

Time limit: 2 s   Memory limit: 256 MB

A telecommunications agency is configuring a network of $n$ satellite transmitters, numbered $1$ through $n$. Each transmitter must be assigned an operating band from the set $\{1, 2, 3\}$.

Geospatial analysis has identified $m$ pairs of transmitters with overlapping coverage areas. To prevent signal collision, any two transmitters in a listed pair must be assigned different operating bands.

A configuration is a sequence of $n$ band assignments, where the $i$-th value is the band assigned to transmitter $i$. The agency will only consider configurations that are completely free of signal collisions.

If valid configurations exist, the agency applies a strict priority system to choose the final deployment. Transmitters with lower indices are considered more critical and must be prioritized for lower-frequency bands. Specifically, among all collision-free configurations, the agency requires the one that assigns the smallest possible band to transmitter $1$. If there are multiple such configurations, the tie is broken by assigning the smallest possible band to transmitter $2$, and so on. 

In other words, you must find and deploy the exactly lexicographically smallest valid sequence of band assignments. If no collision-free configuration is possible, the setup is aborted.

## Input
The first line contains two integers $n$ and $m$ — the number of satellite transmitters and the number of overlapping coverage pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of transmitters that have overlapping coverage and must use different bands.

## Output
If no collision-free configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2, 3\}$), representing the band allocated to transmitter $i$. Output the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Following the expert critique, I completely removed the contrived mathematical cascade/metric that models were symbolically simulating to extract positional weights. Instead, I directly stated the mathematically identical requirement: finding the lexicographically smallest valid configuration. By removing the numerical objective function, models that rely on mapping the problem to a weighted optimization solver will be forced to adapt to a purely combinatorial priority search.
</RATIONALE>
<PRESERVED_ANSWER>
The original noise cascade mathematically evaluated to $M = \sum_{i=1}^n 4^{n-i} b_i$, meaning minimizing $M$ was exactly equivalent to finding the lexicographically smallest sequence of band assignments; thus, all outputs remain identical.
</PRESERVED_ANSWER>
