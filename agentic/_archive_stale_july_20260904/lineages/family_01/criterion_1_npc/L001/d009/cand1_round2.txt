<STATEMENT>
# Problem A — Orbital Network Frequency Coordination

Time limit: 2 s   Memory limit: 256 MB

A telecommunications agency is configuring a network of $n$ satellite transmitters, numbered $1$ through $n$. Each transmitter must be assigned an operating band from the set $\{1, 2, 3\}$.

Geospatial analysis has identified $m$ pairs of transmitters with overlapping coverage areas. To prevent signal collision, any two transmitters in a listed pair must be assigned different operating bands.

A configuration is a sequence of $n$ band assignments, where the $i$-th value is the band assigned to transmitter $i$. The agency will only consider configurations that are completely free of signal collisions. If no such configuration exists, the setup is aborted.

If valid configurations do exist, the agency must deploy the configuration that minimizes the network's total interference metric $M$. 

To compute $M$ for a configuration $b_1, b_2, \dots, b_n$, the agency models the system as a virtual feed-forward routing network of $n$ nodes, numbered $1$ through $n$. For every pair of nodes $u$ and $v$ where $u < v$, there are exactly 3 distinct routing channels directly connecting $u$ to $v$. 
Let $P(u, v)$ denote the total number of valid routing paths from node $u$ to node $v$. (A path may traverse any number of intermediate nodes, moving strictly from lower to higher numbered nodes). 
The routing weight $W_i$ for transmitter $i$ is defined as $1$ plus the sum of all paths from node $i$ to all strictly higher-numbered nodes: 
$$W_i = 1 + \sum_{v=i+1}^n P(i, v)$$
The total interference metric is then the weighted sum of the assigned bands: 
$$M = \sum_{i=1}^n b_i W_i$$

If multiple valid configurations achieve the exact same minimum metric $M$, you must break ties by selecting the configuration that is lexicographically smallest. (That is, compare the configurations starting from transmitter 1; at the first transmitter where they differ, the one with the smaller band number is preferred).

## Input
The first line contains two integers $n$ and $m$ — the number of satellite transmitters and the number of overlapping coverage pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of transmitters that have overlapping coverage and must use different bands.

## Output
If no collision-free configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $b_1, b_2, \dots, b_n$ (where each $b_i \in \{1, 2, 3\}$), representing the band allocated to transmitter $i$. Output the valid configuration that minimizes the total interference metric, applying the specified tie-breaker if necessary.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6

1 3
1 4

3 4
```
Output:
```
NO
```

<RATIONALE>
Replaced the explicit accumulator cascade with a procedural path-counting specification on a virtual feed-forward network. This removes the obvious power-of-four positional weights that models used to recognize the lexicographic shortcut, forcing them to treat it as a generic weighted optimization which will Time Limit Exceed. An explicit lexicographic tie-breaker was added to strictly satisfy the gate's requirement for a disambiguated minimizer.
</RATIONALE>
<PRESERVED_ANSWER>
The number of paths $P(u, v)$ evaluates to $3 \times 4^{v-u-1}$, which makes the weight $W_i$ exactly $4^{n-i}$, mathematically identical to the original accumulator cascade; therefore, the minimum metric configuration remains identically the lexicographically smallest valid assignment.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Graph 3-Coloring with a uniquely optimal sequence selection, preserving its NP-complete status.
</PRESERVED_CLASS>
<RISK>
The gate might still flag the objective as altered if it rigidly expects the phrase "lexicographically smallest" to be the sole primary objective rather than a tie-breaker, though mathematical equivalence and uniqueness are fully preserved.
</RISK>
