We need to assign each transmitter a band from {1,2,3} such that no edge connects two transmitters with the same band. Among all valid assignments, we must minimize the interference metric defined by the cascade process.

Let’s first understand the metric.  
We have:

- Initially: \( A_j = b_j \)
- For step \( k = 1 \) to \( n-1 \):  
  For all \( j > k \): \( A_j \leftarrow A_j + 3 \times A_k \)

This means each \( A_k \) contributes to all later accumulators.  
We can compute the final value of each \( A_j \):

- \( A_1 = b_1 \)
- \( A_2 = b_2 + 3 b_1 \)
- \( A_3 = b_3 + 3 b_2 + 3^2 b_1 \)
- In general:  
  \( A_j = b_j + 3 b_{j-1} + 3^2 b_{j-2} + \dots + 3^{j-1} b_1 \)

So the total metric:

\[
M = \sum_{j=1}^n A_j = \sum_{j=1}^n \sum_{i=1}^j 3^{j-i} b_i
\]

Swap the sums:

\[
M = \sum_{i=1}^n b_i \sum_{j=i}^n 3^{j-i}
\]

The inner sum is a geometric series:

\[
\sum_{j=i}^n 3^{j-i} = \frac{3^{n-i+1} - 1}{3 - 1} = \frac{3^{n-i+1} - 1}{2}
\]

So:

\[
M = \sum_{i=1}^n b_i \cdot \frac{3^{n-i+1} - 1}{2}
\]

Thus the weight for position \( i \) is:

\[
w_i = \frac{3^{n-i+1} - 1}{2}
\]

These weights are strictly decreasing as \( i \) increases (since \( 3^{n-i+1} \) decreases).  
So earlier positions have much larger weights.

Therefore, to minimize \( M \), we want the smallest possible band values in the earliest positions, subject to the graph constraints.

Since bands are only 1, 2, 3, we can do a greedy assignment from position 1 to n:  
At each position, try band 1, then 2, then 3, and pick the smallest that doesn’t conflict with already assigned neighbors.

If at some point no band works, output `NO`.

This greedy works because the weights are strictly decreasing, so minimizing earlier positions is always optimal.

Let’s implement this.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    bands = [0] * n
    
    for i in range(n):
        used = set()
        for nb in adj[i]:
            if bands[nb] != 0:
                used.add(bands[nb])
        for b in (1, 2, 3):
            if b not in used:
                bands[i] = b
                break
        else:
            print("NO")
            return
    
    print("YES")
    print(" ".join(map(str, bands)))

if __name__ == "__main__":
    solve()
```
