**Solution Explanation**

For every transmitter `i` we have to choose a band `b[i] ∈ {1,2,3}`.
For every given pair `(u,v)` the two bands must be different.
If a feasible assignment exists we have to output the one with the smallest
interference metric `M`.

--------------------------------------------------------------------

#### 1.   The metric `M`

The simulation described in the statement is linear:

```
A_j  =  b_j                     (initially)
for k = 1 .. n-1
        for j = k+1 .. n
                A_j += 3 * A_k
M = Σ A_j
```

All operations are additions and multiplications by the constant `3`,
therefore the final value of `M` is a **linear** function of the bands:

```
M = Σ  w[i] * b[i]          (1)
```

The coefficients `w[i]` depend only on the position `i` (the order of the
transmitters) and on `n`, never on the concrete assignment.
They can be obtained once by a direct simulation with symbolic values
`b[i] = 1` and reading the contribution of each position.

For the optimisation problem (1) the only thing that matters are the
coefficients `w[i]`.  
For `n ≤ 40` they are strictly decreasing:

```
w[1]  >> w[2]  >> … >> w[n]
```

Consequently the optimal assignment is the **lexicographically smallest**
sequence `(b[1], b[2], … , b[n])` among all proper 3‑colourings.
(If two assignments differ first at position `i`,
the one with the smaller colour at `i` has a smaller value of (1) because
`w[i]` already dominates the total contribution of all later positions.)

So we only have to find the lexicographically smallest proper 3‑colouring.

--------------------------------------------------------------------

#### 2.   Searching the lexicographically smallest 3‑colouring  

`n ≤ 40` – a tiny number.  
A depth‑first search that tries the colours `1,2,3` **in this order**
for the transmitters `1,2,…,n` automatically explores the colourings
lexicographically.  
The first complete colouring found is therefore the required optimum.

The search is heavily pruned by the obvious condition:

```
when we want to colour vertex v with colour c
    it must differ from every already coloured neighbour of v
```

If no colour is possible we backtrack.
The recursion depth never exceeds `n = 40`.

The algorithm is exact – it tries *all* possibilities that respect the
already fixed prefix, therefore it finds a solution iff one exists.

The worst case (completely empty graph) finishes instantly because colour
`1` works for every vertex.
The hardest case for a backtracking algorithm would be a dense graph that
*is* 3‑colourable, but even there the branching factor quickly drops to `1`
once the three colour classes are forced.

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible configuration exists,
otherwise it prints `YES` and the configuration with the minimum metric `M`.

---

##### Lemma 1  
For a fixed `n` the coefficients `w[1] > w[2] > … > w[n]` are positive.

**Proof.**  
During the simulation each `A_k` is added (multiplied by `3`) to *all*
later accumulators, therefore every original band `b[i]` contributes a
positive amount to every `A_j` with `j ≥ i`. Summation over all `j`
gives a positive coefficient for each `i`. The earlier the position,
the more later accumulators receive the contribution, hence the coefficient
is larger. ∎



##### Lemma 2  
Let `C` and `C'` be two proper colourings and let `p` be the smallest index
with `C[p] ≠ C'[p]`.  
If `C[p] < C'[p]` then `M(C) < M(C')`.

**Proof.**  
From (1)  

```
M(C) - M(C') = w[p]·(C[p]-C'[p]) + Σ_{i>p} w[i]·(C[i]-C'[i])
```

The first term is negative because `C[p] < C'[p]` and `w[p] > 0`.  
All later terms are bounded in absolute value by  

```
| Σ_{i>p} w[i]·(C[i]-C'[i]) | ≤ 2· Σ_{i>p} w[i]          (colours differ at most by 2)
```

By Lemma&nbsp;1 `w[p]` is larger than that sum, therefore the whole
difference is negative, i.e. `M(C) < M(C')`. ∎



##### Lemma 3  
Among all proper colourings the lexicographically smallest colour sequence
has the smallest metric `M`.

**Proof.**  
Take any optimal colouring `C*`.  
If it is not lexicographically smallest, there exists another proper
colouring `C` that is lexicographically smaller.
Let `p` be the first index where they differ.
By Lemma&nbsp;2 `M(C) < M(C*)`, contradicting optimality of `C*`. ∎



##### Lemma 4  
The depth‑first search explores colourings in lexicographic order and
returns the first complete proper colouring it finds.

**Proof.**  
The recursion processes vertices in the fixed order `1,2,…,n`.  
For a vertex it tries colours `1,2,3` in this order and recurses before
trying the next colour.  
Thus the search tree corresponds exactly to the lexicographic ordering of
the colour sequences, and the first leaf reached is the lexicographically
smallest proper colouring. ∎



##### Lemma 5  
If the algorithm outputs `YES` and a colouring `C`, then `C` is a proper
3‑colouring of the given graph.

**Proof.**  
A colour is assigned to a vertex only after checking that it differs from
all already coloured neighbours.  
Induction over the recursion depth shows that after each assignment all
edges whose both ends are already coloured satisfy the inequality.
When the recursion finishes, every vertex is coloured, therefore *all*
edges satisfy the condition. ∎



##### Lemma 6  
If a proper 3‑colouring exists, the algorithm outputs `YES`.

**Proof.**  
Consider any proper colouring `C`.  
During the search, when the algorithm reaches vertex `i` it tries colours
`1,2,3`.  
Because `C[i]` is one of them and it does not conflict with already coloured
neighbours (which are exactly the vertices `1..i-1` already fixed to the same
values as in `C` by the induction hypothesis), the branch using colour
`C[i]` is never pruned.  
Consequently the recursion can follow the whole sequence `C` and reaches a
leaf, so the algorithm will find a solution and output `YES`. ∎



##### Lemma 7  
If the algorithm outputs `NO`, no proper 3‑colouring exists.

**Proof.**  
`NO` is printed only after the complete backtracking search has examined
every possible colour assignment that respects the adjacency constraints
for the already processed prefix and found none that can be extended to a
full colouring.  
If a proper colouring existed, Lemma&nbsp;6 guarantees that the search
would have followed its prefix and finally discovered it – contradiction. ∎



##### Theorem  
The program

* prints `NO` **iff** the graph is not 3‑colourable,
* otherwise prints `YES` and a colouring that minimises the interference
  metric `M`.

**Proof.**  
*If part*: by Lemma&nbsp;7.  
*Only‑if part*: by Lemma&nbsp;6 the algorithm finds a colouring whenever one
exists, therefore it never prints `NO` in that case.

When a colouring is printed, Lemma&nbsp;5 shows it is proper.
By Lemma&nbsp;4 it is the lexicographically smallest proper colouring,
and by Lemma&nbsp;3 this colouring has the smallest possible metric `M`. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Pre‑computation of the coefficients* – `O(n²)` (simple simulation).  
*Backtracking search* – in the worst case `O(3^n)`, but with `n ≤ 40`
and the strong pruning described above it easily fits into the limits.
Memory consumption is `O(n + m)` for the adjacency lists and the recursion
stack (`≤ n`).

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    # ---------- 1. compute weights w[i] ----------
    # symbolic simulation: start with A[i] = x_i (different symbols)
    # we only need the total contribution of each x_i to the final sum.
    # Use integer arithmetic: treat each x_i as 1 and later multiply by its
    # coefficient.
    # Simpler: run the process with concrete numbers 1..n and then solve a
    # linear system? Not needed – we can compute contributions directly.
    # We'll simulate with an array coeff[i] = contribution of b[i] to current A[i].
    # Initially coeff[i] = 1 (A_i = 1 * b_i).
    coeff = [1] * n          # coefficient of b[i] inside A_i at current step
    # after each step k, we add 3 * A_k to later A_j, i.e. their coefficients
    # increase by 3 * coeff[k].
    for k in range(n - 1):
        inc = 3 * coeff[k]
        for j in range(k + 1, n):
            coeff[j] += inc
    # final metric M = sum_i coeff[i] * b_i
    w = coeff                # already the needed weights

    # ---------- 2. backtracking search ----------
    colour = [0] * n          # 0 = unassigned, otherwise 1..3
    found = False

    # order of processing: natural order 0..n-1 (weights decreasing)
    def dfs(v: int) -> bool:
        nonlocal found
        if v == n:
            return True
        # try colours 1,2,3 in order
        for c in (1, 2, 3):
            ok = True
            for nb in adj[v]:
                if nb < v and colour[nb] == c:   # only already coloured neighbours
                    ok = False
                    break
            if not ok:
                continue
            colour[v] = c
            if dfs(v + 1):
                return True
            colour[v] = 0
        return False

    if dfs(0):
        # we have the lexicographically smallest proper colouring
        print("YES")
        print(' '.join(map(str, colour)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
