**Solution Explanation**

For every station we have to choose a frequency `1 … 3`.
For each given pair `(u , v)` the two stations must obtain different
frequencies.
Among all feasible assignments we need the one with the smallest value of  

```
S = f1·4^(n‑1) + f2·4^(n‑2) + … + fn·4^0
```

`4` is larger than the maximal frequency (`3`), therefore the
lexicographically smallest sequence `(f1 , f2 , … , fn)` is exactly the
assignment with minimal `S`.  
So we only have to find the lexicographically smallest proper 3‑colouring
of the given graph.

`n ≤ 40`, therefore a simple depth‑first search with backtracking is fast
enough:

* stations are processed in the natural order `1 … n`;
* for the current station we try the colours `1, 2, 3` in this order;
* a colour is allowed iff none of the already coloured neighbours has the
  same colour;
* as soon as a complete colouring is found we stop – it is already the
  lexicographically smallest one.

The recursion depth is at most `40`.  
The worst case (a complete graph `K40`) is not 3‑colourable; the search
fails very early because the first three stations already need three
different colours, the fourth one already has no colour left.
All realistic inputs finish well within the limits.



--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list adj[1…n]

col[1…n] = 0                     # 0 = not coloured yet
found = False

def dfs(v):
    if v == n:                    # all stations processed
        return True               # success
    for c in (1, 2, 3):           # try colours in increasing order
        ok = True
        for u in adj[v+1]:        # neighbours of station v+1 (0‑based)
            if u <= v and col[u] == c:   # neighbour already coloured
                ok = False
                break
        if not ok:
            continue
        col[v+1] = c
        if dfs(v+1):
            return True
        col[v+1] = 0               # backtrack
    return False

if dfs(0):
    print "YES"
    print col[1] … col[n] separated by spaces
else:
    print "NO"
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically smallest
valid profile iff such a profile exists, otherwise prints `NO`.

---

**Lemma 1**  
During the execution of `dfs(v)` the array `col[1…v]` contains a proper
colouring of the subgraph induced by vertices `{1,…,v}`.

*Proof.*  
Induction over `v`.  
Base `v = 0`: empty set – trivially proper.  
Induction step: before the recursive call `dfs(v+1)` we assign a colour `c`
to vertex `v+1` only after checking that none of its already coloured
neighbours (all of them lie in `{1,…,v}`) has colour `c`.  
Thus the extended colouring stays proper. ∎



**Lemma 2**  
If `dfs(v)` returns `True`, then `col[1…n]` is a proper 3‑colouring of the
whole graph.

*Proof.*  
`True` is returned only when `v == n`, i.e. after colouring all vertices.
By Lemma&nbsp;1 the colouring is proper for every prefix, therefore also for
the whole set. ∎



**Lemma 3**  
If a proper 3‑colouring exists, `dfs(0)` returns `True`.

*Proof.*  
Consider any proper colouring `C`.  
The recursion tries colours for vertex 1 in the order `1,2,3`.  
Since `C` uses one of them, the branch that chooses exactly `C(1)` is not
pruned and recurses to `v = 1`.  
Repeating the argument for vertices `2,3,…,n` shows that the recursion can
follow the exact sequence of colours of `C` and reaches `v = n`,
therefore returns `True`. ∎



**Lemma 4**  
If `dfs(0)` returns `True`, the obtained colouring is the lexicographically
smallest among all proper colourings.

*Proof.*  
The search explores the colour tree in depth‑first order, always trying
the smallest possible colour first at each vertex.
The first leaf (i.e. first complete colouring) reached is therefore the
lexicographically smallest leaf in this tree.
Since the algorithm stops at the first leaf, the returned colouring is the
lexicographically smallest proper colouring. ∎



**Theorem**  
The program outputs  

* `YES` and the lexicographically smallest feasible profile
  iff at least one feasible profile exists;
* `NO` otherwise.

*Proof.*  
If a feasible profile exists, by Lemma&nbsp;3 `dfs(0)` returns `True`,
hence the program prints `YES` and the colouring stored in `col`.
By Lemma&nbsp;2 this colouring is feasible, and by Lemma&nbsp;4 it is the
lexicographically smallest one.

If no feasible profile exists, every recursive branch is eventually
pruned, `dfs(0)` returns `False` and the program prints `NO`. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n ≤ 40`.  
In the worst case the algorithm may explore all partial colourings,
i.e. `O(3^n)` states, but pruning eliminates the vast majority.
For the given limits the practical running time is far below the 2 seconds
limit.

Memory consumption: adjacency list `O(n + m)` and the colour array
`O(n)`, altogether `O(n + m) ≤ O(40^2)`, well inside the 256 MB limit.

#### Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it))
        v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [0] * (n + 1)          # 1‑based

    sys.setrecursionlimit(10000)

    def dfs(v: int) -> bool:    # v stations already coloured (0..n)
        if v == n:
            return True
        idx = v + 1
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if nb <= v and col[nb] == c:
                    ok = False
                    break
            if not ok:
                continue
            col[idx] = c
            if dfs(v + 1):
                return True
            col[idx] = 0
        return False

    if dfs(0):
        out = ['YES', ' '.join(str(col[i]) for i in range(1, n + 1))]
        sys.stdout.write('\n'.join(out))
    else:
        sys.stdout.write('NO')

if __name__ == "__main__":
    solve()
```
