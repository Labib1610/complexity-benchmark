We need to assign frequencies 1, 2, or 3 to n nodes (n ≤ 40) such that adjacent nodes have different frequencies, and among all valid assignments, pick the one with the smallest lexicographic order in base-4 representation (since S = Σ fᵢ·4^(n-i), with fᵢ ∈ {1,2,3}).

Because n can be up to 40, we cannot try all 3^n assignments. But we have only 3 colorsainer — this is a graph 3-coloring problem with constraint that we want the lexicographically smallest assignment.  
We can solve using backtracking with pruning. The ordering of assignments means we always try frequency 1 first, then 2, then 3 for each node. If at any point the graph is not 3-colorable, we backtrack.

Moreover, n=40 means backtracking can be exponentially slow in worst case, but the problem guarantees it’s manageable? Actually, 3-coloring is NP-hard, but with n=40 only. However, many inputs will be sparse, and backtracking often works. We should add pruning: check if the remaining uncolored nodes have >3 available colors constraint etc. But usually simple backtracking with degree sorting works fine for 40 nodes for 3 colors.

We also need to output the assignment. Steps:

1. Read graph as adjacency list.
2. Use recursive backtracking over nodes 0..n-1.
3. For each node, try colors 1,2,3 in order, check adjacency constraints.
4. If we color all nodes, we found the lexicographically smallest assignment by DFS order.
5. If no assignment, print NO.

Since we try smallest first, the first time we complete all nodes, it's the minimal signature.

To improve: order nodes by degree descending (color most constrained first) but still they need to be assigned to produce lexicographic order — however, if we reorder, final result should be output in original node order-no, we output in original order of node indices. If we assign in a different order, we still assign original index when we reach it)Skip Reorder? Actually, to get minimal lexicographic, we should try nodes in natural order 0...n-1. But we can still pick the most constrained next node? That might not yield lexicographic minimal because we may make a larger choice for an early node just to make later possible — but we want minimal at index 0 first. So we must prioritize earlier indices; thus we color in index order wines.

The only optimization: we can precompute degree and maybe use forward checking — check if remaining uncolored nodes can still get a color. Simple approach is enough for 40.

We'll implement recursive function `dfs(node)` where we fill nodes from 0 to n-1.

Pseudo:

```
def solve():
    read n, m
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u,v = map(int,input().split())
        u-=1; v-=1
        adj[u].add(v); adj[v].add(u)
    color = [0]*n
    def backtrack(i):
        if i == n:
            return True
        for c in (1,2,3):
            ok = True
            for nb in adj[i]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[i] = c
                if backtrack(i+1):
                    return True
                color[i] = 0
        return False
    if backtrack(0):
        print("YES")
        print(" ".join(map(str,color)))
    else:
        print("NO")
```

Now produce final code.```python
import sys

def solve():
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    
    adj = [set() for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].add(v)
        adj[v].add(u)
    
    color = [0] * n
    
    def backtrack(i):
        if i == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[i]:
                if color[nb] == c:
                    ok = False
                    break
            if ok:
                color[i] = c
                if backtrack(i + 1):
                    return True
                color[i] = 0
        return False
    
    if backtrack(0):
        sys.stdout.write("YES\n")
        sys.stdout.write(" ".join(map(str, color)) + "\n")
    else:
        sys.stdout.write("NO\n")

if __name__ == "__main__":
    solve()
