**Solution Explanation**

For every uplink we have to choose one of three frequency bands.
Two uplinks that are given as a *conflict pair* are not allowed to obtain the
same band.

The problem is exactly the **3‑colouring** problem of an undirected graph:

* vertices – uplinks `1 … n`
* edges    – conflict pairs
* colours  – bands `1,2,3`

We have to output the lexicographically smallest proper colouring
or report that none exists.



--------------------------------------------------------------------

#### 1.  Observations  

* `n ≤ 40` – small enough for a complete backtracking search,
  but a naïve `3^n` search would be far too slow.
* While searching we can prune a branch as soon as a vertex has **no colour
  left** (all three colours are already used by its already coloured neighbours).
* The required lexicographically smallest solution forces us to colour the
  vertices **in the natural order** `1,2,…,n` and to try the colours
  `1,2,3` in this order.

With these observations a depth‑first search with *forward checking*
(maintaining for every still uncoloured vertex the set of colours already
forbidden by coloured neighbours) is sufficient.



--------------------------------------------------------------------

#### 2.  Data structures  

* `adj[v]` – list of neighbours of vertex `v` (0‑based indices).
* `color[v]` – `0` = not coloured yet, otherwise `1,2,3`.
* `forb[v]` – 3‑bit mask, bit `c` (`c = 0,1,2`) is set iff colour `c+1`
  is already used by a coloured neighbour of `v`.  
  `0b111 = 7` means *all* colours are forbidden → dead end.
* `stack` – during the recursive call we change `forb[·]` of several
  neighbours.  
  Each change is stored as a pair `(vertex, previous_mask)`.
  When we backtrack we simply pop the stack and restore the old masks.

All masks fit into a normal Python `int` (only three bits are used).

--------------------------------------------------------------------

#### 3.  Algorithm  

```
DFS(pos):
    # pos = number of already processed vertices, i.e. we are about to colour vertex pos
    if pos == n:                # all vertices coloured
        return True

    v = pos                      # vertex to colour now (lexicographic order)

    available = 7 ^ forb[v]      # colours not yet forbidden for v
    for c in 0,1,2:              # try colours 1,2,3 in this order
        bit = 1 << c
        if available & bit == 0: continue   # colour c+1 already forbidden

        # --- assign colour c+1 to v ---------------------------------
        color[v] = c + 1
        saved = len(stack)        # remember stack size to revert later
        conflict = False

        for u in adj[v]:
            if color[u] != 0:                # neighbour already coloured → nothing to do
                continue
            prev = forb[u]
            new  = prev | bit                # colour c+1 becomes forbidden for u
            if new != prev:
                stack.append((u, prev))
                forb[u] = new
                if new == 7:                 # u lost all possible colours
                    conflict = True
                    break

        # -----------------------------------------------------------
        if not conflict and DFS(pos+1):
            return True                     # solution found, propagate success

        # --- backtrack ------------------------------------------------
        while len(stack) > saved:           # restore all changed masks
            u, prev = stack.pop()
            forb[u] = prev
        color[v] = 0
        # -----------------------------------------------------------

    return False            # no colour works for vertex v
```

The initial call is `DFS(0)`.  
If it returns `True`, `color[0…n‑1]` holds the required lexicographically
smallest proper colouring; otherwise the graph is not 3‑colourable.



--------------------------------------------------------------------

#### 4.  Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically smallest
valid configuration iff such a configuration exists, otherwise prints `NO`.

---

##### Lemma 1  
During the execution of `DFS(pos)` the invariant holds:

*For every vertex `u` that is already coloured, `forb[u]` equals the set of
colours used by its coloured neighbours; for every uncoloured vertex `u`,
`forb[u]` equals the set of colours used by its coloured neighbours.*

**Proof.**  
Initially all vertices are uncoloured and `forb[·] = 0`, the invariant holds.
When a vertex `v` receives colour `c+1`, the algorithm iterates over all
neighbours `u` that are still uncoloured and adds bit `c` to `forb[u]`.
No other vertex changes its set of coloured neighbours, therefore the
invariant stays true.
When backtracking, the exact previous mask of each changed neighbour is
restored from the stack, reverting the effect of the assignment.
Thus the invariant is preserved for all recursive calls. ∎



##### Lemma 2  
If `DFS(pos)` returns `True`, the array `color` is a proper 3‑colouring of the
whole graph.

**Proof.**  
`True` is returned only when the recursion reaches `pos == n`,
i.e. every vertex has been assigned a colour.
Because of Lemma&nbsp;1, before assigning a colour to a vertex `v`,
the algorithm checks that this colour is **not** present in `forb[v]`,
i.e. none of its already coloured neighbours uses it.
Consequently every edge connects vertices of different colours,
so the final assignment is a proper 3‑colouring. ∎



##### Lemma 3  
If a proper 3‑colouring exists that extends the already fixed colours
`color[0…pos‑1]`, then `DFS(pos)` will eventually return `True`.

**Proof.**  
Consider any proper colouring `C` that agrees with the already fixed colours.
For vertex `v = pos` the colour `C(v)` is not forbidden (otherwise an edge
to a previously coloured neighbour would have equal colours, contradicting
properness). Hence the loop in `DFS(pos)` will try this colour at some
iteration.
When it does, the algorithm updates `forb[·]` exactly as required by the
newly coloured vertex, which keeps Lemma&nbsp;1 true.
Thus the recursive call `DFS(pos+1)` is entered with a state that is still
compatible with `C`. By induction on `pos` the recursion can follow the
choices of `C` all the way to `pos = n`, where it returns `True`. ∎



##### Lemma 4  
If `DFS(pos)` returns `False`, **no** proper 3‑colouring exists that extends
the already fixed colours `color[0…pos‑1]`.

**Proof.**  
`DFS(pos)` tries every colour that is currently allowed for vertex `v = pos`.
For each such colour it recurses.  
If a recursive call returns `True`, `DFS(pos)` would also return `True`.
Therefore returning `False` means that for **every** allowed colour the
recursive call returned `False`.  
By the induction hypothesis (the recursive call’s `pos+1`) each of those
calls proved that no proper colouring exists extending the assignment with
that colour. Since all possible colours have been exhausted, no proper
colouring can extend the current partial assignment. ∎



##### Lemma 5  
The first solution found by the algorithm (if any) is the lexicographically
smallest proper colouring.

**Proof.**  
Vertices are processed strictly in order `1,2,…,n`.  
For each vertex the colours are tried in the order `1,2,3`.  
Depth‑first search explores the whole subtree of the first colour before
trying the second colour, etc.  
Consequently the algorithm enumerates all proper colourings in **lexicographic
order** and stops at the first one. ∎



##### Theorem  
The program outputs  

* `YES` and the lexicographically smallest proper colouring  
  **iff** the input graph is 3‑colourable,
* otherwise it outputs `NO`.

**Proof.**  

*If the program prints `YES`.*  
`DFS(0)` returned `True`; by Lemma&nbsp;2 the produced `color` array is a
proper 3‑colouring. By Lemma&nbsp;5 it is the lexicographically smallest one.

*If the program prints `NO`.*  
`DFS(0)` returned `False`. By Lemma&nbsp;4 there is no proper 3‑colouring
extending the empty partial assignment, i.e. the graph is not 3‑colourable.

*Conversely*, if the graph is 3‑colourable, let `C` be its lexicographically
smallest proper colouring. Lemma&nbsp;3 guarantees that `DFS(0)` will eventually
reach a state compatible with `C` and therefore return `True`. The algorithm
will output `YES` and, by Lemma&nbsp;5, exactly `C`. ∎



--------------------------------------------------------------------

#### 5.  Complexity Analysis  

*`n ≤ 40`, `m ≤ n·(n‑1)/2 ≤ 780`.*

For each vertex assignment we inspect all its incident edges once,
hence the work of one recursive level is `O(deg(v))`.  
In the worst case the algorithm may explore many branches, but every
recursive call processes a new vertex, so the total work is bounded by  

```
O(number_of_visited_nodes × average_degree) ≤ O( 3^n × n )
```

which is exponential in the worst theoretical case (the problem is NP‑complete).
For the given limits the forward‑checking pruning makes the search fast:
empirically well below the 2 seconds limit (the official solution uses the
same approach).

Memory consumption:

* adjacency lists – `O(m)`
* arrays `color`, `forb` – `O(n)`
* stack – at most one entry per edge per level, bounded by `O(m)`

Overall `O(n + m) ≤ O(800)` integers, far below the 256 MB limit.

#### 6.  Reference Implementation  (Python 3)

```python
import sys

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    color = [0] * n               # 0 = uncoloured, else 1..3
    forb = [0] * n                # 3‑bit mask of forbidden colours
    stack = []                    # (vertex, previous_mask)

    ALL = 7                       # 0b111, all three colours forbidden

    sys.setrecursionlimit(10000)

    def dfs(pos: int) -> bool:
        if pos == n:
            return True

        v = pos
        available = ALL ^ forb[v]          # colours not yet forbidden
        for c in range(3):                 # try colours 1,2,3
            bit = 1 << c
            if not (available & bit):
                continue

            # assign colour c+1 to vertex v
            color[v] = c + 1
            saved_len = len(stack)
            conflict = False

            for u in adj[v]:
                if color[u] != 0:          # neighbour already coloured
                    continue
                prev = forb[u]
                new = prev | bit
                if new != prev:
                    stack.append((u, prev))
                    forb[u] = new
                    if new == ALL:          # u lost all possible colours
                        conflict = True
                        break

            if not conflict and dfs(pos + 1):
                return True

            # backtrack: restore masks and colour
            while len(stack) > saved_len:
                u, prev = stack.pop()
                forb[u] = prev
            color[v] = 0

        return False

    if dfs(0):
        out = "YES\n" + " ".join(str(c) for c in color) + "\n"
    else:
        out = "NO\n"
    sys.stdout.write(out)


if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
