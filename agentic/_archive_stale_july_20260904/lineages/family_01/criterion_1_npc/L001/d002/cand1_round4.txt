# Problem A — Hazardous Material Containment

Time limit: 2 s   Memory limit: 256 MB

A research facility is processing distinct hazardous materials, indexed from $1$ to $n$. To ensure site safety, the facility relies on three isolated containment chambers, designated as Chamber 1, Chamber 2, and Chamber 3. Every material must be deposited into exactly one of these three chambers.

During initial testing, the safety team identified pairs of materials that are highly reactive with one another. If any two reactive materials are deposited into the same containment chamber, a catastrophic thermal event will occur. Consequently, such pairs must never share a chamber.

The automated storage system requires a manifest sequence to proceed. A valid manifest is an ordered sequence of $n$ integers, where the $i$-th integer represents the chamber (1, 2, or 3) receiving material $i$. When multiple safe configurations exist, the system mandates the configuration that yields the lexicographically smallest manifest sequence. If no safe configuration exists, the system must trigger an abort protocol.

## Input
The first line contains two integers $n$ and $m$. The facility processes at least $1$ and up to a maximum capacity of $40$ hazardous materials ($n$). The number of reactive pairs $m$ ranges from $0$ up to $n(n-1)/2$.
Each of the next $m$ lines contains two integers $u$ and $v$, identifying a pair of materials that are reactive and cannot share a chamber.

## Output
If the abort protocol must be triggered because no safe manifest is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print the $n$ integers of the required manifest sequence, where the $i$-th integer is the chamber (1, 2, or 3) assigned to material $i$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
