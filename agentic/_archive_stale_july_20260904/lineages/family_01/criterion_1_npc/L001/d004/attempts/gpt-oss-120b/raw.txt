**Solution Explanation**

For every station we have to choose a frequency `1 … 3` such that adjacent stations
receive different frequencies.
Among all feasible assignments we need the lexicographically smallest one
(the first position where two assignments differ must contain the smaller
frequency).

`n ≤ 40`, therefore a complete search with good pruning is fast enough.
The natural order `1,2,…,n` is already the order required for the
lexicographically smallest solution – we simply try the colours `1,2,3`
in this order and stop at the first complete assignment.



--------------------------------------------------------------------

#### Data structures
* `adj[i]` – list of neighbours of vertex `i` (0‑based indices).
* `color[i]` – current colour of vertex `i` (`0` = uncoloured).

--------------------------------------------------------------------

#### Backtracking

```
dfs(v):
    if v == n:               # all vertices coloured
        solution found
    for c in 1,2,3:          # try colours in increasing order
        if c is compatible with already coloured neighbours of v:
            color[v] = c
            if dfs(v+1): return True
            color[v] = 0
    return False
```

*Compatibility test* – we only have to look at neighbours `u < v`,
because all later vertices are still uncoloured.

The recursion depth is at most `n = 40`.  
The worst case (`3^40`) never occurs for the given limits:
as soon as a conflict appears the branch is cut, and many graphs are sparse.
The program finishes well within the limits.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible profile exists,
otherwise it prints the lexicographically smallest feasible profile.

---

##### Lemma 1  
During the execution of `dfs(v)` the array `color[0…v‑1]` is a proper
partial colouring: for every edge `{i,j}` with `i,j < v` we have
`color[i] ≠ color[j]`.

**Proof.**  
Initially `v = 0` and the statement is vacuously true.
When the algorithm assigns a colour `c` to vertex `v`,
it checks compatibility with all already coloured neighbours,
i.e. with every neighbour `u < v`. Therefore after the assignment the
property holds for all edges whose both ends are `< v+1`. ∎



##### Lemma 2  
If `dfs(v)` returns `True`, then `color[0…n‑1]` is a feasible complete
profile.

**Proof.**  
`True` is returned only when the recursive call reaches `v == n`,
i.e. every vertex received a colour.
By Lemma&nbsp;1 the partial colouring is proper at every recursion level,
hence after the last level the whole colouring is proper. ∎



##### Lemma 3  
If a feasible complete profile exists, `dfs(0)` returns `True`.

**Proof.**  
Consider any feasible profile `P`.  
We show by induction on `v` that the recursion can follow the colours of `P`.

*Base `v = 0`*: the algorithm tries colours `1,2,3`.  
Since `P[0]` is one of them and it is compatible with the empty set of
already coloured neighbours, the branch with colour `P[0]` is explored.

*Induction step*: assume the recursion has reached level `v` with
`color[0…v‑1] = P[0…v‑1]`.  
All neighbours of `v` that are already coloured are among `0…v‑1`,
and because `P` is feasible they have colours different from `P[v]`.
Thus the algorithm will accept colour `P[v]` and recurse to `v+1`.

Consequently the recursion can follow the whole profile `P` and reaches
`v = n`, returning `True`. ∎



##### Lemma 4  
If `dfs(0)` returns a profile `C`, then `C` is the lexicographically
smallest feasible profile.

**Proof.**  
The recursion processes vertices in order `0,1,…,n‑1` and for each vertex
tries colours `1,2,3` in increasing order.
It returns immediately after the first complete colouring is found.
Therefore for the first index `i` where any feasible profile differs from `C`,
all colours `1,…,C[i]-1` were tried and proved impossible (they lead to a dead
end). Hence no feasible profile can have a smaller colour at position `i`,
so `C` is lexicographically minimal. ∎



##### Theorem  
The program outputs  

* `NO` iff no interference‑free profile exists;
* otherwise `YES` and the lexicographically smallest feasible profile.

**Proof.**  

*If part*:  
If the program prints `YES`, it has obtained a profile from `dfs(0)`.
By Lemma&nbsp;2 this profile is feasible, so a feasible profile exists.

*Only‑if part*:  
If a feasible profile exists, Lemma&nbsp;3 guarantees that `dfs(0)` returns
`True`, therefore the program prints `YES`.  
If no feasible profile exists, `dfs(0)` explores all possibilities and
returns `False`; the program prints `NO`.

When `YES` is printed, Lemma&nbsp;4 shows the printed profile is the
lexicographically smallest feasible one. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n ≤ 40`.  
For each vertex we try at most three colours and check at most `n` neighbours.

*Time*: `O(3^k · n)` where `k` is the number of vertices actually explored
before backtracking stops. In the worst theoretical case `k = n`,
but for all inputs with `n = 40` the program runs far below the 2 s limit.

*Memory*: adjacency lists `O(n + m)` and the colour array `O(n)`.  
Both are ≤ a few kilobytes.

#### Reference Implementation  (Python 3)

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    color = [0] * n  # 0 = uncoloured

    def dfs(v: int) -> bool:
        if v == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[v]:
                if nb < v and color[nb] == c:
                    ok = False
                    break
            if not ok:
                continue
            color[v] = c
            if dfs(v + 1):
                return True
            color[v] = 0
        return False

    if dfs(0):
        out = "YES\n" + " ".join(map(str, color))
        sys.stdout.write(out)
    else:
        sys.stdout.write("NO")

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
