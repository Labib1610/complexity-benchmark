# Problem A — Facility Shift Allocation

Time limit: 2 s   Memory limit: 256 MB

A manufacturing facility is overhauling its personnel deployment protocols. The workflow consists of four sequential stages:

1. **Registration:** Personnel Administration registers a cohort of new hires, assigning each person a distinct identification number starting from 1 up to the total cohort size, $n$. 
2. **Clearance:** Risk Management produces a list of $m$ interpersonal conflicts. Any two individuals named in a conflict report are deemed incompatible.
3. **Allocation:** Facility Operations is mandated to allocate each new hire to exactly one of three available operational shifts, designated by the identifiers 1, 2, and 3. Safety regulations dictate that individuals deemed incompatible must never be allocated to the same operational shift.
4. **Integration:** Systems Integration compiles the shift roster based on the allocation. If the allocations can be successfully made without violating safety regulations, the roster must list the shift identifiers for all individuals in ascending order of their identification numbers. To maintain a deterministic database, if multiple valid allocation rosters are possible, the automated system strictly requires the lexicographically smallest sequence. If no allocation can satisfy the safety regulations, the deployment must be aborted.

Your objective is to implement the logic that bridges Stage 2 and Stage 4. Given the cohort size and the conflict reports, you must compute the required operational shift for each individual, or detect that the deployment must be aborted.

## Input
The first line contains two integers $n$ and $m$ — the cohort size from Stage 1 and the number of conflict reports from Stage 2. The cohort size $n$ is restricted by the orientation room capacity, dictating a minimum of 1 and a maximum of 40 individuals. The volume of conflict reports $m$ can be as low as 0 and as high as the maximum possible $n(n-1)/2$ distinct pairs.
Each of the subsequent $m$ lines provides two integers $u$ and $v$ — denoting a pair of individuals who are incompatible and cannot share the same operational shift.

## Output
If the deployment must be aborted because no valid allocation is achievable, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print exactly $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), representing the operational shift assigned to person $i$. Among all valid assignments, output the lexicographically smallest sequence (compare $s_1$ first, then $s_2$, and so on).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
