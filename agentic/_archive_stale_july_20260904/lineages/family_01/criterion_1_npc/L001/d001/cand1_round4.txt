# Problem A — HR Workflow Automation

Time limit: 2 s   Memory limit: 256 MB

A manufacturing plant is updating its employee onboarding workflow. The process must assign new hires to daily shifts while respecting security constraints.

The HR department has finalized a cohort of $n$ employees, assigning them sequential IDs starting from $1$ up to $n$. The facility's orientation room has a strict capacity of 40, so the cohort size will never exceed this number, and there will always be at least 1 new hire.

During vetting, the security team flags $m$ specific pairs of employees who have prior disputes. The number of such pairs can be as low as 0 and as high as the maximum possible number of pairs, $n(n-1)/2$. These pairs are deemed incompatible and must be separated.

The operations department must allocate every employee to exactly one of three available work shifts, identified by the numbers 1, 2, and 3. To maintain a safe environment, no two employees in a flagged pair may be assigned to the same shift.

The IT department will then generate access badges. The system requires an ordered configuration of shift numbers for employees $1$ through $n$. To ensure the database remains deterministic, if multiple valid configurations can be formed, the system mandates a specific tie-breaking rule: it prefers the configuration that assigns the smallest possible shift number to employee 1. If a tie remains, it prefers the one that assigns the smallest shift number to employee 2, and continues this sequential preference up to employee $n$. 

If no valid configuration can be formed without violating the security constraints, the IT system must be notified to halt the process.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$, representing a pair of employees who cannot share the same shift.

## Output
If the workflow must halt because no valid assignment is possible, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2, 3\}$), representing the shift of employee $i$. Among all valid configurations, output the one determined by the sequential tie-breaking rule described above.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
