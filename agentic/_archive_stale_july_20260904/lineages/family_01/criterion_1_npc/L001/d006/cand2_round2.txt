# Problem A — Orbital Network Frequency Coordination

Time limit: 2 s   Memory limit: 256 MB

An aerospace consortium is preparing the initialization profile for $n$ orbital uplink stations, numbered $1$ through $n$. Each station must be assigned a frequency value from the set $\{1, 2, 3\}$.

Spatial analysis has identified $m$ pairs of stations whose broadcast footprints intersect. For each listed pair, the two stations must receive different frequencies to avoid interference.

A complete profile is a sequence of $n$ frequencies, where the $i$-th value is the frequency allocated to station $i$. The consortium evaluates all interference-free profiles. If the set of valid profiles is empty, the deployment cannot proceed. 

Otherwise, the system must select the single valid profile that minimizes the network's deployment signature. The deployment signature $S$ of a profile is calculated exactly as follows:
Each frequency $f_i$ is represented as a 2-bit binary string (`01` for 1, `10` for 2, and `11` for 3). These $n$ binary strings are concatenated in order from station $1$ to station $n$ to form a single continuous $2n$-bit binary sequence, with station $1$'s bits being the most significant. This sequence is interpreted as a base-2 integer, which is the signature $S$.

## Input
The first line contains two integers $n$ and $m$ — the number of uplink stations and the number of intersecting footprint pairs ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
Each of the next $m$ lines contains two integers $u$ and $v$ — representing a pair of stations that have intersecting footprints and must use different frequencies.

## Output
If no interference-free profile exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $f_1, f_2, \dots, f_n$ (where each $f_i \in \{1, 2, 3\}$), representing the frequency allocated to station $i$. Output the profile that minimizes the deployment signature.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The explicit base-4 polynomial sum was replaced with an equivalent process of concatenating 2-bit binary representations of the frequencies. Because $f_i \cdot 4^{n-i}$ is mathematically identical to shifting a 2-bit value left by $2(n-i)$ bits, the integer produced is exactly the same as the original deployment signature $S$. This forces the model to independently deduce that minimizing this integer implies lexicographical minimization (and thus a first-feasible DFS approach is optimal), rather than pattern-matching the polynomial formula.
</RATIONALE>
