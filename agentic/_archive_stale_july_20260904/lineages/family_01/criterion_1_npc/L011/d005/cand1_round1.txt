# Problem A — Global Energy State

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a discrete system consisting of $n$ particles. Each particle must be assigned an energy level $c_i \in \{1, 2, 3\}$. 

The system contains $m$ interacting pairs of particles. Let $d_i$ denote the number of interacting pairs that include particle $i$. 

The system's stability is evaluated using two global metrics: the **Alpha metric** ($\alpha$) and the **Beta metric** ($\beta$). 
The Alpha metric is derived from the fourth powers of the energy differences between interacting particles, offset by the system's total interactions:
$$\alpha = 4m + \sum_{j=1}^m (c_{u_j} - c_{v_j})^4$$
where the sum is taken over all $m$ interacting pairs $(u_j, v_j)$.

The Beta metric is derived from the individual energy levels weighted by their interaction counts, minus the cross-interactions:
$$\beta = 5 \sum_{i=1}^n d_i c_i^2 - 10 \sum_{j=1}^m c_{u_j} c_{v_j}$$

A complete configuration of the system $C = (c_1, c_2, \ldots, c_n)$ is considered stable if and only if the two metrics are perfectly balanced, meaning:
$$\alpha = \beta$$

Your objective is to determine a stable configuration for all $n$ particles. A complete configuration is represented as a sequence of $n$ integers $C = (c_1, c_2, \ldots, c_n)$. If multiple stable configurations exist, you must output the sequence that is lexicographically smallest. Specifically, given two distinct stable configurations $C$ and $C'$, configuration $C$ is strictly smaller than $C'$ if $c_k < c'_k$ at the lowest index $k$ where the two sequences differ. If it is impossible to find a stable configuration, report that no solution exists.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the number of particles and the number of interacting pairs, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that particle $u$ and particle $v$ form an interacting pair.

## Output
If no stable configuration can be formed, print a single line containing `NO`.
If a stable configuration is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i \in \{1, 2, 3\}$ is the energy level assigned to particle $i$. If there are multiple valid assignments, you must output the lexicographically smallest sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I changed the presentation of the stability condition from a sum of independent edge energies bounded by 4m to an equality between two global algebraic metrics ($\alpha$ and $\beta$). This forces the model to mathematically equate the two metrics, factor the resulting expression, and analyze its roots to deduce that the condition is equivalent to proper 3-coloring, defeating models that rely on surface-level pattern matching of the edge energy formula.
</RATIONALE>

The equality $\alpha = \beta$ algebraically rearranges to the exact same polynomial sum as the original problem, meaning the identical set of configurations is considered stable for any given input.
</PRESERVED_ANSWER>

</PRESERVED_CLASS>
