<STATEMENT>
# Problem A — Global Energy State

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a discrete system consisting of $n$ particles. Each particle must be assigned an integer energy level $c_i$. The facility provides exactly 3 distinct power grids, numbered 1, 2, and 3, so every particle must draw its energy from one of these three available grids.

The system contains $m$ interacting pairs of particles. For any interacting pair of particles $u$ and $v$ with energy levels $c_u$ and $c_v$, their interaction is governed by the characteristic polynomial:
$$P_{u,v}(x) = \int_0^x (t - c_u)(t - c_v) dt$$

A complete configuration of the system $C = (c_1, c_2, \ldots, c_n)$ is considered stable if and only if the total count of local maximum points (occurring at coordinates $x > 0$) across all $m$ interaction polynomials $P_{u_j, v_j}(x)$ is exactly $m$.

Your objective is to determine a stable configuration for all $n$ particles. A complete configuration is represented as a sequence of $n$ integers $C = (c_1, c_2, \ldots, c_n)$. If multiple stable configurations exist, you must output the sequence that is lexicographically smallest. Specifically, given two distinct stable configurations $C$ and $C'$, configuration $C$ is strictly smaller than $C'$ if $c_k < c'_k$ at the lowest index $k$ where the two sequences differ. If it is impossible to find a stable configuration, report that no solution exists.

## Input
The first line provides two integers $n$ and $m$ (where $n$ is at least 1 and capped by the containment vessel's capacity of 40 particles, and $m$ ranges from 0 up to the maximum possible number of distinct pairs between the $n$ particles), representing the number of particles and the number of interacting pairs, respectively.
The following $m$ lines each contain two integers $u$ and $v$ (valid particle identifiers between 1 and $n$, with $u \neq v$), indicating that particle $u$ and particle $v$ form an interacting pair.

## Output
If no stable configuration can be formed, print a single line containing `NO`.
If a stable configuration is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i$ is the energy grid (1, 2, or 3) assigned to particle $i$. If there are multiple valid assignments, you must output the lexicographically smallest sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
Removed the explicit polynomial evaluation that visually mapped to a bounded difference of 4. Replaced it with an integral whose number of local maxima depends on whether the integration bounds (the energy levels) are distinct. Models must now differentiate the polynomial and reason about its roots to discover that the stability condition is mathematically identical to checking $c_u \neq c_v$.
</RATIONALE>
<PRESERVED_ANSWER>
The derivative of the interaction polynomial is $(x - c_u)(x - c_v)$, which has exactly one local maximum point for $x > 0$ if $c_u \neq c_v$, and zero local maximum points if $c_u = c_v$; thus, requiring exactly $m$ local maxima across $m$ pairs forces $c_u \neq c_v$ for every pair, making the valid configurations identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires assigning variables to 3 discrete states such that no two connected variables share the same state, which is exactly the NP-complete 3-coloring problem.
</PRESERVED_CLASS>
<RISK>
Models might attempt to solve the problem by literally integrating and numerically optimizing the polynomials at runtime instead of symbolically deducing the $c_u \neq c_v$ invariant, leading to Time Limit Exceeded.
</RISK>
