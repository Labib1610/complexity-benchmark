<STATEMENT>
# Problem A — Global Energy State

Time limit: 2 s   Memory limit: 256 MB

You are analyzing a discrete system consisting of $n$ particles. Each particle must be assigned a state $c_i \in \{1, 2, 3\}$. 

The system contains $m$ interacting pairs of particles. A complete configuration of the system $C = (c_1, c_2, \ldots, c_n)$ is considered stable if, for every interacting pair $u$ and $v$, the product of their assigned states $c_u \times c_v$ is not a perfect square. 

Your objective is to determine a stable configuration for all $n$ particles. A complete configuration is represented as a sequence of $n$ integers $C = (c_1, c_2, \ldots, c_n)$. If multiple stable configurations exist, you must output the sequence that is lexicographically smallest. Specifically, given two distinct stable configurations $C$ and $C'$, configuration $C$ is strictly smaller than $C'$ if $c_k < c'_k$ at the lowest index $k$ where the two sequences differ. If it is impossible to find a stable configuration, report that no solution exists.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the number of particles and the number of interacting pairs, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that particle $u$ and particle $v$ form an interacting pair.

## Output
If no stable configuration can be formed, print a single line containing `NO`.
If a stable configuration is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i \in \{1, 2, 3\}$ is the state assigned to particle $i$. If there are multiple valid assignments, you must output the lexicographically smallest sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<METHOD_NAME>
Domain-Specific Algebraic Isomorphism
</METHOD_NAME>
<METHOD_DESCRIPTION>
I replaced the polynomial sum equality with a number-theoretic property ("product is not a perfect square") that is strictly isomorphic on the domain {1, 2, 3}. This hides the graph coloring structure from pattern-matching models without adding complex or contrived mathematical framing, forcing the model to deduce the pairwise inequality constraint from first principles.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes
</METHOD_NOVEL>
<RATIONALE>
The previous polynomial framing allowed models to easily deduce that the maximum interaction energy was reached exactly when values differed, pattern-matching to 3-coloring. By changing the pairwise stability rule to require that the product of the two states is not a perfect square, models must evaluate this number-theoretic property on the domain {1, 2, 3} to realize it is equivalent to an inequality constraint. The exact bounds from the seed have been restored verbatim.
</RATIONALE>
<PRESERVED_ANSWER>
For values in {1, 2, 3}, the product of two distinct values is in {2, 3, 6} (none of which are perfect squares), while the product of two identical values is in {1, 4, 9} (all of which are perfect squares); thus, the condition is logically identical to requiring distinct assignments for interacting pairs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Lexicographically First 3-Coloring, which is NP-complete.
</PRESERVED_CLASS>
