# Problem A — Operational Modes

Time limit: 2 s   Memory limit: 256 MB

You are deploying a wireless network composed of $n$ access points. Each access point requires an operating frequency, chosen from three distinct bands designated by the integers 1, 2, and 3.

Because of geographic proximity, specific pairs of access points overlap in their coverage areas. If any two overlapping access points are set to the identical band, their signals will interfere. A successful deployment assigns a band to every access point such that no overlapping pair shares the same band.

Your objective is to determine a successful deployment for the network. Note that the test data contains adversarial networks of up to 40 access points, specifically designed to exceed the time limit if your solution relies on fixed-order exhaustive trial-and-error. You must incorporate robust search pruning or an advanced exploration strategy to pass.

Should multiple successful deployments be possible, you must evaluate them as complete sequences of length $n$ and select the one that is globally minimal. A deployment sequence $A$ is considered strictly smaller than a deployment sequence $B$ if, at the lowest index $i$ where the two sequences differ, the band assigned to access point $i$ in $A$ is numerically less than the band in $B$. If no interference-free deployment can be found, you must state that it is impossible.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the total number of access points and the number of overlapping pairs, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), specifying that access point $u$ and access point $v$ overlap and cannot use the same band.

## Output
If an interference-free deployment is impossible, output a single line containing `NO`.
If a successful deployment is possible, output `YES` on the first line. On the second line, provide $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i \in \{1, 2, 3\}$ is the band assigned to access point $i$. Output the globally minimal sequence if multiple valid deployments exist.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
