<STATEMENT>
# Problem A — System State Configuration

Time limit: 2 s   Memory limit: 256 MB

You are configuring a system with $n$ components, indexed from $1$ to $n$. Each component $i$ must be assigned a frequency multiplier $c_i$, which must be an integer chosen from $\{1, 2, 3\}$.

The system is subject to $m$ interference constraints. Each constraint specifies a pair of components $u$ and $v$ that interact. When two components $u$ and $v$ interact, their frequency multipliers combine to produce a harmonic signature. To ensure system stability, the remainder when $2^{c_u} + 2^{c_v}$ is divided by 7 must not equal 1, 2, or 4.

For reporting purposes, the complete configuration of the system is represented by a sequence of $n$ integers $c_1, c_2, \ldots, c_n$. If there are multiple stable configurations, you must select the one whose configuration sequence is lexicographically smallest. That is, when comparing two valid sequences, the one with the smaller integer value at the first index where they differ is strictly preferred.

Determine if a stable configuration exists, and if so, output the optimal configuration sequence.

## Input
The first line contains two integers $n$ and $m$. The number of components $n$ is constrained by the chassis capacity, which requires at least a single component and accommodates a maximum of 40 components. The number of constraints $m$ can be as low as zero and as high as the theoretical maximum of one constraint for every distinct pair of components.

Each of the following $m$ lines contains two distinct integers $u$ and $v$. Both values represent valid component indices from 1 up to $n$ inclusive, indicating that component $u$ and component $v$ interact and their assigned frequency multipliers must satisfy the harmonic signature condition.

## Output
If no stable configuration is possible, print a single line containing `NO`.
If a stable configuration is possible, print `YES` on the first line. On the second line, print exactly $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i \in \{1, 2, 3\}$ is the frequency multiplier assigned to component $i$. Among all stable configurations, you must output the lexicographically smallest sequence $c_1, c_2, \ldots, c_n$ (compare $c_1$ first, then $c_2$, etc.).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

I replaced the explicit 3-vector dot-product condition with an equivalent algebraic condition over a finite field (modulo 7). The new constraint `(2^u + 2^v) mod 7 not in {1, 2, 4}` perfectly separates equal states from unequal states for values in `{1, 2, 3}`. This forces the model to actively reason about the state space and evaluate the condition, rather than relying on surface pattern-matching of "dot product of exactly 1" to recognize 3-coloring. I also applied S07 to hide the numeric bounds in the scenario text.
</RATIONALE>

</PRESERVED_ANSWER>
