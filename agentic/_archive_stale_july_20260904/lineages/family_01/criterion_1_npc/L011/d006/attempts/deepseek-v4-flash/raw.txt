We need to assign each particle a value from {1, 2, 3} such that adjacent particles have different values, and among all valid assignments, we pick the one with the smallest base-4 number formed by the sequence.

Since n ≤ 40, we can use a backtracking approach with pruning.  
We’ll assign values in order from 1 to n, always trying the smallest possible value first, and check constraints with already assigned neighbors.

If we reach the end, we have the lexicographically smallest (and thus numerically smallest) valid assignment.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[idx] = c
                if backtrack(idx + 1):
                    return True
                colors[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
