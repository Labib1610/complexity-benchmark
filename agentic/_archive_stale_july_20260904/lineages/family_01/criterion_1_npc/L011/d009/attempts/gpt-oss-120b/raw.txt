**Solution Explanation**

For every component we have to choose one of the three vectors  

```
1 : (1,1,0)   = A
2 : (1,0,1)   = B
3 : (0,1,1)   = C
```

For an interacting pair `(u,v)` the dot product must be exactly `1`.
The dot products of the three vectors are

|   | A | B | C |
|---|---|---|---|
| A | 2 | 1 | 1 |
| B | 1 | 2 | 1 |
| C | 1 | 1 | 2 |

Thus the condition `dot = 1` is satisfied **iff the two vectors are different**.
Consequently the whole problem is exactly the classic *graph 3‑coloring*:

* vertices = components  
* edges   = interference constraints  
* a proper coloring with colors `{1,2,3}` is a feasible configuration.

Among all proper colorings we need the lexicographically smallest
`c1 … cn`.  
If we colour the vertices **in the natural order `1 … n`** and always try
the colors `1,2,3` in this order, the first complete coloring we find is
already the lexicographically smallest one.

`n ≤ 40`, therefore a depth‑first search with simple pruning is fast enough.
During the search we keep for every vertex the list of already coloured
neighbours; a colour is allowed if none of those neighbours uses it.

The algorithm

```
DFS(v):
    if v == n:               # all vertices coloured
        solution found
    for col in 1..3:
        if col is not used by any already coloured neighbour of v:
            assign col to v
            DFS(v+1)
            if solution found: return
    undo assignment of v
```

The recursion stops as soon as a solution is found.
If the whole search finishes without success the graph is not 3‑colorable.

The running time in the worst case is `O(3^n)`, but with `n ≤ 40`
and the strong pruning (a vertex cannot use a colour already taken by a
neighbour) it easily fits into the limits.

#### Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically smallest
valid sequence iff such a sequence exists.

---

##### Lemma 1  
For any edge `{u,v}` the dot product condition `V_u·V_v = 1` holds
iff the assigned integers `c_u` and `c_v` are different.

**Proof.**  
From the table of dot products the value is `1` exactly for the six
ordered pairs `(A,B),(A,C),(B,A),(B,C),(C,A),(C,B)`, i.e. when the two
vectors are different. ∎



##### Lemma 2  
A sequence `c_1 … c_n` satisfies all constraints **iff** it is a proper
3‑coloring of the given graph.

**Proof.**  
By Lemma&nbsp;1 each edge requires the two incident vertices to have
different colours, which is precisely the definition of a proper coloring.
Conversely, any proper coloring makes all edges satisfy the dot product
condition. ∎



##### Lemma 3  
During the DFS, when vertex `v` is processed, all vertices `1 … v-1`
already have their final colours, and no later vertex has been coloured.

**Proof.**  
The recursion always proceeds to `v+1` after fixing a colour for `v`,
and never revisits a smaller index after returning from deeper recursion.
Thus the invariant holds by induction on `v`. ∎



##### Lemma 4  
If the DFS assigns a colour `col` to vertex `v`, then this colour is
compatible with all already coloured neighbours of `v`.

**Proof.**  
Before trying a colour we explicitly test that none of the neighbours
already coloured (by Lemma&nbsp;3 they are exactly the neighbours with index
`< v`) uses `col`. Only if the test succeeds we assign `col`. ∎



##### Lemma 5  
Whenever the DFS reaches `v = n+1` (all vertices coloured) the obtained
sequence is a valid configuration.

**Proof.**  
All edges connect two vertices with indices `≤ n`. For each edge
`{u,v}` the later of the two vertices (say `v`) was coloured after the
earlier one, and by Lemma&nbsp;4 the colour of `v` differed from the colour
of `u`. Hence every edge connects different colours, i.e. the sequence is
a proper 3‑coloring, and by Lemma&nbsp;2 a valid configuration. ∎



##### Lemma 6  
If a valid configuration exists, the DFS will eventually find one.

**Proof.**  
Consider any valid configuration. Process vertices in order `1 … n`.
When the DFS reaches vertex `v`, all earlier vertices have been coloured
exactly as in the considered configuration (by induction). The colour
used for `v` in that configuration is allowed because all its already
coloured neighbours have different colours (the configuration is proper).
Therefore the DFS will try this colour (it tries colours `1,2,3` in order)
and can continue recursively. Hence the recursion can follow the whole
valid configuration and will reach `v = n+1`. ∎



##### Lemma 7  
The first complete coloring found by the DFS is the lexicographically
smallest among all valid colorings.

**Proof.**  
The DFS explores the search tree in depth‑first order, always trying the
smaller colour first at each vertex. Therefore it enumerates all
colorings in lexicographic order of the sequence `c_1 … c_n`. The first
one that is complete and valid (Lemma&nbsp;5) is thus the smallest. ∎



##### Theorem  
The program outputs  

* `NO` iff no valid configuration exists;  
* otherwise `YES` and the lexicographically smallest valid sequence.

**Proof.**  

*If the program prints `YES`.*  
It has found a complete coloring, which by Lemma&nbsp;5 is a valid
configuration. By Lemma&nbsp;7 it is the smallest possible.

*If the program prints `NO`.*  
The DFS explored the whole search space without reaching a complete
coloring. By Lemma&nbsp;6 this is possible only if no valid configuration
exists.

Thus the output satisfies the specification. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`n ≤ 40`, `m ≤ n(n-1)/2`.

*For each recursive call* we test at most `deg(v) ≤ n` neighbours,
so the work per call is `O(n)`.  
The number of calls is bounded by the number of visited partial
assignments; in the worst case `3^n`.  
Hence the worst‑case time is `O(n·3^n)`, which is acceptable for `n = 40`
with the strong pruning of proper coloring.

Memory consumption: adjacency lists `O(n + m)` and the colour array
`O(n)`. Both are well below the limits.

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    color = [0] * n          # 0 = unassigned, else 1..3
    found = False

    def dfs(v: int):
        nonlocal found
        if found:
            return
        if v == n:
            found = True
            return
        # try colours 1,2,3 in order
        for col in (1, 2, 3):
            ok = True
            for nb in adj[v]:
                if nb < v and color[nb] == col:
                    ok = False
                    break
            if not ok:
                continue
            color[v] = col
            dfs(v + 1)
            if found:
                return
            color[v] = 0

    dfs(0)

    out = []
    if not found:
        out.append("NO")
    else:
        out.append("YES")
        out.append(" ".join(str(c) for c in color))
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
