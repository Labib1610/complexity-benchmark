</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaced the explicit base-4 polynomial evaluation with a combinatorial counting problem (number of subordinate microstates) that mathematically evaluates to the exact same base-4 integer. To avoid TLE on sparse graphs (N=40), models must logically deduce that this counting problem is equivalent to a base-4 encoding, and therefore minimized by lexicographical order, allowing them to halt DFS after the first valid assignment. Models that fail to deduce this will likely attempt exhaustive search and TLE.
</METHOD_DESCRIPTION>

<STATEMENT>
# Problem A — Global Energy State

Time limit: 2 s   Memory limit: 256 MB

A physical model comprises $n$ distinct particles, indexed $1$ through $n$. You are required to calibrate the model by assigning each particle an energy state $c_i$ chosen from the set $\{1, 2, 3\}$.

Within this model, there are $m$ specific interacting pairs of particles. A complete calibration of the system $C = (c_1, c_2, \ldots, c_n)$ is deemed stable if and only if no two particles that form an interacting pair share the same energy state (i.e., $c_u \neq c_v$ for every interacting pair $u$ and $v$).

Your task is to find a stable calibration for all $n$ particles. If there are multiple valid ways to achieve stability, you must select the calibration $C$ that yields the strictly minimum possible value for the system's structural penalty $W(C)$. 

The penalty $W(C)$ is determined by the total number of specific *microstates* that are subordinate to the calibration. 
A microstate is defined as a sequence of $n$ integers $y_1, y_2, \ldots, y_n$ where each $y_i \in \{1, 2, 3, 4\}$. 
A microstate $y$ is considered **subordinate** to the calibration $C$ if there exists at least one index $k$ ($1 \le k \le n$) satisfying both of the following conditions:
1. $y_k \le c_k$
2. For all $i < k$, $y_i = 4$.
(Note that for indices $j > k$, the value of $y_j$ can be any integer from $\{1, 2, 3, 4\}$).

The penalty $W(C)$ is exactly the total number of distinct microstates $y$ that are subordinate to $C$.

If it is impossible to find a stable calibration, report that no solution exists.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the number of particles and the number of interacting pairs, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that particle $u$ and particle $v$ form an interacting pair.

## Output
If no stable calibration can be formed, print a single line containing `NO`.
If a stable calibration is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i \in \{1, 2, 3\}$ is the energy state assigned to particle $i$. If there are multiple stable calibrations, you must output the sequence that minimizes the structural penalty $W(C)$.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
I removed the explicit base-4 positional polynomial and replaced it with a combinatorial counting problem (the number of subordinate microstates). This counting problem mathematically evaluates to exactly the same base-4 integer, but forces the model to perform multi-step mathematical deduction to realize it. If the model fails to deduce that the objective is equivalent to lexicographical minimization, it will not know to use an early-stopping DFS and will TLE when evaluating sparse graphs.
</RATIONALE>
<PRESERVED_ANSWER>
The combinatorial definition of the penalty mathematically simplifies to exactly the same base-4 polynomial as the original problem, so the tie-breaking condition and the optimal sequence remain strictly identical for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains finding a valid 3-coloring of a graph, which is NP-complete, and the tie-breaking evaluation adds only polynomial (or implicitly zero) overhead once simplified.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the microstate definition if they fail to realize that the conditions for different $k$ are mutually exclusive, though the wording 'at least one index' is mathematically rigorous regardless of this realization.
</RISK>
