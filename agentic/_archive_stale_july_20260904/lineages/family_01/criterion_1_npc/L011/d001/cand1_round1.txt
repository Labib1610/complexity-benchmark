# Problem A — Channel Allocation

Time limit: 2 s   Memory limit: 256 MB

A wireless network deployment requires assigning each of $n$ access points to exactly one of three available frequency channels, labeled 1, 2, and 3. Certain pairs of access points have overlapping signal footprints. To prevent interference, any two access points with overlapping coverage must be configured to use different channels. Your task is to determine a valid channel assignment for all access points, or conclude that it cannot be done.

*Important:* The evaluation data includes carefully constructed worst-case scenarios for $n=40$. Algorithms that rely on straightforward sequential guessing will explore an excessive number of combinations and fail to run within the time limit.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the number of access points and the number of interference pairs, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that access point $u$ and access point $v$ have overlapping coverage.

## Output
If it is impossible to configure the network without interference, output a single line containing `NO`.
If a configuration is possible, output `YES` on the first line. On the second line, output $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i \in \{1, 2, 3\}$ is the channel assigned to access point $i$. If multiple valid configurations exist, you must output the one that is lexicographically smallest (i.e., comparing the sequence of assignments starting from $c_1$).

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
