<STATEMENT>
# Problem A — Polynomial Evaluation Sequence

Time limit: 2 s   Memory limit: 256 MB

You are tasked with finding a sequence of $n$ integer values $c_1, c_2, \ldots, c_n$. These values represent the evaluations of a polynomial $P(x)$ with real coefficients, of degree at most $n-1$, at the integral points $x = 1, 2, \ldots, n$.

To be valid, the sequence of evaluations must satisfy the following conditions:
1. Every evaluation $c_i = P(i)$ for $1 \le i \le n$ must be an integer chosen exactly from the set $\{1, 2, 3\}$.
2. You are given a list of specific index pairs. For every given pair $(u, v)$, the product of the polynomial's evaluations at these two points, $P(u) \cdot P(v)$, must not be a perfect square (i.e., it cannot equal the square of any integer).

If a valid polynomial exists, you do not need to output its coefficients. You only need to output the sequence of evaluations $C = (c_1, c_2, \ldots, c_n)$. 
If multiple valid sequences of evaluations exist, you must output the sequence that is lexicographically smallest. Specifically, given two distinct valid sequences $C$ and $C'$, configuration $C$ is strictly smaller than $C'$ if $c_k < c'_k$ at the lowest index $k$ where the two sequences differ. 
If no such polynomial can satisfy all conditions, report that no solution exists.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$), representing the number of evaluation points and the number of constraint pairs, respectively.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that the product $P(u) \cdot P(v)$ must not be a perfect square.

## Output
If no valid sequence of evaluations can be formed, print a single line containing `NO`.
If a valid sequence is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \ldots, c_n$, where each $c_i \in \{1, 2, 3\}$ is the value of $P(i)$. If there are multiple valid sequences, you must output the lexicographically smallest sequence.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```

<RATIONALE>
The graph-coloring structure is completely hidden behind a vacuous polynomial interpolation framing. By Lagrange's theorem, any sequence of $n$ values uniquely defines a polynomial of degree at most $n-1$, so this imposes no actual restriction. The inequality constraint is replaced by a non-linear arithmetic condition (product is not a perfect square), which for the domain {1, 2, 3} is exactly equivalent to inequality. This forces models to either see through the mathematical red herrings or fail attempting to solve non-linear integer systems.
</RATIONALE>
<PRESERVED_ANSWER>
Lagrange interpolation guarantees that any sequence $c_1, \ldots, c_n$ corresponds to exactly one valid polynomial of degree $\le n-1$, and for values in {1,2,3}, their product is a perfect square if and only if they are equal, keeping the set of valid sequences identical.
</PRESERVED_ANSWER>
