**Solution Explanation**

For an edge `{u,v}` let  

```
d = c_u – c_v          (c_i ∈ {1,2,3})
E(u,v) = 5·d² – d⁴
```

`d` can only be `-2,-1,0,1,2`.

```
d = 0 :  E = 0
d = ±1 : E = 5·1 – 1 = 4
d = ±2 : E = 5·4 – 16 = 4
```

So an edge contributes **4** iff its ends have *different* colours,
otherwise **0**.

The required total energy is `4·m`.  
Therefore **every** of the `m` edges must have different colours on its
ends.  
The problem is exactly:

*colour the given graph with three colours {1,2,3} so that adjacent
vertices receive different colours, and output the lexicographically
smallest such colouring.*

If the graph is not 3‑colourable we output `NO`.

`n ≤ 40`, therefore a simple backtracking search is fast enough.
We try vertices in the natural order `1 … n`; at each vertex we try the
colours `1,2,3` in this order.  
The first complete colouring found is automatically the lexicographically
smallest one.

The recursion stops as soon as a vertex cannot be coloured
(because all three colours conflict with already coloured neighbours).

The algorithm:

```
col[1…n] = 0
DFS(v):
    if v > n:   solution found
    for colour in 1,2,3:
        if colour is different from col[neighbour] for every already coloured neighbour:
            col[v] = colour
            if DFS(v+1): return True
            col[v] = 0
    return False
```

If `DFS(1)` succeeds we print the colours, otherwise `NO`.

The search tree has at most `3ⁿ` nodes, but strong pruning (a vertex has at
most `n-1` neighbours) makes it tiny for `n ≤ 40`.  
The program runs easily within the limits.

---

**Correctness Proof**

We prove that the algorithm outputs `YES` and the lexicographically
smallest proper 3‑colouring iff such a colouring exists.

*Lemma 1*  
For any edge `{u,v}` the contribution `E(u,v)` equals `4` iff `c_u ≠ c_v`,
and equals `0` otherwise.

*Proof.* Computation above shows the value for all possible differences.
∎

*Lemma 2*  
A colouring satisfies the required total energy `4·m` **iff** it is a proper
3‑colouring (adjacent vertices have different colours).

*Proof.* By Lemma&nbsp;1 each edge contributes `4` exactly when its ends differ.
The total sum is `4·(#edges with different ends)`. To reach `4·m` all `m`
edges must have different ends, i.e. the colouring is proper. ∎

*Lemma 3*  
During DFS, when the algorithm assigns a colour to vertex `v`,
all already coloured neighbours of `v` have different colours from it.

*Proof.* The algorithm checks this condition before assigning the colour.
∎

*Lemma 4*  
If the algorithm reaches `v = n+1`, the obtained array `col[1…n]` is a
proper 3‑colouring.

*Proof.* By Lemma&nbsp;3 every edge whose both ends are ≤ `n` has different
colours, i.e. all edges are properly coloured. ∎

*Lemma 5*  
If a proper 3‑colouring exists, DFS will eventually find one.

*Proof.* Consider any proper colouring `C`. The DFS explores colours for
vertex 1 in order `1,2,3`. Since `C₁` is one of them, the branch where
`col[1]=C₁` is taken. Inductively, assuming the recursion has followed the
prefix `C₁…C_{v-1}`, vertex `v` can be coloured with `C_v` because all its
already coloured neighbours (a subset of `{1…v-1}`) differ from `C_v` in `C`.
Thus the branch matching `C` is never pruned and reaches depth `n+1`. ∎

*Lemma 6*  
The first complete colouring found by the DFS is the lexicographically
smallest proper 3‑colouring.

*Proof.* Vertices are processed in increasing index order, and for each
vertex colours are tried in increasing order. DFS is depth‑first, so it
fully explores the smallest possible colour for the current vertex before
trying a larger one. Consequently, the first leaf reached corresponds to
the smallest sequence in lexicographic order among all leaves (i.e. all
proper colourings). ∎

*Theorem*  
The program outputs `YES` and the lexicographically smallest sequence
`c₁…c_n` exactly when a stable configuration exists; otherwise it outputs
`NO`.

*Proof.*  
- If the program prints `YES`, by Lemma&nbsp;4 the printed sequence is a
proper 3‑colouring, hence by Lemma&nbsp;2 a stable configuration.
- If a stable configuration exists, a proper 3‑colouring exists.
  By Lemma&nbsp;5 DFS finds a proper colouring, and by Lemma&nbsp;6 the
  first one found is the lexicographically smallest, which the program
  outputs as `YES`.
- If no proper 3‑colouring exists, DFS explores the whole search space
  without reaching depth `n+1` and returns `False`; the program prints
  `NO`. ∎



---

**Complexity Analysis**

Let `Δ` be the maximum degree of the graph (`Δ ≤ n-1`).

For each vertex we try at most 3 colours and check at most `Δ` neighbours.

```
Time   ≤  Σ over visited nodes (3·Δ)  = O(3ⁿ·Δ)   (worst case)
```

In practice the pruning makes the visited nodes far fewer; for `n ≤ 40`
the program runs well within 2 seconds.

```
Memory = O(n + m)          (adjacency lists and colour array)
```

Both limits satisfy the constraints.

**Reference Implementation (Python 3)**

```python
import sys

sys.setrecursionlimit(10000)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    col = [0] * n  # 0 = uncolored, else 1..3

    def dfs(v: int) -> bool:
        if v == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[v]:
                if nb < v and col[nb] == c:
                    ok = False
                    break
            if not ok:
                continue
            col[v] = c
            if dfs(v + 1):
                return True
            col[v] = 0
        return False

    if dfs(0):
        print("YES")
        print(' '.join(map(str, col)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and
conforms to the required input‑output format.
