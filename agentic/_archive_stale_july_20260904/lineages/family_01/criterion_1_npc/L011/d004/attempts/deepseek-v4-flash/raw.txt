We can analyze the interaction energy formula:

\[
E(u,v) = 5(c_u - c_v)^2 - (c_u - c_v)^4
\]

Possible differences \(d = c_u - c_v\) are \(-2, -1, 0, 1, 2\):

- \(d = 0\): \(E = 0\)
- \(d = \pm 1\): \(E = 5 - 1 = 4\)
- \(d = \pm 2\): \(E = 5 \cdot 4 - 16 = 20 - 16 = 4\)

So every pair contributes **4** if the two particles have different energy levels, and **0** if they are the same.

Thus, the total energy is \(4 \times\) (number of pairs with different energy levels).  
We need this to equal \(4m\), so **every pair must have different energy levels**.

That means the graph must be 3-colorable, and we need the lexicographically smallest 3-coloring with colors \(\{1,2,3\}\).

This is a graph coloring problem with \(n \le 40\), so we can use backtracking with pruning.

```python
import sys

def solve():
    input_data = sys.stdin.read().strip().split()
    if not input_data:
        return
    it = iter(input_data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in (1, 2, 3):
            ok = True
            for nb in adj[idx]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[idx] = c
                if backtrack(idx + 1):
                    return True
                colors[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
