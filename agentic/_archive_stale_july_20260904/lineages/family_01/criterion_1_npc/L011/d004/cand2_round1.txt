# Problem A — Cycle Synchronization

Time limit: 2 s   Memory limit: 256 MB

You are deploying a distributed processing network consisting of $n$ processing units. Each unit $i$ (for $1 \le i \le n$) must be assigned a cycle multiplier $c_i$. To ensure synchronization with the main hardware clock, each $c_i$ must be a positive integer whose square is strictly less than 10.

The network's architecture includes $m$ shared memory buses, each connecting a specific pair of units $u$ and $v$. To prevent data collisions on a shared bus, the cycle multipliers of the two connected units must satisfy the condition $(c_u - c_v)^2 > 0$. 

A complete network configuration is represented as a sequence of $n$ integers $C = (c_1, c_2, \ldots, c_n)$. A configuration is valid if and only if the collision prevention condition is satisfied for all $m$ shared buses.

Every configuration has an associated latency footprint, calculated exactly as $L = \sum_{i=1}^n c_i \cdot 5^{n-i}$. If multiple valid configurations exist, you must output the sequence $C$ that minimizes this latency footprint. If it is impossible to configure the network to satisfy all bus conditions simultaneously, report that no solution exists.

## Input
The first line provides two integers $n$ and $m$, representing the number of processing units and the number of shared memory buses, respectively. The system can support a number of processing units $n$ ranging from 1 up to the total number of pins on a standard dual in-line package (DIP) that features exactly two rows of 20 pins. The number of shared memory buses $m$ is a non-negative integer up to the theoretical maximum where every distinct pair of units shares exactly one bus.

The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$, $u \neq v$), indicating that processing unit $u$ and processing unit $v$ are connected by a shared memory bus.

## Output
If no valid network configuration can be formed, print a single line containing `NO`.
If a valid configuration is possible, print `YES` on the first line. On the second line, print $n$ integers $c_1, c_2, \ldots, c_n$, where $c_i$ is the cycle multiplier assigned to processing unit $i$. If there are multiple valid assignments, you must output the sequence that minimizes the latency footprint.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
