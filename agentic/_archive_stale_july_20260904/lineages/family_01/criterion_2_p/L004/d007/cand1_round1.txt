# Problem B — Memory Block Balancing

Time limit: 1 s
Memory limit: 256 MB

A backend architecture consists of $n$ microservices. You must assign each microservice a scaling factor $z_i$, which must be either $1$ or $2$.

The system processes $m$ synchronous workflows. Each workflow depends on a specific pair of microservices. 
When a workflow connects microservice $u$ and microservice $v$, it allocates a memory block modeled mathematically as a rectangle of width $z_u$ and height $z_v$.

To meet strict latency requirements, the system must be perfectly balanced. The architecture is perfectly balanced if the sum of the squares of the diagonals of all $m$ rectangles is exactly $2.5$ times the sum of their areas.

Determine if it is possible to assign a valid scaling factor to all $n$ microservices such that the system is perfectly balanced.

## Input
The first line contains two integers $n$ and $m$. The architecture requires at least one microservice, while hardware limits prevent the system from exceeding $200,000$ microservices. The workflow queue can be entirely empty, but cannot exceed $200,000$ active workflows.
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of the two microservices that a workflow depends on.

## Output
If no valid assignment is possible, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $z_1 \dots z_n$ (where each $z_i \in \{1,2\}$) representing the valid assignment. If multiple valid assignments exist, output the lexicographically smallest sequence $z_1 \dots z_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I converted the local edge-by-edge resonance requirement into a single global geometric equation (sum of squared diagonals equals $2.5$ times sum of areas) and restated the bounds indirectly as physical system limits. This forces the model to algebraically prove that the global equality can only be satisfied if every individual pair consists of distinct values, preventing it from immediately pattern-matching the local constraint to graph bipartiteness.
</RATIONALE>
<PRESERVED_ANSWER>
Because the function $x^2+y^2 - 2.5xy \le 0$ for all $x,y \in \{1,2\}$ and equals $0$ only when $x \neq y$, the global sum is exactly balanced if and only if every edge connects distinct values, making the valid configurations identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains mathematically equivalent to finding a valid 2-coloring of a graph, keeping it in P and solvable in $O(n+m)$ via BFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "sum of the squares of the diagonals" as the square of the sum, though standard mathematical English heavily favors the intended meaning.
