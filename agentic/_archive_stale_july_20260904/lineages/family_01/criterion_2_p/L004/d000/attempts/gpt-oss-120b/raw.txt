**Solution Explanation**

For every server we have to choose a zone `1` or `2` such that the two
servers of each interfering pair are in different zones.
That is exactly the *bipartite graph* problem.

If the graph is not bipartite the answer is `NO`.
Otherwise many assignments exist – we have to output the **lexicographically
smallest** one.

--------------------------------------------------------------------

#### 1.   Observations  

* In a connected component of a bipartite graph the vertices are split into
  two colour classes `C0` and `C1`.  
  Flipping the whole component (`C0 ↔ C1`) yields another valid assignment.

* Lexicographic order is decided by the first position where two assignments
  differ.  
  Therefore we can treat each component **independently**:
  the smallest numbered vertex of the component is the first position that
  can be influenced by this component.
  To obtain the smallest possible value there, we simply give this vertex
  zone `1`.  
  Consequently the whole component gets a fixed orientation:
  the colour class containing the smallest vertex receives zone `1`,
  the other class receives zone `2`.

* While scanning vertices `1 … n` the first unvisited vertex is exactly the
  smallest vertex of its component, so we can decide the orientation
  immediately when we start a BFS/DFS from it.

--------------------------------------------------------------------

#### 2.   Algorithm  

```
read n, m
build adjacency list G (1‑based)

colour[1…n] = -1          # -1 = unvisited, 0/1 = temporary bipartite colour
answer[1…n] = 0           # final zones (1 or 2)

for v = 1 … n:
    if colour[v] != -1: continue          # already processed component

    # start new component, v is its smallest vertex
    queue = [v]
    colour[v] = 0                         # temporary colour 0
    component_vertices = [v]

    while queue not empty:
        x = pop queue
        for each neighbour y of x:
            if colour[y] == -1:
                colour[y] = colour[x] ^ 1
                queue.append(y)
                component_vertices.append(y)
            elif colour[y] == colour[x]:
                print "NO" and exit        # not bipartite

    # orientation: colour 0 gets zone 1, colour 1 gets zone 2
    for u in component_vertices:
        answer[u] = 1 if colour[u] == 0 else 2

print "YES"
print answer[1] … answer[n] separated by spaces
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints the lexicographically smallest valid assignment.

---

##### Lemma 1  
During the BFS of a component the algorithm assigns temporary colours
`0/1` exactly as in a standard bipartite check.  
If it ever discovers an edge whose ends have the same temporary colour,
the component (hence the whole graph) is not bipartite.

**Proof.**  
The BFS starts with colour `0` for the start vertex.
Whenever it traverses an edge `(x, y)` it gives `y` the opposite colour
`colour[x] xor 1`. This is precisely the definition of a 2‑colouring.
If later an edge connects two vertices already coloured equally,
they must belong to the same colour class, contradicting the requirement
that adjacent vertices have different colours. ∎



##### Lemma 2  
If the algorithm finishes without printing `NO`, the produced `answer`
is a valid zone assignment (no interfering pair shares a zone).

**Proof.**  
For every component the algorithm performed a BFS that never hit the
conflict of Lemma&nbsp;1, therefore the temporary colours form a proper
2‑colouring of that component.
The final zones are obtained by mapping temporary colour `0 → 1`,
`1 → 2`. Adjacent vertices have opposite temporary colours, thus opposite
zones. ∎



##### Lemma 3  
For each connected component the algorithm assigns zone `1` to its smallest
vertex.

**Proof.**  
The outer loop visits vertices in increasing order.
When it meets the first vertex `v` of a component, all vertices of this
component are still unvisited, so `v` is the smallest one.
The BFS colours `v` with temporary colour `0`, and later the algorithm maps
colour `0` to zone `1`. Hence `v` receives zone `1`. ∎



##### Lemma 4  
Among all valid assignments, the one produced by the algorithm is
lexicographically smallest.

**Proof.**  
Consider the vertices in order `1 … n`.  
Let `i` be the first index where the algorithm’s assignment could differ from
another valid assignment `B`.  
All vertices `< i` belong to components already processed, and by Lemma&nbsp;3
each of those components gives its smallest vertex zone `1`.  
Therefore any other valid assignment must also give those vertices zone `1`,
otherwise it would be lexicographically larger already at an earlier position.
Thus `i` is the smallest vertex of some component `C`.  
Our algorithm gives vertex `i` zone `1` (Lemma&nbsp;3).  
Any other valid assignment can give `i` either zone `1` or `2`.  
If it gives `2`, it is lexicographically larger at position `i`.  
If it gives `1`, then the orientation of component `C` coincides with ours,
so all vertices of `C` have the same zones as in our assignment.
Consequently no assignment can be lexicographically smaller. ∎



##### Lemma 5  
If a valid assignment exists, the algorithm never prints `NO`.

**Proof.**  
A valid assignment implies the graph is bipartite.
During each BFS the algorithm only fails when it discovers an edge whose
ends have equal temporary colours, which would contradict bipartiteness
(Lemma&nbsp;1). Since the graph is bipartite, this never happens. ∎



##### Theorem  
The algorithm outputs  

* `NO` **iff** no zone assignment satisfying the constraints exists;  
* otherwise `YES` followed by the lexicographically smallest valid assignment.

**Proof.**  
*If part*: If the algorithm prints `NO`, by Lemma&nbsp;1 a component is not
bipartite, therefore no 2‑colouring (and no zone assignment) exists.

*Only‑if part*: If a valid assignment exists, the graph is bipartite,
so by Lemma&nbsp;5 the algorithm does not print `NO`.  
It finishes and, by Lemma&nbsp;2, outputs a valid assignment.
By Lemma&nbsp;4 this assignment is lexicographically smallest. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)` time.  

Total time `O(n + m)` ≤ `4·10⁵`, well inside the limits.  
Memory: adjacency list (`2m` integers) + a few arrays of size `n` → `O(n + m)`.

--------------------------------------------------------------------

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        g[u].append(v)
        g[v].append(u)

    colour = [-1] * (n + 1)          # temporary 0/1
    ans = [0] * (n + 1)              # final zones 1/2

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # new component, start is its smallest vertex
        q = deque([start])
        colour[start] = 0
        comp = [start]

        while q:
            x = q.popleft()
            cx = colour[x]
            for y in g[x]:
                if colour[y] == -1:
                    colour[y] = cx ^ 1
                    q.append(y)
                    comp.append(y)
                elif colour[y] == cx:
                    sys.stdout.write("NO")
                    return

        # orientation: colour 0 -> zone 1, colour 1 -> zone 2
        for v in comp:
            ans[v] = 1 if colour[v] == 0 else 2

    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
