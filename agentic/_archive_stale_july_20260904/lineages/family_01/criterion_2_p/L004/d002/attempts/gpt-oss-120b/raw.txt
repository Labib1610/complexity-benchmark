**Solution Explanation**

For every synchronization link `(u , v)` we need  

```
band[u] * band[v] = 2
```

The only possible bands are `1` and `2`, therefore the two ends of every edge must
have *different* bands.
So the problem is exactly:

*Is the given undirected graph bipartite?*  
If it is, output a 2‑colouring with colours `{1,2}` that is lexicographically
smallest.

--------------------------------------------------------------------

#### 1.   Bipartite test and construction  

We run a BFS/DFS on each connected component.

* `col[x] = 0`  → we will output band `1` for `x`  
* `col[x] = 1`  → we will output band `2` for `x`

During the search we assign the start vertex of the component colour `0`
(the smallest index of the component, because we iterate vertices `1 … n`).
All neighbours receive the opposite colour.
If we ever meet an already coloured neighbour with the **same** colour,
the graph is not bipartite → answer `NO`.

Because a whole component can be flipped (`0 ↔ 1`) without breaking any edge,
choosing colour `0` for the smallest index of the component makes the whole
assignment lexicographically minimal:
the first differing position between any two valid assignments belongs to the
first vertex of some component, and we give it the smallest possible value `1`.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n, m
build adjacency list G
col = array of -1 (unvisited)

for v = 1 .. n:
    if col[v] == -1:
        col[v] = 0                     # start colour = 0  → band 1
        queue = [v]
        while queue not empty:
            x = pop queue
            for each y in G[x]:
                if col[y] == -1:
                    col[y] = col[x] ^ 1
                    push y
                elif col[y] == col[x]:
                    print "NO" and exit

print "YES"
output band[i] = 1 if col[i]==0 else 2   for i = 1..n
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `YES` and a correct lexicographically
smallest assignment iff such an assignment exists.

---

##### Lemma 1  
During BFS of a component, the algorithm assigns opposite colours to the
endpoints of every processed edge.

**Proof.**  
When an edge `(x, y)` is examined:
* if `y` is uncoloured, we set `col[y] = col[x] ^ 1`, i.e. opposite.
* if `y` is already coloured, the algorithm checks `col[y] != col[x]`.  
  If they were equal we would abort with `NO`. ∎



##### Lemma 2  
If the algorithm finishes without aborting, the obtained colouring satisfies
`band[u] * band[v] = 2` for every edge.

**Proof.**  
By Lemma&nbsp;1 the two ends of each edge have opposite colours.
`col = 0` → band `1`, `col = 1` → band `2`.  
Thus one endpoint has band `1`, the other `2`; their product is `2`. ∎



##### Lemma 3  
If the algorithm aborts with `NO`, the graph is not bipartite, i.e. no valid
assignment exists.

**Proof.**  
Abort happens only when an edge `(x, y)` is found with `col[x] == col[y]`.
Both vertices belong to the same connected component, and all previously
coloured vertices respect the opposite‑colour rule (induction on BFS steps).
Hence the component contains an odd cycle, which makes it non‑bipartite.
A non‑bipartite graph cannot be 2‑coloured, therefore no assignment exists. ∎



##### Lemma 4  
If the graph is bipartite, the algorithm never aborts.

**Proof.**  
A bipartite graph admits a 2‑colouring. BFS starting from any vertex and always
assigning the opposite colour to neighbours reproduces *some* valid 2‑colouring,
so the situation of Lemma&nbsp;3 never occurs. ∎



##### Lemma 5  
The output produced when the algorithm succeeds is the lexicographically
smallest among all valid assignments.

**Proof.**  
Consider the components in increasing order of their smallest vertex index.
When the algorithm reaches the first vertex `v` of a component, it forces
`col[v]=0` → band `1`. Any valid assignment must give either `1` or `2` to `v`.
Choosing `1` is strictly smaller, and flipping the whole component (changing
all `1↔2`) is the only way to alter `v` while keeping validity.
Thus any other valid assignment either coincides with ours on `v` or is larger
at position `v`. By induction over components the whole sequence is
lexicographically minimal. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no assignment satisfying the condition exists;  
* otherwise `YES` and the lexicographically smallest assignment.

**Proof.**  

*If the algorithm prints `NO`*: by Lemma&nbsp;3 the graph is non‑bipartite,
hence no assignment exists.

*If the algorithm prints `YES`*: by Lemma&nbsp;4 the graph is bipartite,
so a valid assignment exists. Lemma&nbsp;2 shows the produced assignment is
valid, and Lemma&nbsp;5 shows it is lexicographically smallest.

Conversely, if a valid assignment exists, the graph is bipartite,
so by Lemma&nbsp;4 the algorithm does not abort and prints `YES`. ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)` time.  

Total: **Time `O(n + m)`**, **Memory `O(n + m)`**, well within limits.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        g[u].append(v)
        g[v].append(u)

    col = [-1] * (n + 1)          # -1 = unvisited, 0 -> band 1, 1 -> band 2
    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        col[start] = 0
        q = deque([start])
        while q:
            x = q.popleft()
            cx = col[x]
            for y in g[x]:
                if col[y] == -1:
                    col[y] = cx ^ 1
                    q.append(y)
                elif col[y] == cx:
                    sys.stdout.write("NO")
                    return

    # success
    out = ['YES\n']
    out.append(' '.join('1' if col[i] == 0 else '2' for i in range(1, n + 1)))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```
