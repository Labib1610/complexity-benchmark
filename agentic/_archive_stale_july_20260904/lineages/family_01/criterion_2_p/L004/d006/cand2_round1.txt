# Problem B — Microservice Module Allocation

Time limit: 1 s
Memory limit: 256 MB

A backend architecture consists of $n$ microservices. You must assign each microservice a configuration level $z_i \in \{1, 2\}$.

The configuration levels determine the operational modules allocated to a microservice:
- Configuration level 1 allocates only the `Gateway` module.
- Configuration level 2 allocates both the `Gateway` and `Processor` modules.

The system processes $m$ synchronous workflows. Each workflow depends on a specific pair of microservices.
For a workflow to be balanced, the symmetric difference of the modules allocated to its two microservices (i.e., the set of modules allocated to exactly one of the two microservices, but not both) must be exactly the set containing only the `Processor` module.

Determine if it is possible to assign a valid configuration level to all $n$ microservices such that all $m$ workflows are balanced.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of the two microservices that a workflow depends on.

## Output
If no valid assignment is possible, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $z_1 \dots z_n$ (where each $z_i \in \{1,2\}$) representing the valid assignment. If multiple valid assignments exist, output the lexicographically smallest sequence $z_1 \dots z_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
