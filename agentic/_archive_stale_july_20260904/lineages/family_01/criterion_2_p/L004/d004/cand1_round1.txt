<STATEMENT>
# Problem B — Zone Isolation

Time limit: 1 s
Memory limit: 256 MB

A data center contains $n$ servers. You must assign a transmission band to each server. The only permitted bands are 1 and 2. 

The system has $m$ active synchronization links. Each link connects a specific pair of servers. For the network to remain stable, the band assignments must satisfy a continuous energy condition for every link. Specifically, for any two servers $u$ and $v$ connected by a link, if their assigned bands are $z_u$ and $z_v$, the link's energy profile function, defined for all real $x$ as:

$$E(x) = 2x^3 - 3(z_u + z_v)x^2 + 6 z_u z_v x$$

must possess exactly one local maximum and exactly one local minimum on the real number line.

Determine if a valid band configuration exists for all $n$ servers.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of a pair of servers connected by a synchronization link.

## Output
If no valid band configuration is possible, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $z_1 \dots z_n$ (where each $z_i \in \{1,2\}$) representing the valid assignment. If multiple valid assignments exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous versions allowed models to easily deduce bipartiteness by evaluating the simple discrete equation $1^3 + 2^3 = 9$. To remove this shortcut, the compatibility rule has been shifted to a continuous calculus property. Models must now differentiate the cubic function $E(x)$, find that its roots are exactly $z_u$ and $z_v$, and deduce that for local extrema to exist, the roots must be distinct ($z_u \neq z_v$). This forces genuine algebraic and logical reasoning before the graph reduction can even begin.
</RATIONALE>
<PRESERVED_ANSWER>
The derivative of $E(x)$ is $6(x - z_u)(x - z_v)$, which has two distinct roots (and thus creates local extrema) if and only if $z_u \neq z_v$; since the domain is $\{1, 2\}$, this is mathematically identical to the original requirement that connected servers have different bands.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in $O(n + m)$ using Breadth-First Search, keeping it in the P complexity class.
</PRESERVED_CLASS>
