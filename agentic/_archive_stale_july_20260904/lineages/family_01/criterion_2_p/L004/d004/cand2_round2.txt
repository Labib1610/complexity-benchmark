<STATEMENT>
# Problem B — Zone Isolation

Time limit: 1 s
Memory limit: 256 MB

A data center contains $n$ servers. You must assign a transmission band to each server. The only permitted bands are 1 and 2. 

The system has $m$ active synchronization links. Each link connects a specific pair of servers. For the network to remain stable, the band configuration must satisfy a precise resonance condition. Specifically, for any two servers $u$ and $v$ connected by a synchronization link, the definite integral
$$ \int_0^3 (x - z_u)(x - z_v) \, dx $$
must evaluate to exactly $1.5$ (where $z_u$ and $z_v$ are the constant band values assigned to servers $u$ and $v$).

Determine if a valid band configuration exists for all $n$ servers.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of a pair of servers connected by a synchronization link.

## Output
If no valid band configuration is possible, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $z_1 \dots z_n$ (where each $z_i \in \{1,2\}$) representing the valid assignment. If multiple valid assignments exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the algebraic cube-sum condition with a definite integral condition that evaluates to exactly 1.5 if and only if the two assigned bands are distinct. This forces the model to evaluate the integral for all possible pairs in the domain {1, 2} to discover the underlying bipartiteness constraint. Furthermore, I strictly restored the exact format of the input bounds as requested by the gate feedback.
</RATIONALE>
<PRESERVED_ANSWER>
The definite integral of (x - z_u)(x - z_v) from 0 to 3 evaluates to 1.5 exactly when one band is 1 and the other is 2, making the condition logically identical to the original requirement that adjacent servers have different bands.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) time using BFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might incorrectly interpret the integral as requiring a continuous optimization over real numbers rather than simply evaluating it for the discrete domain of {1, 2}.
</RISK>
