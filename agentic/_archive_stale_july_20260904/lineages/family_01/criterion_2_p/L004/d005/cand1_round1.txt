# Problem B — Phase Configuration

Time limit: 1 s
Memory limit: 256 MB

You are calibrating a system of $n$ phase oscillators. Each oscillator $i$ must be configured with a phase state $z_i$. The only permitted phase states are 1 and 2.

The system features $m$ resonance pairings, each linking a specific pair of oscillators. To achieve absolute system resonance, the configuration must satisfy a global harmonic condition. 
For each resonance pairing connecting oscillator $u$ and oscillator $v$, you calculate its harmonic factor, defined as $(z_u \cdot z_v + 1)$. 
The system is considered perfectly resonant if and only if the overall product of the harmonic factors across all $m$ pairings is exactly $3^m$.

Determine if it is possible to assign a valid phase state to all $n$ oscillators such that this global harmonic condition is met.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of a pair of oscillators linked by a resonance pairing.

## Output
If no valid phase state assignment is possible, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $z_1 \dots z_n$ (where each $z_i \in \{1,2\}$) representing the valid assignment. If multiple valid assignments exist, output the lexicographically smallest sequence $z_1 \dots z_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I replaced the explicit local exclusion rule ("no two connected servers can have the same zone") with a global product equation over all pairings. Because the available states are 1 and 2, the harmonic factor $(z_u \cdot z_v + 1)$ can only evaluate to 2, 3, or 5. By unique prime factorization, the product of $m$ such factors equals $3^m$ if and only if every single factor is exactly 3, which mathematically forces $z_u \neq z_v$ for all edges. This forces the model to use mathematical deduction to uncover the local constraint rather than instantly pattern-matching the text to graph coloring.
</RATIONALE>
