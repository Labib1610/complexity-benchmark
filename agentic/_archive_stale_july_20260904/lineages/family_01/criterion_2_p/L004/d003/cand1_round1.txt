# Problem B — Zone Isolation

Time limit: 1 s
Memory limit: 256 MB

A data center contains $n$ servers. You must assign a transmission band to each server. The only permitted bands are 1 and 2. 

The system has $m$ active synchronization links. Each link connects a specific pair of servers. For the network to remain stable, the sum of the cubes of the bands assigned to any two servers connected by a synchronization link must be exactly 9.

Determine if a valid band configuration exists for all $n$ servers.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of a pair of servers connected by a synchronization link.

## Output
If no valid band configuration is possible, print a single line NO.
Otherwise, print YES on the first line. On the second line, print $n$ integers $z_1 \dots z_n$ (where each $z_i \in \{1,2\}$) representing the valid assignment. If multiple valid assignments exist, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I changed the local link rule from a product condition to a cubic sum condition ($x^3 + y^3 = 9$). This removes the specific affordance that models mapped directly to opposite colors, forcing them to mathematically deduce the $\{1,2\}$ mutual exclusion themselves. I did not add the suggested global divisibility constraint because doing so would change the lexicographically smallest assignment for some inputs, violating the Identical Answers constraint.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $x^3 + y^3 = 9$ for $x, y \in \{1,2\}$ is satisfied if and only if one band is 1 and the other is 2, making it logically identical to the original product condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using BFS or DFS.
</PRESERVED_CLASS>
