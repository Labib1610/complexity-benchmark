# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A manufacturing plant is organizing its $n$ staff members into two operational shifts, identified as shift 1 and shift 2. 

There are $m$ specialized tools, each assigned to a specific pair of staff members. To guarantee strict operational standards, every tool must be properly calibrated for both shifts. A tool is considered properly calibrated for a given shift if exactly one of its two assigned staff members is scheduled to work during that shift. If both assigned members are present during the same shift, they interfere with each other's calibration sequence; if neither is present, the sequence cannot be initiated.

You must determine an assignment of each staff member to exactly one shift (either shift 1 or shift 2) such that every tool is properly calibrated for both shift 1 and shift 2, or report that no such arrangement is possible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the two staff members assigned to a single tool.

## Output
If no valid shift arrangement exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $s_1, \dots, s_n$ (each $s_i \in \{1, 2\}$), where $s_i$ is the shift assigned to staff member $i$. If there are multiple valid arrangements, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the "at least one" coverage condition that spanned both shifts with an "exactly one" constraint evaluated independently per shift. This forces the model to logically deduce that "exactly one per shift" for a pair of workers is mathematically equivalent to requiring them to be in different shifts, blocking the immediate pattern match to bipartite coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that exactly one of the two assigned members is present during a shift is logically equivalent to requiring that they are assigned to different shifts, which perfectly matches the original problem's constraint that at least one member is present in each of the two shifts.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying constraint remains a strict inequality between pairs of variables over a binary domain, which is equivalent to 2-coloring a graph (bipartite checking) and remains solvable in linear time.
</PRESERVED_CLASS>
<RISK>
The phrase "its two assigned staff members" could theoretically be misinterpreted if a tool is assigned to the same worker twice ($u=v$), but this edge case evaluates to unsatisfiable in both the original and rewritten versions.
</RISK>
