We can model this as a **bipartite graph** problem.  
Each tool connects two staff members, and for a tool to be active in both shifts, the two staff members must be in **different shifts**.  

So the problem reduces to:  
- Can we 2-color the graph (bipartite check)?  
- If yes, output the lexicographically smallest assignment (shift 1 for the first possible member, etc.).

We’ll use BFS/DFS with coloring, and to get lexicographically smallest, we assign shift 1 to the smallest uncolored node when starting a new component.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(' '.join(str(c + 1) for c in color))
```
