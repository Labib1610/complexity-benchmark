<STATEMENT>
# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A manufacturing plant operates continuously across two daily schedules: schedule 1 and schedule 2. Each of the $n$ staff members must be permanently assigned to exactly one of these schedules.

There are $m$ specialized tools in the plant. Each tool is co-owned by a specific pair of staff members. A tool is handed off between its owners at the changeover between schedules. Therefore, during any active schedule, every tool must have exactly one of its two owners present.

You must determine an assignment of each staff member to either schedule 1 or schedule 2 that satisfies all tool hand-off constraints, or report that no such arrangement is possible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of staff members who co-own a tool.

## Output
If no valid schedule arrangement exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $s_1, \dots, s_n$ (each $s_i \in \{1, 2\}$), where $s_i$ is the schedule assigned to staff member $i$. If there are multiple valid arrangements, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Removed the explicit instruction that the two members of a pair "must be assigned to different teams". Replaced it with an operational requirement that "exactly one of its two owners [must be] present" during any active schedule. This forces the model to deduce the mutually exclusive assignment condition rather than immediately pattern-matching standard bipartite graph coloring phrasing.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that exactly one owner of a tool is present during any given schedule mathematically forces the two co-owners to be assigned to different schedules, preserving the exact same constraint graph and resulting in identical lexicographical outputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (or checking bipartiteness) of an undirected graph, which is solvable in O(n + m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "every tool must have exactly one of its two owners present" as meaning that all tools must be in use, but the wording clearly constrains the attendance of the *owners* rather than the usage of the tools.
</RISK>
