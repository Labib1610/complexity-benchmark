<STATEMENT>
# Problem B — Network Channels

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ communication nodes. Each node $i$ must be assigned a channel $c_i$ belonging to the set $\{1, 2\}$.

The network contains $m$ interference links. Each link connects exactly two specific nodes. 
To maintain a balanced signal across the network, the configuration must satisfy two global resonance conditions simultaneously:
1. The Total Linear Resonance, calculated as the sum of $(c_u + c_v)$ over all $m$ links (where $u$ and $v$ are the two nodes connected by the link), must be exactly $3m$.
2. The Total Multiplicative Resonance, calculated as the sum of $(c_u \cdot c_v)$ over all $m$ links, must be exactly $2m$.

(Note: If the network has zero links, both sums evaluate to an empty sum of $0$, which perfectly matches the required targets $3(0)$ and $2(0)$ for that case).

You must assign a channel to each of the $n$ nodes so that this stability requirement is met. If no such assignment is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$. The infrastructure is designed to support a maximum of two hundred thousand nodes, and there must be at least one node to form a network. The number of links can be anywhere from zero up to the same limit of two hundred thousand.
Each of the next $m$ lines contains two integers $u$ and $v$ — the two nodes connected by a single interference link.

## Output
If no valid channel assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$ (each $c_i \in \{1, 2\}$), where $c_i$ is the channel assigned to node $i$. If there are multiple valid assignments, output the one that is lexicographically smallest. An assignment sequence $A$ is lexicographically smaller than $B$ if, at the first index $i$ where they differ, $A_i < B_i$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The local constraint `c_u != c_v` was removed and replaced by a system of two global sums. Because the variables are restricted to `{1, 2}`, the only way both global sums can equal their targets is if every single edge locally evaluates to the `{1, 2}` state (which mathematically forces a bipartite coloring). This forces the model to algebraically solve the macroscopic linear system to deduce the local bipartite property, defeating models that rely on matching simple local constraints to known graph algorithms. Numeric bounds were also stated indirectly.
</RATIONALE>
<PRESERVED_ANSWER>
The system of equations for the counts of edge types (x for 1-1, y for 2-2, z for 1-2) uniquely solves to x=0, y=0, z=m, making the required conditions mathematically identical to requiring every link to connect different channels.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, keeping it in P and solvable via linear-time BFS.
</PRESERVED_CLASS>
