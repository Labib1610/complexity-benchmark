<METHOD_NAME>Geometric Constraint Disguise</METHOD_NAME>
<METHOD_DESCRIPTION>Replaced the algebraic edge constraint with a geometric tangency condition (circles with radii in {1,2} centered 3 units apart intersecting at exactly one point). This traps pattern-matching models into categorizing the task as computational geometry, while reasoning models will deduce that tangency requires the radii to sum to 3, meaning adjacent nodes must have different values, thereby revealing the underlying 2-coloring structure.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Network Channels

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ communication nodes. Each node $i$ must be assigned a signal radius $c_i$ belonging to the set $\{1, 2\}$.

The network contains $m$ interference links. Each link connects exactly two specific nodes. 
To maintain a balanced network, we define a stability condition for each link. For a link connecting node $u$ and node $v$, imagine drawing two circles of radii $c_u$ and $c_v$ on a 2D plane such that the distance between their centers is exactly 3 units. 
The configuration is considered stable if and only if, for every interference link in the network, the two circles corresponding to its nodes intersect at exactly one point (i.e., they are externally tangent).

You must assign a signal radius to each of the $n$ nodes so that this stability requirement is met for all links. If no such assignment is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the two nodes connected by a single interference link.

## Output
If no valid radius assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$ (each $c_i \in \{1, 2\}$), where $c_i$ is the radius assigned to node $i$. If there are multiple valid assignments, output the one that is lexicographically smallest. An assignment sequence $A$ is lexicographically smaller than $B$ if, at the first index $i$ where they differ, $A_i < B_i$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The conspicuous arithmetic equation `c_u^{c_v} + c_v^{c_u} = 3` immediately signaled an inequality constraint to models. I replaced this with an abstract geometric condition: two circles with radii from {1, 2} placed 3 units apart must intersect at exactly one point. A model must now genuinely reason about geometry to deduce that external tangency requires the radii to sum to 3, which in turn forces adjacent nodes to have different radii. Pattern-matching models are likely to misclassify this as a computational geometry problem.
</RATIONALE>
<PRESERVED_ANSWER>
Two circles centered 3 units apart intersect at exactly one point if and only if the sum of their radii is 3; since the radii must be chosen from {1, 2}, this strictly requires one radius to be 1 and the other to be 2, preserving the exact same valid configurations as the original arithmetic rule.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a lexicographically smallest 2-coloring of a graph, which is solvable in O(n + m) time using Breadth-First Search, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the geometric condition as implying the network nodes themselves have 2D coordinates, though the phrasing "imagine drawing two circles... on a 2D plane" is intended to isolate it as a purely mathematical edge constraint.
</RISK>
