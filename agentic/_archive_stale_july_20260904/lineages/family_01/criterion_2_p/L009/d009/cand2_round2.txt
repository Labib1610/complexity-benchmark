<METHOD_NAME>Global Sum of Asymmetric Node Potentials</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the transparent edge-local resonance equation with a global sum of node potentials. Each node's potential is defined as the sum of its neighbors' channels divided by its own channel. By changing the order of summation, this global node sum transforms into an edge sum where each edge contributes (c_u/c_v + c_v/c_u). The mathematical maximum of this sum is exactly 2.5m, which is achieved if and only if every edge connects a 1 and a 2. This forces the model to deduce a strict discrete bipartite constraint from a global continuous-looking equation, defeating surface-level pattern matching.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Network Channels

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ communication nodes. Each node $i$ must be assigned a channel $c_i \in \{1, 2\}$.

The network contains $m$ interference links. Each link connects exactly two specific nodes. 

To evaluate the stability of a configuration, we compute a local potential for each node. For any node $i$, its potential $P_i$ is defined as the sum of the channels of the nodes at the other end of all its incident interference links, divided by its own channel $c_i$. (If multiple links connect the same pair of nodes, the neighbor's channel is added once for each connecting link). If a node has no incident links, its potential is defined as $0$. 

The network configuration is considered stable if and only if the sum of the potentials of all $n$ nodes is exactly $2.5 \times m$.

You must assign a channel to each of the $n$ nodes so that this stability requirement is met. If no such assignment is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$) — the two nodes connected by a single interference link.

## Output
If no valid channel assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$ (each $c_i \in \{1, 2\}$), where $c_i$ is the channel assigned to node $i$. If there are multiple valid assignments, output the one that is lexicographically smallest. An assignment sequence $A$ is lexicographically smaller than $B$ if, at the first index $i$ where they differ, $A_i < B_i$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit edge-local resonance equation `c_u^{c_v} + c_v^{c_u} = 3` has been completely removed, as it allowed models to trivially isolate edges and test the `{1, 2}` combinations to discover the bipartite requirement. It is replaced by a global node-potential sum constraint. To recognize that this global sum requires proper 2-coloring, the model must mathematically deduce that the node sum is equivalent to an edge sum of `c_u/c_v + c_v/c_u`, and that the target value of `2.5m` is the strict theoretical maximum achievable only when every edge connects opposite channels.
</RATIONALE>
<PRESERVED_ANSWER>
The sum of all node potentials mathematically simplifies to the sum over all edges of `(c_u/c_v + c_v/c_u)`. For channels in `{1, 2}`, an edge contributes exactly 2 if the channels are the same, and 2.5 if they are different; thus, the total sum is 2.5m if and only if every edge connects a 1 and a 2, making the valid assignments identical to the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a proper 2-coloring (checking bipartiteness) and choosing the lexicographically smallest valid assignment, which is solved by Breadth-First Search in O(n + m) time, keeping it in P.
</PRESERVED_CLASS>
