**Solution Explanation**

For a link `u – v` the two circles must be *externally tangent*.
The distance of the centres is fixed to `3`, therefore the radii have to satisfy  

```
c_u + c_v = 3
```

The only allowed radii are `1` and `2`, consequently every edge must connect a
node with radius `1` to a node with radius `2`.

So we have to colour the graph with two colours such that adjacent vertices
receive different colours – exactly the definition of a *bipartite* graph.
If the graph is not bipartite the answer is `NO`.

If it is bipartite there are two possible colourings for each connected
component (they are each other's colour swap).  
We have to output the lexicographically smallest sequence
`c1 … cn` (`1 < 2`).  
Consider a component and let `v` be the smallest‑index vertex inside it.
All vertices with index `< v` belong to earlier components, already fixed.
Choosing colour `1` for `v` makes the whole sequence smaller than choosing `2`,
and it never harms any earlier component.  
Therefore the optimal rule is:

*for every component colour the side that contains its smallest index vertex
with radius `1`.*

The algorithm:

```
result[1…n] = 0
for every vertex not visited:
        BFS/DFS, colour with 0/1, check bipartite
        collect vertices of this component
        let v_min = minimum index in the component
        let col_min = colour[v_min]          # 0 or 1
        for each vertex x in component:
                if colour[x] == col_min: result[x] = 1
                else:                     result[x] = 2
```

If any edge is found with equal colours → not bipartite → `NO`.

Complexities  
`O(n + m)` time, `O(n + m)` memory – fits the limits (`2·10⁵`).

#### Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
valid assignment iff such an assignment exists.

---

##### Lemma 1  
For any edge `u‑v` the stability condition holds **iff**
`c_u` and `c_v` are different (one is `1`, the other `2`).

*Proof.*  
Stability requires external tangency, i.e. `c_u + c_v = 3`.  
The only possible radii are `1` and `2`; the only way to sum to `3` is
`{1,2}`. ∎



##### Lemma 2  
A radius assignment satisfying all links exists **iff** the graph is bipartite.

*Proof.*  
By Lemma&nbsp;1 every edge must join vertices of different radii, i.e. a
2‑colouring of the vertices. Such a colouring exists exactly for bipartite
graphs. ∎



##### Lemma 3  
For a bipartite connected component `C` let `v_min` be its smallest index
vertex and `col_min` its colour in an arbitrary 2‑colouring.
Assigning radius `1` to all vertices of colour `col_min` and radius `2` to the
others yields a valid assignment for `C`.

*Proof.*  
All edges of `C` join vertices of opposite colours, therefore opposite radii,
hence by Lemma&nbsp;1 they satisfy the stability condition. ∎



##### Lemma 4  
Among the two possible assignments for a component `C`,
the one that gives radius `1` to `v_min` is lexicographically smaller
than the other, regardless of the assignments of earlier components.

*Proof.*  
All vertices with index `< v_min` belong to earlier components, their values
are already fixed. At position `v_min` the two assignments differ: one puts
`1`, the other `2`. Since `1 < 2`, the whole sequence with `1` at this position
is lexicographically smaller. ∎



##### Lemma 5  
The algorithm outputs a valid assignment whenever the input graph is bipartite.

*Proof.*  
The BFS colours each component properly (conflict would have been detected).
By Lemma&nbsp;3 the conversion from colours to radii performed by the algorithm
is valid for every component, hence for the whole graph. ∎



##### Lemma 6  
The assignment produced by the algorithm is lexicographically minimal among
all valid assignments.

*Proof.*  
Consider components in increasing order of their minimal vertex index.
When the algorithm processes a component `C`, all earlier components are already
fixed to the minimal possible values (induction hypothesis).  
By Lemma&nbsp;4 the algorithm chooses, for `C`, the smaller of the two possible
assignments, therefore after fixing `C` the prefix up to the largest index of
`C` is minimal. Induction over components yields global minimality. ∎



##### Theorem  
The program prints  

* `NO` iff no valid radius assignment exists;  
* otherwise `YES` and the lexicographically smallest valid assignment.

*Proof.*  

- If the program prints `NO`, it discovered a same‑colour edge, i.e. the graph
  is not bipartite. By Lemma&nbsp;2 no assignment exists.

- If the program prints `YES`, the graph was bipartite, and by Lemma&nbsp;5
  the produced assignment is valid. By Lemma&nbsp;6 it is the lexicographically
  smallest one.

Conversely, if a valid assignment exists, the graph is bipartite
(Lemma&nbsp;2), the program never aborts with `NO`, and by the previous
paragraph it outputs the required answer. ∎

#### Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [ -1 ] * (n + 1)          # 0 / 1
    answer = [0] * (n + 1)
    from collections import deque

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        ok = True
        while q:
            u = q.popleft()
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = colour[u] ^ 1
                    q.append(v)
                    comp.append(v)
                elif colour[v] == colour[u]:
                    print("NO")
                    return
        # decide which colour gets radius 1
        v_min = min(comp)
        col_min = colour[v_min]
        for v in comp:
            answer[v] = 1 if colour[v] == col_min else 2

    # output
    print("YES")
    print(' '.join(str(answer[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
