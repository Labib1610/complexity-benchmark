<STATEMENT>
# Problem B — Alloy Formulation

Time limit: 1 s
Memory limit: 256 MB

You are developing a new alloy composed of $n$ micro-structures. Each micro-structure $i$ must be crystallized into one of two phase states, represented by a phase coefficient $p_i$ of either 1 or 2.

The material contains $m$ structural boundaries. Each boundary separates exactly two specific micro-structures. To maintain the stability of the alloy, the product of the phase coefficients assigned to any two micro-structures separated by a boundary must be exactly 2.

You must assign a phase coefficient to each of the $n$ micro-structures so that this requirement is met for all boundaries. If no such assignment is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the two micro-structures separated by a single structural boundary.

## Output
If no valid phase coefficient assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $p_1, \dots, p_n$ (each $p_i \in \{1, 2\}$), where $p_i$ is the phase coefficient assigned to micro-structure $i$. If there are multiple valid assignments, output the one that is lexicographically smallest. An assignment sequence $A$ is lexicographically smaller than $B$ if, at the first index $i$ where they differ, $A_i < B_i$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The problem was completely reframed into a materials science context, stripping out all network and graph terminology. Instead of asking for the sum of the variables to be 3, it asks for their product to be 2. This requires the model to perform an algebraic deduction to realize that for values restricted to {1, 2}, this constraint is mathematically identical to demanding different values.
</RATIONALE>
<PRESERVED_ANSWER>
Because the variables are strictly 1 or 2, the only way their product can be exactly 2 is if one is 1 and the other is 2, which is exactly the same condition as their sum being 3.
</PRESERVED_ANSWER>
