 We need to assign each node either channel 1 or 2 such that for every edge (u, v),  
the value \( c_u^{c_v} + c_v^{c_u} = 3 \).

Let’s check the possible cases:

- If \( c_u = 1, c_v = 1 \): \( 1^1 + 1^1 = 2 \) → not 3.
- If \( c_u = 1, c_v = 2 \): \( 1^2 + 2^1 = 1 + 2 = 3 \) → works.
- If \( c_u = 2, c_v = 1 \): \( 2^1 + 1^2 = 2 + 1 = 3 \) → works.
- If \( c_u = 2, c_v = 2 \): \( 2^2 + 2^2 = 4 + 4 = 8 \) → not 3.

So the only valid configuration is that every edge connects nodes of different channels.  
That means the graph must be bipartite, and we need to 2-color it.

We also need the lexicographically smallest assignment, so we start with node 1 as channel 1, then BFS/DFS assign alternating colors.

If we find a conflict (same color on both ends of an edge), output `NO`.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c + 1) for c in color))
```
