**Solution Explanation**

For every bridge `(u , v)` we need  

```
p_u² + p_v² = 5
```

`p_i` can only be `1` (`1² = 1`) or `2` (`2² = 4`).  
`1 + 4 = 5`, therefore the two ends of each bridge must have **different**
values.  
So the whole graph has to be *bipartite* and we have to colour its vertices
with two colours, later mapping the colours to the numbers `1` and `2`.

If the graph is not bipartite the answer is `NO`.

If it is bipartite we still have a choice: for each connected component we can
swap the two colour classes.  
To obtain the lexicographically smallest sequence `p₁ … p_n` we simply put
`1` on the colour class that contains the smallest‑indexed vertex of this
component – then the first vertex of the component (the smallest index) gets
value `1`, which is optimal for the whole sequence.

The algorithm:

```
read n, m
build adjacency list
colour[1…n] = -1   // -1 = unvisited, 0/1 = two colour classes
answer[1…n]

for each vertex v = 1 … n
    if colour[v] == -1
        BFS/DFS from v, colour the component with 0/1
        if a conflict appears → not bipartite → print NO
        collect all vertices of this component in a list comp
        find the vertex with minimal index min_v in comp
        let c = colour[min_v]          // colour of the minimal vertex
        // map colour c → 1, the other colour → 2
        for each x in comp
            answer[x] = 1 if colour[x] == c else 2

print YES and the answer array
```

`BFS` guarantees `O(n+m)` time, memory `O(n+m)`.

---

#### Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
valid assignment iff such an assignment exists.

---

##### Lemma 1  
If the algorithm finishes without detecting a conflict, the produced
assignment satisfies `p_u² + p_v² = 5` for every edge.

**Proof.**  
During BFS each visited edge connects vertices of opposite BFS colours
(`0` and `1`). After the component is processed we map one colour to `1`
and the other to `2`. Hence every edge connects a vertex with value `1`
and a vertex with value `2`. `1² + 2² = 5`. ∎



##### Lemma 2  
If the algorithm reports a conflict, no assignment of `{1,2}` can satisfy all
edges.

**Proof.**  
A conflict appears exactly when an edge connects two vertices that already
have the same BFS colour. Any assignment must give different numbers to the
ends of this edge, therefore the two vertices must belong to different colour
classes in any bipartition. The existence of an odd cycle (the reason for the
conflict) makes the graph non‑bipartite, so no 2‑colouring exists, consequently
no `{1,2}` assignment exists. ∎



##### Lemma 3  
For a bipartite connected component, among the two possible assignments
(`colour 0 → 1, colour 1 → 2` or the opposite) the one that gives value `1`
to the smallest‑indexed vertex of the component is lexicographically
smaller than the other.

**Proof.**  
Both assignments are identical on all vertices except that the two colour
classes are swapped. The smallest index where they differ is exactly the
smallest vertex of the component. In the chosen assignment this vertex gets
`1`, in the other it gets `2`. Since `1 < 2`, the chosen assignment is
lexicographically smaller. ∎



##### Lemma 4  
The algorithm’s assignment is lexicographically smallest among all valid
assignments.

**Proof.**  
Consider the vertices in increasing order. Let `v` be the first vertex where
the algorithm’s assignment could differ from some other valid assignment.
`v` belongs to a certain component `C`. By construction the algorithm maps
the colour of the smallest vertex of `C` to `1`. Since `v` is the first
difference, `v` must be that smallest vertex of `C`. Any other valid
assignment must either give `v` the same value (`1`) or the opposite value
(`2`). If it gives `2`, the sequence is lexicographically larger.
If it gives `1`, then on the whole component the mapping coincides with the
algorithm’s mapping (otherwise a later vertex would differ earlier). Hence
no assignment can be lexicographically smaller. ∎



##### Theorem  
The program outputs  

* `NO` iff no assignment of `{1,2}` satisfying all bridges exists;  
* otherwise `YES` and the lexicographically smallest such assignment.

**Proof.**  
*If the program prints `NO`*: this happens only when a conflict is found.
By Lemma&nbsp;2 no valid assignment exists.

*If a valid assignment exists*: the graph is bipartite, so BFS never finds a
conflict. By Lemma&nbsp;1 the produced assignment is valid. By Lemma&nbsp;4 it
is the lexicographically smallest among all valid assignments. Hence the
program prints `YES` and that assignment. ∎



---

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` time, `O(n + m)` memory.  
*BFS over all components*: each vertex and edge processed once → `O(n + m)`
time, `O(n)` extra memory for colour and component lists.  

Total: **Time `O(n + m)`**, **Memory `O(n + m)`**, well within limits.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 two colours
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        ok = True
        while q:
            u = q.popleft()
            cu = colour[u]
            for v in adj[u]:
                if colour[v] == -1:
                    colour[v] = cu ^ 1
                    q.append(v)
                    comp.append(v)
                elif colour[v] == cu:
                    # not bipartite
                    print("NO")
                    return
        # choose mapping: smallest index gets value 1
        min_v = min(comp)
        c_min = colour[min_v]
        for v in comp:
            ans[v] = 1 if colour[v] == c_min else 2

    # isolated vertices (no edges) are already handled: they form a component of size 1
    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
