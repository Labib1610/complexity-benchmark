<STATEMENT>
# Problem B — Quantum Circuit Calibration

Time limit: 1 s
Memory limit: 256 MB

You are calibrating a quantum circuit with $n$ qubits. Each qubit must be initialized to a basis state represented by the integer 1 or 2.

The circuit contains $m$ entanglement gates. Each gate operates on exactly two specific qubits. For the gate to maintain coherence, the basis states of the two qubits it operates on must have completely disjoint active bits that together cover the first two bits of the state register. Specifically, the bitwise AND of the two qubits' basis states must evaluate to exactly 0, and their bitwise XOR must evaluate to exactly 3.

You must assign a basis state to each of the $n$ qubits so that all $m$ entanglement gates maintain coherence. If no such calibration is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the two qubits operated on by a single entanglement gate.

## Output
If no valid calibration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $s_1, \dots, s_n$ (each $s_i \in \{1, 2\}$), where $s_i$ is the basis state assigned to qubit $i$. If there are multiple valid calibrations, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was completely reframed into a quantum computing scenario, and the core constraint ($p_u + p_v = 3$) was replaced with two bitwise operations ($p_u \& p_v = 0$ and $p_u \oplus p_v = 3$). This forces the model to evaluate the truth table of the bitwise operations over the restricted domain $\{1, 2\}$ to discover that it simply means $p_u \neq p_v$. Models that fail to make this deduction will likely attempt complex bitmask DP or 2-SAT formulations instead of recognizing the underlying bipartite coloring structure.
</RATIONALE>
<PRESERVED_ANSWER>
Since the variables are restricted to the set $\{1, 2\}$, the only pair of values that satisfies $x \& y = 0$ and $x \oplus y = 3$ is one $1$ and one $2$, which is mathematically identical to the original constraint $x + y = 3$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a 2-coloring of a graph (or testing bipartiteness), which is solvable in linear time using BFS/DFS.
</PRESERVED_CLASS>
