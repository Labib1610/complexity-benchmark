**Solution Explanation**

For each crystal we may choose one of two arrays  

```
A1 = [1,2,3]          (identity permutation)
A2 = [2,1,3]          (swap 1 and 2)
```

For a bridge `(u , v)` the combined array is the composition  

`C = V_u ∘ V_v` .  
Both `V_u , V_v` are involutions (`V = V⁻¹`).  
The composition of two involutions of size 3 is either

* identity – 0 inversions
* swap (12) – 1 inversion

The problem requires **exactly one inversion**, therefore for every bridge we must have  

`V_u ∘ V_v = swap(12)`.

Because `V_v = V_v⁻¹` this is equivalent to  

`V_u = swap(12) ∘ V_v`.

Consequences  

* if `V_v = A1` (identity) then `V_u = A2`
* if `V_v = A2` (swap)   then `V_u = A1`

Thus the two ends of each bridge must receive **different** arrays.
If we encode `p_i = 1` for `A1` and `p_i = 2` for `A2`,
the condition becomes

```
for every edge (u , v) :   p_u ≠ p_v
```

So the whole graph must be **bipartite**.  
If it is not bipartite the answer is `NO`.

--------------------------------------------------------------------

### Lexicographically smallest assignment

When the graph is bipartite, each connected component has exactly two
valid colourings (the two sides may be swapped).
To obtain the lexicographically smallest whole sequence we handle the
components in increasing order of vertex index.

For a component we colour it arbitrarily (first vertex colour 0, the other
side colour 1).  
Let `x` be the smallest vertex index inside this component.
If `x` currently has colour 1 we flip the whole component
(colour ← 1‑colour).  
After this operation `x` is coloured 0, i.e. `p_x = 1`,
which is optimal for the earliest position of the component.
All later vertices are forced by the bipartite edges, therefore the
obtained assignment is the lexicographically smallest possible.

--------------------------------------------------------------------

### Algorithm
```
read n, m
build adjacency list
col[1…n] = -1                     // -1 = unvisited, 0/1 = colour
ans[1…n] = 0

for v = 1 … n
    if col[v] == -1
        BFS/DFS from v, set col[v] = 0
        store all vertices of this component in list comp
        during search, if an edge connects two vertices with same colour → NOT bipartite → print NO

        minv = minimum index in comp
        if col[minv] == 1               // need to flip whole component
            for u in comp: col[u] ^= 1

        for u in comp: ans[u] = col[u] + 1   // 0→1 , 1→2

print YES
print ans[1] … ans[n]
```

`O(n+m)` time, `O(n+m)` memory.

--------------------------------------------------------------------

### Correctness Proof  

We prove that the algorithm prints `YES` and a lexicographically smallest
valid assignment iff such an assignment exists.

---

#### Lemma 1  
For any edge `(u,v)` the condition “the combined array has exactly one
inversion” is equivalent to `p_u ≠ p_v`.

*Proof.*  
`V_u , V_v` are either identity (`A1`) or swap (`A2`).  
Both are involutions, therefore `V_u ∘ V_v` equals `A2` iff the two
permutations are different, otherwise it equals `A1`.  
`A2` has one inversion, `A1` has none. ∎



#### Lemma 2  
A labeling `p_1…p_n` satisfies all bridges **iff** the graph is bipartite
with the two colour classes corresponding to value 1 and value 2.

*Proof.*  
By Lemma&nbsp;1 each edge requires its ends to have different values,
exactly the definition of a proper 2‑colouring of the graph. ∎



#### Lemma 3  
If the algorithm finishes without printing `NO`, the produced array `ans`
satisfies all bridges.

*Proof.*  
During each BFS the algorithm assigns colours `0/1` so that adjacent
vertices receive opposite colours; otherwise it would have detected a
conflict and printed `NO`.  
After possibly flipping a whole component, opposite colours are still
opposite, therefore for every edge its ends have different colours,
hence different `p` values. By Lemma&nbsp;1 all bridges have exactly one
inversion. ∎



#### Lemma 4  
For every connected component the algorithm chooses the orientation that
makes the smallest‑index vertex of the component receive value 1.

*Proof.*  
The component is first coloured arbitrarily, then the algorithm checks
the colour of its minimum vertex `minv`.  
If it is `1` (value 2) the whole component is flipped, turning `minv`
into colour 0 (value 1). No other vertices change relative order inside
the component. ∎



#### Lemma 5  
The whole array `ans` is lexicographically minimal among all valid
assignments.

*Proof.*  
Consider the vertices in increasing order.
When the first vertex of a component is reached, by Lemma 4 it already
has value 1, which is the smallest possible value for that position.
All later vertices of the same component are forced by the bipartite
edges, so their values are uniquely determined.
Thus no other valid assignment can have a smaller value at the first
position where the two assignments differ. ∎



#### Lemma 6  
If the graph is bipartite, the algorithm never prints `NO`.

*Proof.*  
In a bipartite graph a proper 2‑colouring exists.
The BFS performed by the algorithm exactly constructs such a colouring,
so no edge ever connects vertices of the same colour, and the conflict
test never triggers. ∎



#### Theorem  
The algorithm outputs  

* `NO`  **iff** no assignment of multipliers satisfies all bridges;  
* otherwise `YES` and the lexicographically smallest valid assignment.

*Proof.*  

*If part:*  
If the algorithm prints `NO`, it happened because an edge joined two
vertices with the same colour during BFS. By Lemma 2 this means the graph
is not bipartite, hence by Lemma 2 no valid assignment exists.

*Only‑if part:*  
Assume a valid assignment exists. By Lemma 2 the graph is bipartite.
By Lemma 6 the algorithm does not output `NO`.  
By Lemma 3 the produced `ans` satisfies all bridges, and by Lemma 5 it
is lexicographically minimal among all such assignments. ∎

### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [-1] * (n + 1)          # 0 or 1, -1 = unvisited
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        # BFS for this component
        q = deque([start])
        col[start] = 0
        comp = []
        while q:
            v = q.popleft()
            comp.append(v)
            for nb in adj[v]:
                if col[nb] == -1:
                    col[nb] = 1 - col[v]
                    q.append(nb)
                elif col[nb] == col[v]:
                    print("NO")
                    return
        # make smallest index vertex have colour 0 (value 1)
        minv = min(comp)
        if col[minv] == 1:
            for v in comp:
                col[v] ^= 1
        for v in comp:
            ans[v] = col[v] + 1   # 0->1, 1->2

    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```

and conforms to the required time and memory limits.
