 We have two possible values for each crystal: 1 or 2.  
The condition for each edge (u, v) is that the combined array  
C = [ V_u[ V_v[1] ], V_u[ V_v[2] ], V_u[ V_v[3] ] ]  
must have exactly one inversion.

Let’s compute the possible combinations:

- If both u and v have p=1:  
  V_u = [1,2,3], V_v = [1,2,3]  
  C = [1,2,3] → 0 inversions → invalid.

- If u=1, v=2:  
  V_u = [1,2,3], V_v = [2,1,3]  
  C = [ V_u[2], V_u[1], V_u[3] ] = [2,1,3] → inversions: (2,1) → 1 inversion → valid.

- If u=2, v=1:  
  V_u = [2,1,3], V_v = [1,2,3]  
  C = [ V_u[1], V_u[2], V_u[3] ] = [2,1,3] → 1 inversion → valid.

- If both have p=2:  
  V_u = [2,1,3], V_v = [2,1,3]  
  C = [ V_u[2], V_u[1], V_u[3] ] = [1,2,3] → 0 inversions → invalid.

So the only valid edges are between different values (1 and 2).  
Thus the graph must be bipartite, with the two parts being p=1 and p=2.

We can solve by BFS/DFS coloring. If not bipartite → NO.  
If bipartite, assign colors as 1 and 2, and output the lexicographically smallest assignment (which means we try to assign 1 to the first node if possible).

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
ok = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break
            if not ok:
                break
    if not ok:
        break

if not ok:
    print("NO")
else:
    # color 0 -> p=1, color 1 -> p=2
    # But we want lexicographically smallest: try to assign 1 to node 0 if possible
    # If node 0 is color 1, we can flip all colors
    if color[0] == 1:
        for i in range(n):
            color[i] ^= 1
    res = [1 if c == 0 else 2 for c in color]
    print("YES")
    print(" ".join(map(str, res)))
```
