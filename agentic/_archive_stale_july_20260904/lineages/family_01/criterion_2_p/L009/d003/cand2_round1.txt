# Problem B — Infrastructure Migration

Time limit: 1 s   Memory limit: 256 MB

A technology company is migrating its $n$ microservices to a new infrastructure. Each microservice must be deployed to exactly one of two available hosting environments, designated as environment 1 and environment 2.

There are $m$ integration workflows. Each workflow strictly depends on a specific pair of microservices. A workflow requires two distinct processing resources to function:
- A local cache block, which is only available in environment 1.
- A distributed ledger, which is only available in environment 2.

A workflow successfully accesses a resource if at least one of its two microservices is placed in the environment where that resource is available.

You must assign each microservice to either environment 1 or environment 2 so that all $m$ integration workflows can successfully access both of their required resources, or report that no such deployment plan is possible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the two microservices required for a single integration workflow.

## Output
If no valid deployment plan exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $e_1, \dots, e_n$ (each $e_i \in \{1, 2\}$), where $e_i$ is the environment assigned to microservice $i$. If there are multiple valid deployment plans, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the domain from staff members and machines to microservices and hosting environments. The logical structure—requiring at least one element of a pair to have property A and at least one to have property B—is perfectly preserved but dressed in cloud computing terminology. This forces the model to deduce the mutual exclusion constraint from the resource access rules rather than relying on the specific wording of the seed.
</RATIONALE>
<PRESERVED_ANSWER>
Any valid deployment must assign one microservice to environment 1 and the other to environment 2 for every workflow, which is exactly the same formal constraint as assigning one staff member to routine 1 and the other to routine 2.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring of a graph, or determining if the graph is bipartite, which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
