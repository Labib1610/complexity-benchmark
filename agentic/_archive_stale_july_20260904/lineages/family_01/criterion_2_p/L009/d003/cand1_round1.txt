<STATEMENT>
# Problem B — Level Platforms

Time limit: 1 s   Memory limit: 256 MB

A manufacturing plant is configuring a network of delicate mobile platforms. The plant employs $n$ staff members. The facility operates a single main life-support reactor that generates $200,000$ daily oxygen credits. Each staff member requires exactly one oxygen credit per day. The workforce size $n$ is at least $1$, and its maximum possible value is strictly determined by this reactor capacity.

The plant's staging area is exactly $200,000$ square meters in size. Each platform requires exactly one square meter of staging area. The number of platforms $m$ can be any integer from $0$ up to the maximum number that can simultaneously fit in the staging area.

Each platform is carried jointly by a specific pair of staff members. To maintain ergonomic standards, each staff member must be issued a standardized harness. There are two types of harnesses available, which add a counterweight of either $1$ kg or $2$ kg to the wearer. A staff member is issued exactly one harness, which they wear while carrying any platforms they are assigned to.

For a platform to remain perfectly level during transport, the combined counterweight of the harnesses worn by its two assigned carriers must be exactly $3$ kg.

You must assign each staff member exactly one harness type (either $1$ or $2$) so that every platform in the facility remains perfectly level, or report that no such arrangement is possible.

## Input
The first line contains two integers $n$ and $m$. The limits on these values are derived from the facility's life-support and staging area capacities described above.
Each of the next $m$ lines contains two integers $u$ and $v$ — the two staff members who jointly carry a single platform. Staff members are numbered from $1$ to $n$.

## Output
If no valid harness assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $r_1, \dots, r_n$ (each $r_i \in \{1, 2\}$), where $r_i$ is the harness counterweight assigned to staff member $i$. If there are multiple valid assignments, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The original problem described a scenario where each machine had two phases that must be overseen by its two assigned operators, leading models to easily deduce that the operators must be assigned opposite routines (1 and 2). This rewrite replaces that semantic affordance with an algebraic one: each platform requires a combined counterweight of exactly 3 kg from its two carriers, who each wear either a 1 kg or 2 kg harness. This forces the model to mathematically deduce that $x + y = 3$ with $x, y \in \{1, 2\}$ implies $x \neq y$, rather than relying on the linguistic pattern of covering two distinct phases. Additionally, the constraints on $n$ and $m$ are now encoded indirectly through physical capacities, implementing S07.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the sum of two variables chosen from {1, 2} equals 3 is mathematically identical to stating that the two variables must take opposite values, preserving the exact same bipartite 2-coloring logic and lexicographical tie-breaking behavior.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using Breadth-First Search, keeping it firmly in the P complexity class.
</PRESERVED_CLASS>
