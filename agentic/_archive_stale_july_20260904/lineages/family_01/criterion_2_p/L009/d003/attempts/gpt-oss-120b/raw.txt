**Solution Explanation**

For every receiver we are given two transmitters `u , v`.
The receiver must see total power `3`, i.e. the two transmitters must have
different power levels (`1` and `2` in any order).

So the whole problem is:

* colour each vertex of an undirected graph with colours `1` or `2`
* every edge must join vertices of different colours
* output the lexicographically smallest colour sequence,
  or report that it is impossible.

The condition “different colours on every edge’’ is exactly the definition of a
* bipartite* graph.  
If a connected component is bipartite it has exactly two possible colourings:
the two colour classes can be swapped.

--------------------------------------------------------------------

#### 1.   Checking bipartiteness and collecting components  

We run a BFS/DFS over all vertices.

* `col[v] = -1` – not visited yet  
* while exploring a component we assign temporary colours `0` and `1`
  (just two sides of the bipartition).

If we ever see an edge `v‑w` with `col[v] == col[w]` the graph is **not**
bipartite → answer `NO`.

During the BFS we store all vertices of the current component in a list
`comp`. After the BFS finishes we have the two sides:
`side0 = {v | col[v]==0}` and `side1 = {v | col[v]==1}`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest colouring  

Components are independent, we may decide for each component which side gets
power `1` and which side gets power `2`.

Lexicographic order is decided by the first position where two colourings differ.
Therefore for a component we only have to look at its **smallest vertex index**
`mn = min(comp)`.  
If we give power `1` to the side that contains `mn`, the whole final sequence
becomes as small as possible, because any other choice would put a `2` at this
earliest position.

Thus for every component we:

```
if mn in side0:   assign side0 -> 1 , side1 -> 2
else:             assign side1 -> 1 , side0 -> 2
```

All components are processed in increasing order of their first vertex,
so the whole sequence is lexicographically minimal.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n, m
build adjacency list
col = [-1] * (n+1)          # temporary 0/1 colours
ans = [0] * (n+1)           # final powers 1/2

for v = 1 .. n:
    if col[v] == -1:
        BFS starting from v
        during BFS:
            assign col[vertex] = 0/1
            detect conflict -> print NO and exit
            collect vertices of this component in list comp
        mn = min(comp)
        # decide orientation
        if mn in side0:
            for x in side0: ans[x] = 1
            for x in side1: ans[x] = 2
        else:
            for x in side0: ans[x] = 2
            for x in side1: ans[x] = 1

print YES
print ans[1:] space separated
```

`side0` and `side1` are obtained from `col` values of the vertices in `comp`.

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm outputs `NO` iff no assignment exists,
otherwise outputs the lexicographically smallest valid assignment.

---

##### Lemma 1  
During BFS, if an edge connects two vertices with the same temporary colour,
the original graph is not bipartite and no valid power assignment exists.

**Proof.** A bipartite graph admits a 2‑colouring where every edge joins different
colours. If an edge has equal colours in any 2‑colouring, that colouring is not
bipartite, contradicting the definition. Hence the graph is non‑bipartite and
cannot be coloured with two different values on each edge. ∎



##### Lemma 2  
If the algorithm finishes all BFS traversals without conflict,
the graph is bipartite and the produced `ans` satisfies every edge.

**Proof.** Each BFS assigns temporary colours `0/1` such that every explored
edge joins opposite temporary colours (otherwise we would have stopped by
Lemma&nbsp;1). Thus each connected component is bipartite, and the whole graph
is bipartite. Afterwards we map each temporary colour class of a component to
either power `1` or `2`. Both vertices of any edge belong to opposite temporary
classes, therefore after the mapping they receive opposite powers, i.e. sum `3`.
∎



##### Lemma 3  
For a fixed component, among the two possible power assignments the algorithm
chooses the one that is lexicographically smaller for the whole sequence,
assuming all earlier vertices (indices `< mn`) are already fixed.

**Proof.** Let `mn` be the smallest index in the component.
The two possible assignments differ exactly on the vertices of the component;
all earlier indices are identical.  
If we give power `1` to the side containing `mn`, the value at position `mn`
becomes `1`. Any assignment that gives power `2` to `mn` would have a larger
value at the first differing position, therefore be lexicographically larger.
Thus the algorithm’s choice is optimal. ∎



##### Lemma 4  
Processing components in increasing order of their minimal vertex index and
applying Lemma&nbsp;3 to each yields the globally lexicographically smallest
valid assignment.

**Proof.** Consider the first index where two valid assignments differ.
It belongs to some component `C`. All components whose minimal index is smaller
than that index are identical in both assignments (they were processed earlier).
By Lemma&nbsp;3 our algorithm gives the smallest possible value at the minimal
index of `C`, therefore no other valid assignment can be lexicographically
smaller. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no assignment of powers `1/2` satisfying all receivers exists;  
* otherwise `YES` and the lexicographically smallest such assignment.

**Proof.**  

*If the algorithm prints `NO`*: this happens only when a conflict is found
(Lemma&nbsp;1). Then the graph is not bipartite, so no assignment exists.

*If a valid assignment exists*: the graph is bipartite, therefore no conflict
occurs and the algorithm reaches the construction phase. By Lemma&nbsp;2 the
produced `ans` satisfies all edges. By Lemma&nbsp;4 it is the lexicographically
smallest among all satisfying assignments.

Thus the output is correct in all cases. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and edge is processed once → `O(n + m)` time.  
*Additional work* (building answer) is linear in the size of components,
still `O(n + m)`.

Memory usage: adjacency list `2m` integers, plus a few arrays of size `n` →  
`O(n + m)` ≤ 4·10⁵ integers, well inside the limit.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [-1] * (n + 1)          # temporary 0/1 colours
    ans = [0] * (n + 1)           # final powers 1/2

    for start in range(1, n + 1):
        if col[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        col[start] = 0
        comp = [start]
        while q:
            v = q.popleft()
            for w in adj[v]:
                if col[w] == -1:
                    col[w] = col[v] ^ 1
                    q.append(w)
                    comp.append(w)
                elif col[w] == col[v]:
                    print("NO")
                    return
        # decide orientation
        mn = min(comp)
        side0 = []
        side1 = []
        for v in comp:
            if col[v] == 0:
                side0.append(v)
            else:
                side1.append(v)
        if mn in side0:
            for v in side0:
                ans[v] = 1
            for v in side1:
                ans[v] = 2
        else:
            for v in side0:
                ans[v] = 2
            for v in side1:
                ans[v] = 1

    # all vertices coloured
    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```

The program follows exactly the algorithm proven correct above and conforms
to the required input‑output format.
