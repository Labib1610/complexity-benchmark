We can model each crystal’s value as either 1 or 2.  
The resonance equation is:

\[
S_i + 3 \cdot d_i \cdot p_i = 7 \cdot d_i
\]

Where \( S_i \) is the sum of squares of neighbors’ values.  
If \( p_i = 1 \), then:

\[
S_i + 3 d_i = 7 d_i \implies S_i = 4 d_i
\]

If \( p_i = 2 \), then:

\[
S_i + 6 d_i = 7 d_i \implies S_i = d_i
\]

So:

- If \( p_i = 1 \), the sum of squares of neighbors must be \( 4 d_i \).
- If \( p_i = 2 \), the sum of squares of neighbors must be \( d_i \).

Since each neighbor is 1 or 2, their square is 1 or 4.  
Let \( x_i \) be the number of neighbors with value 2. Then:

- If \( p_i = 1 \):  
  \( 4x_i + 1(d_i - x_i) = 4d_i \)  
  \( 4x_i + d_i - x_i = 4d_i \)  
  \( 3x_i = 3d_i \) → \( x_i = d_i \)  
  So all neighbors must be 2.

- If \( p_i = 2 \):  
  \( 4x_i + 1(d_i - x_i) = d_i \)  
  \( 4x_i + d_i - x_i = d_i \)  
  \( 3x_i = 0 \) → \( x_i = 0 \)  
  So all neighbors must be 1.

Thus the rule is simple:

- If a crystal is 1, all its neighbors must be 2.
- If a crystal is 2, all its neighbors must be 1.

This means the graph must be bipartite, and the two parts correspond to values 1 and 2.  
If the graph is not bipartite, output `NO`.  
If it is bipartite, we can assign values according to the bipartition.  
For lexicographically smallest, we try to assign 1 to as early-indexed nodes as possible.

We can do BFS/DFS coloring, but for lexicographically smallest, we can try assigning 1 to node 1, then propagate constraints, and if conflict, try assigning 2 to node 1.

Implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

def try_assign(start_val):
    color = [-1] * n
    color[0] = start_val
    q = deque([0])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return None
    # For disconnected components, assign greedily
    for i in range(n):
        if color[i] == -1:
            color[i] = 0
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 1 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        return None
    return color

# Try starting with 1
res = try_assign(0)
if res is None:
    res = try_assign(1)

if res is None:
    print("NO")
else:
    print("YES")
    print(' '.join(str(x + 1) for x in res))
```
