# Problem B — Harmonic Stability

Time limit: 1 s
Memory limit: 256 MB

You are configuring $n$ resonance crystals in a laboratory. Each crystal $i$ must be tuned to a frequency multiplier $p_i$ of either 1 or 2.

The setup contains $m$ harmonic bridges. Each bridge connects exactly two specific crystals. 
To determine if a bridge connecting crystal $u$ and crystal $v$ is structurally stable, we evaluate the intersection of two specific geometric intervals based on their tuning.
Let $I_1$ be the closed interval $[0, 2]$ on the real number line, and let $I_2$ be the closed interval $[1, 3]$. 
For the bridge to be stable, the length of the intersection of the interval $I_{p_u}$ and the interval $I_{p_v}$ must be exactly 1. 

You must assign a frequency multiplier to each of the $n$ crystals so that every single harmonic bridge in the entire setup is perfectly stable. If no such assignment is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the two crystals connected by a single harmonic bridge.

## Output
If no valid tuning assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $p_1, \dots, p_n$ (each $p_i \in \{1, 2\}$), where $p_i$ is the frequency multiplier assigned to crystal $i$. If there are multiple valid assignments, output the one that is lexicographically smallest.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem was rewritten to replace the permutation-inversion composition rule with a geometric interval intersection rule. By defining two overlapping intervals $[0, 2]$ and $[1, 3]$, the intersection length is exactly 1 if and only if the two assigned intervals are different (i.e., $p_u \neq p_v$). This forces models to geometrically evaluate the 4 possible pairs of assignments rather than relying on the explicit parity of array inversions, breaking surface-level pattern matching to permutation cycles while retaining the exact same underlying binary constraint.
</RATIONALE>
<PRESERVED_ANSWER>
The intersection of identical intervals has length 2, while the intersection of $I_1$ and $I_2$ is $[1, 2]$ which has length 1; thus the condition is satisfied if and only if $p_u \neq p_v$, precisely matching the original permutation inversion condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The condition on each edge still strictly enforces that connected nodes must have different assignments from $\{1, 2\}$, which is exactly the bipartiteness (2-coloring) check solvable in $O(n+m)$ using BFS.
</PRESERVED_CLASS>
