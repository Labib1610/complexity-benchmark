We need to figure out what the stability condition means in terms of the capacities.

For a link between nodes \(u\) and \(v\) with capacities \(c_u\) and \(c_v\) (each 1 or 2), we build a grid of \(c_u\) rows and \(c_v\) columns.  
The number of distinct contiguous rectangular subgrids in a \(r \times c\) grid is:

\[
\frac{r(r+1)}{2} \cdot \frac{c(c+1)}{2}
\]

We require this to be exactly 3.

Let’s check possibilities:

- If \(c_u = 1, c_v = 1\):  
  \(\frac{1\cdot2}{2} \cdot \frac{1\cdot2}{2} = 1 \cdot 1 = 1\) → not 3.

- If \(c_u = 1, c_v = 2\):  
  \(\frac{1\cdot2}{2} \cdot \frac{2\cdot3}{2} = 1 \cdot 3 = 3\) → OK.

- If \(c_u = 2, c_v = 1\):  
  Same as above → 3 → OK.

- If \(c_u = 2, c_v = 2\):  
  \(\frac{2\cdot3}{2} \cdot \frac{2\cdot3}{2} = 3 \cdot 3 = 9\) → not 3.

So the only valid pairs are (1,2) and (2,1).  
That means: for every edge, the two endpoints must have different capacities.

Thus the problem reduces to:  
Can we 2-color the graph (bipartite check)? If yes, output the lexicographically smallest assignment with values 1 and 2.

Lexicographically smallest means:  
We want node 1 to be 1 if possible, then node 2 to be 1 if possible, etc.  
We can do BFS/DFS coloring, but to get lexicographically smallest, we should try assigning 1 to each node in order if it doesn’t conflict.

We can do:  
- Initialize all as uncolored.  
- For each node in order 1..n, if uncolored, start BFS with color 1.  
- If conflict → NO.

This yields lexicographically smallest because we always try 1 first.

Let’s implement.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] == -1:
        color[start] = 1
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
