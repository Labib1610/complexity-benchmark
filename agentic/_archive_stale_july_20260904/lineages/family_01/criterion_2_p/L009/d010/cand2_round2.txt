<METHOD_NAME>Polynomial Energy Masking</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the geometric tangency condition (which trivially simplifies to $c_u + c_v = 3$) with a quadratic Diophantine-style equation $2c_u^2 + 5c_uc_v + 2c_v^2 = 20$. Over the domain $\{1, 2\}$, this equation is satisfied if and only if $c_u \neq c_v$. Models that rely on surface pattern matching of graph coloring or geometric phrasing will fail to recognize that this is just a bipartiteness check.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem B — Network Channels

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ communication nodes. Each node $i$ must be assigned an operational mode $c_i$ belonging to the set $\{1, 2\}$.

The network contains $m$ interference links. Each link connects exactly two specific nodes. 
To maintain a balanced network, we define a stability condition for each link. For a link connecting node $u$ and node $v$, the interaction energy between their assigned modes must satisfy the following equation:
$2c_u^2 + 5c_uc_v + 2c_v^2 = 20$

The configuration is considered stable if and only if this energy equation holds true for every interference link in the network.

You must assign an operational mode to each of the $n$ nodes so that this stability requirement is met for all links. If no such assignment is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the two nodes connected by a single interference link.

## Output
If no valid mode assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$ (each $c_i \in \{1, 2\}$), where $c_i$ is the mode assigned to node $i$. If there are multiple valid assignments, output the one that is lexicographically smallest. An assignment sequence $A$ is lexicographically smaller than $B$ if, at the first index $i$ where they differ, $A_i < B_i$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The geometric tangency condition was easily mapped by models to $c_u + c_v = 3$, which immediately triggered bipartiteness heuristics. By replacing this with a quadratic equation $2c_u^2 + 5c_uc_v + 2c_v^2 = 20$, the model is forced to evaluate the polynomial over the restricted domain $\{1, 2\}$ to deduce that the condition still strictly requires $c_u \neq c_v$. This prevents superficial pattern matching on graph coloring concepts.
</RATIONALE>
<PRESERVED_ANSWER>
The domain for each $c_i$ is $\{1, 2\}$. Plugging in all combinations: (1,1) yields 9, (2,2) yields 36, and both (1,2) and (2,1) yield 20. Thus, the equation is satisfied if and only if $c_u \neq c_v$, which is identical to the original external tangency constraint $c_u + c_v = 3$.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying mathematical problem remains exact 2-coloring (bipartiteness check), which is solvable in linear time using BFS/DFS, thereby keeping it in P.
</PRESERVED_CLASS>
