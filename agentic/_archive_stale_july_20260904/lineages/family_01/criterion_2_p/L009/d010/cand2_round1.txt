# Problem B — Network Channels

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ communication nodes. Each node $i$ must be assigned a processing mode $c_i$ belonging to the set $\{1, 2\}$.

The network contains $m$ interference links. Each link connects exactly two specific nodes. 
To maintain a balanced network, we define a stability condition for each link based on the interaction energy between the connected nodes. For a link connecting node $u$ and node $v$, the configuration is considered stable if and only if their interaction energy, calculated as $2 c_u^2 + 5 c_u c_v + 2 c_v^2$, is exactly 20.

You must assign a processing mode to each of the $n$ nodes so that this stability requirement is met for all links. If no such assignment is possible, you must report it.

## Input
The first line contains two integers $n$ and $m$. The system allocates a strict limit of 400,000 bytes for node metadata. With each node requiring exactly 2 bytes, this ensures the node count $n$ is at most 200,000 (and at least 1). The link registry has a maximum capacity of 200,000 entries, meaning the link count $m$ is between 0 and 200,000.
Each of the next $m$ lines contains two integers $u$ and $v$ — the two nodes connected by a single interference link.

## Output
If no valid processing mode assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $c_1, \dots, c_n$ (each $c_i \in \{1, 2\}$), where $c_i$ is the mode assigned to node $i$. If there are multiple valid assignments, output the one that is lexicographically smallest. An assignment sequence $A$ is lexicographically smaller than $B$ if, at the first index $i$ where they differ, $A_i < B_i$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I replaced the geometric "externally tangent circles" condition (which trivially implies $c_u + c_v = 3$) with an algebraic interaction energy condition ($2 c_u^2 + 5 c_u c_v + 2 c_v^2 = 20$). Since the variables are restricted to the set {1, 2}, this polynomial evaluates to exactly 20 if and only if $c_u \neq c_v$. Models that rely on pattern matching geometric or summation constraints to recognize bipartite graphs will fail, forcing them to genuinely evaluate the polynomial over the restricted domain to discover the underlying 2-coloring structure. The numeric bounds were also rewritten as physical system limits to satisfy S07.
