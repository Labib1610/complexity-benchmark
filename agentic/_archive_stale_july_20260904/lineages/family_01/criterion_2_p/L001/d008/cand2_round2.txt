<METHOD_NAME>Matrix Trace Obfuscation</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the interval intersection constraint with a matrix trace condition: Tr(M_u × M_v) = -2, where the two choices are diagonal matrices with opposite signs. This hides the XOR/bipartite structure behind linear algebra mechanics, preventing pattern-matching on graph coloring.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Quantum Spin Configuration

Time limit: 1 s
Memory limit: 256 MB

A quantum system consists of $n$ nodes, indexed from 1 to $n$. A configuration assigns each node a specific spin operator matrix. For each node, you must choose its matrix to be either:
- Matrix $A = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}$
- Matrix $B = \begin{pmatrix} -1 & 0 \\ 0 & 1 \end{pmatrix}$

The laboratory maintains a record of $m$ entanglement conditions between these nodes. To ensure system stability, for every recorded condition connecting node $u$ and node $v$, the assigned matrices $M_u$ and $M_v$ must satisfy:
$$ \text{Tr}(M_u \times M_v) = -2 $$
where $\text{Tr}$ denotes the trace of the matrix (the sum of the elements on its main diagonal), and $\times$ denotes standard matrix multiplication. Note that the input may contain multiple records of the same condition, or a condition connecting a node to itself; all listed conditions must be satisfied.

Your task is to determine a valid configuration for all $n$ nodes. Represent the choice of Matrix $A$ as the integer 1, and the choice of Matrix $B$ as the integer 2. A configuration is valid if it produces a sequence of $n$ integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) that satisfies all $m$ recorded conditions. 

If multiple valid sequences exist, you must output the one that is lexicographically smallest. This means it must prioritize assigning 1 to node 1 if possible; then prioritize assigning 1 to node 2, and so on sequentially.

If no configuration can satisfy all $m$ recorded conditions, you must report the failure.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), identifying a pair of nodes in the entanglement record. 

## Output
If no configuration can satisfy the conditions, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) representing the matrix assigned to each respective node from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The interval intersection condition was replaced with a matrix trace property. Because the trace of the product of the two allowed matrices is -2 if they are different, and +2 if they are the same, the underlying constraint remains an exact XOR. This forces models to algebraically evaluate the trace condition to discover the bipartite structure, defeating pure pattern-matching on graph coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The product of Matrix A and Matrix B has a trace of -2, while the product of two identical matrices has a trace of 2; thus, the condition enforces exactly the same "must be different" relation as the seed, keeping all valid assignments and the lexicographic tie-breaker identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a valid 2-coloring of an undirected graph (and preferring the lexicographically smallest color sequence), which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
