<METHOD_NAME>Calculus Orthogonality Masking</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the geometric interval intersection condition with a definite integral of polynomial basis functions over [-1, 1]. The two choices (t and t^2) are orthogonal if and only if they are different, preserving the exact XOR bipartite structure while forcing the model to evaluate integrals to discover it.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>

<STATEMENT>
# Problem B — Basis Function Orthogonality

Time limit: 1 s
Memory limit: 256 MB

A signal processing system consists of $n$ channels, indexed from 1 to $n$. A configuration assigns each channel a specific basis function. For each channel, you must choose its basis function to be either $\phi(t) = t$ or $\phi(t) = t^2$.

The laboratory maintains a record of $m$ interference constraints between these channels. To avoid signal degradation, the system must satisfy a local orthogonality condition for every constraint: for any recorded constraint connecting channel $u$ and channel $v$, their assigned basis functions must be orthogonal over the continuous interval $[-1, 1]$. Specifically, the definite integral $\int_{-1}^{1} \phi_u(t) \phi_v(t) dt$ must equal exactly $0$. (Note that multiple records of the same constraint, or a constraint connecting a channel to itself, must still strictly satisfy this condition without exception).

Your task is to determine a valid configuration for all $n$ channels. If multiple valid configurations exist, you must output the one that is lexicographically smallest when represented as a sequence of choices. Specifically, represent the choice of $\phi(t) = t$ as the integer 1, and the choice of $\phi(t) = t^2$ as the integer 2. The configuration is valid if it produces a sequence of $n$ integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) such that the sequence is lexicographically smaller than any other valid sequence. This means it must prioritize assigning 1 to channel 1 if possible; then prioritize assigning 1 to channel 2, and so on sequentially.

If no configuration can satisfy the orthogonality constraint for all $m$ recorded pairs, you must report the failure.

The system's maximum channel capacity, as well as its maximum constraint capacity, is physically limited by the hardware timer, which caps both $n$ and $m$ at exactly the number of seconds in 55 hours, 33 minutes, and 20 seconds. Both variables are bounded accordingly, with $n \ge 1$ and $m \ge 0$.

## Input
The first line contains two integers $n$ and $m$.
Each of the following $m$ lines contains two integers $u$ and $v$, identifying a constrained pair of channels in the record. Both channel identifiers $u$ and $v$ are at least 1 and at most $n$.

## Output
If no configuration can satisfy the orthogonality constraint, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) representing the choice for each respective channel from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The bipartite graph structure was previously given away by the "intersect at exactly one point" property of intervals [0, 1] and [1, 2]. I replaced this with an orthogonality constraint on functions $t$ and $t^2$ over $[-1, 1]$. Because the integral of $t^3$ is 0 while the integrals of $t^2$ and $t^4$ are non-zero, this perfectly preserves the XOR constraint (nodes must have different assignments) but forces the model to evaluate the calculus to discover it. S07 is implemented by bounding $n$ and $m$ using the exact number of seconds in 55h 33m 20s (200,000).
</RATIONALE>
<PRESERVED_ANSWER>
The definite integral of the product of the two assigned functions over [-1, 1] is 0 if and only if one function is $t$ and the other is $t^2$, making the constraint mathematically identical to the original "intersect at one point" condition, thus keeping the set of valid configurations entirely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest valid 2-coloring of a graph, which is solvable in O(n+m) time using Breadth-First Search, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the integral constraint if their internal symbolic math capabilities hallucinate the integral of $t^2$ or $t^4$ over $[-1, 1]$ to be $0$, though this is standard calculus and unambiguously stated.
</RISK>
