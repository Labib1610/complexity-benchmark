 We can model this as a bipartite graph problem.  
Each station must be assigned either 1 or 2, and for every edge (u, v), we need r_u * r_v = 2.  
That means if r_u = 1 then r_v must be 2, and if r_u = 2 then r_v must be 1.  
So the graph must be bipartite, and the two colors correspond to 1 and 2.

We can use BFS/DFS to color the graph.  
If we find a conflict (an edge connecting two nodes of the same color), then it's impossible.  
Otherwise, we output the coloring, but we need the lexicographically smallest assignment.  
Since 1 < 2, we should try to assign 1 to the smallest index possible.  
We can do this by starting BFS from each unvisited node in increasing index order, and always try to color the starting node with 1 if possible.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # -1 = uncolored, 0 = 1, 1 = 2

def bfs(start):
    q = deque([start])
    color[start] = 0  # try 1 first
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

print("YES")
print(' '.join(str(color[i] + 1) for i in range(n)))
```
