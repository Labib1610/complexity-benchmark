<METHOD_NAME>
Diophantine System of Edge Types
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces the single energy equation (which trivially decomposed into a per-edge maximum, allowing models to deduce that only (1,2) edges could reach the target) with two simultaneous global sum conditions. Neither condition has its maximum at (1,2), and each condition individually allows for mixes of (1,1) and (2,2) edges. Models that rely on local bounds will fail to see the bipartite structure and will likely implement a TLE-prone general solver.
</METHOD_DESCRIPTION>
<METHOD_NOVEL>
yes

<STATEMENT>
# Problem B — Energy State Configuration

Time limit: 1 s
Memory limit: 256 MB

A quantum system consists of $n$ nodes, indexed from 1 to $n$. A tuning configuration assigns each node a specific state, which must be either the integer 1 or the integer 2.

The laboratory maintains a record of $m$ links between these nodes. These links dictate the stability of the system. Let $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) be the sequence of assigned states. 
Let $D_i$ be the total number of times node $i$ appears as an endpoint in the $m$ recorded links. (Note: if a record connects a node to itself, that node appears twice in that single record).

The system features two measurable quantities based on the tuning configuration:
1. The total node potential $P$, defined as $P = \sum_{i=1}^n D_i r_i$.
2. The total link resonance $R$, defined as $R = \sum_{j=1}^m r_{u_j} r_{v_j}$, where $(u_j, v_j)$ represents the $j$-th recorded link.

To avoid destabilization, the system must achieve perfect stability. The system is perfectly stable if and only if both of the following conditions are simultaneously met:
- $P = 3m$
- $R = 2m$

Your task is to determine a valid tuning configuration for all $n$ nodes that achieves perfect stability. If multiple valid configurations exist, you must output the one that produces a sequence $r_1, r_2, \dots, r_n$ that is lexicographically smaller than any other valid sequence. This means it must prioritize assigning 1 to node 1 if possible; then prioritize assigning 1 to node 2, and so on sequentially.

If no configuration can achieve perfect stability, you must report the failure.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), identifying a linked pair of nodes in the record.

## Output
If no tuning configuration can achieve the required stability, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) representing the state assigned to each respective node from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the single energy equation with a system of two global sum constraints (node potential and link resonance). Because neither constraint has its maximum value at the (1,2) state and both individually allow valid mixes of (1,1) and (2,2) edges, models can no longer use a simple upper-bound argument to deduce the bipartite requirement, forcing them to either solve the implicit Diophantine system or fall back to a TLE-prone general solver.
</RATIONALE>
<PRESERVED_ANSWER>
The two sum conditions form a linear system over edge types ($2a+3b+4c=3m$ and $1a+2b+4c=2m$) whose only solution is $a=c=0, b=m$, meaning every edge must have endpoints with different states, which preserves the exact same valid configurations as the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a proper 2-coloring (checking bipartiteness) with a lexicographical tie-breaker, which is solvable in $O(n+m)$ time using BFS.
</PRESERVED_CLASS>
