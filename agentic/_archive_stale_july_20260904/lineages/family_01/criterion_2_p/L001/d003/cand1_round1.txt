<STATEMENT>
# Problem B — Monomer Spin States

Time limit: 1 s   Memory limit: 256 MB

A synthetic polymer is constructed from $n$ individual monomers. Each monomer is labeled with a distinct integer from 1 through $n$. During the preparation phase, you must calibrate the polymer by assigning a spin state to every monomer. A spin state is restricted to being an integer value of either 1 or 2.

The laboratory database contains $m$ entries, each documenting a covalent bond between two monomers. Molecular stability requires that these bonds satisfy a specific interaction constraint. For every bonded pair documented in the database, the product of their assigned spin states must evaluate exactly to 2.

Your objective is to find a full calibration for the $n$ monomers that satisfies all interaction constraints. If multiple valid calibrations exist, you must output the one that is lexicographically smallest. If no such calibration can be found without violating the constraints, you must indicate that the polymer cannot be stabilized.

## Input
The first line contains two integers $n$ and $m$. The number of monomers $n$ ranges from $1$ to $2 \cdot 10^5$. The number of documented bonds $m$ ranges from $0$ to $2 \cdot 10^5$.
The next $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), representing a covalent bond between the monomer labeled $u$ and the monomer labeled $v$.

## Output
If no valid calibration exists, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the spin state assigned to each respective monomer from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the exact-sum-3 condition on states 1 and 2 with a product-equals-2 condition. This forces the models to algebraically deduce that the multiplicative relation implies inequality between the two states, thereby obscuring the standard graph bipartiteness mapping that they were previously pattern-matching from the sum condition.
</RATIONALE>
<PRESERVED_ANSWER>
The product of two values from {1, 2} is 2 if and only if one value is 1 and the other is 2, which is exactly the same condition as their sum being 3, preserving all valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem remains 2-coloring/bipartiteness on an undirected graph, which is solvable in linear time using standard BFS/DFS traversal.
</PRESERVED_CLASS>
