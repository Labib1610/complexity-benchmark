We can model this as a graph bipartiteness problem. Since each monomer can only take value 1 or 2)Skip, and the sum of two bonded monomers must be 3, that means one must be 1 and the other 2. So the graph must be bipartiteasia.

If it is bipartite, we get two color classes. To get the lexicographically smallest sequence, we fix node 1 to 1, then BFS/DFS-coloring. If there are isolated components, we also try assigning 1 to their first node for lexicographic minimality.

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] == -1:
        color[start] = 1
        q = deque([start])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
