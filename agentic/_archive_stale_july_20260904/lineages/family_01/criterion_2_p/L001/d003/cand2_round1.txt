# Problem B — Monomer Spin States

Time limit: 1 s   Memory limit: 256 MB

A synthetic polymer is built from $n$ individual monomers, which are indexed using integers from 1 up to $n$. To establish a synthesis configuration, you must assign an integer spin state of either 1 or 2 to every monomer.

The laboratory has documented $m$ covalent bonds between specific monomers. Molecular stability dictates that a strict resonance rule must hold across every bond in this documentation: the bitwise XOR of the spin states assigned to the two bonded monomers must evaluate to exactly 3.

You must find a synthesis configuration that assigns a valid state to all $n$ monomers without violating the resonance rule. If there are multiple configurations that meet this requirement, you must output the one that forms the lexicographically smallest sequence of states. If no such configuration can be found that satisfies the rule for all documented bonds at once, you must indicate that the synthesis fails.

## Input
The first line contains two integers $n$ and $m$. The total number of monomers $n$ will be at least $1$ and at most $2 \cdot 10^5$. The number of documented bonds $m$ will be between $0$ and $2 \cdot 10^5$, inclusive.
The following $m$ lines each contain two integers $u$ and $v$, denoting that a covalent bond exists between the monomer indexed $u$ and the monomer indexed $v$ ($1 \le u, v \le n$).

## Output
If a valid synthesis configuration is impossible, print `NO` on a single line.
If a valid configuration is possible, print `YES` on the first line. On the second line, print $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the spin state of each monomer from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the "sum to exactly 3" condition with the mathematically equivalent "bitwise XOR evaluates to exactly 3" condition. This forces models to deduce that the states must be distinct across bonds, removing the explicit arithmetic trigger that allowed them to easily recognize the standard bipartite pattern.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed states are 1 and 2, the bitwise XOR evaluates to 3 if and only if the two states are different (1^2 = 3), which is perfectly equivalent to them summing to 3.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem fundamentally remains 2-coloring / bipartiteness checking on an undirected graph, keeping it firmly in P.
</PRESERVED_CLASS>
