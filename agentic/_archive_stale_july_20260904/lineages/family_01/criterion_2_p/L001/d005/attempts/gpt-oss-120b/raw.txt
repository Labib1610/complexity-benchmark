**Solution Explanation**

For every edge `i = (u , v)`

```
(r_u - r_v)^2 = 0   if r_u = r_v
                = 1   if r_u ≠ r_v          ( because r_u , r_v ∈ {1,2} )
```

The required total energy is  

```
 Σ (r_u - r_v)^2 = m
```

so **every recorded edge has to contribute `1`**, i.e. its ends must have
different resonance levels.
Therefore we have to colour the graph with two colours `1` and `2`
so that adjacent vertices have different colours – a classic *proper
2‑colouring*.
A proper 2‑colouring exists **iff the graph is bipartite**.

If the graph is bipartite we still have to output the *lexicographically
smallest* colour sequence.
In each connected component the two colour classes can be swapped.
Let `v0` be the smallest vertex index inside the component.
Choosing the colour class that contains `v0` to be `1` makes `r_{v0}=1`,
which is strictly better than `r_{v0}=2` and does not affect any earlier
vertex (there is none).  
Thus for every component we orient the two colour classes so that the
smallest vertex of the component receives colour `1`.  
Doing this for all components yields the globally lexicographically
smallest sequence.

--------------------------------------------------------------------

#### Algorithm
```
read n , m
build adjacency list G
colour[1..n] = -1          # -1 = unvisited, 0/1 = temporary colours
answer[1..n] = 0

for each vertex v = 1 .. n
    if colour[v] == -1
        # start a new component
        queue ← [v]; colour[v] = 0
        component_vertices = []
        while queue not empty
            x = pop queue
            component_vertices.append(x)
            for each neighbour y of x
                if colour[y] == -1
                    colour[y] = colour[x] ^ 1
                    push y to queue
                else if colour[y] == colour[x]
                    print "NO" and exit   # not bipartite
        # component finished
        # find smallest vertex in this component
        v0 = min(component_vertices)
        # colour class of v0 must become final colour 1
        base = colour[v0]          # 0 or 1
        for each vertex u in component_vertices
            if colour[u] == base:   answer[u] = 1
            else:                    answer[u] = 2

print "YES"
print answer[1] … answer[n] separated by spaces
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no valid configuration exists,
otherwise prints `YES` and the lexicographically smallest valid configuration.

---

##### Lemma 1  
If the algorithm prints `NO`, the graph is not bipartite.

**Proof.** `NO` is printed only when during BFS an edge `(x,y)` with
`colour[x] == colour[y]` is found. This is exactly the definition of a
graph that is not 2‑colourable, i.e. not bipartite. ∎



##### Lemma 2  
If the graph is not bipartite, the algorithm prints `NO`.

**Proof.** A non‑bipartite graph contains a connected component that is not
bipartite. BFS on that component will eventually encounter an edge whose
ends already have the same temporary colour (standard property of BFS
2‑colouring). The algorithm detects it and prints `NO`. ∎



##### Lemma 3  
If the algorithm finishes without printing `NO`, the produced `answer`
is a proper 2‑colouring of the whole graph.

**Proof.** For each component BFS assigns temporary colours `0/1` such that
adjacent vertices differ (otherwise we would have stopped by Lemma 1).
Later we possibly swap the two classes, but swapping does not change the
property that adjacent vertices belong to different final colours.
All components are processed, therefore every edge connects vertices with
different final colours. ∎



##### Lemma 4  
For a component `C`, the algorithm assigns colour `1` to the smallest
vertex of `C`.

**Proof.** `v0 = min(C)` is computed. Its temporary colour is `base`.
All vertices with temporary colour `base` receive final colour `1`,
others receive `2`. Hence `v0` gets colour `1`. ∎



##### Lemma 5  
Among all proper 2‑colourings, the algorithm’s `answer` is lexicographically
minimum.

**Proof.** Consider the vertices in increasing order.
Let `v` be the first vertex where some other proper colouring `col'`
differs from `answer`. `v` belongs to some component `C`.  
By Lemma 4, `answer[v] = 1`. In `col'` the two colour classes of `C` are either
oriented the same way as in `answer` (then `col'[v]=1`) or swapped,
which would give `col'[v]=2`. The latter is the only way to differ, and it
makes `col'` larger at position `v`. Therefore no other proper colouring is
lexicographically smaller. ∎



##### Lemma 6  
If the graph is bipartite, the algorithm outputs a valid configuration.

**Proof.** By Lemma 3 the output is a proper 2‑colouring, hence every edge
connects different colours, contributing `1` to the sum.
There are `m` edges, so the total sum equals `m`. ∎



##### Theorem  
The algorithm prints `NO` iff no valid configuration exists;
otherwise it prints `YES` and the lexicographically smallest valid
configuration.

**Proof.**  
*If* part: If the algorithm prints `NO`, by Lemma 1 the graph is not
bipartite, thus no proper 2‑colouring exists, and consequently no
configuration can satisfy the required sum.

*Only‑if* part: If a valid configuration exists, the graph must be bipartite
(because every edge must join different colours). By Lemma 2 the algorithm
does not print `NO`. By Lemma 6 it outputs a valid configuration, and by
Lemma 5 this configuration is lexicographically minimal. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

`BFS` visits each vertex once and each edge twice.

```
Time   :  O(n + m)
Memory :  O(n + m)   (adjacency list, colour array, queue)
```

Both satisfy the limits (`n,m ≤ 2·10⁵`).

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        g[u].append(v)
        g[v].append(u)

    colour = [-1] * (n + 1)          # temporary 0/1
    ans = [0] * (n + 1)              # final 1/2

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = []
        while q:
            x = q.popleft()
            comp.append(x)
            for y in g[x]:
                if colour[y] == -1:
                    colour[y] = colour[x] ^ 1
                    q.append(y)
                elif colour[y] == colour[x]:
                    print("NO")
                    return
        # orient so that smallest vertex gets final colour 1
        v0 = min(comp)
        base = colour[v0]
        for v in comp:
            ans[v] = 1 if colour[v] == base else 2

    # all good
    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
