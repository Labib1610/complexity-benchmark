We can model this as a graph problem.  
Each monomer is a node, and each bond is an edge.  
The energy condition is:

\[
\sum_{(u,v) \in E} (r_u - r_v)^2 = m
\]

Since \( r_u, r_v \in \{1,2\} \), the squared difference is either 0 or 1.  
So the sum equals the number of edges where the two endpoints have different levels.

Thus, the condition becomes:  
**The number of edges crossing between level 1 and level 2 must be exactly \( m \).**  
That means **every edge must connect nodes of different levels** — i.e., the graph must be bipartite.

So the problem reduces to:  
- Check if the graph is bipartite.  
- If yes, find the lexicographically smallest 2-coloring (with colors 1 and 2).

We can do this with BFS/DFS, assigning colors greedily:  
- Start with node 1 as color 1.  
- For each node, if uncolored, try color 1 first, then propagate.  
- If a conflict occurs, it's not bipartite → output `NO`.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 1
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]  # 1 -> 2, 2 -> 1
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
