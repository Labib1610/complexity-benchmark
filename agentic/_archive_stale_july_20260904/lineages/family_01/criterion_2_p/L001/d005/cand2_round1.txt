# Problem B — Polymer Resonance Tuning

Time limit: 1 s
Memory limit: 256 MB

A synthetic polymer consists of $n$ monomers, indexed from 1 to $n$. A tuning configuration assigns each monomer a resonance level, which must be chosen as either 1 or 2.

The laboratory maintains a record of $m$ covalent bonds between these monomers. To ensure molecular stability, a strict structural rule applies to any pair of monomers connected by a documented bond. For every recorded bonded pair of monomers $u$ and $v$, their assigned resonance levels $r_u$ and $r_v$ must satisfy the following algebraic stability condition:
The sum of the cubes of their resonance levels must be exactly 9. That is, $r_u^3 + r_v^3 = 9$.

Your task is to determine a valid tuning configuration for all $n$ monomers. If multiple valid configurations exist, you must output the sequence of resonance levels that evaluates to the smallest possible mathematical value when interpreted as a decimal fraction $0.r_1r_2\dots r_n$. This means the configuration must prioritize assigning level 1 to monomer 1 if any valid configuration allows it; then, among those valid configurations, prioritize assigning level 1 to monomer 2, and so on sequentially up to monomer $n$. If no configuration can satisfy the structural rule for all recorded bonds simultaneously, you must report the failure.

## Input
The first line contains two integers $n$ and $m$. The laboratory's synthesis reactor can accommodate a minimum of a single monomer and a maximum capacity of two hundred thousand monomers. The registry of covalent bonds can be completely empty, or it can contain up to two hundred thousand documented bonds. Thus, $n$ and $m$ fall within these respective inclusive bounds.
Each of the following $m$ lines contains two integers $u$ and $v$, identifying a bonded pair of monomers in the record. Both monomer identifiers $u$ and $v$ are at least 1 and at most $n$.

## Output
If no valid tuning configuration exists, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) representing the resonance level assigned to each respective monomer from 1 to $n$. This sequence must be the one that evaluates to the smallest possible value when interpreted as a decimal fraction $0.r_1r_2\dots r_n$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
