To solve this problem, we need to determine if a given graph is bipartite (2-colorable) and, if so, find the lexicographically smallest 2-coloring. The graph is represented by `n` nodes and `m` edges (incompatible pairs). 

### Approach
1. **Check Bipartiteness**: The problem reduces to checking if the graph is bipartite. A graph is bipartite if it can be divided into two disjoint sets such that no two nodes within the same set are adjacent. This is equivalent to 2-coloring the graph where adjacent nodes must have different colors.
2. **Lexicographically Smallest Coloring**: If the graph is bipartite, we need to find the lexicographically smallest 2-coloring. The lexicographically smallest sequence is achieved by greedily assigning the smallest possible color (1) to each node, starting from the smallest index, while ensuring that the color does not conflict with any previously colored adjacent nodes. This can be done using a BFS approach where we process nodes in order, assigning the smallest available color that doesn't conflict with adjacent nodes.

### Solution Steps
1. **Graph Representation**: Represent the graph using an adjacency list for efficient traversal.
2. **BFS for Bipartite Check and Coloring**: For each node, if it hasn't been colored, start a BFS from that node. Assign color 1 to the starting node. For each adjacent node, assign the opposite color (2 if the current node is 1, and vice versa). If at any point an adjacent node has the same color as the current node, the graph is not bipartite, and we return "NO".
3. **Lexicographical Order**: To ensure the lexicographically smallest sequence, process nodes in increasing order. For each node, if it hasn't been colored, start BFS from it, assigning the smallest possible color (1) first. This ensures that nodes with smaller indices get the smallest possible colors early in the process.

### Solution Code
```python
import sys
from collections import deque

def solve():
    input = sys.stdin.read().split()
    ptr = 0
    n, m = map(int, input[ptr:ptr+2])
    ptr +=2
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u, v = map(int, input[ptr:ptr+2])
        ptr +=2
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0]*(n+1)
    possible = True
    
    for i in range(1, n+1):
        if color[i] == 0:
            queue = deque()
            queue.append(i)
            color[i] = 1
            while queue and possible:
                u = queue.popleft()
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = 3 - color[u]
                        queue.append(v)
                    elif color[v] == color[u]:
                        possible = False
                        break
                if not possible:
                    break
        if not possible:
            break
    
    if not possible:
        print("NO")
    else:
        print("YES")
        print(' '.join(map(str, color[1:n+1])))

solve()
```

### Explanation
1. **Reading Input**: The input is read all at once for efficiency, especially given the constraints.
2. **Graph Construction**: The adjacency list `adj` is built from the input edges.
3. **BFS for Coloring**: For each node, if it hasn't been colored, BFS is initiated. The starting node is colored 1, and adjacent nodes are colored 2 (or vice versa). If a conflict is found (adjacent nodes with the same color), the graph is not bipartite.
4. **Output Result**: If the graph is bipartite, the coloring is printed. The BFS ensures that nodes are processed in order, and the smallest color is assigned first, leading to the lexicographically smallest sequence.

This approach efficiently checks for bipartiteness and constructs the lexicographically smallest valid coloring if possible.
