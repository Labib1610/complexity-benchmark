**Solution Explanation**

For every incompatible pair `(u , v)` the two workers must be assigned different
windows.  
Thus we have to 2‑color the graph formed by the `m` edges.
If the graph is not bipartite the answer is `NO`.

If it is bipartite we have to output the *lexicographically smallest*
binary sequence `s₁ … sₙ` (`1 < 2`).  
In a bipartite component we may flip the two colour classes.
The first (smallest numbered) vertex of a component decides the whole
orientation:

* make this vertex colour **1** – this is always possible by possibly flipping
  the whole component.
* any other orientation would give this vertex colour **2**, which is larger,
  therefore the whole sequence would be lexicographically larger.

Consequently the optimal algorithm is:

```
for each not yet visited vertex v (in increasing order)
        run BFS/DFS to collect its whole connected component
        during the search colour vertices 0 / 1   (provisional bipartite colours)
        if a conflict appears → graph not bipartite → NO
        let w = smallest index in this component
        if provisional colour[w] == 0 :   map 0 → 1 , 1 → 2
        else                               map 0 → 2 , 1 → 1   (flip)
        write the mapped values into the answer array
```

All components are processed independently, each in `O(size)` time.
Overall complexity `O(n + m)` and memory `O(n + m)`.

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible roster exists,
and otherwise prints the lexicographically smallest feasible roster.

---

##### Lemma 1  
During the BFS of a component the algorithm assigns provisional colours
`0/1` that satisfy all already explored edges.  
If an edge `(x , y)` with `colour[x] == colour[y]` is found,
the component is not bipartite.

**Proof.**  
BFS starts with an arbitrary vertex coloured `0`.  
Whenever an uncoloured neighbour `y` of a vertex `x` is discovered,
the algorithm sets `colour[y] = colour[x] xor 1`, guaranteeing
different colours on that edge.
If later an edge connects two already coloured vertices with equal colours,
any 2‑colouring would give the same colour to its ends, contradicting bipartiteness.
∎



##### Lemma 2  
If the algorithm finishes the BFS of a component without conflict,
the component is bipartite.

**Proof.**  
All edges of the component have been examined.
By Lemma&nbsp;1 each of them connects vertices of opposite provisional colours,
hence the provisional 0/1 assignment is a proper 2‑colouring.
∎



##### Lemma 3  
For a bipartite component the algorithm assigns final windows so that the
smallest‑indexed vertex of the component receives window 1.

**Proof.**  
Let `w` be that vertex and `c = colour[w]` its provisional colour.
If `c = 0` we map `0 → 1 , 1 → 2`; otherwise we flip the mapping.
Thus the final window of `w` is `1` in both cases. ∎



##### Lemma 4  
Let `S` be the sequence produced by the algorithm (when it outputs `YES`).
For every component, any feasible roster that is lexicographically smaller than `S`
must assign window 2 to the smallest‑indexed vertex of that component.

**Proof.**  
Consider a component `C` and its smallest vertex `w`.
By Lemma&nbsp;3 the algorithm gives `w` window 1.
If another feasible roster `T` differs from `S` first at position `w`,
then `T[w]` must be `2` (otherwise it equals `S[w]`).
Thus any lexicographically smaller feasible roster would need to give `w` window 2. ∎



##### Lemma 5  
No feasible roster is lexicographically smaller than the sequence `S`
produced by the algorithm.

**Proof.**  
Assume a feasible roster `T` with `T < S`.  
Let `i` be the first index where they differ.
Vertex `i` belongs to some component `C`.  
All vertices `< i` belong to components whose smallest vertex index is `< i`,
hence by Lemma&nbsp;3 they already have window 1 in `S`.
Since `T[i] < S[i]` and the only possible values are `1,2`,
we must have `T[i]=1` and `S[i]=2`.  
But Lemma&nbsp;3 guarantees that the smallest‑indexed vertex of `C`
receives window 1 in `S`.  
Therefore `i` cannot be the smallest vertex of `C`; it is a later vertex.
Flipping the whole component would change the colour of its smallest vertex,
making the sequence larger at an earlier position, contradicting the minimality
of `i`. Hence such `T` cannot exist. ∎



##### Lemma 6  
If the algorithm outputs `NO`, no feasible roster exists.

**Proof.**  
`NO` is printed only when a component is found non‑bipartite
(Lemma&nbsp;1). Any roster must give different windows to the ends of every edge,
which is impossible for a non‑bipartite component. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff the instance has no feasible roster,  
* otherwise `YES` and the lexicographically smallest feasible roster.

**Proof.**  
*If* the algorithm prints `NO`, by Lemma&nbsp;6 no roster exists.  
*If* it prints `YES`, all components were bipartite (Lemma&nbsp;2), so the
produced sequence `S` is a feasible roster.
By Lemma&nbsp;5 no feasible roster is lexicographically smaller,
hence `S` is the lexicographically minimum one. ∎

#### Complexity Analysis  

*Building adjacency lists*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge processed once → `O(n + m)` time.  
*Total*: `O(n + m)` time, `O(n + m)` memory, well within limits (`n,m ≤ 2·10⁵`).

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    g = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        g[u].append(v)
        g[v].append(u)

    provisional = [-1] * n          # 0 / 1 provisional colours
    answer = [0] * n                # final windows (1 or 2)

    for start in range(n):
        if provisional[start] != -1:
            continue

        # BFS of this component
        q = deque([start])
        provisional[start] = 0
        comp = [start]
        bipartite = True

        while q and bipartite:
            u = q.popleft()
            cu = provisional[u]
            for v in g[u]:
                cv = provisional[v]
                if cv == -1:
                    provisional[v] = cu ^ 1
                    q.append(v)
                    comp.append(v)
                elif cv == cu:
                    bipartite = False
                    break

        if not bipartite:
            print("NO")
            return

        # orient component so that its smallest index gets window 1
        min_vertex = min(comp)
        if provisional[min_vertex] == 0:
            map0, map1 = 1, 2
        else:
            map0, map1 = 2, 1

        for v in comp:
            answer[v] = map0 if provisional[v] == 0 else map1

    print("YES")
    sys.stdout.write(' '.join(map(str, answer)))

if __name__ == "__main__":
    solve()
```
