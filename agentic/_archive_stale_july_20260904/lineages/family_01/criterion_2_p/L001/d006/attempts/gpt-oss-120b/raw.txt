**Solution Explanation**

For a monomer `i` we choose a resonance level `r_i ∈ {1,2}`.
For a bond `{u,v}` the stability score is  

```
S(u,v) = 3 (r_u + r_v) – 2 r_u r_v
```

The required total is `5·m`.  
First we examine the possible values of `S(u,v)`.

| r_u | r_v | S(u,v) |
|-----|-----|--------|
| 1   | 1   | 4 |
| 1   | 2   | 5 |
| 2   | 1   | 5 |
| 2   | 2   | 4 |

So a bond contributes **5** iff its ends have *different* resonance levels,
otherwise it contributes **4**.

The sum over all `m` bonds equals `5·m` **iff every bond contributes 5**,
i.e. **every recorded edge must connect vertices of different values**.
Thus we need a 2‑colouring of the given graph where adjacent vertices have
different colours – exactly the definition of a *bipartite* graph.

If the graph is not bipartite, the answer is `NO`.
If it is bipartite, many colourings exist: for each connected component we may
swap the two colour classes.  
We have to output the lexicographically smallest sequence
`r_1 … r_n` (1 < 2).  

Observation  
For a component let `C` be the set of its vertices and let `A,B` be the two
colour classes produced by any BFS/DFS (they are uniquely defined up to swapping).
Let `v_min` be the smallest index in `C`.  
If we colour `v_min` with `1` we obtain a sequence that is not larger
lexicographically than any sequence where `v_min` gets `2`, because the first
position where the two sequences may differ is exactly `v_min`.  
Therefore the optimal choice for the component is:

*assign colour `1` to the class that contains the smallest vertex of the component,
and colour `2` to the other class.*

Doing this independently for every component yields the globally lexicographically
smallest valid assignment.

The algorithm:

```
read n,m
build adjacency list
if m == 0:
    output YES and n times 1
    exit

colour = [0]* (n+1)          # 0 = unvisited, 1 or 2 = resonance level
for each vertex v = 1..n:
    if colour[v] == 0:
        bfs from v, using temporary parity 0/1
        if a conflict is found -> NOT BIPARTITE -> NO
        collect vertices of this component in list comp
        also collect two groups parity0, parity1
        let min_vertex = min(comp)
        if min_vertex in parity0:
            assign resonance 1 to parity0, 2 to parity1
        else:
            assign resonance 1 to parity1, 2 to parity0
output YES and the resonance list (ignoring index 0)
```

`BFS` runs in `O(|comp| + edges in comp)`. Over all components total time is
`O(n+m)`. Memory `O(n+m)`.

Correctness Proof
-----------------

We prove that the algorithm outputs `YES` with the lexicographically smallest
valid configuration iff such a configuration exists.

### Lemma 1  
For any edge `{u,v}` the stability contribution is 5 iff `r_u ≠ r_v`,
and 4 otherwise.

*Proof.* Direct computation of the four possibilities (shown in the table). ∎



### Lemma 2  
A resonance assignment satisfies the global constraint `∑ S = 5m`
iff the assignment is a proper 2‑colouring of the graph (adjacent vertices have
different values).

*Proof.* By Lemma&nbsp;1 each edge contributes 5 exactly when its ends differ.
The total sum equals `5m` precisely when every edge contributes 5,
i.e. when all edges connect different values. ∎



### Lemma 3  
If the algorithm reports `NO`, the graph is not bipartite, therefore no
valid assignment exists.

*Proof.* The algorithm reports `NO` only when during BFS an edge connects two
vertices that already have the same temporary parity. This is exactly the
definition of a non‑bipartite graph. By Lemma&nbsp;2 a valid assignment would be
a proper 2‑colouring, which cannot exist. ∎



### Lemma 4  
Assume the graph is bipartite. For each connected component the algorithm
assigns resonance `1` to the colour class that contains the smallest‑indexed
vertex of the component. The resulting global assignment is a proper
2‑colouring.

*Proof.* Within a component the two colour classes are opposite on every edge,
so giving the same resonance to each class yields a proper 2‑colouring.
Different components are independent, thus the whole graph is properly coloured. ∎



### Lemma 5  
Among all proper 2‑colourings, the assignment produced by the algorithm is
lexicographically minimal.

*Proof.* Consider any component `C` and let `v = min(C)`.  
Any proper colouring must give opposite values to the two colour classes of `C`.
If a colouring gives `r_v = 2`, then swapping the two classes (still a proper
colouring) would give `r_v = 1` and would be lexicographically smaller,
because the first differing position is `v`.  
Hence in a lexicographically minimal colouring `v` must receive `1`,
and consequently the whole class containing `v` receives `1`.  
The algorithm does exactly this for every component, therefore no other proper
colouring can be lexicographically smaller. ∎



### Lemma 6  
If the graph is bipartite, the algorithm outputs `YES` and a valid assignment.

*Proof.* By Lemma&nbsp;4 the produced assignment is a proper 2‑colouring,
hence by Lemma&nbsp;2 it satisfies the required total stability. ∎



### Theorem  
The algorithm outputs `NO` iff no resonance assignment satisfies the
constraint; otherwise it outputs `YES` and the lexicographically smallest
valid assignment.

*Proof.*  
- If the algorithm outputs `NO`, by Lemma&nbsp;3 the graph is not bipartite,
  thus by Lemma&nbsp;2 no valid assignment exists.
- If the algorithm outputs `YES`, the graph is bipartite; Lemma&nbsp;6 gives a
  valid assignment, and Lemma&nbsp;5 shows it is lexicographically minimal.

Thus the statement holds. ∎



Complexity Analysis
-------------------

- Building adjacency list: `O(n+m)` time, `O(n+m)` memory.
- BFS over all components: each vertex and edge processed once → `O(n+m)` time.
- Overall: **Time `O(n+m)`, Memory `O(n+m)`**, well within limits (`n,m ≤ 2·10⁵`).

Reference Implementation (Python 3)
------------------------------------*/

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    if m == 0:
        # any assignment works, smallest is all 1
        print("YES")
        print(" ".join(["1"] * n))
        return

    # 0 = unvisited, 1/2 = final resonance level
    res = [0] * (n + 1)
    # temporary parity during BFS: 0 or 1
    parity = [0] * (n + 1)

    for start in range(1, n + 1):
        if res[start]:
            continue
        # start new component
        q = deque([start])
        parity[start] = 0
        comp = [start]
        part = [[], []]          # vertices with parity 0 / 1
        part[0].append(start)
        ok = True
        while q and ok:
            v = q.popleft()
            for to in adj[v]:
                if not res[to] and parity[to] == 0 and to not in part[0] and to not in part[1]:
                    # not visited yet in this component
                    parity[to] = parity[v] ^ 1
                    part[parity[to]].append(to)
                    comp.append(to)
                    q.append(to)
                else:
                    # already visited in this component
                    if parity[to] == parity[v]:
                        ok = False
                        break
        if not ok:
            print("NO")
            return
        # decide which parity gets resonance 1
        min_vertex = min(comp)
        if min_vertex in part[0]:
            one, two = 0, 1
        else:
            one, two = 1, 0
        for v in part[one]:
            res[v] = 1
        for v in part[two]:
            res[v] = 2

    # all vertices assigned
    print("YES")
    print(" ".join(str(res[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
