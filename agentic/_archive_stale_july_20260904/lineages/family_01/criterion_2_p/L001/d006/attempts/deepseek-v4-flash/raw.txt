 We can simplify the bond score formula.  

For each bond between \( u \) and \( v \):  
- If both are 1: score = \( 3(1+1) - 2(1)(1) = 6 - 2 = 4 \)  
- If one is 1 and the other is 2: score = \( 3(1+2) - 2(1)(2) = 9 - 4 = 5 \)  
- If both are 2: score = \( 3(2+2) - 2(2)(2) = 12 - 8 = 4 \)  

So the score is 5 only when the two monomers have different values, and 4 when they are the same.  

The total score must be \( 5m \).  
Let \( x \) be the number of edges with different values. Then the total score is:  
\[
4(m - x) + 5x = 4m + x
\]  
We need \( 4m + x = 5m \), so \( x = m \).  

That means **every edge must connect two monomers with different values**.  

So the graph must be bipartite, and we assign 1 to one partition and 2 to the other.  
For lexicographically smallest, we assign 1 to the first node, then BFS/DFS to color the graph. If a conflict occurs, output `NO`.  

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
color[0] = 1  # assign 1 to first node

q = deque([0])
ok = True

while q and ok:
    u = q.popleft()
    for v in adj[u]:
        if color[v] == -1:
            color[v] = 3 - color[u]  # alternate 1 <-> 2
            q.append(v)
        elif color[v] == color[u]:
            ok = False
            break

# In case graph is disconnected, color remaining components
for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q and ok:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break

if not ok:
    print("NO")
else:
    print("YES")
    print(" ".join(str(color[i]) for i in range(n)))
```
