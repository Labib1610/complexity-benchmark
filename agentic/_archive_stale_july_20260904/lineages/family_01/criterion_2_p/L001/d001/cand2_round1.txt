# Problem B — Fluid Balancing

Time limit: 1 s   Memory limit: 256 MB

A fluid distribution network contains $n$ pressure valves, sequentially numbered from 1 to $n$. Each valve must be configured to an internal pressure level of either 1 or 2.

The network is equipped with $m$ balancing pipes. Each balancing pipe connects two specific valves. To ensure proper directional flow and prevent fluid stalling, the system requires that for every balancing pipe, the sum of the pressure levels of the two valves it connects must be exactly 3.

You need to determine a complete configuration of pressure levels for all $n$ valves that satisfies this requirement for all balancing pipes. If no such configuration is possible, you must report the failure. If multiple valid configurations exist, you must output the sequence of pressure levels that is lexicographically smallest.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of pressure valves and the number of balancing pipes.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a balancing pipe connects valve $u$ and valve $v$.

## Output
If no valid configuration of pressure levels can be found, output a single line containing `NO`.
Otherwise, output a line containing `YES`. On the following line, output $n$ space-separated integers $p_1, p_2, \dots, p_n$ (where each $p_i \in \{1, 2\}$) representing the pressure level for each valve. This sequence must be the lexicographically smallest among all valid configurations.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I reframed the scenario from a workforce with incompatible pairs to a fluid network with balancing pipes. I replaced the condition that connected entities must have "different values" with the algebraic equivalent that their sum "must be exactly 3" given the domain {1, 2}. This forces the model to deduce the logical equivalence to inequality before it can recognize the underlying bipartite structure.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement that the sum of two variables from {1, 2} equals 3 is logically identical to requiring them to take different values, maintaining the exact same valid configurations and lexicographical tie-breaking.
</PRESERVED_ANSWER>

The problem remains exactly 2-coloring (bipartiteness testing), which is solvable in linear time using BFS/DFS.
</PRESERVED_CLASS>
