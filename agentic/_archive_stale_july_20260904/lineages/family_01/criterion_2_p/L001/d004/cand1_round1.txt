<METHOD_NAME>Global Matrix Equation Obfuscation (Signless Laplacian)</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the local pairwise sum constraint with a global linear algebra constraint using the signless Laplacian matrix ($M = \text{diag}(D) + A$). Solving $MR = 3D$ for $R \in \{1, 2\}^n$ mathematically forces the exact same alternating assignments as the original problem, but requires algebraic deduction rather than simple graph-pattern matching.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<STATEMENT>
# Problem B — Polymer Resonance Tuning

Time limit: 1 s   Memory limit: 256 MB

A synthetic polymer consists of $n$ monomers, indexed from 1 to $n$. A tuning configuration assigns each monomer a resonance level, which must be chosen as either 1 or 2.

The laboratory maintains a record of $m$ covalent bonds between these monomers. From this record, we define two mathematical structures to evaluate molecular stability:
1. An $n$-dimensional column vector $D$, where $D_i$ is the number of bond endpoints attached to monomer $i$. (A bond between distinct monomers $u$ and $v$ provides one endpoint to $u$ and one to $v$. A bond connecting a monomer to itself provides two endpoints to that monomer).
2. An $n \times n$ symmetric matrix $A$, where $A_{i,j}$ is exactly the number of bonds connecting monomer $i$ and monomer $j$. (If a bond connects a monomer $i$ to itself, it contributes 2 to $A_{i,i}$).

We define the structural matrix $M = \text{diag}(D) + A$, where $\text{diag}(D)$ is the diagonal matrix with vector $D$ on its main diagonal.

A tuning configuration is represented as an $n$-dimensional column vector $R = [r_1, r_2, \dots, r_n]^T$ where each $r_i \in \{1, 2\}$. To ensure molecular stability, the configuration must perfectly satisfy the following matrix equation:
$M R = 3 D$

Your task is to determine a valid tuning configuration vector $R$. If multiple valid vectors exist, you must output the sequence $r_1, r_2, \dots, r_n$ that is lexicographically smallest. If no vector with elements strictly in $\{1, 2\}$ can satisfy the equation, you must report the failure.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$, identifying a bonded pair of monomers in the record. Both monomer identifiers $u$ and $v$ are at least 1 and at most $n$.

## Output
If no valid tuning configuration exists, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) representing the resonance level assigned to each respective monomer from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```
*(Note: In Example 1, $D = [2, 2, 2, 2]^T$. The matrix $M$ has diagonal entries $M_{i,i} = 2$. For $R = [1, 2, 1, 2]^T$, the first row of the product $M R$ evaluates to $2(1) + 1(2) + 0(1) + 1(2) = 6$, which perfectly matches $3 D_1 = 6$.)*

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The direct affordance "the sum of their assigned resonance levels must be exactly 3" allowed models to instantly reduce the problem to 2-coloring. By changing this to the global matrix equation $MR = 3D$ using the signless Laplacian, the local constraints are hidden. Models must now algebraically deduce that the $i$-th row of the equation evaluates to $D_i r_i + \sum A_{i,j} r_j = 3 D_i$, which restricts the neighbors' values to exactly $3 - r_i$. Models that attempt to solve the system using generic linear algebra or constraint solvers will fail the tight time limits.
</RATIONALE>
<PRESERVED_ANSWER>
The matrix equation mathematically simplifies to $\sum_{j} A_{i,j} r_j = D_i (3 - r_i)$ for every monomer $i$; since $r \in \{1, 2\}$ and $\sum A_{i,j} = D_i$, this sum can only be achieved if every neighbor $j$ is assigned strictly $3 - r_i$, making it functionally identical to the original pairwise sum constraint for all possible inputs (including multigraphs and self-loops).
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring (bipartite coloring) of the underlying graph, which is solvable in $O(n + m)$ time using Breadth-First Search, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
Models or users might misinterpret the construction of matrix $A$ for self-loops, though the parenthetical "(If a bond connects a monomer $i$ to itself, it contributes 2 to $A_{i,i}$)" is mathematically precise and aligns with standard algebraic graph theory definitions.
</RISK>
