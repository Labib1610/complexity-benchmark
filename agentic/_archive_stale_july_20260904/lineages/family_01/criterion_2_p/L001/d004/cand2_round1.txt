<STATEMENT>
# Problem B — State Resolution

Time limit: 1 s   Memory limit: 256 MB

A system consists of $n$ variables, indexed from 1 to $n$. A tuning configuration assigns each variable a state, which must be chosen as either 1 or 2.

The laboratory maintains a record of $m$ logical dependencies between pairs of these variables. To ensure system stability, every recorded dependency between a pair of variables must be satisfied. 

The specific logical clause that must be satisfied depends on the sum of the indices of the two variables involved. For each recorded dependency given as a pair $u$ and $v$ in the input, let $k = (u + v) \bmod 4$. The tuning configuration must satisfy the following:
- If $k = 0$: At least one of the variables $u$ or $v$ must be in state 1, AND at least one of the variables $u$ or $v$ must be in state 2.
- If $k = 1$: It must NOT be the case that both $u$ and $v$ are in state 1, AND it must NOT be the case that both $u$ and $v$ are in state 2.
- If $k = 2$: If $u$ is in state 1, then $v$ must be in state 2; AND if $u$ is in state 2, then $v$ must be in state 1.
- If $k = 3$: The statement "$u$ is in state 1" must be logically equivalent to the statement "$v$ is in state 2".

Your task is to determine a valid tuning configuration for all $n$ variables. If multiple valid configurations exist, you must output the sequence of states that is lexicographically smallest. If no configuration can satisfy all recorded dependencies simultaneously, you must report the failure.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$, identifying a pair of variables that have a recorded dependency. Both identifiers $u$ and $v$ are at least 1 and at most $n$.

## Output
If no valid tuning configuration exists, output `NO` on a single line.
Otherwise, output `YES` on the first line. On the second line, output $n$ space-separated integers $r_1, r_2, \dots, r_n$ (where each $r_i \in \{1, 2\}$) representing the state assigned to each respective variable from 1 to $n$. This sequence must be the lexicographically smallest possible valid sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The previous version used a uniform sum constraint ("sum must be exactly 3"), which directly triggered models to recognize bipartite graph coloring. I replaced this with four distinct logical clauses selected by index parity, phrased using standard 2-SAT terminology (implications, equivalences, AND/OR). This forces the model to either blindly implement a general 2-SAT solver (which will fail or TLE when trying to find the lexicographically smallest solution) or to analytically deduce that all four clauses are mathematically equivalent to $r_u \neq r_v$.
</RATIONALE>
<PRESERVED_ANSWER>
For variables restricted to $\{1, 2\}$, all four logical clauses evaluate to true if and only if the two variables are assigned different states, meaning the set of valid configurations and the lexicographically smallest one remain completely identical to the seed problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of an undirected graph, which is solvable in $O(V+E)$ time, keeping it in P.
</PRESERVED_CLASS>
