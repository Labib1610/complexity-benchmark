# Problem B — Power Grid Calibration

Time limit: 1 s   Memory limit: 256 MB

You are calibrating a network of $n$ substations. Each substation must be configured to operate at a power level of either 1 or 2.

There are $m$ proximity reports between pairs of substations. When a proximity report exists between two substations, they share a local grid loop. To avoid overloading or underpowering the loop, the sum of the power levels of any two substations with a proximity report must be exactly 3.

Determine if it is possible to configure all $n$ substations under these constraints. If no such configuration can be made, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of substations with a proximity report.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
