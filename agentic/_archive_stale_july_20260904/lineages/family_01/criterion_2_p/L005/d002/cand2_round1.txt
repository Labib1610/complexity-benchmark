<STATEMENT>
# Problem B — Module Configuration

Time limit: 1 s   Memory limit: 256 MB

You are configuring a system of $n$ modules. Each module must be assigned a logic state of either $1$ or $2$. 

The system has $m$ interference links, each connecting a pair of modules. To prevent system failure, any two modules connected by an interference link must have their logic states configured such that the bitwise XOR (exclusive OR) of their states evaluates to exactly $3$. 

You must assign a logic state to every module. If it is impossible to configure the system to satisfy the requirement for all interference links, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 200000$, $0 \le m \le 200000$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of modules connected by an interference link.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$, each equal to 1 or 2, representing the logic states of the modules. If multiple valid configurations exist, output the lexicographically smallest one.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the edge condition from "product is exactly 2" to "bitwise XOR evaluates to exactly 3". This forces the model to evaluate the bitwise operation over the domain {1, 2} to discover that it still mandates opposite assignments, rather than triggering bipartite graph algorithms via immediate pattern matching on the product of 1 and 2.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed states are 1 and 2, the bitwise XOR of two states is 3 if and only if they are different (1 and 2), which is mathematically identical to their product being 2, keeping all valid configurations exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires assigning one of two states to each node such that no two adjacent nodes share the same state, which is exactly 2-coloring (bipartiteness testing) and remains solvable in linear time.
</PRESERVED_CLASS>
<RISK>
None, as bitwise XOR is a strictly defined mathematical operation with only one possible interpretation for the values 1 and 2.
</RISK>
