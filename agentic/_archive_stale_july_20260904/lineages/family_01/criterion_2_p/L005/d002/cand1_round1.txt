<STATEMENT>
# Problem B — Resource Allocation

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ nodes. Each node must be assigned a tier of either $1$ or $2$. 

The network has $m$ communication channels, each connecting a pair of nodes. Each channel has exactly 3 units of bandwidth available. To fully utilize the network without overloading it, the two nodes connected by any channel must together consume exactly the available bandwidth of that channel. A node assigned to tier $s$ consumes exactly $s$ units of bandwidth on each of its connected channels.

You must assign a tier to every node. If it is impossible to configure the network to satisfy the bandwidth requirement for all channels, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 200000$, $0 \le m \le 200000$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of nodes connected by a communication channel.

## Output
If no valid configuration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$, each equal to 1 or 2, representing the tiers of the nodes. If multiple valid configurations exist, output the lexicographically smallest one.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit condition "product of states is exactly 2" was replaced with a resource allocation constraint requiring nodes to collectively consume exactly 3 units of bandwidth per channel. This removes the direct trigger for 2-coloring while forcing the model to algebraically deduce that $s_u + s_v = 3$ for $s_i \in \{1, 2\}$ implies adjacent nodes must take opposite values.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement $s_u + s_v = 3$ for variables restricted to $\{1, 2\}$ is mathematically equivalent to the original $s_u \times s_v = 2$, meaning the exact same assignments remain valid and the lexicographical tie-breaker yields the same result.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still requires assigning two distinct values to adjacent nodes in an undirected graph, which is the definition of 2-coloring and solvable in $O(n+m)$ time via BFS/DFS.
</PRESERVED_CLASS>
<RISK>
A reader might misinterpret "consumes exactly $s$ units of bandwidth on each of its connected channels" as a global total across all channels rather than a per-channel amount, although the phrasing "on each of its connected channels" is intended to prevent this.
</RISK>
