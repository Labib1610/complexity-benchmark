<STATEMENT>
# Calibration Valves

Time limit: 1 s   Memory limit: 256 MB

A fluid transport network contains $n$ calibration valves, numbered $1$ to $n$. Each valve must be configured to an operating pressure level of either $1$ or $2$.

The network is monitored by $m$ differential sensors. Each sensor bridges a specific pair of valves. To maintain structural equilibrium, a sensor yields a valid reading if and only if the two valves it bridges are configured such that their combined pressure level is exactly $3$.

You must determine a pressure level for each of the $n$ valves such that every sensor in the network yields a valid reading. If there are multiple valid configurations, you must output the sequence of pressure levels $p_1, \dots, p_n$ that is lexicographically smallest. If no valid configuration exists, report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of a pair of valves bridged by a sensor.

## Output
If no valid configuration exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $p_1 \dots p_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit four-row lookup table was replaced with the condition that the combined pressure of connected valves must be exactly 3. Since the only allowed values are 1 and 2, this mathematically enforces that bridged valves have different values ({1,2} or {2,1}), preserving the exact same bipartite structure without triggering pattern-matching on the explicit invalid/valid pairings.
</RATIONALE>
<PRESERVED_ANSWER>
Requiring values from {1,2} to sum to 3 is logically identical to the original lookup table where only (1,2) and (2,1) are valid, so the set of valid configurations for any input is exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding a valid 2-coloring (testing bipartiteness) and picking the lexicographically smallest orientation per connected component, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "combined pressure level" as applying to more than two valves, but the text explicitly says "the two valves it bridges", minimizing this risk.
</RISK>
