We can simplify the equation:

\[
2p_u^2 - 5p_u p_v + 2p_v^2 = 0
\]

Factor:

\[
(2p_u - p_v)(p_u - 2p_v) = 0
\]

So either:

- \(2p_u = p_v\)  
- or \(p_u = 2p_v\)

Since \(p_u, p_v \in \{1, 2\}\), the only valid pairs are:

- (1, 2)  
- (2, 1)

That means every edge must connect two modules with **different** modes.  
So the graph must be bipartite, and we need the lexicographically smallest 2-coloring.

We can solve with BFS/DFS, assigning 1 to the first node in each component, and flipping colors along edges. If a conflict occurs, output `NO`.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
