<STATEMENT>
# Orbital Reflection Synchrony

Time limit: 1 s   Memory limit: 256 MB

A satellite network consists of $n$ orbital modules, numbered $1$ through $n$. You must assign each module an operating mode, represented by the integer $1$ or $2$.

Each mode corresponds to a specific $3 \times 3$ configuration grid:
- Mode 1 corresponds to the grid $C_1$:
  ```text
  1 2 0
  0 1 2
  0 0 1
  ```
- Mode 2 corresponds to the grid $C_2$:
  ```text
  1 0 0
  2 1 0
  0 2 1
  ```

The network's synchronization is governed by $m$ telemetry channels. Each channel connects a specific pair of modules. For a channel to function correctly, the two connected modules must have a compatibility score of exactly $11$. 

The compatibility score between a module with grid $A$ and a module with grid $B$ is calculated as the sum of $A[r][c] \times B[c][r]$ over all rows $r$ and columns $c$ (where $1 \le r, c \le 3$). Because this sum is symmetric with respect to swapping $A$ and $B$, the score is independent of which module is considered $A$ and which is $B$.

Your task is to assign an operating mode ($1$ or $2$) to each of the $n$ modules so that every telemetry channel functions correctly. If multiple valid assignments are possible, you must output the lexicographically smallest valid sequence of modes. If no such assignment is possible, you must report that it cannot be done.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), representing the indices of a pair of modules connected by a telemetry channel.

## Output
If it is impossible to configure the modules to satisfy all channels, output a single line with NO.
If it is possible, output YES on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1,2\}$) giving the lexicographically smallest valid sequence of modes.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The words "matrix", "product", and "trace" were removed, as they acted as a strong trigger for the models to skip reasoning and jump straight to bipartite coloring. By replacing the linear algebra operations with an explicit double sum over a 2D grid, the models are forced to actually evaluate the formula to discover the same/different mode constraint.
</RATIONALE>
<PRESERVED_ANSWER>
The compatibility score for grids A and B evaluates to exactly the trace of the matrix product of A and B, meaning identical grids yield 3 and different grids yield 11, preserving the exact same valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying problem is still finding the lexicographically smallest valid 2-coloring of a graph, keeping the complexity class in P.
</PRESERVED_CLASS>
