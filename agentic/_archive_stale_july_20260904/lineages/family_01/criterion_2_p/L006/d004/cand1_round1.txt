<STATEMENT>
# Assembly Synchronization

Time limit: 1 s   Memory limit: 256 MB

You are configuring a manufacturing plant with $n$ automated assemblers, numbered $1$ through $n$. Each assembler must be programmed with a cycle duration of either $1$ minute or $2$ minutes. 

The plant's quality control system evaluates production using $m$ synchronization links. Each link monitors a specific pair of assemblers during a continuous $2$-minute diagnostic window. At the start of this window, both assemblers begin running simultaneously and operate without interruption. Since an assembler completes a full cycle every $p_i$ minutes (where $p_i$ is its configured cycle duration), it completes exactly $2/p_i$ cycles within the window.

For a synchronization link to pass diagnostics, the total combined number of completed cycles from the two connected assemblers must be exactly $3$. If the combined cycle count is anything other than $3$, the synchronization link fails.

Your task is to assign a cycle duration to each of the $n$ assemblers so that every synchronization link passes diagnostics. If multiple valid configurations are possible, you must output the lexicographically smallest one (preferring a duration of $1$ minute for lower-numbered assemblers). If no such configuration is possible, you must report that it cannot be done.

## Input
The first line contains two integers $n$ and $m$. The physical limits of the facility guarantee that there is at least one assembler and at most two hundred thousand. The wiring infrastructure supports a maximum of two hundred thousand links, and there may be as few as zero.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), representing the indices of a pair of assemblers connected by a synchronization link.

## Output
If it is impossible to configure the assemblers to satisfy all links, output a single line with `NO`.
If it is possible, output `YES` on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1,2\}$) giving the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the direct summation of assigned values with a rate-based calculation where the number of completed cycles is inversely proportional to the assigned value. This mathematically enforces $2/p_u + 2/p_v = 3$, requiring an extra step of reasoning to deduce that $p_u$ and $p_v$ must be different, thereby defeating models that rely on surface-level pattern matching for "sum equals 3". I also applied Strategy S07 to encode the numeric bounds as physical limits of the facility.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $2/p_u + 2/p_v = 3$ for $p_i \in \{1,2\}$ is only satisfied when one value is 1 and the other is 2, which is exactly the same logical constraint as $p_u + p_v = 3$, ensuring all valid assignments remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still asks for a 2-coloring of a graph (with the lexicographically smallest components), which remains solvable in linear time using Breadth-First Search.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the division $2/p_i$ if they assume fractional cycles are allowed to sum to 3 in a way other than $1+2$, but the domain of $p_i$ is strictly $\{1,2\}$, so the only possible cycle counts are 1 and 2, removing any ambiguity.
</RISK>
