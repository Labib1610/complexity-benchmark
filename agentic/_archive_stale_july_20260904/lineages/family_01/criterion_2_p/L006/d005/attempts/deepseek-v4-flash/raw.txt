 We can model each module as a variable that can be either 1 or 2.  
Each channel imposes a constraint between two modules.  

Let’s analyze the transformation:  
- Mode 1: (x, y) → (-x, y)  
- Mode 2: (x, y) → (x, -y)  

If we apply mode of module u then mode of module v, the result must be (-x, -y).  

Let’s check the four combinations:  

- u=1, v=1: (-x, y) → (x, y) → not (-x, -y) → invalid  
- u=1, v=2: (-x, y) → (-x, -y) → valid  
- u=2, v=1: (x, -y) → (-x, -y) → valid  
- u=2, v=2: (x, -y) → (x, y) → not (-x, -y) → invalid  

So the constraint is: **u and v must have different modes**.  

Thus, the problem reduces to:  
Given an undirected graph, can we 2-color it (bipartite check), and if yes, output the lexicographically smallest assignment (1 for first color, 2 for second).  

We can do BFS/DFS, assigning colors, and if conflict → NO.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

# Convert 0 -> 1, 1 -> 2
res = [1 if c == 0 else 2 for c in color]
print("YES")
print(" ".join(map(str, res)))
```
