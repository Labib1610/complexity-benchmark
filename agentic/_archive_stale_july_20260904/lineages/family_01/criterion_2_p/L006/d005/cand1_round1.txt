<STATEMENT>
# Spatial Alignment Network

Time limit: 1 s
Memory limit: 256 MB

You are calibrating a network of $n$ spatial alignment modules, numbered $1$ through $n$. Each module must be assigned exactly one of two operational modes, identified by the integer $1$ or $2$.

The modes determine how a module transforms a 2D input signal $(x, y)$:
- Mode 1 applies the transformation $T_1(x, y) = (-y, x)$.
- Mode 2 applies the transformation $T_2(x, y) = (y, -x)$.

The network's stability is governed by $m$ bidirectional synchronization channels. Each channel connects a specific pair of modules. For a channel to stabilize, the sequential application of the transformations assigned to its two endpoints must leave any input signal completely unchanged. That is, if the channel connects module $u$ and module $v$, it must hold that $T_u(T_v(x, y)) = (x, y)$ for all real coordinates $x$ and $y$. (Because these specific transformations commute, the order of application does not matter). If the composition alters the signal in any way, the channel destabilizes.

Your task is to assign a mode (either $1$ or $2$) to each of the $n$ modules so that every synchronization channel in the network stabilizes. If multiple valid overall assignments are possible, you must output the one whose sequence of assigned integers is lexicographically smallest (i.e., preferring mode 1 for lower-numbered modules whenever a choice exists). If no such assignment exists, you must report that calibration is impossible.

## Input
The first line provides two integers $n$ and $m$. The number of modules $n$ is at least 1, and the number of channels $m$ is at least 0. Neither will exceed the total number of seconds in exactly 55 hours, 33 minutes, and 20 seconds.
The following $m$ lines each contain two integers $u$ and $v$, representing the indices of a pair of modules connected by a synchronization channel.

## Output
If it is impossible to assign modes to satisfy all channels, output a single line with `NO`.
If it is possible, output `YES` on the first line. On the second line, output $n$ integers $p_1 \dots p_n$ (where each $p_i \in \{1,2\}$) giving the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit XOR constraint with a functional composition constraint using 2D transformations, and replaced the numeric bounds with a time conversion equivalent (55h 33m 20s = 200,000s) following S07. This forces the model to mathematically evaluate the compositions to discover that connected modules must have different modes, defeating models that rely on explicitly stated binary incompatibility.
</RATIONALE>
<PRESERVED_ANSWER>
The functional composition $T_u(T_v(x, y)) = (x, y)$ holds if and only if one module is assigned Mode 1 and the other Mode 2, which is logically identical to the original requirement that their XOR evaluates to 3, preserving all valid configurations and the lexicographical tie-breaker.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in O(n + m) time using BFS or DFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the functional composition as requiring them to simulate signals dynamically rather than statically deducing the pairwise constraints, though the universal quantifier "for all real coordinates" should clarify it's a static property.
</RISK>
<METHOD_NAME>
Functional Composition Equivalence
</METHOD_NAME>
<METHOD_DESCRIPTION>
Replaces a direct binary incompatibility constraint (like XOR or inequality) with a requirement that the composition of two functions yields the identity function. This defeats pattern matching by hiding the constraint inside algebraic properties that must be explicitly evaluated to discover the underlying graph coloring structure.
</METHOD_DESCRIPTION>
