# Token Arrangement Network

Time limit: 1 s   Memory limit: 256 MB

A computational network consists of $n$ processing units, numbered $1$ through $n$. You must assign a configuration parameter $c_i \in \{1, 2\}$ to each unit.

The network contains $m$ synchronization channels. Each channel connects a specific pair of units. For a channel to synchronize properly, the parameters of its two connected units, $u$ and $v$, must satisfy a specific combinatorial property:
Suppose you create a multiset containing exactly $c_u$ identical 'Alpha' tokens and $c_v$ identical 'Beta' tokens. The number of strictly distinct linear arrangements (permutations) of all tokens in this multiset must evaluate to exactly 3. If it evaluates to any other number, the channel collapses and yields an invalid state.

Your task is to assign a parameter (either $1$ or $2$) to each of the $n$ units so that every synchronization channel operates correctly.
If multiple valid assignments are possible, you must output the one that strictly minimizes the massive $n$-digit integer formed by concatenating the assigned parameters $c_1 c_2 \dots c_n$ (with $c_1$ acting as the most significant digit). If no such assignment is possible, you must report that it cannot be done.

## Input
The first line provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
The following $m$ lines each contain two integers $u$ and $v$, representing the indices of a pair of units connected by a synchronization channel.

## Output
If it is impossible to configure the units to satisfy all channels, output a single line with NO.
If it is possible, output YES on the first line. On the second line, output $n$ integers $c_1 \dots c_n$ (where each $c_i \in \{1,2\}$) giving the optimal valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit bitwise XOR condition was replaced with a combinatorial property (permutations of a multiset) that evaluates to exactly 3 if and only if the two chosen values are different (1 and 2). The tie-breaking rule was rephrased from "lexicographically smallest" to "minimizing the n-digit integer formed by concatenating the sequence", which is mathematically identical but forces the model to bridge the gap between numeric optimization and array lexicographical order.
</RATIONALE>

The combinatorial constraint mathematically requires adjacent nodes to have different values (1 and 2), which is exactly the original XOR constraint, and minimizing the concatenated integer is strictly equivalent to finding the lexicographically smallest sequence.
</PRESERVED_ANSWER>
