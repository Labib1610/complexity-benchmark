We can compute the trace for each pair of modes:

- Mode 1 × Mode 1:  
  \( M_1 M_1 \) trace = 1+1+1 = 3? Let’s compute:  
  \( M_1 = \begin{pmatrix}1&2&0\\0&1&2\\0&0&1\end{pmatrix} \)  
  \( M_1^2 = \begin{pmatrix}1&4&4\\0&1&4\\0&0&1\end{pmatrix} \), trace =   3.

- Mode 2 × Mode 2:  
  \( M_2 = \begin{pmatrix}1&0&0\\2&1&0\\0&2&1\end{pmatrix} \)  
  \( M_2^2 = \begin{pmatrix}1&0&0\\4&1&0\\4&4&1\end{pmatrix} \), trace =   3.



- Mode 1 × Mode 2:  
  \( M_1 M_2 = \begin{pmatrix}1&0&0\\2&1&0\\4&2&1\end{pmatrix} \), trace =   3? Wait: diagonal =  (1,1,1) → 3.  
  But also \( M_2 M_1 = \begin{pmatrix}1&2&0\\2&5&4\\0&2&5\end{pmatrix} \), trace =   1+5+5=11.  
  Since trace of product is independent of order, we must get 11.  
  So \( M_1 M_2 \) trace =   11? Let’s check:  
  \( M_1 M_2 = \begin{pmatrix}1&0&0\\2&1&0\\4&2&1\end{pmatrix} \) diagonal =   1,1,1 → 3.  
  But \( M_2 M_1 = \begin{pmatrix}1&2&0\\2&5&4\\0&2&5\end{pmatrix} \) diagonal =   1+5+5=11.  
  Since trace(AB)=trace(BA), we should use the product that gives 11.  
  So mode 1 and mode 2 together give trace 11.  
  Mode 1 with mode 1 gives 3, mode 2 with mode 2 gives 3.

Thus a channel works iff the two modules have different modes.

So the problem reduces to: color each vertex 1 or 2 such that every edge connects different colors — i.e., bipartite graph. If not bipartite, output NO. If bipartite, output lexicographically smallest coloring (with 1 and 2) among all valid bipartitions.

Lexicographically smallest: We want vertex 1 as small as possible (1), then vertex 2, etc. This is equivalent to: assign colors via BFS/DFS, but when a component is uncolored, start with color 1 for the smallest-index vertex in that component. Then propagate alternating colors. This yields the lexicographically smallest because any valid coloring must alternate within each connected component; choosing the smallest uncolored vertex as 1 is optimal.

Implementation: adjacency list, BFS/DFS with color array (0 uncolored, 1 or 2). For each vertex i from 1 to n, if uncolored, set color[i]=1, BFS/DFS assign alternating colors. If conflict, NO.

Complexity O(n+m).)

Let’s write the code.```python
import sys
from collections import deque

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u, v = map(int, input().split())
        adj[u].append(v)
        adj[v].append(u)

    color = [0] * (n + 1)

    for start in range(1, n + 1):
        if color[start] == 0:
            color[start] = 1
            q = deque([start])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = 3 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return

    print("YES")
    print(" ".join(map(str, color[1:]))))

if __name__ == "__main__":
    solve()
