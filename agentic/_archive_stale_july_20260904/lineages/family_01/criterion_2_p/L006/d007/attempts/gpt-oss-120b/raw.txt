**Solution Explanation**

For every module we have to choose a mode `1` or `2`.

```
mode 1 :  M1 = |1 2 0|
               |0 1 2|
               |0 0 1|

mode 2 :  M2 = |1 0 0|
               |2 1 0|
               |0 2 1|
```

For a telemetry channel `(u , v)` the product `Mu * Mv` must have trace `11`.

--------------------------------------------------------------------

#### 1.   Which pairs are allowed ?

```
trace(M1·M1) = 3
trace(M2·M2) = 3
trace(M1·M2) = 11          (the same as trace(M2·M1))
```

Only a *different* pair of modes gives the required trace.
Therefore every channel has to connect two modules of **different**
modes.

So the whole problem is exactly:

*colour the vertices of the given graph with two colours
(1 and 2) such that adjacent vertices have different colours.*

That is the classic **bipartite graph** problem.

--------------------------------------------------------------------

#### 2.   Bipartite check and component handling  

We run a BFS/DFS over all vertices.

* `col[v] = 0`  – first colour of the component  
* `col[v] = 1`  – second colour  

During the search, if we ever meet an edge whose ends already have the
same colour, the graph is **not bipartite** → answer `NO`.

While exploring a connected component we store all its vertices.
After the component is finished we have two possible assignments:

```
0 → mode 1 , 1 → mode 2          (call it version A)
0 → mode 2 , 1 → mode 1          (version B)
```

--------------------------------------------------------------------

#### 3.   Lexicographically smallest assignment  

The required output is the lexicographically smallest sequence
`p1 … pn`.

Consider one component.
Let `x` be the smallest index inside this component.
If we use version A, `px` is `1` when `col[x] = 0`,
otherwise it is `2`.  
If we use version B, the value is the opposite.

Both versions are feasible, therefore we can always choose the one
that makes `px = 1`.  
Doing this for **every** component yields the globally smallest
sequence, because the first position where two valid assignments can
differ is exactly the smallest index of some component, and we set it
to `1`.

Implementation:

```
for each component:
        let mn = minimal vertex index in the component
        if col[mn] == 0:   # version A already gives 1
                keep colours as they are
        else:              # need to swap
                for v in component: col[v] ^= 1
```

After processing all components we output `col[v] + 1` (`0 → 1`,
`1 → 2`).

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `YES` and the lexicographically
smallest valid assignment iff such an assignment exists.

---

##### Lemma 1  
For any edge `(u,v)` the condition “trace of the product equals 11”
holds **iff** the modes of `u` and `v` are different.

*Proof.* Computed traces above:
`trace(M1·M1)=trace(M2·M2)=3`, `trace(M1·M2)=trace(M2·M1)=11`. ∎



##### Lemma 2  
If the algorithm reports `NO`, the graph is not bipartite, therefore
no assignment satisfies all edges.

*Proof.* The algorithm reports `NO` only when during BFS an edge is
found whose ends already have the same colour. That is exactly the
definition of a non‑bipartite graph. By Lemma&nbsp;1 any satisfying
assignment must be a proper 2‑colouring, which does not exist. ∎



##### Lemma 3  
If the algorithm finishes without conflict, the produced sequence
satisfies all edges.

*Proof.* BFS colours every edge with opposite colours, otherwise a
conflict would have been detected. After the possible colour swap
inside a component, opposite colours stay opposite. By Lemma&nbsp;1
different colours mean different modes, hence every edge satisfies the
trace condition. ∎



##### Lemma 4  
For each connected component the algorithm chooses the assignment that
gives mode `1` to the smallest indexed vertex of the component.

*Proof.* Let `mn` be that vertex. If its colour is `0` we keep the
current mapping, giving it mode `1`. If its colour is `1` we flip all
colours in the component, turning it into `0` and again giving mode `1`. ∎



##### Lemma 5  
Among all valid assignments the algorithm’s output is lexicographically
minimal.

*Proof.* Consider the first position `i` where two valid assignments
`A` and `B` differ. Vertices `1 … i‑1` are equal, therefore they belong
to components whose smallest index is `< i`.  
Vertex `i` is the smallest index of its component (otherwise a smaller
vertex of the same component would already differ).  
By Lemma&nbsp;4 the algorithm forces this vertex to mode `1`. Any other
valid assignment either also gives `1` (then they are equal at `i`) or
gives `2`, which is larger. Hence no other valid assignment can be
lexicographically smaller. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no assignment of modes satisfies all telemetry channels;  

* otherwise `YES` and the lexicographically smallest satisfying
  assignment.

*Proof.*  
- If the algorithm prints `NO`, by Lemma&nbsp;2 no satisfying assignment
  exists.  
- If it prints `YES`, Lemma&nbsp;3 guarantees the assignment satisfies
  all edges, and Lemma&nbsp;5 guarantees it is the smallest possible.  

Conversely, if a satisfying assignment exists, the graph is bipartite,
so the BFS never meets a conflict and the algorithm will not output
`NO`. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

* `BFS/DFS` visits each vertex once and each edge twice: `O(n + m)` time.  
* All additional work is linear in the size of components: also
  `O(n + m)`.  

Memory consumption: adjacency list `O(n + m)` and a few arrays
`O(n)`. Both fit easily into the limits.

--------------------------------------------------------------------

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    g = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        g[u].append(v)
        g[v].append(u)

    col = [-1] * n          # 0 / 1
    from collections import deque
    for start in range(n):
        if col[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        col[start] = 0
        comp = [start]
        while q:
            v = q.popleft()
            for to in g[v]:
                if col[to] == -1:
                    col[to] = col[v] ^ 1
                    q.append(to)
                    comp.append(to)
                elif col[to] == col[v]:
                    print("NO")
                    return
        # make smallest index vertex colour 0 (=> mode 1)
        mn = min(comp)
        if col[mn] == 1:
            for v in comp:
                col[v] ^= 1

    # all good
    print("YES")
    ans = [str(c + 1) for c in col]
    print(' '.join(ans))

if __name__ == "__main__":
    solve()
```
