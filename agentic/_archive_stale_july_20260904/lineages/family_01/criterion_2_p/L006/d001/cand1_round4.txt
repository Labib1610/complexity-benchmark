# Polarity Configuration

Time limit: 1 s   Memory limit: 256 MB

A satellite deployment involves $n$ magnetic sensors, numbered 1 to $n$. Each sensor must be calibrated to a polarity state from the set $\{1, 2\}$. During operation, $m$ specific pairs of sensors will be placed in close proximity. For each such pair, the two sensors must be calibrated to strictly different polarity states to prevent magnetic locking.

Determine a valid polarity assignment for each of the $n$ sensors. To respect standardization, if multiple valid assignments exist, you must output the one that is lexicographically smallest (assigning state 1 to lower-numbered sensors whenever possible). If no valid assignment exists, report impossibility.

## Input
The first line contains two integers $n$ and $m$. The system requires a minimum of 1 sensor and supports a maximum payload capacity of $2 \cdot 10^5$ sensors. The number of proximity pairs can be as low as 0 and reaches a maximum limit of $2 \cdot 10^5$.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of sensors that will be in close proximity.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
