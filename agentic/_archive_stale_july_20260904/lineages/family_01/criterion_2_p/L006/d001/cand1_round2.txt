<STATEMENT>
# Production Cycle Segregation

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility operates two distinct production cycles daily, designated as cycle 1 and cycle 2. The facility has $n$ employees, numbered $1$ to $n$.

There are $m$ bilateral workflow constraints. Each constraint specifies two employees who must be strictly segregated into different cycles.

Determine a cycle allocation for every employee such that no two employees involved in the same bilateral constraint are placed in the same cycle. If multiple valid allocations exist, you must output the sequence of cycle assignments $s_1 \dots s_n$ that is lexicographically smallest. If no valid schedule exists, report impossibility.

## Input
The first line contains two integers $n$ and $m$. The headcount $n$ relies on a payroll system that requires at least $1$ active employee and supports up to a capacity of $200,000$ employees. The number of constraints $m$ can be $0$ (a completely empty ledger) up to a system maximum of $200,000$ entries.
Each of the subsequent $m$ lines provides two integers $u$ and $v$ (where both are between $1$ and $n$, inclusive) — the IDs of two employees who cannot share a cycle.

## Output
If no valid allocation exists, print a single line `NO`.
Otherwise, print `YES`, followed by a second line containing $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid allocation.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Changed "shifts" to "production cycles" and "incompatible pairs" to "bilateral workflow constraints" to obscure the standard graph coloring framing. The numerical bounds are now expressed as system capacities and minimums rather than bare mathematical inequalities, forcing the reader to interpret the physical constraints to derive the limits.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement to assign each employee to one of two cycles such that no constrained pair shares a cycle is logically identical to 2-coloring the conflict graph, and the exact lexicographical tie-breaker is explicitly maintained.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains a bipartite graph 2-coloring problem solvable in $O(n+m)$ time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
The phrase "lexicographically smallest" might be slightly abstract when applied to a "sequence of cycle assignments", but it is a standard competitive programming term and is clarified by the variables $s_1 \dots s_n$.
</RISK>
