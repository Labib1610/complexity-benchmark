**Solution Explanation**

For every edge `(u , v)` we need  

```
s_u + s_v = 3 ,   s_i ∈ {1,2}
```

The only possibilities are `(1,2)` or `(2,1)`.  
Thus the two ends of an edge must receive **different** values – the graph has to be
*2‑colourable* (bipartite).  
If the graph is not bipartite the answer is `NO`.

If it is bipartite we have two possible colourings for each connected component
(the two colour classes can be swapped).  
Among all global colourings we need the lexicographically smallest sequence
`(s1,…,sn)`.  
Lexicographic order is decided by the first position where two assignments differ,
so we should make the smallest possible value for the smallest index where we have a
choice.

**Observation**

In a component the only freedom is whether colour class `0` gets value `1` and class
`1` gets `2`, or the opposite.  
Let `p` be the smallest vertex index inside the component.
If we give the colour of `p` the value `1` we obtain the smallest possible value at
position `p`, and consequently the smallest possible whole sequence (later positions
cannot improve the order).  
Therefore for each component we simply:

* colour the component arbitrarily (e.g. BFS, colour `0`/`1`);
* if the colour of the smallest vertex is `0` keep the mapping `0→1 , 1→2`,
  otherwise flip it (`1→1 , 0→2`).

Doing this for every component yields the lexicographically minimal feasible assignment.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list
colour[1..n] = -1   // -1 = unvisited, 0/1 = bipartite colour
answer[1..n] = 0

for v = 1 .. n:
    if colour[v] == -1:
        // start new component
        queue = [v]; colour[v] = 0
        component = []          // vertices of this component
        while queue not empty:
            x = pop queue
            component.append(x)
            for each neighbour y of x:
                if colour[y] == -1:
                    colour[y] = colour[x] ^ 1
                    push y
                elif colour[y] == colour[x]:
                    print "NO" and exit   // not bipartite
        // decide mapping for this component
        p = min(component)                // smallest index in component
        if colour[p] == 0:
            map0 = 1; map1 = 2
        else:
            map0 = 2; map1 = 1
        for each vertex u in component:
            answer[u] = map0 if colour[u]==0 else map1

print "YES"
print answer[1] … answer[n] separated by spaces
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm prints `NO` iff no assignment exists, otherwise prints
`YES` and the lexicographically smallest valid assignment.

---

##### Lemma 1  
If the algorithm detects a conflict (`colour[y] == colour[x]` on an edge) then no
assignment satisfying all edges exists.

**Proof.**  
An edge requires its ends to have different values, i.e. different colours.
If during BFS two adjacent vertices receive the same colour, the graph contains an odd
cycle, which is not bipartite. A non‑bipartite graph cannot be 2‑coloured, therefore
no assignment with values `{1,2}` can satisfy all edges. ∎



##### Lemma 2  
If the algorithm finishes without conflict, the produced `answer` satisfies
`s_u + s_v = 3` for every edge.

**Proof.**  
The BFS colours every edge with opposite colours (`0` vs `1`).  
Inside each component we map one colour to `1` and the other to `2`.  
Hence for any edge its ends receive `1` and `2` in some order, their sum is `3`. ∎



##### Lemma 3  
For a fixed connected component, among all assignments that satisfy its edges,
the algorithm yields the lexicographically smallest values on the vertices of this
component (considering only positions belonging to the component).

**Proof.**  
The component has exactly two feasible assignments: colour `0 → 1, 1 → 2` or the
swapped one. Let `p` be the smallest index in the component.
If colour of `p` is `0`, the first assignment gives `s_p = 1`, the second gives
`s_p = 2`. Since `1 < 2`, the first is lexicographically smaller on the whole
sequence, and any later difference cannot change the order.  
If colour of `p` is `1` the algorithm chooses the swapped mapping, again giving
`s_p = 1`. Thus the algorithm always selects the assignment with `s_p = 1`,
which is the smallest possible for the earliest position of the component. ∎



##### Lemma 4  
The concatenation of the component‑wise choices produced by the algorithm is the
lexicographically smallest global assignment.

**Proof.**  
Components are processed in increasing order of their smallest vertex (because the
outer loop iterates `v = 1 .. n`).  
Consider the first index `i` where two valid global assignments differ.
`i` belongs to some component `C`. All earlier indices lie in components whose
assignments are identical in both solutions. By Lemma&nbsp;3 the algorithm gives the
smallest possible value at the smallest index of `C`, which is exactly `i`.  
Therefore any other valid assignment has `s_i ≥ algorithm[i]`, and if it is larger,
the algorithm’s sequence is lexicographically smaller. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no valid assignment exists;  
* otherwise `YES` and the lexicographically smallest valid assignment.

**Proof.**  

*If the algorithm prints `NO`*: by Lemma&nbsp;1 the graph is not bipartite, hence no
assignment exists.

*If a valid assignment exists*: the graph is bipartite, so the algorithm never
detects a conflict and finishes. By Lemma&nbsp;2 the produced `answer` satisfies all
edges, i.e. it is a valid assignment. By Lemma&nbsp;4 it is the lexicographically
smallest among all valid assignments. Hence the algorithm prints `YES` followed by
the required sequence. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all vertices*: each vertex and edge is processed once → `O(n + m)` time.  
*Additional work* (finding minima, filling answer) is linear in component size,
overall `O(n)`.  

Total time `O(n + m)` ≤ `4·10⁵`, well within 1 s.  
Memory: adjacency list (`2m` integers) + arrays `O(n)`, total `O(n + m)` ≤
~`5·10⁵` integers → < 256 MB.

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 bipartite colour
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = []
        while q:
            x = q.popleft()
            comp.append(x)
            for y in adj[x]:
                if colour[y] == -1:
                    colour[y] = colour[x] ^ 1
                    q.append(y)
                elif colour[y] == colour[x]:
                    sys.stdout.write("NO")
                    return
        # decide mapping to get smallest lexicographic
        p = min(comp)
        if colour[p] == 0:
            map0, map1 = 1, 2
        else:
            map0, map1 = 2, 1
        for v in comp:
            ans[v] = map0 if colour[v] == 0 else map1

    out = ["YES", " ".join(str(ans[i]) for i in range(1, n + 1))]
    sys.stdout.write("\n".join(out))

if __name__ == "__main__":
    solve()
```
