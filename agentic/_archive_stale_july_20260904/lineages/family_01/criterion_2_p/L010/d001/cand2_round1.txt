# Cargo Stabilization

Time limit: 1 s   Memory limit: 256 MB

A cargo ship is preparing to transport $n$ shipping containers. To optimize the center of gravity, each container must be filled with a cargo weighing exactly 1 ton or 2 tons.

The ship's hold features a delicate structural grid. The engineers have installed $m$ rigid struts, each linking a specific pair of containers. For the structural integrity of the grid to be maintained, the sum of the weights of the containers at the two ends of any given strut must be exactly 3 tons. If the sum is 2 tons, the strut will detach due to under-tension; if the sum is 4 tons, the strut will buckle under excessive load.

Your task is to determine whether it is possible to assign a weight (1 ton or 2 tons) to each of the $n$ containers such that all $m$ strut conditions are satisfied. 

If a valid configuration exists, you must provide it. Because there may be multiple valid loading plans, the automated crane system requires the lexicographically smallest sequence of weights. A sequence of weights $s_1, \dots, s_n$ is lexicographically smaller than another valid sequence $t_1, \dots, t_n$ if, at the first container index $i$ where they differ, $s_i < t_i$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of containers and the number of struts.
Each of the next $m$ lines contains two integers $u$ and $v$ — indicating that a strut connects container $u$ and container $v$.

## Output
If there is no way to assign the weights to all containers without violating the strut constraints, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each either 1 or 2), representing the lexicographically smallest valid weight assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

</PRESERVED_ANSWER>
