# Resonance Calibration

Time limit: 1 s   Memory limit: 256 MB

A municipal grid involves $n$ environmental monitors. Each monitor is required to be calibrated to one of two operational states, denoted as state 1 and state 2. Due to spatial constraints, specific pairs of monitors are positioned in close proximity. When a proximate pair is calibrated to identical states, their emissions resonate, leading to data corruption.

You will receive $m$ resonance warnings, each detailing a pair of monitors that will corrupt each other's data if they share the same operational state. Your objective is to ascertain if there is a uniform calibration strategy where no resonating pair is assigned the same state.

The municipal grid's registration memory is exactly $800,000$ bytes in size, and each monitor's record occupies exactly $4$ bytes. The grid always has at least one active monitor. Furthermore, the collision detection system has a maximum log capacity of $1,600,000$ bytes for resonance warnings, with each warning occupying exactly $8$ bytes (the log may be completely empty). These physical memory limits strictly define the minimum and maximum possible values for $n$ and $m$.

If such a calibration is achievable, output it. To standardize deployments, the maintenance protocol demands the lexicographically smallest array of state assignments. An array $s_1, \dots, s_n$ is lexicographically smaller than $t_1, \dots, t_n$ if $s_i < t_i$ at the earliest index $i$ where the two arrays diverge.

## Input
The first line contains two integers $n$ and $m$, representing the number of environmental monitors and the number of resonance warnings.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ — a pair of monitors that will resonate if calibrated to the same state.

## Output
If there is no way to calibrate all monitors to state 1 or state 2 without causing resonance, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1 \dots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid calibration array.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
