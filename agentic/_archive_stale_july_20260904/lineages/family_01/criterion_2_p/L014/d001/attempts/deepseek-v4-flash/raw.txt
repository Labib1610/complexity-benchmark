We can model this as a graph problem: each module is a node, and each collision warning is an edge.  
The condition \(|x_u - x_v| = 1\) means adjacent nodes must have different values (1 or 2).  
So the graph must be bipartite. If it’s not, output `NO`.  

To get the lexicographically smallest assignment, we run BFS/DFS from each unvisited node, assigning 1 to the starting node and alternating.  
We must also try starting with 1 first, and if that leads to a conflict, try starting with 2 — but since we want lexicographically smallest, we always try 1 first.  

Here’s the implementation:  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    # color 0 -> 1, color 1 -> 2
    print(' '.join(str(c + 1) for c in color))
```
