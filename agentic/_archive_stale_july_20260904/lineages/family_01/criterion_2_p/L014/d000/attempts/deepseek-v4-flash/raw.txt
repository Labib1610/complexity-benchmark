We can model this as a bipartite graph problem.  
Each module is a node, and each warning is an edge that must connect nodes of different colors (environments).  
We need to check if the graph is bipartite, and if so, produce the lexicographically smallest coloring.

**Approach:**
1. Build adjacency list from input.
2. Use BFS/DFS to color the graph with two colors (1 and 2).
3. If a conflict is found (adjacent nodes with same color), output `NO`.
4. If bipartite, we already have a valid coloring.  
   But we need the lexicographically smallest assignment.  
   Since colors are 1 and 2, we can start each connected component with color 1 for the smallest index node in that component.  
   This ensures lexicographically smallest overall.

```python
from collections import deque
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [-1] * n
    
    for i in range(n):
        if color[i] == -1:
            color[i] = 1
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 3 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
    
    print("YES")
    print(" ".join(str(c) for c in color))

if __name__ == "__main__":
    solve()
```
