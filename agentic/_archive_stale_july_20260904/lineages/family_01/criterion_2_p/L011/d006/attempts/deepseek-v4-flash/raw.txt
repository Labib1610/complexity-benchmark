We can model this as a graph problem.  
Each node has state 1 or 2, and each edge imposes a constraint between its endpoints.  

Let’s analyze the transformation:

- State 1: \( T_1(X, Y) = (X + 3Y, Y) \)  
  Sum after applying: \( (X + 3Y) + Y = X + 4Y \)

- State 2: \( T_2(X, Y) = (X, 3X + Y) \)  
  Sum after applying: \( X + (3X + Y) = 4X + Y \)

Starting from (1,1), sum = 2.

If we apply state 1 first:  
- After state 1: sum = 1 + 4*1 = 5  
- Then apply state 2: sum = 4*X + Y = 4*(1+3*1) + 1 = 4*4 + 1 = 17  

If we apply state 2 first:  
- After state 2: sum = 4*1 + 1 = 5  
- Then apply state 1: sum = X + 4Y = 1 + 4*4 = 17  

So the only way to get sum 17 is if one endpoint is state 1 and the other is state 2.  
Thus, each edge must connect nodes of different states.  

This is exactly a bipartite graph check.  
We need to assign 1 or 2 to each node such that adjacent nodes differ.  
If the graph is not bipartite, output `NO`.  
If it is bipartite, we want the lexicographically smallest assignment.

For lexicographically smallest, we can do BFS/DFS coloring, but when we start a new component, we try state 1 first if possible.  
If assigning 1 causes a conflict, we try 2.  

Implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 0
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

for i in range(n):
    if color[i] == -1:
        # try starting with 0
        color[i] = 0
        if not bfs(i):
            # try starting with 1
            color[i] = 1
            # reset component colors
            # We need to redo BFS for this component
            # So we reset all nodes in this component
            stack = [i]
            comp = []
            while stack:
                u = stack.pop()
                comp.append(u)
                for v in adj[u]:
                    if color[v] != -1 and v not in comp:
                        stack.append(v)
            # Actually simpler: just reset all visited in this component
            # We'll do a fresh BFS with color 1
            # But we must reset colors of this component
            # Let's do a DFS to find component
            comp_nodes = []
            stack = [i]
            visited = set()
            while stack:
                u = stack.pop()
                if u in visited:
                    continue
                visited.add(u)
                comp_nodes.append(u)
                for v in adj[u]:
                    if v not in visited:
                        stack.append(v)
            for u in comp_nodes:
                color[u] = -1
            color[i] = 1
            if not bfs(i):
                print("NO")
                return

print("YES")
print(' '.join(str(c + 1) for c in color))
```
