<STATEMENT>
# Server Synchronization States

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ server nodes. Each node $i$ must be assigned an operational state $x_i$, which is strictly restricted to be either 1 or 2.

The nodes are connected by a set of $m$ bidirectional sync channels. To prevent data corruption during synchronization, the network must satisfy a strict local balance requirement. For every node $i$, if you take the sum of the operational states of the nodes at the other end of each channel connected to $i$, this sum must be exactly equal to $d_i \times (3 - x_i)$, where $d_i$ is the total number of channels connected to node $i$. 

Your task is to determine a valid state assignment for all $n$ nodes. If there are multiple valid ways, you must output the assignment that produces the lexicographically smallest sequence of operational states $x_1, x_2, \dots, x_n$. If it is impossible to satisfy all balance requirements simultaneously, report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$. The number of nodes $n$ is at least 1 and bounded by a network maximum of $2\cdot 10^5$. The number of channels $m$ is at least 0 and at most $2\cdot 10^5$.
Each of the following $m$ lines contains two integers $u$ and $v$ (valid node IDs ranging from 1 to $n$), indicating that a channel exists between node $u$ and node $v$.

## Output
If there is no valid state assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid sequence of operational states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<METHOD_NAME>Global Summation Constraint</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the explicit pairwise conflict condition (pass-through vs inversion functions) with a local summation equation: sum of neighbors' states = d_i * (3 - x_i). Because states are bounded to {1, 2}, this algebraically forces all neighbors to take the opposite state. It defeats survivors by requiring an extreme-value deduction step rather than providing a boolean logic constraint that can be trivially pattern-matched to 2-coloring.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
The surviving models successfully identified the 2-coloring structure by pattern-matching the two transformation functions and their pairwise conflict. I removed all mention of functions and pairwise conflicts. Instead, the constraint is presented as a local sum equation involving the node's degree. To realize this is 2-coloring, the model must now algebraically deduce that the bounds of the variables ($x \in \{1, 2\}$) force the sum to its maximum or minimum, thereby uniquely forcing all neighbors to take the opposite state.
</RATIONALE>
<PRESERVED_ANSWER>
If x_i = 1, the sum equation requires d_i terms (each at most 2) to sum to 2*d_i, forcing all neighbors to be 2; if x_i = 2, it requires d_i terms (each at least 1) to sum to d_i, forcing all neighbors to be 1, which is mathematically identical to the seed's pairwise conflict condition.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains identically equivalent to finding the lexicographically smallest valid 2-coloring of a graph, which is verifiable and solvable via Breadth-First Search in O(n+m) time, keeping it in P.
</PRESERVED_CLASS>
