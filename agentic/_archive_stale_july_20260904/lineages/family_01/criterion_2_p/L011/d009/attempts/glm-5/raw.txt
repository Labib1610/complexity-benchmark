Looking at this problem, I need to find a configuration where the product of all link thermal footprints equals $5^m$.

Each link's thermal footprint is $2^{s_u} + 2^{s_v} - 1$. With $s \in \{1, 2\}$, the possible values are:
- Both state 1: $2 + 2 - 1 = 3$
- One state 1, one state 2: $2 + 4 - 1 = 5$
- Both state 2: $4 + 4 - 1 = 7$

For the product to equal $5^m$, every link must have thermal footprint exactly 5. This means every edge must connect a unit with state 1 to a unit with state 2 — the graph must be bipartite, and we need a valid 2-coloring.

For lexicographically smallest: assign state 1 to each uncolored node (starting from node 1), then assign the opposite state to neighbors via BFS.

```python
import sys
from collections import deque

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n + 1)
    
    for start in range(1, n + 1):
        if color[start] == 0:
            color[start] = 1
            q = deque([start])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = 3 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
    
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n + 1)))

solve()
```
