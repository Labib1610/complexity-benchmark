# Server Synchronization States

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ server nodes. Each node $i$ must be assigned an operational tier $x_i \in \{1, 2\}$.

The nodes are connected by a set of $m$ bidirectional sync channels. (There is at most one channel between any pair of nodes, and no channel connects a node to itself). 

To evaluate the stability of the network, we construct two $n \times n$ matrices:
1. The connectivity matrix $C$, where $C_{u,v} = 1$ if there is a sync channel between node $u$ and node $v$, and $C_{u,v} = 0$ otherwise.
2. The diagonal load matrix $D$, where $D_{i,i} = d_i$ (the total number of sync channels connected to node $i$), and all off-diagonal entries are $0$.

The network's state is represented by the column vector of assigned tiers, $X = [x_1, x_2, \dots, x_n]^T$. 

To prevent data bottlenecks while maintaining hardware limits, the network is considered perfectly balanced if and only if it satisfies the matrix equation:
$$ (C + D) X = 3 D \mathbf{1} $$
where $\mathbf{1}$ is an $n \times 1$ column vector of all ones.

Your task is to determine a valid tier assignment for all $n$ nodes such that the network is perfectly balanced. If there are multiple valid ways, you must output the assignment that produces the lexicographically smallest sequence of operational tiers $x_1, x_2, \dots, x_n$. If it is impossible to satisfy the requirement, report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a sync channel exists between node $u$ and node $v$.

## Output
If there is no valid tier assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid sequence of operational tiers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

Replaced the local edge-wise determinant and product condition with a global matrix equation $(C+D)X = 3D\mathbf{1}$. This removes the obvious unique prime factorization shortcut ($x_u x_v + 1 = 3$). Models must now analyze the row-wise linear constraints and apply an extremal bounding argument (since $x_i \in \{1, 2\}$, the sum $d_i x_i + \sum x_j = 3d_i$ strictly forces all neighbors to be $3 - x_i$) to deduce the underlying 2-coloring requirement.
</RATIONALE>
