# Signal Configuration

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of communication facilities. The network consists of $n$ stations.
Each station $i$ must be assigned a positive integer signal state $x_i$. To ensure hardware compatibility, the assigned state $x_i$ must be a divisor of 2.

The stations are connected by a set of $m$ communication links. Due to signal interference, every link imposes a strict non-linear power requirement on its endpoints: if a link connects station $u$ and station $v$, their signal states must satisfy the equation $x_u^{x_v} + x_v^{x_u} = 3$.

Your task is to determine a valid signal state assignment for all $n$ stations.
If there are multiple valid ways to configure the network, you must output the assignment that is lexicographically smallest when written as the sequence $x_1, x_2, \dots, x_n$. If it is impossible to satisfy all interference conditions simultaneously, you must report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$. The number of stations $n$ is at least 1 and is bounded by the regional addressing limit, which corresponds exactly to the number of grams in 200 kilograms. The number of links $m$ is at least 0 and at most the region's link capacity, which is exactly the number of seconds in 2 days, 7 hours, 33 minutes, and 20 seconds.
Each of the following $m$ lines contains two integers $u$ and $v$ (valid station IDs ranging from 1 to $n$), indicating that a link exists between station $u$ and station $v$.

## Output
If there is no valid configuration, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I replaced the explicit domain `{1, 2}` with "positive integer divisor of 2" and the sum condition `x_u + x_v = 3` with the non-linear equation `x_u^{x_v} + x_v^{x_u} = 3`. This forces the model to algebraically evaluate the configuration space to discover that adjacent nodes must have distinct states, rather than pattern-matching the original literal phrases to graph bipartiteness. I also encoded the numeric bounds as physical quantities (grams in 200kg, seconds in a time span) to fulfill strategy S07.
</RATIONALE>
<PRESERVED_ANSWER>
The domain of positive integer divisors of 2 is exactly {1, 2}, and the only solutions to x_u^{x_v} + x_v^{x_u} = 3 in this domain are the pairs where x_u != x_v, making the constraints mathematically identical to the seed problem.
</PRESERVED_ANSWER>

The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
