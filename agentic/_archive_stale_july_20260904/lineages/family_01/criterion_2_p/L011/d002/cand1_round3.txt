<STATEMENT>
# Facility Staffing

Time limit: 1 s   Memory limit: 256 MB

You are configuring the communication frequencies for a network of facilities. The network consists of $n$ stations.
Each station $i$ must be assigned a frequency multiplier $x_i$. The hardware requires this multiplier to be an integer, with a minimum allowed value of 1 and a maximum of 2.

The stations are connected by $m$ communication links. To prevent signal interference, every link imposes a strict requirement on its endpoints: if a link connects station $u$ and station $v$, the product of their frequency multipliers must be exactly 2.

Your task is to determine a valid frequency configuration for all $n$ stations.
If there are multiple valid configurations, you must output the one that is lexicographically smallest when written as the sequence $x_1, x_2, \dots, x_n$. If it is impossible to satisfy all link requirements simultaneously, you must report that no such configuration exists.

## Input
The first line contains two integers $n$ and $m$. 
The number of stations $n$ is a strictly positive integer. The total power budget for the region is 200 megawatts, and each station draws exactly 1 kilowatt; the maximum possible number of stations is exactly the number of stations this budget can support.
The number of links $m$ is a non-negative integer. The central switch allocates exactly 8 bytes of memory per link record, using a dedicated link buffer of 1,600,000 bytes; the maximum possible number of links is exactly the number of records this buffer can hold.
Each of the following $m$ lines contains two integers $u$ and $v$ (valid station IDs ranging from 1 to $n$), indicating that a link exists between station $u$ and station $v$.

## Output
If there is no valid configuration, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$ (each being 1 or 2), representing the lexicographically smallest valid configuration.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit constraint "sum must be exactly 3" was replaced with "product must be exactly 2". Since the variable domain is strictly {1, 2}, this local constraint is mathematically identical to the seed but defeats surface-level pattern matching for bipartite/2-coloring reductions that look for additive complements. Additionally, numeric upper bounds were restated indirectly through power budgets and memory allocations (Strategy S07), forcing the solver to derive the maximum sizes from the scenario text.
</RATIONALE>
<PRESERVED_ANSWER>
The domain of each variable remains exactly {1, 2}, and for these values, the condition $x_u \times x_v = 2$ is satisfied if and only if one value is 1 and the other is 2, which is identical to the seed's condition $x_u + x_v = 3$.
</PRESERVED_ANSWER>

The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using Breadth-First Search, keeping it in P.
</PRESERVED_CLASS>
