<STATEMENT>
# Facility Staffing

Time limit: 1 s   Memory limit: 256 MB

You are managing the staffing levels for a network of facilities. The network consists of $n$ stations.
By union regulations, each station $i$ must be assigned a staffing level $x_i$ of either 1 or 2.

The stations are connected by a set of $m$ communication links. Due to bandwidth interference and strict union rules, the network must satisfy a set of interrelated constraints. A valid staffing assignment must meet all of the following conditions simultaneously:

1. **Link Interference**: For any link connecting station $u$ and station $v$, the product of their assigned staffing levels must be exactly 2. 
2. **Local Load Balancing**: For every station $u$ with $d$ incident links, the sum of the staffing levels of the stations at the other ends of these $d$ links must be exactly $d \times (3 - x_u)$.
3. **Extended Stability**: To prevent cascading failures, any sequence of four stations connected by three consecutive links (i.e., any walk of length 3) must have a total combined staffing level of exactly 6.

Your task is to determine a valid staffing assignment for all $n$ stations.
If there are multiple valid ways to staff the network, you must output the assignment that is lexicographically smallest when written as the sequence $x_1, x_2, \dots, x_n$. If it is impossible to satisfy all conditions simultaneously, you must report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of stations and the number of communication links, respectively.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a communication link exists between station $u$ and station $v$.

## Output
If there is no valid staffing assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$ (each being 1 or 2), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the direct sum constraint into a product constraint and added two redundant but complex-sounding structural constraints (local load balancing and extended stability walks). This forces the model to mathematically deduce that the first constraint implies the other two and reduces exactly to bipartite 2-coloring. Models that blindly translate all constraints into a general SAT/ILP solver or explicitly verify walks of length 3 will exceed time or memory limits.
</RATIONALE>
<PRESERVED_ANSWER>
The domain {1,2} and the product constraint strictly require adjacent stations to have different values (1 and 2), which mathematically guarantees the two redundant constraints always hold, preserving the exact set of valid assignments and the lexicographical tie-breaker.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
Finding a valid assignment still reduces to 2-coloring the graph and picking the lexicographically smallest valid component assignments, which is solvable in O(n + m) time using BFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "sequence of four stations" as requiring simple paths (no repeated vertices), though the math holds either way, so it shouldn't affect the correctness of derived solvers.
</RISK>
