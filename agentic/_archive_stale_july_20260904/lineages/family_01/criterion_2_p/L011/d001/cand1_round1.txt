<STATEMENT>
# Diagnostic Network

Time limit: 1 s
Memory limit: 256 MB

You are managing the deployment of technical personnel across a diagnostic network. The network consists of $n$ testing stations. 

Each testing station $i$ must be assigned a personnel count $x_i$. The personnel count at any station must be a whole number of individuals. A station cannot be left unstaffed, but due to safety regulations, no station can operate with more than a pair of individuals. 

The network contains $m$ communication links. Each link connects two testing stations. For a link to operate without interference, the combined personnel count of the two connected stations must be exactly equal to the sum of the maximum allowed headcount for a single station and the minimum allowed headcount for a single station.

Your objective is to determine a valid personnel assignment $X = (x_1, x_2, \dots, x_n)$ for all stations that satisfies the requirements of all $m$ links simultaneously. Because multiple valid assignments might exist, you must output the lexicographically smallest sequence of headcounts. If no such assignment is possible under the safety regulations, you must report that it cannot be done.

## Input
The first line contains two integers $n$ and $m$, the number of testing stations and the number of communication links. The network will always have at least a single station, while the number of links may be zero. Neither quantity will ever exceed one-fifth of a million. 
Each of the following $m$ lines contains two integers $u$ and $v$ (between $1$ and $n$), representing a communication link between station $u$ and station $v$.

## Output
If there is no personnel assignment satisfying all link requirements, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid personnel assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
Changed explicit numeric bounds and equations into derived physical capacities (e.g., "cannot be left unstaffed" for minimum 1, "no more than a pair" for maximum 2, and their sum for the link requirement). Stated the maximum $n$ and $m$ as "one-fifth of a million" rather than explicitly $2\cdot 10^5$. This forces the model to semantically parse the constraints and derive the underlying binary domain and sum-3 relation before it can recognize the bipartiteness structure.
</RATIONALE>
<PRESERVED_ANSWER>
The valid domain remains strictly {1, 2} and the link constraint remains mathematically exactly $x_u + x_v = 3$, so the set of valid assignments and their lexicographical order is identical for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is still equivalent to finding the lexicographically first 2-coloring of a graph, which is solvable in linear $O(n+m)$ time using Breadth-First Search, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "a pair" as meaning something other than exactly 2, or misread "sum of the maximum allowed headcount ... and the minimum" as applying to something other than $2+1=3$, though the phrasing is highly explicit.
</RISK>
