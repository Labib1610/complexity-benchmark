We need to analyze the determinant condition.

For an edge \((u, v)\):

\[
M_{u,v} = \begin{pmatrix} x_u & 1 \\ -1 & x_v \end{pmatrix}
\]

The determinant is:

\[
\det(M_{u,v}) = x_u x_v - (1)(-1) = x_u x_v + 1
\]

Since \(x_u, x_v \in \{1, 2\}\), possible values:

- \(1 \cdot 1 + 1 = 2\)
- \(1 \cdot 2 + 1 = 3\)
- \(2 \cdot 1 + 1 = 3\)
- \(2 \cdot 2 + 1 = 5\)

The product over all edges must equal \(3^m\).  
That means every edge must have determinant exactly 3.  
So for every edge \((u, v)\):

\[
x_u x_v + 1 = 3 \quad \Rightarrow \quad x_u x_v = 2
\]

Thus, for every edge, one endpoint must be 1 and the other must be 2.

This is exactly a bipartite graph condition:  
We need to 2-color the graph such that adjacent nodes have different values (1 and 2).

If the graph is not bipartite, it's impossible → output `NO`.

If it is bipartite, we need the lexicographically smallest assignment.  
We can do BFS/DFS coloring, but to get lexicographically smallest, we should try to assign 1 to node 1 if possible, and propagate.

We can do BFS from each unvisited node, trying to assign the smallest possible value to the starting node (1 if possible), and check consistency.

Implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        # try starting with 1
        color[i] = 1
        q = deque([i])
        ok = True
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break
            if not ok:
                break
        if not ok:
            # try starting with 2
            color[i] = 2
            q = deque([i])
            ok = True
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 3 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        ok = False
                        break
                if not ok:
                    break
            if not ok:
                possible = False
                break
        # If starting with 1 works, keep it; else we already switched to 2

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(c) for c in color))
```
