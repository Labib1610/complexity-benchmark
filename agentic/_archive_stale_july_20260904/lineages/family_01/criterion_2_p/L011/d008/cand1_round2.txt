<METHOD_DESCRIPTION>Replaces the global product condition with a sum of non-negative local penalties (x_u^2 + x_v^2 - 5)^2. This forces the LLM to deduce that each term must be zero, meaning x_u^2 + x_v^2 = 5. # Server Synchronization States

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ server nodes. The facility operates at least one server node, but its physical space limits the total number of nodes to two hundred thousand. The cabling infrastructure supports a non-negative number of bidirectional sync channels, up to a strict maximum of two hundred thousand.

Each node $i$ must be assigned an operational tier $x_i \in \{1, 2\}$.

The nodes are connected by a set of $m$ bidirectional sync channels. For a channel connecting node $u$ and node $v$, its phase deviation is defined by the formula $(x_u^2 + x_v^2 - 5)^2$.

The network's total phase deviation is the sum of the phase deviations of all $m$ channels. If the network has no channels, the total sum is $0$. To prevent data bottlenecks while maintaining hardware limits, the network is considered perfectly balanced if and only if its total phase deviation is exactly $0$.

Your task is to determine a valid tier assignment for all $n$ nodes such that the network is perfectly balanced. If there are multiple valid ways, you must output the assignment that produces the lexicographically smallest sequence of operational tiers $x_1, x_2, \dots, x_n$. If it is impossible to satisfy the requirement, report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$, bounded as described in the scenario.
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a sync channel exists between node $u$ and node $v$.

## Output
If there is no valid tier assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid sequence of operational tiers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit product-equals-3^m condition was removed because models easily factored it into edge weights of 3. It is replaced with a sum of squared deviations $(x_u^2 + x_v^2 - 5)^2 = 0$. This forces the model to evaluate the algebraic expression and deduce that each term must be zero, which still maps identically to the requirement that endpoints must have different states, without triggering factorization heuristics. Bounds are stated in text rather than inequalities to satisfy S07.
</RATIONALE>
<PRESERVED_ANSWER>
The condition $(x_u^2 + x_v^2 - 5)^2 = 0$ requires $x_u^2 + x_v^2 = 5$, which for $x_i \in \{1, 2\}$ is only satisfied when one endpoint is 1 and the other is 2, exactly mirroring the original capacity sum requirement.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest valid 2-coloring of a graph, which is solvable in O(n+m) using BFS/DFS, keeping it in P.
</PRESERVED_CLASS>
