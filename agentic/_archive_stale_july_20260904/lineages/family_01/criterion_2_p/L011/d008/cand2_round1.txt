<STATEMENT>
# Crystal Lattice Stabilization

Time limit: 1 s
Memory limit: 256 MB

You are synthesizing a crystalline structure consisting of $n$ atoms. Each atom $i$ must be assigned an energy state $x_i \in \{1, 2\}$.

The atoms are bonded by a set of $m$ bidirectional electromagnetic links. For a link connecting atom $u$ and atom $v$, its *binding deficit* is defined as $5 - x_u - x_v$.

The crystal's *total lattice deficit* is defined as the product of the binding deficits of all $m$ links. (If the crystal has no links, the total lattice deficit is considered to be 1).

To maintain structural stability, the crystal requires a specific baseline energy. For each atom $i$, its local energy contribution is $x_i^{d_i}$, where $d_i$ is the number of link endpoints attached to atom $i$ (each of the $m$ links supplies exactly two endpoints in total). The crystal's *baseline energy* is the product of the local energy contributions of all $n$ atoms.

The crystalline structure is considered *perfectly stabilized* if and only if its total lattice deficit is exactly equal to its baseline energy.

Your task is to determine a valid energy state assignment for all $n$ atoms such that the crystal is perfectly stabilized. If there are multiple valid ways, you must output the assignment that produces the lexicographically smallest sequence of energy states $x_1, x_2, \dots, x_n$. If it is impossible to satisfy the requirement, report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that an electromagnetic link exists between atom $u$ and atom $v$.

## Output
If there is no valid energy state assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid sequence of energy states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I changed the constant global target ($3^m$) and local edge capacity ($x_u + x_v$) into an equation between two variable global products: $\prod (5 - x_u - x_v) = \prod x_i^{d_i}$. This completely removes the affordance of pattern-matching a constant target to a local edge constraint. To solve it, the model must now algebraically rewrite the node-degree product into an edge product, equate the two, and solve the Diophantine equation $3^a \cdot 2^c = 4^b \cdot 2^c$ to deduce that $a=0$ and $b=0$, strictly forcing bipartite coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The requirement $\prod_{(u,v)} (5 - x_u - x_v) = \prod_{i} x_i^{d_i}$ simplifies to $3^a \cdot 2^c = 4^b \cdot 2^c$ (where $a, b, c$ are the number of 1-1, 2-2, and 1-2 edges). By unique prime factorization, this holds if and only if $a=0$ and $b=0$, which is exactly the constraint $x_u \neq x_v$ from the seed problem, preserving all valid assignments exactly.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a bipartite graph (or determining if it's not bipartite), which is solvable in $O(n + m)$ using BFS/DFS, keeping it in P.
</PRESERVED_CLASS>
