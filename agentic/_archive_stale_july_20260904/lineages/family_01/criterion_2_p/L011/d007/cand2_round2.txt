# Server Synchronization States

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ server nodes. Each node $i$ must be assigned an operational state $x_i$. The hardware restricts each node's state such that $x_i \in \{1, 2\}$.

The nodes are connected by a set of $m$ bidirectional sync channels. To ensure fault tolerance during synchronization, every channel imposes a redundancy requirement on its endpoints. Specifically, for each channel connecting node $u$ and node $v$, both of the following conditions must be satisfied:
- At least one of the two endpoints must be assigned state 1.
- At least one of the two endpoints must be assigned state 2.

Your task is to determine a valid state assignment for all $n$ nodes such that every channel satisfies this redundancy requirement. If there are multiple valid ways, you must output the assignment that produces the lexicographically smallest sequence of operational states $x_1, x_2, \dots, x_n$. If it is impossible to satisfy all channel requirements simultaneously, report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$. The number of nodes $n$ is at least 1 and bounded by a network maximum of $2\cdot 10^5$. The number of channels $m$ is at least 0 and at most $2\cdot 10^5$.
Each of the following $m$ lines contains two integers $u$ and $v$ (valid node IDs ranging from 1 to $n$), indicating that a channel exists between node $u$ and node $v$.

## Output
If there is no valid state assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid sequence of operational states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Based on the expert critique, I removed the contrived polynomial/algebraic framing entirely and replaced it with a natural, local constraint. By describing the requirement as two boolean-like clauses ("at least one is 1" and "at least one is 2"), the problem reads like a standard system reliability task. This forces models to recognize that the two conditions strictly simplify to requiring opposite states. Models that blindly pattern-match to 2-SAT will likely struggle to implement the lexicographical tie-breaker correctly, as finding the lexicographically smallest assignment for general 2-SAT is NP-hard, whereas it is trivial if the model correctly deduces the bipartite graph structure.
</RATIONALE>
<PRESERVED_ANSWER>
Since the node states are restricted to {1, 2}, satisfying both "at least one is 1" and "at least one is 2" is mathematically identical to requiring that one endpoint is 1 and the other is 2, ensuring the set of valid assignments and the lexicographical tie-break remain exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
