# Server Protocol Synchronization

Time limit: 1 s   Memory limit: 256 MB

You are configuring a network of $n$ server nodes. Each node $i$ must be assigned an operational state $x_i \in \{1, 2\}$.

The nodes are connected by a set of $m$ bidirectional sync channels. To prevent data collisions, every channel imposes a routing balance requirement on its endpoints. For a channel connecting node $A$ and node $B$, let $u = \min(A, B)$ and $v = \max(A, B)$. The synchronization protocol for this channel represents signals as polynomials in a variable $z$.

The channel initializes a signal polynomial:
$S_{init}(z) = (u + v) + (v - u)z$

This signal is then transformed sequentially by the operational states of the channel's two endpoints.
- When processed by an endpoint in state 1, the signal is multiplied by $P_1(z) = u - vz$, and the result is reduced modulo $z^2 + 1$ (i.e., by applying the relation $z^2 = -1$ so the polynomial remains of the linear form $C + Dz$).
- When processed by an endpoint in state 2, the signal is multiplied by $P_2(z) = u + vz$, and the result is similarly reduced modulo $z^2 + 1$.

The signal polynomial is first transformed by the state of one endpoint and then by the state of the other. (Because polynomial multiplication is commutative, the final polynomial is independent of which endpoint's transformation is applied first.)

The channel is considered balanced if and only if the final signal polynomial is exactly:
$S_{final}(z) = (u^2 + v^2)(u + v) + (u^2 + v^2)(v - u)z$

Your task is to determine a valid state assignment for all $n$ nodes such that every channel is balanced. If there are multiple valid ways, you must output the assignment that produces the lexicographically smallest sequence of operational states $x_1, x_2, \dots, x_n$. If it is impossible to satisfy all channel requirements simultaneously, report that no such assignment exists.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the following $m$ lines contains two integers $A$ and $B$ (valid node IDs ranging from 1 to $n$), indicating that a channel exists between node $A$ and node $B$.

## Output
If there is no valid state assignment, print a single line containing `NO`.
Otherwise, print `YES` on the first line, followed by a second line containing $n$ integers $x_1, x_2, \dots, x_n$, representing the lexicographically smallest valid sequence of operational states.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
