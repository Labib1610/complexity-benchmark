 We need to assign each node a value \( s_i \in \{1, 2\} \) such that for every node \( i \):

\[
d_i \cdot s_i + \sum_{j \in N(i)} s_j = 3 \cdot d_i
\]

Where \( N(i) \) is the multiset of neighbors (counting multiple edges).

Let’s rewrite:

\[
d_i \cdot s_i + \sum_{j \in N(i)} s_j = 3 d_i
\]

If we let \( x_i = s_i - 1 \), then \( x_i \in \{0, 1\} \).  
Then \( s_i = x_i + 1 \).

Substitute:

\[
d_i (x_i + 1) + \sum_{j \in N(i)} (x_j + 1) = 3 d_i
\]

The sum over neighbors of 1 is just \( d_i \) (since each edge contributes one neighbor count). So:

\[
d_i x_i + d_i + d_i + \sum_{j \in N(i)} x_j = 3 d_i
\]

\[
d_i x_i + 2 d_i + \sum_{j \in N(i)} x_j = 3 d_i
\]

\[
d_i x_i + \sum_{j \in N(i)} x_j = d_i
\]

So the condition becomes:

\[
d_i x_i + \sum_{j \in N(i)} x_j = d_i
\]

This is a system of linear equations over integers, but \( x_i \in \{0,1\} \).  
We can solve it as a 2-SAT or check feasibility.

We can also think:  
If \( x_i = 0 \), then \(\sum_{j \in N(i)} x_j = d_i\), meaning all neighbors must be 1.  
If \( x_i = 1 \), then \( d_i + \sum_{j \in N(i)} x_j = d_i \), so \(\sum_{j \in N(i)} x_j = 0\), meaning all neighbors must be 0.

So the rule is:  
- If a node is 0, all its neighbors must be 1.  
- If a node is 1, all its neighbors must be 0.

This is exactly a bipartite graph condition:  
The graph must be bipartite, and the two color classes correspond to \( x=0 \) and \( x=1 \).  
If the graph is not bipartite, impossible.

We also need lexicographically smallest \( s_i \), i.e., smallest \( x_i \) first (since \( s_i = x_i+1 \), smaller \( s \) means smaller \( x \)).  
So we want to assign 0 to as many early nodes as possible.

We can do BFS/DFS coloring, but with a twist:  
We want lexicographically smallest assignment, so we try to assign 0 to node 1 if possible, then node 2, etc.  
This can be done by trying both colorings for each connected component and picking the one that gives smaller sequence.

Implementation plan:
1. Build adjacency list with multiplicity (but for bipartite check, multiplicity doesn’t matter).
2. For each connected component, try two possible colorings (starting with 0 or 1).
3. Check consistency (bipartite).
4. Pick the coloring that gives lexicographically smaller \( s \) sequence.
5. If any component is not bipartite → print NO.

Let's code it.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
visited = [False] * n

def bfs(start, start_color):
    # returns coloring list for this component or None if conflict
    q = deque()
    q.append(start)
    color[start] = start_color
    comp_nodes = [start]
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
                comp_nodes.append(v)
            elif color[v] == color[u]:
                return None
    return comp_nodes

# We'll collect components
components = []
temp_color = [-1] * n
for i in range(n):
    if temp_color[i] == -1:
        # try both colorings
        comp_nodes = []
        # first try with 0
        color = [-1] * n
        res = bfs(i, 0)
        if res is None:
            print("NO")
            sys.exit()
        comp_nodes = res
        # store both possible colorings for this component
        coloring0 = [color[node] for node in comp_nodes]
        # reset and try with 1
        color = [-1] * n
        res = bfs(i, 1)
        if res is None:
            print("NO")
            sys.exit()
        coloring1 = [color[node] for node in comp_nodes]
        components.append((comp_nodes, coloring0, coloring1))
        # mark visited
        for node in comp_nodes:
            temp_color[node] = 0

# Now choose lexicographically smallest overall
final_x = [0] * n
for comp_nodes, col0, col1 in components:
    # Build two possible s sequences for this component
    s0 = [col0[idx] + 1 for idx in range(len(comp_nodes))]
    s1 = [col1[idx] + 1 for idx in range(len(comp_nodes))]
    # Compare lexicographically by node index order
    # We need to compare based on actual node indices
    # So create mapping from node -> value for both options
    map0 = {comp_nodes[i]: s0[i] for i in range(len(comp_nodes))}
    map1 = {comp_nodes[i]: s1[i] for i in range(len(comp_nodes))}
    # Compare by sorted node indices
    sorted_nodes = sorted(comp_nodes)
    for node in sorted_nodes:
        if map0[node] < map1[node]:
            for nd in comp_nodes:
                final_x[nd] = map0[nd] - 1
            break
        elif map0[node] > map1[node]:
            for nd in comp_nodes:
                final_x[nd] = map1[nd] - 1
            break
    else:
        # equal, pick either (0)
        for nd in comp_nodes:
            final_x[nd] = map0[nd] - 1

# Output
print("YES")
print(' '.join(str(x + 1) for x in final_x))
```
