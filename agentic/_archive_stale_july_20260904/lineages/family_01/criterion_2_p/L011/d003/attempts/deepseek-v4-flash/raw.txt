We can solve this by analyzing the equation:

\[
3x_u + 3x_v - 2x_u x_v = 5
\]

Rewriting:

\[
2x_u x_v - 3x_u - 3x_v = -5
\]

Multiply by 2:

\[
4x_u x_v - 6x_u - 6x_v = -10
\]

Add 9 to both sides:

\[
(2x_u - 3)(2x_v - 3) = -1
\]

So:

\[
(2x_u - 3)(2x_v - 3) = -1
\]

Since \(x_u, x_v\) are positive integers, \(2x_u - 3\) and \(2x_v - 3\) are odd integers.  
The only integer factor pairs of \(-1\) are \((1, -1)\) and \((-1, 1)\).

Case 1:  
\(2x_u - 3 = 1 \Rightarrow x_u = 2\)  
\(2x_v - 3 = -1 \Rightarrow x_v = 1\)

Case 2:  
\(2x_u - 3 = -1 \Rightarrow x_u = 1\)  
\(2x_v - 3 = 1 \Rightarrow x_v = 2\)

So each edge must connect a node with state 1 to a node with state 2.  
Thus the graph must be bipartite, with one partition having state 1 and the other state 2.

We need the lexicographically smallest assignment.  
We can do a BFS/DFS coloring, assigning 1 to the smallest possible node in each component, and check for conflicts.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n  # -1 uncolored, 0 -> state 1, 1 -> state 2

for start in range(n):
    if color[start] != -1:
        continue
    # BFS to color component, try to assign 0 (state 1) to start
    color[start] = 0
    q = deque([start])
    ok = True
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                ok = False
                break
        if not ok:
            break
    if not ok:
        print("NO")
        sys.exit()

# Now we have a valid bipartite coloring, but we need lexicographically smallest.
# For each component, we can flip colors if it makes the smallest index in that component have state 1.
visited = [False] * n
for i in range(n):
    if visited[i]:
        continue
    # collect component
    comp = []
    q = deque([i])
    visited[i] = True
    while q:
        u = q.popleft()
        comp.append(u)
        for v in adj[u]:
            if not visited[v]:
                visited[v] = True
                q.append(v)
    # If the smallest node in comp has color 1, flip all colors in comp
    min_node = min(comp)
    if color[min_node] == 1:
        for u in comp:
            color[u] = 1 - color[u]

# Output
res = [1 if c == 0 else 2 for c in color]
print("YES")
print(" ".join(map(str, res)))
```
