<STATEMENT>
# Sensor Polarity Configuration

Time limit: 1 s
Memory limit: 256 MB

You are tasked with calibrating a network of sensors. Each sensor must be assigned an operational mode, which is an integer value $s_i$ chosen from the set $\{1, 2\}$.

The network contains critical links between specific pairs of sensors. To prevent interference, any two sensors $u$ and $v$ connected by a critical link must have their modes configured such that a specific interference metric evaluates to zero. Specifically, the determinant of the $2 \times 2$ matrix $\begin{pmatrix} s_u & 1 \\ 2 & s_v \end{pmatrix}$ must be exactly zero.

You need to determine if it is possible to assign a valid mode to every sensor in the network without violating the interference constraint on any critical link. If there are multiple valid ways to configure the network, you must output the configuration where the sequence of modes $(s_1, s_2, \dots, s_n)$ is lexicographically smallest. (A sequence $A$ is lexicographically smaller than $B$ if $A$ has a smaller value at the first index where the two sequences differ.)

## Input
The first line provides two integers $n$ and $m$, which denote the total number of sensors and the number of critical links, respectively. The facility's central processor is physically capped at two hundred thousand sensor slots, so the number of sensors is at least one and at most this capacity. The number of critical links can range from zero up to the same maximum limit.

The following $m$ lines each contain two integers $u$ and $v$, representing the 1-based indices of the sensors connected by a critical link.

## Output
If there is no way to assign modes that satisfies all link constraints, output a single line with the word `NO`.
If a valid configuration exists, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \ldots, s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest valid assignment of operational modes.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the bitwise AND condition with a $2 \times 2$ matrix determinant condition that mathematically simplifies to $s_u s_v = 2$, enforcing that the modes must be distinct values from $\{1, 2\}$. I also removed the bare inequality bounds, replacing them with a narrative physical capacity limit of two hundred thousand. This forces the model to algebraically deduce the anti-correlation constraint rather than pattern-matching the known bitwise operation trick for 2-coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant condition $s_u s_v - 2 = 0$ is only satisfied when one mode is 1 and the other is 2, which is mathematically identical to the original $s_u \ \& \ s_v = 0$ constraint, keeping all valid configurations and outputs unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains exactly 2-coloring (bipartiteness testing) on a graph, which is solvable in linear time $O(n+m)$ using Breadth-First Search or Depth-First Search.
</PRESERVED_CLASS>
