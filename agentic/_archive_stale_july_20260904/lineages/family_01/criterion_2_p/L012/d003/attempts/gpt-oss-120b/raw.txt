**Solution Explanation**

For every corridor `(u , v)` the amplitudes must satisfy  

```
{ s_u , s_v } = { 1 , 2 }
```

i.e. the two endpoints have *different* values.
Therefore the whole graph has to be **bipartite** – we can colour every vertex
with colour `0` or `1` such that adjacent vertices have opposite colours.
If the graph is not bipartite the answer is `NO`.

If it is bipartite there are exactly two possible assignments for each
connected component:  
colour `0` → amplitude `1`, colour `1` → amplitude `2`, or the opposite.
To obtain the lexicographically smallest whole sequence we treat the
components independently:

* In a component let `p` be the smallest vertex index belonging to it.
* We always choose the assignment that gives `s_p = 1`.  
  (If the colour of `p` is `0` we keep the mapping `0→1,1→2`,
   otherwise we swap it.)

Because the choice for one component never influences any other component,
this greedy rule yields the globally lexicographically smallest sequence.

--------------------------------------------------------------------

#### Algorithm
```
read n, m
build adjacency list G
colour[1..n] = -1          # -1 = unvisited, 0/1 = bipartite colour
answer[1..n] = 0

for v = 1 .. n:
    if colour[v] == -1:
        # start a new component
        queue = [v]
        colour[v] = 0
        component = [v]
        bfs while queue not empty:
            x = pop queue
            for each y in G[x]:
                if colour[y] == -1:
                    colour[y] = colour[x] ^ 1
                    queue.append(y)
                    component.append(y)
                elif colour[y] == colour[x]:
                    print "NO" and exit   # not bipartite

        # component is bipartite, decide which side gets amplitude 1
        p = min(component)                # smallest index in this component
        if colour[p] == 0:   # colour 0 → amplitude 1
            for u in component:
                answer[u] = 1 if colour[u] == 0 else 2
        else:                # colour 1 → amplitude 1, swap
            for u in component:
                answer[u] = 1 if colour[u] == 1 else 2

print "YES"
print answer[1] … answer[n]
```

--------------------------------------------------------------------

#### Correctness Proof  

We prove that the algorithm outputs `NO` iff no valid assignment exists,
and otherwise outputs the lexicographically smallest valid assignment.

---

##### Lemma 1  
If the algorithm prints `NO`, the graph is not bipartite, therefore no
assignment satisfies all corridors.

**Proof.** `NO` is printed only when during BFS an edge `(x,y)` with
`colour[x] == colour[y]` is found. This is exactly the definition of a
non‑bipartite graph. Any assignment must give different amplitudes to
adjacent vertices, i.e. a proper 2‑colouring, which is impossible. ∎



##### Lemma 2  
If the algorithm finishes without printing `NO`, the produced `answer`
satisfies all corridors.

**Proof.** For every component the BFS assigned a proper 2‑colouring
(`colour` values differ on each edge). Afterwards we map the two colours
to amplitudes `1` and `2` (possibly swapping). Hence adjacent vertices receive
different amplitudes, i.e. `{1,2}`. ∎



##### Lemma 3  
For a fixed component, among the two possible amplitude assignments the
algorithm chooses the one that makes the smallest index vertex of the
component equal to `1`.

**Proof.** Let `p` be that smallest index. The algorithm checks the colour
of `p`. If it is `0` we keep mapping `0→1`; otherwise we swap, making colour
`1` map to `1`. Thus `s_p = 1` in both cases, and the other vertices receive
the only remaining consistent values. ∎



##### Lemma 4  
Let `A` be the assignment output by the algorithm and `B` any other valid
assignment. Then `A` is lexicographically not larger than `B`.

**Proof.** Consider the first position `i` where `A` and `B` differ.
Vertex `i` belongs to some component `C`. By construction all vertices
with index `< i` are in components whose smallest index is `< i`,
hence their assignments are already fixed and equal in `A` and `B`.

In component `C` the smallest index is exactly `i` (otherwise a smaller
index would already differ). By Lemma&nbsp;3 `A` gives `s_i = 1`. Any valid
assignment must give either `1` or `2` to `i`; if it gave `1` the two
assignments would coincide at `i`. Since they differ, `B` must have
`s_i = 2`. Therefore `A_i = 1 < 2 = B_i`, so `A` is lexicographically
smaller. ∎



##### Lemma 5  
If a valid assignment exists, the algorithm never prints `NO`.

**Proof.** Existence of a valid assignment implies the graph is bipartite,
because the assignment itself is a proper 2‑colouring. During BFS the
algorithm would never encounter an edge with equal colours, thus never
trigger the `NO` case. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no valid amplitude assignment exists;  
* otherwise `YES` and the lexicographically smallest valid assignment.

**Proof.**  
- If the algorithm prints `NO`, by Lemma&nbsp;1 no assignment exists.  
- If it prints `YES`, by Lemma&nbsp;5 a valid assignment exists, and by
  Lemma&nbsp;2 the produced `answer` is valid. Lemma&nbsp;4 shows it is the
  lexicographically smallest among all valid assignments. ∎



--------------------------------------------------------------------

#### Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once → `O(n + m)`.  
*Overall*: `O(n + m)` time, `O(n + m)` memory, well within the limits
(`n, m ≤ 2·10^5`).

#### Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        g[u].append(v)
        g[v].append(u)

    colour = [-1] * (n + 1)          # -1 unvisited, 0/1 bipartite colour
    ans = [0] * (n + 1)

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # BFS this component
        q = deque([start])
        colour[start] = 0
        comp = [start]
        while q:
            x = q.popleft()
            cx = colour[x]
            for y in g[x]:
                if colour[y] == -1:
                    colour[y] = cx ^ 1
                    q.append(y)
                    comp.append(y)
                elif colour[y] == cx:
                    print("NO")
                    return
        # decide mapping so that smallest index gets amplitude 1
        p = min(comp)
        if colour[p] == 0:
            for v in comp:
                ans[v] = 1 if colour[v] == 0 else 2
        else:
            for v in comp:
                ans[v] = 1 if colour[v] == 1 else 2

    # all components processed
    print("YES")
    print(' '.join(str(ans[i]) for i in range(1, n + 1)))

if __name__ == "__main__":
    solve()
```
