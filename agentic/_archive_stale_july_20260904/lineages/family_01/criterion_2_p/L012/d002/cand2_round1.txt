# Sensor Polarity Configuration

Time limit: 1 s
Memory limit: 256 MB

You are configuring a network of $n$ sensors. Each sensor must be assigned an operating state, represented by an integer $s_i \in \{1, 2\}$.

There are $m$ critical pairs of sensors. For each critical pair $(u, v)$, the system requires that the sum of their assigned states, $s_u + s_v$, has exactly 2 set bits in its binary representation to maintain equilibrium.

Your task is to determine whether there exists a valid state assignment for all $n$ sensors that satisfies this condition for every critical pair. If multiple valid assignments exist, you must find the one that minimizes the network's structural footprint. The structural footprint of an assignment sequence $(s_1, s_2, \dots, s_n)$ is defined as the sum $\sum_{i=1}^n s_i \cdot 2^{n-i}$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$), representing the number of sensors and the number of critical pairs.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that sensors $u$ and $v$ form a critical pair.

## Output
If no valid state assignment can satisfy all conditions, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \ldots, s_n$ (each $s_i \in \{1, 2\}$), representing the valid state assignment that minimizes the structural footprint.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit product condition $s_u \times s_v = 2$ with the requirement that the binary representation of $s_u + s_v$ contains exactly 2 set bits, which is mathematically equivalent for $s_i \in \{1, 2\}$ but avoids triggering immediate pattern matching to opposite colors. I also replaced the "lexicographically smallest" tie-break rule with minimizing the structural footprint $\sum s_i \cdot 2^{n-i}$. This forces models to genuinely reason that the exponential weights make the footprint minimization equivalent to finding the lexicographically smallest sequence, severely punishing naive BigInt implementations with a Time Limit Exceeded while rewarding structural understanding.
</RATIONALE>
<PRESERVED_ANSWER>
The condition on the sum's set bits is only satisfied when $s_u + s_v = 3$ (since $1+1=2$ has 1 bit, $2+2=4$ has 1 bit), perfectly preserving the opposite-state requirement; furthermore, the strict domination of powers of 2 guarantees that the minimum footprint assignment is exactly the lexicographically smallest sequence.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time O(n+m) using Breadth-First Search.
</PRESERVED_CLASS>
