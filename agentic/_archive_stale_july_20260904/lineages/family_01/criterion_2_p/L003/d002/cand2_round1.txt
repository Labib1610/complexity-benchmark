<STATEMENT>
# Problem B — Machine Modes

Time limit: 1 s   Memory limit: 256 MB

A manufacturing process relies on $n$ machines. You must assign each machine a calibration factor of either 1 or 2. 

The system has $m$ critical links between specific pairs of machines. To maintain stability, the calibration factors of the two machines in any critical link must be compatible. Specifically, if the two machines in a link have factors $x$ and $y$, the expression $x \ll y$ (where $\ll$ represents the bitwise left-shift operator) must evaluate to exactly 4. (You may verify that for the allowed factor values, this condition is symmetric and does not depend on which machine is $x$ and which is $y$).

Determine a valid calibration factor for each machine so that all critical links are stable, or report if this is impossible.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$, representing a critical link between machine $u$ and machine $v$.

## Output
If no stable assignment exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $s_1 \dots s_n$ (each either 1 or 2). This sequence must be the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit "multiply to exactly 2" condition with the mathematically equivalent but structurally obscure condition that `x << y == 4`. This forces models to manually evaluate the bitwise operation for the domain {1, 2}, realize it mandates $x \neq y$, and then deduce the bipartite graph structure rather than relying on keyword association with products of 1 and 2.
</RATIONALE>
<PRESERVED_ANSWER>
The allowed values are {1, 2}, and the only pairs that satisfy $x \ll y = 4$ are (1, 2) and (2, 1), which is identical to the original requirement that they multiply to 2.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring / bipartiteness checking, which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
