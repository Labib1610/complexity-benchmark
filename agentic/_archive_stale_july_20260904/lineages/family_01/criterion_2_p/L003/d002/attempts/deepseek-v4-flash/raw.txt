We can model this as a graph problem. Each machine is a node, and each exchange line is an edge.  
The condition for an edge \((u, v)\) to be balanced is:

\[
\frac{s_u}{s_v} \in \{0.5, 2.0\}
\]

Since \(s_u, s_v \in \{1, 2\}\), this means:

- If \(s_u = 1\), then \(s_v\) must be 2.
- If \(s_u = 2\), then \(s_v\) must be 1.

So every edge must connect nodes with **different** states.  
That means the graph must be **bipartite**. If it’s not, output `NO`.

We also need the lexicographically smallest assignment.  
We can do BFS/DFS, assigning state 1 to the first node if possible, and propagate alternating states.  
If a conflict occurs, output `NO`.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

# Convert 0 -> 1, 1 -> 2
res = [c + 1 for c in color]
print("YES")
print(" ".join(map(str, res)))
```
