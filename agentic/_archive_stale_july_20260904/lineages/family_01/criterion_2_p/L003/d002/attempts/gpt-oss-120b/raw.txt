**Solution Explanation**

For every edge `{u,v}` the ratio `state[u] / state[v]` has to be `0.5` or `2`.
With the only possible states `1` and `2` this is true **iff** the two
endpoints have different states.

So the problem is exactly:

* colour the vertices of the given undirected graph with two colours
  (`1` and `2`) such that adjacent vertices have different colours
  (i.e. test bipartiteness) and output the lexicographically smallest
  valid colour sequence.*

--------------------------------------------------------------------

#### 1.   Bipartite checking and component handling  

We run a BFS/DFS over every not yet visited vertex.

During the search we store  

* `col[v]` – `0` = not coloured yet, `1` = colour **1**, `2` = colour **2**  
* `comp` – list of vertices belonging to the current connected component.

When we traverse an edge `v – to`

* if `col[to] == 0` we colour it with the opposite colour of `v`
* else if `col[to] == col[v]` the graph is **not bipartite** → answer `NO`.

The whole component is processed in `O(size)` time, total `O(n+m)`.

--------------------------------------------------------------------

#### 2.   Lexicographically smallest colouring  

For a bipartite component there are exactly two valid colourings:
the one we obtained and the one where all colours are flipped
(`1 ↔ 2`).  
All vertices outside the component are independent, therefore we can
choose the better of the two locally.

The lexicographically smallest global sequence is obtained by the
following rule:

*look at the smallest index vertex inside the component; give it colour 1
if possible.*

Proof:  
Consider two colourings that differ only inside this component.
All vertices with index smaller than the smallest index of the component
are identical in both colourings, therefore the first position where the
two global sequences may differ is exactly that smallest index.
Choosing colour 1 there makes the whole sequence smaller, because `1 < 2`.
Thus the rule yields the optimal orientation for the component, and
components are independent, so applying it to every component gives the
global optimum. ∎



Implementation: after finishing the BFS of a component we find the
minimum index `mn = min(comp)`.  
If `col[mn] == 2` we flip every vertex `v` in `comp` (`col[v] = 3 - col[v]`).

Isolated vertices (components of size 1) are handled the same way;
they keep colour 1, which is optimal.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n, m
build adjacency list
col[1..n] = 0
for v = 1 .. n:
    if col[v] == 0:
        start BFS from v, set col[v] = 1
        comp = []
        while queue not empty:
            pop x
            comp.append(x)
            for each neighbour y of x:
                if col[y] == 0:
                    col[y] = 3 - col[x]          # opposite colour
                    push y
                elif col[y] == col[x]:
                    print "NO" and exit
        # component finished, choose orientation
        mn = min(comp)
        if col[mn] == 2:
            for u in comp:
                col[u] = 3 - col[u]            # flip
print "YES"
print colours col[1] … col[n] separated by spaces
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints `YES` and the lexicographically smallest valid
assignment.

---

##### Lemma 1  
During BFS, if the algorithm never encounters an edge whose endpoints
already have the same colour, the produced `col` is a proper 2‑colouring
of the visited component.

*Proof.*  
The BFS starts with a vertex coloured `1`. Every time we traverse an
edge `x‑y` with `col[y]==0` we assign `col[y]=3-col[x]`, i.e. the opposite
colour. Hence after processing the edge the two endpoints differ.
If later the same edge is examined again, both ends are already coloured
and we check they are different; otherwise we would abort. ∎



##### Lemma 2  
If the algorithm prints `NO`, the input graph is not bipartite, i.e.
no assignment satisfies the condition.

*Proof.*  
`NO` is printed only when an edge `x‑y` with `col[x]==col[y]` is found.
Both vertices belong to the same connected component, and all previously
coloured vertices respect the opposite‑colour rule (Lemma&nbsp;1).  
Thus the component contains an odd cycle, which makes the graph
non‑bipartite. Any assignment would need equal colours on the two
endpoints of that edge, contradicting the requirement that adjacent
vertices differ. ∎



##### Lemma 3  
If the algorithm finishes without printing `NO`, the array `col`
is a valid assignment for the whole graph.

*Proof.*  
Every component is processed separately. By Lemma&nbsp;1 each component
is properly 2‑coloured, therefore every edge connects vertices of different
states (`1` and `2`). All vertices receive a colour, so the whole graph
satisfies the condition. ∎



##### Lemma 4  
For a processed component, after the possible flip described in the
algorithm, the resulting colours are the lexicographically smallest
among the two colourings of that component.

*Proof.*  
Let `p` be the smallest index vertex of the component.
If after BFS `col[p]=1` we keep the colouring – clearly optimal.
If `col[p]=2` we flip all colours, making `col[p]=1`.  
Any valid colouring of the component must give `p` either `1` or `2`.
If it gives `2`, the sequence is larger at position `p`.  
If it gives `1`, it coincides with our flipped colouring (the only
colouring with `p` coloured `1`). Hence our choice is optimal. ∎



##### Lemma 5  
The final colour sequence printed by the algorithm is the lexicographically
smallest among **all** valid assignments.

*Proof.*  
Consider the global sequence. Scan indices from `1` upwards.
When the first index belonging to a component `C` is reached, all earlier
indices belong to components already fixed. By Lemma&nbsp;4 the algorithm
has already chosen for `C` the orientation that gives the smallest possible
value at this first index of `C`. Therefore no other global assignment can
be smaller at that position, and the same argument repeats for the next
still‑undetermined component. Consequently the whole sequence is minimal. ∎



##### Theorem  
The algorithm outputs  

* `NO` iff no valid configuration exists;  
* otherwise `YES` and the lexicographically smallest valid configuration.

*Proof.*  
If the algorithm prints `NO`, by Lemma&nbsp;2 the graph is not bipartite,
hence no configuration exists.  
If it finishes, by Lemma&nbsp;3 the produced `col` is a valid configuration.
By Lemma&nbsp;5 this configuration is the lexicographically smallest one.
Thus the theorem holds. ∎



--------------------------------------------------------------------

#### 5.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and edge is processed once →  
`O(n + m)` time, `O(n)` additional memory for colour array and queue.  

Overall: **Time** `O(n + m)` ≤ `4·10⁵`, **Memory** `O(n + m)` ≤ `~4·10⁵`
well inside the limits.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    col = [0] * (n + 1)          # 0 = uncoloured, 1 or 2
    for start in range(1, n + 1):
        if col[start]:
            continue
        # start new component
        q = deque([start])
        col[start] = 1
        comp = []
        while q:
            v = q.popleft()
            comp.append(v)
            cv = col[v]
            for to in adj[v]:
                if col[to] == 0:
                    col[to] = 3 - cv
                    q.append(to)
                elif col[to] == cv:
                    print("NO")
                    return
        # choose orientation for lexicographically smallest result
        mn = min(comp)
        if col[mn] == 2:
            for v in comp:
                col[v] = 3 - col[v]

    # all good
    print("YES")
    out = ' '.join(str(col[i]) for i in range(1, n + 1))
    print(out)

if __name__ == "__main__":
    solve()
```
