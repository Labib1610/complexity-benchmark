# Problem B — Priority Assignments

Time limit: 1 s   Memory limit: 256 MB

A system consists of $n$ background processes. Each process must be assigned a priority level $s_i \in \{1, 2\}$.

There are $m$ resource contentions logged in the system. Each contention specifies a pair of processes $u$ and $v$ that share a critical resource. To resolve the contention safely, the sum of the priority levels assigned to $u$ and $v$ must be exactly 3.

Determine a valid priority assignment for all $n$ processes, or report if this cannot be done.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of processes involved in a resource contention.

## Output
If no safe assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), representing the lexicographically smallest safe assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
I replaced the explicit mention of machines failing if they operate in "identical modes" with an algebraic constraint: the sum of their assigned priority levels must be exactly 3. This removes the direct textual trigger for bipartite graph coloring, forcing the model to algebraically deduce that $s_u + s_v = 3$ over the domain $\{1, 2\}$ strictly implies $s_u \neq s_v$ before it can recognize the underlying graph structure.
</RATIONALE>
<PRESERVED_ANSWER>
Since the only allowed values are 1 and 2, the equation $s_u + s_v = 3$ is satisfied if and only if one value is 1 and the other is 2, which is logically identical to the original requirement that the modes must not be identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest valid 2-coloring of a graph, which is solvable in O(n + m) time using Breadth-First Search, keeping it in P.
</PRESERVED_CLASS>
