<STATEMENT>
# Problem B — Resonant Foundations

Time limit: 1 s
Memory limit: 256 MB

The structural integrity of a new skyscraper depends on $n$ primary load-bearing pillars, numbered 1 to $n$. The engineering firm must select a concrete composite grade for each pillar. The approved composite grades are exactly 1 and 2.

To mitigate wind-induced vibrations, the design includes $m$ acoustic dampeners. Each dampener spans between a specific pair of distinct pillars. 

The system's vibration control is modeled using linear algebra. 
Let $\mathbf{c}$ be the $n \times 1$ column vector of the chosen composite grades for pillars 1 through $n$.
Let $A$ be the $n \times n$ symmetric matrix where $A_{u,v}$ is the number of dampeners connecting pillar $u$ and pillar $v$.
Let $D$ be the $n \times n$ diagonal matrix where $D_{i,i}$ is the total number of dampeners attached to pillar $i$.
Let $\mathbf{1}$ be the $n \times 1$ column vector of all 1s.

The skyscraper's vibration control system is considered safe if and only if the scalar value evaluated from the matrix expression:
$3 \mathbf{1}^T D \mathbf{c} - \mathbf{c}^T A \mathbf{c}$
is exactly $5m$.

Your task is to determine if there is a safe composite selection for all $n$ pillars. If multiple safe selections exist, the procurement system requires the one that is lexicographically smallest when represented as a sequence of $n$ composite grades.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of the two pillars spanned by a dampener.

## Output
If no safe selection exists, print a single line `NO`.
Otherwise print `YES`, then a second line with $n$ integers $c_1 \dots c_n$ (each being 1 or 2), representing the lexicographically smallest safe selection.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The original problem provided a local edge-wise formula $3(c_u + c_v) - 2 c_u c_v$ which models trivially analyzed to find it yields 4 for matching grades and 5 for differing grades, immediately reducing the $5m$ target to a standard bipartite coloring task. I replaced this local condition with a mathematically equivalent global matrix equation: $3 \mathbf{1}^T D \mathbf{c} - \mathbf{c}^T A \mathbf{c} = 5m$. To solve the problem efficiently, models must now symbolically expand the matrix products, re-index the vertex-degree sum into an edge sum, and independently rediscover the local bipartite constraint, defeating surface pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The term $3 \mathbf{1}^T D \mathbf{c}$ simplifies to $3 \sum d_i c_i$, which equals $\sum_{e=(u,v)} 3(c_u + c_v)$, while $\mathbf{c}^T A \mathbf{c}$ simplifies to $2 \sum_{e=(u,v)} c_u c_v$; thus the global matrix expression is algebraically identical to the original sum of local resonance values, preserving all valid assignments exactly.
</PRESERVED_ANSWER>
