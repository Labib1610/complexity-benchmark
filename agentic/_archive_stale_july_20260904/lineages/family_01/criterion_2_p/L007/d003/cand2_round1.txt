# Problem B — Resonant Foundations

Time limit: 1 s
Memory limit: 256 MB

The structural integrity of a new skyscraper depends on $n$ primary load-bearing pillars, numbered 1 to $n$. The engineering firm must select a concrete composite grade for each pillar. The available grades are 1 and 2.

To mitigate wind-induced vibrations, the design includes $m$ acoustic dampeners. Each dampener spans between a specific pair of pillars. A dampener functions by exploiting the differential resonance between its endpoints. The manufacturer's calibration rule states that a dampener will only remain stable if one of its connected pillars uses grade 1 and the other uses grade 2. If both pillars are assigned grade 1, or both are assigned grade 2, the dampener will shatter under heavy winds.

Your task is to determine if there is a safe composite selection for all $n$ pillars. If multiple safe selections exist, the procurement system requires the one that is lexicographically smallest when represented as a sequence of $n$ composite grades.

## Input
The first line contains two integers $n$ and $m$. The site's footprint restricts the number of pillars $n$ to a maximum of two hundred thousand, while zoning regulations mandate at least one. The inventory of acoustic dampeners $m$ can be as low as zero and is capped at two hundred thousand.
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of the two pillars spanned by a dampener.

## Output
If no safe selection exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $c_1 \dots c_n$ (each being 1 or 2), the lexicographically smallest safe selection.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
