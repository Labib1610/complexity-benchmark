# Problem B — Resonant Foundations

Time limit: 1 s   Memory limit: 256 MB

The structural integrity of a new skyscraper depends on $n$ primary load-bearing pillars, numbered 1 to $n$. The engineering firm must select a concrete composite grade for each pillar. The approved composite grades are exactly 1 and 2.

To mitigate wind-induced vibrations, the design includes $m$ acoustic dampeners. Each dampener spans between a specific pair of pillars. A dampener functions by exploiting the material contrast between its anchor points. Specifically, a dampener will shatter under heavy winds unless one of its connected pillars is built with grade 1 concrete and the other is built with grade 2 concrete. If both pillars use the same grade, the lack of material contrast prevents the dampener from absorbing the stress.

Your task is to determine if there is a safe composite selection for all $n$ pillars. If multiple safe selections exist, the procurement system requires the one that is lexicographically smallest when represented as a sequence of $n$ composite grades.

## Input
The first line contains two integers $n$ and $m$. The architectural blueprints require at least 1 pillar, but site constraints limit the maximum pillar count to $2\cdot 10^5$. The design can include as few as 0 dampeners, up to a structural maximum of $2\cdot 10^5$ dampeners.

Each of the next $m$ lines contains two integers $u$ and $v$ (where both are between 1 and $n$) — the indices of the two pillars spanned by a dampener.

## Output
If no safe selection exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $c_1 \dots c_n$ (each being 1 or 2), the lexicographically smallest safe selection.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit arithmetic hint "sum of the composite grades ... exactly 3" was replaced with a material contrast requirement (one pillar must be grade 1 and the other grade 2). This forces the model to semantically parse the connection rule and deduce the 2-coloring constraint, rather than triggering a bipartite template based on a numeric sum. In addition, the input bounds are stated indirectly via the scenario's physical limits to fulfill the strategy requirement while preserving the exact numbers for the validator.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that one pillar is grade 1 and the other is grade 2 is mathematically identical to their sum being exactly 3 when the only available grades are 1 and 2, so the set of valid configurations is completely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (bipartiteness testing) on an undirected graph, which is solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
