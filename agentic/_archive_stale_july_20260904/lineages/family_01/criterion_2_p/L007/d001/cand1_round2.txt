<STATEMENT>
# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

The factory planning process consists of three stages. In the first stage, human resources determines the exact headcount of employees, $n$, and compiles a registry of $m$ incompatible pairs of employees. 

Your task is the second stage: given this data, issue each employee exactly one shift token. The available tokens have values of 1 and 2. To satisfy safety regulations, for every incompatible pair of employees, the sum of their two shift token values must evaluate to exactly 3. If no such token distribution is possible, you must report the impossibility.

In the third stage, this distribution will be sent to the payroll department for final processing.

## Input
The first line contains two integers $n$ and $m$ (a factory headcount of $1 \le n \le 2\cdot 10^5$, and a registry size of $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — an incompatible pair.

## Output
If no valid token distribution exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \dots s_n$ (each in {1,2}), the lexicographically smallest valid token distribution.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The problem still requires partitioning a graph into two independent sets (shifts 1 and 2). To disrupt pattern-matching on bipartite coloring, the constraint that "no conflicting pair shares a shift" has been replaced with the algebraic requirement that the sum of their assigned shift tokens (which are 1 and 2) must be exactly 3. This forces models to algebraically deduce that connected nodes must have opposite values, rather than relying on keyword matching for two-coloring.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that two values from {1, 2} sum to 3 is mathematically identical to them being different, so the valid assignments and their lexicographical order are completely unchanged.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring (checking bipartiteness and assigning colors), which takes O(n + m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the token sum constraint as a subset sum or knapsack-like problem, though the strict domain of {1, 2} and exact sum of 3 makes the bipartite nature unambiguous to careful reasoning.
</RISK>
