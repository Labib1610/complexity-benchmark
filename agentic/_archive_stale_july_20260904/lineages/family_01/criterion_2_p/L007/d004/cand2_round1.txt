<STATEMENT>
# Problem B — Resonant Foundations

Time limit: 1 s
Memory limit: 256 MB

The structural integrity of a new skyscraper depends on $n$ primary load-bearing pillars, numbered 1 to $n$. The engineering firm must assign a positive integer grade $c_i \ge 1$ to each pillar $i$. Due to thermal expansion limits, every chosen grade must satisfy the following physical constraint:

$c_i^3 + 5 c_i \le 4 c_i^2 + 2$

To mitigate wind-induced vibrations, the design includes $m$ acoustic dampeners. The skyscraper's blueprint can accommodate up to two hundred thousand pillars, and the vibration mitigation budget covers up to the exact same number of dampeners.

Each dampener spans between a specific pair of pillars. For a dampener provided in the blueprints as connecting pillar $u$ and pillar $v$, the engineering software calculates an acoustic stress coefficient $A$:

$A = (3 c_u + 5 c_v) \bmod 7$

The dampener safely distributes stress if and only if $A > 3$. If $A \le 3$, it shatters under heavy winds. 

Your task is to determine if there is a safe composite selection for all $n$ pillars such that no dampener shatters. If multiple safe selections exist, the procurement system requires the one that is lexicographically smallest when represented as a sequence of $n$ composite grades ($c_1, c_2, \dots, c_n$).

## Input
The first line contains two integers $n$ and $m$ — the number of pillars and dampeners.
Each of the next $m$ lines contains two integers $u$ and $v$, representing a dampener connecting pillar $u$ and pillar $v$.

## Output
If no safe selection exists, print a single line `NO`.
Otherwise, print `YES`, followed by a second line containing $n$ integers $c_1 \dots c_n$, representing the lexicographically smallest safe sequence of grades.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<METHOD_DESCRIPTION>
Obscured the discrete 2-state domain using an algebraic inequality over positive integers that only holds for 1 and 2. Replaced the explicit stress matrix with an asymmetric modular arithmetic condition that evaluates to true only when the two grades are different. This prevents models from immediately recognizing the bipartite structure because they fail to reduce the domain to {1, 2} and the edge condition to a simple inequality.
</METHOD_DESCRIPTION>

yes
</METHOD_NOVEL>
<RATIONALE>
The explicit matrix was the primary affordance that allowed models to immediately recognize the bipartite 2-coloring structure. By replacing the domain with a polynomial inequality and the edge condition with a modular arithmetic formula, the model is forced to independently deduce that the domain is strictly {1, 2} and that the edge condition is exactly $c_u \ne c_v$.
</RATIONALE>
<PRESERVED_ANSWER>
The polynomial inequality $c_i^3 + 5 c_i \le 4 c_i^2 + 2$ for positive integers restricts $c_i$ exactly to $\{1, 2\}$, and the formula $(3 c_u + 5 c_v) \bmod 7 > 3$ evaluates to true if and only if $\{c_u, c_v\} = \{1, 2\}$, perfectly matching the original stress matrix logic.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is mathematically isomorphic to 2-coloring a graph (testing for bipartiteness), which remains solvable in $O(n + m)$ time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
A model might misinterpret "positive integer grade $c_i \ge 1$" if it ignores the inequality, but the mathematical wording is standard and unambiguous.
