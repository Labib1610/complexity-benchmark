 We need to assign each pillar a value of 1 or 2 such that for every edge (u, v), the sum of their values is exactly 3.  
That means if one is 1, the other must be 2, and vice versa. This is exactly a bipartite graph check with two colors.

So the problem reduces to:
- Check if the graph is bipartite.
- If yes, output the lexicographically smallest assignment (which means we try to assign 1 as early as possible, but respecting bipartiteness).

We can do BFS/DFS coloring, but to get lexicographically smallest, we should try to assign 1 to the smallest index possible, and if conflict occurs, it's impossible.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

def bfs(start):
    q = deque([start])
    color[start] = 0  # try 0 first (meaning value 1)
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                return False
    return True

# Try to assign 1 (color 0) to smallest possible nodes
for i in range(n):
    if color[i] == -1:
        if not bfs(i):
            print("NO")
            sys.exit()

# Convert color to 1 or 2
res = [1 if c == 0 else 2 for c in color]
print("YES")
print(" ".join(map(str, res)))
```
