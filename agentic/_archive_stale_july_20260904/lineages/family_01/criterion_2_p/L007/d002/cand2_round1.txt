# Problem B — Resonant Foundations

Time limit: 1 s   Memory limit: 256 MB

The structural integrity of a new skyscraper depends on $n$ primary load-bearing pillars, numbered 1 to $n$. A standard manufacturing batch produces exactly one hundred thousand pillars. The foundation blueprint requires at least one pillar, and its absolute maximum capacity is two full manufacturing batches. The design also includes $m$ acoustic dampeners. The number of dampeners $m$ can be zero, and is capped at the same absolute maximum limit of two full manufacturing batches.

Each pillar must be calibrated with a specific structural tuning parameter. The hardware supports exactly two tuning settings, represented by the integers 1 and 2.

To mitigate wind-induced vibrations, the $m$ dampeners are installed such that each connects a specific pair of pillars. If the two pillars connected by a dampener resonate identically, the dampener will shatter. To prevent this, the calibration must ensure that the sum of the tuning parameters for any two connected pillars is exactly 3.

Your task is to determine if there is a valid calibration for all $n$ pillars. If multiple valid configurations exist, the procurement system requires the one that is lexicographically smallest when represented as a sequence of $n$ tuning parameters.

## Input
The first line contains two integers $n$ and $m$, bounded strictly by the manufacturing and design limits detailed above.
Each of the next $m$ lines contains two integers $u$ and $v$ — the indices of the two pillars connected by a dampener.

## Output
If no valid calibration exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $c_1 \dots c_n$ (each being 1 or 2), representing the lexicographically smallest valid calibration sequence.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit bounds have been replaced with a textual description based on "manufacturing batches" of 100,000, forcing the model to read and derive the $2 \cdot 10^5$ limits. Additionally, the explicit "must be different" rule has been reframed mathematically: the sum of the two assigned tuning parameters (which are strictly 1 and 2) must be exactly 3. This removes the obvious "different colors" template and tests whether the model can deduce the bipartite constraint from the arithmetic relationship.
</RATIONALE>
<PRESERVED_ANSWER>
The available settings are 1 and 2, and their sum is 3 if and only if they are different; therefore, the exact same assignments are valid and the lexicographically smallest sequence remains identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core logic remains finding a valid 2-coloring for an undirected graph (bipartiteness testing), which is solvable in O(n+m) time using BFS or DFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret "two full manufacturing batches" if they fail to link it to the previously stated batch size, but the phrasing is direct and unambiguous.
</RISK>
