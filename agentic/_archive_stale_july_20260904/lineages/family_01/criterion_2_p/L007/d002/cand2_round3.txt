<STATEMENT>
# Problem B — Harmonic Synchronization

Time limit: 1 s   Memory limit: 256 MB

A manufacturing plant operates $n$ automated assembly units, indexed from 1 to $n$. Each unit must be calibrated to one of two phase states, represented by the identifiers 1 and 2.

To maintain structural stability, the plant utilizes $m$ rigid linkages. Each linkage attaches a specific pair of units. The mechanical resonance across any linkage requires a strict phase balance. Specifically, for any single linkage connecting two units, the sum of the phase state identifiers assigned to those two units must evaluate to exactly 3.

Your task is to determine if a valid phase state assignment exists for all $n$ units. If multiple valid assignments exist, the control system requires the one that is lexicographically smallest when represented as a sequence of $n$ phase state identifiers.

## Input
The first line contains two integers $n$ and $m$. The unit count $n$ is at least $1$ and at most $2\cdot 10^5$. The linkage count $m$ is at least $0$ and at most $2\cdot 10^5$.
Each of the following $m$ lines contains two integers $u$ and $v$ — the indices of the units attached by a linkage.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, followed by a second line containing $n$ integers $c_1 \dots c_n$ (each being 1 or 2), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit requirement that connected nodes must have "different" identifiers immediately flags the problem as standard bipartite coloring / 2-coloring. To defeat models relying on this surface pattern, the adjacency constraint is reframed as an algebraic condition: the sum of the two identifiers must equal 3. Since the available identifiers are strictly 1 and 2, this enforces exactly the same logical separation without using the vocabulary of graph coloring or inequality.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that two values from {1, 2} sum to 3 is mathematically identical to requiring that the two values be different, meaning the set of valid assignments and the lexicographically smallest assignment remain perfectly unchanged for all inputs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The underlying structure is still assigning one of two states to vertices such that no adjacent vertices share a state, which is exactly the 2-coloring / bipartiteness testing problem solvable in O(n+m) via Breadth-First Search.
</PRESERVED_CLASS>
