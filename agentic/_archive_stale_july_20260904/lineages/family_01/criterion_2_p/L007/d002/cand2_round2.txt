# Problem B — Resonant Foundations

Time limit: 1 s   Memory limit: 256 MB

The structural integrity of a new skyscraper depends on $n$ load-bearing units, numbered $1$ to $n$. A standard site footprint dictates that the unit count $n$ is an integer ranging from a minimum of $1$ up to a maximum capacity of $2 \cdot 10^5$. To suppress vibrations, the design incorporates $m$ acoustic braces. The vibration mitigation budget allows $m$ to be any integer from $0$ up to a maximum of $2 \cdot 10^5$.

You must assign an operational mode $c_i \in \{1, 2\}$ to each unit $i$. For an acoustic brace to function correctly, it must span between a unit in mode $1$ and a unit in mode $2$. Therefore, for every brace connecting units $u$ and $v$, the set of their assigned modes $\{c_u, c_v\}$ must be exactly equal to the set $\{1, 2\}$. If the assigned modes do not form this exact set, the brace will shatter under heavy winds.

Your task is to determine if there is a safe mode assignment for all $n$ units. If multiple safe assignments exist, the procurement system requires the one that is lexicographically smallest when represented as a sequence of $n$ integers.

## Input
The first line contains the two integers $n$ and $m$ (the number of units and braces, respectively).
Each of the next $m$ lines contains two integers $u$ and $v$. These represent the indices of the two units spanned by a brace. It is guaranteed that $u$ and $v$ are valid unit indices between $1$ and $n$ inclusive.

## Output
If no safe assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $c_1 \dots c_n$ (each in $\{1, 2\}$), representing the lexicographically smallest safe assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
