We need to check if the graph is bipartite.  
The condition: XOR > AND for values 1 and 2.  

Let’s check possible pairs:  
- (1,1): XOR=0, AND=1 → 0 > 1 false  
- (1,2): XOR=3, AND=0 → 3 > 0 true  
- (2,1): same as above true  
- (2,2): XOR=0, AND=2 → false  

So valid edges only connect different values.  
Thus, the graph must be bipartite.  

We also need the lexicographically smallest assignment.  
We can do BFS/DFS, assigning 1 to the first node, then alternate.  
If conflict → NO.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
