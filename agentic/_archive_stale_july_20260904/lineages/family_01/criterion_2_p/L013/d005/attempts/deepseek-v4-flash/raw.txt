We can model this as a graph coloring problem with two possible rules.  

Let’s check the composition condition:  

- Rule 1: \( f(x) = -x \)  
- Rule 2: \( f(x) = 1/x \)  

For a link between nodes \(u\) and \(v\), we need:  
\( f_u(f_v(x)) = -1/x \).  

Check the four possible assignments:  

1. Both rule 1:  
   \( f_u(f_v(x)) = -(-x) = x \) → not stable.  
2. Both rule 2:  
   \( f_u(f_v(x)) = 1/(1/x) = x \) → not stable.  
3. \(u\) rule 1, \(v\) rule 2:  
   \( f_u(f_v(x)) = -(1/x) = -1/x \) → stable.  
4. \(u\) rule 2, \(v\) rule 1:  
   \( f_u(f_v(x)) = 1/(-x) = -1/x \) → stable.  

So the link is stable **iff** the two endpoints have different rules.  

Thus the problem reduces to:  
- Check if the graph is bipartite.  
- If yes, output the lexicographically smallest 2-coloring (with colors 1 and 2).  

For lexicographically smallest, we assign node 1 as rule 1, then BFS/DFS assign alternating colors, and if a conflict occurs, it’s impossible.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 0
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 1 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    # color 0 -> rule 1, color 1 -> rule 2
    print(' '.join(str(c + 1) for c in color))
```
