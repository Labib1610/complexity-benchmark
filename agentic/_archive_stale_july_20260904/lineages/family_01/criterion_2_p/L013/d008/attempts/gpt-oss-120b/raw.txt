**Solution Explanation**

For a node we have to choose one of the two operators  

```
T1 = D + I          (operator 1)
T2 = D – I          (operator 2)
```

`D` – derivative, `I` – multiplication by the identity function.  
For a link `{u , v}` the composed operator is `T_u ∘ T_v`.  
The link is *stable* iff this operator is formally self‑adjoint, i.e.

```
∫ g · (T_u∘T_v)(f) = ∫ f · (T_u∘T_v)(g)      for all compact‑support f,g
```

--------------------------------------------------------------------

#### 1.   When is a composition self‑adjoint ?

Write the three possible compositions (they commute).

```
T1∘T1 = (D+I)(D+I) = D² + 2D + I
T2∘T2 = (D-I)(D-I) = D² – 2D + I
T1∘T2 = T2∘T1 = (D+I)(D-I) = D² – I
```

For a linear differential operator  

```
L = D² + a·D + b·I
```

the formal adjoint is  

```
L* = D² – a·D + b·I                (because (D)* = –D , (I)* = I)
```

`L` is self‑adjoint  **iff** `a = 0`.

* `T1∘T1` and `T2∘T2` have `a = ±2` → **not** self‑adjoint.
* `T1∘T2` (and `T2∘T1`) have `a = 0` → **self‑adjoint**.

Therefore a link is stable **iff its two endpoints use different operators**.

--------------------------------------------------------------------

#### 2.   The whole problem

We have to colour the given undirected graph with two colours
`1` and `2` such that adjacent vertices have different colours.
That is exactly the classic *bipartite graph* problem.

*If the graph is not bipartite → answer `NO`.*

If it is bipartite we have to output the **lexicographically smallest**
colour sequence `s₁ … s_n` (1 < 2).

For each connected component the bipartition is unique up to swapping the
two sides.  
So for a component we have two possible colourings:

```
side 0 → 1 , side 1 → 2          (orientation A)
side 0 → 2 , side 1 → 1          (orientation B)
```

To obtain the minimal global sequence we decide the orientation **greedy**
while scanning vertices `1 … n` :

* when we first meet a vertex of a component whose orientation is still
  undecided, we choose the orientation that gives colour `1` to this vertex.
* all later vertices of the same component are forced by that choice.

This greedy rule is optimal because the first position where two possible
global colourings differ is exactly the first vertex of a component that
has not been fixed yet; giving it colour `1` makes the whole sequence
lexicographically smaller, and later decisions cannot affect earlier
positions.

--------------------------------------------------------------------

#### 3.   Algorithm
```
read n,m
build adjacency list
side[1..n] = -1                # 0 or 1 inside a component
comp[1..n] = -1                # component id
orientation = []              # for each component: None / 0 (side0→1) / 1 (side0→2)

for each vertex v = 1..n
    if side[v] == -1
        start BFS/DFS from v
        assign side values, store vertices of this component
        if we ever find an edge (x,y) with side[x] == side[y] → not bipartite → NO
        give this component id = c, store its vertex list
        orientation.append(None)

# choose orientations greedily
answer = [0]*n
for i = 1 .. n
    c = comp[i]
    if orientation[c] is None
        # we want colour 1 for vertex i
        if side[i] == 0: orientation[c] = 0          # side0 → 1
        else:            orientation[c] = 1          # side0 → 2, side1 → 1
    # now set colour of i according to orientation
    if orientation[c] == 0:
        answer[i-1] = 1 if side[i]==0 else 2
    else:
        answer[i-1] = 2 if side[i]==0 else 1

print YES and the answer
```

--------------------------------------------------------------------

#### 4.   Correctness Proof  

We prove that the algorithm prints `NO` iff no valid assignment exists,
otherwise prints the lexicographically smallest valid assignment.

---

##### Lemma 1  
A link `{u,v}` is stable **iff** the operators assigned to `u` and `v`
are different.

*Proof.* From the analysis of compositions we have:

* same operators → composition contains a `±2·D` term → not self‑adjoint.
* different operators → composition equals `D² – I` → self‑adjoint.

∎



##### Lemma 2  
An assignment of operators to all nodes satisfies all links **iff**
the underlying graph is coloured with two colours so that adjacent
vertices have different colours (i.e. the graph is bipartite).

*Proof.* By Lemma&nbsp;1 a link is stable exactly when its endpoints have
different operators. Translating operators `1,2` to colours `1,2` gives the
required proper 2‑colouring, and conversely any proper 2‑colouring yields a
stable assignment. ∎



##### Lemma 3  
If the algorithm reports `NO` then the graph is not bipartite.

*Proof.* The algorithm performs a BFS assigning sides `0/1`. Encountering an
edge whose ends already have the same side means an odd cycle exists,
hence the graph is not bipartite. Conversely, if the graph is not
bipartite such an edge must appear, so the algorithm will output `NO`. ∎



##### Lemma 4  
Assume the graph is bipartite. After the greedy orientation step,
the produced colour sequence `s` is a proper 2‑colouring.

*Proof.* For each component we fix an orientation that maps each side
(`0` or `1`) to a colour (`1` or `2`). All vertices of the component receive
the colour dictated by their side, therefore any edge inside the component
connects vertices of opposite sides and receives opposite colours.
Edges between components do not exist. Hence the whole assignment is proper. ∎



##### Lemma 5  
Among all proper 2‑colourings, the greedy orientation yields the
lexicographically smallest colour sequence.

*Proof.* Consider the vertices in order `1 … n`. Let `i` be the first index
where two proper colourings `A` and `B` differ. Then `i` belongs to some
component `C` whose orientation is not fixed before processing `i`.  
The greedy algorithm chooses the orientation that gives colour `1` to
vertex `i`. Therefore `A[i]=1` and any other proper colouring must have
`B[i]=2` (otherwise it would coincide with `A` at `i`). Hence `A` is
lexicographically smaller than `B`. Since this holds for any other proper
colouring, the greedy result is the minimum. ∎



##### Lemma 6  
If the graph is bipartite, the algorithm outputs a valid assignment.

*Proof.* By Lemma&nbsp;4 the assignment is a proper 2‑colouring, therefore
by Lemma&nbsp;2 all links are stable. ∎



##### Theorem  
The algorithm prints  

* `NO` iff no stable assignment exists;  
* otherwise `YES` and the lexicographically smallest stable assignment.

*Proof.*  
- If the algorithm prints `NO`, by Lemma&nbsp;3 the graph is not bipartite,
  thus by Lemma&nbsp;2 no stable assignment exists.
- If a stable assignment existed, the graph would be bipartite,
  so the algorithm would not output `NO`. By Lemma&nbsp;6 it outputs a
  stable assignment, and by Lemma&nbsp;5 this assignment is the
  lexicographically smallest one.

∎

#### 5.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory `O(n + m)`  
*BFS over all components*: each vertex and edge visited once → `O(n + m)`  
*Greedy orientation pass*: `O(n)`  

Total time `O(n + m)` ≤ `4·10⁵`, well inside the limits.  
Memory `O(n + m)` ≤ `~4·10⁵` integers, also well within 256 MB.

#### 6.   Reference Implementation  (Python 3)

```python
import sys
sys.setrecursionlimit(1 << 25)

def solve() -> None:
    data = sys.stdin.read().strip().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(next(it)) - 1
        v = int(next(it)) - 1
        adj[u].append(v)
        adj[v].append(u)

    side = [-1] * n          # 0 / 1 inside component
    comp = [-1] * n          # component id
    comps = []               # list of vertex lists per component
    from collections import deque

    comp_cnt = 0
    for v in range(n):
        if side[v] != -1:
            continue
        q = deque([v])
        side[v] = 0
        comp[v] = comp_cnt
        verts = [v]
        ok = True
        while q:
            x = q.popleft()
            for y in adj[x]:
                if side[y] == -1:
                    side[y] = side[x] ^ 1
                    comp[y] = comp_cnt
                    q.append(y)
                    verts.append(y)
                elif side[y] == side[x]:
                    print("NO")
                    return
        comps.append(verts)
        comp_cnt += 1

    orientation = [None] * comp_cnt   # 0: side0->1, 1: side0->2
    ans = [0] * n

    for i in range(n):
        c = comp[i]
        if orientation[c] is None:
            # we want colour 1 for vertex i
            orientation[c] = 0 if side[i] == 0 else 1
        if orientation[c] == 0:
            ans[i] = 1 if side[i] == 0 else 2
        else:
            ans[i] = 2 if side[i] == 0 else 1

    print("YES")
    print(' '.join(map(str, ans)))

if __name__ == "__main__":
    solve()
```
