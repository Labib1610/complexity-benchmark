# Robotic Routing Network

Time limit: 1 s
Memory limit: 256 MB

A network consists of $n$ routing stations. Each station must be assigned exactly one of two navigational modules to control a test robot moving on an infinite 2D grid. The grid squares are colored like a chessboard: a square at coordinates $(x, y)$ is "white" if $x + y$ is even, and "black" if $x + y$ is odd.

- **Module 1**:
  - If the robot is on a white square, it moves 1 step North (to $(x, y+1)$).
  - If the robot is on a black square, it moves 1 step East (to $(x+1, y)$).
- **Module 2**:
  - If the robot is on a white square, it moves 1 step West (to $(x-1, y)$).
  - If the robot is on a black square, it moves 1 step South (to $(x, y-1)$).

There are $m$ bidirectional links in the network. Each link connects two specific stations $u$ and $v$. 

A link is considered **stable** if and only if a robot starting at ANY arbitrary square $(x, y)$ on the grid, applying the module at station $u$, and then applying the module at station $v$, ends up exactly back at its starting square $(x, y)$. This must hold true for all possible starting squares. If there is even one starting square where the robot does not return to exactly $(x, y)$, the link is unstable and the entire network configuration is invalid. (Since the links are bidirectional, the order of $u$ and $v$ does not matter; a stable link restores the robot's position regardless of which station's module is applied first).

Your task is to determine whether there is an assignment of modules (either 1 or 2) to all $n$ stations such that every link in the network is stable. If multiple valid assignments exist, you must output the one that minimizes the sequence of assigned module numbers $s_1, s_2, \dots, s_n$ lexicographically.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a link connects station $u$ and station $v$.

## Output
If no stable assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \ldots, s_n$ (each being 1 or 2) representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
The explicit matrix transformations from the seed problem allowed models to calculate their products, recognize they are mutual inverses, and immediately map the problem to standard bipartite graph coloring. I replaced the matrices with a parity-based 2D grid movement system. The two modules are mathematically rigorous mutual inverses (Module 1 moves parity Even->Odd via North, Odd->Even via East; Module 2 reverses this exactly), meaning a link is only stable if its endpoints receive different modules. This forces the model to genuinely trace the spatial logic to discover the XOR constraint rather than pattern-matching linear algebra templates. The exact numeric bounds were restored to fix the previous fidelity failure.
</RATIONALE>
<PRESERVED_ANSWER>
The grid movement rules dictate that applying identical modules successively results in a net displacement of (+1, +1) or (-1, -1), while applying opposite modules returns the robot to its exact starting coordinates; therefore, a link is stable if and only if its endpoints are assigned different modules, exactly preserving the original problem's constraint and lexicographically smallest output requirement.
</PRESERVED_ANSWER>
