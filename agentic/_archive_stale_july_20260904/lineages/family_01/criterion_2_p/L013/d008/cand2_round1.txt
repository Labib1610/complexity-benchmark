<STATEMENT>
# Routing Protocol Network

Time limit: 1 s
Memory limit: 256 MB

A network consists of $n$ nodes. Each node must be configured with exactly one of two routing protocols, designated as Protocol 1 and Protocol 2. 

Each protocol applies a specific permutation to any 5-element data sequence $(d_1, d_2, d_3, d_4, d_5)$ passing through it. 
- Protocol 1 rearranges the sequence by moving the element at position 1 to position 3, position 2 to position 5, position 3 to position 4, position 4 to position 2, and position 5 to position 1.
- Protocol 2 rearranges the sequence by moving the element at position 1 to position 5, position 2 to position 4, position 3 to position 1, position 4 to position 3, and position 5 to position 2.

There are $m$ bidirectional links in the network. Each link connects two specific nodes $u$ and $v$. A link is considered *transparent* if and only if the sequential application of the protocols assigned to its two endpoints (in either order) restores every possible 5-element data sequence to its original order. If there exists even one data sequence that is altered after passing through both endpoints, the link is not transparent and the entire network configuration is considered invalid.

Your task is to determine whether there is an assignment of protocols (either 1 or 2) to all $n$ nodes such that every link in the network is transparent. If multiple valid assignments exist, you must output the one that minimizes the sequence of assigned protocol numbers $s_1, s_2, \dots, s_n$ lexicographically.

## Input
The first line contains two integers $n$ and $m$. The number of nodes $n$ is at least 1 and does not exceed the maximum number of 5-byte packets that fit into a 1-megabyte ($10^6$ bytes) payload. The number of links $m$ is non-negative and bounded by this same maximum.
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a link connects node $u$ and node $v$.

## Output
If no transparent configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \ldots, s_n$ (each being 1 or 2) representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
