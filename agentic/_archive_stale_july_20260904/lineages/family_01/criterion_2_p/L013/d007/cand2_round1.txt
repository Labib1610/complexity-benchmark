<STATEMENT>
# Transformation Network

Time limit: 1 s
Memory limit: 256 MB

A network consists of $n$ nodes. Each node must be assigned exactly one of two signal-routing protocols:
- **Protocol 1**: Shifts the signal state forward alphabetically with wrap-around (`A` $\to$ `B`, `B` $\to$ `C`, `C` $\to$ `D`, `D` $\to$ `A`).
- **Protocol 2**: Shifts the signal state backward alphabetically with wrap-around (`A` $\to$ `D`, `B` $\to$ `A`, `C` $\to$ `B`, `D` $\to$ `C`).

There are $m$ links in the network. Each link connects two specific nodes $u$ and $v$. A link is considered **stable** if and only if a signal initially in state `A` does **not** end up in state `C` after being processed by the protocol assigned to node $u$ and then immediately by the protocol assigned to node $v$. (Because the protocols are symmetric in their effects, processing the signal through $v$ and then $u$ yields the exact same stability result, so the link direction does not matter). 

If there exists even one link that produces state `C` from an initial state `A`, that link is unstable and the entire network configuration is invalid.

Your task is to determine whether there is an assignment of protocols (either 1 or 2) to all $n$ nodes such that every link in the network is stable. If multiple valid assignments exist, you must output the one that minimizes the sequence of assigned protocol numbers $s_1, s_2, \dots, s_n$ lexicographically.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a link connects node $u$ and node $v$.

## Output
If no stable assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \ldots, s_n$ (each being 1 or 2) representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<METHOD_DESCRIPTION>Replaced the affine transformations with a 4-state transition system (+1 mod 4 and -1 mod 4). Checking stability requires evaluating the 2-step transitions, which forces the model to deduce the bipartite condition from the state machine rather than recognizing a standard algebraic fixed-point equation.</METHOD_DESCRIPTION>
<METHOD_NOVEL>yes</METHOD_NOVEL>
<RATIONALE>
The models were able to algebraically simplify the affine transformation fixed-point condition to $u \neq v$. By changing the domain to a finite state machine with character states, the models must now step through the logical transitions to realize that identical protocols yield the invalid state `C`, whereas differing protocols yield `A`, preserving the $u \neq v$ requirement while breaking algebraic pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
Assigning identical protocols to linked nodes results in state `C` (unstable), while assigning different protocols results in state `A` (stable), making the valid configurations exactly the same as the original problem (adjacent nodes must have different assignments).
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in linear time using BFS/DFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the problem as requiring a global signal simulation across the entire network rather than a local 2-node check, though the phrase "processed by node u and then immediately by node v" is intended to clarify it's a local link property.
</RISK>
