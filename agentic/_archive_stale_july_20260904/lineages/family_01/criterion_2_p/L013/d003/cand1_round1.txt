# Magnetic Resonance Equilibrium

Time limit: 1 s
Memory limit: 256 MB

The facility manages $n$ containment fields. Each field must be assigned an operation tier, restricted to the values 1 and 2. 

There are $m$ synchronization channels. Each channel connects a specific pair of fields. A channel is considered stable if and only if the operation tiers of its two connected fields, say $t_u$ and $t_v$, satisfy the equation $t_u^2 + t_v^2 = 5$. If any channel connects a pair of fields that fail to meet this condition, the entire network will halt.

Your task is to determine whether it is possible to assign an operation tier to every field such that all channels are stable. If there are multiple valid assignments, the safety protocol requires the one that is lexicographically smallest. (An assignment $s_1, s_2, \dots, s_n$ is lexicographically smaller than $t_1, t_2, \dots, t_n$ if $s_i < t_i$ at the first field $i$ where they differ).

## Input
The facility is bound by a hardware maximum of $200,000$ for any component category due to thermal constraints.
The first line of input provides two integers: the number of fields $n$ (which is at least one) and the number of channels $m$ (which may be zero). Both are guaranteed not to exceed the thermal limit.
Each of the subsequent $m$ lines contains two integers $u$ and $v$ (1-indexed), indicating that a synchronization channel connects field $u$ and field $v$.

## Output
If no stable assignment exists, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers (each being 1 or 2) representing the lexicographically smallest stable assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

The explicit "one is exactly twice the other" constraint was replaced with the equation $t_u^2 + t_v^2 = 5$. This removes the obvious alternating pattern language that models use to immediately identify bipartite graph coloring, forcing them to evaluate the equation over the domain $\{1, 2\}$ to deduce the required structure. Furthermore, strategy S07 was applied to state the bounds indirectly through a physical "thermal limit".
</RATIONALE>
<PRESERVED_ANSWER>
Since the operation tiers are restricted to the values 1 and 2, the only way the sum of their squares can equal 5 is if one is 1 and the other is 2, which is logically identical to the original requirement that one must be exactly twice the other.
</PRESERVED_ANSWER>
