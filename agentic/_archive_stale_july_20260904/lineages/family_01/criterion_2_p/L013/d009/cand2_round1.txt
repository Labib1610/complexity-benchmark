<STATEMENT>
# Signal Routing Network

Time limit: 1 s
Memory limit: 256 MB

A network consists of $n$ nodes. Each node must be assigned exactly one of two signal basis functions defined on the real line:
- Basis 1: $f_1(x) = e^x$
- Basis 2: $f_2(x) = e^{-x}$

There are $m$ links in the network. Each link connects two specific nodes $u$ and $v$. A link is considered stable if and only if the combined signal function on that link, defined as the sum $g_{u,v}(x) = f_u(x) + f_v(x)$, has exactly one local extremum (a local minimum or local maximum) over the domain of all real numbers.

If there is even one link in the network that is not stable, the entire configuration is invalid.

Your task is to determine whether there is an assignment of basis functions (either 1 or 2) to all $n$ nodes such that every link in the network is stable. If multiple valid assignments exist, you must output the one that minimizes the sequence of assigned basis numbers $s_1, s_2, \dots, s_n$ lexicographically.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), indicating that a link connects node $u$ and node $v$.

## Output
If no stable assignment exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, \ldots, s_n$ (each being 1 or 2) representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The seed problem relied on the self-adjointness of composed differential operators, which advanced models easily simplified to $D^2-1$ and mapped directly to graph bipartiteness. To defeat this, I replaced the differential operators with exponential basis functions and changed the stability condition to evaluating the number of local extrema of their sum. Models must now perform basic calculus ($2e^x$ and $2e^{-x}$ have no extrema, while $e^x + e^{-x}$ has exactly one) to deduce the $u \neq v$ constraint, rewarding genuine mathematical reasoning while breaking surface-level pattern matching to known graph algorithms.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that the sum of the basis functions has exactly one local extremum is mathematically true if and only if the two functions are different, exactly preserving the original requirement that adjacent nodes must have different assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains a bipartite graph 2-coloring problem with a lexicographical tie-breaker, which is solvable in O(n+m) time using Breadth-First Search, keeping it strictly in the P complexity class.
</PRESERVED_CLASS>
