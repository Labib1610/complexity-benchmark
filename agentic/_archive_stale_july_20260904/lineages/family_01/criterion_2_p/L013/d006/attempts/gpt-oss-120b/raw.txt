**Solution Explanation**

For a node we have to choose one of the two affine transformations  

```
T1(V) = M·V + B1 ,   B1 = ( 1 , -1 )
T2(V) = M·V + B2 ,   B2 = ( -1 , 1 )
M = [[0,1],[1,0]]      (swap the two coordinates)
```

For an edge `{u,v}` the composition in one order is  

```
Tu ( Tv (V) ) = M·(M·V + Bv) + Bu = V + ( M·Bv + Bu )
```

`M·B1 = B2` and `M·B2 = B1`.  
Therefore  

```
M·Bv + Bu =  B2 + B1   if Bu = B1 , Bv = B1
           =  B1 + B2   if Bu = B2 , Bv = B2
           =  0         if Bu ≠ Bv
```

The composition has a fixed point **iff** the translation vector is `0`,
i.e. **iff the two endpoints use different transformations**.
The same holds for the opposite order, so an edge is *stable* exactly when
its two endpoints receive *different* numbers `1` and `2`.

Consequences
------------

* The whole graph must be **bipartite** (2‑colourable).
* In each connected component the two colour classes can be swapped.
* To obtain the lexicographically smallest sequence `s1 … sn`
  we simply give colour `1` to the smallest numbered vertex of every component
  (the other vertices of the component receive `2`).

Thus the problem is reduced to ordinary bipartite checking and a deterministic
colouring.

Algorithm
---------

```
read n,m and the edges
build adjacency list

colour[1…n] = -1          # -1 = unvisited, 0 or 1 = two colour classes
for v = 1 … n (in increasing order):
        if colour[v] == -1:
                colour[v] = 0                # smallest vertex of this component gets colour 0
                bfs/dfs from v:
                        for each edge (x, y):
                                if colour[y] == -1: colour[y] = colour[x] ^ 1
                                else if colour[y] == colour[x]:   # not bipartite
                                        print "NO" and exit

print "YES"
for i = 1 … n:
        output 1 if colour[i] == 0 else 2
```

The BFS guarantees `O(n+m)` time, `O(n+m)` memory.

Correctness Proof
-----------------

We prove that the algorithm prints `YES` and a lexicographically smallest
valid assignment iff such an assignment exists.

---

### Lemma 1  
For an edge `{u,v}` the composition `Tu∘Tv` (and also `Tv∘Tu`) has a fixed
point **iff** the assigned numbers of `u` and `v` are different.

*Proof.*  
From the computation above  

```
Tu∘Tv (V) = V + (M·Bv + Bu)
```

`M·Bv + Bu = 0` exactly when `{Bu,Bv}` = `{B1,B2}` i.e. the numbers differ.
If the vector is `0` the transformation is the identity, hence every `V`
is a fixed point; otherwise it is a non‑zero translation and has no fixed
point. ∎



### Lemma 2  
A configuration of numbers `1/2` is valid (all edges stable) **iff**
the underlying graph is bipartite and the numbers form a proper 2‑colouring.

*Proof.*  
By Lemma&nbsp;1 an edge is stable exactly when its endpoints have different
numbers. Hence all edges are stable exactly when every edge connects vertices
with different numbers, i.e. the numbers constitute a proper 2‑colouring.
A graph admits a proper 2‑colouring iff it is bipartite. ∎



### Lemma 3  
During the processing of a connected component the algorithm assigns colour
`0` to its smallest numbered vertex and colour `1` to all vertices at odd
distance from it, colour `0` to those at even distance. If a conflict is
detected, the component (and therefore the whole graph) is not bipartite.

*Proof.*  
The BFS starts with the smallest vertex `s` and sets `colour[s]=0`.  
Whenever an edge `(x,y)` is traversed, the algorithm forces `colour[y]` to be
`colour[x] xor 1`. This is exactly the definition of a bipartite 2‑colouring.
If later we meet an already coloured neighbour with the same colour,
an odd cycle exists, so the component is not bipartite. ∎



### Lemma 4  
If the algorithm finishes without printing `NO`, the produced sequence
`s_i = 1` if `colour[i]=0` else `2` is a valid assignment.

*Proof.*  
By Lemma&nbsp;3 every component was successfully coloured, therefore the whole
graph is bipartite. The mapping `0 → 1 , 1 → 2` preserves the property that
adjacent vertices have different numbers, so by Lemma&nbsp;2 the assignment is
valid. ∎



### Lemma 5  
Among all valid assignments the algorithm’s assignment is lexicographically
minimal.

*Proof.*  
Consider any connected component `C`. Let `p` be its smallest vertex index.
The algorithm forces `s_p = 1` (because `colour[p]=0`).  
In any valid assignment the two colour classes of `C` can only be swapped,
so either `s_p = 1` or `s_p = 2`. Choosing `s_p = 1` is strictly better for the
lexicographic order, and it does not affect vertices with index `< p`
(because they belong to earlier components).  
Since the algorithm does this for every component, no other valid assignment
can have a smaller value at the first position where they differ. ∎



### Theorem  
The algorithm outputs  

* `NO` iff no valid assignment exists;  
* otherwise `YES` and the lexicographically smallest valid assignment.

*Proof.*  

*If part.*  
If the algorithm prints `NO`, a conflict was found during BFS.
By Lemma&nbsp;3 the corresponding component is not bipartite, therefore by
Lemma&nbsp;2 no valid assignment exists.

*Only‑if part.*  
Assume a valid assignment exists. Then the graph is bipartite
(Lemma&nbsp;2). BFS never meets a colour conflict, so the algorithm never
prints `NO`. By Lemma&nbsp;4 the produced assignment is valid, and by
Lemma&nbsp;5 it is the lexicographically smallest one. ∎



Complexity Analysis
-------------------

*Time* – each vertex and each edge is processed once: `O(n + m)`.

*Memory* – adjacency lists plus colour array: `O(n + m)`.



Reference Implementation (Python 3)
------------------------------------

```python
import sys
from collections import deque

def solve() -> None:
    data = sys.stdin.buffer.read().split()
    if not data:
        return
    it = iter(data)
    n = int(next(it))
    m = int(next(it))

    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(next(it)); v = int(next(it))
        adj[u].append(v)
        adj[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0 or 1 = two sides

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # start a new component, give the smallest vertex colour 0
        colour[start] = 0
        q = deque([start])
        while q:
            v = q.popleft()
            cv = colour[v]
            for to in adj[v]:
                if colour[to] == -1:
                    colour[to] = cv ^ 1
                    q.append(to)
                elif colour[to] == cv:
                    # not bipartite
                    sys.stdout.write("NO")
                    return

    # all components bipartite, build answer
    out = ['YES\n']
    ans = ['1' if colour[i] == 0 else '2' for i in range(1, n + 1)]
    out.append(' '.join(ans))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```

and conforms to the required input‑output format.
