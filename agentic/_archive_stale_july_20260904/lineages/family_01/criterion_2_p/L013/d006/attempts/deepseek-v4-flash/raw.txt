We can model this as a graph coloring problem.  
Let’s analyze the transformations:

- \( M = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix} \) swaps coordinates.
- \( B_1 = (1, -1) \), \( B_2 = (-1, 1) \).

For a link between nodes \(u\) and \(v\), we check stability:

If both use the same transformation, say both use \(T_1\):  
\( f(f(V)) = M(MV + B_1) + B_1 = V + M B_1 + B_1 \).  
Compute \( M B_1 = (-1, 1) \), so \( M B_1 + B_1 = (0,0) \).  
Thus \( f(f(V)) = V \) for all \(V\) → unstable.

If both use \(T_2\):  
\( M B_2 = (1, -1) \), so \( M B_2 + B_2 = (0,0) \) → unstable.

If one uses \(T_1\) and the other \(T_2\):  
\( f_1(f_2(V)) = M(MV + B_2) + B_1 = V + M B_2 + B_1 = V + (1,-1) + (1,-1) = V + (2,-2) \),  
which is never equal to \(V\) → stable.

So:  
- Same transformation → unstable.  
- Different transformations → stable.

Thus the problem reduces to:  
Can we 2-color the graph such that adjacent nodes have different colors?  
That’s exactly checking if the graph is bipartite.

If bipartite, we output the lexicographically smallest coloring (with 1 and 2).  
Lexicographically smallest means we try to assign 1 to node 1 if possible, then propagate.

We can do BFS/DFS with color assignment, preferring 1 when possible.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 1
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
