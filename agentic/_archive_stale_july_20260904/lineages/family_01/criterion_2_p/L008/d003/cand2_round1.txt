<STATEMENT>
# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A factory employs $n$ workers, with $m$ synchronization links established among them. You must assign a shift code $s_i \in \{1, 2\}$ to each worker $i$. 

To maintain proper timing, the factory must pass a global synchronization check. For each synchronization link connecting a pair of workers $u$ and $v$, the system computes their combined load, which is defined as the sum $s_u + s_v$. The factory's total load metric is the product of the combined loads of all $m$ synchronization links. (If there are no links, i.e., $m=0$, the total load metric is defined as 1).

Determine if there is a valid assignment of shift codes for all workers such that the factory's total load metric is exactly $3^m$.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers connected by a synchronization link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \ldots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The explicit sequence `[1, 2, 1]` allowed models to immediately extract the valid pairs `(1, 2)` and `(2, 1)`, bypassing any need to derive the conflict condition. I replaced this with a global constraint where the product of `(s_u + s_v)` over all $m$ links must equal $3^m$. Because $s_i \in \{1, 2\}$, the sum $s_u + s_v \in \{2, 3, 4\}$. By prime factorization, a product of these sums can only equal $3^m$ if every individual sum is exactly 3. This forces the models to first deduce the local constraint ($s_u \neq s_v$) from the global product before they can recognize the underlying bipartite graph structure.
</RATIONALE>
<PRESERVED_ANSWER>
Since $s_i \in \{1, 2\}$, the sum $s_u + s_v$ is in $\{2, 3, 4\}$, and the only way their product over $m$ links can be exactly $3^m$ is if every single link has a sum of 3, which is mathematically identical to requiring $s_u \neq s_v$ for every link just as in the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to checking if a graph is bipartite (2-colorable) and finding the lexicographically smallest coloring, which is solvable in $O(n + m)$ time using BFS.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the empty product for $m=0$, but the explicit parenthetical `(If there are no links, i.e., m=0, the total load metric is defined as 1)` completely removes this ambiguity.
</RISK>
