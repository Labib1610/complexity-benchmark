# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

There are $n$ workers in a factory, and $m$ synchronization links between them. Each worker $i$ must be assigned a shift code $s_i \in \{1, 2\}$. For every synchronization link between a pair of workers $u$ and $v$, their assigned shift codes must satisfy the condition that the greatest common divisor of $(s_u + 1)$ and $(s_v + 1)$ is exactly 1. 

Given these conditions, assign each worker a shift code, or report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers connected by a synchronization link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \ldots s_n$ (each in $\{1,2\}$), the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The suggested removal of adding a global subset-sum constraint was rejected because it would change the valid answers for many inputs (violating Hard Constraint 1) and make the problem NP-complete (violating Hard Constraint 3). Instead, the affordance "the sum of their assigned shift codes must be exactly 3" was removed. It was replaced with a mathematically equivalent local constraint using the greatest common divisor, which forces models to logically deduce the $s_u \neq s_v$ relationship rather than pattern-matching on basic arithmetic inversion.
</RATIONALE>
<PRESERVED_ANSWER>
For $s \in \{1, 2\}$, $s+1 \in \{2, 3\}$, and $\gcd(s_u+1, s_v+1)=1$ is true if and only if one code is 1 and the other is 2, preserving the exact same valid assignments as the seed.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly 2-coloring / bipartiteness testing, solvable in O(n+m) time using BFS, keeping it in P.
</PRESERVED_CLASS>
