<STATEMENT>
# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A factory employs $n$ workers, with $m$ synchronization links established among them. You must assign a shift code $s_i \in \{1, 2\}$ to each worker $i$. 

To maintain proper timing, every synchronization link connecting a pair of workers $u$ and $v$ requires that the two-element sequence $[s_u, s_v]$ forms a contiguous subarray of the reference sequence $[1, 2, 1]$.

Determine if there is a valid assignment of shift codes for all workers.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers connected by a synchronization link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \ldots s_n$ (each in $\{1,2\}$), representing the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The previous version used the condition "the sum of their assigned shift codes must be exactly 3", which models trivially pattern-matched to graph 2-coloring. The suggested removal (adding a global subset-sum constraint) was ignored because it would change the problem's complexity to NP-complete and alter valid outputs, violating the hard constraints. Instead, the local constraint was rewritten to require that the sequence of the two shift codes forms a contiguous subarray of `[1, 2, 1]`. This forces the model to evaluate the valid subsegments (`[1, 2]` and `[2, 1]`) to deduce that adjacent workers must have different shifts, breaking the immediate pattern match while preserving the exact same logic.
</RATIONALE>
<PRESERVED_ANSWER>
The contiguous subarrays of length 2 in `[1, 2, 1]` are exactly `[1, 2]` and `[2, 1]`, which precisely enforces that $s_u \neq s_v$ for $s_i \in \{1, 2\}$, making it logically identical to the original "sum is 3" constraint and preserving all valid assignments.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The core problem remains identical to 2-coloring a graph (checking bipartiteness), which is solvable in O(n+m) time using Breadth-First Search, keeping it strictly in P.
</PRESERVED_CLASS>
