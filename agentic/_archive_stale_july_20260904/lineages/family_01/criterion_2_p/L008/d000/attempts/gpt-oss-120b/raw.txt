**Solution Explanation**

For every worker we have to choose one of two shifts `1` or `2`.
Conflicting workers must obtain different shifts.
The conflict graph is therefore required to be *bipartite*.
If it is not bipartite the answer is `NO`.

If the graph is bipartite there are two possible colourings for each
connected component – they are obtained from each other by swapping the
two colours.
Among all valid colourings we have to output the *lexicographically
smallest* sequence  
` s1 s2 … sn ` ( `1 < 2` ).

--------------------------------------------------------------------

#### 1.   Observations  

* In a connected component the two colourings differ only by a global
  swap of the two colours.
* The first vertex (smallest index) belonging to a component decides the
  lexicographic order for this component:
  giving it colour `1` is always better than giving it colour `2`,
  and any other choice would make the whole answer larger.
* While scanning the vertices `1 … n` the first not‑yet‑coloured vertex
  of a component is exactly its smallest index.

Therefore we can colour each component **once**, starting the BFS/DFS
from its smallest vertex and give this start vertex colour `0`
(shift `1`).  
All other vertices of the component receive the only possible colours
compatible with it, and the whole assignment is the lexicographically
smallest one.

--------------------------------------------------------------------

#### 2.   Algorithm
```
read n, m
build adjacency list G[1…n]

colour[1…n] = -1          # -1 = not visited yet
for v = 1 … n:
    if colour[v] == -1:               # new component, v is its smallest vertex
        colour[v] = 0                 # shift 1
        queue = [v]
        while queue not empty:
            x = pop queue
            for each neighbour y of x:
                if colour[y] == -1:
                    colour[y] = colour[x] ^ 1
                    push y into queue
                else if colour[y] == colour[x]:
                    print "NO" and exit   # odd cycle → not bipartite

print "YES"
output (colour[i] + 1) for i = 1 … n
```

--------------------------------------------------------------------

#### 3.   Correctness Proof  

We prove that the algorithm prints `NO` iff no feasible assignment exists,
otherwise it prints `YES` and the lexicographically smallest feasible
assignment.

---

##### Lemma 1  
During the BFS of a component the algorithm assigns colours `0/1` that
satisfy all already processed edges.

**Proof.**  
The start vertex receives colour `0`.  
Whenever an edge `(x, y)` is examined:
* if `y` is uncoloured, we set `colour[y] = colour[x] xor 1`, guaranteeing
  different colours on the edge,
* if `y` is already coloured, the algorithm checks that the colours differ.
  If they are equal we abort (see Lemma 2). ∎



##### Lemma 2  
If the algorithm aborts with `NO`, the conflict graph is not bipartite,
hence no feasible assignment exists.

**Proof.**  
The abort happens exactly when an edge `(x, y)` with
`colour[x] == colour[y]` is found.
All previously coloured vertices respect the bipartite condition
(Lemma 1). Adding the edge creates an odd cycle, therefore the whole graph
cannot be 2‑coloured. ∎



##### Lemma 3  
If the algorithm finishes without abort, the produced assignment
(colour + 1) is a feasible shift assignment.

**Proof.**  
All edges were examined. By Lemma 1 each edge connects vertices of
different colours, therefore after adding `1` the two shifts are different.
∎



##### Lemma 4  
For every connected component the algorithm gives shift `1` to its
smallest‑indexed vertex.

**Proof.**  
The outer loop processes vertices in increasing order.
When the first vertex `v` of a component is encountered, it is still
uncoloured, so a new BFS starts with `colour[v] = 0`.  
All later vertices of the same component are coloured inside this BFS,
hence `v` keeps colour `0` → shift `1`. ∎



##### Lemma 5  
Among all feasible assignments the one produced by the algorithm is
lexicographically smallest.

**Proof.**  
Consider the vertices from `1` to `n`.  
Let `i` be the first index where the algorithm’s assignment could differ
from another feasible assignment `A`.  
Vertex `i` belongs to some component `C`.  
By Lemma 4 the algorithm gives shift `1` to `i`.  
Any feasible assignment must give either `1` or `2` to `i`.  
If it gives `2`, the algorithm is already lexicographically smaller.
If it gives `1`, then the whole colour pattern inside `C` must be identical
to the algorithm’s (the only other possible pattern would swap the two
shifts and would give `2` to `i`).  
Thus no feasible assignment can be lexicographically smaller. ∎



##### Theorem  
The algorithm outputs  

* `NO` **iff** the conflict graph is not bipartite (no feasible shift
  assignment exists);
* otherwise `YES` followed by the lexicographically smallest feasible
  assignment.

**Proof.**  
*If part*: If the algorithm prints `NO`, by Lemma 2 the graph is not
bipartite, hence no assignment exists.  

*Only‑if part*: If the graph is not bipartite, any 2‑colouring attempt
must encounter an edge whose ends already have the same colour, causing
the algorithm to abort and print `NO`.  

If the graph is bipartite, the algorithm never aborts, produces a feasible
assignment (Lemma 3) and this assignment is lexicographically smallest
(Lemma 5). ∎



--------------------------------------------------------------------

#### 4.   Complexity Analysis  

*Building adjacency list*: `O(n + m)` memory and time.  
*BFS over all components*: each vertex and each edge is processed once,
`O(n + m)` time.  

Total time `O(n + m) ≤ 4·10⁵`, well inside the 1 s limit.  
Memory consumption `O(n + m)` (adjacency list and colour array), below
256 MB.

#### 5.   Reference Implementation  (Python 3)

```python
import sys
from collections import deque

def solve() -> None:
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    it = iter(data)
    n = next(it)
    m = next(it)

    g = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = next(it)
        v = next(it)
        g[u].append(v)
        g[v].append(u)

    colour = [-1] * (n + 1)          # -1 = unvisited, 0/1 = temporary colours

    for start in range(1, n + 1):
        if colour[start] != -1:
            continue
        # start is the smallest vertex of its component
        colour[start] = 0
        q = deque([start])
        while q:
            x = q.popleft()
            cx = colour[x]
            for y in g[x]:
                if colour[y] == -1:
                    colour[y] = cx ^ 1
                    q.append(y)
                elif colour[y] == cx:
                    # not bipartite
                    sys.stdout.write("NO")
                    return

    # feasible, produce lexicographically smallest assignment
    out = ['YES\n']
    shifts = [str(colour[i] + 1) for i in range(1, n + 1)]
    out.append(' '.join(shifts))
    sys.stdout.write('\n'.join(out))

if __name__ == "__main__":
    solve()
```
