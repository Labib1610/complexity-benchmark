# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

There are $n$ workers in a factory, and $m$ synchronization links between them. Each worker must be assigned a shift code, which is either 1 or 2. For every synchronization link between a pair of workers, the sum of their assigned shift codes must be exactly 3. 

Given these conditions, assign each worker a shift code, or report impossibility.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers connected by a synchronization link.

## Output
If no valid assignment exists, print a single line NO.
Otherwise print YES, then a second line with $n$ integers $s_1 \ldots s_n$ (each in $\{1,2\}$), the lexicographically smallest valid assignment.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Replaced the direct "conflict" and "not share" wording with an algebraic constraint (sum equals 3) over the same domain {1, 2}. This removes the obvious graph-coloring affordances, forcing models to deduce that the sum condition on these specific values is equivalent to an inequality constraint before they can apply a bipartite checking algorithm.
</RATIONALE>
<PRESERVED_ANSWER>
The condition that two variables from {1, 2} sum to 3 is mathematically identical to requiring them to be different, so the set of valid assignments and the lexicographically smallest valid sequence are exactly the same.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding a 2-coloring of an undirected graph, which is verifiable and solvable in linear time (P) using BFS or DFS.
</PRESERVED_CLASS>
