We can model this as a bipartite graph problem: each edge requires the two endpoints to have different shift codes (since 1+2=3). So we need to check if the graph is bipartite and assign colors accordingly, with 1 and 2 as the two colors.

To get the lexicographically smallest assignment, we should try to assign 1 to as many early-indexed nodes as possible. This means we should start BFS/DFS from each unvisited node in increasing index order, and assign the starting node color 1.

```python
from collections import deque
import sys

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(c) for c in color))
```
