Let me analyze the resonance equation: $2(s_u^2 + s_v^2) = 5 \cdot s_u \cdot s_v$

For $s_u = s_v = 1$: $2(1+1) = 4 \neq 5$. Not stable.
For $s_u = s_v = 2$: $2(4+4) = 16 \neq 20$. Not stable.
For $s_u = 1, s_v = 2$: $2(1+4) = 10 = 5 \cdot 2 = 10$. Stable!

So connected workers must have different shift codes. This is a bipartite graph check.

To minimize the structural weight $\sum s_i \cdot 3^{n-i}$, we want earlier positions (higher weight) to have value 1. So for each connected component, we try assigning 1 to the node that appears earliest (smallest index), and 2 to its neighbors, etc. If this causes a conflict, we try the other way. If both fail, it's not bipartite.

```python
import sys
from sys import stdin

def solve():
    input_data = stdin.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n+1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n+1)
    
    for start in range(1, n+1):
        if color[start] != 0:
            continue
        # Try coloring start with 1
        color[start] = 1
        stack = [start]
        ok = True
        order = [start]
        while stack and ok:
            u = stack.pop()
            for v in adj[u]:
                if color[v] == 0:
                    color[v] = 3 - color[u]
                    stack.append(v)
                    order.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break
        
        if ok:
            continue
        
        # Reset and try coloring start with 2
        for node in order:
            color[node] = 0
        color[start] = 2
        stack = [start]
        ok = True
        while stack and ok:
            u = stack.pop()
            for v in adj[u]:
                if color[v] == 0:
                    color[v] = 3 - color[u]
                    stack.append(v)
                elif color[v] == color[u]:
                    ok = False
                    break
        
        if not ok:
            print("NO")
            return
    
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n+1)))

solve()
```
