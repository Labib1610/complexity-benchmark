We can treat this as a graph coloring problem.  
The resonance equation:

\[
2(s_u^2 + s_v^2) = 5 s_u s_v
\]

For \(s_u, s_v \in \{1,2\}\), check:

- If both are 1: \(2(1+1)=4\), \(5\cdot1=5\) → not equal.
- If both are 2: \(2(4+4)=16\), \(5\cdot4=20\) → not equal.
- If one is 1 and the other is 2: \(2(1+4)=10\), \(5\cdot2=10\) → equal.

So the only stable links are between workers with different shift codes.  
Thus, the graph must be bipartite. If it is, we can color it with 1 and 2.

We also need the lexicographically smallest sequence in the given weight sense.  
Since \(3^{n-i}\) is huge, the smallest weight means we want the earliest positions to be as small as possible.  
So we should try to assign 1 to as many early nodes as possible, but still keep bipartiteness.

We can do a BFS/DFS coloring, but when we have a choice (unvisited node), we assign 1 first, then propagate.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 1
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 3 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
