import sys

# The resonance equation is 2(s_u^2 + s_v^2) = 5 * s_u * s_v
# Given s_i in {1, 2}:
# If s_u = 1, s_v = 1: 2(1+1) = 4, 5(1*1) = 5. 4 != 5.
# If s_u = 1, s_v = 2: 2(1+4) = 10, 5(1*2) = 10. 10 == 10. (Valid)
# If s_u = 2, s_v = 1: 2(4+1) = 10, 5(2*1) = 10. 10 == 10. (Valid)
# If s_u = 2, s_v = 2: 2(4+4) = 16, 5(2*2) = 20. 16 != 20.
# Thus, for every edge (u, v), s_u must be different from s_v.
# This means the graph must be bipartite.
# To minimize sum(s_i * 3^(n-i)), we want s_i = 1 whenever possible.
# For each connected component, we have two possible colorings (1, 2) or (2, 1).
# We choose the one that makes the first node in the component 1 if possible.
# Actually, to minimize the sum, we greedily pick s_i = 1 for the smallest index i
# in each component.
