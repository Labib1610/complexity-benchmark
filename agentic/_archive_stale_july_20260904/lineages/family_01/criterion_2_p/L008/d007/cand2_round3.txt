# Problem B — Harmonic Resonance

Time limit: 1 s   Memory limit: 256 MB

A factory employs $n$ workers, with $m$ synchronization links established among them. You must assign a shift code $s_i \in \{1, 2\}$ to each worker $i$. 

To maintain proper timing, the machines of connected workers must resonate at compatible frequencies. A synchronization link between two workers $u$ and $v$ is stable if and only if the resonance matrix 
$$R_{u,v} = \begin{pmatrix} s_u & 1 & 0 \\ 1 & s_v & 1 \\ 0 & 1 & s_u \end{pmatrix}$$
is singular (i.e., its determinant is exactly zero).

Determine if there is a valid assignment of shift codes for all workers such that every synchronization link is stable.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers connected by a synchronization link.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1,2\}$) representing the valid assignment. If there are multiple valid assignments, output the one that minimizes the structural weight of the sequence, defined as $\sum_{i=1}^n s_i \cdot 3^{n-i}$. Print this assignment as a full sequence of $n$ integers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I removed the "harmonic buildup" cycle condition, which was mathematically redundant but acted as a massive semantic hint for bipartiteness (stating that cycles must have equal numbers of 1s and 2s). I also replaced the specific 2x2 matrix trace condition with a 3x3 matrix singularity condition. This forces models to independently evaluate the determinant to discover the local $s_u \neq s_v$ constraint, and then independently deduce the bipartite nature of the problem without any global structural hints.
</RATIONALE>
<PRESERVED_ANSWER>
The determinant of the 3x3 matrix is $s_u(s_u s_v - 2)$, which is zero for $s_i \in \{1, 2\}$ if and only if $s_u \neq s_v$; this perfectly matches the seed's edge constraint and naturally rejects self-loops, while the deleted cycle condition was strictly redundant for any valid 2-coloring.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly Lexicographically Smallest 2-Coloring, which is solvable in linear time using BFS, preserving the P complexity class.
</PRESERVED_CLASS>
