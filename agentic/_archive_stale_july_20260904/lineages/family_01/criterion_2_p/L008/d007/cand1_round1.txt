<STATEMENT>
# Problem B — Harmonic Resonance

Time limit: 1 s   Memory limit: 256 MB

A factory employs $n$ workers, with $m$ synchronization links established among them. You must assign a shift code $s_i \in \{1, 2\}$ to each worker $i$. 

To maintain proper timing, the machines of connected workers must resonate at compatible frequencies. A synchronization link between two workers $u$ and $v$ is stable if and only if the complex number $(s_u + s_v i)^4$ has a real part equal to $-7$, where $i$ is the imaginary unit.

Additionally, to prevent harmonic buildup, any valid assignment must satisfy a geometric balance condition for every simple cycle in the network. Specifically, if a simple cycle consists of $k$ workers $v_1, v_2, \dots, v_k$ in order, the 2D points with polar coordinates $(r, \theta) = (s_{v_j}, \frac{2\pi j}{k})$ for $j=1, 2, \dots, k$ must have their centroid (center of mass) exactly at the origin $(0,0)$.

Determine if there is a valid assignment of shift codes for all workers such that every synchronization link is stable and the harmonic buildup condition is satisfied.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers connected by a synchronization link.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1,2\}$) representing the valid assignment. If there are multiple valid assignments, output the one that minimizes the tuning coefficient of the sequence, defined as $\sum_{i=1}^n s_i \cdot 3^{n-i}$. Print this assignment as a full sequence of $n$ integers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The edge condition was replaced with a complex arithmetic identity evaluated at $(s_u + s_v i)^4$. Since $s_i \in \{1, 2\}$, the real part is $-7$ if and only if $s_u \neq s_v$, perfectly preserving the 2-coloring requirement. The cycle condition was replaced with a geometric centroid requirement in polar coordinates; mathematically, the centroid of any alternating sequence of length $\ge 4$ mapped to these polar coordinates is exactly $(0,0)$. This makes the cycle condition a vacuous truth for any valid assignment, just like the original, but prevents models from recognizing it as a standard bipartite property.
</RATIONALE>
<PRESERVED_ANSWER>
The complex equation strictly enforces $s_u \neq s_v$ on all edges, and the geometric centroid condition is mathematically guaranteed to be satisfied by any alternating sequence on an even cycle, meaning the set of valid assignments is completely identical to the original problem.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem still reduces to finding the lexicographically smallest proper 2-coloring of a graph, which is solvable in $O(n+m)$ using a greedy Breadth-First Search, keeping it firmly in P.
</PRESERVED_CLASS>
<RISK>
Models might struggle to correctly parse the mathematical notation of polar coordinates, but the definition $(r, \theta) = (s_{v_j}, \frac{2\pi j}{k})$ is standard and unambiguous.
</RISK>
