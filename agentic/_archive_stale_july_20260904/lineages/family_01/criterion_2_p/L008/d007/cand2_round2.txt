# Problem B — Harmonic Resonance

Time limit: 1 s   Memory limit: 256 MB

A factory employs $n$ workers, with $m$ synchronization links established among them. You must assign a shift code $s_i \in \{1, 2\}$ to each worker $i$. 

To maintain proper timing, the scheduling must satisfy a local balance condition for every worker. Specifically, for any worker $i$, let $d_i$ be the number of synchronization links connected to them. The sum of the shift codes of all workers directly connected to worker $i$ must be exactly equal to $d_i \times (3 - s_i)$.

Additionally, to prevent harmonic buildup, any valid assignment must ensure that in every simple cycle within the factory's synchronization network, the product of the shift codes of all workers in that cycle is exactly $2^{k/2}$, where $k$ is the number of workers in the cycle.

Determine if there is a valid assignment of shift codes for all workers such that the local balance condition is satisfied for every worker and the harmonic buildup condition holds.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers connected by a synchronization link.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1,2\}$) representing the valid assignment. If there are multiple valid assignments, output the one that minimizes the structural weight of the sequence, defined as $\sum_{i=1}^n s_i \cdot 3^{n-i}$. Print this assignment as a full sequence of $n$ integers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the validity condition from a matrix trace to a local neighborhood sum requirement, and disguised the cycle parity condition as a product requirement. This forces the model to mathematically deduce that the local sum bounds exactly restrict the graph to a proper 2-coloring, rather than relying on explicit pairwise inequality cues.
</RATIONALE>
<PRESERVED_ANSWER>
The local sum condition mathematically forces all neighbors of a worker to have the opposite shift code, making it strictly equivalent to proper 2-coloring, while the cycle product condition is a redundant property of all bipartite graphs.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to finding the lexicographically smallest 2-coloring of a graph, which is solvable in O(n + m) time using BFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
Models might misinterpret the cycle product condition as implying $k$ must always be even, but since valid assignments only exist for bipartite graphs (which exclusively have even cycles), this does not introduce any ambiguity.
</RISK>
