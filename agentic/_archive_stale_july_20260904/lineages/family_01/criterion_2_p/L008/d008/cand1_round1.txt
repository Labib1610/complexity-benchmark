<METHOD_NAME>Global Algebraic Constraint & Polynomial Tie-Breaker</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces pairwise inequality constraints with a single global quadratic equation that mathematically forces all pairs to be unequal due to the domain bounds. Replaces the lexicographical tie-breaker with polynomial evaluation at x=2, which strictly preserves the ordering without using string/sequence terminology.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Quadratic System

Time limit: 1 s   Memory limit: 256 MB

You are given a system of $n$ discrete variables $s_1, s_2, \ldots, s_n$. You must assign a value $s_i \in \{1, 2\}$ to each variable.

You are also given $m$ pairs of variable indices $(u_j, v_j)$ for $j = 1, \ldots, m$. 
Your task is to determine if there exists an assignment for the variables that satisfies the following global equation:
$$ \sum_{j=1}^m (s_{u_j} - s_{v_j})^2 = m $$

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u_j$ and $v_j$ ($1 \le u_j, v_j \le n$) — the indices of the variables in the $j$-th pair.

## Output
If no such assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ representing the valid assignment. If there are multiple valid assignments, output the one that minimizes the value of $P(2)$, where $P(x)$ is the polynomial defined as $P(x) = \sum_{i=1}^n s_i x^{n-i}$.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The graph-coloring semantics have been replaced with a single global quadratic equation. Because $s_i \in \{1, 2\}$, the maximum value of $(s_u - s_v)^2$ is 1, so the sum can only equal $m$ if every single pair evaluates to 1, completely forcing $s_u \neq s_v$. The lexicographical tie-breaker is replaced by evaluating a base-2 polynomial, which is mathematically identical in its strict ordering but avoids string terminology. This forces the model to algebraically deduce the bipartite nature and the positional tie-breaker rather than relying on pattern matching.
</RATIONALE>
<PRESERVED_ANSWER>
The maximum possible value of $(s_u - s_v)^2$ is 1, so the sum reaches $m$ if and only if $s_{u_j} \neq s_{v_j}$ for all $m$ pairs, which is exactly the original unequal-shift condition; furthermore, minimizing a base-2 polynomial with coefficients in {1, 2} perfectly and uniquely matches lexicographical ordering.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains exactly equivalent to 2-coloring / bipartiteness testing on a graph with $n$ vertices and $m$ edges, which is solvable in O(n+m) time using BFS/DFS.
</PRESERVED_CLASS>
