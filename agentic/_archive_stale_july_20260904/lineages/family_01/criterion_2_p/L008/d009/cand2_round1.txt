# Problem B — Harmonic Resonance

Time limit: 1 s   Memory limit: 256 MB

A facility operates $n$ resonance generators, with $m$ interference testing links established between specific pairs of generators. You must configure each generator $i$ by assigning it a state $s_i \in \{1, 2\}$. 

To maintain system stability, the global configuration must satisfy a specific energy balance equation. Let $d_i$ be the number of links connected to generator $i$. We define the total node potential $W$ as:
$$W = \sum_{i=1}^n d_i (s_i - 3)^2$$

Additionally, we define the total interaction energy $P$ as the sum of the products of the states of the two connected generators across all $m$ links. That is, for every link connecting some generator $u$ and generator $v$, we compute $s_u \times s_v$, and $P$ is the sum of these $m$ values.

The system is in a balanced state if and only if the following equation holds exactly:
$$W + 2P = 9m$$

Determine if there is a valid configuration for all generators such that the system is balanced. 

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of generators connected by an interference testing link.

## Output
If no valid configuration exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1,2\}$) representing the valid configuration. If there are multiple valid configurations, output the lexicographically smallest sequence $s_1, s_2, \ldots, s_n$. (Lexicographic order compares $s_1$, then $s_2$, etc.)

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
The edge-wise 2-coloring constraint ($s_u \neq s_v$) was algebraically encoded into a single global quadratic equation $W + 2P = 9m$. By expanding and regrouping the terms from nodes to edges, this equation is mathematically equivalent to $\sum_{e} (s_u + s_v - 3)^2 = 0$. Because it is presented as a global energy balance involving node degrees and a sum of products, it masks the local bipartite structure, forcing the model to either perform a non-trivial algebraic factorization or mistakenly treat it as a hard global optimization problem.
</RATIONALE>
<PRESERVED_ANSWER>
The global equation simplifies exactly to $\sum (s_u + s_v - 3)^2 = 0$, which for $s_i \in \{1, 2\}$ strictly enforces $s_u \neq s_v$ for every link, making the set of valid configurations identical to the seed problem's valid 2-colorings.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem remains equivalent to bipartite graph checking and 2-coloring, which is solvable in linear time O(n+m) using BFS or DFS.
</PRESERVED_CLASS>
