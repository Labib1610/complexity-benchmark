For generators with states $s_u, s_v$:
- State 1: $c_1 = 1+i$
- State 2: $c_2 = 1-i$

Product of two signatures:
- (1,1): $(1+i)^2 = 2i$, imaginary part = 2
- (1,2): $(1+i)(1-i) = 2$, imaginary part = 0
- (2,1): same as (1,2), imaginary part = 0
- (2,2): $(1-i)^2 = -2i$, imaginary part = -2

So for each edge, the imaginary part is:
- 2 if both states are 1
- -2 if both states are 2
- 0 if states differ

The footprint is the sum of squares: $\sum (\text{imag})^2$. For this to be 0, each imaginary part must be 0, meaning every edge must connect generators of different states.

This is exactly a bipartiteness check! The graph must be 2-colorable.

For the lexicographically smallest assignment, we need to assign states greedily. Since state 1 < state 2, we want to assign state 1 whenever possible. Using BFS/DFS, when we visit a node, assign it the smallest state consistent with its already-assigned neighbors.

Let me think about the greedy approach more carefully. We process nodes in order 1 to n. For each unassigned node, assign it state 1, then propagate constraints via BFS/DFS (neighbors get state 2, their neighbors get state 1, etc.). If a conflict is found, output NO.

Wait, but we need to be careful: assigning node $i$ to state 1 might force some node $j > i$ to state 2, but maybe assigning node $i$ to state 2 would allow node $j$ to be state 1. However, since we want lexicographically smallest and we process in order, assigning the current node to the smallest valid state is correct — we only backtrack if there's no valid coloring at all (bipartiteness violation), not for optimization.

Actually, the key insight: if the graph is bipartite, there are exactly 2 valid colorings per connected component (swap 1↔2). For lexicographically smallest, in each component, we want the first-visited node to be state 1. Processing nodes 1..n in order, when we find an unvisited node, we start a BFS/DFS from it, assign it state 1, and alternate. This gives the lexicographically smallest result because:
- The first node in each component (smallest index) gets state 1
- All other nodes' states are determined by parity of distance

This is optimal because the first node in each component must be either 1 or 2, and 1 is smaller. Once it's fixed, everything else in the component is determined.

import sys
from collections import deque

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u = int(input_data[idx]) - 1; idx += 1
        v = int(input_data[idx]) - 1; idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n  # 0 = unassigned, 1 = state 1, 2 = state 2
    
    for start in range(n):
        if color[start] != 0:
            continue
        color[start] = 1
        queue = deque([start])
        while queue:
            u = queue.popleft()
            for v in adj[u]:
                if color[v] == 0:
                    color[v] = 3 - color[u]
                    queue.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    return
    
    print("YES")
    print(' '.join(str(color[i]) for i in range(n)))

solve()
