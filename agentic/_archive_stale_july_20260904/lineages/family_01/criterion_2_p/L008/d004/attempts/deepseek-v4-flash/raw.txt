We can model this as a bipartite graph problem.  

Each worker gets shift code 1 or 2.  
The compatibility condition means:  
- If worker `u` has shift 1 (primary 5, secondary 10) and worker `v` has shift 2 (primary 10, secondary 5), then `u`'s primary (5) matches `v`'s secondary (5), and `v`'s primary (10) matches `u`'s secondary (10).  
- If both have the same shift, the teeth counts won’t match (5 vs 10 or 10 vs 5).  

So each edge must connect workers of different shift codes.  
That means the graph must be bipartite.  

We can solve with BFS/DFS coloring, assigning 1 or 2.  
For lexicographically smallest, we try to assign 1 whenever possible during traversal.  

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
