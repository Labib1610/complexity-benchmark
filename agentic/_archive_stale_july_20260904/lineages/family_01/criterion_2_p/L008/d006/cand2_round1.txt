<METHOD_NAME>Geometric Linear Independence</METHOD_NAME>
<METHOD_DESCRIPTION>Replaces the algebraic equality with a condition that 2D phase vectors (s_i, s_i^2) of connected endpoints must be linearly independent. Since the domain is {1, 2}, this evaluates to true if and only if s_u != s_v. This defeats survivors by forcing them to geometrically analyze the vectors instead of recognizing a simple bipartite coloring inequality.</METHOD_DESCRIPTION>

<STATEMENT>
# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A factory employs $n$ workers, with $m$ synchronization links established among them. You must assign a shift code $s_i \in \{1, 2\}$ to each worker $i$.

Each worker's shift code determines their phase vector, defined as $\vec{p}_i = (s_i, s_i^2)$. 
A synchronization link between two workers $u$ and $v$ is only stable if their phase vectors are linearly independent. In other words, the triangle formed by the origin $(0,0)$, $\vec{p}_u$, and $\vec{p}_v$ must have a strictly positive area.

Determine if there is a valid assignment of shift codes for all workers such that every synchronization link in the factory is stable.

## Input
The first line contains two integers $n$ and $m$. The total number of workers $n$ is at least 1 and does not exceed the number of seconds in a continuous duration of 55 hours, 33 minutes, and 20 seconds. The number of links $m$ can be as low as zero and is capped at the exact same maximum limit.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers connected by a synchronization link.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1,2\}$) representing the valid assignment. If there are multiple valid assignments, output the one that minimizes the characteristic sum of the sequence, defined as $\sum_{i=1}^n s_i \cdot 3^{n-i}$. Print this assignment as a full sequence of $n$ integers separated by spaces.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
</STATEMENT>
<RATIONALE>
Changed the stability condition from an explicit algebraic equation to a geometric linear independence check on 2D vectors $(s_i, s_i^2)$. This forces the model to deduce that the area of the triangle is non-zero if and only if $s_u \neq s_v$, preventing simple pattern matching to bipartite coloring. Also restated the numeric bounds using a time conversion to satisfy the indirection strategy.
</RATIONALE>
<PRESERVED_ANSWER>
Because the vectors $(1,1)$ and $(2,4)$ are linearly independent while identical vectors are linearly dependent, the geometric condition is exactly equivalent to $s_u \neq s_v$, so all valid assignments and the tie-breaking metric remain identical.
</PRESERVED_ANSWER>
<PRESERVED_CLASS>
The problem is still equivalent to checking whether a graph is bipartite (2-colorable), which is solvable in linear time using BFS or DFS, keeping it in P.
</PRESERVED_CLASS>
<RISK>
The phrase "strictly positive area" might be interpreted as requiring a specific orientation (signed area), but "area of the triangle" conventionally refers to the absolute area, so it should remain unambiguous.
</RISK>
