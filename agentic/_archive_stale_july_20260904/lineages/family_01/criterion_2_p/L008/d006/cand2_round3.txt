<STATEMENT>
# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A factory employs $n$ workers, with $m$ synchronization links established among them. The facility's safety regulations allow a minimum of 1 worker and a maximum of 200,000 workers. The communication infrastructure supports anywhere from 0 up to 200,000 synchronization links.

You must assign a shift code $s_i \in \{1, 2\}$ to each worker $i$.

To maintain proper timing, the machines of connected workers must resonate at compatible frequencies. A synchronization link between two workers $u$ and $v$ is only stable if a rectangle constructed with side lengths $s_u$ and $s_v$ has a perimeter of exactly 6.

Determine if there is a valid assignment of shift codes for all workers such that every synchronization link in the factory is stable.

## Input
The first line contains the two integers $n$ and $m$.
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers connected by a synchronization link.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1,2\}$) representing the valid assignment. If there are multiple valid assignments, output the one that minimizes the structural weight of the sequence, defined as $\sum_{i=1}^n s_i \cdot 3^{n-i}$. Print this assignment as a full sequence of $n$ integers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

I replaced the bare numeric bounds with text describing the minimum and maximum allowed workers and links, implementing S07. I also replaced the direct algebraic resonance equation with a geometric condition (the perimeter of a rectangle with sides $s_u$ and $s_v$ equals 6), which evaluates to $s_u \neq s_v$ over the domain {1, 2}. This forces models to logically deduce the structural constraint rather than pattern-match an explicit equation to 2-coloring.
</RATIONALE>
<PRESERVED_ANSWER>
Over the domain {1, 2}, a rectangle with side lengths $s_u$ and $s_v$ has a perimeter of 6 if and only if one side is 1 and the other is 2, perfectly preserving the original $s_u \neq s_v$ constraint and all original answers.
</PRESERVED_ANSWER>
