# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A manufacturing facility operates with $n$ workers. Throughout the facility, there are $m$ communication tethers, each linking a specific pair of workers. Your task is to allocate a shift ID $s_i \in \{1, 2\}$ to every worker $i$.

To ensure operations run smoothly, any two workers connected by a tether must have harmonized shift IDs. Specifically, a tether between worker $u$ and worker $v$ is harmonized if and only if their assigned shift IDs satisfy the following exponential condition:
$$ s_u^{s_v} + s_v^{s_u} = 3 $$

You must determine whether it is possible to assign a shift ID to every worker in such a way that all $m$ communication tethers in the facility are harmonized.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the subsequent $m$ lines provides two integers $u$ and $v$ ($1 \le u, v \le n$, $u \ne v$), identifying a pair of workers connected by a tether.

## Output
If no such valid assignment of shift IDs can be found, output `NO` on a single line.
If a valid assignment exists, output `YES` on the first line. On the second line, output $n$ space-separated integers $s_1, s_2, \ldots, s_n$ (where each $s_i \in \{1, 2\}$) representing the shift ID for each worker. If multiple valid assignments are possible, you must output the one that minimizes the sequence's structural weight, which is calculated as $\sum_{i=1}^n s_i \cdot 3^{n-i}$. Print this assignment as a full sequence of $n$ integers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
