<STATEMENT>
# Problem B — Day and Night

Time limit: 1 s   Memory limit: 256 MB

A factory employs $n$ workers, with $m$ synchronization links established among them. You must assign a shift code $s_i \in \{1, 2\}$ to each worker $i$.

The factory uses a geometric calibration system for its machinery. When two workers $u$ and $v$ are connected by a synchronization link, their machines combine to form a regular polygon in the Euclidean plane with $s_u + s_v$ sides. A synchronization link is only stable if the resulting regular polygon has an interior angle of exactly $60^\circ$. (Note that a valid polygon in the Euclidean plane must have at least 3 sides).

Determine if there is a valid assignment of shift codes for all workers such that every synchronization link in the factory is stable.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$).
Each of the next $m$ lines contains two integers $u$ and $v$ — a pair of workers connected by a synchronization link.

## Output
If no valid assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \ldots, s_n$ (each in $\{1,2\}$) representing the valid assignment. If there are multiple valid assignments, output the one that minimizes the structural weight of the sequence, defined as $\sum_{i=1}^n s_i \cdot 3^{n-i}$. Print this assignment as a full sequence of $n$ integers.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```

<RATIONALE>
I replaced the algebraic resonance equation with a geometric condition: the sum of the shift codes must equal the number of sides of a regular Euclidean polygon with a 60-degree interior angle. Since only an equilateral triangle (3 sides) has a 60-degree interior angle, this forces $s_u + s_v = 3$, which over the domain $\{1, 2\}$ is mathematically identical to $s_u \neq s_v$. This forces the model to first solve the geometric trivia before it can recognize the underlying bipartite graph 2-coloring structure.
</RATIONALE>

The geometric condition restricts $s_u + s_v$ to exactly 3, which for variables in $\{1, 2\}$ is true if and only if $s_u \neq s_v$, perfectly preserving the original truth table for stable links.
</PRESERVED_ANSWER>
