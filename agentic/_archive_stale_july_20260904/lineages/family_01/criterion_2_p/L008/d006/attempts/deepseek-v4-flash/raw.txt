 We need to check the conditions for the graph and assign shift codes 1 or 2.

First, let’s analyze the matrix condition:

We have:
- \( A_1 = \begin{pmatrix} 1 & 2 \\ 0 & 1 \end{pmatrix} \)
- \( A_2 = \begin{pmatrix} 1 & 0 \\ 2 & 1 \end{pmatrix} \)

For a link between \(u\) and \(v\) with codes \(s_u\) and \(s_v\), we need:
\[
\text{trace}(A_{s_u} A_{s_v}) = 6
\]

Let’s compute the four possibilities:

1. \(s_u = 1, s_v = 1\):
\[
A_1 A_1 = \begin{pmatrix} 1 & 2 \\ 0 & 1 \end{pmatrix} \begin{pmatrix} 1 & 2 \\ 0 & 1 \end{pmatrix} = \begin{pmatrix} 1 & 4 \\ 0 & 1 \end{pmatrix}
\]
Trace = \(1 + 1 = 2\) → not 6.

2. \(s_u = 1, s_v = 2\):
\[
A_1 A_2 = \begin{pmatrix} 1 & 2 \\ 0 & 1 \end{pmatrix} \begin{pmatrix} 1 & 0 \\ 2 & 1 \end{pmatrix} = \begin{pmatrix} 5 & 2 \\ 2 & 1 \end{pmatrix}
\]
Trace = \(5 + 1 = 6\) → works.

3. \(s_u = 2, s_v = 1\):
\[
A_2 A_1 = \begin{pmatrix} 1 & 0 \\ 2 & 1 \end{pmatrix} \begin{pmatrix} 1 & 2 \\ 0 & 1 \end{pmatrix} = \begin{pmatrix} 1 & 2 \\ 2 & 5 \end{pmatrix}
\]
Trace = \(1 + 5 = 6\) → works.

4. \(s_u = 2, s_v = 2\):
\[
A_2 A_2 = \begin{pmatrix} 1 & 0 \\ 2 & 1 \end{pmatrix} \begin{pmatrix} 1 & 0 \\ 2 & 1 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 4 & 1 \end{pmatrix}
\]
Trace = \(1 + 1 = 2\) → not 6.

So the condition is: **adjacent workers must have different shift codes** (1 and 2).

Thus, the graph must be bipartite. If it’s not bipartite, output `NO`.

If it is bipartite, we assign 1 to one partition and 2 to the other.  
But we also need the lexicographically smallest sequence according to the weight \(\sum s_i \cdot 3^{n-i}\).  
Since 1 < 2, we want as many 1s as possible at the start.  
So we should try both color assignments (start with 1 at node 1, or start with 2 at node 1) and pick the one with smaller weight.

Implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

def try_assign(start_color):
    color = [-1] * n
    color[0] = start_color
    q = deque([0])
    ok = True
    while q and ok:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                ok = False
                break
    if not ok:
        return None
    # Check for disconnected components
    for i in range(n):
        if color[i] == -1:
            color[i] = 0
            q = deque([i])
            while q:
                u = q.popleft()
                for v in adj[u]:
                    if color[v] == -1:
                        color[v] = 1 - color[u]
                        q.append(v)
                    elif color[v] == color[u]:
                        return None
    return color

# Try both starting colors for node 0
res1 = try_assign(0)
res2 = try_assign(1)

if res1 is None and res2 is None:
    print("NO")
else:
    # Choose the one with smaller weight
    def weight(arr):
        w = 0
        for val in arr:
            w = w * 3 + (val + 1)  # since codes are 1 or 2
        return w

    if res1 is not None and res2 is not None:
        if weight(res1) <= weight(res2):
            best = res1
        else:
            best = res2
    elif res1 is not None:
        best = res1
    else:
        best = res2

    print("YES")
    print(" ".join(str(x + 1) for x in best))
```
