We can solve this by trying all possible assignments of bands 1, 2, and 3 to the stations, but since n can be up to 40, brute force over 3^n is impossible.  
However, the problem is essentially a graph coloring problem with 3 colors, and we need the lexicographically smallest coloring.  

We can use backtracking with pruning:  
- Assign colors to vertices in order 1..n.  
- At each step, try the smallest possible color (1, then 2, then 3) that doesn’t conflict with already colored neighbors.  
- If we reach a dead end, backtrack.  

Since n ≤ 40, this backtracking is feasible for most cases, especially because the graph is not necessarily dense.  

Here’s the implementation:  

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def is_safe(node, c):
    for nb in adj[node]:
        if color[nb] == c:
            return False
    return True

def solve(idx):
    if idx == n:
        return True
    for c in (1, 2, 3):
        if is_safe(idx, c):
            color[idx] = c
            if solve(idx + 1):
                return True
            color[idx] = 0
    return False

if solve(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
