We need to assign each node one of three colors (zones) such that no edge connects two nodes of the same color.  
This is exactly the **3-coloring** problem, which is NP-hard in general, but here **n ≤ 40**, so we can use backtracking with pruning.

We can solve it with a recursive backtracking that tries colors 1, 2, 3 in order for each node, ensuring lexicographically smallest assignment.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n
found = False

def backtrack(idx):
    global found
    if idx == n:
        found = True
        return True
    for c in range(1, 4):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if backtrack(idx + 1):
                return True
            color[idx] = 0
    return False

if backtrack(0):
    print("YES")
    print(" ".join(map(str, color)))
else:
    print("NO")
```
