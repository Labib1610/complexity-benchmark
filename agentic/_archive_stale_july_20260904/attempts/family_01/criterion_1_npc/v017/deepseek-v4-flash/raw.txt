We need to assign each employee to one of 3 periods such that incompatible pairs are in different periods, and among all valid assignments, we output the lexicographically smallest sequence.

Since \( n \leq 40 \), we can use a backtracking approach with pruning, trying to assign the smallest possible period to each employee in order.

We’ll represent the graph with adjacency lists, and during assignment, check that the chosen period is not used by any incompatible already-assigned neighbor.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    assignment = [0] * n
    used = [False] * n  # not really needed, but we can track assigned
    
    def backtrack(idx):
        if idx == n:
            return True
        for period in (1, 2, 3):
            # check compatibility
            ok = True
            for nb in adj[idx]:
                if assignment[nb] == period:
                    ok = False
                    break
            if ok:
                assignment[idx] = period
                if backtrack(idx + 1):
                    return True
                assignment[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, assignment)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
