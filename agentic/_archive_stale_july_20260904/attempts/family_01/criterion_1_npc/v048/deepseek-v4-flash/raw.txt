We need to assign each specialist to one of 3 cycles such that no two connected by friction are in the same cycle.  
This is equivalent to a **3-coloring** problem on a graph with up to 40 nodes.  
We also need the lexicographically smallest coloring.

Since \( n \leq 40 \), we can use **backtracking with pruning**:

- Try assigning colors 1, 2, 3 to each node in order.
- At each step, check that the color doesn’t conflict with already colored neighbors.
- If we reach the end, we have a valid coloring.
- Because we try colors in increasing order, the first complete assignment found is lexicographically smallest.

We also need to handle the case where no valid coloring exists.

Here’s the implementation:

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    colors = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in range(1, 4):
            ok = True
            for nb in adj[idx]:
                if colors[nb] == c:
                    ok = False
                    break
            if ok:
                colors[idx] = c
                if backtrack(idx + 1):
                    return True
                colors[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, colors)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
