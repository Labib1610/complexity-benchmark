We need to determine if the graph is 3-colorable, and among all valid 3-colorings, output the lexicographically smallest assignment of colors (1, 2, 3) to vertices 1..n.

Since n ≤ 40, we can use backtracking with pruning. We'll assign colors to vertices in order from 1 to n, trying colors 1, 2, 3, and check if the assignment is valid so far. We also need to ensure we don't explore symmetric color permutations unnecessarily, but since n is small and the graph is small, simple backtracking with pruning should work.

We'll implement a recursive function that assigns a color to the current vertex, checks constraints with already colored neighbors, and moves to the next vertex. If we reach the end, we have a valid coloring.

We must be careful: the lexicographically smallest assignment is found by trying colors in increasing order at each step, and the first complete assignment found is the answer.

Let's implement it.

```python
import sys

def solve():
    input = sys.stdin.readline
    n, m = map(int, input().split())
    adj = [[] for _ in range(n)]
    for _ in range(m):
        u, v = map(int, input().split())
        u -= 1
        v -= 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * n
    
    def backtrack(idx):
        if idx == n:
            return True
        for c in range(1, 4):
            ok = True
            for nb in adj[idx]:
                if nb < idx and color[nb] == c:
                    ok = False
                    break
            if ok:
                color[idx] = c
                if backtrack(idx + 1):
                    return True
                color[idx] = 0
        return False
    
    if backtrack(0):
        print("YES")
        print(" ".join(map(str, color)))
    else:
        print("NO")

if __name__ == "__main__":
    solve()
```
