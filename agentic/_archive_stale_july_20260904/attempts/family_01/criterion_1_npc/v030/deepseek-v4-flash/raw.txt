We need to assign each employee one of three phases (1, 2, or 3) such that no two employees connected by an edge have the same phase. This is a graph 3-coloring problem. Since n ≤ 40, we can use backtracking with pruning.

We also need the lexicographically smallest assignment (by employee index). So we try colors in order 1, 2, 3 for each employee.

Here’s the implementation:

```python
n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [0] * n

def backtrack(idx):
    if idx == n:
        return True
    for c in range(1, 4):
        ok = True
        for nb in adj[idx]:
            if color[nb] == c:
                ok = False
                break
        if ok:
            color[idx] = c
            if backtrack(idx + 1):
                return True
            color[idx] = 0
    return False

if backtrack(0):
    print("YES")
    print(" ".join(str(c) for c in color))
else:
    print("NO")
```
