We can model this as a bipartite graph problem.  
Each module is a node, and each contention is an edge that must connect nodes of different colors (states).  
We can use BFS/DFS to try to 2-color the graph.  

To get the lexicographically smallest configuration (favoring state 1 for lower indices), we should start BFS from the smallest uncolored node each time, assigning it state 1.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    print("NO")
                    sys.exit()

print("YES")
print(" ".join(str(color[i]) for i in range(n)))
```
