We need to solve the problem using graph bipartiteness checking, plus a greedy lexicographic assignment.

If the graph has an odd cycle, it’s not bipartite → impossible.  
If it’s bipartite, we need to assign each connected component’s coloring such that vertex 1 (if present) is assigned vessel 1 whenever possible, and overall the label sequence is lexicographically smallest.

**Approach:**

- Build adjacency list.
- For each unvisited component, run BFS/DFS to assign colors based on bipartite check.
- During checking, for each component:
  - There are two possible assignments: either start with color 0 or color 1.
  - Choose whichever gives lexicographically smaller global prefix.
- Since components are processed in order of the smallest index in them, we can decide locally: For a component containing the smallest unvisited node `v`, we set that node to 1 (color 0 in 0/1 representation) if possible, because this yields lexicographically smallest sequence. But we must consider: if assigning v=1 causes the component to have v’s opposite color as 2, that is still valid because no conflicts. So always assign the smallest node of each component to vessel 1.
- This yields the global lexicographically smallest assignment.

Implementation details:
- We use iterative DFS or BFS to avoid recursion depth issues (n up to 2e5).

---

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for start in range(n):
    if color[start] != -1:
        continue
    # BFS for bipartite check, assign start to color 0
    color[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = 1 - color[u]
                q.append(v)
            elif color[v] == color[u]:
                print("NO")
                sys.exit(0)

# Now we have a valid coloring (colors 0 and 1)
# To get lexicographically smallest sequence:
# For each connected component, if its smallest index is colored 1, flip entire component
visited = [False] * n
for i in range(n):
    if not visited[i]:
        # find component
        comp = []
        q = deque([i])
        visited[i] = True
        while q:
            u = q.popleft()
            comp.append(u)
            for v in adj[u]:
                if not visited[v]:
                    visited[v] = True
                    q.append(v)
        min_node = min(comp)
        if color[min_node] == 1:
            # flip this component
            for u in comp:
                color[u] = 1 - color[u]

# Output
print("YES")
print(' '.join(str(c + 1) for c in color))
```
