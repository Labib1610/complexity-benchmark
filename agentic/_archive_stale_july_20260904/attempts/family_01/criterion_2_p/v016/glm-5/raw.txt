Looking at this problem, we need to assign technicians to two schedules such that no incompatible pair shares the same schedule. This is a 2-coloring (bipartite checking) problem.

For the lexicographically smallest assignment, we need to be careful. The key insight is:
- For each connected component, we have two possible colorings (swap 1s and 2s)
- To get lexicographically smallest, for each component we should try to assign the smallest possible value to the smallest-indexed vertex in that component

The approach:
1. Build the graph
2. For each unvisited vertex (in order 1 to n), start BFS/DFS
3. Assign the starting vertex value 1, then alternate
4. If we detect a conflict (odd cycle), output NO
5. For lexicographically smallest: since we process vertices in order 1 to n, and assign the first unvisited vertex in each component the value 1, this gives us the lexicographically smallest result

Wait, but we need to verify this gives lexicographically smallest. Consider a component where vertex 1 is in it - we assign it 1. For other components, the smallest vertex gets 1. This is optimal because:
- For the component containing vertex 1, assigning 1 to vertex 1 is better than assigning 2
- For each subsequent component, assigning 1 to its smallest vertex is better

Actually, we need to be more careful. When we process vertices in order and a vertex is already colored, we can't change it. When we encounter an uncolored vertex, we should color it 1 (which is better than 2). This greedy approach works because coloring decisions in one component don't affect another.

import sys
from collections import deque

def solve():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(input_data[idx]); idx += 1
    m = int(input_data[idx]); idx += 1
    
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        u = int(input_data[idx]); idx += 1
        v = int(input_data[idx]); idx += 1
        adj[u].append(v)
        adj[v].append(u)
    
    color = [0] * (n + 1)
    
    for start in range(1, n + 1):
        if color[start] == 0:
            color[start] = 1
            queue = deque([start])
            while queue:
                u = queue.popleft()
                for v in adj[u]:
                    if color[v] == 0:
                        color[v] = 3 - color[u]
                        queue.append(v)
                    elif color[v] == color[u]:
                        print("NO")
                        return
    
    print("YES")
    print(' '.join(str(color[i]) for i in range(1, n + 1)))

solve()
