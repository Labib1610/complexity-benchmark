We can model this as a bipartite graph problem: each handover pair must have opposite shift values (since their sum must be 3, and shifts are 1 or 2).  

So we need to check if the graph is bipartite, and if so, assign the lexicographically smallest labeling (1 for first component, then 2 for the other side, but with smallest possible values overall).

We can do a BFS/DFS coloring, and when we have a choice, we assign the smaller value first.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(color[i]) for i in range(n)))
```
