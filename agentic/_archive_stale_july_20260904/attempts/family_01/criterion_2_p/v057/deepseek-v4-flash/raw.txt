We can model this as a bipartite graph problem:  
Each sensor is a node, and each alert is an edge.  
The condition “sum of modes = 3” means one sensor must be mode 1 and the other mode 2.  
So we need to 2-color the graph (bipartite check).  
If it’s not bipartite, output `NO`.  
If it is, we want the lexicographically smallest assignment, which means we try to assign mode 1 as early as possible, but we must respect the bipartite constraints.

We can do this with BFS/DFS, assigning colors greedily:  
For each unvisited node, start with color 1, then propagate.  
If a conflict occurs, it’s not bipartite.

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for i in range(n):
    if color[i] == -1:
        color[i] = 1
        q = deque([i])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = 3 - color[u]
                    q.append(v)
                elif color[v] == color[u]:
                    possible = False
                    break
            if not possible:
                break
    if not possible:
        break

if not possible:
    print("NO")
else:
    print("YES")
    print(" ".join(str(c) for c in color))
```
