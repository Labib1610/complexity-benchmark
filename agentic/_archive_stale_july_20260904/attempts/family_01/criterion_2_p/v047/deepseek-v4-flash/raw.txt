We need to check if the graph is bipartite and, if so, produce the lexicographically smallest assignment.

The lexicographically smallest assignment means we try to assign astronaut 1 to habitat 1, then proceed in order, assigning the smallest possible habitat number that keeps the graph bipartite.

We can do this with BFS/DFS, but to get lexicographically smallest, we process nodes in order and assign greedily, using BFS to propagate constraints.

Here’s the implementation:

```python
import sys
from collections import deque

input = sys.stdin.readline

n, m = map(int, input().split())
adj = [[] for _ in range(n)]
for _ in range(m):
    u, v = map(int, input().split())
    u -= 1
    v -= 1
    adj[u].append(v)
    adj[v].append(u)

color = [-1] * n
possible = True

for start in range(n):
    if color[start] != -1:
        continue
    color[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if color[v] == -1:
                color[v] = color[u] ^ 1
                q.append(v)
            elif color[v] == color[u]:
                possible = False
                break
        if not possible:
            break
    if not possible:
        break

if not possible:
    print("NO")
else:
    # Now we have a valid 2-coloring, but we need lexicographically smallest.
    # We'll try to flip colors in components if it makes earlier nodes smaller.
    # Since color[0] is 0, we can try to keep it 0.
    # For each component, if the node with smallest index has color 1, flip the whole component.
    visited = [False] * n
    for i in range(n):
        if not visited[i]:
            # BFS to collect component
            comp = []
            q = deque([i])
            visited[i] = True
            while q:
                u = q.popleft()
                comp.append(u)
                for v in adj[u]:
                    if not visited[v]:
                        visited[v] = True
                        q.append(v)
            # Find smallest index in component
            min_idx = min(comp)
            if color[min_idx] == 1:
                # flip
                for u in comp:
                    color[u] ^= 1

    print("YES")
    print(' '.join(str(c + 1) for c in color))
```
