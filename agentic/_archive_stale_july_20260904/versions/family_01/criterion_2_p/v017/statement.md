# Problem B — Automated Roster Generation Pipeline

Time limit: 1 s
Memory limit: 256 MB

You are implementing the core assignment module for an automated workforce management pipeline. The pipeline operates in three sequential phases:

**Phase 1: Constraint Extraction.** The HR database scans employee profiles to identify pairs of individuals who cannot be deployed at the same time. This could be due to interpersonal conflicts or overlapping specialized duties that require one person to remain on standby. The database exports a list of these incompatible pairs.

**Phase 2: The Assignment Module (Your Task).** Your software receives the total number of personnel and the list of incompatible pairs from Phase 1. The facility operates exactly two daily shifts, labeled 1 and 2. Your module must assign every individual to one of these two shifts such that no two individuals in an incompatible pair are given the same shift. 

Because the subsequent phase requires a strictly deterministic input, if there are multiple valid ways to assign the shifts, your module must select the one that results in the lexicographically smallest sequence of shift labels when reading the assignments for individuals 1 through $n$. If no valid assignment configuration exists for the two shifts, your module must trigger an abort sequence.

**Phase 3: Deployment and Payroll.** The system takes the output from your module, finalizes the roster, and calculates differential pay based on the shift labels. You do not need to implement this phase.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$) — the number of personnel and the number of incompatible pairs generated by Phase 1.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), representing an incompatible pair of individuals. 

## Output
If the assignment module must trigger an abort sequence because no valid shift configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the shift assignment for each individual, which must be the lexicographically smallest valid sequence.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```
