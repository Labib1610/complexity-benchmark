# Problem A — Phase II: Payload Routing Verification

Time limit: 5 s
Memory limit: 256 MB

## Description
The regional logistics pipeline operates in three distinct phases. 

Phase I (Demand Aggregation) compiles all daily transfer requirements. The output of Phase I is a list of distinct transfer requests, each specifying a starting facility, a receiving facility, and an exact number of discrete payload units that must be moved.

Your task is to implement Phase II (Payload Routing Verification). You are given a network of $n$ facilities connected by $m$ one-way corridors, along with the transfer requests generated by Phase I. Each corridor has a maximum payload threshold. This threshold limits the total number of payload units that can traverse the corridor in a single day, regardless of which transfer request they belong to. Because all transfers occur simultaneously, they compete for the same corridor thresholds. Payload units cannot be divided, and the number of units routed for any request on any corridor must be a non-negative integer.

For each transfer request, the number of payload units leaving the starting facility must equal the requested amount, and the same number must arrive at the receiving facility. At any other facility, the number of units for that specific transfer entering the facility must exactly equal the number of units leaving it.

Phase III (Manifest Generation) will later assign specific vehicles and drivers, but it requires a valid routing plan from Phase II. You must output a valid plan that fulfills all Phase I requests while respecting the shared corridor thresholds, or report that the network cannot support the requests.

## Input
The first line contains three integers $n$, $m$, and $k$ — the number of facilities, the number of corridors, and the number of Phase I transfer requests.

The next $k$ lines represent the Phase I output. The $i$-th of these lines contains three integers $s_i$, $t_i$, and $d_i$, representing the starting facility, receiving facility, and the required number of payload units for the $i$-th transfer request.

The next $m$ lines describe the network infrastructure. The $j$-th of these lines contains three integers $u_j$, $v_j$, and $c_j$, indicating a one-way corridor from facility $u_j$ to facility $v_j$ with a maximum payload threshold of $c_j$ units.

## Output
If Phase III can proceed, output `YES` on the first line. Then, output $k$ lines. The $i$-th line must contain $m$ integers, where the $j$-th integer is the number of payload units from the $i$-th transfer request routed through the $j$-th corridor (in the order the corridors were provided in the input). 

If the network cannot support all requests simultaneously, output `NO`.

## Example
### Input
```
4 5 2
1 4 2
2 3 1
1 2 2
2 4 2
1 3 1
3 4 1
2 3 1
```

### Output
```
YES
2 2 0 0 0
0 0 0 0 1
```
