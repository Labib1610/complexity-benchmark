# Problem A — Production Phase Allocation

Time limit: 2 s
Memory limit: 256 MB

A manufacturing plant operates three daily production phases: Phase 1, Phase 2, and Phase 3. There are $n$ workers available. To ensure safety, the plant's hazard system flags certain pairs of workers who must not be active during the same phase. 

The plant uses a strict sequential priority system to assign each worker to exactly one of the three phases. The system finalizes assignments in order, starting with worker 1 and ending with worker $n$. For any given worker, Phase 1 is the most preferred, followed by Phase 2, and finally Phase 3. 

The system operates under the following rule: when determining the assignment for worker $i$, it will assign them to the most preferred phase that still allows for at least one fully valid schedule to be completed for all remaining workers $i+1$ through $n$. If choosing Phase 1 for worker $i$ would inevitably lead to a hazard violation for some worker later in the process regardless of how subsequent assignments are made, the system evaluates Phase 2 instead, and so on. 

Your task is to determine the final schedule produced by this sequential priority system, ensuring no flagged pair of workers share a phase, or to detect if no safe schedule can be formed at all.

## Input
The first line provides two integers $n$ and $m$ — the total number of workers and the number of hazard flags ($1 \le n \le 40$, $0 \le m \le n(n-1)/2$).
The following $m$ lines each contain two integers $u$ and $v$, indicating that worker $u$ and worker $v$ cannot be assigned to the same phase.

## Output
If there is no way to assign all workers without violating the hazard rules, output a single line containing `NO`.
Otherwise, output `YES` on the first line. On the second line, output $n$ integers $s_1, s_2, \dots, s_n$ separated by spaces, where $s_i \in \{1, 2, 3\}$ represents the phase assigned to worker $i$. The sequence must represent the assignment generated by the plant's priority system.

## Example 1
Input:
```
4 5
1 2
1 3
2 3
1 4
2 4
```
Output:
```
YES
1 2 3 3
```

## Example 2
Input:
```
4 6
1 2
1 3
1 4
2 3
2 4
3 4
```
Output:
```
NO
```
