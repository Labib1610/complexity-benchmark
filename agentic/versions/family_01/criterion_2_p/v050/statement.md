# Facility Shift-Allocation Pipeline

Time limit: 1 s   Memory limit: 256 MB

The automated resource management system at a manufacturing plant processes staff scheduling through a multi-stage pipeline:

1. **Incompatibility Ingestion (Completed)**: Conflict records generated by safety supervisors are compiled into a master list of paired workers who cannot operate during the same operational block.
2. **Phase Assignment (Active Module)**: Each worker numbered $1$ through $n$ must be assigned to either operational block $1$ or operational block $2$. A valid allocation ensures that for every recorded conflict pair, the two workers are assigned to different blocks. Furthermore, to maintain deterministic scheduling, if multiple valid allocations exist, the module must output the sequence $s_1, s_2, \dots, s_n$ that is lexicographically smallest.
3. **Access Authorization (Downstream)**: The generated schedule is parsed to provision security badges for the facility doors.

Your task is to implement Module 2 (Phase Assignment). Determine if a valid allocation of operational blocks exists for all $n$ workers, and if so, produce the lexicographically smallest allocation.

## Input
The first line of the input contains two integers $n$ and $m$ ($1 \le n \le 2\cdot 10^5$, $0 \le m \le 2\cdot 10^5$) — the number of workers and the number of conflict pairs, respectively.

Each of the following $m$ lines contains two integers $u$ and $v$ ($1 \le u, v \le n$), representing a pair of workers who cannot share the same operational block.

## Output
If no valid operational block allocation exists, print a single line containing `NO`.

Otherwise, print `YES` on the first line, followed by a second line containing $n$ space-separated integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$), representing the lexicographically smallest valid allocation.

## Example 1
Input:
```
4 4
1 2
2 3
3 4
1 4
```
Output:
```
YES
1 2 1 2
```

## Example 2
Input:
```
3 3
1 2
1 3
2 3
```
Output:
```
NO
```
