# Problem B — Automated Roster Generation Pipeline

Time limit: 1 s
Memory limit: 256 MB

You are implementing the core assignment module for an automated workforce management pipeline. The pipeline operates in three sequential phases:

**Phase 1: Constraint Extraction.** The HR database scans employee profiles to identify pairs of individuals who require a handover protocol. The database exports a list of these handover pairs.

**Phase 2: The Assignment Module (Your Task).** Your software receives the total number of personnel and the list of handover pairs from Phase 1. The facility operates exactly two daily shifts, labeled 1 and 2. Your module must assign every individual to one of these two shifts. 

The assignment is subject to a strict balance mechanism: for every handover pair consisting of employee $u$ and employee $v$, their assigned shift values $s_u$ and $s_v$ must sum to exactly 3.

Because the subsequent phase requires a strictly deterministic input, if there are multiple valid configurations, your module must select the one that produces the lexicographically smallest sequence of shift values $s_1, s_2, \dots, s_n$. If no configuration of shift values can satisfy all handover rules simultaneously, your module must trigger an abort sequence.

**Phase 3: Deployment and Payroll.** The system takes the output from your module, finalizes the roster, and calculates differential pay based on the shift labels. You do not need to implement this phase.

## Input
The first line of the input provides two integers $n$ and $m$ ($1 \le n \le 2 \cdot 10^5$, $0 \le m \le 2 \cdot 10^5$) — the number of personnel and the number of handover pairs generated by Phase 1.
The following $m$ lines each contain two integers $u$ and $v$ ($1 \le u, v \le n$), representing a handover pair of individuals. 

## Output
If the assignment module must trigger an abort sequence because no valid shift configuration exists, print a single line containing `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1, s_2, \dots, s_n$ (where each $s_i \in \{1, 2\}$) representing the shift assignment for each individual, which must be the lexicographically smallest valid sequence.

## Example 1
**Input:**
```
4 4
1 2
2 3
3 4
1 4
```
**Output:**
```
YES
1 2 1 2
```

## Example 2
**Input:**
```
3 3
1 2
1 3
2 3
```
**Output:**
```
NO
```
