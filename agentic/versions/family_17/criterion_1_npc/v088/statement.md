# Problem A — Phase 2: Roster Finalization

Time limit: 5 s   Memory limit: 256 MB

## Description
The mobilization pipeline for the regional relief effort consists of three distinct phases.

**Phase 1: Vetting and Simulation.** The system processes volunteer applications and assigns sequential badge numbers from $1$ to $3q$. It then runs a synergy simulation on various combinations, eventually outputting a master list of $t$ viable three-person squad configurations. The badge numbers in each configuration are always sorted in increasing order. This phase is already complete.

**Phase 2: Roster Finalization.** Your module takes over here. It must ingest the master list from Phase 1 and attempt to activate a subset of exactly $q$ configurations. Since the field requires all $3q$ vetted volunteers, your module must ensure that every single badge number from $1$ to $3q$ is included in exactly one activated configuration. Activated configurations cannot share volunteers.

**Phase 3: Deployment.** If your module successfully generates a roster, the logistics system will assign each activated squad to a specific sector. If your module determines that no such roster is possible, the pipeline halts and triggers an alternative mobilization strategy.

Your task is to implement the Phase 2 module. Given the master list of viable configurations, determine whether a valid roster can be formed, and if so, output the activated configurations.

## Input
The first line contains two integers $q$ and $t$ ($1 \le q \le 200$, $0 \le t \le 20000$), representing the total number of squads required and the number of viable configurations generated by Phase 1.
The following $t$ lines each contain three integers $a$, $b$, and $c$ ($1 \le a < b < c \le 3q$), representing the badge numbers in one viable configuration.

## Output
If the Phase 2 module can successfully form a roster, print `YES` on the first line. On the following $q$ lines, print the three badge numbers for each configuration activated in the roster.
If no valid roster can be formed, print `NO`.

## Examples
### Example 1
Input:
```
2 3
1 2 3
4 5 6
1 4 5
```
Output:
```
YES
1 2 3
4 5 6
```
