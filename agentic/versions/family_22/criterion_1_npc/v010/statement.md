# Problem A — Coordinating the Production Run

Time limit: 5 s   Memory limit: 256 MB

## Description
A factory is preparing to execute a production run consisting of $n$ distinct operations, numbered $1$ to $n$. The production run is divided into a sequence of discrete cycles. During any single cycle, the factory can execute multiple operations, but the maximum number of operations that can occur simultaneously in one cycle is capped at $M$, which is the number of available identical operators. Each operation requires exactly one full cycle to complete. There is no benefit to leaving an operator idle, but there is also no penalty for finishing early.

Certain operations rely on materials generated by other operations. There are $m$ such dependencies. If operation $b$ needs the material from operation $a$, operation $a$ must be assigned to a cycle that occurs strictly before the cycle assigned to $b$. They cannot be executed during the same cycle, because the material from $a$ only becomes available at the start of the cycle following its completion. All operators are identical, so any operation can be handled by any operator; the only decision is which cycle each operation occurs in.

The factory is constrained by a strict limit of $T$ total cycles. You must allocate every operation to a specific cycle (numbered $1$ to $T$) such that all material dependencies are respected, no cycle is assigned more than $M$ operations, and the highest cycle number used does not exceed $T$. If no such allocation exists, you must report this. (With a small number of operators, the per-cycle capacity limit and the chains of material dependencies pull against each other, meaning an allocation that respects dependencies might still overflow the cycle capacity and vice versa.)

## Input
The first line contains four integers $n$, $M$, $T$, and $m$.
Each of the next $m$ lines contains two integers $a$ and $b$, indicating that operation $a$ must be completed in a strictly earlier cycle than operation $b$.

## Output
Print `YES` followed by $n$ integers $cycle[1..n]$ (the cycle number assigned to each operation, ranging from $1$ to $T$). If there are multiple valid allocations, you may output any of them. If no valid allocation is possible, print `NO`.

## Example

**Input**
```text
4 2 3 3
1 2
1 3
2 4
```

**Output**
```text
YES
1 2 2 3
```
