# Problem B — Sequence Accumulation

Time limit: 1 s   Memory limit: 256 MB

## Description

You are given a collection of $j$ elements. Each element has an $X$ value and a $Y$ value.

You must arrange all $j$ elements into a single sequence, using each element exactly once. Let your chosen sequence of elements be $E_1, E_2, \dots, E_j$.

For your sequence, we define two series of values, $A_k$ and $B_k$ for $1 \le k \le j$, generated by the following rules:

- $A_0 = 0$
- $B_0 = 0$
- For each step $k$ from 1 to $j$:
  $A_k = A_{k-1} + X(E_k)$
  $B_k = \max(A_k, B_{k-1}) + Y(E_k)$

Your objective is to choose the sequence that minimizes the final value $B_j$. Report this minimum possible value of $B_j$.

## Input

The first line contains a single integer $j$ ($1 \le j \le 200000$).
Each of the next $j$ lines contains two integers: the $X$ value and the $Y$ value of an element ($1 \le X, Y \le 1000000$).

## Output

Print a single integer: the smallest possible value of $B_j$ across all valid sequences.

## Examples

### Example 1

**Input**
```
3
3 2
2 4
1 3
```

**Output**
```
10
```

### Example 2

**Input**
```
1
5 3
```

**Output**
```
8
```

### Example 3

**Input**
```
3
2 2
2 2
2 2
```

**Output**
```
8
```

## Note

In Example 1, one optimal sequence places the elements in the order: 3rd element, then 2nd element, then 1st element.
- Step 1 (Element 3): $X = 1$, $Y = 3$.
  $A_1 = 0 + 1 = 1$.
  $B_1 = \max(1, 0) + 3 = 4$.
- Step 2 (Element 2): $X = 2$, $Y = 4$.
  $A_2 = 1 + 2 = 3$.
  $B_2 = \max(3, 4) + 4 = 8$.
- Step 3 (Element 1): $X = 3$, $Y = 2$.
  $A_3 = 3 + 3 = 6$.
  $B_3 = \max(6, 8) + 2 = 10$.

The final value $B_3$ is 10. No sequence yields a smaller $B_3$.
