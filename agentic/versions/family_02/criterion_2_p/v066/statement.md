# Phase 2: Telemetry Processor

Time limit: 1 s   Memory limit: 256 MB

## Description

The automated recovery sequence for a stellarator operates in three distinct phases. In Phase 1, diagnostic scanners assess the $n$ modules of the reactor and produce a list of $m$ safety interlocks that must be respected during the reboot sequence. 

Your task is to implement Phase 2. The telemetry processor must assign an operating state to each of the $n$ modules, choosing either Standard or Auxiliary for each. The interlocks provided by Phase 1 are given as pairs of target conditions. A target condition specifies a particular module and the state it should be placed in. To prevent a cascade failure, the processor must verify if there is a global assignment of states such that every single interlock has at least one of its two target conditions fulfilled.

If such an assignment is found, the processor must output it so that Phase 3 can compile the physical relay sequences and execute the reboot. If no such assignment exists among all possible combinations, the processor must abort the sequence.

## Input
The first line contains two integers $n$ and $m$ ($1 \le n \le 10^5$, $0 \le m \le 2\cdot 10^5$), representing the number of modules and the number of safety interlocks generated by Phase 1.
The next $m$ lines each contain two non-zero integers $c_1$ and $c_2$, representing the two target conditions for a safety interlock. The absolute value of an integer indicates the module's index (from 1 to $n$). A positive integer means the target condition is for that module to be in the Standard state. A negative integer means the target condition is for that module to be in the Auxiliary state.

## Output
If Phase 3 must be aborted because no valid assignment exists, print a single line `NO`.
Otherwise, print `YES` on the first line. On the second line, print $n$ integers $s_1\ s_2\ \ldots\ s_n$ separated by spaces, representing a valid assignment for the modules (where $s_i \in \{0, 1\}$). Output 1 if the $i$-th module is assigned the Standard state, or 0 if it is assigned the Auxiliary state. If multiple valid assignments exist, any of them will be accepted by Phase 3.

## Example 1
Input:
```
2 2
1 2
-1 -2
```
Output:
```
YES
1 0
```

## Example 2
Input:
```
1 2
1 1
-1 -1
```
Output:
```
NO
```
